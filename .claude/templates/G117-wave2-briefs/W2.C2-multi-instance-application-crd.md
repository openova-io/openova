## Scope (do exactly this, no more, no less)

Today the `Application` CRD treats `<blueprint, org>` as a unique pair (chart-default singleton). G117.2 needs N instances per Blueprint per Environment when `Blueprint.spec.multiInstance.enabled=true`. Concretely:

1. **Extend the `Application` CRD spec**:
   - Add `spec.instanceId` (immutable after creation; defaults to first 8 chars of `metadata.uid`)
   - Add `spec.isolationLevel` enum: `namespace` (default) | `vcluster`
   - Add `spec.namingTemplate` string with Go-template syntax (default: `{{.AppName}}-{{.InstanceID}}` for `namespace` isolation, `{{.AppName}}` for `vcluster` isolation since vCluster name already namespaces)

2. **Promote unique-key invariant** at admission:
   - When `Blueprint.spec.multiInstance.enabled=false` → reject create if any Application already exists with same `(blueprint, org)` (return 409 per OpenAPI contract)
   - When `Blueprint.spec.multiInstance.enabled=true` AND `multiInstance.maxPerOrg > 0` → reject create if existing-count ≥ `maxPerOrg`
   - When `Application.spec.name` collides with an existing instance in same Org for same Blueprint → reject 409 regardless of multiInstance flag

3. **Namespace allocation logic** (in application-controller, called BEFORE fan-out):
   - `namespace` isolation: render `namingTemplate` → that's the target namespace for ALL HRs across ALL clusters in fan-out
   - `vcluster` isolation: use existing vCluster of the Org's Environment; `namingTemplate` resolves to a chart-release-name (the chart still lands in the vCluster's default namespace, but HR names differ)
   - Namespace creation is idempotent (`metav1.CreateOptions{}` + ignore-AlreadyExists)
   - Namespace labels: `catalyst.openova.io/org=<org>`, `catalyst.openova.io/app=<name>`, `catalyst.openova.io/instance=<instanceId>`

4. **catalyst-api `POST /apps/instances` validation**:
   - Validate per OpenAPI request schema (`CreateInstanceRequest`)
   - Pre-check multi-instance gate (return 409 + `Error{code: "multi-instance-disabled", message: ...}`)
   - Pre-check maxPerOrg (return 409 + `Error{code: "max-per-org-exceeded", ...}`)
   - Pre-check name collision (return 409 + `Error{code: "name-collision", ...}`)
   - On success: create Application CR, return 201 + Application JSON per OpenAPI
