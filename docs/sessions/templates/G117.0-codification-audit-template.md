# G117.0 — hw86 codification audit + image swap to pure-main

> **Mandate**: At end of Wave-3, before EPIC #2737 closure, walk every runtime patch ever applied to the active Sovereign (default: hw86) during the G91 / G112 / G113 / G117 sprints; cross-reference each against its codifying merged-main PR; surface any uncodified patches as gaps; then swap the running container images to a clean tag of `:main` and re-verify with 4 mandatory probes.
>
> **Why** (per `feedback_validate_agent_outcomes_no_theater.md` + `feedback_zero_touch_fresh_prov_mandate.md` + the G91 manual-recovery memory pin): every `kubectl edit` / `kubectl patch` / per-Pod `kubectl exec` ever run against the live Sovereign is a divergence between "what main says the cluster should be" and "what the cluster actually is". When we swap to pure-main images without auditing first, divergences silently revert and the Sovereign breaks in ways that are hard to root-cause.
>
> **Decision tree gate** (per Section 12): if ANY row in Sections 3-8 has no codifying PR, the swap is **HELD** until those gaps are codified by follow-up PRs. NO row may be glossed over as "OK, probably codified somewhere" — that's the moral failure mode this template exists to prevent.
