- Null-guards on empty data (PR #1185 shape)

- `kubectl --dry-run=server` against a running cluster as the only validator (PR #1933 shape)

### Multi-layer RCA (Principle 16) — required in every PR body

Lead with:

- **Trigger** — what surfaced this
- **Incident management** — what kept the system alive during the bug
- **Defense** — the structural fix that makes the bug-class impossible
- **Containment** — the regression-trap (test, gate, or assertion) that prevents recurrence

Containment alone = panacea = rejected.
