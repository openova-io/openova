- **Mid-walk the mothership `catalyst-api` pod OOMKilled** (exitCode 137, restartCount 8) and restarted. **Finding: the OOM restart ROTATES the handover-JWT keypair** (the key on the ephemeral path `/var/lib/catalyst/handover-jwt-private.pem` is regenerated each boot), so a previously-valid minted token starts returning `401 unauthenticated` after a restart → must re-extract the key and re-mint. Helper auto-re-mints on 401/503. catalyst-api was stable (no new OOM) for the duration of the rendered walk.
