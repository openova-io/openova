**Result:** ✅ 13 / ❌ 3 (walked live on hw133, 2026-06-14). The Organizations menu fully replaces BSS — sidebar, parent-first row with correct `internal·corporate·showback·vcluster·Active` badges, showback panels, redirects (`/bss`, `/parent-domains`), and the Internal-kind defaults flip (showback+namespace, no voucher) + Advanced override all work. Three real failures: **(1)** new sub-orgs are **mis-badged customer/real/vcluster** even when Internal is explicitly selected (backend ignores the kind — the documented GAP, confirmed live); **(2)** **Enter org** mints a correct support-session JWT + ≤60-min banner but the target sub-org console is blank (org still Provisioning, no live deployment) so it does **not land logged-in**; **(3)** plan **Create** succeeds and the plan reaches the marketplace storefront (no redeploy) but the **console plans table stays `load plans: HTTP 404 / No plans yet`** and never shows the created row.

**Gaps:** new sub-orgs mis-badged; org-detail Users/Roles tabs not built yet; Enter-org must actually land logged in (not just redirect); console commerce plans-list GET returns 404 (storefront write path works, console read path broken).
