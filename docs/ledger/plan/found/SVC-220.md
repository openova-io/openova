# SVC-220: found and not fixed

- Rule G6 of `scripts/check-service-model.py` takes the foundation slots from its own constant `FOUNDATION`, which lacks slots 04b, 12b and 15b. After this package those three carry the label `catalyst.openova.io/ring: foundation`, so the constant and the label disagree. If G6 read the label instead, `bp-storage-ready` (slot 15b), whose chart ships no function test, would join the list `G6.foundation-without-function-test`, which the rule forbids; `bp-kured` (slot 04b) has a test. No package owns this yet.
- `scripts/generate-catalog.py` lists only the slot files named `<number>-<name>.yaml` in `bootstrapKit` (42 of 67): a slot whose prefix carries a letter (01a, 13b, 15b, 16a, ...) is not listed, so its ring is not in outputs 1 and 2 either. The wizard's generated kit list (SVC-230) reads this output.
