# FND-044: forms seen and not taken

- tools/guards/cmd/acceptance-exit/main.go (`judge`, the `skip` of `[[`): the words of `[[ ]]` are not judged, so `[[ "$(go test ./...)" = ok ]]` reads a tested command through a substitution that loses its status and is no finding.
- tools/guards/cmd/acceptance-exit/main.go (`judge`, the held substitution): a substitution kept by an assignment has the status of the last command of its list, so in `n="$(go test ./...; echo ok)" && test "$n" = ok` the `;` (or a newline) drops the status of `go test`, and the guard judges that list neither as a pipe nor as a loop: no finding.
