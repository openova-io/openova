- `clusters/_template/bootstrap-kit/01-cilium.yaml` (lines 391 to 397, `cluster.name: ${CLUSTER_MESH_NAME:=}`): the comment says the Cilium chart accepts an empty `cluster.name`. With Helm v3.18.4 it does not: Cilium 1.19.3 `templates/hubble/tls-helm/server-secret.yaml` line 3 applies `replace` to `.Values.cluster.name`, and `helm template` of `platform/cilium/chart` with the slot's values and `CLUSTER_MESH_NAME` empty stops with `invalid value; expected string`, whatever `CLUSTER_MESH_ID` is (with Helm v3.16.3 it stops only when `CLUSTER_MESH_ID` is not 0). Every provider pack writes `CLUSTER_MESH_NAME`, so no install is affected today; with a pack that left it empty, a Helm of that line would refuse slot 01. NET-121 may not change the slot; the package that next owns slot 01 should make the default a name or drop the claim from the comment.
