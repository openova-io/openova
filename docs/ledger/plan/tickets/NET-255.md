# NET-255 — Journey WAF, its corpus and gate check NET-G15 as expected-fail

## In plain words

**The problem today.** Decision record 0038 puts a web application firewall in the public path of a Sovereign, and says a firewall counts as in the path only when its proof passes. Nothing can run that proof today: there is no set of attack requests to send and no check in the acceptance suite. Without them the work that builds the firewall would have nothing to be measured against.

**What changes.** The repository gains a fixed set of 43 attack requests taken from the upstream rule set's own tests, and the acceptance suite gains the check that sends them through each firewall and judges the answers. The list of checks marks it as expected to fail for now: it runs and is recorded but cannot fail a run until the firewall exists.

**Done means:**

- A corpus of 43 attack requests is in the repository, each named after the upstream rule and test it comes from, and each is a request that the firewall denies at the lowest paranoia level in block mode.
- The check sends every request of the corpus to every public host of each firewall and fails when a host in block mode does not deny one, or a host in detect mode denies one or does not log it.
- The check fails when a listener of the protected gateway can be reached past the firewall, from a node address or from the public entry address.
- The check fails when an exclusion that expired yesterday is accepted at admission, or when one that expires tomorrow is refused, and it stores nothing while proving it.
- With no firewall object the check records one failed step named no web application firewall in the path, so a Sovereign without a firewall is never reported as proven.
- The list of checks shows the check as expected-fail, implemented by this package and delivered by NET-257.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The acceptance suite holds gate check NET-G15, "Firewall proof", in `tests/acceptance/sovereign/internal/suite/check_waf.go`, and the gate manifest lists it as `expected-fail`. The corpus `tests/waf/corpus/crs-4.14.0.txt` holds 43 requests written from the regression tests of the OWASP Core Rule Set v4.14.0, the version that `coraza-proxy-wasm` 0.6.0 pins (ADR-0038 point WF3). In a cloud run the check finds each WebApplicationFirewall object (`webapplicationfirewalls.compose.openova.io`) of each region and runs journey WAF of ADR-0038 point WF7 against the public hosts of its Gateway: WAF-1 a benign request answers 200 or a redirect, WAF-2 every corpus request to a host in mode `block` answers 403, WAF-3 every corpus request to a host in mode `detect` passes and is logged, WAF-4 no dial past the firewall connects, WAF-5 an exclusion that expired yesterday is refused at admission. With no object the check records one failed step named "no web application firewall in the path". NET-257 builds the definition and the first implementation and moves the check to `required`; this ticket does neither.

## 3. The model (the law)
1. The check is one file that calls `RegisterCheck` in `init()` and holds the literal `NET-G15`; its test is one file. No other file of the suite changes except the README. The module stays standard library only.
2. The corpus is every file `*.txt` of `tests/waf/corpus/`, read from the checkout of the candidate (`CheckContext.RepoRoot`). A line that starts with `#` is a comment; every other line is one JSON object with `rule`, `test`, `method`, `target` (it starts with `/`), and `headers` and `body` when the upstream test sends them. A line that is not such an entry, or a corpus without a request, stops the check with an error before any request.
3. Each corpus line is one positive test of `tests/regression/tests/<rule file>/<rule>.yaml` of the upstream rule set at tag v4.14.0. Each rule is a request rule of paranoia level 1 with severity `CRITICAL`, so one request reaches the inbound anomaly threshold of 5 alone and is denied at every paranoia level from 1 to 4. The protocol rules (920, 921, 922) are left out: a proxy may answer a malformed request itself with 400, which is not the firewall's answer.
4. The public hosts of an object are the host names, without a wildcard, of every HTTPRoute whose `parentRefs` name the object's Gateway (`spec.gatewayRef.name`, in the namespace of the object; a parentRef without a namespace means the namespace of the route). The mode of a host is its entry of `spec.hostOverrides`, else `spec.mode`. Every request goes to `https://<host><target>`, the path a client takes; a redirect is not followed. A Gateway without a listener, or without a public host, fails the first step of its object and the object's other steps are not run.
5. WAF-2 and WAF-3 add the query argument `net-g15=<run>-<host>-<entry>-` to each corpus request, so that a log line can be matched to its request; the ending `-` keeps entry 1 from matching entry 10. A request that gets no answer fails, and the other requests to that host are not sent.
6. The check never writes a WebApplicationFirewall object: ADR-0038 point WF6 says the object is committed through the write path of ADR-0021, never written to the cluster directly. So a run reaches mode `detect` only through a host whose `spec.hostOverrides` entry says `detect`. A mode that no host is in measured nothing and fails its step (WAF-2 or WAF-3). The entry stays `destructive: false`.
7. "Logged" in WAF-3 is read from the logs of the Pods labelled `k8s-app=cilium-envoy`, container `cilium-envoy`, of every region, over the time since the requests started plus 120 seconds: a line must hold `Coraza` and the marker of the request. `coraza-proxy-wasm` 0.6.0 writes each matched rule with the rule's `ErrorLog()`, which holds `[uri "<request target>"]`. Only `status.implementation: coraza` has a log reader in this check; an object of another implementation fails WAF-3 with that reason, and the package that ships another implementation adds its reader.
8. WAF-4 dials TCP (5 seconds each, from where the suite runs) and fails when one connects: every ExternalIP of every Node of the object's region on every listener port of the Gateway, and also on 80 and 443 for implementation `native`, whose edge nodes answer only its load balancer (ADR-0038 point WF5); every address a public host resolves to, on every listener port other than 80 and 443. With implementation `coraza` a listener of the Gateway on 80 or 443 fails: the Gateway's listeners must have moved to internal ports (point WF2). No address to dial measured nothing and fails.
9. WAF-5 sends the object back as a server-side dry-run update (`kubectl apply --server-side --dry-run=server --force-conflicts --field-manager=net-g15`), with one more exclusion (`id: net-g15-probe`, `ruleIds: [941100]`, the first public host, `pathPrefix: /net-g15-probe`, a reason, `approvedBy: NET-G15`) that expired yesterday (UTC, `YYYY-MM-DD`): it must be refused. The same with tomorrow must be accepted, so the refusal is shown to be about the date. A dry run stores nothing, as in check SEC-G07.
10. With no object in any region, or no region that serves the kind, one step named `no web application firewall in the path` fails. A Sovereign without a firewall is never reported as proven (ADR-0019 point 7); this follows check BSS-G01 (BSS-060), which fails at its first step while the run lacks what it needs, and the rule of the suite that a step that measured nothing fails.
11. No sleep, no ticker, no polling loop: every request and read is made once.
12. The manifest entry NET-G15 moves from `not-built` to `expected-fail` and gains its `implementation` line; no other field and no other entry changes.

import (
	"context"
	"encoding/json"

// Check NET-G15, Firewall proof: journey WAF of ADR-0038 point WF7 for each
// WebApplicationFirewall object of each region, on the public hosts of the
// HTTPRoutes of its Gateway, each in the mode of its hostOverrides entry or
// spec.mode. WAF-1 a GET / answers 200 or a redirect; WAF-2 each corpus
// request (tests/waf/corpus/) to a block host answers 403; WAF-3 to a detect
// host it passes and a cilium-envoy log line holds "Coraza" and its marker
// net-g15=<run>-<host>-<entry>-, <host> numbered over all objects of the run,
// so no two requests share one; WAF-4 no dial past the firewall connects;
// WAF-5 an exclusion that expired yesterday is refused at admission and one
// that expires tomorrow is not. Nothing measured fails. The rules in full are
// in tests/acceptance/sovereign/README.md.
const (
	wafID       = "NET-G15"
	wafKind     = "webapplicationfirewalls.compose.openova.io"
	wafCorpus   = "tests/waf/corpus"
	wafNoObject = "no web application firewall in the path"
)

// wafEntry is one request of the corpus.
type wafEntry struct {
	Rule    int               `json:"rule"`
	Test    int               `json:"test"`
	Method  string            `json:"method"`
	Target  string            `json:"target"`
	Headers map[string]string `json:"headers"`
	Body    string            `json:"body"`
}

type wafCheck struct {
	kubectl   kubectlFunc
	transport http.RoundTripper // nil: http.DefaultTransport
	scheme    string            // "": https
	dial      func(ctx context.Context, addr string) error
	lookup    func(ctx context.Context, host string) ([]string, error)
	now       func() time.Time
}

func init() {
	RegisterCheck(wafCheck{kubectl: kube.Region.Run, now: time.Now, lookup: net.DefaultResolver.LookupHost, dial: func(ctx context.Context, addr string) error {
		conn, err := (&net.Dialer{Timeout: 5 * time.Second}).DialContext(ctx, "tcp", addr)
		if err == nil {
			_ = conn.Close()
		}
		return err
	}})
}

func (wafCheck) ID() string { return wafID }

func (c wafCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
	if len(cc.Regions) == 0 {
		return errors.New("the run has no region")
	}
	corpus, err := loadWAFCorpus(cc.RepoRoot)
	if err != nil {
		return err
	}
	run, n, objects, numbered, seen := strings.ToLower(NewRunID(c.now())), 0, 0, 0, Evidence{}
	for _, region := range cc.Regions {
		list, err := c.list(ctx, region, wafKind, "-A")
		switch {
		case err != nil && strings.Contains(err.Error(), notServed):
			seen[region.ID] = "kind not served"
		case err != nil:
			n++
			checkStep(rec, wafID, n, "the WebApplicationFirewall objects of region "+region.ID+" are read", func(Evidence) error { return err })
		default:
			seen[region.ID] = len(list)
			for _, o := range list {
				objects++
				n, numbered = c.object(ctx, cc, rec, region, o, corpus, run, numbered, n)
			}
		}
	}
	if objects == 0 {
		checkStep(rec, wafID, n+1, wafNoObject, func(ev Evidence) error {
			ev["objects_by_region"] = seen
			return errors.New(wafNoObject + ": no WebApplicationFirewall object, so no firewall was measured")
		})
	}
	return nil
}

// object runs WAF-1 to WAF-5 for one object, whose hosts the markers number from numbered+1, and returns the last step and host numbers.
func (c wafCheck) object(ctx context.Context, cc *CheckContext, rec StepRecorder, region kube.Region, o kube.Object, corpus []wafEntry, run string, numbered, n int) (int, int) {
	ns, gw, impl := o.Namespace(), o.Str("spec", "gatewayRef", "name"), o.Str("status", "implementation")
	of := " (WebApplicationFirewall " + ns + "/" + o.Name() + ", region " + region.ID + ")"
	var hosts []string
	modes, ports := map[string]string{}, []int{}
	n++
	if !checkStep(rec, wafID, n, "the Gateway "+ns+"/"+gw+" and its public hosts are read"+of, func(ev Evidence) error {
		ev["implementation"], ev["mode"], ev["level"], ev["rule_set"] = impl, o.Str("spec", "mode"), o.Get("spec", "level"), o.Str("spec", "ruleSet", "version")
		gws, err := c.list(ctx, region, "gateways.gateway.networking.k8s.io", "-n", ns)
		if err != nil {
			return err
		}
		for _, g := range gws {
			for _, l := range g.Objects("spec", "listeners") {
				if g.Name() == gw {
					ports = append(ports, l.Int("port"))
				}
			}
		}
		routes, err := c.list(ctx, region, "httproutes.gateway.networking.k8s.io", "-A")
		if err != nil {
			return err
		}
		for _, r := range routes {
			for _, p := range r.Objects("spec", "parentRefs") {
				names, _ := r.Get("spec", "hostnames").([]any)
				for _, h := range names {
					if s, _ := h.(string); p.Str("name") == gw && nonEmpty(p.Str("namespace"), r.Namespace()) == ns && s != "" && !strings.Contains(s, "*") && modes[s] == "" {
						hosts, modes[s] = append(hosts, s), o.Str("spec", "mode")
					}
				}
			}
		}
		for _, h := range o.Objects("spec", "hostOverrides") {
			if modes[h.Str("host")] != "" && h.Str("mode") != "" {
				modes[h.Str("host")] = h.Str("mode")
			}
		}
		sort.Strings(hosts)
		ev["listener_ports"], ev["hosts"] = ports, modes
		if len(ports) == 0 || len(hosts) == 0 {
			return fmt.Errorf("the Gateway %s/%s has %d listeners and %d public hosts; nothing to measure", ns, gw, len(ports), len(hosts))
		}
		return nil
	}) {
		return n, numbered
	}
	client := &http.Client{Transport: c.transport, Timeout: 20 * time.Second,
		CheckRedirect: func(*http.Request, []*http.Request) error { return http.ErrUseLastResponse }}
	n++
	checkStep(rec, wafID, n, "WAF-1: a benign GET / of every public host answers 200 or a redirect"+of, func(ev Evidence) error {
		var bad []string
		for _, h := range hosts {
			if code, err := c.ask(ctx, client, h, wafEntry{Method: http.MethodGet, Target: "/"}, ""); err != nil || !slices.Contains(openCodes, code) {
				bad = append(bad, fmt.Sprintf("%s: HTTP %d %v", h, code, err))
			}
		}
		ev["hosts"], ev["failed"] = len(hosts), bad
		return joinFailures(bad)
	})
	for _, mode := range []string{"block", "detect"} {
		n++
		start := c.now()
		checkStep(rec, wafID, n, map[string]string{"block": "WAF-2: every corpus request to a host in mode block answers 403",
			"detect": "WAF-3: every corpus request to a host in mode detect passes and is logged"}[mode]+of, func(ev Evidence) error {
			var bad []string
			markers := map[string]string{}
		nextHost:
			for i, h := range hosts {
				for j, e := range corpus {
					if modes[h] != mode {
						break
					}
					marker, what := fmt.Sprintf("net-g15=%s-%d-%d-", run, numbered+i+1, j+1), fmt.Sprintf("%s rule %d test %d", h, e.Rule, e.Test)
					switch code, err := c.ask(ctx, client, h, e, marker); {
					case err != nil: // the host does not answer: its other requests are not sent
						bad = append(bad, what+": "+err.Error())
						continue nextHost
					case mode == "block" && code != http.StatusForbidden:
						bad = append(bad, fmt.Sprintf("%s: HTTP %d, not denied", what, code))
					case mode == "detect" && code == http.StatusForbidden:
						bad = append(bad, what+": HTTP 403, denied in mode detect")
					default:
						markers[marker] = what
					}
				}
			}
			ev["requests"] = len(markers) + len(bad)
			if len(markers)+len(bad) == 0 {
				return fmt.Errorf("no public host is in mode %s; nothing was measured", mode)
			}
			if mode == "detect" && len(markers) > 0 {
				missing, err := c.unlogged(ctx, cc.Regions, impl, markers, c.now().Sub(start))
				if err != nil {
					return err
				}
				bad = append(bad, missing...)
			}
			ev["failed"] = bad
			return joinFailures(bad)
		})
	}
	n++
	checkStep(rec, wafID, n, "WAF-4: no dial to a node or entry address reaches a listener of the Gateway past the firewall"+of, func(ev Evidence) error {
		nodes, err := c.list(ctx, region, "nodes")
		if err != nil {
			return err
		}
		var targets, bad []string
		add := func(addr string, ports ...int) {
			for _, p := range ports {
				targets = append(targets, net.JoinHostPort(addr, strconv.Itoa(p)))
			}
		}
		internal, nodePorts := slices.DeleteFunc(slices.Clone(ports), func(p int) bool { return p == 80 || p == 443 }), ports
		if impl == "native" {
			nodePorts = append(slices.Clone(ports), 80, 443)
		} else if impl == "coraza" && len(internal) < len(ports) {
			bad = append(bad, "a listener of the Gateway is on port 80 or 443, in front of the firewall")
		}
		for _, node := range nodes {
			for _, a := range node.Objects("status", "addresses") {
				if a.Str("type") == "ExternalIP" {
					add(a.Str("address"), nodePorts...)
				}
			}
		}
		for _, h := range hosts {
			addrs, err := c.lookup(ctx, h)
			if err != nil {
				return err
			}
			for _, a := range addrs {
				add(a, internal...)
			}
		}
		slices.Sort(targets)
		targets = slices.Compact(targets)
		for _, t := range targets {
			if c.dial(ctx, t) == nil {
				bad = append(bad, t+" connected")
			}
		}
		if len(targets) == 0 {
			bad = append(bad, "no address to dial; nothing was measured")
		}
		ev["dials"], ev["failed"] = targets, bad
		return joinFailures(bad)
	})
	n++
	checkStep(rec, wafID, n, "WAF-5: an exclusion whose expires is in the past is refused at admission"+of, func(ev Evidence) error {
		past := c.dryRun(ctx, region, o, hosts[0], c.now().UTC().Add(-24*time.Hour).Format(time.DateOnly))
		future := c.dryRun(ctx, region, o, hosts[0], c.now().UTC().Add(24*time.Hour).Format(time.DateOnly))
		ev["past"], ev["future"] = fmt.Sprint(past), fmt.Sprint(future)
		switch {
		case past == nil:
			return errors.New("the update with an exclusion that expired yesterday was accepted")
		case future != nil:
			return fmt.Errorf("the same update with an exclusion that expires tomorrow was refused too, so the refusal is not shown to be about the date: %v", future)
		}
		return nil
	})
	return n, numbered + len(hosts)
}

// ask sends one request to host and returns the HTTP code. A marker is added
// to the query of the target.
func (c wafCheck) ask(ctx context.Context, client *http.Client, host string, e wafEntry, marker string) (int, error) {
	target := e.Target
	if marker != "" {
		target += map[bool]string{true: "&", false: "?"}[strings.Contains(target, "?")] + marker
	}
	req, err := http.NewRequestWithContext(ctx, e.Method, nonEmpty(c.scheme, "https")+"://"+host+target, strings.NewReader(e.Body))
	if err != nil {
		return 0, err
	}
	for k, v := range e.Headers {
		req.Header.Set(k, v)
	}
	res, err := client.Do(req)
	if err != nil {
		return 0, err
	}
	defer func() { _ = res.Body.Close() }()
	return res.StatusCode, nil
}

// unlogged returns the requests of markers that no line of a cilium-envoy
// Pod's log names, read back over the time since the requests started.
func (c wafCheck) unlogged(ctx context.Context, regions []kube.Region, impl string, markers map[string]string, since time.Duration) ([]string, error) {
	if impl != "coraza" {
		return nil, fmt.Errorf("implementation %q: the check reads the log of implementation coraza only", impl)
	}
	var lines []string
	for _, region := range regions {
		pods, err := c.list(ctx, region, "pods", "-A", "-l", "k8s-app=cilium-envoy")
		if err != nil {
			return nil, err
		}
		for _, p := range pods {
			out, err := c.kubectl(region, ctx, nil, "logs", "-n", p.Namespace(), p.Name(), "-c", "cilium-envoy", "--since="+strconv.Itoa(int(since.Seconds())+120)+"s")
			if err != nil {
				return nil, err
			}
			lines = append(lines, strings.Split(string(out), "\n")...)
		}
	}
	var missing []string
	for marker, what := range markers {
		if !slices.ContainsFunc(lines, func(l string) bool { return strings.Contains(l, "Coraza") && strings.Contains(l, marker) }) {
			missing = append(missing, what+": passed but not logged")
		}
	}
	sort.Strings(missing)
	return missing, nil
}

// dryRun sends the object back with one more exclusion that expires on day,
// as a server-side dry-run update, and returns the refusal or nil.
func (c wafCheck) dryRun(ctx context.Context, region kube.Region, o kube.Object, host, day string) error {
	s, _ := o.Get("spec").(map[string]any)
	spec := map[string]any{}
	maps.Copy(spec, s)
	ex, _ := spec["exclusions"].([]any)
	spec["exclusions"] = append(slices.Clone(ex), map[string]any{"id": "net-g15-probe", "ruleIds": []int{941100}, "host": host,
		"pathPrefix": "/net-g15-probe", "reason": "admission probe of gate check NET-G15, never stored", "approvedBy": "NET-G15", "expires": day})
	body, err := json.Marshal(map[string]any{"apiVersion": o.Str("apiVersion"), "kind": o.Str("kind"),
		"metadata": map[string]any{"name": o.Name(), "namespace": o.Namespace()}, "spec": spec})
	if err != nil {
		return err
	}
	_, err = c.kubectl(region, ctx, strings.NewReader(string(body)), "apply", "--server-side", "--dry-run=server", "--force-conflicts", "--field-manager=net-g15", "-f", "-")

}

func (c wafCheck) list(ctx context.Context, region kube.Region, resource string, scope ...string) ([]kube.Object, error) {
	out, err := c.kubectl(region, ctx, nil, append(append([]string{"get", resource}, scope...), "-o", "json")...)
	if err != nil {
		return nil, err
	}
	var l kube.List
	if err := json.Unmarshal(out, &l); err != nil {
		return nil, fmt.Errorf("[%s] the list of %s is not JSON: %v", region.ID, resource, err)
	}
	return l.Items, nil
}

// loadWAFCorpus reads every file *.txt of the corpus folder under root.
func loadWAFCorpus(root string) ([]wafEntry, error) {
	files, _ := filepath.Glob(filepath.Join(root, wafCorpus, "*.txt"))
	var corpus []wafEntry
	for _, name := range files {
		text, err := os.ReadFile(filepath.Clean(name))
		if err != nil {
			return nil, err
		}
		for i, line := range strings.Split(string(text), "\n") {
			var e wafEntry
			if t := strings.TrimSpace(line); t == "" || strings.HasPrefix(t, "#") {
				continue
			} else if err := json.Unmarshal([]byte(t), &e); err != nil || e.Rule <= 0 || e.Method == "" || !strings.HasPrefix(e.Target, "/") {
				return nil, fmt.Errorf("%s line %d is not a corpus entry with rule, method and target: %v", name, i+1, err)
			}
			corpus = append(corpus, e)
		}
	}
	if len(corpus) == 0 {
		return nil, fmt.Errorf("the corpus %s holds no request", wafCorpus)
	}
	return corpus, nil
}

// joinFailures is nil for no failure, else one error that names the first ten.
func joinFailures(bad []string) error {
	if len(bad) > 10 {
		bad = append(bad[:10:10], fmt.Sprintf("and %d more", len(bad)-10))
	}
	if len(bad) == 0 {
		return nil
	}
	return errors.New(strings.Join(bad, "; "))
}

func wafRun(t *testing.T, f *wafFake, root string) (failed []string, reason string) {
	c := wafCheck{kubectl: f.kubectl, scheme: "http", transport: f,
		dial: func(_ context.Context, addr string) error {
			return map[bool]error{true: nil, false: errors.New("connection refused")}[addr == f.connects]

		now:    func() time.Time { return time.Date(2026, 11, 19, 10, 0, 0, 0, time.UTC) }}
	r := &runner{out: io.Discard, run: &Run{Mode: "run"}}
	r.runChecks(context.Background(), &Manifest{Checks: []ManifestCheck{entry(wafID, StateExpectedFail)}}, []Check{c},
		&CheckContext{Regions: []kube.Region{{ID: "region-a"}, {ID: "region-b"}}, RepoRoot: root}, true)
	for _, s := range r.run.Steps {
		if s.Status == Fail {
			failed, reason = append(failed, strings.SplitN(s.Name, ":", 2)[0]), reason+s.Error+"\n"
		}
	}
	if (r.run.Checks[0].Status == Pass) != (len(failed) == 0) {
		t.Errorf("check status %s with failed steps %v", r.run.Checks[0].Status, failed)
	}
	return failed, reason
}
