# PRD-206 — cortex screens

## In plain words

**The problem today.** The knowledge hub has its routes for search, upload, documents, job events and answers, but no screen. People of an Organization cannot add a source, upload a file, follow its indexing or ask an assistant without writing requests by hand, and a definition must never be changed anywhere but through the platform's Application route.

**What changes.** The product gains its own screens. Documents, jobs and questions go to cortex with the signed-in user's token; sources and assistants are saved only as a change of the Application's parameters, guarded by the version the screen read.

**Done means:**

- A person signed in to the Organization's realm sees the sources with their indexing state, uploads a file with or without its own readers, follows each job as it changes and asks an assistant, whose answer lists its citations.
- Adding or removing a source or an assistant sends the whole parameters to the Application update route with If-Match set to the version read, and the bindings exactly as read.
- When the Application changed since the screen read it, nothing is overwritten: the screen reloads it, lists where the refused save and the stored parameters differ, and offers the draft again.
- An Application route that returns no version gets no save at all.
- The screens load no third-party code: TypeScript compiled by tsc, tested with node's own test runner.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`products/cortex/ui` holds the screens of `bp-cortex`: Sources, Upload, Documents, Jobs and Assistants. They are TypeScript compiled by `tsc` into ES modules beside the tracked `web/index.html` and `web/styles.css`, with no runtime dependency and no bundler; `embed.go` (package `ui`, variable `Web`) embeds `web/` for a binary that serves them. The screens sign on against the Organization's realm with the authorisation-code flow and PKCE, read their settings from `web/config.json`, and call cortex with the user's token. A source or an assistant is a definition, so it is never sent to cortex: every save is `PUT {platformURL}/api/v1/sovereigns/{sovereign}/applications/{application}?namespace={namespace}` with the whole `spec.parameters`, `If-Match` set to the `ETag` the screen read and `bindings` exactly as read; on 409 `conflict` or 412 the screen reloads the Application and shows the difference. A person sees it this way: the check `work-package / acceptance` is green, and the test run prints `ℹ pass 41` and `ℹ fail 0`.

## 3. The model (the law)
1. Every change of a source or an assistant is one call of the Application update route: method `PUT`, the address of item 2 of field 5, header `If-Match` with the `ETag` of the last read, header `Authorization: Bearer <user token>`, body `{"parameters": <the whole spec.parameters>}`. No other route receives a definition.
2. `bindings` is sent exactly as read, also when an edit changed it; an Application read without `bindings` is saved without it.
3. A read of the Application that carries no `ETag` refuses with `no-version-from-the-application-route`, and the screens then save nothing: no save without a version.
4. A save answered 412, or 409 with the error code `conflict`, reloads the Application and raises a conflict that carries the Application as stored now and the differences between the refused save and it; the screen shows them and keeps the draft in its form. A list of definitions is compared by `id` (a path reads `sources[board].title`). Any other refusal, 409 `managed-by-git` included, is shown with its code and detail and nothing is reloaded.
5. A source and an assistant are checked before the save against the Blueprint's `configSchema`: the id pattern `^[a-z][a-z0-9-]{1,40}$` and uniqueness, a title of 1 to 120 characters, the parser `documents` or `text`, at least one manager, the principal forms of `access.readers` and `access.managers`, instructions of at most 8000 characters, at least one defined source with a tier `primary`, `secondary` or `fallback`, `topK` 1 to 50. A source that an assistant reads is not removed.
6. Upload is `POST /v1/sources/{id}/documents` with one part `file` and one part `reader` per principal; with no reader the document has the readers of its source.
7. The job stream `GET /v1/events` is read from a fetch body (the browser's EventSource cannot send the token). A frame `event: job` is listed (newest first, at most 200) and makes the screen refetch the sources, and the document when it is shown. When the server ends the stream it is opened again after 5 seconds. There is no timer that polls.
8. A 401 from any route starts the sign-on again. The token lives in the tab's session storage only.
9. The browser loads no third-party code: `package.json` has no `dependencies`; its two `devDependencies` are `typescript` and `@types/node`.

+# cortex screens
+
+The screens of `bp-cortex` for the people of one Organization: sources, upload, documents, live
+job state and assistants. TypeScript compiled by `tsc` to ES modules the browser loads as they
+are; no runtime dependency and no bundler.
+
+## What each screen calls
+
+| Screen | Reads | Writes |
+|---|---|---|
+| Sources | the Application's `spec.parameters.sources`, `GET /v1/sources` | the Application update route |
+| Upload | the upload sources of the parameters | `POST /v1/sources/{id}/documents` (`file`, optional `reader` parts) |
+| Documents | `POST /v1/search`, `GET /v1/documents/{id}`, `GET /v1/documents/{id}/content` | `DELETE /v1/documents/{id}` |
+| Jobs | `GET /v1/events` (a frame is a hint: the screens refetch) | none |
+| Assistants | `spec.parameters.assistants`, `GET /v1/models` | the Application update route; `POST /v1/chat/completions` |
+
+A source or an assistant is a definition, so it is never sent to cortex. Every save is
+`PUT {platformURL}/api/v1/sovereigns/{sovereign}/applications/{application}?namespace={namespace}`
+with the whole `spec.parameters`, the version the screen read (`ETag`) in `If-Match`, and
+`bindings` exactly as read. On 409 `conflict` or 412 the screen reloads the Application, lists where the
+refused save and the stored parameters differ, and offers the draft again. An Application route
+that returns no `ETag` gets no save at all.
+
+Every call carries the signed-in user's access token. Sign-on is the authorisation-code flow with
+PKCE against the Organization's realm, as the public registration `clientId`; the token is kept in
+the tab's session storage.
+
+## Settings
+
+The release that serves `web/` writes `web/config.json`:
+
+```json
+{"issuerURL": "https://<realm issuer>", "clientId": "cortex", "cortexURL": "",
+ "platformURL": "https://<platform API>", "sovereign": "<id>", "application": "<name>", "namespace": "<namespace>"}
+```
+
+`cortexURL` empty means the screens and cortex share an origin.
+

+  applications: Applications;
+  redraw: () => void;
+  confirm: (question: string) => boolean;
+  save: (content: Blob, name: string) => void; // hands a file to the browser
+  later: (work: () => void, ms: number) => void;
+  signIn: () => void; // the token was refused: sign on again

+const JOBS_KEPT = 200;

+export function createApp(d: Deps): { state: State; actions: Actions; start(): Promise<void> } {
+  const state = emptyState();
+
+  // failure returns the line to show, or null when the token was refused and sign-on restarts.
+  const failure = (err: unknown): string | null => {
+    if (err instanceof ApiError && err.status === 401) {
+      d.signIn();
+      return null;
+    }
+    return describe(err);
+  };
+
+  const run = async (work: () => Promise<void>): Promise<void> => {
+    state.busy = true;
+    state.message = "";
+    d.redraw();
+    try {
+      await work();
+    } catch (err) {
+      state.message = failure(err) ?? "";
+    } finally {
+      state.busy = false;
+      d.redraw();
+    }
+  };
+
+  // change saves edit to the Application. On a conflict the Application is replaced by the one
+  // stored now and the differences are shown; the draft stays so the form offers it again.
+  const change = async (edit: (p: Params) => Params, done: string): Promise<boolean> => {
+    if (!state.app) throw new Error("the Application is not loaded, so nothing can be saved");
+    try {
+      state.app = await d.applications.save(state.app, edit);
+    } catch (err) {
+      if (!(err instanceof Conflict)) throw err;
+      state.app = err.current;
+      state.conflict = err.differences;
+      state.message = "Not saved: the Application changed since it was read.";
+      return false;
+    }
+    state.conflict = null;
+    state.message = done;
+    return true;
+  };
+

+  let again = false;
+  const refreshSources = async (): Promise<void> => {
+    if (refreshing) {
+      again = true;
+      return;
+    }
+    refreshing = true;
+    try {
+      do {
+        again = false;
+        state.sources = await d.cortex.sources();
+      } while (again);
+    } finally {
+      refreshing = false;
+      d.redraw();
+    }
+  };
+

+    const doc = await d.cortex.document(id);
+    state.documents = [doc, ...state.documents.filter((x) => x.id !== id)];
+  };
+

+    state.jobs = [e, ...state.jobs].slice(0, JOBS_KEPT);
+    d.redraw();

+    if (e.documentId && state.documents.some((x) => x.id === e.documentId)) {
+      void remember(e.documentId)
+        .catch(() => (state.documents = state.documents.filter((x) => x.id !== e.documentId)))
+        .finally(d.redraw);
+    }

+        return;
+      }
+    }
+    state.live = false;
+    d.redraw();
+    d.later(() => void stream(), REOPEN_MS);
+  };

+    show(tab) {
+      state.tab = tab;
+      d.redraw();
+    },
+    addSource: (s) =>

+        state.draftSource = s;
+        if (problems.length > 0) {
+          state.message = problems.join("; ");
+          return;
+        }
+        if (await change((p) => withSource(p, s), `Saved: source ${s.id}. It appears when the release is applied.`)) state.draftSource = null;
+      }),
+    removeSource: (id) =>
+      run(async () => {
+        if (!d.confirm(`Remove source ${id}? Its documents, passages and originals are deleted.`)) return;
+        await change((p) => withoutSource(p, id), `Saved: source ${id} removed.`);
+      }),
+    addAssistant: (a) =>

+        const problems = state.app ? assistantProblems(a, state.app.parameters) : [];
+        state.draftAssistant = a;
+        if (problems.length > 0) {
+          state.message = problems.join("; ");
+          return;
+        }
+        if (await change((p) => withAssistant(p, a), `Saved: assistant ${a.id}.`)) state.draftAssistant = null;
+      }),
+    removeAssistant: (id) =>
+      run(async () => {
+        if (!d.confirm(`Remove assistant ${id}?`)) return;
+        await change((p) => withoutAssistant(p, id), `Saved: assistant ${id} removed.`);
+      }),
+    upload: (sourceId, file, readers) =>
+      run(async () => {
+        const bad = readers.filter((r) => !READER.test(r));
+        if (bad.length > 0) {
+          state.message = `Not a reader: ${bad.join(", ")}`;
+          return;
+        }
+        const res = await d.cortex.upload(sourceId, file, file.name, readers);
+        state.message = `Uploaded ${file.name}: document ${res.documentId}, job ${res.jobId}.`;
+        await remember(res.documentId);
+      }),
+    search: (query) =>
+      run(async () => {
+        state.hits = await d.cortex.search(query);
+        if (state.hits.length === 0) state.message = "Nothing found that you may read.";
+      }),
+    open: (id) =>
+      run(async () => {
+        await remember(id);
+        state.tab = "documents";
+      }),
+    download: (id) =>
+      run(async () => {
+        const doc = state.documents.find((x) => x.id === id);
+        d.save(await d.cortex.content(id), doc?.title || id);
+      }),
+    remove: (id) =>
+      run(async () => {
+        if (!d.confirm(`Delete document ${id}?`)) return;
+        const res = await d.cortex.remove(id);
+        state.message = `Deletion queued as job ${res.jobId}.`;
+      }),
+    ask: (assistant, question) =>
+      run(async () => {
+        state.answer = null;
+        state.answer = await d.cortex.ask(assistant, question);
+      }),
+  };
+
+  const start = async (): Promise<void> => {
+    const failed: string[] = [];
+    const take = async <T>(what: string, p: Promise<T>, set: (v: T) => void): Promise<void> => {
+      try {
+        set(await p);
+      } catch (err) {
+        const line = failure(err);
+        if (line !== null) failed.push(`${what}: ${line}`);
+      }
+    };
+    await Promise.all([
+      take("Application", d.applications.load(), (v) => (state.app = v)),
+      take("sources", d.cortex.sources(), (v) => (state.sources = v)),
+      take("assistants", d.cortex.models(), (v) => (state.models = v)),
+    ]);
+    state.message = failed.join(" | ");
+    d.redraw();
+    void stream();
+  };
+
+  return { state, actions, start };
+}

+// Conflict is a save refused because the Application changed after it was read.
+export class Conflict extends Error {
+  constructor(
+    readonly current: Loaded,
+    readonly differences: Difference[],
+  ) {
+    super("the Application changed since it was read");
+  }
+}
+
+export class Applications {
+  constructor(
+    private readonly cfg: Config,
+    private readonly token: () => string,
+    private readonly fetchFn: Fetch,
+  ) {}
+
+  url(): string {
+    const c = this.cfg;
+    const path = `/api/v1/sovereigns/${encodeURIComponent(c.sovereign)}/applications/${encodeURIComponent(c.application)}`;
+    return `${c.platformURL}${path}?namespace=${encodeURIComponent(c.namespace)}`;
+  }
+
+  async load(): Promise<Loaded> {
+    const res = await call(this.fetchFn, this.token, this.url());
+    const etag = res.headers.get("ETag");
+    // Without a version a save could overwrite another person's; the screens then do not save.
+    if (!etag) throw new ApiError(res.status, "no-version-from-the-application-route");
+    const body = (await res.json()) as { parameters?: Params };
+    return { parameters: body.parameters ?? {}, etag };
+  }
+
+  // save sends edit applied to what was read. It returns the Application as stored after the
+  // save, or throws Conflict with the Application as it is now.
+  async save(read: Loaded, edit: (p: Params) => Params): Promise<Loaded> {
+    const next: Params = { ...edit(structuredClone(read.parameters)) };
+    if ("bindings" in read.parameters) next.bindings = structuredClone(read.parameters.bindings);
+    else delete next.bindings;
+    try {
+      await callJSON(this.fetchFn, this.token, this.url(), {
+        method: "PUT",
+        headers: { "Content-Type": "application/json", "If-Match": read.etag },
+        body: JSON.stringify({ parameters: next }),
+      });
+    } catch (err) {
+      if (err instanceof ApiError && (err.status === 412 || (err.status === 409 && err.code === "conflict"))) {
+        const current = await this.load();
+        throw new Conflict(current, diff(next, current.parameters));
+      }
+      throw err;
+    }
+    return this.load();
+  }
+}

+// registration, no secret. The access token lives in the tab's session storage only.
+
+import type { Config } from "./config.js";
+import type { Fetch } from "./http.js";
+
+export interface Endpoints {
+  authorization_endpoint: string;
+  token_endpoint: string;
+}
+export interface Session {
+  token: string;
+  expiresAt: number; // milliseconds since the epoch
+}
+export type Store = Pick<Storage, "getItem" | "setItem" | "removeItem">;
+
+const SESSION = "cortex.session";
+const PENDING = "cortex.signin";
+
+function base64url(bytes: Uint8Array): string {
+  let s = "";
+  for (const b of bytes) s += String.fromCharCode(b);
+  return btoa(s).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
+}
+
+export function randomString(): string {
+  return base64url(crypto.getRandomValues(new Uint8Array(32)));
+}
+
+export async function challengeOf(verifier: string): Promise<string> {
+  const digest = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(verifier));
+  return base64url(new Uint8Array(digest));
+}
+
+export async function discover(cfg: Config, fetchFn: Fetch): Promise<Endpoints> {
+  const res = await fetchFn(`${cfg.issuerURL}/.well-known/openid-configuration`);
+  if (!res.ok) throw new Error(`sign-on discovery: HTTP ${res.status}`);
+  const doc = (await res.json()) as Partial<Endpoints>;
+  if (!doc.authorization_endpoint || !doc.token_endpoint) throw new Error("sign-on discovery: endpoints missing");
+  return { authorization_endpoint: doc.authorization_endpoint, token_endpoint: doc.token_endpoint };
+}
+
+// signInURL remembers a new verifier and state and returns the address to send the browser to.
+export async function signInURL(cfg: Config, ep: Endpoints, redirectURI: string, store: Store): Promise<string> {
+  const verifier = randomString();
+  const state = randomString();
+  store.setItem(PENDING, JSON.stringify({ verifier, state }));
+  const q = new URLSearchParams({
+    response_type: "code",
+    client_id: cfg.clientId,
+    redirect_uri: redirectURI,
+    scope: "openid",
+    state,
+    code_challenge: await challengeOf(verifier),
+    code_challenge_method: "S256",
+  });
+  return `${ep.authorization_endpoint}?${q}`;
+}
+
+// finishSignIn trades the code of the redirect for a token. A state that is not the one this tab
+// started is refused, and the remembered verifier is used once.
+export async function finishSignIn(
+  cfg: Config,
+  ep: Endpoints,
+  params: URLSearchParams,
+  redirectURI: string,
+  store: Store,
+  fetchFn: Fetch,
+  now: number,
+): Promise<Session> {
+  const pending = JSON.parse(store.getItem(PENDING) ?? "null") as { verifier: string; state: string } | null;
+  store.removeItem(PENDING);
+  const code = params.get("code");
+  if (!pending || !code || params.get("state") !== pending.state) throw new Error("sign-on: the answer does not belong to this tab");
+  const res = await fetchFn(ep.token_endpoint, {
+    method: "POST",
+    headers: { "Content-Type": "application/x-www-form-urlencoded" },
+    body: new URLSearchParams({
+      grant_type: "authorization_code",
+      code,
+      redirect_uri: redirectURI,
+      client_id: cfg.clientId,
+      code_verifier: pending.verifier,
+    }),
+  });
+  if (!res.ok) throw new Error(`sign-on: HTTP ${res.status}`);
+  const body = (await res.json()) as { access_token?: string; expires_in?: number };
+  if (!body.access_token || typeof body.expires_in !== "number") throw new Error("sign-on: no access token");
+  const session = { token: body.access_token, expiresAt: now + body.expires_in * 1000 };
+  store.setItem(SESSION, JSON.stringify(session));
+  return session;
+}
+
+// currentSession is the stored session, or null when there is none or it has expired.
+export function currentSession(store: Store, now: number): Session | null {
+  const s = JSON.parse(store.getItem(SESSION) ?? "null") as Session | null;
+  if (!s || typeof s.token !== "string" || !(s.expiresAt > now)) return null;
+  return s;
+}
+
+export function signOut(store: Store): void {
+  store.removeItem(SESSION);
+}

+// parseFrames takes the complete frames out of text and returns them with the incomplete rest.
+export function parseFrames(text: string): { frames: Frame[]; rest: string } {
+  const blocks = text.replace(/\r\n?/g, "\n").split("\n\n");
+  const rest = blocks.pop() ?? "";
+  const frames: Frame[] = [];
+  for (const block of blocks) {
+    let event = "message";
+    const data: string[] = [];
+    for (const line of block.split("\n")) {
+      if (line.startsWith(":") || line === "") continue;
+      const i = line.indexOf(":");
+      const field = i < 0 ? line : line.slice(0, i);
+      const value = i < 0 ? "" : line.slice(i + 1).replace(/^ /, "");
+      if (field === "event") event = value;
+      else if (field === "data") data.push(value);
+    }
+    if (data.length > 0) frames.push({ event, data: data.join("\n") });
+  }
+  return { frames, rest };

+// One call with the signed-in user's token. A refused call becomes an ApiError that carries the
+// status, the error code of the body ({"error": "<code>", "detail": "<text>"}) and Retry-After,
+// so a screen can name the reason.
+
+export type Fetch = typeof fetch;
+
+export class ApiError extends Error {
+  constructor(
+    readonly status: number,
+    readonly code: string,
+    readonly detail = "",
+    readonly retryAfter: string | null = null,
+  ) {
+    super(`${code} (HTTP ${status})`);
+  }
+}
+
+export async function call(fetchFn: Fetch, token: () => string, url: string, init: RequestInit = {}): Promise<Response> {
+  const headers = new Headers(init.headers);
+  headers.set("Authorization", `Bearer ${token()}`);
+  const res = await fetchFn(url, { ...init, headers });
+  if (res.ok) return res;
+  let code = `http-${res.status}`;
+  let detail = "";
+  try {
+    const body = (await res.json()) as { error?: unknown; detail?: unknown };
+    if (typeof body.error === "string" && body.error !== "") code = body.error;
+    if (typeof body.detail === "string") detail = body.detail;
+  } catch {
+    // a body that is not JSON keeps the code http-<status>
+  }
+  throw new ApiError(res.status, code, detail, res.headers.get("Retry-After"));
+}
+
+export async function callJSON<T>(fetchFn: Fetch, token: () => string, url: string, init: RequestInit = {}): Promise<T> {
+  return (await (await call(fetchFn, token, url, init)).json()) as T;
+}
+
+// describe turns an error into the line a screen shows.
+export function describe(err: unknown): string {
+  if (err instanceof ApiError) {
+    const detail = err.detail ? `: ${err.detail}` : "";
+    const wait = err.retryAfter ? `; try again in ${err.retryAfter} s` : "";
+    return `Refused: ${err.code}${detail}${wait}`;
+  }
+  return err instanceof Error ? err.message : String(err);
+}

+    return keys.flatMap((k) => diff(yours[k], stored[k], at(k, false)));
+  }

+    handle(formData(e.currentTarget));
+  };

+  const v = form.get(name);
+  return typeof v === "string" ? v.trim() : "";
