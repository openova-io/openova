# FND-104 — Truth patch of the canonical documents

## In plain words

**The problem today.** The status and architecture documents carry hand-written tables of components, bootstrap slots and custom resources that no longer match the tree. Several documents also say things that are not true: recovery within 30 seconds after the loss of a region, compliance mappings published per control, session recordings kept on object storage, a compliance dashboard for each Organization, and a public readme that calls the control plane placeholders and names a provisioner service, a workload identity and licence files that do not exist.

**What changes.** The hand-written inventories give way to state lines and links to the generated files, and each false statement is removed or replaced by a true one. The highest allowed number of unmarked sections falls by the seven sections that gain a state line.

**Done means:**

- Sections 1 to 4 and 8 of the status document and section 9 of the architecture document each start with a built state line and point at a generated inventory instead of a hand-written table.
- The definition of done no longer promises recovery within 30 seconds after the loss of a region; it says recovery takes minutes, by a promotion that a sovereign-admin approves.
- The compliance section of the security document and the Organization dashboard section of the SRE handbook are marked target with decision record 0029, and the claims of published mappings and chaos testing are gone.
- The architecture document no longer says that session recordings are kept on SeaweedFS.
- The public readme no longer calls the control plane placeholders and no longer names SPIRE as the workload identity, a provisioner host or a licence file per component.
- The baseline of unmarked sections is 52, and the check of the canonical documents passes.

The rest of this ticket is the exact instruction for the model that does the work.

def apply(text, edit):
    kind = edit[0]
    if kind == "section":
        start, end, count, headings, new = edit[1:]
        lines = text.split("\n")
        if lines.count(start) != 1:
            return None, "the line %r occurs %d times, not once" % (start, lines.count(start))
        if lines.count(end) != 1:
            return None, "the line %r occurs %d times, not once" % (end, lines.count(end))
        a, b = lines.index(start), lines.index(end)
        if b < a:
            return None, "the line %r comes before %r" % (end, start)
        block = lines[a:b]
        if len(block) != count:
            return None, "the block from %r to %r has %d lines, not %d" % (start, end, len(block), count)
        found = [x for x in block if x.startswith("## ") or x.startswith("### ")]
        if found != headings:
            return None, "the block from %r holds the headings %r, not %r" % (start, found, headings)
        return "\n".join(lines[:a]) + "\n" + new + "\n".join(lines[b:]), None
    if kind == "text":
        old, new = edit[1:]
        n = text.count(old)
        if n != 1:
            return None, "the text %r occurs %d times, not once" % (old[:80], n)
        return text.replace(old, new), None
    if kind == "first-line":
        old, new = edit[1:]
        first, sep, rest = text.partition("\n")
        if first != old:
            return None, "the first line is %r, not %r" % (first, old)
        return new + sep + rest, None
    return None, "unknown kind %r" % kind
