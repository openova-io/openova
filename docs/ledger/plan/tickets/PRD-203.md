# PRD-203 — cortex query process: token check, gateway client, search, definitions loader

## In plain words

**The problem today.** The document search of the AI hub has a database layer and nothing that serves it. No process checks who calls, no code reaches the platform's model gateway, and nothing loads the sources an Organization defines into the store. The product guard has no rule over the code of this product yet.

**What changes.** A query process serves the search and the list of sources, checks every call against a token of the Organization's sign-in realm, and reaches models only through the gateway. A loader applies the defined sources to the store, and two guard rules keep every route authenticated and the product code free of unsafe patterns.

**Done means:**

- A call to the search or the sources route without a token, with an expired token or with a token for another audience is refused with 401, and a test that walks every route of the router proves it.
- A search returns only passages of documents the caller may read, and naming a source the caller cannot read is refused with 403.
- The query is embedded, and reranked when asked, through the platform's model gateway with the key read from its mounted file; when the gateway fails the search answers 503.
- No log line holds the text of a search, even when the gateway repeats that text in an error.
- A change of the sources in the definitions ConfigMap reaches the store without a restart, an invalid version changes nothing, and a write that failed is tried again.
- The product guard turns red when the cortex router test is missing, and when product Go code skips TLS verification, formats SQL, reads a credential from the environment, starts another program or allows every origin.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`products/cortex` gains the query process and the packages it is built from. `cortex query` (in `cmd/cortex`) applies the store's migrations, opens the store with the role `cortex_query`, and serves `POST /v1/search` and `GET /v1/sources` on `--listen` behind the token check of `internal/auth`, and `GET /healthz`, `GET /readyz` and `GET /metrics` on `--health-listen`, a listener that no route publishes. `internal/auth` checks a token of the Organization's realm (format, algorithm, signature against the realm's key set found through the issuer's OpenID configuration, issuer, audience `cortex`, expiry) and derives the caller's principals. `internal/gateway` calls the model gateway's `/embeddings` and `/rerank` with the virtual key read from its file on every call. `internal/search` checks the sources asked for against those the caller reads, embeds the query, runs the store's trimmed search, reranks and adds each hit's title and address. `internal/httpapi` is the router; its test `TestEveryRouteAuthenticated` walks every route, and `TestNoQueryTextIsLogged` proves that no search text reaches the log. `internal/definitions` parses the sources of the definitions ConfigMap and a loader watches that ConfigMap with an informer and calls `ApplyDefinitions`; the index process of PRD-204 runs it. The store port gains `Sources` and `Documents`, both trimmed by row-level security, and `Postgres.Ping`. `scripts/check-products.py` extends rule G-P4 to cortex and adds rule G-P5. A person sees it this way: the checks `go vet and go test — products/cortex` and `go test with PostgreSQL — products/cortex` are green on the pull request, and `python3 scripts/check-products.py` prints `G-P5=0`.

## 3. The model (the law)
1. Every route of `--listen` answers only a call whose bearer token passes these checks, in order: a compact JWS whose header and claims are JSON objects and whose header has no `crit`; `alg` is `RS256`, `PS256` or `ES256`; `kid` names a key of the realm's key set whose type fits `alg` (an RSA key of 2048 bits or more for `RS256` and `PS256`, a P-256 key for `ES256`) and whose own `alg`, when it has one, is the same, and the signature verifies; `iss` equals `--issuer`; `aud` (a string or a list) contains `cortex`; `exp` is present and in the future. The key set is cached; a `kid` that is not in it fetches it again at most once a minute after a fetch that succeeded. The fetch runs detached from the call with a timeout of its own, one at a time for all waiting callers, and a known `kid` never waits for it. Any failure is 401 with the body `{"error":"unauthenticated"}` and a `WWW-Authenticate` header.
2. The check wraps the whole router, so it runs before routing: a path that is no route needs a token too. A route handler also refuses with 401 a request that reached it without a caller.
3. The principals of an accepted token are `user:<sub>`, `user:<email>` when `email_verified` is true, one `group:<value>` per entry of `groups`, and `org:members`.
4. `/healthz`, `/readyz` and `/metrics` are served only on `--health-listen` and never routed. `TestEveryRouteAuthenticated` holds them as its closed list of unrouted paths. `/readyz` answers 200 only while the database answers.
5. `POST /v1/search` takes `{"query": 1 to 2000 characters, "sources": [id], "topK": 1 to 50 (default 8), "rerank": bool (default true)}`. An unknown field, a body that is not one JSON object and a value out of range answer 400 `invalid-request`. Each source asked for must be one in which the caller may read a document (`ReadableSources`), or the answer is 403 `source-forbidden`, also for a source that does not exist. Without sources the search covers every readable source. The store's trimmed search runs with the caller's principals. When the parameters set a rerank alias and the request does not set `rerank` to false, the store returns `topK` times 4 candidates (at most 200), the gateway reranks them and the best `topK` are kept, scored by the reranker; otherwise the score is the cosine similarity. Each hit gets the title and address of its document from `Documents`, read with the caller's principals; a hit whose document is not returned is left out. A gateway failure answers 503 `gateway-unavailable`.
6. `GET /v1/sources` answers `{"items": [{"id", "title", "state", "documents", "chunks", "lastSyncAt", "lastError"}]}` from `Sources`: only the sources in which the caller reads a document, each with the documents and chunks the caller may read.
7. The gateway client calls only `<base>/embeddings` (OpenAI shape) and `<base>/rerank` (`{model, query, documents, top_n}` to `{results: [{index, relevance_score}]}`), with `Authorization: Bearer <key>`, the key read from its file on every call. The text of an error holds the route and the status, never the body of the answer. The base defaults to `http://model-gateway.model-gateway.svc.cluster.local:8080/v1`, the key file to `/var/run/secrets/openova/model-key`.
8. One log line per call: method, route, status and duration. A request body, a query string and a search text are never logged.
9. The database address is read from the file `--database-url-file` and the gateway key from its file. No value is read from the environment.
10. The definitions are the document under the key `definitions.yaml` (YAML or JSON) of the ConfigMap `cortex-definitions`. `Parse` reads its list `sources` and refuses the whole list on the first entry that breaks a rule: an id of the form `^[a-z][a-z0-9-]{1,40}$` that occurs once, a title of 1 to 120 characters, a connector type `upload`, `git` or `web`, readers of the reader form that the store also takes (`store.CheckPrincipal`, one check for both), at least one manager that is a `user:` or a `group:`, at most 500 sources. The digest of a source is the SHA-256 of its entry in canonical JSON. The loader hands every valid version to `ApplyDefinitions`; a refused version, a ConfigMap without the key and a deleted ConfigMap change nothing; a version whose write failed is tried again by a rate-limited queue. Nothing polls.
11. The store port gains `Sources(ctx, principals)` and `Documents(ctx, principals, ids)`; both run in the trimmed read-only transaction, so row-level security applies. `Postgres.Ping` reports whether the database answers.
12. Guard G-P4 scans `products/cortex/internal/httpapi` and `products/fingate/internal/api`. Guard G-P5 is a hard zero over the non-test Go files of `products/cortex` and `products/fingate`: `InsecureSkipVerify: true`; `exec.Command`; `os.Getenv` or `os.LookupEnv` of a name that contains `PASSWORD`, `SECRET`, `TOKEN` or `KEY` in any letter case; a wildcard CORS origin; a `fmt.Sprintf` whose format literal holds `SELECT`, `INSERT`, `UPDATE`, `DELETE` or `WHERE`. Each rule has failing fixtures in the self-test. G-P5 matches these plain forms only: a name in a constant or a raw string, or an origin written into the header map directly, passes it, and review holds those. It is not widened here, because the guard is Python and the repository grows no Python.

		log.Error("cortex query cannot listen", "error", err.Error())
		return 2
	}
	health, err := lc.Listen(ctx, "tcp", healthListen)
	if err != nil {
		_ = api.Close()
		log.Error("cortex query cannot listen", "error", err.Error())
		return 2
	}
	if d.listening != nil {
		d.listening(api.Addr(), health.Addr())
	}
	servers := []*http.Server{{Handler: srv.Handler(), ReadHeaderTimeout: 10 * time.Second},
		{Handler: srv.Health(), ReadHeaderTimeout: 10 * time.Second}}
	errs := make(chan error, 2)
	for i, ln := range []net.Listener{api, health} {
		go func() { errs <- servers[i].Serve(ln) }()
	}
	log.Info("cortex query serves", "listen", api.Addr().String(), "health", health.Addr().String())
	code := 0
	select {
	case <-ctx.Done():
	case err := <-errs:
		log.Error("a listener failed", "error", err.Error())
		code = 1
	}
	stop, cancel := context.WithTimeout(context.WithoutCancel(ctx), stopGrace)
	defer cancel()
	for _, s := range servers {
		_ = s.Shutdown(stop)
	}
	return code
}

// Package auth checks the bearer token of a call to cortex and derives the caller's principals.
//
// A token of the Organization's realm is accepted when every check holds, in this order:
//
//	format     a compact JWS of three base64url parts whose header and claims are JSON objects,
//	           with no crit header
//	algorithm  the header's alg is RS256, PS256 or ES256
//	signature  the header's kid names a key of the realm's key set of a type that fits alg, and
//	           the signature verifies with it. The key set is cached; an unknown kid fetches it
//	           again, at most once per RefreshInterval
//	issuer     iss equals the configured issuer, the value identity.issuerURL
//	audience   aud, a string or a list, contains Audience
//	expiry     exp is present and in the future
//
// The first check that fails ends the call with an *Error; there is no other way to identify a
// caller. The principals of an accepted token are user:<sub>, user:<email> when email_verified
// is true, one group:<value> per entry of the groups claim, and org:members.

		return nil, errors.New("auth: no key source")
	}

// DiscoveryKeySource reads the issuer's OpenID configuration and then the key set it names.
// The configuration must name the same issuer.
func DiscoveryKeySource(client *http.Client, issuer string) KeySource {

		doc, err := get(ctx, client, strings.TrimSuffix(issuer, "/")+"/.well-known/openid-configuration")
		if err != nil {
			return nil, err
		}
		var meta struct {
			Issuer  string `json:"issuer"`
			JWKSURI string `json:"jwks_uri"`
		}
		if err := json.Unmarshal(doc, &meta); err != nil {
			return nil, fmt.Errorf("auth: the OpenID configuration: %w", err)
		}
		if meta.Issuer != issuer || !strings.HasPrefix(meta.JWKSURI, "https://") {
			return nil, fmt.Errorf("auth: the OpenID configuration names issuer %q and key set %q", meta.Issuer, meta.JWKSURI)
		}

func get(ctx context.Context, client *http.Client, address string) ([]byte, error) {
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, address, nil)
	if err != nil {
		return nil, err
	}
	resp, err := client.Do(req)
	if err != nil {
		return nil, err
	}
	defer func() { _ = resp.Body.Close() }()
	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("auth: %s answered %d", address, resp.StatusCode)
	}

// Check applies the checks in order and returns the caller of an accepted token.
func (c *Checker) Check(ctx context.Context, compact string) (Caller, error) {
	parts := strings.Split(compact, ".")
	if len(parts) != 3 {
		return Caller{}, fail("format", "the token is not a compact JWS")
	}
	var seg [3][]byte
	for i, p := range parts {
		b, err := base64.RawURLEncoding.DecodeString(p)
		if err != nil {
			return Caller{}, fail("format", "part %d is not base64url", i+1)
		}
		seg[i] = b
	}
	var header struct {
		Alg  string          `json:"alg"`
		Kid  string          `json:"kid"`
		Crit json.RawMessage `json:"crit"`
	}
	var raw map[string]json.RawMessage
	if json.Unmarshal(seg[0], &header) != nil || json.Unmarshal(seg[1], &raw) != nil || raw == nil {
		return Caller{}, fail("format", "the header or the claims are not a JSON object")
	}
	if header.Crit != nil {
		return Caller{}, fail("format", "the header has crit")
	}
	if !slices.Contains(Algorithms, header.Alg) {
		return Caller{}, fail("algorithm", "%q is not one of %v", header.Alg, Algorithms)
	}
	key, err := c.key(ctx, header.Kid, header.Alg)
	if err != nil {
		return Caller{}, err
	}
	if !verify(header.Alg, key, []byte(parts[0]+"."+parts[1]), seg[2]) {
		return Caller{}, fail("signature", "the signature does not verify")
	}
	var iss string
	if claim(raw, "iss", &iss) != nil || iss != c.cfg.Issuer {
		return Caller{}, fail("issuer", "iss %q is not the issuer", iss)
	}
	var aud []string
	var one string
	if claim(raw, "aud", &one) == nil && one != "" {
		aud = []string{one}
	} else if claim(raw, "aud", &aud) != nil {
		aud = nil
	}
	if !slices.Contains(aud, Audience) {
		return Caller{}, fail("audience", "aud %q does not contain %q", aud, Audience)
	}
	var exp float64
	if _, ok := raw["exp"]; !ok || claim(raw, "exp", &exp) != nil || math.IsNaN(exp) || math.Abs(exp) > 1e12 {
		return Caller{}, fail("expiry", "exp is missing or not a number")
	}
	if sec, frac := math.Modf(exp); !c.cfg.Now().Before(time.Unix(int64(sec), int64(frac*1e9))) {
		return Caller{}, fail("expiry", "the token has expired")
	}
	return principals(raw), nil
}

// principals derives the caller from the claims of an accepted token. A claim of the wrong
// type counts as absent.
func principals(raw map[string]json.RawMessage) Caller {
	var cl Caller
	var email string
	var verified bool
	var groups []string
	_ = claim(raw, "sub", &cl.Subject)
	_ = claim(raw, "email", &email)
	_ = claim(raw, "email_verified", &verified)
	_ = claim(raw, "groups", &groups)
	if cl.Subject != "" {
		cl.Principals = append(cl.Principals, "user:"+cl.Subject)
	}
	if verified && email != "" && email != cl.Subject {
		cl.Principals = append(cl.Principals, "user:"+email)
	}
	for _, g := range groups {
		if g != "" && !slices.Contains(cl.Principals, "group:"+g) {
			cl.Principals = append(cl.Principals, "group:"+g)
		}
	}
	cl.Principals = append(cl.Principals, "org:members")
	return cl
}

func claim(raw map[string]json.RawMessage, name string, v any) error {
	if b, ok := raw[name]; ok {
		return json.Unmarshal(b, v)
	}
	return nil
}

// key returns the key kid for alg. An unknown kid fetches the key set again, at most once per
// RefreshInterval after a fetch that succeeded. One fetch runs at a time and serves every caller
// that waits for it; a known kid never waits, and a caller that goes away stops waiting only.
func (c *Checker) key(ctx context.Context, kid, alg string) (any, error) {
	if kid == "" {
		return nil, fail("signature", "the header names no key")
	}
	c.mu.Lock()
	if _, ok := c.keys[kid]; !ok && (c.fetched.IsZero() || c.cfg.Now().Sub(c.fetched) >= RefreshInterval) {
		if c.flight == nil {
			c.flight = make(chan struct{})
			go c.fetch(context.WithoutCancel(ctx), c.flight)
		}
		flight := c.flight
		c.mu.Unlock()
		select {
		case <-flight:
		case <-ctx.Done():
			return nil, fail("signature", "key %q is unknown: %v", kid, ctx.Err())
		}
		c.mu.Lock()
	}
	k, ok := c.keys[kid]
	pinned, fetchErr := c.algs[kid], c.fetchErr
	c.mu.Unlock()
	if !ok && fetchErr != nil {
		return nil, fail("signature", "key %q is unknown; the key set cannot be read: %v", kid, fetchErr)
	} else if !ok {
		return nil, fail("signature", "key %q is unknown", kid)
	}
	_, isEC := k.(*ecdsa.PublicKey)
	if isEC != (alg == "ES256") || (pinned != "" && pinned != alg) {
		return nil, fail("signature", "key %q does not sign with %s", kid, alg)
	}
	return k, nil
}

// fetch reads the key set within FetchTimeout and closes done. A set that cannot be read keeps
// the keys known so far and does not start the RefreshInterval.
func (c *Checker) fetch(ctx context.Context, done chan struct{}) {
	ctx, cancel := context.WithTimeout(ctx, FetchTimeout)
	defer cancel()
	doc, err := c.cfg.Keys(ctx)
	var keys map[string]any
	var algs map[string]string
	if err == nil {
		keys, algs, err = parseKeySet(doc)
	}
	c.mu.Lock()
	defer c.mu.Unlock()
	if c.fetchErr, c.flight = err, nil; err == nil {
		c.keys, c.algs, c.fetched = keys, algs, c.cfg.Now()
	}
	close(done)
}

// parseKeySet keeps the signature keys with a key identifier: RSA keys of at least 2048 bits
// and EC keys on P-256.
func parseKeySet(doc []byte) (map[string]any, map[string]string, error) {
	var set struct {
		Keys []struct{ Kty, Use, Kid, Alg, N, E, Crv, X, Y string } `json:"keys"`
	}
	if err := json.Unmarshal(doc, &set); err != nil {
		return nil, nil, err
	}
	keys, algs := map[string]any{}, map[string]string{}
	b64 := base64.RawURLEncoding.DecodeString
	for _, k := range set.Keys {
		if k.Kid == "" || (k.Use != "" && k.Use != "sig") {
			continue
		}
		switch k.Kty {
		case "RSA":
			n, err1 := b64(k.N)
			e, err2 := b64(k.E)
			if err1 != nil || err2 != nil || len(e) == 0 || len(e) > 4 {
				continue
			}
			pub := &rsa.PublicKey{N: new(big.Int).SetBytes(n)}
			for _, b := range e {
				pub.E = pub.E<<8 | int(b)
			}
			if pub.N.BitLen() < 2048 || pub.E < 3 {
				continue
			}
			keys[k.Kid] = pub
		case "EC":
			x, err1 := b64(k.X)
			y, err2 := b64(k.Y)
			if k.Crv != "P-256" || err1 != nil || err2 != nil || len(x) != 32 || len(y) != 32 {
				continue
			}
			pub, err := ecdsa.ParseUncompressedPublicKey(elliptic.P256(), append(append([]byte{4}, x...), y...))
			if err != nil {
				continue
			}
			keys[k.Kid] = pub
		default:
			continue
		}
		algs[k.Kid] = k.Alg
	}
	return keys, algs, nil
}

// verify checks the signature sig of signed with key under alg.
func verify(alg string, key any, signed, sig []byte) bool {

	switch k := key.(type) {
	case *rsa.PublicKey:
		if alg == "PS256" {
			return rsa.VerifyPSS(k, crypto.SHA256, digest[:], sig, &rsa.PSSOptions{SaltLength: rsa.PSSSaltLengthEqualsHash}) == nil
		}
		return rsa.VerifyPKCS1v15(k, crypto.SHA256, digest[:], sig) == nil
	case *ecdsa.PublicKey:
		if len(sig) != 64 {
			return false
		}
		return ecdsa.Verify(k, digest[:], new(big.Int).SetBytes(sig[:32]), new(big.Int).SetBytes(sig[32:]))
	}
	return false
}

// The definitions are the Application's parameters, which the chart writes as one YAML or JSON
// document under the key DataKey of the ConfigMap ConfigMapName in the program's namespace.

// Parse returns the sources of a definitions document. The digest of each is the SHA-256 of
// its entry in canonical JSON (keys sorted, no space), so a change of any field of the entry
// changes it and a change of layout does not.
func Parse(doc []byte) ([]store.SourceDefinition, error) {
	j, err := yaml.YAMLToJSON(doc)
	if err != nil {
		return nil, fmt.Errorf("definitions: not YAML: %w", err)
	}
	var top map[string]json.RawMessage
	if err := json.Unmarshal(j, &top); err != nil || top == nil {
		return nil, errors.New("definitions: the document is not an object")
	}
	// A missing or null sources is refused: only an explicit empty list means no sources, so a
	// typo or an empty chart value cannot delete every source of the installation.
	s, ok := top["sources"]
	if !ok || string(s) == "null" {
		return nil, errors.New("definitions: the document has no list sources; write sources: [] for none")
	}
	var raws []json.RawMessage
	if err := json.Unmarshal(s, &raws); err != nil {
		return nil, errors.New("definitions: sources is not a list")
	}
	if len(raws) > MaxSources {
		return nil, fmt.Errorf("definitions: %d sources, at most %d", len(raws), MaxSources)
	}
	defs := make([]store.SourceDefinition, 0, len(raws))
	seen := map[string]bool{}
	for i, raw := range raws {
		var e entry
		if err := json.Unmarshal(raw, &e); err != nil {
			return nil, fmt.Errorf("definitions: sources[%d] is not a source: %w", i, err)
		}
		if err := check(e); err != nil {
			return nil, fmt.Errorf("definitions: sources[%d] %q: %w", i, e.ID, err)
		}
		if seen[e.ID] {
			return nil, fmt.Errorf("definitions: source %q is defined twice", e.ID)
		}
		seen[e.ID] = true
		var v any
		_ = json.Unmarshal(raw, &v)
		canonical, _ := json.Marshal(v)
		sum := sha256.Sum256(canonical)
		defs = append(defs, store.SourceDefinition{ID: e.ID, Title: e.Title, Digest: hex.EncodeToString(sum[:]),

	}
	return defs, nil
}

		return fmt.Errorf("id does not match %s", idForm)
	case n < 1 || n > 120:
		return errors.New("title must be 1 to 120 characters")
	case e.Connector == nil || !connectors[e.Connector.Type]:
		return errors.New("connector.type must be upload, git or web")
	case e.Access == nil || e.Access.Readers == nil || len(e.Access.Managers) == 0:
		return errors.New("access needs readers and at least one manager")
	}

		if !readerForm.MatchString(p) || store.CheckPrincipal(p) != nil {
			return fmt.Errorf("reader %q is not a principal", p)
		}
	}
	for _, p := range e.Access.Managers {
		if !managerForm.MatchString(p) || store.CheckPrincipal(p) != nil {
			return fmt.Errorf("manager %q is not a user or a group", p)
		}
	}

}

// The loader: an informer on the one ConfigMap of the definitions, and a rate-limited queue of
// one key in front of ApplyDefinitions. Each event puts the key in the queue; the worker reads
// the newest version from the informer's cache, so versions that arrive while one is applied
// are folded into one. A version that is refused is not tried again. A version that the store
// fails to apply is tried again with growing delays until it is applied or a newer one
// replaces it. Nothing here polls: the informer's watch and the queue's delays drive it.

import (
	"context"
	"errors"
	"fmt"
	"sync"

	corev1 "k8s.io/api/core/v1"
	metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"
	"k8s.io/apimachinery/pkg/fields"

	"k8s.io/client-go/kubernetes"
	"k8s.io/client-go/tools/cache"
	"k8s.io/client-go/util/workqueue"

	"github.com/openova-io/openova/products/cortex/internal/store"

// Applier receives every valid version of the sources. The store opened with the index role is one.
type Applier interface {
	ApplyDefinitions(ctx context.Context, defs []store.SourceDefinition) error
}

// Loader keeps the store's sources equal to the definitions of one ConfigMap.
type Loader struct {
	factory   informers.SharedInformerFactory
	namespace string
	name      string
	apply     Applier
	logf      func(format string, a ...any)
	queue     workqueue.TypedRateLimitingInterface[string]

	applied chan struct{}
	once    sync.Once
}

// NewLoader returns a loader of the ConfigMap name in namespace. logf receives one line for
// every version applied, refused or retried, and never the document; it may be nil.
func NewLoader(client kubernetes.Interface, namespace, name string, apply Applier, logf func(format string, a ...any)) *Loader {
	if logf == nil {
		logf = func(string, ...any) {}
	}
	selector := fields.OneTermEqualSelector("metadata.name", name).String()
	factory := informers.NewSharedInformerFactoryWithOptions(client, 0, informers.WithNamespace(namespace),
		informers.WithTweakListOptions(func(o *metav1.ListOptions) { o.FieldSelector = selector }))
	return &Loader{factory: factory, namespace: namespace, name: name, apply: apply, logf: logf,
		queue:   workqueue.NewTypedRateLimitingQueue(workqueue.DefaultTypedControllerRateLimiter[string]()),
		applied: make(chan struct{})}
}

// Applied is closed when the first version has been applied.
func (l *Loader) Applied() <-chan struct{} { return l.applied }

// Run watches the ConfigMap and applies its versions until ctx ends.
func (l *Loader) Run(ctx context.Context) error {
	cms := l.factory.Core().V1().ConfigMaps()
	enqueue := func(obj any) {
		if cm, ok := obj.(*corev1.ConfigMap); ok && cm.Name == l.name {
			l.queue.Add(l.name)
		}
	}
	if _, err := cms.Informer().AddEventHandler(cache.ResourceEventHandlerFuncs{
		AddFunc:    enqueue,
		UpdateFunc: func(_, obj any) { enqueue(obj) },
		DeleteFunc: func(any) {
			l.logf("definitions: ConfigMap %s/%s was deleted; the sources in use stay", l.namespace, l.name)
		},
	}); err != nil {
		return fmt.Errorf("definitions: %w", err)
	}
	l.factory.Start(ctx.Done())
	defer l.factory.Shutdown()
	if !cache.WaitForCacheSync(ctx.Done(), cms.Informer().HasSynced) {
		return errors.New("definitions: the informer did not sync before the end")
	}
	go func() {
		<-ctx.Done()
		l.queue.ShutDown()
	}()
	get := cms.Lister().ConfigMaps(l.namespace).Get
	for l.next(ctx, get) {
		continue
	}
	return nil
}

// next applies the newest version once. It returns false when the queue was shut down.
func (l *Loader) next(ctx context.Context, get func(string) (*corev1.ConfigMap, error)) bool {
	key, quit := l.queue.Get()
	if quit {
		return false
	}
	defer l.queue.Done(key)
	cm, err := get(key)
	if err != nil {
		l.queue.Forget(key)
		return true
	}
	at := fmt.Sprintf("ConfigMap %s/%s version %s", cm.Namespace, cm.Name, cm.ResourceVersion)
	raw, ok := cm.Data[DataKey]
	if !ok {
		err = fmt.Errorf("it has no key %s", DataKey)
	}
	var defs []store.SourceDefinition
	if err == nil {
		defs, err = Parse([]byte(raw))
	}
	if err != nil {
		l.queue.Forget(key)
		l.logf("definitions: refused %s: %v; the sources in use stay", at, err)
		return true
	}
	if err := l.apply.ApplyDefinitions(ctx, defs); err != nil {
		l.logf("definitions: %s was not applied: %v; it is tried again", at, err)
		l.queue.AddRateLimited(key)
		return true
	}
	l.queue.Forget(key)
	l.once.Do(func() { close(l.applied) })
	l.logf("definitions: applied %s: %d sources", at, len(defs))
	return true
}

// model. It calls two routes of the gateway's address: POST <base>/embeddings in the OpenAI
// shape and POST <base>/rerank ({model, query, documents, top_n} -> {results: [{index,

// Client calls the gateway.
type Client struct {
	base    string
	keyFile string
	http    *http.Client
}

// New returns a client of the gateway at baseURL that reads its key from keyFile.
func New(baseURL, keyFile string, hc *http.Client) (*Client, error) {
	u, err := url.Parse(baseURL)
	if err != nil || (u.Scheme != "http" && u.Scheme != "https") || u.Host == "" || u.User != nil || u.RawQuery != "" {
		return nil, fmt.Errorf("gateway: %q is not an http or https address", baseURL)
	}
	if keyFile == "" {
		return nil, errors.New("gateway: no key file")
	}
	if hc == nil {
		hc = http.DefaultClient
	}
	return &Client{base: strings.TrimSuffix(baseURL, "/"), keyFile: keyFile, http: hc}, nil
}

// post sends in as JSON to route and decodes the answer into out.
func (c *Client) post(ctx context.Context, route string, in, out any) error {
	key, err := os.ReadFile(c.keyFile)
	if err != nil || len(bytes.TrimSpace(key)) == 0 {
		return fmt.Errorf("%w: the key file %s cannot be read or is empty", ErrUnavailable, c.keyFile)
	}
	body, err := json.Marshal(in)
	if err != nil {
		return err
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, c.base+route, bytes.NewReader(body))
	if err != nil {
		return err
	}
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+string(bytes.TrimSpace(key)))
	resp, err := c.http.Do(req)
	if err != nil {
		return fmt.Errorf("%w: %s: the call failed", ErrUnavailable, route)
	}
	defer func() { _ = resp.Body.Close() }()
	if resp.StatusCode != http.StatusOK {
		_, _ = io.Copy(io.Discard, io.LimitReader(resp.Body, maxAnswer))
		return fmt.Errorf("%w: %s answered %d", ErrUnavailable, route, resp.StatusCode)
	}
	if err := json.NewDecoder(io.LimitReader(resp.Body, maxAnswer)).Decode(out); err != nil {
		return fmt.Errorf("%w: %s: the answer is not the expected JSON", ErrUnavailable, route)
	}
	return nil
}

type Embedder struct {
	c          *Client
	alias      string
	dimensions int
}

// Embedder returns the embedder of alias, whose vectors have dimensions values.
func (c *Client) Embedder(alias string, dimensions int) *Embedder {
	return &Embedder{c: c, alias: alias, dimensions: dimensions}
}

// Dimensions is the length of every vector Embed returns.
func (e *Embedder) Dimensions() int { return e.dimensions }

// Embed returns one vector per text, in the order of texts.
func (e *Embedder) Embed(ctx context.Context, texts []string) ([][]float32, error) {
	var out struct {
		Data []struct {
			Index     int       `json:"index"`
			Embedding []float32 `json:"embedding"`
		} `json:"data"`
	}
	if err := e.c.post(ctx, "/embeddings", map[string]any{"model": e.alias, "input": texts}, &out); err != nil {
		return nil, err
	}
	if len(out.Data) != len(texts) {
		return nil, fmt.Errorf("%w: /embeddings returned %d vectors for %d texts", ErrUnavailable, len(out.Data), len(texts))
	}
	vectors := make([][]float32, len(texts))
	for _, d := range out.Data {
		if d.Index < 0 || d.Index >= len(texts) || vectors[d.Index] != nil || len(d.Embedding) != e.dimensions {
			return nil, fmt.Errorf("%w: /embeddings returned index %d with %d values; want each index once with %d values",
				ErrUnavailable, d.Index, len(d.Embedding), e.dimensions)
		}
		vectors[d.Index] = d.Embedding
	}
	return vectors, nil
}

type Ranked struct {
	Index int     `json:"index"`
	Score float64 `json:"relevance_score"`
}

type Reranker struct {
	c     *Client
	alias string
}

// Reranker returns the reranker of alias.
func (c *Client) Reranker(alias string) *Reranker { return &Reranker{c: c, alias: alias} }

// Rerank returns at most topN documents, best first.
func (r *Reranker) Rerank(ctx context.Context, query string, documents []string, topN int) ([]Ranked, error) {
	var out struct {
		Results []Ranked `json:"results"`
	}
	in := map[string]any{"model": r.alias, "query": query, "documents": documents, "top_n": topN}
	if err := r.c.post(ctx, "/rerank", in, &out); err != nil {
		return nil, err
	}
	seen := map[int]bool{}
	for _, x := range out.Results {
		if x.Index < 0 || x.Index >= len(documents) || seen[x.Index] {
			return nil, fmt.Errorf("%w: /rerank returned index %d for %d documents", ErrUnavailable, x.Index, len(documents))
		}
		seen[x.Index] = true
	}
	sort.SliceStable(out.Results, func(i, j int) bool { return out.Results[i].Score > out.Results[j].Score })
	if len(out.Results) > topN {
		out.Results = out.Results[:topN]
	}
	return out.Results, nil
}

// Handler serves the routes behind the token check.
func (s *Server) Handler() http.Handler { return s.authenticate(s.mux) }

// Health serves the cluster-internal paths.
func (s *Server) Health() http.Handler { return s.health }

// Routes returns the patterns that Handler serves.
func (s *Server) Routes() []string { return append([]string(nil), s.routes...) }

// Unrouted returns the patterns that Health serves.
func (s *Server) Unrouted() []string { return append([]string(nil), s.unrouted...) }

// route registers a route of Handler. The handler runs only with the caller the token check found.
func (s *Server) route(pattern string, h func(http.ResponseWriter, *http.Request, auth.Caller)) {
	s.routes = append(s.routes, pattern)
	s.mux.Handle(pattern, s.observe(pattern, func(w http.ResponseWriter, r *http.Request) {
		c, ok := r.Context().Value(callerKey{}).(auth.Caller)
		if !ok || len(c.Principals) == 0 {
			writeError(w, http.StatusUnauthorized, "unauthenticated")
			return
		}
		h(w, r, c)
	}))
}

// internal registers a path of Health.
func (s *Server) internal(pattern string, h http.HandlerFunc) {
	s.unrouted = append(s.unrouted, pattern)
	s.health.Handle(pattern, h)
}

// authenticate checks the bearer token of every call before next routes it.
func (s *Server) authenticate(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		token, ok := strings.CutPrefix(r.Header.Get("Authorization"), "Bearer ")
		var c auth.Caller
		err := errors.New("no bearer token")
		if ok && token != "" {
			c, err = s.cfg.Auth.Check(r.Context(), token)
		}
		if err != nil {
			s.count("unauthenticated", http.StatusUnauthorized)
			s.cfg.Log.Info("call refused", "method", r.Method, "path", r.URL.Path, "reason", err.Error())
			w.Header().Set("WWW-Authenticate", `Bearer realm="cortex"`)
			writeError(w, http.StatusUnauthorized, "unauthenticated")
			return
		}
		next.ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), callerKey{}, c)))
	})
}

	status int

		start := time.Now()
		rec := &recorder{ResponseWriter: w, status: http.StatusOK}
		h(rec, r)
		s.count(pattern, rec.status)
		s.cfg.Log.Info("call", "method", r.Method, "route", pattern, "status", rec.status, "ms", time.Since(start).Milliseconds())
	})
}

func (s *Server) search(w http.ResponseWriter, r *http.Request, c auth.Caller) {
	var req search.Request
	dec := json.NewDecoder(http.MaxBytesReader(w, r.Body, maxBody))
	dec.DisallowUnknownFields()
	// One JSON object and nothing after it: a second Decode must meet the end of the body.
	if err := dec.Decode(&req); err != nil || !errors.Is(dec.Decode(new(json.RawMessage)), io.EOF) {
		writeError(w, http.StatusBadRequest, "invalid-request")
		return
	}
	results, err := s.cfg.Search.Search(r.Context(), c.Principals, req)
	switch {
	case errors.Is(err, search.ErrInvalid):
		writeError(w, http.StatusBadRequest, "invalid-request")
	case errors.Is(err, search.ErrForbidden):
		writeError(w, http.StatusForbidden, "source-forbidden")
	case errors.Is(err, search.ErrUnavailable):
		s.cfg.Log.Warn("search: the gateway failed", "error", err.Error())
		writeError(w, http.StatusServiceUnavailable, "gateway-unavailable")
	case err != nil:
		s.cfg.Log.Error("search failed", "error", err.Error())
		writeError(w, http.StatusInternalServerError, "internal")
	default:
		writeJSON(w, http.StatusOK, map[string]any{"results": results})
	}
}

	ErrForbidden   = errors.New("source-forbidden")
	ErrUnavailable = errors.New("gateway-unavailable")
)

// Request is the body of POST /v1/search. Nil fields take their defaults.
type Request struct {
	Query   string   `json:"query"`
	Sources []string `json:"sources"`
	TopK    *int     `json:"topK"`
	Rerank  *bool    `json:"rerank"`
}

// Result is one hit.
type Result struct {
	DocumentID string `json:"documentId"`
	SourceID   string `json:"sourceId"`
	Title      string `json:"title"`
	URI        string `json:"uri"`
	Chunk      Chunk  `json:"chunk"`
}

// Chunk is the passage of a hit. Page is null for a format without pages. Score is the
// reranker's relevance when the hits were reranked, else the cosine similarity.
type Chunk struct {
	ID    int64   `json:"id"`
	Text  string  `json:"text"`
	Page  *int    `json:"page"`
	Score float64 `json:"score"`
}

// Embedder embeds the query.
type Embedder interface {
	Embed(ctx context.Context, texts []string) ([][]float32, error)
}

// Reranker orders passages by relevance, best first.
type Reranker interface {
	Rerank(ctx context.Context, query string, documents []string, topN int) ([]gateway.Ranked, error)
}

// Service runs searches. Reranker is nil when the parameters set no rerank alias.
type Service struct {
	Store    store.Store
	Embedder Embedder
	Reranker Reranker
}

// Search runs r for the caller's principals.
func (s *Service) Search(ctx context.Context, principals []string, r Request) ([]Result, error) {
	topK := DefaultTopK
	if r.TopK != nil {
		topK = *r.TopK
	}
	switch n := utf8.RuneCountInString(r.Query); {
	case !utf8.ValidString(r.Query) || n < 1 || n > MaxQuery:
		return nil, fmt.Errorf("%w: query must be 1 to %d characters", ErrInvalid, MaxQuery)
	case topK < 1 || topK > MaxTopK:
		return nil, fmt.Errorf("%w: topK must be 1 to %d", ErrInvalid, MaxTopK)
	}
	readable, err := s.Store.ReadableSources(ctx, principals)
	if err != nil {
		return nil, err
	}
	sources := readable
	if len(r.Sources) > 0 {
		sources = nil
		for _, id := range r.Sources {
			if !slices.Contains(readable, id) {
				return nil, ErrForbidden // also for a source that does not exist: its existence is not told
			}
			if !slices.Contains(sources, id) {
				sources = append(sources, id)
			}
		}
	}
	if len(sources) == 0 {
		return []Result{}, nil
	}
	vectors, err := s.Embedder.Embed(ctx, []string{r.Query})
	if err != nil || len(vectors) != 1 {
		return nil, fmt.Errorf("%w: embedding: %v", ErrUnavailable, err)
	}
	rerank := s.Reranker != nil && (r.Rerank == nil || *r.Rerank)
	limit := topK
	if rerank {
		limit = min(topK*Candidates, store.MaxLimit)
	}
	hits, err := s.Store.Search(ctx, principals, sources, vectors[0], limit)
	if err != nil {
		return nil, err
	}
	if rerank && len(hits) > 0 {
		texts := make([]string, len(hits))
		for i, h := range hits {
			texts[i] = h.Text
		}
		ranked, err := s.Reranker.Rerank(ctx, r.Query, texts, topK)
		if err != nil {
			return nil, fmt.Errorf("%w: rerank: %v", ErrUnavailable, err)
		}
		reordered := make([]store.Hit, 0, len(ranked))
		for _, x := range ranked {
			h := hits[x.Index]
			h.Score = x.Score
			reordered = append(reordered, h)
		}
		hits = reordered
	}
	if len(hits) > topK {
		hits = hits[:topK]
	}
	return s.results(ctx, principals, hits)
}

// results adds the title and address of each hit's document. A hit whose document the caller
// may no longer read, or that was deleted meanwhile, is left out.
func (s *Service) results(ctx context.Context, principals []string, hits []store.Hit) ([]Result, error) {
	var ids []string
	for _, h := range hits {
		if !slices.Contains(ids, h.DocumentID) {
			ids = append(ids, h.DocumentID)
		}
	}
	docs, err := s.Store.Documents(ctx, principals, ids)
	if err != nil {
		return nil, err
	}
	byID := map[string]store.Document{}
	for _, d := range docs {
		byID[d.ID] = d
	}
	out := make([]Result, 0, len(hits))
	for _, h := range hits {
		d, ok := byID[h.DocumentID]
		if !ok {
			continue
		}
		c := Chunk{ID: h.ChunkID, Text: h.Text, Score: h.Score}
		if h.Page > 0 {
			c.Page = &h.Page
		}
		out = append(out, Result{DocumentID: h.DocumentID, SourceID: h.SourceID, Title: d.Title, URI: d.URI, Chunk: c})
	}
	return out, nil
}

import (
	"context"
	"fmt"

	"github.com/jackc/pgx/v5"

// sourcesSQL lists the sources in which a principal of $1 holds a grant, or reads a document
// through its own reader list. Row-level security trims the two counts to the rows the caller
// reads; the chunk count binds the principals again, as SearchSQL does.
const sourcesSQL = `SELECT s.id, s.title, s.state, s.last_sync_at, s.last_error,
  (SELECT count(*) FROM document d WHERE d.source_id = s.id),
  (SELECT count(*) FROM chunk c WHERE c.source_id = s.id AND c.readers && $1::text[])
FROM source s
WHERE EXISTS (SELECT 1 FROM source_acl a WHERE a.source_id = s.id AND a.principal = ANY ($1::text[]))
   OR EXISTS (SELECT 1 FROM document d JOIN document_acl x ON x.document_id = d.id
               WHERE d.source_id = s.id AND x.principal = ANY ($1::text[]))
ORDER BY s.id`

// documentsSQL reads the documents $1; row-level security leaves out those the caller may not read.
const documentsSQL = `SELECT d.id::text, d.source_id, d.title, d.uri, d.state, d.updated_at
FROM document d WHERE d.id = ANY ($1::uuid[]) ORDER BY d.id`

// CheckPrincipal refuses p when the store does not take it as a principal. The parser of the
// definitions applies it, so a version the store would refuse is refused there, once.
func CheckPrincipal(p string) error { return checkPrincipals([]string{p}) }

// Sources returns the sources the principals read, with what they read of each.
func (p *Postgres) Sources(ctx context.Context, principals []string) ([]SourceStatus, error) {
	var out []SourceStatus
	err := p.trimmed(ctx, principals, func(tx pgx.Tx) error {
		rows, err := tx.Query(ctx, sourcesSQL, principals)
		if err != nil {
			return fmt.Errorf("store: sources: %w", err)
		}
		out, err = pgx.CollectRows(rows, func(r pgx.CollectableRow) (SourceStatus, error) {
			var s SourceStatus
			err := r.Scan(&s.ID, &s.Title, &s.State, &s.LastSyncAt, &s.LastError, &s.Documents, &s.Chunks)
			return s, err
		})
		if err != nil {
			return fmt.Errorf("store: sources: %w", err)
		}
		return nil
	})
	return out, err
}

// Documents returns the documents of ids the principals read.
func (p *Postgres) Documents(ctx context.Context, principals []string, ids []string) ([]Document, error) {
	var out []Document
	err := p.trimmed(ctx, principals, func(tx pgx.Tx) error {
		if len(ids) == 0 {
			return nil
		}
		rows, err := tx.Query(ctx, documentsSQL, ids)
		if err != nil {
			return fmt.Errorf("store: documents: %w", err)
		}
		out, err = pgx.CollectRows(rows, func(r pgx.CollectableRow) (Document, error) {
			var d Document
			err := r.Scan(&d.ID, &d.SourceID, &d.Title, &d.URI, &d.State, &d.UpdatedAt)
			return d, err
		})
		if err != nil {
			return fmt.Errorf("store: documents: %w", err)
		}
		return nil
	})
	return out, err
}

// Ping reports whether the database answers.
func (p *Postgres) Ping(ctx context.Context) error {
	if err := p.pool.Ping(ctx); err != nil {
		return fmt.Errorf("store: %w", err)
	}
	return nil
}
