# FND-038 — Suite helper: a test Organization and a Blueprint install

## In plain words

**The problem today.** A check of the acceptance suite that needs an Organization with an Application in it has to write its own set-up: the calls that create the Organization, install the Blueprint and remove both again, and the waits between them. Only the isolation journey has such a set-up today, inside its own code, so every new check of another area would copy it once more.

**What changes.** The suite has one helper with three calls: create a test Organization unless it exists, install a named Blueprint in it, and remove the Organization with what it holds. Each goes through the console API only and waits, within a time limit, until the API reports the object ready or gone.

**Done means:**

- A check can create a test Organization, install a named Blueprint in it and remove both with three calls of the suite, and each call returns only when the console API reports the object ready or gone, or fails when its time limit is over.
- An Organization that already exists and is ready is not created a second time.
- The helper refuses an Organization whose name does not start with gate-, and a run without a console session, before it sends anything.
- The tests of the helper answer from recorded console responses with no cluster, and prove a pass and a failure for each of the three calls.
- The suite still uses the standard library only, and no journey of the suite changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
After this ticket the package `suite` of the acceptance suite (`tests/acceptance/sovereign/internal/suite/`) has three exported functions in the new file `fixture_org.go`: `EnsureOrganization`, `InstallBlueprint` and `RemoveOrganization`. A check that needs a test Organization with an Application installed calls them instead of writing its own set-up. They go through the console API of the check (`cc.API`) and nothing else, and each waits, within a time limit, until the API reports the object ready or gone. The calls and their bodies are the ones journey ISO already makes (`check_org_isolation.go`); the three that change state are the entries `POST /api/v1/organizations`, `POST /catalyst/v1/apps/instances` and `DELETE /api/v1/organizations/{id}` of the route table `docs/contracts/C9-mutating-routes.yaml`. The new file `fixture_org_test.go` proves each function against recorded answers of a local HTTP test server, with no cluster.

## 3. The model (the law)
1. **Three functions.** `EnsureOrganization(ctx context.Context, cc *CheckContext, slug string) error`, `InstallBlueprint(ctx context.Context, cc *CheckContext, org, blueprint, name string, values map[string]any) error` and `RemoveOrganization(ctx context.Context, cc *CheckContext, slug string) error`.
2. **The console API only.** Every call goes through `cc.API` (`Do` and `Get` of `tests/acceptance/sovereign/internal/api/client.go`). No `kubectl`, no `os/exec`, no other client. When `cc` or `cc.API` is nil (a run without a console session) the function returns an error and sends nothing; there is no fallback.
3. **Only slugs of the gate.** All three functions refuse, before any call, a slug that does not match `^gate-[a-z0-9]([a-z0-9-]{0,56}[a-z0-9])?$`.
4. **The routes and bodies of journey ISO.**
   - `POST /api/v1/organizations` with `{"subdomain": slug, "admin_email": slug + "@acceptance.invalid", "kind": "internal", "plan_slug": "m"}`; the answer must be 202 with an `org_tenant_id`. Plan `m` is the plan of the Organization in which journey ISO installs its Application (`isoPlanA`).
   - `POST /catalyst/v1/apps/instances` with `{"blueprint", "org", "environment", "name", "topology": "singleton", "placement": {"regions": [the first region of the run]}, "values"}`; the Environment is the first that `GET /api/v1/refs/organizations/{slug}/environments` lists; the answer must be 201. `values` nil means the chart's defaults.
   - `DELETE /api/v1/organizations/{id}` with no body, where `{id}` is the `org_tenant_id` that `GET /api/v1/organizations` lists for the slug; the answer must be 2xx.
5. **Ensure creates once.** `EnsureOrganization` reads `GET /api/v1/organizations`. A row of the slug whose state is not `deleted` is not created again; when that row is `done`, nothing else is sent. Otherwise it reads `GET /api/v1/organizations/{id}` until `state` is `done`; `failed` ends the wait at once with the row's `last_error`.
6. **Ready and gone.** `InstallBlueprint` waits until `GET /api/v1/sovereigns/{deployment}/applications/{name}?namespace={slug}` reports `Ready=True`, read with `appView.ready` of `journeys.go`. An Application lives in the namespace of its Organization, which is the slug. `RemoveOrganization` waits until `GET /api/v1/organizations/{slug}` answers 404 with the error `org-tenant-not-found` (neither the record nor the Organization CR is left) and `GET /api/v1/sovereigns/{deployment}/applications` lists no Application in the namespace of the slug. A 404 of another kind, such as an unknown route, is not gone.
7. **The waits of journey ISO.** 30 minutes for the Organization, 25 for the Application, 15 for the removal, one read every 10 seconds.
8. **Nothing else changes.** No other file of the suite changes, no check is added, `go.mod` gains no requirement, and `journeys.go` and `match.go` are not touched.

// The helper of a test Organization (FND-038). A check that needs an
// Organization with a Blueprint installed calls EnsureOrganization,
// InstallBlueprint and RemoveOrganization instead of writing its own set-up.

//

//	DELETE /api/v1/organizations/{id}   no body, answers 2xx
//

	LastError string `json:"last_error"`

	switch {
	case cc == nil || cc.API == nil:

		return fmt.Errorf("the slug %q is not a slug of the gate: it starts with gate- and is a DNS label", slug)
	}
	return nil
}

		Items []fixtureOrgRow `json:"items"`

		return nil, err

		}

	return nil, nil

// EnsureOrganization creates the Organization slug, unless it exists, and

func EnsureOrganization(ctx context.Context, cc *CheckContext, slug string) error {

		return err
	}

	if err != nil {
		return err
	}
	if row == nil {
		body := map[string]any{"subdomain": slug, "admin_email": slug + "@acceptance.invalid", "kind": "internal", "plan_slug": fixturePlan}

			return err
		}

			return fmt.Errorf("POST /api/v1/organizations %s: HTTP %d (want 202): %s", slug, res.Status, trunc(string(res.Body), 300))

		}

			return fmt.Errorf("POST /api/v1/organizations %s answered no org_tenant_id", slug)
		}

	}

}

// InstallBlueprint installs the Application name of blueprint, with values

		return err

		}

			return false, err.Error(), nil
		}

			Error string `json:"error"`
		}

		}

	})
	if err != nil {
		return fmt.Errorf("the Organization %s is not gone: %w", slug, err)
	}
	return nil
}

	key := r.Method + " " + r.URL.RequestURI()
	c.calls = append(c.calls, key)
	if b, _ := io.ReadAll(r.Body); len(b) > 0 {
		c.bodies = append(c.bodies, key+" "+string(b))
	}
	q := c.answers[key]
	if len(q) == 0 {
		w.WriteHeader(599)
		return
	}
	a := q[0]
	if len(q) > 1 {
		c.answers[key] = q[1:]
	}
	status, body, _ := strings.Cut(a, " ")
	code, err := strconv.Atoi(status)
	if err != nil {
		code = 599
	}
	w.WriteHeader(code)
	_, _ = io.WriteString(w, body)
}

// fixtureRun starts the console with answers and runs fn against it with the
// waits of a test. It returns the calls, the bodies and the error of fn.
func fixtureRun(t *testing.T, answers map[string][]string, fn func(ctx context.Context, cc *CheckContext) error) (string, string, error) {
	t.Helper()
	saved := fixtureWaits
	fixtureWaits.org, fixtureWaits.app, fixtureWaits.gone, fixtureWaits.every = 300*time.Millisecond, 300*time.Millisecond, 300*time.Millisecond, time.Millisecond
	defer func() { fixtureWaits = saved }()
	c := &fixtureConsole{answers: answers}
	srv := httptest.NewServer(c)
	defer srv.Close()
	cc := &CheckContext{API: api.New(srv.URL, "s"), Deploy: &DeploymentInfo{ID: "dep-1"}, Regions: []kube.Region{{ID: "r-a"}, {ID: "r-b"}}}
	err := fn(context.Background(), cc)
	c.mu.Lock()
	defer c.mu.Unlock()
	return strings.Join(c.calls, ", "), strings.Join(c.bodies, ", "), err
}

func fixtureWant(t *testing.T, what, got, want string) {
	t.Helper()
	if got != want {
		t.Errorf("%s:\n got %s\nwant %s", what, got, want)
	}
}

func fixtureFails(t *testing.T, err error, want string) {
	t.Helper()
	if err == nil || !strings.Contains(err.Error(), want) {
		t.Errorf("error %v, want one that says %q", err, want)
	}
}
