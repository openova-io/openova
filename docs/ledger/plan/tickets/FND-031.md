# FND-031 — Gate manifest and verdict tool; the mode and the override go

## In plain words

**The problem today.** The switch that decides whether a release may go out has a report-only mode that never stops anything, and a keyword in a pull request's text can override it. So today the gate cannot stop a bad release.

**What changes.** One tool decides whether each automatic check counts as passed. A check that is about installing counts only after two fresh installations agree. Every other check counts when two runs on a Sovereign at the same release agree. The report-only mode and the override are removed. A check can only move forward, never back.

**Done means:**

- The override keyword and the mode appear nowhere in the scripts and workflows.
- A change that moves a check backward is refused.
- The tool lists every check and never shows a check that is not built as passed.
- The tool's own tests pass.
- An index of the nine contracts exists.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`scripts/acceptance-gate.py` is a new tool with five commands: `validate`, `verdict`, `validate-record`, `export` and `--self-test`. `validate` refuses a change of `docs/ledger/gates.yaml` that moves a check backward, or that sets a check to `required` from a package other than the one the entry names. `verdict` says which checks are green by one pass rule: two consecutive gate records of one candidate that agree, the newer one no older than the manifest's `max_age_days` (14 today). Every check of the manifest declares its kind of proof. A `fresh` check is about installing, handing over or wiping, and only records of fresh installations count for it. A `running` check counts every such record, whether the Sovereign was installed fresh or updated in place. The repository variable `ACCEPTANCE_GATE_MODE`, the default mode `report` and the token `ACCEPTANCE-OVERRIDE:` are gone from the scripts and the workflows. The job `acceptance-gate` is gone from `.github/workflows/catalyst-build.yaml`. A new workflow, `gate-manifest`, runs the self-test and `validate` on every pull request. `docs/contracts/README.md` lists the nine contracts. `tests/acceptance/sovereign/README.md` describes the new commands.

## 3. The model (the law)
1. `scripts/acceptance-gate.py` is the file of the embedded block `acceptance-gate.py`, byte for byte. It has these commands and no other: `validate --base <ref> --body-file <file>`, `verdict [--check <id>] [--json]`, `validate-record <file>`, `export`, `--self-test`.
2. The tool has no mode, no override and no environment variable that changes a result. The strings `ACCEPTANCE_GATE_MODE` and `ACCEPTANCE-OVERRIDE` occur in no file under `scripts/` and `.github/`.
3. This package does not write `docs/ledger/gates.yaml` and does not write `docs/ledger/plan.yaml`. Both are on `main` already. When `docs/ledger/gates.yaml` is missing, `validate` prints the one line `docs/ledger/gates.yaml is missing` and exits 1; `verdict`, `validate-record` and `export` print the one line `acceptance-gate.py: docs/ledger/gates.yaml is missing` on standard error and exit 2. When `docs/ledger/plan.yaml` is missing, `validate` prints the failure line `rule 6: docs/ledger/plan.yaml is missing`, then its summary line, and exits 1.
4. When the manifest is valid, `validate` prints the one line `docs/ledger/gates.yaml: valid, <n> checks` and exits 0. When it is not valid, `validate` prints one line per failure, then the one summary line `docs/ledger/gates.yaml: not valid, <n> failure(s)`, and exits 1. Each failure line starts with `rule <number>: `. When rule 1 fails, only the lines of rule 1 are printed, because the other rules need a well-formed manifest. `validate` exits 2 when it cannot run: `<ref>` is not a commit, the body file cannot be read, the manifest or the plan is not valid YAML, or the YAML library is not installed. It then prints one line on standard error that starts with `acceptance-gate.py: `. A missing manifest is not one of these cases: it is the exit code 1 of item 3. Its seven rules:
   - Rule 1. The schema holds. The manifest has the fields `schema`, `pass_rule`, `retired_ids` and `checks`, and no other. `schema` is `openova.io/gates/v1`. `pass_rule` holds exactly `consecutive` and `max_age_days`; `consecutive` is 2; `max_age_days` is a whole number from 1 to 90. `retired_ids` is a list of check identifiers, each once. A check has the fields `id`, `title`, `owner`, `state`, `runs_in`, `destructive`, `needs`, `proof`, `asserts` and `delivered_by`, may have `implementation` and `implemented_by`, and has no other field. An `id` matches `^[A-Z]{3}-G[0-9]{2}$` and is used once; the checks are sorted by `id`; `title` has 1 to 100 characters; `owner` equals the first three letters of the `id` and is one of ACC, AIP, BSS, CLD, CMP, CTL, FND, INF, MIG, NET, PRD, SEC, SOV, SVC; `state` is `not-built`, `expected-fail` or `required`; `runs_in` is a non-empty list of `local`, `cloud`, `self`, each once, and holds `local` or `cloud`; `destructive` is true or false; `needs` is a list, each value once, and every value is in the closed list of item 5; `proof` is `fresh` or `running`, and a check without `proof` or with another value is refused; `asserts` is a non-empty string; `implementation`, when present, is a non-empty string; `implemented_by`, when present, is a package identifier; `delivered_by` is a package identifier; an identifier in `retired_ids` is not used by a check. A package identifier matches `^[A-Z]{3}-([0-9]{3}|S[0-9])$`.
   - Rule 2. Forward only. A check that exists at `<ref>` keeps its state or moves later in the order `not-built`, `expected-fail`, `required`.
   - Rule 3. A check whose state is not `not-built` has an `implementation` path that exists and is of an allowed kind: a Go file under `tests/acceptance/sovereign/`; a folder under `products/catalyst/bootstrap/ui/e2e/gate/` or `core/marketplace/e2e/gate/` that holds at least one file ending in `.spec.ts`; a file under `scripts/`. Any other path is refused. The tool does not look for a registration of the check in the Go suite: package FND-032 adds that clause.
   - Rule 4. A change of state to `required` is accepted only when the body names the package of `delivered_by`. A change to `expected-fail` is accepted from the package of `implemented_by`, from the package of `delivered_by`, or from `PLAN`.
   - Rule 5. A check is removed only when its identifier is in `retired_ids` and the body carries `Decision: ADR-NNNN`, where the file `docs/adr/NNNN-*.md` has the line `Status: Accepted` and the line `Retires-Check: <id>`. An identifier never leaves `retired_ids`.
   - Rule 6. `delivered_by` names a package of `docs/ledger/plan.yaml` whose `flips` holds the check. `implemented_by`, when present, names a package whose `implements` holds it.
   - Rule 7. Adding a check, changing a field of a check other than `state` and `implementation`, or changing `pass_rule`, needs `Work-Package: PLAN` in the body. A change of `proof` is such a change.
5. The closed list of `needs` values: `multi-region`, `upgrade-path`, `previous-wipe`, `model-simulation`, `model-selfhosted`, `host-security-service`, `nested-virtualization`, `vsphere-lab`, `windows-target`, `product-ai-hub`, `model-transcription`, `product-open-banking`, `gpu`.
6. The body file is the text of the pull-request body. Every line `Work-Package: <ID>` in it names a package, and every line `Decision: ADR-NNNN` names a decision record. A rule that asks for a package passes when one of the named packages is the right one.
7. `verdict` prints one line per check: identifier, state, proof, `green` or `not-green`, reason. The reason of a check that is not green starts with `pass rule <n>: `, where `<n>` is the number of the pass rule that failed. Before the list it prints on standard error one line `note: <file> does not count: <reason>` for each record that does not count, and one line `note: <file> counts for running checks only: provision.fresh is not true` for each record that counts and is not of a fresh installation. With `--json` it prints `{"checks": [{"id", "state", "proof", "green", "reason"}]}`. With `--check <id>` it prints that check only and exits 0 if the check is green and 1 if it is not. An `<id>` that is not in the manifest prints the line `<id>: not a check of docs/ledger/gates.yaml` on standard error, after those notes, and exits 1. Without `--check` it exits 0 when the list was printed. Its rules:
   - Pass rule 1. A record counts if `schema` is `openova.io/acceptance-sovereign/v2`, `run_in` is `cloud`, `producer.kind` is `workflow`, `candidate.id` is not empty, `candidate.commit` is 40 hexadecimal characters and an ancestor of `origin/main`, the ref `origin/rc/<candidate.id>` points at `candidate.commit`, `suite_git_sha` equals `candidate.commit`, and `started_at` and `finished_at` are times. Such a record counts for every `running` check. Its `provision.fresh` may be true or false: the environment may have been updated in place. It counts for a `fresh` check only when, in addition, `provision.fresh` is true. A version 1 record never counts. A record with `producer.kind: manual` never counts.
   - Pass rule 2. The pair is formed for each kind of proof, from the counting records ordered by `finished_at`. For a `running` check the pair is the two newest counting records, fresh or not; their `deployment_id` values may be the same. For a `fresh` check the pair is the two newest counting records whose `provision.fresh` is true; their `deployment_id` values must both be present, not empty, and differ. In both kinds the pair is valid if both records name the same `candidate.id`, the older one finished before the newer one started, every release name has the same chart versions in both, and every image reference that both list has the same digest in both. A record that has no `artifacts.charts` list or no `artifacts.images` list, or an empty one, makes the pair not valid.
   - Pass rule 3. A check with `cloud` in `runs_in` is green if its state is not `not-built`, the pair of its kind is valid, the newer record's `finished_at` is at most `max_age_days` old, the check applied in at least one record of the pair, and it has status `PASS` in every record of the pair in which it applied. A check applied in a record when every value of its `needs` is in that record's `capabilities`. A check in state `not-built` is never green, whatever the records say.
   - Pass rule 4. A check without `cloud` in `runs_in` is green when its state is `required`.
   - The rule that a reason names. Pass rule 2: fewer than two records count for the kind of the check, or the pair is not valid. Pass rule 3: the state is `not-built`, the newer record is too old, the check applied in no record of the pair, or a status is not `PASS`. Pass rule 4: the check does not run in the cloud and its state is not `required`. A record that fails pass rule 1 is named in a note, not in a reason.
   - A green check in state `expected-fail` is printed with the reason starting `unexpected pass:`.
8. `validate-record <file>` checks a version 2 record. When the record is valid it prints the one line `<file>: valid` and exits 0. When it is not, it prints one line per fault, each starting with `<file>: `, and exits 1. A file that is not JSON is one fault. A file that cannot be read exits 2. The fields it accepts are exactly these: `schema`, `run_id`, `env`, `console`, `deployment_id`, `mode`, `run_in` (`local` or `cloud`), `capabilities`, `suite_git_sha`, `started_at`, `finished_at`, `result`, `candidate` (`id`, `commit`), `producer` (`kind` of `workflow` or `manual`, `workflow`, `run_id`, `run_attempt`), `provision` (`provider`, `created_at`, `ready_at`, `regions` with `id`, `nodes_requested`, `nodes_ready`, and `fresh`), `checks` (`id`, `state_at_run`, `status`, `reason`), `journeys`, `subject`, `steps`. Any other field is refused. A later package adds a field to the table `RECORD` of the tool in the pull request that adds the field's writer or reader. Pass rule 5: a record may say `result: PASS` only if every check in it with `state_at_run: required` has status `PASS`, or has status `SKIP` while a value of its `needs` is missing from `capabilities`.
9. `export` prints the manifest as JSON on standard output.
10. `--self-test` needs the Python standard library only. The YAML library is imported inside the function `parse_yaml` and nowhere else. It has one case or more for each rule, among them: a `running` check is green from two in-place records of one candidate; a `fresh` check is not green from those same two records; a `fresh` check is green from two fresh records with different deployment identifiers; a manifest entry without `proof` is refused; the value `sometimes` is refused. The self-test prints one line per case and ends with `SELF-TEST OK (97 cases)`.
11. `.github/workflows/catalyst-build.yaml` has no job `acceptance-gate` and no comment block about it. The job `deploy` has `needs: [build-ui, build-api]`.
12. `.github/workflows/gate-manifest.yaml` is the file of the embedded block `gate-manifest.yaml`. It runs on `pull_request` and on `merge_group`, with no path filter. It runs the self-test before it installs PyYAML. On a pull request it runs `validate --base "HEAD^1"` with the pull-request body. On a merge group it runs `validate --base HEAD --body-file /dev/null`, which checks rules 1, 3 and 6 on the merged tree.
13. `docs/contracts/README.md` is the file of the embedded block `contracts-README.md`. Its table has nine rows, C1 to C9.
14. In `tests/acceptance/sovereign/README.md` the bullet `Deploy.` is replaced by the bullet `Gate.`, and the heading above it ends in "the gate manifest".
15. Not allowed: a `--mode` flag kept for compatibility; a `verdict --check` that exits 0 for a check that is not green; a new variable, flag or commit-message token that opens the gate.

on:

permissions:

        return out
    ids = []
    for i, c in enumerate(checks):
        if not isinstance(c, dict) or not isinstance(c.get("id"), str):
            bad(f"checks[{i}] has no id")
            continue
        cid = c["id"]
        ids.append(cid)
        for k in c:
            if k not in CHECK_FIELDS:
                bad(f"{cid}: unknown field {k}")
        if not CHECK_ID.match(cid):
            bad(f"{cid}: the id must match {CHECK_ID.pattern}")
        title = c.get("title")
        if not isinstance(title, str) or not 1 <= len(title) <= TITLE_MAX:
            bad(f"{cid}: title must be a string of 1 to {TITLE_MAX} characters")
        if c.get("owner") not in AREAS or c.get("owner") != cid[:3]:
            bad(f"{cid}: owner must be an area and equal the prefix of the id")
        if c.get("state") not in STATES:
            bad(f"{cid}: state must be one of {', '.join(STATES)}")
        ri = c.get("runs_in")
        if (not isinstance(ri, list) or not ri or any(x not in RUNS_IN for x in ri) or len(set(ri)) != len(ri)):
            bad(f"{cid}: runs_in must be a non-empty list of {', '.join(RUNS_IN)}, each once")
        elif "local" not in ri and "cloud" not in ri:
            bad(f"{cid}: runs_in must hold local or cloud")
        if not isinstance(c.get("destructive"), bool):
            bad(f"{cid}: destructive must be true or false")
        needs = c.get("needs")
        if not isinstance(needs, list) or len(set(map(str, needs))) != len(needs):
            bad(f"{cid}: needs must be a list, each value once")
        else:
            for x in needs:
                if x not in CAPABILITIES:
                    bad(f"{cid}: needs value {x} is not in the closed list")
        if not isinstance(c.get("proof"), str) or c["proof"] not in PROOFS:
            bad(f"{cid}: proof must be one of {', '.join(PROOFS)}")
        if not isinstance(c.get("asserts"), str) or not c["asserts"].strip():
            bad(f"{cid}: asserts must be a sentence")
        if "implementation" in c and (not isinstance(c["implementation"], str) or not c["implementation"].strip()):
            bad(f"{cid}: implementation must be a path")
        if "implemented_by" in c and (not isinstance(c["implemented_by"], str) or not PACKAGE_ID.match(c["implemented_by"])):
            bad(f"{cid}: implemented_by must be a package identifier")
        if not isinstance(c.get("delivered_by"), str) or not PACKAGE_ID.match(c["delivered_by"]):
            bad(f"{cid}: delivered_by must be a package identifier")
    for cid in sorted(set(x for x in ids if ids.count(x) > 1)):
        bad(f"{cid}: the id is used more than once")
    if ids != sorted(ids):
        bad("checks are not sorted by id")
    for cid in ids:
        if cid in retired:
            bad(f"{cid}: a retired id is never used again")
    return out


def implementation_problem(root, c):
    """Rule 3 for one check: None, or what is wrong with its implementation path."""
    path = c.get("implementation")
    if not path:
        return f"state is {c['state']} but there is no implementation"
    norm = os.path.normpath(path).replace(os.sep, "/")
    if os.path.isabs(path) or norm.startswith("../") or norm == "..":
        return f"implementation {path} is not a path inside the repository"
    full = os.path.join(root, norm)
    if norm.startswith(GO_SUITE) and norm.endswith(".go"):
        # A Go file of the suite. Package FND-032 adds the registration clause here.
        return None if os.path.isfile(full) else f"implementation {path} does not exist"
    for harness in BROWSER_ROOTS:
        if (norm + "/").startswith(harness) and norm + "/" != harness:
            if not os.path.isdir(full):
                return f"implementation {path} does not exist"
            for _, _, files in os.walk(full):
                if any(f.endswith(".spec.ts") for f in files):
                    return None
            return f"implementation {path} holds no file ending in .spec.ts"
    if norm.startswith(SCRIPTS):
        return None if os.path.isfile(full) else f"implementation {path} does not exist"
    return (f"implementation {path} is not of an allowed kind (a Go file under {GO_SUITE}, a folder under "
            f"{' or '.join(BROWSER_ROOTS)}, or a script under {SCRIPTS})")


def trailers(body):
    """The packages and the decision records that the pull-request body names."""
    wp = set(re.findall(r"^Work-Package: (\S+)[ \t\r]*$", body, re.M))
    dec = set(re.findall(r"^Decision: (ADR-[0-9]{4})[ \t\r]*$", body, re.M))
    return wp, dec


def adr_retires(root, decision, cid):
    """True if docs/adr/NNNN-*.md has the lines `Status: Accepted` and `Retires-Check: <cid>`."""
    for p in sorted(glob.glob(os.path.join(root, ADR_DIR, decision[4:] + "-*.md"))):
        with open(p, encoding="utf-8") as fh:
            lines = [ln.rstrip() for ln in fh.read().split("\n")]
        if "Status: Accepted" in lines and f"Retires-Check: {cid}" in lines:
            return True
    return False


def checks_by_id(m):
    if not isinstance(m, dict) or not isinstance(m.get("checks"), list):
        return {}
    return {c["id"]: c for c in m["checks"] if isinstance(c, dict) and isinstance(c.get("id"), str)}


def validate_manifest(now, base, body, plan, root):
    """Failure lines for the manifest `now`.

    base  the manifest at the base ref, or None when it has none
    body  the text of the pull-request body
    plan  the parsed docs/ledger/plan.yaml, or None when the file is missing
    root  the repository root, for rule 3 and rule 5
    """
    out = rule1(now)
    if out:
        return out          # the other rules need a well-formed manifest
    wp, decisions = trailers(body)
    said = ", ".join(sorted(wp)) or "no package"
    new, old = checks_by_id(now), checks_by_id(base)
    # rule 2
    for cid, o in old.items():
        n = new.get(cid)
        before = STATES.index(o["state"]) if o.get("state") in STATES else 0
        if n is not None and STATES.index(n["state"]) < before:
            out.append(f"rule 2: {cid}: the state moved backward, from {o['state']} to {n['state']}")
    # rule 3
    for cid, n in new.items():
        if n["state"] != "not-built":
            problem = implementation_problem(root, n)
            if problem:
                out.append(f"rule 3: {cid}: {problem}")
    # rule 4
    for cid, n in new.items():
        was = old[cid].get("state") if cid in old else None
        if n["state"] == "required" and was != "required":
            if n["delivered_by"] not in wp:
                out.append(f"rule 4: {cid}: only {n['delivered_by']} sets it to required; the body names {said}")
        elif n["state"] == "expected-fail" and was in (None, "not-built"):
            allowed = {n["delivered_by"], "PLAN"} | ({n["implemented_by"]} if "implemented_by" in n else set())
            if not wp & allowed:
                out.append(f"rule 4: {cid}: only {', '.join(sorted(allowed))} set it to expected-fail; the body names {said}")
    # rule 5
    retired_now = now["retired_ids"]
    for cid in old:
        if cid in new:
            continue
        if cid not in retired_now:
            out.append(f"rule 5: {cid}: removed, but not added to retired_ids")
        elif not any(adr_retires(root, d, cid) for d in decisions):
            out.append(f"rule 5: {cid}: removed without `Decision: ADR-NNNN` naming an accepted record with `Retires-Check: {cid}`")
    if isinstance(base, dict) and isinstance(base.get("retired_ids"), list):
        for cid in base["retired_ids"]:
            if cid not in retired_now:
                out.append(f"rule 5: {cid}: a retired id may not leave retired_ids")
    # rule 6
    if plan is None:
        out.append(f"rule 6: {PLAN} is missing")
    elif not isinstance(plan, dict) or not isinstance(plan.get("packages"), list):
        out.append(f"rule 6: {PLAN} has no packages list")
    else:
        packages = {p.get("id"): p for p in plan["packages"] if isinstance(p, dict)}
        for cid, n in new.items():
            for field, listed in (("delivered_by", "flips"), ("implemented_by", "implements")):
                if field not in n:
                    continue
                p = packages.get(n[field])
                if p is None:
                    out.append(f"rule 6: {cid}: {field} {n[field]} is not a package of {PLAN}")
                elif cid not in (p.get(listed) or []):
                    out.append(f"rule 6: {cid}: package {n[field]} does not list it in {listed}")
    # rule 7
    if "PLAN" not in wp:
        for cid, n in new.items():
            if cid not in old:
                out.append(f"rule 7: {cid}: adding a check needs Work-Package: PLAN")
                continue
            changed = [f for f in CHECK_FIELDS if f not in ("state", "implementation") and old[cid].get(f) != n.get(f)]
            if changed:
                out.append(f"rule 7: {cid}: a change of {', '.join(changed)} needs Work-Package: PLAN")
        if isinstance(base, dict) and base.get("pass_rule") != now["pass_rule"]:
            out.append("rule 7: a change of pass_rule needs Work-Package: PLAN")
    return out

class GitFacts:
    """What the pass rule asks Git."""

    def __init__(self, root):
        self.root = root

    def is_ancestor(self, commit):
        return git(self.root, "merge-base", "--is-ancestor", commit, "origin/main").returncode == 0

    def rc_commit(self, candidate_id):
        r = git(self.root, "rev-parse", "--verify", "--quiet", f"refs/remotes/origin/rc/{candidate_id}^{{commit}}")
        return r.stdout.strip() if r.returncode == 0 else None


def not_counting(rec, facts):
    """Pass rule 1: None if the record counts, else the reason it does not."""
    if not isinstance(rec, dict):
        return "it is not a JSON object"
    if rec.get("schema") != RECORD_SCHEMA:
        return "the schema is not version 2"
    if rec.get("run_in") != "cloud":
        return "run_in is not cloud"
    producer = rec.get("producer")
    if not isinstance(producer, dict) or producer.get("kind") != "workflow":
        return "producer.kind is not workflow"
    cand = rec.get("candidate") if isinstance(rec.get("candidate"), dict) else {}
    cid, commit = cand.get("id"), cand.get("commit")
    if not isinstance(cid, str) or not cid:
        return "candidate.id is empty"
    if not isinstance(commit, str) or not HEX40.match(commit):
        return "candidate.commit is not a commit id"
    if not facts.is_ancestor(commit):
        return "candidate.commit is not an ancestor of origin/main"
    if facts.rc_commit(cid) != commit:
        return f"the ref origin/rc/{cid} does not point at candidate.commit"
    if rec.get("suite_git_sha") != commit:
        return "suite_git_sha differs from candidate.commit"
    if parse_time(rec.get("started_at")) is None or parse_time(rec.get("finished_at")) is None:
        return "started_at or finished_at is not a time"
    return None


def is_fresh(rec):
    """Pass rule 1: True if the record is of a fresh installation. Only such a record counts for a `fresh` check."""
    provision = rec.get("provision")
    return isinstance(provision, dict) and provision.get("fresh") is True


def counting_records(records, facts, notes=None):
    """Pass rule 1. records is a list of (name, record). Returns the records that count, the oldest first."""
    counting = []
    for name, rec in records:
        why = not_counting(rec, facts)
        if why is not None:
            if notes is not None:
                notes.append(f"{name} does not count: {why}")
            continue
        counting.append((name, rec))
        if notes is not None and not is_fresh(rec):
            notes.append(f"{name} counts for running checks only: provision.fresh is not true")
    counting.sort(key=lambda x: parse_time(x[1]["finished_at"]))
    return counting


def artefacts(rec):
    """({release: versions}, {image reference: digests}), or None when the record has no artefact list."""
    art = rec.get("artifacts")
    if not isinstance(art, dict):
        return None
    charts, images = art.get("charts"), art.get("images")
    if not isinstance(charts, list) or not charts or not isinstance(images, list) or not images:
        return None
    cm, im = {}, {}
    for e in charts:
        if not isinstance(e, dict) or not isinstance(e.get("release"), str) or not isinstance(e.get("version"), str):
            return None
        cm.setdefault(e["release"], set()).add(e["version"])
    for e in images:
        if not isinstance(e, dict) or not isinstance(e.get("ref"), str) or not isinstance(e.get("digest"), str):
            return None
        im.setdefault(e["ref"], set()).add(e["digest"])
    return cm, im


def find_pair(counting, proof, total):
    """Pass rule 2 for one kind of proof. counting is what counting_records returned; total is the number of
    records that were read. Returns ((older, newer), None) or (None, reason)."""
    pool = [x for x in counting if is_fresh(x[1])] if proof == "fresh" else counting
    if len(pool) < 2:
        return None, f"no pair: {len(pool)} of {total} records count for a {proof} check"
    older, newer = pool[-2], pool[-1]
    names = f"{older[0]} and {newer[0]}"
    if older[1]["candidate"]["id"] != newer[1]["candidate"]["id"]:
        return None, f"no valid pair: {names} name different candidates"
    if proof == "fresh":
        first, second = older[1].get("deployment_id"), newer[1].get("deployment_id")
        if not first or not second or first == second:
            return None, f"no valid pair: {names} do not have two different deployment_id values"
    if not parse_time(older[1]["finished_at"]) < parse_time(newer[1]["started_at"]):
        return None, f"no valid pair: {older[0]} did not finish before {newer[0]} started"
    a, b = artefacts(older[1]), artefacts(newer[1])
    if a is None or b is None:
        return None, f"no valid pair: {older[0] if a is None else newer[0]} has no artefact list"
    if a[0] != b[0]:
        differ = sorted(k for k in set(a[0]) | set(b[0]) if a[0].get(k) != b[0].get(k))
        return None, f"no valid pair: chart versions differ for release {differ[0]}"
    for ref in sorted(set(a[1]) & set(b[1])):
        if a[1][ref] != b[1][ref]:
            return None, f"no valid pair: image digests differ for {ref}"
    return (older, newer), None


def status_in(rec, cid):
    for e in rec.get("checks") if isinstance(rec.get("checks"), list) else []:
        if isinstance(e, dict) and e.get("id") == cid:
            return e.get("status")
    return None


def verdict(m, records, facts, now, notes=None):
    """Pass rules 1 to 4: one row per check of the manifest. now is seconds since 1970.
    The reason of a check that is not green starts with the pass rule that failed."""
    counting = counting_records(records, facts, notes)
    pairs = {proof: find_pair(counting, proof, len(records)) for proof in PROOFS}
    max_age = m["pass_rule"]["max_age_days"]
    rows = []
    for c in m["checks"]:
        pair, why = pairs[c["proof"]]
        if "cloud" not in c["runs_in"]:
            green = c["state"] == "required"
            reason = ("it does not run in the cloud; required, proven by the local conformance run" if green
                      else f"pass rule 4: it does not run in the cloud and its state is {c['state']}")
        elif c["state"] == "not-built":
            green, reason = False, "pass rule 3: its state is not-built"
        elif pair is None:
            green, reason = False, "pass rule 2: " + why
        else:
            green, reason = cloud_verdict(c, pair, max_age, now)
            if not green:
                reason = "pass rule 3: " + reason
        rows.append({"id": c["id"], "state": c["state"], "proof": c["proof"], "green": green, "reason": reason})
    return rows


def cloud_verdict(c, pair, max_age, now):
    """Pass rule 3 for one check and a valid pair."""
    age = (now - parse_time(pair[1][1]["finished_at"])) / 86400.0
    if age > max_age:
        return False, f"the newer record {pair[1][0]} is {int(age)} days old; the limit is {max_age}"
    seen = []
    for name, rec in pair:
        declared = rec.get("capabilities") if isinstance(rec.get("capabilities"), list) else []
        if set(c["needs"]) <= set(declared):
            seen.append((name, status_in(rec, c["id"])))
    if not seen:
        return False, f"it applied in no record of the pair (needs {', '.join(c['needs'])})"
    failed = [f"{status or 'no result'} in {name}" for name, status in seen if status != "PASS"]
    if failed:
        return False, "; ".join(failed)
    text = f"PASS in {len(seen)} of 2 records of the pair, candidate {pair[1][1]['candidate']['id']}"
    return True, ("unexpected pass: " if c["state"] == "expected-fail" else "") + text


def load_records(root):

def check_value(v, kind, where, out):
    """Appends one line to out for each way v differs from kind."""
    if isinstance(kind, dict):
        if not isinstance(v, dict):
            out.append(f"{where}: must be an object")
            return
        for k in v:
            if k not in kind:
                out.append(f"{where + '.' if where else ''}{k}: unknown field")
        for k, (required, sub) in kind.items():
            if k in v:
                check_value(v[k], sub, f"{where + '.' if where else ''}{k}", out)
            elif required:
                out.append(f"{where + '.' if where else ''}{k}: missing")
    elif isinstance(kind, tuple) and kind[0] == "enum":
        if not isinstance(v, str) or v not in kind[1]:
            out.append(f"{where}: must be one of {', '.join(kind[1])}")
    elif isinstance(kind, tuple) and kind[0] == "list":
        if not isinstance(v, list):
            out.append(f"{where}: must be a list")
            return
        for i, x in enumerate(v):
            check_value(x, kind[1], f"{where}[{i}]", out)
    elif isinstance(kind, tuple) and kind[0] == "map":
        if not isinstance(v, dict):
            out.append(f"{where}: must be an object")
            return
        for k, x in v.items():
            check_value(x, kind[1], f"{where}.{k}", out)
    elif kind == "object":
        if not isinstance(v, dict):
            out.append(f"{where}: must be an object")
    elif kind == "str":
        if not isinstance(v, str):
            out.append(f"{where}: must be a string")
    elif kind == "int":
        if not is_int(v):
            out.append(f"{where}: must be a whole number")
    elif kind == "bool":
        if not isinstance(v, bool):
            out.append(f"{where}: must be true or false")
    elif kind == "time":
        if parse_time(v) is None:
            out.append(f"{where}: must be a time such as 2026-11-20T08:15:00Z")
    elif kind == "hex40":
        if not isinstance(v, str) or not HEX40.match(v):
            out.append(f"{where}: must be 40 hexadecimal characters")


def validate_record(rec, m):
    """Failure lines for one version 2 record. m is the manifest: it gives the `needs` of each check."""
    out = []
    if not isinstance(rec, dict):
        return ["the record is not a JSON object"]
    if rec.get("schema") != RECORD_SCHEMA:
        return [f"schema: must be {RECORD_SCHEMA}"]
    check_value(rec, RECORD, "", out)
    if out:
        return out          # the rules below need a well-formed record
    if not RUN_ID.match(rec["run_id"]):
        out.append(f"run_id: must match {RUN_ID.pattern}")
    if not rec["env"]:
        out.append("env: must not be empty")
    if parse_time(rec["finished_at"]) < parse_time(rec["started_at"]):
        out.append("finished_at: is earlier than started_at")
    if rec["run_in"] == "cloud":
        if not rec.get("deployment_id"):
            out.append("deployment_id: required when run_in is cloud")
        if "provision" not in rec:
            out.append("provision: required when run_in is cloud")
    cand = rec["candidate"]
    if cand["id"] and (not CANDIDATE_ID.match(cand["id"]) or not cand["id"].endswith("-" + cand["commit"][:7])):
        out.append("candidate.id: must be empty or <UTC yyyymmddThhmmssZ>-<first 7 characters of candidate.commit>")
    producer = rec["producer"]
    if producer["kind"] == "workflow":
        for k in ("workflow", "run_id"):
            if not producer.get(k):
                out.append(f"producer.{k}: required when kind is workflow")
        if "run_attempt" not in producer:
            out.append("producer.run_attempt: required when kind is workflow")
    needs = {c["id"]: c["needs"] for c in m["checks"]}
    seen = set()
    for i, e in enumerate(rec["checks"]):
        if e["id"] in seen:
            out.append(f"checks[{i}].id: {e['id']} is listed twice")
        seen.add(e["id"])
        if e["id"] not in needs:
            out.append(f"checks[{i}].id: {e['id']} is not a check of {MANIFEST}")
        if e["status"] != "PASS" and not e.get("reason"):
            out.append(f"checks[{i}].reason: required when status is not PASS")
    if rec["result"] == "PASS":         # pass rule 5
        for e in rec["checks"]:
            if e["state_at_run"] != "required" or e["status"] == "PASS":
                continue
            unmet = e["id"] in needs and not set(needs[e["id"]]) <= set(rec["capabilities"])
            if not (e["status"] == "SKIP" and unmet):
                out.append(f"result: is PASS, but required check {e['id']} has status {e['status']}")
    return out
