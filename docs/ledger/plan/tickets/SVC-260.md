# SVC-260 — provides, requires, the contract format, the registry and the install API

## In plain words

**The problem today.** A Blueprint cannot say which service it offers or which service it needs, so the install route can only wire a backing service that the caller names exactly. There is no written contract of what a consumer may rely on, and so no way to offer a second implementation of the same service.

**What changes.** Blueprints declare the capabilities they provide and require, a capability has a versioned contract file format and an index built from the tree, and the install route resolves a required capability to one implementation and gives the consumer the location of its connection files. A request that names the backing Blueprint as today gives the same result as before.

**Done means:**

- A Blueprint that provides a capability and is not shareable is refused by the schema.
- An install request that names a required capability creates or reuses a provider of the default implementation, and the consumer receives where its connection files will be mounted.
- An install request that leaves out a required capability, names one the Blueprint does not require, or asks for an implementation that is not offered is refused with its own error code and writes nothing.
- An install request that names the backing Blueprint as before writes the same objects as before.
- The capability index is written by a Go tool, and a pull request whose index is out of date turns red.
- No Python line is added and no gate check changes its state.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A Blueprint declares what it offers and what it needs: `spec.provides` (capability, contract version, implementation kind) and `spec.requires` (capability, contract version, alias, optional), in the cluster definition `products/catalyst/chart/crds/blueprint.yaml` and in `platform/_schemas/blueprint.schema.json`, where a Blueprint with `provides` must be `shareable: true`. The format of a capability contract file `platform/_capabilities/<name>.yaml` is `platform/_schemas/capability.schema.json`. The capability index `products/catalyst/bootstrap/api/internal/catalog/capabilities.json` is generated by `sh products/catalyst/bootstrap/api/internal/capability/write.sh` (a Go command) and kept in sync by the workflow `check-capability-index.yaml`. The new Go package `internal/capability` is the registry: which Blueprints implement a capability, which one is the default, and which one a request resolves to. The install route `POST /catalyst/v1/apps/instances` accepts a `backing[]` element that names a capability the consumer requires, refuses a wrong request before it writes anything, creates or reuses the provider Application of the resolved implementation with the canonical Context entry, and writes `spec.parameters.bindings.<alias>` on the consumer. A `backing[]` element that names a Blueprint, as every caller sends today, writes the same objects as on `main`.

## 3. The model (the law)
1. The definition `products/catalyst/chart/crds/blueprint.yaml` gains, after `contextSchema`, `spec.provides` (list map keyed by `capability`, at most 8; `capability` `^[a-z][a-z0-9-]{1,40}$`, `contract` `^v[1-9][0-9]*$`, `implementation` `in-cluster` or `cloud-native`) and `spec.requires` (list map keyed by `alias`, at most 8; `capability`, `contract`, `alias` `^[a-z][a-z0-9-]{0,30}$`, `optional` default false). No other field of the definition changes, and the Application definition is not changed.
2. `platform/_schemas/blueprint.schema.json` gains the same two fields with `additionalProperties: false` and the rule: a Blueprint with `provides` must be `shareable: true`. `products/catalyst/bootstrap/api/internal/blueprintedit/blueprint.schema.json` stays equal to it byte for byte (`TestSchemaCopyMatchesSource`), and `products/catalyst/bootstrap/api/internal/intent/crds/schemas.json` is regenerated from the definition (`TestSchemasMatchSources`).
3. `platform/_schemas/capability.schema.json` is the contract file format: `apiVersion: catalyst.openova.io/v1`, `kind: Capability`, `metadata.name` equal to the file name, `spec.title`, `spec.defaultImplementation`, optional `spec.compositeKind`, and `spec.contracts[]` with `version`, `status` (`current` or `deprecated`), `keys[]`, `contextFields[]` and `probe`. A context field may not take a name of the canonical Context entry (`name`, `capability`, `contract`, `alias`, `consumer`, `binding`). No contract file is added here: the first one enters with its first provider in SVC-270, because the index writer refuses a contract whose `defaultImplementation` does not provide it.
4. The index is generated, never edited by hand. `write.sh` runs the Go command `internal/capability/cmd/capability-index`, which reads every `platform/_capabilities/*.yaml` (checked against the schema) and the `provides` and `requires` of every `platform/*/blueprint.yaml` and `products/*/blueprint.yaml`. With `--check` it writes nothing, exits 1 when the committed index differs and 2 when an input is wrong: a contract outside the schema or not YAML, a contract name that is not its file name, a version listed twice, a context default of the wrong type, a `blueprint.yaml` that is not YAML, a `provides` or `requires` entry that names no contract file or no declared version, a `defaultImplementation` that does not provide its capability, a capability provided twice or an alias required twice by one Blueprint, a missing `platform/` or `products/` folder. A missing `platform/_capabilities/` folder is no error: the index is then an empty list. `scripts/generator_registry.py` lists the index with `write.sh` as its writer, from the path filters of its workflow.
5. The workflow `.github/workflows/check-capability-index.yaml` runs `write.sh --check` on every pull request and push to `main` that changes an input, the index, the package or the workflow, and in the merge group. The catalog package embeds the index (`catalog.CapabilitiesJSON`).
6. The registry (`capability.NewRegistry(index, Blueprint objects, Sovereign object, Availability)`): an implementation is usable when it is not deprecated, and a `cloud-native` one only when `Availability` says yes. The default is the Sovereign entry's default when it is offered, else the contract's `defaultImplementation` when it is offered, else the offered `in-cluster` implementation with the lowest name, else none. A Sovereign entry of `spec.catalog.capabilities[]` narrows the offered set and sets `organizationChoice`. `Resolve` fails with `ErrUnknownCapability`, `ErrWrongCapability`, `ErrNotOffered` or `ErrNoImplementation`. `Contract.ContextValues` fills the defaults of absent context fields and refuses an undeclared field, a value of the wrong type or outside its `enum`, and a required field with no value. The install route passes no Sovereign object and `NoCloudProfile` (no cloud-native implementation is available) until SVC-300 and the cloud profile give them.
7. `BackingSelection` (`internal/instances/create.go`) gains `capability`, `alias`, `implementation` and `context`; `blueprint` becomes optional. Shape errors, HTTP 400: `backing-ambiguous` (an element sets both `capability` and `blueprint`, or names an alias a second time), `backing-alias-required` (`capability` without `alias`), `backing-blueprint-required` (neither `capability` nor `blueprint`). `backing-alias-required` is not in the error list the design gave; it is added because the alias is the key of `requires`, and without it the element cannot be matched.
8. The capability path (package `internal/capability/binding`) is checked and resolved before anything is written; a refused request leaves no Application. HTTP 422: `requirement-missing` (a `requires` entry that is not optional has no element), `capability-not-required` (alias and capability are not a `requires` entry), `implementation-not-offered` (the requested or default implementation is not offered, or it provides another contract version), `implementation-wrong-capability` (the requested Blueprint does not provide the capability), `context-field-invalid`. HTTP 500 `capability-index-invalid`; HTTP 503 `blueprint-unavailable` when the Blueprint objects cannot be listed. The Blueprint objects are listed only when an element names a capability.
9. A resolved element takes the existing create or reuse branch with the resolved implementation Blueprint. In create mode the provider Application is named `<consumer>-<alias>`, so that two bindings of one capability are two Applications. The provider's Context entry has the canonical shape: `name`, `capability`, `contract`, `alias`, `consumer` (`blueprint`, `application`, `namespace`, `mode: shared`), `binding.path`, then the values of the contract's context fields. The consumer gets `spec.parameters.bindings.<alias>` with `capability`, `contract`, `path` and `mountPath: /bindings/<alias>`. The path is `mounted/data/<consumer namespace>/shared/binding-<alias>/e1`, inside the read rule of the mounted tier `mounted/data/<ns>/shared/*` of `platform/openbao/chart/templates/_config.tpl`. The install route is the only writer of the path and of `spec.parameters.bindings`; no connection value is written.
10. An element with `blueprint` set and `capability` empty takes the path it took before: provider name `<consumer>-<slug>`, Context entry `name`, `owner`, `consumer` (`blueprint`, `mode`) and `reflect` (`secretName`, `namespaces`), and the same objects as on `main` (`TestCreateInstance_BackingByBlueprint_ObjectsAsBeforeCapabilities`).
11. Nothing is deleted. No Python file is added or edited. No chart version line changes. No gate check moves: SVC-G02 stays `not-built`, because no second implementation exists before SVC-290.

+// Resolve checks a request against the consumer Blueprint's spec.requires and resolves every element of sels
+// that names a capability to one implementation. It writes nothing, so a refused request leaves no provider
+// Application behind. The result is indexed like sels; an element that names a Blueprint has nil. idx nil
+// means the embedded index. The Blueprint objects are listed only when an element names a capability.
+//
+// Refusals, HTTP 422: requirement-missing (a requires entry that is not optional has no element);
+// capability-not-required (the element's alias and capability are not a requires entry);
+// implementation-not-offered (the requested or default implementation is not offered on this Sovereign, or it
+// satisfies another contract version); implementation-wrong-capability (the requested Blueprint does not
+// provide the capability); context-field-invalid. HTTP 500 capability-index-invalid; HTTP 503
+// blueprint-unavailable when the Blueprint objects cannot be listed.
+func Resolve(ctx context.Context, client dynamic.Interface, idx capability.Index, consumer string, requires []capability.Requirement, sels []instances.BackingSelection) ([]*Resolved, *Refusal) {
+	refuse := func(code, format string, args ...interface{}) *Refusal {
+		return &Refusal{Status: http.StatusUnprocessableEntity, Code: code, Message: fmt.Sprintf(format, args...)}
+	}
+	sent := map[string]bool{}
+	for _, sel := range sels {
+		if sel.Capability != "" {
+			sent[sel.Alias] = true
+		}
+	}
+	byAlias := map[string]capability.Requirement{}
+	for _, req := range requires {
+		byAlias[req.Alias] = req
+		if !req.Optional && !sent[req.Alias] {
+			return nil, refuse("requirement-missing", "Blueprint %s requires %s %s as %q; the request has no backing element with that capability and alias",
+				consumer, req.Capability, req.Contract, req.Alias)
+		}
+	}
+	out := make([]*Resolved, len(sels))
+	var reg capability.Registry
+	for i, sel := range sels {
+		if sel.Capability == "" {
+			continue
+		}
+		req, ok := byAlias[sel.Alias]
+		if !ok || req.Capability != sel.Capability {
+			return nil, refuse("capability-not-required", "Blueprint %s does not require %s as %q", consumer, sel.Capability, sel.Alias)
+		}
+		if reg == nil {

+		}

+// Build reads the tree at root and returns the capability index (the bytes of capabilities.json), or the
+// input errors, one line each, naming the file. schema is platform/_schemas/capability.schema.json.
+//
+// Errors: a contract file that is not YAML or fails the schema; a contract whose metadata.name is not its
+// file name, or that lists one version twice, or whose field default or enum does not fit the field's type; a
+// blueprint.yaml that is not YAML; a Blueprint that provides one capability twice or requires one alias
+// twice; a provides or requires entry that names a capability or contract version with no contract file; a
+// contract whose defaultImplementation does not provide it; a missing platform/ or products/ folder. A
+// missing platform/_capabilities/ folder is no error: it holds no contract, so the index is an empty list.
+func Build(root string, schema []byte) ([]byte, []string) {
+	tree := os.DirFS(root)
+	var errs []string
+	compiled, err := compileSchema(schema)
+	if err != nil {
+		return nil, []string{SchemaPath + ": " + err.Error()}
+	}
+	contracts, cErrs := readContracts(tree, compiled)
+	errs = append(errs, cErrs...)
+
+	providers := map[string][]Provider{}
+	for _, top := range blueprintSources {
+		dirs, err := fs.ReadDir(tree, top)
+		if err != nil {
+			errs = append(errs, top+"/: input folder cannot be read: "+err.Error())
+			continue
+		}
+		for _, d := range dirs {
+			if !d.IsDir() {
+				continue
+			}
+			rel := top + "/" + d.Name() + "/blueprint.yaml"
+			raw, err := fs.ReadFile(tree, rel)
+			if errors.Is(err, fs.ErrNotExist) {
+				continue
+			}
+			if err != nil {
+				errs = append(errs, rel+": "+err.Error())
+				continue
+			}
+			var bp blueprintFile
+			if err := decodeYAML(raw, &bp, nil); err != nil {
+				errs = append(errs, rel+": not YAML: "+err.Error())
+				continue
+			}
+			errs = append(errs, checkBlueprint(rel, bp, contracts)...)
+			for _, p := range bp.Spec.Provides {
+				providers[p.Capability] = append(providers[p.Capability],
+					Provider{Blueprint: bp.Metadata.Name, Contract: p.Contract, Implementation: p.Implementation})
+			}
+		}
+	}
+
+	out := file{Comment: "Generated by " + WriteCommand + " from " + ContractsDir + "/*.yaml and every blueprint.yaml. Do not edit.",
+		Capabilities: []entry{}}
+	names := make([]string, 0, len(contracts))
+	for n := range contracts {
+		names = append(names, n)
+	}
+	sort.Strings(names)
+	for _, n := range names {
+		cf := contracts[n]
+		ps := providers[n]
+		sort.Slice(ps, func(i, j int) bool { return ps[i].Blueprint < ps[j].Blueprint })
+		def := false
+		for _, p := range ps {
+			def = def || p.Blueprint == cf.Spec.DefaultImplementation
+		}
+		if !def {
+			errs = append(errs, fmt.Sprintf("%s/%s.yaml: defaultImplementation %s does not provide %s (no blueprint.yaml of %s lists it in spec.provides)",
+				ContractsDir, n, cf.Spec.DefaultImplementation, n, strings.Join(blueprintSources, "/ or ")+"/"))
+		}
+		if ps == nil {
+			ps = []Provider{}
+		}
+		out.Capabilities = append(out.Capabilities, entry{Name: n, Title: cf.Spec.Title, DefaultImplementation: cf.Spec.DefaultImplementation,
+			CompositeKind: cf.Spec.CompositeKind, Contracts: cf.Spec.Contracts, Providers: ps})
+	}
+	if len(errs) > 0 {
+		return nil, errs
+	}
+	var buf bytes.Buffer
+	enc := json.NewEncoder(&buf)
+	enc.SetIndent("", "  ")
+	enc.SetEscapeHTML(false)
+	if err := enc.Encode(out); err != nil {
+		return nil, []string{IndexPath + ": " + err.Error()}
+	}
+	return buf.Bytes(), nil
+}

+func compileSchema(schema []byte) (*jsonschema.Schema, error) {
+	c := jsonschema.NewCompiler()
+	c.Draft = jsonschema.Draft2020
+	if err := c.AddResource("file:///capability.schema.json", bytes.NewReader(schema)); err != nil {
+		return nil, err
+	}
+	return c.Compile("file:///capability.schema.json")
+}
+
+// decodeYAML converts YAML to JSON, checks it against schema when one is given, and decodes it into v.
+func decodeYAML(raw []byte, v interface{}, schema *jsonschema.Schema) error {
+	js, err := yaml.YAMLToJSON(raw)
+	if err != nil {
+		return err
+	}
+	if schema != nil {
+		var doc interface{}
+		if err := json.Unmarshal(js, &doc); err != nil {
+			return err
+		}
+		if err := schema.Validate(doc); err != nil {
+			return schemaFailure(err)
+		}
+	}
+	return json.Unmarshal(js, v)
+}
+
+// schemaFailure lists every failing leaf of a validation error, sorted, on one line.
+func schemaFailure(err error) error {
+	var ve *jsonschema.ValidationError
+	if !errors.As(err, &ve) {
+		return err
+	}
+	var leaves []string
+	var walk func(*jsonschema.ValidationError)
+	walk = func(e *jsonschema.ValidationError) {
+		if len(e.Causes) == 0 {
+			leaves = append(leaves, "at '"+e.InstanceLocation+"': "+e.Message)
+		}
+		for _, c := range e.Causes {
+			walk(c)
+		}
+	}
+	walk(ve)
+	sort.Strings(leaves)
+	return fmt.Errorf("fails %s: %s", SchemaPath, strings.Join(leaves, "; "))
+}

+// readContracts reads every platform/_capabilities/*.yaml, keyed by capability name.
+func readContracts(tree fs.FS, schema *jsonschema.Schema) (map[string]contractFile, []string) {
+	out := map[string]contractFile{}
+	var errs []string
+	files, err := fs.ReadDir(tree, ContractsDir)
+	if errors.Is(err, fs.ErrNotExist) {
+		return out, nil
+	}
+	if err != nil {
+		return out, []string{ContractsDir + "/: cannot be read: " + err.Error()}
+	}
+	for _, f := range files {
+		if f.IsDir() || !strings.HasSuffix(f.Name(), ".yaml") {
+			continue
+		}
+		rel := ContractsDir + "/" + f.Name()
+		raw, err := fs.ReadFile(tree, rel)
+		if err != nil {
+			errs = append(errs, rel+": "+err.Error())
+			continue
+		}
+		var cf contractFile
+		if err := decodeYAML(raw, &cf, schema); err != nil {
+			errs = append(errs, rel+": "+err.Error())
+			continue
+		}
+		if want := strings.TrimSuffix(f.Name(), ".yaml"); cf.Metadata.Name != want {
+			errs = append(errs, fmt.Sprintf("%s: metadata.name is %q, the file name says %q", rel, cf.Metadata.Name, want))
+			continue
+		}
+		seen := map[string]bool{}
+		for _, c := range cf.Spec.Contracts {
+			if seen[c.Version] {
+				errs = append(errs, fmt.Sprintf("%s: contract version %s is listed twice", rel, c.Version))
+			}
+			seen[c.Version] = true
+			for _, fld := range c.ContextFields {
+				if fld.Default != nil {
+					if _, err := fld.check(fld.Default); err != nil {
+						errs = append(errs, fmt.Sprintf("%s: contract %s: the default of context field %q does not fit it: %v", rel, c.Version, fld.Name, err))
+					}
+				}
+				for _, e := range fld.Enum {
+					if _, err := (ContextField{Name: fld.Name, Type: fld.Type}).check(e); err != nil {
+						errs = append(errs, fmt.Sprintf("%s: contract %s: an enum value of context field %q is not of its type: %v", rel, c.Version, fld.Name, err))
+					}
+				}
+			}
+		}
+		out[cf.Metadata.Name] = cf
+	}
+	return out, errs
+}

+// checkBlueprint: each provides and requires entry names a contract file and one of its versions; no
+// capability is provided twice and no alias required twice.
+func checkBlueprint(rel string, bp blueprintFile, contracts map[string]contractFile) []string {
+	var errs []string
+	known := func(field, capability, version string) {
+		cf, ok := contracts[capability]
+		if !ok {
+			errs = append(errs, fmt.Sprintf("%s: spec.%s names capability %q, which has no file %s/%s.yaml", rel, field, capability, ContractsDir, capability))
+			return
+		}
+		for _, c := range cf.Spec.Contracts {
+			if c.Version == version {
+				return
+			}
+		}
+		errs = append(errs, fmt.Sprintf("%s: spec.%s names %s contract %q, which %s/%s.yaml does not declare", rel, field, capability, version, ContractsDir, capability))
+	}
+	provided := map[string]bool{}
+	for _, p := range bp.Spec.Provides {
+		if provided[p.Capability] {
+			errs = append(errs, fmt.Sprintf("%s: spec.provides lists capability %q twice", rel, p.Capability))
+		}
+		provided[p.Capability] = true
+		known("provides", p.Capability, p.Contract)
+	}
+	aliases := map[string]bool{}
+	for _, r := range bp.Spec.Requires {
+		if aliases[r.Alias] {
+			errs = append(errs, fmt.Sprintf("%s: spec.requires lists alias %q twice", rel, r.Alias))
+		}
+		aliases[r.Alias] = true
+		known("requires", r.Capability, r.Contract)
+	}
+	return errs
+}

+// LoadIndex parses the generated capabilities.json. A file without the capabilities list is an error: an
+// empty index is written as an empty list, never as a missing one.
+func LoadIndex(raw []byte) (Index, error) {
+	var probe map[string]json.RawMessage
+	if err := json.Unmarshal(raw, &probe); err != nil {
+		return nil, fmt.Errorf("capability index: %w", err)
+	}
+	if _, ok := probe["capabilities"]; !ok {
+		return nil, errors.New("capability index: no capabilities list")
+	}
+	var f file
+	if err := json.Unmarshal(raw, &f); err != nil {
+		return nil, fmt.Errorf("capability index: %w", err)
+	}
+	idx := &index{byName: map[string]entry{}}
+	for _, e := range f.Capabilities {
+		if e.Name == "" {
+			return nil, errors.New("capability index: a capability has no name")
+		}
+		if _, dup := idx.byName[e.Name]; dup {
+			return nil, fmt.Errorf("capability index: capability %s is listed twice", e.Name)
+		}
+		for i := range e.Contracts {
+			e.Contracts[i].Capability = e.Name
+		}
+		idx.byName[e.Name] = e
+	}
+	return idx, nil
+}
+
+func (x *index) Contract(capability, version string) (Contract, bool) {
+	for _, c := range x.byName[capability].Contracts {
+		if c.Version == version {
+			return c, true
+		}
+	}
+	return Contract{}, false
+}
+
+func (x *index) Current(capability string) (Contract, bool) {
+	var best Contract
+	found := false
+	for _, c := range x.byName[capability].Contracts {
+		if c.Status == "current" && (!found || versionNumber(c.Version) > versionNumber(best.Version)) {
+			best, found = c, true
+		}
+	}
+	return best, found
+}
+
+func (x *index) Capabilities() []string {
+	out := make([]string, 0, len(x.byName))
+	for n := range x.byName {
+		out = append(out, n)
+	}
+	sort.Strings(out)
+	return out
+}
+
+func (x *index) DefaultImplementation(capability string) string {
+	return x.byName[capability].DefaultImplementation
+}
+
+func (x *index) Title(capability string) string { return x.byName[capability].Title }
+
+// versionNumber is N of a contract version vN; 0 when it is not of that form.
+func versionNumber(v string) int {
+	n := 0
+	if len(v) < 2 || v[0] != 'v' {
+		return 0
+	}
+	for _, r := range v[1:] {
+		if r < '0' || r > '9' {
+			return 0
+		}
+		n = n*10 + int(r-'0')
+	}
+	return n
+}

+// usable: not deprecated, and available (in-cluster always; cloud-native only when avail says so).
+func (r *registry) usable(capability string, im Implementation) bool {
+	if im.Lifecycle == "deprecated" {
+		return false
+	}
+	if im.Implementation == "cloud-native" {
+		ok, _ := r.avail.Available(capability)
+		return ok

+// Offer: offered = every usable provider (narrowed to the Sovereign's offered list when it has an entry for
+// the capability). Default = the entry's default when it is offered; else the contract's
+// defaultImplementation when it is offered; else the offered in-cluster implementation with the lowest name
+// in byte order; else empty.
+func (r *registry) Offer(capability string) Offer {
+	o := Offer{Capability: capability, OrganizationChoice: "allowed"}
+	ch, hasChoice := r.choices[capability]
+	for _, im := range r.byCap[capability] {
+		if r.usable(capability, im) && (!hasChoice || ch.offered[im.Blueprint]) {
+			o.Offered = append(o.Offered, im)
+		}
+	}
+	in := func(name string) bool {
+		for _, im := range o.Offered {
+			if im.Blueprint == name {
+				return true
+			}
+		}
+		return false
+	}
+	switch {
+	case hasChoice && ch.def != "" && in(ch.def):
+		o.Default = ch.def
+	case r.idx != nil && in(r.idx.DefaultImplementation(capability)):
+		o.Default = r.idx.DefaultImplementation(capability)
+	default:
+		for _, im := range o.Offered { // sorted by name
+			if im.Implementation == "in-cluster" {
+				o.Default = im.Blueprint
+				break
+			}
+		}
+	}
+	if hasChoice {
+		o.OrganizationChoice = ch.organizationChoice
+	}
+	return o
+}

+func (r *registry) Resolve(capability, requested string) (Implementation, error) {
+	if !r.known(capability) {
+		return Implementation{}, fmt.Errorf("%w: %s", ErrUnknownCapability, capability)
+	}
+	o := r.Offer(capability)
+	if requested == "" {
+		requested = o.Default
+		if requested == "" {
+			return Implementation{}, ErrNoImplementation
+		}
+	} else {
+		provides := false
+		for _, im := range r.byCap[capability] {
+			provides = provides || im.Blueprint == requested
+		}
+		if !provides {
+			return Implementation{}, fmt.Errorf("%w: %s does not provide %s", ErrWrongCapability, requested, capability)
+		}
+		if o.OrganizationChoice == "fixed" && requested != o.Default {
+			return Implementation{}, fmt.Errorf("%w: %s is fixed to %s on this Sovereign", ErrNotOffered, capability, o.Default)
+		}
+	}
+	for _, im := range o.Offered {
+		if im.Blueprint == requested {
+			return im, nil
+		}
+	}
+	return Implementation{}, fmt.Errorf("%w: %s for %s", ErrNotOffered, requested, capability)
+}

+// ContextValues checks the values a caller sent for the contract's contextFields and returns them with the
+// defaults of absent fields filled in. Refused (ErrContextField): a field the contract does not declare, a
+// value of the wrong type or outside the field's enum, a required field with no value and no default.
+func (c Contract) ContextValues(in map[string]interface{}) (map[string]interface{}, error) {
+	declared := map[string]ContextField{}
+	for _, f := range c.ContextFields {
+		declared[f.Name] = f
+	}
+	names := make([]string, 0, len(in))
+	for n := range in {
+		names = append(names, n)
+	}
+	sort.Strings(names)
+	for _, n := range names {
+		if _, ok := declared[n]; !ok {
+			return nil, fmt.Errorf("%w: %s %s declares no context field %q", ErrContextField, c.Capability, c.Version, n)
+		}
+	}
+	out := map[string]interface{}{}
+	for _, f := range c.ContextFields {
+		v, given := in[f.Name]
+		if !given && f.Default == nil {
+			if f.Required {
+				return nil, fmt.Errorf("%w: context field %q is required", ErrContextField, f.Name)
+			}
+			continue
+		}
+		if !given {
+			v = f.Default
+		}
+		nv, err := f.check(v)
+		if err != nil {
+			return nil, err
+		}
+		out[f.Name] = nv
+	}
+	return out, nil
+}
+
+// check returns v in the form a Kubernetes object carries (an integral JSON number becomes int64), or
+// ErrContextField.
+func (f ContextField) check(v interface{}) (interface{}, error) {
+	bad := fmt.Errorf("%w: context field %q must be of type %s, got %v", ErrContextField, f.Name, f.Type, v)
+	switch f.Type {
+	case "string":
+		if _, ok := v.(string); !ok {
+			return nil, bad
+		}
+	case "boolean":
+		if _, ok := v.(bool); !ok {
+			return nil, bad
+		}
+	case "array":
+		if _, ok := v.([]interface{}); !ok {
+			return nil, bad
+		}
+	case "integer":
+		switch n := v.(type) {
+		case int64:
+		case int:
+			v = int64(n)
+		case float64:
+			if n != math.Trunc(n) || math.Abs(n) > 1<<53 {
+				return nil, bad
+			}
+			v = int64(n)
+		default:
+			return nil, bad
+		}
+	default:
+		return nil, fmt.Errorf("%w: context field %q has an unknown type %q", ErrContextField, f.Name, f.Type)
+	}
+	if len(f.Enum) == 0 {
+		return v, nil
+	}
+	// The enum of an array field lists the values each item may take.
+	items := []interface{}{v}
+	if list, ok := v.([]interface{}); ok {
+		items = list
+	}
+	for _, it := range items {
+		if !inEnum(f.Enum, it) {
+			return nil, fmt.Errorf("%w: context field %q must be one of %v, got %v", ErrContextField, f.Name, f.Enum, it)
+		}
+	}
+	return v, nil
+}
+
+// inEnum compares a value with the enum of the index, where JSON gives every number as float64.
+func inEnum(enum []interface{}, v interface{}) bool {
+	for _, e := range enum {
+		switch ev := e.(type) {
+		case string:
+			if s, ok := v.(string); ok && s == ev {
+				return true
+			}
+		case bool:
+			if b, ok := v.(bool); ok && b == ev {
+				return true
+			}
+		case float64:
+			switch n := v.(type) {
+			case int64:
+				if float64(n) == ev {
+					return true
+				}
+			case float64:
+				if n == ev {
+					return true
+				}
+			}
+		}
+	}
+	return false
+}
