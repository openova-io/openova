# AIP-113 — Durable spool and admin routes

## In plain words

**The problem today.** The model meter keeps a record of its last requests but offers no way to read it, and it has no health, readiness or metrics routes. It does not keep the stream position of a published usage event, so a check cannot follow an event onto the bus. Its image cannot say which build it is, and nothing proves that the meter records no prompt or answer text.

**What changes.** The meter serves health, readiness, metrics and the record of each recent request on a second address, apart from the proxy, and each record carries the stream position of its event. The binary prints its build version, and a test proves that no request or answer text reaches the log, the records, the metrics or the spool.

**Done means:**

- The meter answers health, readiness, metrics and the record of a recent request on its admin address, and none of these on the proxy address.
- Readiness fails with status 503 when the spool directory cannot take a new file.
- The record of a published request carries the stream sequence the bus acknowledged, and 0 when the event was spooled or not published.
- The metrics count requests by outcome, tokens by class and principal, and events published, spooled and dropped.
- The command version prints the version the build set, and the services build sets it to the short commit.
- A test with an echo back end, unstreamed and streamed, finds no request or answer text in the log line, the ring route, the metrics or the spool files.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The model meter (`core/services/model-meter`) is one binary with two subcommands: `serve` (the proxy and its admin listener, also run when no subcommand is given) and `version` (prints the build version). `serve` opens a second listener on `ADMIN_ADDR` (default `:9090`) with four routes: `GET /healthz`, `GET /readyz` (200 when the spool directory takes a new file, else 503), `GET /metrics` (five counter families in the Prometheus text format, written by hand, no new dependency) and `GET /internal/events/{requestId}` (the ring entry of one of the last 1,000 requests, or 404). Each ring entry carries `sequence`, the JetStream stream sequence of the acknowledged publish, or 0. One function, `finish`, writes the log line, adds the ring entry and counts the metrics of every request. A test proves that no request or answer text reaches the log line, the ring route, the metrics or the spool files. The image is built with the version passed in by the services build. The change is the ten files of the block `AIP-113.patch` and one added line in `.github/workflows/services-build.yaml`; nothing else changes.

## 3. The model (the law)
1. Subcommands. `model-meter` with no argument or with `serve` runs the proxy and the admin listener. `model-meter version` prints the value of `main.version` and a line end, and exits 0. Any other first argument prints `model-meter: unknown subcommand "<arg>"; use serve or version` to standard error and exits 2. A configuration error of `serve` exits 1, as before.
2. The admin listener is its own `http.Server` on `ADMIN_ADDR`, default `:9090`. It is never served on the proxy listener `LISTEN_ADDR`; the proxy still answers every path outside `/v1/` with 404. When either listener fails, `serve` exits 1.
3. `GET /healthz` answers 200 `ok` while the process runs. `GET /readyz` creates a file `.readyz-*` in `SPOOL_DIR` and removes it; it answers 200 `ok` when both succeed and 503 otherwise (the directory is missing or not writable). The drain reads only files that end in `.json`, so it never reads that file.
4. `GET /metrics` writes exactly five counter families: `model_meter_requests_total{organization,alias,backend,status}`, `model_meter_tokens_total{organization,alias,principal,class}` with `class` in `input`, `cache_read`, `cache_write`, `output`, `model_meter_events_published_total` (acknowledged at once plus drained from the spool), `model_meter_events_spooled_total` and `model_meter_events_dropped_total`. Tokens are counted only for a request with status `ok` and a usage block, with the quantities of the usage event's measures; a class whose quantity is 0 gets no series.
5. `GET /internal/events/{requestId}` answers the newest ring entry of that request as a JSON object with exactly twelve keys: `requestId`, `organization`, `principalKind`, `principal`, `alias`, `backend`, `stream`, `status`, `httpStatus`, `published`, `sequence`, `event` (the published CloudEvent, or `null`). An unknown identifier gets 404 `not_found`. An event published later by the drain does not change the entry.
6. Sequence. `NATSConn.PublishRawSeq(ctx, subject, msgID, body) (uint64, error)` in `core/services/shared/events/nats.go` publishes like `PublishRaw` and returns the stream sequence of the acknowledgement. `PublishRaw` keeps its signature and calls `PublishRawSeq`. The meter's `Bus` interface asks for `PublishRawSeq`; `Publisher.Publish` returns `(uint64, error)`: the sequence after an acknowledgement, 0 with `ErrSpooled` or another error.
7. `finish` replaces `logLine`. It writes the log line with the same keys as before, then adds the ring entry, then counts the metrics. Every request passes through it exactly once.
8. No text. The log line, the ring entry, the metrics and the spool files never hold the text of a request or of an answer. `TestNoRequestOrAnswerTextIsRecorded` proves it with an echo back end, unstreamed and streamed.
9. Version in the image. The `Containerfile` declares `ARG VERSION=dev` and builds with `-X main.version=${VERSION}`, and exposes 8080 and 9090. The build step of `.github/workflows/services-build.yaml` passes `build-args: VERSION=${{ steps.vars.outputs.sha_short }}`. Another service's `Containerfile` declares no such argument and ignores it.
10. Nothing is deleted. `go.mod` and `go.sum` do not change.

+// observe counts one request, and its tokens when it ended ok with a usage block. The token

+func (m *Metrics) observe(rec Record, u Usage) {

+			m.tokens[[4]string{rec.Organization, rec.Alias, rec.Principal, class}] += ms.Quantity
+		}
+	}

+var labelEscaper = strings.NewReplacer(`\`, `\\`, `"`, `\"`, "\n", `\n`)

+// writeFamily writes one counter family, its series sorted by their labels.
+func writeFamily(w io.Writer, name, help string, labels [4]string, series map[[4]string]int64) {
+	_, _ = fmt.Fprintf(w, "# HELP %s %s\n# TYPE %s counter\n", name, help, name)
+	keys := make([][4]string, 0, len(series))
+	for k := range series {
+		keys = append(keys, k)
+	}
+	sort.Slice(keys, func(i, j int) bool { return strings.Join(keys[i][:], "\x00") < strings.Join(keys[j][:], "\x00") })
+	for _, k := range keys {
+		pairs := make([]string, 4)
+		for i := range labels {
+			pairs[i] = labels[i] + `="` + labelEscaper.Replace(k[i]) + `"`
+		}
+		_, _ = fmt.Fprintf(w, "%s{%s} %d\n", name, strings.Join(pairs, ","), series[k])
+	}
+}

+func writeCounter(w io.Writer, name, help string, v int64) {

+// Ready reports whether the spool directory takes a new file: it creates one and removes it.
+// The drain reads only files named *.json, so it never reads this one.
+func (p *SpoolPublisher) Ready() error {
+	if p.SpoolDir == "" {
+		return errors.New("meter: no spool directory configured")
+	}
+	f, err := os.CreateTemp(p.SpoolDir, ".readyz-*")
+	if err != nil {
+		return err
+	}
+	closeErr := f.Close()
+	if err := os.Remove(f.Name()); err != nil {
+		return err
+	}
+	return closeErr
+}

+// NewAdmin returns the handler of the admin listener for the proxy h and its publisher p.
+func NewAdmin(h *Handler, p *SpoolPublisher) http.Handler {
+	mux := http.NewServeMux()
+	mux.HandleFunc("GET /healthz", func(w http.ResponseWriter, _ *http.Request) {
+		_, _ = io.WriteString(w, "ok\n")
+	})
+	mux.HandleFunc("GET /readyz", func(w http.ResponseWriter, _ *http.Request) {
+		if err := p.Ready(); err != nil {
+			h.log.Warn("meter: not ready, the spool directory does not take a file", "error", err)
+			http.Error(w, "the spool directory is not writable", http.StatusServiceUnavailable)
+			return
+		}
+		_, _ = io.WriteString(w, "ok\n")
+	})
+	mux.HandleFunc("GET /metrics", func(w http.ResponseWriter, _ *http.Request) {
+		w.Header().Set("Content-Type", "text/plain; version=0.0.4; charset=utf-8")
+		h.metrics.mu.Lock()
+		writeFamily(w, "model_meter_requests_total", "Requests by outcome.",
+			[4]string{"organization", "alias", "backend", "status"}, h.metrics.requests)
+		writeFamily(w, "model_meter_tokens_total", "Tokens of the requests that ended ok, by class.",
+			[4]string{"organization", "alias", "principal", "class"}, h.metrics.tokens)
+		h.metrics.mu.Unlock()
+		writeCounter(w, "model_meter_events_published_total", "Usage events acknowledged by the bus, at once or from the spool.",
+			p.publishedOK.Load()+p.spoolDrained.Load())
+		writeCounter(w, "model_meter_events_spooled_total", "Usage events written to the spool directory.", p.spooled.Load())
+		writeCounter(w, "model_meter_events_dropped_total", "Usage events lost.", p.spoolDropFatal.Load())
+	})
+	mux.HandleFunc("GET /internal/events/{requestId}", func(w http.ResponseWriter, r *http.Request) {
+		rec, ok := h.ring.Get(r.PathValue("requestId"))
+		if !ok {
+			writeError(w, http.StatusNotFound, "not_found", "no request with this identifier among the last requests")
+			return
+		}
+		w.Header().Set("Content-Type", "application/json")
+		_ = json.NewEncoder(w).Encode(rec)
+	})
