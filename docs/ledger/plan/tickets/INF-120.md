# INF-120 — Runner image and node-mode tasks

## In plain words

**The problem today.** The machine plane can list machines, but nothing can look inside one. There is no image that carries the scanning tools, no program that runs a scan on a node and stores what it found, and no agreed form for the result of such a run.

**What changes.** A new image holds the program machine-runner and the tools it starts, each at an exact version whose checksum the build checks. The program takes the software inventory of a node and evaluates a hardening profile on it, stores the files in the evidence bucket and writes one short result document. The tools keep their home and their temporary files in the work folder, so the image runs with a read-only root file system.

**Done means:**

- Every tool of the runner image is listed in one lock file with its exact version, its address and its checksum, and the image build stops when a download does not match.
- The image holds a licence file that names each tool, its licence and how it is used.
- The inventory task writes a CycloneDX inventory of the node without fetching anything, and the hardening task evaluates a profile with the rules a baseline disables left out.
- A node whose release has no data stream is reported as no-profile-for-release, never as passing.
- A collector that was stopped gives the outcome Incomplete, and nothing is stored for it.
- The files of a run are stored under <namespace>/<machine>/<run>/ in the evidence bucket, and the tests prove this against a fake S3 server.
- A pull request that changes the runner builds the image and starts it twice: as built, and as a runner Job starts it, with a read-only root file system and one memory volume at the work folder, where the inventory task runs to its end. The merge pushes and signs the image.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The machine plane has a runner. The image `ghcr.io/openova-io/openova/machine-runner`, built from `products/machine-runner/Containerfile`, holds the program `/usr/local/bin/machine-runner` and the tools of `products/machine-runner/tools.lock.yaml`: ansible-core 2.21.6, ansible-runner 2.4.3, Trivy 0.76.1, the OpenSCAP scanner 1.4.2 with `oscap-chroot`, and the ComplianceAsCode 0.1.82 data streams of the Ubuntu and RHEL families. The program runs, in node mode, the task `inventory` (a CycloneDX inventory of the node's file system, taken offline) and the task `hardening` (an XCCDF profile evaluated with `oscap-chroot`). It stores the task's files in the evidence bucket under `<machine namespace>/<machine name>/<run name>/` and writes one result document of at most 4096 bytes to the container's termination message. The home of the image and its `/tmp` are the work folder `/run/machine-runner`, so the tools run with a read-only root file system when a memory volume is mounted there. On a pull request the workflow `Build machine-runner` runs the runner's tests, builds the image and starts it, once as built and once as a runner Job starts it; on `main` it pushes the image and signs it through the shared action. Nothing starts a runner Job yet.

## 3. The model (the law)
1. **The image.** `products/machine-runner/Containerfile` is built with the repository root as its context. Three stages, each `FROM` named by digest: `build` (Go 1.26.11 on Alpine) builds `./cmd/machine-runner` of the API module with `CGO_ENABLED=0`; `fetch` (Debian 13 slim) downloads every tool of the lock; the final stage (the same Debian image) installs the tools and the program. The final image's user is `65534:65534` and its entry point is `/usr/local/bin/machine-runner`. A node-mode Job sets its own user (root) in the chart of a later package.
   **The home and `/tmp`.** The final stage creates `/run/machine-runner`, empty, owned by `65534:65534`, mode `0700`; sets `HOME=/run/machine-runner`; and replaces `/tmp` by a link to `/run/machine-runner`. Reasons: ansible-core creates `~/.ansible/tmp` when it starts, and the home of user 65534 in `/etc/passwd` is `/nonexistent`, which cannot be created; Trivy makes its temporary folders in `/tmp`; oscap always names its temporary folder `/tmp/oscap.XXXXXX` and reads no `TMPDIR`. A runner Job (later packages) runs with a read-only root file system, mounts a memory volume (`emptyDir`) at `/run/machine-runner` and mounts no volume at `/tmp`; the home and `/tmp` are then writable and hold nothing from one run to the next. The version checks of the build run as root before these lines, and their `/root/.ansible` is removed. The work folder is not a path of the host.
2. **The tool lock.** `products/machine-runner/tools.lock.yaml` has the schema `openova.io/machine-runner-tools/v1` and a list `tools`. Each entry has, in this key order, `name`, `version` (exact, quoted), `source` (the `https://` address of the release file), `sha256`, `licence` (an SPDX identifier) and `use`, which is `separate-process` or `data`. There are nine entries: `ansible-core`, `ansible-runner`, `trivy`, `libopenscap33`, `openscap-common`, `openscap-scanner`, `python3-openscap`, `openscap-utils`, `scap-security-guide`. The OpenSCAP scanner comes as the five Debian packages of the source package `openscap` 1.4.2+dfsg-1, from a fixed snapshot of the Debian archive, so that no package of it can move under the build. A tool enters the image only through this file.
3. **The build checks the lock.** The stage `fetch` reads the lock line by line, stops when an entry's `use` is not `separate-process` or `data`, stops when the number of entries read differs from the number of `  - name: ` lines, downloads each `source` to `/tools/<name>/<last part of the source>` and stops when its SHA-256 differs. The Debian libraries that the tools depend on (Python 3, the Python libraries of ansible-core and ansible-runner, the libraries of OpenSCAP) come from the Debian archive of the base image; `pip check` must find every dependency of the two wheels met, and `pip` is removed again.
4. **Licences.** The GPL and LGPL tools ship as separate programs, never linked into `machine-runner`. `products/machine-runner/LICENSES.md` has one row per entry of the lock (name, version, licence, how it is used) and is copied to `/usr/share/doc/machine-runner/LICENSES.md`; the licence texts of Trivy and of the content are copied to `/usr/share/doc/trivy/` and `/usr/share/doc/scap-security-guide/`.
5. **The data streams.** The image holds the data streams `ssg-ubuntu*-ds.xml`, `ssg-rhel<N>-ds.xml`, `ssg-almalinux*-ds.xml` and `ssg-ol<N>-ds.xml` of the content release, in `/content/scap/<release>/` (for 0.1.82: eleven files). The data stream of a target is `ssg-<product><version>-ds.xml`: family `ubuntu` gives product `ubuntu` and the version without its dot (`24.04` gives `2404`); `rhel`, `almalinux` and `oraclelinux` give `rhel`, `almalinux` and `ol` with the major version. Any other family has no data stream. The family names are those the inventory controller writes on a `Machine`.
6. **The result document** (package `internal/machines/runresult`). One JSON object, schema `openova.io/machine-run-result/v1`, members in this order: `schema`, `outcome`, `message`, `hostKeys`, `fingerprint`, `os`, `evidence`, `hardening`, `patch`, `test`, `completed`. `schema`, `outcome`, `message` and `completed` are always present; the others only for the task that produced them. The outcome is one of the closed list `Succeeded`, `NoChange`, `Failed`, `Incomplete`, `Unreachable`, `AuthFailed`, `IdentityMismatch`, `NoAddress`, `Refused`, `WindowClosed`, `Timeout`, `Cancelled`, `Killed`. The encoded document is at most 4096 bytes: a longer one is shortened in `message` only (its longest leading part that fits, cut between two characters, then `...`); one that does not fit with an empty message is an error. A termination message that is not a parsable document of this schema with an outcome of the list reads as outcome `Failed` with message `no-result`. The type is the whole contract from the start: the members `hostKeys`, `fingerprint`, `os`, `patch` and `test` and the outcomes that no task of this version gives are filled by the later tasks of packages INF-420, INF-440 and INF-512, which add their tasks beside this package and do not change it. Rule of conduct 9 is no reason to shorten it.
7. **The arguments** (package `internal/machines/runner`, file `config.go`). `--task` (one of `facts`, `inventory`, `hardening`, `patch`, `test`), `--mode` (`node` or `ssh`), `--machine` and `--run` (each `<namespace>/<name>`), `--address` (optional, an IP address; the contract passes it to every run, node mode does not use it), `--os-family`, `--os-version`, `--evidence-endpoint` (`https://host[:port]`, nothing after the port), `--evidence-region`, `--evidence-bucket`, `--evidence-prefix`, which must equal `<machine namespace>/<machine name>/<run name>/`; for the task `hardening` only, `--profile-id` (an XCCDF profile identifier), `--content-release` (such as `0.1.82`) and `--disabled-rules` (comma-separated XCCDF rule identifiers). An unknown flag, a missing value or a value of the wrong form gives outcome `Refused` with a message that starts with `invalid-arguments: `.
8. **What this version runs.** Node mode only, the tasks `inventory` and `hardening`. Any other valid task or mode gives outcome `Refused` with message `not-supported: task <task>` or `not-supported: mode <mode>`.
9. **Task `inventory`.** It runs exactly `trivy rootfs --format cyclonedx --skip-db-update --offline-scan --cache-dir <work>/trivy-cache --output <work>/sbom.cdx.json /host`, with `TRIVY_DISABLE_TELEMETRY`, `TRIVY_SKIP_VERSION_CHECK` and `TRIVY_NO_PROGRESS` set to `true`. It fetches no database and no tool. The file must be a JSON document whose `bomFormat` is `CycloneDX`. The work folder `<work>` is the memory volume `/run/machine-runner`.
10. **Task `hardening`.** A content release that has no folder in `/content/scap` gives outcome `Refused`, message `content-release-not-in-image: <release>`. A target whose data stream is not in that folder gives outcome `Succeeded`, message `no-profile-for-release`, a `hardening` member with zero rules, and a file `hardening.results.json` with that reason and no rule; `oscap-chroot` does not run. Otherwise it runs `oscap-chroot /host xccdf eval --results-arf <work>/hardening.arf.xml [--tailoring-file <work>/hardening.tailoring.xml] --profile <profile> <data stream>`. With disabled rules, the tailoring file holds one XCCDF 1.2 profile, `<profile-id>_openova_tailored`, that extends the given profile and deselects each disabled rule, and that profile is evaluated. Exit codes 0 (every rule passed) and 2 (a rule failed) are results. The rule results are read from the ARF file: `pass` and `fixed` count as pass, `fail` as fail, `notapplicable` as not applicable, `error` and `unknown` as error; `notchecked` and `informational` are kept in the file and not counted; `notselected` is left out. An ARF file with no rule result gives `Failed`. `hardening.results.json` has the schema `openova.io/machine-hardening-results/v1` and the members `schema`, `profileId`, `contentRelease`, `dataStream`, `reason`, `counts` (`pass`, `fail`, `notApplicable`, `error`) and `rules` (each `id`, `result`).
11. **Never a false success.** Every task writes `<work>/<task>.completed` as its last step, and the document's `completed` is true only when that file exists. A task that reports success without the marker becomes `Incomplete`. A collector stopped by a signal gives `Incomplete`; a run whose context ended (SIGTERM) gives `Cancelled`; any other exit code that is not a result gives `Failed` with the end of the collector's error output. Files are stored only for a task that succeeded and completed; a failed task stores nothing.
12. **Evidence.** The key pair is read from the object-storage binding mounted at `/var/run/secrets/evidence-store`, with the file names of contract `object-storage` v1: `access-key-id` and `secret-access-key` (required), and `ca.crt` (optional, added to the trusted certificates when present). The runner speaks S3 over HTTPS with certificate validation, through the library `github.com/minio/minio-go/v7` that the API module already requires, one PUT per file. The object key is `<evidence-prefix><file>`. Each stored file gives an `evidence` entry with `kind` (`sbom`, `hardening-arf` or `hardening-results`), `key` (the object key, without the bucket) and `sha256` (of the content). A failed store gives `Failed` with a message that starts with `evidence-upload-failed: `. No Kubernetes Secret is read or created.
13. **The program.** `cmd/machine-runner/main.go` calls `runner.Main`, which writes the encoded document to `/dev/termination-log` and to stdout and returns exit code 0 for `Succeeded` and `NoChange` and 1 for every other outcome. SIGTERM and an interrupt cancel the run.
14. **The workflow.** `.github/workflows/build-machine-runner.yaml` runs on a pull request and on a push to `main` that change the runner's files, the two API packages, `go.mod`, `go.sum` or the workflow. It runs the tests of the two packages and of the command with `-race`, builds the image, and on a pull request loads it and starts it. As built: the user is `65534:65534`, `HOME` is `/run/machine-runner` and empty, `/tmp` links to it, every tool prints its version, the Ubuntu 24.04 data stream is there, and the program without arguments prints a `Refused` document and exits 1. As a runner Job starts it (`--read-only` and a memory file system at `/run/machine-runner`, mode `0777` as an `emptyDir` has): the tools print their versions, `mktemp -d /tmp/oscap.XXXXXX` succeeds, and the task `inventory` runs as root with no network on the folder `products/machine-runner` of the checkout mounted at `/host`, completes (`"completed":true`) and ends with exit code 1 and the message `evidence-upload-failed: sbom.cdx.json: ...`, because nothing listens at the endpoint `https://127.0.0.1:9`. On `main` it pushes `ghcr.io/openova-io/openova/machine-runner:<short SHA>` and signs and attests it through `./.github/actions/sign-and-attest`. The signing step passes four inputs, in this order: `ref`, `digest`, `release-key: ${{ secrets.RELEASE_COSIGN_KEY }}` and `release-key-password: ${{ secrets.RELEASE_COSIGN_PASSWORD }}`. Every call of the action passes the last two since package FND-063, because a composite action cannot read a secret; the action uses the key only on `refs/heads/main`. Every action is named by its commit.
15. **The generated components page.** `docs/generated/components.md` lists every folder of `products/`; its generator adds the row of `products/machine-runner`.
16. **Not in this ticket.** The playbooks under `/content/playbooks`, the OpenSSH program, Nuclei and the ZAP script come with the tasks that use them. No chart, no Job, no OpenBao object, no bucket and no image pin.

# machine-runner

The container image of the runner Jobs of the machine plane: one short-lived Job per run and
target, which runs one task and stores what it found.

## Role in Catalyst

Infrastructure plumbing of the Blueprint `bp-machine-operations` (`platform/machine-operations/`).
The image is not an Application and is not installed on its own. It is run as a Job in the
namespace `machine-ops` by the operations controller of that Blueprint; in this version no
controller starts it yet. The machine plane is described
in its decision record,
[`docs/adr/0031-infrastructure-plane.md`](../../docs/adr/0031-infrastructure-plane.md).

## What the image holds

- `/usr/local/bin/machine-runner`, built from `products/catalyst/bootstrap/api/cmd/machine-runner`.
- The tools of `tools.lock.yaml`, each at an exact version whose SHA-256 the build checks:
  ansible-core, ansible-runner, Trivy, the OpenSCAP scanner with `oscap-chroot`, and the
  ComplianceAsCode data streams of the Ubuntu and RHEL families under
  `/content/scap/<release>/`.
- `LICENSES.md`: the licence of each tool and how it is used.

The default user is `65534`. A node-mode Job runs as root with a read-only root file system and
the node's file system mounted read-only at `/host`.

The home of the image (`HOME`) is the work folder `/run/machine-runner`, which is empty in the
image, and `/tmp` is a link to the same folder. A runner Job mounts a memory volume at
`/run/machine-runner` and no volume at `/tmp`. So a tool that writes in its home or in `/tmp`
(ansible-core with `~/.ansible/tmp`, Trivy, oscap with `/tmp/oscap.XXXXXX`) works with a
read-only root file system, and nothing stays from one run to the next.

## Tasks of this version (node mode)

| Task | Collector | Files stored |
|---|---|---|
| `inventory` | `trivy rootfs --format cyclonedx --skip-db-update --offline-scan /host` | `sbom.cdx.json` |
| `hardening` | `oscap-chroot /host xccdf eval` with the profile, the data stream of the node's release and a tailoring file of the disabled rules | `hardening.arf.xml`, `hardening.results.json` |

The inventory task updates no database and fetches nothing. A node whose release has no data
stream in the image gets outcome `Succeeded` with no rule and the message
`no-profile-for-release`. Every other task and SSH mode give outcome `Refused`.

## Arguments

`machine-runner --task=<inventory|hardening> --mode=node --machine=<namespace>/<name>
--run=<namespace>/<name> --os-family=<family> --os-version=<version>
--evidence-endpoint=https://<host>[:<port>] --evidence-region=<region>
--evidence-bucket=<bucket> --evidence-prefix=<machine namespace>/<machine name>/<run name>/`,
and for `hardening` also `--profile-id`, `--content-release` and `--disabled-rules`
(comma-separated XCCDF rule identifiers).

## Evidence and result

Each file is stored in the evidence bucket under `<prefix><file>`, over HTTPS with certificate
validation. The key pair is read from the object-storage binding mounted at
`/var/run/secrets/evidence-store` (files `access-key-id` and `secret-access-key`, and `ca.crt`
when the endpoint's certificate is not publicly trusted). Nothing is stored for a task that did
not finish.

The program writes one result document (`openova.io/machine-run-result/v1`, at most 4096 bytes)
to `/dev/termination-log` and to stdout. `completed` is true only when the task wrote its
completion marker; a collector that was stopped gives outcome `Incomplete`.

## Build and upgrade

`.github/workflows/build-machine-runner.yaml` runs the runner's tests and builds the image on a
pull request, and pushes, signs and attests `ghcr.io/openova-io/openova/machine-runner:<short SHA>`
on `main`. An upgrade of a tool changes its entry in `tools.lock.yaml` (version, source and
sha256 together) and the matching row of `LICENSES.md`.

// Package runresult holds the result document of a machine-runner Job: one JSON object
// that the runner writes as the container's termination message, at most MaxBytes long.
//
// The members schema, outcome, message and completed are always present. The other
// members are present only for the task that produced them.
package runresult

import (
	"encoding/json"
	"errors"
	"fmt"
	"unicode/utf8"
)

// Schema is the value of the member schema.
const Schema = "openova.io/machine-run-result/v1"

// MaxBytes is the largest encoded document: the size of a termination message.
const MaxBytes = 4096

// Outcome is the closed list of results of one run on one target.
type Outcome string

// The outcome values.
const (
	Succeeded        Outcome = "Succeeded"
	NoChange         Outcome = "NoChange"
	Failed           Outcome = "Failed"
	Incomplete       Outcome = "Incomplete"
	Unreachable      Outcome = "Unreachable"
	AuthFailed       Outcome = "AuthFailed"
	IdentityMismatch Outcome = "IdentityMismatch"
	NoAddress        Outcome = "NoAddress"
	Refused          Outcome = "Refused"
	WindowClosed     Outcome = "WindowClosed"
	Timeout          Outcome = "Timeout"
	Cancelled        Outcome = "Cancelled"
	Killed           Outcome = "Killed"
)

// Outcomes returns every outcome value, in the order of the contract.
func Outcomes() []Outcome {
	return []Outcome{Succeeded, NoChange, Failed, Incomplete, Unreachable, AuthFailed,
		IdentityMismatch, NoAddress, Refused, WindowClosed, Timeout, Cancelled, Killed}
}

// Valid reports whether o is one of the outcome values.
func (o Outcome) Valid() bool {
	for _, v := range Outcomes() {
		if o == v {
			return true
		}
	}
	return false
}

// MessageNoResult is the message of a run whose Job ended without a parsable document.
const MessageNoResult = "no-result"

// Document is the result document.
type Document struct {
	Schema      string       `json:"schema"`
	Outcome     Outcome      `json:"outcome"`
	Message     string       `json:"message"`
	HostKeys    []HostKey    `json:"hostKeys,omitempty"`
	Fingerprint *Fingerprint `json:"fingerprint,omitempty"`
	OS          *OS          `json:"os,omitempty"`
	Evidence    []Evidence   `json:"evidence,omitempty"`
	Hardening   *Hardening   `json:"hardening,omitempty"`
	Patch       *Patch       `json:"patch,omitempty"`
	Test        *Test        `json:"test,omitempty"`
	Completed   bool         `json:"completed"`
}

// HostKey is one SSH host key the target offered.
type HostKey struct {
	Type   string `json:"type"`
	SHA256 string `json:"sha256"`
}

// Fingerprint is the identity the target reported about itself.
type Fingerprint struct {
	FirmwareUUID string `json:"firmwareUUID"`
	InstanceUUID string `json:"instanceUUID"`
	Serial       string `json:"serial"`
	MachineID    string `json:"machineID"`
}

// OS is the operating system the target reported.
type OS struct {
	Family  string `json:"family"`
	Version string `json:"version"`
	Arch    string `json:"arch"`
	Kernel  string `json:"kernel"`
}

// Evidence is one file the run stored in the evidence bucket. Key is the object key in
// that bucket and SHA256 the hex digest of the stored content.
type Evidence struct {
	Kind   string `json:"kind"`
	Key    string `json:"key"`
	SHA256 string `json:"sha256"`
}

// Hardening is the summary of a hardening evaluation. ResultsKey is the object key of
// the file hardening.results.json.
type Hardening struct {
	ProfileID      string `json:"profileId"`
	ContentRelease string `json:"contentRelease"`
	Pass           int    `json:"pass"`
	Fail           int    `json:"fail"`
	NotApplicable  int    `json:"notApplicable"`
	Error          int    `json:"error"`
	ResultsKey     string `json:"resultsKey"`
}

// Patch is the summary of a patch run.
type Patch struct {
	PackagesChanged    int  `json:"packagesChanged"`
	RebootRequired     bool `json:"rebootRequired"`
	Rebooted           bool `json:"rebooted"`
	PendingAfter       int  `json:"pendingAfter"`
	HealthChecksPassed bool `json:"healthChecksPassed"`
}

// Test is the summary of a test run.
type Test struct {
	Findings   int    `json:"findings"`
	ResultsKey string `json:"resultsKey"`
}

// ErrTooLarge means the document is longer than MaxBytes even with an empty message.
var ErrTooLarge = errors.New("result document is longer than 4096 bytes without its message")

// ellipsis ends a shortened message.
const ellipsis = "..."

// Encode returns d as compact JSON of at most MaxBytes bytes, with the member schema
// set to Schema. A longer document is shortened in its message only: the message keeps
// its longest leading part, cut between two characters, that lets the document fit,
// followed by "...". It returns ErrTooLarge when the document does not fit with an
// empty message, and an error for an outcome that is not in the closed list.
func Encode(d Document) ([]byte, error) {
	if !d.Outcome.Valid() {
		return nil, fmt.Errorf("outcome %q is not one of the outcome values", d.Outcome)
	}
	d.Schema = Schema
	out, err := json.Marshal(d)
	if err != nil {
		return nil, err
	}
	if len(out) <= MaxBytes {
		return out, nil
	}
	message := d.Message
	runes := utf8.RuneCountInString(message)
	fits := func(n int) ([]byte, bool) {
		d.Message = prefix(message, n) + ellipsis
		if n == 0 {
			d.Message = ""
		}
		b, err := json.Marshal(d)
		return b, err == nil && len(b) <= MaxBytes
	}
	best, ok := fits(0)
	if !ok {
		return nil, ErrTooLarge
	}
	low, high := 0, runes // the longest n with fits(n) lies in [low, high)
	for low+1 < high {
		mid := (low + high) / 2
		if b, ok := fits(mid); ok {
			low, best = mid, b
		} else {
			high = mid
		}
	}
	return best, nil
}

// prefix returns the first n characters of s.
func prefix(s string, n int) string {
	i := 0
	for n > 0 && i < len(s) {
		_, size := utf8.DecodeRuneInString(s[i:])
		i += size
		n--
	}
	return s[:i]
}

// Parse reads a termination message. It fails when the text is not one JSON object,
// when schema is not Schema or when outcome is not in the closed list.
func Parse(text []byte) (Document, error) {
	var d Document
	if err := json.Unmarshal(text, &d); err != nil {
		return Document{}, err
	}
	if d.Schema != Schema {
		return Document{}, fmt.Errorf("schema %q is not %q", d.Schema, Schema)
	}
	if !d.Outcome.Valid() {
		return Document{}, fmt.Errorf("outcome %q is not one of the outcome values", d.Outcome)
	}
	return d, nil
}

// OrNoResult returns the parsed document, or the document of a Job that ended without a
// parsable one: outcome Failed with message no-result.
func OrNoResult(text []byte) Document {
	d, err := Parse(text)
	if err != nil {
		return Document{Schema: Schema, Outcome: Failed, Message: MessageNoResult}
	}
	return d
}

	fs.StringVar(&c.Evidence.Prefix, "evidence-prefix", "", "the key prefix <namespace>/<machine>/<run>/")
	if err := fs.Parse(args); err != nil {
		return Config{}, err
	}
	if fs.NArg() != 0 {
		return Config{}, fmt.Errorf("unexpected argument %q", fs.Arg(0))
	}
	var problems []string
	bad := func(format string, a ...any) { problems = append(problems, fmt.Sprintf(format, a...)) }
	if !contains(tasks, c.Task) {
		bad("--task must be one of %s", strings.Join(tasks, ", "))
	}
	if !contains(modes, c.Mode) {
		bad("--mode must be one of %s", strings.Join(modes, ", "))
	}
	var ok bool
	if c.Machine, ok = parseRef(machine); !ok {
		bad("--machine must be <namespace>/<name>")
	}
	if c.Run, ok = parseRef(run); !ok {
		bad("--run must be <namespace>/<name>")
	}
	if c.Address != "" && net.ParseIP(c.Address) == nil {
		bad("--address must be an IP address")
	}
	if !familyRE.MatchString(c.OSFamily) {
		bad("--os-family must be a lower-case word")
	}
	if !versionRE.MatchString(c.OSVersion) {
		bad("--os-version must be a version such as 24.04")
	}
	if c.Task == TaskHardening {
		if !profileRE.MatchString(c.ProfileID) {
			bad("--profile-id must be an XCCDF profile identifier")
		}
		if !releaseRE.MatchString(c.ContentRelease) {
			bad("--content-release must be a release such as 0.1.82")
		}
		if disabled != "" {
			for _, rule := range strings.Split(disabled, ",") {
				if !ruleRE.MatchString(rule) {
					bad("--disabled-rules: %q is not an XCCDF rule identifier", rule)
				}
				c.DisabledRules = append(c.DisabledRules, rule)
			}
		}
	} else if c.ProfileID != "" || c.ContentRelease != "" || disabled != "" {
		bad("--profile-id, --content-release and --disabled-rules belong to the task hardening")
	}
	if err := checkEndpoint(c.Evidence.Endpoint); err != nil {
		bad("--evidence-endpoint %s", err)
	}
	if !regionRE.MatchString(c.Evidence.Region) {
		bad("--evidence-region must be a region name")
	}
	if !bucketRE.MatchString(c.Evidence.Bucket) {
		bad("--evidence-bucket must be a bucket name")
	}
	if want := c.Machine.Namespace + "/" + c.Machine.Name + "/" + c.Run.Name + "/"; c.Evidence.Prefix != want {
		bad("--evidence-prefix must be %q", want)
	}
	if len(problems) > 0 {
		return Config{}, errors.New(strings.Join(problems, "; "))
	}
	return c, nil
}

// parseRef reads <namespace>/<name>.
func parseRef(s string) (Ref, bool) {
	ns, name, found := strings.Cut(s, "/")
	if !found || !namespaceRE.MatchString(ns) || !nameRE.MatchString(name) {
		return Ref{}, false
	}
	return Ref{Namespace: ns, Name: name}, true
}

// checkEndpoint accepts https://host[:port] with no path, query or user part.
func checkEndpoint(s string) error {
	u, err := url.Parse(s)
	switch {
	case err != nil || u.Host == "":
		return errors.New("must be https://host[:port]")
	case u.Scheme != "https":
		return errors.New("must use https")
	case u.User != nil || (u.Path != "" && u.Path != "/") || u.RawQuery != "" || u.Fragment != "":
		return errors.New("must be https://host[:port] with nothing after the port")
	}
	return nil
}

func contains(list []string, s string) bool {
	for _, v := range list {
		if v == s {
			return true
		}
	}
	return false
}

// machine plane on one target, stores the task's files in the evidence bucket and writes

// taskResult is what a task returns to Run.
type taskResult struct {
	outcome   runresult.Outcome
	message   string
	files     []file
	hardening *runresult.Hardening
}

func failed(format string, a ...any) taskResult {
	return taskResult{outcome: runresult.Failed, message: fmt.Sprintf(format, a...)}
}

func refused(message string) taskResult {
	return taskResult{outcome: runresult.Refused, message: message}
}

// Run runs one task and returns its result document. The document says completed only
// when the task's completion marker exists. Files are stored only for a task that
// succeeded and completed; a failed store turns the outcome to Failed.
func Run(ctx context.Context, cfg Config, env Env) runresult.Document {
	var t taskResult
	switch {
	case cfg.Mode != ModeNode:
		t = refused(messageNotSupported + "mode " + cfg.Mode)
	case cfg.Task == TaskInventory:
		t = inventory(ctx, cfg, env)
	case cfg.Task == TaskHardening:
		t = hardening(ctx, cfg, env)
	default:
		t = refused(messageNotSupported + "task " + cfg.Task)
	}
	doc := runresult.Document{Outcome: t.outcome, Message: t.message}
	doc.Completed = markerExists(env, cfg.Task)
	if t.outcome == runresult.Succeeded && !doc.Completed {
		t = taskResult{outcome: runresult.Incomplete, message: "completion-marker-missing"}
		doc.Outcome, doc.Message = t.outcome, t.message
	}
	if t.outcome != runresult.Succeeded {
		return doc
	}
	evidence, err := store(ctx, cfg, env, t.files)
	if err != nil {
		doc.Outcome, doc.Message = runresult.Failed, messageUploadFailed+err.Error()
		return doc
	}
	doc.Evidence = evidence
	if t.hardening != nil {
		for _, e := range evidence {
			if e.Kind == KindHardeningResults {
				t.hardening.ResultsKey = e.Key
			}
		}
		doc.Hardening = t.hardening
	}
	return doc
}

// Main reads the arguments, runs the task and writes the result document to the
// termination-message file and to stdout. It returns the exit code: 0 for the outcomes
// Succeeded and NoChange, 1 for every other outcome.
func Main(ctx context.Context, args []string, env Env, stdout, stderr io.Writer) int {
	var doc runresult.Document
	cfg, err := ParseArgs(args)
	if err != nil {
		doc = runresult.Document{Outcome: runresult.Refused, Message: messageInvalid + err.Error()}
	} else {
		doc = Run(ctx, cfg, env)
	}
	out, err := runresult.Encode(doc)
	if err != nil {
		doc = runresult.Document{Outcome: runresult.Failed, Message: "result-not-encoded: " + err.Error()}
		out, _ = runresult.Encode(doc)
	}
	if env.ResultFile != "" {
		if err := os.WriteFile(env.ResultFile, out, 0o600); err != nil {
			_, _ = fmt.Fprintf(stderr, "machine-runner: the result file was not written: %v\n", err)
		}
	}
	_, _ = fmt.Fprintln(stdout, string(out))
	if doc.Outcome == runresult.Succeeded || doc.Outcome == runresult.NoChange {
		return 0
	}
	return 1
}

// markerPath is the completion marker of a task.
func markerPath(env Env, task string) string {
	return filepath.Join(env.WorkDir, task+".completed")
}

// writeMarker is the last step of every task.
func writeMarker(env Env, task string) error {
	return os.WriteFile(markerPath(env, task), []byte(task+"\n"), 0o600)
}

func markerExists(env Env, task string) bool {
	if task == "" {
		return false
	}
	info, err := os.Stat(markerPath(env, task))
	return err == nil && info.Mode().IsRegular()
}

// collect runs one collector program. It returns nil when the program exits with one of
// the codes in ok. A program stopped by a signal gives Incomplete; a run whose context
// ended gives Cancelled; any other exit gives Failed with the end of the program's
// error output.
func collect(ctx context.Context, extraEnv []string, ok []int, program string, args ...string) *taskResult {
	cmd := exec.CommandContext(ctx, program, args...) //nolint:gosec // the program is a fixed path of Env; every argument was checked by ParseArgs
	cmd.Env = append(os.Environ(), extraEnv...)
	var stderr tail
	cmd.Stdout = io.Discard
	cmd.Stderr = &stderr
	err := cmd.Run()
	name := filepath.Base(program)
	if ctx.Err() != nil {
		return &taskResult{outcome: runresult.Cancelled, message: "cancelled while " + name + " ran"}
	}
	if err == nil {
		return nil
	}
	var exit *exec.ExitError
	if !errors.As(err, &exit) {
		return &taskResult{outcome: runresult.Failed, message: name + " did not start: " + err.Error()}
	}
	code := exit.ExitCode()
	if code < 0 {
		return &taskResult{outcome: runresult.Incomplete, message: name + " was stopped: " + exit.String()}
	}
	if containsInt(ok, code) {
		return nil
	}
	msg := fmt.Sprintf("%s exited %d", name, code)
	if s := strings.TrimSpace(stderr.String()); s != "" {
		msg += ": " + s
	}
	return &taskResult{outcome: runresult.Failed, message: msg}
}

func containsInt(list []int, n int) bool {
	for _, v := range list {
		if v == n {
			return true
		}
	}
	return false
}

// tail keeps the last 512 bytes written to it.
type tail struct{ b []byte }

func (t *tail) Write(p []byte) (int, error) {
	t.b = append(t.b, p...)
	if len(t.b) > 512 {
		t.b = t.b[len(t.b)-512:]
	}
	return len(p), nil
}

func (t *tail) String() string { return strings.ToValidUTF8(string(t.b), "") }

package runner

import (
	"context"
	"encoding/json"
	"encoding/xml"
	"errors"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"strings"
	"time"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/machines/runresult"
)

// HardeningResultsSchema is the schema of the file hardening.results.json.
const HardeningResultsSchema = "openova.io/machine-hardening-results/v1"

// HardeningResults is the file hardening.results.json: the result of every rule the
// evaluation selected, and the four counts of the result document. Reason is
// no-profile-for-release when the image has no data stream for the target's release;
// DataStream and Rules are then empty.
type HardeningResults struct {
	Schema         string       `json:"schema"`
	ProfileID      string       `json:"profileId"`
	ContentRelease string       `json:"contentRelease"`
	DataStream     string       `json:"dataStream"`
	Reason         string       `json:"reason"`
	Counts         Counts       `json:"counts"`
	Rules          []RuleResult `json:"rules"`
}

// Counts are the rule results by class.
type Counts struct {
	Pass          int `json:"pass"`
	Fail          int `json:"fail"`
	NotApplicable int `json:"notApplicable"`
	Error         int `json:"error"`
}

// RuleResult is the XCCDF result of one rule.
type RuleResult struct {
	ID     string `json:"id"`
	Result string `json:"result"`
}

// dataStreamProducts maps an operating-system family to the product prefix of the
// ComplianceAsCode data stream files, ssg-<prefix><version>-ds.xml. Ubuntu takes its
// version without the dot (24.04 gives 2404); every other family its major version.
// A family that is not listed has no data stream.
var dataStreamProducts = map[string]string{
	"ubuntu":      "ubuntu",
	"rhel":        "rhel",
	"almalinux":   "almalinux",
	"oraclelinux": "ol",
}

// DataStream returns the file name of the data stream for an operating-system family and
// version, and false when the family has none.
func DataStream(family, version string) (string, bool) {
	product, ok := dataStreamProducts[family]
	if !ok {
		return "", false
	}
	parts := strings.Split(version, ".")
	if family == "ubuntu" {
		if len(parts) != 2 || len(parts[0]) != 2 || len(parts[1]) != 2 {
			return "", false
		}
		return "ssg-" + product + parts[0] + parts[1] + "-ds.xml", true
	}
	return "ssg-" + product + parts[0] + "-ds.xml", true
}

// TailoredProfileID is the identifier of the profile a tailoring file derives from the
// profile it extends.
func TailoredProfileID(profileID string) string { return profileID + "_openova_tailored" }

// hardening evaluates one profile against the node's file system with oscap-chroot and
// writes hardening.arf.xml and hardening.results.json. A release of the content that the
// image does not hold is refused. A target whose release has no data stream succeeds with
// no rule and the message no-profile-for-release.
func hardening(ctx context.Context, cfg Config, env Env) taskResult {
	release := filepath.Join(env.ContentDir, cfg.ContentRelease)
	if info, err := os.Stat(release); err != nil || !info.IsDir() {
		return refused("content-release-not-in-image: " + cfg.ContentRelease)
	}
	summary := &runresult.Hardening{ProfileID: cfg.ProfileID, ContentRelease: cfg.ContentRelease}
	results := HardeningResults{Schema: HardeningResultsSchema, ProfileID: cfg.ProfileID,
		ContentRelease: cfg.ContentRelease, Rules: []RuleResult{}}
	name, ok := DataStream(cfg.OSFamily, cfg.OSVersion)
	ds := filepath.Join(release, name)
	if info, err := os.Stat(ds); !ok || err != nil || !info.Mode().IsRegular() {
		results.Reason = MessageNoProfile
		if err := writeJSON(filepath.Join(env.WorkDir, FileHardeningResults), results); err != nil {
			return failed("%s was not written: %v", FileHardeningResults, err)
		}
		if err := writeMarker(env, TaskHardening); err != nil {
			return failed("the completion marker was not written: %v", err)
		}
		return taskResult{outcome: runresult.Succeeded, message: MessageNoProfile, hardening: summary,
			files: []file{{KindHardeningResults, FileHardeningResults}}}
	}
	results.DataStream = name
	arf := filepath.Join(env.WorkDir, FileHardeningARF)
	args := []string{env.HostRoot, "xccdf", "eval", "--results-arf", arf}
	profile := cfg.ProfileID
	if len(cfg.DisabledRules) > 0 {
		tailoring := filepath.Join(env.WorkDir, "hardening.tailoring.xml")
		if err := os.WriteFile(tailoring, Tailoring(ds, cfg.ProfileID, cfg.DisabledRules, time.Now()), 0o600); err != nil {
			return failed("the tailoring file was not written: %v", err)
		}
		profile = TailoredProfileID(cfg.ProfileID)
		args = append(args, "--tailoring-file", tailoring)
	}
	args = append(args, "--profile", profile, ds)
	// oscap exits 0 when every rule passed and 2 when a rule failed; both are results.
	if r := collect(ctx, nil, []int{0, 2}, env.OscapChroot, args...); r != nil {
		return *r
	}
	rules, err := ReadARF(arf)
	if err != nil {
		return failed("%s cannot be read: %v", FileHardeningARF, err)
	}
	if len(rules) == 0 {
		return failed("%s holds no rule result", FileHardeningARF)
	}
	results.Rules = rules
	results.Counts = Count(rules)
	if err := writeJSON(filepath.Join(env.WorkDir, FileHardeningResults), results); err != nil {
		return failed("%s was not written: %v", FileHardeningResults, err)
	}
	if err := writeMarker(env, TaskHardening); err != nil {
		return failed("the completion marker was not written: %v", err)
	}
	summary.Pass, summary.Fail = results.Counts.Pass, results.Counts.Fail
	summary.NotApplicable, summary.Error = results.Counts.NotApplicable, results.Counts.Error
	return taskResult{outcome: runresult.Succeeded, hardening: summary,
		files: []file{{KindHardeningARF, FileHardeningARF}, {KindHardeningResults, FileHardeningResults}}}
}

// Count sorts rule results into the four counts: pass and fixed are pass; fail is fail;
// notapplicable is not applicable; error and unknown are error. The results notchecked
// and informational are not counted.
func Count(rules []RuleResult) Counts {
	var c Counts
	for _, r := range rules {
		switch r.Result {
		case "pass", "fixed":
			c.Pass++
		case "fail":
			c.Fail++
		case "notapplicable":
			c.NotApplicable++
		case "error", "unknown":
			c.Error++
		}
	}
	return c
}

const xccdfNS = "http://checklists.nist.gov/xccdf/1.2"

// ReadARF returns the XCCDF rule results of an ARF file, in file order, without the
// rules whose result is notselected.
func ReadARF(path string) ([]RuleResult, error) {
	f, err := os.Open(path) //nolint:gosec // a fixed name in the work folder
	if err != nil {
		return nil, err
	}
	defer func() { _ = f.Close() }()
	dec := xml.NewDecoder(f)
	var out []RuleResult
	var current *RuleResult
	inResult := false
	for {
		tok, err := dec.Token()
		if errors.Is(err, io.EOF) {
			break
		}
		if err != nil {
			return nil, err
		}
		switch t := tok.(type) {
		case xml.StartElement:
			if t.Name.Space != xccdfNS {
				continue
			}
			switch t.Name.Local {
			case "rule-result":
				current = &RuleResult{}
				for _, a := range t.Attr {
					if a.Name.Local == "idref" {
						current.ID = a.Value
					}
				}
			case "result":
				inResult = current != nil
			}
		case xml.CharData:
			if inResult {
				current.Result += strings.TrimSpace(string(t))
			}
		case xml.EndElement:
			if t.Name.Space != xccdfNS {
				continue
			}
			switch t.Name.Local {
			case "result":
				inResult = false
			case "rule-result":
				if current == nil {
					continue
				}
				if current.ID == "" || current.Result == "" {
					return nil, fmt.Errorf("a rule-result without idref or result")
				}
				if current.Result != "notselected" {
					out = append(out, *current)
				}
				current = nil
			}
		}
	}
	return out, nil
}

// Tailoring returns an XCCDF 1.2 tailoring file for the data stream ds. Its one profile
// extends profileID and deselects each rule in disabled. Every identifier has been
// checked by ParseArgs; the text is escaped all the same.
func Tailoring(ds, profileID string, disabled []string, now time.Time) []byte {
	var b strings.Builder
	b.WriteString(`<?xml version="1.0" encoding="UTF-8"?>` + "\n")
	b.WriteString(`<xccdf:Tailoring xmlns:xccdf="` + xccdfNS + `" id="xccdf_io.openova_tailoring_machine-runner">` + "\n")
	b.WriteString(`  <xccdf:benchmark href="` + escape(ds) + `"/>` + "\n")
	b.WriteString(`  <xccdf:version time="` + now.UTC().Format("2006-01-02T15:04:05") + `">1</xccdf:version>` + "\n")
	b.WriteString(`  <xccdf:Profile id="` + escape(TailoredProfileID(profileID)) + `" extends="` + escape(profileID) + `">` + "\n")
	b.WriteString(`    <xccdf:title>` + escape(profileID) + ` tailored by machine-runner</xccdf:title>` + "\n")
	for _, rule := range disabled {
		b.WriteString(`    <xccdf:select idref="` + escape(rule) + `" selected="false"/>` + "\n")
	}
	b.WriteString("  </xccdf:Profile>\n</xccdf:Tailoring>\n")
	return []byte(b.String())
}

func escape(s string) string {
	var b strings.Builder
	_ = xml.EscapeText(&b, []byte(s))
	return b.String()
}

func writeJSON(path string, v any) error {
	data, err := json.MarshalIndent(v, "", "  ")
	if err != nil {
		return err
	}
	return os.WriteFile(path, append(data, '\n'), 0o600)
}

// The files of the object-storage binding (contract object-storage v1) that the runner
// reads. The key pair is required; ca.crt is present when the endpoint's certificate is
// not publicly trusted.
const (
	BindingAccessKeyID     = "access-key-id"
	BindingSecretAccessKey = "secret-access-key"
	BindingCA              = "ca.crt"
)

// binding is the key pair of the evidence bucket and the optional certificate bundle.
type binding struct {
	accessKeyID     string
	secretAccessKey string
	ca              []byte
}

// readBinding reads the binding files in dir. A missing or empty key file is an error.
func readBinding(dir string) (binding, error) {
	var b binding
	for _, f := range []struct {
		name string
		to   *string
	}{{BindingAccessKeyID, &b.accessKeyID}, {BindingSecretAccessKey, &b.secretAccessKey}} {
		data, err := os.ReadFile(filepath.Join(dir, f.name)) //nolint:gosec // a fixed name in the mounted binding
		if err != nil {
			return binding{}, fmt.Errorf("the binding file %s cannot be read", f.name)
		}
		*f.to = strings.TrimSpace(string(data))
		if *f.to == "" {
			return binding{}, fmt.Errorf("the binding file %s is empty", f.name)
		}
	}
	ca, err := os.ReadFile(filepath.Join(dir, BindingCA)) //nolint:gosec // a fixed name in the mounted binding
	switch {
	case err == nil:
		b.ca = ca
	case !errors.Is(err, os.ErrNotExist):
		return binding{}, fmt.Errorf("the binding file %s cannot be read: %v", BindingCA, err)
	}
	return b, nil
}

// store puts each file of the work folder into the evidence bucket under the key
// <prefix><file name>, over HTTPS with certificate validation, and returns the evidence
// entries in the order of files.
func store(ctx context.Context, cfg Config, env Env, files []file) ([]runresult.Evidence, error) {
	b, err := readBinding(env.BindingDir)
	if err != nil {
		return nil, err
	}
	pool, err := x509.SystemCertPool()
	if err != nil {
		pool = x509.NewCertPool()
	}
	if len(b.ca) > 0 && !pool.AppendCertsFromPEM(b.ca) {
		return nil, fmt.Errorf("the binding file %s holds no certificate", BindingCA)
	}
	transport := http.DefaultTransport.(*http.Transport).Clone()
	transport.TLSClientConfig = &tls.Config{RootCAs: pool, MinVersion: tls.VersionTLS12}
	endpoint, err := url.Parse(cfg.Evidence.Endpoint)
	if err != nil {
		return nil, err
	}
	client, err := minio.New(endpoint.Host, &minio.Options{
		Creds:     credentials.NewStaticV4(b.accessKeyID, b.secretAccessKey, ""),
		Secure:    true,
		Region:    cfg.Evidence.Region,
		Transport: transport,
	})
	if err != nil {
		return nil, err
	}
	var out []runresult.Evidence
	for _, f := range files {
		e, err := put(ctx, client, cfg, filepath.Join(env.WorkDir, f.name), f)
		if err != nil {
			return nil, fmt.Errorf("%s: %w", f.name, err)
		}
		out = append(out, e)
	}
	return out, nil
}

// put stores one file and returns its evidence entry.
func put(ctx context.Context, client *minio.Client, cfg Config, path string, f file) (runresult.Evidence, error) {
	h, err := os.Open(path) //nolint:gosec // a fixed name in the work folder
	if err != nil {
		return runresult.Evidence{}, err
	}
	defer func() { _ = h.Close() }()
	sum := sha256.New()
	size, err := io.Copy(sum, h)
	if err != nil {
		return runresult.Evidence{}, err
	}
	if _, err := h.Seek(0, io.SeekStart); err != nil {
		return runresult.Evidence{}, err
	}
	contentType := "application/json"
	if strings.HasSuffix(f.name, ".xml") {
		contentType = "application/xml"
	}
	key := cfg.Evidence.Prefix + f.name
	if _, err := client.PutObject(ctx, cfg.Evidence.Bucket, key, h, size,
		minio.PutObjectOptions{ContentType: contentType, DisableMultipart: true}); err != nil {
		return runresult.Evidence{}, err
	}
	return runresult.Evidence{Kind: f.kind, Key: key, SHA256: hex.EncodeToString(sum.Sum(nil))}, nil
}

// unchunk decodes an aws-chunked body: chunks of "<hex size>[;...]\r\n<data>\r\n".
func unchunk(body []byte) []byte {
	var out []byte
	r := bufio.NewReader(bytes.NewReader(body))
	for {
		line, err := r.ReadString('\n')
		if err != nil {
			return out
		}
		size, err := strconv.ParseInt(strings.TrimSpace(strings.SplitN(line, ";", 2)[0]), 16, 64)
		if err != nil || size == 0 {
			return out
		}
		chunk := make([]byte, size)
		if _, err := io.ReadFull(r, chunk); err != nil {
			return out
		}
		out = append(out, chunk...)
		_, _ = r.ReadString('\n')
	}
}
