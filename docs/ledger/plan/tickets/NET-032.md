# NET-032 — Reserve platform namespace names as Organization slugs

## In plain words

**The problem today.** An Organization's slug becomes the name of its namespace on the host cluster. The Organization kind refuses only twenty words, so an Organization can be named after a platform namespace such as kube-system, keycloak or flux-system and take it over. The organizations service, where a customer picks the slug, refuses none of them.

**What changes.** The Organization kind and the organizations service both refuse every namespace name of the bootstrap kit and the retired platform names. A new guard keeps the two lists in step with the kit, so a new kit namespace cannot be forgotten.

**Done means:**

- Creating an Organization in the organizations service with the slug mgmt, or with the name of any namespace of the bootstrap kit, is answered with HTTP 422 and the message slug is reserved.
- The Organization kind refuses the same slugs, and also the words that name a cloud provider.
- A sample Organization with the slug mgmt is refused by the schema test of the sovereign-admin API, and the same object with an ordinary slug passes.
- A guard on every pull request fails when a namespace of the kit's placement table is missing from the kind's list, or when the organizations service's list differs from it.
- No shared file names a cloud provider on more lines than before, and no file gains the name of the withdrawn product.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
No Organization can take the name of a platform namespace. The Organization kind (`products/catalyst/chart/crds/organization.yaml`) refuses, as `spec.slug`, every `namespace:` value of `clusters/_template/bootstrap-kit/placement.yaml`, the retired platform names and the words it refuses today. ## 3. The model (the law)
1. **The kind's list.** The `not.enum` list of `spec.slug` in `products/catalyst/chart/crds/organization.yaml` holds exactly these 71 words:
   - the 20 words of today: `system flux crossplane catalyst gitea hetzner huawei oci aws gcp azure contabo rtz dmz mgt prod stg uat dev poc`;
   - the retired platform names: `mgmt monitoring ingress default edge platform org-services`;
   - every distinct `namespace:` value of `clusters/_template/bootstrap-kit/placement.yaml` that is not already above: 44 words, two of which name a cloud provider (`hcloud-csi`, `huawei-evs-csi`).
2. **The word `sandbox` is not reserved.** No namespace of that name exists in the repository, the product of that name is withdrawn (decision record 0023), and `scripts/check-sandbox-word.py` (workflow `check-repo-hygiene`) fails a pull request that adds a file holding that word. Writing it into the kind would add one.
3. **The list is one flow sequence.** The list is written as `enum: [ ... ]` over eleven lines, so the four words that name a cloud provider share one line. `scripts/check-provider-leaks.py` counts a line that names a provider in shared code, and the count may only fall: today the file has 6 such lines (2 of them the list entries `hetzner` and `huawei`); after the change it has 5. The description of `slug` is rewritten to describe the list instead of naming some of its words.
4. **The service's list.** `reservedSlugs` in `core/services/tenant/handlers/handlers.go` holds exactly the words of the kind's list that the provider-leak scanner does not count (its `TIER1` and `TIER2` patterns): 67 words, all but `hetzner`, `huawei`, `hcloud-csi`, `huawei-evs-csi`. Shared code names no cloud provider (that guard refuses a new shared file with such a line), and the Organization kind refuses those four words on its own. The words are written in one raw string read by `strings.Fields`, so the guard can read them.
5. **The service's refusal.** `validTenantSlug` returns false for a reserved word. `CreateOrg` checks `reservedSlugs` first, after the required-field check and before the pattern check and the store: a reserved slug is answered with HTTP 422 and the JSON body `{"error":"slug is reserved"}`. A slug that does not match the pattern is answered with HTTP 400 as today.
6. **The guard.** `scripts/check-reserved-slugs.py` has two rules. `kit`: every namespace of `placement.yaml` is in the kind's list. `go`: the service's list equals the kind's list without the words the provider-leak scanner counts; a missing word and an extra word are each a finding. A file it cannot read or parse is a failure, never a pass. `--self-test` shows on fixtures that every rule and every unreadable case fails. It uses Python 3, PyYAML and `scripts/check-provider-leaks.py`, whose `TIER1` and `TIER2` it loads instead of copying them.
7. **The workflow.** `.github/workflows/check-reserved-slugs.yaml` runs the self-test and then the guard on every pull request, merge group and push to `main`, with no path filter: a check that a path filter skips never reports. Its checkout action is pinned by commit, as `scripts/check-pins.py` requires of a new workflow.
8. **The sample and its test.** `products/catalyst/chart/crds/tests/organization-sample-reserved-slug.yaml` is one Organization that is valid in every field but its slug `mgmt`. `TestOrganizationSampleReservedSlug` in `products/catalyst/bootstrap/api/internal/intent/organization_slug_test.go` proves the schema refuses it with exactly one error, the `not` rule of `spec.slug`, and accepts it with the slug `acme-co`. It is a file of its own because the sample reader of that package reads only the first document of a file.
9. **The schema bundle.** `products/catalyst/bootstrap/api/internal/intent/crds/schemas.json` is written by its own test (`INTENT_WRITE_SCHEMAS=1`), never by hand. One line changes: the Organization's.
10. Nothing else changes. No version line, no baseline file, no other slug check.

#!/usr/bin/env python3
"""check-reserved-slugs.py - an Organization never takes the name of a platform namespace.

An Organization's slug names its namespace on the host cluster. Two lists refuse the slugs
that would take a platform namespace over:

  CRD  the not.enum list of spec.slug in products/catalyst/chart/crds/organization.yaml
       (every version of the kind);
  GO   the words of reservedSlugs in core/services/tenant/handlers/handlers.go, written as
       var reservedSlugs = func() map[string]bool { ... strings.Fields(`<words>`) ... }().

This guard keeps both lists in step with the namespaces of the bootstrap kit, the
`namespace:` value of every slot in clusters/_template/bootstrap-kit/placement.yaml.

Usage, from anywhere inside the repository:

  python3 scripts/check-reserved-slugs.py [--repo DIR]
  python3 scripts/check-reserved-slugs.py --self-test

Exit code 0: the rules hold. 1: a rule is broken, or a file the rules read is missing or
cannot be read; one line per finding. 2: wrong usage.

The rules, exactly.

  kit  Every namespace of placement.yaml is in the CRD list.
  go   The GO list holds exactly the words of the CRD list that name no cloud provider. A word
       names a cloud provider when the provider-leak scanner counts it (TIER1 or TIER2 of
       scripts/check-provider-leaks.py): shared code names no provider, and the
       Organization kind refuses those words on its own. A word missing from the GO list
       and a word the GO list holds besides are each a finding.

Python 3, PyYAML and the scripts of this repository only.
"""
import importlib.util
import os
import re
import subprocess
import sys
import tempfile

import yaml

PLACEMENT = "clusters/_template/bootstrap-kit/placement.yaml"
CRD = "products/catalyst/chart/crds/organization.yaml"
GO = "core/services/tenant/handlers/handlers.go"
LEAKS = "scripts/check-provider-leaks.py"
GO_VAR = "var reservedSlugs = func() map[string]bool {"
GO_WORDS = re.compile(r"strings\.Fields\(`([^`]*)`\)")


class Unreadable(Exception):
    """A file the rules read is missing or malformed. The check then fails: never a pass on
    missing evidence."""


def read(root, rel):
    try:
        with open(os.path.join(root, rel), encoding="utf-8") as f:
            return f.read()
    except OSError as e:
        raise Unreadable("%s: cannot be read: %s" % (rel, e.strerror))


def kit_namespaces(root):
    try:
        doc = yaml.safe_load(read(root, PLACEMENT))
        slots = doc["spec"]["slots"]
        names = [s["namespace"] for s in slots]
    except (yaml.YAMLError, KeyError, TypeError) as e:
        raise Unreadable("%s: no spec.slots[].namespace: %s" % (PLACEMENT, e))
    if not slots or not all(isinstance(n, str) and n for n in names):
        raise Unreadable("%s: spec.slots is empty or a namespace is not a word" % PLACEMENT)
    return set(names)


def crd_words(root):
    try:
        docs = [d for d in yaml.safe_load_all(read(root, CRD)) if d]
        lists = [v["schema"]["openAPIV3Schema"]["properties"]["spec"]["properties"]["slug"]["not"]["enum"]
                 for d in docs for v in d["spec"]["versions"]]
    except (yaml.YAMLError, KeyError, TypeError) as e:
        raise Unreadable("%s: no spec.slug.not.enum: %s" % (CRD, e))
    if not lists or not lists[0] or any(l != lists[0] for l in lists):
        raise Unreadable("%s: spec.slug.not.enum is missing, empty or differs between versions" % CRD)
    if not all(isinstance(w, str) for w in lists[0]):
        raise Unreadable("%s: spec.slug.not.enum holds a value that is not a word" % CRD)
    return set(lists[0])


def go_words(root):
    text = read(root, GO)
    if text.count(GO_VAR) != 1:
        raise Unreadable("%s: the line %r is there %d times, not once" % (GO, GO_VAR, text.count(GO_VAR)))
    m = GO_WORDS.search(text, text.index(GO_VAR))
    if not m or not m.group(1).split():
        raise Unreadable("%s: reservedSlugs has no strings.Fields(`...`) list" % GO)
    return set(m.group(1).split())


def provider_rule(root):
    path = os.path.join(root, LEAKS)
    if not os.path.isfile(path):
        raise Unreadable("%s: cannot be read" % LEAKS)
    spec = importlib.util.spec_from_file_location("provider_leaks", path)
    module = importlib.util.module_from_spec(spec)
    try:
        spec.loader.exec_module(module)
        tier1, tier2 = module.TIER1, module.TIER2
    except Exception as e:  # noqa: BLE001 - any failure to load is a missing rule
        raise Unreadable("%s: TIER1 and TIER2 cannot be loaded: %s" % (LEAKS, e))
    return lambda word: bool(tier1.search(word) or tier2.search(word))


def findings(root):
    kit, crd, go = kit_namespaces(root), crd_words(root), go_words(root)
    names_provider = provider_rule(root)
    out = ["kit: namespace %s of %s is not in the list of %s" % (n, PLACEMENT, CRD)
           for n in sorted(kit - crd)]
    want = {w for w in crd if not names_provider(w)}
    out += ["go: %s is in the list of %s but not in reservedSlugs of %s" % (w, CRD, GO)
            for w in sorted(want - go)]
    out += ["go: reservedSlugs of %s holds %s, which %s" % (
        GO, w, "names a cloud provider" if names_provider(w) else "the list of %s does not hold" % CRD)
        for w in sorted(go - want)]
    return out, len(kit), len(crd), len(go)


def check(root):
    try:
        out, kit, crd, go = findings(root)
    except Unreadable as e:
        print("reserved-slugs: %s" % e)
        return 1
    for line in out:
        print("reserved-slugs: %s" % line)
    if out:
        return 1
    print("reserved-slugs: ok, %d kit namespaces, %d words in the kind, %d in reservedSlugs" % (kit, crd, go))
    return 0

def self_test():

    failures = []

    def case(name, want, edit=None, drop=None):

func createOrgAs(t *testing.T, body string) *httptest.ResponseRecorder {
	t.Helper()
	req := httptest.NewRequest(http.MethodPost, "/tenant/orgs", strings.NewReader(body))
	req = req.WithContext(middleware.WithClaims(context.Background(), map[string]any{"sub": "u-1"}))

	(&Handler{}).CreateOrg(rec, req)
	return rec
}

func assertReserved(t *testing.T, slug string, rec *httptest.ResponseRecorder) {
	t.Helper()
	if rec.Code != http.StatusUnprocessableEntity {
		t.Fatalf("slug %q: status %d, want %d; body %s", slug, rec.Code, http.StatusUnprocessableEntity, rec.Body.String())
	}
	var got map[string]string
	if err := json.Unmarshal(rec.Body.Bytes(), &got); err != nil {
		t.Fatalf("slug %q: body is not JSON: %v: %s", slug, err, rec.Body.String())
	}
	if got["error"] != "slug is reserved" {
		t.Fatalf("slug %q: error %q, want %q", slug, got["error"], "slug is reserved")
	}
}

// TestCreateOrg_SlugMgmtIsRefused: the slug mgmt is answered with HTTP 422
// and the message "slug is reserved".
func TestCreateOrg_SlugMgmtIsRefused(t *testing.T) {

}

	}
}
