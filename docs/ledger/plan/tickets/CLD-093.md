# CLD-093 — Contract rule: adding a region plans only additions

## In plain words

**The problem today.** Adding a region to a running Sovereign must leave its existing regions as they are. Nothing checks that a cloud module plans only new resources when a region is added, so a module that rewrites or replaces the resources of an existing region would show it first on a live Sovereign.

**What changes.** A small check reads an OpenTofu plan and fails on anything but new and unchanged resources. On every pull request the local provider pack is applied with one region and planned with two, and the check judges that plan before the two-region pack comes up.

**Done means:**

- A plan that would update, replace, delete or forget a resource fails the check, and so does a plan that creates nothing.
- The check proves with its self-test that each of its rules can fail.
- On every pull request the job conformance-local applies the local module with one region, plans two regions against that state, and fails when that plan changes anything that already exists.
- The machines of that proof are destroyed before the two-region pack comes up, also after a failure.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A new script, `scripts/check-plan-additive.py`, reads an OpenTofu plan in its JSON form (the output of `tofu show -json <plan file>`) and exits 0 only when the plan creates at least one resource and leaves every other resource unchanged. The job `conformance-local` of `.github/workflows/conformance-local.yaml` gets five new steps before its step "Up (two regions)": they apply the local module (`infra/providers/local`) with the one region of the contract fixture `single-region.tfvars.json`, plan the fixture `two-region.tfvars.json` against that state, run the script on that plan, and destroy what they applied. A person sees on every pull request that the check `conformance-local` passes only when adding a region to the local pack plans additions and nothing else.

## 3. The model (the law)
1. **The rule.** Adding a region to a deployment plans only additions: every managed resource of the plan is created or unchanged. Update, delete, replacement (delete and create, in either order) and forget are failures.
2. **The script.** `scripts/check-plan-additive.py` is the block `check-plan-additive.py` of field 5, byte for byte. Its rules: (1) every entry of `resource_changes` with `mode` `managed` has the actions `["create"]` or `["no-op"]`; (2) the plan creates at least one managed resource, because a plan that creates nothing added no region and proves nothing; (3) no managed entry of `resource_drift` has the action `delete`, because such a resource appears as a create but is made again, not added. Entries with `mode` `data` are not judged: reading a data source changes nothing. Outputs are not judged. Input without `format_version` or `planned_values`, a plan with `"errored": true`, and a `resource_changes` or `resource_drift` that is not a list are refused. Exit codes: 0 pass, 1 a rule failed, 2 wrong usage or not a plan. Each failure prints one line that starts with `NOT ADDITIVE`; the last line is a summary. `--self-test` runs 18 cases and shows that every rule can fail and can pass.
3. **The proof on the local pack.** The two contract fixtures `infra/providers/_contract/fixtures/single-region.tfvars.json` and `two-region.tfvars.json` hold the same inputs; the second has one more region, `region-b`. The new steps run OpenTofu in `infra/providers/local` with their own working data and state under `$RUNNER_TEMP/plan-additive`: `init`; `apply` with the first fixture; `plan` with the second fixture against that state, written to a plan file; `show -json` of that file; the script on that JSON; `destroy` with the first fixture, also after a failure (`if: always()`), and a pass when nothing was applied.
4. **Place in the job.** The five steps are the block `CLD-093-steps.yaml` of field 5, byte for byte, inserted directly before the step "Up (two regions)" with one empty line between. The job is the one that already checks out the repository and installs OpenTofu 1.11.6. No new job is added: a new job in a workflow without a path filter would start on every pull request, and `scripts/check-pr-jobs.py count` limits those jobs (to 12 at this commit). No new `uses:` line is added, so the pin ratchet `scripts/check-pins.py` counts no new reference.
5. **No clash with the pack.** The proof's machines use the fixture's Sovereign name and deployment identifier, and its Docker network uses the module's default address range, which the pack uses too. They are destroyed before "Up (two regions)" starts. When a step of the proof fails, the steps after it that have no condition do not run, so the pack is not brought up.
6. **Nothing is fixed here.** When the local module does not meet the rule, the job is red and that is the finding. No file under `infra/providers` changes in this ticket.

```python
#!/usr/bin/env python3
"""check-plan-additive.py - a plan that adds a region creates resources and changes none.

Adding a region to a Sovereign must leave the regions it already has as they are. This check
reads an OpenTofu plan in its JSON form, the output of `tofu show -json <plan file>`, and
judges it by three rules:
  1. Every managed resource in resource_changes has the action create or no-op. Any other
     action fails: update, delete, a replacement (delete and create in either order), forget.
  2. The plan creates at least one managed resource. A plan that creates nothing did not add a
     region, so it proves nothing.
  3. No managed resource in resource_drift was deleted outside OpenTofu. Such a resource shows
     as a create in resource_changes, but it is made again, not added.
Data sources (mode data) are not judged: reading one changes nothing. Outputs are not judged.
A file that is not a plan (no format_version, no planned_values) or a plan that errored is
refused with exit code 2.

Usage (from the repository root):
  python3 scripts/check-plan-additive.py <plan.json>   judge the plan; - reads standard input
  python3 scripts/check-plan-additive.py --self-test   show that every rule can fail and pass
Output: one line `NOT ADDITIVE <address>: <reason>` for each resource that breaks a rule, then
one summary line. Exit codes: 0 the plan only adds; 1 a rule failed; 2 wrong usage or not a plan.
"""
import json
import os
import subprocess
import sys
import tempfile

ALLOWED = (["create"], ["no-op"])


class NotAPlan(Exception):
    """The input cannot be judged: it is not the JSON form of an OpenTofu plan."""


def load(text):
    """The plan object of a JSON text. Raises NotAPlan when the text is not a plan."""
    try:
        plan = json.loads(text)
    except ValueError as e:
        raise NotAPlan("not JSON: %s" % e)
    if not isinstance(plan, dict) or "format_version" not in plan or "planned_values" not in plan:
        raise NotAPlan("not a plan: format_version or planned_values is missing")
    if plan.get("errored") is True:
        raise NotAPlan("the plan errored, so it is not complete")
    for key in ("resource_changes", "resource_drift"):
        if not isinstance(plan.get(key, []), list):
            raise NotAPlan("not a plan: %s is not a list" % key)
    return plan


def managed(entries):
    """The entries of a plan list that are managed resources."""
    return [e for e in entries if isinstance(e, dict) and e.get("mode") == "managed"]


def actions(entry):
    return list(((entry.get("change") or {}).get("actions")) or [])


def judge(plan):
    """(exit code, lines) for a plan object: 0 when the plan only adds, 1 otherwise."""
    lines = []
    changes = managed(plan.get("resource_changes", []))
    for e in changes:
        a = actions(e)
        if a not in ALLOWED:
            lines.append("NOT ADDITIVE %s: action %s" % (e.get("address", "?"), ",".join(a) or "none"))
    for e in managed(plan.get("resource_drift", [])):
        if "delete" in actions(e):
            lines.append("NOT ADDITIVE %s: deleted outside OpenTofu, so the plan makes it again" % e.get("address", "?"))
    created = sum(1 for e in changes if actions(e) == ["create"])
    unchanged = sum(1 for e in changes if actions(e) == ["no-op"])
    if created == 0:
        lines.append("NOT ADDITIVE: the plan creates no resource, so it adds no region")
    if lines:
        lines.append("check-plan-additive: FAIL, %d finding(s); %d to create, %d unchanged" % (len(lines), created, unchanged))
        return 1, lines
    lines.append("check-plan-additive: ok, %d to create, %d unchanged" % (created, unchanged))
    return 0, lines


def run(argv):
    if len(argv) != 1 or argv[0].startswith("--"):
        print("usage: check-plan-additive.py <plan.json> | - | --self-test", file=sys.stderr)
        return 2
    try:
        if argv[0] == "-":
            text = sys.stdin.read()
        else:
            with open(argv[0], encoding="utf-8") as fh:
                text = fh.read()
        plan = load(text)
    except (OSError, NotAPlan) as e:
        print("check-plan-additive: %s" % e, file=sys.stderr)
        return 2
    code, lines = judge(plan)
    for line in lines:
        print(line)
    return code


def self_test():
    def rc(address, acts, mode="managed"):
        return {"address": address, "mode": mode, "change": {"actions": acts}}

    def plan(changes, drift=None, **more):
        p = {"format_version": "1.2", "planned_values": {}, "resource_changes": changes}
        if drift is not None:
            p["resource_drift"] = drift
        p.update(more)
        return p

    base = [rc("a.old", ["no-op"]), rc("a.new", ["create"]), rc("data.x.y", ["read"], mode="data")]
    cases = [
        ("pass: creates and unchanged resources, a data source read", plan(base), 0),
        ("pass: a drift that only updates is not judged", plan(base, [rc("a.old", ["update"])]), 0),
        ("rule 1: an update fails", plan(base + [rc("a.x", ["update"])]), 1),
        ("rule 1: a delete fails", plan(base + [rc("a.x", ["delete"])]), 1),
        ("rule 1: a replacement (delete, create) fails", plan(base + [rc("a.x", ["delete", "create"])]), 1),
        ("rule 1: a replacement (create, delete) fails", plan(base + [rc("a.x", ["create", "delete"])]), 1),
        ("rule 1: a forget fails", plan(base + [rc("a.x", ["forget"])]), 1),
        ("rule 1: a resource without actions fails", plan(base + [{"address": "a.x", "mode": "managed"}]), 1),
        ("rule 2: a plan that creates nothing fails", plan([rc("a.old", ["no-op"])]), 1),
        ("rule 2: a plan without resource_changes fails", plan([]), 1),
        ("rule 3: a resource deleted outside OpenTofu fails", plan(base, [rc("a.old", ["delete"])]), 1),
    ]
    failed = 0
    for name, p, want in cases:
        got, lines = judge(load(json.dumps(p)))
        ok = got == want and (want == 0 or any(l.startswith("NOT ADDITIVE") for l in lines))
        print("%s %s" % ("ok  " if ok else "FAIL", name))
        failed += 0 if ok else 1
    refused = [
        ("refused: a text that is not JSON", "{"),
        ("refused: a state, not a plan", json.dumps({"format_version": "1.0", "values": {}})),
        ("refused: a plan that errored", json.dumps(plan(base, errored=True))),
        ("refused: resource_changes that is not a list", json.dumps(plan({}))),
    ]
    for name, text in refused:
        try:
            load(text)
            ok = False
        except NotAPlan:
            ok = True
        print("%s %s" % ("ok  " if ok else "FAIL", name))
        failed += 0 if ok else 1
    # The command itself, on files: exit codes 0, 1 and 2.
    with tempfile.TemporaryDirectory() as d:
        for name, content, want in (
            ("command: a plan that only adds exits 0", json.dumps(plan(base)), 0),
            ("command: a plan with an update exits 1", json.dumps(plan(base + [rc("a.x", ["update"])])), 1),
            ("command: a file that is not a plan exits 2", "not a plan", 2),
        ):
            path = os.path.join(d, "plan.json")
            with open(path, "w", encoding="utf-8") as fh:
                fh.write(content)
            got = subprocess.run([sys.executable, os.path.abspath(__file__), path], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL).returncode
            ok = got == want
            print("%s %s" % ("ok  " if ok else "FAIL", name))
            failed += 0 if ok else 1
    print("check-plan-additive self-test: %s" % ("ok" if failed == 0 else "FAILED"))
    return 0 if failed == 0 else 1


if __name__ == "__main__":
    if sys.argv[1:] == ["--self-test"]:
        sys.exit(self_test())
    sys.exit(run(sys.argv[1:]))
```
