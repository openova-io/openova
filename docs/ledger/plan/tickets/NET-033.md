# NET-033 — The definition-of-done verifier stops requiring retired releases

## In plain words

**The problem today.** The shell verifier that says whether a Sovereign is ready demands three releases that the platform no longer installs. It reports them as missing on every Sovereign, so it can never say ready.

**What changes.** The verifier stops demanding the three retired releases. Every release it still demands is one that the bootstrap kit installs.

**Done means:**

- The verifier no longer names the three retired releases.
- Every release that the verifier demands is installed by a slot of the bootstrap kit.
- The verifier is still valid shell, and no other line of it changed.

The rest of this ticket is the exact instruction for the model that does the work.
