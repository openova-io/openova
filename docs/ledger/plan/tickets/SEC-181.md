# SEC-181 — OpenBao restore drill: a known key is read back from a restored snapshot

## In plain words

**The problem today.** OpenBao is backed up to the bucket every six hours, but nothing proves that a snapshot can be restored and still holds the values written before it. A backup that is never restored can be empty, unreadable or unsealable without anyone noticing, and the backup is switched off on every Sovereign today.

**What changes.** Every Sovereign runs the backup and, before each one, a drill that restores the newest snapshot into a throw-away OpenBao and reads back a value it wrote just before. A gate check reads the drill's record in every region and fails when the restore is missing, stale or wrong.

**Done means:**

- A fresh Sovereign takes a snapshot of OpenBao every six hours and runs the restore drill before each one, in every region.
- The drill's token is minted for the drill alone, can read and write only the drill's own path, lives at most 15 minutes, cannot be renewed and is in no Secret.
- The restore goes into a scratch OpenBao in the drill's own pod and never touches the live store.
- A value read back that differs from the one written fails the drill, and its record says why.
- Gate check SEC-G10 is required: it fails in a region with no drill record, with a restored snapshot older than 7 hours, with a value read back unlike the one written or with a token that lived longer than 15 minutes.
- The gate check of the OpenBao seal still refuses every Job in namespace openbao except those of the backup and the drill.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. Off by default: with `restoreDrill.enabled` false nothing of the drill renders, and the desired state has no policy or token role `sec-g10-drill`. The kit, not the chart default, switches it on.
2. The drill writes a fresh random canary under `<kv>/data/sec-g10-drill/canary` before the snapshot it restores, and restores this region's first snapshot in the bucket that is newer than the write.
3. The drill's token is minted by service account `openbao-config` (login role `openbao-config-admin`) through token role `sec-g10-drill`: policy `sec-g10-drill` only, no default policy, at most 15 minutes, not renewable, a child of the login. No Secret holds it. The drill revokes its login, and with it the token, at the end of every run.
4. Policy `sec-g10-drill` grants read and write on the canary path and on nothing else.
5. The restore goes into a scratch OpenBao in the drill's own pod: the store's seal stanza and the node's seal file, storage inside the pod, listening on `127.0.0.1` only. The drill never writes to the live store except its canary.
6. The drill fails when the value read back differs from the value written. Its record, ConfigMap `openbao/openbao-restore-drill`, holds the snapshot's key and time, the SHA-256 digests of the value written and of the value read, the token's lifetime and renewability and any error; never a value or a token.
7. The bucket's key pair reaches namespace `openbao` only as the reflector's copy of `flux-system/object-storage`; only the reflector writes that copy, and the register lists it.
8. SEC-G10 runs in the cloud only (`runs_in: [cloud]`, unchanged) and fails per region on no record (nothing measured), a snapshot older than 7 hours, digests that differ, a token lifetime over 15 minutes or a renewable token.
9. SEC-G03 accepts exactly the Jobs `openbao-backup-<digits>` and `openbao-restore-drill-<digits>`; a Job of any other name, also one that starts with `openbao-backup-`, still fails it.
10. The cloud-init render test's expected object of `object-storage.yaml` carries the four reflector annotations; nothing of the bootstrap Secrets enters first boot.

+// CronJob openbao-restore-drill of bp-openbao (templates/restore-drill.yaml)
+// runs before each backup: with a token minted by the configuration identity
+// through token role sec-g10-drill it writes a fresh canary, restores this
+// region's first snapshot that is newer than the write from the bucket into a
+// scratch OpenBao, and reads the canary back. It records the result in
+// ConfigMap openbao/openbao-restore-drill: snapshot (the object key),
+// snapshotTime, written and read (the SHA-256 digests of the value written
+// and of the value read back), tokenTTLSeconds, tokenRenewable, finished and
+// error. The check reads that ConfigMap with `kubectl get` and creates no
+// object. The step of a region fails when there is no record (no drill has
+// run: nothing was measured), when the drill recorded an error, when the
+// restored snapshot is older than 7 hours, when the digest read back is not
+// the 64-character digest written, or when the drill token lived longer than
+// 15 minutes or was renewable.

+	secBackupRecord = "openbao-restore-drill"
+	secBackupMaxAge = 7 * time.Hour
+	secBackupMaxTTL = 15 * 60 // seconds
+)

+var secBackupDigest = regexp.MustCompile(`^[0-9a-f]{64}$`)

+type secBackupCheck struct {
+	kubectl kubectlFunc
+	now     func() time.Time
+}

+func (secBackupCheck) ID() string { return secBackupID }

+func (c secBackupCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
+	if len(cc.Regions) == 0 {
+		return errors.New("the run has no region")
+	}
+	for i, region := range cc.Regions {
+		checkStep(rec, secBackupID, i+1, "an OpenBao snapshot of region "+region.ID+" younger than 7 hours was restored and returned the canary written before it",

+	}
+	return nil
+}

+func (c secBackupCheck) region(ctx context.Context, region kube.Region, ev Evidence) error {
+	ev["region"] = region.ID
+	out, err := c.kubectl(region, ctx, nil, "-n", secBaoNS, "get", "configmap", secBackupRecord, "--ignore-not-found", "-o", "json")
+	if err != nil {
+		return err
+	}
+	if strings.TrimSpace(string(out)) == "" {
+		return fmt.Errorf("namespace %s holds no ConfigMap %s: no restore drill has run, nothing was measured", secBaoNS, secBackupRecord)
+	}
+	var cm struct {
+		Data map[string]string `json:"data"`
+	}
+	if err := json.Unmarshal(out, &cm); err != nil {
+		return fmt.Errorf("ConfigMap %s is not JSON: %v", secBackupRecord, err)
+	}
+	d := cm.Data
+	for k, name := range map[string]string{"snapshot": "snapshot", "snapshotTime": "snapshot_time", "written": "written", "read": "read",
+		"tokenTTLSeconds": "token_ttl_seconds", "tokenRenewable": "token_renewable", "finished": "finished", "error": "error"} {
+		ev[name] = d[k]
+	}
+	faults := []string{}
+	if d["error"] != "" {
+		faults = append(faults, "the drill failed: "+d["error"])
+	}
+	if t, err := time.Parse(time.RFC3339, d["snapshotTime"]); err != nil {
+		faults = append(faults, fmt.Sprintf("the drill record holds no snapshot time (%q)", d["snapshotTime"]))
+	} else if age := c.now().Sub(t); age > secBackupMaxAge {
+		ev["age_minutes"] = int(age.Minutes())
+		faults = append(faults, fmt.Sprintf("the restored snapshot %q is %s old, more than 7 hours", d["snapshot"], age.Round(time.Minute)))
+	}
+	if !secBackupDigest.MatchString(d["written"]) || d["read"] != d["written"] {
+		faults = append(faults, fmt.Sprintf("the canary read back from the restored snapshot is not the one written (written %q, read %q)", d["written"], d["read"]))
+	}
+	if ttl, err := strconv.Atoi(d["tokenTTLSeconds"]); err != nil || ttl <= 0 || ttl > secBackupMaxTTL {
+		faults = append(faults, fmt.Sprintf("the drill token lived %q seconds: not measured or more than 15 minutes", d["tokenTTLSeconds"]))
+	}
+	if d["tokenRenewable"] != "false" {
+		faults = append(faults, fmt.Sprintf("the drill token was renewable (%q)", d["tokenRenewable"]))
+	}
+	if len(faults) > 0 {
+		return errors.New(strings.Join(faults, "; "))
+	}
+	return nil
+}
