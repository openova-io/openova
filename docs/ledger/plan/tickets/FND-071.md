# FND-071 — Leftover lister: a read-only listing of what a wiped deployment left in the cloud account, failing closed

## In plain words

**The problem today.** After a wipe nobody can prove that the cloud account is empty before the next installation is fired. The wipe's own check of leftovers skips a listing that fails, so an account that could not be read looks clean. There is no tool that lists the account on its own, read-only, and refuses to say clean when it could not see everything.

**What changes.** A new lister in the provider adapter reads every kind of resource the platform creates and names what a wiped deployment left, with the number of each kind in the account. A provider-neutral program and a script run it on the deployment's variables document and answer clean, leftovers, usage error or not measured.

**Done means:**

- The script, given the variables document of a wiped deployment, lists the cloud account and exits 0 only when no resource of the deployment is left.
- A resource named with the deployment's name prefix, a free address that is down and not the bastion's, or a detached storage-driver volume is reported as a leftover, by kind, and the script exits 1.
- A listing that fails, answers an error, answers without its list or answers a list cut short makes the script exit 3 and print no report.
- The report gives for each kind the number of resources in the whole account, so the quota use can be written down.
- The lister only reads: it sends no request that creates, changes or deletes anything.
- The program and the script name no cloud provider; the provider-leak check stays green.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A person who has wiped a deployment runs `scripts/flight-sweep.sh <variables document>` with that deployment's `tofu.auto.tfvars.json` (a destroy keeps it). The script builds `products/catalyst/bootstrap/api/cmd/flight-sweep` and runs it. The program reads `provider`, `sovereign_fqdn` and `deployment_id` from the document, finds the provider in the registry and asks its leftover lister. The lister of the provider adapter lists ten kinds in the whole cloud account (servers, volumes, addresses, load balancers, NAT gateways, networks, security groups, key pairs, peerings, buckets), names the leftovers of the deployment and counts every resource of each kind. The program prints one JSON report and exits 0 when nothing was left, 1 when something was, 2 on a usage error and 3 when the account was not listed completely. It deletes nothing. A later package (FND-072) calls this script after every wipe; another (FND-075) writes its numbers into the gate record.

## 3. The model (the law)
1. `products/catalyst/bootstrap/api/internal/providers/provider.go` gains an optional interface `LeftoverLister` with one method `ListLeftovers(ctx context.Context, spec LeftoverSpec) (*LeftoverReport, error)`, and the types `LeftoverSpec` (`DeploymentID`, `SovereignFQDN`, `Creds ProviderCreds`), `LeftoverKind` (`kind`, `used`, `leftovers` in JSON) and `LeftoverReport` (`namePrefix`, `kinds`, and the method `LeftoverCount`). Nothing else in that file changes. It names no provider.
2. The lister lives in the provider adapter, in the new file `products/catalyst/bootstrap/api/internal/providers/huawei/leftovers.go`, because only the plug-in paths may name a provider (the provider-leak check). It reuses the adapter's own helpers `endpointFor`, `httpClientFor`, `doSignedRequest`, `snippet`, `defaultRegion`, `rawPublicIP` and `isProtectedBastionEIP`, and changes none of them.
3. The name prefix is the one of `infra/providers/huawei/main.tf`: `catalyst-` + the Sovereign FQDN with dots as dashes + `-` + the first 8 characters of the deployment id. A resource is the deployment's when its name is the prefix, or starts with the prefix and a dash.
4. The ten kinds, in this order, with the call that lists each: `servers` (compute `GET /v1/{project}/cloudservers/detail`, list `servers`), `volumes` (`GET /v2/{project}/cloudvolumes/detail`, `volumes`), `addresses` (`GET /v1/{project}/publicips`, `publicips`), `load_balancers` (`GET /v3/{project}/elb/loadbalancers`, `loadbalancers`), `nat_gateways` (`GET /v2/{project}/nat_gateways`, `nat_gateways`), `networks` (`GET /v1/{project}/vpcs`, `vpcs`), `security_groups` (`GET /v1/{project}/security-groups`, `security_groups`), `keypairs` (`GET /v2/{project}/os-keypairs`, `keypairs[].keypair.name`), `peerings` (`GET /v2.0/vpc/peerings`, `peerings`), `buckets` (object-storage list of all buckets). These are the calls the adapter's wipe already makes.
5. A leftover is: a resource of any kind named by rule 3 (an address by its bandwidth name); also an address whose status is `DOWN`, that has no port and that is not the bastion's (`isProtectedBastionEIP`); also a volume whose name starts with `pvc-`, whose status is `available` and that has no attachment. Servers and the other kinds count only by name. The label of an address is its IP address; of every other kind, its name.
6. `used` of a kind is the number of resources of that kind in the whole account, the deployment's or not, the bastion's included. `leftovers` is sorted and never null.
7. Fail closed. Each listing fails the whole call, with an error and no report, on: a transport error; a status other than 200 (a 404 too); an answer that is not a JSON object; an answer without its list key; a list that does not decode; a top-level `count` larger than the length of the list. A failed bucket listing fails the call too. Missing access key, secret key or project id, an empty FQDN, or a deployment id shorter than 8 characters fail the call.
8. Credentials come from `LeftoverSpec.Creds.Raw`: `huawei_access_key`, `huawei_secret_key`, `huawei_project_id` and `huawei_region` (the keys of the variables document), else `access_key`, `secret_key`, `project_id` and `region`. The region defaults to `defaultRegion`.
9. Read-only. The lister sends only GET requests and only lists buckets. It never deletes, and the bastion is never a target.
10. The program `products/catalyst/bootstrap/api/cmd/flight-sweep` takes exactly `-vars <file>`. It passes every top-level string of the document as a credential. Exit codes: 0 no leftover; 1 one or more leftovers; 2 usage error, unreadable file, not a JSON object, or one of `provider`, `sovereign_fqdn`, `deployment_id` empty or absent; 3 unknown provider, a provider without `LeftoverLister`, or a lister error. On 0 and 1 it prints the JSON object `{"provider", "namePrefix", "leftoverCount", "kinds"}` on standard output; on 2 and 3 it prints the reason on standard error and nothing on standard output. It names no provider.
11. The script `scripts/flight-sweep.sh` takes one argument: the document, or `--self-test`. It builds the program into a temporary folder, runs it and removes the folder. Its exit code is the program's for 0 to 3, and 3 for any other code or when the build fails. With no argument or two it prints the usage and exits 2. Its `--self-test` proves each rule with a case that would fail. It names no provider. It is executable.
12. Nothing is deleted by this ticket.

+func run(args []string, stdout, stderr io.Writer, get func(string) (providers.CloudProvider, error)) int {

+		_, _ = fmt.Fprintf(stderr, "flight-sweep: "+format+"\n", a...)

+		return fail(2, "%s is not a JSON object: %v", *vars, err)

+func listItems(client *http.Client, hw hwCreds, url, key string) ([]map[string]any, error) {
+	body, status, err := doSignedRequest(client, hw, http.MethodGet, url, nil)
+	if err != nil {
+		return nil, err
+	}
+	if status != http.StatusOK {
+		return nil, fmt.Errorf("status %d: %s", status, snippet(body, 240))
+	}
+	var top map[string]json.RawMessage
+	if err := json.Unmarshal(body, &top); err != nil {
+		return nil, fmt.Errorf("decode the answer: %w", err)
+	}
+	list, ok := top[key]
+	if !ok {
+		return nil, fmt.Errorf("the answer has no %q list", key)
+	}
+	var items []map[string]any
+	if err := json.Unmarshal(list, &items); err != nil {
+		return nil, fmt.Errorf("decode %q: %w", key, err)
+	}
+	var count int
+	if c, ok := top["count"]; ok && json.Unmarshal(c, &count) == nil && count > len(items) {
+		return nil, fmt.Errorf("the answer counts %d but lists %d", count, len(items))

+// ListLeftovers implements providers.LeftoverLister.
+func (p *Provider) ListLeftovers(ctx context.Context, spec providers.LeftoverSpec) (*providers.LeftoverReport, error) {
+	first := func(keys ...string) string {
+		for _, k := range keys {
+			if v := strings.TrimSpace(spec.Creds.Get(k)); v != "" {
+				return v
+			}
+		}
+		return ""
+	}
+	hw := hwCreds{AccessKey: first("huawei_access_key", "access_key"), SecretKey: first("huawei_secret_key", "secret_key"),
+		ProjectID: first("huawei_project_id", "project_id")}
+	if hw.AccessKey == "" || hw.SecretKey == "" || hw.ProjectID == "" {
+		return nil, errors.New("huawei leftovers: the access key, the secret key and the project id are required")
+	}
+	region := first("huawei_region", "region")
+	if region == "" {
+		region = defaultRegion
+	}
+	fqdn, dep := strings.TrimSpace(spec.SovereignFQDN), strings.TrimSpace(spec.DeploymentID)
+	if fqdn == "" || len(dep) < 8 {
+		return nil, errors.New("huawei leftovers: the Sovereign FQDN and a deployment id of at least 8 characters are required")
+	}
+	prefix := "catalyst-" + strings.ReplaceAll(fqdn, ".", "-") + "-" + dep[:8]
+	own := func(name string) bool { return name == prefix || strings.HasPrefix(name, prefix+"-") }
+	report := &providers.LeftoverReport{NamePrefix: prefix}
+	collect := func(l leftoverListing, items []map[string]any) {
+		labels := []string{}
+		for _, it := range items {
+			if label, left := l.pick(it, own); left {
+				labels = append(labels, label)
+			}
+		}
+		sort.Strings(labels)
+		report.Kinds = append(report.Kinds, providers.LeftoverKind{Kind: l.kind, Used: len(items), Leftovers: labels})
+	}
+	client := httpClientFor(spec.Creds)
+	for _, l := range leftoverListings {
+		items, err := listItems(client, hw, endpointFor(l.service, region)+strings.ReplaceAll(l.path, "{p}", hw.ProjectID), l.key)
+		if err != nil {
+			return nil, fmt.Errorf("huawei leftovers: list %s: %w", l.kind, err)
+		}
+		collect(l, items)
+	}
+	items, err := listBuckets(ctx, client.Transport, hw, region)
+	if err != nil {
+		return nil, fmt.Errorf("huawei leftovers: list buckets: %w", err)
+	}
+	collect(leftoverListing{kind: "buckets", pick: leftoverByName}, items)
+	return report, nil

+// LeftoverLister is an OPTIONAL extension: a provider that can list what a
+// wiped deployment left in its cloud account. It only reads; it never

+	ListLeftovers(ctx context.Context, spec LeftoverSpec) (*LeftoverReport, error)

+// LeftoverSpec names the wiped deployment. Creds is the credential bag of

+type LeftoverSpec struct {

+// LeftoverKind is the result for one kind of resource. Used counts every
+// resource of the kind in the account; Leftovers names, sorted, those the

+type LeftoverKind struct {

+	Used      int      `json:"used"`
+	Leftovers []string `json:"leftovers"`

+# flight-sweep.sh - list what a wiped deployment left in its cloud account. It
+# only reads. Usage: scripts/flight-sweep.sh <variables document> | --self-test
+# The document is the wiped deployment's tofu.auto.tfvars.json (a destroy keeps
+# it). The script builds products/catalyst/bootstrap/api/cmd/flight-sweep and
+# runs it on the document; the JSON report goes to standard output.
+# Exit codes: 0 nothing was left; 1 leftovers were found; 2 usage error, or the
+# document cannot be read or lacks a key; 3 not measured (the program does not
+# build, the provider has no lister, a listing failed, any other exit code).
+set -uo pipefail
+
+api="$(cd "$(dirname "$0")/.." && pwd)/products/catalyst/bootstrap/api"
+
+code_of() { case "$1" in 0|1|2|3) echo "$1" ;; *) echo 3 ;; esac; }
+
+sweep() { # sweep <variables document>
+  local bin rc
+  bin="$(mktemp -d)" || return 3
+  if ! (cd "$api" && go build -o "$bin/flight-sweep" ./cmd/flight-sweep) >&2; then
+    echo "flight-sweep: not measured: the program does not build" >&2
+    rm -rf "$bin"; return 3
+  fi
+  "$bin/flight-sweep" -vars "$1"; rc=$?
+  rm -rf "$bin"
+  return "$(code_of "$rc")"
+}

+self_test() {
+  local dir failed=0 got
