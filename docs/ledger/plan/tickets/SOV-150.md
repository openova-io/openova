# SOV-150 — Kit sources become substitutions, with a render-equivalence test

## In plain words

**The problem today.** Later work will turn the registry addresses and Secret names that the kit writes as fixed text into values that each Sovereign supplies. Nothing can show today that such a change leaves what Flux applies exactly as it was. Nothing shows it either for a Sovereign that does not carry the new values yet.

**What changes.** A script renders the kit the way Flux fills in its values, with a stored set of values, and compares a change with its base object by object. A check runs the script's own test and renders the whole kit on every change to the kit.

**Done means:**

- A change that only replaces a fixed text of the kit by a value with the same content renders the same, and the comparison passes.
- A change that alters any rendered object fails the comparison, and the output names the file and the object.
- The comparison is made with all the stored values and again with only the values that every Sovereign carries today, so a value that older Sovereigns cannot fill is found.
- The stored values hold every key of the variables contract and every key of the kit list, with registry values that reproduce today's chart sources.
- The script shows on a small repository of its own that each of its rules can fail.
- Every pull request that changes the kit, its values or the script runs that test and renders every part of the kit.
- No file of the kit changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. The script, the value file and the workflow are the three blocks of field 5, byte for byte. This ticket adds these three files and changes no other file.
2. **Roots.** A root is a folder under `clusters/_template` that the boot template `infra/providers/_shared/cloudinit-control-plane.tftpl` gives to a Flux Kustomization, in a line `path: ./clusters/_template/<root>`. The script reads those lines and expands every branch of their template conditions (`%{ if ... }`, `%{ else }`, `%{ endif }`). At the commit of field 4 there are five such lines and nine roots: `bootstrap-kit`, `bootstrap-kit-crs`, `infrastructure/providers`, `infrastructure/providers/hetzner`, `sovereign-region/base`, `sovereign-region/multi-region`, `sovereign-region/multi-region-follower`, `sovereign-tls`, `sovereign-tls-hetzner`. Each of them reads the ConfigMap `flux-system/sovereign-variables` through `postBuild.substituteFrom`. The script names no root and no cloud itself.
3. **Files of a root.** The script walks the root's `kustomization.yaml`: every listed file, every listed folder (through its own `kustomization.yaml`), every patch file, and each `kustomization.yaml` itself, so the text of an inline patch is compared too. A `kustomization.yaml` may hold only the fields `apiVersion`, `kind`, `resources` and `patches`. Any other field, a listed path that does not exist, and a path outside `clusters/_template` cannot be judged.
4. **Substitution, the model of Flux.** Per YAML document: a document whose annotation or label `kustomize.toolkit.fluxcd.io/substitute` is `disabled` is taken as it is. Every other document is parsed, written again as YAML with sorted keys, substituted, and parsed again, so comments take no part and a quote of the source is not kept. The forms are `${NAME}`, `${NAME:-default}` and `${NAME:=default}` (the value when it is set and not empty, else the default), `${NAME-default}` and `${NAME=default}` (the value when it is set, else the default). A default may hold a further `${...}`. An unset name gives the empty text. `$$` gives `$`. `$NAME` without braces is left as it is. Any other form cannot be judged.
5. **Rendered root.** The list of the root's documents as canonical JSON (sorted keys), each with its file. Its hash is the SHA-256 of that list. Two trees render a root the same when the hashes are equal.
6. **Values.** `tests/fixtures/variables/today.env` has one line `KEY=VALUE` per key; a blank line and a line starting with `#` are skipped; the value is the rest of the line as it is. It holds, in this order, the 39 contract keys of `docs/contracts/c5-upstream-variables.schema.json` (in the order of its `properties`) and the 75 kit keys of `docs/contracts/c5-kit-keys.txt` (in the order of that file), nothing else. The registry keys hold the values that reproduce the chart sources the kit names today: `REGISTRY_HOST=ghcr.io`, `ORIGIN_REGISTRY_HOST=ghcr.io`, `REGISTRY_SCHEME=https`, `REGISTRY_PATH_CHARTS=openova-io`, `REGISTRY_PULL_SECRET=ghcr-pull`, `REGISTRY_PATH_XPKG=proxy-xpkg`. The other contract keys hold the example values of the contract. The kit keys hold test values under the name `render-test.example.test`.
7. **Two value sets.** `full` is every line of the file. `kit` is only the keys that `docs/contracts/c5-kit-keys.txt` lists. A Sovereign carries the kit keys and no contract key until a later package puts the contract keys into its variables, so a change must render the same with `kit` too, or older Sovereigns would render it differently.
8. **Commands and exit codes.** Without arguments, or with `--base <git-ref>`: compare the working tree with that commit (default: `git merge-base HEAD origin/main`). It prints one line per value set and root, `<set> <root> same <hash>` or `<set> <root> DIFFERENT base=<hash> head=<hash>` followed by up to ten lines that name the file, kind, namespace and name of each differing document, then one verdict line. `--print [--kit <dir>]` prints `<set> <root> <hash> <documents>` for every root of the kit in `<dir>` (default the checkout's `clusters/_template`). `--self-test` builds a small Git repository of its own 32 times and shows that each rule holds and can fail; it reads nothing of the checkout. Exit code 0: every root renders the same with both sets (with `--print`: every root rendered). Exit code 1: a root renders differently. Exit code 2: something cannot be judged, and the line `check-kit-render-equivalence: cannot judge: <reason>` says what.
9. **The workflow** `.github/workflows/check-kit-render-equivalence.yaml` runs on a pull request and on a push to `main` that change `clusters/_template/**`, the boot template, `docs/contracts/c5-kit-keys.txt`, the value file, the script or the workflow itself, and on request. Its one job, `kit render equivalence`, installs PyYAML, runs the self-test, then `--print`. It does not compare with the merge base: a change that is meant to change what Flux applies, such as a chart version, renders differently by design. The comparison belongs to the acceptance commands of the packages that claim to change nothing.
10. Nothing of the kit, the boot template, the contract files or any guard baseline changes. The count of fixed source addresses in the kit stays as it is.

            if kind in stop:
                return outs, i
            if kind == "text":
                outs = [o + value for o in outs]
                i += 1
            elif kind == "if":
                then, i = seq(i + 1, ("else", "endif"))
                other = [""]
                if tokens[i][0] == "else":
                    other, i = seq(i + 1, ("endif",))
                if i >= len(tokens) or tokens[i][0] != "endif":
                    raise CannotJudge("a template condition has no endif: %s" % text)
                i += 1
                outs = [o + b for o in outs for b in then + other]
            else:
                raise CannotJudge("a template condition is not balanced: %s" % text)
        if stop:
            raise CannotJudge("a template condition is not closed: %s" % text)
        return outs, i

    outs, _ = seq(0, ())
    return outs


def roots_of(template_path):
    try:
        lines = open(template_path, encoding="utf-8").read().split("\n")
    except OSError as e:
        raise CannotJudge("%s cannot be read: %s" % (template_path, e))
    found = []
    for line in lines:
        m = PATH_LINE.match(line)
        if m:
            for r in expand(m.group(1)):
                r = r.strip("/")
                if not ROOT_NAME.fullmatch(r) or ".." in r.split("/"):
                    raise CannotJudge("%s names the path %r, which is not a folder name" % (template_path, r))
                if r not in found:
                    found.append(r)
    if not found:
        raise CannotJudge("%s names no path ./clusters/_template/<root>" % template_path)
    return sorted(found)


# ---- values

def read_values(path, keys_path):
    try:
        text = open(path, encoding="utf-8").read()
    except OSError as e:
        raise CannotJudge("%s cannot be read: %s" % (path, e))
    full = {}
    for n, line in enumerate(text.split("\n"), 1):
        if not line.strip() or line.startswith("#"):
            continue
        key, eq, value = line.partition("=")
        if not eq or not NAME.fullmatch(key):
            raise CannotJudge("%s line %d is not KEY=VALUE" % (path, n))
        if key in full:
            raise CannotJudge("%s names %s twice" % (path, key))
        full[key] = value
    try:
        kit_keys = {k.strip() for k in open(keys_path, encoding="utf-8") if k.strip()}
    except OSError as e:
        raise CannotJudge("%s cannot be read: %s" % (keys_path, e))
    return [("full", full), ("kit", {k: v for k, v in full.items() if k in kit_keys})]


# ---- substitution

def closing(text, i):
    """Index of the } that closes the ${ whose content starts at i; nested ${...} are skipped."""
    depth = 0
    while i < len(text):
        if text.startswith("$$", i):
            i += 2
            continue
        if text.startswith("${", i):
            depth += 1
            i += 2
            continue
        if text[i] == "}":
            if depth == 0:
                return i
            depth -= 1
        i += 1
    raise CannotJudge("a ${ is not closed")


def evaluate(expr, values):
    m = NAME.match(expr)
    if not m:
        raise CannotJudge("unsupported substitution ${%s}" % expr)
    name, rest = m.group(0), expr[m.end():]
    if rest == "":
        return values.get(name, "")
    for op in (":-", ":=", "-", "="):
        if rest.startswith(op):
            default = rest[len(op):]
            value = values.get(name)
            if op in (":-", ":="):
                use = value is not None and value != ""
            else:
                use = value is not None
            return value if use else substitute(default, values)
    raise CannotJudge("unsupported substitution ${%s}" % expr)


def substitute(text, values):
    out = []
    i = 0
    while i < len(text):
        if text.startswith("$$", i):
            out.append("$")
            i += 2
        elif text.startswith("${", i):
            end = closing(text, i + 2)
            out.append(evaluate(text[i + 2:end], values))
            i = end + 1
        else:
            out.append(text[i])
            i += 1
    return "".join(out)


# ---- documents

def dumper():
    yaml = yaml_module()

    class Emitter(yaml.emitter.Emitter):
        def choose_scalar_style(self):
            style = super().choose_scalar_style()
            return '"' if style == "'" else style

    class Dumper(Emitter, yaml.serializer.Serializer, yaml.representer.SafeRepresenter, yaml.resolver.Resolver):
        def __init__(self, stream, **kw):
            Emitter.__init__(self, stream, width=kw.get("width"), allow_unicode=kw.get("allow_unicode"))
            yaml.serializer.Serializer.__init__(self)
            yaml.representer.SafeRepresenter.__init__(self, sort_keys=True)
            yaml.resolver.Resolver.__init__(self)

    def text(rep, data):
        return rep.represent_scalar("tag:yaml.org,2002:str", data, style="|" if "\n" in data else None)

    Dumper.add_representer(str, text)
    return Dumper


def disabled(doc):
    meta = doc.get("metadata") if isinstance(doc, dict) else None
    if not isinstance(meta, dict):
        return False
    for part in ("annotations", "labels"):
        marks = meta.get(part)
        if isinstance(marks, dict) and marks.get(DISABLED) == "disabled":
            return True
    return False


class Kit:
    """One kit folder. Each file is read and written again once; each value set only substitutes and parses."""

    def __init__(self, kit):
        if not os.path.isdir(kit):
            raise CannotJudge("%s is not a directory" % kit)
        self.kit = kit
        self.dump_with = dumper()
        self.texts = {}

    def documents(self, rel):
        if rel not in self.texts:
            yaml = yaml_module()
            load = getattr(yaml, "CSafeLoader", yaml.SafeLoader)
            try:
                docs = [d for d in yaml.load_all(open(os.path.join(self.kit, rel), encoding="utf-8"), Loader=load) if d is not None]
            except (OSError, yaml.YAMLError) as e:
                raise CannotJudge("%s cannot be read as YAML: %s" % (rel, str(e).split("\n")[0]))
            self.texts[rel] = [(True, canonical(d)) if disabled(d) else
                               (False, yaml.dump(d, Dumper=self.dump_with, width=1 << 30, allow_unicode=True, default_flow_style=False))
                               for d in docs]
        return self.texts[rel]

    def render(self, rel, values):
        yaml = yaml_module()
        load = getattr(yaml, "CSafeLoader", yaml.SafeLoader)
        out = []
        for fixed, text in self.documents(rel):
            if fixed:
                out.append(text)
                continue
            try:
                out.append(canonical(yaml.load(substitute(text, values), Loader=load)))
            except yaml.YAMLError as e:
                raise CannotJudge("%s is not YAML after substitution: %s" % (rel, str(e).split("\n")[0]))
            except CannotJudge as e:
                raise CannotJudge("%s: %s" % (rel, e))
        return out

    def root(self, root, values):
        rows = []
        for rel in files_of(self.kit, root):
            for n, doc in enumerate(self.render(rel, values)):
                rows.append("%s\t%d\t%s" % (rel, n, doc))
        return hashlib.sha256(("\n".join(rows) + "\n").encode("utf-8")).hexdigest(), rows


def canonical(doc):
    return json.dumps(doc, sort_keys=True, separators=(",", ":"), default=str)


def files_of(kit, root):
    """The files of one root in the order the kustomization.yaml files list them, as paths under the kit."""
    yaml = yaml_module()
    files = []

    def inside(rel):
        rel = os.path.normpath(rel)
        if rel == ".." or rel.startswith("../") or os.path.isabs(rel):
            raise CannotJudge("%s is outside %s" % (rel, KIT))
        return rel

    def walk(d, seen):
        if d in seen:
            raise CannotJudge("%s is listed twice in root %s" % (d, root))
        seen.add(d)
        k_rel = os.path.join(d, "kustomization.yaml")
        k_path = os.path.join(kit, k_rel)
        if not os.path.isfile(k_path):
            raise CannotJudge("%s/%s does not exist" % (KIT, k_rel))
        try:
            k = yaml.safe_load(open(k_path, encoding="utf-8")) or {}
        except yaml.YAMLError as e:
            raise CannotJudge("%s/%s cannot be read: %s" % (KIT, k_rel, str(e).split("\n")[0]))
        if not isinstance(k, dict):
            raise CannotJudge("%s/%s is not a mapping" % (KIT, k_rel))
        extra = sorted(set(k) - KUSTOMIZATION_FIELDS)
        if extra:
            raise CannotJudge("%s/%s uses %s, which this model does not render" % (KIT, k_rel, ", ".join(extra)))
        files.append(k_rel)
        for r in k.get("resources") or []:
            if not isinstance(r, str) or "://" in r:
                raise CannotJudge("%s/%s lists %r, which is not a local path" % (KIT, k_rel, r))
            p = inside(os.path.join(d, r))
            if os.path.isdir(os.path.join(kit, p)):
                walk(p, seen)
            elif os.path.isfile(os.path.join(kit, p)):
                files.append(p)
            else:
                raise CannotJudge("%s/%s lists %s, which does not exist" % (KIT, k_rel, r))
        for patch in k.get("patches") or []:
            if isinstance(patch, dict) and "path" in patch:
                p = inside(os.path.join(d, patch["path"]))
                if not os.path.isfile(os.path.join(kit, p)):
                    raise CannotJudge("%s/%s names patch %s, which does not exist" % (KIT, k_rel, patch["path"]))
                files.append(p)

    walk(os.path.normpath(root), set())
    return files


def render_kit(kit, roots, value_sets):
    k = Kit(kit)
    return {(name, root): k.root(root, values) for name, values in value_sets for root in roots}


# ---- git

def git(repo, *args):
    r = subprocess.run(["git", "-C", repo] + list(args), stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    if r.returncode != 0:
        raise CannotJudge("git %s failed: %s" % (" ".join(args), r.stderr.decode("utf-8", "replace").strip()))
    return r.stdout


def kit_at(repo, ref, into):
    sha = git(repo, "rev-parse", "--verify", "--quiet", ref + "^{commit}").decode().strip()
    data = git(repo, "archive", "--format=tar", sha, KIT)
    with tarfile.open(fileobj=io.BytesIO(data)) as t:
        for m in t.getmembers():
            if not (m.isdir() or m.isfile()) or m.name.startswith("/") or ".." in m.name.split("/"):
                raise CannotJudge("%s holds %s, which this model does not read" % (ref, m.name))
        try:
            t.extractall(into, filter="data")
        except TypeError:  # a Python without extraction filters; every member was checked above
            t.extractall(into)
    return sha, os.path.join(into, KIT)


def describe(rows):
    """One label per document of a rendered root: its file, kind, namespace and name."""
    out = {}
    for row in rows:
        rel, n, doc = row.split("\t", 2)
        obj = json.loads(doc)
        meta = obj.get("metadata") if isinstance(obj, dict) else None
        meta = meta if isinstance(meta, dict) else {}
        kind = obj.get("kind", "?") if isinstance(obj, dict) else "?"
        out.setdefault("%s %s %s/%s" % (rel, kind, meta.get("namespace", "-"), meta.get("name", "#" + n)), []).append(doc)
    return out


# ---- commands

def compare(repo, ref):
    roots = roots_of(os.path.join(repo, TEMPLATE))
    value_sets = read_values(os.path.join(repo, FIXTURE), os.path.join(repo, KIT_KEYS))
    with tempfile.TemporaryDirectory() as tmp:
        sha, base_kit = kit_at(repo, ref, tmp)
        base = render_kit(base_kit, roots, value_sets)
        head = render_kit(os.path.join(repo, KIT), roots, value_sets)
    different = 0
    for name, _ in value_sets:
        for root in roots:
            b, h = base[(name, root)], head[(name, root)]
            if b[0] == h[0]:
                print("%-4s %s same %s" % (name, root, h[0]))
                continue
            different += 1
            print("%-4s %s DIFFERENT base=%s head=%s" % (name, root, b[0], h[0]))
            db, dh = describe(b[1]), describe(h[1])
            shown = 0
            for label in sorted(set(db) | set(dh)):
                if db.get(label) != dh.get(label):
                    where = "only at the base" if label not in dh else "only in the working tree" if label not in db else "differs"
                    if shown < 10:
                        print("     %s: %s" % (where, label))
                    shown += 1
            if shown > 10:
                print("     ... and %d more" % (shown - 10))
    if different:
        print("%s: %d rendered roots differ from %s; a change that only moves values into substitutions renders the same" % (ME, different, sha[:12]))
        return 1
    print("%s: every root renders the same at %s and in the working tree, with both value sets" % (ME, sha[:12]))
    return 0


def print_kit(repo, kit):
    roots = roots_of(os.path.join(repo, TEMPLATE))
    value_sets = read_values(os.path.join(repo, FIXTURE), os.path.join(repo, KIT_KEYS))
    rendered = render_kit(kit, roots, value_sets)
    for name, _ in value_sets:
        for root in roots:
            digest, rows = rendered[(name, root)]
            print("%-4s %s %s %d" % (name, root, digest, len(rows)))
    return 0
