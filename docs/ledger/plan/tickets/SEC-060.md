# SEC-060 — Keycloak secrets no longer computable

## In plain words

**The problem today.** The client secrets of the platform's sign-in realm are hashes of fixed text: the name of the Keycloak release, its namespace and a word per client. Every Sovereign installed from the same release has the same secrets, and anyone who reads the public chart can compute them. With a client secret an attacker can act as that application towards the sign-in service.

**What changes.** First boot writes one random salt per Sovereign, and both charts that derive the secrets append it to every seed, so no secret can be computed and two Sovereigns share none. A new required gate check reads the realm of every region and fails when a secret is still one of the computable values.

**Done means:**

- On a fresh Sovereign no client secret of the sign-in realm, of an Organization realm or of the PIN broker equals the hash of the release name, the namespace and the fixed word.
- The Keycloak chart and the platform chart derive the same service-account and PIN broker secrets from the same salt, so the platform API still signs in to Keycloak.
- An install of either chart that requires the salt and has none fails with a message that names the missing value.
- A Sovereign installed before this change has no salt in its seed and keeps the secrets Keycloak already holds; its releases keep reconciling.
- The salt reaches the charts only through a Secret object, never through Helm values or a Flux substitute.
- Gate check SEC-G06 is required and fails a region whose realm holds a computable secret, or where nothing was measured.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
No Keycloak client secret of a Sovereign can be computed from public text. bp-keycloak (bootstrap-kit slot 09) derives every client secret as the SHA-256 of a seed; its five derivations (Tier-1 and Tier-2 clients, the catalyst-api-server service account, the catalyst-pin broker, the per-Organization broker) and the Keycloak credentials host bridge of bp-catalyst-platform (slot 13) append one random salt of the Sovereign to that seed. The provider modules make the salt (`random_password`, 48 characters, one per Sovereign), first boot writes it as key `KEYCLOAK_CLIENT_SECRET_SALT` of the seed Secret `flux-system/bootstrap-seed`, and both slots read it with an optional `valuesFrom` into `sso.tier1ClientSecretSalt`. With `sso.requireSalt: true`, which both slots set, an install without a salt fails; an upgrade of a release installed before the salt existed renders as before. Gate check SEC-G06 (`check_sec_differ.go`) is `required` and reads the realm imports of every region.

+#!/usr/bin/env bash
+# SEC-060 — no Keycloak client secret of a Sovereign can be computed from its
+# release name and namespace.
+#
+# Every client secret this chart derives (the eight realm clients, the
+# catalyst-pin broker and each per-Org sovereign-broker) is the SHA-256 of a
+# seed made of the release name, the namespace and a fixed word. Since SEC-060
+# the seed also carries sso.tier1ClientSecretSalt, a random salt per Sovereign
+# that bootstrap-kit slot 09 reads from the seed Secret of first boot. The
+# Keycloak credentials host bridge of bp-catalyst-platform derives the
+# catalyst-api-server and catalyst-pin secrets again, from the same salt.
+#
+# Asserts:
+#   1. two salts give ten different secrets each: the eight clients, the pin
+#      broker and one per-Org broker, in the realm JSON and in the Secrets;
+#   2. one salt renders the same ten secrets every time;
+#   3. an install with sso.requireSalt=true and no salt fails, naming SEC-060;
+#   4. an upgrade with sso.requireSalt=true and no salt (a Sovereign installed
+#      before the salt existed) renders the secrets it had before: the pin
+#      broker is still SHA-256 of "<release>|<namespace>|catalyst-pin-broker";
+#   5. the host bridge of bp-catalyst-platform, given the same salt, renders
+#      the catalyst-api-server and catalyst-pin secrets byte-equal to this
+#      chart's, with a salt and without one.
+#
+# Runs with helm, yq (v4.44.3 in CI) and jq; plain selections, no slices.
+set -euo pipefail
+
+CHART_DIR="$(cd "$(dirname "$0")/.." && pwd)"
+REPO_ROOT="$(cd "$CHART_DIR/../../.." && pwd)"
+PLATFORM_CHART="$REPO_ROOT/products/catalyst/chart"
+TMP="$(mktemp -d)"
+trap 'rm -rf "$TMP"' EXIT
+
+REALM_CM="keycloak-sovereign-realm-config"
+ORG_CM="keycloak-org-realm-acme-config"
+CLIENTS="catalyst-api-server grafana gitea harbor openbao guacamole powerdns-admin hubble-ui"
+
+fail() { echo "FAIL: $*" >&2; exit 1; }
+
+# render OUT [helm flags...]: the chart as slot 09 installs it (release
+# keycloak in namespace keycloak), with one per-Org realm. The bundled
+# PostgreSQL is off: its subchart refuses an upgrade render without its
+# passwords, and no secret of this test comes from it.
+render() {
+  local out="$1"
+  shift
+  helm template keycloak "$CHART_DIR" --namespace keycloak \
+    --set sovereignFQDN=hw00.omani.works \
+    --set "tenantRealms[0].slug=acme" \
+    --set keycloak.postgresql.enabled=false --set keycloak.externalDatabase.host=pg.test --set keycloak.externalDatabase.existingSecret=keycloak-database-secret \
+    --set sso.requireSalt=true "$@" >"$out" 2>"$out.err"
+}
+
+# secrets RENDER: one line "<name> <secret>" for each of the ten secrets, and
+# the two Secrets that carry a realm value.
+secrets() {
+  local r="$1" realm org
+  realm=$(yq -r "select(.kind == \"ConfigMap\" and .metadata.name == \"$REALM_CM\") | .data[\"sovereign-realm.json\"]" "$r")
+  org=$(yq -r "select(.kind == \"ConfigMap\" and .metadata.name == \"$ORG_CM\") | .data[\"org-realm.json\"]" "$r")
+  for c in $CLIENTS; do
+    printf '%s %s\n' "client/$c" "$(printf '%s' "$realm" | jq -r --arg c "$c" '.clients[] | select(.clientId == $c) | .secret')"
+  done
+  printf '%s %s\n' "idp/catalyst-pin" "$(printf '%s' "$realm" | jq -r '.identityProviders[] | select(.alias == "catalyst-pin") | .config.clientSecret')"
+  printf '%s %s\n' "org/acme/sovereign-broker" "$(printf '%s' "$org" | jq -r '.identityProviders[] | select(.alias == "sovereign-broker") | .config.clientSecret')"
+  printf '%s %s\n' "secret/catalyst-kc-sa-credentials" "$(yq -r 'select(.kind == "Secret" and .metadata.name == "catalyst-kc-sa-credentials") | .stringData["client-secret"]' "$r")"
+  printf '%s %s\n' "secret/catalyst-pin-broker-credentials" "$(yq -r 'select(.kind == "Secret" and .metadata.name == "catalyst-pin-broker-credentials") | .stringData["client-secret"]' "$r")"
+}
+
+sha() { printf '%s' "$1" | sha256sum | cut -d' ' -f1; }
+
+value() { awk -v k="$2" '$1 == k { print $2 }' "$1"; }
+
+echo "=== SEC-060 client-secret salt (bp-keycloak) ==="
+
+SALT_A="sec060-salt-a-0123456789abcdefghijklmnopqrstuvwxyzABCD"
+SALT_B="sec060-salt-b-0123456789abcdefghijklmnopqrstuvwxyzABCD"
+render "$TMP/a.yaml" --set "sso.tier1ClientSecretSalt=$SALT_A" || fail "the render with salt A failed: $(cat "$TMP/a.yaml.err")"
+render "$TMP/a2.yaml" --set "sso.tier1ClientSecretSalt=$SALT_A" || fail "the second render with salt A failed"
+render "$TMP/b.yaml" --set "sso.tier1ClientSecretSalt=$SALT_B" || fail "the render with salt B failed"
+secrets "$TMP/a.yaml" >"$TMP/a.txt"
+secrets "$TMP/a2.yaml" >"$TMP/a2.txt"
+secrets "$TMP/b.yaml" >"$TMP/b.txt"

+func (c secDifferCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
+	if len(cc.Regions) == 0 {
+		return errors.New("the run has no region")
+	}
+	n := 0
+	measured := 0
+	for _, region := range cc.Regions {
+		imp, err := c.read(ctx, region)
+		if err == nil && len(imp.maps) == 0 {
+			continue
+		}
+		measured++
+		n++
+		checkStep(rec, secDifferID, n, "no Keycloak client secret of region "+region.ID+" is derived from constants", func(ev Evidence) error {
+			if err != nil {
+				return err
+			}
+			return judgeRealmSecrets(imp, ev)
+		})
+	}
+	if measured == 0 {
+		checkStep(rec, secDifferID, 1, "a region holds the realm imports of bp-keycloak", func(ev Evidence) error {
+			ev["regions"] = len(cc.Regions)
+			return fmt.Errorf("no region has a realm import in namespace %s: nothing was measured", secDifferNS)
+		})
+	}
+	return nil

+// read lists the ConfigMaps of namespace keycloak in region and collects their realm imports.
+func (c secDifferCheck) read(ctx context.Context, region kube.Region) (realmImports, error) {
+	out, err := c.kubectl(region, ctx, nil, "get", "configmaps", "-n", secDifferNS, "-o", "json")
+	if err != nil {
+		return realmImports{}, fmt.Errorf("listing the ConfigMaps of namespace %s: %v", secDifferNS, err)
+	}
+	var l struct {
+		Items []kube.Object `json:"items"`
+	}
+	if err := json.Unmarshal(out, &l); err != nil {
+		return realmImports{}, fmt.Errorf("the ConfigMaps of namespace %s are not JSON: %v", secDifferNS, err)
+	}
+	return collectRealmImports(l.Items), nil
+}

+// collectRealmImports reads every data value of items that is a JSON realm.
+func collectRealmImports(items []kube.Object) realmImports {
+	var imp realmImports
+	ids, orgs := map[string]bool{}, map[string]bool{}
+	for _, cm := range items {
+		name := cm.Name()
+		if strings.HasSuffix(name, secDifferSuffix) {
+			imp.release = strings.TrimSuffix(name, secDifferSuffix)
+		}
+		data, _ := cm.Get("data").(map[string]any)
+		keys := make([]string, 0, len(data))
+		for k := range data {
+			keys = append(keys, k)
+		}
+		sort.Strings(keys)
+		held := false
+		for _, k := range keys {
+			text, _ := data[k].(string)
+			var realm kube.Object
+			if json.Unmarshal([]byte(text), &realm) != nil || realm.Str("realm") == "" {
+				continue
+			}
+			held = true
+			at := name + "/" + realm.Str("realm")
+			for _, cl := range realm.Objects("clients") {
+				id := cl.Str("clientId")
+				ids[id] = true
+				if s := cl.Str("secret"); s != "" {
+					imp.secrets = append(imp.secrets, realmSecret{at + "/client:" + id, s})
+				}
+			}
+			for _, idp := range realm.Objects("identityProviders") {
+				alias := idp.Str("alias")
+				ids[alias], ids[idp.Str("config", "clientId")] = true, true
+				if s := idp.Str("config", "clientSecret"); s != "" {
+					imp.secrets = append(imp.secrets, realmSecret{at + "/idp:" + alias, s})
+				}
+			}
+		}
+		if held {
+			imp.maps = append(imp.maps, name)
+			if slug := cm.Str("metadata", "labels", secDifferOrgSlug); slug != "" {
+				orgs[slug] = true
+			}
+		}
+	}
+	imp.ids, imp.orgs = sortedSet(ids), sortedSet(orgs)
+	return imp
+}

+func sortedSet(m map[string]bool) []string {
+	out := []string{}
+	for k := range m {
+		if k != "" {
+			out = append(out, k)
+		}
+	}
+	sort.Strings(out)
+	return out
+}

+func sha256Hex(s string) string {
+	h := sha256.Sum256([]byte(s))
+	return hex.EncodeToString(h[:])
+}
+
+// unsaltedSeeds maps the SHA-256 of every seed without a salt to the seed.
+func unsaltedSeeds(release string, ids, orgs []string) map[string]string {
+	base := release + "|" + secDifferNS + "|"
+	seeds := []string{base + "catalyst-api-server-sa", base + "catalyst-pin-broker"}
+	for _, id := range ids {
+		seeds = append(seeds, base+"tier1-sso|"+id, base+"tier2-sso|"+id)
+	}
+	for _, o := range orgs {
+		seeds = append(seeds, base+"tenant-broker|"+o)
+	}
+	out := map[string]string{}
+	for _, s := range seeds {
+		out[sha256Hex(s)] = s
+	}
+	return out
+}
+
+// judgeRealmSecrets passes when the imports hold a secret and none is a seed without the salt.
+func judgeRealmSecrets(imp realmImports, ev Evidence) error {
+	ev["realm_imports"] = imp.maps
+	if imp.release == "" {
+		return fmt.Errorf("no ConfigMap <release>%s in namespace %s: the release name is unknown", secDifferSuffix, secDifferNS)
+	}
+	ev["release"] = imp.release
+	if len(imp.secrets) == 0 {
+		return fmt.Errorf("the realm imports %s hold no client secret", strings.Join(imp.maps, ", "))
+	}
+	known := unsaltedSeeds(imp.release, imp.ids, imp.orgs)
+	hashes := map[string]string{}
+	derived, placeholders := []string{}, 0
+	for _, s := range imp.secrets {
+		if strings.HasPrefix(s.value, "$(") || strings.HasPrefix(s.value, "${") {
+			placeholders++
+			continue
+		}
+		hashes[s.where] = sha256Hex(s.value)[:secDifferPrefix]
+		if seed, ok := known[s.value]; ok {
+			derived = append(derived, s.where+" is the SHA-256 of "+seed)
+		}
+	}
+	ev["secrets"], ev["placeholders"], ev["secret_sha256_prefix"] = len(imp.secrets), placeholders, hashes
+	if len(hashes) == 0 {
+		return fmt.Errorf("every client secret of the realm imports is a placeholder (%d): nothing was measured", placeholders)
+	}
+	if len(derived) > 0 {
+		sort.Strings(derived)
+		return errors.New("client secrets are derived from constants, without the salt of the Sovereign: " + strings.Join(derived, "; "))
+	}
+	return nil
+}

+// differConfigMaps reads the ConfigMaps of a helm render: for each document,
+// its name, its labels and each data value written as a literal block.
+func differConfigMaps(t *testing.T, render string) []kube.Object {
+	t.Helper()
+	out := []kube.Object{}
+	for _, doc := range strings.Split(render, "\n---\n") {
+		lines := strings.Split(doc, "\n")
+		meta, labels, data := obj{}, obj{}, obj{}
+		section, key, block := "", "", []string{}
+		flush := func() {
+			if key != "" {
+				data[key] = strings.Join(block, "\n")
+			}
+			key, block = "", nil
+		}
+		for _, l := range lines {
+			switch {
+			case key != "" && (strings.HasPrefix(l, "    ") || l == ""):
+				block = append(block, strings.TrimPrefix(l, "    "))
+				continue
+			case key != "":
+				flush()
+			}
+			switch {
+			case l == "metadata:" || l == "data:":
+				section = strings.TrimSuffix(l, ":")
+			case section == "metadata" && strings.HasPrefix(l, "  name: "):
+				meta["name"] = strings.TrimPrefix(l, "  name: ")
+			case section == "metadata" && strings.HasPrefix(l, "    catalyst.openova.io/org-slug: "):
+				labels["catalyst.openova.io/org-slug"] = strings.Trim(strings.TrimPrefix(l, "    catalyst.openova.io/org-slug: "), `"`)
+			case section == "data" && strings.HasPrefix(l, "  ") && strings.HasSuffix(l, ": |"):
+				key = strings.TrimSuffix(strings.TrimPrefix(l, "  "), ": |")
+			case !strings.HasPrefix(l, " "):
+				section = ""
+			}
+		}
+		flush()
+		if strings.Contains(doc, "\nkind: ConfigMap\n") && len(data) > 0 {
+			meta["labels"] = labels
+			out = append(out, kube.Object{"metadata": meta, "data": data})
+		}
+	}
+	if len(out) == 0 {
+		t.Fatalf("the render holds no ConfigMap:\n%s", render)
+	}
+	return out
+}
