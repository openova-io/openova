# SEC-090 — Guards

## In plain words

**The problem today.** Nothing in the repository stops a change from adding a Secret manifest to Git, a password that a chart generates or derives when it renders, a Go call that writes a Secret, a reflector scope that copies a Secret into every namespace, or a new reference to the OpenBao unseal material. The packages that remove these shapes one chart at a time cannot hold their ground while new ones can still be added.

**What changes.** Eight guards scan the whole tree on every pull request, merge group and push to main. Seven of them keep the findings of today in an allow-list per file that may only shrink; the eighth allows no finding at all.

**Done means:**

- A pull request that adds a password generator such as randAlphaNum to a chart template turns the check secret-guards red.
- A pull request that adds a Secret manifest under the clusters folder or to a chart template, a credential derived with sha256sum, a Go call that writes a Secret, a reflector scope for every namespace or a new reference to the OpenBao unseal material turns the same check red.
- Each allow-list names every file that has a finding on the day the guards merge, with its count; a lower count passes and names the line to change or delete.
- Each guard proves with its own self-test, on fixtures, that each of its rules can fail.
- The allow-lists do not raise the count of files that hold the word sandbox.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The workflow `.github/workflows/secret-guards.yaml` runs eight guards on every pull request, every merge group and every push to `main`, with no path filter. Each guard is a script `scripts/check-<name>.sh` that scans the whole tree of tracked files at the commit under test (never only the diff). Seven guards compare what they find with their allow-list `scripts/secret-guard-baselines/check-<name>.txt` (one `path:count` line per file): a count that rises or a path that is new turns the check `secret-guards` red, a count that falls passes and prints the line to change or delete. The eighth guard, the delivery lint, has no allow-list and fails on any finding. The allow-lists are written from the tree on the day the guards merge, so the check is green on that day and every later secret shape of these kinds is refused. The rules live once, in `scripts/secret-guards.py`; each guard's `--self-test` proves on fixtures that each of its rules can fail. The guard `scripts/check-sandbox-word.py` does not read the allow-lists, because each of their lines is the name of a file and a file name does not count there.

## 3. The model (the law)
1. The guards and their rules. "Own chart template" means a file under `<chart>/templates/`, where `<chart>` is a folder under `platform/` or `products/` that holds a `Chart.yaml` and is not inside a `charts/` folder. A chart inside a `charts/` folder is vendored. Counts are per line: a line that matches counts once.

| Guard | Script | Files scanned | A line is a finding when |
|---|---|---|---|
| G1 | `scripts/check-no-secret-values-in-git.sh` | tracked files under `clusters/` | it is `kind: Secret` (spaces allowed around it) |
| G2 | `scripts/check-no-chart-random-secrets.sh` | own chart templates | it holds `randAlphaNum`, `randAlpha ` (with the space), `randNumeric`, `randAscii`, `genCA`, `genPrivateKey`, `genSelfSignedCert`, `genSignedCert`, `htpasswd` or `derivePassword` |
| G3 | `scripts/check-no-plain-secret-manifests.sh` | own chart templates | it is `kind: Secret` (spaces allowed around it) |
| G4 | `scripts/check-no-derived-credentials.sh` | own chart templates | it holds `sha256sum` and not `checksum/`, and it or one of the four lines above it holds `secret`, `password`, `token`, `seed` or `salt` in any case |
| G5 | `scripts/check-no-secret-writers.sh` | Go files not ending in `_test.go` | it calls `Secrets(...).Create(`, `.Update(`, `.Patch(` or `.Apply(`; or it is `kind: Secret` |
| G6 | `scripts/check-reflector-scope.sh` | (a) files under `infra/` and `clusters/`, own chart templates, Go files not ending in `_test.go`; (b) own chart templates | (a) it is not a comment (`#` or `//` first) and sets `reflection-auto-namespaces` to an empty value or to a value that holds `.*` or `[a-z]`; (b) the file has a line `kind: ExternalSecret` or `kind: PushSecret`, and the line is a `name:` (or `- name:`) line, not a comment, that holds `vault-region1` |
| G7 | `scripts/check-openbao-no-unseal-secret.sh` | tracked files under `platform/`, `products/`, `clusters/`, `infra/`, `core/`, `scripts/`, `tests/`, `.github/`, except `scripts/secret-guard-baselines/` | it holds the name of the OpenBao unseal-key Secret (`openbao-unseal-` followed by `keys`) or the name of the root-token generation endpoint (`generate-` followed by `root`) |
| G9 | `scripts/check-secret-delivery-lint.sh` | every chart template under `platform/` and `products/`, vendored charts included | (a) the file has a line `kind: SecretProviderClass` and the line starts a `secretObjects:` key; (b) the file has a line `kind: ExternalSecret` and the line is a `name:` (or `- name:`) line, not a comment, that holds `openbao-mounted` |

2. The allow-list of guard `check-<name>` is `scripts/secret-guard-baselines/check-<name>.txt`: one line `path:count` per file with at least one finding, sorted by path, with no comment and no empty line. G9 has no allow-list file. Every guard reads its allow-list on each run; a missing or malformed allow-list is exit code 2.
3. Each guard, run with no argument: exit 1 when a file has more findings than its allow-list line allows or has findings and no line; it prints `FAIL` lines with each finding as `path:line: text`. A file with fewer findings than its line, or none, passes; the guard prints `LOWER <allow-list>: replace the line '<p>:<n>' with '<p>:<m>'` or `LOWER <allow-list>: delete the line '<p>:<n>'`. Otherwise it prints one line that starts with `OK ` and exits 0.
4. Each guard has the modes `--self-test` (fixtures in throw-away Git repositories, one failing case per rule, a rise, a new path, a fall, a malformed allow-list), `--count <path>` (one integer: the findings in files under `<path>`) and `--list <path>` (`path:count` per file under `<path>`; `.` is the whole tree). The allow-lists of this package are written by `--list .`.
5. No guard scans only a diff, and no guard exits 0 on a finding above its allow-list.
6. The allow-lists may only shrink. This package writes them from the tree, with the command of step 14; it adds no line by hand.
7. The scan for secret values (keys and tokens in any file) is the workflow `security-scan`, which runs Trivy's secret scanner over the whole tree and fails on a new finding. This package adds no second secret scanner and no `.gitleaks.toml`.
8. `scripts/check-sandbox-word.py` does not read `scripts/secret-guard-baselines/*.txt` (that folder only, not a deeper folder). Every other file of that folder is still read. Its baseline `docs/ledger/sandbox-word-baseline.txt` is not changed.

"""The rules of the secret guards G1 to G7 and G9 (SEC-090).

Each guard is a script scripts/check-<guard>.sh that runs this file with its
guard name. The scripts are what CI runs and what the meta-guard
scripts/check-guards-are-wired.sh sees; this file holds the rules once, so the
self-test runs the same code as the real scan.

Every guard scans the whole tree of tracked files (git ls-files), never only a
diff. A guard with an allow-list compares what it finds with
scripts/secret-guard-baselines/check-<guard>.txt, one "path:count" line per
file:

  - a path whose count rises fails;
  - a path that is not in the allow-list fails;
  - a path whose count falls passes, and the guard prints the line to change

The allow-list may only shrink. A guard without an allow-list fails on any
finding.

Usage:

def tracked_files(root):
    """Every tracked file of the repository at root, sorted."""
    r = subprocess.run(["git", "-C", root, "ls-files", "-z"], stdout=subprocess.PIPE, stderr=subprocess.PIPE,
                       env=GIT_ENV)
    if r.returncode != 0:
        raise SetupError("git ls-files failed in %s: %s" % (root, r.stderr.decode("utf-8", "replace").strip()))
    return sorted(p for p in r.stdout.decode("utf-8", "replace").split("\0") if p)


def read_lines(root, path):
    """The lines of a text file, or None for a binary or unreadable file."""
    try:
        with open(os.path.join(root, path), "rb") as f:
            data = f.read()
    except OSError:
        return None
    if b"\0" in data:
        return None
    return data.decode("utf-8", "replace").split("\n")


def chart_roots(files, own_only):

        if not any(kind.search(l) for l in lines):
            return []
        return [i + 1 for i, l in enumerate(lines) if pattern.search(l) and not is_comment(l)]
    return rule


def derived_credentials(lines):
    """G4: a line with sha256sum (not a checksum/ annotation) whose own line or
    one of the four lines above it names a secret, password, token, seed or salt."""
    found = []
    for i, l in enumerate(lines):
        if "sha256sum" in l and "checksum/" not in l:
            if any(CREDENTIAL_WORD.search(x) for x in lines[max(0, i - 4): i + 1]):
                found.append(i + 1)
    return found


def wide_reflection(lines):
    """G6 (a): a reflection-auto-namespaces value that is empty or holds a
    pattern (.* or [a-z]), so that the reflector copies into every namespace."""
    found = []
    for i, l in enumerate(lines):
        if is_comment(l):

        m = REFLECT_NAMESPACES.search(l)
        if not m:

            found.append(i + 1)
    return found

class SetupError(Exception):

def scan(guard, root):
    """{path: [line numbers]} for every file with at least one finding."""
    files = tracked_files(root)
    found = {}
    for select, rule in GUARDS[guard]["rules"]:
        for p in sorted(set(select(files))):
            lines = read_lines(root, p)
            if lines is None:
                continue
            hits = rule(lines)
            if hits:
                found.setdefault(p, set()).update(hits)
    return {p: sorted(v) for p, v in sorted(found.items())}

def baseline_path(guard):
    return "%s/check-%s.txt" % (BASELINE_DIR, guard)


def read_allow_list(guard, root):
    path = os.path.join(root, baseline_path(guard))
    if not os.path.isfile(path):
        raise SetupError("the allow-list %s does not exist" % baseline_path(guard))
    allowed = {}
    with open(path, encoding="utf-8") as f:
        for n, line in enumerate(f.read().split("\n"), 1):
            if line == "":
                continue
            m = re.match(r"^([^:\s]+):([1-9][0-9]*)$", line)
            if not m or m.group(1) in allowed:
                raise SetupError("%s line %d is not a new 'path:count' line: %r" % (baseline_path(guard), n, line))
            allowed[m.group(1)] = int(m.group(2))
    return allowed


def check(guard, root, say):
    """Scan root and compare with the allow-list. Returns the exit code."""
    g = GUARDS[guard]
    found = scan(guard, root)
    allowed = read_allow_list(guard, root) if g["allow_list"] else {}
    failures = 0
    for p, hits in found.items():
        have = allowed.get(p)
        if have is None:
            say("FAIL %s: %s has %d finding(s) and is not in the allow-list" % (guard, p, len(hits)))
        elif len(hits) > have:
            say("FAIL %s: %s has %d finding(s), the allow-list allows %d" % (guard, p, len(hits), have))
        else:
            continue
        failures += 1
        lines = read_lines(root, p) or []
        for n in hits:
            text = lines[n - 1].strip() if n <= len(lines) else ""
            say("  %s:%d: %s" % (p, n, text[:160]))
    for p, have in sorted(allowed.items()):
        now = len(found.get(p, []))
        if now == 0:
            say("LOWER %s: delete the line '%s:%d'" % (baseline_path(guard), p, have))
        elif now < have:
            say("LOWER %s: replace the line '%s:%d' with '%s:%d'" % (baseline_path(guard), p, have, p, now))
    if failures:
        if g["allow_list"]:
            say("FAIL %s: %d file(s) above the allow-list %s. It may only shrink: remove the new "
                "finding(s); never raise or add a line." % (g["title"], failures, baseline_path(guard)))
        else:
            say("FAIL %s: %d file(s) with a finding. This guard has no allow-list." % (g["title"], failures))
        return 1
    if g["allow_list"]:
        say("OK %s: %d finding(s) in %d file(s), none above the allow-list." % (
            g["title"], sum(len(v) for v in found.values()), len(found)))
    else:
        say("OK %s: no finding." % g["title"])
    return 0

def make_tree(files):
    root = tempfile.mkdtemp(prefix="secret-guards-")
    for p, content in files.items():
        full = os.path.join(root, p)
        os.makedirs(os.path.dirname(full), exist_ok=True)
        with open(full, "w", encoding="utf-8") as f:
            f.write(content)
    for args in (["init", "-q"], ["add", "-A"]):
        subprocess.run(["git", "-C", root] + args, check=True, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
                       env=GIT_ENV)
    return root


def run_case(guard, files):
    """check() on a fixture tree: (exit code, printed lines)."""
    out = []
    root = make_tree(files)
    try:
        code = check(guard, root, out.append)
    finally:
        shutil.rmtree(root, ignore_errors=True)
    return code, out


def self_test(guard):
    fx = FIXTURES[guard]
    fails = []

    def expect(label, ok, detail=""):
        print("  %s %s" % ("ok  " if ok else "FAIL", label))
        if not ok:
            fails.append(label)
            if detail:
                print("       " + detail.replace("\n", "\n       "))

    base = dict(fx["controls"])
    allowed = fx["allowed"]
    if allowed:
        path, content = allowed
        base[path] = content
        base[baseline_path(guard)] = "%s:1\n" % path
        root = make_tree(base)
        try:
            got = scan(guard, root)
        finally:
            shutil.rmtree(root, ignore_errors=True)
        expect("the allowed file is found once and no look-alike is counted",
               list(got) == [path] and len(got[path]) == 1, "found: %r" % got)
        folder = os.path.dirname(path)
        expect("--count and --list select by path",
               len(select_path(got, folder).get(path, [])) == 1 and select_path(got, folder + "x") == {}
               and select_path(got, ".") == got, "found: %r" % got)
        code, out = run_case(guard, base)
        expect("the tree at its allow-list passes", code == 0 and not any(l.startswith("LOWER") for l in out),
               "\n".join(out))
        rise = dict(base)
        rise[path] = content + fx["extra_site"]
        code, out = run_case(guard, rise)
        expect("a rise of an allowed file fails", code == 1, "\n".join(out))
        fall = dict(base)
        del fall[path]
        code, out = run_case(guard, fall)
        expect("a removed finding passes and asks to delete its line",
               code == 0 and "LOWER %s: delete the line '%s:1'" % (baseline_path(guard), path) in out, "\n".join(out))
        broken = dict(base)
        broken[baseline_path(guard)] = "%s:x\n" % path
        code, out = run_case_setup(guard, broken)
        expect("a malformed allow-list line is a setup error", code == 2, "\n".join(out))
    else:
        code, out = run_case(guard, base)
        expect("the clean tree passes", code == 0, "\n".join(out))
    for label, extra in fx["bad"]:
        tree = dict(base)
        tree.update(extra)
        code, out = run_case(guard, tree)
        expect("fails on %s" % label, code == 1, "\n".join(out))
    if fails:
        print("SELF-TEST FAILED: %s (%d case(s))" % (guard, len(fails)))
        return 1
    print("OK %s: self-test passed; fixtures only, no cluster was contacted." % guard)
    return 0


def run_case_setup(guard, files):
    """Like run_case, but a SetupError becomes exit code 2, as in main()."""
    try:
        return run_case(guard, files)
    except SetupError as e:
        return 2, [str(e)]


# ---------------------------------------------------------------- main

def main(argv):
    if not argv or argv[0] not in GUARDS:
        print("usage: secret-guards.py <guard> [--self-test | --count <path> | --list <path>]; guards: %s"
              % ", ".join(sorted(GUARDS)), file=sys.stderr)
        return 2
    guard, rest = argv[0], argv[1:]
    root = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
    try:
        if rest == ["--self-test"]:
            return self_test(guard)
        if len(rest) == 2 and rest[0] in ("--count", "--list"):
            found = select_path(scan(guard, root), rest[1])
            if rest[0] == "--count":
                print(sum(len(v) for v in found.values()))
            else:
                for p, hits in found.items():
                    print("%s:%d" % (p, len(hits)))
            return 0
        if rest:
            print("unknown arguments: %s" % " ".join(rest), file=sys.stderr)
            return 2
        return check(guard, root, print)
    except SetupError as e:
        print("ERROR %s: %s" % (guard, e), file=sys.stderr)
        return 2


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
