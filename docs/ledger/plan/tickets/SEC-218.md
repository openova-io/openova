# SEC-218 — Every kit slot whose chart renders a SecretProviderClass depends on bp-secrets-store-csi

## In plain words

**The problem today.** A release whose chart renders a SecretProviderClass can install only after the Secrets Store CSI driver has installed that kind. The Grafana slot does not wait for the driver, and the reduced kit of the local provider pack carries neither the driver nor OpenBao, on which the driver depends. The next change of the console chart adds such an object, and its two-region test install failed for 40 minutes because the kind never arrived.

**What changes.** Every slot whose chart renders the kind waits for the driver, the local kit carries the driver and OpenBao, and a guard of the tree guards renders every kit and refuses a slot that renders the kind without that edge or in a kit without the driver.

**Done means:**

- The console slot and the Grafana slot name the Secrets Store CSI driver among the releases they wait for.
- The reduced kit of the local provider pack carries OpenBao and the driver, and both come up Ready in its two regions.
- A guard renders every kit at the values of each provider pack that applies it, in both region roles, and fails when a release renders a SecretProviderClass without waiting for the driver, or when its kit lacks the driver or a release the driver depends on.
- The guard and its tests run in the tree guards on every pull request, and each rule of the guard has a test that makes it fail.
- Run against the tree before this change, the guard fails and names the Grafana slot.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. A release renders the kind when its chart, rendered as Flux installs it (the kit substituted with the pack's values, the release's name, target namespace and values, the kind's API version declared), holds an object of kind `SecretProviderClass`. A suspended release installs nothing and is not judged.
2. Every release that renders the kind, other than the driver, names the driver's release `flux-system/bp-secrets-store-csi` in `spec.dependsOn`, sits in a kit that holds the driver's release not suspended, and is not itself a release the driver depends on (that edge would be a cycle).
3. In a kit that holds the driver, every release the driver depends on, directly or through others, is a release of the kit and is not suspended. Slot 15b depends on `bp-openbao`; slot 08 (`bp-openbao`) depends on `bp-gateway-api` and `bp-cnpg`.
4. A kit is the shared kit `clusters/_template/bootstrap-kit/kustomization.yaml`, judged at the values of each pack that applies it, and each pack's own kit `clusters/_template/providers/<pack>/kit/kustomization.yaml`, judged at that pack's values; a pack is a folder `infra/providers/<pack>` with a `pack.yaml`. The roles are primary (`tests/fixtures/variables/today.env`, then the pack's literal substitutes) and secondary (`tests/fixtures/variables/two-region-secondary.env` between the two).
5. A release whose chart is not a chart of this tree is named in `outsideTree` of `main.go` with the reason it renders no SecretProviderClass; an entry no kit holds is a finding, a release that is not named stops the guard (exit 2), and so does a render in which no release of any kit renders the kind.
6. The local kit `clusters/_template/providers/local/kit/kustomization.yaml` stays the output of `scripts/generators/local-kit.py`: `bp-openbao` leaves `infra/providers/local/kit-exclude.txt`, and the generator then lists slot 08 and slot 15b. `docs/generated/bootstrap-slots.md` stays the output of `scripts/generators/slots.py`, and `scripts/expected-bootstrap-deps.yaml` holds the new edges.
7. No chart, no version line, no slot 08, 13b or 15b and no gate changes. No new Python. No live system is read or written.

+	return 0

+// verdict judges the releases of one kit at one pack's values in one role. It
+// returns a line for each release that renders the kind and holds, the
+// findings, and the number of releases that render the kind.
+func verdict(where string, rels []release) (notes, findings []string, users int) {
+	byID := map[string]release{}
+	var drivers []release
+	for _, r := range rels {
+		byID[r.id()] = r
+		if r.chart == driverChart && !r.suspended {
+			drivers = append(drivers, r)
+		}
+	}
+	bad := func(format string, args ...any) {
+		findings = append(findings, "kit-spc-depends: FINDING "+where+": "+fmt.Sprintf(format, args...))
+	}
+	if len(drivers) > 1 {
+		var ids []string
+		for _, d := range drivers {
+			ids = append(ids, d.id()+" ("+d.file+")")
+		}
+		bad("%d releases of chart %s: %s; one installs the kind", len(drivers), driverChart, strings.Join(ids, ", "))
+		return nil, findings, countUsers(rels)
+	}
+	// The releases the driver depends on, directly or through others.
+	closure := map[string]bool{}
+	if len(drivers) == 1 {
+		d := drivers[0]
+		stack := append([]string(nil), d.deps...)
+		via := map[string]string{}
+		for _, n := range d.deps {
+			via[n] = d.id()
+		}
+		for len(stack) > 0 {
+			n := stack[len(stack)-1]
+			stack = stack[:len(stack)-1]
+			if closure[n] {
+				continue
+			}
+			closure[n] = true
+			r, ok := byID[n]
+			switch {
+			case !ok:
+				bad("the driver's release %s (%s) depends on %s (through %s), which the kit does not hold: the driver never installs", d.id(), d.file, n, via[n])
+				continue
+			case r.suspended:
+				bad("the driver's release %s (%s) depends on %s (%s, through %s), which is suspended here: the driver never installs", d.id(), d.file, n, r.file, via[n])
+			}
+			for _, m := range r.deps {
+				if _, seen := via[m]; !seen {
+					via[m] = n
+				}
+				stack = append(stack, m)
+			}
+		}
+	}
+	for _, r := range rels {
+		if r.suspended || len(r.kinds) == 0 || r.chart == driverChart {
+			continue
+		}
+		users++
+		what := fmt.Sprintf("%s (%s, chart %s) renders %s %s", r.id(), r.file, r.chart, kindName, strings.Join(r.kinds, ", "))
+		if len(drivers) == 0 {
+			bad("%s, and the kit holds no release of chart %s that is not suspended: the kind never arrives", what, driverChart)
+			continue
+		}
+		d := drivers[0]
+		if closure[r.id()] {
+			bad("%s, and the driver's release %s depends on it: an edge to the driver would be a cycle", what, d.id())
+			continue
+		}
+		if !contains(r.deps, d.id()) {
+			bad("%s, and its spec.dependsOn does not name %s (%s), which installs the kind", what, d.id(), d.file)
+			continue
+		}
+		notes = append(notes, fmt.Sprintf("kit-spc-depends: ok %s: %s, and waits for %s", where, what, d.id()))
+	}
+	return notes, findings, users
+}

+func countUsers(rels []release) int {
+	n := 0
+	for _, r := range rels {
+		if !r.suspended && len(r.kinds) > 0 && r.chart != driverChart {
+			n++
+		}
+	}
+	return n
+}

+// packSubstitutes reads the literal substitutes of one pack, KEY=value each:
+// the entries KEY: "value" of its provider-substitutes.yaml.tftpl, then the
+// entries KEY = "value" of the block pack_substitutes of its main.tf (a later
+// entry of a key wins). A value the pack computes (one that holds ${ or %{, or
+// is not a quoted string) is left out, so the base value stands for it.
+func packSubstitutes(dir string) ([]string, error) {
+	var out []string
+	b, err := os.ReadFile(filepath.Join(dir, "provider-substitutes.yaml.tftpl")) // #nosec G304 -- a file of the tree
+	switch {
+	case err == nil:
+		sc := bufio.NewScanner(bytes.NewReader(b))
+		for sc.Scan() {
+			if m := reYAMLEntry.FindStringSubmatch(sc.Text()); m != nil && literal(m[2]) {
+				out = append(out, m[1]+"="+m[2])
+			}
+		}
+	case !errors.Is(err, fs.ErrNotExist):
+		return nil, err
+	}
+	b, err = os.ReadFile(filepath.Join(dir, "main.tf")) // #nosec G304 -- a file of the tree
+	switch {
+	case err == nil:
+		in, opened, depth := false, false, 0
+		sc := bufio.NewScanner(bytes.NewReader(b))
+		for sc.Scan() {
+			line := sc.Text()
+			if !in {
+				if !reHCLBlock.MatchString(line) {
+					continue
+				}
+				in, opened, depth = true, false, 0
+			}
+			if m := reHCLEntry.FindStringSubmatch(line); m != nil && literal(m[2]) {
+				out = append(out, m[1]+"="+m[2])
+			}
+			opened = opened || strings.Contains(line, "{")
+			depth += strings.Count(line, "{") - strings.Count(line, "}")
+			if opened && depth <= 0 {
+				in = false
+			}
+		}
+	case !errors.Is(err, fs.ErrNotExist):
+		return nil, err
+	}
+	return out, nil
+}
