# CTL-230 — Batch F: resource browser

## In plain words

**The problem today.** The resource browser of the console writes objects of the cluster directly, also objects whose desired state Git owns, and keeps no durable record of these writes. No shared rule in the platform API says which direct writes are allowed, who may make them and how they are recorded.

**What changes.** One package of the platform API holds that rule and its record. The routes of the resource browser and the operations start to use it in the next tasks of the same batch; this task changes no route.

**Done means:**

- The platform API has one package that names the Git owner of an object from its Flux labels, its Flux owner reference or its kind.
- That package refuses a direct write of a Git-owned object with the answer 409 managed-by-git and the name of the owner.
- It allows any other direct write only for the owner tier with a written reason of at least ten characters.
- It records an allowed write and an operation on the audit stream before the write, answers 503 audit-unavailable when the stream does not take the record, and records the result after the write.
- A test proves that the kinds the package treats as Git-owned are exactly the kinds of the intent lock of the platform chart.
- No route and no existing file changes.

## 2. End goal
catalyst-api has one package, `products/catalyst/bootstrap/api/internal/clusterwrite`, that decides whether a route may write an object of the cluster directly and records every direct write it allows. It answers three questions in one place: who owns the object in Git (`Owner`), whether a direct write is refused (`RefuseGitOwned`, `Refuse`) or allowed by break-glass (`BreakGlass`, `Allow`), and how an allowed write or an operation is recorded (`BreakGlass`, `Operation`). Its tests prove every rule, and one of them proves that its list of Git-owned kinds is the list of the intent lock of the platform chart. This task adds the package and its tests and nothing else. The routes of the resource browser (scale, update, apply, delete, multi-document apply) and the four operations (restart, exec, job retry, reconcile) are moved onto it by the next tasks of this batch.

## 3. The model (the law)
1. **Git owner.** `Owner(gvr, live)` returns the owner of an object and `true`, or `""` and `false`. The first rule that matches wins:
   - the label `kustomize.toolkit.fluxcd.io/name` is not empty: `Kustomization <namespace>/<name>`, where the namespace is the label `kustomize.toolkit.fluxcd.io/namespace` (without it: `Kustomization <name>`);
   - the label `helm.toolkit.fluxcd.io/name` is not empty: `HelmRelease <namespace>/<name>`, the namespace from `helm.toolkit.fluxcd.io/namespace` (without it: `HelmRelease <name>`);
   - an owner reference whose `apiVersion` contains `fluxcd.io`: `<kind> <object namespace>/<name>` of that reference;
   - the label `app.kubernetes.io/managed-by` is `flux` in any case: `Flux`;
   - the resource is a kind of the intent lock: `the intent lock (<resource>.<group>)`. This rule holds also when `live` is nil, an object that does not exist yet.
2. **The kinds of the intent lock** are the 13 group and resource pairs of `intentLock.resources` in `products/catalyst/chart/values.yaml`. The package lists them in `lockedKinds`; the test `TestLockedKindsEqualTheIntentLockOfTheChart` reads the chart values and fails when the two lists differ.
3. **Refusal.** `RefuseGitOwned` writes the answer 409 with the JSON body `{"error":"managed-by-git","code":"409","owner":"<owner>","detail":"the desired state of <resource> <namespace>/<name> is owned by Git (<owner>); change it in Git"}` and returns true when Git owns the object. Otherwise it writes nothing and returns false. `Refuse(w, owner, detail)` writes the same answer with a detail of the caller's.
4. **Break-glass.** `BreakGlass(w, r, bus, Write)` allows a direct write of an object that Git does not own only when both hold:
   - the caller has the owner tier: the tier claim is `owner` (case and spaces ignored) or the realm role is `catalyst-owner`. A request without claims passes, as at every write gate of the resource browser today (`requireResourceMutationAuth` lets a request without the auth layer through). Otherwise: 403 `{"error":"break-glass-owner-only","code":"403",...}`.
   - the reason, without leading and trailing spaces, has at least 10 characters (`MinReasonLength`). Otherwise: 400 `{"error":"break-glass-reason-required","code":"400",...}`.
   `Allow(w, r, bus, gvr, live, Write)` applies rule 3 first and then `BreakGlass`.
5. **Operation.** `Operation(w, r, bus, Op)` needs no reason and no tier: the route keeps its own tier gate.
6. **The record (contract C3, subject `catalyst.audit.recorded.v1`).** `BreakGlass` and `Operation` record the same way:
   - before the write, one `audit.Event` with `Phase` `intent`, a new `ID` (`natsbus.NewID()`), `SovereignID` the cluster, `Actor` from `Actor`, published with `audit.Bus.PublishStrict`, which returns only after the stream acknowledged it;
   - when `PublishStrict` fails (also when the bus has no publisher), the answer is 503 `{"error":"audit-unavailable","code":"503","detail":"<error>"}` and the caller writes nothing;
   - the returned `Finish(ctx, err)` publishes with `audit.Bus.Publish` a copy of the event with `Phase` `result`, a new `ID`, `Result` `ok` (or `error` when `err` is not nil, with the error at the end of `Detail`), and ` (intent <ID of the intent event>)` appended to `Detail`;
   - audit type `break-glass` (`AuditTypeBreakGlass`) with `Detail` `<verb> <resource> <namespace>/<name>: <reason>`; audit type `operation-<name>` (`AuditTypeOperationPrefix` + name) with `Detail` `<name> <target>`;
   - a nil bus records nothing and lets the write go ahead. That is the state of a test harness that sets no audit bus; `cmd/api/main.go` always sets one (`h.SetAuditBus(newAuditBusFromEnv(log))`).
7. **Actor.** `Actor(claims, r)` is the e-mail of the claims, else their subject, else the header `X-User-Email`, else `operator`. It is the same rule as `retryOperatorIdentity` of `internal/handler/jobs_retry.go`, which this task does not change.
8. **The package writes nothing to the cluster.** It has no Kubernetes client call. The direct-write guard (`scripts/check-no-direct-cluster-write.py`) counts the same as before.
9. **Nothing else changes.** No existing file changes. The handler package and its size guard (`scripts/check-api-structure.py`) are untouched. No module gains a dependency: the package imports only modules that `products/catalyst/bootstrap/api/go.mod` already requires.

// Package clusterwrite decides whether a route of catalyst-api may write an
// object of the cluster directly, and records each direct write it allows.
//
//  1. An object whose desired state Git owns is never written directly: it
//     carries a Flux ownership label or owner reference, or it is of a kind
//     of the intent lock. The answer is 409 managed-by-git with the owner.
//  2. Any other object is written only by break-glass: the owner tier and a
//     reason of at least MinReasonLength characters (BreakGlass, Allow).
//  3. An operation (restart, exec, job-retry, reconcile) needs no reason; the
//     route keeps its own tier gate (Operation).
//
// Rules 2 and 3 record the write the same way. An audit event with phase
// intent must reach the stream before the write, or the answer is 503
// audit-unavailable and nothing is written. An event with phase result
// follows the write.
package clusterwrite

import (

	"encoding/json"
	"fmt"
	"net/http"

	AuditTypeBreakGlass = "break-glass"

	// an operation, for example operation-restart.

// Owner names the owner in Git of an object of the resource gvr. live is
// the object, or nil when it does not exist. owned is false when Git owns
// nothing of it.
func Owner(gvr schema.GroupVersionResource, live *unstructured.Unstructured) (owner string, owned bool) {
	if live != nil {
		labels := live.GetLabels()
		for _, flux := range []struct{ group, kind string }{
			{"kustomize.toolkit.fluxcd.io", "Kustomization"}, {"helm.toolkit.fluxcd.io", "HelmRelease"},
		} {
			if name := labels[flux.group+"/name"]; name != "" {
				return flux.kind + " " + qualified(labels[flux.group+"/namespace"], name), true
			}
		}
		for _, ref := range live.GetOwnerReferences() {
			if strings.Contains(ref.APIVersion, "fluxcd.io") {
				return ref.Kind + " " + qualified(live.GetNamespace(), ref.Name), true
			}
		}
		if strings.EqualFold(labels["app.kubernetes.io/managed-by"], "flux") {
			return "Flux", true
		}
	}
	if lockedKinds[gvr.GroupResource()] {
		return "the intent lock (" + gvr.GroupResource().String() + ")", true
	}
	return "", false
}

func qualified(namespace, name string) string {
	if namespace == "" {
		return name
	}
	return namespace + "/" + name
}

// Refuse writes the answer 409 managed-by-git with the owner and a detail.
func Refuse(w http.ResponseWriter, owner, detail string) {
	writeJSON(w, http.StatusConflict, "managed-by-git", owner, detail)
}

// RefuseGitOwned writes the 409 answer and returns true when Git owns the
// object; it writes nothing and returns false otherwise.
func RefuseGitOwned(w http.ResponseWriter, gvr schema.GroupVersionResource, live *unstructured.Unstructured, namespace, name string) bool {
	owner, owned := Owner(gvr, live)
	if owned {
		Refuse(w, owner, fmt.Sprintf("the desired state of %s %s is owned by Git (%s); change it in Git",
			gvr.Resource, qualified(namespace, name), owner))
	}
	return owned
}

// OwnerTier says whether claims carry the owner tier: the tier claim owner
// or the realm role catalyst-owner. Nil claims pass, as at every write gate
// of the resource browser (a request without the auth layer, in tests).
func OwnerTier(claims *auth.Claims) bool {
	return claims == nil || strings.EqualFold(strings.TrimSpace(claims.Tier), "owner") || claims.HasRealmRole("catalyst-owner")
}

// Actor names the caller for an audit event and a log line: the e-mail or
// subject of the claims, else the header X-User-Email, else "operator".
func Actor(claims *auth.Claims, r *http.Request) string {
	if claims != nil {
		if e := strings.TrimSpace(claims.Email); e != "" {
			return e
		}
		if s := strings.TrimSpace(claims.Sub); s != "" {
			return s
		}
	}
	if e := strings.TrimSpace(r.Header.Get("X-User-Email")); e != "" {
		return e
	}
	return "operator"
}

// Write describes one break-glass write: Verb is scale, update, apply or
// delete; Resource is the plural resource name.
type Write struct {
	Cluster, Verb, Resource, Namespace, Name, Reason string
}

// Op describes one operation: Name is restart, exec, job-retry or
// reconcile; Target names what it acts on.
type Op struct {
	Cluster, Name, Target string
}

// Finish records the result of a write: err is its error, or nil.
type Finish func(ctx context.Context, err error)

// BreakGlass applies rule 2. When it returns false it has written the
// answer (403, 400 or 503) and the caller writes nothing. Otherwise the
// caller writes and then calls the Finish. A nil bus records nothing (a
// test harness without an audit bus); main.go always sets one.
func BreakGlass(w http.ResponseWriter, r *http.Request, bus *audit.Bus, wr Write) (Finish, bool) {
	claims := auth.ClaimsFromContext(r.Context())
	reason := strings.TrimSpace(wr.Reason)
	if !OwnerTier(claims) {
		writeJSON(w, http.StatusForbidden, "break-glass-owner-only", "", "a direct write of an object that Git does not own needs the owner tier")
		return nil, false
	}
	if len(reason) < MinReasonLength {
		writeJSON(w, http.StatusBadRequest, "break-glass-reason-required", "", fmt.Sprintf(
			"a direct write needs a reason of at least %d characters in the field reason", MinReasonLength))
		return nil, false
	}
	return record(w, r, bus, audit.Event{AuditType: AuditTypeBreakGlass, SovereignID: wr.Cluster,
		Detail: fmt.Sprintf("%s %s %s: %s", wr.Verb, wr.Resource, qualified(wr.Namespace, wr.Name), reason)})
}

// Allow applies rules 1 and 2 to the write of one live object (nil when it
// does not exist yet).
func Allow(w http.ResponseWriter, r *http.Request, bus *audit.Bus, gvr schema.GroupVersionResource, live *unstructured.Unstructured, wr Write) (Finish, bool) {
	if RefuseGitOwned(w, gvr, live, wr.Namespace, wr.Name) {
		return nil, false
	}
	return BreakGlass(w, r, bus, wr)
}

// Operation applies rule 3: it records the intent of the operation and
// returns its Finish. When it returns false it has written the 503 answer
// and the caller acts on nothing. A nil bus records nothing, as above.
func Operation(w http.ResponseWriter, r *http.Request, bus *audit.Bus, op Op) (Finish, bool) {
	return record(w, r, bus, audit.Event{AuditType: AuditTypeOperationPrefix + op.Name, SovereignID: op.Cluster,
		Detail: op.Name + " " + op.Target})
}

// record publishes ev with phase intent and waits for the stream; its
// Finish publishes the event with phase result.
func record(w http.ResponseWriter, r *http.Request, bus *audit.Bus, ev audit.Event) (Finish, bool) {
	if bus == nil {
		return func(context.Context, error) {}, true
	}
	ev.Actor = Actor(auth.ClaimsFromContext(r.Context()), r)
	ev.ID, ev.Phase = natsbus.NewID(), audit.PhaseIntent
	if err := bus.PublishStrict(r.Context(), ev); err != nil {
		writeJSON(w, http.StatusServiceUnavailable, "audit-unavailable", "", err.Error())
		return nil, false
	}
	return func(ctx context.Context, err error) {
		result := ev
		result.ID, result.Phase, result.Result = "", audit.PhaseResult, "ok"
		result.Detail = ev.Detail + " (intent " + ev.ID + ")"
		if err != nil {
			result.Result, result.Detail = "error", result.Detail+": "+err.Error()
		}
		bus.Publish(ctx, result)
	}, true
}

func writeJSON(w http.ResponseWriter, status int, code, owner, detail string) {
	body := map[string]string{"error": code, "code": fmt.Sprint(status), "detail": detail}
	if owner != "" {
		body["owner"] = owner
	}
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(body)
}
