# SOV-120 — The sovereign-ops command and its image

## In plain words

**The problem today.** The life-cycle actions of a Sovereign (seeding its own repository, copying a release, the hand-over steps) are to run as Kubernetes Jobs of one command, and that command does not exist. There is no image to run them in, and no agreed way for such a Job to report what it did.

**What changes.** A new command with a dispatcher, a fixed one-line JSON result and fixed exit codes, and an image that carries the command and the tools its actions need. Later tasks add one subcommand each.

**Done means:**

- Every run of the command ends with one JSON line that names the command, says success or failed, lists its evidence and gives the error, and the same line is written to the termination log of the container.
- The exit code is 0 on success, 1 on a failure and 75 on a failure the caller may retry.
- A missing or unknown subcommand fails with exit code 1 and a result line.
- A pull request that changes the command runs its tests and builds its image, and a broken test or a broken image turns it red.
- On main the image is pushed with the short commit as its tag and signed.
- The image holds the OpenTofu release that the provisioning API image holds, with the same checksums.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. **Files.** The seven new files are the blocks of field 5, byte for byte. Nothing else changes.
2. **The module.** `core/cmd/sovereign-ops/go.mod` names the module `github.com/openova-io/openova/core/cmd/sovereign-ops` with `go 1.23`, the version of `core/controllers/go.mod`, and requires nothing. There is no `go.sum`: with no requirement there is nothing to record. The first subcommand that imports another module adds its `require`, its `replace` and its `go.sum`.
3. **The result line.** Every run, also a failed one and one with a wrong subcommand, ends with exactly one line of JSON on standard output, the object `{"command":"<subcommand>","result":"success|failed","evidence":[...],"error":"..."}` with its keys in that order. `evidence` is a list of strings and is `[]`, never `null`, when empty. `error` is `""` on success. The characters `<`, `>` and `&` are written as they are. The same line is written to the file `/dev/termination-log`, which Kubernetes shows as the container's termination message; a failed write there is ignored, because outside a Pod the file may not exist. Logs go to standard error. Package `internal/ops`, function `Finish`, writes the line.
4. **The exit codes.** 0 when the subcommand returns no error. 75 when its error wraps `ops.ErrTransient` (made with `ops.Transient(err)`): a failure the caller may retry. 1 for every other error, and for a missing or unknown subcommand. A failed write of the line to standard output also gives 1.
5. **The dispatcher.** `main.go` holds the table `subcommands`, a map from the subcommand name to a function `func(ctx context.Context, args []string, stderr io.Writer) ([]string, error)` that returns the evidence and the error. The table is empty in this ticket. With no argument, the error is `usage: sovereign-ops <subcommand> [flags]; subcommands: [<names>]`; with an unknown name it is `unknown subcommand "<name>"; subcommands: [<names>]`; `<names>` is the sorted table, separated by single spaces. The process stops on `SIGTERM` and interrupt through the context.
6. **The image** (`core/cmd/sovereign-ops/Containerfile`, built with the repository root as context). Stage `build`: `golang:1.26-alpine`, a static binary (`CGO_ENABLED=0`). Stage `tofu`: the OpenTofu release `1.11.6`, checked against the SHA-256 values that `products/catalyst/bootstrap/api/Containerfile` pins for amd64 and arm64; the three `ARG` lines are the same in both files. Final stage: `alpine:3.20` with `ca-certificates`, `git`, `helm` and `cosign` from the Alpine package repositories, the `tofu` binary at `/usr/local/bin/tofu`, the command at `/usr/local/bin/sovereign-ops` as the entry point, and user `65534:65534`.
7. **The workflow** (`.github/workflows/build-sovereign-ops.yaml`, workflow `Build sovereign-ops`, one job with the check name `build sovereign-ops`). It runs on a pull request and on a push to `main` that change `core/cmd/sovereign-ops/**` or the workflow, and by hand. Steps: Go from the module's `go.mod`; `go test -count=1 -race ./...` in `core/cmd/sovereign-ops`; the image build. On a pull request the image is built and not pushed, and nothing logs in to the registry. // Command sovereign-ops runs one life-cycle action of a Sovereign, as a
// Kubernetes Job or CronJob: sovereign-ops <subcommand> [flags]. Every
// subcommand is idempotent and ends with the result line and exit code of
// package internal/ops. Logs go to standard error.
package main

import (
	"context"
	"fmt"
	"io"
	"os"
	"os/signal"
	"sort"
	"strings"
	"syscall"

	"github.com/openova-io/openova/core/cmd/sovereign-ops/internal/ops"
)

// subcommands is the dispatcher's table. A subcommand is one entry here and
// one package under internal/.
var subcommands = map[string]func(ctx context.Context, args []string, stderr io.Writer) ([]string, error){}

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	code := run(ctx, os.Args[1:], os.Stdout, os.Stderr, "/dev/termination-log")
	stop()
	os.Exit(code)
}

// run dispatches args to a subcommand and returns the exit code. A missing
// or unknown subcommand fails with exit code 1.
func run(ctx context.Context, args []string, stdout, stderr io.Writer, termLog string) int {
	var names []string
	for n := range subcommands {
		names = append(names, n)
	}
	sort.Strings(names)
	if len(args) == 0 {
		return ops.Finish(stdout, termLog, "", nil, fmt.Errorf("usage: sovereign-ops <subcommand> [flags]; subcommands: [%s]", strings.Join(names, " ")))
	}
	cmd, ok := subcommands[args[0]]
	if !ok {
		return ops.Finish(stdout, termLog, args[0], nil, fmt.Errorf("unknown subcommand %q; subcommands: [%s]", args[0], strings.Join(names, " ")))
	}
	evidence, err := cmd(ctx, args[1:], stderr)
	return ops.Finish(stdout, termLog, args[0], evidence, err)
}

// Package ops holds what every subcommand of sovereign-ops shares: the
// result line and the exit codes. A run ends with one JSON line on standard
// output, also written to the termination log:
//
//	{"command":"seed-repo","result":"success","evidence":["..."],"error":""}
//
// Exit code 0 is success, 1 a failure, 75 a transient failure that the
// caller may retry.
package ops

import (
	"bytes"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"os"
)

// The exit codes of every subcommand.
const (
	ExitSuccess   = 0
	ExitFailed    = 1
	ExitTransient = 75
)

// ErrTransient marks a failure that the caller may retry.
var ErrTransient = errors.New("transient")

// Transient wraps err so that errors.Is(err, ErrTransient) holds. nil stays nil.
func Transient(err error) error {
	if err == nil {
		return nil
	}
	return fmt.Errorf("%w: %w", ErrTransient, err)
}

// Line is the result line of one run.
type Line struct {
	Command  string   `json:"command"`
	Result   string   `json:"result"`
	Evidence []string `json:"evidence"`
	Error    string   `json:"error"`
}

// Finish writes the result line of a run that ended with evidence and err
// to out and to the file termLog, and returns the exit code. A failed
// write to termLog is ignored: outside a Pod the file may not exist.
func Finish(out io.Writer, termLog, command string, evidence []string, err error) int {
	l, code := Line{Command: command, Result: "success", Evidence: append([]string{}, evidence...)}, ExitSuccess
	if err != nil {
		l.Result, l.Error, code = "failed", err.Error(), ExitFailed
		if errors.Is(err, ErrTransient) {
			code = ExitTransient
		}
	}
	var b bytes.Buffer
	enc := json.NewEncoder(&b)
	enc.SetEscapeHTML(false)
	if eerr := enc.Encode(l); eerr != nil {
		return ExitFailed
	}
	if _, werr := out.Write(b.Bytes()); werr != nil {
		return ExitFailed
	}
	if termLog != "" {
		_ = os.WriteFile(termLog, b.Bytes(), 0o600)
	}
	return code
}

import (
	"bytes"
	"errors"
	"os"
	"path/filepath"
	"testing"

// TestResultLine checks the exact result line on stdout and in the
// termination log: evidence is never null, error is empty on success.
func TestResultLine(t *testing.T) {
	for _, c := range []struct {
		evidence []string
		err      error
		want     string
	}{
		{nil, nil, `{"command":"probe","result":"success","evidence":[],"error":""}`},
		{[]string{"commit abc", "wrote a/<b>.yaml"}, nil, `{"command":"probe","result":"success","evidence":["commit abc","wrote a/<b>.yaml"],"error":""}`},
		{[]string{"read x"}, errors.New("boom"), `{"command":"probe","result":"failed","evidence":["read x"],"error":"boom"}`},
		{nil, Transient(errors.New("no answer")), `{"command":"probe","result":"failed","evidence":[],"error":"transient: no answer"}`},
	} {
		termLog := filepath.Join(t.TempDir(), "termination-log")
		var out bytes.Buffer
		Finish(&out, termLog, "probe", c.evidence, c.err)
		got, err := os.ReadFile(filepath.Clean(termLog))
		if err != nil || out.String() != c.want+"\n" || string(got) != c.want+"\n" {
			t.Fatalf("stdout %q, termination log %q (%v), want %q", out.String(), got, err, c.want)
		}
	}
}

// TestExitCodes checks 0, 1 and 75, also when the termination log cannot
// be written.
func TestExitCodes(t *testing.T) {
	missing := filepath.Join(t.TempDir(), "no-such-dir", "termination-log")
	for _, c := range []struct {
		err  error
		want int
	}{
		{nil, 0},
		{errors.New("boom"), 1},
		{Transient(errors.New("no answer")), 75},
		{errors.Join(errors.New("seed"), Transient(errors.New("no answer"))), 75},
	} {
		var out bytes.Buffer
		if got := Finish(&out, missing, "probe", nil, c.err); got != c.want || out.Len() == 0 {
			t.Fatalf("error %v: exit code %d and %d bytes on stdout, want %d and one line", c.err, got, out.Len(), c.want)
		}
	}
	if Transient(nil) != nil {
		t.Fatal("Transient(nil) is not nil")
	}
}
