# PRD-205 — Assistants: models list, answers with citations, residency refusal

## In plain words

**The problem today.** The document search can find passages, but nobody can ask a question and get an answer. Chat front ends expect the OpenAI routes for models and chat, and cortex has neither. Nothing stops an answer from going to a model outside the Sovereign.

**What changes.** A caller lists the assistants it may use and asks one of them a question; the answer comes from the passages the caller may read, through the platform's model gateway, with those passages as citations. An answer through a model outside the Sovereign is refused unless the Organization allows it.

**Done means:**

- A caller sees on the model list only the assistants whose users include one of its principals.
- An answer carries the passages it was given as citations, in a plain answer and in the last chunk of a streamed one.
- Secondary sources are searched only when the primary ones gave too few passages, and fallback sources only when both gave none; a source the caller cannot read is never searched.
- An answer is refused with 409 external-models-not-allowed while the gateway lists the chat alias as simulation, with no owner or not at all, unless the Organization set allowExternalModels.
- A request with tools is refused, an assistant the caller may not use is not found, and a gateway that answers 429 passes its Retry-After on.
- The query process does not start without its definitions file or without a chat alias in it.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`products/cortex` answers questions. The query process (`cortex query`) gains `GET /v1/models` and `POST /v1/chat/completions` in the OpenAI shape, behind the token check that guards every route. The models list holds one entry per assistant of the definitions whose `users` contain one of the caller's principals. A chat request names an assistant as its `model`; the answer is one search over the assistant's sources by tier, trimmed to the caller's own principals, then one generation through the gateway's chat alias `models.chat.alias`, and it carries the passages as a top-level `citations` list. Unless `policy.allowExternalModels` is true, an answer is refused with 409 `external-models-not-allowed` while the gateway's `GET /v1/models` lists the chat alias with `owned_by` equal to `simulation`, with no `owned_by`, or not at all. The query process reads the assistants, the chat alias and the policy from the definitions document mounted as a file (`--definitions-file`). A person sees it this way: the check `go vet and go test — products/cortex` is green on the pull request, and `TestModelsRoute`, `TestChatRoute`, `TestTiers` and `TestChatAndOwners` pass.

## 3. The model (the law)
1. `GET /v1/models` answers 200 `{"object": "list", "data": [...]}` with one object `{"id": <assistant id>, "object": "model", "created": 0, "owned_by": "cortex"}` per assistant whose `users` contain one of the caller's principals, in the order of the definitions. An empty list is `"data": []`.
2. `POST /v1/chat/completions` reads a JSON body of at most 1 MiB: `model` (the assistant id), `messages` (role `system`, `user` or `assistant`; content a string or a list of parts of type `text`), `stream`, `tools` and `functions`; other fields are ignored. It decides in this order: a body that is not one JSON object, or a content that is neither form, is 400 `invalid-request`; a non-null `tools` or `functions` is 400 `tools-not-supported`; no message, a last message whose role is not `user`, or another role is 400 `invalid-request`; an assistant that does not exist or that none of the caller's principals may use is 404 `assistant-not-found`; then the residency check of item 3; then the search and the generation.
3. Residency: when `policy.allowExternalModels` is not true, the query process reads the gateway's `GET <base>/models` and refuses with 409 `external-models-not-allowed` when the chat alias is listed with `owned_by` `simulation`, with no `owned_by`, or is not listed. Any other `owned_by` is inside the Sovereign. With `allowExternalModels: true` no check is made.
4. Tiers: the search runs over the assistant's sources that the caller may read (`ReadableSources` of the store), tier by tier: `primary` first; `secondary` only when the primary sources gave fewer than `topK` passages, to fill up to `topK`; `fallback` only when the other two gave none. Each search is the trimmed search of `POST /v1/search` with the assistant's `retrieval.rerank`. The query is the text of the last user message, trimmed, at most 2000 characters.
5. The generation sends to the chat alias one system message, the assistant's `instructions`, an empty line, `Passages:` and each passage as `[n] <title>` and its text (or ` none was found.` when there is none), followed by the request's messages unchanged. The answer is the gateway's first choice.
6. A plain answer is 200 `{"id", "object": "chat.completion", "created", "model": <assistant id>, "choices": [{"index": 0, "message": {"role": "assistant", "content"}, "finish_reason"}], "usage", "citations": [{"index", "documentId", "title", "uri", "page"}]}`, where citation `index` n is the passage `[n]` of the prompt. A streamed answer is `text/event-stream`: one chunk with the whole text, one last chunk with the finish reason, the usage and the citations, then `data: [DONE]`.
7. The gateway's 429 is 429 `rate-limited` with the gateway's `Retry-After`; another failure of the gateway or of the search's embedding is 503 `gateway-unavailable`. No log line holds the text of a message.
8. The definitions file: `models.chat.alias` is required; `assistants` holds at most 200 entries, each with an id of the form `^[a-z][a-z0-9-]{1,40}$` that occurs once, a title of 1 to 120 characters, instructions of at most 8000 characters, at least one source with a tier of `primary` (the default), `secondary` or `fallback`, `retrieval.topK` 1 to 50 (default 8), `retrieval.rerank` (default true) and users of the form of `access.readers`. A version that breaks a rule is refused whole; the file is read on each call and parsed again only when it changed, and a refused version leaves the last valid one in use. `cortex query` does not start (exit code 2) without `--definitions-file` or with a first version that is refused.
9. The gateway client gains `Chat` (`POST <base>/chat/completions`, not streamed) and `Owners` (`GET <base>/models`, the `owned_by` of each alias), and a 429 of any route returns a `*RateLimited` that carries `Retry-After` and still wraps `ErrUnavailable`.

// Source is one source of an assistant and its tier.
type Source struct{ ID, Tier string }

// Assistant is one entry of assistants, with the schema's defaults applied.

// Parse returns the Config of a definitions document. It refuses the whole document on the first
// entry that breaks a rule of the schema.
func Parse(doc []byte) (Config, error) {
	j, err := yaml.YAMLToJSON(doc)
	if err != nil {
		return Config{}, fmt.Errorf("assistants: not YAML: %w", err)
	}
	var d struct {
		Models struct {
			Chat struct{ Alias string } `json:"chat"`
		} `json:"models"`
		Policy struct {
			AllowExternalModels bool `json:"allowExternalModels"`
		} `json:"policy"`
		Assistants []struct {
			ID, Title, Instructions string
			Sources                 []struct{ ID, Tier string }
			Retrieval               struct {
				TopK   *int  `json:"topK"`
				Rerank *bool `json:"rerank"`
			}
			Users []string
		} `json:"assistants"`
	}
	if err := json.Unmarshal(j, &d); err != nil {
		return Config{}, fmt.Errorf("assistants: %w", err)
	}
	cfg := Config{ChatAlias: d.Models.Chat.Alias, AllowExternalModels: d.Policy.AllowExternalModels}
	if cfg.ChatAlias == "" || len(d.Assistants) > 200 {
		return Config{}, errors.New("assistants: models.chat.alias is missing or there are more than 200 assistants")
	}
	for i, e := range d.Assistants {
		a := Assistant{ID: e.ID, Title: e.Title, Instructions: e.Instructions, TopK: 8, Rerank: true, Users: e.Users}
		if e.Retrieval.TopK != nil {
			a.TopK = *e.Retrieval.TopK
		}
		if e.Retrieval.Rerank != nil {
			a.Rerank = *e.Retrieval.Rerank
		}
		n := utf8.RuneCountInString(a.Title)
		bad := !idForm.MatchString(a.ID) || slices.ContainsFunc(cfg.Assistants, func(b Assistant) bool { return b.ID == a.ID }) ||
			n < 1 || n > 120 || utf8.RuneCountInString(a.Instructions) > 8000 || len(e.Sources) == 0 || a.TopK < 1 || a.TopK > 50
		for _, s := range e.Sources {
			if s.Tier == "" {
				s.Tier = "primary"
			}
			bad = bad || s.ID == "" || !slices.Contains(tiers, s.Tier)
			a.Sources = append(a.Sources, Source{s.ID, s.Tier})
		}
		for _, u := range a.Users {
			bad = bad || !userForm.MatchString(u)
		}
		if bad {
			return Config{}, fmt.Errorf("assistants[%d] %q breaks a rule of the schema (id, title, instructions, sources, tier, topK or users)", i, a.ID)
		}

	}
	return cfg, nil

// File is the definitions document mounted as a file.
type File struct {
	Path string
	Log  *slog.Logger // one line for each version refused after a valid one; nil: none

	mu  sync.Mutex
	raw []byte
	cfg *Config
}

// Config returns the newest valid version of the file. It fails only while no version was valid.
func (f *File) Config() (Config, error) {
	raw, err := os.ReadFile(f.Path)
	f.mu.Lock()
	defer f.mu.Unlock()
	if err == nil && f.cfg != nil && bytes.Equal(raw, f.raw) {
		return *f.cfg, nil
	}
	var cfg Config
	if err == nil {
		f.raw = raw
		cfg, err = Parse(raw)
	}
	switch {
	case err == nil:
		f.cfg = &cfg
	case f.cfg == nil:
		return Config{}, err
	case f.Log != nil:
		f.Log.Warn("assistants: the definitions file was refused; the last valid version stays", "error", err.Error())
	}
	return *f.cfg, nil
}

// Gateway is the part of the model gateway an answer uses; *gateway.Client is one.
type Gateway interface {
	Chat(ctx context.Context, alias string, messages []gateway.Message) (gateway.Completion, error)
	Owners(ctx context.Context) (map[string]string, error)
}

// Service answers with the assistants of Config. Search runs every retrieval.
type Service struct {
	Config  func() (Config, error)
	Search  *search.Service
	Gateway Gateway
}

func (a Assistant) usedBy(principals []string) bool {
	return slices.ContainsFunc(a.Users, func(u string) bool { return slices.Contains(principals, u) })
}

// Usable returns the assistants that one of the principals may use, in the order of the definitions.
func (s *Service) Usable(principals []string) ([]Assistant, error) {
	cfg, err := s.Config()
	if err != nil {
		return nil, err
	}
	out := []Assistant{}
	for _, a := range cfg.Assistants {
		if a.usedBy(principals) {
			out = append(out, a)
		}
	}
	return out, nil
}

// Citation names the passage [Index] of the prompt an answer was given.
type Citation struct {

	DocumentID string `json:"documentId"`

// Answer asks the assistant id for the principals. The last message is the user's question and
// the text of the retrieval; the assistant's instructions and the passages go first, as a system
// message. An assistant that does not exist or that none of the principals may use is ErrNotFound.
func (s *Service) Answer(ctx context.Context, principals []string, id string, messages []gateway.Message) (Answer, error) {
	if len(messages) == 0 || messages[len(messages)-1].Role != "user" ||
		slices.ContainsFunc(messages, func(m gateway.Message) bool { return !slices.Contains([]string{"system", "user", "assistant"}, m.Role) }) {
		return Answer{}, ErrInvalid
	}
	cfg, err := s.Config()
	if err != nil {
		return Answer{}, err
	}
	i := slices.IndexFunc(cfg.Assistants, func(a Assistant) bool { return a.ID == id && a.usedBy(principals) })
	if i < 0 {
		return Answer{}, ErrNotFound
	}
	if !cfg.AllowExternalModels {
		owners, err := s.Gateway.Owners(ctx)
		if err != nil {
			return Answer{}, err
		}
		if o := owners[cfg.ChatAlias]; o == "" || o == "simulation" {
			return Answer{}, ErrExternal
		}
	}
	query := []rune(strings.TrimSpace(messages[len(messages)-1].Content))
	hits, err := s.retrieve(ctx, principals, cfg.Assistants[i], string(query[:min(len(query), search.MaxQuery)]))
	if err != nil {
		return Answer{}, err
	}
	prompt := cfg.Assistants[i].Instructions + "\n\nPassages:"
	cites := make([]Citation, 0, len(hits))
	for n, h := range hits {
		prompt += "\n\n[" + fmt.Sprint(n+1) + "] " + h.Title + "\n" + h.Chunk.Text
		cites = append(cites, Citation{n + 1, h.DocumentID, h.Title, h.URI, h.Chunk.Page})
	}
	if len(hits) == 0 {
		prompt += " none was found."
	}

// retrieve searches the tiers in order, each over its sources that the principals may read: the
// secondary sources only when the primary ones gave fewer than topK passages, to fill up to topK,
// and the fallback sources only when the other two gave none.
func (s *Service) retrieve(ctx context.Context, principals []string, a Assistant, query string) ([]search.Result, error) {
	readable, err := s.Search.Store.ReadableSources(ctx, principals)
	if err != nil {
		return nil, err
	}
	out := []search.Result{}
	for _, tier := range tiers {
		if (tier == "secondary" && len(out) >= a.TopK) || (tier == "fallback" && len(out) > 0) {
			break
		}
		var ids []string
		for _, src := range a.Sources {
			if src.Tier == tier && slices.Contains(readable, src.ID) && !slices.Contains(ids, src.ID) {
				ids = append(ids, src.ID)
			}
		}
		if len(ids) == 0 {
			continue
		}
		n := a.TopK - len(out)
		found, err := s.Search.Search(ctx, principals, search.Request{Query: query, Sources: ids, TopK: &n, Rerank: &a.Rerank})
		if err != nil {
			return nil, err
		}
		out = append(out, found...)
	}
	return out, nil
}

// chatRequest is the part of an OpenAI chat request that cortex reads; other fields are ignored.
type chatRequest struct {
	Model    string `json:"model"`
	Messages []struct {
		Role    string          `json:"role"`
		Content json.RawMessage `json:"content"`
	} `json:"messages"`
	Stream    bool            `json:"stream"`
	Tools     json.RawMessage `json:"tools"`
	Functions json.RawMessage `json:"functions"`
}

func (s *Server) chat(w http.ResponseWriter, r *http.Request, c auth.Caller) {
	var req chatRequest
	dec := json.NewDecoder(http.MaxBytesReader(w, r.Body, maxChat))
	if err := dec.Decode(&req); err != nil || !errors.Is(dec.Decode(new(json.RawMessage)), io.EOF) {
		writeError(w, http.StatusBadRequest, "invalid-request")
		return
	}
	if (len(req.Tools) > 0 && string(req.Tools) != "null") || (len(req.Functions) > 0 && string(req.Functions) != "null") {
		writeError(w, http.StatusBadRequest, "tools-not-supported")
		return
	}
	msgs := make([]gateway.Message, 0, len(req.Messages))
	for _, m := range req.Messages {
		text, ok := contentText(m.Content)
		if !ok {
			writeError(w, http.StatusBadRequest, "invalid-request")
			return
		}
		msgs = append(msgs, gateway.Message{Role: m.Role, Content: text})
	}
	a, err := s.cfg.Assistant.Answer(r.Context(), c.Principals, req.Model, msgs)
	var limited *gateway.RateLimited
	switch {
	case errors.As(err, &limited):
		if limited.RetryAfter != "" {
			w.Header().Set("Retry-After", limited.RetryAfter)
		}
		writeError(w, http.StatusTooManyRequests, "rate-limited")
	case errors.Is(err, assistant.ErrInvalid), errors.Is(err, search.ErrInvalid):
		writeError(w, http.StatusBadRequest, "invalid-request")
	case errors.Is(err, assistant.ErrNotFound):
		writeError(w, http.StatusNotFound, "assistant-not-found")
	case errors.Is(err, assistant.ErrExternal):
		writeError(w, http.StatusConflict, "external-models-not-allowed")
	case errors.Is(err, gateway.ErrUnavailable), errors.Is(err, search.ErrUnavailable):
		s.cfg.Log.Warn("chat: the gateway failed", "error", err.Error())
		writeError(w, http.StatusServiceUnavailable, "gateway-unavailable")
	case err != nil:
		s.cfg.Log.Error("chat failed", "error", err.Error())
		writeError(w, http.StatusInternalServerError, "internal")
	case req.Stream:
		w.Header().Set("Content-Type", "text/event-stream")
		w.Header().Set("Cache-Control", "no-cache")
		for _, f := range []map[string]any{
			{"choices": []map[string]any{{"index": 0, "delta": map[string]string{"role": "assistant", "content": a.Content}, "finish_reason": nil}}},
			{"choices": []map[string]any{{"index": 0, "delta": map[string]string{}, "finish_reason": a.FinishReason}}, "usage": a.Usage, "citations": a.Citations},
		} {
			f["id"], f["object"], f["created"], f["model"] = a.ID, "chat.completion.chunk", a.Created, req.Model
			b, _ := json.Marshal(f)
			_, _ = fmt.Fprintf(w, "data: %s\n\n", b)
		}
		_, _ = io.WriteString(w, "data: [DONE]\n\n")
	default:
		choice := map[string]any{"index": 0, "message": map[string]string{"role": "assistant", "content": a.Content}, "finish_reason": a.FinishReason}
		writeJSON(w, http.StatusOK, map[string]any{"id": a.ID, "object": "chat.completion", "created": a.Created, "model": req.Model,
			"choices": []map[string]any{choice}, "usage": a.Usage, "citations": a.Citations})
	}
}

// contentText reads the content of a message: a string, or a list of text parts.
func contentText(raw json.RawMessage) (string, bool) {
	var text string
	if json.Unmarshal(raw, &text) == nil {
		return text, true
	}
	var parts []struct{ Type, Text string }
	if json.Unmarshal(raw, &parts) != nil {
		return "", false
	}
	var b strings.Builder
	for _, p := range parts {
		if p.Type != "text" {
			return "", false
		}
		b.WriteString(p.Text)
	}
	return b.String(), true
}
