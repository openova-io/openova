# FND-173 — Remove the unimported type mirror

## In plain words

**The problem today.** The Go types of Application and Blueprint exist twice. One copy is compiled into the controllers. The other copy is imported by nothing and has fallen behind the first, and the project instructions still tell authors to add new types to it.

**What changes.** The copy that nothing imports is deleted. The project instructions name the compiled copy as the one place for these types.

**Done means:**

- The folder of the unused copy is gone from the repository.
- The controllers still build from the copy they have always used.
- The project instructions send authors to the compiled copy and no longer name the deleted folder.
- The list of deleted paths holds the folder, so a pull request that brings it back turns red.
- The list of Go modules that no pull request tests no longer names the two deleted modules.

The rest of this ticket is the exact instruction for the model that does the work.
