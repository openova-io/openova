# NET-013 — The gate dials the API port from an address in no list

## In plain words

**The problem today.** A new Sovereign opens its Kubernetes API port only to listed addresses. Nothing proves that from outside. The gate runs on a machine that is in a list, so it always gets an answer and cannot see a closed port. A check that cannot fail proves nothing.

**What changes.** Every gate run first tries the API port of each control-plane address from a second machine: a runner hosted by GitHub, whose address is in no list. A new required gate check fails unless every address gave no answer there and answered from the gate runner.

**Done means:**

- Every gate run tries the Kubernetes API port of every control-plane address from a runner hosted by GitHub, before the suite starts.
- That runner holds no credential of the environment.
- The gate check passes only when every control-plane address gave no answer to that runner and answered the gate runner.
- The check fails when the port answered or refused from outside, when an address was not tried from outside, and when the run was given no outcome at all.
- The check is required from now on, so a gate run on an environment whose API port is open to every address fails.
- A pull request never starts the two new jobs. It runs the unit tests of the suite and the self-test of the new tool.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A gate run proves from outside that the Kubernetes API port of a Sovereign is closed to the world. The gate workflow `.github/workflows/foundation-gate.yaml` has two new jobs. The job `addresses` runs on the gate runner and reads the public addresses of the control-plane nodes of every region. The job `outside` runs on a runner hosted by GitHub. The address of that runner is in no list of the Sovereign's firewall, and the job holds no credential. It opens a TCP connection to port 6443 of each address and prints what happened. The job `live` gives that line to the suite as `ACCEPT_API_PORT_OUTSIDE`. The suite has the new gate check NET-G02 "API port limited", in state `required`. It passes only when every control-plane address is `timeout` from outside and answers on 6443 from the machine that runs the suite. It fails when the run was given no outcome.

## 3. The model (the law)
1. **The value.** The flag `--api-port-outside` (variable `ACCEPT_API_PORT_OUTSIDE`) is one line: `<address>=<outcome>,<address>=<outcome>`. An address is an IP address, version 4 or 6, without a port, and is given once. An outcome is one of `open`, `timeout`, `refused`, `error`, in lower case. Spaces around an item, an address and an outcome are ignored. The suite keeps an address in the form that Go's `net.IP` prints.
2. **An empty value** means the run did not say. Every step of NET-G02 then fails with `the run was not given the outcome of the dial from outside (--api-port-outside)`.
3. **A value in another form stops the run** before anything runs: `Execute` returns an error that starts with `--api-port-outside: `, and the program exits with code 3. This is what `--nodes-requested` does.
4. **The record is not changed.** The value is no field of the record. What it said is in the evidence of the steps of NET-G02. `scripts/acceptance-gate.py` and `internal/suite/result.go` are not changed.
5. **Gate check NET-G02** is one file, `tests/acceptance/sovereign/internal/suite/check_api_port.go`, that calls `RegisterCheck` in `init()`. It records one step per region, `NET-G02.1` and `NET-G02.2`. A step reads the `ExternalIP` addresses of the nodes with the label `catalyst.openova.io/role=control-plane`, as check NET-G01 does. For each address:
   - a TCP connection to port 6443 from the machine that runs the suite must be accepted. This is the control: the address is alive, so a time-out from outside is the firewall. Any other result fails with `<address>:6443 is <result> from here, so a time-out from outside proves nothing`;
   - the value must name the address. If not, the step fails with `<address>:6443 was not dialled from outside`;
   - the outcome from outside must be `timeout`. `open`, `refused` and `error` fail with `<address>:6443 is <outcome> from outside`.
6. A region without a control-plane `ExternalIP` address fails its step. An address of the value that is no control-plane address is not judged.
7. **The evidence of a step**: `addresses` (the control-plane addresses, sorted), `from_here` (address to the result of the control) and `from_outside` (address to the outcome of the value).
8. The check uses the dialer, the result names, the role label and the port number of check NET-G01 (`peerPortsDial`, `peerPortsOutcome`, `peerPortsRoleLabel`, `peerPortsControlPort` in `check_peer_ports.go`). It does not change that file.
9. **The tool** `scripts/gate-outside-dial.py` has three uses.
   - `addresses <nodes.json> [<nodes.json> ...]`: each file is the output of `kubectl get nodes -o json` of one region. It prints the control-plane `ExternalIP` addresses of all files on one line, sorted, each once, joined by commas. A file without such an address, a file that cannot be read and an address that is no IP address end it with exit code 2.
   - `dial <address>,<address>,...`: it opens a TCP connection to port 6443 of each address, with a limit of 5 seconds, and prints the value of rule 1 on one line, in the order given. An address is dialled up to three times; the outcome is `timeout` only when all three attempts timed out, and the first other result ends the attempts. An accepted connection is `open`, a refused one is `refused`, every other error is `error`. An empty list, an address given twice and a text that is no IP address end it with exit code 2. It does not judge: an open port is exit code 0.
   - `--self-test`: 19 cases, with no connection that leaves the machine.
10. **The workflow.** `.github/workflows/foundation-gate.yaml` gets:
    - the job `addresses`: `needs: [unit, candidate]`, the same `if` as the job `live` (never on a pull request or a merge group), `runs-on: ${{ inputs.runner }}`, `environment: gate`, `permissions: contents: read`. It writes the two kubeconfigs from the secrets `ACCEPTANCE_KUBECONFIG_A` and `ACCEPTANCE_KUBECONFIG_B`, reads the nodes of both regions, runs the tool with `addresses` and gives the line as its output `list`;
    - the job `outside`: `needs: [addresses]`, `runs-on: ubuntu-latest`, no environment, no secret, `permissions: contents: read`. It runs the tool with `dial` on the output `list` and gives the line as its output `outcome`;
    - in the job `live`: `needs: [unit, candidate, outside]`, and the step with the id `run` passes `ACCEPT_API_PORT_OUTSIDE: ${{ needs.outside.outputs.outcome }}`;
    - in the job `unit`: one more step, `python3 scripts/gate-outside-dial.py --self-test`;
    - in the path list of the trigger `pull_request`: `scripts/gate-outside-dial.py`;
    - seven comment lines at the top that describe the two jobs.
11. Nothing else in the workflow changes: the inputs, the secrets, the `if` of the job `live`, its permissions and every other step stay as they are. When the job `addresses` fails, the job `outside` does not run, the job `live` still runs (its `if` starts with `!cancelled()`), the value is empty, and NET-G02 fails. The check never passes on nothing.
12. **The manifest.** In `docs/ledger/gates.yaml` the entry NET-G02 moves from `state: not-built` to `state: required` and gains the line `implementation: tests/acceptance/sovereign/internal/suite/check_api_port.go`. No other line of the file changes.
13. The flag row of `tests/acceptance/sovereign/README.md` is added. The table of checks in that file has no row of area NET and gets none.
14. This ticket deletes no file and no behaviour.

// Check NET-G02, API port limited: port 6443 of every control-plane address
// answers only the sources that the firewall of the Sovereign lists.
//
// The suite runs on the gate runner, and the firewall lists that machine: it
// could not read the clusters otherwise. So the suite cannot see a closed
// port by itself. The gate workflow dials port 6443 of every control-plane
// address from a second machine, a runner hosted by GitHub whose address is
// in no list, and gives the outcome to the run as --api-port-outside:
// "<address>=<outcome>,<address>=<outcome>", where an outcome is open,
// timeout, refused or error (scripts/gate-outside-dial.py writes it).
//
// The addresses are the ExternalIP addresses of the nodes with the label
// catalyst.openova.io/role=control-plane, as check NET-G01 reads them. For
// each address of each region:
//
//   - a TCP connection to port 6443 from here is accepted. This is the
//     control: the address is alive, so a time-out from outside is the
//     firewall and not an address that nothing listens on;
//   - the outcome from outside is timeout. An address that was not dialled
//     from outside fails, and so does every other outcome: open and refused
//     mean that the packet got through the firewall.
//
// A run that was not given --api-port-outside fails the check, and so does a
// region without a control-plane address. It never passes on nothing.
const apiPortID = "NET-G02"

// apiPortOutcomes are the outcomes that --api-port-outside may name.
var apiPortOutcomes = map[string]bool{"open": true, "timeout": true, "refused": true, "error": true}

type apiPortCheck struct{}

func init() { RegisterCheck(apiPortCheck{}) }

func (apiPortCheck) ID() string { return apiPortID }

func (apiPortCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
	for i, region := range cc.Regions {
		name := "port 6443 of the control-plane addresses of region " + region.ID + " answers here and times out from outside"
		rec.Step(apiPortID+"."+strconv.Itoa(i+1), name, func(ev Evidence) error {
			if cc.Deploy == nil || cc.Deploy.APIPortOutside == nil {
				return errors.New("the run was not given the outcome of the dial from outside (--api-port-outside)")
			}
			nodes, err := region.GetList(ctx, "nodes", "")
			if err != nil {
				return err
			}
			seen := map[string]bool{}
			addresses := []string{}
			for _, node := range nodes {
				if node.Str("metadata", "labels", peerPortsRoleLabel) != "control-plane" {
					continue
				}
				for _, a := range node.Objects("status", "addresses") {
					if ip := a.Str("address"); a.Str("type") == "ExternalIP" && ip != "" && !seen[ip] {
						seen[ip] = true
						addresses = append(addresses, ip)
					}
				}
			}
			sort.Strings(addresses)
			ev["addresses"] = addresses
			if len(addresses) == 0 {
				return fmt.Errorf("no control-plane node of region %s has an ExternalIP address", region.ID)
			}
			here, outside := map[string]string{}, map[string]string{}
			failures := []string{}
			for _, ip := range addresses {
				target := net.JoinHostPort(ip, strconv.Itoa(peerPortsControlPort))
				here[ip] = peerPortsOutcome(peerPortsDial(ctx, target))
				if here[ip] != "open" {
					failures = append(failures, fmt.Sprintf("%s is %s from here, so a time-out from outside proves nothing", target, here[ip]))
				}
				key := ip
				if parsed := net.ParseIP(ip); parsed != nil {
					key = parsed.String() // the form parseAPIPortOutside keeps
				}
				outcome, dialled := cc.Deploy.APIPortOutside[key]
				if !dialled {
					failures = append(failures, target+" was not dialled from outside")
					continue
				}
				outside[ip] = outcome
				if outcome != "timeout" {
					failures = append(failures, fmt.Sprintf("%s is %s from outside", target, outcome))
				}
			}
			ev["from_here"], ev["from_outside"] = here, outside
			if len(failures) > 0 {
				return fmt.Errorf("region %s: %v", region.ID, failures)
			}
			return nil
		})
	}
	return nil
}

// parseAPIPortOutside reads the value of --api-port-outside:
// "<address>=<outcome>,<address>=<outcome>". An address is an IP address and
// is given once; an outcome is one of apiPortOutcomes. The addresses are kept
// in the form net.IP prints. It returns nil for an empty value: the run did
// not say.
func parseAPIPortOutside(s string) (map[string]string, error) {
	parts := splitList(s)
	if len(parts) == 0 {
		return nil, nil
	}
	out := map[string]string{}
	for _, part := range parts {
		address, outcome, found := strings.Cut(part, "=")
		ip := net.ParseIP(strings.TrimSpace(address))
		outcome = strings.TrimSpace(outcome)
		if !found || ip == nil || !apiPortOutcomes[outcome] {
			return nil, fmt.Errorf("--api-port-outside: %q is not <address>=<outcome> with an outcome of open, timeout, refused or error", part)
		}
		if _, twice := out[ip.String()]; twice {
			return nil, fmt.Errorf("--api-port-outside: address %s is named twice", ip)
		}
		out[ip.String()] = outcome
	}
	return out, nil
}
