# AIP-042 — Check AIP-G01 judges running containers only

## In plain words

**The problem today.** The gate check that proves the header-trusting metering sidecar is gone fails a region when any Pod in its Pod list names the sidecar image. An evicted Pod stays in that list in phase Failed until someone deletes it, although it runs nothing. The first gate run on the environment failed for exactly such a Pod, eight days old, while the gateway ran without the sidecar.

**What changes.** The check skips a Pod that has ended (phase Failed or Succeeded) and counts how many it skipped. Every other Pod is judged as before, a Pending one and one of unknown phase too.

**Done means:**

- A Pod in phase Failed or Succeeded whose spec names the metering-sidecar image does not fail check AIP-G01.
- A Pod in phase Running, Pending or Unknown, or with no phase, that names the image still fails the check.
- A region whose every Pod has ended fails the check as unmeasured; it is never a pass.
- The evidence of each region step counts the Pods that were skipped because they had ended.
- The tests of the check prove each rule: they fail when the check judges ended Pods, and they fail when it skips Pods that may still run.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Gate check AIP-G01 "No header-trusting meter" (`tests/acceptance/sovereign/internal/suite/check_aip_g01.go`) fails a region only for a metering-sidecar image in a Pod that has not ended. A Pod in phase `Failed` or `Succeeded` runs no container and is skipped; it is counted in the step's evidence as `ended`. A Pod in any other phase is judged as today: `Pending` (its containers are about to run), `Running`, `Unknown` (the node does not answer, so a container may still run) and a Pod with no phase. Everything else the check does stays: every container list is judged, the text matches anywhere in the image reference, a region with nothing measured fails, a run with no region fails.

## 3. The model (the law)
1. In `check_aip_g01.go` a Pod is skipped when, and only when, its `status.phase` is `Failed` or `Succeeded`. These two phases are the map `meterEndedPhases`. No other phase is skipped, and an empty phase is judged.
2. The containers of a skipped Pod are not counted in `images`. So a region whose every Pod has ended has `images` 0 and fails with the existing message `no container was found in region <id>: nothing was measured`.
3. The evidence of a region step holds `pods` (every Pod listed, skipped or not, as today), `ended` (the Pods skipped), `images` and `found`. The step identifiers `AIP-G01.<n>`, the step name and both failure messages do not change.
4. The test file `check_aip_g01_test.go` keeps its eight scenarios, its evidence assertions and its no-region case unchanged. It adds: only ended Pods hold the sidecar (pass; the measured case, an evicted Pod in phase `Failed`, and a `Succeeded` Pod with the image in an init container); a `Running`, a `Pending` and an `Unknown` Pod with the image (each fails); a region whose only Pod has ended (fails as unmeasured); and an evidence assertion for the ended Pods (`pods` 3, `ended` 2, `images` 1, `found` empty).
5. Nothing else changes: not the manifest entry of AIP-G01 in `docs/ledger/gates.yaml`, not another file of the suite, not a `go.mod` or `go.sum`.

package suite

import (
	"context"

// Check AIP-G01, No header-trusting meter: no Pod that has not ended, in any
// namespace of any region, has a container whose image reference holds the text
// meterImageText. The metering sidecar of bp-newapi took the customer and
// the Organization of a model call from two request headers that any caller
// can set, so its usage records could be charged to anyone. It is switched
// off since AIP-040.
//
// The rule matches the text anywhere in the image reference, not only the
// last path segment: the image is named services-metering-sidecar, and after a
// hand-over the registry host changes while the name does not. Every
// container of a Pod is judged: its init containers, its containers and its
// ephemeral containers. A region whose Pods hold no container fails: nothing
// was measured, and that is never a pass.
//
// Only a Pod that has not ended is judged. A Pod in phase Failed or Succeeded
// (meterEndedPhases) runs no container: an evicted Pod stays in the list in
// phase Failed until it is deleted, and it would fail the check for a sidecar
// that runs nowhere. Every other phase is judged, an empty one too: Pending
// (the container is about to run), Running, and Unknown (the node does not
// answer, so the container may still run). The containers of an ended Pod are
// not counted, so a region whose every Pod has ended fails as unmeasured.
const meterImageID = "AIP-G01"

// meterImageText is the text that no image reference of a Pod may hold.
const meterImageText = "metering-sidecar"

// meterContainerLists are the lists of a Pod spec that hold containers.
var meterContainerLists = []string{"initContainers", "containers", "ephemeralContainers"}

// meterEndedPhases are the phases of a Pod whose containers have all stopped
// for good.
var meterEndedPhases = map[string]bool{"Failed": true, "Succeeded": true}

type meterImageCheck struct{}

func init() { RegisterCheck(meterImageCheck{}) }

func (meterImageCheck) ID() string { return meterImageID }

func (meterImageCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
	if len(cc.Regions) == 0 {
		return errors.New("the run has no region")
	}
	for i, region := range cc.Regions {
		rec.Step(meterImageID+"."+strconv.Itoa(i+1), "no container runs a metering-sidecar image in region "+region.ID, func(ev Evidence) error {
			pods, err := region.GetList(ctx, "pods", "")
			if err != nil {
				return err
			}
			images, ended, found := 0, 0, []string{}
			for _, pod := range pods {
				if meterEndedPhases[pod.Str("status", "phase")] {
					ended++
					continue
				}
				for _, list := range meterContainerLists {
					for _, c := range pod.Objects("spec", list) {
						images++
						if ref := c.Str("image"); strings.Contains(ref, meterImageText) {
							found = append(found, pod.Namespace()+"/"+pod.Name()+"/"+c.Str("name")+" "+ref)
						}
					}
				}
			}
			sort.Strings(found)
			ev["pods"], ev["ended"], ev["images"], ev["found"] = len(pods), ended, images, found
			switch {
			case images == 0:
				return fmt.Errorf("no container was found in region %s: nothing was measured", region.ID)
			case len(found) > 0:
				return fmt.Errorf("%d containers in region %s run an image whose name holds %q: %s",
					len(found), region.ID, meterImageText, strings.Join(found, "; "))
			}
			return nil
		})
	}
	return nil
}
