## 2. End goal
The folder `products/ops-records` is a new Go module, `github.com/openova-io/openova/products/ops-records`, with no dependency outside the Go standard library. It holds three packages: `internal/ids` makes the identifiers of the records (ULIDs, with the prefixes `INC-` and `PRB-`); `internal/health` serves `GET /healthz` and `GET /readyz`; `internal/store` defines the seven record tables of the schema `ops` as Go types, the `Store` interface with its rules, the in-memory store `Memory`, and the contract test that every store of the package runs. The workflow `.github/workflows/test-ungated-trees.yaml` runs `go test` in the module on every pull request that changes it, and the generated inventory `docs/generated/components.md` lists the folder. A person can observe this on the pull request: the check `go test — products/ops-records` runs and passes. This is the first part of the operations-records service. The PostgreSQL store, its migration and the program come with AIP-229, which runs the same contract test against PostgreSQL. The title of this package names the schema and its migrations: in this package the schema is the set of Go record types of `internal/store`, and no migration file is written.

## 3. The model (the law)
1. The module path is `github.com/openova-io/openova/products/ops-records`, the `go` line is `go 1.24`, and the module has no `require` line and no `go.sum`.
2. Every identifier is a ULID: 26 characters of Crockford base 32, time in milliseconds first, 80 random bits after. Identifiers from one generator always rise. An incident identifier is `INC-` and a ULID, a problem identifier `PRB-` and a ULID. Signals, judgements and outbox rows carry the ULID alone. Timeline entries and feedback get a rising number from the store.
3. The store has seven tables of the schema `ops`: `signals`, `incidents`, `incident_events`, `problems`, `judgements`, `feedback`, `outbox`. The table `change_links` is not part of this module yet. Every row carries a non-empty Organization slug. A read with an empty Organization reads every Organization (the sovereign-admin); a non-empty one reads that Organization only, and a row of another Organization is reported as not found.
4. The values of the fixed fields are: signal source `alert`, `security`, `access`; signal state `open`, `cleared`; incident state `open`, `mitigated`, `resolved`; severity 1 (most urgent) to 4; `severity_set_by` `rules`, `agent`, `person`; `opened_by` `rules`, `agent`; timeline actor kind `rules`, `agent`, `person`, `system`; problem state `open`, `known`, `closed`; judgement outcome `applied`, `rejected_invalid`, `late_applied`, `late_rejected`, `timeout`, `unavailable`, or empty while the judgement waits; feedback kind `merge`, `detach`, `severity`, `not_related`. An outbox subject has the form `catalyst.<domain>.<event>.v<major>`.
5. Every write happens inside `Store.InTx`. When its function returns an error or panics, nothing it wrote is kept. An outbox row is written only inside a transaction, so it is always written in the same transaction as the business row it reports. `PendingOutbox` returns the unpublished rows in the order they were enqueued; `MarkPublished` records the publication once.
6. The contract test `runContract` in `internal/store/contract_test.go` is the definition of the store's behaviour. `TestMemoryContract` runs it on the in-memory store, with 21 cases. A later store adds its own test that calls `runContract`; no case is removed for it.
7. `GET /healthz` always answers 200 with the status `ok` and the version. `GET /readyz` answers 200 only when at least one check is registered and every check passes within its time limit (3 seconds by default); otherwise 503 with the status `degraded` and each check's result.
8. The workflow `.github/workflows/test-ungated-trees.yaml` names `products/ops-records/**` in both path filters (pull request and push) and `products/ops-records` in the matrix of the job `go-modules`. Nothing else in that file changes.
9. `docs/generated/components.md` is written by its generator, `scripts/generators/components.py`, never by hand. It gains exactly one line.
10. No program (`cmd/`), no chart, no Blueprint file, no Containerfile, no bootstrap-kit slot and no migration is added. Nothing installs the service.

// Package ids makes the identifiers of the operations records.
//
// Every identifier is a ULID: 26 characters of Crockford base 32. The first 10 characters hold
// the time in milliseconds since 1970 (48 bits), the last 16 hold 80 random bits. Identifiers
// made later sort later as plain strings. Within one millisecond a Generator adds one to the
// random part of the identifier before, so identifiers made by one Generator always rise.
//
// Incidents carry the prefix "INC-" and problems the prefix "PRB-". Signals, judgements and
// outbox rows carry the ULID alone.
package ids

import (
	"crypto/rand"
	"errors"
	"io"
	"strings"
	"sync"
	"time"
)

// Length is the number of characters of a ULID.
const Length = 26

// Prefixes of the identifiers that carry one.
const (
	IncidentPrefix = "INC-"
	ProblemPrefix  = "PRB-"
)

const alphabet = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"

// maxMillis is the largest time a ULID can hold: 2^48 - 1 milliseconds.
const maxMillis = 1<<48 - 1

// ErrInvalid is returned for a string that is not a ULID.
var ErrInvalid = errors.New("ids: not a ULID")

// ErrOverflow is returned when the random part cannot rise within one millisecond.
var ErrOverflow = errors.New("ids: random part overflows within one millisecond")

// Generator makes rising ULIDs. The zero value is not usable; call NewGenerator.
type Generator struct {
	mu      sync.Mutex
	now     func() time.Time
	entropy io.Reader
	last    uint64   // milliseconds of the last identifier
	random  [10]byte // random part of the last identifier
	started bool
}

// NewGenerator returns a Generator that reads the time from now and random bits from entropy.
// A nil now means time.Now; a nil entropy means crypto/rand.
func NewGenerator(now func() time.Time, entropy io.Reader) *Generator {
	if now == nil {
		now = time.Now
	}
	if entropy == nil {
		entropy = rand.Reader
	}
	return &Generator{now: now, entropy: entropy}
}

// Next returns a new ULID. It is greater than every ULID this Generator returned before,
// also when the clock stands still or steps back.
func (g *Generator) Next() (string, error) {
	g.mu.Lock()
	defer g.mu.Unlock()
	ms := g.now().UnixMilli()
	if ms < 0 || ms > maxMillis {
		return "", errors.New("ids: time out of range")
	}
	t := uint64(ms) // #nosec G115 -- checked to lie in 0..2^48-1 above
	if g.started && t <= g.last {
		// Same millisecond, or the clock stepped back: keep the last time, add one.
		for i := len(g.random) - 1; ; i-- {
			if i < 0 {
				return "", ErrOverflow
			}
			g.random[i]++
			if g.random[i] != 0 {
				break
			}
		}
		return encode(g.last, g.random), nil
	}
	var r [10]byte
	if _, err := io.ReadFull(g.entropy, r[:]); err != nil {
		return "", err
	}
	g.last, g.random, g.started = t, r, true
	return encode(t, r), nil
}

var std = NewGenerator(nil, nil)

// New returns a new ULID from the package's own Generator. It panics only when the system's
// random source fails or the clock is outside the years 1970 to 10889.
func New() string {
	id, err := std.Next()
	if err != nil {
		panic(err)
	}
	return id
}

// NewIncident returns "INC-" followed by a new ULID.
func NewIncident() string { return IncidentPrefix + New() }

// NewProblem returns "PRB-" followed by a new ULID.
func NewProblem() string { return ProblemPrefix + New() }

// Valid reports whether s is a ULID in the canonical form: 26 characters of the alphabet,
// upper case, and a first character of at most 7.
func Valid(s string) bool {
	if len(s) != Length || s[0] > '7' {
		return false
	}
	for i := 0; i < len(s); i++ {
		if strings.IndexByte(alphabet, s[i]) < 0 {
			return false
		}
	}
	return true
}

// ValidIncident reports whether s is "INC-" followed by a ULID.
func ValidIncident(s string) bool {
	return strings.HasPrefix(s, IncidentPrefix) && Valid(strings.TrimPrefix(s, IncidentPrefix))
}

// ValidProblem reports whether s is "PRB-" followed by a ULID.
func ValidProblem(s string) bool {
	return strings.HasPrefix(s, ProblemPrefix) && Valid(strings.TrimPrefix(s, ProblemPrefix))
}

// Time returns the time a ULID holds, in UTC with millisecond precision.
func Time(s string) (time.Time, error) {
	if !Valid(s) {
		return time.Time{}, ErrInvalid
	}
	var ms int64
	for i := 0; i < 10; i++ {
		ms = ms<<5 | int64(strings.IndexByte(alphabet, s[i]))
	}
	return time.UnixMilli(ms).UTC(), nil
}

// encode writes 48 bits of time and 80 bits of randomness as 26 characters, most significant
// bits first. The 128 bits are read in groups of five from the left, after two zero bits.
func encode(ms uint64, r [10]byte) string {
	var b [16]byte
	for i := 0; i < 6; i++ {
		b[i] = byte(ms >> (8 * (5 - i))) // #nosec G115 -- one byte of the 48-bit time
	}
	copy(b[6:], r[:])
	out := make([]byte, Length)
	// Bit position p counts from the left of the 130-bit string (two leading zero bits).
	for c := 0; c < Length; c++ {
		v := 0
		for k := 0; k < 5; k++ {
			p := c*5 + k - 2
			bit := 0
			if p >= 0 {
				bit = int(b[p/8]>>(7-p%8)) & 1
			}
			v = v<<1 | bit
		}
		out[c] = alphabet[v]
	}
	return string(out)
}

// Package health serves the two health routes of the operations-records service.
//
//	GET /healthz  liveness: the process is up. Always 200 {"status":"ok","version":"<version>"}.
//	GET /readyz   readiness: every check passes within its time limit.
//	              200 {"status":"ready","checks":{"<name>":"ok"}}
//	              503 {"status":"degraded","checks":{"<name>":"ok"|"<error text>"}}
//
// A check is a named function. The store's Ping is the first one; the program registers it.
// With no check registered, /readyz answers 503: a service that has checked nothing is not
// ready.
package health

import (
	"context"
	"encoding/json"
	"net/http"
	"sort"
	"sync"
	"time"
)

// DefaultTimeout is the time limit of one readiness check.
const DefaultTimeout = 3 * time.Second

// Check is one readiness check. It returns nil when the part it checks works.
type Check func(ctx context.Context) error

// Handler holds the version and the readiness checks.
type Handler struct {
	version string
	timeout time.Duration

	mu     sync.RWMutex
	checks map[string]Check
}

// New returns a Handler that reports version on /healthz and gives each check timeout.
// A timeout of zero or less means DefaultTimeout.
func New(version string, timeout time.Duration) *Handler {
	if timeout <= 0 {
		timeout = DefaultTimeout
	}
	return &Handler{version: version, timeout: timeout, checks: map[string]Check{}}
}

// Add registers a readiness check under name. A second check with the same name replaces
// the first.
func (h *Handler) Add(name string, c Check) {
	h.mu.Lock()
	defer h.mu.Unlock()
	h.checks[name] = c
}

// Register adds the two routes to mux.
func (h *Handler) Register(mux *http.ServeMux) {
	mux.HandleFunc("GET /healthz", h.Healthz)
	mux.HandleFunc("GET /readyz", h.Readyz)
}

// Healthz answers the liveness route.
func (h *Handler) Healthz(w http.ResponseWriter, _ *http.Request) {
	writeJSON(w, http.StatusOK, map[string]any{"status": "ok", "version": h.version})
}

// Readyz answers the readiness route. The checks run one after the other, in the order of
// their names, each with its own time limit.
func (h *Handler) Readyz(w http.ResponseWriter, r *http.Request) {
	h.mu.RLock()
	names := make([]string, 0, len(h.checks))
	for n := range h.checks {
		names = append(names, n)
	}
	checks := make(map[string]Check, len(h.checks))
	for n, c := range h.checks {
		checks[n] = c
	}
	h.mu.RUnlock()
	sort.Strings(names)

	results := map[string]string{}
	ready := len(names) > 0
	for _, n := range names {
		ctx, cancel := context.WithTimeout(r.Context(), h.timeout)
		err := run(ctx, checks[n])
		cancel()
		if err != nil {
			results[n] = err.Error()
			ready = false
			continue
		}
		results[n] = "ok"
	}
	if !ready {
		writeJSON(w, http.StatusServiceUnavailable, map[string]any{"status": "degraded", "checks": results})
		return
	}
	writeJSON(w, http.StatusOK, map[string]any{"status": "ready", "checks": results})
}

// run calls c and returns its error, or the context's error when c does not return in time.
func run(ctx context.Context, c Check) error {
	done := make(chan error, 1)
	go func() { done <- c(ctx) }()
	select {
	case err := <-done:
		return err
	case <-ctx.Done():
		return ctx.Err()

// Package store holds the records of the operations-records service and the interface every
// store implements.
//
// The records are seven tables of one database schema, "ops": signals, incidents,
// incident_events, problems, judgements, feedback and outbox. Every row carries the slug of
// its Organization. Two implementations satisfy the interface: the in-memory store of this
// package (memory.go) and a PostgreSQL store. Both must pass the same contract test
// (contract_test.go); the contract test is the definition of the behaviour described here.
//
// Rules every implementation keeps:
//
//   - Organization. Every row has a non-empty Organization. A read whose Organization argument
//     is empty reads every Organization (the sovereign-admin's view); a non-empty one reads
//     that Organization only. A row of another Organization is reported as ErrNotFound.
//     A write names the Organization of the row it writes.
//   - Identifiers. A signal, judgement or outbox row has a ULID; an incident "INC-" and a
//     ULID; a problem "PRB-" and a ULID (package ids). Identifiers are unique across
//     Organizations: inserting an identifier that exists returns ErrConflict. Incident events
//     and feedback get a rising number from the store; the ID given on append is ignored.
//   - References. Signal.IncidentID, Incident.ParentID, IncidentEvent.IncidentID and
//     Feedback.IncidentID name an incident, Incident.ProblemID a problem, of the same
//     Organization. A reference to a row that does not exist there returns ErrNotFound.
//     An empty optional reference means none.
//   - Values. A field with a fixed set of values (the constants below) accepts only those.
//     A row that breaks a rule of Validate is refused with an error that wraps ErrInvalid,
//     and nothing is written.
//   - JSON. A JSON field holds one valid JSON value. An empty required JSON field (Body, Data,
//     Offered, RuleResult, Payload) is stored as the object {}. An empty Answer means null.
//     Compare JSON by meaning: a store may change spacing and key order.
//   - Time. Times are kept to the microsecond and returned in UTC. A required time that is
//     zero is refused. A nil optional time means none.
//   - Copies. A row returned by the store is a copy: changing it changes nothing stored.
//   - Transactions. Every write happens inside InTx. When the function given to InTx returns
//     an error, nothing it wrote is kept. Reads inside the transaction see its writes; reads
//     outside see them only after InTx returned nil. An outbox row is written in the same
//     transaction as the business row it reports (the producer rule of the event contract).
//   - Order. Lists come in the order each method states. Rows with equal times are ordered
//     by identifier in the same direction: oldest first puts the smaller identifier first,
//     newest first puts the greater identifier first.
//     A limit of zero or less means DefaultLimit; a limit above MaxLimit means MaxLimit.
//   - Context. A call with a context that is already done returns the context's error and

// Tx is a transaction: the reads see its own writes.
type Tx interface {
	Reader
	Writer
}

// Store is one database of operations records.
type Store interface {
	Reader

	// InTx runs fn in one transaction. When fn returns nil the writes are kept; when it
	// returns an error, or panics, none is kept and InTx returns that error (or panics
	// again). tx must not be used after fn returned: its methods then return ErrTxDone.
	InTx(ctx context.Context, fn func(ctx context.Context, tx Tx) error) error

	// PendingOutbox returns up to limit outbox rows that are not published, in the order
	// they were enqueued (not the order of their identifiers or times).
	PendingOutbox(ctx context.Context, limit int) ([]OutboxRow, error)
	// MarkPublished records that the outbox row id was published at the time given. A row
	// that is published already keeps its first time. An unknown id returns ErrNotFound.
	MarkPublished(ctx context.Context, id string, at time.Time) error

	// Ping returns nil when the store can serve.
	Ping(ctx context.Context) error
	// Close releases the store. Calls after Close return an error.
	Close() error
}

// ValidateSignal returns an error wrapping ErrInvalid when s breaks a rule of a signal.
func ValidateSignal(s Signal) error {
	if err := need("organization", s.Organization, "kind", s.Kind, "entity kind", s.EntityKind,
		"entity ref", s.EntityRef, "title", s.Title, "fingerprint", s.Fingerprint); err != nil {
		return err
	}
	switch {
	case !ids.Valid(s.ID):
		return invalid("signal id %q is not a ULID", s.ID)
	case !oneOf(s.Source, SourceAlert, SourceSecurity, SourceAccess):
		return invalid("signal source %q", s.Source)
	case !oneOf(s.State, SignalOpen, SignalCleared):
		return invalid("signal state %q", s.State)
	case !severityOK(s.SeverityFloor):
		return invalid("severity floor %d", s.SeverityFloor)
	case s.FirstSeen.IsZero() || s.LastSeen.IsZero():
		return invalid("first seen and last seen are required")
	case s.LastSeen.Before(s.FirstSeen):
		return invalid("last seen is before first seen")
	case s.IncidentID != "" && !ids.ValidIncident(s.IncidentID):
		return invalid("incident id %q", s.IncidentID)
	}
	return jsonOK("body", s.Body)
}

// ValidateIncident returns an error wrapping ErrInvalid when in breaks a rule of an incident.
func ValidateIncident(in Incident) error {
	if err := need("organization", in.Organization, "title", in.Title); err != nil {
		return err
	}
	switch {
	case !ids.ValidIncident(in.ID):
		return invalid("incident id %q", in.ID)
	case !severityOK(in.Severity):
		return invalid("severity %d", in.Severity)
	case !oneOf(in.SeveritySetBy, ByRules, ByAgent, ByPerson):
		return invalid("severity set by %q", in.SeveritySetBy)
	case !oneOf(in.State, IncidentOpen, IncidentMitigated, IncidentResolved):
		return invalid("incident state %q", in.State)
	case !oneOf(in.OpenedBy, ByRules, ByAgent):
		return invalid("opened by %q", in.OpenedBy)
	case in.OpenedAt.IsZero():
		return invalid("opened at is required")
	case (in.State == IncidentResolved) != (in.ResolvedAt != nil):
		return invalid("resolved at is set exactly when the state is resolved")
	case in.ResolvedAt != nil && in.ResolvedAt.Before(in.OpenedAt):
		return invalid("resolved at is before opened at")
	case in.ParentID != "" && !ids.ValidIncident(in.ParentID):
		return invalid("parent id %q", in.ParentID)
	case in.ParentID == in.ID:
		return invalid("an incident cannot be its own parent")
	case in.ProblemID != "" && !ids.ValidProblem(in.ProblemID):
		return invalid("problem id %q", in.ProblemID)
	}
	return nil
}

// Memory is the in-memory store. It keeps the rules of the package documentation and is
// used by the tests of every package of the service. It keeps nothing after the process
// ends.
//
// A transaction holds the write lock for its whole length and works on a copy of the data;
// the copy replaces the data when the transaction's function returns nil.
type Memory struct {
	mu     sync.RWMutex
	data   *memData
	closed bool
}

type memData struct {
	signals    map[string]Signal
	incidents  map[string]Incident
	events     []IncidentEvent // in the order appended
	problems   map[string]Problem
	judgements map[string]Judgement
	feedback   []Feedback  // in the order added
	outbox     []OutboxRow // in the order enqueued
	nextEvent  int64
	nextFeed   int64
}

// NewMemory returns an empty in-memory store.
func NewMemory() *Memory {
	return &Memory{data: &memData{
		signals:    map[string]Signal{},
		incidents:  map[string]Incident{},
		problems:   map[string]Problem{},
		judgements: map[string]Judgement{},
	}}

var errClosed = errors.New("store: closed")

func (d *memData) clone() *memData {
	c := &memData{
		signals:    make(map[string]Signal, len(d.signals)),
		incidents:  make(map[string]Incident, len(d.incidents)),
		events:     make([]IncidentEvent, len(d.events)),
		problems:   make(map[string]Problem, len(d.problems)),
		judgements: make(map[string]Judgement, len(d.judgements)),
		feedback:   make([]Feedback, len(d.feedback)),
		outbox:     make([]OutboxRow, len(d.outbox)),
		nextEvent:  d.nextEvent,
		nextFeed:   d.nextFeed,
	}
	// Rows are stored in normal form, and a transaction replaces a row instead of changing
	// it, so a shallow copy of each row is safe. MarkPublished changes a row in place, but
	// only under the write lock, when no transaction holds a copy.
	for k, v := range d.signals {
		c.signals[k] = v
	}
	for k, v := range d.incidents {
		c.incidents[k] = v
	}
	for k, v := range d.problems {
		c.problems[k] = v
	}
	for k, v := range d.judgements {
		c.judgements[k] = v
	}
	copy(c.events, d.events)
	copy(c.feedback, d.feedback)
	copy(c.outbox, d.outbox)
	return c
}

// read runs fn on the committed data under the read lock.
func (m *Memory) read(ctx context.Context, fn func(d *memData) error) error {
	if err := ctx.Err(); err != nil {
		return err
	}
	m.mu.RLock()
	defer m.mu.RUnlock()
	if m.closed {
		return errClosed
	}
	return fn(m.data)
}

// InTx runs fn in one transaction.
func (m *Memory) InTx(ctx context.Context, fn func(ctx context.Context, tx Tx) error) error {
	if err := ctx.Err(); err != nil {
		return err
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	if m.closed {
		return errClosed
	}
	tx := &memTx{d: m.data.clone()}
	defer func() { tx.done = true }()
	if err := fn(ctx, tx); err != nil {
		return err
	}
	if err := ctx.Err(); err != nil {
		return err
	}
	m.data = tx.d
	return nil
}

// PendingOutbox returns unpublished outbox rows in the order they were enqueued.
func (m *Memory) PendingOutbox(ctx context.Context, limit int) ([]OutboxRow, error) {
	var out []OutboxRow
	err := m.read(ctx, func(d *memData) error {
		n := clampLimit(limit)
		for _, o := range d.outbox {
			if o.PublishedAt == nil {
				out = append(out, normOutboxRow(o))
				if len(out) == n {
					break
				}
			}
		}
		return nil
	})
	return out, err
}

// MarkPublished records the publication of one outbox row.
func (m *Memory) MarkPublished(ctx context.Context, id string, at time.Time) error {
	if err := ctx.Err(); err != nil {
		return err
	}
	if at.IsZero() {
		return invalid("published at is required")
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	if m.closed {
		return errClosed
	}
	for i := range m.data.outbox {
		if m.data.outbox[i].ID != id {
			continue
		}
		if m.data.outbox[i].PublishedAt == nil {
			t := normTime(at)
			m.data.outbox[i].PublishedAt = &t
		}
		return nil
	}
	return ErrNotFound
}

// Ping returns nil while the store is open.
func (m *Memory) Ping(ctx context.Context) error {

}

var (
	ctx  = context.Background()
	t0   = time.Date(2026, 12, 1, 9, 0, 0, 0, time.UTC)
	zone = time.FixedZone("plus4", 4*3600)
)

// at returns t0 plus n minutes.
func at(n int) time.Time { return t0.Add(time.Duration(n) * time.Minute) }

func ptr(t time.Time) *time.Time { return &t }

// canonical renders a row so that two rows with the same meaning render the same: JSON by
// meaning, times as RFC 3339 with their zone.
func canonical(t *testing.T, v any) string {
	t.Helper()
	raw, err := json.Marshal(v)
	if err != nil {
		t.Fatal(err)
	}
	var generic any
	if err := json.Unmarshal(raw, &generic); err != nil {
		t.Fatal(err)
	}
	out, err := json.Marshal(generic)
	if err != nil {
		t.Fatal(err)
	}
	return string(out)
}

func same(t *testing.T, what string, got, want any) {
	t.Helper()
	if g, w := canonical(t, got), canonical(t, want); g != w {
		t.Fatalf("%s:\n got  %s\n want %s", what, g, w)
	}
}

func is(t *testing.T, what string, err, want error) {
	t.Helper()
	if !errors.Is(err, want) {
		t.Fatalf("%s: err = %v, want %v", what, err, want)
	}
}

func ok(t *testing.T, what string, err error) {
	t.Helper()
	if err != nil {
		t.Fatalf("%s: %v", what, err)
	}
}

// write runs fn in one transaction and fails the test when it does not commit.
func write(t *testing.T, s Store, fn func(tx Tx) error) {
	t.Helper()
	ok(t, "transaction", s.InTx(ctx, func(_ context.Context, tx Tx) error { return fn(tx) }))
}

// tryWrite runs fn in one transaction and returns its error.
func tryWrite(s Store, fn func(tx Tx) error) error {
	return s.InTx(ctx, func(_ context.Context, tx Tx) error { return fn(tx) })
}

	})

	pend, err := s.PendingOutbox(ctx, 0)
	ok(t, "pending", err)

	})

func testOutbox(t *testing.T, s Store) {
