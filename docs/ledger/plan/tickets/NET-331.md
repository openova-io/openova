# NET-331 — Port 80 answers the console host

## In plain words

**The problem today.** Where the Gateways of a Sovereign bind the ports of the nodes directly, port 80 of a node belongs to the shared Gateway, and the console's own Gateway listens on the console ports instead. No route of the shared Gateway holds the console's host name, so a plain HTTP request for the console on port 80 of a node answers 404. The conformance check of the cluster class fails on it in both regions of the standing Sovereign.

**What changes.** A redirect on the port-80 listener of the shared Gateway answers a request for the console host with a permanent redirect to the console's HTTPS address. A test renders what a Sovereign runs and fails when port 80 does not answer so.

**Done means:**

- A plain HTTP request for the console host on port 80 of a gateway node is answered with a permanent redirect to https://console.<fqdn>/, in every provider pack whose Gateways bind the ports of the nodes and in every zone layout.
- The redirect is attached to the port-80 listener only, so an HTTPS request for the console on port 443 is never redirected to itself.
- The redirect names no backend Service, so it cannot break the configuration of the shared Gateway.
- No node port is created or used, and no Helm release changes.
- A test of the repository fails when the redirect is missing or attached to the wrong port, and passes with the change.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Gate check NET-G17 sends `GET http://console.<fqdn>/` to port 80 of a gateway node and wants one of 200, 301, 302, 303, 307, 308. On the standing two-region Sovereign it answered 404 in both regions on 27 November. After the change, the Flux Kustomization `sovereign-tls` (`clusters/_template/sovereign-tls`) also creates the HTTPRoute `kube-system/console-http-redirect`. It attaches to the Gateway `kube-system/cilium-gateway` by `port: 80` and answers the host `console.<fqdn>` with `301` and `Location: https://console.<fqdn>/`. The new test `tests/e2e/bootstrap-kit/console_port80_net331_test.go` renders the ConfigMap `sovereign-tls-vars` and every resource of that Kustomization for every pack that binds host ports, and three zone layouts. It resolves the answer on node port 80 and node port 443 the way Cilium 1.19.3 attaches routes. It fails on `origin/main` with `404 (no route of Gateway kube-system/cilium-gateway, listener http, port 80, ...)` and passes with the change.

## 3. The model (the law)
1. Where a pack sets `CILIUM_GATEWAY_HOSTNETWORK_ENABLED` to `"true"`, a node serves port 80 and port 443 directly on the host-network cilium-envoy, and one host port is bound by one Gateway. The shared Gateway `kube-system/cilium-gateway` holds port 80 and port 443. The console Gateway `kube-system/cilium-gateway-console` binds its listeners on `CONSOLE_GATEWAY_HTTP_PORT` and `CONSOLE_GATEWAY_HTTPS_PORT` (8080 and 8443 in every such pack).
2. The HTTPRoute `kube-system/console-http-redirect` has one parentRef: the Gateway `kube-system/cilium-gateway`, `port: 80`, no `sectionName`. The name of the port-80 listener depends on the zone layout (`http`, `http-<fqdn-dashed>`). The port does not.
3. Its only hostname is `console.${SOVEREIGN_FQDN}`. Its only rule has one filter, `RequestRedirect` with `scheme: https` and `statusCode: 301`, and no `backendRefs`.
4. It attaches to no port-443 listener. There, a redirect to `https://console.<fqdn>/` would loop.
5. No Service is created and no node port is used. No Helm release and no chart changes. The object is new, and the Flux Kustomization `sovereign-tls` creates it.
6. `clusters/_template/sovereign-tls/kustomization.yaml` keeps only the keys `apiVersion`, `kind` and `resources`. It lists the new file right after `cilium-gateway-console.yaml`.

```yaml
# NET-331 — port 80 of a gateway node answers for the console host.
# ─────────────────────────────────────────────────────────────────────────────
# Where the Gateways bind host ports (cilium-config gateway hostNetwork on), a
# node serves port 80 and port 443 directly, and one host port can be bound by
# one Gateway only. The shared `cilium-gateway` holds node:80 and node:443
# (PARENT_DOMAINS_LISTENERS_YAML: `http` / `https`, or `http-<zone>` /
# `http-<fqdn-dashed>` on a multi-zone Sovereign). The console Gateway therefore
# binds its listeners on the pack's console ports instead
# (CONSOLE_GATEWAY_HTTP_PORT / CONSOLE_GATEWAY_HTTPS_PORT: 8080 / 8443 in every
# pack that binds host ports today), where the console's own load balancer
# forwards public :80 / :443.
#
# So a request on node:80 for console.<fqdn> reaches the shared Gateway's port-80
# listener, where no route held the console host: it answered 404 (gate check
# NET-G17, capability gateway.cilium, in both regions). This route gives the
# console host an answer there: a 301 to https://console.<fqdn>/, the address the
# console is served on.
#
# Attached by `port: 80`, not by sectionName: the name of the shared Gateway's
# port-80 listener depends on the zone layout, the port does not. It attaches to
# NO port-443 listener, where a redirect to https://console.<fqdn>/ would loop.
# Cilium's Gateway API matches a parentRef port against the listener port, and
# the HTTPRoute CRD of bp-gateway-api carries the field.
#
# Redirect only, no backendRefs: it names no Service, so it cannot poison the
# shared Gateway's CiliumEnvoyConfig (the #4053 class the console Gateway exists
# to avoid). Where the console rides the shared Gateway itself (console
# isolation off), the console routes hold this host too; either answer is the
# console's own (a 301 to https, or the page).
#
# No NodePort anywhere: node:80 is the hostNetwork cilium-envoy listener.
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: console-http-redirect
  namespace: kube-system
  labels:
    catalyst.openova.io/sovereign: ${SOVEREIGN_FQDN}
    catalyst.openova.io/component: cilium-gateway
spec:
  parentRefs:
    - group: gateway.networking.k8s.io
      kind: Gateway
      name: cilium-gateway
      namespace: kube-system
      port: 80
  hostnames:
    - console.${SOVEREIGN_FQDN}
  rules:
    - filters:
        - type: RequestRedirect
          requestRedirect:
            scheme: https
            statusCode: 301
```

```go
// n331HostMatch is Gateway API hostname matching: an exact name, or a wildcard
// *.<suffix> that the host ends in; an empty pattern matches every host.
func n331HostMatch(pattern, host string) bool {
	if pattern == "" || pattern == host {
		return true
	}
	return strings.HasPrefix(pattern, "*.") && strings.HasSuffix(host, pattern[1:])
}

	case "Selector":
		labels := map[string]string{"kubernetes.io/metadata.name": ns}
		sel, _ := dig(l.allowed, "namespaces", "selector").(map[string]any)
		ml, _ := sel["matchLabels"].(map[string]any)
		for k, v := range ml {
			if labels[k] != n331Str(v) {
				return false
			}
		}
		for _, e := range list(sel["matchExpressions"]) {
			key, op := n331Str(dig(e, "key")), n331Str(dig(e, "operator"))
			val, has := labels[key]
			in := false
			for _, v := range list(dig(e, "values")) {
				in = in || (has && n331Str(v) == val)
			}
			switch op {
			case "In":
				if !in {
					return false
				}
			case "NotIn":
				if in {
					return false
				}
			case "Exists":
				if !has {
					return false
				}
			case "DoesNotExist":
				if has {
					return false
				}
			default:
				t.Fatalf("listener %s: selector operator %q", l.name, op)
			}
		}
		return true
	default:
		t.Fatalf("listener %s: allowedRoutes from %q", l.name, from)
	}
	return false
}

// n331Answer resolves GET / for host on a node port: the most specific
// listener of that port and protocol that holds the host, then the rules of the
// routes attached to it. Every Gateway listener on the port must belong to one
// Gateway: a host port is bound once.
func n331Answer(t *testing.T, docs []map[string]any, host string, port int, protocol string) string {
	t.Helper()
	var on []n331Listener
	gws := map[string]bool{}
	for _, d := range docs {
		if d["kind"] != "Gateway" {
			continue
		}
		for _, l := range list(dig(d, "spec", "listeners")) {
			if n331Int(dig(l, "port")) != port {
				continue
			}
			al, _ := dig(l, "allowedRoutes").(map[string]any)
			li := n331Listener{n331Str(dig(d, "metadata", "namespace")), n331Str(dig(d, "metadata", "name")), n331Str(dig(l, "name")),
				n331Str(dig(l, "protocol")), n331Str(dig(l, "hostname")), port, al}
			gws[li.gwNS+"/"+li.gw] = true
			if li.protocol == protocol && n331HostMatch(li.hostname, host) {
				on = append(on, li)
			}
		}
	}
	if len(gws) > 1 {
		t.Fatalf("Gateways %v all declare port %d: one host port is bound by one Gateway", gws, port)
	}
	if len(on) == 0 {
		return fmt.Sprintf("404 (no %s listener on port %d holds %s)", protocol, port, host)
	}
	// Envoy picks the most specific virtual host: an exact name, else the longest wildcard.
	sort.SliceStable(on, func(i, j int) bool {
		ei, ej := !strings.HasPrefix(on[i].hostname, "*"), !strings.HasPrefix(on[j].hostname, "*")
		if ei != ej {
			return ei
		}
		return len(on[i].hostname) > len(on[j].hostname)
	})
	l := on[0]
	answers := map[string]bool{}
	for _, r := range docs {
		if r["kind"] != "HTTPRoute" {
			continue
		}
		ns := n331Str(dig(r, "metadata", "namespace"))
		if !n331Attached(r, ns, l) || !n331Admits(t, l, ns) {
			continue
		}
		hosts := list(dig(r, "spec", "hostnames"))
		held := len(hosts) == 0
		for _, h := range hosts {
			held = held || n331HostMatch(n331Str(h), host)
		}
		if !held {
			continue
		}
		if a := n331Rule(r, l, host); a != "" {
			answers[a] = true
		}
	}
	if len(answers) == 0 {
		return fmt.Sprintf("404 (no route of Gateway %s/%s, listener %s, port %d, holds %s)", l.gwNS, l.gw, l.name, port, host)
	}
	if len(answers) > 1 {
		t.Fatalf("routes on listener %s give %s different answers %v: Gateway API orders them by creation time, which no render has", l.name, host, answers)
	}
	for a := range answers {
		return a
	}
	return ""
}

// n331Attached is the parentRef rule of Cilium's ingestion: neither sectionName
// nor port attaches to every listener; a sectionName must name the listener and
// a port, when set, must be its port.
func n331Attached(r map[string]any, ns string, l n331Listener) bool {
	for _, pr := range list(dig(r, "spec", "parentRefs")) {
		group, kind, pns := n331Str(dig(pr, "group")), n331Str(dig(pr, "kind")), n331Str(dig(pr, "namespace"))
		if group == "" {
			group = "gateway.networking.k8s.io"
		}
		if kind == "" {
			kind = "Gateway"
		}
		if pns == "" {
			pns = ns
		}
		if group != "gateway.networking.k8s.io" || kind != "Gateway" || pns != l.gwNS || n331Str(dig(pr, "name")) != l.gw {
			continue
		}
		section, port := n331Str(dig(pr, "sectionName")), dig(pr, "port")
		if section != "" && section != l.name {
			continue
		}
		if port != nil && n331Int(port) != l.port {
			continue
		}
		return true
	}
	return false
}

// n331Rule is the answer of the first rule of r that GET / matches: a redirect
// as "<code> <Location>" (Gateway API: code 302 when unset; the port of the
// scheme when a scheme is set, else the listener's), or "200 (backend ...)".
func n331Rule(r map[string]any, l n331Listener, host string) string {
	for _, rule := range list(dig(r, "spec", "rules")) {
		matches := list(dig(rule, "matches"))
		hit := len(matches) == 0
		for _, m := range matches {
			path, method := dig(m, "path"), n331Str(dig(m, "method"))
			pt, pv := n331Str(dig(path, "type")), n331Str(dig(path, "value"))
			hit = hit || ((path == nil || ((pt == "" || pt == "PathPrefix") && (pv == "" || pv == "/"))) &&
				dig(m, "headers") == nil && dig(m, "queryParams") == nil && (method == "" || method == "GET"))
		}
		if !hit {
			continue
		}
		for _, f := range list(dig(rule, "filters")) {
			if n331Str(dig(f, "type")) != "RequestRedirect" {
				continue
			}
			rr := dig(f, "requestRedirect")
			code := 302
			if c := dig(rr, "statusCode"); c != nil {
				code = n331Int(c)
			}
			scheme, to := n331Str(dig(rr, "scheme")), n331Str(dig(rr, "hostname"))
			port := l.port
			if p := dig(rr, "port"); p != nil {
				port = n331Int(p)
			} else if scheme == "https" {
				port = 443
			} else if scheme == "http" {
				port = 80
			}
			if scheme == "" {
				scheme = map[string]string{"HTTPS": "https"}[l.protocol]
				if scheme == "" {
					scheme = "http"
				}
			}
			if to == "" {
				to = host
			}
			if (scheme == "https" && port != 443) || (scheme == "http" && port != 80) {
				to += ":" + strconv.Itoa(port)
			}
			path := "/"
			if v := n331Str(dig(rr, "path", "replaceFullPath")) + n331Str(dig(rr, "path", "replacePrefixMatch")); v != "" {
				path = v
			}
			return fmt.Sprintf("%d %s://%s%s", code, scheme, to, path)
		}
		if refs := list(dig(rule, "backendRefs")); len(refs) > 0 {
			return fmt.Sprintf("200 (backend %v)", dig(refs[0], "name"))
		}
		return "500 (a rule with neither a redirect nor a backend)"
	}
	return ""
}
```
