# CTL-110 — Commit library gitwrite

## In plain words

**The problem today.** Platform code writes its intent to Git in several different ways, file by file. Nothing checks which paths a writer may touch, nothing refuses a Kubernetes Secret, and the commit message does not say who asked for the change. A change of several files can land half written. The writers that later move off these ways need one library to move onto.

**What changes.** A new Go package commits a whole set of files in one Git commit or none. Before any call to Git it checks the fields, the allowed paths and the content, and every commit carries a fixed message that names the change, the person and the surface. Nothing that runs today calls it yet.

**Done means:**

- The new package and the new Gitea batch call build, vet and pass their tests on the pull request.
- A commit of several files is one call to Gitea, and when Gitea refuses one file, no file of the commit is applied.
- A file outside the paths of the writer's scope, or a file that holds a Kubernetes Secret, is refused before any call to Gitea.
- A write that expects a version of a file that has changed since is refused with a conflict that names the file.
- Tests can use an in-memory writer that behaves like the real one.
- No existing file of the repository changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The controllers module (`core/controllers`) gains the Go package `core/controllers/pkg/gitwrite` (import path `github.com/openova-io/openova/core/controllers/pkg/gitwrite`), the commit library of contract C4 (`docs/contracts/C4-git-layout-and-commit-library.md`, section 1). A caller hands it a `Change`: a scope, a repository, 1 to 200 files, a summary, the person, a change id and the surface the change came through. The library checks the change, reads the current files, and makes one atomic commit through Gitea's batch call, or no commit when every file already has the wanted content. Its sub-package `gitwrite/fake` gives tests an in-memory `Writer` that runs the same library code. The existing Gitea client gains the batch call `ChangeFiles` and `BranchHead` in a new file. Nothing that runs today calls the new code: each writer moves onto it in its own later package (CTL-162, CTL-207, CTL-220, CTL-240, CTL-250, CTL-260).

## 3. The model (the law)
The files of this ticket are complete and embedded. These are the rules they implement, so that a reader can check them; you do not write any of it.

1. **One way to Git.** `gitwrite` reaches Git only through the client `core/controllers/pkg/gitea`. It never runs the `git` command. The only `http.Client` it makes is the one with the configured time-out that it hands to `gitea.NewWithHTTP`. It changes no caller.
2. **The surface is the contract's.** The types, constants, functions and errors are exactly those of section 1 of `docs/contracts/C4-git-layout-and-commit-library.md`: `Repo`, `Identity`, `Op` (`OpUpsert`, `OpDelete`), `AbsentSHA`, `FileChange`, `Via` (five values), `Change`, `FileResult`, `Result`, `Entry`, `Writer`, `Scope`, the five scope functions, `SharedRobot`, `TokenSource`, `SharedTokenSource`, `Config`, `New`, `NewChangeID`, the five sentinel errors, `ConflictError` and `IsConflict`. `*Client` implements `Writer`. The scopes are: `FleetIntent(fqdn)` robot `catalyst-fleet-bot`, prefix `clusters/<fqdn>/intent/`; `OrgIntent(slug)` robot `<slug>-iac-bot`, prefix `intent/`; `Catalog()` robot `catalyst-fleet-bot`, prefix `""` (every path); `FleetRendered(fqdn)` robot `catalyst-shared`, prefix `clusters/<fqdn>/regions/`; `OrgRendered()` robot `catalyst-shared`, prefixes `regions/`, `vcluster/`, `continuum/`.
3. **Order of `Commit`.** Field checks; path policy; Secret scan; read of every file's current content and blob SHA; no-op detection; `IfMatch` check; one `ChangeFiles` call. The first three make no network call.
4. **Atomic.** All files that must change go into one `POST /api/v1/repos/{owner}/{repo}/contents` call, with operation `create` for an absent file, `update` with the read SHA for an existing one, and `delete` with the read SHA. The lab test CTL-050 (record `docs/ledger/plan/spikes/CTL-050.md`) measured on Gitea 1.22.3 that this call applies every file or none, so the Git data sequence is not used.
5. **No-op.** An upsert whose content equals the file byte for byte, and a delete of an absent file, are not sent. When nothing is left, no call is made, `Committed` is false and `Commit` is the branch head (from `BranchHead`). This check comes before the `IfMatch` check, as in rule 3.
6. **Compare-and-swap.** A non-empty `IfMatch` is compared with the SHA read in rule 3: `AbsentSHA` needs the file to be absent; any other value needs the file to exist with that SHA. A mismatch returns `*ConflictError{Path, Want: the IfMatch, Current: the read SHA or "" when absent}` and sends nothing. When Gitea answers the batch call with HTTP 404, 409 or 422, the library reads every file again in path order. If one has another SHA than before, that file moved after the read: with an `IfMatch` on any file of the change, it returns `*ConflictError` for the first such file (`Want` is its `IfMatch`, or the SHA read before, or `AbsentSHA` when it was absent); with no `IfMatch`, it starts again from the read, at most `MaxRetries` times, and then returns that `*ConflictError`. If no file moved, it returns Gitea's error. The lab test showed that Gitea's error names the SHAs but not the path, and only the first mismatch; reading again finds the path.
7. **Path policy.** A path is refused with `ErrForbiddenPath` when it is outside every prefix of `Scope.Prefixes`, starts or ends with `/`, or has an empty, `.` or `..` element. A scope with no prefix refuses every path. `Read` and `List` refuse a bad path shape but do not check the prefixes.
8. **No secrets.** Each upsert whose path ends in `.yaml`, `.yml` or `.json` (in any letter case) is split into YAML documents (JSON is YAML). A document with `apiVersion: v1` and `kind: Secret` returns `ErrSecretContent`. A document that does not parse is skipped, so a file that does not parse is committed as it is. Deletes are not scanned.
9. **Field checks**, each returning an error that wraps `ErrInvalid`: a scope without name or robot; a repository without owner or name; 0 or more than 200 files; a file without path; an operation other than `upsert` or `delete`; a path that occurs twice; a summary that is not one line of 1 to 72 characters (counted as characters, not bytes); a change id that is not 26 characters of the ULID alphabet `0123456789ABCDEFGHJKMNPQRSTVWXYZ` with a first character of `7` or less; a `Via` that is not one of `console`, `api`, `mcp`, `event`, `controller`; an author with a name and no e-mail or the reverse; an extra trailer whose key does not match `^[A-Z][A-Za-z-]*$`, is `Change-Id`, `Requested-By` or `Requested-Via`, or whose value is empty or has a line break.
10. **Message.** The lines `<Summary>`, an empty line, `Change-Id: <ChangeID>`, `Requested-By: <Author.Email, or the committer name when the author is empty>`, `Requested-Via: <Via>`, then one `<Key>: <value>` line per extra trailer, sorted by key. The lines are joined by a newline, with no newline after the last one.
11. **Identity.** The committer is `<robot>` with e-mail `<robot>@<RobotDomain>`, where `<robot>` is `Scope.Robot`, or `catalyst-shared` when the token source is `SharedTokenSource`. The author is `Change.Author` when it is set, otherwise the committer. The token is the one the token source gives for `Scope.Robot`; an empty token is an error.
12. **Errors from Gitea.** HTTP 5xx, a connection error and a time-out (the client's or the context's deadline) wrap `ErrUnavailable`. HTTP 401 and 403, and every other answer, are Gitea's `*gitea.HTTPError`, wrapped. A context cancelled by the caller is not unavailability. `Read` of a missing file or repository wraps `ErrNotFound`. `List` of a missing directory returns an empty, non-nil slice; of a missing repository, `ErrNotFound`.
13. **New.** `BaseURL`, `Tokens` and `RobotDomain` are required. `HTTPTimeout` 0 means 15 seconds and `MaxRetries` 0 means 3; a negative value of either is refused. Every refusal wraps `ErrInvalid`.
14. **NewChangeID** returns 26 characters: ten for the time in milliseconds, then sixteen random ones from `crypto/rand`, in the ULID alphabet.
15. **Gitea client.** `core/controllers/pkg/gitea/change_files.go` adds `CommitIdentity`, `ChangeFile`, `ChangeFilesRequest`, `ChangedFile`, `ChangeFilesResponse`, `(*Client).ChangeFiles` (one `POST /repos/{owner}/{repo}/contents`; any answer other than 2xx is `*HTTPError`; a `null` entry of the answer, a deleted file, is skipped) and `(*Client).BranchHead` (`GET /repos/{owner}/{repo}/branches/{branch}`, the field `commit.id`). No existing function of `gitea.Client` changes.
16. **The fake.** `fake.New()` runs the real `gitwrite` client against `gitwrite/internal/giteadouble`, an in-memory Gitea served on a loopback listener of the test process; `Close()` stops it. Every repository and branch exists and starts empty. Its committer is the scope's robot with domain `robots.fake.invalid`. It adds `Put` (write a file as set-up, recorded as no commit) and `Commits()` (the commits made through `Commit`). The double answers as the lab test measured: the batch is checked whole before any file is applied; a wrong SHA is HTTP 422 `sha does not match [given: <sha>, expected: <sha>]`; a create of an existing file is HTTP 422 `repository file already exists [path: <path>]`.
17. **Not in this package.** The region scopes `RegionPlatform`, `Regions` and `WriteAllRegions` (CTL-112); a pull-request mode (CTL-700); per-robot tokens (CTL-126); moving any writer onto the library (CTL-162, CTL-207, CTL-220, CTL-240, CTL-250, CTL-260). The rule that no caller writes a `kustomization.yaml` into an `intent/` directory binds the callers; the library does not enforce it.
18. Nothing existing is changed or deleted.

// Package gitwrite is the one way platform code commits intent to Git.
// Its contract is docs/contracts/C4-git-layout-and-commit-library.md,
// part 1. It calls the client in core/controllers/pkg/gitea and nothing

// intent/ path.
//
// A Change is one atomic commit: every file of it is applied in one call
// to Gitea, or none is. Before any network call, Commit checks the fields,

// Repo names one repository. Branch "" means "main".
type Repo struct {
	Owner  string
	Name   string
	Branch string
}

// Identity is a Git author or committer.
type Identity struct {
	Name  string
	Email string
}

// Op is what a FileChange does to its file.
type Op string

const (
	OpUpsert Op = "upsert" // create the file or replace its content
	OpDelete Op = "delete" // delete the file; deleting an absent file is not an error
)

// AbsentSHA as IfMatch means "the file must not exist".
const AbsentSHA = "absent"

// FileChange is one file in a commit.
type FileChange struct {
	Path    string // repository-relative, no leading slash, no ".." element
	Op      Op
	Content []byte // ignored for OpDelete
	IfMatch string // "" no precondition; AbsentSHA; or the blob SHA the file must have
}

// Via names the surface a change was requested through.
type Via string

const (
	ViaConsole    Via = "console"
	ViaAPI        Via = "api"
	ViaMCP        Via = "mcp"
	ViaEvent      Via = "event"      // a projected database decision
	ViaController Via = "controller" // adoption commits and rendered files

// Change is one atomic commit.
type Change struct {
	Scope    Scope             // selects the robot and the allowed paths; required
	Repo     Repo              // required
	Files    []FileChange      // 1..200; paths unique
	Summary  string            // first line of the message, 1..72 characters, required
	Author   Identity          // the person; zero value means the robot is also the author
	ChangeID string            // required; from NewChangeID
	Via      Via               // required
	Trailers map[string]string // extra trailers; keys match ^[A-Z][A-Za-z-]*$; default nil
}

// FileResult is the state of one file after Commit.
type FileResult struct {
	Path    string
	BlobSHA string // "" for a deleted file
}

// Result is the outcome of Commit.
type Result struct {
	Commit    string // commit SHA; the current head when Committed is false
	Committed bool   // false when every file already had the wanted content
	Files     []FileResult
}

// Entry is one entry of a directory listing.
type Entry struct {
	Path    string
	BlobSHA string
	IsDir   bool
}

// Writer is what handlers, controllers and consumers depend on.

	// Commit applies all files in one commit or none.
	Commit(ctx context.Context, c Change) (Result, error)
	// Read returns a file and its blob SHA. A missing file returns ErrNotFound.
	Read(ctx context.Context, s Scope, r Repo, path string) (content []byte, blobSHA string, err error)
	// List returns the entries directly under dir. A missing dir returns an empty slice.
	List(ctx context.Context, s Scope, r Repo, dir string) ([]Entry, error)
}

type TokenSource interface {

}

	value string
}

func (s sharedTokenSource) Token(context.Context, string) (string, error) {
	return s.value, nil

// Config configures a Client.
type Config struct {
	BaseURL     string        // Gitea base URL, in-cluster; required
	Tokens      TokenSource   // required
	RobotDomain string        // e-mail domain of robot identities; required; "robots.<sovereign-fqdn>"
	HTTPTimeout time.Duration // default 15s
	MaxRetries  int           // default 3; used only when no FileChange has IfMatch set
}

// Client is the Writer that talks to Gitea.
type Client struct {
	cfg    Config
	hc     *http.Client
	shared bool
}

var _ Writer = (*Client)(nil)

// New checks cfg and returns a Client. BaseURL, Tokens and RobotDomain are
// required. HTTPTimeout 0 means 15 seconds and MaxRetries 0 means 3; a
// negative value of either is refused. Every refusal wraps ErrInvalid.
func New(cfg Config) (*Client, error) {
	if cfg.BaseURL == "" || cfg.Tokens == nil || cfg.RobotDomain == "" {
		return nil, fmt.Errorf("%w: Config needs BaseURL, Tokens and RobotDomain", ErrInvalid)
	}
	if cfg.HTTPTimeout < 0 || cfg.MaxRetries < 0 {
		return nil, fmt.Errorf("%w: HTTPTimeout and MaxRetries must not be negative", ErrInvalid)
	}
	if cfg.HTTPTimeout == 0 {
		cfg.HTTPTimeout = 15 * time.Second
	}
	if cfg.MaxRetries == 0 {
		cfg.MaxRetries = 3
	}
	_, shared := cfg.Tokens.(sharedTokenSource)
	return &Client{cfg: cfg, hc: &http.Client{Timeout: cfg.HTTPTimeout}, shared: shared}, nil
}

// crockford is the alphabet of a ULID.
const crockford = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"

// NewChangeID returns a new 26-character ULID: ten characters of the
// time in milliseconds, then sixteen random characters.
func NewChangeID() string {
	var random [16]byte
	if _, err := rand.Read(random[:]); err != nil {
		panic("gitwrite: no random source: " + err.Error())
	}
	var id [26]byte
	ms := time.Now().UnixMilli()
	for i := 9; i >= 0; i-- {
		id[i] = crockford[ms%32]
		ms /= 32
	}
	for i, b := range random {
		id[10+i] = crockford[b&31]
	}
	return string(id[:])
}

// validChangeID reports whether id has the form NewChangeID returns.
func validChangeID(id string) bool {
	if len(id) != 26 || id[0] > '7' {
		return false
	}
	for _, r := range id {
		if !strings.ContainsRune(crockford, r) {
			return false
		}
	}
	return true
}

var (
	ErrNotFound      = errors.New("gitwrite: not found")
	ErrForbiddenPath = errors.New("gitwrite: path outside the scope")
	ErrSecretContent = errors.New("gitwrite: content holds a Secret object")
	ErrInvalid       = errors.New("gitwrite: invalid change")
	ErrUnavailable   = errors.New("gitwrite: git server unavailable")
)

// ConflictError is returned when an IfMatch precondition fails.
type ConflictError struct {
	Path    string
	Want    string // the IfMatch value
	Current string // current blob SHA, "" if the file is absent
}

func (e *ConflictError) Error() string {
	current := e.Current
	if current == "" {
		current = AbsentSHA
	}
	return fmt.Sprintf("gitwrite: %s changed: want %s, current %s", e.Path, e.Want, current)
}

// IsConflict reports whether err is or wraps a *ConflictError.
func IsConflict(err error) bool {
	var ce *ConflictError
	return errors.As(err, &ce)
}

	content []byte

// Commit applies all files of ch in one commit or none. The order is:
// field checks, path policy, Secret scan, read of the current files,
// no-op detection, IfMatch check, one ChangeFiles call. When Gitea
// refuses the call because a file moved after the read, Commit returns
// *ConflictError if any file has IfMatch, and otherwise starts again
// from the read, at most MaxRetries times.
func (c *Client) Commit(ctx context.Context, ch Change) (Result, error) {
	if err := checkFields(ch); err != nil {
		return Result{}, err
	}
	if err := checkPaths(ch); err != nil {
		return Result{}, err
	}
	if err := checkSecrets(ch); err != nil {
		return Result{}, err
	}
	gc, err := c.gitea(ctx, ch.Scope.Robot)
	if err != nil {
		return Result{}, err
	}
	branch := branchOf(ch.Repo)
	committer := c.committer(ch.Scope)
	author := committer
	requestedBy := committer.Name
	if ch.Author != (Identity{}) {
		author = ch.Author
		requestedBy = ch.Author.Email
	}
	message := commitMessage(ch, requestedBy)
	withIfMatch := false
	for _, f := range ch.Files {
		if f.IfMatch != "" {
			withIfMatch = true
		}
	}

	for attempt := 0; ; attempt++ {
		cur, err := readFiles(ctx, gc, ch.Repo, branch, ch.Files)
		if err != nil {
			return Result{}, err
		}
		ops, results := planOps(ch.Files, cur)
		if len(ops) == 0 {
			head, err := gc.BranchHead(ctx, ch.Repo.Owner, ch.Repo.Name, branch)
			if err != nil {
				return Result{}, fmt.Errorf("gitwrite: read the head of %s: %w", branch, classify(ctx, err))
			}
			return Result{Commit: head, Committed: false, Files: results}, nil
		}
		if err := checkIfMatch(ch.Files, cur); err != nil {
			return Result{}, err
		}
		resp, err := gc.ChangeFiles(ctx, ch.Repo.Owner, ch.Repo.Name, gitea.ChangeFilesRequest{
			Branch:    branch,
			Message:   message,
			Author:    gitea.CommitIdentity{Name: author.Name, Email: author.Email},
			Committer: gitea.CommitIdentity{Name: committer.Name, Email: committer.Email},
			Files:     ops,
		})
		if err == nil {
			written := map[string]string{}
			for _, f := range resp.Files {
				written[f.Path] = f.SHA
			}
			for i, f := range ch.Files {
				if sha, ok := written[f.Path]; ok && f.Op == OpUpsert {
					results[i].BlobSHA = sha
				}
			}
			return Result{Commit: resp.CommitSHA, Committed: true, Files: results}, nil
		}
		if !mayBeMismatch(err) {
			return Result{}, fmt.Errorf("gitwrite: commit: %w", classify(ctx, err))
		}
		moved, rerr := firstMoved(ctx, gc, ch, branch, cur)
		if rerr != nil {
			return Result{}, rerr
		}
		if moved == nil {
			return Result{}, fmt.Errorf("gitwrite: commit: %w", classify(ctx, err))
		}
		if withIfMatch || attempt >= c.cfg.MaxRetries {
			return Result{}, moved
		}
	}
}

// Read returns the file at path and its blob SHA. The scope selects the
// robot whose token is used; the path is not checked against its prefixes.
func (c *Client) Read(ctx context.Context, s Scope, r Repo, path string) ([]byte, string, error) {
	if s.Robot == "" || r.Owner == "" || r.Name == "" || path == "" {
		return nil, "", fmt.Errorf("%w: Read needs a scope robot, a repository and a path", ErrInvalid)
	}
	if !validPath(path) {
		return nil, "", fmt.Errorf("%w: %q", ErrForbiddenPath, path)
	}
	gc, err := c.gitea(ctx, s.Robot)
	if err != nil {
		return nil, "", err
	}
	f, err := gc.GetFile(ctx, r.Owner, r.Name, branchOf(r), path)
	if err != nil {
		if errors.Is(err, gitea.ErrFileNotFound) || errors.Is(err, gitea.ErrRepoNotFound) {
			return nil, "", fmt.Errorf("%w: %s: %w", ErrNotFound, path, err)
		}
		return nil, "", fmt.Errorf("gitwrite: read %s: %w", path, classify(ctx, err))
	}
	content, err := f.Decoded()
	if err != nil {
		return nil, "", fmt.Errorf("gitwrite: decode %s: %w", path, err)
	}
	return content, f.SHA, nil
}

// List returns the entries directly under dir, in the order Gitea gives.
// dir "" is the repository root; one trailing slash is ignored. A missing
// dir returns an empty slice; a missing repository returns ErrNotFound.
func (c *Client) List(ctx context.Context, s Scope, r Repo, dir string) ([]Entry, error) {
	if s.Robot == "" || r.Owner == "" || r.Name == "" {
		return nil, fmt.Errorf("%w: List needs a scope robot and a repository", ErrInvalid)
	}
	dir = strings.TrimSuffix(dir, "/")
	if dir != "" && !validPath(dir) {
		return nil, fmt.Errorf("%w: %q", ErrForbiddenPath, dir)
	}
	gc, err := c.gitea(ctx, s.Robot)
	if err != nil {
		return nil, err
	}
	list, err := gc.ListContents(ctx, r.Owner, r.Name, branchOf(r), dir)
	if err != nil {
		if errors.Is(err, gitea.ErrFileNotFound) {
			return []Entry{}, nil
		}
		if errors.Is(err, gitea.ErrRepoNotFound) {
			return nil, fmt.Errorf("%w: %w", ErrNotFound, err)
		}
		return nil, fmt.Errorf("gitwrite: list %s: %w", dir, classify(ctx, err))
	}
	out := make([]Entry, 0, len(list))
	for _, e := range list {
		out = append(out, Entry{Path: e.Path, BlobSHA: e.SHA, IsDir: e.Type == "dir"})
	}
	return out, nil
}

// gitea returns a Gitea client that carries the token of robot.
func (c *Client) gitea(ctx context.Context, robot string) (*gitea.Client, error) {
	token, err := c.cfg.Tokens.Token(ctx, robot)
	if err != nil {
		return nil, fmt.Errorf("gitwrite: token of %s: %w", robot, err)
	}
	if token == "" {
		return nil, fmt.Errorf("gitwrite: the token source gave an empty token for %s", robot)
	}
	return gitea.NewWithHTTP(c.cfg.BaseURL, token, c.hc), nil
}

	robot := s.Robot
	if c.shared {
		robot = SharedRobot
	}

func branchOf(r Repo) string {
	if r.Branch == "" {

}

// checkFields is semantics 6 of the contract: every refusal wraps ErrInvalid.
func checkFields(ch Change) error {
	invalid := func(format string, args ...any) error {
		return fmt.Errorf("%w: "+format, append([]any{ErrInvalid}, args...)...)
	}
	if ch.Scope.Name == "" || ch.Scope.Robot == "" {
		return invalid("the scope needs a name and a robot")
	}
	if ch.Repo.Owner == "" || ch.Repo.Name == "" {
		return invalid("the repository needs an owner and a name")
	}
	if len(ch.Files) == 0 || len(ch.Files) > maxFiles {
		return invalid("%d files; a change has 1 to %d", len(ch.Files), maxFiles)
	}
	if n := utf8.RuneCountInString(ch.Summary); n < 1 || n > 72 || strings.ContainsAny(ch.Summary, "\r\n") {
		return invalid("the summary must be one line of 1 to 72 characters")
	}
	if !validChangeID(ch.ChangeID) {
		return invalid("change id %q is not a ULID from NewChangeID", ch.ChangeID)
	}
	switch ch.Via {
	case ViaConsole, ViaAPI, ViaMCP, ViaEvent, ViaController:
	default:
		return invalid("via %q is not one of console, api, mcp, event, controller", ch.Via)
	}
	if (ch.Author.Name == "") != (ch.Author.Email == "") {
		return invalid("the author needs both a name and an e-mail, or neither")
	}
	for k, v := range ch.Trailers {
		if !trailerKey.MatchString(k) || fixedTrailers[k] {
			return invalid("trailer key %q", k)
		}
		if v == "" || strings.ContainsAny(v, "\r\n") {
			return invalid("trailer %s needs a value of one line", k)
		}
	}
	seen := map[string]bool{}
	for _, f := range ch.Files {
		if f.Path == "" {
			return invalid("a file has no path")
		}
		if f.Op != OpUpsert && f.Op != OpDelete {
			return invalid("op %q of %s", f.Op, f.Path)
		}
		if seen[f.Path] {
			return invalid("path %s occurs twice", f.Path)
		}
		seen[f.Path] = true
	}
	return nil
}

// validPath refuses a leading or trailing slash and an empty, "." or ".." element.
func validPath(p string) bool {
	if p == "" || strings.HasPrefix(p, "/") || strings.HasSuffix(p, "/") {
		return false
	}
	for _, el := range strings.Split(p, "/") {
		if el == "" || el == "." || el == ".." {
			return false
		}
	}
	return true
}

// checkPaths is semantics 4 of the contract.
func checkPaths(ch Change) error {
	for _, f := range ch.Files {
		if !validPath(f.Path) || !underPrefix(f.Path, ch.Scope.Prefixes) {
			return fmt.Errorf("%w: %s (scope %s)", ErrForbiddenPath, f.Path, ch.Scope.Name)
		}
	}
	return nil
}

func underPrefix(p string, prefixes []string) bool {
	for _, prefix := range prefixes {
		if strings.HasPrefix(p, prefix) {
			return true
		}
	}
	return false
}

// checkSecrets is semantics 5 of the contract.
func checkSecrets(ch Change) error {
	for _, f := range ch.Files {
		if f.Op != OpUpsert {
			continue
		}
		lower := strings.ToLower(f.Path)
		if !strings.HasSuffix(lower, ".yaml") && !strings.HasSuffix(lower, ".yml") && !strings.HasSuffix(lower, ".json") {
			continue
		}
		if holdsSecret(f.Content) {
			return fmt.Errorf("%w: %s", ErrSecretContent, f.Path)
		}
	}
	return nil
}

// holdsSecret splits content into YAML documents (JSON is YAML) and
// reports whether one of them has apiVersion v1 and kind Secret. A
// document that does not parse is skipped; it holds no Secret object.
func holdsSecret(content []byte) bool {
	reader := utilyaml.NewYAMLReader(bufio.NewReader(bytes.NewReader(content)))
	for {
		doc, err := reader.Read()
		if err != nil {
			return false
		}
		var obj map[string]any
		if yaml.Unmarshal(doc, &obj) != nil {
			continue
		}
		if obj["apiVersion"] == "v1" && obj["kind"] == "Secret" {
			return true
		}
	}
}

// commitMessage is semantics 7 of the contract. The lines are joined by
// a newline; there is no newline after the last line.
func commitMessage(ch Change, requestedBy string) string {
	lines := []string{
		ch.Summary,
		"",
		"Change-Id: " + ch.ChangeID,
		"Requested-By: " + requestedBy,
		"Requested-Via: " + string(ch.Via),
	}
	keys := make([]string, 0, len(ch.Trailers))
	for k := range ch.Trailers {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	for _, k := range keys {
		lines = append(lines, k+": "+ch.Trailers[k])
	}
	return strings.Join(lines, "\n")
}

// readFiles reads the current state of every file of the change.
func readFiles(ctx context.Context, gc *gitea.Client, r Repo, branch string, files []FileChange) (map[string]current, error) {
	out := make(map[string]current, len(files))
	for _, f := range files {
		st, err := readOne(ctx, gc, r, branch, f.Path)
		if err != nil {
			return nil, err
		}
		out[f.Path] = st
	}
	return out, nil
}

func readOne(ctx context.Context, gc *gitea.Client, r Repo, branch, path string) (current, error) {
	file, err := gc.GetFile(ctx, r.Owner, r.Name, branch, path)
	if errors.Is(err, gitea.ErrFileNotFound) {
		return current{}, nil
	}
	if errors.Is(err, gitea.ErrRepoNotFound) {
		return current{}, fmt.Errorf("%w: repository %s/%s: %w", ErrNotFound, r.Owner, r.Name, err)
	}
	if err != nil {
		return current{}, fmt.Errorf("gitwrite: read %s: %w", path, classify(ctx, err))
	}
	content, err := file.Decoded()
	if err != nil {
		return current{}, fmt.Errorf("gitwrite: decode %s: %w", path, err)
	}
	return current{exists: true, sha: file.SHA, content: content}, nil
}

// planOps returns the operations of the files whose wanted state differs
// from cur, and a result per file in the order of files. A file that
// already has the wanted state is not sent.
func planOps(files []FileChange, cur map[string]current) ([]gitea.ChangeFile, []FileResult) {
	var ops []gitea.ChangeFile
	results := make([]FileResult, len(files))
	for i, f := range files {
		st := cur[f.Path]
		results[i] = FileResult{Path: f.Path}
		switch f.Op {
		case OpUpsert:
			results[i].BlobSHA = st.sha
			if st.exists && bytes.Equal(st.content, f.Content) {
				continue
			}
			op := gitea.ChangeFile{Operation: "create", Path: f.Path, ContentBase64: base64.StdEncoding.EncodeToString(f.Content)}
			if st.exists {
				op.Operation = "update"
				op.SHA = st.sha
			}
			ops = append(ops, op)
		case OpDelete:
			if st.exists {
				ops = append(ops, gitea.ChangeFile{Operation: "delete", Path: f.Path, SHA: st.sha})
			}
		}
	}
	return ops, results
}

// checkIfMatch is the first half of semantics 3: each IfMatch is compared
// with the blob SHA read before the commit.
func checkIfMatch(files []FileChange, cur map[string]current) error {
	for _, f := range files {
		if f.IfMatch == "" {
			continue
		}
		st := cur[f.Path]
		if f.IfMatch == AbsentSHA {
			if st.exists {
				return &ConflictError{Path: f.Path, Want: AbsentSHA, Current: st.sha}
			}
			continue
		}
		if !st.exists || st.sha != f.IfMatch {
			return &ConflictError{Path: f.Path, Want: f.IfMatch, Current: st.sha}
		}
	}
	return nil
}

// mayBeMismatch reports whether Gitea's refusal can be a file that moved
// after the read: HTTP 404, 409 or 422.
func mayBeMismatch(err error) bool {
	var he *gitea.HTTPError
	if !errors.As(err, &he) {
		return false
	}
	return he.Status == http.StatusNotFound || he.Status == http.StatusConflict || he.Status == http.StatusUnprocessableEntity
}

// firstMoved reads every file again, in the order of their paths, and
// returns a *ConflictError for the first one whose blob SHA is no longer
// the one read before the commit, or nil when none moved. Want is the
// file's IfMatch, or the SHA read before (AbsentSHA when it was absent).
func firstMoved(ctx context.Context, gc *gitea.Client, ch Change, branch string, before map[string]current) (*ConflictError, error) {
	files := append([]FileChange(nil), ch.Files...)
	sort.Slice(files, func(i, j int) bool { return files[i].Path < files[j].Path })
	for _, f := range files {
		now, err := readOne(ctx, gc, ch.Repo, branch, f.Path)
		if err != nil {
			return nil, err
		}
		was := before[f.Path]
		if now.exists == was.exists && now.sha == was.sha {
			continue
		}
		want := f.IfMatch
		if want == "" {
			want = was.sha
			if !was.exists {
				want = AbsentSHA
			}
		}
		return &ConflictError{Path: f.Path, Want: want, Current: now.sha}, nil
	}
	return nil, nil
}

// classify is semantics 10 of the contract: HTTP 5xx, a time-out or a
// connection error wraps ErrUnavailable; any other error, HTTP 401 and
// 403 among them, is returned as it is. A cancelled context is not
// unavailability.
func classify(ctx context.Context, err error) error {
	if errors.Is(err, context.Canceled) || errors.Is(ctx.Err(), context.Canceled) {
		return err
	}
	var he *gitea.HTTPError
	if errors.As(err, &he) {
		if he.Status >= 500 {
			return fmt.Errorf("%w: %w", ErrUnavailable, err)
		}
		return err
	}
	var ue *url.Error
	if errors.As(err, &ue) || errors.Is(err, context.DeadlineExceeded) {
		return fmt.Errorf("%w: %w", ErrUnavailable, err)
	}
	return err
}

// Package giteadouble is an in-memory stand-in for the four Gitea API
// calls that gitwrite makes: read a file, list a directory, read a branch
// head, and commit a batch of files. It answers as Gitea 1.22 does: the
// batch is checked whole before any file is applied, a wrong SHA is HTTP
// 422 "sha does not match", a create of an existing file is HTTP 422
// "repository file already exists". Every repository and branch exists
// and starts empty. It is used by the tests of gitwrite and by
// gitwrite/fake; it is not a production server.
package giteadouble

import (
	"crypto/sha256"
	"encoding/base64"
	"encoding/hex"
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"path"
	"sort"
	"strings"
	"sync"
)

// Commit is one commit the double made through the batch call.
type Commit struct {
	Owner, Repo, Branch string
	SHA                 string
	Message             string
	AuthorName          string
	AuthorEmail         string
	CommitterName       string
	CommitterEmail      string
	Token               string   // the token the request carried
	Paths               []string // the paths of the batch, in its order
}

type branch struct {
	head  string
	files map[string][]byte
}

// Server is the double. Its zero value is not usable; call New.
type Server struct {
	mu       sync.Mutex
	branches map[string]*branch
	commits  []Commit
	calls    map[string]int

	// Intercept, when set, is called for every request with its method
	// and kind ("file", "list", "branch" or "change"). A return value
	// other than 0 is sent as the HTTP status and nothing changes.
	Intercept func(method, kind string) int
	// BeforeChange, when set, runs at the start of every batch call,
	// before the batch is checked. It may call Put to play a writer that
	// commits between gitwrite's read and its write.
	BeforeChange func()
}

// New returns an empty double.
func New() *Server {
	return &Server{branches: map[string]*branch{}, calls: map[string]int{}}
}

// BlobSHA is the SHA the double gives content. It is not Git's SHA-1.
func BlobSHA(content []byte) string {
	sum := sha256.Sum256(append([]byte("blob\x00"), content...))
	return hex.EncodeToString(sum[:])[:40]
}

func key(owner, repo, br string) string {
	return owner + "/" + repo + "/" + br
}

// get returns the branch, created empty on first use. s.mu is held.
func (s *Server) get(owner, repo, br string) *branch {
	k := key(owner, repo, br)
	b, ok := s.branches[k]
	if !ok {
		b = &branch{head: BlobSHA([]byte("empty " + k)), files: map[string][]byte{}}
		s.branches[k] = b
	}
	return b
}

// move gives the branch a new head after a change. s.mu is held.
func move(b *branch, what string) {
	b.head = BlobSHA([]byte(b.head + "\x00" + what))
}

// Put writes a file outside the batch call, as another writer would, and
// moves the head. It records no Commit.
func (s *Server) Put(owner, repo, br, p string, content []byte) {
	s.mu.Lock()
	defer s.mu.Unlock()
	b := s.get(owner, repo, br)
	b.files[p] = append([]byte(nil), content...)
	move(b, "put "+p)
}

// Files returns a copy of the files of a branch.
func (s *Server) Files(owner, repo, br string) map[string][]byte {
	s.mu.Lock()
	defer s.mu.Unlock()
	out := map[string][]byte{}
	for p, c := range s.get(owner, repo, br).files {
		out[p] = append([]byte(nil), c...)
	}
	return out
}

// Head returns the head of a branch.
func (s *Server) Head(owner, repo, br string) string {
	s.mu.Lock()
	defer s.mu.Unlock()
	return s.get(owner, repo, br).head
}

// Commits returns a copy of the commits made through the batch call.
func (s *Server) Commits() []Commit {
	s.mu.Lock()
	defer s.mu.Unlock()
	return append([]Commit(nil), s.commits...)
}

// Calls returns how many requests of a kind were answered, refused ones
// included. Kind "" counts every request.
func (s *Server) Calls(kind string) int {
	s.mu.Lock()
	defer s.mu.Unlock()
	if kind == "" {
		n := 0
		for _, c := range s.calls {
			n += c
		}
		return n
	}
	return s.calls[kind]
}

func reply(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(v)
}

func message(w http.ResponseWriter, status int, text string) {
	reply(w, status, map[string]string{"message": text})
}

// ServeHTTP answers the four calls under /api/v1/repos/{owner}/{repo}/.
func (s *Server) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	rest, ok := strings.CutPrefix(r.URL.EscapedPath(), "/api/v1/repos/")
	parts := strings.SplitN(rest, "/", 4)
	if !ok || len(parts) < 3 {
		message(w, http.StatusNotFound, "no such route")
		return
	}
	owner, err1 := url.PathUnescape(parts[0])
	repo, err2 := url.PathUnescape(parts[1])
	tail := ""
	if len(parts) == 4 {
		var err error
		if tail, err = url.PathUnescape(parts[3]); err != nil {
			message(w, http.StatusBadRequest, "bad path")
			return
		}
	}
	if err1 != nil || err2 != nil {
		message(w, http.StatusBadRequest, "bad path")
		return
	}
	kind := ""
	switch {
	case parts[2] == "contents" && len(parts) == 3 && r.Method == http.MethodPost:
		kind = "change"
	case parts[2] == "contents" && r.Method == http.MethodGet:
		kind = "file"
	case parts[2] == "branches" && len(parts) == 4 && r.Method == http.MethodGet:
		kind = "branch"
	default:
		message(w, http.StatusNotFound, "no such route")
		return
	}
	s.mu.Lock()
	s.calls[kind]++
	s.mu.Unlock()
	if s.Intercept != nil {
		if status := s.Intercept(r.Method, kind); status != 0 {
			message(w, status, fmt.Sprintf("intercepted with %d", status))
			return
		}
	}
	token, ok := strings.CutPrefix(r.Header.Get("Authorization"), "token ")
	if !ok || token == "" {
		message(w, http.StatusUnauthorized, "token is required")
		return
	}
	br := r.URL.Query().Get("ref")
	if br == "" {
		br = "main"
	}
	switch kind {
	case "change":
		s.change(w, r, owner, repo, token)
	case "file":
		s.file(w, owner, repo, br, tail)
	case "branch":
		s.mu.Lock()
		head := s.get(owner, repo, tail).head
		s.mu.Unlock()
		reply(w, http.StatusOK, map[string]any{"name": tail, "commit": map[string]string{"id": head}})
	}
}

// file answers GET contents: a file object, a directory listing, or 404.
func (s *Server) file(w http.ResponseWriter, owner, repo, br, p string) {
	s.mu.Lock()
	defer s.mu.Unlock()
	b := s.get(owner, repo, br)
	if content, ok := b.files[p]; ok && p != "" {
		reply(w, http.StatusOK, map[string]any{
			"name": path.Base(p), "path": p, "type": "file", "sha": BlobSHA(content),
			"size": len(content), "content": base64.StdEncoding.EncodeToString(content),
		})
		return
	}
	prefix := ""
	if p != "" {
		prefix = p + "/"
	}
	children := map[string]map[string]any{}
	for fp, content := range b.files {
		rest, ok := strings.CutPrefix(fp, prefix)
		if !ok {
			continue
		}
		name, _, isDir := strings.Cut(rest, "/")
		entry := map[string]any{"name": name, "path": prefix + name, "type": "file", "sha": BlobSHA(content)}
		if isDir {
			entry = map[string]any{"name": name, "path": prefix + name, "type": "dir", "sha": BlobSHA([]byte("tree " + prefix + name))}
		}
		children[name] = entry
	}
	if len(children) == 0 && p != "" {
		message(w, http.StatusNotFound, "object does not exist [rel_path: "+p+"]")
		return
	}
	names := make([]string, 0, len(children))
	for name := range children {
		names = append(names, name)
	}
	sort.Strings(names)
	list := make([]map[string]any, 0, len(names))
	for _, name := range names {
		list = append(list, children[name])
	}
	reply(w, http.StatusOK, list)
}

type batch struct {
	Branch    string `json:"branch"`
	Message   string `json:"message"`
	Author    struct{ Name, Email string }
	Committer struct{ Name, Email string }
	Files     []struct {
		Operation string `json:"operation"`
		Path      string `json:"path"`
		Content   string `json:"content"`
		SHA       string `json:"sha"`
	} `json:"files"`
}

// change answers the batch call: all files or none.
func (s *Server) change(w http.ResponseWriter, r *http.Request, owner, repo, token string) {
	var req batch
	if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
		message(w, http.StatusBadRequest, "bad body: "+err.Error())
		return
	}
	if s.BeforeChange != nil {
		s.BeforeChange()
	}
	br := req.Branch
	if br == "" {
		br = "main"
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	b := s.get(owner, repo, br)
	decoded := make([][]byte, len(req.Files))
	for i, f := range req.Files {
		content, exists := b.files[f.Path]
		switch f.Operation {
		case "create":
			if exists {
				message(w, http.StatusUnprocessableEntity, "repository file already exists [path: "+f.Path+"]")
				return
			}
		case "update", "delete":
			if f.SHA == "" {
				message(w, http.StatusUnprocessableEntity, "a SHA must be given [path: "+f.Path+"]")
				return
			}
			if !exists {
				message(w, http.StatusNotFound, "repository file does not exist [path: "+f.Path+"]")
				return
			}
			if f.SHA != BlobSHA(content) {
				message(w, http.StatusUnprocessableEntity, "sha does not match [given: "+f.SHA+", expected: "+BlobSHA(content)+"]")
				return
			}
		default:
			message(w, http.StatusUnprocessableEntity, "unknown operation "+f.Operation)
			return
		}
		if f.Operation != "delete" {
			c, err := base64.StdEncoding.DecodeString(f.Content)
			if err != nil {
				message(w, http.StatusBadRequest, "content is not base64 [path: "+f.Path+"]")
				return
			}
			decoded[i] = c
		}
	}
	files := make([]any, 0, len(req.Files))
	paths := make([]string, 0, len(req.Files))
	for i, f := range req.Files {
		paths = append(paths, f.Path)
		if f.Operation == "delete" {
			delete(b.files, f.Path)
			files = append(files, nil)
			continue
		}
		b.files[f.Path] = decoded[i]
		files = append(files, map[string]any{"path": f.Path, "type": "file", "sha": BlobSHA(decoded[i])})
	}
	move(b, "commit "+req.Message+"\x00"+strings.Join(paths, "\x00"))
	s.commits = append(s.commits, Commit{
		Owner: owner, Repo: repo, Branch: br, SHA: b.head, Message: req.Message,
		AuthorName: req.Author.Name, AuthorEmail: req.Author.Email,
		CommitterName: req.Committer.Name, CommitterEmail: req.Committer.Email,
		Token: token, Paths: paths,
	})
	reply(w, http.StatusCreated, map[string]any{"files": files, "commit": map[string]string{"sha": b.head}})
}

import (

// CommitIdentity is the author or the committer of a ChangeFiles commit.
type CommitIdentity struct {
	Name  string `json:"name"`
	Email string `json:"email"`
}

// ChangeFile is one file operation of ChangeFiles.
type ChangeFile struct {
	// Operation is "create", "update" or "delete".
	Operation string `json:"operation"`
	// Path is repository-relative, with no leading slash.
	Path string `json:"path"`
	// ContentBase64 is the new content, base64 encoded. Empty for "delete".
	ContentBase64 string `json:"content,omitempty"`
	// SHA is the blob SHA the file has now. Required for "update" and
	// "delete": Gitea refuses the whole commit when it differs.
	SHA string `json:"sha,omitempty"`
}

// ChangeFilesRequest is the body of POST /repos/{owner}/{repo}/contents.
type ChangeFilesRequest struct {
	Branch    string         `json:"branch,omitempty"`
	Message   string         `json:"message"`
	Author    CommitIdentity `json:"author"`
	Committer CommitIdentity `json:"committer"`
	Files     []ChangeFile   `json:"files"`
}

// ChangedFile is one file that a ChangeFiles commit created or updated.
type ChangedFile struct {
	Path string
	SHA  string
}

// ChangeFilesResponse is the answer of ChangeFiles.
type ChangeFilesResponse struct {
	// CommitSHA is the SHA of the new commit.
	CommitSHA string
	// Files holds one entry per created or updated file. A deleted file
	// has no entry.
	Files []ChangedFile
}

// ChangeFiles applies every operation of req in one commit, or none of
// them (POST /repos/{owner}/{repo}/contents, Gitea 1.21 and later).
// Gitea checks each SHA on the server; one mismatch refuses the whole
// commit with HTTP 422. Any answer other than 2xx is returned as
// *HTTPError.
func (c *Client) ChangeFiles(ctx context.Context, org, repo string, req ChangeFilesRequest) (ChangeFilesResponse, error) {
	if org == "" || repo == "" || len(req.Files) == 0 {
		return ChangeFilesResponse{}, errors.New("gitea: ChangeFiles requires non-empty org, repo and files")
	}
	endpoint := fmt.Sprintf("/repos/%s/%s/contents", url.PathEscape(org), url.PathEscape(repo))
	var raw struct {
		Files []*struct {
			Path string `json:"path"`
			SHA  string `json:"sha"`
		} `json:"files"`
		Commit struct {
			SHA string `json:"sha"`
		} `json:"commit"`
	}
	if _, _, err := c.do(ctx, http.MethodPost, endpoint, req, &raw); err != nil {
		return ChangeFilesResponse{}, err
	}
	if raw.Commit.SHA == "" {
		return ChangeFilesResponse{}, errors.New("gitea: ChangeFiles: the answer names no commit")
	}
	out := ChangeFilesResponse{CommitSHA: raw.Commit.SHA}
	for _, f := range raw.Files {
		if f != nil && f.Path != "" {
			out.Files = append(out.Files, ChangedFile{Path: f.Path, SHA: f.SHA})
		}
	}
	return out, nil
}

// BranchHead returns the SHA of the commit at the head of branch
// (GET /repos/{owner}/{repo}/branches/{branch}). A missing repository or
// branch returns *HTTPError with Status 404.
func (c *Client) BranchHead(ctx context.Context, org, repo, branch string) (string, error) {
	if org == "" || repo == "" || branch == "" {
		return "", errors.New("gitea: BranchHead requires non-empty org, repo and branch")
	}
	endpoint := fmt.Sprintf("/repos/%s/%s/branches/%s",
		url.PathEscape(org), url.PathEscape(repo), url.PathEscape(branch))
	var out struct {
		Commit struct {
			ID string `json:"id"`
		} `json:"commit"`
	}
	if _, _, err := c.do(ctx, http.MethodGet, endpoint, nil, &out); err != nil {
		return "", err
	}
	if out.Commit.ID == "" {
		return "", errors.New("gitea: BranchHead: the answer names no commit")
	}
	return out.Commit.ID, nil
}
