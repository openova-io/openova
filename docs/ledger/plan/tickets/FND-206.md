# FND-206 — The size budget of a story leaves out the lines a registered generator writes

## In plain words

**The problem today.** The scope check counts every changed line of a pull request toward the size of its story, also the lines of a file that a generator writes. A story that regenerates a large file is then refused although the part a person wrote is small. A generated file should be judged where it is made: at its generator and the files the generator reads.

**What changes.** The scope check leaves out the files that the registry of generated files lists: neither their lines nor the files count toward the size. Every other file is counted as before.

**Done means:**

- A pull request whose only large change is a file that a registered generator writes keeps the size budget of its story.
- The same number of lines in a file that a person wrote is still refused.
- A file that only says it is generated, but that the registry does not list, is still counted.
- When the registry cannot be read, every file is counted and the refusal says why.
- When the size rule refuses a pull request, its line says how many generated lines and files it left out.

The rest of this ticket is the exact instruction for the model that does the work.
