# CTL-010 — Guard: no new direct cluster write

## In plain words

**The problem today.** The API server and the platform services write to the cluster directly in about a hundred places. The platform is moving those writes to Git, one group of routes at a time. Nothing stops a change from adding a new direct write while that work goes on.

**What changes.** A check on every pull request counts the direct cluster writes in each file of the API server and of the services, and compares them with stored numbers. A change that adds one fails. A change that removes one must lower the stored number in the same change.

**Done means:**

- A pull request that adds a Kubernetes client write call to a file of the API server or of the services turns red.
- A pull request that adds a raw Kubernetes REST write to a file of the services turns red.
- A new file that holds such a write turns the pull request red, wherever it lies in those two trees.
- A pull request that removes such a write must lower the stored number in the same change, so the stored numbers are always exact.
- The check proves on itself that each of its rules can fail.
- No product code changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every pull request gets a check named `no-direct-cluster-write`. It counts, in each Go file of the API server (`products/catalyst/bootstrap/api`) and of the services (`core/services`), two kinds of direct write to the cluster: Kubernetes client write calls (metric `K`) and raw REST writes to the Kubernetes API (metric `R`, in `core/services` only). It compares each file's count with the number stored for that file in `scripts/baselines/direct-cluster-writes.json`. The check is red when a count is above its stored number, and red when it is below it until the stored number is lowered in the same change. A person can see the result on any pull request: the check prints the two totals `K=<n>` and `R=<n>`.

## 3. The model (the law)
1. The guard is the script `scripts/check-no-direct-cluster-write.py`. It reads the working tree. It needs Python 3 and nothing else.
2. It reads every file under `products/catalyst/bootstrap/api` and under `core/services`, in every sub-directory, whose name ends in `.go` and does not end in `_test.go`. No folder is left out.
3. In each file it first drops every line whose first non-blank characters are `//`. Then it counts two metrics:
   - `K`, in both trees: the matches of this regular expression over the remaining text of the file. A match may span lines.
     ```
     \.(Create|Update|UpdateStatus|Patch|Delete|DeleteCollection|Apply|ApplyStatus)\(\s*(?:ctx|[A-Za-z]*[cC]tx|r\.Context\(\)|req\.Context\(\)|context\.[A-Za-z]+\(\))\s*,
     ```
     It finds a call of a Kubernetes client write method whose first argument is a context.
   - `R`, in `core/services` only: the remaining lines that match this regular expression.
     ```
     k8sRequest\((http\.Method(Post|Put|Patch|Delete)|"(POST|PUT|PATCH|DELETE)")|h\.k8sDelete\(|h\.k8sPatchRemoveFinalizers\(
     ```
     It finds a raw REST write to the Kubernetes API.
4. The stored numbers are the file `scripts/baselines/direct-cluster-writes.json`, called the baseline. Its form is the shared form of the guard baselines under `scripts/baselines`:
   ```
   {"schema": "openova.io/guard-baseline/v1",
    "counts": {"K": {"<repository path>": <number>}, "R": {"<repository path>": <number>}},
    "allow": [{"metric": "<K or R>", "path": "<repository path>", "count": <number>, "reason": "<ten characters or more>", "owner": "<area prefix>"}]}
   ```
   `counts` holds, per metric, one entry for each file with at least one match. A file that is absent from a metric is allowed zero. Every number is 1 or more.
5. `allow` lists matches that are permanent or that belong to another area. The count of an allow entry is subtracted from the file's count before the comparison. An entry has exactly the five keys shown, `count` is 1 or more, `reason` has ten characters or more, `owner` is three capital letters, and there is at most one entry per metric and path. This ticket writes `allow` as the empty list. Later packages add entries.
6. The rule, for every metric and every path: when the count after the allow entries is above the path's entry, the script exits with code 1 and names the lines of the matches. When the entry is above the count, it exits with code 1 too: the baseline must be lowered in the same change. When an allow entry is above the file's count, or is malformed, it exits with code 1. Otherwise it exits with code 0. Whenever it judges, it prints the two lines `K=<total>` and `R=<total>`: the matches in the tree, before the allow entries.
7. So a new file with a write fails, wherever it lies in the two trees. A file whose last write left fails until its entry leaves the baseline.
8. A baseline only goes down. `--write-baseline` writes the baseline from the tree. When the baseline file exists, it refuses to raise an entry or to add a path, exits with code 1 and leaves the file as it was; when it writes, it keeps the allow list as it is.
9. When a tree or the baseline cannot be read, the script judges nothing and exits with code 2. A missing baseline, a missing tree, a tree without a counted file, a baseline of another schema and a baseline entry of 0 are never a pass.
10. `--self-test` builds a small tree of its own, 32 times, and shows for each rule that it fails and for each exception that it passes. It reads nothing of the repository.
11. The workflow `.github/workflows/check-no-direct-cluster-write.yaml` has the triggers `pull_request` and `merge_group` and no path filter. Its one job, `no-direct-cluster-write`, runs the self-test first and then the guard.
12. The script and the workflow are the two blocks of field 5, byte for byte. The baseline is written by the script (step 6 of field 16). It is never typed or edited by hand.
13. This ticket changes no product code and no existing file. It deletes nothing.

    kept = [(n + 1, line) for n, line in enumerate(lines) if not line.lstrip().startswith(b"//")]
    if metric == "R":
        return [n for n, line in kept if R_RE.search(line)]
    offsets, at = [], 0                               # where each kept line starts in the joined text
    for _, line in kept:
        offsets.append(at)
        at += len(line) + 1
    text = b"\n".join(line for _, line in kept)
    return [kept[bisect.bisect_right(offsets, m.start()) - 1][0] for m in K_RE.finditer(text)]


def measure(root):
    """metric -> repository path -> line numbers of the matches; files without a match are left out."""
    have = {}
    for metric in METRICS:
        have[metric] = {}
        for tree in SCOPES[metric]:
            for path in go_files(root, tree):
                found = scan(root, path, metric)
                if found:
                    have[metric][path] = found
    return have


def read_baseline(root):
    """Returns (counts, allow entries that are well formed, failure lines about the allow list)."""
    try:
        with open(os.path.join(root, BASELINE), encoding="utf-8") as f:
            doc = json.load(f)
    except (OSError, ValueError) as e:
        raise Unreadable("%s cannot be read: %s" % (BASELINE, e))
    counts = doc.get("counts") if isinstance(doc, dict) else None
    if not isinstance(doc, dict) or doc.get("schema") != SCHEMA or not isinstance(counts, dict) or sorted(counts) != sorted(METRICS):
        raise Unreadable("%s: need schema %s and counts for exactly %s" % (BASELINE, SCHEMA, ", ".join(METRICS)))
    for metric in METRICS:
        entries = counts[metric]
        if not isinstance(entries, dict) or not all(type(v) is int and v >= 1 for v in entries.values()):
            raise Unreadable("%s: counts.%s must map a path to a whole number of 1 or more" % (BASELINE, metric))
    allow = doc.get("allow")
    if not isinstance(allow, list):
        raise Unreadable("%s: allow must be a list" % BASELINE)
    good, fails, seen = [], [], set()
    for i, entry in enumerate(allow):
        where = "allow[%d]" % i
        if not isinstance(entry, dict) or sorted(entry) != ALLOW_KEYS:
            fails.append("%s: an allow entry has exactly the keys %s" % (where, ", ".join(ALLOW_KEYS)))
        elif entry["metric"] not in METRICS:
            fails.append("%s: metric must be K or R" % where)
        elif not isinstance(entry["path"], str) or not entry["path"]:
            fails.append("%s: path must be a repository path" % where)
        elif type(entry["count"]) is not int or entry["count"] < 1:
            fails.append("%s: count must be a whole number of 1 or more" % where)
        elif not isinstance(entry["reason"], str) or len(entry["reason"].strip()) < 10:
            fails.append("%s: reason must be ten characters or more" % where)
        elif not isinstance(entry["owner"], str) or not OWNER.match(entry["owner"]):
            fails.append("%s: owner must be an area prefix of three capital letters" % where)
        elif (entry["metric"], entry["path"]) in seen:
            fails.append("%s: a second allow entry for %s %s; one entry per metric and path" % (where, entry["metric"], entry["path"]))
        else:
            seen.add((entry["metric"], entry["path"]))
            good.append(entry)
    return counts, good, fails


def net(have, allow):
    """(metric -> path -> count after the allow entries, failure lines for allow entries above the count)."""
    out, fails = {}, []
    for metric in METRICS:
        out[metric] = {path: len(lines) for path, lines in have[metric].items()}
    for entry in allow:
        metric, path = entry["metric"], entry["path"]
        now = out[metric].get(path, 0)
        if entry["count"] > now:
            fails.append("%s: %s has %d, its allow entry says %d; lower the allow entry in the same change" % (metric, path, now, entry["count"]))
        out[metric][path] = max(now - entry["count"], 0)
    for metric in METRICS:
        out[metric] = {path: n for path, n in out[metric].items() if n}
    return out, fails


def compare(have, after, entries):
    """One (rose, line) per path whose count after the allow entries is not exactly its baseline entry."""
    out = []
    for metric in METRICS:
        for path in sorted(set(after[metric]) | set(entries[metric])):
            now, entry = after[metric].get(path, 0), entries[metric].get(path, 0)
            if now > entry:
                at = ", ".join(str(n) for n in have[metric].get(path, []))
                out.append((True, "%s: %s has %d, the baseline allows %d (match lines: %s); a new direct cluster write is not allowed" % (metric, path, now, entry, at)))
            elif now < entry:
                out.append((False, "%s: %s has %d, the baseline still says %d; lower the baseline in the same change" % (metric, path, now, entry)))
    return out


def run(root, write=False, say=print):
    """The whole guard. Returns the exit code."""
    try:
        have = measure(root)
        target = os.path.join(root, BASELINE)
        if write:
            kept, good = [], []                       # the allow list is kept as it is; only its good entries count
            if os.path.exists(target):
                old, good, _ = read_baseline(root)
                after, over = net(have, good)
                rises = over + [line for rose, line in compare(have, after, old) if rose]
                if rises:
                    for line in rises:
                        say("%s: FAIL %s" % (ME, line))
                    say("%s: the baseline was not written: a baseline only goes down" % ME)
                    return 1
                with open(target, encoding="utf-8") as f:
                    kept = json.load(f)["allow"]
            after, _ = net(have, good)
            os.makedirs(os.path.dirname(target), exist_ok=True)
            with open(target, "w", encoding="utf-8") as f:
                f.write(json.dumps({"schema": SCHEMA, "counts": after, "allow": kept}, indent=2, sort_keys=True) + "\n")
            say("%s: wrote %s" % (ME, BASELINE))
        entries, allow, fails = read_baseline(root)
    except Unreadable as e:
        say("%s: cannot judge: %s" % (ME, e))
        return 2
    after, over = net(have, allow)
    fails += over + [line for rose, line in compare(have, after, entries)]
    for metric in METRICS:
        say("%s=%d" % (metric, sum(len(lines) for lines in have[metric].values())))
    for line in fails:
        say("%s: FAIL %s" % (ME, line))
    if fails:
        say("%s: %d failure(s). To lower the baseline after a write left: python3 scripts/%s.py --write-baseline" % (ME, len(fails), ME))
    return 1 if fails else 0
