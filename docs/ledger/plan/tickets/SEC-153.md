# SEC-153 — Flux renders bootstrap Secrets from one seed: robot token, pool-domain login, DNS key, hand-over key

## In plain words

**The problem today.** Every control-plane node carries four bootstrap Secrets in its start-up data as whole manifests: names, namespaces, reflector annotations and values. Those bytes count against the start-up data limit of the cloud, and only the values need to be there before Flux runs. A Sovereign installed earlier has these Secrets and nothing else to render them from.

**What changes.** First boot writes only the raw values, once, into one seed Secret, and Flux renders the four Secrets from manifests in Git. A Sovereign installed earlier builds that seed from its own four Secrets the first time it reconciles this change, so its Secrets keep their values and its kit keeps running.

**Done means:**

- A fresh control-plane node's start-up data holds none of the four Secret manifests, only one file of their values, and creates the seed Secret exactly once, on both clouds and in both region roles.
- The four Secrets that Flux renders from the seed have the same names, namespaces, types, keys, values and reflector annotations as the ones first boot wrote before.
- On a Sovereign installed before the change, the seed is built from its four Secrets before anything renders from it, the kit keeps reconciling, and no Secret value changes; a second run changes nothing.
- When one of the four Secrets, a key or a value is missing or empty, no seed is built, no Secret is written, and the failure names the Secret and the key.
- Guard G1 passes a Secret manifest under clusters/ only when every value in it is exactly one reference, and fails a literal, mixed text, a default, an empty value and a manifest without entries.
- Every control-plane start-up data surface stays within its limit, 1,378 bytes smaller than before, with nothing packed to make room.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The control-plane start-up data of every pack carries the raw values of four bootstrap Secrets once, in the file `/var/lib/catalyst/bootstrap-seed.env`, and creates the Secret `flux-system/bootstrap-seed` from it. The manifests of `harbor-robot-token`, `pdm-basicauth`, `sovereign-tls-secrets` (namespace `flux-system`) and `catalyst-handover-jwt-public` (namespace `catalyst-system`) are files under `clusters/_template/bootstrap-secrets`, and the Flux Kustomization `bootstrap-secrets`, on which `bootstrap-kit` depends, renders them from the seed. A Sovereign installed before this change gets its seed from a one-time Job of the Kustomization `bootstrap-seed`, which reads its four Secrets and writes the seed before `bootstrap-secrets` may render; its kit keeps reconciling and its four Secrets keep their values. Guard G1 accepts these manifests because they hold references, not values. Three Go tests prove the upgrade path, each failing when its property is broken.

## 3. The model (the law)
1. Start-up data carries values, not manifests. Each byte left in the template must be there before Flux and OpenBao exist: the platform API (kit slot 13), the pool-domain calls, the DNS-01 solver (through `sovereign-tls`) and the hand-over check read these values from their first start, and no secret store exists before Flux. Names, namespaces, types and reflector annotations are files in Git.
2. The seed file has one `KEY=value` line per value, the value base64-encoded (the hand-over key is JSON; base64 text holds no character Flux substitution or YAML would change): `HARBOR_ROBOT_TOKEN`, `PDM_BASIC_AUTH_USER`, `PDM_BASIC_AUTH_PASS`, `POWERDNS_API_KEY`, `HANDOVER_JWT_PUBLIC_KEY`. First boot creates the seed with `kubectl -n flux-system create secret generic bootstrap-seed --from-env-file=bootstrap-seed.env` after the server-side apply of the three remaining Secret files, on the same line, and shreds the seed file with them. `create` records no last-applied state.
3. Every manifest under `clusters/_template/bootstrap-secrets` is a template of references: each entry under `data` and `stringData` is exactly one `${NAME}`. `data` takes the base64 text as it is; `sovereign-tls-secrets` keeps `stringData`, because its one key holds the base64 text of the DNS-01 key as its value (the Kustomization `sovereign-tls` substitutes it into `data.api-key`).
4. Order of the root children (`clusters/_template/root/base-primary`, which every region folder builds): `bootstrap-seed` (wait, its Job) → `bootstrap-secrets` (dependsOn `bootstrap-seed`; substituteFrom the Secret `bootstrap-seed`, never optional; wait) → `bootstrap-kit` (dependsOn `bootstrap-secrets`). A missing seed stops the build of `bootstrap-secrets`; it never renders an empty value or a literal `${NAME}` into a live Secret.
5. The upgrade path is a path of the product inside the tree a Sovereign reconciles: the Kustomization `bootstrap-seed` applies `clusters/_template/bootstrap-secrets/seed` (a ServiceAccount, two Roles and RoleBindings, the ConfigMap `bootstrap-seed-build` holding `build-seed.sh`, the Job `bootstrap-seed-build`). Why not a step of the release delivery: a Sovereign before its cutover follows the branch its first boot names and receives a merge without any delivery, so only a path inside its tree reaches it; the same Kustomization reaches a Sovereign after its cutover inside the delivered tree. One mechanism covers both.
6. `build-seed.sh` (POSIX shell, run once by the kubectl image the `sovereign-tls` Jobs use) exits 0 when the seed exists. Otherwise it reads the five values from the four Secrets: for a `data` manifest the stored base64 text of the key, for `sovereign-tls-secrets` the value of the key. A Secret that cannot be read, a missing key, an empty value or a value that is not base64 text: it names the Secret and the key, builds no seed, writes nothing and exits 1. Else it writes the values to a file in memory (emptyDir, medium Memory) and runs `kubectl create secret generic bootstrap-seed --from-env-file=... --field-manager=catalyst-bootstrap-seed`; it never writes one of the four Secrets. The Job's `backoffLimit` (4) covers a failed API call; no loop polls. Its rights: `get` on the four Secrets and the seed by name, `create` of Secrets in `flux-system`.
7. Guard G1 (`scripts/check-no-secret-values-in-git.sh`): a file under `clusters/` whose Secret manifests are all templates (every entry exactly one `${NAME}` of capitals, digits and underscores; at least one entry; no field but `apiVersion`, `kind`, `metadata`, `type`, `immutable`, `data`, `stringData`) is named by the Go command `tools/guards/cmd/secret-templates` and not counted; every other Secret manifest under `clusters/` stays a finding. The allow-list only shrinks: its one line (`clusters/_template/sovereign-tls/powerdns-api-credentials.yaml:1`) is now a template and is deleted. The self-test runs `go test` of the command, then the Python self-test. `scripts/secret-guards.py` changes two lines and grows by none.
8. The seed Secret is entered in `scripts/secret-guard-baselines/secret-object-register.yaml` as class T (removal SOV-810), and the threat-model table of `docs/SECURITY.md` and its copy `scripts/secret-guard-baselines/threat-model.md` change together (guard G11).
9. Deleted: the four `write_files` entries `harbor-robot-token-secret.yaml`, `sovereign-tls-secrets.yaml`, `pdm-basicauth-secret.yaml`, `handover-jwt-public-secret.yaml`, their `-f` and shred arguments, and the first-boot creation of the namespace `openbao` (nothing of first boot lands there; kit slot 08 declares it). `catalyst-system` is still created by first boot: the kit, which declares it, waits for `bootstrap-secrets`.
10. No new Python, no new image, no NodePort, no packed entry, no raised limit.

+// renderedSecret is a manifest of clusters/_template/bootstrap-secrets after
+// Flux's substitution, read as the API server stores it.
+type renderedSecret struct {
+	liveSecret
+	problems []string
+}
+
+var fluxReference = regexp.MustCompile(`\$\{([^}]*)\}`)
+
+// renderBootstrapSecrets substitutes the manifests from vars as Flux does: in
+// the text of each document, ${NAME} becomes the value, the empty text when
+// vars has no NAME. A problem is an empty value, a "${" left in a value, a
+// reference vars does not hold, or a data value that is not base64.
+func renderBootstrapSecrets(t *testing.T, root string, vars map[string]string) []renderedSecret {
+	t.Helper()
+	dir := filepath.Join(root, seedSecretsDir)
+	var out []renderedSecret
+	for _, r := range list(readYAMLDocs(t, filepath.Join(dir, "kustomization.yaml"))[0]["resources"]) {
+		path := filepath.Join(dir, fmt.Sprint(r))
+		raw, err := os.ReadFile(path) //nolint:gosec // a file of this repository
+		if err != nil {
+			t.Fatal(err)
+		}
+		for i, text := range regexp.MustCompile(`(?m)^---\s*$`).Split(string(raw), -1) {
+			var before map[string]any
+			if err := yaml.Unmarshal([]byte(text), &before); err != nil || before["kind"] != "Secret" {
+				continue
+			}
+			var rs renderedSecret
+			for _, field := range []string{"data", "stringData"} {
+				for k, v := range asMap(before[field]) {
+					for _, m := range fluxReference.FindAllStringSubmatch(fmt.Sprint(v), -1) {
+						if _, ok := vars[m[1]]; !ok {
+							rs.problems = append(rs.problems, fmt.Sprintf("%s document %d %s.%s: ${%s} is not a key of the seed", r, i, field, k, m[1]))
+						}
+					}
+				}
+			}
+			substituted := fluxReference.ReplaceAllStringFunc(text, func(m string) string { return vars[m[2:len(m)-1]] })
+			var after map[string]any
+			if err := yaml.Unmarshal([]byte(substituted), &after); err != nil {
+				t.Fatalf("%s document %d after substitution: %v", r, i, err)
+			}
+			rs.ns, rs.name = fmt.Sprint(dig(after, "metadata", "namespace")), fmt.Sprint(dig(after, "metadata", "name"))
+			rs.typ = fmt.Sprint(after["type"])
+			rs.annotations, rs.data = map[string]string{}, map[string]string{}
+			for k, v := range asMap(dig(after, "metadata", "annotations")) {
+				rs.annotations[k] = fmt.Sprint(v)
+			}
+			for field, encoded := range map[string]bool{"data": true, "stringData": false} {
+				for k, v := range asMap(after[field]) {
+					s, _ := v.(string)
+					if s == "" || strings.Contains(s, "${") {
+						rs.problems = append(rs.problems, fmt.Sprintf("%s %s.%s renders %q", rs.id(), field, k, s))
+					}
+					if encoded {
+						b, err := base64.StdEncoding.DecodeString(s)
+						if err != nil || len(b) == 0 {
+							rs.problems = append(rs.problems, fmt.Sprintf("%s data.%s renders %q, not the base64 of a value", rs.id(), k, s))
+						}
+						s = string(b)
+					}
+					rs.data[k] = s
+				}
+			}
+			out = append(out, rs)
+		}
+	}
+	sort.Slice(out, func(i, j int) bool { return out[i].id() < out[j].id() })
+	return out
+}

+func asMap(v any) map[string]any { m, _ := v.(map[string]any); return m }

+// reconcileRegion replays Flux's order over the root children of one region,
+// with the stub as its cluster, and returns what went wrong. Each pass takes
+// the children in name order, which puts bootstrap-kit and bootstrap-secrets
+// before bootstrap-seed; a child is reconciled only when every child it
+// dependsOn is ready. bootstrap-seed runs the seed builder: with wait it is
+// ready when the Job has succeeded, without wait it is ready at once and its
+// Job runs only after the next pass. bootstrap-secrets renders from the seed
+// and applies the four Secrets; a missing seed fails its build unless the
+// source is optional, and then it renders without it. bootstrap-kit's first
+// consumers need the four Secrets.
+func reconcileRegion(t *testing.T, root string, ks map[string]fluxKustomization, f *seedFixture) []string {
+	t.Helper()
+	var problems []string
+	names := make([]string, 0, len(ks))
+	for n := range ks {
+		names = append(names, n)
+	}
+	sort.Strings(names)
+	ready := map[string]bool{}
+	var queued, next []func()
+	runJob := func() bool {
+		rc, out := f.build(t)
+		if rc != 0 {
+			problems = append(problems, "the seed builder exits "+fmt.Sprint(rc)+": "+strings.TrimSpace(out))
+		}
+		return rc == 0
+	}
+	for pass := 0; pass < 6; pass++ {
+		for _, n := range names {
+			k := ks[n]
+			waiting := false
+			for _, d := range k.dependsOn {
+				waiting = waiting || !ready[d]
+			}
+			if ready[n] || waiting {
+				continue
+			}
+			switch n {
+			case "bootstrap-seed":
+				if k.path != "./clusters/_template/bootstrap-secrets/seed" {
+					problems = append(problems, "bootstrap-seed builds "+k.path+", not the seed builder")
+				}
+				if k.wait {
+					ready[n] = runJob()
+				} else {
+					ready[n] = true
+					queued = append(queued, func() { runJob() })
+				}
+			case "bootstrap-secrets":
+				src, ok := k.seedSource()
+				if !ok {
+					problems = append(problems, "bootstrap-secrets does not substitute from the Secret "+seedSecret)
+					continue
+				}
+				vars, have := f.get(t, seedNamespace, seedSecret)
+				if !have && !src.optional {
+					problems = append(problems, "bootstrap-secrets was reconciled before the seed existed (its build fails: Secret flux-system/bootstrap-seed not found)")
+					continue
+				}
+				for _, r := range renderBootstrapSecrets(t, root, vars) {
+					problems = append(problems, r.problems...)
+					f.put(t, r.ns, r.name, r.data)
+				}
+				ready[n] = true
+			case "bootstrap-kit":
+				for _, s := range oldBootstrapSecrets() {
+					if _, ok := f.get(t, s.ns, s.name); !ok {
+						problems = append(problems, "bootstrap-kit was reconciled before the Secret "+s.id()+" existed")
+					}
+				}
+				ready[n] = true
+			default:
+				ready[n] = true
+			}
+		}
+		for _, job := range next {
+			job()
+		}
+		next, queued = queued, nil
+	}
+	for _, n := range names {
+		if !ready[n] {
+			problems = append(problems, n+" never became ready")
+		}
+	}
+	return problems
+}

+// Command secret-templates names the files under clusters/ whose Secret
+// manifests are templates of references, which guard G1
+// (scripts/check-no-secret-values-in-git.sh) does not count as Secret values.
+//
+// G1 counts every line `kind: Secret` of a file under clusters/ as a Secret
+// value committed to Git. A manifest that Flux renders from a Secret of the
+// cluster (postBuild.substituteFrom) holds no value, only the name of one:
+// clusters/_template/bootstrap-secrets renders the bootstrap Secrets from the
+// seed Secret flux-system/bootstrap-seed that first boot creates. Such a
+// manifest is a template, and it passes only when
+//
+//	every entry under data and stringData is exactly one reference ${NAME},
+//	NAME of capitals, digits and underscores, as YAML reads the value
+//	(plain, "${NAME}" or '${NAME}'): no literal, no text around the
+//	reference, no default (${NAME:=x}, ${NAME:-x}), no empty value;
+//	data and stringData hold at least one entry together;
+//	the manifest has no field but apiVersion, kind, metadata, type,
+//	immutable, data and stringData. metadata (labels, annotations) is not
+//	judged.
+//
+// A file is named only when it has at least one Secret, every Secret in it is
+// such a template, and every line `kind: Secret` of the file (the line G1
+// counts, SECRET_KIND of scripts/secret-guards.py) is the kind of one of those
+// templates. Every other file stays a finding of G1, under its allow-list.
+//
+// The manifest is read as written, by a strict reader of the one form a
+// template needs: each field of the manifest starts a line of its own at the
+// left edge; metadata, data and stringData are block mappings; apiVersion,
+// kind, type and immutable hold one word or one quoted string on their line;
+// each entry of data and stringData is one line `key: value`, at one indent.
+// A document is split at a line `---` or `...`. A form the reader does not
+// know (a flow mapping, a block scalar, an anchor or alias, a tag, a comment
+// after a value, a tab, a carriage return) is not a template, so YAML can
+// never read a value the reader did not judge.
+//
+// It reads the files Git lists (tracked, and new files Git does not ignore)
+// under clusters/. It prints the path of each template file, one per line, and
+// to standard error why each other file with a line `kind: Secret` is not one.

+// judgeFile returns "" when the file holds at least one Secret, every Secret
+// in it is a template and every line `kind: Secret` is the kind of one of
+// them; otherwise the first reason it is not.
+func judgeFile(text string) string {
+	lines := strings.Split(text, "\n")
+	kinds := map[int]bool{} // the lines `kind: Secret` of the templates
+	secrets, start := 0, 0
+	for i := 0; i <= len(lines); i++ {
+		if i < len(lines) && !separator.MatchString(lines[i]) {
+			continue
+		}
+		doc := lines[start:i]
+		kind, at := kindOf(doc)
+		if kind == "Secret" {
+			secrets++
+			if why := judge(doc, start); why != "" {
+				return fmt.Sprintf("the Secret of line %d: %s", start+at+1, why)
+			}
+			kinds[start+at] = true
+		}
+		start = i + 1
+	}
+	for i, l := range lines {
+		if secretKindLine.MatchString(l) && !kinds[i] {
+			return fmt.Sprintf("line %d names the kind Secret outside the kind field of a template", i+1)
+		}
+	}
+	if secrets == 0 {
+		return "it holds no Secret"
+	}
+	return ""
+}

+// kindOf returns the value of the first field kind of a document, unquoted,
+// and the index of its line in the document.
+func kindOf(doc []string) (string, int) {
+	for i, l := range doc {
+		if m := fieldLine.FindStringSubmatch(l); m != nil && m[1] == "kind" {
+			return unquote(strings.TrimRight(m[2], " ")), i
+		}
+	}
+	return "", -1

+func unquote(v string) string {
+	if len(v) >= 2 && (v[0] == '"' && v[len(v)-1] == '"' && !strings.ContainsAny(v[1:len(v)-1], "\"\\") ||
+		v[0] == '\'' && v[len(v)-1] == '\'' && !strings.Contains(v[1:len(v)-1], "'")) {
+		return v[1 : len(v)-1]
+	}
+	return v
+}

+// judge returns "" when one Secret document is a template, otherwise why it
+// is not. first is the index of the document's first line in the file.
+func judge(doc []string, first int) string {
+	seen := map[string]bool{}
+	keys := map[string]bool{}
+	block, indent, entries := "", 0, 0
+	for i, l := range doc {
+		n := first + i + 1
+		if strings.ContainsAny(l, "\t\r") {
+			return fmt.Sprintf("line %d holds a tab or a carriage return", n)
+		}
+		body := strings.TrimLeft(l, " ")
+		if body == "" || body[0] == '#' {
+			continue // a blank line or a comment
+		}
+		if body == l { // a field of the manifest
+			m := fieldLine.FindStringSubmatch(l)
+			if m == nil {
+				return fmt.Sprintf("line %d is not a field `key: value` of the manifest", n)
+			}
+			key, value := m[1], strings.TrimRight(m[2], " ")
+			if !fields[key] {
+				return fmt.Sprintf("the field %s (line %d) can carry a value; a template has only apiVersion, kind, metadata, type, immutable, data and stringData", key, n)
+			}
+			if seen[key] {
+				return fmt.Sprintf("the field %s appears twice (line %d)", key, n)
+			}
+			seen[key] = true
+			block, indent = "", 0
+			switch {
+			case key == "metadata" || key == "data" || key == "stringData":
+				if value != "" && value[0] != '#' {
+					return fmt.Sprintf("%s (line %d) is not a block mapping", key, n)
+				}
+				block = key
+			case !oneWord.MatchString(value):
+				return fmt.Sprintf("the value of %s (line %d) is not one word on its line", key, n)
+			}
+			continue
+		}
+		switch block {
+		case "metadata":
+			continue // labels and annotations are not judged
+		case "data", "stringData":
+		default:
+			return fmt.Sprintf("line %d continues a field that holds no block", n)
+		}
+		m := entryLine.FindStringSubmatch(l)
+		if m == nil {
+			return fmt.Sprintf("line %d of %s is not one entry `key: ${NAME}`", n, block)
+		}
+		if indent == 0 {
+			indent = len(m[1])
+		} else if len(m[1]) != indent {
+			return fmt.Sprintf("line %d of %s is not at the indent of its first entry", n, block)
+		}
+		key, value := m[2], strings.TrimRight(m[3], " ")
+		if keys[block+"."+key] {
+			return fmt.Sprintf("%s.%s appears twice (line %d)", block, key, n)
+		}
+		keys[block+"."+key] = true
+		switch {
+		case value == "" || value == `""` || value == `''`:
+			return fmt.Sprintf("%s.%s (line %d) is empty", block, key, n)
+		case !reference.MatchString(unquote(value)):
+			return fmt.Sprintf("%s.%s (line %d) is not exactly one reference ${NAME} (NAME of capitals, digits and underscores; no literal, no text around it, no default)", block, key, n)
+		}
+		entries++
+	}
+	if entries == 0 {
+		return "it has no entry under data or stringData"
+	}
+	return ""
