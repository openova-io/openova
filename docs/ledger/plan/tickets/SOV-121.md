# SOV-121 — The seed-repo command of sovereign-ops

## In plain words

**The problem today.** A Sovereign's root objects (its variables ConfigMap and the Flux Kustomizations that apply the bootstrap kit) are created by the first boot and exist only in the cluster. Nothing writes them into the Sovereign's own Git repository, so Git cannot own them and a lost object is not restored from Git.

**What changes.** The life-cycle command gets a subcommand that reads these objects from the region's cluster and commits them, cleaned of server-written fields, into that region's folder of the Sovereign repository. It writes once and then never again, and it refuses to commit a secret value or an object that carries its values inline.

**Done means:**

- Run in a region whose root folder in the repository is empty, the subcommand writes the variables ConfigMap and each root Kustomization in one commit, each object in a file of its own, with a list file beside them.
- A second run commits nothing and says that the root is seeded already.
- A file that someone changed in Git after the seed keeps its content.
- A variables key that names a secret value, or a Kustomization that carries an inline substitution map, makes the run fail with nothing committed.
- The image of the command still builds on a pull request, now with the subcommand inside.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The command `sovereign-ops` (`core/cmd/sovereign-ops`, merged by SOV-120) gets its first subcommand, `seed-repo`. Run as a Kubernetes Job in one region's cluster, `sovereign-ops seed-repo --region <region-id> --git-url <gitea-url> --git-token-file <file>` reads the ConfigMap `flux-system/sovereign-variables` and the root Flux Kustomizations of that region, removes what the API server wrote, and commits them in one commit into `clusters/<SOVEREIGN_FQDN>/regions/<region-id>/platform/root/` of the repository `openova/sovereign-regions`, through the commit library `gitwrite`. Once that folder holds its `kustomization.yaml`, every later run commits nothing. The run ends with the result line and exit code of SOV-120. The tests prove the four behaviours with the in-memory commit library: it writes once and then does nothing, it never overwrites a newer commit, it refuses an inline substitution map or a secret key, and its cluster reader reports an absent object and a failed server correctly. The image build of the pull request proves that the image still builds, now with the commit library inside.

The module imports two packages of `core/controllers`: `pkg/gitwrite` (and, in tests, `pkg/gitwrite/fake`). It does not import `pkg/upstream`, because that package imports the controller runtime (`sigs.k8s.io/controller-runtime/pkg/client`), which would bring the controller runtime and the Kubernetes client into the module and the image.
3. **The command line.** `sovereign-ops seed-repo --region <id> --git-url <url> --git-token-file <file> [--repo <owner>/<name>]`. `--repo` defaults to `openova/sovereign-regions`. A missing flag, an extra argument or a `--repo` without exactly one `/` fails with exit code 1 and the error `usage: seed-repo --region <id> --git-url <url> --git-token-file <file> [--repo <owner>/<name>]`. An empty token file fails with exit code 1.
4. **What it reads.** Only HTTP GET requests to the Kubernetes API of the cluster the Pod runs in, with the Pod's service account (`/var/run/secrets/kubernetes.io/serviceaccount`): the ConfigMap `flux-system/sovereign-variables`, then the Kustomizations `bootstrap-kit`, `bootstrap-kit-crs`, `sovereign-tls` and `infrastructure-providers` in `flux-system` (`kustomize.toolkit.fluxcd.io/v1`), in that order. These are the four root Kustomizations the first-boot template writes (the fourth only in the primary region; an absent one is skipped). The fifth Kustomization of that template, `sovereign-region-bootstrap`, is not seeded: it applies the region folder that the seed writes into, so it would own itself. HTTP 404 is "absent". HTTP 429, any 5xx, no answer or an unreadable body is transient (exit code 75). Any other status is a failure (exit code 1). Numbers in the answer are kept as written (`json.Decoder.UseNumber`).
5. **Where it writes.** `<fqdn>` is the value `SOVEREIGN_FQDN` of the ConfigMap. The folder is `clusters/<fqdn>/regions/<region>/platform/root/`, the one prefix of `gitwrite.RegionPlatform(<fqdn>, ["root"], [<region>])` (contract C4, `docs/contracts/C4-git-layout-and-commit-library.md` section 2.2: module `root`, the scope that the name `sovereign-root` maps to). The writer is `gitwrite.New` with `BaseURL` the `--git-url`, `Tokens` `gitwrite.SharedTokenSource(<token from the file, trimmed>)` and `RobotDomain` `robots.<fqdn>`. The commit has `Via` `controller`, the summary `seed-repo: root of region <region>`, a new `ChangeID`, and `IfMatch: absent` on every file.
6. **What it writes.** Contract C4 section 2.1 asks for one object per file, the file named `<metadata.name>.yaml`, and on every object the label `app.kubernetes.io/managed-by: flux` and the annotation `catalyst.openova.io/change-id: <the commit's ChangeID>`. So the files are `sovereign-variables.yaml`, then `<name>.yaml` for each Kustomization found, then `kustomization.yaml` (`apiVersion: kustomize.config.k8s.io/v1beta1`, `kind: Kustomization`, `resources:` the other files in that order). Each object loses `status`, the metadata fields `managedFields`, `resourceVersion`, `uid`, `creationTimestamp`, `generation`, `selfLink`, `finalizers`, `ownerReferences`, `deletionTimestamp`, `deletionGracePeriodSeconds`, and the annotations `kubectl.kubernetes.io/last-applied-configuration` and `reconcile.fluxcd.io/requestedAt`. The ConfigMap also loses `binaryData` and gains the annotation `kustomize.toolkit.fluxcd.io/substitute: disabled`, so that the Kustomization that applies the region folder does not substitute into it.
7. **Once, and Git wins.** If `platform/root/kustomization.yaml` exists, the run commits nothing and its evidence is `seeded already: <path> is blob <sha>`. If the folder holds other files but no `kustomization.yaml`, the run fails with exit code 1 and names them. If another writer creates one of the files between the check and the commit, the commit library returns a conflict, and the run ends with exit code 75 (the next run then finds the root seeded). A Git server that does not answer is also exit code 75. On success the evidence is `commit <sha>`, then `wrote <path>` for each file.
8. **Refusals; nothing is committed.** The ConfigMap is absent or has no `SOVEREIGN_FQDN`. A key of the ConfigMap names a secret value under rule 5 of contract C5: its name ends in `_KEY`, `_TOKEN`, `_PASSWORD` or `_SECRET_VALUE` and is not `RELEASE_PUBLIC_KEY_B64` or `SOVEREIGN_REGION_KEY`. A root Kustomization has `spec.postBuild.substitute` (an inline map): values reach Git only through the ConfigMap. The two lists of rule 5 are a copy of `secretSuffixes` and `SecretNameExceptions` in `core/controllers/pkg/upstream/upstream.go` (item 2 says why it is not imported); the test `TestRule5MatchesUpstream` reads that file and fails when the copy differs. The commit library itself refuses any `v1` `Secret` document.
9. **The dispatcher.** The table `subcommands` of `main.go` gets the one entry `"seed-repo": seedrepo.Main`. `TestDispatch` therefore lists the names as `[probe seed-repo]` and gains the case `seed-repo` with no flags (exit code 1, the usage line of item 3).
10. **The image.** The stage `build` of the `Containerfile` copies `core/controllers/go.mod`, `core/controllers/go.sum` and `core/controllers/pkg/` to `/src/core/controllers/`, where the replace directive points, before it copies the command. The other stages do not change.
11. **The workflow.** `Build sovereign-ops` also runs on a push to `main` and on a pull request that change `core/controllers/go.mod`, `core/controllers/go.sum`, `core/controllers/pkg/gitea/**`, `core/controllers/pkg/gitwrite/**` or `core/controllers/pkg/upstream/**`: what the command builds from, and the file its test reads. `core/services/catalyst-catalog`'s workflow filters the same way. Nothing else in the workflow changes.

// Command sovereign-ops runs one life-cycle action of a Sovereign, as a
// Kubernetes Job or CronJob: sovereign-ops <subcommand> [flags]. Every
// subcommand is idempotent and ends with the result line and exit code of
// package internal/ops. Logs go to standard error.
package main

import (
	"context"
	"fmt"
	"io"
	"os"
	"os/signal"
	"sort"
	"strings"
	"syscall"

	"github.com/openova-io/openova/core/cmd/sovereign-ops/internal/ops"
	"github.com/openova-io/openova/core/cmd/sovereign-ops/internal/seedrepo"
)

// subcommands is the dispatcher's table. A subcommand is one entry here and
// one package under internal/.
var subcommands = map[string]func(ctx context.Context, args []string, stderr io.Writer) ([]string, error){
	"seed-repo": seedrepo.Main,
}

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	code := run(ctx, os.Args[1:], os.Stdout, os.Stderr, "/dev/termination-log")
	stop()
	os.Exit(code)
}

// run dispatches args to a subcommand and returns the exit code. A missing
// or unknown subcommand fails with exit code 1.
func run(ctx context.Context, args []string, stdout, stderr io.Writer, termLog string) int {
	var names []string
	for n := range subcommands {
		names = append(names, n)
	}
	sort.Strings(names)
	if len(args) == 0 {
		return ops.Finish(stdout, termLog, "", nil, fmt.Errorf("usage: sovereign-ops <subcommand> [flags]; subcommands: [%s]", strings.Join(names, " ")))
	}
	cmd, ok := subcommands[args[0]]
	if !ok {
		return ops.Finish(stdout, termLog, args[0], nil, fmt.Errorf("unknown subcommand %q; subcommands: [%s]", args[0], strings.Join(names, " ")))
	}
	evidence, err := cmd(ctx, args[1:], stderr)
	return ops.Finish(stdout, termLog, args[0], evidence, err)
}

//
// seed-repo commits the root of one region into the Sovereign's own Git
// repository, once. It reads from the region's cluster the ConfigMap
// flux-system/sovereign-variables and each Kustomization of
// RootKustomizations, and writes them with a kustomization.yaml that lists
// them into clusters/<fqdn>/regions/<region>/platform/root/, in one commit
// of the commit library gitwrite (contract C4, scope RegionPlatform, module
// root). <fqdn> is the value SOVEREIGN_FQDN of the ConfigMap. As contract C4
// asks, each file holds one object, is named <metadata.name>.yaml and carries
// the label app.kubernetes.io/managed-by and the annotation
// catalyst.openova.io/change-id.
//
// Git wins once the root is there: when platform/root/kustomization.yaml
// exists, seed-repo commits nothing, so a commit made after the seed is
// never overwritten. When the folder holds files but no kustomization.yaml,
// it fails and names them. It also fails, and commits nothing, when a root
// Kustomization carries an inline postBuild.substitute map or a key of the
// ConfigMap names a secret value: no value reaches Git except through the

// Seed runs seed-repo for one region. newWriter returns the commit library
// client for the Sovereign with the given FQDN. The evidence names the
// commit and each file written, or the file that shows the root is seeded.
func Seed(ctx context.Context, c Cluster, newWriter func(fqdn string) (gitwrite.Writer, error), region string, repo gitwrite.Repo) ([]string, error) {
	vars, err := c.Get(ctx, "v1", "ConfigMap", "flux-system", "sovereign-variables")
	if err != nil {
		return nil, fmt.Errorf("read ConfigMap flux-system/sovereign-variables: %w", err)
	}
	data, _ := vars["data"].(map[string]interface{})
	fqdn, _ := data["SOVEREIGN_FQDN"].(string)
	if vars == nil || fqdn == "" {
		return nil, errors.New("ConfigMap flux-system/sovereign-variables does not exist or has no value SOVEREIGN_FQDN")
	}
	scope := gitwrite.RegionPlatform(fqdn, []string{"root"}, []string{region})
	if len(scope.Prefixes) != 1 {
		return nil, fmt.Errorf("%q and %q do not name one region folder", fqdn, region)
	}
	dir := scope.Prefixes[0]
	w, err := newWriter(fqdn)
	if err != nil {
		return nil, err
	}
	if _, sha, err := w.Read(ctx, scope, repo, dir+"kustomization.yaml"); err == nil {
		return []string{"seeded already: " + dir + "kustomization.yaml is blob " + sha}, nil
	} else if !errors.Is(err, gitwrite.ErrNotFound) {
		return nil, gitError("read "+dir+"kustomization.yaml", err)
	}
	entries, err := w.List(ctx, scope, repo, dir)
	if err != nil {
		return nil, gitError("list "+dir, err)
	}
	if len(entries) > 0 {
		var names []string
		for _, e := range entries {
			names = append(names, e.Path)
		}
		sort.Strings(names)
		return nil, fmt.Errorf("%s holds %s but no kustomization.yaml; seed-repo writes only into an empty folder", dir, strings.Join(names, ", "))
	}
	changeID := gitwrite.NewChangeID()
	ch := gitwrite.Change{Scope: scope, Repo: repo, Summary: "seed-repo: root of region " + region, ChangeID: changeID, Via: gitwrite.ViaController}
	var resources []interface{}
	add := func(name string, obj map[string]interface{}) error {
		b, err := yaml.Marshal(obj)
		if err != nil {
			return fmt.Errorf("encode %s: %w", name, err)
		}
		ch.Files = append(ch.Files, gitwrite.FileChange{Path: dir + name, Op: gitwrite.OpUpsert, Content: b, IfMatch: gitwrite.AbsentSHA})
		resources = append(resources, name)
		return nil
	}
	keys := make([]string, 0, len(data))
	for k := range data {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	for _, k := range keys {
		if namesSecret(k) {
			return nil, fmt.Errorf("the key %s of ConfigMap flux-system/sovereign-variables names a secret value; nothing is committed", k)
		}
	}
	cm := clean(vars, changeID)
	delete(cm, "binaryData")
	cm["metadata"].(map[string]interface{})["annotations"].(map[string]interface{})["kustomize.toolkit.fluxcd.io/substitute"] = "disabled"
	if err := add("sovereign-variables.yaml", cm); err != nil {
		return nil, err
	}
	for _, name := range RootKustomizations {
		obj, err := c.Get(ctx, "kustomize.toolkit.fluxcd.io/v1", "Kustomization", "flux-system", name)
		if err != nil {
			return nil, fmt.Errorf("read Kustomization flux-system/%s: %w", name, err)
		}
		if obj == nil {
			continue
		}
		spec, _ := obj["spec"].(map[string]interface{})
		postBuild, _ := spec["postBuild"].(map[string]interface{})
		if _, inline := postBuild["substitute"]; inline {
			return nil, fmt.Errorf("the Kustomization flux-system/%s carries an inline postBuild.substitute map; nothing is committed", name)
		}
		if err := add(name+".yaml", clean(obj, changeID)); err != nil {
			return nil, err
		}
	}
	if err := add("kustomization.yaml", map[string]interface{}{"apiVersion": "kustomize.config.k8s.io/v1beta1",
		"kind": "Kustomization", "resources": resources}); err != nil {
		return nil, err
	}
	res, err := w.Commit(ctx, ch)
	if err != nil {
		return nil, gitError("commit "+dir, err)
	}
	evidence := []string{"commit " + res.Commit}
	for _, f := range ch.Files {
		evidence = append(evidence, "wrote "+f.Path)
	}
	return evidence, nil
}

// namesSecret reports whether rule 5 of contract C5 refuses the key name.
func namesSecret(key string) bool {
	for _, e := range secretNameExceptions {
		if key == e {
			return false
		}
	}
	for _, s := range secretSuffixes {
		if strings.HasSuffix(key, s) {
			return true
		}
	}
	return false
}

// clean returns a copy of obj without status and the fields of
// dropMetadata and dropAnnotations, with the label
// app.kubernetes.io/managed-by flux and the annotation
// catalyst.openova.io/change-id that every committed object carries.
func clean(obj map[string]interface{}, changeID string) map[string]interface{} {
	out, meta, labels, annotations := map[string]interface{}{}, map[string]interface{}{}, map[string]interface{}{}, map[string]interface{}{}
	for k, v := range obj {
		out[k] = v
	}
	delete(out, "status")
	m, _ := obj["metadata"].(map[string]interface{})
	for k, v := range m {
		meta[k] = v
	}
	for _, k := range dropMetadata {
		delete(meta, k)
	}
	l, _ := m["labels"].(map[string]interface{})
	for k, v := range l {
		labels[k] = v
	}
	a, _ := m["annotations"].(map[string]interface{})
	for k, v := range a {
		annotations[k] = v
	}
	for _, k := range dropAnnotations {
		delete(annotations, k)
	}
	labels["app.kubernetes.io/managed-by"] = "flux"
	annotations["catalyst.openova.io/change-id"] = changeID
	meta["labels"], meta["annotations"] = labels, annotations
	out["metadata"] = meta
	return out
}

// gitError describes a failed call to the commit library. A Git server that
// did not answer, and a file another writer created first, may be retried.
func gitError(what string, err error) error {
	err = fmt.Errorf("%s: %w", what, err)
	if errors.Is(err, gitwrite.ErrUnavailable) || gitwrite.IsConflict(err) {
		return ops.Transient(err)
	}
	return err
}

// apiServer reads objects from the Kubernetes API with the Pod's service
// account.
type apiServer struct {
	base, token string
	client      *http.Client
}

func inCluster() (*apiServer, error) {
	host, port := os.Getenv("KUBERNETES_SERVICE_HOST"), os.Getenv("KUBERNETES_SERVICE_PORT")
	token, terr := os.ReadFile(serviceAccount + "/token")
	ca, cerr := os.ReadFile(serviceAccount + "/ca.crt")
	pool := x509.NewCertPool()
	if host == "" || port == "" || terr != nil || cerr != nil || !pool.AppendCertsFromPEM(ca) {
		return nil, errors.New("seed-repo runs in a Pod of the region's cluster: no Kubernetes service address or service account")
	}
	tr := &http.Transport{TLSClientConfig: &tls.Config{RootCAs: pool, MinVersion: tls.VersionTLS12}}
	return &apiServer{base: "https://" + net.JoinHostPort(host, port), token: strings.TrimSpace(string(token)),
		client: &http.Client{Transport: tr, Timeout: 30 * time.Second}}, nil
}

// plurals maps the kinds seed-repo reads to their resource names.
var plurals = map[string]string{"ConfigMap": "configmaps", "Kustomization": "kustomizations"}

func (a *apiServer) Get(ctx context.Context, apiVersion, kind, namespace, name string) (map[string]interface{}, error) {
	prefix := "/apis/"
	if apiVersion == "v1" {
		prefix = "/api/"
	}
	path := prefix + apiVersion + "/namespaces/" + namespace + "/" + plurals[kind] + "/" + name
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, a.base+path, nil)
	if err != nil {
		return nil, err
	}
	req.Header.Set("Authorization", "Bearer "+a.token)
	req.Header.Set("Accept", "application/json")
	resp, err := a.client.Do(req)
	if err != nil {
		return nil, ops.Transient(err)
	}
	defer func() { _ = resp.Body.Close() }()
	switch {
	case resp.StatusCode == http.StatusNotFound:
		return nil, nil
	case resp.StatusCode == http.StatusTooManyRequests || resp.StatusCode >= 500:
		return nil, ops.Transient(fmt.Errorf("GET %s: HTTP %d", path, resp.StatusCode))
	case resp.StatusCode != http.StatusOK:
		return nil, fmt.Errorf("GET %s: HTTP %d", path, resp.StatusCode)
	}
	// UseNumber keeps every number as the API server wrote it.
	dec := json.NewDecoder(resp.Body)
	dec.UseNumber()
	var obj map[string]interface{}
	if err := dec.Decode(&obj); err != nil {
		return nil, ops.Transient(fmt.Errorf("GET %s: %w", path, err))
	}
	return obj, nil
}
