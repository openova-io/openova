# CMP-032 — The aggregator uses the package: subjects, one judge, seven results; duplicate evaluators deleted

## In plain words

**The problem today.** The compliance score of a Sovereign judges the same check twice: the engine reports it on a Pod and again on the Deployment that owns the Pod, and the aggregator counts both. Its scoring lives in the HTTP handler, knows only four results, and reads a weight object from the cluster that no Sovereign has, so the package with the real score rules is not used.

**What changes.** The handler keeps only the routes and the stream; the state and the scoring move to the read model of the compliance package. A verdict on a Pod counts for its Deployment, StatefulSet, DaemonSet or CronJob, a skipped check leaves the score, and a result of an unknown producer is dropped and counted.

**Done means:**

- A check that the engine reports on a Deployment and on its Pod is judged once, on the Deployment, and the worst of the two results counts.
- A Pod with a controller no longer appears as a subject of its own in the scorecard, the violations or the published scores, and the findings page of the Pod shows its controller.
- A skipped result does not change a score, and a result whose producer the model does not own is dropped and counted.
- The scorecard, policies, violations, resource and stream routes keep every field name, and the two gauges keep their names.
- The aggregator reads no EnvironmentPolicy object, and the handler package has fewer lines.
- The committed scorecard of a fixed set of events before the change differs from the one after it, and a test holds the after one.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The compliance aggregator of catalyst-api (`products/catalyst/bootstrap/api/internal/handler/compliance.go`) no longer keeps or scores state of its own. Three new files of `products/catalyst/bootstrap/api/internal/compliance` do it: `resolver.go` (the top controller and the labels of an object, from the workload events and the informer cache), `adapters/` (one adapter per source kind: the reports of group `wgpolicyk8s.io`, and the synthetic reports of in-process evaluators), and `readmodel.go` (the findings of every source object per cluster, scored with `SubjectScore` and `ScopePosture` of `score.go` over an embedded fallback model). ## 3. The model (the law)
1. **Subjects.** A finding is judged on the top controller of the object its result names: `CacheResolver.TopOwner` follows controller `ownerReferences` of kind ReplicaSet, Deployment, StatefulSet, DaemonSet, Job and CronJob (Pod to ReplicaSet to Deployment; Pod to Job to CronJob), at most four steps, and stops at an owner the cache does not hold. A Pod with no controller is its own subject. The resolver reads the objects the workload events show it (`Observe`) and, for an object no event showed, the informer cache (`Lister`, satisfied by `*k8scache.Factory`); it never calls an API server. `Subject` fills Organization, Environment and Application from the labels the aggregator read before (`catalyst.openova.io/…` first, then `openova.io/…`, then `app.kubernetes.io/instance` and `app.kubernetes.io/name` for the application), EnvironmentType from the text after the last `-` of the Environment, and Exposure `other` for every subject.
2. **One judge.** A check reported on a Pod and on its controller lands on one subject. Rule 1 of `score.go` takes the worst result of the check's own source.
3. **Seven results.** The adapter maps `pass`, `fail` and `warn` to themselves, `skip` to `na`, and `error` or any other word to `not-measured`. Only `pass`, `fail` and `warn` enter a numerator or a denominator.
4. **The read model** is keyed by the source object (apiVersion, kind, namespace and name of the report; for a synthetic report, its check and the object it judged). A new event of an object replaces every finding of that object; a deletion removes them. A subject with no finding left leaves the model, and its gauge series `catalyst_compliance_score{scope="resource"}` is deleted (#5352).
5. **The fallback model** is the content of `internal/compliance/testdata/model-default.yaml`, embedded: one group and one axis `all`, no mandatory check, cap 100. The read model adds one check of weight 1 on that axis for every check id it observes from the engine (`kyverno`) or from an evaluator; of the two the engine wins. A result whose source no producer of the model owns (for example `catalyst-conformance`) is no finding: it is dropped and counted (`ReadModel.Dropped`). CMP-041 loads the real model; nothing else changes the numbers.
6. **The handler** feeds the read model from the Factory fanout and maps its postures to the existing types: `Score.Total` and `Score.Score` are `Posture.Overall`, `Numerator` and `Denominator` the sums of the axes, `Violations` the count of failed checks, `PolicyResults` the effective result per check. The rollups are the scopes application, environment, organization and sovereign of `ReadModel.Rollups`. `PolicyView.Weight` is the check's weight in the model.
7. **Deleted.** From `compliance.go`: `resourceState`, `policyVerdict`, `recordVerdict`, `recomputeAndPublish`, `enrichResourceState`, `applyLabelsTo`, `ingestWorkloadLabels`, `ingestKyvernoReport`, `ingestSyntheticReport`, `pruneKyvernoReport`, `pruneSyntheticReport`, `pruneResource`, `rollupsFor`, `computeScore`, `normalizedScore`, `kyvernoResourceFor` (moved to `adapters.ResourceFor`), `guessStateful`, `splitResourceKey`, `cloneResourceState`, `EnvironmentPolicyResolver`, `EnvironmentPolicySpec`, `PolicyWeight`, `NewDynamicEnvironmentPolicyResolver` and its type, `resolveEnvPolicy`; from `cmd/api/main.go`: `newComplianceEnvironmentPolicyResolverFromEnv`. `EnvironmentPolicyGVR` and `labelOr` stay: `policy_mode.go`, `compliance_runtime.go` and `dashboard.go` read them.
8. **Not changed.** No JSON field name, no route, no gauge or counter name, nothing under `internal/k8scache/`, and no file of `internal/compliance` that CMP-030 wrote.

+// model: one adapter per source kind. An adapter reads only the event and the
+// resolver; it keeps no state and never calls an API server.

+// ReportGroup is the only API group whose reports PolicyReport reads.
+const ReportGroup = "wgpolicyk8s.io"
+
+// maxMessage is the longest Finding.Message an adapter keeps.
+const maxMessage = 500
+
+// PolicyReport reads the results of the PolicyReport and ClusterPolicyReport
+// objects of group wgpolicyk8s.io: one finding per result, judged on the top
+// controller of the object the result names.
+type PolicyReport struct{}
+
+// Kinds returns the informer kinds of the two report objects.
+func (PolicyReport) Kinds() []string { return []string{"policyreport", "clusterpolicyreport"} }
+
+// Apply returns one finding per result of the report; nil for a deletion or
+// a report of another group.
+func (PolicyReport) Apply(ev k8scache.Event, r compliance.Resolver) []compliance.Finding {
+	obj := ev.Object
+	if obj == nil || ev.Type == k8scache.EventDeleted || groupOf(obj.GetAPIVersion()) != ReportGroup {
+		return nil
+	}
+	evidence := compliance.ObjectRef{APIVersion: obj.GetAPIVersion(), Kind: obj.GetKind(), Namespace: obj.GetNamespace(), Name: obj.GetName()}
+	results, _, _ := unstructured.NestedSlice(obj.Object, "results")
+	var out []compliance.Finding
+	for _, ri := range results {
+		res, ok := ri.(map[string]any)
+		if !ok {
+			continue
+		}
+		policy, _, _ := unstructured.NestedString(res, "policy")
+		rule, _, _ := unstructured.NestedString(res, "rule")
+		result, _, _ := unstructured.NestedString(res, "result")
+		message, _, _ := unstructured.NestedString(res, "message")
+		source, _, _ := unstructured.NestedString(res, "source")
+		if policy == "" || result == "" {
+			continue
+		}
+		kind, ns, name := ResourceFor(obj, res)
+		if name == "" {
+			continue
+		}
+		f := compliance.Finding{
+			Check:      policy,
+			Source:     sourceOf(source),
+			Subject:    r.TopOwner(ev.Cluster, ns, kind, name),
+			Result:     ResultOf(result),
+			Message:    truncate(message),
+			Evidence:   evidence,
+			ObservedAt: ev.At,
+		}
+		if rule != "" {
+			f.Properties = map[string]string{"rule": rule}
+		}
+		out = append(out, f)
+	}
+	return out
+}

+// ResourceFor returns the object one result of a report names: the first
+// entry of the result's resources, else the report's scope, else the report
+// itself.
+func ResourceFor(report *unstructured.Unstructured, result map[string]any) (kind, ns, name string) {
+	if rs, ok, _ := unstructured.NestedSlice(result, "resources"); ok && len(rs) > 0 {
+		if r, ok := rs[0].(map[string]any); ok {
+			kind, _, _ = unstructured.NestedString(r, "kind")
+			ns, _, _ = unstructured.NestedString(r, "namespace")
+			name, _, _ = unstructured.NestedString(r, "name")
+			if name != "" {
+				return
+			}
+		}
+	}
+	scope, _, _ := unstructured.NestedMap(report.Object, "scope")
+	if len(scope) > 0 {
+		kind, _ = scope["kind"].(string)
+		ns, _ = scope["namespace"].(string)
+		name, _ = scope["name"].(string)
+		if name != "" {
+			return
+		}
+	}
+	return "PolicyReport", report.GetNamespace(), report.GetName()
+}

+// ResultOf maps a producer result to a Result: skip is na, error and any
+// unknown word are not-measured.

+	switch strings.ToLower(strings.TrimSpace(result)) {
+	case "pass":
+		return compliance.Pass
+	case "fail":
+		return compliance.Fail
+	case "warn":
+		return compliance.Warn
+	case "skip", "na":
+		return compliance.NA
+	}
+	return compliance.NotMeasured

+// the engine; any other producer keeps its own name, which no check of the
+// fallback model names.

+	if s == "" || strings.EqualFold(s, "kyverno") {
+		return compliance.SourceKyverno
+	}
+	return compliance.Source(s)

+	}

+// withObserved returns base with one check of weight 1 on the first axis of
+// type checks for every check id of fs that base does not hold and whose
+// source has a producer today. Of the two producers the engine wins.
+func withObserved(base *Model, fs []Finding) *Model {
+	have := map[string]bool{}
+	for _, c := range base.Checks {
+		have[c.ID] = true
+	}
+	src := map[string]Source{}
+	for _, f := range fs {
+		if have[f.Check] || (f.Source != SourceKyverno && f.Source != SourceEvaluator) {
+			continue
+		}
+		if s, ok := src[f.Check]; !ok || (s == SourceEvaluator && f.Source == SourceKyverno) {
+			src[f.Check] = f.Source
+		}
+	}
+	if len(src) == 0 {
+		return base
+	}
+	axis := ""
+	for _, a := range base.Axes {
+		if a.Type == AxisTypeChecks {
+			axis = a.ID
+			break
+		}
+	}
+	ids := make([]string, 0, len(src))
+	for id := range src {
+		ids = append(ids, id)
+	}
+	sort.Strings(ids)
+	m := *base
+	m.Checks = append([]Check(nil), base.Checks...)
+	for _, id := range ids {
+		m.Checks = append(m.Checks, Check{ID: id, Title: id, Source: src[id], Axis: axis, Weight: 1})
+	}
+	return &m
+}

+// Checks returns the checks the cluster is scored with, in model order.
+func (rm *ReadModel) Checks(cluster string) []Check {
+	return append([]Check(nil), rm.view(cluster).model.Checks...)
+}

+// Rollup is the posture of one scope, with the Organization, Environment and
+// Application of the first subject of the scope in key order.
+type Rollup struct {
+	Posture
+	Organization, Environment, Application string
+}
+
+// Rollups returns the posture of the cluster and of every Application,
+// Environment and Organization a subject names, ordered by scope and id. It
+// returns nil when the cluster has no subject.
+func (rm *ReadModel) Rollups(cluster string) []Rollup {
+	v := rm.view(cluster)
+	if len(v.subjects) == 0 {
+		return nil
+	}
+	type scopeID struct{ scope, id string }
+	groups := map[scopeID][]Subject{}
+	for _, s := range v.subjects {
+		for _, g := range []scopeID{{ScopeApplication, s.Application}, {ScopeEnvironment, s.Environment}, {ScopeOrganization, s.Organization}, {ScopeSovereign, cluster}} {
+			if g.id != "" {
+				groups[g] = append(groups[g], s)
+			}
+		}
+	}
+	out := make([]Rollup, 0, len(groups))
+	for g, ss := range groups {
+		out = append(out, Rollup{Posture: ScopePosture(v.model, g.scope, g.id, cluster, ss, v.findingsOf(ss), nil),
+			Organization: ss[0].Organization, Environment: ss[0].Environment, Application: ss[0].Application})
+	}
+	sort.Slice(out, func(i, j int) bool { return out[i].Scope+"\x00"+out[i].ID < out[j].Scope+"\x00"+out[j].ID })
+	return out
+}

+// CheckResult is the effective result of one check on one subject and the
+// finding that decided it: the first finding of the check's source with that
+// result, or a zero Finding when a waiver or an exemption decided it.
+type CheckResult struct {
+	Check   string
+	Source  Source
+	Result  Result
+	Finding Finding
+}
+
+// SubjectView is the posture of one subject (scope workload) and the effective
+// result of every check that has a finding of its own source on the subject.
+type SubjectView struct {
+	Subject   Subject
+	Posture   Posture
+	Results   []CheckResult // in model order
+	UpdatedAt time.Time     // the newest ObservedAt of the subject's findings
+}
+
+func subjectView(v view, s Subject) SubjectView {
+	fs := v.bySubject[s.Key]
+	sv := SubjectView{Subject: s, Posture: ScopePosture(v.model, ScopeWorkload, s.Key.Name, s.Key.Cluster, []Subject{s}, fs, nil)}
+	idx := indexFindings(fs)
+	for _, f := range fs {
+		if f.ObservedAt.After(sv.UpdatedAt) {
+			sv.UpdatedAt = f.ObservedAt
+		}
+	}
+	for i := range v.model.Checks {
+		c := &v.model.Checks[i]
+		var own []Finding
+		for _, f := range idx[findingKey{subject: s.Key, check: c.ID}] {
+			if f.Source == c.Source {
+				own = append(own, f)
+			}
+		}
+		if len(own) == 0 {
+			continue
+		}
+		cr := CheckResult{Check: c.ID, Source: c.Source, Result: effectiveResult(v.model, s.Key, c, own, nil)}
+		for _, f := range own {
+			if f.Result == cr.Result {
+				cr.Finding = f
+				break
+			}
+		}
+		sv.Results = append(sv.Results, cr)
+	}
+	return sv
+}

+// Subject returns the view of subject k, and false when k has no finding.
+// The kind is matched without regard to case.
+func (rm *ReadModel) Subject(k SubjectKey) (SubjectView, bool) {
+	v := rm.view(k.Cluster)
+	for _, s := range v.subjects {
+		if s.Key.Namespace == k.Namespace && s.Key.Name == k.Name && strings.EqualFold(s.Key.Kind, k.Kind) {
+			return subjectView(v, s), true
+		}
+	}
+	return SubjectView{}, false
+}
+
+// Subjects returns the view of every subject of the cluster, in key order.
+func (rm *ReadModel) Subjects(cluster string) []SubjectView {
+	v := rm.view(cluster)
+	out := make([]SubjectView, 0, len(v.subjects))
+	for _, s := range v.subjects {
+		out = append(out, subjectView(v, s))
+	}
+	return out
+}
+
+// sortKey orders subjects by cluster, kind, namespace and name.
+func sortKey(k SubjectKey) string {
+	return strings.Join([]string{k.Cluster, k.Kind, k.Namespace, k.Name}, "\x00")
+}
+
+func sortSubjects(ss []Subject) {
+	sort.Slice(ss, func(i, j int) bool { return sortKey(ss[i].Key) < sortKey(ss[j].Key) })
+}
+
+// findingLess is a total order of findings: subject, check, evidence, message.
+func findingLess(a, b Finding) bool {
+	ka := strings.Join([]string{sortKey(a.Subject), a.Check, fmt.Sprint(a.Evidence), a.Message}, "\x00")
+	return ka < strings.Join([]string{sortKey(b.Subject), b.Check, fmt.Sprint(b.Evidence), b.Message}, "\x00")
+}

+// The labels a subject's Organization, Environment and Application are read
+// from, first match wins. They are the labels the aggregator read before this
+// package existed.
+var (
+	applicationLabels  = []string{"catalyst.openova.io/application", "openova.io/application", "app.kubernetes.io/instance", "app.kubernetes.io/name"}
+	environmentLabels  = []string{"catalyst.openova.io/environment", "openova.io/environment"}
+	organizationLabels = []string{"catalyst.openova.io/organization", "openova.io/organization"}
+)
+
+// ownerKinds are the controller kinds TopOwner walks through: a Pod to its
+// ReplicaSet, Job, StatefulSet or DaemonSet; a ReplicaSet to its Deployment;
+// a Job to its CronJob.
+var ownerKinds = map[string]bool{
+	"ReplicaSet": true, "Deployment": true, "StatefulSet": true,
+	"DaemonSet": true, "Job": true, "CronJob": true,
+}
+
+// maxOwnerDepth bounds the walk; the longest real chain is Pod, Job, CronJob.
+const maxOwnerDepth = 4
+
+// Lister reads the objects of one kind from the informer cache of a cluster.
+// *k8scache.Factory satisfies it.
+type Lister interface {
+	List(clusterID, kindName string, sel labels.Selector) ([]*unstructured.Unstructured, time.Duration, error)
+}
+
+type objectFacts struct {
+	labels map[string]string
+	owner  *ownerRef // the controller owner of a kind TopOwner walks through, nil when none
+}
+
+type ownerRef struct{ kind, name string }
+
+// CacheResolver answers the questions of Resolver from the objects it was
+// shown with Observe and, for an object it was not shown, from a Lister. It
+// never calls an API server.
+type CacheResolver struct {
+	lister Lister
+	now    func() time.Time
+
+	mu      sync.RWMutex
+	objects map[SubjectKey]objectFacts // Kind lower-cased
+}
+
+// NewCacheResolver returns a resolver over lister; lister may be nil.
+func NewCacheResolver(lister Lister) *CacheResolver {
+	return &CacheResolver{lister: lister, now: time.Now, objects: map[SubjectKey]objectFacts{}}
+}
+
+func lookupKey(cluster, namespace, kind, name string) SubjectKey {
+	return SubjectKey{Cluster: cluster, Namespace: namespace, Kind: strings.ToLower(kind), Name: name}
+}
+
+func factsOf(obj *unstructured.Unstructured) objectFacts {
+	f := objectFacts{labels: obj.GetLabels()}
+	for _, o := range obj.GetOwnerReferences() {
+		if o.Controller != nil && *o.Controller && ownerKinds[o.Kind] && o.Name != "" {
+			f.owner = &ownerRef{kind: o.Kind, name: o.Name}
+			break
+		}
+	}
+	return f
+}
+
+// Observe records the labels and the controller owner of the event's object,
+// or forgets them when the event is a deletion.
+func (r *CacheResolver) Observe(ev k8scache.Event) {
+	if ev.Object == nil || ev.Object.GetName() == "" {
+		return
+	}
+	k := lookupKey(ev.Cluster, ev.Object.GetNamespace(), ev.Object.GetKind(), ev.Object.GetName())
+	r.mu.Lock()
+	defer r.mu.Unlock()
+	if ev.Type == k8scache.EventDeleted {
+		delete(r.objects, k)
+		return
+	}
+	r.objects[k] = factsOf(ev.Object)
+}
+
+func (r *CacheResolver) facts(cluster, namespace, kind, name string) (objectFacts, bool) {
+	r.mu.RLock()
+	f, ok := r.objects[lookupKey(cluster, namespace, kind, name)]
+	r.mu.RUnlock()
+	if ok || r.lister == nil || kind == "" {
+		return f, ok
+	}
+	items, _, err := r.lister.List(cluster, strings.ToLower(kind), labels.Everything())
+	if err != nil {
+		return objectFacts{}, false
+	}
+	for _, it := range items {
+		if it.GetName() == name && it.GetNamespace() == namespace {
+			return factsOf(it), true
+		}
+	}
+	return objectFacts{}, false
+}
+
+// TopOwner follows controller ownerReferences through the cache and returns
+// the top controller, or the object itself when it has no controller owner or
+// is not in the cache. The walk stops at an owner the cache does not hold.
+func (r *CacheResolver) TopOwner(cluster, namespace, kind, name string) SubjectKey {
+	k := SubjectKey{Cluster: cluster, Namespace: namespace, Kind: kind, Name: name}
+	for i := 0; i < maxOwnerDepth; i++ {
+		f, ok := r.facts(cluster, namespace, k.Kind, k.Name)
+		if !ok || f.owner == nil {
+			break
+		}
+		k.Kind, k.Name = f.owner.kind, f.owner.name
+	}
+	return k
+}
+
+// Subject returns k with the Organization, Environment and Application read
+// from the labels of the object k names. Exposure is "other" for every
+// subject.
+func (r *CacheResolver) Subject(k SubjectKey) Subject {
+	f, _ := r.facts(k.Cluster, k.Namespace, k.Kind, k.Name)
+	s := Subject{
+		Key:          k,
+		Organization: labelOr(f.labels, organizationLabels),
+		Environment:  labelOr(f.labels, environmentLabels),
+		Application:  labelOr(f.labels, applicationLabels),
+		Exposure:     "other",
+	}
+	if i := strings.LastIndex(s.Environment, "-"); i >= 0 {
+		s.EnvironmentType = s.Environment[i+1:]
+	}
+	return s
+}
+
+// Now returns the time of the resolver's clock.
+func (r *CacheResolver) Now() time.Time { return r.now() }
+
+func labelOr(lbls map[string]string, keys []string) string {
+	for _, k := range keys {
+		if v := lbls[k]; v != "" {
+			return v
+		}
+	}
+	return ""
+}
