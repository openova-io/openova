# FND-039 — The suite writes the provision block of a cloud record

## In plain words

**The problem today.** The record checker refuses every record of a run in the cloud unless it describes the installation under test: its provider, when it was created and became ready, its nodes, and whether it is a fresh installation. The suite writes none of this, so the gate workflow can commit no record of a live run. The suite also cannot tell its regions apart on an environment installed since the bootstrap variables moved into a ConfigMap.

**What changes.** A run in the cloud measures the installation from the clusters at its end and writes the whole description into its record. A record counts as fresh only when the environment was created after the candidate was cut and nobody changed it by hand, so a standing environment that was updated in place is never fresh. The suite reads the bootstrap variables from the new ConfigMap and, on older environments, from the old place.

**Done means:**

- A record that the suite writes for a run in the cloud is accepted by the record checker.
- The record of a standing environment updated in place to a candidate says fresh false, and its creation time is the birth of the environment.
- The record of an installation made after the candidate was cut, with no change by hand at the start or the end of the run, says fresh true.
- A value that the suite cannot read fails the run and is named in the record; it is never guessed.
- The suite finds the region of each cluster on environments installed before and after the bootstrap variables moved into a ConfigMap.
- A run that is not in the cloud writes its record as before.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every `run` of the acceptance suite with `--run-in cloud` ends with a new discovery step `D0.11`. It reads the installation under test from the two clusters and writes the whole object `provision` of the record: `provider`, `created_at`, `ready_at`, `regions` and `fresh`, next to the two values of a wipe when the run was given them. `python3 scripts/acceptance-gate.py validate-record` accepts such a record, so the gate workflow `.github/workflows/foundation-gate.yaml` (FND-035) can commit the records of live runs. The record of a standing environment that was updated in place says `fresh: false` and carries the birth of that environment as `created_at`. Step `D0.2` reads the region of each cluster from the ConfigMap `flux-system/sovereign-variables` on environments installed since SOV-130, and from the Kustomization `bootstrap-kit` on older ones. A run that is not in the cloud writes its record exactly as before.

## 3. The model (the law)
1. The new file `tests/acceptance/sovereign/internal/suite/provision.go` holds step `D0.11` and its rules. Its tests are the new file `tests/acceptance/sovereign/internal/suite/provision_test.go`. Both are copied from the blocks of this ticket and fixed by their checksums.
2. The type `Provision` of `tests/acceptance/sovereign/internal/suite/result.go` becomes two embedded parts: `*Installation` (the fields `provider`, `created_at`, `ready_at`, `regions`, `fresh`) and `*PreviousWipe` (the fields `previous_deployment_id` and `previous_wipe_orphans`, with the Go names they have today). A part that is nil is left out of the record. The type `ProvisionRegion` is one entry of `regions`: `id`, `nodes_requested`, `nodes_ready`.
3. `Execute` in `runner.go` calls `measureProvision` once, after the gate checks and before `FinishedAt` is set, only when the mode is `run` and `--run-in` is `cloud`. A run with `--run-in local` never measures and never writes `Installation`; it writes `PreviousWipe` only when it is given the two flags of a wipe, as before.
4. Every value is read from the clusters with `kubectl get`. Only the requested node counts come from a flag (`--nodes-requested`). The rules:
   - `provider`: the value `PROVIDER` of the bootstrap variables of region A. Region B must report the same value.
   - The bootstrap variables of a region: the `data` of the ConfigMap `flux-system/sovereign-variables` when it exists (an environment installed since SOV-130), else `spec.postBuild.substitute` of the Kustomization `flux-system/bootstrap-kit`.
   - `created_at`: the earliest `metadata.creationTimestamp` of the namespace `kube-system` in the two regions. This is the birth of the environment, also when it was updated in place since. It is the same time that the gate workflow uses to judge a run.
   - `ready_at`: when the hand-over chain ended, read from the ConfigMap `catalyst/self-sovereign-cutover-status` of region A: `cutoverFinishedAt` when `cutoverComplete` is `true`, otherwise `step.<failedStep>.finishedAt` when `failedStep` is set.
   - `regions`: one entry per region, region A first: the region id of step `D0.2`, the nodes that `--nodes-requested` names for that id (`0` when it names none) and the nodes whose condition `Ready` is `True`.
   - `fresh`: `true` only when all of these hold: the run names a candidate; `created_at` was read and is later than the time at the start of the candidate id (the time the candidate was cut); and check FND-G02 passed at the start and at the end of the run in both regions (every step of FND-G02 that is not SKIP passed, and each region has a passing first look and a passing look at the end). An environment that was updated in place to a candidate was created before that candidate was cut, so its record is never fresh. The reason is written in the evidence of step `D0.11` as `fresh_reason`.
5. A value that cannot be read fails step `D0.11`, and with it the run (a step of `D0` that is not PASS fails the run). The record still holds the whole object: a time that was not read is `0001-01-01T00:00:00Z`, a provider that was not read is empty, and the error of the step names every value that was not read. A step that fails this way never stops the record from being written.
6. `regionIdentity` in `discover.go` reads `SOVEREIGN_REGION_KEY` and `CILIUM_LB_IPAM_CIDRS` from the bootstrap variables of rule 4 instead of from the Kustomization only. The two evidence texts of step `D0.2` that named the old place say "the bootstrap variables".
7. Nothing else changes: no flag, no file of `scripts/`, no workflow, no other check. The module keeps the Go standard library only.

// measureProvision records step D0.11 and writes the installation into the
// object provision of the record, next to the wipe values set before.
// requested is the value of --nodes-requested, nil when it was not given.
func (r *runner) measureProvision(ctx context.Context, requested map[string]int) {
	inst := &Installation{Regions: []ProvisionRegion{}}
	if r.run.Provision == nil {
		r.run.Provision = &Provision{}
	}
	r.run.Provision.Installation = inst
	prior := append([]*Step(nil), r.run.Steps...)
	r.step("D0", provisionStepID, "the installation under test: provider, creation, readiness, nodes, and whether it is fresh", func(ev Evidence) error {
		return measureInstallation(ctx, []kube.Region{r.A, r.B}, requested, r.run.Candidate.ID, prior, inst, ev)
	})
}

// measureInstallation fills inst from the regions, the first region first, and
// returns an error that names every value it could not read.
func measureInstallation(ctx context.Context, regions []kube.Region, requested map[string]int, candidateID string,
	prior []*Step, inst *Installation, ev Evidence) error {
	problems, sources := []string{}, []string{}
	var born time.Time
	bornRead := true
	for i, reg := range regions {
		entry := ProvisionRegion{ID: reg.ID, NodesRequested: requested[reg.ID]}
		vars, source, err := sovereignVariables(ctx, reg)
		switch {
		case err != nil:
			problems = append(problems, "provider: "+err.Error())
		case vars["PROVIDER"] == "":
			problems = append(problems, fmt.Sprintf("provider: the bootstrap variables of region %s (%s) have no PROVIDER", reg.ID, source))
		case i == 0:
			inst.Provider = vars["PROVIDER"]
		case inst.Provider != "" && vars["PROVIDER"] != inst.Provider:
			problems = append(problems, fmt.Sprintf("provider: region %s reports %s and region %s reports %s",
				reg.ID, vars["PROVIDER"], regions[0].ID, inst.Provider))
		}
		sources = append(sources, source)
		t, err := kubeSystemCreated(ctx, reg)
		if err != nil {
			bornRead = false
			problems = append(problems, "created_at: "+err.Error())
		} else if born.IsZero() || t.Before(born) {
			born = t
		}
		if nodes, err := reg.GetList(ctx, "nodes", ""); err != nil {
			problems = append(problems, "nodes_ready: "+err.Error())
		} else {
			for _, n := range nodes {
				if status, _, _, _ := n.Condition("Ready"); status == "True" {
					entry.NodesReady++
				}
			}
		}
		inst.Regions = append(inst.Regions, entry)
	}
	if bornRead {
		inst.CreatedAt = born
	}
	if at, source, err := handoverEnded(ctx, regions[0]); err != nil {
		problems = append(problems, "ready_at: "+err.Error())
	} else {
		inst.ReadyAt, ev["ready_source"] = at, source
	}
	inst.Fresh, ev["fresh_reason"] = freshness(candidateID, inst.CreatedAt, prior, regions)
	ev["variables"] = sources
	if len(problems) > 0 {
		return errors.New("not read: " + strings.Join(problems, "; "))
	}
	return nil
}

// getNamed returns the object of a kind with that name, and whether it exists.
// namespace "" is for a kind without a namespace.
func getNamed(ctx context.Context, reg kube.Region, resource, namespace, name string) (kube.Object, bool, error) {
	list, err := reg.GetList(ctx, resource, namespace, "--field-selector", "metadata.name="+name)
	if err != nil {
		return nil, false, err
	}
	for _, o := range list {
		if o.Name() == name {
			return o, true, nil
		}
	}
	return nil, false, nil
}

// freshness says whether the record is of a fresh installation, and why.
func freshness(candidateID string, created time.Time, prior []*Step, regions []kube.Region) (bool, string) {
	stamp, _, _ := strings.Cut(candidateID, "-")
	cut, err := time.Parse("20060102T150405Z", stamp)
	switch {
	case candidateID == "":
		return false, "not fresh: the run names no candidate"
	case err != nil:
		return false, "not fresh: the candidate id " + candidateID + " does not start with the time it was cut"
	case created.IsZero():
		return false, "not fresh: the creation time of the environment was not read"
	case !created.After(cut):
		return false, fmt.Sprintf("not fresh: the environment was created at %s, before candidate %s was cut at %s, so it was updated in place",
			created.Format(time.RFC3339), candidateID, cut.Format(time.RFC3339))
	}
	if held, why := zeroTouchHeld(prior, regions); !held {
		return false, "not fresh: " + why
	}
	return true, "fresh: created after the candidate was cut, and check " + zeroTouchID + " passed at the start and at the end in every region"
}

// zeroTouchHeld says whether check FND-G02 passed at the start and at the end
// of the run in every region. Its steps (check_zero_touch.go) are, per region,
// a first look FND-G02.start.<n>, a step that points at it (evidence
// start_step) and a look at the end; the clause it cannot measure is SKIP.
func zeroTouchHeld(prior []*Step, regions []kube.Region) (bool, string) {
	for _, s := range prior {
		if s.Journey == zeroTouchID && s.Status != Pass && s.Status != Skip {
			return false, fmt.Sprintf("check %s failed in step %s: %s", zeroTouchID, s.ID, s.Error)
		}
	}
	for _, reg := range regions {
		start, end := false, false
		for _, s := range prior {
			if s.Journey != zeroTouchID || s.Status != Pass || s.Evidence["region"] != reg.ID {
				continue
			}
			_, pointer := s.Evidence["start_step"]
			start = start || strings.HasPrefix(s.ID, zeroTouchID+".start.")
			end = end || (!pointer && !strings.HasPrefix(s.ID, zeroTouchID+".start."))
		}
		if !start {
			return false, fmt.Sprintf("check %s took no passing look at region %s at the start of the run", zeroTouchID, reg.ID)
		}
		if !end {
			return false, fmt.Sprintf("check %s took no passing look at region %s at the end of the run", zeroTouchID, reg.ID)
		}
	}
	return true, ""
}
