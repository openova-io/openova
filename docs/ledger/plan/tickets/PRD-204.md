# PRD-204 — cortex ingestion of uploads: job table, upload and document routes, index process, text parser, chunker, events stream

## In plain words

**The problem today.** The document search can search, but nothing puts a document into it. There is no way to upload a file, no process that turns a file into searchable passages, and no way to read, download, delete or follow a document. The loader of the defined sources exists but nothing runs it.

**What changes.** A manager uploads a text file to a source, with an optional list of readers. A second process takes each upload from a job table, splits it into passages, embeds them through the model gateway and makes them searchable; readers can fetch the document and its original and follow job changes as a live stream, and a manager can delete it.

**Done means:**

- An upload by a manager of an upload source is answered with the new document and its job, and an upload by anyone else, to another kind of source, of a file that is too large or of a type that is not text is refused.
- A document uploaded with its own reader list is readable only by those readers and the managers of its source.
- The index process applies the defined sources, claims each queued job once, retries a failed one after 1, 5 and 25 minutes, and wakes on a database notification instead of polling.
- A text upload becomes passages that start with the document title and their heading path, each embedded through the model gateway.
- A reader gets the document, its original bytes and a live stream of the jobs it may see; a manager deletes a document and its original.
- Removing a source from the definitions also deletes the originals of its documents.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`products/cortex` takes documents in. The query process (`cortex query`) gains `POST /v1/sources/{id}/documents`, `GET /v1/documents/{id}`, `GET /v1/documents/{id}/content`, `DELETE /v1/documents/{id}` and `GET /v1/events`, all behind the token check that already guards every route. An upload stores the original in the originals bucket (contract `object-storage` v1, signed with AWS Signature Version 4) and queues an `index` job; the query process writes nothing else, as its database role allows. The second command of the same binary, `cortex index`, connects with the role `cortex_index`, runs the definitions loader of PRD-203, and runs the job table's claim loop: an index job records the document (with its own reader list when the upload named readers), parses the text, chunks it, embeds the chunks through the model gateway and writes them; a delete job removes the original and the document. Migration `0002` adds the connector type and chunk settings of a source, the job's item, and a trigger that sends `NOTIFY cortex_job` on every insert and state change of a job, which wakes the claim loop and feeds the events stream. A person sees it this way: the checks `go vet and go test — products/cortex` and `go test with PostgreSQL — products/cortex` are green on the pull request with the new subtests of `TestPostgresStore`, and `TestUploadRoute`, `TestEventsStream` and `TestIndexServesAndStops` pass.

## 3. The model (the law)
1. `POST /v1/sources/{id}/documents` decides in this order, before it reads the body: a caller that does not manage the source (no `source_acl` row with role `manager` for one of its principals), also for a source that does not exist, gets 403 `not-manager`; a source whose connector type is not `upload` gets 409 `not-an-upload-source`. Then the body must be multipart with exactly one part `file`, at most 100 parts `reader` and no other part, else 400 `invalid-request`; a body over the upload limit plus 1 MiB, or a file over the limit, gets 413 `too-large`; a reader that is not of the form `^(user|group|agent):[^\s]{1,200}$|^org:members$` or that the store refuses gets 400 `invalid-reader`; the type is decided by sniffing the first 512 bytes, and only `text/plain; charset=utf-8` is allowed, else 415 `type-not-allowed`. The limit is `--max-upload-mb` (1 to 1024, default 50), which the chart sets from `policy.maxUploadMb`.
2. An accepted upload stores the original under `<document id>/<SHA-256 of the content>` and queues one job `index` whose item is `{"externalId": "upload:<id>", "title", "uri": "/v1/documents/<id>/content", "mediaType": "text/plain", "sha256", "object", "readers"}`; the title is the file name without control characters, at most 200 characters, or `upload`. The answer is 202 `{"documentId", "jobId"}`. With at least one reader the document is readable only by those readers and the managers of its source.
3. `GET /v1/documents/{id}` answers 200 `{"id", "sourceId", "title", "uri", "state", "updatedAt"}` for a document the caller may read (row-level security decides) and 404 `document-not-found` otherwise, also for an id that is not a UUID. `GET /v1/documents/{id}/content` answers the original bytes as `application/octet-stream`, an attachment, with `X-Content-Type-Options: nosniff`, and 404 when the document is not readable or its original is gone. `DELETE /v1/documents/{id}` answers 404 for a document the caller cannot read, 403 `not-manager` for one whose source it does not manage, and otherwise queues a job `delete` whose item holds the document's object and answers 202 `{"jobId"}`.
4. `GET /v1/events` is a `text/event-stream`: a comment line `: connected`, then one frame `event: job` with `data: {"jobId", "sourceId", "documentId", "kind", "state", "at"}` for each insert or state change of a job whose document the caller reads or whose source it manages (a job without a document: whose source it reads or manages), and a comment line `: keep-alive` after each 20 seconds without a write. The keep-alive comes from a timer that every write resets; nothing polls. A stream ends after 5 minutes and the client opens another with a current token. A subscriber more than 64 events behind loses events and never holds up the hub or another subscriber.
5. Migration `0002` (embedded below) adds `source.connector`, `source.chunk_tokens` (128 to 2048, default 512) and `source.chunk_overlap` (0 to 256 and less than the tokens, default 64), `job.item`, an index of due jobs and the trigger `job_notify` that runs `pg_notify('cortex_job', <job id>)` after every insert and every update of the state of a job. A source that migration `0001` left has no connector until the loader applies the definitions again, and takes no upload before.
6. The claim loop: a claim takes the oldest job that is queued, failed, or running with its lease run out, and is due, with `FOR UPDATE SKIP LOCKED`; it sets it running, adds one attempt and holds it for a lease of 30 minutes. A finished job is `done`. A failed job is `failed` and due again after 1, 5 and 25 minutes; it is `dead` when its fourth run fails, when the handler's error wraps `jobs.ErrPermanent`, and when it is claimed after the lease of its fourth run ran out (it does not run then). The worker runs a claim pass when it starts, on every notification of `cortex_job`, and when the next job is due by the database's clock; there is no polling loop.
7. An index job records the document as `fetched`, with its own reader list and `acl_inherit` false when the item names readers, in one transaction under the shared advisory lock that `ReplaceChunks` takes, and reads the chunk settings of its source. If the source was removed it deletes the original and is dead. It reads the original, parses it with the text parser, chunks it, embeds the chunks in calls of at most 32 through the gateway and replaces the document's chunks; the document is then `indexed`, or `failed` when a step failed. When the original is gone (a delete ran while the job waited for a retry) it deletes the document and is dead.
8. A delete job deletes the object of its item, then the document, whose chunks and reader list go with it. `ApplyDefinitions` queues one delete job, with the document's object, for each document of a source it removes, in the transaction that removes it.
9. The text parser reads `text/plain` and `text/markdown`: a line of one to six `#` and a space is a heading, a block of list items is a list, a block of lines that start with `|` is a table, a fenced block is a paragraph kept as it is, every other block is a paragraph; the title is the first heading of level 1; bytes that are not UTF-8 are replaced. Its output is the parsed document `openova.io/parsed-document/v1`.
10. The chunker splits on headings first, then cuts each section into windows of at most `chunk.tokens` tokens that overlap by `chunk.overlap`; a token is a run of characters without white space, and the white space after it is kept. Each chunk starts with the document title and its heading path joined by ` > `, then an empty line; its page is the page of its first token.
11. The definitions parser reads the connector type and `chunk` of each source. A missing `chunk` or key takes the schema's default; `null`, another key, a value that is not a whole number, a value out of range and an overlap that is not less than the tokens are refused, so the whole version is refused. A key the schema requires stays refused when it is missing or null, as before.
12. `cortex index` takes `--database-url-file`, `--embed-alias`, `--embed-dimensions`, `--originals-dir`, `--namespace` (default: the namespace of its service account), `--definitions-configmap` (default `cortex-definitions`), `--model-gateway-url`, `--model-key-file` and `--health-listen`, and serves `/healthz`, `/readyz` and `/metrics` there only. `cortex query` gains `--originals-dir` (required) and `--max-upload-mb`.
13. The originals binding is the folder of the contract's files: `endpoint` (`https://host[:port]` only), `region`, `bucket`, `path-style` (`true` or `false`) and, when present, `ca.crt`. The keys `access-key-id` and `secret-access-key` are read from their files on every call. An object key this package does not make is never sent. No log line holds a file's content, its name or a reader.

// Package chunk splits a parsed document into the chunks that are embedded and searched.
//
// It splits on headings first: the elements between two headings form a section. A section is
// then cut into windows of at most tokens tokens, each window but the first starting overlap
// tokens before the end of the one before it. A token is a run of characters without white
// space; the white space after it is kept, so a list or a table keeps its lines. Each chunk
// starts with one line that names the document's title and the path of headings above it,
// joined by " > ", and an empty line. The page of a chunk is the page of its first token.
package chunk

import (
	"regexp"
	"strings"

	"github.com/openova-io/openova/products/cortex/internal/parse"
)

// Piece is one chunk of a document, numbered from 0 in document order.
type Piece struct {
	Ordinal int
	Page    int
	Text    string
}

var token = regexp.MustCompile(`\S+\s*`)

type word struct {
	text string
	page int
}

// Split returns the chunks of doc. title is used when the parsed document has none. tokens is
// at least 1 and overlap is less than tokens; the store keeps both in their ranges.
func Split(doc parse.Document, title string, tokens, overlap int) []Piece {
	if doc.Title != "" {
		title = doc.Title
	}
	tokens = max(tokens, 1)
	if overlap < 0 || overlap >= tokens {
		overlap = 0
	}
	var out []Piece
	var path []string // the headings above, by level; "" for a level that is skipped
	var words []word
	flush := func() {
		head := []string{title}
		for i, h := range path {
			if h != "" && (i > 0 || h != title) {
				head = append(head, h)
			}
		}
		prefix := strings.Join(head, " > ") + "\n\n"
		for start := 0; start < len(words); start += tokens - overlap {
			end := min(start+tokens, len(words))
			var b strings.Builder
			b.WriteString(prefix)
			for _, w := range words[start:end] {
				b.WriteString(w.text)
			}
			out = append(out, Piece{Ordinal: len(out), Page: words[start].page, Text: strings.TrimSpace(b.String())})
			if end == len(words) {
				break
			}
		}
		words = nil
	}
	for _, el := range doc.Elements {
		if el.Type == "heading" && el.Level >= 1 && el.Level <= 6 {
			flush()
			for len(path) < el.Level {
				path = append(path, "")
			}
			path = append(path[:el.Level-1], el.Text)
			continue
		}
		found := token.FindAllString(el.Text, -1)
		for i, t := range found {
			if i == len(found)-1 {
				t = strings.TrimRight(t, " \t\r\n") + "\n\n"
			}
			words = append(words, word{text: t, page: el.Page})
		}
	}
	flush()
	return out
}

// Package events carries the changes of jobs to the callers of GET /v1/events in the query
// process. A Hub listens on cortex_job (every insert and state change of a job notifies it),
// reads the job, and hands one Event to every subscriber. A subscriber that does not keep up
// loses events and never holds up the hub or another subscriber: an event is a hint, and the
// client reads the current state again. Which subscriber may see an event is decided by the
// subscriber, with its own principals.
package events

import (
	"context"
	"log/slog"
	"sync"
	"time"

	"github.com/openova-io/openova/products/cortex/internal/store"
)

// Event is the data of one frame of the stream.
type Event struct {
	JobID      string    `json:"jobId"`
	SourceID   string    `json:"sourceId"`
	DocumentID string    `json:"documentId"`
	Kind       string    `json:"kind"`
	State      string    `json:"state"`
	At         time.Time `json:"at"`
}

// Source is where the hub learns of jobs; *store.Postgres is one.
type Source interface {
	Listen(ctx context.Context, fn func(jobID string)) error
	Job(ctx context.Context, id string) (store.Job, error)
}

// Buffer is the number of events a subscriber may hold before the hub drops its events.
const Buffer = 64

// Hub hands events to subscribers.
type Hub struct {
	mu   sync.Mutex
	subs map[chan Event]struct{}
}

// NewHub returns a hub without subscribers.
func NewHub() *Hub { return &Hub{subs: map[chan Event]struct{}{}} }

// Subscribe returns the events from now on, and the function that ends the subscription.
func (h *Hub) Subscribe() (<-chan Event, func()) {
	ch := make(chan Event, Buffer)
	h.mu.Lock()
	h.subs[ch] = struct{}{}
	h.mu.Unlock()
	return ch, func() {
		h.mu.Lock()
		delete(h.subs, ch)
		h.mu.Unlock()
	}
}

// Publish hands e to every subscriber that has room for it, without waiting.
func (h *Hub) Publish(e Event) {
	h.mu.Lock()
	defer h.mu.Unlock()
	for ch := range h.subs {
		select {

		case <-ctx.Done():
		case <-time.After(reconnect):
		}

		writeError(w, http.StatusBadRequest, "invalid-request")
		return

		writeError(w, http.StatusBadRequest, "invalid-reader")
		return

// the connection open and polls nothing. A stream ends after StreamFor; the client opens
// another with a current token.
func (s *Server) events(w http.ResponseWriter, r *http.Request, c auth.Caller) {
	heartbeat, streamFor := s.cfg.Heartbeat, s.cfg.StreamFor
	if heartbeat <= 0 {
		heartbeat = 20 * time.Second
	}
	if streamFor <= 0 {
		streamFor = 5 * time.Minute
	}
	ctx, cancel := context.WithTimeout(r.Context(), streamFor)
	defer cancel()
	ch, stop := s.cfg.Hub.Subscribe()
	defer stop()
	rc := http.NewResponseController(w)
	w.Header().Set("Content-Type", "text/event-stream")
	w.Header().Set("Cache-Control", "no-store")
	w.WriteHeader(http.StatusOK)
	idle := time.NewTimer(heartbeat)
	defer idle.Stop()
	send := func(text string) bool {
		idle.Reset(heartbeat)
		if _, err := io.WriteString(w, text); err != nil {
			return false
		}
		return rc.Flush() == nil
	}
	if !send(": connected\n\n") {
		return
	}
	for {
		select {
		case <-ctx.Done():
			return
		case <-idle.C:
			if !send(": keep-alive\n\n") {
				return
			}
		case e := <-ch:
			if ok, err := s.cfg.Store.MayWatch(ctx, c.Principals, e.SourceID, e.DocumentID); err != nil || !ok {
				continue
			}
			data, _ := json.Marshal(e)
			if !send(fmt.Sprintf("event: job\ndata: %s\n\n", data)) {
				return
			}
		}
	}
}

		return nil, fmt.Errorf("ingest: path-style is %q, not true or false", values["path-style"])

	_ = resp.Body.Close()

func (b *Bucket) do(ctx context.Context, method, key string, body io.Reader, size int64, sum string) (*http.Response, error) {
	if !objectKey.MatchString(key) {
		return nil, fmt.Errorf("ingest: %q is not an object key", key)
	}
	var keys [2]string
	for i, name := range []string{"access-key-id", "secret-access-key"} {
		v, err := os.ReadFile(filepath.Clean(filepath.Join(b.dir, name)))
		if err != nil || len(strings.TrimSpace(string(v))) == 0 {
			return nil, fmt.Errorf("ingest: the binding has no readable %s", name)
		}
		keys[i] = strings.TrimSpace(string(v))
	}
	req, err := http.NewRequestWithContext(ctx, method, b.base+"/"+key, body)
	if err != nil {
		return nil, err
	}
	if body != nil {
		req.ContentLength = size
	}
	req.Header.Set("x-amz-content-sha256", sum)
	sign(req, keys[0], keys[1], b.region, b.now())
	resp, err := b.http.Do(req)
	if err != nil {

	}

// sign adds the headers x-amz-date and Authorization of AWS Signature Version 4 for the
// service s3. It signs host and every header named range or x-amz-*; the header
// x-amz-content-sha256 must hold the payload's digest. The request has no query.
func sign(req *http.Request, accessKey, secretKey, region string, t time.Time) {
	stamp := t.UTC().Format("20060102T150405Z")
	req.Header.Set("x-amz-date", stamp)
	names := []string{"host"}
	for k := range req.Header {
		if lk := strings.ToLower(k); lk == "range" || strings.HasPrefix(lk, "x-amz-") {
			names = append(names, lk)
		}
	}
	sort.Strings(names)
	var headers strings.Builder
	for _, n := range names {
		v := req.URL.Host
		if n != "host" {
			v = strings.TrimSpace(req.Header.Get(n))
		}
		headers.WriteString(n + ":" + v + "\n")
	}
	signed := strings.Join(names, ";")
	canonical := strings.Join([]string{req.Method, req.URL.EscapedPath(), req.URL.RawQuery, headers.String(), signed,
		req.Header.Get("x-amz-content-sha256")}, "\n")
	scope := stamp[:8] + "/" + region + "/s3/aws4_request"
	digest := sha256.Sum256([]byte(canonical))
	toSign := "AWS4-HMAC-SHA256\n" + stamp + "\n" + scope + "\n" + hex.EncodeToString(digest[:])
	k := []byte("AWS4" + secretKey)
	for _, part := range []string{stamp[:8], region, "s3", "aws4_request", toSign} {
		m := hmac.New(sha256.New, k)
		m.Write([]byte(part))
		k = m.Sum(nil)
	}
	req.Header.Set("Authorization", "AWS4-HMAC-SHA256 Credential="+accessKey+"/"+scope+",SignedHeaders="+signed+
		",Signature="+hex.EncodeToString(k))
}

// content is read twice and must hold size bytes; readers is the document's own reader list.
func (in *Intake) Upload(ctx context.Context, sourceID, filename string, content io.ReadSeeker, size int64, readers []string) (documentID, jobID string, err error) {
	head := make([]byte, 512)
	n, err := io.ReadFull(content, head)
	if err != nil && !errors.Is(err, io.ErrUnexpectedEOF) && !errors.Is(err, io.EOF) {
		return "", "", err
	}
	mediaType, ok := MediaTypes[http.DetectContentType(head[:n])]
	if !ok {
		return "", "", ErrType
	}
	h := sha256.New()
	if _, err := content.Seek(0, io.SeekStart); err != nil {
		return "", "", err
	}
	if _, err := io.Copy(h, content); err != nil {
		return "", "", err
	}
	if _, err := content.Seek(0, io.SeekStart); err != nil {
		return "", "", err
	}
	sum := hex.EncodeToString(h.Sum(nil))
	documentID = newID()
	it := Item{ExternalID: "upload:" + documentID, Title: title(filename), URI: "/v1/documents/" + documentID + "/content",
		MediaType: mediaType, SHA256: sum, Object: documentID + "/" + sum, Readers: readers}
	if err := in.Objects.Put(ctx, it.Object, content, size, sum); err != nil {
		return "", "", err
	}
	item, _ := json.Marshal(it)
	jobID, err = in.Queue.Enqueue(ctx, store.Job{Kind: "index", SourceID: sourceID, DocumentID: documentID, Item: item})
	if err != nil {
		return "", "", err
	}
	return documentID, jobID, nil

		return errors.Join(fmt.Errorf("%w: the original was deleted", jobs.ErrPermanent), x.Store.DeleteDocument(ctx, j.DocumentID))
	}

	}
	return x.Store.MarkDocument(ctx, j.DocumentID, "indexed")
}

func (x *Indexer) write(ctx context.Context, id string, it Item, settings store.ChunkSettings) error {
	rc, _, err := x.Objects.Get(ctx, it.Object)
	if err != nil {
		return err
	}
	defer func() { _ = rc.Close() }()
	doc, err := x.Parser.Parse(ctx, it.MediaType, rc)
	if errors.Is(err, parse.ErrMediaType) {
		return fmt.Errorf("%w: %v", jobs.ErrPermanent, err)
	}
	if err != nil {
		return err
	}
	pieces := chunk.Split(doc, it.Title, settings.Tokens, settings.Overlap)
	chunks := make([]store.Chunk, 0, len(pieces))
	for start := 0; start < len(pieces); start += embedBatch {
		batch := pieces[start:min(start+embedBatch, len(pieces))]
		texts := make([]string, len(batch))
		for i, p := range batch {
			texts[i] = p.Text
		}
		vectors, err := x.Embedder.Embed(ctx, texts)
		if err != nil {
			return err
		}
		if len(vectors) != len(batch) {
			return fmt.Errorf("ingest: %d vectors for %d chunks", len(vectors), len(batch))
		}
		for i, p := range batch {
			chunks = append(chunks, store.Chunk{Ordinal: p.Ordinal, Page: p.Page, Text: p.Text, Embedding: vectors[i]})
		}
	}
	return x.Store.ReplaceChunks(ctx, id, chunks, nil)
}

// Package jobs runs the job table's claim loop in the index process.
//
// A job's life: queued, then running, then done; or failed, due again after 1, 5 and 25
// minutes, and dead when it fails once more after its third retry. A job whose handler returns
// an error that wraps ErrPermanent is dead at once. A claim holds a running job for a lease;
// a job whose process ended while it ran is due again when the lease runs out, and that counts
// as an attempt. The claim takes the oldest due job with FOR UPDATE SKIP LOCKED, so two index
// processes never run one job together.
//
// There is no polling loop. The worker runs one claim pass when it starts and whenever LISTEN
// cortex_job delivers a notification (every insert and state change of a job sends one), and
// otherwise sleeps until the next job is due.
package jobs

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"time"

	"github.com/openova-io/openova/products/cortex/internal/store"
)

// ErrPermanent is wrapped by a handler's error that no retry can mend.
var ErrPermanent = errors.New("jobs: permanent")

// Retries are the delays before the retries of a failed job.
var Retries = []time.Duration{time.Minute, 5 * time.Minute, 25 * time.Minute}

// Lease is how long a claim holds a running job; Reconnect is the delay before LISTEN, or a
// read of the next due job, is tried again after it failed.
const (
	Lease     = 30 * time.Minute
	Reconnect = 5 * time.Second
)

// Queue is the part of the store the worker uses; *store.Postgres is one.
type Queue interface {
	Claim(ctx context.Context, lease time.Duration) (*store.Job, error)
	NextDue(ctx context.Context) (time.Duration, bool, error)
	Finish(ctx context.Context, id string) error
	Fail(ctx context.Context, id, message string, retry time.Duration, dead bool) error
	Listen(ctx context.Context, fn func(jobID string)) error
}

// Worker claims jobs and hands each to Handle.
type Worker struct {
	Queue  Queue
	Handle func(ctx context.Context, j store.Job) error
	Log    *slog.Logger
}

// Run claims and runs jobs until ctx ends.
func (w *Worker) Run(ctx context.Context) error {
	wake := make(chan struct{}, 1)
	poke := func(string) {
		select {
		case wake <- struct{}{}:
		default:
		}
	}
	go func() {
		for ctx.Err() == nil {
			if err := w.Queue.Listen(ctx, poke); err != nil {
				w.Log.Warn("jobs: LISTEN cortex_job failed; it is tried again", "error", err.Error())
			}
			select {
			case <-ctx.Done():
			case <-time.After(Reconnect):
			}
		}
	}()
	for {
		w.pass(ctx)
		// The pass ended on a claim that found nothing, so a job that is due now is held by
		// another claim for a moment: wait a little for it rather than spin.
		var due <-chan time.Time
		if in, ok, err := w.Queue.NextDue(ctx); err != nil {
			w.Log.Warn("jobs: the next due job cannot be read", "error", err.Error())
			due = time.After(Reconnect)
		} else if ok {
			due = time.After(max(in, 50*time.Millisecond))
		}
		select {
		case <-ctx.Done():
			return nil
		case <-wake:
		case <-due:
		}
	}
}

// pass runs due jobs until none is due.
func (w *Worker) pass(ctx context.Context) {
	for ctx.Err() == nil {
		j, err := w.Queue.Claim(ctx, Lease)
		if err != nil {
			w.Log.Warn("jobs: claim failed", "error", err.Error())
			return
		}
		if j == nil {
			return
		}
		w.run(ctx, *j)
	}
}

// run runs one claimed job and records how it ended.
func (w *Worker) run(ctx context.Context, j store.Job) {
	var err error
	if j.Attempts > len(Retries)+1 {
		err = fmt.Errorf("%w: the lease of its last attempt ran out", ErrPermanent)
	} else {
		err = w.Handle(ctx, j)
	}
	log := w.Log.With("job", j.ID, "kind", j.Kind, "attempt", j.Attempts)
	if err == nil {
		if err := w.Queue.Finish(ctx, j.ID); err != nil {
			log.Warn("jobs: done, but not recorded; it runs again when the lease runs out", "error", err.Error())
		}
		return
	}
	dead := errors.Is(err, ErrPermanent) || j.Attempts > len(Retries)
	var retry time.Duration
	if !dead {
		retry = Retries[j.Attempts-1]
	}
	log.Warn("jobs: failed", "error", err.Error(), "dead", dead, "retry", retry.String())
	if err := w.Queue.Fail(context.WithoutCancel(ctx), j.ID, err.Error(), retry, dead); err != nil {
		log.Warn("jobs: the failure was not recorded; it runs again when the lease runs out", "error", err.Error())
	}
}

// Text parses plain text and Markdown: a line that starts with one to six # is a heading, a
// block of lines that are all list items is a list, a block of lines that all start with | is a
// table, a fenced block is a paragraph kept as it is, and every other block of lines without an
// empty line is a paragraph. The title is the first heading of level 1. Bytes that are not
// UTF-8 are replaced.
type Text struct{}

// Parse reads content of the media type text/plain or text/markdown.
func (Text) Parse(_ context.Context, mediaType string, content io.Reader) (Document, error) {
	if mediaType != "text/plain" && mediaType != "text/markdown" {
		return Document{}, ErrMediaType
	}
	raw, err := io.ReadAll(content)
	if err != nil {
		return Document{}, err
	}
	text := strings.ReplaceAll(strings.ToValidUTF8(string(raw), "�"), "\r\n", "\n")
	doc := Document{Schema: Schema, Elements: []Element{}}
	var block []string
	fence := ""
	flush := func() {
		if len(block) > 0 {
			doc.Elements = append(doc.Elements, Element{Type: kind(block, fence != ""), Text: strings.Join(block, "\n")})
		}
		block = nil
	}
	for _, line := range strings.Split(text, "\n") {
		trimmed := strings.TrimSpace(line)
		switch {
		case fence != "":
			block = append(block, line)
			if strings.HasPrefix(trimmed, fence) {
				flush()
				fence = ""
			}
		case strings.HasPrefix(trimmed, "```") || strings.HasPrefix(trimmed, "~~~"):
			flush()
			fence = trimmed[:3]
			block = append(block, line)
		case trimmed == "":
			flush()
		case heading.MatchString(line):
			flush()
			m := heading.FindStringSubmatch(line)
			doc.Elements = append(doc.Elements, Element{Type: "heading", Level: len(m[1]), Text: m[2]})
			if doc.Title == "" && len(m[1]) == 1 {
				doc.Title = m[2]
			}
		default:
			block = append(block, line)
		}
	}
	flush()
	return doc, nil
}

// kind returns the type of a block of lines.
func kind(block []string, fenced bool) string {
	if fenced {
		return "paragraph"
	}
	list, table := true, true
	for _, l := range block {
		list = list && listItem.MatchString(l)
		table = table && strings.HasPrefix(strings.TrimSpace(l), "|")
	}
	switch {
	case table:
		return "table"
	case list:
		return "list"
	}
	return "paragraph"
}
