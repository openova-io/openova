# CTL-160 — Package intent: validate, serialise, commit, wait

## In plain words

**The problem today.** The routes of the platform's API write objects straight into the cluster. The plan moves those writes to Git, so that a commit records every change and Flux applies it. The commit library exists, but nothing yet turns a route's object into a checked, canonical file, commits it with the right conditions, and tells the route when the cluster has picked it up.

**What changes.** A new package of the API takes the objects of one change, checks each against its definition, writes them to Git in one commit or recognises that nothing changed, and then waits until the cluster cache shows the change. A small tool can stop Flux from applying one kind again, for a rollback. No route uses the package yet.

**Done means:**

- An object that breaks its definition is refused with the names of the wrong fields, and nothing is committed.
- Several objects of one change land in one Git commit, and a repeated identical request makes no commit.
- A request that names an outdated version of a file is refused as a conflict and changes nothing.
- After a commit the package reports whether the cluster cache carried the change within the wait time.
- The rollback tool can set and remove the Flux pause annotation on every object of one kind.
- The tests of the bootstrap API also run when a definition file changes, so an outdated copy of the definitions is found on that pull request.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The catalyst-api module (`products/catalyst/bootstrap/api`) gains the Go package `internal/intent` (import path `github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/intent`). A route that changes intent will hand it the objects of one change. The package validates each object against the schema of its kind, which it embeds; adds the label `app.kubernetes.io/managed-by: flux` and the annotation `catalyst.openova.io/change-id`; serialises each object to the canonical bytes of an intent file; detects a no-op; commits every file in one commit through the commit library `gitwrite` (`core/controllers/pkg/gitwrite`, from CTL-110); and waits on the informer cache until every object carries the new change identifier or is gone, for at most the sync wait. `cmd/api/intent_wire.go` adapts the informer cache (`internal/k8scache`) to the package and builds its dependencies from the environment. `scripts/intent-detach.py` sets or removes the Flux annotation `kustomize.toolkit.fluxcd.io/reconcile: disabled` on every object of one kind; it is the rollback tool of the packages that move routes onto `intent`. The workflow `.github/workflows/test-bootstrap-api.yaml` also runs when a definition file that the package embeds changes. No route calls the package yet: CTL-162 is the first.

## 3. The model (the law)
The seven program files of this ticket are complete and embedded. The schema bundle is generated by a test of the package. The workflow gets three exact edits. These are the rules the files implement, so that a reader can check them; you do not write any of it.

1. **Surface.** Package `intent` declares exactly: the constants `ChangeIDAnnotation = "catalyst.openova.io/change-id"`, `ManagedByLabel = "app.kubernetes.io/managed-by"`, `ManagedByValue = "flux"`, `DefaultSyncWait = 15 * time.Second`; the types `Deps` (fields `Git gitwrite.Writer`, `Cache ObjectCache`, `ClusterID string`, `FQDN string`, `SyncWait time.Duration`), `ObjectCache` (methods `Get(clusterID, kind, namespace, name string) *unstructured.Unstructured` and `Watch(clusterID, kind string) (events <-chan CacheEvent, cancel func())`), `CacheEvent` (`Type` one of `ADDED`, `MODIFIED`, `DELETED`; `Object`), `Target` (`APIVersion`, `Kind`, `Namespace`, `Name`, `Path`, `Op gitwrite.Op`), `Outcome` (`ChangeID`, `Commit`, `Noop`, `Applied`, `Targets`, `ETag`) and `SchemaError` (`Kind`, `Name`, `Errors field.ErrorList`); the error `ErrInvalid`; and the functions `Validate(obj) field.ErrorList`, `Serialize(obj) ([]byte, error)` and `Submit(ctx, d Deps, scope gitwrite.Scope, repo gitwrite.Repo, upserts []*unstructured.Unstructured, deletes []Target, pathOf func(*unstructured.Unstructured) string, summary string, author gitwrite.Identity, via gitwrite.Via, ifMatch string, trailers map[string]string) (Outcome, error)`.
2. **The cache kind.** A kind in `ObjectCache` is the cache's kind name: the object's `kind` in lower case (`Application` is `application`). `Deps.ClusterID` is the cache's identifier of the cluster that applies the intent; `Submit` reads and watches that cluster only.
3. **Validate.** An object needs `apiVersion`, `kind` and `metadata.name`; each one that is missing is a `Required` field error. The schema of `<group>/<version>/<Kind>` is looked up in the embedded bundle and the whole object is checked with the schema validator of `k8s.io/kube-openapi/pkg/validation/validate` (the validator the Kubernetes API server uses for a custom resource, without its CEL rules). Each finding becomes one field error: a missing required field is `Required`, every other finding `Invalid`, with the field path the validator names. The list is sorted by field and then by message. A kind of a group that ends in `openova.io` with no schema in the bundle is one `Invalid` error on `apiVersion`. Any other kind with no schema (a ConfigMap, a CronJob) gets no schema check: the API server owns its schema.
4. **The bundle.** `internal/intent/crds/schemas.json` holds the `openAPIV3Schema` of every version of every CustomResourceDefinition in `products/catalyst/chart/crds/*.yaml` and `platform/crossplane-claims/chart/templates/crds/useraccess.yaml`, keyed `<group>/<version>/<Kind>`. A file under a `templates/` folder first loses every line whose first non-blank characters are `{{` (the Helm `if` and `end`). The file is a JSON object with one key per line, in key order, each value compact JSON, and a final newline. Go cannot embed a file outside its module, so the bundle is generated, not copied: the test `TestSchemasMatchSources` builds it from those files and fails when the file differs; with `INTENT_WRITE_SCHEMAS=1` it writes the file instead. Any pull request that changes one of those definition files must run that command again in the same change.
5. **Serialize.** The object without `status`, `metadata.managedFields`, `metadata.resourceVersion`, `metadata.uid`, `metadata.creationTimestamp`, `metadata.generation` and `metadata.selfLink`; keys sorted; two-space YAML (`sigs.k8s.io/yaml`); one trailing newline. Two calls with the same object give the same bytes. The argument is not changed.
6. **Submit, in this order.** (a) Three checks of the call, in this order, each refused with an error that wraps `ErrInvalid`: `Deps` without `Git` or `Cache`; no upsert and no delete; upserts without `pathOf`. (b) Create one change identifier with `gitwrite.NewChangeID`. (c) Take the upserts one by one, in the order given, and make three checks of each, in this order: a nil upsert is refused with an error that wraps `ErrInvalid`; the object is validated, and one that fails returns `*SchemaError`; `pathOf` giving `""` is refused with an error that wraps `ErrInvalid`. After the last upsert take the deletes one by one: a delete without `Kind`, `Name` or `Path` is refused with an error that wraps `ErrInvalid`. The first check that fails ends the call, and nothing is read or committed. So an object that breaks its schema and also has no path returns `*SchemaError`; a nil upsert that follows an object that breaks its schema is not reached; and a wrong delete is reported only when every upsert passed its three checks. (d) On a copy of each upsert set the label `app.kubernetes.io/managed-by: flux` and the annotation `catalyst.openova.io/change-id: <change id>`; the caller's objects are not changed. (e) Read the current file of every target with `Writer.Read`; `gitwrite.ErrNotFound` means absent, any other error is returned as it is. (f) When `ifMatch` is not empty it is compared with the first object's file (the first upsert, or the first delete when there is no upsert): `gitwrite.AbsentSHA` needs the file absent, any other value needs that blob SHA; a mismatch returns `*gitwrite.ConflictError` and nothing is committed. (g) No-op: every upsert's file exists and equals the new file once both have the change-id annotation removed (compared as canonical bytes of rule 5), and every delete's file is absent. Then the library is asked for the head with every file as it is, each bound by the blob SHA just read (a file that moved in between is a conflict, never overwritten); the outcome has `Noop: true`, that head as `Commit`, the first upsert's blob SHA as `ETag`, the change identifier of the first upsert's file (or the new one when the file has none) as `ChangeID`, and `Applied` true when the cache already holds every upsert with its file's change identifier and lacks every deleted object. It does not wait. (h) Otherwise one `Writer.Commit` with every upsert (the new bytes) and every delete; `ifMatch` is set as `IfMatch` on the first object only. Errors of the library are returned as they are, so a caller can test them with `errors.Is` and `errors.As` (`*gitwrite.ConflictError`, `gitwrite.ErrUnavailable`, `gitwrite.ErrForbiddenPath`, `gitwrite.ErrSecretContent`, `gitwrite.ErrInvalid`). `ETag` is the blob SHA of the first file after the commit (empty for a delete). (i) Wait: one `Watch` per kind, then read the cache; after each event read it again; stop when every upsert carries the new change identifier and every deleted object is absent (`Applied: true`), or when `SyncWait` (15 seconds when not above zero) passes or the context ends (`Applied: false`, no error; the commit stays). Every watch is cancelled before `Submit` returns. The wait polls nothing: no ticker, no sleep.
7. **One commit, one repository.** One call of `Submit` is one commit in one repository. A route that must change two repositories calls it twice; how such a route answers is the route's package's decision.
8. **The adapter** (`cmd/api/intent_wire.go`, package `main`). `newIntentCache(f *k8scache.Factory)` returns the `ObjectCache`. `Get` uses `Factory.List(clusterID, kind, nil)` and returns the object with that namespace and name, or nil; it never calls the API server. `Watch` resolves the kind through `Factory.Registry()`, subscribes to the cache once per kind with `Factory.Subscribe("system:catalyst-api:intent", {kind})`, keeps that subscription open, and fans its events out to its own watchers, each filtered to its cluster; `cancel` closes the watcher's channel. The cache's own subscriptions are never cancelled by the adapter, because closing one while the cache sends an event is a data race (measured with the race detector). When a watcher's channel is full the oldest event is dropped, as the cache does.
9. **The dependencies.** `newIntentDeps(f, clusterID, getenv)` returns `intent.Deps` with `Git` from `gitwrite.New` with `BaseURL` `CATALYST_GITEA_URL`, `Tokens` `gitwrite.SharedTokenSource(CATALYST_GITEA_TOKEN)` (the URL and the token catalyst-api uses today) and `RobotDomain` `robots.<SOVEREIGN_FQDN>`; `Cache` from `newIntentCache`; `ClusterID`; `FQDN` from `SOVEREIGN_FQDN`; `SyncWait` from `CATALYST_INTENT_SYNC_WAIT`, a Go duration above zero, default 15 seconds. A missing URL, token, FQDN, cache or cluster identifier, or a bad duration, is an error. Nothing calls it yet except its test; CTL-162 calls it from `main.go` and chooses the cluster identifier there.
10. **The rollback tool.** `python3 scripts/intent-detach.py <kind> --kubeconfig <path> [--namespace <ns>] [--reattach]` lists the objects of the kind with `kubectl get` (every namespace without `--namespace`), then runs `kubectl annotate --overwrite` once per object with `kustomize.toolkit.fluxcd.io/reconcile=disabled`, or with `kustomize.toolkit.fluxcd.io/reconcile-` when `--reattach` is given. It prints one line per object and then `detached <n> objects of kind <kind>` (or `reattached ...`). Exit 0 done, 1 a kubectl call failed, 2 wrong usage. `--self-test` proves each rule with a fake kubectl and needs no cluster. It runs only on an operator's machine; nothing in CI calls kubectl.
11. **Nothing else changes.** No route, no handler, no `main.go`, no `go.mod` or `go.sum` (every import is already a requirement of the module), no baseline of a guard. The package writes nothing to the cluster, polls nothing, and keeps no database.

	FQDN      string        // this Sovereign's FQDN
	SyncWait  time.Duration // CATALYST_INTENT_SYNC_WAIT, default 15s
}

// ObjectCache is the part of the informer cache the package uses. A kind is
// the cache's kind name: the object's kind in lower case.
type ObjectCache interface {
	// Get returns the cached object, or nil when it is absent.
	Get(clusterID, kind, namespace, name string) *unstructured.Unstructured
	// Watch delivers every later add, update and delete of one kind; cancel stops it.
	Watch(clusterID, kind string) (events <-chan CacheEvent, cancel func())
}

// CacheEvent is one change of an object in the cache.
type CacheEvent struct {
	Type   string // "ADDED", "MODIFIED", "DELETED"
	Object *unstructured.Unstructured
}

// Target is one object of a change and the file that holds it.
type Target struct {
	APIVersion, Kind, Namespace, Name string
	Path                              string // repository path
	Op                                gitwrite.Op
}

// Outcome is the result of Submit.
type Outcome struct {
	ChangeID string
	Commit   string
	Noop     bool
	Applied  bool // every target carried ChangeID (or was gone) within SyncWait
	Targets  []Target
	ETag     string
}

// SchemaError is returned by Submit when an object fails its schema.
// Nothing was committed.
type SchemaError struct {
	Kind   string
	Name   string
	Errors field.ErrorList
}

func (e *SchemaError) Error() string {
	return fmt.Sprintf("intent: %s %s fails its schema: %s", e.Kind, e.Name, e.Errors.ToAggregate().Error())
}

// ErrInvalid is wrapped by every refusal of a malformed call to Submit.
var ErrInvalid = errors.New("intent: invalid call")

// Serialize returns the canonical bytes of an intent file: the object
// without status, metadata.managedFields, metadata.resourceVersion,
// metadata.uid, metadata.creationTimestamp, metadata.generation and
// metadata.selfLink; keys sorted; two-space YAML; one trailing newline.
func Serialize(obj *unstructured.Unstructured) ([]byte, error) {
	if obj == nil {
		return nil, fmt.Errorf("%w: no object", ErrInvalid)
	}
	c := obj.DeepCopy()
	delete(c.Object, "status")
	if md, ok := c.Object["metadata"].(map[string]interface{}); ok {
		for _, k := range []string{"managedFields", "resourceVersion", "uid", "creationTimestamp", "generation", "selfLink"} {
			delete(md, k)
		}
	}
	out, err := yaml.Marshal(c.Object)
	if err != nil {
		return nil, fmt.Errorf("intent: serialise %s %s: %w", obj.GetKind(), obj.GetName(), err)
	}
	return out, nil
}

// cacheKind is the cache's kind name of an object kind.
func cacheKind(kind string) string {
	return strings.ToLower(kind)
}

// withoutChangeID returns the canonical bytes of obj with the change-id
// annotation removed, and the value it had.
func withoutChangeID(obj *unstructured.Unstructured) ([]byte, string, error) {
	c := obj.DeepCopy()
	ann := c.GetAnnotations()
	id := ann[ChangeIDAnnotation]
	if ann != nil {
		delete(ann, ChangeIDAnnotation)
		if len(ann) == 0 {
			ann = nil
		}
		c.SetAnnotations(ann)
	}
	b, err := Serialize(c)
	return b, id, err
}

// parseFile reads one object from the bytes of an intent file.
func parseFile(content []byte) (*unstructured.Unstructured, bool) {
	m := map[string]interface{}{}
	if err := yaml.Unmarshal(content, &m); err != nil || len(m) == 0 {
		return nil, false
	}
	return &unstructured.Unstructured{Object: m}, true
}

// fileState is the state of one target's file before the change.
type fileState struct {
	exists  bool
	content []byte
	sha     string
}

func readState(ctx context.Context, d Deps, scope gitwrite.Scope, repo gitwrite.Repo, path string) (fileState, error) {
	content, sha, err := d.Git.Read(ctx, scope, repo, path)
	if errors.Is(err, gitwrite.ErrNotFound) {
		return fileState{}, nil
	}
	if err != nil {
		return fileState{}, err
	}
	return fileState{exists: true, content: content, sha: sha}, nil
}

// waitTarget is what Submit waits for: the object carrying wantID, or the
// object being absent when absent is true. wantID "" means present.
type waitTarget struct {
	kind, namespace, name string
	wantID                string
	absent                bool
}

func (w waitTarget) done(d Deps) bool {
	obj := d.Cache.Get(d.ClusterID, w.kind, w.namespace, w.name)
	if w.absent {
		return obj == nil
	}
	if obj == nil {
		return false
	}
	return w.wantID == "" || obj.GetAnnotations()[ChangeIDAnnotation] == w.wantID
}

func allDone(d Deps, ws []waitTarget) bool {
	for _, w := range ws {
		if !w.done(d) {
			return false
		}
	}
	return true
}

// await watches every kind of ws and reports whether every target is done
// before SyncWait passes or ctx ends. It reads the cache once at the start
// and again after each event; it never polls.
func await(ctx context.Context, d Deps, ws []waitTarget) bool {
	wait := d.SyncWait
	if wait <= 0 {
		wait = DefaultSyncWait
	}
	wake := make(chan struct{}, 1)
	stop := make(chan struct{})
	seen := map[string]bool{}
	var cancels []func()
	for _, w := range ws {
		if seen[w.kind] {
			continue
		}
		seen[w.kind] = true
		events, cancel := d.Cache.Watch(d.ClusterID, w.kind)
		cancels = append(cancels, cancel)
		go func() {
			for {
				select {
				case _, ok := <-events:
					if !ok {
						return
					}
					select {
					case wake <- struct{}{}:
					default:
					}
				case <-stop:
					return
				}
			}
		}()
	}
	defer func() {
		close(stop)
		for _, cancel := range cancels {
			cancel()
		}
	}()
	timer := time.NewTimer(wait)
	defer timer.Stop()
	for {
		if allDone(d, ws) {
			return true
		}
		select {
		case <-wake:
		case <-timer.C:
			return allDone(d, ws)
		case <-ctx.Done():
			return allDone(d, ws)
		}
	}
}

// Submit validates each upsert, sets the label and the change-id
// annotation, detects a no-op (equal to the current file ignoring the
// change-id annotation), commits all files in one commit, and waits up to
// SyncWait for the informer cache. ifMatch applies to the first object
// only: the first upsert, or the first delete when there is no upsert.
// pathOf gives the repository path of each upsert.
func Submit(ctx context.Context, d Deps, scope gitwrite.Scope, repo gitwrite.Repo, upserts []*unstructured.Unstructured, deletes []Target, pathOf func(*unstructured.Unstructured) string, summary string, author gitwrite.Identity, via gitwrite.Via, ifMatch string, trailers map[string]string) (Outcome, error) {
	if d.Git == nil || d.Cache == nil {
		return Outcome{}, fmt.Errorf("%w: Deps needs Git and Cache", ErrInvalid)
	}
	if len(upserts)+len(deletes) == 0 {
		return Outcome{}, fmt.Errorf("%w: no object to change", ErrInvalid)
	}
	if len(upserts) > 0 && pathOf == nil {
		return Outcome{}, fmt.Errorf("%w: upserts need pathOf", ErrInvalid)
	}
	changeID := gitwrite.NewChangeID()

	type upsert struct {
		obj    *unstructured.Unstructured
		path   string
		bytes  []byte
		bare   []byte // canonical bytes without the change-id annotation
		state  fileState
		fileID string // change-id annotation of the current file
	}
	var ups []upsert
	var targets []Target
	for _, in := range upserts {
		if in == nil {
			return Outcome{}, fmt.Errorf("%w: a nil upsert", ErrInvalid)
		}
		if errs := Validate(in); len(errs) > 0 {
			return Outcome{}, &SchemaError{Kind: in.GetKind(), Name: in.GetName(), Errors: errs}
		}
		obj := in.DeepCopy()
		labels := obj.GetLabels()
		if labels == nil {
			labels = map[string]string{}
		}
		labels[ManagedByLabel] = ManagedByValue
		obj.SetLabels(labels)
		ann := obj.GetAnnotations()
		if ann == nil {
			ann = map[string]string{}
		}
		ann[ChangeIDAnnotation] = changeID
		obj.SetAnnotations(ann)
		path := pathOf(in)
		if path == "" {
			return Outcome{}, fmt.Errorf("%w: pathOf gave no path for %s %s", ErrInvalid, in.GetKind(), in.GetName())
		}
		b, err := Serialize(obj)
		if err != nil {
			return Outcome{}, err
		}
		bare, _, err := withoutChangeID(obj)
		if err != nil {
			return Outcome{}, err
		}
		ups = append(ups, upsert{obj: obj, path: path, bytes: b, bare: bare})
		targets = append(targets, Target{APIVersion: obj.GetAPIVersion(), Kind: obj.GetKind(), Namespace: obj.GetNamespace(), Name: obj.GetName(), Path: path, Op: gitwrite.OpUpsert})
	}
	for _, t := range deletes {
		if t.Path == "" || t.Kind == "" || t.Name == "" {
			return Outcome{}, fmt.Errorf("%w: a delete needs Kind, Name and Path", ErrInvalid)
		}
		t.Op = gitwrite.OpDelete
		targets = append(targets, t)
	}

	// Read every current file and detect a no-op.
	noop := true
	for i := range ups {
		st, err := readState(ctx, d, scope, repo, ups[i].path)
		if err != nil {
			return Outcome{}, err
		}
		ups[i].state = st
		if !st.exists {
			noop = false
			continue
		}
		cur, ok := parseFile(st.content)
		if !ok {
			noop = false
			continue
		}
		bare, id, err := withoutChangeID(cur)
		if err != nil || string(bare) != string(ups[i].bare) {
			noop = false
			continue
		}
		ups[i].fileID = id
	}
	delStates := make([]fileState, len(deletes))
	for i, t := range deletes {
		st, err := readState(ctx, d, scope, repo, t.Path)
		if err != nil {
			return Outcome{}, err
		}
		delStates[i] = st
		if st.exists {
			noop = false
		}
	}

	// ifMatch is checked here as well as by the library, because the
	// library reports a no-op before it compares IfMatch.
	if ifMatch != "" {
		first, firstPath := fileState{}, ""
		if len(ups) > 0 {
			first, firstPath = ups[0].state, ups[0].path
		} else {
			first, firstPath = delStates[0], deletes[0].Path
		}
		if (ifMatch == gitwrite.AbsentSHA && first.exists) || (ifMatch != gitwrite.AbsentSHA && ifMatch != first.sha) {
			return Outcome{}, &gitwrite.ConflictError{Path: firstPath, Want: ifMatch, Current: first.sha}
		}
	}

	change := gitwrite.Change{Scope: scope, Repo: repo, Summary: summary, Author: author, ChangeID: changeID, Via: via, Trailers: trailers}
	if noop {
		// Ask the library for the head with the files as they are: each
		// file must still have the SHA just read, so a file that moved in
		// between is a conflict, never overwritten.
		for _, u := range ups {
			change.Files = append(change.Files, gitwrite.FileChange{Path: u.path, Op: gitwrite.OpUpsert, Content: u.state.content, IfMatch: u.state.sha})
		}
		for _, t := range deletes {
			change.Files = append(change.Files, gitwrite.FileChange{Path: t.Path, Op: gitwrite.OpDelete, IfMatch: gitwrite.AbsentSHA})
		}
		res, err := d.Git.Commit(ctx, change)
		if err != nil {
			return Outcome{}, err
		}
		out := Outcome{ChangeID: changeID, Commit: res.Commit, Noop: true, Targets: targets}
		if len(ups) > 0 {
			out.ETag = ups[0].state.sha
			if ups[0].fileID != "" {
				out.ChangeID = ups[0].fileID
			}
		}
		var ws []waitTarget
		for _, u := range ups {
			ws = append(ws, waitTarget{kind: cacheKind(u.obj.GetKind()), namespace: u.obj.GetNamespace(), name: u.obj.GetName(), wantID: u.fileID})
		}
		for _, t := range deletes {
			ws = append(ws, waitTarget{kind: cacheKind(t.Kind), namespace: t.Namespace, name: t.Name, absent: true})
		}
		out.Applied = allDone(d, ws)
		return out, nil
	}

	for i, u := range ups {
		fc := gitwrite.FileChange{Path: u.path, Op: gitwrite.OpUpsert, Content: u.bytes}
		if i == 0 {
			fc.IfMatch = ifMatch
		}
		change.Files = append(change.Files, fc)
	}
	for i, t := range deletes {
		fc := gitwrite.FileChange{Path: t.Path, Op: gitwrite.OpDelete}
		if i == 0 && len(ups) == 0 {
			fc.IfMatch = ifMatch
		}
		change.Files = append(change.Files, fc)
	}
	res, err := d.Git.Commit(ctx, change)
	if err != nil {
		return Outcome{}, err
	}
	out := Outcome{ChangeID: changeID, Commit: res.Commit, Noop: !res.Committed, Targets: targets}
	if len(res.Files) > 0 {
		out.ETag = res.Files[0].BlobSHA
	}
	var ws []waitTarget
	for _, u := range ups {
		ws = append(ws, waitTarget{kind: cacheKind(u.obj.GetKind()), namespace: u.obj.GetNamespace(), name: u.obj.GetName(), wantID: changeID})
	}
	for _, t := range deletes {
		ws = append(ws, waitTarget{kind: cacheKind(t.Kind), namespace: t.Namespace, name: t.Name, absent: true})
	}
	if !res.Committed {
		out.Applied = allDone(d, ws)
		return out, nil
	}
	out.Applied = await(ctx, d, ws)
	return out, nil
}

// flux is a gitwrite.Writer that plays Flux: after each commit it applies
// the committed files to the cache, after delay. With off it applies nothing.

	*fake.Writer
	cache *fakeCache
	delay time.Duration
	off   bool
	mu    sync.Mutex
	paths map[string][3]string // path -> kind, namespace, name
	wg    sync.WaitGroup
}

func (f *flux) Commit(ctx context.Context, c gitwrite.Change) (gitwrite.Result, error) {
	res, err := f.Writer.Commit(ctx, c)
	if err != nil || !res.Committed || f.off {
		return res, err
	}
	f.wg.Add(1)
	go func() {
		defer f.wg.Done()
		time.Sleep(f.delay)
		f.mu.Lock()
		defer f.mu.Unlock()
		for _, fc := range c.Files {
			if fc.Op == gitwrite.OpDelete {
				if k, ok := f.paths[fc.Path]; ok {
					f.cache.remove(k[0], k[1], k[2])

	}()
	return res, nil
}

package intent

import (
	_ "embed"
	"encoding/json"
	"fmt"
	"sort"
	"strings"
	"sync"

	openapierrors "k8s.io/kube-openapi/pkg/validation/errors"
	"k8s.io/kube-openapi/pkg/validation/spec"
	"k8s.io/kube-openapi/pkg/validation/strfmt"
	"k8s.io/kube-openapi/pkg/validation/validate"

	"k8s.io/apimachinery/pkg/apis/meta/v1/unstructured"
	"k8s.io/apimachinery/pkg/runtime/schema"
	"k8s.io/apimachinery/pkg/util/validation/field"
)

// schemaBundle holds the openAPIV3Schema of every version of every
// definition in products/catalyst/chart/crds/*.yaml and
// platform/crossplane-claims/chart/templates/crds/useraccess.yaml, keyed
// "<group>/<version>/<Kind>". Go cannot embed a file outside its module, so
// the bundle is generated from those files; TestSchemasMatchSources fails
// when it differs from them and rewrites it when INTENT_WRITE_SCHEMAS=1.
//
//go:embed crds/schemas.json
var schemaBundle []byte

var (
	schemasOnce sync.Once
	schemas     map[string]*spec.Schema
	schemasErr  error
)

func loadSchemas() (map[string]*spec.Schema, error) {
	schemasOnce.Do(func() {
		raw := map[string]json.RawMessage{}
		if err := json.Unmarshal(schemaBundle, &raw); err != nil {
			schemasErr = fmt.Errorf("intent: read the schema bundle: %w", err)
			return
		}
		out := make(map[string]*spec.Schema, len(raw))
		for key, r := range raw {
			s := &spec.Schema{}
			if err := json.Unmarshal(r, s); err != nil {
				schemasErr = fmt.Errorf("intent: read the schema %s: %w", key, err)
				return
			}
			out[key] = s
		}
		schemas = out
	})
	return schemas, schemasErr
}

// Validate checks obj against the embedded schema of its apiVersion and
// kind. It returns nil or a list of field errors, sorted by field. An
// object needs apiVersion, kind and metadata.name. A kind of a group that
// ends in "openova.io" with no embedded schema is an error; any other kind
// with no embedded schema is not checked further (the API server owns it).
func Validate(obj *unstructured.Unstructured) field.ErrorList {
	if obj == nil {
		return field.ErrorList{field.Required(field.NewPath("object"), "")}
	}
	var errs field.ErrorList
	apiVersion, kind := obj.GetAPIVersion(), obj.GetKind()
	if apiVersion == "" {
		errs = append(errs, field.Required(field.NewPath("apiVersion"), ""))
	}
	if kind == "" {
		errs = append(errs, field.Required(field.NewPath("kind"), ""))
	}
	if obj.GetName() == "" {
		errs = append(errs, field.Required(field.NewPath("metadata", "name"), ""))
	}
	if len(errs) > 0 {
		return errs
	}
	gv, err := schema.ParseGroupVersion(apiVersion)
	if err != nil {
		return field.ErrorList{field.Invalid(field.NewPath("apiVersion"), apiVersion, err.Error())}
	}
	all, err := loadSchemas()
	if err != nil {
		return field.ErrorList{field.InternalError(field.NewPath("apiVersion"), err)}
	}
	s, ok := all[gv.Group+"/"+gv.Version+"/"+kind]
	if !ok {
		if strings.HasSuffix(gv.Group, "openova.io") {
			return field.ErrorList{field.Invalid(field.NewPath("apiVersion"), apiVersion, "no schema is embedded for kind "+kind)}
		}
		return nil
	}
	res := validate.NewSchemaValidator(s, nil, "", strfmt.Default).Validate(obj.Object)
	for _, e := range res.Errors {
		errs = append(errs, toFieldError(e))
	}
	sort.SliceStable(errs, func(i, j int) bool {
		if errs[i].Field != errs[j].Field {
			return errs[i].Field < errs[j].Field
		}
		return errs[i].Detail < errs[j].Detail
	})
	return errs
}

// toFieldError turns one error of the schema validator into a field error.
func toFieldError(e error) *field.Error {
	v, ok := e.(*openapierrors.Validation)
	if !ok {
		return field.Invalid(field.NewPath("<object>"), nil, e.Error())
	}
	name := strings.TrimPrefix(v.Name, ".")
	if name == "" {
		name = "<object>"
	}
	p := field.NewPath(name)
	if v.Code() == openapierrors.RequiredFailCode {
		return field.Required(p, v.Error())
	}
	return field.Invalid(p, v.Value, v.Error())
}

// dropTemplateLines removes the lines of a Helm template whose first
// non-blank characters are "{{".
func dropTemplateLines(b []byte) []byte {
	var out bytes.Buffer
	sc := bufio.NewScanner(bytes.NewReader(b))
	sc.Buffer(make([]byte, 0, 1024*1024), 16*1024*1024)
	for sc.Scan() {
		if strings.HasPrefix(strings.TrimSpace(sc.Text()), "{{") {
			continue
		}
		out.Write(sc.Bytes())
		out.WriteByte('\n')
	}
	return out.Bytes()
}

// buildBundle builds the bytes of crds/schemas.json from the definition
// files: one line per "<group>/<version>/<Kind>" key, in key order, each
// holding the version's openAPIV3Schema as compact JSON.
func buildBundle(root fs.FS, files []string) ([]byte, error) {
	entries := map[string][]byte{}
	for _, f := range files {
		b, err := fs.ReadFile(root, f)
		if err != nil {
			return nil, err
		}
		if strings.Contains(f, "/templates/") {
			b = dropTemplateLines(b)
		}
		r := utilyaml.NewYAMLReader(bufio.NewReader(bytes.NewReader(b)))
		for {
			doc, err := r.Read()
			if errors.Is(err, io.EOF) {
				break
			}
			if err != nil {
				return nil, fmt.Errorf("%s: %w", f, err)
			}
			var crd struct {
				Kind string `json:"kind"`
				Spec struct {
					Group string `json:"group"`
					Names struct {
						Kind string `json:"kind"`
					} `json:"names"`
					Versions []struct {
						Name   string `json:"name"`
						Schema struct {
							OpenAPIV3Schema json.RawMessage `json:"openAPIV3Schema"`
						} `json:"schema"`
					} `json:"versions"`
				} `json:"spec"`
			}
			if err := yaml.Unmarshal(doc, &crd); err != nil {
				return nil, fmt.Errorf("%s: %w", f, err)
			}
			if crd.Kind != "CustomResourceDefinition" {
				continue
			}
			for _, v := range crd.Spec.Versions {
				if len(v.Schema.OpenAPIV3Schema) == 0 {
					continue
				}
				key := crd.Spec.Group + "/" + v.Name + "/" + crd.Spec.Names.Kind
				if _, dup := entries[key]; dup {
					return nil, fmt.Errorf("%s: %s is defined twice", f, key)
				}
				var compact bytes.Buffer
				if err := json.Compact(&compact, v.Schema.OpenAPIV3Schema); err != nil {
					return nil, fmt.Errorf("%s: %s: %w", f, key, err)
				}
				entries[key] = compact.Bytes()
			}
		}
	}
	keys := make([]string, 0, len(entries))
	for k := range entries {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	var out bytes.Buffer
	out.WriteString("{\n")
	for i, k := range keys {
		q, _ := json.Marshal(k)
		out.Write(q)
		out.WriteString(":")
		out.Write(entries[k])
		if i < len(keys)-1 {
			out.WriteString(",")
		}
		out.WriteString("\n")
	}
	out.WriteString("}\n")
	return out.Bytes(), nil
}

// intentWatchUser is the subject under which the watches of package intent
// subscribe to the informer cache.
const intentWatchUser = "system:catalyst-api:intent"

// intentCache adapts the informer cache to intent.ObjectCache. It reads
// the cache only; it never calls the API server. Each kind is subscribed to
// once, on its first Watch, and the subscription stays open: closing a
// subscription of the cache while it sends an event is a data race, so the
// adapter fans the events out to its own watchers instead.
type intentCache struct {
	f    *k8scache.Factory
	mu   sync.Mutex
	hubs map[string]*intentHub // by the cache's kind name
}

// intentHub holds the watchers of one kind.
type intentHub struct {
	next int
	subs map[int]intentSub
}

type intentSub struct {
	cluster string
	ch      chan intent.CacheEvent
}

var _ intent.ObjectCache = (*intentCache)(nil)

func newIntentCache(f *k8scache.Factory) *intentCache {
	return &intentCache{f: f, hubs: map[string]*intentHub{}}
}

// Get returns the cached object of one kind with this namespace and name
// in one cluster, or nil.
func (c *intentCache) Get(clusterID, kind, namespace, name string) *unstructured.Unstructured {
	items, _, err := c.f.List(clusterID, kind, nil)
	if err != nil {
		return nil
	}
	for _, it := range items {
		if it.GetNamespace() == namespace && it.GetName() == name {
			return it
		}
	}
	return nil
}

// Watch delivers the later events of one kind in one cluster until cancel
// is called; cancel closes the channel. When the channel is full, the
// oldest event is dropped, as the cache does for its own subscribers.
func (c *intentCache) Watch(clusterID, kind string) (<-chan intent.CacheEvent, func()) {
	name := k8scache.CanonicalKindName(kind)
	if k, ok := c.f.Registry().Get(kind); ok {
		name = k8scache.CanonicalKindName(k.Name)
	}
	c.mu.Lock()
	h, ok := c.hubs[name]
	if !ok {
		h = &intentHub{subs: map[int]intentSub{}}
		c.hubs[name] = h
		src, _ := c.f.Subscribe(intentWatchUser, map[string]struct{}{name: {}})
		go c.pump(h, src)
	}
	id := h.next
	h.next++
	ch := make(chan intent.CacheEvent, 16)
	h.subs[id] = intentSub{cluster: clusterID, ch: ch}
	c.mu.Unlock()
	var once sync.Once
	return ch, func() {
		once.Do(func() {
			c.mu.Lock()
			defer c.mu.Unlock()
			delete(h.subs, id)
			close(ch)
		})
	}
}

// pump hands every event of one kind to the watchers of its cluster.
func (c *intentCache) pump(h *intentHub, src <-chan k8scache.Event) {
	for ev := range src {
		ce := intent.CacheEvent{Type: string(ev.Type), Object: ev.Object}
		c.mu.Lock()
		for _, s := range h.subs {
			if s.cluster != ev.Cluster {
				continue
			}
			select {
			case s.ch <- ce:
			default:
				select {
				case <-s.ch:
				default:
				}
				select {
				case s.ch <- ce:
				default:
				}
			}
		}
		c.mu.Unlock()
	}
}

// intentGitConfig is the configuration of the commit library: the Gitea

// CATALYST_GITEA_TOKEN) and the robot e-mail domain robots.<SOVEREIGN_FQDN>.

#!/usr/bin/env python3
"""intent-detach.py - stop Flux from applying the intent of one kind, or let it apply again.

When a batch of routes moves its writes to Git and must be rolled back, Flux must stop
applying the files that batch committed, because the old routes write the cluster
directly again. This tool sets the annotation

  kustomize.toolkit.fluxcd.io/reconcile: disabled

on every object of one kind, so that Flux leaves those objects alone; with --reattach it
removes the annotation again. The files stay in Git. It is the rollback tool of the batches
that move routes onto the package intent of catalyst-api.

Usage:
  python3 scripts/intent-detach.py <kind> --kubeconfig <path> [--namespace <ns>] [--reattach]
  python3 scripts/intent-detach.py --self-test

<kind> is a kind as kubectl names it, for example application or applications.apps.openova.io.
Without --namespace every namespace is read. The tool runs kubectl, which must be on PATH,
once to list the objects and once per object to annotate it. It prints one line per object
and then the count:

  detached <n> objects of kind <kind>        (or: reattached <n> objects of kind <kind>)

Exit codes: 0 done; 1 a kubectl call failed (the objects before it are already changed, and
running the same command again is safe); 2 wrong usage.
"""
import argparse
import json
import subprocess
import sys

ANNOTATION = "kustomize.toolkit.fluxcd.io/reconcile"


def kubectl(args):
    """Run kubectl with args. Return (exit code, stdout, stderr)."""
    p = subprocess.run(["kubectl"] + args, capture_output=True, text=True, check=False)
    return p.returncode, p.stdout, p.stderr


def run(kind, kubeconfig, namespace, reattach, runner, out, err):
    """Annotate or un-annotate every object of kind. Return the exit code."""
    base = ["--kubeconfig", kubeconfig]
    scope = ["-n", namespace] if namespace else ["-A"]
    code, stdout, stderr = runner(base + ["get", kind] + scope + ["-o", "json"])
    if code != 0:
        print("intent-detach: kubectl get %s failed: %s" % (kind, stderr.strip()), file=err)
        return 1
    try:
        items = json.loads(stdout).get("items", [])
    except (ValueError, AttributeError) as e:
        print("intent-detach: kubectl get %s printed no list: %s" % (kind, e), file=err)
        return 1
    change = ANNOTATION + "-" if reattach else ANNOTATION + "=disabled"
    count = 0
    for item in items:
        meta = item.get("metadata", {})
        name, ns = meta.get("name", ""), meta.get("namespace", "")
        where = ["-n", ns] if ns else []
        code, _, stderr = runner(base + ["annotate", "--overwrite", kind, name] + where + [change])
        if code != 0:
            print("intent-detach: kubectl annotate %s %s failed: %s" % (kind, name, stderr.strip()), file=err)
            return 1
        print("%s %s" % (ns + "/" + name if ns else name, "reattached" if reattach else "detached"), file=out)
        count += 1
    print("%s %d objects of kind %s" % ("reattached" if reattach else "detached", count, kind), file=out)
    return 0


class Recorder:
    """A fake kubectl for the self-test: it records each call and answers from a script."""

    def __init__(self, listing, fail_on=None):
        self.calls = []
        self.listing = listing
        self.fail_on = fail_on

    def __call__(self, args):
        self.calls.append(args)
        if self.fail_on and self.fail_on in args:
            return 1, self.listing, "refused"
        if "get" in args:
            return 0, self.listing, ""
        return 0, "", ""


class Sink:
    def __init__(self):
        self.lines = []

    def write(self, s):
        self.lines.append(s)

    def text(self):
        return "".join(self.lines)


def self_test():
    """Prove that every rule of the tool can fail. Return the exit code."""
    failures = []
    cases = []

    def check(name, cond):
        cases.append(name)
        if not cond:
            failures.append(name)

    two = json.dumps({"items": [
        {"metadata": {"name": "site", "namespace": "acme"}},
        {"metadata": {"name": "acme"}},
    ]})

    r, out = Recorder(two), Sink()
    code = run("application", "/k", None, False, r, out, Sink())
    check("detach exits 0", code == 0)
    check("detach lists every namespace", r.calls[0] == ["--kubeconfig", "/k", "get", "application", "-A", "-o", "json"])
    check("detach annotates a namespaced object in its namespace",
          r.calls[1] == ["--kubeconfig", "/k", "annotate", "--overwrite", "application", "site", "-n", "acme", ANNOTATION + "=disabled"])
    check("detach annotates a cluster object without a namespace",
          r.calls[2] == ["--kubeconfig", "/k", "annotate", "--overwrite", "application", "acme", ANNOTATION + "=disabled"])
    check("detach prints the count", out.text().endswith("detached 2 objects of kind application\n"))

    r, out = Recorder(two), Sink()
    code = run("application", "/k", "acme", True, r, out, Sink())
    check("reattach exits 0", code == 0)
    check("reattach lists one namespace", r.calls[0] == ["--kubeconfig", "/k", "get", "application", "-n", "acme", "-o", "json"])
    check("reattach removes the annotation", r.calls[1][-1] == ANNOTATION + "-")
    check("reattach prints the count", out.text().endswith("reattached 2 objects of kind application\n"))

    r, out = Recorder(json.dumps({"items": []})), Sink()
    check("no objects is a count of 0", run("application", "/k", None, False, r, out, Sink()) == 0
          and out.text() == "detached 0 objects of kind application\n" and len(r.calls) == 1)

    r, out = Recorder(two, fail_on="get"), Sink()
    check("a failed listing exits 1", run("application", "/k", None, False, r, out, Sink()) == 1 and len(r.calls) == 1)

    r, out = Recorder(two, fail_on="annotate"), Sink()
    check("a failed annotation exits 1", run("application", "/k", None, False, r, out, Sink()) == 1 and len(r.calls) == 2)

    r, out = Recorder("not json"), Sink()
    check("a listing that is not JSON exits 1", run("application", "/k", None, False, r, out, Sink()) == 1)

    for name in failures:
        print("self-test FAIL: " + name)
    if failures:
        return 1
    print("self-test: %d cases passed" % len(cases))
    return 0
