# SEC-163 — The secrets store's Jobs

## In plain words

**The problem today.** The job that sets up the internal certificate authorities stays in the namespace of the secrets store after it has finished, and the gate check of that namespace admits no such job, so it fails on every run. The restore drill cannot restore any snapshot: the scratch store it restores into has a read-only file system and nowhere to write the snapshot's temporary file, so the drill check fails in both regions.

**What changes.** The setup job is deleted as soon as it finishes, and installing or upgrading the chart runs it again. The scratch store of the drill gets a writable temporary directory of its own; the rest of its file system stays read-only.

**Done means:**

- After the setup job of the certificate authorities has finished, no job of it is left in the namespace of the secrets store.
- The setup job stays part of the chart's release: installing or upgrading the chart runs it again, and a run on a store that already holds both authorities writes nothing.
- The scratch store of the restore drill can write the temporary file of the snapshot it restores, and its root file system stays read-only.
- The changed chart applies over the two releases a Sovereign holds today, with the finished setup job still there, and no patch is refused.
- The two gate checks themselves are unchanged.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
In the chart `platform/openbao/chart` (bp-openbao) the PKI bootstrap Job `openbao-pki-bootstrap-<hash>` of SEC-250 carries `ttlSecondsAfterFinished: 0` and stays an object of the release, with no Helm hook. ## 3. The model (the law)
1. `templates/pki-bootstrap-job.yaml`: `spec.ttlSecondsAfterFinished: 0`, after `backoffLimit: 6`. The Job has no annotation `helm.sh/hook`. Its name keeps its rule (a hash of the script, the image and the inputs), and this change alters none of them, so the Job keeps its name and its pod template.
2. The Job is no Helm hook: Helm waits for a hook Job, and this Job retries until the configuration reconciler of the same release has bound its role, so a hook would hold the install until then, and a start slower than the install timeout would be a failed install, which remediation answers with an uninstall. Kit slot 08 installs and upgrades with `disableWait: true`, so nothing waits for the release Job either, and nothing reads a finished one.
3. Each later install or upgrade creates the Job again (Helm creates an object of the release that is not live) and it runs once more; a run on a store that holds both issuers writes nothing (case P5 of `tests/pki-render.sh`, unchanged).
4. `templates/restore-drill.yaml`: the init container `scratch` mounts the volume `scratch-tmp` (emptyDir, `sizeLimit: 2Gi`) at `/tmp`, not read-only. Its root file system stays read-only (`readOnlyRootFilesystem: true`), its raft storage stays at `/scratch`, and no other container changes.
5. The gate checks are not touched: SEC-G03 (`tests/acceptance/sovereign/internal/suite/check_sec_seal.go`) and SEC-G10 (`check_sec_backup.go`) judge as before, and `docs/ledger/gates.yaml` does not change.
6. Tests: `tests/pki-render.sh` P4 adds one line `ok`: the Job has `ttlSecondsAfterFinished` 0 and no hook. `tests/restore-drill-render.sh` adds case 7: the scratch container's root file system is read-only, and each directory it writes (the raft `path` of its configuration and `$TMPDIR`, else `/tmp`) is a mount, not read-only, of an emptyDir volume. New `tests/upgrade-over-deployed.sh` runs the case `TestOpenBaoAppliesOverEveryState` of `tools/chart-upgrade` (new file `openbao_test.go`), the pattern of the disk-driver chart (`tools/chart-upgrade/huawei_evs_csi_test.go`).

+			return true
+		}
+	}
+	return false

+// writableTmp: the init container mounts, not read-only, an emptyDir volume at /tmp.
+func writableTmp(spec *corev1.PodSpec, container string) bool {
+	for _, c := range spec.InitContainers {
+		if c.Name != container {
+			continue
+		}
+		for _, m := range c.VolumeMounts {
+			if m.MountPath != "/tmp" || m.ReadOnly {
+				continue
+			}
+			for _, v := range spec.Volumes {
+				if v.Name == m.Name && v.EmptyDir != nil {
+					return true
+				}
+			}
+		}
+	}
+	return false
