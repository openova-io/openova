# AIP-040 — Switch off the header-trusting metering sidecar

## In plain words

**The problem today.** The model gateway of every Organization runs a metering sidecar that takes the customer and the Organization of each model call from two request headers. Any caller can set those headers, so a caller can have its usage charged to someone else. Nothing checks that this sidecar is gone from the clusters.

**What changes.** The gateway chart stops rendering the sidecar. A new gate check fails a region when any container runs the sidecar image, and it is required from now on. The quota model of an Organization keeps its reserve for the sidecar until a later task removes it.

**Done means:**

- The gateway chart renders its Pod without the metering sidecar by default.
- Gate check AIP-G01 is required. It fails a region when a container of any Pod has an image whose name holds metering-sidecar, whatever registry the image comes from.
- The check also fails a region where it finds no container at all, so a run that read nothing is never a pass.
- The quota tests of an Organization pass: the quota model still reserves room for the sidecar, and the tests now refuse only a model that reserves less than the chart renders.
- The tests of the new check run on every pull request without a cluster.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The bp-newapi chart (`platform/newapi/chart`) renders the model gateway Pod without the metering sidecar: `meteringSidecar.enabled` is `false` in `platform/newapi/chart/values.yaml`. With the flag off, the Service's `http` port targets the gateway container directly. The acceptance suite has the gate check AIP-G01 "No header-trusting meter", in state `required`: in every region, no container of any Pod (init, regular or ephemeral) has an image reference that holds the text `metering-sidecar`, and a region with no container at all fails. The quota model of an Organization (`platformStack` in the org-controller) is not changed: it still reserves the Pod with three containers, which is 500m of CPU limit more than the Pod now needs. The quota tests that compared that model with the chart as equalities now accept a model that reserves at least what the chart renders, and still refuse one that reserves less. AIP-041 removes the reserve and restores the equalities.

+// Check AIP-G01, No header-trusting meter: no Pod of any namespace of any
+// region has a container whose image reference holds the text
+// meterImageText. The metering sidecar of bp-newapi took the customer and
+// the Organization of a model call from two request headers that any caller
+// can set, so its usage records could be charged to anyone. It is switched
+// off since AIP-040.
+//
+// The rule matches the text anywhere in the image reference, not only the
+// last path segment: the image is named services-metering-sidecar, and after a
+// hand-over the registry host changes while the name does not. Every
+// container of a Pod is judged: its init containers, its containers and its
+// ephemeral containers. A region whose Pods hold no container fails: nothing
+// was measured, and that is never a pass.
+const meterImageID = "AIP-G01"
+
+// meterImageText is the text that no image reference of a Pod may hold.
+const meterImageText = "metering-sidecar"
+
+// meterContainerLists are the lists of a Pod spec that hold containers.
+var meterContainerLists = []string{"initContainers", "containers", "ephemeralContainers"}
+
+type meterImageCheck struct{}
+
+func init() { RegisterCheck(meterImageCheck{}) }
+
+func (meterImageCheck) ID() string { return meterImageID }
+
+func (meterImageCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
+	if len(cc.Regions) == 0 {
+		return errors.New("the run has no region")
+	}
+	for i, region := range cc.Regions {
+		rec.Step(meterImageID+"."+strconv.Itoa(i+1), "no container runs a metering-sidecar image in region "+region.ID, func(ev Evidence) error {
+			pods, err := region.GetList(ctx, "pods", "")
+			if err != nil {
+				return err
+			}
+			images, found := 0, []string{}
+			for _, pod := range pods {
+				for _, list := range meterContainerLists {
+					for _, c := range pod.Objects("spec", list) {
+						images++
+						if ref := c.Str("image"); strings.Contains(ref, meterImageText) {
+							found = append(found, pod.Namespace()+"/"+pod.Name()+"/"+c.Str("name")+" "+ref)
+						}
+					}
+				}
+			}
+			sort.Strings(found)
+			ev["pods"], ev["images"], ev["found"] = len(pods), images, found
+			switch {
+			case images == 0:
+				return fmt.Errorf("no container was found in region %s: nothing was measured", region.ID)
+			case len(found) > 0:
+				return fmt.Errorf("%d containers in region %s run an image whose name holds %q: %s",
+					len(found), region.ID, meterImageText, strings.Join(found, "; "))
+			}
+			return nil
+		})
+	}
