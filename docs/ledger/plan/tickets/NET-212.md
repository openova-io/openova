# NET-212 — Show the separation; refuse the claim when it is none

## In plain words

**The problem today.** Two regions of a Sovereign can run in one availability zone of one cloud region, and then one outage of that zone stops both. Nothing on the Sovereign says whether its regions are separate failure domains, and a gate run can claim disaster recovery for such a Sovereign without anything refusing the claim.

**What changes.** The Sovereign object states its region separation, none, zone or site, with a condition that says whether its regions are separate failure domains. A new required gate check confirms that value in every region and writes it, with a short summary line, into the gate record, and the gate tool refuses a record that claims disaster recovery while its regions share one failure domain.

**Done means:**

- The Sovereign object of every region carries its region separation and a condition named RegionSeparation, both computed from its network record.
- Two regions in one zone give none with the condition False and the reason SameFailureDomain; two zones of one cloud region give zone and two cloud regions give site, each with the condition True.
- The new gate check is required, fails a region whose object does not state the value its network record gives, and writes the value with a summary line such as two clusters, one failure domain into the gate record.
- A gate record that declares the capability disaster-recovery while its regions share one failure domain, or without a stated separation, is refused by the gate tool.
- A gate check that needs the capability disaster-recovery is recorded as skipped, never as passed, in a gate run that does not declare it.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every region's Sovereign object (`sovereigns.catalyst.openova.io/sovereign-self`) states the region separation of the Sovereign in `status.regionSeparation` (`none`, `zone` or `site`) and in the condition `RegionSeparation`, written by its existing writer `sovereign-ops sovereign-object` from the regions of `status.network`. The kind declares the field. The new required gate check NET-G12 "Region separation stated" reads the object of every region, confirms the value, and writes it with a summary line into the gate record as `provision.separation`; on the current two-region environment the record reads `{"value": "none", "summary": "two clusters, one failure domain"}`. The gate tool gains the capability flag `disaster-recovery` and refuses a record that declares it while `provision.separation` is absent or `none`. So a gate check that needs `disaster-recovery` is never run, and never passes, on regions that share one failure domain: the existing rule of `needs` records it as SKIP. The console notice of the separation is not part of this ticket (field 11).

## 3. The model (the law)
1. **The rule.** For the list of regions of `status.network` (each with `cloudRegion` and `az`): fewer than two regions give `none`; every region with its own `cloudRegion` gives `site`; otherwise every region with its own pair of `cloudRegion` and `az` gives `zone`; anything else gives `none`. This is the rule the provider modules already use for `regionSeparation` of their output `network_registry` (`infra/providers/huawei/main.tf`, local `network_registry_separation`).
2. **One writer.** The value and the condition are written only by `core/cmd/sovereign-ops/internal/sovereignobject`, in the same status apply that writes `status.network`. They are computed from the regions of `status.network`, not copied from `status.network.regionSeparation`. While `status.network` is absent, both are absent.
3. **The condition.** Type `RegionSeparation`. `zone`: status `True`, reason `SeparateZones`, message `Every region runs in its own availability zone.` `site`: status `True`, reason `SeparateSites`, message `Every region runs in its own cloud region.` `none`: status `False`, reason `SameFailureDomain`, message `Regions share one failure domain. Not a disaster-recovery configuration.`, or `The Sovereign has one region: one failure domain.` for one region. `lastTransitionTime` is the time of the run, and keeps the value of the object's existing `RegionSeparation` condition while the status stays the same. The writer reads the object for that with the `get` right it already holds; its rights do not change.
4. **The kind.** `status.regionSeparation` of `products/catalyst/chart/crds/sovereign.yaml` is a string with the enum `none`, `zone`, `site`. Nothing else of the kind changes. `status.conditions` already exists. The schema bundle `products/catalyst/bootstrap/api/internal/intent/crds/schemas.json` is regenerated from the kind by its own test command; it is never edited by hand.
5. **The gate check.** NET-G12 is one file, `tests/acceptance/sovereign/internal/suite/check_region_separation.go`, registered in `init()`, `kubectl get` only. One step `NET-G12.<n>` per region, then one step `NET-G12.<regions+1>`. A region fails when it has not exactly one Sovereign object, when the object has no `status.network`, when `status.regionSeparation` or `status.network.regionSeparation` differs from the rule of item 1 applied to `status.network.regions`, or when the condition `RegionSeparation` is absent or has another status or reason than item 3 gives. The last step fails when a region failed, when the regions state different values, or when the value is `none` and the run declares `disaster-recovery`. It hands `{value, summary}` to the record under the evidence key `separation`.
6. **The summary line.** `<n> clusters, one failure domain` for `none` (`one cluster, one failure domain` for one region), `<n> clusters in <n> zones` for `zone`, `<n> clusters in <n> sites` for `site`, where `<n>` is the number of regions of `status.network` written as a word from one to six, and in digits above six.
7. **The record.** `Provision` of `tests/acceptance/sovereign/internal/suite/result.go` gains `Separation *Separation` (JSON `separation`, left out when nil). `Finalize` moves a `*Separation` found under the evidence key `separation` into `provision.separation` when the record has a provision, and deletes it from the step's evidence. The table `RECORD` of `scripts/acceptance-gate.py` gains `provision.separation`: an object with `value` (one of `none`, `zone`, `site`) and `summary` (string), both required.
8. **The claim.** `disaster-recovery` joins the closed list `CAPABILITIES` of `scripts/acceptance-gate.py`. `validate_record` refuses a record whose `capabilities` hold `disaster-recovery` while `provision.separation.value` is not `zone` or `site`, with the line `capabilities: disaster-recovery needs provision.separation zone or site, not <value>`, where `<value>` is `none` or `absent`. A gate run declares `disaster-recovery` only when the input `capabilities` of the workflow `foundation-gate` holds it; this ticket sets it on no gate check (a plan change names it in a check's `needs` later).
9. **The manifest.** In `docs/ledger/gates.yaml` the entry NET-G12 moves from `state: not-built` to `state: required` and gains `implementation: tests/acceptance/sovereign/internal/suite/check_region_separation.go`; nothing else of the file changes.
10. **New code outside the handler package.** No file of `products/catalyst/bootstrap/api/internal/handler/` changes.

// regionSeparationRegion returns the value that the Sovereign object of one
// region states and the number of regions of its registry.
func regionSeparationRegion(ctx context.Context, region kube.Region, ev Evidence) (string, int, error) {
	objects, err := region.GetList(ctx, networkRegistryKind, "")
	if err != nil {
		return "", 0, err
	}
	if len(objects) != 1 {
		return "", 0, fmt.Errorf("region %s has %d Sovereign objects, want exactly 1", region.ID, len(objects))
	}
	o := objects[0]
	network, ok := o.Get("status", "network").(map[string]any)
	if !ok {
		return "", 0, fmt.Errorf("region %s: the Sovereign object %s has no status.network", region.ID, o.Name())
	}
	registry := kube.Object(network)
	regions := registry.Objects("regions")
	rule := regionSeparationRule(regions)
	stated := o.Str("status", "regionSeparation")
	status, reason, _, found := o.Condition(regionSeparationCondition)
	ev["stated"], ev["rule"], ev["registry"], ev["regions"] = stated, rule, registry.Str("regionSeparation"), len(regions)
	ev["condition"] = strings.TrimSpace(status + " " + reason)

	failures := []string{}
	if stated != rule {
		failures = append(failures, fmt.Sprintf("status.regionSeparation is %q, the regions of status.network give %s", stated, rule))
	}
	if r := registry.Str("regionSeparation"); r != rule {
		failures = append(failures, fmt.Sprintf("status.network.regionSeparation is %q, the regions of status.network give %s", r, rule))
	}
	wantStatus, wantReason := "False", "SameFailureDomain"
	switch rule {
	case "zone":
		wantStatus, wantReason = "True", "SeparateZones"
	case "site":
		wantStatus, wantReason = "True", "SeparateSites"
	}
	switch {
	case !found:
		failures = append(failures, "the condition "+regionSeparationCondition+" is absent")

		failures = append(failures, fmt.Sprintf("the condition %s is %s %s, want %s %s", regionSeparationCondition, status, reason, wantStatus, wantReason))
	}
	if len(failures) > 0 {
		return "", 0, fmt.Errorf("region %s: %s", region.ID, strings.Join(failures, "; "))
	}
	return stated, len(regions), nil
}

// regionSeparationRule is the region separation of the regions of a registry.
func regionSeparationRule(regions []kube.Object) string {
	clouds, pairs := map[string]bool{}, map[string]bool{}
	for _, r := range regions {
		clouds[r.Str("cloudRegion")] = true
		pairs[r.Str("cloudRegion")+"/"+r.Str("az")] = true
	}
	switch n := len(regions); {
	case n < 2:
		return "none"
	case len(clouds) == n:
		return "site"
	case len(pairs) == n:
		return "zone"
	}
	return "none"
}

// regionSeparationSummary is the summary line of the record, for example
// "two clusters, one failure domain" or "two clusters in two zones".
func regionSeparationSummary(value string, regions int) string {
	words := []string{"no", "one", "two", "three", "four", "five", "six"}
	n := strconv.Itoa(regions)
	if regions >= 0 && regions < len(words) {
		n = words[regions]
	}
	clusters := n + " clusters"
	if regions == 1 {
		clusters = "one cluster"
	}
	switch value {
	case "zone":
		return clusters + " in " + n + " zones"
	case "site":
		return clusters + " in " + n + " sites"
	}
	return clusters + ", one failure domain"
}

package sovereignobject

import "time"

// ConditionType is the type of the condition that states the region separation.
const ConditionType = "RegionSeparation"

// now is the clock of lastTransitionTime; a test replaces it.
var now = time.Now

// Separation is the region separation of a registry document, by the rule of
// the provider modules: site when every region has its own cloudRegion; zone
// when the cloud regions repeat but every region has its own pair of
// cloudRegion and az; none otherwise, and always for fewer than two regions.
func Separation(network map[string]interface{}) string {
	regions, _ := network["regions"].([]interface{})
	clouds, pairs := map[string]bool{}, map[string]bool{}
	for _, r := range regions {
		m, _ := r.(map[string]interface{})
		cloud, _ := m["cloudRegion"].(string)
		az, _ := m["az"].(string)
		clouds[cloud] = true
		pairs[cloud+"/"+az] = true
	}
	switch n := len(regions); {
	case n < 2:
		return "none"
	case len(clouds) == n:
		return "site"
	case len(pairs) == n:
		return "zone"
	}
	return "none"
}

// separationCondition is the condition RegionSeparation for sep. It keeps the
// lastTransitionTime of the same condition of current while its status stays.
func separationCondition(sep string, regions int, current map[string]interface{}) map[string]interface{} {
	status, reason := "False", "SameFailureDomain"
	message := "Regions share one failure domain. Not a disaster-recovery configuration."
	switch {
	case sep == "zone":
		status, reason, message = "True", "SeparateZones", "Every region runs in its own availability zone."
	case sep == "site":
		status, reason, message = "True", "SeparateSites", "Every region runs in its own cloud region."
	case regions < 2:
		message = "The Sovereign has one region: one failure domain."
	}
	since := now().UTC().Format(time.RFC3339)
	st, _ := current["status"].(map[string]interface{})
	list, _ := st["conditions"].([]interface{})
	for _, x := range list {
		old, _ := x.(map[string]interface{})
		if t, _ := old["lastTransitionTime"].(string); old["type"] == ConditionType && old["status"] == status && t != "" {
			since = t
		}
	}
	return map[string]interface{}{"type": ConditionType, "status": status, "reason": reason, "message": message, "lastTransitionTime": since}
}
