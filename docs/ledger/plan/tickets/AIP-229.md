# AIP-229 — Operations records: PostgreSQL store with migration 0001 and the ops-records program

## In plain words

**The problem today.** The operations-records service can keep its records only in memory. Nothing survives a restart, there is no database schema and no safe way to change one, and no program starts the service. A store on a real database would have no test that runs anywhere.

**What changes.** The module gains a PostgreSQL store that passes the same contract test as the in-memory store, the first migration of its schema with the migrator that applies it, and the program that applies the migrations and then serves the health routes. A CI job with a PostgreSQL database runs every test of the module on each pull request that changes it. The job names each action and its database image by fixed content, so neither can change under the same name.

**Done means:**

- The PostgreSQL store passes all 21 cases of the store contract test against a real database in CI.
- In CI the schema goes up, down and up again, and two programs that start at the same time apply it once.
- A pull request that changes products/ops-records runs a job with a PostgreSQL database, and a skipped database test turns that job red.
- The program ops-records applies the pending migrations, then answers /healthz and /readyz, and is ready only while the database answers.
- The program takes the database login only from two mounted files and refuses a password given any other way.
- The new job names its two actions by a commit hash and its database image by a digest, and the check that counts unpinned references stays green.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The module `products/ops-records` (created by AIP-221) gains three things. First, `internal/store/postgres.go`: the type `Postgres`, a store on PostgreSQL that implements the interface `Store` of `internal/store/store.go` and passes the same contract test (`runContract`, 21 cases) as the in-memory store. Second, migration 0001 of schema `ops` (`internal/store/migrations/0001_ops_records.up.sql` and `.down.sql`) and the migrator `internal/store/migrate.go` that applies and reverts it. Third, the program `cmd/ops-records`: it applies the pending migrations and serves `GET /healthz` and `GET /readyz`. The workflow `.github/workflows/test-ungated-trees.yaml` moves the module from the shared `go-modules` matrix to its own job `ops-records`, which starts a PostgreSQL service, runs every test of the module against it and fails when a test is skipped. The job names its two actions by their commit hash and its service image by its digest. A person can observe this on the pull request: the check `go test — products/ops-records (+ PostgreSQL store)` runs, its notice says `skipped 0`, and it is green; the check `check-pins` is green too.

## 3. The model (the law)
1. The module's `go.mod` is the block `go.mod`: the `go` line is `go 1.25.0`, and the one direct requirement is `github.com/jackc/pgx/v5 v5.13.0`. `go.sum` is the block `go.sum`. Releases of the driver below v5.9.2 and of `golang.org/x/text` below v0.41.0 carry known vulnerabilities that the check `security-scan` reports (field 4); v5.13.0 has none and brings `golang.org/x/text` v0.41.0.
2. Migration 0001 creates the seven tables of schema `ops`: `problems`, `incidents`, `signals`, `incident_events`, `judgements`, `feedback`, `outbox`, with the columns of the record types of `internal/store/store.go`. Every table has `organization text NOT NULL`. Every reference (`signals.incident_id`, `incidents.parent_id`, `incidents.problem_id`, `incident_events.incident_id`, `feedback.incident_id`) is a two-column foreign key on `(organization, id)`, so it can name a row of the same Organization only. The checks of the tables repeat the rules of `store.go` (identifier forms, fixed values, non-empty fields, time order). `judgements.outcome` is the empty string while a judgement waits. `outbox.seq` is an identity column: the order of enqueueing, which `PendingOutbox` follows. The table `change_links` is not created.
3. The migrator. A migration is two files, `migrations/<NNNN>_<name>.up.sql` and `.down.sql`, built into the program with `embed`. Versions start at 0001 and have no gap; any other file name is refused. The migrator creates schema `ops` and the table `ops.schema_migrations (version, name, applied_at)` when they are missing. Each migration runs in its own transaction, together with the row that records it, under the transaction-scoped advisory lock `0x6f70732d72656373`, so two programs that start at the same time apply it once. A down migration drops its tables and leaves schema `ops` and `ops.schema_migrations`. A database whose version is higher than the program knows is refused with `ErrSchemaNewer` and left unchanged. A released migration is never changed; a change of the schema is a new version.
4. The PostgreSQL store keeps every rule at the top of `internal/store/store.go`. A write that the rules refuse (`ErrInvalid`, `ErrNotFound`, `ErrConflict`) is refused before any statement can fail, so the transaction stays usable, as in the in-memory store: references are checked with a query first, and an insert of an existing identifier uses `ON CONFLICT (id) DO NOTHING`. Identifiers are ordered with `COLLATE "C"`, as Go orders strings.
5. The database tests are in `internal/store/postgres_test.go`: `TestPostgresContract` (the contract test on the PostgreSQL store), `TestPostgresMigrations` (up, down and up again), `TestPostgresMigrateConcurrently`, `TestPostgresSchemaNewer` and `TestPostgresCredentials`. They read the database from the environment variable `OPS_RECORDS_TEST_DSN` through the helper `testDSN` of that file. The helper holds the one skip of this change, the line `t.Skip(testDSNVariable + " is not set: this test needs a PostgreSQL database")`: each of the five tests is skipped by it when the variable is not set. This ticket names that line and allows it; the job of invariant 6 turns such a skip into a failure. The tests drop schema `ops` in that database and create it again. Without the variable, the rest of the module's tests run as before.
6. The CI job `ops-records` starts PostgreSQL 16 as a service (the image `postgres:16-alpine`, named by its digest: invariant 10), sets `OPS_RECORDS_TEST_DSN` to it and runs `go test -count=1 -v ./...` in the module. It fails when no test ran, when any test was skipped, when `go test` failed, or when `TestPostgresContract` did not pass by name. This is the same discipline as the job `pool-domain-manager` of the same workflow. The module leaves the `go-modules` matrix, whose job has no database and only warns on a skip. The path filters of the workflow do not change.
7. The program `ops-records`. `ops-records` or `ops-records serve` applies the pending migrations and then serves the health routes of `internal/health`, with the readiness check `database` (the store's `Ping`). `ops-records migrate` applies them and exits. `ops-records version` prints the version (set with `-ldflags "-X main.version=<version>"`, default `dev`). It reads `OPS_RECORDS_DATABASE_URL` (required, the database with no password), `OPS_RECORDS_DATABASE_CREDENTIALS_DIR` (required, a directory with the files `username` and `password`, which the store reads again for every new connection) and `OPS_RECORDS_LISTEN` (default `:8080`). A password in the URL, in `PGPASSWORD` or in a PostgreSQL password file is refused. Exit codes: 0 done; 1 the database or the server failed; 2 the configuration is wrong. The program offers no down migration. On SIGTERM or SIGINT it stops serving within 10 seconds and closes the store.
8. `store.go`, `memory.go`, `contract_test.go`, `internal/ids` and `internal/health` do not change. No chart, no Blueprint file, no Containerfile, no bootstrap-kit slot is added: nothing installs the service yet. The module's `README.md` is replaced by the block `README.md`, which describes the new state.

# ops-records

The operations-records service: the records of signals, incidents, their timelines, problems,
judgements and feedback of each Organization, and the outbox of the events it publishes.

Role in Catalyst: an Application Blueprint of the agent plane. It is written in Go, as its own
module. Its place in the model is described in [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).

State today: the module holds the identifiers (`internal/ids`), the health routes
(`internal/health`), the store interface with an in-memory store and a PostgreSQL store
(`internal/store`), migration 0001 of the schema, the contract test every store must pass,
and the program `cmd/ops-records`. Nothing installs the service yet: it has no chart, no
Blueprint file and no bootstrap-kit slot.

Records: one database schema, `ops`, with the tables `signals`, `incidents`, `incident_events`,
`problems`, `judgements`, `feedback` and `outbox`. Every row carries its Organization, and a
read for one Organization sees only that Organization's rows. The rules every store keeps are
written at the top of `internal/store/store.go`.

Migrations: `internal/store/migrations/<NNNN>_<name>.up.sql` and `.down.sql`, built into the
program. The program applies the pending ones when it starts, each in its own transaction under
an advisory lock, and records them in `ops.schema_migrations`. It refuses a database whose
version it does not know. A released migration is never changed; a change is a new version.

Program: `ops-records` (or `ops-records serve`) applies the migrations and serves `GET /healthz`
and `GET /readyz` (ready when the database answers); `ops-records migrate` applies them and
exits; `ops-records version` prints the version. Configuration:

- `OPS_RECORDS_DATABASE_URL` (required): the database, as a `postgres://` URL with no password.
- `OPS_RECORDS_DATABASE_CREDENTIALS_DIR` (required): a directory with the files `username` and
  `password`, mounted from OpenBao. They are read for every new connection, so a rotated
  credential is used without a restart. A password anywhere else is refused.
- `OPS_RECORDS_LISTEN`: the address of the health routes, default `:8080`.

Tests: `go vet ./... && go test ./...` in this folder. The PostgreSQL tests need a database
named by `OPS_RECORDS_TEST_DSN` (for example
`postgres://ops:ops@localhost:5432/ops_test?sslmode=disable`) and are skipped without it; they
drop and create schema `ops` there. The job `ops-records` of
`.github/workflows/test-ungated-trees.yaml` runs every test on each pull request that changes
this folder, with a PostgreSQL service, and fails when a test is skipped.

// Postgres is the PostgreSQL store. It keeps the rules of the package documentation on the
// seven tables of schema ops, which migration 0001 creates (migrate.go). It passes the same
// contract test as the in-memory store (postgres_test.go).
//
// A write that the rules refuse (ErrInvalid, ErrNotFound, ErrConflict) is refused before any
// statement can fail, so the transaction stays usable, as it does in the in-memory store.
type Postgres struct {
	pool   *pgxpool.Pool
	closed atomic.Bool
}

// PostgresConfig says how to reach the database.
type PostgresConfig struct {
	// URL is the database as a postgres:// URL or a key=value string.
	URL string
	// Credentials, when set, is called for every new connection and returns the user name
	// and the password of that connection. They replace any user and password of URL.
	Credentials func(ctx context.Context) (user, password string, err error)
	// MaxConns is the largest number of open connections; zero or less keeps the default
	// of the driver.
	MaxConns int32
}

// OpenPostgres returns a store on the database of cfg. It does not connect: the first call
// that needs the database does, and Ping reports whether it can.
func OpenPostgres(ctx context.Context, cfg PostgresConfig) (*Postgres, error) {
	pc, err := pgxpool.ParseConfig(cfg.URL)
	if err != nil {
		return nil, fmt.Errorf("store: the database URL cannot be read: %w", err)
	}
	if cfg.MaxConns > 0 {
		pc.MaxConns = cfg.MaxConns
	}
	if cfg.Credentials != nil {
		credentials := cfg.Credentials
		pc.BeforeConnect = func(ctx context.Context, cc *pgx.ConnConfig) error {
			user, password, err := credentials(ctx)
			if err != nil {
				return fmt.Errorf("store: database credentials: %w", err)
			}
			cc.User, cc.Password = user, password
			return nil
		}
	}
	pool, err := pgxpool.NewWithConfig(ctx, pc)
	if err != nil {
		return nil, fmt.Errorf("store: %w", err)
	}
	return &Postgres{pool: pool}, nil
}

// querier is what a pool and a transaction share.
type querier interface {
	Exec(ctx context.Context, sql string, args ...any) (pgconn.CommandTag, error)
	Query(ctx context.Context, sql string, args ...any) (pgx.Rows, error)
	QueryRow(ctx context.Context, sql string, args ...any) pgx.Row
}

func (p *Postgres) ready(ctx context.Context) error {
	if err := ctx.Err(); err != nil {
		return err
	}
	if p.closed.Load() {
		return errClosed
	}
	return nil
}

// InTx runs fn in one transaction.
func (p *Postgres) InTx(ctx context.Context, fn func(ctx context.Context, tx Tx) error) error {
	if err := p.ready(ctx); err != nil {
		return err
	}
	ptx, err := p.pool.Begin(ctx)
	if err != nil {
		return fmt.Errorf("store: begin: %w", err)
	}
	tx := &pgTx{tx: ptx}
	committed := false
	defer func() {
		tx.done.Store(true)
		if !committed {
			_ = ptx.Rollback(context.WithoutCancel(ctx))
		}
	}()
	if err := fn(ctx, tx); err != nil {
		return err
	}
	if err := ctx.Err(); err != nil {
		return err
	}
	if err := ptx.Commit(ctx); err != nil {
		return fmt.Errorf("store: commit: %w", err)
	}
	committed = true
	return nil
}

// PendingOutbox returns unpublished outbox rows in the order they were enqueued.
func (p *Postgres) PendingOutbox(ctx context.Context, limit int) ([]OutboxRow, error) {
	if err := p.ready(ctx); err != nil {
		return nil, err
	}
	rows, err := p.pool.Query(ctx, `SELECT id, organization, subject, payload, created_at, published_at
		FROM ops.outbox WHERE published_at IS NULL ORDER BY seq LIMIT $1`, clampLimit(limit))
	if err != nil {
		return nil, fmt.Errorf("store: pending outbox: %w", err)
	}
	return collect(rows, func(r pgx.Rows) (OutboxRow, error) {
		var o OutboxRow
		var payload []byte
		err := r.Scan(&o.ID, &o.Organization, &o.Subject, &payload, &o.CreatedAt, &o.PublishedAt)
		o.Payload = payload
		return normOutboxRow(o), err
	})
}

// MarkPublished records the publication of one outbox row.
func (p *Postgres) MarkPublished(ctx context.Context, id string, at time.Time) error {
	if err := p.ready(ctx); err != nil {
		return err
	}
	if at.IsZero() {
		return invalid("published at is required")
	}
	tag, err := p.pool.Exec(ctx, `UPDATE ops.outbox SET published_at = coalesce(published_at, $2) WHERE id = $1`,
		id, normTime(at))
	if err != nil {
		return fmt.Errorf("store: mark published: %w", err)
	}
	if tag.RowsAffected() == 0 {
		return ErrNotFound
	}
	return nil
}

func collect[T any](rows pgx.Rows, scan func(pgx.Rows) (T, error)) ([]T, error) {
	defer rows.Close()
	var out []T
	for rows.Next() {
		v, err := scan(rows)
		if err != nil {
			return nil, fmt.Errorf("store: read row: %w", err)
		}
		out = append(out, v)
	}
	if err := rows.Err(); err != nil {
		return nil, fmt.Errorf("store: read rows: %w", err)
	}
	return out, nil
}

// one returns the single row of rows, or ErrNotFound.
func one[T any](rows pgx.Rows, err error, scan func(pgx.Rows) (T, error)) (T, error) {
	var zero T
	if err != nil {
		return zero, fmt.Errorf("store: query: %w", err)
	}
	list, err := collect(rows, scan)
	if err != nil {
		return zero, err
	}
	if len(list) == 0 {
		return zero, ErrNotFound
	}
	return list[0], nil
}

package store

import (
	"context"
	"embed"
	"errors"
	"fmt"
	"io/fs"
	"regexp"
	"sort"
	"strconv"
)

// The migrations of schema ops. Each version has one file to apply it and one to revert it:
//
//	migrations/<NNNN>_<name>.up.sql
//	migrations/<NNNN>_<name>.down.sql
//
// Versions start at 0001 and have no gap. A migration that has been released is never
// changed; a change of the schema is a new version.
//
// The migrator keeps the applied versions in the table ops.schema_migrations, which it creates
// with schema ops before it applies anything. Each migration runs in its own transaction,
// together with the row that records it, under a transaction-scoped advisory lock, so two
// programs that start at the same time apply each migration once. A down migration removes
// the tables of its version and leaves schema ops and ops.schema_migrations in place.

//go:embed migrations/*.sql
var migrationFiles embed.FS

// Migration is one version of the schema.
type Migration struct {
	Version int
	Name    string
	Up      string
	Down    string
}

// ErrSchemaNewer is returned when the database holds a version that this program does not know.
var ErrSchemaNewer = errors.New("store: the database schema is newer than this program")

// migrateLock is the key of the advisory lock that the migrator takes in each transaction.
const migrateLock int64 = 0x6f70732d72656373 // "ops-recs"

var migrationName = regexp.MustCompile(`^([0-9]{4})_([a-z0-9_]+)\.(up|down)\.sql$`)

// Migrations returns the migrations of this program, oldest first.
func Migrations() ([]Migration, error) {
	sub, err := fs.Sub(migrationFiles, "migrations")
	if err != nil {
		return nil, err
	}
	return parseMigrations(sub)
}

// parseMigrations reads the migration files of the top directory of fsys.
func parseMigrations(fsys fs.FS) ([]Migration, error) {
	entries, err := fs.ReadDir(fsys, ".")
	if err != nil {
		return nil, fmt.Errorf("store: migrations: %w", err)
	}
	byVersion := map[int]*Migration{}
	for _, e := range entries {
		m := migrationName.FindStringSubmatch(e.Name())
		if e.IsDir() || m == nil {
			return nil, fmt.Errorf("store: migrations: %q is not <NNNN>_<name>.up.sql or .down.sql", e.Name())
		}
		version, _ := strconv.Atoi(m[1])
		body, err := fs.ReadFile(fsys, e.Name())
		if err != nil {
			return nil, fmt.Errorf("store: migrations: %w", err)
		}
		mig := byVersion[version]
		if mig == nil {
			mig = &Migration{Version: version, Name: m[2]}
			byVersion[version] = mig
		}
		if mig.Name != m[2] {
			return nil, fmt.Errorf("store: migrations: version %04d has two names, %q and %q", version, mig.Name, m[2])
		}
		if m[3] == "up" {
			mig.Up = string(body)
		} else {
			mig.Down = string(body)
		}
	}
	out := make([]Migration, 0, len(byVersion))
	for _, mig := range byVersion {
		out = append(out, *mig)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Version < out[j].Version })
	for i, mig := range out {
		if mig.Version != i+1 {
			return nil, fmt.Errorf("store: migrations: version %04d is missing", i+1)
		}
		if mig.Up == "" || mig.Down == "" {
			return nil, fmt.Errorf("store: migrations: version %04d needs both an up and a down file", mig.Version)
		}
	}
	if len(out) == 0 {
		return nil, errors.New("store: migrations: none found")
	}
	return out, nil
}

const migrationsTable = `CREATE SCHEMA IF NOT EXISTS ops;
CREATE TABLE IF NOT EXISTS ops.schema_migrations (
    version    integer     PRIMARY KEY,
    name       text        NOT NULL,
    applied_at timestamptz NOT NULL DEFAULT now()
)`

// SchemaVersion returns the newest version applied to the database, or 0.
func (p *Postgres) SchemaVersion(ctx context.Context) (int, error) {
	if err := p.ready(ctx); err != nil {
		return 0, err
	}
	var present bool
	if err := p.pool.QueryRow(ctx, `SELECT to_regclass('ops.schema_migrations') IS NOT NULL`).Scan(&present); err != nil {
		return 0, fmt.Errorf("store: schema version: %w", err)
	}
	if !present {
		return 0, nil
	}
	return currentVersion(ctx, p.pool)
}

func currentVersion(ctx context.Context, q querier) (int, error) {
	var v int
	if err := q.QueryRow(ctx, `SELECT coalesce(max(version), 0) FROM ops.schema_migrations`).Scan(&v); err != nil {
		return 0, fmt.Errorf("store: schema version: %w", err)
	}
	return v, nil
}

// MigrateUp applies every migration the database does not have yet, oldest first, and returns
// the versions it applied. It returns ErrSchemaNewer when the database has a version this
// program does not know, and changes nothing then.
func (p *Postgres) MigrateUp(ctx context.Context) ([]int, error) {
	migs, err := Migrations()
	if err != nil {
		return nil, err
	}
	var applied []int
	for _, mig := range migs {
		done, err := p.migrateStep(ctx, func(current int) (string, bool, error) {
			if current > len(migs) {
				return "", false, fmt.Errorf("%w: version %d, this program knows %d", ErrSchemaNewer, current, len(migs))
			}
			if current >= mig.Version {
				return "", false, nil
			}
			return mig.Up, true, nil
		}, `INSERT INTO ops.schema_migrations (version, name) VALUES ($1, $2)`, mig.Version, mig.Name)
		if err != nil {
			return applied, fmt.Errorf("store: migration %04d up: %w", mig.Version, err)
		}
		if done {
			applied = append(applied, mig.Version)
		}
	}
	return applied, nil
}

// MigrateDown reverts up to steps migrations, newest first, and returns the versions it
// reverted. It stops when no migration is left. Reverting a migration deletes its tables
// and every row in them.
func (p *Postgres) MigrateDown(ctx context.Context, steps int) ([]int, error) {
	migs, err := Migrations()
	if err != nil {
		return nil, err
	}
	var reverted []int
	for i := 0; i < steps; i++ {
		var version int
		done, err := p.migrateStep(ctx, func(current int) (string, bool, error) {
			if current > len(migs) {
				return "", false, fmt.Errorf("%w: version %d, this program knows %d", ErrSchemaNewer, current, len(migs))
			}
			if current == 0 {
				return "", false, nil
			}
			version = current
			return migs[current-1].Down, true, nil
		}, `DELETE FROM ops.schema_migrations WHERE version = (SELECT max(version) FROM ops.schema_migrations)`)
		if err != nil {
			return reverted, fmt.Errorf("store: migration down: %w", err)
		}
		if !done {
			break
		}
		reverted = append(reverted, version)
	}
	return reverted, nil
}

// migrateStep runs one migration in one transaction. choose gets the current version and
// returns the SQL to run, or false when there is nothing to do. record is run after the SQL,
// in the same transaction.
func (p *Postgres) migrateStep(ctx context.Context, choose func(current int) (string, bool, error),
	record string, args ...any) (bool, error) {
	if err := p.ready(ctx); err != nil {
		return false, err
	}
	tx, err := p.pool.Begin(ctx)
	if err != nil {
		return false, err
	}
	defer func() { _ = tx.Rollback(context.WithoutCancel(ctx)) }()
	if _, err := tx.Exec(ctx, `SELECT pg_advisory_xact_lock($1)`, migrateLock); err != nil {
		return false, err
	}
	if _, err := tx.Exec(ctx, migrationsTable); err != nil {
		return false, err
	}
	current, err := currentVersion(ctx, tx)
	if err != nil {
		return false, err
	}
	sql, run, err := choose(current)
	if err != nil || !run {
		return false, err
	}
	if _, err := tx.Exec(ctx, sql); err != nil {
		return false, err
	}
	if _, err := tx.Exec(ctx, record, args...); err != nil {
		return false, err
	}
	if err := tx.Commit(ctx); err != nil {
		return false, err
	}
	return true, nil
}

-- Migration 0001 of the operations-records service: the seven tables of schema ops.
--
-- The migrator (internal/store/migrate.go) creates schema ops and ops.schema_migrations
-- before it runs this file, and runs it in one transaction. The rules of each column are
-- written in internal/store/store.go; the checks below repeat them, so that a row that
-- breaks them cannot be written by any program. Every table has the column organization,
-- and every reference names a row of the same Organization (the two-column foreign keys).
-- The table change_links is not part of this version.

CREATE TABLE ops.problems (
    id           text        PRIMARY KEY CHECK (id ~ '^PRB-[0-7][0-9A-HJKMNP-TV-Z]{25}$'),
    organization text        NOT NULL CHECK (organization <> ''),
    title        text        NOT NULL CHECK (title <> ''),
    statement    text        NOT NULL DEFAULT '',
    state        text        NOT NULL CHECK (state IN ('open', 'known', 'closed')),
    created_at   timestamptz NOT NULL,
    UNIQUE (organization, id)
);
CREATE INDEX problems_by_created ON ops.problems (organization, created_at DESC);

CREATE TABLE ops.incidents (
    id              text        PRIMARY KEY CHECK (id ~ '^INC-[0-7][0-9A-HJKMNP-TV-Z]{25}$'),
    organization    text        NOT NULL CHECK (organization <> ''),
    title           text        NOT NULL CHECK (title <> ''),
    severity        integer     NOT NULL CHECK (severity BETWEEN 1 AND 4),
    severity_set_by text        NOT NULL CHECK (severity_set_by IN ('rules', 'agent', 'person')),
    state           text        NOT NULL CHECK (state IN ('open', 'mitigated', 'resolved')),
    opened_by       text        NOT NULL CHECK (opened_by IN ('rules', 'agent')),
    opened_at       timestamptz NOT NULL,
    resolved_at     timestamptz NULL,
    parent_id       text        NULL,
    problem_id      text        NULL,
    UNIQUE (organization, id),
    CHECK (parent_id <> id),
    CHECK ((state = 'resolved') = (resolved_at IS NOT NULL)),
    CHECK (resolved_at IS NULL OR resolved_at >= opened_at),
    FOREIGN KEY (organization, parent_id) REFERENCES ops.incidents (organization, id),
    FOREIGN KEY (organization, problem_id) REFERENCES ops.problems (organization, id)
);
CREATE INDEX incidents_by_opened ON ops.incidents (organization, opened_at DESC);
CREATE INDEX incidents_by_parent ON ops.incidents (parent_id) WHERE parent_id IS NOT NULL;
CREATE INDEX incidents_by_problem ON ops.incidents (problem_id) WHERE problem_id IS NOT NULL;

    organization   text        NOT NULL CHECK (organization <> ''),
    source         text        NOT NULL CHECK (source IN ('alert', 'security', 'access')),

// Command ops-records is the operations-records service.
//
//	ops-records [serve]   apply the pending migrations, then serve the health routes
//	ops-records migrate   apply the pending migrations and exit
//	ops-records version   print the version and exit
//
// Environment:
//
//	OPS_RECORDS_DATABASE_URL              required: the database, as a postgres:// URL or a
//	                                      key=value string, with no password
//	OPS_RECORDS_DATABASE_CREDENTIALS_DIR  required: a directory with the two files username
//	                                      and password, mounted from OpenBao; both are read
//	                                      again for every new connection, so a rotated
//	                                      credential is used without a restart
//	OPS_RECORDS_LISTEN                    the address of the health routes; default ":8080"
//
// A password in the URL or in the environment of the driver (PGPASSWORD, a password file)
// is refused: the database credential reaches the program only as the mounted files.
//
// Exit codes: 0 done; 1 the database or the server failed; 2 the configuration is wrong.
package main

import (
	"context"
	"errors"
	"fmt"
	"io"
	"net"
	"net/http"
	"os"
	"os/signal"
	"strings"
	"syscall"
	"time"

	"github.com/jackc/pgx/v5"

	"github.com/openova-io/openova/products/ops-records/internal/health"
	"github.com/openova-io/openova/products/ops-records/internal/store"
)

// version is set at build time: -ldflags "-X main.version=<version>".
var version = "dev"

const (
	envURL        = "OPS_RECORDS_DATABASE_URL"
	envLoginDir   = "OPS_RECORDS_DATABASE_CREDENTIALS_DIR"
	envListen     = "OPS_RECORDS_LISTEN"
	defaultListen = ":8080"
	shutdownGrace = 10 * time.Second
)

// database is what the program needs of the store.
type database interface {
	MigrateUp(ctx context.Context) ([]int, error)
	Ping(ctx context.Context) error
	Close() error
}

// program holds what the commands read and write, so that a test can replace each part.
type program struct {
	getenv    func(string) string
	stdout    io.Writer
	stderr    io.Writer
	open      func(ctx context.Context, url, credentialsDir string) (database, error)
	listening func(addr net.Addr) // called once the health routes listen; may be nil
}

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), syscall.SIGINT, syscall.SIGTERM)
	p := program{getenv: os.Getenv, stdout: os.Stdout, stderr: os.Stderr, open: openPostgres}
	code := p.run(ctx, os.Args[1:])
	stop()
	os.Exit(code)
}

func (p program) run(ctx context.Context, args []string) int {
	command := "serve"
	if len(args) > 0 {
		command = args[0]
	}
	if len(args) > 1 {
		return p.fail(2, "too many arguments; usage: ops-records [serve|migrate|version]")
	}
	switch command {
	case "version":
		_, _ = fmt.Fprintln(p.stdout, version)
		return 0
	case "serve", "migrate":
	default:
		return p.fail(2, "unknown command %q; usage: ops-records [serve|migrate|version]", command)
	}

	url, dir := p.getenv(envURL), p.getenv(envLoginDir)
	if url == "" || dir == "" {
		return p.fail(2, "%s and %s must both be set", envURL, envLoginDir)
	}
	if err := refusePassword(url); err != nil {
		return p.fail(2, "%v", err)
	}
	db, err := p.open(ctx, url, dir)
	if err != nil {
		return p.fail(2, "%v", err)
	}
	defer func() { _ = db.Close() }()

	applied, err := db.MigrateUp(ctx)
	if err != nil {
		return p.fail(1, "migrate: %v", err)
	}
	p.logf("schema ops: applied %d migration(s) %v", len(applied), applied)
	if command == "migrate" {
		return 0
	}
	return p.serve(ctx, db)
}

func (p program) serve(ctx context.Context, db database) int {
	addr := p.getenv(envListen)
	if addr == "" {
		addr = defaultListen
	}
	h := health.New(version, 0)
	h.Add("database", db.Ping)
	mux := http.NewServeMux()
	h.Register(mux)

	ln, err := net.Listen("tcp", addr)
	if err != nil {
		return p.fail(1, "listen on %s: %v", addr, err)
	}
	srv := &http.Server{Handler: mux, ReadHeaderTimeout: 5 * time.Second}
	served := make(chan error, 1)
	go func() { served <- srv.Serve(ln) }()
	p.logf("serving the health routes on %s, version %s", ln.Addr(), version)
	if p.listening != nil {
		p.listening(ln.Addr())
	}

	select {
	case err := <-served:
		return p.fail(1, "serve: %v", err)
	case <-ctx.Done():
	}
	shutdown, cancel := context.WithTimeout(context.WithoutCancel(ctx), shutdownGrace)
	defer cancel()
	if err := srv.Shutdown(shutdown); err != nil {
		return p.fail(1, "shutdown: %v", err)
	}
	if err := <-served; err != nil && !errors.Is(err, http.ErrServerClosed) {
		return p.fail(1, "serve: %v", err)
	}
	p.logf("stopped")
	return 0
}

// refusePassword returns an error when the driver would find a password anywhere but in the
// credential files: in the URL, in PGPASSWORD or in a password file.
func refusePassword(url string) error {
	cfg, err := pgx.ParseConfig(url)
	if err != nil {
		return fmt.Errorf("%s cannot be read: %v", envURL, err)
	}
	if cfg.Password != "" {
		return fmt.Errorf("a database password was found outside %s; put it in the file password there, "+
			"never in %s, PGPASSWORD or a password file", envLoginDir, envURL)
	}
	return nil
}

// readCredentials reads the files username and password of dir. One final line end is removed.
func readCredentials(dir string) (string, string, error) {
	root, err := os.OpenRoot(dir)
	if err != nil {
		return "", "", err
	}
	defer func() { _ = root.Close() }()
	var values [2]string
	for i, name := range []string{"username", "password"} {
		f, err := root.Open(name)
		if err != nil {
			return "", "", err
		}
		raw, err := io.ReadAll(io.LimitReader(f, 4096))
		_ = f.Close()
		if err != nil {
			return "", "", err
		}
		v := strings.TrimSuffix(strings.TrimSuffix(string(raw), "\n"), "\r")
		if v == "" {
			return "", "", fmt.Errorf("the file %s in %s is empty", name, dir)
		}
		values[i] = v
	}
