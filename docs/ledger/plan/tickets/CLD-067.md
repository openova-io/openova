# CLD-067 — Gate check CLD-G06 as a suite file

## In plain words

**The problem today.** The gate check that must prove a Crossplane upgrade leaves the adoption of the cloud resources intact has no code. Before Crossplane can be upgraded, a run of the acceptance suite has to be able to say whether every adopted resource is still bound and healthy.

**What changes.** The acceptance suite gets the check. In every region it reads the CloudAdoption claims and the OpenTofu Workspaces they compose, and fails when a region has no claim or a claim or its one Workspace is not Synced and Ready. It also records which package every Crossplane provider and function was pulled from.

**Done means:**

- The gate check of the Crossplane upgrade fails a region that has no CloudAdoption claim.
- It fails a region where a claim, or the Workspace the claim composes, is not Synced and Ready.
- It fails a region where a claim composes no Workspace or more than one.
- Every run records the package reference of each Crossplane provider and function, and a package reference never fails the check.
- The tests of the check run on every pull request without a cluster, with one failing case per rule.
- The gate manifest lists the check as expected-fail, with its code file.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. The check is one file, `tests/acceptance/sovereign/internal/suite/check_crossplane.go`, that calls `RegisterCheck` in `init()` and holds the identifier `"CLD-G06"`. Its tests are one file, `check_crossplane_test.go`. Both are the blocks of this ticket.
2. The check records one step per region, in the order of `cc.Regions`: `CLD-G06.1` for the first region, `CLD-G06.2` for the second. The step reads, with `kubectl get -o json -A` through `kube.Region.GetList`: `cloudadoptions.compose.openova.io` (the claims), `workspaces.opentofu.upbound.io`, `providers.pkg.crossplane.io` and `functions.pkg.crossplane.io`.
3. The step fails when the claims or the Workspaces cannot be read, and when the region has no claim ("nothing was measured").
4. The step fails for each claim that is not `Synced=True` and `Ready=True`. A missing condition fails like a false one.
5. The step fails for each claim without `spec.resourceRef.name`, and for each claim that does not compose exactly one Workspace. A Workspace belongs to a claim when its label `crossplane.io/composite` equals the claim's `spec.resourceRef.name`: Crossplane puts that label, with the name of the composite resource, on every resource it composes, and the claim names its composite in `spec.resourceRef`. A Workspace that no claim composes is counted and not judged.
6. The step fails for each composed Workspace that is not `Synced=True` and `Ready=True`.
7. The package reference of every provider (`provider/<name>`) and function (`function/<name>`) is recorded in the evidence `packages`. It is never judged: the hand-over rewrites the package references, so one run cannot say which registry is right. A package list that cannot be read is recorded in the evidence `packages_unread` and does not fail the step.
8. The check only reads: it runs `kubectl get` and nothing else. The suite stays a module of the Go standard library only.
9. The step's evidence holds `claims` (the number of claims), `workspaces` (the number of Workspaces), `composed` (claim to Workspace name), `not_ready` (every problem, sorted) and `packages`.
10. The manifest entry CLD-G06 changes only in `state` (to `expected-fail`) and gains the line `implementation: tests/acceptance/sovereign/internal/suite/check_crossplane.go`. No other line of `docs/ledger/gates.yaml` changes.

package suite

import (
	"context"
	"errors"
	"fmt"
	"sort"
	"strconv"
	"strings"

	"github.com/openova-io/openova/tests/acceptance/sovereign/internal/kube"

// Check CLD-G06, Crossplane upgrade leaves Workspaces and packages intact. It
// asserts what one run can see, in every region:
//   - the region has at least one CloudAdoption claim;
//   - every CloudAdoption claim is Synced=True and Ready=True;
//   - every claim composes exactly one Workspace: one Workspace carries the
//     label crossplane.io/composite with the value of the claim's
//     spec.resourceRef.name. A claim without spec.resourceRef.name composes
//     none;
//   - that Workspace is Synced=True and Ready=True.
//
// The package reference (spec.package) of every Crossplane provider and
// function is recorded as evidence and not judged: the hand-over rewrites the
// package references, so one run cannot say which registry is right. The check
// only reads: it runs `kubectl get` and nothing else.
const crossplaneID = "CLD-G06"

// The kinds the check reads, by their full resource names.
const (
	crossplaneClaimResource     = "cloudadoptions.compose.openova.io"
	crossplaneWorkspaceResource = "workspaces.opentofu.upbound.io"
	crossplaneProviderResource  = "providers.pkg.crossplane.io"
	crossplaneFunctionResource  = "functions.pkg.crossplane.io"
)

// crossplaneCompositeLabel is the label that Crossplane puts on every
// resource it composes. Its value is the name of the composite resource.
const crossplaneCompositeLabel = "crossplane.io/composite"

type crossplaneCheck struct{}

func init() { RegisterCheck(crossplaneCheck{}) }

func (crossplaneCheck) ID() string { return crossplaneID }

func (crossplaneCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
	for i, region := range cc.Regions {
		id := crossplaneID + "." + strconv.Itoa(i+1)
		rec.Step(id, "every CloudAdoption claim is Synced and Ready and composes exactly one Synced and Ready Workspace in region "+region.ID, func(ev Evidence) error {
			crossplanePackages(ctx, region, ev)
			claims, err := region.GetList(ctx, crossplaneClaimResource, "")
			if err != nil {
				return err
			}
			workspaces, err := region.GetList(ctx, crossplaneWorkspaceResource, "")
			if err != nil {
				return err
			}
			byComposite := map[string][]kube.Object{}
			for _, w := range workspaces {
				if composite := w.Str("metadata", "labels", crossplaneCompositeLabel); composite != "" {
					byComposite[composite] = append(byComposite[composite], w)
				}
			}
			composed, bad := map[string]string{}, []string{}
			for _, claim := range claims {
				name := claim.Namespace() + "/" + claim.Name()
				if why := crossplaneSyncedReady(claim); why != "" {
					bad = append(bad, "claim "+name+" "+why)
				}
				composite := claim.Str("spec", "resourceRef", "name")
				if composite == "" {
					bad = append(bad, "claim "+name+" has no spec.resourceRef.name")
					continue
				}
				own := byComposite[composite]
				if len(own) != 1 {
					bad = append(bad, fmt.Sprintf("claim %s composes %d Workspaces with %s=%s, want 1", name, len(own), crossplaneCompositeLabel, composite))
					continue
				}
				composed[name] = own[0].Name()
				if why := crossplaneSyncedReady(own[0]); why != "" {
					bad = append(bad, "Workspace "+own[0].Name()+" of claim "+name+" "+why)
				}
			}
			sort.Strings(bad)
			ev["claims"], ev["workspaces"], ev["composed"], ev["not_ready"] = len(claims), len(workspaces), composed, bad
			if len(claims) == 0 {
				return errors.New("no CloudAdoption claim was found: nothing was measured")
			}
			if len(bad) > 0 {
				return fmt.Errorf("%d problems with the %d CloudAdoption claims: %s", len(bad), len(claims), strings.Join(bad, "; "))
			}
			return nil
		})
	}
	return nil
}

// crossplaneSyncedReady returns "" when the object is Synced=True and
// Ready=True, and else what is wrong with it.
func crossplaneSyncedReady(o kube.Object) string {
	why := []string{}
	for _, t := range []string{"Synced", "Ready"} {
		status, reason, _, found := o.Condition(t)
		switch {
		case !found:
			why = append(why, "has no "+t+" condition")
		case status != "True":
			why = append(why, "is "+t+"="+status+" ("+reason+")")
		}
	}
	return strings.Join(why, " and ")
}

// crossplanePackages records the package reference of every Crossplane
// provider and function of the region as evidence. Nothing here is judged:
// a list that cannot be read is recorded with its error.
func crossplanePackages(ctx context.Context, region kube.Region, ev Evidence) {
	packages, unread := map[string]string{}, []string{}
	for _, kind := range []struct{ prefix, resource string }{
		{"provider/", crossplaneProviderResource},
		{"function/", crossplaneFunctionResource},
	} {
		list, err := region.GetList(ctx, kind.resource, "")
		if err != nil {
			unread = append(unread, err.Error())
			continue
		}
		for _, p := range list {
			packages[kind.prefix+p.Name()] = p.Str("spec", "package")
		}
	}
	ev["packages"] = packages
	if len(unread) > 0 {
		ev["packages_unread"] = unread
	}
}
