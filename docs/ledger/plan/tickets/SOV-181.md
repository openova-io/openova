# SOV-181 — The provisioning routes refuse a Sovereign that is not a mothership

## In plain words

**The problem today.** Every Sovereign runs the same API as the mothership, so a Sovereign that is not a mothership still serves the routes that create, wipe and re-provision deployments and that fetch their access files. Nothing in the API refuses them, although such a Sovereign has nothing to provision. The API now knows its own mode at run time, but no route uses it.

**What changes.** The provisioning routes check the mode first. In mode sovereign they refuse with 403 and the code not-in-mothership-mode; in mode mothership they work as before. The views of jobs, component state and reconcilers stay open on every Sovereign.

**Done means:**

- On a Sovereign in mode sovereign, each of the nine provisioning routes answers 403 with the body {"error":"not-in-mothership-mode"}, and the request never reaches its handler.
- On the mothership, and on a Sovereign whose variables document sets mode mothership, the same nine routes reach their handlers unchanged.
- A Sovereign whose variables cannot be read is treated as mode sovereign, so it refuses; the mothership without a cluster client keeps provisioning.
- The jobs, component-state, reconciler, deployment and topology views answer on a Sovereign in both modes.
- The route table names the new wrapper on exactly the nine routes, and every other route is unchanged.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A Sovereign that is not a mothership cannot be asked to provision or wipe. Nine routes of catalyst-api are wrapped by a new middleware, `MothershipOnly`, of the package `products/catalyst/bootstrap/api/internal/sovself`: `POST /api/v1/deployments`, `DELETE /api/v1/deployments/{id}`, `GET /api/v1/deployments/{id}/kubeconfig`, `POST /api/v1/deployments/{id}/phases/{phase}/retry`, `POST /api/v1/deployments/{id}/wipe`, `POST /api/v1/deployments/{id}/republish-dns`, `POST /api/v1/deployments/{id}/mint-handover-token`, `DELETE /api/v1/deployments/{id}/release-subdomain` and `POST /api/v1/registrar/{registrar}/set-ns`. In mode `sovereign` each answers `403 {"error":"not-in-mothership-mode"}` and its handler does not run. In mode `mothership` each reaches its handler unchanged. The mode is the one `GET /api/v1/sovereign/self` already answers (package SOV-180), read by the same object, so both read one kept answer. Every other route, among them the views of jobs, component state and reconcilers that the Sovereign console reads, is unchanged.

## 3. The model (the law)
1. **One mode, one reader.** The mode comes from `internal/sovself`, the reader SOV-180 added. `buildRouter` in `cmd/api/routes.go` makes one `sovself.Route` (`sovself.New(h.SovereignSelf, log)`) and keeps it in the new field `self` of `routeDeps`. The self route is served by `d.self.Serve`, the gate is `d.self.MothershipOnly`. No second reader, no new environment variable, no host name decides the mode.
2. **The rule of the gate.** `func (rt *Route) MothershipOnly(next http.Handler) http.Handler` reads the mode with the route's own kept read (`rt.current()`, kept for `CacheTTL`, 15 seconds). When the mode is `mothership` the request goes to `next` unchanged. Otherwise it answers status 403 with `Content-Type: application/json` and the body `{"error":"not-in-mothership-mode"}` followed by a newline, through the package's own `writeJSON`, and `next` is not called.
3. **How the mode is decided** (unchanged, SOV-180): the key `SOVEREIGN_MODE` of the ConfigMap `flux-system/sovereign-variables`; an absent key or a value other than `sovereign` and `mothership` gives the contract default `sovereign`. Without that ConfigMap, a process without `SOVEREIGN_FQDN` is the mothership and one with it is a Sovereign. A read that fails counts as an absent ConfigMap. So a Sovereign whose ConfigMap cannot be read refuses, and the mothership (no ConfigMap, no `SOVEREIGN_FQDN`) keeps provisioning.
4. **The closed list.** Exactly the nine routes of field 2 are wrapped, each with `rg.With(d.self.MothershipOnly)` in front of its registration in `cmd/api/routes_deployments.go` (eight) and `cmd/api/routes_registrar.go` (one). No other route is wrapped. The public cloud-init routes (`PUT /api/v1/deployments/{id}/kubeconfig`, `PUT /api/v1/deployments/{id}/cloudinit-log`), the hand-over routes and every read view stay as they are.
5. **The route table.** `chi.Walk` reports the middleware of `With` after the group's, so the nine routes move from chain 2 to a new chain 3, which is chain 2 with `sovself.(*Route).MothershipOnly-fm` appended. In `cmd/api/testdata/routes.golden` the nine route lines end in ` 3` in place of ` 2`, and the line of chain 3 is added. The handler names do not change.
6. **Contract C9 does not change.** The methods and paths of the mutating routes are the same, so `docs/contracts/C9-mutating-routes.yaml` and its generator agree as before; the generator reads only the method and path of each golden line.
7. **Tests.** `internal/sovself/mothership_only_test.go` proves the rule of the gate for each way the mode is decided. `cmd/api/routes_mothership_only_test.go` proves on the real router that exactly the nine routes carry the gate, and, by sending a request through each route's own middleware chain to a stand-in for its handler, that each answers 403 in mode sovereign and reaches its handler in mode mothership, and that nine read views reach their handler in both modes.
8. Nothing else changes: no handler, no `main.go`, no chart, no contract file, no guard baseline, no console code.

// walked is one route of the router: its middleware chain and its names.
type walked struct {
	mws   []func(http.Handler) http.Handler
	names []string
}

func walkRoutes(t *testing.T) map[string]walked {
	t.Helper()
	routes := map[string]walked{}
	err := chi.Walk(buildRouter(goldenDeps()), func(method, path string, _ http.Handler, mws ...func(http.Handler) http.Handler) error {
		w := walked{mws: mws}
		for _, mw := range mws {
			w.names = append(w.names, funcName(reflect.ValueOf(mw).Pointer()))
		}
		routes[method+" "+path] = w
		return nil
	})
	if err != nil {
		t.Fatalf("walk the router: %v", err)
	}
	return routes
}

// TestMothershipOnlyRoutes: the routes wrapped by MothershipOnly are exactly

func TestMothershipOnlyRoutes(t *testing.T) {

// serve sends one request for route through the route's own middleware
// chain to a stand-in for its handler, and returns the status, the body and
// whether the stand-in ran.
func serve(t *testing.T, routes map[string]walked, route string) (int, string, bool) {
	t.Helper()
	w, ok := routes[route]
	if !ok {
		t.Fatalf("%s: not registered", route)
	}
	reached := false
	endpoint := http.HandlerFunc(func(rw http.ResponseWriter, _ *http.Request) {
		reached = true
		rw.WriteHeader(http.StatusTeapot)
	})
	method, path, _ := strings.Cut(route, " ")
	concrete := strings.ReplaceAll(pathParam.ReplaceAllString(path, "x"), "*", "x")
	rec := httptest.NewRecorder()
	chi.Chain(w.mws...).Handler(endpoint).ServeHTTP(rec, httptest.NewRequest(method, concrete, nil))
	return rec.Code, rec.Body.String(), reached
}

// gated sends one POST through MothershipOnly and returns the status, the

func gated(t *testing.T, rt *Route) (int, string, bool) {
	t.Helper()
	reached := false
	next := http.HandlerFunc(func(w http.ResponseWriter, _ *http.Request) {
		reached = true
		w.WriteHeader(http.StatusAccepted)
	})
	rec := httptest.NewRecorder()
	rt.MothershipOnly(next).ServeHTTP(rec, httptest.NewRequest(http.MethodPost, "/api/v1/deployments", nil))
	return rec.Code, rec.Body.String(), reached
}

// TestMothershipOnly: a provisioning route reaches its handler only in mode
// mothership; in mode sovereign it answers 403 not-in-mothership-mode.
func TestMothershipOnly(t *testing.T) {
	sovereign := map[string]string{"SOVEREIGN_FQDN": "alpha.example.org"}
	cases := []struct {
		name    string
		vars    map[string]string // nil: no variables document
		env     map[string]string
		allowed bool
	}{
		{"mode sovereign", map[string]string{"SOVEREIGN_MODE": "sovereign"}, sovereign, false},
		{"a document with only kit keys is mode sovereign", map[string]string{"SOVEREIGN_FQDN": "alpha.example.org"}, sovereign, false},
		{"a value the contract does not allow is mode sovereign", map[string]string{"SOVEREIGN_MODE": "parent"}, sovereign, false},
		{"mode mothership", map[string]string{"SOVEREIGN_MODE": "mothership"}, sovereign, true},
		{"no document and no SOVEREIGN_FQDN is the mothership", nil, map[string]string{}, true},
		{"no document and SOVEREIGN_FQDN is a Sovereign", nil, sovereign, false},
	}
	for _, c := range cases {
		cs := cluster(t)
		if c.vars != nil {
			cs = cluster(t, configMap("flux-system", "sovereign-variables", c.vars))
		}
		code, body, reached := gated(t, route(cs, c.env, true, &clock{time.Unix(0, 0)}))
		if c.allowed {
			if code != http.StatusAccepted || !reached {
				t.Errorf("%s: status %d, handler ran %v; want 202 from the handler", c.name, code, reached)
			}
			continue
		}
		if code != http.StatusForbidden || reached {
			t.Errorf("%s: status %d, handler ran %v; want 403 and the handler not run", c.name, code, reached)
		}
		if body != "{\"error\":\"not-in-mothership-mode\"}\n" {
			t.Errorf("%s: body %q", c.name, body)
		}
	}
}

// TestMothershipOnlyFailsClosed: on a Sovereign whose ConfigMaps cannot be
// read, or that has no cluster client, the route is refused; the mothership
// without a cluster client keeps it.
func TestMothershipOnlyFailsClosed(t *testing.T) {
	cs := cluster(t, configMap("flux-system", "sovereign-variables", map[string]string{"SOVEREIGN_MODE": "mothership"}))
	cs.PrependReactor("get", "configmaps", func(k8stesting.Action) (bool, runtime.Object, error) {
		return true, nil, errors.New("connection refused")
	})

		t.Errorf("a read that fails on a Sovereign: status %d, handler ran %v; want 403", code, reached)
	}
	noClient := func() (kubernetes.Interface, error) { return nil, errors.New("not in a cluster") }
	for _, c := range []struct {
		name    string
		env     map[string]string
		allowed bool
	}{
		{"no cluster client on a Sovereign", map[string]string{"SOVEREIGN_FQDN": "alpha.example.org"}, false},

			t.Errorf("%s: status %d, handler ran %v; want the handler run %v", c.name, code, reached, c.allowed)
		}
	}
}
