# FND-014 — A deployment may name the Git ref it follows

## In plain words

**The problem today.** A new Sovereign always follows the main branch, or the one branch the provisioning service is configured with. A request to create a deployment cannot choose the ref. So a release candidate cannot be installed on a test Sovereign without changing the configuration of the service itself.

**What changes.** A request to create a deployment may carry one optional field that names the ref, which is main or a release-candidate ref. The fire command of the lifecycle script sends that field when its variable is set.

**Done means:**

- A request that names a release-candidate ref gives the new Sovereign that ref as the branch it follows.
- A request without the field behaves exactly as before.
- A request that names any other branch is refused with a clear error, before anything is provisioned.
- The lifecycle script sends the field only when its variable is set, and its request is unchanged otherwise.
- The existing tests of the provisioning code still pass.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The request body of `POST /api/v1/deployments` accepts one new optional field, `gitopsBranch`. Its value is `main` or a release-candidate ref of the form `rc/<id>`. The value becomes the tofu variable `gitops_branch`, which is the branch the new Sovereign follows. A request without the field behaves as today. A request with any other value is answered with HTTP 400 and the body `{"error":"invalid gitopsBranch"}`, and nothing is provisioned. The command `fire` of `scripts/sovereign-lifecycle.sh` sends the field when the environment variable `GITOPS_BRANCH` is set.

## 3. The model (the law)
1. The type `Request` in `products/catalyst/bootstrap/api/internal/provisioner/provisioner.go` has one new field: `GitopsBranch string` with the tag `json:"gitopsBranch,omitempty"`. The field is optional.
2. An accepted value is the empty string, or a string that matches the expression `^(main|rc/[0-9]{8}T[0-9]{6}Z-[0-9a-f]{7})$`. A release-candidate ref is `rc/<UTC yyyymmddThhmmssZ>-<first 7 hex characters of the commit>`, as in `rc/20261120T060000Z-4be7a11`. No other branch name is accepted.
3. One function decides: `resolveGitopsBranch(req Request) (string, error)`. An empty field gives `env("CATALYST_GITOPS_BRANCH", "main")`, which is today's value. A value that matches the expression is returned as it is. Any other value gives an error whose text is exactly `invalid gitopsBranch`.
4. The value of the environment variable `CATALYST_GITOPS_BRANCH` is not matched against the expression. It is not checked today, and that does not change.
5. `func (r *Request) Validate()` calls `resolveGitopsBranch` first and returns its error. The create handler already answers an error of `Validate()` with HTTP 400 and the body `{"error":"<text>"}`. The handler does not change.
6. `writeTfvars` writes the resolved value under the key `gitops_branch`. That is the only reader of the field. The name of the tofu variable does not change.
7. The field is not stored on the deployment entry that the API keeps on disk. No file under `internal/store` changes.
8. In `scripts/sovereign-lifecycle.sh` the command `fire` adds the key `gitopsBranch` to the request body when the environment variable `GITOPS_BRANCH` is set and not empty. When it is unset or empty, the body is the same as today. The script does not check the value; the server does. The line that `fire` prints before the request shows the value.
9. This ticket deletes no file. It adds no line to `docs/ledger/deleted-paths.txt`.

The new code in `GO`, between the last field of `Request` and the comment of `Validate()`, reads like this after the change (the indentation is one tab):

```go
	ObjectStorageBucket    string `json:"objectStorageBucket"`

	// GitopsBranch is the Git ref the new Sovereign follows. Empty means the
	// value of CATALYST_GITOPS_BRANCH, or "main" when that is unset. Any
	// other value must match gitopsBranchPattern (see resolveGitopsBranch).
	GitopsBranch string `json:"gitopsBranch,omitempty"`
}

// gitopsBranchPattern lists the Git refs a deployment request may name:
// "main", or a release-candidate ref rc/<UTC yyyymmddThhmmssZ>-<first 7 hex
// characters of the commit>. No other branch name is accepted.
var gitopsBranchPattern = regexp.MustCompile(`^(main|rc/[0-9]{8}T[0-9]{6}Z-[0-9a-f]{7})$`)

// resolveGitopsBranch returns the Git ref the new Sovereign follows. An empty
// field gives the value of CATALYST_GITOPS_BRANCH, or "main" when that is
// unset, as before the field existed. A value that matches
// gitopsBranchPattern is returned as it is. Any other value is an error.
func resolveGitopsBranch(req Request) (string, error) {
	if req.GitopsBranch == "" {
		return env("CATALYST_GITOPS_BRANCH", "main"), nil
	}
	if !gitopsBranchPattern.MatchString(req.GitopsBranch) {
		return "", errors.New("invalid gitopsBranch")
	}
	return req.GitopsBranch, nil
}
```

// Tests for the request field gitopsBranch (FND-014). A deployment request
// may name the Git ref the new Sovereign follows: "main", or a candidate ref
// rc/<UTC yyyymmddThhmmssZ>-<first 7 hex characters of the commit>. Without
// the field a request behaves as before. Any other value is refused.

package provisioner

import (
	"encoding/json"
	"strings"
	"testing"
)

const gitopsBranchCandidate = "rc/20261120T060000Z-4be7a11"

// gitopsBranchRequest returns a request that is valid apart from the field.
func gitopsBranchRequest(value string) Request {
	req := validBase()
	req.Region = "fsn1"
	req.GitopsBranch = value
	return req
}

// gitopsBranchTfvars returns the tofu variable gitops_branch, the field's reader.
func gitopsBranchTfvars(t *testing.T, value string) any {
	t.Helper()
	dir := t.TempDir()
	if err := writeTfvars(dir, gitopsBranchRequest(value)); err != nil {
		t.Fatalf("writeTfvars with gitopsBranch=%q: %v", value, err)
	}
	return readTfvars(t, dir)["gitops_branch"]
}

// Case "empty": the ref is the value of CATALYST_GITOPS_BRANCH, or "main" when
// that is unset. The environment value is not matched against the pattern.
func TestGitopsBranchEmpty(t *testing.T) {
	for _, tc := range []struct{ env, want string }{{"", "main"}, {"mirror-branch", "mirror-branch"}} {
		t.Setenv("CATALYST_GITOPS_BRANCH", tc.env)
		if got, err := resolveGitopsBranch(Request{}); err != nil || got != tc.want {
			t.Fatalf("env %q: resolveGitopsBranch(empty) = %q, %v; want %q", tc.env, got, err, tc.want)
		}
		if got := gitopsBranchTfvars(t, ""); got != tc.want {
			t.Fatalf("env %q: gitops_branch = %v, want %q", tc.env, got, tc.want)
		}
	}
	req := gitopsBranchRequest("")
	if err := req.Validate(); err != nil {
		t.Fatalf("Validate() without gitopsBranch: %v", err)
	}
	if raw, err := json.Marshal(Request{}); err != nil || strings.Contains(string(raw), "gitopsBranch") {
		t.Fatalf("a request without the field must encode without the key gitopsBranch: %s, %v", raw, err)
	}
}

// gitopsBranchAccepted proves that value arrives under its JSON name, passes
// Validate(), wins over the environment and reaches gitops_branch unchanged.
func gitopsBranchAccepted(t *testing.T, value string) {
	t.Helper()
	t.Setenv("CATALYST_GITOPS_BRANCH", "mirror-branch")
	var decoded Request
	if err := json.Unmarshal([]byte(`{"gitopsBranch":"`+value+`"}`), &decoded); err != nil {
		t.Fatalf("decode request body: %v", err)
	}
	if got, err := resolveGitopsBranch(decoded); err != nil || got != value {
		t.Fatalf("resolveGitopsBranch(%q) = %q, %v; want %q", value, got, err, value)
	}
	req := gitopsBranchRequest(value)
	if err := req.Validate(); err != nil {
		t.Fatalf("Validate() with gitopsBranch=%q: %v", value, err)
	}
	if got := gitopsBranchTfvars(t, value); got != value {
		t.Fatalf("gitops_branch = %v, want %q", got, value)
	}
}

func TestGitopsBranchCandidateRef(t *testing.T) { gitopsBranchAccepted(t, gitopsBranchCandidate) }

	} {

			t.Errorf("resolveGitopsBranch(%q) = %q, %v; want the error %q", value, got, err, want)
		}
		req := gitopsBranchRequest(value)
		if err := req.Validate(); err == nil || err.Error() != want {
			t.Errorf("Validate() with gitopsBranch=%q: %v; want the error %q", value, err, want)
		}
		if err := writeTfvars(t.TempDir(), gitopsBranchRequest(value)); err == nil || err.Error() != want {
			t.Errorf("writeTfvars with gitopsBranch=%q: %v; want the error %q", value, err, want)
		}
	}
}
