# NET-011 — API port limited to declared sources

## In plain words

**The problem today.** Every new Sovereign on the reference cloud opens its Kubernetes API port to the whole internet. Only the API's own authentication stands between any address and the cluster. Nothing records which addresses really need the port.

**What changes.** The port admits only the ranges the sovereign-admin works from, the outbound addresses of the provisioning API and the Sovereign's own addresses. The provisioning API passes these ranges to the cloud module, and it refuses to create a Sovereign while its own outbound ranges are not configured.

**Done means:**

- No firewall rule of the reference cloud module opens the Kubernetes API port to every address; the module tests show one rule per declared source.
- A range that would open the port to every address, or that is not a valid IPv4 network, is refused by the cloud module and by the provisioning API.
- While the provisioning API has no outbound ranges configured, a create request is refused with HTTP 422 and a plain reason.
- A create request may name its own sovereign-admin ranges; without them the configured default ranges are used.
- The network registry of a Sovereign lists both access lists.
- The platform chart and its Kustomize twin pass both ranges to the provisioning API.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A Sovereign provisioned on the reference provider (`infra/providers/huawei`) opens TCP port 6443, the Kubernetes API, to four kinds of source and to nothing else: the ranges the sovereign-admin works from (OpenTofu variable `admin_cidrs`), the egress ranges of the provisioning catalyst-api (variable `provisioner_cidrs`), every region's node subnet and pod range, and the Sovereign's own public addresses. No rule of port 6443 has the source `0.0.0.0/0`. catalyst-api writes both variables into every deployment's `tofu.auto.tfvars.json`. It takes `provisioner_cidrs` from the env `CATALYST_EGRESS_CIDRS` and `admin_cidrs` from the new optional request field `adminCIDRs`, or from the env `CATALYST_DEFAULT_ADMIN_CIDRS` when the request has none. A `POST /api/v1/deployments` is answered with HTTP 422 and the text `CATALYST_EGRESS_CIDRS is not set: the provisioner could not reach the new cluster` while `CATALYST_EGRESS_CIDRS` is empty, so no Sovereign is created that its provisioner cannot reach. Both chart twins pass the two env vars. The output `network_registry` carries the two lists.

## 3. The model (the law)
1. The rule `huaweicloud_networking_secgroup_rule.ingress_6443` in `infra/providers/huawei/main.tf` has one rule per target region and per source. The sources are every value of `local.sovereign_public_sources` (key `<region>|cp|<region>` or `<region>|nat|<region>`), and every entry of the new local `api_access_cidrs` (key `<region>|<cidr>`). `api_access_cidrs` is `distinct(concat(var.admin_cidrs, var.provisioner_cidrs, local.mesh_ingress_cidrs))`, so a range named in more than one list gets one rule. Every key is known at plan time. No source is `0.0.0.0/0`. The rule is TCP 6443 only.
2. `variables.tf` declares `admin_cidrs` and `provisioner_cidrs`: type `list(string)`, default `[]`. Each has one validation: every entry is an IPv4 network in canonical CIDR form with a prefix longer than 0. The condition is `alltrue([for c in var.<name> : can(cidrnetmask(c)) && !endswith(c, "/0") && try(cidrsubnet(c, 0, 0) == c, false)])`. It accepts `[]` and refuses `0.0.0.0/0`, `::/0`, any IPv6 range, a bare address, a prefix above 32 and a range with host bits set.
3. In `local.network_registry`, `controlPlaneAccess.adminCIDRs` is `var.admin_cidrs` and `controlPlaneAccess.provisionerCIDRs` is `var.provisioner_cidrs`. The key names stay `adminCIDRs` and `provisionerCIDRs`: `scripts/check-network-registry.py` reads them. With the defaults both are `[]`, so the registry documents under `scripts/tests/check-network-registry/` do not change.
4. catalyst-api (`products/catalyst/bootstrap/api/internal/provisioner/control_plane_sources.go`, new):
   - `CATALYST_EGRESS_CIDRS` and `CATALYST_DEFAULT_ADMIN_CIDRS` are comma-separated lists. Blanks around an entry and empty entries are dropped.
   - `EgressCIDRs()` returns the egress list. `AdminCIDRs(req)` returns `req.AdminCIDRs` when it is not empty, else the default list. Both never return nil.
   - `CheckControlPlaneSources(req)` returns `ErrEgressCIDRsUnset` when the egress list is empty. It returns an error for each entry of either list that is not an IPv4 network in canonical CIDR form (`netip.ParsePrefix`, IPv4 only, masked, written canonically) or that has prefix length 0. The error names the list: `adminCIDRs`, `CATALYST_DEFAULT_ADMIN_CIDRS` or `CATALYST_EGRESS_CIDRS`.
   - `AdmitRequest(&req)` runs `req.Validate()` first. Its error is answered with 400, as before. Then it runs `CheckControlPlaneSources`, whose error is answered with 422.
5. The request type `provisioner.Request` gains `AdminCIDRs []string` with the JSON name `adminCIDRs`, `omitempty`. Its reader is `writeTfvars` in the same package.
6. `writeTfvars` writes `admin_cidrs` = `AdminCIDRs(req)` and `provisioner_cidrs` = `EgressCIDRs()` for every provider and never fails on them. `Destroy` calls `writeTfvars` too, so a wipe is never refused for a missing list. The second provider's module does not declare the two variables yet: OpenTofu only warns about an undeclared variable in a tfvars file.
7. `Provision` refuses to start when `CheckControlPlaneSources` fails, after `Validate()`. That covers the retry path, which calls `Provision` without the handler.
8. The handler package does not grow. In `CreateDeployment` the four lines that call `req.Validate()` and answer 400 are replaced by four lines that call `provisioner.AdmitRequest(&req)` and answer with the status it returns.
9. The platform chart has the top-level values `provisioner.egressCIDRs: []` and `provisioner.defaultAdminCIDRs: []`. `templates/api-deployment.yaml` sets `CATALYST_EGRESS_CIDRS` and `CATALYST_DEFAULT_ADMIN_CIDRS` to the lists joined with commas. `templates/api-deployment-kustomize.yaml` is applied as raw Kustomize, where no Helm value is rendered. It sets the same two names from ConfigMap `catalyst-provisioner`, keys `egress-cidrs` and `default-admin-cidrs`, both `optional: true`. Both twins set the same names, so the twin counts of `scripts/check-lifecycle-ratchets.sh` do not change.
10. The guard baseline line `G1<TAB>infra/providers/huawei/main.tf<TAB>1` is deleted from `scripts/network-guards-baseline.tsv`. After the change that file offends G1 no more, and the guard refuses a baseline line for a file without offence.
11. Thirteen existing handler tests post a valid create request and expect it to be accepted. Each gains the line `t.Setenv("CATALYST_EGRESS_CIDRS", "192.0.2.10/32")` as its first line.
12. Nothing else is deleted. No chart version, slot pin or image tag changes.
13. Names. The list of the ranges that the sovereign-admin works from is named with the word `admin` in every place: the OpenTofu variable `admin_cidrs`, the request field `adminCIDRs`, the Go names `AdminCIDRs` and `EnvDefaultAdminCIDRs`, the env `CATALYST_DEFAULT_ADMIN_CIDRS`, the ConfigMap key `default-admin-cidrs` and the chart value `provisioner.defaultAdminCIDRs`. This is the role name `sovereign-admin` of `docs/GLOSSARY.md` and the registry key `adminCIDRs` that exists already. No identifier, key, comment or message of this change names that person with another word.

// Who may reach the Kubernetes API port 6443 of a new Sovereign (NET-011).
//
// The OpenTofu module opens port 6443 to the Sovereign's own addresses and to
// two lists that this file computes:
//
//	provisioner_cidrs  the source ranges of this API's own outbound traffic,
//	                   from CATALYST_EGRESS_CIDRS. The provisioner dials the
//	                   new cluster's API during phase 1; without these ranges
//	                   it cannot reach the cluster.
//	admin_cidrs        the ranges the sovereign-admin works from: the request
//	                   field adminCIDRs, or CATALYST_DEFAULT_ADMIN_CIDRS
//	                   when the request carries none.
//
// Both environment values are comma-separated lists. Every entry is an IPv4
// network in canonical CIDR form, such as 198.51.100.0/28; a prefix of length
// 0 is refused. A create request is refused with HTTP 422 when
// CATALYST_EGRESS_CIDRS is empty, or when an entry of either list is not such
// a network. The module's variables refuse the same values at `tofu plan`.

package provisioner

import (
	"errors"
	"fmt"
	"net/http"
	"net/netip"
	"os"
	"strings"
)

// The environment variables of the two lists.
const (
	EnvEgressCIDRs       = "CATALYST_EGRESS_CIDRS"
	EnvDefaultAdminCIDRs = "CATALYST_DEFAULT_ADMIN_CIDRS"
)

// ErrEgressCIDRsUnset is the refusal of a create request while
// CATALYST_EGRESS_CIDRS holds no entry.
var ErrEgressCIDRsUnset = errors.New("CATALYST_EGRESS_CIDRS is not set: the provisioner could not reach the new cluster")

// cidrList splits a comma-separated value into its trimmed, non-empty
// entries. It never returns nil, so the tfvars file holds [] and not null.
func cidrList(raw string) []string {
	out := []string{}
	for _, part := range strings.Split(raw, ",") {
		if entry := strings.TrimSpace(part); entry != "" {
			out = append(out, entry)
		}
	}
	return out
}

// EgressCIDRs returns the entries of CATALYST_EGRESS_CIDRS; never nil.
func EgressCIDRs() []string {
	return cidrList(os.Getenv(EnvEgressCIDRs))
}

// AdminCIDRs returns the request's adminCIDRs, or the entries of
// CATALYST_DEFAULT_ADMIN_CIDRS when the request has none; never nil.
func AdminCIDRs(req Request) []string {
	if len(req.AdminCIDRs) > 0 {
		return append([]string{}, req.AdminCIDRs...)
	}
	return cidrList(os.Getenv(EnvDefaultAdminCIDRs))
}

// checkSourceCIDR returns an error unless entry is an IPv4 network in
// canonical CIDR form with a prefix longer than 0. list names where the
// entry came from.
func checkSourceCIDR(list, entry string) error {
	prefix, err := netip.ParsePrefix(entry)
	if err != nil || !prefix.Addr().Is4() || prefix.Masked() != prefix || prefix.String() != entry {
		return fmt.Errorf("%s entry %q is not an IPv4 network in CIDR form, such as 198.51.100.0/28", list, entry)
	}
	if prefix.Bits() == 0 {
		return fmt.Errorf("%s entry %q is refused: the API port is never open to every address", list, entry)
	}
	return nil
}

// CheckControlPlaneSources returns the reason a create request must be
// refused with HTTP 422, or nil.
func CheckControlPlaneSources(req Request) error {
	egress := EgressCIDRs()
	if len(egress) == 0 {
		return ErrEgressCIDRsUnset
	}
	for _, entry := range egress {
		if err := checkSourceCIDR(EnvEgressCIDRs, entry); err != nil {
			return err
		}
	}
	list := "adminCIDRs"
	if len(req.AdminCIDRs) == 0 {
		list = EnvDefaultAdminCIDRs
	}
	for _, entry := range AdminCIDRs(req) {
		if err := checkSourceCIDR(list, entry); err != nil {
			return err
		}
	}
	return nil
}

// AdmitRequest judges a create request. An error of Validate() is answered
// with HTTP 400, as before; an error of CheckControlPlaneSources with HTTP
// 422. Without an error the status is 200 and means nothing.
func AdmitRequest(req *Request) (int, error) {
	if err := req.Validate(); err != nil {
		return http.StatusBadRequest, err
	}
	if err := CheckControlPlaneSources(*req); err != nil {
		return http.StatusUnprocessableEntity, err
	}
	return http.StatusOK, nil
}
