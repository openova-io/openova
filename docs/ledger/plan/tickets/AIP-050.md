# AIP-050 — Agent-plane guards

## In plain words

**The problem today.** The model plane is being moved behind one model gateway, with metered calls and short-lived agent tokens. What it replaces is still spread over many files: the model vendor's hosts named directly, a subscription credential copied between components, identity headers that the caller sets itself, base URLs that skip the gateway, and a tool bearer that lives for a year. Nothing stops a change from adding one more of them, and nothing yet checks the agent definitions that will come later.

**What changes.** One guard checks the whole repository on every pull request. It counts each of these patterns and compares the count with a stored number and a list of the files allowed to hold it. A count may only fall, the stored numbers may only fall, and agent definitions are checked by fixed rules from the first one on.

**Done means:**

- A pull request that adds the model vendor's host, the subscription credential key, a caller-set identity header, a base URL that bypasses the gateway, or the tool bearer to a file outside the stored list turns red.
- A pull request that adds one more such line or file than the stored number allows turns red, and so does one that raises a stored number.
- An agent definition that stores a model key, binds a forbidden tool, or has fewer than 20 valid evaluation cases turns the pull request red.
- The stored numbers equal what the repository holds today: 13, 23, 3, 6, 5, 18 and 2.
- The guard proves on trees of its own that each of its rules can fail.
- No existing file changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every pull request gets a check named `agent-plane-guards`. It runs the guard `scripts/check-agent-plane.py` over the whole repository. The guard counts seven things that the model plane is leaving behind (rules G1 to G6 and G7d) and compares each count with a stored maximum and a stored list of allowed files in `scripts/agent-plane-baseline.yaml`. It also checks agent definitions by three fixed rules (G7a to G7c), which bind as soon as the first agent definition is added. A stored maximum may only fall: the check compares the baseline with the one on the base branch. A person can see the result on any pull request: the check prints `G1=13`, `G2=23`, `G3=3`, `G4=6`, `G5=5`, `G6=18`, `G7a=0`, `G7b=0`, `G7c=0`, `G7d=2` and `check-agent-plane: OK`.

## 3. The model (the law)
1. The guard is the script `scripts/check-agent-plane.py`. It needs Python 3, PyYAML and git. It reads the files that Git tracks and the new files that Git does not ignore, each only when it exists in the checkout (`git ls-files --cached --others --exclude-standard`). A path is relative to the repository root. "Outside docs" means that the path does not start with `docs/`.
2. The counted rules. Each counts the files or the lines that match a pattern:
   - `G1`: files outside docs, not ending in `_test.go`, with a line that names `api.anthropic.com` or `console.anthropic.com`. Counts files.
   - `G2`: files outside docs with a line that holds `claudeAiOauth`, the key of the subscription credential document. Counts files. Test files count.
   - `G3`: every file, docs included, with a line that holds the first eight characters of the client identifier of the vendor's token endpoint (the constant `CLIENT_ID` of the script). Counts lines.
   - `G4`: files outside docs, not ending in `_test.go`, with a line that holds `x-customer-id` or `x-tenant-id` in any letter case. Counts lines.
   - `G5`: files outside docs, not ending in `_test.go` or `.md`, with a line that holds `OPENAI_BASE_URL`, `OPENAI_API_BASE` or `ANTHROPIC_BASE_URL` and does not hold `model-gateway.model-gateway.svc`. A line that holds the gateway address points at the platform's model gateway and does not count. Counts files.
   - `G6`: files outside docs with a line that holds `mcpBearerTTL` or `OPENOVA_MCP_BEARER`. Counts files.
   - `G7d`: files under `products/axon/src/` with a line that holds `claude-agent-sdk`. Counts files.
3. For each counted rule: a count above the stored `max` fails. A file with a match that is not in the stored `allow` list fails, also when the count did not rise. A count below `max` passes and prints a line `NOTE <rule>: ...` that says to lower it.
4. The hard rules read every file ending in `.yaml` or `.yml` under `platform/kagent/` or under a folder `products/agents-<name>/`. Each finding fails.
   - `G7a`: a line that sets the key `apiKeySecret`.
   - `G7b`: a line that is not a comment line and names a tool of the baseline's `forbiddenTools` list as a whole word. Letters, digits, `_` and `-` next to the name do not end a word.
   - `G7c`: under `products/agents-<name>/` only. A YAML document (documents are split at lines that start with `---`) that has the top-level line `kind: Agent` must give its name literally, either as `metadata: { name: <name> ... }` or as a block `metadata:` whose first indentation level holds `name: <name>`. The folder `products/agents-<name>/evals/<agent name>/` must hold at least 20 valid case files named `NNN-<slug>.json` (three digits, a dash, then lower-case letters, digits and dashes). A case file is valid when it is a JSON object with exactly the keys `schema` (the value `openova.io/agent-eval/v1`), `agent` (the agent's name), `input` (an object), `accept` (a non-empty list of objects), `reject` (a list of objects) and `notes` (a non-empty string). Each invalid case file is a finding too.
5. No file of the repository is an agent definition today: `platform/kagent/` and `products/agents-*/` do not exist. G7a to G7c pass on the repository and are proven by the self-test and by acceptance A8.
6. The baseline `scripts/agent-plane-baseline.yaml` has exactly the keys `schema` (`openova.io/agent-plane-baseline/v1`), `forbiddenTools` (a non-empty list of distinct tool names; today `create_application`) and `rules`. `rules` has exactly the keys `G1` to `G6` and `G7d`, each with exactly `max` (a whole number of 0 or more) and `allow` (a sorted list of distinct paths). A baseline that is missing or breaks this form is never a pass: the guard judges nothing and exits with code 2.
7. A stored number may only fall. With `--base <commit>`, a `max` above the one in the baseline at that commit fails, and so does a forbidden tool that the baseline at that commit lists and this one does not. When the baseline does not exist at that commit, this part passes.
8. `--write-baseline` judges first. When a rule fails it writes nothing and exits with code 1. Otherwise it writes every `max` as the measured count and every `allow` as the files that match, keeps `forbiddenTools`, and writes the same text form as the block of field 5. Later packages lower the baseline with it. This ticket does not run it: the baseline is a block of this ticket.
9. Exit codes: 0, every rule holds; 1, a rule is broken; 2, nothing was judged (the baseline is missing or malformed, Git cannot list the files, no file was found) or wrong usage.
10. The script does not match its own patterns: each pattern is written in two pieces. Adding the script and the baseline changes no count.
11. `--self-test` builds small Git trees of its own, 53 times, and shows for each rule that it fails and for each exception that it passes. It reads nothing of the repository.
12. The workflow `.github/workflows/agent-plane-guards.yaml` has the triggers `pull_request` and `merge_group` and no path filter. Its one job, `agent-plane-guards`, checks out two commits, installs PyYAML, runs the self-test, then runs the guard with `--base HEAD^1`. On a pull request the checkout is the merge commit, and its first parent is the base branch.
13. The script, the workflow and the baseline are the three blocks of field 5, byte for byte. This ticket changes no existing file and deletes nothing.

def list_files(root):
    r = subprocess.run(["git", "-C", root, "ls-files", "-z", "--cached", "--others", "--exclude-standard"],

def parse_baseline(text, where):

    except yaml.YAMLError as e:

           "schema: " + SCHEMA, "forbiddenTools:"] + ["- " + q(t) for t in ft] + ["rules:"]
    for k in KEYS:
        a = rules[k]["allow"]
        out += ["  %s:" % k, "    max: %d" % rules[k]["max"]]
        out += (["    allow:"] + ["    - " + q(p) for p in a]) if a else ["    allow: []"]
    return "\n".join(out) + "\n"


def agent_names(text):
    """The metadata.name (or None) of every document of a YAML text that is an Agent."""
    docs = re.split(r"(?m)^---.*$", text)
    names = []
    for doc in docs:
        lines = doc.split("\n")
        if not any(KIND_AGENT.match(l) for l in lines):
            continue
        name = None
        for i, l in enumerate(lines):
            m = FLOW_NAME.match(l)
            if m:
                name = m.group(1)
            elif re.match(r"^metadata:\s*(?:#.*)?$", l):
                block = [b for b in lines[i + 1:] if b.strip() and not b.lstrip().startswith("#")]
                block = block[:next((j for j, b in enumerate(block) if not b[0].isspace()), len(block))]
                ind = len(block[0]) - len(block[0].lstrip()) if block else 0
                found = [BLOCK_NAME.match(b) for b in block]
                name = next((m.group(2) for m in found if m and len(m.group(1)) == ind), None)
            else:
                continue
            break
        names.append(name)
    return names


def case_error(path, name):
    try:
        with open(path, "rb") as f:
            c = json.loads(f.read().decode("utf-8"))
    except (OSError, ValueError) as e:
        return "is not JSON (%s)" % e
    if not isinstance(c, dict) or sorted(c) != ["accept", "agent", "input", "notes", "reject", "schema"]:
        return "must have exactly the keys schema, agent, input, accept, reject, notes"
    if c["schema"] != EVAL_SCHEMA or c["agent"] != name:
        return "must have schema %s and agent %s" % (EVAL_SCHEMA, name)
    objs = lambda v: isinstance(v, list) and all(isinstance(x, dict) for x in v)
    if not isinstance(c["input"], dict) or not objs(c["accept"]) or not c["accept"] or not objs(c["reject"]):
        return "needs an object input, a non-empty list of objects accept and a list of objects reject"
    if not isinstance(c["notes"], str) or not c["notes"].strip():
        return "needs a non-empty notes"
    return None


def judge(root, base=None, write=False):
    """Returns (exit code, output lines)."""
    path = os.path.join(root, BASELINE)
    old = None
    try:
        files = list_files(root)
        if os.path.isfile(path):
            with open(path, encoding="utf-8") as f:
                ft, rules = parse_baseline(f.read(), BASELINE)
        elif write:
            ft, rules = list(DEFAULT_FORBIDDEN), None
        else:
            raise CannotJudge(BASELINE + " is missing")
        if base:
            if subprocess.run(["git", "-C", root, "cat-file", "-e", base + "^{commit}"], stderr=subprocess.DEVNULL).returncode:
                raise CannotJudge("the commit %s is unknown" % base)
            r = subprocess.run(["git", "-C", root, "show", "%s:%s" % (base, BASELINE)], stdout=subprocess.PIPE, stderr=subprocess.DEVNULL)
            if r.returncode == 0:
                old = parse_baseline(r.stdout.decode("utf-8"), "%s at %s" % (BASELINE, base))
    except CannotJudge as e:
        return 2, ["%s: cannot judge: %s" % (ME, e)]
    hits = {k: {} for k in KEYS}
    g7 = {"G7a": [], "G7b": [], "G7c": []}
    tool = re.compile(rb"(?<![A-Za-z0-9_-])(?:" + b"|".join(re.escape(t.encode()) for t in ft) + rb")(?![A-Za-z0-9_-])")
    for p in files:
        with open(os.path.join(root, p), "rb") as f:
            data = f.read()
        for key, unit, pat, scope in RULES:
            if scope(p) and pat.search(data):
                n = sum(1 for l in data.split(b"\n") if pat.search(l) and not (key == "G5" and GATEWAY in l))
                if n:
                    hits[key][p] = n
        if not (AGENT_TREE.match(p) and p.endswith((".yaml", ".yml"))):
            continue
        for i, l in enumerate(data.split(b"\n"), 1):
            if API_KEY.match(l):
                g7["G7a"].append("FAIL G7a: %s:%d sets apiKeySecret" % (p, i))
            if not l.lstrip().startswith(b"#") and tool.search(l):
                g7["G7b"].append("FAIL G7b: %s:%d names a forbidden tool" % (p, i))
        prod = PRODUCT.match(p)
        for name in agent_names(data.decode("utf-8", "replace")) if prod else []:
            if name is None:
                g7["G7c"].append("FAIL G7c: %s has an Agent without a literal metadata.name" % p)
                continue
            folder = "%s/evals/%s/" % (prod.group(1), name)
            good = 0
            for c in [c for c in files if c.startswith(folder) and CASE.match(c[len(folder):])]:
                err = case_error(os.path.join(root, c), name)
                g7["G7c"] += ["FAIL G7c: %s %s" % (c, err)] if err else []
                good += 0 if err else 1
            if good < 20:
                g7["G7c"].append("FAIL G7c: Agent %s in %s has %d valid case files under %s, needs 20" % (name, p, good, folder))
    counts = {k: sum(hits[k].values()) if UNIT[k] == "lines" else len(hits[k]) for k in KEYS}
    out = []
    for k in KEYS if rules else []:
        if counts[k] > rules[k]["max"]:
            out.append("FAIL %s: %d %s, the baseline allows %d" % (k, counts[k], UNIT[k], rules[k]["max"]))
        elif counts[k] < rules[k]["max"]:
            out.append("NOTE %s: %d %s, below the stored %d; lower it with --write-baseline" % (k, counts[k], UNIT[k], rules[k]["max"]))
        out += ["FAIL %s: %s has a hit and is not on the allow-list" % (k, p) for p in sorted(hits[k]) if p not in rules[k]["allow"]]
    out += g7["G7a"] + g7["G7b"] + g7["G7c"]
    if old is not None:
        out += ["FAIL %s: max %d is above the %d stored at %s" % (k, rules[k]["max"], old[1][k]["max"], base)
                for k in KEYS if rules[k]["max"] > old[1][k]["max"]]
        out += ["FAIL forbiddenTools: %s was listed at %s and is gone" % (t, base) for t in old[0] if t not in ft]
    fails = sum(1 for l in out if l.startswith("FAIL "))
    out += ["%s=%d" % (k, counts[k]) for k in KEYS[:6]] + ["%s=%d" % (k, len(g7[k])) for k in sorted(g7)]
    out.append("G7d=%d" % counts["G7d"])
    if fails:
        out.append("%s: FAIL, %d finding(s)%s" % (ME, fails, "; the baseline was not written" if write else ""))
        return 1, out
    if write:
        os.makedirs(os.path.dirname(path), exist_ok=True)
        with open(path, "w", encoding="utf-8") as f:
            f.write(dump_baseline(ft, {k: {"max": counts[k], "allow": sorted(hits[k])} for k in KEYS}))
        return 0, out + ["%s: wrote %s" % (ME, BASELINE)]
    return 0, out + ["%s: OK" % ME]


def build(t, files, baseline):
    subprocess.run(["git", "init", "-q", t], check=True)
    for p, text in dict(files, **({BASELINE: baseline} if baseline else {})).items():
        os.makedirs(os.path.dirname(os.path.join(t, p)), exist_ok=True)
        with open(os.path.join(t, p), "w") as f:
            f.write(text)
