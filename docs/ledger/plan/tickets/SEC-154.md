# SEC-154 — Flux renders bootstrap Secrets from one seed: pull login, object storage, cloud credentials

## In plain words

**The problem today.** Every control-plane node still carries three bootstrap Secrets in its start-up data as whole manifests: the registry pull login, the object storage login and the cloud account credentials. Only their values need to be there before Flux runs; the rest costs bytes against the start-up data limit of the cloud. The guard that lets a Secret template into Git checks the form of a template but not where its values come from, so a template whose value sits in a committed file would pass.

**What changes.** First boot writes only the values of these three Secrets, into the one seed Secret it already creates, and Flux renders the three Secrets from files in Git, the cloud credentials from the file of the cloud the Sovereign runs on. A Sovereign installed earlier adds the missing values to its seed from its own Secrets before anything renders from it. The guard now also refuses a template whose names can come from a committed file.

**Done means:**

- A fresh control-plane node's start-up data holds no Secret manifest, only the seed file with the values of the seven bootstrap Secrets, on both clouds and in both region roles.
- The pull login, the object storage login and the cloud credentials that Flux renders from the seed have the same names, namespaces, types, keys, values and reflector annotations as the ones first boot wrote before, the cloud credentials with the keys of the cloud's own module.
- On a Sovereign installed before the change, whose seed lacks these values, the seed gets them from its live Secrets before anything renders from it, no value the seed already holds changes, and a second run changes nothing; when one of these Secrets, a key or a value is missing, nothing is written and the kit waits.
- Guard G1 refuses a Secret template whose name is also an inline substitute or a key of a committed ConfigMap source, or whose folder no Kustomization renders from a Secret, and passes every template on the tree.
- Every control-plane start-up data surface of the reference cloud is 972 bytes smaller, and every surface of every cloud stays within its limit with nothing packed to make room.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The control-plane start-up data of every pack carries no Secret manifest. The values of `ghcr-pull`, `object-storage` and `cloud-credentials` (namespace `flux-system`) join the five values of SEC-153 in `/var/lib/catalyst/bootstrap-seed.env`, from which first boot creates the seed Secret `flux-system/bootstrap-seed`. `ghcr-pull` and `object-storage` are templates under `clusters/_template/bootstrap-secrets`; `cloud-credentials`, whose keys are the pack's own, is a template in each pack's overlay `clusters/_template/providers/<pack>/bootstrap-secrets`, which builds the shared folder and adds it. The Flux Kustomization `bootstrap-secrets` renders the overlay of the Sovereign's pack (its path names it through `PROVIDER` of the ConfigMap `sovereign-variables`). A Sovereign installed between SEC-153 and this change holds the three Secrets and a seed without their values: the Job `bootstrap-seed-build`, which runs again because its template changes, adds them from the live Secrets before `bootstrap-secrets` may render. Guard G1 (`tools/guards/cmd/secret-templates`) passes a template only when every name it references comes only from a Secret source of the Kustomization that renders it.

## 3. The model (the law)
1. Start-up data carries values, not manifests. Each byte added to the template must be there before Flux and OpenBao exist: the kit's first pull uses `ghcr-pull` (every kit HelmRelease, kit key `REGISTRY_PULL_SECRET`), the network and storage drivers of slots 01, 50, 55, 55a and 55b and Crossplane's OpenTofu provider read `cloud-credentials`, the registry and backup charts (slots 19, 34) read `object-storage`; no secret store exists before Flux. Names, namespaces, types, keys and reflector annotations are files in Git.
2. The seed file gains, after the five lines of SEC-153: `GHCR_PULL_DOCKERCONFIGJSON` (the whole `.dockerconfigjson`, one value under one name, base64-encoded; the same bytes first boot wrote before), `OBJECT_STORAGE_ENDPOINT`, `OBJECT_STORAGE_REGION`, `OBJECT_STORAGE_BUCKET`, `OBJECT_STORAGE_ACCESS_KEY`, `OBJECT_STORAGE_SECRET_KEY` (base64-encoded; each fills two keys of `object-storage`), and one `CLOUD_CREDENTIALS_<KEY>` per key of the pack's `cloud_credentials_secret_yaml` body (its `stringData`, or its `data` decoded): the key in capitals with every other character an underscore, the value raw, an empty placeholder as an empty value. The template names no provider: it reads the body the module passes, and the contract input stays as it is.
3. Why the cloud credentials are raw: a worker's whole first-boot text is a value of the second provider's body (6,585 to 7,232 bytes, already base64 text); encoded again it put the second provider's secondary-region render at 32,357 bytes, over its guard of 32,256 (measured). Raw, a value may hold only letters, digits and `+ / = . _ : -`; `regex()` in the template stops the render of any other value (a quote, a `$`, a space or a line end could change the YAML Flux substitutes it into). The pack's manifest reads them under `stringData`. CLD-190 decides on the second provider.
4. `cloud-credentials` lives in the pack's overlay, not in the shared folder: its keys name the cloud, and `scripts/check-provider-leaks.py` lets a provider name rise in no shared file; `clusters/_template/providers/<pack>/` is a pack root (`scripts/check-provider-pack-additive.sh`), so a new cloud adds its overlay with its own files. Each overlay's `kustomization.yaml` lists `../../../bootstrap-secrets` and, for a pack with a cloud account, `cloud-credentials.yaml`; the local pack has no cloud account, its body has no key, and every reader of that Secret on it reads it as optional.
5. The Kustomization `bootstrap-secrets` (`clusters/_template/root/base-primary/bootstrap-secrets.yaml`) changes only its path, to `./clusters/_template/providers/${PROVIDER}/bootstrap-secrets`; the root Kustomization substitutes `PROVIDER` from `sovereign-variables`, which has held it since #3145. Order, substituteFrom (the Secret `bootstrap-seed`, never optional) and wait stay as SEC-153 made them.
6. The upgrade path. `build-seed.sh` reads which keys the seed holds (none when it does not exist) and, for each value the seed lacks, reads the live Secret that holds it: the entries of `SEED_ENTRIES` (now in the Job's environment, eleven lines: the five of SEC-153, `ghcr-pull` and the five of `object-storage`) by the rule of SEC-153 (a Secret that cannot be read, a missing key, an empty value or a value that is not base64 text stops it), and every key of `cloud-credentials` (decoded; an empty value carried as it is; a character outside the raw set or a line end stops it). Then it creates the seed (no seed yet) or adds the lacking keys with one merge patch of `stringData` read from a file in memory (`--field-manager=catalyst-bootstrap-seed`). It never changes or removes a key the seed holds, so a value first boot wrote stays; when anything is missing it writes nothing and exits 1, the Job fails, `bootstrap-secrets` and the kit wait, and no live Secret is rendered from a seed that lacks its value. Its rights gain `get` on the three Secrets and `patch` on the seed by name.
7. The Job runs again on an installed Sovereign because `SEED_ENTRIES` is part of its immutable template: a change of it makes Flux (`force: true` on `bootstrap-seed`) replace the Job, and `bootstrap-secrets` waits for `bootstrap-seed` at the same revision (dependsOn, wait). A Secret that joins the seed joins that list.
8. Guard G1, the source of a template's names. Every name a Secret template under `clusters/` references under `data` or `stringData` must come only from a `postBuild.substituteFrom` entry of kind `Secret` of each Flux Kustomization under `clusters/` that renders the template's folder, directly or through an overlay that builds it (a `${VAR}` in a path stands for any one folder; a folder without a `kustomization.yaml` renders every folder below it, as Flux generates one). A finding: the name is also a key of that Kustomization's inline `postBuild.substitute`; the name is a key of a ConfigMap that its `substituteFrom` names and that is a manifest tracked in the repository (a file, a chart template or the first-boot template; not under `docs/`); the Kustomization names no `substituteFrom` entry of kind `Secret` or its `postBuild` cannot be read; no Kustomization renders the folder. A file with a finding is not a template, so G1 counts its `kind: Secret` line. The rule is in Go (`tools/guards/cmd/secret-templates/sources.go`, standard library only, with a reader of block YAML); its tests are `TestTemplateNameFromInlineSubstituteIsAFinding`, `TestTemplateNameFromTrackedConfigMapIsAFinding`, `TestTemplateNameWithoutASecretSourceIsAFinding` and `TestTemplateNameFromTheSecretSourcePasses`. A name in a label or an annotation is not judged, as metadata is not.
9. Guard G6 (`scripts/check-reflector-scope.sh`) counts the per-Org pattern of the `ghcr-pull` reflector lists (#4246, #4423) once. The finding moves with the manifest: its allow-list line `infra/providers/_shared/cloudinit-control-plane.tftpl:1` becomes `clusters/_template/bootstrap-secrets/ghcr-pull.yaml:1`; the list keeps its 19 lines and no scope is added. The render test asserts `ghcr-pull`'s annotations through test (c), so no copy of the pattern is added.
10. Deleted: the `write_files` entries `ghcr-pull-secret.yaml`, `object-storage-secret.yaml` and `cloud-credentials-secret.yaml` and their `-f` and shred arguments. No new Python, no new image, no NodePort, no packed entry, no raised limit.

+// kustomization.yaml renders every folder below it, as Flux generates one.
+// A path that only a kustomize patch sets is not read: a folder rendered only
+// through such a patch has no Kustomization and is a finding.
+//
+// Which ConfigMap is tracked: a document of kind ConfigMap, named in its
+// metadata as the substituteFrom entry names it, in a YAML or template file
+// that Git lists outside docs/, whether it stands alone, in a chart template
+// or inside the first-boot template. A key is any line `KEY:` of that

+// fluxKustomization is what the rule reads of a Flux Kustomization.
+type fluxKustomization struct {
+	file, name, path string
+	substitute       map[string]bool // the keys of postBuild.substitute
+	secrets          []string        // substituteFrom entries of kind Secret
+	configMaps       []string        // substituteFrom entries of kind ConfigMap
+	unreadable       string          // why postBuild cannot be read
+}
+
+func (k fluxKustomization) id() string { return fmt.Sprintf("%s (%s)", k.name, k.file) }
+
+var (
+	pathVariable   = regexp.MustCompile(`\$\{[^}]*\}`)
+	configMapKind  = regexp.MustCompile(`^(\s*)kind:\s*["']?ConfigMap["']?\s*(#.*)?$`)
+	keyLine        = regexp.MustCompile(`^\s*["']?([-._A-Za-z0-9]+)["']?\s*:(\s|$)`)
+	trackedSuffix  = []string{".yaml", ".yml", ".tpl", ".tftpl"}
+	kustomizations = []string{"kustomization.yaml", "kustomization.yml", "Kustomization"}

+// fluxKustomizations reads the Flux Kustomizations of one file.
+func fluxKustomizations(file, text string) []fluxKustomization {
+	var out []fluxKustomization
+	for _, doc := range documents(text) {
+		root, err := parseYAML(doc)
+		if err != nil || !root.isMap {
+			continue
+		}
+		if root.get("kind").scalar != "Kustomization" || !strings.HasPrefix(root.get("apiVersion").scalar, "kustomize.toolkit.fluxcd.io/") {
+			continue
+		}
+		k := fluxKustomization{file: file, name: root.get("metadata").get("name").scalar, substitute: map[string]bool{}}
+		spec := root.get("spec")
+		k.path = spec.get("path").scalar
+		post := spec.get("postBuild")
+		switch {
+		case post.isNull():
+		case !post.isMap:
+			k.unreadable = "postBuild is not a block mapping"
+		default:
+			sub, from := post.get("substitute"), post.get("substituteFrom")
+			switch {
+			case sub.isMap:
+				for _, key := range sub.keys {
+					k.substitute[key] = true
+				}
+			case !sub.isNull():
+				k.unreadable = "postBuild.substitute is not a block mapping"
+			}
+			switch {
+			case from.isSeq:
+				for _, e := range from.seq {
+					if !e.isMap {
+						k.unreadable = "an entry of postBuild.substituteFrom is not a block mapping"
+						continue
+					}
+					switch kind, name := e.get("kind").scalar, e.get("name").scalar; kind {
+					case "Secret":
+						k.secrets = append(k.secrets, name)
+					case "ConfigMap":
+						k.configMaps = append(k.configMaps, name)
+					default:
+						k.unreadable = fmt.Sprintf("an entry of postBuild.substituteFrom has the kind %q", kind)
+					}
+				}
+			case !from.isNull():
+				k.unreadable = "postBuild.substituteFrom is not a block sequence"
+			}
+		}
+		out = append(out, k)
+	}
+	return out
+}

+// renderedFolders are the folders a Flux Kustomization renders.
+func renderedFolders(tree fs.FS, k fluxKustomization) map[string]bool {
+	out := map[string]bool{}
+	p := strings.TrimPrefix(path.Clean(strings.TrimPrefix(k.path, "./")), "/")
+	if k.path == "" || p == "." || strings.HasPrefix(p, "..") {
+		return out
+	}
+	matches := []string{p}
+	if pathVariable.MatchString(p) {
+		var err error
+		if matches, err = fs.Glob(tree, pathVariable.ReplaceAllString(p, "*")); err != nil {
+			return out
+		}
+	}
+	for _, m := range matches {
+		if info, err := fs.Stat(tree, m); err == nil && info.IsDir() {
+			build(tree, m, out)
+		}
+	}
+	return out
+}

+// build adds dir and every folder it builds to out.
+func build(tree fs.FS, dir string, out map[string]bool) {
+	if out[dir] {
+		return
+	}
+	out[dir] = true
+	for _, name := range kustomizations {
+		b, err := fs.ReadFile(tree, path.Join(dir, name))
+		if errors.Is(err, fs.ErrNotExist) {
+			continue
+		}
+		if err != nil {
+			return
+		}
+		root, err := parseYAML(strings.Split(string(b), "\n"))
+		if err != nil {
+			return
+		}
+		for _, field := range []string{"resources", "components"} {
+			for _, e := range root.get(field).seq {
+				target := path.Clean(path.Join(dir, e.scalar))
+				if e.scalar == "" || strings.Contains(e.scalar, "://") || strings.HasPrefix(target, "..") {
+					continue
+				}
+				if info, err := fs.Stat(tree, target); err == nil && info.IsDir() {
+					build(tree, target, out)
+				}
+			}
+		}
+		return
+	}
+	// No kustomization.yaml: Flux generates one with every folder below.
+	entries, err := fs.ReadDir(tree, dir)
+	if err != nil {
+		return
+	}
+	for _, e := range entries {
+		if e.IsDir() {
+			build(tree, path.Join(dir, e.Name()), out)
+		}
+	}
+}

+// configMapKeys returns, per ConfigMap name of names, the keys of its tracked
+// documents and the files they are in.
+func configMapKeys(tree fs.FS, files []string, names map[string]bool) map[string]map[string]string {
+	out := map[string]map[string]string{}
+	if len(names) == 0 {
+		return out
+	}
+	for _, f := range files {
+		if strings.HasPrefix(f, "docs/") || !hasSuffix(f, trackedSuffix) {
+			continue
+		}
+		b, err := fs.ReadFile(tree, f)
+		if err != nil || !strings.Contains(string(b), "ConfigMap") {
+			continue
+		}
+		lines := strings.Split(string(b), "\n")
+		for i, l := range lines {
+			m := configMapKind.FindStringSubmatch(l)
+			if m == nil {
+				continue
+			}
+			base := len(m[1])
+			start, end := documentBounds(lines, i, base)
+			name := ""
+			for _, d := range lines[start:end] {
+				if v, ok := deeperField(d, base, "name"); ok && name == "" {
+					name = v
+				}
+			}
+			if !names[name] {
+				continue
+			}
+			if out[name] == nil {
+				out[name] = map[string]string{}
+			}
+			for _, d := range lines[start:end] {
+				if km := keyLine.FindStringSubmatch(d); km != nil && indentOf(d) > base {
+					if _, seen := out[name][km[1]]; !seen {
+						out[name][km[1]] = f
+					}
+				}
+			}
+		}
+	}
+	return out
+}

+// documentBounds is the document around line i whose fields stand at indent
+// base: it ends at a separator or at a line indented less than base; a blank
+// line, a comment and a template directive (%{ or {{ at its start) do not end it.
+func documentBounds(lines []string, i, base int) (int, int) {
+	inside := func(l string) bool {
+		t := strings.TrimSpace(l)
+		if t == "---" || strings.HasPrefix(t, "--- ") || t == "..." {
+			return false
+		}
+		return t == "" || strings.HasPrefix(t, "#") || strings.HasPrefix(t, "%{") || strings.HasPrefix(t, "{{") || indentOf(l) >= base
+	}
+	start, end := i, i+1
+	for start > 0 && inside(lines[start-1]) {
+		start--
+	}
+	for end < len(lines) && inside(lines[end]) {
+		end++
+	}
+	return start, end
+}
+
+// deeperField returns the value of a line `field: value` indented more than base.
+func deeperField(l string, base int, field string) (string, bool) {
+	if indentOf(l) <= base {
+		return "", false
+	}
+	t := strings.TrimSpace(l)
+	if !strings.HasPrefix(t, field+":") {
+		return "", false
+	}
+	return unquote(strings.TrimSpace(stripComment(strings.TrimPrefix(t, field+":")))), true
+}
+
+func indentOf(l string) int { return len(l) - len(strings.TrimLeft(l, " ")) }
+
+func hasSuffix(s string, suffixes []string) bool {
+	for _, x := range suffixes {
+		if strings.HasSuffix(s, x) {
+			return true
+		}
+	}
+	return false
+}

+// sourceFindings judges the source of the names of every template: for each
+// template file that has a finding, the first reason.
+func sourceFindings(tree fs.FS, repoFiles []string, templates map[string][]string, ks []fluxKustomization) map[string]string {
+	renders := map[string][]fluxKustomization{} // folder -> the Kustomizations that render it
+	for _, k := range ks {
+		for dir := range renderedFolders(tree, k) {
+			renders[dir] = append(renders[dir], k)
+		}
+	}
+	wanted := map[string]bool{}
+	for _, k := range ks {
+		for _, c := range k.configMaps {
+			wanted[c] = true
+		}
+	}
+	keys := configMapKeys(tree, repoFiles, wanted)
+	out := map[string]string{}
+	paths := make([]string, 0, len(templates))
+	for p := range templates {
+		paths = append(paths, p)
+	}
+	sort.Strings(paths)
+	for _, p := range paths {
+		dir := path.Dir(p)
+		by := renders[dir]
+		if len(by) == 0 {
+			out[p] = fmt.Sprintf("no Flux Kustomization under clusters/ renders its folder %s, so nothing says where its names come from", dir)
+			continue
+		}
+		why := ""
+		for _, k := range by {
+			switch {
+			case k.unreadable != "":
+				why = fmt.Sprintf("the Flux Kustomization %s renders its folder and its postBuild cannot be read: %s", k.id(), k.unreadable)
+			case len(k.secrets) == 0:
+				why = fmt.Sprintf("the Flux Kustomization %s renders its folder and names no postBuild.substituteFrom entry of kind Secret", k.id())
+			}
+			for _, name := range templates[p] {
+				if why != "" {
+					break
+				}
+				if k.substitute[name] {
+					why = fmt.Sprintf("the name %s is also a key of the inline postBuild.substitute of the Flux Kustomization %s, so its value is in Git", name, k.id())
+					continue
+				}
+				for _, c := range k.configMaps {
+					if f, ok := keys[c][name]; ok {
+						why = fmt.Sprintf("the name %s is a key of the ConfigMap %s (%s), which the Flux Kustomization %s names in postBuild.substituteFrom, so its value is in Git", name, c, f, k.id())
+						break
+					}
+				}
+			}
+			if why != "" {
+				break
+			}
+		}
+		if why != "" {
+			out[p] = why
+		}
+	}
+	return out
+}

+// documents splits a file at its lines `---` or `...` at the left edge.
+func documents(text string) [][]string {
+	var out [][]string
+	var cur []string
+	for _, l := range strings.Split(text, "\n") {
+		if separator.MatchString(l) {
+			out = append(out, cur)
+			cur = nil
+			continue
+		}
+		cur = append(cur, l)
+	}
+	return append(out, cur)
+}

+// yNode is a node of the block YAML this rule reads: a mapping, a sequence or
+// a scalar. A flow collection is a scalar holding its text.
+type yNode struct {
+	scalar       string
+	isMap, isSeq bool
+	keys         []string
+	m            map[string]*yNode
+	seq          []*yNode
+}
+
+var null = &yNode{}
+
+func (n *yNode) get(key string) *yNode {
+	if n == nil || !n.isMap || n.m[key] == nil {
+		return null
+	}
+	return n.m[key]
+}
+
+func (n *yNode) isNull() bool { return !n.isMap && !n.isSeq && n.scalar == "" }
+
+type yLine struct {
+	indent int
+	text   string
+}
+
+var blockScalar = regexp.MustCompile(`(?:^-|:)\s+[|>][-+0-9]*$`)
+
+// parseYAML reads one document of block YAML: mappings, sequences, plain and
+// quoted scalars, comments and block scalars (skipped). A tab in the
+// indentation or a line that is neither an entry nor an item is an error.
+func parseYAML(doc []string) (*yNode, error) {
+	var ls []yLine
+	for i := 0; i < len(doc); i++ {
+		raw := strings.TrimRight(doc[i], " \r")
+		t := strings.TrimLeft(raw, " ")
+		if t == "" || strings.HasPrefix(t, "#") {
+			continue
+		}
+		if strings.HasPrefix(t, "\t") {
+			return nil, fmt.Errorf("line %d: a tab in the indentation", i+1)
+		}
+		ind := len(raw) - len(t)
+		t = stripComment(t)
+		ls = append(ls, yLine{ind, t})
+		if blockScalar.MatchString(t) {
+			for i+1 < len(doc) && (strings.TrimSpace(doc[i+1]) == "" || indentOf(doc[i+1]) > ind) {
+				i++
+			}
+		}
+	}
+	if len(ls) == 0 {
+		return null, nil
+	}
+	i := 0
+	n, err := parseBlock(ls, &i, ls[0].indent)
+	if err == nil && i < len(ls) {
+		err = fmt.Errorf("an entry at indent %d after the document's block", ls[i].indent)
+	}
+	return n, err
+}
+
+func isItem(t string) bool { return t == "-" || strings.HasPrefix(t, "- ") }
+
+func parseBlock(ls []yLine, i *int, ind int) (*yNode, error) {
+	if isItem(ls[*i].text) {
+		return parseSeq(ls, i, ind)
+	}
+	return parseMap(ls, i, ind)
+}
+
+func parseSeq(ls []yLine, i *int, ind int) (*yNode, error) {
+	n := &yNode{isSeq: true}
+	for *i < len(ls) && ls[*i].indent == ind && isItem(ls[*i].text) {
+		rest := strings.TrimLeft(strings.TrimPrefix(ls[*i].text, "-"), " ")
+		var item *yNode
+		switch _, _, isEntry := splitEntry(rest); {
+		case rest == "":
+			*i++
+			item = null
+			if *i < len(ls) && ls[*i].indent > ind {
+				var err error
+				if item, err = parseBlock(ls, i, ls[*i].indent); err != nil {
+					return nil, err
+				}
+			}
+		case isEntry:
+			at := ind + len(ls[*i].text) - len(rest)
+			ls[*i] = yLine{at, rest}
+			var err error
+			if item, err = parseMap(ls, i, at); err != nil {
+				return nil, err
+			}
+		default:
+			item = &yNode{scalar: unquote(rest)}
+			*i++
+		}
+		n.seq = append(n.seq, item)
+	}
+	return n, nil
+}
+
+func parseMap(ls []yLine, i *int, ind int) (*yNode, error) {
+	n := &yNode{isMap: true, m: map[string]*yNode{}}
+	for *i < len(ls) && ls[*i].indent == ind && !isItem(ls[*i].text) {
+		key, value, ok := splitEntry(ls[*i].text)
+		if !ok {
+			return nil, fmt.Errorf("%q is not an entry key: value", ls[*i].text)
+		}
+		*i++
+		child := null
+		switch {
+		case value != "":
+			child = &yNode{scalar: unquote(value)}
+		case *i < len(ls) && (ls[*i].indent > ind || ls[*i].indent == ind && isItem(ls[*i].text)):
+			var err error
+			if child, err = parseBlock(ls, i, ls[*i].indent); err != nil {
+				return nil, err
+			}
+		}
+		if _, dup := n.m[key]; !dup {
+			n.keys = append(n.keys, key)
+		}
+		n.m[key] = child
+	}
+	if *i < len(ls) && ls[*i].indent > ind {
+		return nil, fmt.Errorf("%q is indented more than its mapping", ls[*i].text)
+	}
+	return n, nil
+}
+
+// splitEntry splits `key: value` (a plain or quoted key); ok is false when the
+// text is not an entry.
+func splitEntry(t string) (string, string, bool) {
+	if t == "" || strings.ContainsAny(t[:1], "[{|>*&!%@`") {
+		return "", "", false
+	}
+	if t[0] == '"' || t[0] == '\'' {
+		end := strings.IndexByte(t[1:], t[0])
+		if end < 0 || !strings.HasPrefix(t[end+2:], ":") {
+			return "", "", false
+		}
+		return t[1 : end+1], strings.TrimSpace(t[end+3:]), true
+	}
+	for j := 0; j < len(t); j++ {
+		if t[j] == ':' && (j == len(t)-1 || t[j+1] == ' ') {
+			return t[:j], strings.TrimSpace(t[j+1:]), true
+		}
+	}
+	return "", "", false
+}
+
+// stripComment removes a comment ` #...` that follows a value outside quotes.
+func stripComment(t string) string {
+	quote := byte(0)
+	for j := 0; j < len(t); j++ {
+		switch c := t[j]; {
+		case quote != 0:
+			if c == quote {
+				quote = 0
+			}
+		case c == '"' || c == '\'':
+			if j == 0 || t[j-1] == ' ' || t[j-1] == ':' || t[j-1] == '-' {
+				quote = c
+			}
+		case c == '#' && (j == 0 || t[j-1] == ' '):
+			return strings.TrimRight(t[:j], " ")
+		}
+	}
+	return t
+}
