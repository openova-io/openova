# CLD-101 — Golden files for the variables the engine writes

## In plain words

**The problem today.** The provisioning engine will soon move its cloud-specific code out into the cloud adapters. Nothing today records exactly which variables the engine hands to an OpenTofu module, so such a move could silently change what a cloud receives. Nothing proves either that the deployment records already on disk, which still carry a cloud token field, keep loading after the request type changes.

**What changes.** Two golden files record, for one fixed request per cloud, every variable the engine writes, and a test fails when the engine writes anything else. A second test loads a deployment record written in the stored form of today and checks its provider and regions.

**Done means:**

- A test writes the variables of a fixed Hetzner request and of a fixed Huawei request and fails when either differs from its golden file.
- The two golden files are produced by the test itself from the code on the main branch, with the keys sorted, and no machine setting changes them.
- A deployment record in the stored form of today, with a redacted cloud token, loads through the store without an error and keeps its provider and both regions.
- No code outside tests changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. `TestTfvarsGolden` is in the new file `products/catalyst/bootstrap/api/internal/provisioner/tfvars_golden_test.go`, package `provisioner`. It has one subtest per cloud, named `hetzner` and `huawei`.
2. Each subtest calls `writeTfvars(dir, req)` with a fixed request and reads `<dir>/tofu.auto.tfvars.json`. It decodes the file and encodes it again with the keys of every object sorted, an indent of two spaces, no HTML escaping and a final newline. The result must equal `testdata/tfvars-<cloud>.golden.json` byte for byte. On a difference the test names the first differing line.
3. With the flag `-update` (`go test ... -args -update`) each subtest writes its golden file instead of comparing. The golden files are never written by hand.
4. The test is independent of the machine. It sets every environment variable whose name starts with `CATALYST_` to empty, then sets the five that `writeTfvars` reads to fixed values: `CATALYST_API_PUBLIC_URL`, `CATALYST_GITOPS_REPO_URL`, `CATALYST_GITOPS_BRANCH`, `CATALYST_EGRESS_CIDRS` and `CATALYST_DEFAULT_ADMIN_CIDRS`.
5. The two requests set every field of `provisioner.Request` and of `provisioner.RegionSpec`; the credential fields of the other cloud stay empty, as in a real request. The singular fields `Region`, `ControlPlaneSize`, `WorkerSize` and `WorkerCount` carry the values of `Regions[0]`, as `Validate` leaves them. The test does not call `Validate`. Every value is made up: no real token, no real address, no installation name.
6. `TestLegacyRecordLoads` is in the new file `products/catalyst/bootstrap/api/internal/store/legacy_record_test.go`, package `store`. It copies `../provisioner/testdata/legacy-record.json` into an empty directory as `4c3a9e1f0b2d7a65.json`, opens a `Store` there, and requires: `LoadAll` returns exactly that one record and reports no file; `Load("4c3a9e1f0b2d7a65")` succeeds; for both, the id is `4c3a9e1f0b2d7a65`, the status `ready`, the provider `hetzner` in the stored form and in `ToProvisionerRequest()`, and the two regions in order with provider, cloud region, both sizes and the worker count. It asserts nothing about the token fields, so it still holds when those fields leave the request type.
7. `legacy-record.json` is the exact text that `Store.Save` writes today for a `Record` whose request was passed through `Redact`.
8. No file outside the five new files changes. No code outside tests changes.

// sortedJSON encodes a JSON document again with the keys of every object
// sorted, an indent of two spaces, no HTML escaping and a final newline.
func sortedJSON(raw []byte) ([]byte, error) {
	dec := json.NewDecoder(bytes.NewReader(raw))
	dec.UseNumber()
	var doc any
	if err := dec.Decode(&doc); err != nil {
		return nil, err
	}
	var out bytes.Buffer
	enc := json.NewEncoder(&out)
	enc.SetIndent("", "  ")
	enc.SetEscapeHTML(false)
	if err := enc.Encode(doc); err != nil {
		return nil, err
	}
	return out.Bytes(), nil
}

// firstDifference names the first line where two documents differ.
func firstDifference(want, got []byte) string {
	w, g := strings.Split(string(want), "\n"), strings.Split(string(got), "\n")
	for i := 0; i < len(w) || i < len(g); i++ {
		var wl, gl string
		if i < len(w) {
			wl = w[i]
		}
		if i < len(g) {
			gl = g[i]
		}
		if wl != gl {
			return fmt.Sprintf("line %d\n golden: %s\n now:    %s", i+1, wl, gl)
		}
	}
	return "the documents differ"
}

package store

// TestLegacyRecordLoads proves that a deployment record in the form the store
// has written so far still loads (work package CLD-101). Its provider stands
// at the top and in every region, and it carries "hetznerToken": "<redacted>".
// Work packages that move the credentials of a request into other fields keep
// this test green: a record already on a volume is read before it is ever
// written again.
func TestLegacyRecordLoads(t *testing.T) {
	const id = "4c3a9e1f0b2d7a65" // the "id" inside the record
	raw, err := os.ReadFile(filepath.Join("..", "provisioner", "testdata", "legacy-record.json"))
	if err != nil {
		t.Fatalf("read the legacy record: %v", err)
	}
	dir := t.TempDir()
	if err := os.WriteFile(filepath.Join(dir, id+".json"), raw, 0o600); err != nil {
		t.Fatalf("place the legacy record: %v", err)
	}
	s, err := New(dir)
	if err != nil {
		t.Fatalf("New: %v", err)
	}
	var loadErrors []string
	recs, err := s.LoadAll(func(path string, err error) { loadErrors = append(loadErrors, path+": "+err.Error()) })
	if err != nil || len(loadErrors) > 0 || len(recs) != 1 {
		t.Fatalf("LoadAll: %d records, error %v, refused %v; want the one legacy record", len(recs), err, loadErrors)
	}
	single, err := s.Load(id)
	if err != nil {
		t.Fatalf("Load: %v", err)
	}
	for name, rec := range map[string]Record{"LoadAll": recs[0], "Load": single} {
		if rec.ID != id || rec.Status != "ready" {
			t.Errorf("%s: id %q status %q, want %q %q", name, rec.ID, rec.Status, id, "ready")
		}
		req := rec.Request.ToProvisionerRequest()
		for where, got := range map[string]string{"stored": rec.Request.Provider, "request": req.Provider} {
			if got != "hetzner" {
				t.Errorf("%s: provider of the %s form = %q, want %q", name, where, got, "hetzner")
			}
		}
		checkLegacyRegions(t, name+", stored form", rec.Request.Regions)
		checkLegacyRegions(t, name+", request", req.Regions)
	}
}

// checkLegacyRegions asserts the two regions of the legacy record, in order.
func checkLegacyRegions(t *testing.T, where string, got []provisioner.RegionSpec) {
	t.Helper()
	want := []provisioner.RegionSpec{
		{Provider: "hetzner", CloudRegion: "fsn1", ControlPlaneSize: "cpx31", WorkerSize: "cpx41", WorkerCount: 3},
		{Provider: "hetzner", CloudRegion: "hel1", ControlPlaneSize: "cpx31", WorkerSize: "cpx41", WorkerCount: 2},
	}
	if len(got) != len(want) {
		t.Errorf("%s: %d regions, want %d", where, len(got), len(want))
		return
	}
	for i, w := range want {
		g := got[i]
		if g.Provider != w.Provider || g.CloudRegion != w.CloudRegion || g.ControlPlaneSize != w.ControlPlaneSize ||
			g.WorkerSize != w.WorkerSize || g.WorkerCount != w.WorkerCount {
			t.Errorf("%s: region %d = %+v, want %+v", where, i, g, w)
		}
	}
}
