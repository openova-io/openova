# AIP-120 — Agent tokens and the signer key set route

## In plain words

**The problem today.** An agent of an Organization has no identity of its own today. The only credential an agent workspace holds is a long-lived bearer, and the API has no way to give an in-cluster workload a short-lived token for one agent of one Organization. The key that signs console sessions has no published key set with a key identifier, so no other service can verify a token of this Sovereign.

**What changes.** A workload named in the chart value agentTokens.callers asks catalyst-api for a token of at most one hour for one agent of one Organization, and the API publishes the key set of its signer. An agent token is confined to its own Organization and may only read; a new gate check proves this on every release.

**Done means:**

- POST /api/v1/internal/agent-tokens gives a named in-cluster workload a signed token of 60 to 3600 seconds for one agent of one Organization, at tier viewer or developer, and writes one audit event; the token is never logged.
- A workload that no entry names, or a request outside its entry, is refused, and an unreadable list of callers refuses every request.
- GET /api/v1/auth/signers.jwks serves one key, the key that agent tokens name in their header.
- An agent token reads routes of its own Organization, is refused on every other route, and is refused on every request that changes state.
- Console sessions and the three existing internal routes work exactly as before.
- Gate check AIP-G07 is required and fails a Sovereign where any of these does not hold.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
catalyst-api issues agent tokens and confines them. A workload inside the Sovereign whose ServiceAccount is named in the chart value `agentTokens.callers` calls `POST /api/v1/internal/agent-tokens` with its projected ServiceAccount token and gets a JWT, signed by the session signer of the pod, for one agent of one Organization, at tier viewer or developer, for 60 to 3600 seconds. `GET /api/v1/auth/signers.jwks` serves the public key of that signer with its key identifier. An agent token passes the session check of catalyst-api, the Organization scope guard confines it to the Organization of its `org_id` claim, and the new middleware `agenttoken.Restrict` lets it read and refuses every request that changes state. The function that asks the cluster to judge a ServiceAccount token moves out of the handler package into the new package `internal/sacaller`, unchanged, so that both the internal routes and the new route call it. The gate check AIP-G07 becomes required: on a Sovereign it mints a token as the chart's default caller and proves each of these rules. A person sees the result in the tests of the new packages, in the route table `cmd/api/testdata/routes.golden`, and in the gate record of the next release.

## 3. The model (the law)
The format, the routes and the checks are those of `docs/contracts/model-contract.md` section 2, which is published and does not change.

1. **Token.** Header exactly `{"alg": "RS256", "kid": "<key identifier>", "typ": "JWT"}`. The key identifier is the RFC 7638 thumbprint of the signer's public key: the SHA-256 of `{"e":"<e>","kty":"RSA","n":"<n>"}` with no white space, base64url without padding. Claims exactly these sixteen: `iss` (`CATALYST_PIN_ISSUER` when set, else `https://console.<SOVEREIGN_FQDN>`, the rule of `pinIssuer` in `internal/handler/auth.go`), `aud` `["model-gateway", "platform-tools", "catalyst-api"]`, `sub` `agent:<organization>/<agent>`, `typ` `agent`, `org` and `org_id` the Organization slug, `agent`, `tier` (`viewer` or `developer`), `realm_access` `{"roles": ["catalyst-<tier>"]}`, `role` `openova-user`, `email` `<agent>@<organization>.agents.invalid`, `email_verified` `false`, `caller` (the TokenReview user name of the workload that asked), `iat`, `exp` and `jti` (a UUID). It is signed by `handoverjwt.Signer.SignCustomClaimsWithKeyID`. Sessions are not changed: `SignCustomClaims` and `PublicJWK` keep their behaviour and sessions name no key.
2. **Callers.** The environment variable `CATALYST_AGENT_TOKEN_CALLERS` is a JSON list. Each entry has exactly the keys `caller`, `organizations` (`["*"]` or slugs), `maxTier` (`viewer` or `developer`) and `agents` (`["*"]` or names of the form `^[a-z][a-z0-9-]{1,62}$`). A caller is named by at most one entry. The chart value `agentTokens.callers` holds the list as one string; its default is exactly one entry: `[{"caller": "system:serviceaccount:catalyst-system:catalyst-conformance", "organizations": ["conformance"], "maxTier": "viewer", "agents": ["conformance-probe"]}]`. Both deployment templates set the variable; `api-deployment-kustomize.yaml` is raw Kustomize and repeats the default as a literal.
3. **Issue route.** `POST /api/v1/internal/agent-tokens`, outside the session group, in `registerPublicInternal`. Body `{"organization", "agent", "tier", "ttlSeconds"}`; `ttlSeconds` is optional (default 1800, integer 60 to 3600); an unknown field or a second JSON object is refused. Answers, in the order they are judged: 503 `agent-tokens-misconfigured` (the variable is unset or breaks rule 2, or `SOVEREIGN_FQDN` is empty; it never falls back to allowing); 503 `signer-unavailable` (no signer); 401 `missing-bearer`; 502 `token-review-failed` (the TokenReview did not accept the token, through `sacaller.Validate`); 403 `unauthorized-sa` (no entry names the caller); 422 `invalid-request` (the body; a tier other than viewer or developer, such as admin, is this answer); 403 `caller-not-allowed` (Organization, agent or tier outside the caller's entry); 200 `{"token", "expiresAt"}` with `Cache-Control: no-store`. Every error body is `{"error": "<code>", "detail": "<text>"}`. Every 200 publishes one audit event: type `agent-token.issue`, `Actor` the caller, `TargetUser` the `sub`, `Tier` the tier, `Detail` `caller=… organization=… agent=… tier=… jti=…`. The token is never logged or stored.
4. **Key set route.** `GET /api/v1/auth/signers.jwks`, outside the session group, in `registerPublicAuth`, no authentication. 200, `application/json`, `Cache-Control: max-age=300`, `{"keys": [<PublicJWKWithKeyID>]}`: one key. Without a signer: 503 `signer-unavailable`.
5. **Verification.** `auth.Claims` gains `Typ` (`typ`), `Agent` (`agent`) and `Audience` (`aud`, one string or a list; another shape leaves it empty and never fails the parse). `auth.Config` gains `LocalKeyID`; `ValidateToken` uses `LocalPublicKey` when the header has no `kid` or when the `kid` equals `LocalKeyID`; every other branch is unchanged. `main()` sets `LocalKeyID` on the same line that sets `LocalPublicKey`, so `main()` does not grow. `claimsAreOrgScoped` also returns true when `Typ` is `agent` (any letter case).
6. **Restrict.** `agenttoken.Restrict` runs in the session group on the line after `rg.Use(h.OrgScopeGuard)`. For claims whose `Typ` is not `agent`, and for a request without claims, it does nothing. For an agent token: an audience without `catalyst-api` is 401 `agent-token-wrong-audience`; `GET`, `HEAD` and `OPTIONS` pass; any other method passes only when an entry of `agenttoken.MutationsAllowed` matches the method, the whole path and a tier at least its `MinTier`; otherwise 403 `agent-token-forbidden`. `MutationsAllowed` is empty.
7. **Wiring.** `buildRouter` in `cmd/api/routes.go` makes the routes object, as it makes `self`: `agenttoken.New(h.GetHandoverSigner(), jobauth.InCluster, h.AuditBus(), log)`. `main()` gains no line (the structure guard). The handler package gains no method and no file; it shrinks, and `scripts/baselines/api-structure.json` is lowered by its own tool.
8. **Moved function.** The body of `validateInternalBearer` moves unchanged into `sacaller.Validate(ctx, core, bearer)`; `validateInternalBearer` becomes one line that calls it. The one TokenReview call moves with it, so the direct-cluster-write baseline loses the count of `internal_auth.go` and gains an allow entry for `internal/sacaller/sacaller.go`, the same reason that `internal/jobauth/jobauth.go` carries.
9. **Records.** Contract C9 gains the entry of the issue route: write class `none`, operation empty, disposition `keep`, done. The route table gains the two routes and `agenttoken.Restrict` in the session chains. The gate manifest entry AIP-G07 moves from `not-built` to `required` and gains its implementation line; no other field of it changes.
10. **Gate check AIP-G07** (`tests/acceptance/sovereign/internal/suite/check_aip_g07.go`), in the first region, the region the API runs in, nine steps: (1) `kubectl -n catalyst-system create token catalyst-conformance --duration=10m`; (2) mint a viewer token for agent `conformance-probe` of Organization `conformance`, answer 200, header with `kid`, claims `typ` agent, `org_id`, `agent`, `tier` viewer and an audience with `catalyst-api`; (3) the key set lists exactly that key and the signature verifies with it; (4) `GET /api/v1/refs/organizations` with the token answers 200 and lists no Organization but `conformance`; (5) `GET /api/v1/sovereigns/<deployment>/applications` answers 403 `org-scoped-forbidden`; (6) `POST /api/v1/org/applications` answers 403 `agent-token-forbidden`; (7) a request for tier admin answers 422 `invalid-request`; (8) a request for Organization `other` answers 403 `caller-not-allowed`; (9) a token of 60 seconds reads at once and the same read answers 401 ninety seconds after the mint. No token reaches the record. A run without a console address fails the check.
11. Nothing is deleted.

// Package sacaller tells catalyst-api which in-cluster workload sent a
// request. The workload presents its projected ServiceAccount token as
// `Authorization: Bearer`; a TokenReview of the cluster the API runs in
// judges the token and names the account. The token is never read here:
// the review checks its signature, its expiry, its audience and that the
// ServiceAccount still exists.
//
// The internal routes of internal/handler (internal_auth.go) and the
// agent-token route of internal/agenttoken call the same function.
package sacaller

import (
	"context"
	"fmt"
	"strings"

	authnv1 "k8s.io/api/authentication/v1"
	metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"
	"k8s.io/client-go/kubernetes"
)

// Validate runs a TokenReview against the cluster's authentication chain.
// Returns the resolved username on success, for example
// system:serviceaccount:<namespace>:<name>, or an error describing why the
// token was rejected.
//
// Production wires core to a real kubernetes.Interface; tests inject a
// fake.NewSimpleClientset and prepend a reactor for the `tokenreviews`
// resource so the apiserver round-trip is mocked.
func Validate(ctx context.Context, core kubernetes.Interface, bearer string) (string, error) {
	if bearer == "" {
		return "", fmt.Errorf("empty bearer token")
	}
	if core == nil {
		return "", fmt.Errorf("no cluster client to review the token with")
	}
	tr := &authnv1.TokenReview{Spec: authnv1.TokenReviewSpec{Token: bearer}}
	resp, err := core.AuthenticationV1().TokenReviews().Create(ctx, tr, metav1.CreateOptions{})
	if err != nil {
		return "", fmt.Errorf("token review API call failed: %w", err)
	}
	if !resp.Status.Authenticated {
		// resp.Status.Error is operator-actionable (e.g. "token expired").
		// Returned verbatim so the caller can log it.
		detail := resp.Status.Error
		if detail == "" {
			detail = "token not authenticated by apiserver"
		}
		return "", fmt.Errorf("token review rejected: %s", detail)
	}
	user := strings.TrimSpace(resp.Status.User.Username)
	if user == "" {
		return "", fmt.Errorf("token review returned empty username")
	}
	return user, nil
}

package sacaller

import (
	"context"
	"errors"
	"strings"
	"testing"

	authnv1 "k8s.io/api/authentication/v1"
	k8sruntime "k8s.io/apimachinery/pkg/runtime"
	fakek8s "k8s.io/client-go/kubernetes/fake"
	clienttesting "k8s.io/client-go/testing"
)

// review returns a fake cluster whose TokenReview answers with status, or
// fails with err when err is not nil. seen receives the token reviewed.
func review(status authnv1.TokenReviewStatus, err error, seen *string) *fakek8s.Clientset {
	client := fakek8s.NewSimpleClientset()
	client.PrependReactor("create", "tokenreviews", func(action clienttesting.Action) (bool, k8sruntime.Object, error) {
		tr := action.(clienttesting.CreateAction).GetObject().(*authnv1.TokenReview)
		*seen = tr.Spec.Token
		if err != nil {
			return true, nil, err
		}
		out := tr.DeepCopy()
		out.Status = status
		return true, out, nil
	})
	return client
}

// TestValidateReturnsTheReviewedUser: the token goes to the review
// unchanged and the user name the review resolved comes back.
func TestValidateReturnsTheReviewedUser(t *testing.T) {
	var seen string
	core := review(authnv1.TokenReviewStatus{Authenticated: true,
		User: authnv1.UserInfo{Username: " system:serviceaccount:ops:ops-records "}}, nil, &seen)
	user, err := Validate(context.Background(), core, "projected-token")
	if err != nil || user != "system:serviceaccount:ops:ops-records" {
		t.Fatalf("Validate = %q, %v", user, err)
	}
	if seen != "projected-token" {
		t.Fatalf("the review saw the token %q", seen)
	}
}

// TestValidateRefuses: every way a token is not accepted is an error, and
// no error ever names the token.
func TestValidateRefuses(t *testing.T) {
	var seen string
	cases := []struct {
		name   string
		core   *fakek8s.Clientset
		bearer string
		want   string
	}{
		{"no bearer", review(authnv1.TokenReviewStatus{Authenticated: true}, nil, &seen), "", "empty bearer token"},
		{"the review fails", review(authnv1.TokenReviewStatus{}, errors.New("connection refused"), &seen), "secret-token", "token review API call failed: connection refused"},
		{"not authenticated", review(authnv1.TokenReviewStatus{Error: "token expired"}, nil, &seen), "secret-token", "token review rejected: token expired"},
		{"not authenticated, no reason", review(authnv1.TokenReviewStatus{}, nil, &seen), "secret-token", "token review rejected: token not authenticated by apiserver"},
		{"no user name", review(authnv1.TokenReviewStatus{Authenticated: true}, nil, &seen), "secret-token", "token review returned empty username"},
	}
	for _, c := range cases {
		t.Run(c.name, func(t *testing.T) {
			user, err := Validate(context.Background(), c.core, c.bearer)
			if err == nil || user != "" {
				t.Fatalf("Validate = %q, %v; want an error", user, err)
			}
			if !strings.Contains(err.Error(), c.want) || strings.Contains(err.Error(), "secret-token") {
				t.Fatalf("error %q, want %q and never the token", err, c.want)
			}
		})
	}
	if _, err := Validate(context.Background(), nil, "secret-token"); err == nil || err.Error() != "no cluster client to review the token with" {
		t.Fatalf("no cluster client: %v", err)
	}
}

// An agent token is the short-lived identity of one agent of one
// Organization. It is a JWT signed RS256 by the session signer of this

	Type = "agent"

	// The three audiences of every agent token.
	AudienceGateway = "model-gateway"
	AudienceTools   = "platform-tools"
	AudienceAPI     = "catalyst-api"

var (
	// agentName is the form of an agent name.
	agentName = regexp.MustCompile(`^[a-z][a-z0-9-]{1,62}$`)
	// orgSlug is the form of an Organization slug: a DNS label, because an
	// Organization's Applications live in the namespace of that name.
	orgSlug = regexp.MustCompile(`^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?$`)
	// tierRank orders the two tiers an agent token may carry.
	tierRank = map[string]int{"viewer": 1, "developer": 2}
	// callerKeys are the keys of an entry of CallersEnv, all required.
	callerKeys = []string{"agents", "caller", "maxTier", "organizations"}
)

// Caller is one entry of CallersEnv.
type Caller struct {
	// Caller is the TokenReview user name of the workload,
	// system:serviceaccount:<namespace>:<name>.
	Caller string `json:"caller"`
	// Organizations it may ask for: slugs, or ["*"].
	Organizations []string `json:"organizations"`
	// MaxTier is the highest tier it may ask for: viewer or developer.
	MaxTier string `json:"maxTier"`
	// Agents it may ask for: names, or ["*"].
	Agents []string `json:"agents"`
}

// ParseCallers reads the value of CallersEnv. Every entry has exactly the
// four keys of Caller, a caller that no other entry names, at least one
// Organization and one agent, each "*" or of the right form, and a maxTier
// of viewer or developer. Anything else is an error, and the issue route
// then refuses every request.
func ParseCallers(value string) ([]Caller, error) {
	var raw []map[string]json.RawMessage
	if err := json.Unmarshal([]byte(value), &raw); err != nil {
		return nil, fmt.Errorf("%s is not a JSON list of objects: %v", CallersEnv, err)
	}
	if raw == nil {
		return nil, fmt.Errorf("%s is not a JSON list of objects", CallersEnv)
	}
	out := make([]Caller, 0, len(raw))
	seen := map[string]bool{}
	for i, fields := range raw {
		keys := make([]string, 0, len(fields))
		for k := range fields {
			keys = append(keys, k)
		}
		if !sameKeys(keys, callerKeys) {
			return nil, fmt.Errorf("%s entry %d: the keys must be exactly %s", CallersEnv, i, strings.Join(callerKeys, ", "))
		}
		var c Caller
		data, _ := json.Marshal(fields)
		if err := json.Unmarshal(data, &c); err != nil {
			return nil, fmt.Errorf("%s entry %d: %v", CallersEnv, i, err)
		}
		switch {
		case strings.TrimSpace(c.Caller) == "" || c.Caller != strings.TrimSpace(c.Caller):
			return nil, fmt.Errorf("%s entry %d: caller is empty or has blanks", CallersEnv, i)
		case seen[c.Caller]:
			return nil, fmt.Errorf("%s entry %d: caller %s is named twice", CallersEnv, i, c.Caller)
		case tierRank[c.MaxTier] == 0:
			return nil, fmt.Errorf("%s entry %d: maxTier %q is not viewer or developer", CallersEnv, i, c.MaxTier)
		case !validList(c.Organizations, orgSlug):
			return nil, fmt.Errorf("%s entry %d: organizations must be [\"*\"] or a list of slugs", CallersEnv, i)
		case !validList(c.Agents, agentName):
			return nil, fmt.Errorf("%s entry %d: agents must be [\"*\"] or a list of agent names", CallersEnv, i)
		}
		seen[c.Caller] = true
		out = append(out, c)
	}
	return out, nil
}

func sameKeys(have, want []string) bool {
	if len(have) != len(want) {
		return false
	}
	for _, w := range want {
		found := false
		for _, h := range have {
			found = found || h == w
		}
		if !found {
			return false
		}
	}
	return true
}

func validList(list []string, form *regexp.Regexp) bool {
	if len(list) == 0 {
		return false
	}
	for _, v := range list {
		if v != wildcard && !form.MatchString(v) {
			return false
		}
	}
	return true
}

func listed(list []string, v string) bool {
	for _, x := range list {
		if x == wildcard || x == v {
			return true
		}
	}
	return false
}

// permits returns nil when the entry may ask for this token, and otherwise
// says why not.
func (c Caller) permits(org, agent, tier string) error {
	switch {
	case !listed(c.Organizations, org):
		return fmt.Errorf("the entry of %s does not name Organization %s", c.Caller, org)
	case !listed(c.Agents, agent):
		return fmt.Errorf("the entry of %s does not name agent %s", c.Caller, agent)
	case tierRank[tier] > tierRank[c.MaxTier]:
		return fmt.Errorf("the entry of %s allows tier %s at most", c.Caller, c.MaxTier)
	}
	return nil
}

// Clients returns the cluster client that the TokenReview runs with.
type Clients func() (kubernetes.Interface, error)

// Tokens serves the issue route and the key set route.
type Tokens struct {

// New returns the routes of agent tokens. signer is the session signer of
// this pod; without it both routes answer 503 signer-unavailable. clients
// gives the client the TokenReview runs with. bus receives the audit event
// of every issue; nil writes none.
func New(signer *handoverjwt.Signer, clients Clients, bus *audit.Bus, log *slog.Logger) *Tokens {
	if log == nil {
		log = slog.New(slog.NewTextHandler(io.Discard, nil))
	}
	return &Tokens{signer: signer, clients: clients, audit: bus, log: log, now: time.Now}

// issuer is the claim iss: the session issuer of this Sovereign, the rule
// of pinIssuer in internal/handler/auth.go (CATALYST_PIN_ISSUER, else
// handoverjwt.OwnIssuer). A pod without SOVEREIGN_FQDN is not a Sovereign
// and issues no agent token.
func issuer() (string, error) {
	if strings.TrimSpace(os.Getenv("SOVEREIGN_FQDN")) == "" {
		return "", errors.New("SOVEREIGN_FQDN is empty: this pod is not a Sovereign")
	}
	if v := strings.TrimSpace(os.Getenv("CATALYST_PIN_ISSUER")); v != "" {
		return v, nil
	}
	return handoverjwt.OwnIssuer(), nil
}

// issueRequest is the body of the issue route.
type issueRequest struct {
	Organization string `json:"organization"`
	Agent        string `json:"agent"`
	Tier         string `json:"tier"`
	TTLSeconds   *int   `json:"ttlSeconds"`
}

// HandleIssue serves POST /api/v1/internal/agent-tokens.
//
//   - 503 agent-tokens-misconfigured: CallersEnv is unset or does not
//     parse, or SOVEREIGN_FQDN is empty. It never falls back to allowing.
//   - 503 signer-unavailable: this pod has no signer, or signing failed.
//   - 401 missing-bearer: no `Authorization: Bearer` header.
//   - 502 token-review-failed: the TokenReview did not accept the token.
//   - 403 unauthorized-sa: the caller is in no entry.
//   - 422 invalid-request: the body is not the request of the contract.
//   - 403 caller-not-allowed: the Organization, the agent or the tier is
//     outside the caller's entry.
//   - 200 {"token": "<jwt>", "expiresAt": "<RFC 3339 time>"}.
func (t *Tokens) HandleIssue(w http.ResponseWriter, r *http.Request) {
	value, set := os.LookupEnv(CallersEnv)
	callers, err := ParseCallers(value)
	if !set {
		err = errors.New(CallersEnv + " is not set")
	}
	iss, issErr := issuer()
	if err == nil {
		err = issErr
	}
	if err != nil {
		t.log.Warn("agent token: the issue route is misconfigured", "err", err)
		writeError(w, http.StatusServiceUnavailable, "agent-tokens-misconfigured", err.Error())
		return
	}
	if t.signer == nil {
		writeError(w, http.StatusServiceUnavailable, "signer-unavailable", "this pod has no session signer")
		return
	}
	bearer := bearerOf(r)
	if bearer == "" {
		writeError(w, http.StatusUnauthorized, "missing-bearer", "Authorization: Bearer <serviceaccount-token> header is required")
		return
	}
	var core kubernetes.Interface
	if t.clients != nil {
		if c, cErr := t.clients(); cErr == nil {
			core = c
		}
	}
	user, err := sacaller.Validate(r.Context(), core, bearer)
	if err != nil {
		writeError(w, http.StatusBadGateway, "token-review-failed", err.Error())
		return
	}
	var entry *Caller
	for i := range callers {
		if callers[i].Caller == user {
			entry = &callers[i]
		}
	}
	if entry == nil {
		t.log.Info("agent token: refused a caller", "caller", user)
		writeError(w, http.StatusForbidden, "unauthorized-sa", fmt.Sprintf("token resolved to %q, which no entry of %s names", user, CallersEnv))
		return
	}
	req, ttl, err := readRequest(w, r)
	if err != nil {
		writeError(w, http.StatusUnprocessableEntity, "invalid-request", err.Error())
		return
	}
	if err := entry.permits(req.Organization, req.Agent, req.Tier); err != nil {
		t.log.Info("agent token: refused a request", "caller", user, "why", err.Error())
		writeError(w, http.StatusForbidden, "caller-not-allowed", err.Error())
		return
	}
	token, claims, err := t.mint(iss, user, req.Organization, req.Agent, req.Tier, ttl)
	if err != nil {
		writeError(w, http.StatusServiceUnavailable, "signer-unavailable", err.Error())
		return
	}
	if t.audit != nil {
		t.audit.Publish(r.Context(), audit.Event{
			AuditType:  AuditType,
			Actor:      user,
			TargetUser: claims.Subject,
			Tier:       req.Tier,
			Detail:     fmt.Sprintf("caller=%s organization=%s agent=%s tier=%s jti=%s", user, req.Organization, req.Agent, req.Tier, claims.ID),
		})
	}
	w.Header().Set("Cache-Control", "no-store")
	writeJSON(w, http.StatusOK, map[string]string{
		"token":     token,
		"expiresAt": claims.ExpiresAt.UTC().Format(time.RFC3339),
	})
}

// readRequest decodes and checks the body of the issue route.
func readRequest(w http.ResponseWriter, r *http.Request) (issueRequest, time.Duration, error) {
	var req issueRequest
	dec := json.NewDecoder(http.MaxBytesReader(w, r.Body, maxBody))
	dec.DisallowUnknownFields()
	if err := dec.Decode(&req); err != nil {
		return req, 0, fmt.Errorf("the body is not the JSON object of the issue route: %v", err)
	}
	if _, err := dec.Token(); err != io.EOF {
		return req, 0, errors.New("the body holds more than one JSON object")
	}
	ttl := DefaultTTL
	if req.TTLSeconds != nil {
		ttl = time.Duration(*req.TTLSeconds) * time.Second
	}
	switch {
	case !orgSlug.MatchString(req.Organization):
		return req, 0, errors.New("organization must be an Organization slug")
	case !agentName.MatchString(req.Agent):
		return req, 0, errors.New("agent must match ^[a-z][a-z0-9-]{1,62}$")
	case tierRank[req.Tier] == 0:
		return req, 0, errors.New("tier must be viewer or developer")
	case ttl < MinTTL || ttl > MaxTTL:
		return req, 0, errors.New("ttlSeconds must be an integer from 60 to 3600")
	}
	return req, ttl, nil
}

// mint signs the token of section 2.1 of the contract.
func (t *Tokens) mint(iss, caller, org, agent, tier string, ttl time.Duration) (string, Claims, error) {
	jti, err := uuid.NewRandom()
	if err != nil {
		return "", Claims{}, fmt.Errorf("generate jti: %w", err)
	}
	now := t.now().UTC().Truncate(time.Second)
	claims := Claims{
		RegisteredClaims: jwt.RegisteredClaims{
			Issuer:    iss,
			Subject:   "agent:" + org + "/" + agent,
			Audience:  jwt.ClaimStrings{AudienceGateway, AudienceTools, AudienceAPI},
			IssuedAt:  jwt.NewNumericDate(now),
			ExpiresAt: jwt.NewNumericDate(now.Add(ttl)),
			ID:        jti.String(),
		},
		Typ:           Type,
		Org:           org,
		OrgID:         org,
		Agent:         agent,
		Tier:          tier,
		RealmAccess:   RealmAccess{Roles: []string{"catalyst-" + tier}},
		Role:          role,
		Email:         agent + "@" + org + ".agents.invalid",
		EmailVerified: false,
		Caller:        caller,
	}
	token, err := t.signer.SignCustomClaimsWithKeyID(claims)
	if err != nil {
		return "", Claims{}, err
	}
	return token, claims, nil
}

// HandleJWKS serves GET /api/v1/auth/signers.jwks: one key, the public key
// of the signer of this pod with its key identifier. Public material only.
func (t *Tokens) HandleJWKS(w http.ResponseWriter, _ *http.Request) {
	if t.signer == nil {
		writeError(w, http.StatusServiceUnavailable, "signer-unavailable", "this pod has no session signer")
		return
	}
	jwk, err := t.signer.PublicJWKWithKeyID()
	if err != nil {
		writeError(w, http.StatusServiceUnavailable, "signer-unavailable", err.Error())
		return
	}
	w.Header().Set("Cache-Control", "max-age=300")
	writeJSON(w, http.StatusOK, map[string][]json.RawMessage{"keys": {jwk}})
}

// bearerOf returns the token of an `Authorization: Bearer` header, or "".
func bearerOf(r *http.Request) string {
	const prefix = "Bearer "
	h := r.Header.Get("Authorization")
	if len(h) <= len(prefix) || !strings.EqualFold(h[:len(prefix)], prefix) {
		return ""
	}
	return strings.TrimSpace(h[len(prefix):])
}

func writeJSON(w http.ResponseWriter, status int, body any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(body)
}

func writeError(w http.ResponseWriter, status int, code, detail string) {
	writeJSON(w, status, map[string]string{"error": code, "detail": detail})
}

package agenttoken

import (
	"net/http"
	"regexp"
	"slices"
	"strings"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/auth"
)

// Mutation is one request that changes state and that an agent token of at
// least MinTier may make.
type Mutation struct {
	Method  string
	Path    *regexp.Regexp // matched against the whole request path; anchor it
	MinTier string         // viewer or developer
}

// MutationsAllowed is every request other than GET, HEAD and OPTIONS that
// an agent token may make at catalyst-api. It is empty: an agent token
// changes nothing. The package that needs a mutation adds its one entry.
var MutationsAllowed = []Mutation{}

// Restrict is the middleware of the session route group that runs after
// the Organization scope guard. It does nothing for a request whose
// session claims are not those of an agent token (typ is not "agent").
// For an agent token:
//
//  1. an audience without catalyst-api: 401 agent-token-wrong-audience;
//  2. GET, HEAD and OPTIONS pass;
//  3. any other method passes only when an entry of MutationsAllowed
//     matches the method, the path and the tier; otherwise 403
//     agent-token-forbidden.
//
// The Organization scope guard has already confined the token to the
// Organization of its claim org_id (claimsAreOrgScoped in
// internal/handler/org_scope.go).
func Restrict(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		claims := auth.ClaimsFromContext(r.Context())
		if claims == nil || !strings.EqualFold(strings.TrimSpace(claims.Typ), Type) {
			next.ServeHTTP(w, r)
			return
		}
		if !slices.Contains(claims.Audience, AudienceAPI) {
			writeError(w, http.StatusUnauthorized, "agent-token-wrong-audience", "the audience of this agent token does not hold "+AudienceAPI)
			return
		}
		switch r.Method {
		case http.MethodGet, http.MethodHead, http.MethodOptions:
			next.ServeHTTP(w, r)
			return
		}
		for _, m := range MutationsAllowed {
			if m.Method == r.Method && m.Path.MatchString(r.URL.Path) && tierRank[claims.Tier] >= tierRank[m.MinTier] && tierRank[m.MinTier] > 0 {
				next.ServeHTTP(w, r)
				return
			}
		}
		writeError(w, http.StatusForbidden, "agent-token-forbidden", "an agent token may not "+r.Method+" "+r.URL.Path)
	})
}

// restricted runs Restrict for a request carrying claims (nil: none) and
// returns the status and whether the next handler ran.
func restricted(claims *auth.Claims, method, path string) (int, bool) {
	reached := false
	h := Restrict(http.HandlerFunc(func(w http.ResponseWriter, _ *http.Request) {
		reached = true
		w.WriteHeader(http.StatusOK)
	}))
	req := httptest.NewRequest(method, path, nil)
	if claims != nil {
		req = req.WithContext(context.WithValue(req.Context(), auth.ClaimsKey, claims))
	}
	rec := httptest.NewRecorder()
	h.ServeHTTP(rec, req)
	return rec.Code, reached
}

// signedJWT signs header and payload with key, RS256.
func signedJWT(t *testing.T, key *rsa.PrivateKey, header, payload string) string {
	t.Helper()
	input := base64.RawURLEncoding.EncodeToString([]byte(header)) + "." + base64.RawURLEncoding.EncodeToString([]byte(payload))
	digest := sha256.Sum256([]byte(input))
	sig, err := rsa.SignPKCS1v15(rand.Reader, key, crypto.SHA256, digest[:])
	if err != nil {
		t.Fatal(err)
	}
	return input + "." + base64.RawURLEncoding.EncodeToString(sig)
}

// refusedWith records the answer of do and fails unless it has the status
// and the error code given.
func refusedWith(ev Evidence, do func() (agentAnswer, error), what string, status int, code string) error {
	a, err := do()
	if err != nil {
		return err
	}
	ev["status"], ev["error"] = a.status, a.code
	if a.status != status || a.code != code {
		return fmt.Errorf("%s answered %d %q, want %d %q", what, a.status, a.code, status, code)
	}
	return nil
}

// agentCall sends one request. bearer, when not empty, is sent as
// `Authorization: Bearer`; no error and no evidence ever holds it.
func agentCall(ctx context.Context, client *http.Client, base, method, path, bearer string, body any) (agentAnswer, error) {
	var rd io.Reader
	if body != nil {
		b, err := json.Marshal(body)
		if err != nil {
			return agentAnswer{}, err
		}
		rd = bytes.NewReader(b)
	}
	req, err := http.NewRequestWithContext(ctx, method, strings.TrimRight(base, "/")+path, rd)
	if err != nil {
		return agentAnswer{}, fmt.Errorf("%s %s: %v", method, path, err)
	}
	req.Header.Set("Accept", "application/json")
	if body != nil {
		req.Header.Set("Content-Type", "application/json")
	}
	if bearer != "" {
		req.Header.Set("Authorization", "Bearer "+bearer)
	}
	res, err := client.Do(req)
	if err != nil {
		return agentAnswer{}, fmt.Errorf("%s %s: no answer", method, path)
	}
	defer func() { _ = res.Body.Close() }()
	data, err := io.ReadAll(io.LimitReader(res.Body, 1<<20))
	if err != nil {
		return agentAnswer{}, fmt.Errorf("%s %s: read the body: %v", method, path, err)
	}
	a := agentAnswer{status: res.StatusCode}
	if json.Unmarshal(data, &a.body) == nil {
		a.code, _ = a.body["error"].(string)
	}
	return a, nil
}

// jwtParts decodes the header and the claims of a compact JWT without
// verifying it.
func jwtParts(token string) (header, claims map[string]any, err error) {
	parts := strings.Split(token, ".")
	if len(parts) != 3 {
		return nil, nil, errors.New("the answer holds no token of three parts")
	}
	for i, out := range []*map[string]any{&header, &claims} {
		b, err := base64.RawURLEncoding.DecodeString(parts[i])
		if err != nil {
			return nil, nil, fmt.Errorf("part %d of the token is not base64url", i+1)
		}
		if err := json.Unmarshal(b, out); err != nil {
			return nil, nil, fmt.Errorf("part %d of the token is not a JSON object", i+1)
		}
	}
	return header, claims, nil
}

// verifyRS256 verifies the signature of a compact JWT with an RSA key of a
// key set.
func verifyRS256(token string, key map[string]any) error {
	n, _ := key["n"].(string)
	e, _ := key["e"].(string)
	nb, errN := base64.RawURLEncoding.DecodeString(n)
	eb, errE := base64.RawURLEncoding.DecodeString(e)
	if key["kty"] != "RSA" || errN != nil || errE != nil || len(nb) == 0 || len(eb) == 0 || len(eb) > 4 {
		return fmt.Errorf("the key of the key set is not an RSA key with n and e")
	}
	pub := &rsa.PublicKey{N: new(big.Int).SetBytes(nb), E: int(new(big.Int).SetBytes(eb).Int64())}
	parts := strings.Split(token, ".")
	sig, err := base64.RawURLEncoding.DecodeString(parts[2])
	if err != nil {
		return errors.New("the signature of the token is not base64url")
	}
	digest := sha256.Sum256([]byte(parts[0] + "." + parts[1]))
	if err := rsa.VerifyPKCS1v15(pub, crypto.SHA256, digest[:], sig); err != nil {
		return errors.New("the signature of the token does not verify with the key of the key set")
	}
	return nil
}

// holds reports whether a claim that is a string or a list holds v.
func holds(claim any, v string) bool {
	switch x := claim.(type) {
	case string:
		return x == v
	case []any:
		for _, item := range x {
			if item == v {
				return true
			}
		}
	}
	return false
}
