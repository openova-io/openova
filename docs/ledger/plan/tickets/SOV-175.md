# SOV-175 — The Sovereign object gets its writer

## In plain words

**The problem today.** Nothing writes the Sovereign object, so the record that names a Sovereign, its regions and its network is empty on every installation, and the required gate check that compares the network record with the running clusters fails everywhere. A follower region does not even know the kind, because the chart that ships it is suspended there. The network record that the cloud modules produce never leaves the parent.

**What changes.** Every region runs a small job at bootstrap that writes the Sovereign object from the region's own values. At hand-over the parent hands the network record to every region without adding anything to the boot data of a node, and the job runs again and copies it into the object. A new required gate check proves that each region holds exactly one such object, written by this job.

**Done means:**

- Every region of a new installation, the follower included, serves the Sovereign kind and runs the writer job without a hand step.
- Each region holds exactly one Sovereign object, named sovereign-self, whose name, deployment, provider and regions equal the values of that region.
- After hand-over the object of each region holds the network record exactly as the cloud module wrote it, and the job runs again whenever a new record arrives.
- A value that has no source is left out of the object, and the job's result names it.
- The boot data of a node does not grow by a single byte.
- Gate check SOV-G17 is required and fails a region whose object is missing, doubled, written by hand or different from its sources.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
On every new installation each region's cluster holds exactly one object of the existing cluster-scoped kind `Sovereign` (`sovereigns.catalyst.openova.io`, `v1alpha1`), named `sovereign-self`, written with server-side apply by `sovereign-ops sovereign-object` under the field manager `sovereign-ops`. Its `spec` holds the values of the region's ConfigMap `flux-system/sovereign-variables` (FQDN, deployment id, provider, topology, regions, parent domains), and after hand-over its `status.network` is the output `network_registry` of the provider module, unchanged. The follower region, where `bp-catalyst-platform` is suspended, serves the kind through bootstrap-kit slot 12b. The registry reaches each region in the ConfigMap `flux-system/sovereign-network-registry`, which the parent writes from the OpenTofu state of the deployment in the step that already applies the adoption claims at hand-over; the control-plane user data does not change. The required gate check SOV-G17 "The Sovereign object is written" proves the object in every region. With it, gate check NET-G08 (merged with NET-102) has the object it reads.

## 3. The model (the law)
1. One object per region cluster, named `sovereign-self`, kind `Sovereign`; no new kind. The writer creates or updates only that object and its status subresource and reads only the two ConfigMaps `flux-system/sovereign-variables` and `flux-system/sovereign-network-registry`. When the cluster holds another Sovereign object, the run writes its own object and then fails and names the other one; it deletes nothing.
2. Every field of the object comes from a real source, one key per field: `spec.fqdn` from `SOVEREIGN_FQDN` (the run fails without it); `spec.deploymentId` from `SOVEREIGN_DEPLOYMENT_ID` when it is 16 hexadecimal digits; `spec.provider` from `PROVIDER` when it is not empty (the command holds no list of providers: the kind's enum decides, and a value it refuses fails the write with the API server's message); `spec.bcpTopology` from `SOVEREIGN_BCP_TOPOLOGY` when the value is a topology of the kind; `spec.regions` from `SOVEREIGN_REGIONS_JSON`, one entry per element in order, `code` = its `cloudRegion`, `provider` = its `provider` when not empty; `spec.parentDomains` from `PARENT_DOMAINS_YAML` when every entry has a name and the role `primary` or `org-pool`. A field whose key is absent or does not qualify is left out, and the evidence of the run names it with the reason. `status.network` is the document `NETWORK_REGISTRY_JSON` of `sovereign-network-registry`, decoded with its numbers kept and copied unchanged; while that ConfigMap does not exist the status is applied empty, which removes a `status.network` the writer wrote before. A document that is not one JSON object fails the run before anything is written. Nothing else of the kind is written: not `status.regions`, `ready`, `phase`, `regionCount` or `conditions`, which have no source.
3. The subcommand `sovereign-object` of `core/cmd/sovereign-ops` takes no flag and no argument, reads the cluster with the Pod's service account, and ends with the result line and exit code of `internal/ops`: 0 written, 1 a failure a retry does not change, 75 a transient failure (no answer, HTTP 429 or 5xx, or HTTP 404 on apply while the kind is not served yet).
4. The kind reaches every region through the Flux Kustomization `flux-system/sovereign-object` of bootstrap-kit slot `12b-sovereign-object.yaml`. It has no suspend and no region condition, applies `./clusters/_template/sovereign-object` from the GitRepository `openova` with `prune: true`, `force: true`, `wait: false`, and pins the image `ghcr.io/openova-io/openova/sovereign-ops` in its `images` entry, and carries the labels `catalyst.openova.io/slot: "12b"` and `catalyst.openova.io/ring: foundation`. `scripts/check-service-model.py` takes a slot's Flux Kustomization as its release, as it takes a HelmRelease, so the count `G8.slots-without-ring` stays at 68; its self-test gains the cases for a Kustomization slot. `docs/generated/bootstrap-slots.md` is regenerated by `python3 scripts/generators/slots.py` and lists slot 12b. The folder lists `products/catalyst/chart/crds/sovereign.yaml` itself, not a copy, patched with the two annotations `kustomize.toolkit.fluxcd.io/prune: disabled` and `kustomize.toolkit.fluxcd.io/substitute: disabled`, the service account `flux-system/sovereign-object` with exactly the rights of item 1, and one Job.
5. The Job is named `sovereign-object-${NETWORK_REGISTRY_REVISION:=bootstrap}`; the Kustomization substitutes only from the ConfigMap `sovereign-network-registry`, marked optional. So the writer runs at bootstrap (name `sovereign-object-bootstrap`, spec only) and again whenever the parent writes a new registry (new revision, new name; Flux creates the new Job and prunes the old one). The Job runs as UID 65534, read-only root file system, no privilege escalation, every capability dropped, `restartPolicy: Never`, `backoffLimit: 6`, and a failure policy that ends the Job on exit code 1.
6. The carrier of the registry is the step that already reads the OpenTofu state of the deployment at hand-over, `runPostHandoverAdoptionApply` of `products/catalyst/bootstrap/api/internal/handler/post_handover_adoption_apply.go`. Right after it read `terraform.tfstate` it calls `lifecycle.DeliverNetworkRegistry`, which takes the value of the output `network_registry`, builds the ConfigMap `flux-system/sovereign-network-registry` with the keys `NETWORK_REGISTRY_JSON` (the document as the module wrote it) and `NETWORK_REGISTRY_REVISION` (the first 12 hexadecimal digits of its SHA-256), and server-side-applies it under the field manager `catalyst-api/network-registry` into every cluster of the deployment that the parent's cluster cache holds (`k8scache.Factory`: the cluster `<deployment id>` first, then each `<deployment id>-<region key>`), with the cache's own dynamic client. So no new place of the API builds a client from a kubeconfig (`scripts/check-lifecycle-ratchets.sh`, `child_client_sites`, stays at 12). A region that fails does not stop the others; the result is one log line. The handler file does not grow: the lines it gains are taken from its own header comment, so `scripts/check-api-structure.py` keeps its baseline. New code goes in `internal/lifecycle`.
7. Nothing is added to the control-plane user data, the boot template or a provider module.
8. Gate check SOV-G17 is one file, `tests/acceptance/sovereign/internal/suite/check_sovereign_object.go`, registered in `init()`, one step `SOV-G17.<n>` per region, `kubectl get` only. A region fails when it has no Sovereign object, more than one, or one not named `sovereign-self`; when the field manager `sovereign-ops` wrote neither the object nor its status; when `spec.fqdn`, `spec.deploymentId` or `spec.provider` is absent or differs from `SOVEREIGN_FQDN`, `SOVEREIGN_DEPLOYMENT_ID`, `PROVIDER`, or the ConfigMap lacks that key; when the codes of `spec.regions` differ from the `cloudRegion` values of `SOVEREIGN_REGIONS_JSON`; when `sovereign-network-registry` is absent; or when `status.network` differs from its document. In `docs/ledger/gates.yaml` SOV-G17 moves from `state: not-built` to `state: required` and gains its `implementation` line; nothing else of the file changes.
9. After every image built on `main`, `.github/workflows/build-sovereign-ops.yaml` writes the image's short commit id into the one `newTag:` line of slot 12b and pushes it with the release-writer key through `./.github/actions/deploy-bump`; the step fails when it does not find exactly one such line.

+// Main runs sovereign-object against the cluster the Pod runs in. It takes

+func Main(ctx context.Context, args []string, _ io.Writer) ([]string, error) {
+	if len(args) != 0 {
+		return nil, errors.New("usage: sovereign-object")

+	}

+// apiServer talks to the Kubernetes API with the Pod's service account.
+type apiServer struct {
+	base, token string
+	client      *http.Client
+}
+
+func inCluster() (*apiServer, error) {
+	host, port := os.Getenv("KUBERNETES_SERVICE_HOST"), os.Getenv("KUBERNETES_SERVICE_PORT")
+	token, terr := os.ReadFile(serviceAccount + "/token")
+	ca, cerr := os.ReadFile(serviceAccount + "/ca.crt")
+	pool := x509.NewCertPool()
+	if host == "" || port == "" || terr != nil || cerr != nil || !pool.AppendCertsFromPEM(ca) {
+		return nil, errors.New("sovereign-object runs in a Pod of the region's cluster: no Kubernetes service address or service account")
+	}
+	tr := &http.Transport{TLSClientConfig: &tls.Config{RootCAs: pool, MinVersion: tls.VersionTLS12}}
+	return &apiServer{base: "https://" + net.JoinHostPort(host, port), token: strings.TrimSpace(string(token)),
+		client: &http.Client{Transport: tr, Timeout: 30 * time.Second}}, nil
+}
+
+// Get returns the object at path, nil when the API server answers 404.
+func (a *apiServer) Get(ctx context.Context, path string) (map[string]interface{}, error) {
+	code, body, err := a.do(ctx, http.MethodGet, path, "", nil)
+	if err != nil {
+		return nil, err
+	}
+	if code == http.StatusNotFound {
+		return nil, nil
+	}
+	if err := status("GET", path, code, body); err != nil {
+		return nil, err
+	}
+	// UseNumber keeps every number as the API server wrote it.
+	dec := json.NewDecoder(bytes.NewReader(body))
+	dec.UseNumber()
+	var obj map[string]interface{}
+	if err := dec.Decode(&obj); err != nil {
+		return nil, ops.Transient(fmt.Errorf("GET %s: %w", path, err))
+	}
+	return obj, nil
+}
+
+// Apply sends body as a server-side apply patch to path, under the field
+// manager sovereign-ops, taking over fields another manager holds. A 404 means
+// the kind is not served yet (its definition is still being installed), so
+// the caller may retry.
+func (a *apiServer) Apply(ctx context.Context, path string, body []byte) error {
+	q := url.Values{"fieldManager": {FieldManager}, "force": {"true"}}
+	code, out, err := a.do(ctx, http.MethodPatch, path+"?"+q.Encode(), "application/apply-patch+yaml", body)
+	if err != nil {
+		return err
+	}
+	if code == http.StatusNotFound {
+		return ops.Transient(fmt.Errorf("PATCH %s: HTTP 404, the Sovereign kind is not served yet", path))
+	}
+	return status("PATCH", path, code, out)
+}

+func (a *apiServer) do(ctx context.Context, method, path, contentType string, body []byte) (int, []byte, error) {
+	req, err := http.NewRequestWithContext(ctx, method, a.base+path, bytes.NewReader(body))
+	if err != nil {
+		return 0, nil, err
+	}
+	req.Header.Set("Authorization", "Bearer "+a.token)
+	req.Header.Set("Accept", "application/json")
+	if contentType != "" {
+		req.Header.Set("Content-Type", contentType)
+	}
+	resp, err := a.client.Do(req)
+	if err != nil {
+		return 0, nil, ops.Transient(err)
+	}
+	defer func() { _ = resp.Body.Close() }()
+	out, err := io.ReadAll(io.LimitReader(resp.Body, 4<<20))
+	if err != nil {
+		return 0, nil, ops.Transient(fmt.Errorf("%s %s: %w", method, path, err))
+	}
+	return resp.StatusCode, out, nil
+}

+// status turns an answer that is not 2xx into an error: 429 and 5xx may be
+// retried, every other code is a failure that names the API server's message.
+func status(method, path string, code int, body []byte) error {
+	if code >= 200 && code < 300 {
+		return nil
+	}
+	var st struct {
+		Message string `json:"message"`
+	}
+	_ = json.Unmarshal(body, &st)
+	err := fmt.Errorf("%s %s: HTTP %d %s", method, path, code, st.Message)
+	if code == http.StatusTooManyRequests || code >= 500 {
+		return ops.Transient(err)
+	}
+	return err
+}

+// Network decodes the registry document. Numbers keep their text, so the
+// document reaches the object unchanged.
+func Network(doc string) (map[string]interface{}, error) {
+	if strings.TrimSpace(doc) == "" {
+		return nil, errors.New("the key is absent or empty")
+	}
+	dec := json.NewDecoder(strings.NewReader(doc))
+	dec.UseNumber()
+	var v interface{}
+	if err := dec.Decode(&v); err != nil {
+		return nil, fmt.Errorf("not JSON: %w", err)
+	}
+	if dec.More() {
+		return nil, errors.New("more than one JSON value")
+	}
+	m, ok := v.(map[string]interface{})
+	if !ok {
+		return nil, errors.New("not a JSON object")
+	}
+	return m, nil
+}

+func specRegions(doc string) ([]interface{}, string) {
+	var list []map[string]interface{}
+	if err := json.Unmarshal([]byte(doc), &list); err != nil || len(list) == 0 {
+		return nil, "SOVEREIGN_REGIONS_JSON is not a JSON list of regions"
+	}
+	out := make([]interface{}, 0, len(list))
+	for i, r := range list {
+		code, _ := r["cloudRegion"].(string)
+		if code == "" {
+			return nil, fmt.Sprintf("entry %d of SOVEREIGN_REGIONS_JSON has no cloudRegion", i)
+		}
+		entry := map[string]interface{}{"code": code}
+		if p, _ := r["provider"].(string); p != "" {
+			entry["provider"] = p
+		}
+		out = append(out, entry)
+	}
+	return out, ""
+}

+func parentDomains(doc string) ([]interface{}, string) {
+	var list []map[string]interface{}
+	if err := yaml.Unmarshal([]byte(doc), &list); err != nil || len(list) == 0 {
+		return nil, "PARENT_DOMAINS_YAML is not a list of domains"
+	}
+	out := make([]interface{}, 0, len(list))
+	for i, d := range list {
+		name, _ := d["name"].(string)
+		role, _ := d["role"].(string)
+		if name == "" || !contains(roles, role) {
+			return nil, fmt.Sprintf("entry %d of PARENT_DOMAINS_YAML has no name or a role other than primary and org-pool", i)
+		}
+		out = append(out, map[string]interface{}{"name": name, "role": role})
+	}
+	return out, ""
+}

+// written lists the spec fields in a fixed order, with the count of a list.
+func written(spec map[string]interface{}) []string {
+	var out []string
+	for _, f := range []string{"fqdn", "deploymentId", "provider", "bcpTopology", "regions", "parentDomains"} {
+		switch v := spec[f].(type) {
+		case nil:
+		case []interface{}:
+			out = append(out, fmt.Sprintf("%s (%d)", f, len(v)))
+		default:
+			out = append(out, f)
+		}
+	}
+	return out
+}

+func apply(ctx context.Context, c Cluster, path string, obj map[string]interface{}) error {
+	var b bytes.Buffer
+	enc := json.NewEncoder(&b)
+	enc.SetEscapeHTML(false)
+	if err := enc.Encode(obj); err != nil {
+		return err
+	}
+	return c.Apply(ctx, path, b.Bytes())
+}

+func stringData(cm map[string]interface{}) map[string]string {
+	out := map[string]string{}
+	d, _ := cm["data"].(map[string]interface{})
+	for k, v := range d {
+		if s, ok := v.(string); ok {
+			out[k] = s
+		}
+	}
+	return out
+}

+func contains(list []string, v string) bool {
+	for _, x := range list {
+		if x == v {
+			return true
+		}
+	}
+	return false

+// The output network_registry of the provider module exists only in the
+// OpenTofu state of the deployment, on the parent. When a deployment is handed
+// over, the step that applies the adoption claims from that state (handler file

+// ErrNoNetworkRegistry: the state was written by a module without the output.
+var ErrNoNetworkRegistry = errors.New("the OpenTofu state holds no output network_registry")

+// NetworkRegistryFromState returns the value of the output network_registry of
+// an OpenTofu state file: the registry as JSON text, exactly as the module
+// wrote it.
+func NetworkRegistryFromState(state []byte) (string, error) {
+	var st struct {
+		Outputs map[string]struct {
+			Value json.RawMessage `json:"value"`
+		} `json:"outputs"`
+	}
+	if err := json.Unmarshal(state, &st); err != nil {
+		return "", fmt.Errorf("read the OpenTofu state: %w", err)
+	}
+	out, ok := st.Outputs["network_registry"]
+	if !ok {
+		return "", ErrNoNetworkRegistry
+	}
+	var doc string
+	if err := json.Unmarshal(out.Value, &doc); err != nil {
+		return "", fmt.Errorf("output network_registry is not a string: %w", err)
+	}
+	var obj map[string]any
+	if err := json.Unmarshal([]byte(doc), &obj); err != nil {
+		return "", fmt.Errorf("output network_registry is not a JSON object: %w", err)
+	}
+	return doc, nil

+// NetworkRegistryConfigMap returns the ConfigMap that carries registry. The
+// revision is the first 12 hexadecimal digits of the SHA-256 of the document.
+func NetworkRegistryConfigMap(registry string) *unstructured.Unstructured {
+	sum := sha256.Sum256([]byte(registry))
+	return &unstructured.Unstructured{Object: map[string]any{
+		"apiVersion": "v1",
+		"kind":       "ConfigMap",
+		"metadata": map[string]any{
+			"name":      NetworkRegistryName,
+			"namespace": NetworkRegistryNamespace,
+			"labels":    map[string]any{"app.kubernetes.io/managed-by": "catalyst-api"},
+		},
+		"data": map[string]any{
+			NetworkRegistryKey:         registry,
+			NetworkRegistryRevisionKey: hex.EncodeToString(sum[:])[:12],
+		},
+	}}

+// Clusters is the part of the parent's cluster cache (k8scache.Factory) that
+// the delivery uses: the registered cluster ids and the dynamic client of one.
+type Clusters interface {
+	Clusters() []string
+	DynamicClientFor(clusterID string) (dynamic.Interface, error)
+}

+// NetworkRegistryClusters returns the clusters of the deployment among ids:
+// <deploymentID> first, then each <deploymentID>-<regionKey> by name.
+func NetworkRegistryClusters(ids []string, deploymentID string) []string {
+	if deploymentID == "" {
+		return nil
+	}
+	var primary, others []string
+	for _, id := range ids {
+		switch {
+		case id == deploymentID:
+			primary = append(primary, id)
+		case strings.HasPrefix(id, deploymentID+"-") && len(id) > len(deploymentID)+1:
+			others = append(others, id)
+		}
+	}
+	sort.Strings(others)
+	return append(primary, others...)
+}

+// ApplyFunc writes cm with the dynamic client of one cluster.
+type ApplyFunc func(ctx context.Context, dyn dynamic.Interface, cm *unstructured.Unstructured) error
+
+// DeliverNetworkRegistry reads the registry from state and writes its
+// ConfigMap into every cluster of the deployment that clusters holds. It
+// returns one line per cluster, "<cluster id>: <result>", for the log. A
+// cluster that fails does not stop the others.
+func DeliverNetworkRegistry(ctx context.Context, state []byte, deploymentID string, clusters Clusters, apply ApplyFunc) []string {
+	registry, err := NetworkRegistryFromState(state)
+	if err != nil {
+		return []string{"not delivered: " + err.Error()}
+	}
+	if clusters == nil || (reflect.ValueOf(clusters).Kind() == reflect.Ptr && reflect.ValueOf(clusters).IsNil()) {
+		return []string{"not delivered: the parent has no cluster cache"}
+	}
+	ids := NetworkRegistryClusters(clusters.Clusters(), deploymentID)
+	if len(ids) == 0 {
+		return []string{"not delivered: the cluster cache holds no cluster of deployment " + deploymentID}
+	}
+	cm := NetworkRegistryConfigMap(registry)
+	rev := cm.Object["data"].(map[string]any)[NetworkRegistryRevisionKey]
+	out := make([]string, 0, len(ids))
+	for _, id := range ids {
+		dyn, err := clusters.DynamicClientFor(id)
+		if err == nil {
+			err = apply(ctx, dyn, cm.DeepCopy())
+		}
+		if err != nil {
+			out = append(out, fmt.Sprintf("%s: %v", id, err))
+			continue
+		}
+		out = append(out, fmt.Sprintf("%s: revision %s", id, rev))
+	}
+	return out
+}

+// ApplyConfigMap server-side-applies cm with dyn.
+func ApplyConfigMap(ctx context.Context, dyn dynamic.Interface, cm *unstructured.Unstructured) error {
+	body, err := cm.MarshalJSON()
+	if err != nil {
+		return err
+	}
+	force := true
+	_, err = dyn.Resource(schema.GroupVersionResource{Version: "v1", Resource: "configmaps"}).Namespace(cm.GetNamespace()).
+		Patch(ctx, cm.GetName(), types.ApplyPatchType, body, metav1.PatchOptions{FieldManager: networkRegistryManager, Force: &force})
+	return err
+}

+def subst(text, values):
+    text = text.replace("$$", "\0")
+    for _ in range(5):
+        def one(m):
+            name, op, default = m.group(1), m.group(2), m.group(3)
+            v = values.get(name)
+            if op in (":=", ":-"):
+                return v if v else default
+            if op in ("=", "-"):
+                return v if v is not None else default
+            return v or ""
+        new = VAR.sub(one, text)
+        if new == text:
+            break
+        text = new
+    return text.replace("\0", "$")

+func sovereignObjectRegion(ctx context.Context, region kube.Region, ev Evidence) error {
+	objects, err := region.GetList(ctx, networkRegistryKind, "", "--show-managed-fields")
+	if err != nil {
+		return err
+	}
+	names := make([]string, 0, len(objects))
+	for _, o := range objects {
+		names = append(names, o.Name())

+	if len(objects) != 1 || objects[0].Name() != sovereignObjectName {
+		return fmt.Errorf("region %s has the Sovereign objects [%s], want exactly [%s]", region.ID, strings.Join(names, " "), sovereignObjectName)
+	}

+	}

+		want = append(want, s)
+	}

+		got = append(got, r.Str("code"))
+	}
+	compared["regions"] = got
+	if len(list) > 0 && !reflect.DeepEqual(got, want) {
+		failures = append(failures, fmt.Sprintf("the codes of spec.regions are [%s], the cloudRegion values of SOVEREIGN_REGIONS_JSON are [%s]",

+	}

+	if len(failures) > 0 {

+	}
+	return nil

+func sovereignObjectHas(list []string, v string) bool {
+	for _, x := range list {

+		}

+// sovereignObjectStrings returns the string values of a JSON object.

+		if s, ok := x.(string); ok {

+		}
+	}
