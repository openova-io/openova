# CLD-094 — Standing check CLD-G12: the plan of a provisioned deployment shows no change

## In plain words

**The problem today.** Nothing checks that the infrastructure of a running deployment still matches the code that would provision it today. A change to a cloud module, or to the code that writes the module's variables, can plan to replace or rewrite live resources, and nobody sees it until someone applies it. A read-only plan of the standing environment showed dozens of planned changes that no gate run reported.

**What changes.** Every gate run makes a plan of the deployment it tests, with the module and the variables code of the commit under test, on a copy of the deployment's working directory. Any planned change fails the run and is listed in the gate record.

**Done means:**

- A gate run records the zero-change check for the deployment it tested, with each planned change listed by resource address and action.
- A plan without changes passes the check; a planned change, a failed plan or a step that could not run fails it.
- The check is required, so a gate record that holds a planned change has the result FAIL.
- The check changes nothing of the deployment: its working directory, state and record stay as they were, and no credential or value leaves the engine Pod.
- The variables file is written by the engine's own code from the deployment record, and a test proves that for an unchanged deployment it is the same file, byte for byte.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every gate run on a Sovereign makes, inside the engine Pod of the parent that provisioned it, an OpenTofu plan of the deployment: on a copy of the deployment's working directory, with the module of the commit under test staged as the engine stages it and the variables file written again from the deployment record by the engine code of that commit. Gate check CLD-G12 passes only when the plan exits 0 with `No changes.`. Any planned change is a FAIL whose reason names the counts and whose evidence lists every planned action by address; it is never subtracted, filtered or explained away. The check is `required`, so such a record has the result FAIL. The result is merged into the gate record by `scripts/acceptance-gate.py merge-check`, the way the sign-in check FND-G07 is.

## 3. The model (the law)
1. CLD-G12 is PASS only when all four steps end with exit code 0 and the plan step printed `No changes.`: `copy`, `regenerate`, `init`, `plan`. Exit code 2 of `tofu plan -detailed-exitcode` is FAIL with the `Plan:` line as reason and every `  # <address> will be|must be <action>` line as evidence. There is no baseline, no ignore list and no comparison with another plan.
2. Where it runs. The gate runner holds only the two kubeconfigs of the Sovereign; the deployment's working directory, its record and the cloud credentials are on the volume of the parent's engine, which runs `tofu` itself. So the check runs inside that Pod with `kubectl exec` (namespace `catalyst`, target `deploy/catalyst-api`), with a kubeconfig of the parent from the new secret `ACCEPTANCE_PARENT_KUBECONFIG` of the environment `gate`. This follows the sign-in check FND-G07 of the same job, which reads the identity provider's administrator password from that Pod's own mount so that it never leaves the Pod.
3. What is planned. `<CATALYST_TOFU_WORKDIR>/<id>` (default `/var/lib/catalyst/tofu/<id>`) is copied into a temporary directory of the Pod, everything but `.terraform`: the state, the lock file and the kept variables file come along. The copy's `*.tf` and `*.tftpl` files, and those of `seal/`, are removed; the module `infra/providers/<provider>/` of the commit under test is staged in their place the way `stageModule` stages it (its `*.tf` and `*.tftpl` files, those of `seal/`, and `infra/providers/_shared` beside the copy). The provider is the record's `request.provider`.
4. The variables file. `tfvars-regenerate -record <record> -dir <copy>`, built from the commit under test, rebuilds the request from the record `<CATALYST_DEPLOYMENTS_DIR>/<id>.json` with `store.RedactedRequest.ToProvisionerRequest`. A record holds no credential and not every field of the request; those fields are read from the kept variables file under the key that `writeTfvars` writes each one to, the way `internal/handler/wipe.go` reads the cloud credentials back from it. The fields that are not credentials are named with their keys in type `kept` of the command. No credential and no provider is named: a string field of the request that does not come back through `store.Redact` and the record is a credential, and its key is the one that holds its probe value in a probe file that `writeTfvars` writes for the request (function `credentialKeys`). The request is validated as `Provision` validates it and written with `provisioner.WriteTfvars`, a new exported wrapper of `writeTfvars`. The values the engine takes from its environment come from the Pod's environment, which is the engine's. The command prints only the names of the top-level keys that differ from the kept file.
5. Nothing of the deployment is written. Every step works on the copy; `tofu plan` runs with `-lock=false`; the copy is removed when the remote part ends. The provider plugin cache of the engine is used as the engine uses it. Only these lines leave the Pod: the step markers, the changed key names, the lines with `Error: ` (from the text `Error: ` on), the action lines and the `Plan:` or `No changes.` line. No value leaves it.
6. A missing measurement is never a pass. The secret not set, no deployment id, the Pod not reached, no record, no working directory, no module of the provider, a build failure, a step that did not start or did not finish: each is FAIL with the reason. `init` may take 15 minutes and `plan` 30 minutes at most.
7. CLD-G12 is `required` with `implementation: scripts/check-zero-change-plan.sh`. `merge-check` then sets the record's result to FAIL when CLD-G12 fails (pass rule 5 of the gate tool).
8. The workflow step never fails the job: it writes the result file, or leaves it missing, and `merge-check` records it. It runs after the step that adds FND-G07 and before the step `Validate the record`, only when the suite measured the Sovereign.
9. The deployment id is the input `deployment_id` of the workflow, or else the field `deployment_id` of the record the suite wrote.

    "copy": "copy the working directory and stage the module of the commit under test",

        if raw.strip():
            other.append(raw.strip())
        continue

        aborts.append(rest)

        if len(p) == 3 and p[0] in ORDER and re.match(r"^[0-9]+$", p[1]):
            ended[p[0]] = (int(p[1]), p[2])

            said.setdefault(p[0], []).append(p[1] if len(p) > 1 else "")

def ms(a, b):
    try:
        f = "%Y-%m-%dT%H:%M:%SZ"
        return max(0, int((datetime.datetime.strptime(b, f) - datetime.datetime.strptime(a, f)).total_seconds() * 1000))
    except ValueError:
        return 0

def stamp(v):
    return v if re.match(r"^\d{4}-\d\d-\d\dT\d\d:\d\d:\d\dZ$", v or "") else now

steps = []
def add(sid, status, start, finish, error=None, evidence=None):

        st["error"] = error[:4000]
    if evidence:
        st["evidence"] = evidence
    steps.append(st)

    add("reach", "FAIL", now, now, "no step of the check ran: " + why)

        if steps and steps[-1]["status"] == "PASS":
            add(sid, "FAIL", now, now, "the step did not start")
        break

    lines = said.get(sid, [])
    if sid not in ended:
        add(sid, "FAIL", start, now, "the step did not finish" + (": " + "; ".join(lines[-5:]) if lines else ""))
        break

        errs = [l for l in lines if l.startswith("Error: ")]

            add(sid, "FAIL", start, finish, "tofu plan exited 0 without the line No changes.")

            add(sid, "FAIL", start, finish, "the plan shows changes: " + (summary[0] if summary else "no Plan line was printed"),

// Command tfvars-regenerate writes the variables file of a deployment again
// from its record, with the engine's own code (work package CLD-094, gate
// check CLD-G12).
//
// Usage: tfvars-regenerate -record <deployment record> -dir <working directory>
//
// The record is the deployment's <id>.json in the engine's deployments
// directory. The directory holds tofu.auto.tfvars.json, the variables file the
// deployment was last applied with (the kept file). The file is written again
// in place, so give the command a copy of the working directory.
//
// The request is the record's: every field that the record holds comes from
// it. A record holds no credential and not every field of the request; those
// fields are read from the kept file, under the key that writeTfvars writes
// each one to, the way the wipe reads the cloud credentials back from it. The
// fields that are not credentials are named in type kept below, with their
// keys. The credentials are not named: a string field that the record does
// not give back is one, and its key is found by writing a probe file with
// writeTfvars (see credentials). The request is then validated, as Provision
// validates it, and provisioner.WriteTfvars writes the file. The values that
// writeTfvars reads from the environment (the parent address, the repository
// address, and the branch and the address lists when the kept file has none)
// come from this process's environment: run the command where the engine runs.
//
// Standard output gets one line per top-level key whose value differs from the
// kept file, sorted: "changed <key>", "added <key>" or "removed <key>". No
// value is printed, because the file holds credentials. Exit codes: 0 the file
// was written; 2 usage error, or the record or the kept file cannot be read;
// 3 the engine refused the request or could not write the file.
package main

import (
	"encoding/json"
	"flag"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"reflect"
	"sort"
	"strconv"
	"strings"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/provisioner"
	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/store"
)

// tfvarsName is the variables file of a working directory.
const tfvarsName = "tofu.auto.tfvars.json"

// kept holds the request fields that a deployment record does not hold and
// that are not credentials, under the keys of the variables file that
// writeTfvars writes them to. A field of kept that is a string has the name of
// its request field, so that credentials leaves it alone. The test
// TestRoundTrip fails when a field of the request is missing here.
type kept struct {
	BcpTopology         string         `json:"bcp_topology"`
	AdminCIDRs          []string       `json:"admin_cidrs"`
	ConsoleIsolation    string         `json:"console_isolation_enabled"`
	SharedPostgres      string         `json:"enable_shared_pg"`
	QATest              string         `json:"qa_test_session_enabled"`
	QAFixturesNamespace string         `json:"qa_fixtures_namespace"`
	QAOrganization      string         `json:"qa_organization"`
	ClusterMeshName     string         `json:"cluster_mesh_name"`
	ClusterMeshID       int            `json:"cluster_mesh_id"`
	GitopsBranch        string         `json:"gitops_branch"`
	Variables           map[string]any `json:"variables"`
}

func main() {
	os.Exit(run(os.Args[1:], os.Stdout, os.Stderr))
}

func run(args []string, stdout, stderr io.Writer) int {
	fail := func(code int, format string, a ...any) int {
		_, _ = fmt.Fprintf(stderr, "tfvars-regenerate: "+format+"\n", a...)
		return code
	}
	fs := flag.NewFlagSet("tfvars-regenerate", flag.ContinueOnError)
	fs.SetOutput(stderr)
	recordPath := fs.String("record", "", "the deployment record, <id>.json of the deployments directory")
	dir := fs.String("dir", "", "a copy of the deployment's working directory, holding "+tfvarsName)
	if err := fs.Parse(args); err != nil {
		return 2
	}
	if *recordPath == "" || *dir == "" || fs.NArg() != 0 {
		return fail(2, "usage: tfvars-regenerate -record <deployment record> -dir <working directory>")
	}
	var rec store.Record
	if err := readJSON(*recordPath, &rec); err != nil {
		return fail(2, "record: %v", err)
	}
	if strings.TrimSpace(rec.ID) == "" {
		return fail(2, "record: %s has no id", *recordPath)
	}
	path := filepath.Join(*dir, tfvarsName)
	var before map[string]any
	if err := readJSON(path, &before); err != nil {
		return fail(2, "kept file: %v", err)
	}
	var k kept
	if err := readJSON(path, &k); err != nil {
		return fail(2, "kept file: %v", err)
	}
	req := fromRecord(rec)
	fill(&req, k)
	if err := credentials(&req, before); err != nil {
		return fail(3, "find the keys of the credentials: %v", err)
	}
	if err := req.Validate(); err != nil {
		return fail(3, "the engine refuses the request of the record: %v", err)
	}
	if err := provisioner.WriteTfvars(*dir, req); err != nil {
		return fail(3, "write %s: %v", path, err)
	}
	var after map[string]any
	if err := readJSON(path, &after); err != nil {
		return fail(3, "read the written file again: %v", err)
	}
	for _, line := range differences(before, after) {
		_, _ = fmt.Fprintln(stdout, line)
	}
	return 0
}

// fromRecord is the request that a record gives back.
func fromRecord(rec store.Record) provisioner.Request {
	req := rec.Request.ToProvisionerRequest()
	req.DeploymentID = rec.ID
	return req
}

// fill sets on req the fields of type kept, from the kept file.
func fill(req *provisioner.Request, k kept) {
	req.BcpTopology = k.BcpTopology
	req.AdminCIDRs = k.AdminCIDRs
	if k.ConsoleIsolation != "" {
		on := k.ConsoleIsolation == "true"
		req.ConsoleIsolationEnabled = &on
	}
	req.EnableSharedPostgres = k.SharedPostgres == "true"
	req.QATestEnabled = k.QATest == "true"
	req.QAFixturesNamespace, req.QAOrganization = k.QAFixturesNamespace, k.QAOrganization
	req.ClusterMeshName, req.ClusterMeshID = k.ClusterMeshName, k.ClusterMeshID
	req.GitopsBranch = k.GitopsBranch
	if auto, ok := k.Variables["HANDOVER_AUTO"].(string); ok && auto != "" {
		on := auto == "true"
		req.FireCutoverOnHandover = &on
	}
}

// credentials sets on req every credential from the kept file, under the key
// that credentialKeys finds for it. A credential is always the kept file's:
// the record holds none, only the marker of a redacted value. A field that
// writeTfvars does not write for this request keeps the record's value.
func credentials(req *provisioner.Request, file map[string]any) error {
	keys, err := credentialKeys(*req)
	if err != nil {
		return err
	}
	rv := reflect.ValueOf(req).Elem()
	for i, key := range keys {
		s, _ := file[key].(string)
		rv.Field(i).SetString(s)
	}
	return nil
}

// credentialKeys returns, by field index, the key of the variables file that
// writeTfvars writes each credential of req to. The credentials are the
// fields that unheld returns. Each is given a probe value of its own,
// writeTfvars writes a probe file for the request in a temporary directory,
// and the top-level key that holds the probe value of a field is its key (the
// first in sorted order, when several hold it). The probe file holds no
// credential, because a probe value stands in for each one, and it is removed.
func credentialKeys(req provisioner.Request) (map[int]string, error) {
	fields := unheld()
	pv := reflect.ValueOf(&req).Elem()
	for _, i := range fields {
		pv.Field(i).SetString(probeValue(i))
	}
	tmp, err := os.MkdirTemp("", "tfvars-regenerate-")
	if err != nil {
		return nil, err
	}
	defer func() { _ = os.RemoveAll(tmp) }()
	if err := provisioner.WriteTfvars(tmp, req); err != nil {
		return nil, err
	}
	var written map[string]any
	if err := readJSON(filepath.Join(tmp, tfvarsName), &written); err != nil {
		return nil, err
	}
	keyOf := map[string]string{} // probe value -> key
	for key, value := range written {
		if s, ok := value.(string); ok {
			if old, seen := keyOf[s]; !seen || key < old {
				keyOf[s] = key
			}
		}
	}
	out := map[int]string{}
	for _, i := range fields {
		if key, ok := keyOf[probeValue(i)]; ok {
			out[i] = key
		}
	}
	return out, nil
}

// unheld returns the indexes of the string fields of the request that a
// record does not give back and that type kept does not name: a request with
// each of them set loses the value through store.Redact and fromRecord,
// because the record holds the field redacted or not at all.
func unheld() []int {
	named := map[string]bool{}
	kt := reflect.TypeOf(kept{})
	for i := 0; i < kt.NumField(); i++ {
		named[kt.Field(i).Name] = true
	}
	t := reflect.TypeOf(provisioner.Request{})
	var full provisioner.Request
	fv := reflect.ValueOf(&full).Elem()
	var strs []int
	for i := 0; i < t.NumField(); i++ {
		if f := t.Field(i); f.IsExported() && f.Type.Kind() == reflect.String && !named[f.Name] {
			fv.Field(i).SetString(probeValue(i))
			strs = append(strs, i)
		}
	}
	back := reflect.ValueOf(fromRecord(store.Record{ID: full.DeploymentID, Request: store.Redact(full)}))
	var out []int
	for _, i := range strs {
		if back.Field(i).String() != fv.Field(i).String() {
			out = append(out, i)
		}
	}
	return out
}

// probeValue is the value that field i of the request carries in a probe.
func probeValue(i int) string {
	return "tfvars-regenerate-probe-" + strconv.Itoa(i)
}

// differences names the top-level keys whose value differs between the kept
// file and the written one, sorted.
func differences(before, after map[string]any) []string {
	var out []string
	for key, value := range after {
		old, ok := before[key]
		switch {
		case !ok:
			out = append(out, "added "+key)
		case !reflect.DeepEqual(old, value):
			out = append(out, "changed "+key)
		}
	}
	for key := range before {
		if _, ok := after[key]; !ok {
			out = append(out, "removed "+key)
		}
	}
	sort.Slice(out, func(i, j int) bool {
		return strings.SplitN(out[i], " ", 2)[1] < strings.SplitN(out[j], " ", 2)[1]
	})
	return out
}

func readJSON(path string, into any) error {
	raw, err := os.ReadFile(filepath.Clean(path))
	if err != nil {
		return err
	}
	if err := json.Unmarshal(raw, into); err != nil {
		return fmt.Errorf("%s is not the expected JSON: %v", path, err)
	}
	return nil
}

// TestEveryKeptFieldMatters: blanking any one field of the kept file that
// the command reads (a field of type kept or a credential that the file
// holds) changes the file written again, so none of them is dead and the
// round trip above really covers each one.
func TestEveryKeptFieldMatters(t *testing.T) {
	pinEnv(t)
	req := request("huawei")
	recordPath, work := deployment(t, req)
	path := filepath.Join(work, tfvarsName)
	original := readFile(t, path)
	var doc map[string]any
	if err := json.Unmarshal(original, &doc); err != nil {
		t.Fatalf("decode the kept file: %v", err)
	}
	keys := map[string]any{}
	raw, _ := json.Marshal(kept{})
	_ = json.Unmarshal(raw, &keys)
	_ = req.Validate()
	creds, err := credentialKeys(req)
	if err != nil {
		t.Fatalf("credentialKeys: %v", err)
	}
	for _, key := range creds {
		// A credential that this file leaves empty cannot change the result
		// (the hetzner round trip covers its token), so only the others are tried.
		if s, _ := doc[key].(string); s != "" {
			keys[key] = nil
		}
	}
	for key := range keys {
		t.Run(key, func(t *testing.T) {
			changed := map[string]any{}
			for k, v := range doc {
				changed[k] = v
			}
			if key == "variables" {
				vars := map[string]any{}
				for k, v := range doc["variables"].(map[string]any) {
					vars[k] = v
				}
				vars["HANDOVER_AUTO"] = "true"
				changed[key] = vars
			} else {
				delete(changed, key)
			}
			body, _ := json.Marshal(changed)
			if err := os.WriteFile(path, body, 0o600); err != nil {
				t.Fatalf("write: %v", err)
			}
			// The field matters when the engine refuses the request without it (exit
			// code 3) or writes another file.
			var stdout, stderr bytes.Buffer
			code := run([]string{"-record", recordPath, "-dir", work}, &stdout, &stderr)
			if code != 0 && code != 3 {
				t.Fatalf("exit code %d, stderr: %s", code, stderr.String())
			}
			if code == 0 && bytes.Equal(readFile(t, path), original) {
				t.Errorf("without %s in the kept file the command still wrote the original file", key)
			}
		})
	}
}

// TestReportsWhatTheRecordChanges: a record that differs from the kept file

func TestReportsWhatTheRecordChanges(t *testing.T) {

// TestRefusals: what the command cannot read is exit code 2, what the engine
// refuses is exit code 3, and neither is ever a written file.
func TestRefusals(t *testing.T) {
	pinEnv(t)
	recordPath, work := deployment(t, request("huawei"))
	empty := t.TempDir()
	badRecord := filepath.Join(t.TempDir(), "bad.json")
	if err := os.WriteFile(badRecord, []byte(`{"id": "", "request": {}}`), 0o600); err != nil {
		t.Fatal(err)
	}
	refused := request("huawei")
	refused.Regions[0].ControlPlaneSize = ""
	refusedRecord := filepath.Join(t.TempDir(), "refused.json")
	raw, _ := json.Marshal(store.Record{ID: "fedcba9876543210", Request: store.Redact(refused)})
	if err := os.WriteFile(refusedRecord, raw, 0o600); err != nil {
		t.Fatal(err)
	}
	for _, c := range []struct {
		name string
		args []string
		code int
	}{
		{"no arguments", nil, 2},
		{"no directory", []string{"-record", recordPath}, 2},
		{"a stray argument", []string{"-record", recordPath, "-dir", work, "x"}, 2},
		{"no record file", []string{"-record", filepath.Join(empty, "none.json"), "-dir", work}, 2},
		{"a record without an id", []string{"-record", badRecord, "-dir", work}, 2},
		{"no kept file", []string{"-record", recordPath, "-dir", empty}, 2},
		{"a request the engine refuses", []string{"-record", refusedRecord, "-dir", work}, 3},
	} {
		t.Run(c.name, func(t *testing.T) {
			var stdout, stderr bytes.Buffer
			if code := run(c.args, &stdout, &stderr); code != c.code {
				t.Errorf("exit code %d, want %d; stderr: %s", code, c.code, stderr.String())
			}
		})
	}
	if _, err := os.Stat(filepath.Join(empty, tfvarsName)); err == nil {
		t.Errorf("a refused run wrote a variables file")
	}
}
