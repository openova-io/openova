# AIP-158 — The purchase funnel's install path wires no long-lived bearer

## In plain words

**The problem today.** Since AIP-157 the BSS door no longer points an Organization's agent workspace at the Secret and the secret-store path of the year-long bearer that nothing mints any more. The purchase funnel, the second door that installs the agent workspace for an Organization bought in the storefront, still writes that wiring, and its test still demands it. The two doors disagree again, and the agent-plane guard still counts the funnel file as one that names the bearer.

**What changes.** The funnel writes only the Organization tenant host for the agent workspace's tool server, like the BSS door. Its test asserts that no file of a purchased Organization names the bearer wiring, and the agent-plane guard's stored count goes down by one.

**Done means:**

- An agent workspace installed for a purchased Organization carries the Organization console host for its tool server and no bearer Secret, verify-key Secret or secret-store path of a bearer.
- No other file the funnel writes for that Organization names the bearer wiring.
- A change that wires the bearer into the funnel again turns its test red.
- The agent-plane guard passes with its stored count lowered by its own tool, and no longer lists the funnel file.

The rest of this ticket is the exact instruction for the model that does the work.
