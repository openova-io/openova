# CMP-043 — CMP-G03 is required in the conformance pack

## In plain words

**The problem today.** The hermetic test pack runs the compliance-model check as expected to fail, a marking under which it may fail without turning a change red. The marking was set while the pack ran an API image without the model loader. That image is pinned on main now and the check passes in the pack, so the marking no longer marks a known gap: it would hide a regression.

**What changes.** The check is required in the test pack, as it is on the gate of a Sovereign: a change that breaks the model, the policies or the API's scoring turns its conformance run red. The pack's list of held checks stays, with no check in it, for a later check that proves a change to a pinned image.

**Done means:**

- The pack's list of checks held at expected-fail names no line for CMP-G03.
- A run of the acceptance suite in local, with the manifest and the list of the tree, prints no hold for CMP-G03 and runs it as required.
- The conformance run of the pull request reports CMP-G03 PASS (required), and the result of its gate suite is PASS.
- A run in cloud or in self is not changed, and CMP-G03 stays required on the gate.
