# SEC-192 — Producer identities and the simulation back end's own-path role

## In plain words

**The problem today.** A party that must put a value into another namespace's store of mounted values has no identity for it. The only way today is a broad grant that would also read every value it writes. The simulation back end has no role to read its own model credential or to write a refreshed one back.

**What changes.** Each producer gets its own identity that may write and update values only on listed paths and can never read them. The simulation back end gets one role that reads and writes its own model-credential path and nothing else.

**Done means:**

- The control-plane API writes a value into a listed path of another namespace and cannot read that value back.
- A pod of the namespace the value was written for reads it.
- The control-plane API reads a robot token it wrote only under its own service-account path, through its own workload identity.
- The simulation back end reads its model credential, writes it back, and reaches no other path.
- A producer entry with a path outside the store's path grammar, a bad or repeated name, no paths or no service account stops the chart from rendering.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The desired state of the bp-openbao configuration reconciler (ConfigMap `openbao-config-desired`, `platform/openbao/chart/templates/_config.tpl`) carries one policy and one Kubernetes auth role named `producer-<name>` for each entry of the new value `producers`, and the policy and role `axon-credential`. A producer creates and updates values on its listed patterns below `mounted/data/` and reads and deletes their metadata; it never reads a value (ADR-0018 S20). The default entry `catalyst-api` binds the service account the catalyst-api Deployment runs as. The simulation back end (service account `axon` of namespace `axon`) creates, updates and reads its own model-credential path and nothing else, which is the one named exception of ADR-0018 S20.

## 3. The model (the law)
1. **Value.** New value `producers` in `platform/openbao/chart/values.yaml`: a list of entries `{name, serviceAccount, namespace, paths}`. `name` matches `[a-z0-9-]+` and is unique; `serviceAccount` and `namespace` are DNS labels; `paths` is not empty. Each pattern is `<ns>/sa/<sa>/<name>...` or `<ns>/shared/<name>...`, where `+` stands for one segment, and ends in `<name>*`, `<name>/*` or `<name>/e<epoch>`. Any other pattern, a bad or repeated name, an entry without paths or without a service account and namespace fails the render, each with its own message.
2. **Producer policy.** For each entry one op `write sys/policies/acl/producer-<name>`; for each pattern `P`, in list order, exactly `path "mounted/data/P"` with capabilities `["create", "update"]` and `path "mounted/metadata/P"` with `["read", "delete"]`. No `read` on a data path.
3. **Producer role.** For each entry one op `write auth/<kubernetesAuth.mountPath>/role/producer-<name>` binding `serviceAccount` in `namespace`, audience `openbao`, policies `["producer-<name>"]`, `ttl` 15m, `max_ttl` 1h.
4. **axon-credential.** Always rendered: policy `axon-credential` with create, update and read on `mounted/data/axon/sa/axon/model-credential/*` and read on `mounted/metadata/axon/sa/axon/model-credential/*`; role `axon-credential` binding `axon` in `axon`, audience `openbao`, `ttl` 15m, `max_ttl` 15m. No delete. This is the role and the path that `products/axon/src/config.ts` lines 83 and 84 already name.
5. **Default entry.** `catalyst-api`, service account `catalyst-api-cutover-driver` (the account the Deployment runs as, `products/catalyst/chart/templates/api-deployment.yaml` line 179), namespace `catalyst-system` (the target namespace of `clusters/_template/bootstrap-kit/13-bp-catalyst-platform.yaml` line 65), patterns `catalyst-system/sa/catalyst-api-cutover-driver/gitea-robot-*`, `axon/sa/axon/model-credential/*`, `+/shared/enrol-*`, `vm-migration-system/sa/vm-migration-worker/source-*`, `+/shared/user-*`. A list set in the values replaces the default; an empty list renders no producer and keeps `axon-credential`.
6. **Read-back.** catalyst-api reads a value back only under its own service-account subtree, through policy `workload` (SEC-190); its producer policy never reads.
7. **Order.** The producer policies and then `axon-credential` come after every existing policy op; their roles come after every existing role. The reconciler file `files/openbao-config-reconcile.sh` does not change.
8. **Tests.** `config-desired-render.sh` gains case C8 (shell, yq and jq; no line of Python); `tests/e2e/bp-openbao-config-live.sh` gains case L9. No chart version changes; the release writer bumps it after the merge.
