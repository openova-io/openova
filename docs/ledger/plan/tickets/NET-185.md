# NET-185 — The Sovereign's name servers answer on public port 53, over UDP and TCP, in every region

## In plain words

**The problem today.** A zone can only be delegated to the Sovereign's own name servers once they answer from the internet. On the reference cloud nothing answers on public port 53: the security group does not admit it and the DNS front door that binds the node's port is switched off there. The node's own resolver also sits on a loopback port 53 that the network layer would hand to that front door once it is on, so the node's lookups would fail whenever the DNS Pod is down.

**What changes.** Each region's control-plane address answers DNS on port 53 over UDP and TCP, served by the DNS front door's host port on every node, with no node port. The node's own resolver stops listening on the loopback stub before the cluster starts and asks the network's servers directly. A new required gate check asks each region's address over UDP and TCP and refuses an open resolver.

**Done means:**

- On the reference cloud each region's security group admits port 53 over UDP and over TCP from every source, and the module test proves both rules for two regions.
- The DNS front door runs as the DaemonSet with host port 53 on every node of the reference cloud, as on the second provider and the local pack; no Service of type NodePort and no node-port listener is added.
- On every node of both cloud packs where systemd-resolved runs, it no longer listens on 127.0.0.53 before k3s starts, and /etc/resolv.conf names the network's own servers; the start-up data of every node role stays under its size limit.
- Gate check NET-G19 is required: it fails when a region's control-plane address gives no reply over UDP or over TCP within 5 seconds, when a reply offers recursion, when a name outside the Sovereign's zones gets an answer record, and when a region has no public control-plane address (not measured).
- The gate run's network policy lets the suite reach UDP 53 and TCP 53 of the install's addresses, beside TCP 6443 and 443.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
On every provider the Sovereign's name servers answer DNS on public port 53, over UDP and over TCP, at the name-server address of each region: the public address of its primary control-plane node (the contract output `control_plane_ips_per_region`, the ExternalIP the node registers with `--node-external-ip`). On the reference cloud the kit's DNS front door, dnsdist in host-port mode (a DaemonSet with hostPort 53 for UDP and TCP on every node, no host network, no Service of its own), is switched on, and each region security group admits 53/UDP and 53/TCP from every source; the packet reaches node:53 through the control-plane EIP's 1:1 NAT. The second provider and the local pack already serve it so and do not change. On every node of both cloud packs, before k3s starts and only where systemd-resolved runs, the stub listener on 127.0.0.53 is off and `/etc/resolv.conf` links `/run/systemd/resolve/resolv.conf`, so the node's own lookups never reach dnsdist. Gate check NET-G19 "The name servers answer on public port 53 in every region" is required and proves it on every cloud install; the gate run's NetworkPolicy lets the suite reach port 53 of the install. No NodePort anywhere.

Through systemd-resolved's stub at 127.0.0.53 the node's lookups would reach the Sovereign's authoritative server and fail whenever its Pod is not running. Of the two ways out (the stub off, or Cilium sending the node's lookups to dnsdist), the stub goes off: the tree already resolves this way where a host port 53 is proven, the local pack masks systemd-resolved for exactly this reason (`infra/providers/local/image/Containerfile` lines 25 to 30); the other way would make every node lookup depend on the authoritative server, which answers only the Sovereign's zones, and a hostIP is one fixed address for a whole DaemonSet. The item is plain POSIX and runs before the k3s item of each template, so the node resolves through the network's own servers before Cilium and dnsdist run, while they start and after.

One step per region: the ExternalIP addresses of the nodes labelled `catalyst.openova.io/role=control-plane`, each once, sorted; none fails the region as not measured. For each address, over UDP then TCP, an SOA query for `<domain>.` and an A query for `example.com.`, each with RD set and bounded by `nameServersTimeout` (5 seconds, the dial included). A reply counts only when it has the query's ID, the QR bit and the same question. The step fails when the SOA query gets no reply (naming address, transport and the bound), when any reply sets RA, when the SOA reply is SERVFAIL, and when `example.com.` gets an answer record; `example.com.` with no reply passes. The rcode of the SOA reply is otherwise recorded, not judged: the check proves that a name server answers at the address; the delegated zone is SOV-G19 (SOV-310). +// Check NET-G19, the name servers answer on public port 53 in every region.
+//
+// The name-server address of a region is the public address of its primary
+// control-plane node: the output control_plane_ips_per_region of every
+// provider module, which the node registers as its ExternalIP
+// (--node-external-ip). The addresses are the ExternalIP addresses of the
+// nodes with the label catalyst.openova.io/role=control-plane, as checks
+// NET-G01 and NET-G02 read them. The queries leave the gate run's machine,
+// which is outside every network of the Sovereign. For each address:
+//
+//   - an SOA query for the Sovereign's domain (the sovereignFQDN of step
+//     D0.1) gets a reply over UDP and over TCP, each within 5 seconds;
+//   - no reply sets RA (recursion available), and no reply to the SOA query
+//     is SERVFAIL (a front door with no name server behind it);
+//   - a query for a name outside the Sovereign's zones (example.com.) gets
+//     no answer record, over UDP and over TCP: the server is no open
+//     resolver. A query of that name that gets no reply passes this rule.
+//

+// question. Its rcode is recorded and not judged further: the check proves
+// that a name server answers at the address, not what the zone holds. The
+// evidence holds, per query, the address, the transport, the rcode, the
+// flags and the milliseconds. A region whose control-plane nodes have no
+// ExternalIP fails as not measured, and so does a run that did not learn the
+// Sovereign's name. The check creates nothing.

+// askNameServer sends one query of class IN over transport ("udp" or "tcp")
+// to target and reads the reply. A failure is recorded in Error.
+func askNameServer(ctx context.Context, transport, target, name string, qtype uint16) nameServersQuery {
+	out := nameServersQuery{Transport: transport, Name: name}
+	start := time.Now()
+	defer func() { out.Ms = time.Since(start).Milliseconds() }()
+	msg, err := dnsQueryMessage(name, qtype)
+	if err != nil {
+		out.Error = err.Error()
+		return out
+	}
+	ctx, cancel := context.WithTimeout(ctx, nameServersTimeout)
+	defer cancel()
+	conn, err := nameServersDial(ctx, transport, target)
+	if err != nil {
+		out.Error = err.Error()
+		return out
+	}
+	defer func() { _ = conn.Close() }()
+	if deadline, ok := ctx.Deadline(); ok {
+		_ = conn.SetDeadline(deadline)
+	}
+	reply, err := exchangeDNS(conn, transport, msg)
+	if err != nil {
+		out.Error = err.Error()
+		return out
+	}
+	flags := binary.BigEndian.Uint16(reply[2:4])
+	out.Rcode, out.Flags = dnsRcodeName(int(flags&0x000f)), dnsFlagNames(flags)
+	out.Answers = int(binary.BigEndian.Uint16(reply[6:8]))
+	return out
+}

+// exchangeDNS writes msg on conn and returns the first reply to it. Over UDP a
+// datagram that is no reply to msg is skipped; over TCP each message carries
+// its two-byte length.
+func exchangeDNS(conn net.Conn, transport string, msg []byte) ([]byte, error) {
+	if transport == "tcp" {
+		framed, err := dnsLength(msg)
+		if err != nil {
+			return nil, err
+		}
+		if _, err := conn.Write(append(framed, msg...)); err != nil {
+			return nil, err
+		}
+		var size [2]byte
+		if _, err := io.ReadFull(conn, size[:]); err != nil {
+			return nil, err
+		}
+		reply := make([]byte, binary.BigEndian.Uint16(size[:]))
+		if _, err := io.ReadFull(conn, reply); err != nil {
+			return nil, err
+		}
+		return reply, checkDNSReply(reply, msg)
+	}
+	if _, err := conn.Write(msg); err != nil {
+		return nil, err
+	}
+	buf := make([]byte, 65535)
+	for {
+		n, err := conn.Read(buf)
+		if err != nil {
+			return nil, err
+		}
+		if checkDNSReply(buf[:n], msg) == nil {
+			return buf[:n], nil
+		}
+	}
+}
+
+// dnsLength is the two-byte length that frames msg over TCP.
+func dnsLength(msg []byte) ([]byte, error) {
+	n := len(msg)
+	if n > math.MaxUint16 {
+		return nil, fmt.Errorf("a DNS message of %d bytes is too long", n)
+	}
+	return binary.BigEndian.AppendUint16(nil, uint16(n)), nil
+}
+
+// checkDNSReply reports whether reply is a DNS response to the query msg: the
+// same ID, the QR bit, one question equal to that of msg.
+func checkDNSReply(reply, msg []byte) error {
+	question := msg[12:]
+	switch {
+	case len(reply) < 12+len(question):
+		return fmt.Errorf("a reply of %d bytes is too short", len(reply))
+	case !bytes.Equal(reply[0:2], msg[0:2]):
+		return errors.New("the reply carries another ID")
+	case reply[2]&0x80 == 0:
+		return errors.New("the reply has no QR bit")
+	case binary.BigEndian.Uint16(reply[4:6]) != 1 || !bytes.EqualFold(reply[12:12+len(question)], question):
+		return errors.New("the reply answers another question")
+	}
+	return nil
+}
+
+// dnsQueryMessage is a query for name of type qtype and class IN, with a
+// random ID and RD set: a server that recurses would show it.
+func dnsQueryMessage(name string, qtype uint16) ([]byte, error) {
+	var id [2]byte
+	if _, err := rand.Read(id[:]); err != nil {
+		return nil, err
+	}
+	msg := append([]byte{}, id[0], id[1], 0x01, 0x00, 0, 1, 0, 0, 0, 0, 0, 0)
+	for _, label := range strings.Split(strings.TrimSuffix(name, "."), ".") {
+		if label == "" || len(label) > 63 {
+			return nil, fmt.Errorf("%q is no DNS name", name)
+		}
+		msg = append(append(msg, byte(len(label))), label...)
+	}
+	msg = append(msg, 0)
+	msg = binary.BigEndian.AppendUint16(msg, qtype)
+	return binary.BigEndian.AppendUint16(msg, 1), nil
+}
+
+func dnsRcodeName(rcode int) string {
+	names := []string{"NOERROR", "FORMERR", "SERVFAIL", "NXDOMAIN", "NOTIMP", "REFUSED"}
+	if rcode < len(names) {
+		return names[rcode]
+	}
+	return "RCODE" + strconv.Itoa(rcode)
+}
+
+// dnsFlagNames lists the header flags of a reply that are set, as dig does.
+func dnsFlagNames(flags uint16) string {
+	set := []string{}
+	for _, f := range []struct {
+		bit  uint16
+		name string
+	}{{0x8000, "qr"}, {0x0400, "aa"}, {0x0200, "tc"}, {0x0100, "rd"}, {0x0080, "ra"}} {
+		if flags&f.bit != 0 {
+			set = append(set, f.name)
+		}
+	}
+	return strings.Join(set, " ")
+}

+// fakeDNSReply answers the query q: the question echoed, AA set, and one answer
+// record (SOA for sov.test, A for another name when the server is open). It
+// returns nil for a query the server does not answer.
+func fakeDNSReply(q []byte, b nsBehaviour) []byte {
+	end := 12
+	labels := []string{}
+	for q[end] != 0 {
+		labels = append(labels, string(q[end+1:end+1+int(q[end])]))
+		end += 1 + int(q[end])
+	}
+	question := q[12 : end+5]
+	inZone := strings.HasSuffix(strings.Join(labels, ".")+".", "sov.test.")
+	if b.silent || (b.drop && !inZone) {
+		return nil
+	}
+	flags := uint16(0x8000|0x0400) | binary.BigEndian.Uint16(q[2:4])&0x0100
+	if b.ra {
+		flags |= 0x0080
+	}
+	answer := []byte(nil)
+	switch {
+	case inZone && b.rcode == 0:
+		answer = append([]byte{0xc0, 0x0c, 0, dnsTypeSOA, 0, 1, 0, 0, 0x0e, 0x10, 0, 26, 0xc0, 0x0c, 0xc0, 0x0c}, make([]byte, 20)...)
+	case inZone:
+		flags |= b.rcode
+	case b.open:
+		answer = []byte{0xc0, 0x0c, 0, dnsTypeA, 0, 1, 0, 0, 0x0e, 0x10, 0, 4, 192, 0, 2, 1}
+	default:
+		flags |= 5 // REFUSED: the name is in no zone of the server
+	}
+	r := append([]byte{q[0], q[1]}, binary.BigEndian.AppendUint16(nil, flags)...)
+	ancount := byte(0)
+	if answer != nil {
+		ancount = 1
+	}
+	r = append(r, 0, 1, 0, ancount, 0, 0, 0, 0)
+	return append(append(r, question...), answer...)
+}
