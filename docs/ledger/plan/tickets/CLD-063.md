# CLD-063 — Mirror the Crossplane packages

## In plain words

**The problem today.** Every new cluster installs the Crossplane provider for OpenTofu straight from the vendor's package registry. The vendor's terms let an older version of such a package stop being available without a paid subscription. Nothing in the platform keeps a copy of the packages it installs, or of the two packages the next upgrade steps need.

**What changes.** A new workflow names the three packages by their exact digest. On a pull request it proves that each one still exists upstream. On the main branch it copies each one into the platform's own registry, with the same digest.

**Done means:**

- The repository has one new workflow that names three Crossplane packages, each with a tag and an exact digest.
- On a pull request that changes the workflow, a check reads each package from the vendor registry by its digest, prints the three digests, copies nothing and uses no secret.
- On the main branch the same workflow copies each package into the registry project crossplane of harbor.openova.io and reads the copy back by the same digest.
- The workflow fails when a package cannot be read, when a tag no longer names its digest, or when a copy or its read-back fails.
- No other file of the repository changes; the cluster files still install the provider from the vendor registry.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The repository holds a new workflow, `.github/workflows/mirror-crossplane-packages.yaml`, with one job and one check, both named `mirror-crossplane-packages`. The workflow names three Crossplane packages by repository path, tag and digest: `upbound/provider-opentofu` `v1.1.3` (the version `clusters/_template` installs today), `upbound/provider-opentofu` `v1.1.11` (the version a later package moves to) and `crossplane-contrib/function-patch-and-transform` `v0.11.2` (the highest release of that function). On a pull request that changes the workflow, the check reads each package from `xpkg.upbound.io` by its digest, checks that the tag still names that digest, and prints one line `DIGEST <source>:<tag> <digest>` per package. It copies nothing and reads no secret. On a push to `main` that changes the workflow, and when it is started by hand, the job does the same reading and then copies each package to `harbor.openova.io/crossplane/<repository path>`, under the same tag and with the same digest, and reads each copy back by that digest. A person sees the result on the pull request of this ticket: the check `mirror-crossplane-packages` is green and its log lists the three digests.

6. 7. The copy step logs in as `robot$openova-warmup` with the repository secret `BASTION_HARBOR_ROBOT_TOKEN`, the same account and secret the warmup workflow uses for `harbor.openova.io`. It fails at once when the secret is empty. No other step and no job-level value reads a secret.
8. The copy keeps the digest. It copies each image that the package's index lists, by digest, with skopeo, then writes the index itself with its original bytes through the registry interface, with a push token from the registry's token service. Then it reads the copy back by the package digest and fails unless the bytes have that digest. It prints `MIRRORED <copy>@<digest>` for each package.
9. The workflow creates no project and no account on the registry. The project `crossplane` and the push right of `robot$openova-warmup` on it are set up outside this repository; until they are, the run on `main` fails with a message that says so.
10. No other file changes. The package line of `clusters/_template/infrastructure/providers/base/provider-opentofu.yaml` stays `xpkg.upbound.io/upbound/provider-opentofu:v1.1.3`. This ticket deletes nothing.

name: mirror-crossplane-packages

# Mirror the Crossplane packages into the OpenOva registry (CLD-063).
#
# clusters/_template installs the Crossplane provider provider-opentofu
# from the vendor registry xpkg.upbound.io. The vendor publishes its
# "official" packages under a policy that lets a version vanish for a
# pull without a subscription. This workflow copies each package below,
# by digest, into the hosted project `crossplane` of harbor.openova.io, so
# a copy exists that the vendor cannot take away. The repository path is
# kept: xpkg.upbound.io/<org>/<name> becomes
# harbor.openova.io/crossplane/<org>/<name>, with the same tag and the
# same digest.
#
# The packages, one per line: repository path, tag, digest. Each digest is
# the digest of the tag's OCI index as xpkg.upbound.io served it on
# 2026-11-13:
#   upbound/provider-opentofu v1.1.3   the version clusters/_template installs today
#   upbound/provider-opentofu v1.1.11  the version a later package moves to
#   crossplane-contrib/function-patch-and-transform v0.11.2
#                                      the highest release of the function
# A package is added by adding its line, with the digest read from the
# vendor registry. A line is never changed in place.
#
# What runs when:
#   - On a pull request that changes this file, the job only reads: it
#     checks that each source digest exists upstream, that its tag still
#     names that digest, and prints one line per package:
#       DIGEST <source>:<tag> <digest>
#     It copies nothing and uses no secret.
#   - On a push to main that changes this file, and by hand, it reads the
#     same way and then copies each package: first every image its index
#     lists, by digest, then the index itself with its original bytes, so
#     the copy has the same digest. It reads the copy back by digest and
#     prints:
#       MIRRORED <copy>@<digest>
#     The job fails when a source, a copy or a read-back fails.
#
# The copy needs, on harbor.openova.io: the hosted project `crossplane`,
# and push rights on it for the robot account robot$openova-warmup, whose
# password is the repository secret BASTION_HARBOR_ROBOT_TOKEN. This
# workflow creates neither.
#
# Event-driven only: no schedule. The job contacts no cluster.

on:
  pull_request:
    paths:
      - '.github/workflows/mirror-crossplane-packages.yaml'
  push:
    branches: [main]
    paths:
      - '.github/workflows/mirror-crossplane-packages.yaml'
  workflow_dispatch:

permissions:
  contents: read

jobs:

    timeout-minutes: 30

      MIRROR_HOST: harbor.openova.io

          set -euo pipefail
          sudo apt-get update -qq
          sudo apt-get install -y -qq skopeo
          skopeo --version

          manifest="${RUNNER_TEMP}/manifest.json"
          while read -r repo tag digest; do
            [ -n "${repo}" ] || continue
            src="${SOURCE_REGISTRY}/${repo}"
            if ! skopeo inspect --raw --retry-times 3 "docker://${src}@${digest}" > "${manifest}"; then

              exit 1

              echo "::error::${src}:${tag} now names ${got}, not ${digest}"

          import base64, json, os, re, sys, urllib.error, urllib.parse, urllib.request

              req = urllib.request.Request(url, data=body, method=method, headers=headers or {})
              try:
                  with urllib.request.urlopen(req, timeout=120) as resp:

              for item in doc.get("manifests", []):
                  print(item["digest"])

              code, headers, _ = call("GET", "https://%s/v2/" % host)
              challenge = headers.get("WWW-Authenticate", "") if code == 401 else ""
              if challenge.lower().startswith("bearer"):
                  params = dict(re.findall(r'(\w+)="([^"]*)"', challenge))
                  query = urllib.parse.urlencode({"service": params.get("service", ""), "scope": "repository:%s:pull,push" % repo})
                  code, _, answer = call("GET", params["realm"] + "?" + query, headers=auth)
                  if code != 200:
                      sys.exit("the token service answered %d" % code)
                  token = json.loads(answer)
                  auth = {"Authorization": "Bearer " + (token.get("token") or token["access_token"])}
              code, _, answer = call("PUT", "https://%s/v2/%s/manifests/%s" % (host, repo, tag), body, dict(auth, **{"Content-Type": media}))
              if code not in (200, 201):
                  sys.exit("writing the index answered %d: %s" % (code, answer[:300].decode(errors="replace")))

          if sys.argv[1] == "children":
              children(sys.argv[2])
          else:
              put(*sys.argv[2:6])
          PY

          index="${RUNNER_TEMP}/index.json"
          manifest="${RUNNER_TEMP}/manifest.json"

            dst="${MIRROR_HOST}/${MIRROR_PROJECT}/${repo}"

              for kid in ${kids}; do

                  echo "::error::the copy of ${src}@${kid} to ${dst} failed. The project ${MIRROR_PROJECT} must exist on ${MIRROR_HOST}, and ${MIRROR_USERNAME} must be allowed to push to it."
                  exit 1
                fi
              done

                exit 1
              fi
            elif ! skopeo copy --retry-times 3 "docker://${src}@${digest}" "docker://${dst}:${tag}"; then

              exit 1
            fi
            echo "MIRRORED ${dst}@${digest}"
          done <<< "${PACKAGES}"
