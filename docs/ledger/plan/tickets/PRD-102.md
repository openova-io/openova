# PRD-102 — Generated types and server interfaces (oapi-codegen, strict server)

## In plain words

**The problem today.** The open-banking product holds the six interface documents of the standard, but no Go code describes their requests and responses. Every later part of the product would have to write those types by hand, and nothing would show when they drift from the documents.

**What changes.** A code generator of one fixed version, run with go generate, writes one Go package per document: its types and a server interface for the standard library router. The generated code is committed, the product's checks run on it, and a test proves that the generator's settings and its outputs agree.

**Done means:**

- Each of the six interface documents has its own generated Go package, and the product builds and passes go vet with them.
- Running go generate in the generator folder writes the committed packages again byte for byte, so a hand edit turns the existing drift check red.
- The generator is one exact version, pinned in a Go module of its own, and the six documents are unchanged.
- A test of the generator module fails when a document has no generator line, when the settings of one document differ from the others, or when a file the generator did not write lies among the generated ones.
- That test runs on every pull request that changes the product.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`products/fingate/internal/gen/` holds six generated Go packages, one per OpenAPI document of profile `rw-4.0.0`: `accountinfo`, `paymentinitiation`, `vrp`, `confirmationfunds`, `events` and `eventnotifications`. Each holds the request and response types of its document and a strict server interface for the standard library router (`net/http`), with one method per operation of the document. The generator is `oapi-codegen` v2.6.0, pinned in the Go module `products/fingate/tools` and run by `go generate ./...` in that folder. Running it again writes the same bytes, which the existing check `go generate changes nothing — products/fingate` proves on every pull request. A test in the generator module proves that the generator lines, the settings files and the generated files agree, and that test runs on every pull request that changes the product. The six documents are not changed.

## 3. The model (the law)
1. The generator is `oapi-codegen`, Go module `github.com/oapi-codegen/oapi-codegen/v2`, version `v2.6.0`. It is pinned by the line `tool github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen` of `products/fingate/tools/go.mod`, a Go module of its own named `github.com/openova-io/openova/products/fingate/tools` with the line `go 1.24`. The generator's dependencies stay in that module; they never enter the product module `products/fingate/go.mod`.
2. `products/fingate/tools/generate.go` (block `generate.go`) holds six `go:generate` lines, one per document, each of the form `//go:generate go tool oapi-codegen -config oapi/<package>.yaml ../profiles/rw-4.0.0/<document>`. The package name is the document's file name without `-openapi.yaml` and without dashes.
3. Each settings file `products/fingate/tools/oapi/<package>.yaml` sets exactly: `package: <package>`; `output: ../internal/gen/<package>/<package>.gen.go`; under `generate`, `models`, `std-http-server` and `strict-server`, each `true`; under `output-options`, `resolve-type-name-collisions: true`. Only `accountinfo.yaml` sets one more key, `output-options.overlay.path: oapi/accountinfo-overlay.yaml`. No settings file generates a client or an embedded copy of the document.
4. The two naming settings exist because of the account information document. It names a parameter and a schema `AccountId`, and a parameter and a schema `StatementId`: `resolve-type-name-collisions` gives the parameter types the suffix `Parameter` (`AccountIdParameter`). It also names the schemas `OBRate1_0` and `OB_Rate1_0`, and `OBRate1_1` and `OB_Rate1_1`, which become one Go name each when the underscore is dropped: the overlay `products/fingate/tools/oapi/accountinfo-overlay.yaml` gives the two schemas with the underscore the Go name they have in the document (`x-go-name: OB_Rate1_0`, `x-go-name: OB_Rate1_1`). An overlay changes only the generator's copy in memory. The document file is never edited.
5. The generated files are `products/fingate/internal/gen/<package>/<package>.gen.go`, one per package and no other file. They are committed and never edited by hand. Each carries the line `// Code generated by github.com/oapi-codegen/oapi-codegen/v2 version v2.6.0 DO NOT EDIT.` and imports `github.com/oapi-codegen/runtime` and `github.com/oapi-codegen/runtime/strictmiddleware/nethttp`. Their SHA-256 values are those of step 15.
6. The product module requires `github.com/oapi-codegen/runtime v1.2.0`. The executor adds it with `go get` and `go mod tidy` (steps 16 and 17), so a requirement that another package added to `products/fingate/go.mod` stays.
7. The test `products/fingate/tools/generate_test.go` (block `generate_test.go`) reads the folder `products/fingate` and checks five rules: (1) every `go:generate` line has the form of law 2 and names each package once; (2) the lines name each `*-openapi.yaml` document of `profiles/rw-4.0.0` exactly once, under the package name of law 2; (3) `tools/oapi` holds one settings file per line, and an overlay file only when a settings file names it; (4) each settings file has exactly the settings of law 3 and no unknown key; (5) each generated file exists with the header line of law 5 and its `package` line, and `internal/gen` holds no other file. The test `TestEveryRuleCanFail` breaks a correct folder in memory, once per rule and kind of mistake, 16 cases, and expects the rule to fail.
8. The generator module is tested on every pull request: `.github/workflows/test-ungated-trees.yaml` lists `products/fingate/tools` once in its `go-modules` matrix, and `scripts/check-modules-tested.py` passes. `docs/ledger/untested-modules.txt` does not change.
9. Nothing else is added: no handler that implements an interface, no HTTP server, no client, no chart. The six documents, `profile.yaml`, `.github/workflows/fingate-ci.yaml` and `products/fingate/README.md` do not change.

package tools

// The tests of this file prove that the generator's inputs and outputs fit together:
// one go:generate line per document of profile rw-4.0.0, one settings file per line,
// the same settings in each, and one generated file per document. Whether the generated
// files are up to date is checked by running go generate (the generate job of
// .github/workflows/fingate-ci.yaml), not here.

import (
	"bytes"
	"fmt"
	"io/fs"
	"os"
	"path"
	"regexp"
	"sort"
	"strings"
	"testing"
	"testing/fstest"

	"gopkg.in/yaml.v3"
)

const (
	profileDir = "profiles/rw-4.0.0"
	header     = "// Code generated by github.com/oapi-codegen/oapi-codegen/v2 version v2.6.0 DO NOT EDIT."
)

var directive = regexp.MustCompile(`^//go:generate go tool oapi-codegen -config oapi/([a-z]+)\.yaml \.\./profiles/rw-4\.0\.0/([a-z-]+-openapi\.yaml)$`)

// settings is the shape of one file oapi/<package>.yaml. A key it does not name is an error.
type settings struct {
	Package       string          `yaml:"package"`
	Output        string          `yaml:"output"`
	Generate      map[string]bool `yaml:"generate"`
	OutputOptions struct {
		ResolveTypeNameCollisions bool `yaml:"resolve-type-name-collisions"`
		Overlay                   *struct {
			Path string `yaml:"path"`
		} `yaml:"overlay"`
	} `yaml:"output-options"`
}

// check reads the folder products/fingate as fsys and returns one line per broken rule.
func check(fsys fs.FS) []string {
	var fails []string
	fail := func(format string, args ...any) { fails = append(fails, fmt.Sprintf(format, args...)) }

	// Rule 1: every go:generate line has the one allowed form; each package is named once.
	src, err := fs.ReadFile(fsys, "tools/generate.go")
	if err != nil {
		return []string{"rule 1: tools/generate.go cannot be read: " + err.Error()}
	}
	docOf := map[string]string{}
	for _, line := range strings.Split(string(src), "\n") {
		if !strings.HasPrefix(line, "//go:generate") {
			continue
		}
		m := directive.FindStringSubmatch(line)
		if m == nil {
			fail("rule 1: a go:generate line has another form: %s", line)
			continue
		}
		if _, seen := docOf[m[1]]; seen {
			fail("rule 1: package %s is generated twice", m[1])
		}
		docOf[m[1]] = m[2]
	}

	// Rule 2: the lines name each document of the profile exactly once, and the package
	// name is the document name without "-openapi.yaml" and without dashes.
	docs, err := fs.Glob(fsys, profileDir+"/*-openapi.yaml")
	if err != nil || len(docs) == 0 {
		return append(fails, "rule 2: no document found in "+profileDir)
	}
	named := map[string]int{}
	for pkg, doc := range docOf {
		named[doc]++
		if want := strings.ReplaceAll(strings.TrimSuffix(doc, "-openapi.yaml"), "-", ""); pkg != want {
			fail("rule 2: %s is generated as package %s, want %s", doc, pkg, want)
		}
	}
	for _, d := range docs {
		if n := named[path.Base(d)]; n != 1 {
			fail("rule 2: document %s has %d go:generate lines, want 1", path.Base(d), n)
		}
		delete(named, path.Base(d))
	}
	for doc := range named {
		fail("rule 2: a go:generate line names %s, which is not a document of the profile", doc)
	}

	// Rule 3: oapi/ holds one settings file per line, and an overlay only for a file that names it.
	files, err := fs.Glob(fsys, "tools/oapi/*.yaml")
	if err != nil {
		return append(fails, "rule 3: tools/oapi cannot be read: "+err.Error())
	}
	overlays := map[string]bool{}
	for _, f := range files {
		name := path.Base(f)
		if strings.HasSuffix(name, "-overlay.yaml") {
			overlays["oapi/"+name] = false
			continue
		}
		if _, ok := docOf[strings.TrimSuffix(name, ".yaml")]; !ok {
			fail("rule 3: settings file %s is named by no go:generate line", name)
		}
	}

	// Rule 4: each settings file has exactly the shared settings, and rule 5: each
	// generated file exists with the generator's header and its package line.
	pkgs := make([]string, 0, len(docOf))
	for pkg := range docOf {
		pkgs = append(pkgs, pkg)
	}
	sort.Strings(pkgs)
	for _, pkg := range pkgs {
		raw, err := fs.ReadFile(fsys, "tools/oapi/"+pkg+".yaml")
		if err != nil {
			fail("rule 3: settings file %s.yaml is missing", pkg)
			continue
		}
		var s settings
		dec := yaml.NewDecoder(bytes.NewReader(raw))
		dec.KnownFields(true)
		if err := dec.Decode(&s); err != nil {
			fail("rule 4: %s.yaml cannot be read: %v", pkg, err)
			continue
		}
		if s.Package != pkg {
			fail("rule 4: %s.yaml sets package %q, want %q", pkg, s.Package, pkg)
		}
		out := "../internal/gen/" + pkg + "/" + pkg + ".gen.go"
		if s.Output != out {
			fail("rule 4: %s.yaml sets output %q, want %q", pkg, s.Output, out)
		}
		want := map[string]bool{"models": true, "std-http-server": true, "strict-server": true}
		if fmt.Sprint(s.Generate) != fmt.Sprint(want) {
			fail("rule 4: %s.yaml generates %v, want %v", pkg, s.Generate, want)
		}
		if !s.OutputOptions.ResolveTypeNameCollisions {
			fail("rule 4: %s.yaml does not set resolve-type-name-collisions", pkg)
		}
		if o := s.OutputOptions.Overlay; o != nil {
			if _, ok := overlays[o.Path]; !ok || o.Path != "oapi/"+pkg+"-overlay.yaml" {
				fail("rule 4: %s.yaml names overlay %q, want an existing oapi/%s-overlay.yaml", pkg, o.Path, pkg)
			} else {
				overlays[o.Path] = true
			}
		}
		gen, err := fs.ReadFile(fsys, strings.TrimPrefix(out, "../"))
		if err != nil {
			fail("rule 5: the generated file of %s is missing", pkg)
			continue
		}
		if !bytes.Contains(gen, []byte("\n"+header+"\n")) || !bytes.Contains(gen, []byte("\npackage "+pkg+"\n")) {
			fail("rule 5: internal/gen/%s/%s.gen.go lacks the generator's header or the line package %s", pkg, pkg, pkg)
		}
	}
	for o, used := range overlays {

func TestEveryRuleCanFail(t *testing.T) {
	good := func() fstest.MapFS {

				"generate:\n  models: true\n  std-http-server: true\n  strict-server: true\n" +
				"output-options:\n  resolve-type-name-collisions: true\n" + extra)}
		}
		return fstest.MapFS{
			"tools/generate.go": {Data: []byte("package tools\n\n" +
				"//go:generate go tool oapi-codegen -config oapi/accountinfo.yaml ../profiles/rw-4.0.0/account-info-openapi.yaml\n" +
				"//go:generate go tool oapi-codegen -config oapi/vrp.yaml ../profiles/rw-4.0.0/vrp-openapi.yaml\n")},
			profileDir + "/account-info-openapi.yaml":     {Data: []byte("openapi: 3.0.0\n")},
			profileDir + "/vrp-openapi.yaml":              {Data: []byte("openapi: 3.0.0\n")},
			profileDir + "/profile.yaml":                  {Data: []byte("id: rw-4.0.0\n")},
			"tools/oapi/accountinfo.yaml":                 set("accountinfo", "  overlay:\n    path: oapi/accountinfo-overlay.yaml\n"),
			"tools/oapi/accountinfo-overlay.yaml":         {Data: []byte("overlay: 1.0.0\n")},
			"tools/oapi/vrp.yaml":                         set("vrp", ""),
			"internal/gen/accountinfo/accountinfo.gen.go": gen("accountinfo"),
			"internal/gen/vrp/vrp.gen.go":                 gen("vrp"),
		}
	}
	if f := check(good()); len(f) != 0 {
		t.Fatalf("the correct folder fails: %v", f)
	}
	replace := func(file, old, new string) func(fstest.MapFS) {
		return func(m fstest.MapFS) {
			m[file] = &fstest.MapFile{Data: []byte(strings.Replace(string(m[file].Data), old, new, 1))}
		}
	}
	cases := []struct {
		name, rule string
		breakIt    func(fstest.MapFS)
	}{
		{"a go:generate line of another form", "rule 1:", replace("tools/generate.go", "go tool oapi-codegen", "go run oapi-codegen")},
		{"a package generated twice", "rule 1:", replace("tools/generate.go", "oapi/vrp.yaml ../profiles/rw-4.0.0/vrp", "oapi/accountinfo.yaml ../profiles/rw-4.0.0/vrp")},
		{"a document without a go:generate line", "rule 2:", func(m fstest.MapFS) {
			m[profileDir+"/events-openapi.yaml"] = &fstest.MapFile{Data: []byte("openapi: 3.0.0\n")}
		}},
		{"a package not named after its document", "rule 2:", replace("tools/generate.go", "oapi/vrp.yaml", "oapi/vrps.yaml")},
		{"a settings file named by no line", "rule 3:", func(m fstest.MapFS) { m["tools/oapi/events.yaml"] = m["tools/oapi/vrp.yaml"] }},
		{"an overlay named by no settings file", "rule 3:", func(m fstest.MapFS) {
			m["tools/oapi/vrp-overlay.yaml"] = &fstest.MapFile{Data: []byte("overlay: 1.0.0\n")}
		}},
		{"a missing settings file", "rule 3:", func(m fstest.MapFS) { delete(m, "tools/oapi/vrp.yaml") }},
		{"an unknown settings key", "rule 4:", replace("tools/oapi/vrp.yaml", "generate:", "embedded-spec: true\ngenerate:")},
		{"a wrong package setting", "rule 4:", replace("tools/oapi/vrp.yaml", "package: vrp", "package: other")},
		{"a wrong output setting", "rule 4:", replace("tools/oapi/vrp.yaml", "/vrp.gen.go", "/other.gen.go")},
		{"another generate set", "rule 4:", replace("tools/oapi/vrp.yaml", "  strict-server: true\n", "  client: true\n")},
		{"no resolve-type-name-collisions", "rule 4:", replace("tools/oapi/vrp.yaml", "resolve-type-name-collisions: true", "resolve-type-name-collisions: false")},
		{"an overlay of another package", "rule 4:", replace("tools/oapi/accountinfo.yaml", "oapi/accountinfo-overlay.yaml", "oapi/vrp-overlay.yaml")},
		{"a missing generated file", "rule 5:", func(m fstest.MapFS) { delete(m, "internal/gen/vrp/vrp.gen.go") }},
		{"a generated file without the header", "rule 5:", replace("internal/gen/vrp/vrp.gen.go", "DO NOT EDIT.", "edited.")},
		{"a hand-written file among the generated ones", "rule 5:", func(m fstest.MapFS) { m["internal/gen/vrp/extra.go"] = &fstest.MapFile{Data: []byte("package vrp\n")} }},
	}
	for _, c := range cases {
		t.Run(c.name, func(t *testing.T) {
			m := good()
			c.breakIt(m)
			fails := check(m)
			hit := false
			for _, f := range fails {
				hit = hit || strings.HasPrefix(f, c.rule)
			}
			if !hit {
				t.Errorf("want a failure of %s, got %v", strings.TrimSuffix(c.rule, ":"), fails)
			}
		})
	}
}
