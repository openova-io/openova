# INF-010 — Guard for the machine plane

## In plain words

**The problem today.** The platform is about to add machine operations and virtual machines: an inventory, scans, patching and light tests run by a runner image. A few patterns would make that work unsafe or unlicensable, such as nodes that reboot themselves, images named by moving tags, tools under a licence the platform does not ship, and switched-off host-key checks. Nothing stops a change from adding them.

**What changes.** A check on every pull request counts seven such patterns per file and compares the counts with stored numbers. Two patterns that exist today may only shrink; the other five must stay at zero.

**Done means:**

- A pull request that adds an automatic node reboot or a moving machine-image tag turns red.
- A pull request that puts a forbidden scanning tool, an unpinned runner tool or base image, or a switched-off host-key or certificate check into the machine plane turns red.
- A pull request that adds a free-text target field or a credential field to a machine resource definition turns red.
- The two patterns that exist today are recorded, and a change that removes one must lower the stored number in the same change.
- The check proves on itself that each of its rules can fail.
- No product code changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every pull request gets a check named `check-machine-plane`. It runs the script `scripts/check-machine-plane.py`, which counts seven patterns per file and compares each count with the number stored in `scripts/baselines/machine-plane.json`. Two patterns exist today: two automatic node reboots in the boot templates and four machine images named by a moving tag in the Hetzner module. They may only shrink. The other five patterns concern folders of the machine plane, which other packages create, and they must stay at zero. A person can see the result on any pull request: the check prints one line `<metric>=<total>` for each of the seven metrics.

## 3. The model (the law)
1. The guard is the script `scripts/check-machine-plane.py`. It reads the working tree. It needs Python 3; it reads YAML files with PyYAML.
2. It counts seven metrics, each per file. Hidden folders (a name that starts with `.`) are skipped. A scope folder or file that does not exist counts zero, except where rule 3 says otherwise. The folder `docs/` is never scanned.
   - `node-auto-reboot`: every file under `infra/`; the lines that hold `Automatic-Reboot "true"`.
   - `moving-image-tag`: the files `infra/providers/*/main.tf`; the lines that match the regular expression `image\s*=\s*"[a-z]+-[0-9.]+"` (an image named by a moving tag).
   - `forbidden-tool`: every file under `products/machine-runner/` and `platform/machine-operations/`; the lines that name `wazuh`, `nmap`, `awx`, `caldera`, `syft` or `grype`, in any case, where no letter or digit stands right before or after the name; and the lines that name `packer` followed, within 24 characters and no digit between, by a version of 1.10 or later. In `products/machine-runner/tools.lock.yaml` the packer rule reads the tool entries instead of the lines: an entry whose `name` is `packer` and whose `version` is 1.10 or later counts one.
   - `unpinned-runner-tool`: in `products/machine-runner/tools.lock.yaml`, each tool entry that lacks a `sha256` of 64 lowercase hex characters, a non-empty `licence`, or an exact `version` (a YAML string of numbers joined by dots, with an optional suffix; not a range, not a wildcard, not an `x`, not `latest`, not an unquoted number). In `products/machine-runner/Containerfile`, each `FROM` line whose image has no `@sha256:` digest of 64 hex characters; `scratch` and the name of an earlier stage (`AS <name>`) are allowed.
   - `host-key-check-disabled`: every file under `products/machine-runner/content/` and `products/catalyst/bootstrap/api/internal/machines/runner/`; the lines that hold `StrictHostKeyChecking=no`, `UserKnownHostsFile=/dev/null`, `validate_certs: false` or `no`, `InsecureIgnoreHostKey`, or `ignore_errors: true` or `yes` (spaces, quotes and the case of the value may differ).
   - `free-text-target`: the files `platform/machine-operations/chart/crds/testscopes.yaml` and `platform/machine-operations/chart/crds/machineruns.yaml`; each schema property named `host`, `url`, `path`, `command`, `address` or `cidr`.
   - `machine-credential-field`: the files `platform/machine-operations/chart/crds/*.yaml`, `platform/crossplane-claims/chart/templates/xrds/virtualmachine*.yaml` and `platform/virtual-machine/chart/values.schema.json`; each schema property named `password`, `privateKey`, `secretKey`, `token` or `keyPair`.

   A schema property is a key of a mapping that is the value of a key named `properties`, at any depth. Property names are compared without regard to case. Every `{{ ... }}` span is removed from a YAML file before it is read, so a Helm template is read as YAML.
3. When `infra/` holds no file, when no file matches `infra/providers/*/main.tf`, when a scanned YAML or JSON file cannot be read, when `tools.lock.yaml` is not one YAML document with a list under `tools`, or when PyYAML is missing for a file that needs it, the script judges nothing and exits with code 2.
4. The stored numbers are the file `scripts/baselines/machine-plane.json`, the baseline, in the shared form of the guard baselines under `scripts/baselines`:
   ```
   {"schema": "openova.io/guard-baseline/v1",
    "counts": {"<metric>": {"<repository path>": <number>}},
    "allow": [{"metric": "<metric>", "path": "<repository path>", "count": <number>, "reason": "<ten characters or more>", "owner": "<area prefix>"}]}
   ```
   `counts` holds all seven metrics. A file absent from a metric is allowed zero. Every number is 1 or more.
5. `allow` lists matches that belong to another area. An allow entry's count is subtracted from the file's count before the comparison. An entry has exactly the five keys shown, `count` is 1 or more, `reason` has ten characters or more, `owner` is three capital letters, and there is at most one entry per metric and path.
6. The last five metrics (`forbidden-tool`, `unpinned-runner-tool`, `host-key-check-disabled`, `free-text-target`, `machine-credential-field`) are hard zeros: the baseline holds no count and no allow entry for them.
7. The rule, for every metric and every path: the script exits with code 1 when the count after the allow entries is above the path's entry (and names the lines), when the entry is above the count (the baseline must be lowered in the same change), when an allow entry is above the file's count or is malformed, and when a hard-zero metric has a count or an allow entry. Otherwise it exits with code 0. Whenever it judges, it prints the seven lines `<metric>=<total>`, in the order of rule 2: the findings in the tree, before the allow entries.
8. A baseline only goes down. `--write-baseline` writes the baseline from the tree. When the baseline file exists, it refuses to raise an entry or to add a path, exits with code 1 and leaves the file as it was; when it writes, it keeps the allow list as it is.
9. `--self-test` builds a small tree of its own, 64 times, and shows for each rule that it fails and for each exception that it passes. It reads nothing of the repository. It needs PyYAML.
10. The baseline of this ticket holds the two `node-auto-reboot` lines of today as counts, and one allow entry: metric `moving-image-tag`, path `infra/providers/hetzner/main.tf`, count 4, owner `CLD`. The Hetzner module names its server images by the moving tag `ubuntu-24.04`; the cloud area re-proves (CLD-182) or retires (CLD-190) that module.
11. The workflow `.github/workflows/check-machine-plane.yaml` has the triggers `pull_request` and `merge_group` and no path filter. Its one job, `check-machine-plane`, installs PyYAML, runs the self-test and then the guard.
12. The script, the workflow and the baseline are the three blocks of field 5, byte for byte. None is typed or edited by hand.
13. This ticket changes no product code and no existing file. It deletes nothing.

    out = []
    for folder, dirs, names in os.walk(base):
        dirs[:] = sorted(d for d in dirs if not d.startswith("."))
        for name in names:
            full = os.path.join(folder, name)
            if os.path.isfile(full):
                out.append(os.path.relpath(full, root).replace(os.sep, "/"))
    return sorted(out)

def pattern(root, pattern_text):
    """Repository paths that match a glob pattern, files only, sorted."""
    found = glob.glob(os.path.join(root, pattern_text))
    return sorted(os.path.relpath(p, root).replace(os.sep, "/") for p in found if os.path.isfile(p))

def lines(root, path):
    with open(os.path.join(root, path), "rb") as f:
        return f.read().decode("utf-8", errors="replace").split("\n")

def grep(root, path, regex):
    """['line N', ...] for the lines of one file that match regex."""
    return ["line %d" % (n + 1) for n, line in enumerate(lines(root, path)) if regex.search(line)]

def yaml_text(root, path):
    """The text of one YAML file with every {{ ... }} span removed; PyYAML is checked here."""
    try:
        import yaml  # noqa: F401
    except ImportError:
        raise Unreadable("PyYAML is needed to read %s" % path)
    return "\n".join(TEMPLATE_RE.sub("", line) for line in lines(root, path))

def load_yaml_nodes(root, path):
    """The YAML node trees of one file."""
    import yaml
    try:
        return list(yaml.compose_all(yaml_text(root, path), Loader=yaml.SafeLoader))
    except yaml.YAMLError as e:
        raise Unreadable("%s is not valid YAML: %s" % (path, str(e).replace("\n", " ")))

def properties_named(root, path, names):
    """['line N: property <name>', ...] for every schema property of one file whose name is in names."""
    docs = load_yaml_nodes(root, path)
    import yaml
    out = []

    def visit(node):
        if isinstance(node, yaml.MappingNode):
            for key, value in node.value:
                if isinstance(key, yaml.ScalarNode) and key.value == "properties" and isinstance(value, yaml.MappingNode):
                    for prop, _ in value.value:
                        if isinstance(prop, yaml.ScalarNode) and prop.value.lower() in names:
                            out.append("line %d: property %s" % (prop.start_mark.line + 1, prop.value))
                visit(value)
        elif isinstance(node, yaml.SequenceNode):
            for item in node.value:
                visit(item)

    for doc in docs:
        visit(doc)
    return out

def version_at_least(text, major, minor):
    m = re.match(r"\s*v?([0-9]+)\.([0-9]+)", str(text))
    return bool(m) and (int(m.group(1)), int(m.group(2))) >= (major, minor)

def lock_entries(root):
    """The tool entries of the runner's tool lock, as (line number, value) pairs; [] when it is absent."""
    if not os.path.isfile(os.path.join(root, LOCK)):
        return []
    docs = load_yaml_nodes(root, LOCK)
    import yaml
    data = yaml.safe_load(yaml_text(root, LOCK))
    if len(docs) != 1 or not isinstance(data, dict) or not isinstance(data.get("tools"), list):
        raise Unreadable("%s must be one YAML document with a list under tools" % LOCK)
    tools_node = [v for k, v in docs[0].value if k.value == "tools"][0]
    return [(item.start_mark.line + 1, entry) for item, entry in zip(tools_node.value, data["tools"])]

def forbidden_tool(root):
    out = {}
    for p in walk(root, RUNNER) + walk(root, OPS):
        found = []
        for n, line in enumerate(lines(root, p)):
            hit = bool(TOOL_RE.search(line))
            if not hit and p != LOCK:
                hit = any((int(a), int(b)) >= (1, 10) for a, b in PACKER_RE.findall(line))
            if hit:
                found.append("line %d" % (n + 1))
        out[p] = found
    for at, entry in lock_entries(root):
        if isinstance(entry, dict) and str(entry.get("name", "")).strip().lower() == "packer" \
                and version_at_least(entry.get("version", ""), 1, 10):
            out.setdefault(LOCK, []).append("line %d: packer entry" % at)
    return out

def unpinned_runner_tool(root):
    out = {}
    for at, entry in lock_entries(root):
        e = entry if isinstance(entry, dict) else {}
        version, sha, licence = e.get("version"), e.get("sha256"), e.get("licence")
        exact = isinstance(version, str) and VERSION_RE.fullmatch(version) and not LOOSE_RE.search(version)
        if not (isinstance(sha, str) and SHA_RE.fullmatch(sha)) or not (isinstance(licence, str) and licence.strip()) or not exact:
            out.setdefault(LOCK, []).append("line %d: tool entry" % at)
    if os.path.isfile(os.path.join(root, CONTAINERFILE)):
        stages = {"scratch"}
        for n, line in enumerate(lines(root, CONTAINERFILE)):
            m = FROM_RE.match(line)
            if not m:
                continue
            words = [w for w in m.group(1).split() if not w.startswith("--")]
            image = words[0] if words else ""
            if not (DIGEST_RE.search(image) or image.lower() in stages):
                out.setdefault(CONTAINERFILE, []).append("line %d" % (n + 1))
            if len(words) >= 3 and words[1].lower() == "as":
                stages.add(words[2].lower())
    return out

def measure(root):
    """metric -> repository path -> findings; files without a finding are left out."""
    return {m: {p: f for p, f in MEASURE[m](root).items() if f} for m in METRICS}

def read_baseline(root):
    """Returns (counts, allow entries that are well formed, failure lines about the baseline)."""
    try:
        with open(os.path.join(root, BASELINE), encoding="utf-8") as f:
            doc = json.load(f)
    except (OSError, ValueError) as e:
        raise Unreadable("%s cannot be read: %s" % (BASELINE, e))
    counts = doc.get("counts") if isinstance(doc, dict) else None
    if not isinstance(doc, dict) or doc.get("schema") != SCHEMA or not isinstance(counts, dict) or sorted(counts) != sorted(METRICS):
        raise Unreadable("%s: need schema %s and counts for exactly the metrics %s" % (BASELINE, SCHEMA, ", ".join(METRICS)))
    for metric in METRICS:
        entries = counts[metric]
        if not isinstance(entries, dict) or not all(type(v) is int and v >= 1 for v in entries.values()):
            raise Unreadable("%s: counts.%s must map a path to a whole number of 1 or more" % (BASELINE, metric))
    allow = doc.get("allow")
    if not isinstance(allow, list):
        raise Unreadable("%s: allow must be a list" % BASELINE)
    fails = ["%s is a hard zero: the baseline may hold no count for it (%s)" % (m, ", ".join(sorted(counts[m])))
             for m in HARD_ZERO if counts[m]]
    good, seen = [], set()
    for i, entry in enumerate(allow):
        where = "allow[%d]" % i
        if not isinstance(entry, dict) or sorted(entry) != ALLOW_KEYS:
            fails.append("%s: an allow entry has exactly the keys %s" % (where, ", ".join(ALLOW_KEYS)))
        elif entry["metric"] not in METRICS:
            fails.append("%s: metric must be one of %s" % (where, ", ".join(METRICS)))
        elif entry["metric"] in HARD_ZERO:
            fails.append("%s: %s is a hard zero: it takes no allow entry" % (where, entry["metric"]))
        elif not isinstance(entry["path"], str) or not entry["path"]:
            fails.append("%s: path must be a repository path" % where)
        elif type(entry["count"]) is not int or entry["count"] < 1:
            fails.append("%s: count must be a whole number of 1 or more" % where)
        elif not isinstance(entry["reason"], str) or len(entry["reason"].strip()) < 10:
            fails.append("%s: reason must be ten characters or more" % where)
        elif not isinstance(entry["owner"], str) or not OWNER.match(entry["owner"]):
            fails.append("%s: owner must be an area prefix of three capital letters" % where)
        elif (entry["metric"], entry["path"]) in seen:
            fails.append("%s: a second allow entry for %s %s; one entry per metric and path" % (where, entry["metric"], entry["path"]))
        else:
            seen.add((entry["metric"], entry["path"]))
            good.append(entry)
    return counts, good, fails

def net(have, allow):
    """(metric -> path -> count after the allow entries, failure lines for allow entries above the count)."""
    out, fails = {}, []
    for metric in METRICS:
        out[metric] = {path: len(found) for path, found in have[metric].items()}
    for entry in allow:
        metric, path = entry["metric"], entry["path"]
        now = out[metric].get(path, 0)
        if entry["count"] > now:
            fails.append("%s: %s has %d, its allow entry says %d; lower the allow entry in the same change" % (metric, path, now, entry["count"]))
        out[metric][path] = max(now - entry["count"], 0)
    for metric in METRICS:
        out[metric] = {path: n for path, n in out[metric].items() if n}
    return out, fails

def compare(have, after, entries):
    """One (rose, line) per path whose count after the allow entries is not exactly its baseline entry."""
    out = []
    for metric in METRICS:
        for path in sorted(set(after[metric]) | set(entries[metric])):
            now, entry = after[metric].get(path, 0), entries[metric].get(path, 0)
            if now > entry:
                at = ", ".join(have[metric].get(path, []))
                out.append((True, "%s: %s has %d, the baseline allows %d (at: %s); %s" % (metric, path, now, entry, at, WHY[metric])))
            elif now < entry:
                out.append((False, "%s: %s has %d, the baseline still says %d; lower the baseline in the same change" % (metric, path, now, entry)))
    return out

def run(root, write=False, say=print):
    """The whole guard. Returns the exit code."""
    try:
        have = measure(root)
        target = os.path.join(root, BASELINE)
        if write:
            kept, good = [], []                       # the allow list is kept as it is; only its good entries count
            if os.path.exists(target):
                old, good, _ = read_baseline(root)
                after, over = net(have, good)
                rises = over + [line for rose, line in compare(have, after, old) if rose]
                if rises:
                    for line in rises:
                        say("%s: FAIL %s" % (ME, line))
                    say("%s: the baseline was not written: a baseline only goes down" % ME)
                    return 1
                with open(target, encoding="utf-8") as f:
                    kept = json.load(f)["allow"]
            after, _ = net(have, good)
            os.makedirs(os.path.dirname(target), exist_ok=True)
            with open(target, "w", encoding="utf-8") as f:
                f.write(json.dumps({"schema": SCHEMA, "counts": after, "allow": kept}, indent=2, sort_keys=True) + "\n")
            say("%s: wrote %s" % (ME, BASELINE))
        entries, allow, fails = read_baseline(root)
    except Unreadable as e:
        say("%s: cannot judge: %s" % (ME, e))
        return 2
    after, over = net(have, allow)
    fails += over + [line for rose, line in compare(have, after, entries)]
    for metric in METRICS:
        say("%s=%d" % (metric, sum(len(found) for found in have[metric].values())))
    for line in fails:
        say("%s: FAIL %s" % (ME, line))
    if fails:
        say("%s: %d failure(s). To lower the baseline after a finding left: python3 scripts/%s.py --write-baseline" % (ME, len(fails), ME))
    return 1 if fails else 0
