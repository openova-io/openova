# CMP-022 — The console stops claiming what does not exist

## In plain words

**The problem today.** The compliance pages of the console show things that do not exist. A strip of eight regulatory frameworks is offered as a filter, but no policy is tagged with a framework, so the filter does nothing. A Security Lead page is the same page in other colours, and the page of one policy has a mode switch whose request changes nothing the engine reads.

**What changes.** The framework list and its chips, the Security Lead page with its routes and the mode switch are deleted. The page of one policy shows the mode the API reports, says where the mode is changed, and asks the API for that policy's violations only.

**Done means:**

- No page of the console offers a regulatory-framework filter, and the console source holds no framework list.
- The addresses of the Security Lead page answer with no page of their own; the compliance dashboard, the page of one policy and the runtime page keep their addresses.
- The page of one policy shows the mode as Enforce or Audit with the sentence Mode is changed from the Policies screen, and offers no control that changes it.
- The page of one policy asks the API only for the violations of that policy.
- The browser test of the compliance pages has no case for the deleted page or the switch, and it passes.

The rest of this ticket is the exact instruction for the model that does the work.
