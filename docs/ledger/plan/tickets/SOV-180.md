# SOV-180 — The API serves the Sovereign's mode and variables, with the contract's defaults

## In plain words

**The problem today.** The API cannot say whether it runs as a mothership or as a Sovereign, where its Sovereign pulls from, or how far the hand-over has gone: no code reads the variables document, and nothing records that the hand-over happened. The console therefore guesses the mode. Every session that a Sovereign signs before its cutover names the mothership as its issuer.

**What changes.** The API reads the mode, the source and the release from the variables document while it runs, and the phase from the cutover status, and reports them on the route the console already calls. The hand-over import records the phase. A Sovereign signs its sessions with its own console address.

**Done means:**

- The self route of a Sovereign answers its mode, source, phase, custody holder, release and Kubernetes version.
- A Sovereign whose variables document holds only the bootstrap-kit keys answers with the contract defaults: mode sovereign, source origin, channel stable.
- The mothership still answers 404 not-a-sovereign on that route, and the answer now names the mode mothership.
- After the hand-over archive is stored, the cutover status records phase HandedOver, and a later phase is never set back.
- A Sovereign without the issuer override signs its sessions with https://console. followed by its own name; the mothership keeps its own address.
- The handler code of the API does not grow, and no guard count rises.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The API of every Sovereign knows at run time what it is and how far it has come, and says so on the route the console already calls. `GET /api/v1/sovereign/self` answers, besides `deploymentId` and `sovereignFQDN`, the fields `mode`, `phase`, `consume`, `custodyHolder`, `release` (`channel`, `version`) and `kubernetesVersion`. The mode, the source and the release are read from the variables document, the ConfigMap `flux-system/sovereign-variables` of contract C5 (`docs/contracts/c5-upstream-variables.schema.json`); the phase and the custody holder from the cutover status ConfigMap; the version from the cluster. A key that is absent gives its contract default, so a new Sovereign whose document holds only the bootstrap-kit keys answers correctly today. The hand-over import (`POST /api/v1/handover/tofu-archive`) records `phase: HandedOver` once the archive is stored. `pinIssuer()` returns the Sovereign's own console address. This is the first part of package SOV-180; the rest is named in field 11.

## 3. The model (the law)
1. **One new package serves the route.** `products/catalyst/bootstrap/api/internal/sovself` (file `sovself.go`) holds the route `Route` with the method `Serve`, registered in `products/catalyst/bootstrap/api/cmd/api/routes_sovereign.go` as `sovself.New(h.SovereignSelf, d.log).Serve`. New code goes in a new package: the handler package may not grow (guard `scripts/check-api-structure.py`).
2. **The handler keeps only the identity.** In `internal/handler/sovereign_self.go` the method `HandleSovereignSelf(w, r)` becomes `SovereignSelf(r) (deploymentID, fqdn string, ok bool)` with the same resolution order as before; `ok` is false where the old method answered 404. The type `SovereignSelfResponse` and the unused `var _ = context.Background` are deleted. The method count stays 637.
3. **Reading the variables document.** The route reads `flux-system/sovereign-variables` (the constants `upstream.Namespace` and `upstream.Name` of `core/controllers/pkg/upstream`). Each of the four keys it needs is read on its own: a value the contract allows is taken, an absent key or a value the contract does not allow gives the contract default. The defaults and the allowed values are those of the schema: `SOVEREIGN_MODE` `sovereign` (`sovereign`, `mothership`), `SOVEREIGN_CONSUME` `origin` (`origin`, `local`), `RELEASE_CHANNEL` `stable` (`stable`, `candidate`, `edge`), `RELEASE_VERSION` `''` (pattern `^$|^[0-9]+\.[0-9]+\.[0-9]+(-[0-9A-Za-z.-]+)?$`). `upstream.Load` is not used here: it refuses a document without every required key, and the documents of today hold the kit keys only.
4. **A cluster without the document.** It was installed before contract C5. Its mode follows the marker such a process already carries (`main.go` and `sovereign_self.go` use it today): without `SOVEREIGN_FQDN` the process is the mothership, with it a Sovereign. No new environment variable, and no host name decides the mode. The route does not answer 503 in that case: the console resolves the deployment id from this route on every Sovereign installed before contract C5.
5. **The phase and the custody holder.** They are read from the cutover status ConfigMap: `catalyst/self-sovereign-cutover-status`, or the namespace and name in `CATALYST_CUTOVER_NAMESPACE` and `CATALYST_CUTOVER_STATUS_CONFIGMAP`, as the cutover engine reads them. `phase` is `HandedOver` or `Independent` when the key holds one of them, and `Bootstrapping` otherwise. `custodyHolder` is `self` when the key holds `self`, and `parent` otherwise. `kubernetesVersion` is the `GitVersion` of the server.
6. **Reads are bounded.** The route is outside the session gate, so one answer is kept for 15 seconds (`CacheTTL`). Each read has 5 seconds: the context of the two ConfigMap reads and the timeout of the in-cluster client, which also bounds the server-version read. A read that fails for a reason other than an absent object is logged, counts as an absent object, and that answer is not kept. Without a cluster client the route answers with the defaults.
7. **The mothership answer.** Where `SovereignSelf` returns `ok` false, the route answers 404 with the same body as before (`error` `not-a-sovereign`, `detail`, `status` 404, `code` `"404"`) and the field `mode` added.
8. **The phase writer.** `ReceiveTofuArchive` in `internal/handler/handover.go`, after the archive is sealed in OpenBao, calls `markHandedOver`. It reads the status ConfigMap with `readCutoverStatus` and, only when `phase` is empty, writes `phase: HandedOver` with `patchCutoverStatus`, the merge patch the sequencer already uses (it creates the ConfigMap when absent). A recorded phase is never changed back. A failure is logged and does not fail the hand-over. No new cluster write call is added (guard `scripts/check-no-direct-cluster-write.py`).
9. **The session issuer.** `handoverjwt.OwnIssuer()` (new, `internal/handoverjwt/signer.go`) returns `https://console.<SOVEREIGN_FQDN>` (trimmed, lower case, without a final dot), and the mothership origin when `SOVEREIGN_FQDN` is empty. `pinIssuer()` in `internal/handler/auth.go` returns `CATALYST_PIN_ISSUER` when set, as before, and `handoverjwt.OwnIssuer()` otherwise. `MothershipIssuer()`, `DefaultIssuer()` and the accepted issuers of a hand-over token do not change.
10. **Baselines and tables.** The handler package shrinks by two lines, so `scripts/baselines/api-structure.json` lowers `handler_lines` from 98125 to 98123 in the same change. The route table `cmd/api/testdata/routes.golden` names the new handler of the self route. The route is a GET, so contract C9 (`docs/contracts/C9-mutating-routes.yaml`) does not change.
11. **The test workflow reads what the test reads.** The new test `TestDefaultsAreTheContracts` reads `docs/contracts/c5-upstream-variables.schema.json`, so `.github/workflows/test-bootstrap-api.yaml` gains that path in both trigger lists.
12. Nothing else changes: no chart, no kit file, no contract file, no environment variable, no Service, no `main.go`.

+// (its deployment id and its name) and the run-time state the console
+// reads: the mode, the hand-over phase, where it pulls charts and packages
+// from, who holds custody, the release it follows and its Kubernetes
+// version.

+// The mode, the source and the release come from the variables document:
+// the ConfigMap flux-system/sovereign-variables (contract C5, published as
+// docs/contracts/c5-upstream-variables.schema.json). Each key is read on

+// Serve answers the route. On a process that is not on a Sovereign it

+func (rt *Route) Serve(w http.ResponseWriter, r *http.Request) {

+			"mode":   s.mode,
+			"status": http.StatusNotFound,
+			"code":   "404",
+		})
+		return
+	}
+	writeJSON(w, http.StatusOK, Response{
+		DeploymentID:      id,
+		SovereignFQDN:     fqdn,
+		Mode:              s.mode,
+		Phase:             s.phase,
+		Consume:           s.consume,
+		CustodyHolder:     s.custody,
+		Release:           Release{Channel: s.channel, Version: s.version},
+		KubernetesVersion: s.kube,

+// current returns the kept answer while it is younger than CacheTTL, and
+// reads the cluster otherwise.
+func (rt *Route) current() state {
+	rt.mu.Lock()
+	defer rt.mu.Unlock()
+	if rt.haveKept && rt.now().Sub(rt.keptAt) < CacheTTL {
+		return rt.kept
+	}
+	ctx, cancel := context.WithTimeout(context.Background(), readTimeout)
+	defer cancel()
+	s, complete := rt.read(ctx)
+	if complete {
+		rt.kept, rt.keptAt, rt.haveKept = s, rt.now(), true
+	}
+	return s
+}

+// read reads the two ConfigMaps and the server version. complete is false
+// when a read failed for another reason than an absent object.
+func (rt *Route) read(ctx context.Context) (state, bool) {
+	legacyMothership := strings.TrimSpace(rt.env("SOVEREIGN_FQDN")) == ""
+	if rt.client == nil {
+		c, err := rt.newClient()
+		if err != nil {
+			rt.log.Warn("sovereign self: no cluster client; answering with the defaults", "err", err)
+			return resolve(nil, false, legacyMothership, nil, ""), false
+		}
+		rt.client = c
+	}
+	vars, present, varsRead := rt.configMap(ctx, upstream.Namespace, upstream.Name)
+	ns := strings.TrimSpace(rt.env("CATALYST_CUTOVER_NAMESPACE"))
+	if ns == "" {
+		ns = "catalyst"
+	}
+	name := strings.TrimSpace(rt.env("CATALYST_CUTOVER_STATUS_CONFIGMAP"))
+	if name == "" {
+		name = "self-sovereign-cutover-status"
+	}
+	status, _, statusRead := rt.configMap(ctx, ns, name)
+	complete := varsRead && statusRead
+	kube := ""
+	if v, err := rt.client.Discovery().ServerVersion(); err == nil {
+		kube = v.GitVersion
+	} else {
+		rt.log.Warn("sovereign self: cannot read the server version", "err", err)
+		complete = false
+	}
+	return resolve(vars, present, legacyMothership, status, kube), complete
+}

+// configMap returns the data of one ConfigMap. present is false when it
+// does not exist; ok is false when it could not be read.
+func (rt *Route) configMap(ctx context.Context, ns, name string) (data map[string]string, present, ok bool) {
+	cm, err := rt.client.CoreV1().ConfigMaps(ns).Get(ctx, name, metav1.GetOptions{})
+	switch {
+	case err == nil:

+	case apierrors.IsNotFound(err):
+		return nil, false, true
+	default:
+		rt.log.Warn("sovereign self: cannot read a ConfigMap; it counts as absent", "namespace", ns, "name", name, "err", err)
+		return nil, false, false
+	}
+}

+// resolve turns what was read into the answer. vars is the data of the
+// variables document and present tells whether it exists; status is the
+// data of the cutover status ConfigMap.
+func resolve(vars map[string]string, present, legacyMothership bool, status map[string]string, kube string) state {
+	s := state{
+		mode:    contractValue(vars, "SOVEREIGN_MODE"),
+		consume: contractValue(vars, "SOVEREIGN_CONSUME"),
+		channel: contractValue(vars, "RELEASE_CHANNEL"),
+		version: contractValue(vars, "RELEASE_VERSION"),
+		phase:   PhaseBootstrapping,
+		custody: "parent",
+		kube:    kube,
+	}
+	if !present && legacyMothership {
+		s.mode = ModeMothership
+	}
+	switch p := strings.TrimSpace(status["phase"]); p {
+	case "HandedOver", "Independent":
+		s.phase = p
+	}
+	if strings.TrimSpace(status["custodyHolder"]) == "self" {
+		s.custody = "self"
+	}
+	return s
+}

+// contractValue returns the value of key in vars when the contract allows
+// it, and the contract default otherwise.
+func contractValue(vars map[string]string, key string) string {

+		v = strings.TrimSpace(v)
+		if contractAllows[key](v) {
+			return v
+		}
+	}
+	return contractDefaults[key]
+}

+func TestDefaultsAreTheContracts(t *testing.T) {
+	raw, err := os.ReadFile(filepath.Clean(schemaPath))

+			Enum    []string `json:"enum"`
+			Pattern string   `json:"pattern"`

+		if !ok {
+			t.Errorf("%s: not a key of the schema", key)

+		}
+		if p.Default == nil || *p.Default != want {
+			t.Errorf("%s: this package's default is %q, the schema's is %v", key, want, p.Default)
+		}
+		for _, v := range p.Enum {
+			if !contractAllows[key](v) {
+				t.Errorf("%s: the schema allows %q and this package does not", key, v)
+			}
+		}
+		if len(p.Enum) > 0 && contractAllows[key]("not-a-value") {
+			t.Errorf("%s: this package allows a value the schema does not", key)
+		}
