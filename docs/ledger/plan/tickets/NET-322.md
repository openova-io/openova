# NET-322 — Class file, schema and conformance probe as a suite profile

## In plain words

**The problem today.** A cluster class says what a cluster can do: which network policies it enforces, whether it runs without kube-proxy, whether the gateway binds port 443 on chosen nodes, and more. Decision record 0037 admits a second class beside the reference class, but no file holds a class, nothing says what a class file may contain, and no test checks that a cluster can do what its class declares.

**What changes.** The repository holds the schema of a class file, the reference class and the managed class. The acceptance suite gains a check that reads the class of the regions and probes, in every region, each capability the class declares; the list of checks makes it required.

**Done means:**

- The reference class and the managed class are files that the schema accepts, and the managed class holds exactly the text that decision record 0037 shows.
- The class of one provider lives in that provider's own folder; the shared folder holds only classes that name no provider.
- For each capability the class declares, a broken cluster fails exactly the probe of that capability, in every region.
- A capability the class declares false is not probed, and the check names it as not applicable.
- The check fails when two Pods share an address, and it deletes what it created, also after a failure.
- The list of checks makes the check required and names its file.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A cluster class is a data file: one boolean per capability flag. `platform/cluster-classes/` holds the schema `schema.json`, the reference class `reference-k3s-cilium.yaml` (every flag true) and a README with the probe of each flag. The managed class of ADR-0037 MC6, `cce-standard-vpc`, lives in the pack of its provider, `infra/providers/huawei/cluster-classes/cce-standard-vpc.yaml`, with exactly the content that MC6 shows. The acceptance suite under `tests/acceptance/sovereign/` reads both folders with a reader of its own (standard library only) and has gate check NET-G17 in `check_cluster_class.go`: in every region of a gate run it checks that the nodes run the class's distribution, runs the probe of every flag the class declares `true`, names every flag declared `false` as not applicable, and fails when two Pods share an address. The gate manifest makes NET-G17 `required` and names its file. The tests of the reader and of the check run on every pull request without a cluster.

## 3. The model (the law)
1. The eight new files are the result of the embedded patch `NET-322.patch` and of nothing else; work step 5 states their checksums. `docs/ledger/gates.yaml` is changed by work step 6 only (two lines added, one removed, all in the entry NET-G17). `tests/acceptance/sovereign/README.md` is changed by work steps 8 to 10 only. `docs/generated/components.md` is written by its generator in work step 12 only.
2. A class file has the fields `name` (the file name without `.yaml`), `kind` (`reference`, `managed-byo-cilium`, `managed-native-cilium`, `managed-chained` or `managed-opaque`), `provider` (`any` or a provider pack), `distribution`, `mayHostControlPlane`, `capabilities` (each of the 13 flags of the schema, `true` or `false`) and `notes` (optional). `lb.noNodePort` is the constant `true`: a class whose public entry needs a node port is not admitted (ADR-0026).
3. The reader (`cluster_class.go`) reads a subset of YAML so that what it reads is what every YAML reader reads: `key: value` lines, the two-space indented lines of `capabilities`, blank lines and comment lines. It refuses every other line, a key given twice, and a value that YAML 1.1 reads as a boolean or null other than `true` and `false`. It applies the schema keywords `type`, `required`, `properties`, `additionalProperties` (false only), `enum`, `const` and `pattern`, and refuses a schema that uses any other keyword, so the schema cannot hold a rule that the reader does not apply.
4. Where a class lives. `platform/cluster-classes/` holds the schema and the classes with `provider: any`. The class of one provider lives in that provider's pack, `infra/providers/<provider>/cluster-classes/<name>.yaml`, with `provider:` set to that pack's name. ADR-0037 MC6 names the path `platform/cluster-classes/cce-standard-vpc.yaml`; `scripts/check-provider-leaks.py` refuses a provider name outside the plug-in paths, so the file goes into the pack, as the category of a provider's Blueprint is declared in `infra/providers/<provider>/card-categories.yaml` while the shared file names no provider. The content is exactly the block of MC6. The reader refuses a class name that has two files, and a class in a pack whose `provider` is not the pack's name.
5. The class of every region of a run is the reference class: the suite drives the regions of the Sovereign's control plane, and only a class with `mayHostControlPlane: true` may run it (ADR-0037 MC5). A region of the managed class joins a run with NET-329.
6. The steps of NET-G17, each recorded with `checkStep` as `NET-G17.<n>`:
   1. The class file passes the schema, declares `mayHostControlPlane: true`, and every flag it declares `true` has a probe. The evidence names `probed` and `not_applicable` (the flags declared `false`). When the step fails, nothing else runs.
   2. Then per region, in the order of the run: every node runs the class's distribution (`k3s`: the kubelet version holds `+k3s`); the probe objects are in place and every probe Pod is Ready within 180 seconds; one step per flag declared `true`, in the order of the schema, with the probe of the table in `platform/cluster-classes/README.md`; no two Pods that are not on the host network and have not finished share an address (two network plug-ins on one cluster hand out the same addresses); and the namespace and the cluster-wide policy are deleted, also when an earlier step failed.
7. What the check writes, per region: a namespace `net-class-<run>` of its own, one CiliumClusterwideNetworkPolicy of the same name that selects only Pods of that namespace, and in the namespace one NetworkPolicy, two CiliumNetworkPolicies, four server Pods, two dial Pods (the `Dialer` of `check_policy_dials.go`) and one Pod on the host network of every node. It creates no Service, no DaemonSet and no node port. Everything else it reads, or runs with `kubectl exec`: `nc` and `wget` in its own Pods, `cilium-dbg status` and `hubble observe` in the Cilium agents, and the scripts of checks FND-G05 (`scripts/check-live-nodeports.sh`) and FND-G09 (`scripts/check-live-node-encryption.sh`).
8. The flags and the gate manifest. The manifest's `needs` field is a closed list of the capabilities of a run (`scripts/acceptance-gate.py` line 133), and the plan flips one check, NET-G17, for this package. So the check applies the rule of `needs` to each flag itself: a flag declared `false` is not applicable, its probe does not run, and step 1 names it. A flag declared `true` that probes `false` fails the check.
9. The entry NET-G17 of `docs/ledger/gates.yaml` has `state: required` and `implementation: tests/acceptance/sovereign/internal/suite/check_cluster_class.go`. No other line of the manifest changes.
10. A new flag goes into `schema.json` with its probe in the same change: `TestClassSchema_EveryFlagHasOneProbe` fails otherwise, and step 1 refuses a class that declares `true` a flag without a probe. The suite keeps using the Go standard library only. No chart, no Python and no yq are added or changed. This ticket deletes no file.

+## The file
+
+`schema.json` is the schema. Fields: `name` (the file name without
+`.yaml`), `kind` (`reference`, `managed-byo-cilium`, `managed-native-cilium`,
+`managed-chained` or `managed-opaque`), `provider` (`any` or a provider pack),

+schema, `true` or `false`) and `notes` (optional). `lb.noNodePort` must be
+`true`: a class whose public entry needs a node port is not admitted

+
+A class file uses a subset of YAML, so that the acceptance suite, a module of
+the standard library only, reads it as every YAML reader does: `key: value`
+lines, the two-space indented lines of `capabilities`, blank lines and comment
+lines; a value is `true`, `false` or text that starts with a letter and holds
+neither `: ` nor ` #`. The reader is
+`tests/acceptance/sovereign/internal/suite/cluster_class.go`; it refuses any
+other line, and any keyword in `schema.json` that it does not apply.

+func (c clusterClassCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
+	if len(cc.Regions) == 0 {
+		return errors.New("the run has no region")
+	}
+	var class *Class
+	var flags []string
+	ok := checkStep(rec, clusterClassID, 1, "the class "+c.class+" of the regions of the run is a valid class file that may host the control plane", func(ev Evidence) error {
+		schema, err := ReadClassSchema(cc.RepoRoot)
+		if err != nil {
+			return err
+		}
+		if class, err = ReadClass(cc.RepoRoot, schema, c.class); err != nil {
+			return err
+		}
+		flags = schema.Flags
+		probed, na, unknown := []string{}, []string{}, []string{}
+		for _, f := range flags {
+			_, has := probeFor(f)
+			switch {
+			case !class.Capabilities[f]:
+				na = append(na, f)
+			case !has:
+				unknown = append(unknown, f)
+			default:
+				probed = append(probed, f)
+			}
+		}
+		ev["class"], ev["kind"], ev["distribution"], ev["probed"], ev["not_applicable"] = class.Name, class.Kind, class.Distribution, probed, na
+		if len(unknown) > 0 {
+			return fmt.Errorf("the class declares %v true, and the suite has no probe for them", unknown)
+		}
+		if !class.MayHostControlPlane {
+			return fmt.Errorf("the class %s declares mayHostControlPlane false, and every region of the run runs the Sovereign's control plane", class.Name)
+		}
+		return nil
+	})
+	if !ok {
+		return nil
+	}
+	run := strings.ToLower(NewRunID(time.Now()))
+	n := 1
+	for _, region := range cc.Regions {
+		n = c.runRegion(ctx, cc, rec, region, class, flags, run, n)
+	}
+	return nil
+}

+func (c clusterClassCheck) runRegion(ctx context.Context, cc *CheckContext, rec StepRecorder, region kube.Region, class *Class, flags []string, run string, n int) int {
+	ns := "net-class-" + run
+	p := &classRegion{kubectl: c.kubectl, region: region, cc: cc, ns: ns, run: run,
+		dialer: &Dialer{Kubectl: c.kubectl, Region: region, Run: run},
+		client: DialSource{Namespace: ns, Labels: map[string]string{classRoleLabel: "client"}},
+		fqdn:   DialSource{Namespace: ns, Labels: map[string]string{classRoleLabel: "fqdn"}}}
+	in := " in region " + region.ID
+	n++
+	nodesRead := checkStep(rec, clusterClassID, n, "every node"+in+" runs the distribution "+class.Distribution, func(ev Evidence) error {
+		var err error
+		if p.nodes, err = p.list(ctx, "", "nodes"); err != nil {
+			return err
+		}
+		return judgeDistribution(class.Distribution, p.nodes, ev)
+	})
+	created, policy := false, false
+	n++
+	started := nodesRead && checkStep(rec, clusterClassID, n, "the probe Pods and policies are in place in the namespace "+ns+in, func(ev Evidence) error {
+		ev["namespace"] = ns
+		if _, err := c.kubectl(region, ctx, nil, "create", "namespace", ns); err != nil {
+			return err
+		}
+		created, policy = true, true // a create that fails half way may leave the cluster-wide policy
+		return p.setUp(ctx, ev)
+	})
+	if started {
+		for _, f := range flags {
+			probe, _ := probeFor(f)
+			if !class.Capabilities[f] {
+				continue
+			}
+			n++
+			checkStep(rec, clusterClassID, n, f+": "+probe.what+in, func(ev Evidence) error {
+				ev["flag"], ev["region"] = f, region.ID
+				return probe.run(ctx, p, ev)
+			})
+		}
+	}
+	n++
+	checkStep(rec, clusterClassID, n, "no two Pods"+in+" share an address", func(ev Evidence) error {
+		pods, err := p.list(ctx, "", "pods", "-A")
+		if err != nil {
+			return err
+		}
+		return judgePodAddresses(pods, ev)
+	})
+	if created || policy {
+		n++
+		checkStep(rec, clusterClassID, n, "the namespace "+ns+" and the CiliumClusterwideNetworkPolicy "+ns+in+" are deleted", func(Evidence) error {
+			cleanup, cancel := context.WithTimeout(context.WithoutCancel(ctx), time.Minute)
+			defer cancel()
+			var errs []error
+			if _, err := c.kubectl(region, cleanup, nil, "delete", "ciliumclusterwidenetworkpolicy", ns, "--wait=false", "--ignore-not-found"); err != nil {
+				errs = append(errs, err)
+			}
+			if created {
+				if _, err := c.kubectl(region, cleanup, nil, "delete", "namespace", ns, "--wait=false", "--ignore-not-found"); err != nil {
+					errs = append(errs, err)
+				}
+			}
+			return errors.Join(errs...)
+		})
+	}
+	return n
+}

+// distributionRules say how a node shows its distribution.
+var distributionRules = map[string]func(node kube.Object) bool{
+	"k3s": func(node kube.Object) bool {
+		return strings.Contains(node.Str("status", "nodeInfo", "kubeletVersion"), "+k3s")
+	},
+}

+func judgeDistribution(distribution string, nodes []kube.Object, ev Evidence) error {
+	rule, ok := distributionRules[distribution]
+	if !ok {
+		return fmt.Errorf("the suite has no rule to tell distribution %q from a node", distribution)
+	}
+	versions, other := map[string]string{}, []string{}
+	for _, node := range nodes {
+		versions[node.Name()] = node.Str("status", "nodeInfo", "kubeletVersion")
+		if !rule(node) {
+			other = append(other, node.Name())
+		}
+	}
+	ev["kubelet_versions"] = versions
+	switch {
+	case len(nodes) == 0:
+		return errors.New("the region has no node")
+	case len(other) > 0:
+		return fmt.Errorf("the nodes %v do not run %s", other, distribution)
+	}
+	return nil
+}

+// judgePodAddresses fails when two Pods that are not on the host network and
+// have not finished hold one address.
+func judgePodAddresses(pods []kube.Object, ev Evidence) error {
+	holders := map[string][]string{}
+	for _, pod := range pods {
+		phase := pod.Str("status", "phase")
+		if pod.Get("spec", "hostNetwork") == true || phase == "Succeeded" || phase == "Failed" {
+			continue
+		}
+		ips := []string{}
+		for _, x := range pod.Objects("status", "podIPs") {
+			ips = append(ips, x.Str("ip"))
+		}
+		if len(ips) == 0 && pod.Str("status", "podIP") != "" {
+			ips = append(ips, pod.Str("status", "podIP"))
+		}
+		for _, ip := range ips {
+			holders[ip] = append(holders[ip], pod.Namespace()+"/"+pod.Name())
+		}
+	}
+	shared := map[string][]string{}
+	for ip, who := range holders {
+		if len(who) > 1 {
+			shared[ip] = who
+		}
+	}
+	ev["addresses"], ev["shared"] = len(holders), shared
+	switch {
+	case len(holders) == 0:
+		return errors.New("no Pod address was read")
+	case len(shared) > 0:
+		return fmt.Errorf("two Pods or more share an address: %v", shared)
+	}
+	return nil
+}

+// setUp creates the policies first, so that every probe Pod starts under
+// them, then the Pods, and waits until every Pod is Ready.
+func (p *classRegion) setUp(ctx context.Context, ev Evidence) error {
+	if err := p.create(ctx, classPolicies(p.ns)); err != nil {
+		return err
+	}
+	pods := []any{}
+	for _, role := range classServerRoles {
+		pods = append(pods, classPod(p.ns, "class-"+role+"-"+p.run, p.run, role, "", []string{"sh", "-c", classServerLoop}))
+	}
+	for i, node := range p.nodes {
+		pods = append(pods, classPod(p.ns, "class-node-"+p.run+"-"+strconv.Itoa(i+1), p.run, "node", node.Name(), []string{"sleep", dialPodLife}))
+	}
+	if err := p.create(ctx, pods); err != nil {
+		return err
+	}
+	if err := p.dialer.Start(ctx, []DialSource{p.client, p.fqdn}); err != nil {
+		return err
+	}
+	if _, err := p.kubectl(p.region, ctx, nil, "-n", p.ns, "wait", "--for=condition=Ready", "pod", "-l", classRunLabel+"="+p.run, "--timeout="+classWait); err != nil {
+		return fmt.Errorf("the probe Pods are not Ready: %v", err)
+	}
+	all, err := p.list(ctx, p.ns, "pods")
+	if err != nil {
+		return err
+	}
+	p.servers, p.onNode, p.podNode = map[string]kube.Object{}, map[string]kube.Object{}, map[string]string{}
+	for _, pod := range all {
+		p.podNode[pod.Name()] = pod.Str("spec", "nodeName")
+		switch role := pod.Str("metadata", "labels", classRoleLabel); {
+		case pod.Str("metadata", "labels", classRunLabel) != p.run:
+		case role == "node":
+			p.onNode[pod.Str("spec", "nodeName")] = pod
+		case slices.Contains(classServerRoles, role):
+			p.servers[role] = pod
+		}
+	}
+	ev["servers"], ev["node_probes"], ev["dial_pods"] = len(p.servers), len(p.onNode), p.dialer.Pods()
+	for _, role := range classServerRoles {
+		if p.servers[role].Str("status", "podIP") == "" {
+			return fmt.Errorf("the server Pod %s has no address", role)
+		}
+	}
+	for _, node := range p.nodes {
+		if p.onNode[node.Name()].Str("status", "hostIP") == "" {
+			return fmt.Errorf("no probe Pod with a host address runs on the node %s", node.Name())
+		}
+	}
+	return nil
+}

+// classPolicies are the policies of the probes, the cluster-wide one last.

+			"spec": map[string]any{"podSelector": role("k8s"), "policyTypes": []string{"Ingress"}}},
+		map[string]any{"apiVersion": "cilium.io/v2", "kind": "CiliumNetworkPolicy", "metadata": map[string]any{"name": "class-l7", "namespace": ns},
+			"spec": map[string]any{"endpointSelector": role("l7"), "ingress": []any{map[string]any{
+				"fromEndpoints": []any{role("client")},
+				"toPorts": []any{map[string]any{"ports": []any{port(strconv.Itoa(classPort), "TCP")},
+					"rules": map[string]any{"http": []any{map[string]any{"method": "GET", "path": "/allowed"}}}}}}}}},
+		map[string]any{"apiVersion": "cilium.io/v2", "kind": "CiliumNetworkPolicy", "metadata": map[string]any{"name": "class-fqdn", "namespace": ns},
+			"spec": map[string]any{"endpointSelector": role("fqdn"), "egress": []any{map[string]any{
+				"toEndpoints": []any{map[string]any{"matchLabels": map[string]any{"io.kubernetes.pod.namespace": "kube-system", "k8s-app": "kube-dns"}}},
+				"toPorts": []any{map[string]any{"ports": []any{port("53", "UDP"), port("53", "TCP")},
+					"rules": map[string]any{"dns": []any{map[string]any{"matchName": strings.TrimSuffix(fqdnAllowed, ".")}}}}}}}}},
+		map[string]any{"apiVersion": "cilium.io/v2", "kind": "CiliumClusterwideNetworkPolicy", "metadata": map[string]any{"name": ns},

+				"endpointSelector": map[string]any{"matchLabels": map[string]any{"io.kubernetes.pod.namespace": ns, classRoleLabel: "cilium"}},
+				"ingress":          []any{map[string]any{"fromEntities": []string{"ingress"}}}}},
+	}

+// classPod is a probe Pod, built like the dial Pod of check_policy_dials.go.
+// With a node it runs on the host network of that node and tolerates every
+// taint, so that one runs on every node.
+func classPod(ns, name, run, role, node string, command []string) map[string]any {
+	spec := map[string]any{
+		"restartPolicy": "Never", "terminationGracePeriodSeconds": 1,
+		"automountServiceAccountToken": false, "enableServiceLinks": false,
+		"securityContext": map[string]any{"runAsNonRoot": true, "runAsUser": 65534, "runAsGroup": 65534,
+			"seccompProfile": map[string]any{"type": "RuntimeDefault"}},
+		"containers": []any{map[string]any{
+			"name": "probe", "image": secProbeImage, "command": command,
+			"securityContext": map[string]any{"allowPrivilegeEscalation": false, "readOnlyRootFilesystem": true,
+				"capabilities": map[string]any{"drop": []string{"ALL"}}},
+			"resources": map[string]any{"requests": map[string]any{"cpu": "10m", "memory": "16Mi"},
+				"limits": map[string]any{"memory": "64Mi"}},
+		}},
+	}
+	if node != "" {
+		spec["nodeName"], spec["hostNetwork"], spec["dnsPolicy"] = node, true, "ClusterFirstWithHostNet"
+		spec["tolerations"] = []any{map[string]any{"operator": "Exists"}}
+	}
+	return map[string]any{"apiVersion": "v1", "kind": "Pod",
+		"metadata": map[string]any{"name": name, "namespace": ns, "labels": map[string]any{classRunLabel: run, classRoleLabel: role}},
+		"spec":     spec}
+}

+// openThenShut dials the server without a policy, which must connect, and the
+// server of role, which a policy of the probe selects, which must time out.
+func (p *classRegion) openThenShut(ctx context.Context, ev Evidence, role string) error {
+	for _, d := range []struct{ role, expect string }{{"open", "allow"}, {role, "deny"}} {
+		to := p.serverTarget(d.role)
+		res, err := p.dialer.Dial(ctx, p.client, to)

+		}
+		ev[d.role+"_server"] = res.Outcome
+		if err := judgeDial(DialRow{Name: d.role, From: p.client, To: to, Expect: d.expect}, res); err != nil {
+			return fmt.Errorf("the %s server: %v", d.role, err)
+		}
+	}
+	return nil
+}

+// probePolicyFQDN: the DNS-name rule of the policy class-fqdn names only
+// fqdnAllowed, so Cilium's DNS proxy answers that name to the Pod it selects
+// and refuses every other. The other name connects from the client Pod, which
+// no policy selects, so the drop is the rule's.
+func probePolicyFQDN(ctx context.Context, p *classRegion, ev Evidence) error {
+	for _, c := range []struct {
+		from DialSource
+		key  string
+		ok   func(string) bool
+		want string
+	}{
+		{p.client, "without_rule", func(o string) bool { return o == DialConnected }, "connected"},
+		{p.fqdn, "with_rule", func(o string) bool { return o == DialUnresolved || o == DialTimedOut }, "unresolved or timed-out"},
+	} {
+		res, err := p.dialNames(ctx, c.from, fqdnOther, 443)
+		if err != nil {
+			return err
+		}
+		ev[c.key+"_allowed_name"], ev[c.key+"_other_name"] = res.Control, res.Outcome
+		if res.Control != DialConnected {
+			return fmt.Errorf("from %s the allowed name %s:53 %s (%s), want connected", c.from.key(), fqdnAllowed, res.Control, res.ControlOutput)
+		}
+		if !c.ok(res.Outcome) {
+			return fmt.Errorf("from %s the name %s:443 %s (%s), want %s", c.from.key(), fqdnOther, res.Outcome, res.Output, c.want)
+		}
+	}
+	return nil
+}

+// dialNames dials fqdnAllowed on port 53, then host, from the dial Pod of s,
+// again while the first dial does not connect, as Dialer.Dial does.
+func (p *classRegion) dialNames(ctx context.Context, s DialSource, host string, port int) (DialResult, error) {
+	deadline := time.Now().Add(dialNetworkWait)
+	for {
+		b, err := p.kubectl(p.region, ctx, strings.NewReader(dialScript), "-n", p.ns, "exec", "-i", p.dialPod(s), "-c", "dial", "--",
+			"sh", "-s", "--", fqdnAllowed, "53", host, strconv.Itoa(port))
+		if err != nil {
+			return DialResult{}, fmt.Errorf("run the dial in %s/%s: %v", p.ns, p.dialPod(s), err)
+		}
+		v := map[string]string{}
+		for _, line := range strings.Split(string(b), "\n") {
+			if k, val, found := strings.Cut(line, "="); found {
+				v[k] = strings.TrimSpace(val)
+			}
+		}
+		res := DialResult{Control: dialOutcome(v["control_rc"], v["control_out"]), ControlOutput: v["control_out"],

+// Cluster classes (ADR-0037). A class file <name>.yaml declares what a cluster
+// of its class can do: one boolean per capability flag. A class that names no
+// provider lives in platform/cluster-classes/; the class of one provider lives
+// in its pack, infra/providers/<provider>/cluster-classes/ (ClassFiles). Check
+// NET-G17 (check_cluster_class.go) reads the class of the regions of the run
+// with ReadClass and probes every flag that the class declares true.
+//
+// The suite is a module of the standard library only, so ReadClass reads the
+// subset of YAML that a class file may use and refuses every other line, so
+// that what it reads is what any YAML reader reads: "key: value" at the left
+// margin; one map, "capabilities:", whose lines "flag: value" are indented by
+// exactly two spaces; blank lines; and lines whose first character other than a
+// space is #. A value is true or false, or text that starts with a letter, is
+// not a word that YAML 1.1 reads as a boolean or as null, and holds neither
+// ": " nor " #". A key is given once.
+//
+// The schema platform/cluster-classes/schema.json then judges the document.
+// ReadClassSchema applies the keywords type, required, properties,
+// additionalProperties (false only), enum, const and pattern, and the
+// annotations $schema, $id, title and description; a schema that uses any
+// other keyword is refused, so the schema can never hold a rule that the
+// reader does not apply.
+const (
+	classDir      = "platform/cluster-classes"
+	classPackGlob = "infra/providers/*/cluster-classes/*.yaml"
+	classSchema   = "platform/cluster-classes/schema.json"
+	classMap      = "capabilities" // the one key whose value is a map
+)
+
+// Class is one class file.
+type Class struct {
+	Name, Kind, Provider, Distribution, Notes string
+	MayHostControlPlane                       bool
+	Capabilities                              map[string]bool
+}

+// ClassSchema is the schema of the class files. Flags are the capability
+// flags in the order of the schema's required list of capabilities.
+type ClassSchema struct {
+	root  *schemaNode
+	Flags []string
+}

+type schemaNode struct {
+	Type                 string                 `json:"type"`
+	Required             []string               `json:"required"`
+	Properties           map[string]*schemaNode `json:"properties"`
+	AdditionalProperties *bool                  `json:"additionalProperties"`
+	Enum                 []any                  `json:"enum"`
+	Const                any                    `json:"const"`
+	Pattern              string                 `json:"pattern"`
+	pattern              *regexp.Regexp
+}

+// schemaKeywords are the keywords that ReadClassSchema accepts.
+var schemaKeywords = []string{"$schema", "$id", "title", "description", "type", "required", "properties",
+	"additionalProperties", "enum", "const", "pattern"}

+// ReadClassSchema reads the schema of the class files from the checkout at root.
+func ReadClassSchema(root string) (*ClassSchema, error) {
+	data, err := os.ReadFile(filepath.Clean(filepath.Join(root, filepath.FromSlash(classSchema))))
+	if err != nil {
+		return nil, err
+	}
+	var raw any
+	if err := json.Unmarshal(data, &raw); err != nil {
+		return nil, fmt.Errorf("%s is not JSON: %v", classSchema, err)
+	}
+	if err := checkSchemaKeywords("", raw); err != nil {
+		return nil, fmt.Errorf("%s: %v", classSchema, err)
+	}
+	var root0 schemaNode
+	if err := json.Unmarshal(data, &root0); err != nil {
+		return nil, fmt.Errorf("%s: %v", classSchema, err)
+	}
+	if err := root0.compile(""); err != nil {
+		return nil, fmt.Errorf("%s: %v", classSchema, err)
+	}
+	caps := root0.Properties[classMap]
+	if root0.Type != "object" || caps == nil || caps.Type != "object" || len(caps.Required) == 0 {
+		return nil, fmt.Errorf("%s: the root and its property %s must be objects, and %s must require its flags", classSchema, classMap, classMap)
+	}
+	listed := make([]string, 0, len(caps.Properties))
+	for k := range caps.Properties {
+		listed = append(listed, k)
+	}
+	want := slices.Clone(caps.Required)
+	sort.Strings(listed)
+	sort.Strings(want)
+	if !slices.Equal(listed, want) {
+		return nil, fmt.Errorf("%s: the flags that %s requires (%v) are not exactly the flags it describes (%v)", classSchema, classMap, caps.Required, listed)
+	}
+	return &ClassSchema{root: &root0, Flags: slices.Clone(caps.Required)}, nil
+}

+// checkSchemaKeywords refuses a keyword that the reader does not apply.
+func checkSchemaKeywords(at string, v any) error {
+	m, ok := v.(map[string]any)
+	if !ok {
+		return fmt.Errorf("%s is not an object", schemaPath(at))
+	}
+	for k, sub := range m {
+		if !slices.Contains(schemaKeywords, k) {
+			return fmt.Errorf("%s uses the keyword %q, which the reader does not apply", schemaPath(at), k)
+		}
+		if k != "properties" {
+			continue
+		}
+		props, ok := sub.(map[string]any)
+		if !ok {
+			return fmt.Errorf("%s.properties is not an object", schemaPath(at))
+		}
+		for name, p := range props {
+			if err := checkSchemaKeywords(at+"."+name, p); err != nil {
+				return err
+			}
+		}
+	}
+	return nil
+}

+func schemaPath(at string) string {
+	if at == "" {
+		return "the root"
+	}
+	return strings.TrimPrefix(at, ".")

+func (n *schemaNode) compile(at string) error {
+	if n.AdditionalProperties != nil && *n.AdditionalProperties {
+		return fmt.Errorf("%s: additionalProperties may only be false", schemaPath(at))
+	}
+	if n.Pattern != "" {
+		re, err := regexp.Compile(n.Pattern)
+		if err != nil {
+			return fmt.Errorf("%s: pattern: %v", schemaPath(at), err)
+		}
+		n.pattern = re
+	}
+	for k, p := range n.Properties {
+		if p == nil {
+			return fmt.Errorf("%s.%s: no schema", schemaPath(at), k)
+		}
+		if err := p.compile(at + "." + k); err != nil {
+			return err
+		}
+	}
+	return nil
+}

+// validate returns one line per rule of n that v breaks, in a stable order.
+func (n *schemaNode) validate(at string, v any) []string {
+	out := []string{}
+	switch n.Type {
+	case "object":
+		if _, ok := v.(map[string]any); !ok {
+			return []string{schemaPath(at) + ": want a map"}
+		}
+	case "string":
+		if _, ok := v.(string); !ok {
+			return []string{fmt.Sprintf("%s: want text, got %v", schemaPath(at), v)}
+		}
+	case "boolean":
+		if _, ok := v.(bool); !ok {
+			return []string{fmt.Sprintf("%s: want true or false, got %v", schemaPath(at), v)}
+		}
+	case "":
+	default:
+		return []string{fmt.Sprintf("%s: the schema's type %q is not applied by the reader", schemaPath(at), n.Type)}
+	}
+	if n.Const != nil && v != n.Const {
+		out = append(out, fmt.Sprintf("%s: must be %v, got %v", schemaPath(at), n.Const, v))
+	}
+	if len(n.Enum) > 0 && !slices.Contains(n.Enum, v) {
+		out = append(out, fmt.Sprintf("%s: %v is not one of %v", schemaPath(at), v, n.Enum))
+	}
+	if s, ok := v.(string); ok && n.pattern != nil && !n.pattern.MatchString(s) {
+		out = append(out, fmt.Sprintf("%s: %q does not match %s", schemaPath(at), s, n.Pattern))
+	}
+	m, ok := v.(map[string]any)
+	if !ok {
+		return out
+	}
+	for _, k := range n.Required {
+		if _, has := m[k]; !has {
+			out = append(out, fmt.Sprintf("%s: %s is missing", schemaPath(at), k))
+		}
+	}
+	keys := make([]string, 0, len(m))
+	for k := range m {
+		keys = append(keys, k)
+	}
+	sort.Strings(keys)
+	for _, k := range keys {
+		p, known := n.Properties[k]
+		switch {
+		case known:
+			out = append(out, p.validate(at+"."+k, m[k])...)
+		case n.AdditionalProperties != nil:
+			out = append(out, fmt.Sprintf("%s: %s is not a field of the schema", schemaPath(at), k))
+		}
+	}
+	return out
+}

+var (
+	classKeyRE  = regexp.MustCompile(`^[A-Za-z][A-Za-z0-9.]*$`)
+	classTextRE = regexp.MustCompile(`^[A-Za-z]`)
+	// classYAMLWords are the words YAML 1.1 reads as a boolean or as null.
+	classYAMLWords = []string{"y", "n", "yes", "no", "on", "off", "true", "false", "null"}

+// parseClassYAML reads the YAML subset of a class file.
+func parseClassYAML(data []byte) (map[string]any, error) {
+	doc := map[string]any{}
+	var inMap map[string]any
+	for i, line := range strings.Split(strings.TrimSuffix(string(data), "\n"), "\n") {
+		trimmed := strings.TrimLeft(line, " ")
+		if trimmed == "" || strings.HasPrefix(trimmed, "#") {
+			continue
+		}
+		indent := len(line) - len(trimmed)
+		if indent != 0 && (indent != 2 || inMap == nil) {
+			return nil, fmt.Errorf("line %d: indented by %d spaces; only the lines of %s are indented, by 2", i+1, indent, classMap)
+		}
+		key, value, found := strings.Cut(trimmed, ":")
+		if !found || !classKeyRE.MatchString(key) || (value != "" && !strings.HasPrefix(value, " ")) {
+			return nil, fmt.Errorf("line %d: not a line \"key: value\": %q", i+1, line)
+		}
+		value = strings.TrimPrefix(value, " ")
+		target := doc
+		if indent == 2 {
+			target = inMap
+		} else {
+			inMap = nil
+		}
+		if _, twice := target[key]; twice {
+			return nil, fmt.Errorf("line %d: %s is given twice", i+1, key)
+		}
+		if value == "" {
+			if indent != 0 || key != classMap {
+				return nil, fmt.Errorf("line %d: %s has no value; only %s is a map", i+1, key, classMap)
+			}
+			inMap = map[string]any{}
+			doc[key] = inMap
+			continue
+		}
+		v, err := classScalar(value)
+		if err != nil {
+			return nil, fmt.Errorf("line %d: %s: %v", i+1, key, err)
+		}
+		target[key] = v
+	}
+	return doc, nil
+}
+
+// classScalar is the value of one scalar of the subset.
+func classScalar(s string) (any, error) {
+	switch {
+	case s == "true":
+		return true, nil
+	case s == "false":
+		return false, nil
+	case strings.TrimSpace(s) != s:
+		return nil, fmt.Errorf("the value %q starts or ends with a space", s)
+	case !classTextRE.MatchString(s) || slices.Contains(classYAMLWords, strings.ToLower(s)):
+		return nil, fmt.Errorf("the value %q is neither true, false nor text that starts with a letter", s)
+	case strings.Contains(s, ": ") || strings.Contains(s, " #"):
+		return nil, fmt.Errorf("the value %q holds \": \" or \" #\", which YAML reads otherwise", s)
+	}
+	return s, nil
+}

+// ReadClass reads the class file of name from the checkout at root and judges
+// it by the schema. A file whose name field is not its file name, or whose
+// provider is not the provider of its folder, is refused.
+func ReadClass(root string, schema *ClassSchema, name string) (*Class, error) {
+	files, err := ClassFiles(root)
+	if err != nil {
+		return nil, err
+	}
+	file, ok := files[name]
+	if !ok {
+		return nil, fmt.Errorf("no class file %s.yaml in %s or %s", name, classDir, classPackGlob)
+	}
+	data, err := os.ReadFile(filepath.Clean(filepath.Join(root, filepath.FromSlash(file))))
+	if err != nil {
+		return nil, err
+	}
+	doc, err := parseClassYAML(data)
+	if err != nil {
+		return nil, fmt.Errorf("%s: %v", file, err)
+	}
+	if bad := schema.root.validate("", doc); len(bad) > 0 {
+		return nil, fmt.Errorf("%s breaks %s: %s", file, classSchema, strings.Join(bad, "; "))
+	}
+	c := &Class{Capabilities: map[string]bool{}}
+	c.Name, _ = doc["name"].(string)
+	c.Kind, _ = doc["kind"].(string)
+	c.Provider, _ = doc["provider"].(string)
+	c.Distribution, _ = doc["distribution"].(string)
+	c.Notes, _ = doc["notes"].(string)
+	c.MayHostControlPlane, _ = doc["mayHostControlPlane"].(bool)
+	for k, v := range doc[classMap].(map[string]any) {
+		c.Capabilities[k] = v.(bool)
+	}
+	if c.Name != name {
+		return nil, fmt.Errorf("%s: its name is %q, want the file name %q", file, c.Name, name)
+	}
+	if want := classFolderProvider(file); c.Provider != want {
+		return nil, fmt.Errorf("%s: its provider is %q, want %q, the provider of its folder", file, c.Provider, want)
+	}
+	return c, nil
+}
+
+// classFolderProvider is the provider that a class file of the folder of file
+// must declare: any in classDir, else the provider pack the folder belongs to.
+func classFolderProvider(file string) string {
+	if strings.HasPrefix(file, classDir+"/") {
+		return "any"
+	}
+	return strings.Split(file, "/")[2] // infra/providers/<provider>/cluster-classes/<name>.yaml
+}
+
+// ClassFiles maps the name of every class file of the checkout at root to its
+// path. A class that names no provider lives in classDir; the class of one
+// provider lives in that provider's pack (classPackGlob), since a file outside
+// the plug-in paths names no provider. A name used twice is refused.
+func ClassFiles(root string) (map[string]string, error) {
+	out := map[string]string{}
+	for _, pattern := range []string{classDir + "/*.yaml", classPackGlob} {
+		found, err := filepath.Glob(filepath.Join(root, filepath.FromSlash(pattern)))
+		if err != nil {
+			return nil, err
+		}
+		for _, f := range found {
+			rel, err := filepath.Rel(root, f)
+			if err != nil {
+				return nil, err
+			}
+			rel = filepath.ToSlash(rel)
+			name := strings.TrimSuffix(path.Base(rel), ".yaml")
+			if first, twice := out[name]; twice {
+				return nil, fmt.Errorf("the class %s has two files, %s and %s", name, first, rel)
+			}
+			out[name] = rel
+		}
+	}
+	if len(out) == 0 {
+		return nil, errors.New("no class file in " + classDir + " or " + classPackGlob)
+	}
+	return out, nil
+}
+
+// ClassNames are the names of the class files of the checkout at root, sorted.
+func ClassNames(root string) ([]string, error) {
+	files, err := ClassFiles(root)
+	if err != nil {
+		return nil, err
+	}
+	out := make([]string, 0, len(files))
+	for name := range files {
+		out = append(out, name)
+	}
+	sort.Strings(out)
+	return out, nil
+}
