# BSS-050 — Ratchets of this area

## In plain words

**The problem today.** The billing area is to converge on one plan source, one owner per money entity and a billing engine that stands apart from the platform. Nothing stops a change from going the other way meanwhile: one more place that writes a plan price, one more file that reaches Kubernetes from the engine, one more route in the frozen storefront services, or one test of the price waterfall fewer. Each later package of this area removes such places, and no check keeps them removed.

**What changes.** One guard with ten rules counts eleven things on every pull request and compares them with stored numbers. Ten counts may not rise above today's value; the count of price-waterfall tests may not fall. A package that removes a counted place lowers the stored number in its own pull request.

**Done means:**

- A pull request that adds a plan price or shape written in Go code turns red.
- A pull request that makes the billing engine import a Kubernetes or NATS library outside the places allowed for it, read a Secret object, or name a platform module in its go.mod turns red.
- A pull request that adds a route to the six storefront services, or a Kubernetes client import to the storefront back end, turns red.
- A pull request that removes or renames a test of the price waterfall turns red.
- The stored numbers are today's values: 13 plan literals, 3 collector importers, 1 Secret read, 2 tables of the second invoice system, 88 storefront routes, 2 storefront files with a Kubernetes import, 4 readers of the engine's plan shape, 7 waterfall tests, and zero for the three hard rules.
- The guard proves on itself that each of its rules can fail.
- No product code changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every pull request gets a check named `bss-ratchets`. It runs the guard `scripts/check-bss-ratchets.py`, whose ten guards count eleven things of the billing area (guard 7 counts two) and compare them with the stored numbers in `scripts/baselines/bss.json`. Ten of the counts are ceilings: a pull request that raises one fails. One, the tests of the price waterfall, is a floor: a pull request that lowers it fails. A person can read the counts on any pull request: the check prints eleven lines, from `plan_literal_sites=13` to `engine_plan_shape_callers=4`. The later packages of this area lower the ceilings, each in its own pull request, as they remove what is counted.

## 3. The model (the law)
1. The guard is the script `scripts/check-bss-ratchets.py`. It reads the files on disk under the repository root, not what git tracks. Item 2 names the folders it never enters. It needs Python 3 and nothing else.
2. Each guard is one function and returns its hits: one hit per line or one per file. A guard that reads the Go files of a folder reads every sub-folder, only files whose name ends in `.go`, and leaves out files whose name ends in `_test.go`. Guard 8 reads only the `_test.go` files. A line whose first text is `//` is a comment and never counts. A folder whose name starts with a dot, and a folder named `node_modules`, is never entered, at any depth: tools keep other checkouts, caches and installed packages there, and they are not code of this repository. No Go file that git tracks lies in such a folder (pre-flight P20).
3. An import is a line of one of the forms `"<path>"`, `<name> "<path>"`, `import "<path>"` or `import <name> "<path>"`, with an optional trailing `//` comment. A string in other code is not an import.
4. The ten guards, in the order the script prints them. "Engine" is the folder `products/chargeback`.

   The four expressions, in the order of the table:
   ```
   PriceBaisa: [0-9]|MonthlyOMR: [0-9]|CPULimit: "
   ```

5. The stored numbers are the file `scripts/baselines/bss.json`, called the baseline. Its form is its own; it is not the per-file form `openova.io/guard-baseline/v1` of the other files under `scripts/baselines`, because these guards count totals:
   ```
   {"schema": "openova.io/bss-ratchets/v1",
    "ceilings": {"<guard>": <number>, ...},
    "floors": {"waterfall_tests": <number>}}
   ```
   `ceilings` holds exactly the ten names other than `waterfall_tests`; `floors` holds exactly `waterfall_tests`. Every number is a whole number of 0 or more. There is no allow list: the number is the list.
6. The rule, for every guard. A count above its ceiling exits with code 1 and lists the hits, one per line. A count below its floor exits with code 1 and lists the tests that are left. A count below its ceiling, or above its floor, passes with a line that starts with `check-bss-ratchets: NOTE`: the package that removed a hit sets the number in the same change. Otherwise the exit code is 0. Whenever it judges, it prints one line `<guard>=<count>` per guard.
7. A guard over a path that does not exist cannot fail. So a missing scanned folder or file, a scanned folder without a Go file, and a baseline that is missing, of another schema, with another key, with another set of guard names or with a number that is not a whole number of 0 or more are never a pass: the guard judges nothing and exits with code 2.
8. `--self-test` builds small trees of its own, 63 times, and shows for each guard that it fails and for each exception that it passes. It reads nothing of the repository.
9. The workflow `.github/workflows/bss-ratchets.yaml` has the triggers `pull_request` and `merge_group` and no path filter. Its one job, `bss-ratchets`, runs the self-test first and then the guard.
10. The script, the workflow and the baseline are the three blocks of field 5, byte for byte. This ticket changes no existing file and deletes nothing.

```python
class Unreadable(Exception):
    """A scanned path or the baseline cannot be read. Nothing is judged: exit 2."""


def go_files(root, folder, tests=False):
    """Repository paths of the Go files under folder ("" is the whole tree), sorted.
    tests=False: only files not ending in _test.go; tests=True: only files ending in it.
    A folder below it whose name starts with a dot or is in SKIP_DIRS is not entered."""
    top = os.path.join(root, folder)
    if not os.path.isdir(top):
        raise Unreadable("%s is not a directory" % (folder or "the root"))
    out = []
    for here, dirs, names in os.walk(top):
        dirs[:] = sorted(d for d in dirs if not d.startswith(".") and d not in SKIP_DIRS)
        for name in names:
            if name.endswith(".go") and name.endswith("_test.go") == tests:
                out.append(os.path.relpath(os.path.join(here, name), root).replace(os.sep, "/"))
    if not out:
        raise Unreadable("%s holds no %sGo file" % (folder or "the root", "test " if tests else ""))
    return sorted(out)


def lines_of(root, path):
    full = os.path.join(root, path)
    if not os.path.isfile(full):
        raise Unreadable("%s is not a file" % path)
    with open(full, encoding="utf-8", errors="replace") as f:
        return f.read().split("\n")


def is_comment(line):
    return line.lstrip().startswith("//")


def line_hits(root, paths, pattern, skip=None):
    """'path:line' for every non-comment line of paths that matches pattern (and not skip)."""
    out = []
    for path in paths:
        for n, line in enumerate(lines_of(root, path), 1):
            if not is_comment(line) and pattern.search(line) and not (skip and skip.search(line)):
                out.append("%s:%d" % (path, n))
    return out


def import_re(prefix):
    return re.compile(r'^\s*(?:import\s+)?(?:[A-Za-z_.][A-Za-z0-9_]*\s+)?"(' + re.escape(prefix) + r'[^"]*)"\s*(?://.*)?$')


def importers(root, paths, prefix, outside=()):
    """Files of paths, not under a folder of outside, with an import line of a path starting with prefix."""
    rx, out = import_re(prefix), []
    for path in paths:
        if any(path.startswith(o + "/") for o in outside):
            continue
        if any(rx.search(line) for line in lines_of(root, path)):
            out.append(path)
    return out


# ---- the ten guards

def plan_literal_sites(root):
    return line_hits(root, go_files(root, ""), re.compile(r'PriceBaisa: [0-9]|MonthlyOMR: [0-9]|CPULimit: "'))


COLLECTOR = ENGINE + "/internal/collector"


def collector_importers(root):
    rx, out = import_re("github.com/openova-io/openova/" + COLLECTOR + "/"), []
    for path in go_files(root, ENGINE):
        own = path[len(COLLECTOR) + 1:].split("/")[0] if path.startswith(COLLECTOR + "/") else None
        for line in lines_of(root, path):
            m = rx.search(line)
            if m and m.group(1)[len("github.com/openova-io/openova/" + COLLECTOR + "/"):].split("/")[0] != own:
                out.append(path)
                break
    return out


def engine_k8s_outside_adapter(root):
    return importers(root, go_files(root, ENGINE), "k8s.io/",
                     (ENGINE + "/internal/adapter/openova", ENGINE + "/cmd/chargeback"))


def engine_platform_imports(root):
    path = ENGINE + "/go.mod"
    return ["%s:%d" % (path, n) for n, line in enumerate(lines_of(root, path), 1) if "openova-io/openova/core/" in line]


def engine_secret_reads(root):
    return line_hits(root, go_files(root, ENGINE + "/internal"), re.compile(r"Secrets\("))


def order_capture_second_system(root):
    return line_hits(root, ["core/services/billing/store/store.go"],
                     re.compile(r"CREATE TABLE IF NOT EXISTS (?:invoices|subscriptions)\b"))


def storefront_backend_routes(root):
    return line_hits(root, ["core/services/%s/handlers/routes.go" % s for s in SIX], re.compile(r"\bmux\.Handle(?:Func)?\("))


def storefront_backend_k8s(root):
    return importers(root, [p for s in EIGHT for p in go_files(root, "core/services/" + s)], "k8s.io/")


WATERFALL = re.compile(r"Waterfall|Partner\w*(?:Price|Margin|Tier)")


def waterfall_tests(root):
    rx, out = re.compile(r"^func (Test\w*)\("), []
    for path in go_files(root, ENGINE + "/internal", tests=True):
        for n, line in enumerate(lines_of(root, path), 1):
            m = rx.search(line)
            if m and WATERFALL.search(m.group(1)):
                out.append("%s:%d %s" % (path, n, m.group(1)))
    return out


def engine_nats_importers(root):
    return importers(root, go_files(root, ENGINE), "github.com/nats-io/",
                     (ENGINE + "/internal/bus", ENGINE + "/cmd/chargeback"))


def engine_plan_shape_callers(root):
    return line_hits(root, go_files(root, ENGINE), re.compile(r"\bPlanShape\("),
                     skip=re.compile(r"^\s*func\s+(?:\([^)]*\)\s*)?PlanShape\("))

NAMES = [g[0] for g in GUARDS]
FLOORS = [g[0] for g in GUARDS if g[2] == "floor"]
CEILINGS = [n for n in NAMES if n not in FLOORS]


def read_baseline(root):
    """name -> (kind, number). Raises Unreadable when the file cannot be judged."""
    try:
        with open(os.path.join(root, BASELINE), encoding="utf-8") as f:
            doc = json.load(f)
    except (OSError, ValueError) as e:
        raise Unreadable("%s cannot be read: %s" % (BASELINE, e))
    if not isinstance(doc, dict) or sorted(doc) != TOP_KEYS or doc["schema"] != SCHEMA:
        raise Unreadable("%s: need exactly the keys %s, schema %s" % (BASELINE, ", ".join(TOP_KEYS), SCHEMA))
    out = {}
    for kind, want in (("ceiling", CEILINGS), ("floor", FLOORS)):
        part = doc[kind + "s"]
        if not isinstance(part, dict) or sorted(part) != sorted(want):
            raise Unreadable("%s: %ss must hold exactly %s" % (BASELINE, kind, ", ".join(want)))
        for name, value in part.items():
            if type(value) is not int or value < 0:
                raise Unreadable("%s: %ss.%s must be a whole number of 0 or more" % (BASELINE, kind, name))
            out[name] = (kind, value)
    return out


def run(root, say=print):
    """The whole guard. Returns the exit code."""
    try:
        have = {name: measure(root) for name, measure, _, _ in GUARDS}
        base = read_baseline(root)
    except Unreadable as e:
        say("%s: cannot judge: %s" % (ME, e))
        return 2
    fails, notes = [], []
    for name, _, _, why in GUARDS:
        kind, limit = base[name]
        n = len(have[name])
        say("%s=%d" % (name, n))
        if kind == "ceiling" and n > limit:
            fails.append("FAIL %s: %d is above the ceiling %d; %s. Hits:" % (name, n, limit, why))
            fails += ["  %s" % hit for hit in have[name]]
        elif kind == "floor" and n < limit:
            fails.append("FAIL %s: %d is below the floor %d; %s. Left:" % (name, n, limit, why))
            fails += ["  %s" % hit for hit in have[name]]
        elif n != limit:
            notes.append("%s: %d is %s the %s %d; set it to %d in %s in the same change"
                         % (name, n, "below" if kind == "ceiling" else "above", kind, limit, n, BASELINE))
    for line in notes:
        say("%s: NOTE %s" % (ME, line))
    for line in fails:
        say("%s: %s" % (ME, line))
    return 1 if fails else 0

def self_test():
    failed = 0
    for what, write, remove, change, want, needle in CASES:
        root = tempfile.mkdtemp(prefix=ME + "-")
        said = []
        try:
            for path, text in list(BASE_TREE.items()) + list(write.items()):
                os.makedirs(os.path.dirname(os.path.join(root, path)), exist_ok=True)
                with open(os.path.join(root, path), "w", encoding="utf-8") as f:
                    f.write(text)
            doc = {"schema": SCHEMA, "ceilings": {n: 0 for n in CEILINGS}, "floors": {n: 1 for n in FLOORS}}
            if change:
                change(doc)
            os.makedirs(os.path.join(root, os.path.dirname(BASELINE)))
            with open(os.path.join(root, BASELINE), "w", encoding="utf-8") as f:
                json.dump(doc, f)
            for path in remove:
                full = os.path.join(root, path)
                os.rmdir(full) if os.path.isdir(full) else os.remove(full)
            got = run(root, say=said.append)
        finally:
            shutil.rmtree(root, ignore_errors=True)
        ok = got == want and any(needle in line for line in said)
        failed += 0 if ok else 1
        print("%s  %s" % ("ok  " if ok else "FAIL", what) + ("" if ok else "\n      wanted exit %d and %r; got exit %s and %r" % (want, needle, got, said)))
    print("%s: self-test %s: %d of %d cases as expected" % (ME, "failed" if failed else "passed", len(CASES) - failed, len(CASES)))
    return 1 if failed else 0
```
