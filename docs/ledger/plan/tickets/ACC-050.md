# ACC-050 — Truth in the access documents

## In plain words

**The problem today.** The documents of the browser access gateway say that every session is recorded to object storage, that access is time-bound and approved, and that recordings serve as compliance evidence. None of this is built: the gateway records nothing. The same claim reaches the catalogue that the console shows, through the Blueprint card.

**What changes.** The two README files and the Blueprint card say what the gateway does today and that sessions are not recorded. The README points once to the decision record that holds the target design, and the generated catalogue files are regenerated so that the console shows the corrected card.

**Done means:**

- No line of the gateway README, its chart README or its Blueprint file says that sessions are recorded to object storage.
- The gateway README has a section Target, not built and links decision record 0033 exactly once.
- The Blueprint card summary of the gateway no longer names session recording, and the description of the recording volume size says that it is unused.
- The generated catalogue files carry the corrected summary, and regenerating them changes nothing.
- No chart template, chart value, version line or other Blueprint field changed.

The rest of this ticket is the exact instruction for the model that does the work.
