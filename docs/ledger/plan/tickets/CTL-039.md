# CTL-039 — Read routes for the region registry and the Environment list

## In plain words

**The problem today.** The acceptance suite asks the console API for the Sovereign's regions and for its Environments, but the API has neither route. The suite therefore accepts a missing region list and reads the Environments straight from the cluster with kubectl, so a run never proves that the API can name the objects an install must refer to.

**What changes.** The API answers both questions: the regions from its one region list, and the Environments from its informer cache. The suite takes both answers from the API and fails when it cannot.

**Done means:**

- On a Sovereign, the region route lists the same region ids that the install routes accept, in their order.
- On a Sovereign, the Environment route lists every Environment of the cluster the API runs in, sorted by name, with its Organization, type, placement and regions.
- While the informer cache cannot give a complete Environment list, the Environment route answers 503 and never a partial list.
- On the mothership both routes answer 404, and an Organization session is refused by the existing scope guard.
- The suite fails a run when either route does not answer 200, and it contains no kubectl read of Environments.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
On a Sovereign, `GET /api/v1/sovereigns/{id}/regions` answers `200` with `{"regions": [{"id", "label", "primary", "provider"}, ...]}`, the region list the install routes already validate against, and `GET /api/v1/sovereigns/{id}/environments` answers `200` with `{"items": [{"name", "organizationRef", "envType", "placement", "regions"}], "total": n}`, read from the informer cache. The discovery steps D0.2 and D0.4 of the acceptance suite in `tests/acceptance/sovereign` take both from the API. A `404` on the region route is no longer accepted, and the suite no longer runs `kubectl get environments` when the Environment route is missing. A person sees it in the new tests of `internal/topologyread`, in the two new lines of the route table, and in the evidence of the next acceptance record, where D0.2 lists the registry and D0.4 names the API route as its source.

## 3. The model (the law)
1. The two handlers live in the new package `products/catalyst/bootstrap/api/internal/topologyread`. Nothing is added to `internal/handler` (that package may only shrink, `scripts/check-api-structure.py`) or to `cmd/api/main.go`.
2. Both routes are registered in `registerSessionSovereigns` of `cmd/api/routes_sovereigns.go`, inside the session group (chain 2 of the route table). The existing Organization scope guard therefore refuses them to an Organization session (403 `org-scoped-forbidden`); nothing in this ticket changes that guard.
3. Both routes answer only on a Sovereign: a process whose environment variable `SOVEREIGN_FQDN` is not empty after trimming, the same marker as `isChroot` in `internal/handler/sovereign_secondary_kubeconfig.go`. Elsewhere (the mothership, which holds the clusters of many Sovereigns) both answer `404` with `{"error": "not-a-sovereign", "detail": "..."}` and read nothing.
4. A Sovereign serves only itself, so the `{id}` of the path is not compared with anything (the other Sovereign views of the API alias every id onto the local cluster the same way, `resolveChrootClusterID` in `internal/handler/k8s.go`).
5. The region route answers `200` with `{"regions": regions.Registry()}`, verbatim and in the registry's order; an empty registry is `{"regions":[]}`. `regions.Registry()` (`internal/regions/registry.go`) stays the one region list of the API: the install routes check every region against it (`regions.IDs()`, `internal/handler/install_refs.go`). No second region source is read.
6. The Environment route reads the kind `environment` from the informer cache (`k8scache.Factory.List`), never from the API server. It reads one cluster, the one the API runs in, chosen by the rule of `resolveChrootClusterID`: the cluster whose id equals `{id}`; else the only cluster of the cache; else the first cluster, in sorted order, whose id starts with `sovereign-`; else the first cluster in sorted order. This is the cluster against which an install checks that its Environment exists.
7. The Environment route never serves a partial or guessed list. Cache not set up, no cluster in the cache, or the kind not readable on the chosen cluster: `503` `cache-unavailable`. The kind's informer on that cluster has not finished its first list: `503` `cache-not-synced`. Otherwise `200` with one item per Environment object, sorted by name: `name` (metadata), `organizationRef`, `envType` and `placement` (from `spec`, empty when absent) and `regions` (`spec.regions` verbatim, `[]` when absent), and `total`, the number of items.
8. Every refusal is JSON `{"error": "<code>", "detail": "<text>"}` with `Content-Type: application/json`, as in `internal/jobauth`.
9. In `tests/acceptance/sovereign/internal/suite/discover.go`: step D0.2 fails on any answer of the region route other than `200` (the `404` case and its text `ADR-0015 D3 pending` are deleted); `listEnvironments` returns an error on any answer other than `200` (the `kubectl get environments` fallback through region A is deleted). The rest of D0.2 is unchanged: its region identity from the bootstrap variables of each kubeconfig, the console topology check and the gateway addresses stay, with their `TEMPORARY` evidence.
10. The route table `cmd/api/testdata/routes.golden` gains exactly the two lines of the new routes and stays sorted. Contract C9 lists only POST, PUT, PATCH and DELETE routes, so it does not change.

// Package topologyread serves two read routes of catalyst-api that the
// acceptance suite and the console use to name existing objects
// (ADR-0015 D3 and D4):
//
//	GET /api/v1/sovereigns/{id}/regions       the Sovereign's region registry
//	GET /api/v1/sovereigns/{id}/environments  the Environment objects
//
// Both answer only on a Sovereign: a catalyst-api whose environment has
// SOVEREIGN_FQDN. Elsewhere (the mothership) they answer 404
// not-a-sovereign, because one mothership process holds the clusters of
// many Sovereigns. A Sovereign serves only itself, so the {id} of the
// path is not compared with anything.
//
// The regions are regions.Registry(), the one region list of the API,
// in its order; the install routes accept exactly these ids.
//
// The Environments come from the informer cache, never from the API
// server. They are read from the cluster this catalyst-api runs in, the
// cluster the install routes check an Environment against. That cluster
// is chosen as every other Sovereign view of the API chooses it: the
// cluster whose id is the {id} of the path; else the only cluster of the
// cache; else the first cluster whose id starts with "sovereign-"; else
// the first cluster in sorted order. While that cluster's Environment
// informer has not finished its first list, the route answers 503
// cache-not-synced: a partial list is never served.
package topologyread

import (
	"encoding/json"
	"net/http"
	"os"
	"sort"
	"strings"
	"time"

	"github.com/go-chi/chi/v5"
	"k8s.io/apimachinery/pkg/apis/meta/v1/unstructured"
	"k8s.io/apimachinery/pkg/labels"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/k8scache"
	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/regions"
)

// EnvironmentKind is the name of the Environment kind in the informer cache.
const EnvironmentKind = "environment"

// lister is the part of the informer cache this package reads.
// *k8scache.Factory has these three methods.
type lister interface {
	Clusters() []string
	Synced() map[string]map[string]bool
	List(clusterID, kindName string, sel labels.Selector) ([]*unstructured.Unstructured, time.Duration, error)
}

// Routes holds the two route handlers.
type Routes struct {
	cache       func() lister
	registry    func() []regions.Region
	onSovereign func() bool
}

// New returns the routes. cache returns the informer cache of the
// process, or nil while it is not set up; it is called on every request.
func New(cache func() *k8scache.Factory) *Routes {
	return &Routes{
		cache: func() lister {
			if f := cache(); f != nil {
				return f
			}
			return nil
		},
		registry: regions.Registry,
		onSovereign: func() bool {
			return strings.TrimSpace(os.Getenv("SOVEREIGN_FQDN")) != ""
		},
	}
}

// Environment is one item of the Environment list. Regions is the
// object's spec.regions, verbatim.
type Environment struct {
	Name            string `json:"name"`
	OrganizationRef string `json:"organizationRef"`
	EnvType         string `json:"envType"`
	Placement       string `json:"placement"`
	Regions         []any  `json:"regions"`
}

// EnvironmentList is the body of a 200 answer of the Environment list.
type EnvironmentList struct {
	Items []Environment `json:"items"`
	Total int           `json:"total"`
}

// Regions serves GET /api/v1/sovereigns/{id}/regions. The body is
// {"regions": [{"id", "label", "primary", "provider"}, ...]}.
func (rt *Routes) Regions(w http.ResponseWriter, r *http.Request) {
	if !rt.onSovereign() {
		refuse(w, http.StatusNotFound, "not-a-sovereign", "this catalyst-api does not run on a Sovereign")
		return
	}
	reg := rt.registry()
	if reg == nil {
		reg = []regions.Region{}
	}
	write(w, http.StatusOK, map[string]any{"regions": reg})
}

// Environments serves GET /api/v1/sovereigns/{id}/environments. The body
// is an EnvironmentList, sorted by name.
func (rt *Routes) Environments(w http.ResponseWriter, r *http.Request) {
	if !rt.onSovereign() {
		refuse(w, http.StatusNotFound, "not-a-sovereign", "this catalyst-api does not run on a Sovereign")
		return
	}
	c := rt.cache()
	if c == nil {
		refuse(w, http.StatusServiceUnavailable, "cache-unavailable", "the informer cache is not set up")
		return
	}
	cluster, ok := homeCluster(chi.URLParam(r, "id"), c.Clusters())
	if !ok {
		refuse(w, http.StatusServiceUnavailable, "cache-unavailable", "the informer cache holds no cluster")
		return
	}
	objs, _, err := c.List(cluster, EnvironmentKind, labels.Everything())
	if err != nil {
		refuse(w, http.StatusServiceUnavailable, "cache-unavailable", err.Error())
		return
	}
	if !c.Synced()[cluster][EnvironmentKind] {
		refuse(w, http.StatusServiceUnavailable, "cache-not-synced",
			"the Environment informer of cluster "+cluster+" has not finished its first list")
		return
	}
	items := make([]Environment, 0, len(objs))
	for _, o := range objs {
		items = append(items, environmentOf(o))
	}
	sort.Slice(items, func(i, j int) bool { return items[i].Name < items[j].Name })
	write(w, http.StatusOK, EnvironmentList{Items: items, Total: len(items)})
}

// homeCluster picks the cluster this catalyst-api runs in, by the rule
// of the package comment. ok is false when the cache holds no cluster.
func homeCluster(pathID string, clusters []string) (string, bool) {
	if len(clusters) == 0 {
		return "", false
	}
	sorted := append([]string(nil), clusters...)
	sort.Strings(sorted)
	for _, c := range sorted {
		if c == pathID {
			return c, true
		}
	}
	if len(sorted) == 1 {
		return sorted[0], true
	}
	for _, c := range sorted {
		if strings.HasPrefix(c, "sovereign-") {
			return c, true
		}
	}
	return sorted[0], true
}

// environmentOf reads one Environment object. An absent field is the
// empty value; spec.regions absent is an empty list.
func environmentOf(o *unstructured.Unstructured) Environment {
	org, _, _ := unstructured.NestedString(o.Object, "spec", "organizationRef")
	envType, _, _ := unstructured.NestedString(o.Object, "spec", "envType")
	placement, _, _ := unstructured.NestedString(o.Object, "spec", "placement")
	regs, _, _ := unstructured.NestedSlice(o.Object, "spec", "regions")
	if regs == nil {
		regs = []any{}
	}
	return Environment{
		Name:            o.GetName(),
		OrganizationRef: org,
		EnvType:         envType,
		Placement:       placement,
		Regions:         regs,
	}
}

// refuse writes {"error": code, "detail": detail}.
func refuse(w http.ResponseWriter, status int, code, detail string) {
	write(w, status, map[string]string{"error": code, "detail": detail})
}

func write(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(v)
}
