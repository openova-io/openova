# INF-052 — Check INF-G01: upgrade windows and recovery; set to required

## In plain words

**The problem today.** The acceptance check of coordinated node restarts watches kured restart three nodes, but it does not look at the time windows of the Kubernetes upgrades, and it does not look at what runs on the cluster after the restarts. An upgrade could then restart a control-plane node while kured restarts another one, and a restart could leave kured or an installed component broken, and the check would still pass. It is also only expected to fail, so its result blocks nothing.

**What changes.** The check also fails when an upgrade window meets the hours in which kured restarts nodes, and when kured itself or an installed component has not recovered within the time limit. The check becomes required, and it runs only in a gate run that asks for node restarts.

**Done means:**

- The check fails when an upgrade Plan has no window, or a window that overlaps the hours in which kured restarts nodes or ends less than 30 minutes before they start.
- A cluster without upgrade Plans, or without their kind, passes that rule.
- The check fails when kured itself does not have every Pod ready, or when a component that was Ready before the first restart is not Ready again, within the time limit of the restarts.
- The check is required in the list of gate checks, and it runs only in a gate run that declares the capability node-reboot; every other run records it as skipped.
- Its tests run on every pull request without a cluster, with one failing case for each new rule.

The rest of this ticket is the exact instruction for the model that does the work.

The type `rebootCheck` keeps its fields `kubectl`, `now` and `wait`; the tests keep the fake cluster and the fake clock. The check still writes with `kubectl create`, `wait` and `delete` only, and never patches.
3. **The order of the steps in a region.** (a) kured's settings; (b) the window rule; (c) the three nodes; (d) the reboot span; (e) the HelmReleases are read; (f) the sentinel Pods; (g) the namespace is deleted; (h) the readings. A step that fails ends the region, so steps (b) and (e) touch no node when they fail.
4. **The window rule (step b).** The check lists `plans.upgrade.cattle.io` in every namespace (`kubectl get -o json --request-timeout=15s plans.upgrade.cattle.io -A`). When kubectl answers with the text `the server doesn't have a resource type` (the constant `notServed` of `check_compliance_mode.go`), the cluster does not serve the kind and the step passes. Any other failed read fails the step. No Plan passes. For each Plan:
   - It must have `spec.window` with `startTime` and `endTime` in the form `HH:MM` and a `timeZone` that `time.LoadLocation` knows and that is not empty. A missing or unreadable field fails, and is named. The check assumes no default, as it assumes none for kured.
   - A window whose start equals its end fails.
   - The window and kured's span are compared as times of the day in UTC. Each is converted with the offset that its own time zone has at the moment of the step. A window runs from its start to its end, wrapping past midnight when the end is earlier; so does the span.
   - The window fails when it overlaps the span.
   - Otherwise it fails when the time from the end of the window to the next start of the span is less than 30 minutes (the constant `rebootGap`). In the lab, upgrade Jobs started up to 1101 seconds after their window had closed (`docs/ledger/plan/spikes/INF-030.md`, the finding "Disjoint windows still let two nodes be unavailable at once").
   - **The days.** `spec.window.days` is not read, as kured's `--reboot-days` is not. Both are judged as if they were open every day. That is the strictest reading: a window and a span that do not meet as daily spans do not meet on fewer days either.
   - With the kit's span (00:30 to 22:00 UTC), a window from 22:00 to 00:00 UTC passes, and a window from 22:00 to 00:30 UTC fails.
   The step's error names every Plan that fails, sorted, with the reason.
5. **The HelmReleases before (step e).** Just before the sentinel Pods, after any wait for the span, the check lists `helmreleases.helm.toolkit.fluxcd.io` in every namespace once (the constant `hrResource` of `journeys.go`) and keeps, by namespace and name, every HelmRelease whose condition `Ready` is `True`. When none is Ready the step fails: the recovery could not be judged, and no node is touched.
6. **The recovery (step h).** When a reading of the nodes shows that the three nodes have new boot identifiers, no node is unschedulable and every node is Ready, the check reads DaemonSet `kube-system/kured` and the HelmReleases again. The step passes when the DaemonSet has `status.desiredNumberScheduled` of at least 1 and `status.numberReady` equal to it, and every HelmRelease of step (e) has `Ready` `True` again; a HelmRelease that is gone counts as not Ready. A HelmRelease that was not Ready before is not judged. Otherwise the readings go on. A read that fails is no observation and is counted with the failed readings. When the time limit ends first, the step fails and its reason names what has not recovered.
7. **The manifest.** The entry `INF-G01` of `docs/ledger/gates.yaml` moves from `state: expected-fail` to `state: required`. No other field of the entry changes, and no other entry changes. The rule of the manifest tool that only `delivered_by` sets a check to required is met: `delivered_by` of the entry is INF-052.
8. **Where the check runs.** The entry keeps `needs: [node-reboot]`, `destructive: true` and `runs_in: [cloud]`. The suite records a check whose `needs` the run does not declare as SKIP and does not run it; such a SKIP does not fail a run, even for a required check. The gate workflow `foundation-gate` declares `multi-region` and adds the flags of its input `capabilities`, empty by default. So only a gate run started with `capabilities` set to `node-reboot` restarts nodes.
9. **The README** of the suite says what the check now judges, and that it runs only in a run that declares `node-reboot`. Its sentence that the check does not read the upgrade Plans, the pods of kured or the HelmReleases and is therefore `expected-fail` is removed.
10. **Nothing is deleted** by this ticket.

// window returns how long the reboot span stays open from now, 0 when it is
// closed, and how long it is until the span opens the next time.
func (k rebootSettings) window(now time.Time) (open, next time.Duration) {
	local := now.In(k.zone)
	minute := local.Hour()*60 + local.Minute()
	if since, length := rebootMod(minute-k.start), rebootMod(k.end-k.start); since < length {
		open = time.Duration(length-since) * time.Minute
	}
	return open, time.Duration(rebootMod(k.start-minute-1)+1)*time.Minute - time.Duration(local.Second())*time.Second
}

// rebootMod is m modulo the minutes of a day, never negative.
func rebootMod(m int) int { return (m%1440 + 1440) % 1440 }

// rebootUTC turns a minute of the day in zone into a minute of the day in
// UTC, with the offset that zone has at now.
func rebootUTC(minute int, zone *time.Location, now time.Time) int {
	_, offset := now.In(zone).Zone()
	return rebootMod(minute - offset/60)
}

// rebootWindow judges the window of one upgrade Plan against the reboot span
// of k at now. It returns the window as the Plan writes it and why it fails,
// "" when it passes.
func rebootWindow(plan kube.Object, k rebootSettings, now time.Time) (window, problem string) {
	w, _ := plan.Get("spec", "window").(map[string]any)
	if w == nil {
		return "", "has no spec.window"
	}
	o := kube.Object(w)
	window = o.Str("startTime") + "-" + o.Str("endTime") + " " + o.Str("timeZone")
	start, errStart := time.Parse("15:04", o.Str("startTime"))
	end, errEnd := time.Parse("15:04", o.Str("endTime"))
	zone, errZone := time.LoadLocation(o.Str("timeZone"))
	switch {
	case errStart != nil || errEnd != nil:
		return window, "has no startTime and endTime of the form HH:MM in spec.window"
	case errZone != nil || o.Str("timeZone") == "":
		return window, "has no time zone that the check knows in spec.window.timeZone"
	}
	ws := rebootUTC(start.Hour()*60+start.Minute(), zone, now)
	length := rebootMod(end.Hour()*60 + end.Minute() - start.Hour()*60 - start.Minute())
	ks, span := rebootUTC(k.start, k.zone, now), rebootMod(k.end-k.start)
	switch {
	case length == 0:
		return window, "has a window that starts when it ends"
	case rebootMod(ks-ws) < length || rebootMod(ws-ks) < span:
		return window, "has a window that overlaps the reboot span " + k.span
	case rebootMod(ks-ws-length) < rebootGap:
		return window, fmt.Sprintf("has a window that ends %d minutes before the reboot span %s starts, less than %d", rebootMod(ks-ws-length), k.span, rebootGap)
	}
	return window, ""
}

// recovery reads the DaemonSet of kured and the HelmReleases. It returns what
// has not recovered yet, "" when kured has every Pod ready and every
// HelmRelease of ready is Ready again.
func (c rebootCheck) recovery(ctx context.Context, region kube.Region, ready []string, ev Evidence) (string, error) {
	sets, err := c.list(ctx, region, "daemonsets", "-n", rebootNamespace)
	if err != nil {
		return "", err
	}
	now, err := c.releases(ctx, region)
	if err != nil {
		return "", err
	}
	podsReady, desired := 0, 0
	for _, ds := range sets {
		if ds.Name() == rebootDaemonSet {
			podsReady, desired = ds.Int("status", "numberReady"), ds.Int("status", "desiredNumberScheduled")
		}
	}
	waiting, notAgain := []string{}, []string{}
	for _, name := range ready {
		if !now[name] {
			notAgain = append(notAgain, name)
		}
	}
	ev["kured_ready"], ev["helmreleases_not_ready_again"] = fmt.Sprintf("%d/%d", podsReady, desired), notAgain
	if desired == 0 || podsReady != desired {
		waiting = append(waiting, fmt.Sprintf("DaemonSet %s/%s has %d of %d Pods ready", rebootNamespace, rebootDaemonSet, podsReady, desired))
	}
	if len(notAgain) > 0 {
		waiting = append(waiting, fmt.Sprintf("%d of %d HelmReleases that were Ready before are not Ready: %s", len(notAgain), len(ready), strings.Join(notAgain, ", ")))
	}

}

// watch reads the nodes until the three chosen nodes have restarted, every
// node is schedulable and Ready, kured has every Pod ready and every
// HelmRelease of ready is Ready again, a rule is broken or the time limit ends.
func (c rebootCheck) watch(ctx context.Context, region kube.Region, k rebootSettings, chosen []string, before map[string]rebootNode, ready []string, placed time.Time, ev Evidence) error {
	since, drained, oldIDs, newIDs := map[string]time.Time{}, map[string]bool{}, map[string]string{}, map[string]string{}
	for _, name := range chosen {
		oldIDs[name] = before[name].boot
	}
	readings, failed, most, last := 0, 0, 0, "no reading of the nodes succeeded"
	ev["boot_ids_before"], ev["boot_ids_after"] = oldIDs, newIDs
	for {
		nodes, err := c.nodes(ctx, region)
		now := c.now()
		if err != nil {
			failed++
		} else {
			readings++
		}
		ev["readings"], ev["failed_readings"], ev["seconds"] = readings, failed, int(now.Sub(placed).Seconds())
		if err == nil {
			down, notReady := []string{}, 0
			for name, node := range nodes {
				if !node.ready {
					notReady++
				}
				if !node.cordoned {
					delete(since, name)
					continue
				}
				down = append(down, name)
				if _, seen := since[name]; !seen {
					since[name] = now
				}
				if held := now.Sub(since[name]); held > k.drain+k.release {
					return fmt.Errorf("node %s has been unschedulable for %s, longer than drain timeout + lock release delay (%s): its drain does not finish", name, held, k.drain+k.release)
				}
			}
			sort.Strings(down)
			most = max(most, len(down))
			ev["most_unschedulable"] = most
			if len(down) > 1 {
				return fmt.Errorf("%d nodes are unschedulable at once: %s", len(down), strings.Join(down, ", "))
			}
			for _, name := range chosen {
				node := nodes[name]
				drained[name] = drained[name] || node.cordoned
				if node.boot == "" || node.boot == oldIDs[name] {
					continue
				}
				if !drained[name] {
					return fmt.Errorf("node %s has a new boot identifier and was never read unschedulable: it restarted without a drain", name)
				}
				newIDs[name] = node.boot
			}
			last = fmt.Sprintf("%d of %d nodes restarted, %d unschedulable, %d not Ready", len(newIDs), len(chosen), len(down), notReady)
			if len(newIDs) == len(chosen) && len(down) == 0 && notReady == 0 {
				waiting, err := c.recovery(ctx, region, ready, ev)
				switch {
				case err != nil:
					failed++
					ev["failed_readings"] = failed
				case waiting == "":
					return nil
				default:
					last += "; " + waiting
				}
			}
		}
		if now.Sub(placed) >= k.limit() {
			return fmt.Errorf("%s after the pending reboots were placed: %s", k.limit(), last)
		}
		if err := c.wait(ctx, rebootEvery); err != nil {
			return err
		}
	}
}
