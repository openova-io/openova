# AIP-102 — Tool calls passed through; no shared sessions

## In plain words

**The problem today.** Axon cannot serve an agent: it never returns tool calls, so a caller's tools are lost, and every request starts from nothing. It reports zero token usage, and it still checks caller keys of its own although only the model gateway may reach it.

**What changes.** A request with tools gets tool calls back, and the follow-up with the results continues the same model run. Usage is the real count of the model message, and the key check is gone.

**Done means:**

- A request with tools gets tool calls and the finish reason tool_calls, and the follow-up with every result continues the same upstream run and returns its answer.
- A follow-up that leaves out a result gets 400, one from another Organization gets 404, and one that arrives after the parked run expired starts a new run with the conversation as a transcript.
- No upstream run is handed to a second conversation, and an upstream rate limit answers 429 with Retry-After 30.
- Token usage in every answer comes from the raw stream events of the model message, with cached and cache-write counts.
- Axon has no caller-key check, one file imports the agent kit, and the agent-plane guard and the deletion guard pass.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`products/axon` serves `POST /v1/chat/completions` as a pass-through model back end. The caller's tools reach the model unchanged through an in-process tool server and come back as `tool_calls` with `finish_reason: tool_calls`; the run waits, parked, and the follow-up request that carries every result continues that same run. A parked run that expired, or a conversation with history and no parked run, starts a new run whose prompt is the transcript of the conversation. No run is reused for another conversation. Usage is read from the kit's raw stream events. The caller-key check and `src/middleware/auth.ts` are gone, `src/providers/claude.ts` is replaced by `src/upstream.ts`, `src/turns.ts` and `src/transcript.ts`, and `cd products/axon && npm ci && npm run build && npm test` passes 42 tests.

## 3. The model (the law)
1. `src/upstream.ts` is the only file under `products/axon/src` that imports the agent kit. It exports `UpstreamEvent`, `UpstreamRun`, `UpstreamOptions`, `Upstream`, `ToolResults`, `EventMapper` and `KitUpstream`. One upstream run is one call of the kit's `query()` with: `model`, `systemPrompt`, `tools: []`, `settingSources: []`, `mcpServers: { t: <in-process server> }` and `allowedTools: ["mcp__t"]` when the request registers tools (otherwise `{}` and `[]`), `permissionMode: "dontAsk"`, `persistSession: false`, `includePartialMessages: true`, `effort` only for `reasoning_effort` `low`, `medium` or `high`, `env` the process environment without `CLAUDECODE` (with `CLAUDE_CODE_OAUTH_TOKEN` only when an access token is given), and one `abortController` per run.
2. The in-process server is the kit's `createSdkMcpServer({ name: "t" })` with low-level `tools/list` and `tools/call` handlers: the list is the caller's tools unchanged (`inputSchema` is the caller's `parameters`, or `{"type":"object"}`), and a call never executes anything; it waits for the caller's result.
3. Events come from the raw stream only (`stream_event` messages of the top level): `message_start` gives the input, cache-read and cache-write counts; a text delta gives `text_delta`; a tool-use block start of a tool named `mcp__t__<name>` gives `tool_start` with `<name>`; its `input_json_delta` gives `tool_args_delta`; the last `message_delta` gives the stop reason and the output count; `message_stop` gives one `message_end` with the caller's tool uses of that model message. A `result` message gives `run_end`, with an error (and `api_error_status` when present) when it is not a success. Assembled `assistant` messages are ignored: they repeat one usage block per content block (spike AIP-020, T10).
4. `ToolResults` keeps the results not yet delivered and the handlers not yet answered. A handler is matched by the tool-use identifier at `_meta["claudecode/toolUseId"]` of the call (spike AIP-020, T2), else by the first pending tool use with the same name and a deeply equal input. This holds whether the kit invokes the handlers of one model message together or one after another (T6).
5. `close()` of a run that has not ended calls the kit's `interrupt()` first and aborts after it: an abort alone sends one more model request with a made-up empty tool result (spike AIP-020, X2).
6. `Turns` in `src/turns.ts`, per request: (a) the trailing `tool` messages are the results; (b) when a parked chain waits for one of their identifiers: another Organization (header `x-openova-organization`, empty when absent) gets 404 `model_not_found` with the message `model not found`; a missing result gets 400 `missing_tool_results`; otherwise every waiting call is resolved with its message text and the chain reads on; (c) otherwise a new run starts, its prompt the one user message when the conversation is exactly that, else the transcript of rule 8.
7. A step reads events until a model message ends. With tool uses: the answer has `tool_calls` (identifier the upstream tool-use identifier, `function.arguments` the JSON text of the input) and `finish_reason: tool_calls`, the chain parks and a timer of `AXON_PARK_TTL_MS` closes it; with `parallel_tool_calls: false` only the first call is returned and the others are answered on resume with `Not executed: one tool call per step is allowed. Call it again if it is still needed.` Without tool uses: `finish_reason` is `length` for `max_tokens`, `content_filter` for `refusal`, else `stop`; the step waits for `run_end` and closes the chain. A model message whose only tool use is a tool outside the caller's list (the kit answers it itself) does not end the step.
8. The transcript (`render` of `src/transcript.ts`): `<conversation>`, one line group per non-system message (`User: <text>`; `Assistant: <text>` before its `Assistant called tool <name> with id <id> and arguments <json>` lines; `Tool result for <id>: <text>`), `</conversation>`, a blank line, `Continue the conversation. Respond to the last entry above.`. Text parts are joined with a newline; an image part is `[image omitted]`.
9. Usage of an answer: `prompt_tokens` = input + cache-read + cache-write, `completion_tokens` = output, `total_tokens` = the sum, `prompt_tokens_details.cached_tokens` = cache-read, `prompt_tokens_details.cache_write_tokens` = cache-write, summed over the model messages of the step.
10. Errors have the body `{"error": {"message", "type", "code"}}`. An upstream 429 gives 429 `rate_limit_exceeded` with `Retry-After: 30`; an upstream 401 gives 503 `simulation_credential_invalid`; any other upstream failure gives 502 `backend_error`. A `model` outside `AXON_MODEL_MAP` gives 404 `model_not_found`; an image part 400 `unsupported_content`; a tool name of more than 56 characters 400 `tool_name_too_long`; no messages or a tool without a name 400 `invalid_request`.
11. `tool_choice: none` registers no tools. `required` or a named function is asked for in the system prompt and named in the response header `x-openova-emulated: tool_choice`.
12. A streamed request gets, until AIP-103, the whole answer as one content chunk (role, text and the tool calls with `index`), one finish chunk, the usage chunk when `stream_options.include_usage` is set, and `data: [DONE]`.
13. `Config` is exactly `port`, `modelMap` (`AXON_MODEL_MAP`, default `{"sim-default":"claude-sonnet-4-6","sim-fast":"claude-haiku-4-5-20251001"}`) and `parkTtlMs` (`AXON_PARK_TTL_MS`, default 600000). `GET /v1/models` lists the keys of the model map. There is no caller key: `AXON_API_KEYS`, `apiKeys` and `defaultModel` leave the source.
14. Deleted: `src/providers/claude.ts` (the old provider, `chat`, `chatStream`, `formatPrompt`, the hard-coded model list) and `src/middleware/auth.ts` (the key check). Both are added to `docs/ledger/deleted-paths.txt`.

+        if (e.stopReason === "tool_use") continue;
+        let end = await chain.run.next();

+        this.close(chain);
+        return { text, toolCalls: [], finishReason: finishOf(e.stopReason), usage: usageOf(total), emulated };
+      }
+    }

+  private park(chain: Chain, pending: string[], internal: string[]): void {
+    chain.state = "parked";
+    chain.pending = pending;
+    chain.internal = internal;
+    for (const id of pending) this.parked.set(id, chain);
+    const timer = setTimeout(() => this.close(chain), this.o.parkTtlMs);
+    if (typeof timer === "object" && typeof timer.unref === "function") timer.unref();

+  }

+    chain.timer = undefined;
+    for (const id of chain.pending) this.parked.delete(id);
+  }

+    if (chain.state === "closed") return;
+    this.unpark(chain);
+    chain.state = "closed";
+    this.chains.delete(chain);
+    chain.run.close();
+  }

+ * Matches the kit's tool handlers to the caller's results. Results not yet
+ * delivered are kept by tool-call identifier, handlers not yet answered wait.

+export class ToolResults {
+  private stored = new Map<string, string>();
+  private waiting = new Map<string, (text: string) => void>();
+  private pending: ToolUse[] = [];
+  private unmatched: { name: string; input: unknown; answer: (id: string) => void }[] = [];

+  /** The caller's tool uses of one model message. */
+  seen(uses: ToolUse[]): void {
+    this.pending.push(...uses);
+    for (const h of [...this.unmatched]) {
+      const use = this.find(h.name, h.input);
+      if (use) {
+        this.unmatched.splice(this.unmatched.indexOf(h), 1);
+        this.take(use.id);
+        h.answer(use.id);
+      }
+    }
+  }

+  invoked(id: string | undefined, name: string, input: unknown): Promise<string> {
+    return new Promise((resolve) => {
+      const answer = (toolId: string) => {
+        const text = this.stored.get(toolId);
+        if (text === undefined) {
+          this.waiting.set(toolId, resolve);
+        } else {
+          this.stored.delete(toolId);
+          resolve(text);
+        }
+      };
+      const use = id ? { id } : this.find(name, input);
+      if (use) {
+        this.take(use.id);
+        answer(use.id);
+      } else {
+        this.unmatched.push({ name, input, answer });
+      }
+    });
+  }

+    const handler = this.waiting.get(id);
+    if (handler) {
+      this.waiting.delete(id);
+      handler(text);
+    } else {

+    }

+  map(msg: SDKMessage): UpstreamEvent[] {

+      const message = msg.subtype === "success" ? msg.result : msg.errors.join("; ") || msg.subtype;
+      return [{ kind: "run_end", error: { status, message } }];

+        if (ev.delta.type !== "input_json_delta" || !block) return [];

+        return [{ kind: "tool_args_delta", index: block.index, json: ev.delta.partial_json }];
+      }
+      case "message_delta":
+        this.stopReason = ev.delta.stop_reason ?? this.stopReason;
+        this.usage.output = ev.usage.output_tokens;
+        return [];
+      case "message_stop": {

+class KitRun implements UpstreamRun {
+  private events: UpstreamEvent[] = [];
+  private readers: ((e: UpstreamEvent) => void)[] = [];
+  private ended: UpstreamEvent | undefined;
+  private closed = false;
+  private results = new ToolResults();
+  private mapper = new EventMapper();
+  private abort = new AbortController();
+  private q: Query;
+
+  constructor(o: UpstreamOptions) {
+    const env: Record<string, string | undefined> = { ...process.env };
+    delete env.CLAUDECODE;
+    if (o.accessToken) env.CLAUDE_CODE_OAUTH_TOKEN = o.accessToken;
+    const withTools = o.tools.length > 0;
+    const options: Options = {
+      model: o.model,
+      systemPrompt: o.systemPrompt,
+      tools: [],
+      settingSources: [],
+      mcpServers: withTools ? { t: toolServer(o.tools, this.results) } : {},
+      allowedTools: withTools ? ["mcp__t"] : [],
+      permissionMode: "dontAsk",
+      persistSession: false,
+      includePartialMessages: true,
+      env,
+      abortController: this.abort,
+    };
+    if (o.effort) options.effort = o.effort;
+    this.q = query({ prompt: o.prompt, options });
+    void this.pump();
+  }
+
+  private async pump(): Promise<void> {
+    try {
+      for await (const msg of this.q) {
+        for (const e of this.mapper.map(msg)) {
+          if (e.kind === "message_end") this.results.seen(e.toolUses);
+          this.push(e);
+        }
+        if (msg.type === "result") break;
+      }
+      this.push({ kind: "run_end", error: { message: "the run ended without a result" } });
+    } catch (err) {
+      this.push({ kind: "run_end", error: { message: err instanceof Error ? err.message : String(err) } });
+    }
+  }
+
+  private push(e: UpstreamEvent): void {
+    if (this.ended) return;
+    if (e.kind === "run_end") this.ended = e;
+    const reader = this.readers.shift();
+    if (reader) reader(e);
+    else this.events.push(e);
+  }
+
+  next(): Promise<UpstreamEvent> {
+    const e = this.events.shift() ?? this.ended;
+    if (e) return Promise.resolve(e);
+    return new Promise((resolve) => this.readers.push(resolve));
+  }
+
+  resolveTool(id: string, text: string): void {
+    this.results.resolve(id, text);
+  }
+
+  close(): void {
+    if (this.closed) return;
+    this.closed = true;
+    if (this.ended) {
+      this.abort.abort();
+      return;
+    }
+    // Interrupt first: an abort alone sends one more model request with a
+    // made-up empty result for the pending tool call.
+    void this.q
+      .interrupt()
+      .catch(() => undefined)
+      .finally(() => this.abort.abort());
+  }
+}

+// A scripted stand-in for the kit. Each step is one model message; after a
+// message with tool uses the fake invokes its handlers, together or one after
+// the other, and goes on only when every handler has its result.
+import {
+  ToolResults,
+  type ToolUse,
+  type Upstream,
+  type UpstreamEvent,
+  type UpstreamOptions,
+  type UpstreamRun,
+  type Usage,
+} from "../src/upstream.js";
+
+export interface FakeStep {
+  text?: string;
+  tools?: ToolUse[];
+  stop?: string;
+  usage?: Usage;
+}
+
+export interface FakeScript {
+  steps: FakeStep[];
+  error?: { status?: number; message: string };
+  handlers?: "together" | "sequential";
+}
+
+export const STEP_USAGE: Usage = { input: 1, cacheRead: 0, cacheWrite: 0, output: 1 };
+
+export class FakeRun implements UpstreamRun {
+  closed = false;
+  ended = false;
+  delivered: { id: string; text: string }[] = [];
+  private events: UpstreamEvent[] = [];
+  private readers: ((e: UpstreamEvent) => void)[] = [];
+  private results = new ToolResults();
+
+  constructor(
+    public options: UpstreamOptions,
+    private script: FakeScript,
+  ) {
+    void this.play();
+  }
+
+  private async play(): Promise<void> {
+    for (const s of this.script.steps) {
+      const tools = s.tools ?? [];
+      if (s.text) this.push({ kind: "text_delta", text: s.text });
+      tools.forEach((u, index) => {
+        this.push({ kind: "tool_start", index, id: u.id, name: u.name });
+        this.push({ kind: "tool_args_delta", index, json: JSON.stringify(u.input) });
+      });
+      const stopReason = s.stop ?? (tools.length > 0 ? "tool_use" : "end_turn");
+      this.push({ kind: "message_end", stopReason, toolUses: tools, usage: s.usage ?? STEP_USAGE });
+      if (tools.length === 0) continue;
+      this.results.seen(tools);
+      const call = async (u: ToolUse) => this.delivered.push({ id: u.id, text: await this.results.invoked(u.id, u.name, u.input) });
+      if (this.script.handlers === "together") await Promise.all(tools.map(call));
+      else for (const u of tools) await call(u);
+      if (this.closed) return;
+    }
+    this.ended = true;
+    this.push({ kind: "run_end", error: this.script.error });
+  }
+
+  private push(e: UpstreamEvent): void {
+    const reader = this.readers.shift();
+    if (reader) reader(e);
+    else this.events.push(e);
+  }
+
+  next(): Promise<UpstreamEvent> {
+    const e = this.events.shift();
+    if (e) return Promise.resolve(e);
+    return new Promise((resolve) => this.readers.push(resolve));
+  }
+
+  resolveTool(id: string, text: string): void {
+    this.results.resolve(id, text);
+  }
+
+  close(): void {
+    this.closed = true;
+  }
+}
+
+/** Hands out one scripted run per start call, in order. */
+export class FakeUpstream implements Upstream {
+  runs: FakeRun[] = [];
+
+  constructor(private scripts: FakeScript[]) {}
+
+  start(o: UpstreamOptions): UpstreamRun {
+    const script = this.scripts[this.runs.length];
+    if (!script) throw new Error(`no script for run ${this.runs.length + 1}`);
+    const run = new FakeRun(o, script);
+    this.runs.push(run);
+    return run;
+  }
+}
