# SVC-125 — Blueprint proofs check: the function-test result in the gate record

## In plain words

**The problem today.** Every chart of the foundation ring is to ship a function test that proves the chart works, but no gate run reads the result of those tests. The record of a run lists which chart versions ran, not whether their tests passed. So no Blueprint can be shown to be proven, and a release whose test failed goes unnoticed.

**What changes.** A new gate check reads the test result of every release in every region and writes it, with the Blueprint name, into the record of the run. It fails when a release of the foundation ring has no passing test, except for five charts that have no test yet. The check starts as expected to fail; a later task makes it required.

**Done means:**

- A chart entry of a gate record can carry the Blueprint name and the function-test result pass, fail or none, and the record checker accepts these three values and refuses any other.
- A release whose test has not finished is never recorded as none; it gets no result at all.
- A release of the foundation ring with a failed, missing or unfinished test fails the check; the five exempt charts are recorded and not judged.
- The check never reads the Ready condition or the failure count of a release, and it only reads the cluster.
- The gate manifest lists the Blueprint proofs check as expected to fail, with its check file as the implementation.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every gate run of the acceptance suite that selects gate check SVC-G06 "Blueprint proofs" reads, in every region, the function-test result of every HelmRelease from the newest revision in its status. It writes the result (`pass`, `fail` or `none`) and the Blueprint name onto the entry of that release in `artifacts.charts[]` of the run record, and it fails when a release of the foundation ring that is not exempt has no passing test. The record schema of `scripts/acceptance-gate.py` accepts the two new fields. In `docs/ledger/gates.yaml`, SVC-G06 is `expected-fail` and names its check file. Package SVC-135 later makes it `required`.

## 3. The model (the law)
1. Gate check SVC-G06 is one file, `tests/acceptance/sovereign/internal/suite/check_svc_proofs.go`, that calls `RegisterCheck` in `init()`. Its tests are one file, `tests/acceptance/sovereign/internal/suite/check_svc_proofs_test.go`. Both are copied from the blocks of this ticket and fixed by their checksums.
2. The result of one HelmRelease is read from its newest revision, `status.history[0].testHooks` (a map from the name of a test hook to an object with `phase`):
   - `pass`: every test hook of that revision has phase `Succeeded`.
   - `fail`: a test hook of that revision has phase `Failed`.
   - `none`: no hook ran. Either `spec.test.enable` is not `true`, or `testHooks` is empty and the condition `TestSuccess` is `True` with the message `no test hooks`.
   - `pending`: anything else. The release is not settled (`status.observedGeneration` differs from `metadata.generation`, or it has a condition of type `Reconciling`), `status.history` is empty, or the test has not finished. An empty `testHooks` while `TestSuccess` is not `True` with `no test hooks` is `pending`, never `none`.
3. The check never reads the condition `Ready` or `status.failures`. With `spec.test.ignoreFailures: true`, `Ready` turns `True` before the test has run and stays `True` when it fails, and `status.failures` becomes 1 after a failed test. The lab record `docs/ledger/plan/spikes/SVC-120.md` measured this on Flux v2.4.0 (helm-controller v1.1.0).
4. A HelmRelease is of the foundation ring when its label `catalyst.openova.io/ring` is `foundation`. When it has no such label, it is of the foundation ring when the candidate declares it, by `metadata.namespace` and `metadata.name`, in a file of `clusters/_template/bootstrap-kit/` whose number (the text of the file name before the first `-`) is one of these 40: `01 01a 02 02a 03 04 05 05a 06 06a 07 08 09 10 11 12 12a 13 13b 13c 13e 14 15 15a 16 16a 16b 16c 16d 17 18 19 26 26b 27 27a 28 49 60 62`. Only a `kind: HelmRelease` document of such a file counts. A label with another value means the release is not of the foundation ring.
5. The Blueprint name of a HelmRelease is the name of its chart: `spec.chart.spec.chart`, or else `status.history[0].chartName`. Five Blueprints of the foundation ring have no function test yet and are exempt: `bp-cnpg-pair`, `bp-continuum`, `bp-reflector`, `bp-sealed-secrets`, `bp-self-sovereign-cutover`. Their releases are recorded and not judged.
6. Steps. `SVC-G06.1` reads the foundation HelmReleases that the candidate declares (the checkout of `--repo-root`); it fails when it finds none. Then one step per region, `SVC-G06.2`, `SVC-G06.3`, in region order. A region step fails when the foundation releases were not read, when the region cannot be read, when no release of the foundation ring is found in the region ("nothing was measured"), or when a foundation release that is not exempt has a result other than `pass`. Its error names each such release as `<namespace>/<name> (<Blueprint>) <result>: <why>`. Its evidence holds `releases`, `results` (the number of releases per result), `foundation`, `judged`, `not_pass`, `exempt` and `proofs`.
7. Hand-over to the record. The evidence key `proofs` of a region step holds a `map[string]ChartProof` keyed by `<region>/<namespace>/<release>`, with every release whose result is not `pending`. `Run.Finalize` copies each result onto the entry of `artifacts.charts[]` of the same region, namespace and release, as `blueprint` and `functionTest`. An entry without a result keeps neither field. The map stays in the evidence of its step. Check FND-G01 writes `artifacts` only in cloud runs; in a run without `artifacts` the results are in the step evidence only.
8. `tests/acceptance/sovereign/internal/suite/result.go`: `ChartArtifact` gains `Blueprint` (`json:"blueprint,omitempty"`) and `FunctionTest` (`json:"functionTest,omitempty"`); the file gains the constant `ProofsKey = "proofs"`, the type `ChartProof`, and the loop in `Finalize` of point 7. A record without results is written exactly as before.
9. `scripts/acceptance-gate.py`: the record schema (table `RECORD`) gives each entry of `artifacts.charts` two optional fields, `blueprint` (a string) and `functionTest` (one of `pass`, `fail`, `none`). The self-test gains two cases: a chart with both fields is valid, and a `functionTest` of another value is refused. The self-test then has 110 cases.
10. `docs/ledger/gates.yaml`: the entry SVC-G06 moves from `state: not-built` to `state: expected-fail` and gains the line `implementation: tests/acceptance/sovereign/internal/suite/check_svc_proofs.go`. No other line of the file changes. This package never sets `required`; SVC-135 does.
11. The check reads each region once, through `kube.Region.GetList`. It does not wait for a test, writes nothing to a cluster and runs no `kubectl exec`. A test runs only on a Helm install or upgrade, so the result is as old as the newest revision.
12. The module keeps using the Go standard library only.

// The results of one HelmRelease.
const (
	proofPass    = "pass"
	proofFail    = "fail"
	proofNone    = "none"
	proofPending = "pending"

type proofsCheck struct{}

func init() { RegisterCheck(proofsCheck{}) }

func (proofsCheck) ID() string { return proofsID }

func (proofsCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
	n := 0
	next := func() string { n++; return proofsID + "." + strconv.Itoa(n) }

	var declared map[string]bool
	rec.Step(next(), "the candidate declares the HelmReleases of the foundation ring in "+pinsDir, func(ev Evidence) error {
		var err error
		if declared, err = proofsFoundation(cc.RepoRoot); err != nil {
			return err
		}
		ev["declared"] = len(declared)
		if len(declared) == 0 {
			declared = nil
			return fmt.Errorf("no HelmRelease was found in a foundation slot file of %s under --repo-root", pinsDir)
		}
		return nil
	})

	for _, region := range cc.Regions {
		rec.Step(next(), "every foundation HelmRelease that is not exempt has a passing function test in region "+region.ID, func(ev Evidence) error {
			if declared == nil {
				return errors.New("the foundation HelmReleases were not read")
			}
			releases, err := region.GetList(ctx, hrResource, "")
			if err != nil {
				return err
			}
			proofs, counts := map[string]ChartProof{}, map[string]int{}
			foundation, judged, notPass, exempt := 0, 0, []string{}, []string{}
			for _, hr := range releases {
				key := hr.Namespace() + "/" + hr.Name()
				blueprint := proofsBlueprint(hr)
				result, why := proofOf(hr)
				counts[result]++
				if result != proofPending {
					proofs[region.ID+"/"+key] = ChartProof{Blueprint: blueprint, FunctionTest: result}
				}
				ring := hr.Str("metadata", "labels", ringLabel)
				if ring != "foundation" && (ring != "" || !declared[key]) {
					continue
				}
				foundation++
				line := key + " (" + nonEmpty(blueprint, "no chart") + ") " + result
				if why != "" {
					line += ": " + why
				}
				if proofExempt[blueprint] {
					exempt = append(exempt, line)
					continue
				}
				judged++
				if result != proofPass {
					notPass = append(notPass, line)
				}
			}
			sort.Strings(notPass)
			sort.Strings(exempt)
			ev["releases"], ev["results"], ev["foundation"] = len(releases), counts, foundation
			ev["judged"], ev["not_pass"], ev["exempt"] = judged, notPass, exempt
			ev[ProofsKey] = proofs
			switch {
			case foundation == 0:
				return errors.New("no HelmRelease of the foundation ring was found: nothing was measured")
			case len(notPass) > 0:
				return fmt.Errorf("%d of %d foundation HelmReleases have no passing function test: %s", len(notPass), judged, strings.Join(notPass, "; "))
			}
			return nil
		})
	}
	return nil
}

// proofOf returns the result of the function test of the newest revision of
// one HelmRelease, and why when the result is not pass.
func proofOf(hr kube.Object) (result, why string) {
	if enabled, _ := hr.Get("spec", "test", "enable").(bool); !enabled {
		return proofNone, "spec.test.enable is not true"
	}
	if gen, seen := hr.Int("metadata", "generation"), hr.Int("status", "observedGeneration"); gen != seen {
		return proofPending, fmt.Sprintf("status.observedGeneration %d is not metadata.generation %d", seen, gen)
	}
	if _, _, _, reconciling := hr.Condition("Reconciling"); reconciling {
		return proofPending, "the release has a Reconciling condition"
	}
	history := hr.Objects("status", "history")
	if len(history) == 0 {
		return proofPending, "status.history holds no revision"
	}
	hooks, _ := history[0].Get("testHooks").(map[string]any)
	if len(hooks) == 0 {
		status, reason, message, found := hr.Condition("TestSuccess")
		if found && status == "True" && message == "no test hooks" {
			return proofNone, "the chart has no test hook"
		}
		if !found {
			return proofPending, "no test hook is recorded and there is no TestSuccess condition"
		}
		return proofPending, "no test hook is recorded and TestSuccess is " + status + " (" + reason + ")"
	}
	names := make([]string, 0, len(hooks))
	for name := range hooks {
		names = append(names, name)
	}
	sort.Strings(names)
	failed, unfinished := []string{}, []string{}
	for _, name := range names {
		hook, _ := hooks[name].(map[string]any)
		switch phase := kube.Object(hook).Str("phase"); phase {
		case "Succeeded":
		case "Failed":
			failed = append(failed, name)
		default:
			unfinished = append(unfinished, name+" has phase "+nonEmpty(phase, "none"))
		}
	}
	switch {
	case len(failed) > 0:
		return proofFail, "test hook " + strings.Join(failed, ", ") + " failed"
	case len(unfinished) > 0:
		return proofPending, "test hook " + strings.Join(unfinished, ", ")
	}
	return proofPass, ""
}

// proofsBlueprint is the Blueprint name of a HelmRelease: the name of its
// chart, from spec.chart.spec.chart, or else from the newest revision.
func proofsBlueprint(hr kube.Object) string {
	if chart := hr.Str("spec", "chart", "spec", "chart"); chart != "" {
		return chart
	}
	if history := hr.Objects("status", "history"); len(history) > 0 {
		return history[0].Str("chartName")
	}
	return ""
}

// proofsFoundation reads <root>/clusters/_template/bootstrap-kit/*.yaml and
// returns "<namespace>/<name>" of every HelmRelease in a slot file whose
// number (the text of the file name before the first "-") is one of
// foundationSlots.
func proofsFoundation(root string) (map[string]bool, error) {
	if root == "" {
		return nil, errors.New("the run has no --repo-root")
	}
	files, err := filepath.Glob(filepath.Join(root, filepath.FromSlash(pinsDir), "*.yaml"))
	if err != nil {
		return nil, err
	}
	slots := map[string]bool{}
	for _, s := range strings.Fields(foundationSlots) {
		slots[s] = true
	}
	sort.Strings(files)
	out := map[string]bool{}
	for _, file := range files {
		number, _, _ := strings.Cut(filepath.Base(file), "-")
		if !slots[number] {
			continue
		}
		text, err := os.ReadFile(filepath.Clean(file))
		if err != nil {
			return nil, err
		}
		for _, doc := range strings.Split("\n"+string(text), "\n---") {
			at := pinValues(doc)
			if at["kind"] == "HelmRelease" && at["metadata/name"] != "" {
				out[at["metadata/namespace"]+"/"+at["metadata/name"]] = true
			}
		}
	}
	return out, nil
}
