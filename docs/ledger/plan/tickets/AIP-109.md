# AIP-109 — The old gateway's values drop a commented channel example that names the vendor's host

## In plain words

**The problem today.** The values file of the old model gateway still carries a commented example of a channel to the model vendor, with the vendor's API host in it. Because of that one comment the file sits on the agent-plane guard's list of files allowed to name the host, and it takes a place that the new Axon chart needs.

**What changes.** The commented vendor channel goes from the example, and the file leaves the guard's allow list, so the host can no longer return there unnoticed. The guard's stored limit is not lowered, so the Axon chart can take the freed place.

**Done means:**

- The old gateway's values file names neither the vendor nor its host; the two other channel examples of the comment stay.
- The agent-plane guard passes with the values file off its allow list for the vendor host, so putting the host back in that file turns the guard red.
- The guard's stored limit for that rule stays at 8, one above the files that name the host today.
- The chart of the old gateway renders exactly the same objects as before.

The rest of this ticket is the exact instruction for the model that does the work.
