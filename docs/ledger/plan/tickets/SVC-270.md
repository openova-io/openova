# SVC-270 — In-cluster object storage and the capability probe

## In plain words

**The problem today.** No capability contract exists yet, so no Blueprint can ask for object storage by contract, and nothing makes a bucket with a key of its own for one consumer. Nothing proves that a binding works the way a consumer uses it.

**What changes.** Object storage gets its first implementation: one bucket and one key of its own for each consumer, on the Sovereign's own object store, handed over as files read from the secrets store and never as a Kubernetes Secret. A small probe Blueprint mounts those files, and its test writes, reads and deletes an object with them.

**Done means:**

- The object storage contract file exists, and the capability index names bp-object-bucket as its implementation.
- A bucket request renders one Job in the object store's namespace and no Secret object, and the same request in another namespace is refused.
- The probe Blueprint mounts each binding as nine files from OpenBao, renders no Secret object, and its function test runs the probe.
- The probe's tests and the probe image pass against a real S3 server before an image is pushed.
- OpenBao has the write-only identity of the bucket Jobs, and OpenBao's network policy admits the namespace they run in.
- The catalogue lists both new Blueprints, and no version line of an existing chart changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The capability `object-storage`, contract `v1`, is the file `platform/_capabilities/object-storage.yaml`, and the capability index `products/catalyst/bootstrap/api/internal/catalog/capabilities.json` names its first implementation, `bp-object-bucket` (`platform/object-bucket`). For each Context of an Application of that chart (the list `spec.parameters.buckets`, in the shape the install API writes), one Job in the SeaweedFS namespace makes one bucket and one access key that may act on that bucket only, on the Sovereign's own SeaweedFS, and writes the nine keys of the contract to the Context's binding path in OpenBao as the write-only producer `binding`. No key becomes a Secret object. `bp-capability-probe` (`platform/capability-probe`) is the consumer that proves a binding: it mounts each bound binding as nine files through the Secrets Store CSI driver, and its function test runs the probe built from `core/cmd/capability-probe`, which puts an object with the binding's own key, gets it back, compares it and deletes it. `.github/workflows/build-capability-probe.yaml` tests the probe against a real SeaweedFS over TLS and pushes only an image that passed the probe. OpenBao's network policy admits the SeaweedFS namespace, so the Jobs can log in.

## 3. The model (the law)
1. The contract file (format `platform/_schemas/capability.schema.json`): `defaultImplementation: bp-object-bucket`, `compositeKind: ObjectBucket`, one contract `v1` with status `current`, nine keys (`type`, `provider`, `endpoint`, `region`, `bucket`, `path-style`, `access-key-id`, `secret-access-key`, and `ca.crt`, the only optional one), the context fields `versioning` (boolean, default false) and `retentionDays` (integer, default 0), and the probe `object-storage-v1`. An endpoint is `https://`; `http://` only for a service name of the cluster.
2. `bp-object-bucket`: class `data-service`, `shareable: true`, visibility `unlisted`, lifecycle `experimental`; it provides `object-storage` `v1` as implementation `in-cluster` and depends on `bp-seaweedfs`. Spike SVC-250 recorded outcome 2 (`docs/ledger/plan/spikes/SVC-250.md`): a key scoped to one bucket is made only with the administrator's reach, so a release with Contexts runs in namespace `seaweedfs` (the render refuses another namespace) and one instance serves every consumer.
3. Per Context one Job, named by a digest of the Context, the settings and the script, running `files/context.sh` in the kit's SeaweedFS image as service account `object-bucket` with a projected token of audience `openbao`. It makes the bucket `<name>-<first 8 hex of the SHA-256 of namespace/name/alias>`, sets a storage rule of one volume per growth (spike SVC-250: a new bucket otherwise takes 7 of the kit's 30 volume slots) and the time to live of `retentionDays`, sets versioning, makes an identity with Read, Write, List and Tagging on that bucket only, and writes the nine keys to `binding.path` as OpenBao role `producer-binding`. A key whose binding exists is kept. `retentionDays` above 0 with `versioning: true` is refused. No Secret object is rendered, the platform's root key is never used for a Context, and the SeaweedFS endpoint gets no route.
4. The list of Contexts of a revision is the ConfigMap `<release>-contexts`. On an upgrade the chart reads that list from the cluster (`lookup`): a Context that left `.Values.buckets` gets a pre-upgrade Job that deletes its key and its binding and keeps its bucket.
5. `bp-capability-probe`: class `application`, visibility `unlisted`, `requires: [{capability: object-storage, contract: v1, alias: objects, optional: true}]`. For each bound alias: one SecretProviderClass with one object per contract key (provider `openbao`, role `workload`), never `secretObjects`; one read-only CSI volume at `/bindings/<alias>`; an idle Deployment whose readiness runs the probe with `--keys-only`; and the function test, a `helm.sh/hook: test` Pod that runs the probe on each alias and prints `FUNCTION-TEST pass` or `FUNCTION-TEST fail` last. With no bound alias the chart renders nothing. A bound alias without `image.tag` is refused.
6. The probe: `capability-probe --probe <name> --binding-dir <dir>` exits 0 with one line `PROBE pass <probe> ...` and 1 with one line `PROBE fail <probe> <reason>`; `object-storage-v1` checks the keys, then puts, gets, compares and deletes the exact version of one object. It prints no key value.
7. The build: on every event the tests run against SeaweedFS 4.22 (the kit's release) with TLS from a private CA (`core/cmd/capability-probe/testdata/s3-server.sh`), and the built image must pass the probe against it; only a push to `main` pushes and signs the image, and its promote job pins `image.tag` in the chart and bumps the chart's patch version with the deploy-bump action, as `build-k8s-ws-proxy.yaml` does.
8. `bp-openbao` gains the producer entry `binding` (service account `object-bucket`, namespace `seaweedfs`, pattern `+/shared/binding-*`): create and update on the data, read and delete on the metadata, no read of a value. `bp-plane-isolation` admits namespace `seaweedfs` to OpenBao.
9. The five generated files are written by their generators, the service-model baseline `G6.function-test-charts` by `--write-baseline` (one more chart with a function test). No version line of an existing chart changes. No Python is added. No live system is read or written. No NodePort.

+// Command capability-probe checks one binding of a capability contract the way a consumer uses it
+// (docs/adr/0020, S7 and S11; contract files platform/_capabilities/<name>.yaml).
+//
+//	capability-probe --probe <name> --binding-dir <dir>   read the contract keys as files in <dir>, check
+//	                                                      every required key is present and well formed,
+//	                                                      then exercise the service
+//	capability-probe --probe <name> --binding-dir <dir> --keys-only   only check the keys (readiness)
+//	capability-probe --idle                               wait until the pod is stopped (the idle consumer
+//	                                                      of bp-capability-probe)
+//
+// Exit 0 with one line "PROBE pass <probe> <what was done>". Exit 1 with one line
+// "PROBE fail <probe> <reason>" otherwise. The probe prints no key value, secret or not.
+package main
+
+import (
+	"context"
+	"flag"
+	"fmt"
+	"io"
+	"os"
+	"os/signal"
+	"strings"
+	"syscall"
+	"time"
+)
+
+// probeFunc checks the binding files in dir and, unless keysOnly, exercises the service through
+// them; it returns what it did.
+type probeFunc func(ctx context.Context, dir string, keysOnly bool) (string, error)
+
+// probes is the set of probe names a contract file may name in spec.contracts[].probe.
+var probes = map[string]probeFunc{
+	"object-storage-v1": objectStorageV1,
+}
+
+// probeTimeout bounds one probe run; the function test of a chart has 300 seconds in all.
+const probeTimeout = 2 * time.Minute
+
+func main() {
+	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
+	code := run(ctx, os.Args[1:], os.Stdout)
+	stop()
+	os.Exit(code)
+}
+
+func run(ctx context.Context, args []string, out io.Writer) int {
+	fs := flag.NewFlagSet("capability-probe", flag.ContinueOnError)
+	fs.SetOutput(io.Discard)
+	name := fs.String("probe", "", "name of the probe, as in spec.contracts[].probe of the contract file")
+	dir := fs.String("binding-dir", "", "directory that holds one file per contract key")
+	idle := fs.Bool("idle", false, "wait until the process is stopped")
+	keysOnly := fs.Bool("keys-only", false, "check the keys only; do not exercise the service (a readiness check)")
+	if err := fs.Parse(args); err != nil {
+		return fail(out, "-", "usage: "+err.Error())
+	}
+	if fs.NArg() > 0 {
+		return fail(out, "-", "usage: unexpected argument "+fs.Arg(0))
+	}
+	if *idle {
+		if *name != "" || *dir != "" || *keysOnly {
+			return fail(out, "-", "usage: --idle takes no other flag")
+		}
+		<-ctx.Done()
+		return 0
+	}
+	if *name == "" {
+		return fail(out, "-", "usage: --probe is required")
+	}
+	probe, ok := probes[*name]
+	if !ok {
+		return fail(out, *name, "unknown probe")
+	}
+	if *dir == "" {
+		return fail(out, *name, "usage: --binding-dir is required")
+	}
+	pctx, cancel := context.WithTimeout(ctx, probeTimeout)
+	defer cancel()
+	done, err := probe(pctx, *dir, *keysOnly)
+	if err != nil {
+		return fail(out, *name, err.Error())
+	}
+	_, _ = fmt.Fprintf(out, "PROBE pass %s %s\n", *name, done)
+	return 0
+}
+
+func fail(out io.Writer, name, reason string) int {
+	_, _ = fmt.Fprintf(out, "PROBE fail %s %s\n", name, oneLine(reason))
+	return 1
+}
+
+// oneLine keeps the result to the one line the function test reads.
+func oneLine(s string) string {
+	return strings.Join(strings.Fields(s), " ")
+}

+// bindingKey is one key of a contract version: one file in the binding directory.
+type bindingKey struct {
+	name     string
+	required bool
+}

+// objectStorageV1Keys are the keys of contract v1 of platform/_capabilities/object-storage.yaml.
+var objectStorageV1Keys = []bindingKey{
+	{"type", true},
+	{"provider", true},
+	{"endpoint", true},
+	{"region", true},
+	{"bucket", true},
+	{"path-style", true},
+	{"access-key-id", true},
+	{"secret-access-key", true},
+	{"ca.crt", false},

+var bucketName = regexp.MustCompile(`^[a-z0-9][a-z0-9.-]{1,61}[a-z0-9]$`)

+// readBinding reads one file per key. A required key must be a file with a value; an optional key
+// may be absent or empty (an empty file stands for an absent key: the producer writes every key).
+func readBinding(dir string, keys []bindingKey) (map[string]string, error) {
+	values := make(map[string]string, len(keys))
+	fsys := os.DirFS(dir)
+	for _, k := range keys {
+		raw, err := fs.ReadFile(fsys, k.name)
+		switch {
+		case errors.Is(err, fs.ErrNotExist) && !k.required:
+			continue
+		case errors.Is(err, fs.ErrNotExist):
+			return nil, fmt.Errorf("key %s missing", k.name)
+		case err != nil:
+			return nil, fmt.Errorf("key %s unreadable: %v", k.name, err)
+		}
+		v := strings.TrimSpace(string(raw))
+		if v == "" && k.required {
+			return nil, fmt.Errorf("key %s empty", k.name)
+		}
+		values[k.name] = v
+	}
+	return values, nil
+}

+// objectStorageBinding is a checked binding of contract object-storage v1.
+type objectStorageBinding struct {
+	endpoint  string
+	host      string
+	secure    bool
+	region    string
+	bucket    string
+	pathStyle bool
+	accessKey string
+	secretKey string
+	roots     *x509.CertPool
+}

+// checkObjectStorage checks that every key is well formed. It names the key and never its value
+// when the key is a credential.
+func checkObjectStorage(v map[string]string) (objectStorageBinding, error) {
+	b := objectStorageBinding{region: v["region"], accessKey: v["access-key-id"], secretKey: v["secret-access-key"]}
+	if v["type"] != "s3" {
+		return b, fmt.Errorf("key type is %q, want s3", v["type"])
+	}
+	u, err := url.Parse(v["endpoint"])
+	if err != nil {
+		return b, fmt.Errorf("key endpoint %q is not a URL", v["endpoint"])
+	}
+	switch {
+	case u.Host == "" || u.Hostname() == "":
+		return b, fmt.Errorf("key endpoint %q has no host", v["endpoint"])
+	case u.User != nil || u.RawQuery != "" || u.Fragment != "" || (u.Path != "" && u.Path != "/"):
+		return b, fmt.Errorf("key endpoint %q must be scheme://host[:port] only", v["endpoint"])
+	case u.Scheme == "https":
+		b.secure = true
+	case u.Scheme == "http" && clusterLocal(u.Hostname()):
+		b.secure = false
+	case u.Scheme == "http":
+		return b, fmt.Errorf("key endpoint %q: http is allowed only for a service name of the cluster (*.svc, *.svc.cluster.local)", v["endpoint"])
+	default:
+		return b, fmt.Errorf("key endpoint %q: scheme must be https", v["endpoint"])
+	}
+	b.endpoint, b.host = v["endpoint"], u.Host
+	if !bucketName.MatchString(v["bucket"]) {
+		return b, fmt.Errorf("key bucket %q is not a bucket name", v["bucket"])
+	}
+	b.bucket = v["bucket"]
+	switch v["path-style"] {
+	case "true":
+		b.pathStyle = true
+	case "false":
+	default:
+		return b, fmt.Errorf("key path-style is %q, want true or false", v["path-style"])
+	}
+	if pem := v["ca.crt"]; pem != "" {
+		b.roots = x509.NewCertPool()
+		if !b.roots.AppendCertsFromPEM([]byte(pem)) {
+			return b, errors.New("key ca.crt holds no PEM certificate")
+		}
+	}
+	return b, nil
+}

+func clusterLocal(host string) bool {
+	return strings.HasSuffix(host, ".svc") || strings.HasSuffix(host, ".svc.cluster.local")
+}

+// objectStorageV1 puts an object, gets it back, compares it and deletes it, with the binding's own
+// key. It removes the exact version it wrote, so a versioned bucket keeps nothing either.
+func objectStorageV1(ctx context.Context, dir string, keysOnly bool) (string, error) {
+	v, err := readBinding(dir, objectStorageV1Keys)
+	if err != nil {
+		return "", err
+	}
+	b, err := checkObjectStorage(v)
+	if err != nil {
+		return "", err
+	}
+	if keysOnly {
+		return fmt.Sprintf("keys of bucket %s at %s present and well formed (provider %s)", b.bucket, b.endpoint, v["provider"]), nil
+	}
+	client, err := newS3Client(b)
+	if err != nil {
+		return "", err
+	}
+	suffix := make([]byte, 8)
+	if _, err := rand.Read(suffix); err != nil {
+		return "", fmt.Errorf("random object name: %v", err)
+	}
+	key := "capability-probe/" + hex.EncodeToString(suffix)
+	body := []byte("capability-probe object-storage-v1 " + key + "\n")
+
+	put, err := client.PutObject(ctx, b.bucket, key, bytes.NewReader(body), int64(len(body)),
+		minio.PutObjectOptions{ContentType: "text/plain"})
+	if err != nil {
+		return "", fmt.Errorf("put object %s into bucket %s at %s: %v", key, b.bucket, b.endpoint, err)
+	}
+	remove := func(ctx context.Context) error {
+		return client.RemoveObject(ctx, b.bucket, key, minio.RemoveObjectOptions{VersionID: put.VersionID})
+	}
+	// After the put every failure removes the object first, with its own short deadline.
+	undo := func(cause error) (string, error) {
+		cctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
+		defer cancel()
+		if err := remove(cctx); err != nil {
+			return "", fmt.Errorf("%v; and removing object %s failed: %v", cause, key, err)
+		}
+		return "", cause
+	}
+	obj, err := client.GetObject(ctx, b.bucket, key, minio.GetObjectOptions{VersionID: put.VersionID})
+	if err != nil {
+		return undo(fmt.Errorf("get object %s: %v", key, err))
+	}
+	got, err := io.ReadAll(obj)
+	_ = obj.Close()
+	if err != nil {
+		return undo(fmt.Errorf("get object %s: %v", key, err))
+	}
+	if !bytes.Equal(got, body) {
+		return undo(fmt.Errorf("object %s read back (%d bytes) differs from the object written (%d bytes)", key, len(got), len(body)))
+	}
+	if err := remove(ctx); err != nil {
+		return "", fmt.Errorf("delete object %s: %v", key, err)
+	}
+	_, err = client.StatObject(ctx, b.bucket, key, minio.StatObjectOptions{})
+	if err == nil {
+		return "", fmt.Errorf("object %s still exists after its delete", key)
+	}
+	if code := minio.ToErrorResponse(err).Code; code != "NoSuchKey" {
+		return "", fmt.Errorf("stat of object %s after its delete: %v", key, err)
+	}
+	return fmt.Sprintf("put, got and deleted object %s in bucket %s at %s (provider %s)", key, b.bucket, b.endpoint, v["provider"]), nil
+}
+
+func newS3Client(b objectStorageBinding) (*minio.Client, error) {
+	transport, err := minio.DefaultTransport(b.secure)
+	if err != nil {
+		return nil, fmt.Errorf("S3 client transport: %v", err)
+	}
+	if b.roots != nil && transport.TLSClientConfig != nil {
+		transport.TLSClientConfig.RootCAs = b.roots
+	}
+	lookup := minio.BucketLookupDNS
+	if b.pathStyle {
+		lookup = minio.BucketLookupPath
+	}
+	client, err := minio.New(b.host, &minio.Options{
+		Creds:        credentials.NewStaticV4(b.accessKey, b.secretKey, ""),
+		Secure:       b.secure,
+		Region:       b.region,
+		BucketLookup: lookup,
+		Transport:    transport,
+		MaxRetries:   2,
+	})
+	if err != nil {
+		return nil, fmt.Errorf("S3 client for %s: %v", b.endpoint, err)
+	}
+	return client, nil
+}

+stop)

+  exit 0
+  ;;

+  exit 2
+  ;;

+  {"name": "admin", "credentials": [{"accessKey": "$admin_key", "secretKey": "$admin_secret"}], "actions": ["Admin"]},

+   "actions": ["Read:probe-bucket", "Write:probe-bucket", "List:probe-bucket", "Tagging:probe-bucket",
+               "Read:probe-versioned", "Write:probe-versioned", "List:probe-versioned", "Tagging:probe-versioned"]}

+    exit 1
+  fi
+  sleep 1
+done
+echo "PROBE_TEST_S3_DIR=$dir"

+# bp-capability-probe
+
+A consumer of capabilities that exists to prove them: an idle Deployment of the `capability-probe`
+image (`core/cmd/capability-probe`) that mounts each bound binding as files, and a function test that
+runs the contract's probe on each.
+
+**Role in Catalyst.** An `application` Blueprint, `unlisted`. It `requires` each capability that has
+a probe, every entry `optional: true`; the install API binds the ones asked for and writes
+`spec.parameters.bindings.<alias>` ([ADR-0020](../../docs/adr/0020-service-model-classes-and-capability-contracts.md), S4, S7 and S11;
+[`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md)). The gate record reads its `functionTest`.
+
+## What it renders, for each bound alias
+
+- A `SecretProviderClass` `<release>-<alias>` of provider `openbao`, role `workload`, with one object
+  per key of the contract (`platform/_capabilities/<capability>.yaml`), each read from the binding's
+  path. `secretObjects` is never set: no key becomes a Secret object.
+- A read-only CSI volume of it at `/bindings/<alias>` in the idle Deployment, which is ready when
+  `capability-probe --keys-only` finds every key present and well formed.
+- The function test: `capability-probe --probe <probe> --binding-dir /bindings/<alias>`. For
+  `object-storage` v1 the probe puts an object with the binding's own key, gets it back, compares
+  it and deletes it. Its last line is `FUNCTION-TEST pass bp-capability-probe ...`, or
+  `FUNCTION-TEST fail bp-capability-probe binding <alias> <reason>`.
+
+With no bound alias the chart renders nothing: there is nothing to probe.
+
+## Configuration
+
+| Value | Default | Meaning |
+|---|---|---|
+| `image.tag` | `""` | Pinned by the promote job of `.github/workflows/build-capability-probe.yaml`; a bound alias needs it |
+| `bindings` | `{}` | Written by the install API only |
+| `openbao.addr`, `openbao.role` | the kit's OpenBao, `workload` | What the CSI driver reads with |
+
+## Operational notes
+
+- A probe Pod writes one object of a few bytes and removes it, the exact version it wrote, so a
+  versioned bucket keeps nothing either.
+- A new contract with a probe adds its keys to `capabilityProbe.contracts` (`chart/templates/_helpers.tpl`)
+  and an optional `requires` entry here; `chart/tests/render.sh` compares the keys with the contract file.
+- Tests: `chart/tests/render.sh`; the probe's own tests run against a real S3 server in
+  `build-capability-probe.yaml`.

+# bp-object-bucket
+
+The in-cluster implementation of the capability `object-storage`, contract `v1`
+(`platform/_capabilities/object-storage.yaml`): one bucket on the Sovereign's own SeaweedFS for each
+Context, each with its own access key that may act on that bucket only.
+
+**Role in Catalyst.** A `data-service` Blueprint, `shareable`, `unlisted`. It is the default
+implementation of `object-storage`. A consumer Blueprint declares
+`requires: [{capability: object-storage, contract: v1, alias: <alias>}]`; the install API resolves the
+requirement to this Blueprint, adds a Context entry to `spec.parameters.buckets` of its Application
+and gives the consumer `spec.parameters.bindings.<alias>` (S4 and S7 of
+[ADR-0020](../../docs/adr/0020-service-model-classes-and-capability-contracts.md); [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md)).
+
+## What one Context gets
+
+For each entry of `buckets` the chart runs one Job (`chart/files/context.sh`) in the SeaweedFS image:
+
+1. It creates the bucket `<name>-<8 hex of sha256 of namespace/name/alias>` when it is absent, and
+   sets its storage rule: one volume per growth (spike SVC-250 measured that a new bucket otherwise
+   takes 7 of the kit's 30 volume slots), and a time to live of `retentionDays` when it is above 0.
+2. It enables versioning when `versioning` is true, and suspends it when it is false on a bucket
+   that has it.
+3. It makes a SeaweedFS identity of the bucket's name with `Read`, `Write`, `List` and `Tagging` on
+   that bucket only, with a fresh key, and writes the nine keys of the contract to the entry's
+   `binding.path` in OpenBao, as the producer `binding` of bp-openbao, which may write and never read.
+   A key whose binding already exists is kept, so a re-run never changes the key a consumer holds.
+
+Removing an entry runs a pre-upgrade Job that deletes the identity and the binding and keeps the
+bucket. The keys never become a Secret object; the platform's own administrator key is never used.
+
+## Configuration
+
+| Value | Default | Meaning |
+|---|---|---|
+| `buckets` | `[]` | The Context entries; written by the install API only |
+| `seaweedfs.namespace` | `seaweedfs` | A release with a Context must run here |
+| `seaweedfs.master`, `seaweedfs.filer` | the kit's services | What the Jobs' `weed shell` dials |
+| `seaweedfs.s3Endpoint` | `http://seaweedfs-s3.seaweedfs.svc.cluster.local:8333` | The binding's `endpoint` |
+| `seaweedfs.caBundle` | `""` | The binding's `ca.crt` |
+| `openbao.role` | `producer-binding` | The producer identity the Jobs log in as |
+| `serviceAccount` | `object-bucket` | The identity that role binds |
+
+## Operational notes
+
+- **One instance.** Spike SVC-250 recorded outcome 2: a key scoped to one bucket can be made only
+  from the SeaweedFS namespace, so one instance runs there and Organizations reuse it (SVC-275 adds
+  it to the kit).
+- **Endpoint.** The kit's S3 gateway serves HTTP inside the cluster (slot 18, `s3.httpsPort: 0`).
+  The contract allows `http` only for a service name of the cluster.
+- **Regions.** A bucket lives in the SeaweedFS of the region its Job ran in; the contract does not
+  replicate a bucket to another region.
+- **Uninstall.** Uninstalling the release removes no key and no binding; remove the entries first.
+- **Not yet enforced.** Until NET-163 enforces the SeaweedFS NetworkPolicy, any pod can reach the
+  filer; when it does, its rules must keep this release's egress to OpenBao.
+- Tests: `chart/tests/render.sh` (the render, and the script against stubs of `weed` and `curl`).

+#!/bin/sh
+# shellcheck disable=SC2153 # every upper-case name is set by the Job (templates/_helpers.tpl, objectBucket.job)
+# bp-object-bucket: one Context (one entry of .Values.buckets), run by the Job of templates/jobs.yaml
+# in the SeaweedFS image (weed and curl; no jq).
+#
+#   MODE=create  make the bucket if it is absent, set its storage rule and versioning, make a key
+#                that may act on this bucket only, and write the nine keys of object-storage v1 to
+#                BINDING_PATH as the OpenBao producer. A key whose binding exists is kept, so a
+#                re-run never changes the key a running consumer holds.
+#   MODE=remove  delete the key and the binding; the bucket and its objects are kept.
+#
+# weed shell exits 0 even when its command fails; its line "error: ..." on stderr is the failure.
+# No key value is ever printed. The last line is "OBJECT-BUCKET <pass|fail> <context> <what>".
+set -eu
+umask 077
+W=${WORK_DIR:-/tmp/work}
+mkdir -p "$W"
+say() { echo "OBJECT-BUCKET $1 $CONTEXT $2"; }
+fail() { say fail "$1"; exit 1; }
+oneline() { tr '\n' ' ' <"$1" | cut -c1-300; }
+
+# wsh <out> <command and flags>: one command of weed shell; returns 1 when it printed an error.
+wsh() {
+  out=$1
+  shift
+  if ! printf '%s\n' "$*" | timeout 120 weed shell -master="$SEAWEEDFS_MASTER" -filer="$SEAWEEDFS_FILER" >"$out" 2>"$W/err"; then
+    fail "weed shell $1 did not finish: $(oneline "$W/err")"
+  fi
+  ! grep -q -E '^(error|unknown command):' "$W/err"
+}
+
+# bao <method> <path> [body file]: one call to OpenBao with the token of the login; prints the HTTP code.
+bao() {
+  if [ $# -eq 3 ]; then
+    curl -sS -o "$W/answer" -w '%{http_code}' --max-time 20 -H "@$W/header" -H 'Content-Type: application/json' \
+      -X "$1" --data-binary "@$3" "$OPENBAO_ADDR/v1/$2" 2>"$W/curl" || :
+  else
+    curl -sS -o "$W/answer" -w '%{http_code}' --max-time 20 -H "@$W/header" -X "$1" "$OPENBAO_ADDR/v1/$2" 2>"$W/curl" || :
+  fi
+}
+
+login() {
+  printf '{"role":"%s","jwt":"%s"}' "$OPENBAO_ROLE" "$(cat "$TOKEN_FILE")" >"$W/login.json"
+  code=$(curl -sS -o "$W/login" -w '%{http_code}' --max-time 20 -H 'Content-Type: application/json' \
+    -X POST --data-binary "@$W/login.json" "$OPENBAO_ADDR/v1/auth/$OPENBAO_AUTH_PATH/login" 2>"$W/curl") || :
+  rm -f "$W/login.json"
+  [ "$code" = 200 ] || fail "OpenBao login as $OPENBAO_ROLE at $OPENBAO_ADDR: HTTP $code $(oneline "$W/curl")"
+  token=$(sed -n 's/.*"client_token":"\([^"]*\)".*/\1/p' "$W/login")
+  rm -f "$W/login"
+  [ -n "$token" ] || fail "OpenBao login as $OPENBAO_ROLE: the answer holds no client token"
+  printf 'X-Vault-Token: %s\n' "$token" >"$W/header"
+}
+
+# user_exists: 0 when the identity exists, 1 when SeaweedFS answers it is not found.
+user_exists() {
+  if wsh "$W/user" s3.user.show -name "$USER_NAME"; then
+    return 0
+  fi
+  grep -q NotFound "$W/err" || fail "show user $USER_NAME: $(oneline "$W/err")"
+  return 1
+}
+
+META_PATH=mounted/metadata/${BINDING_PATH#mounted/data/}
+login
+
+if [ "$MODE" = remove ]; then
+  if user_exists; then
+    wsh /dev/null s3.configure -user="$USER_NAME" -delete -apply || fail "delete user $USER_NAME: $(oneline "$W/err")"
+    key=deleted
+  else
+    key=absent
+  fi
+  code=$(bao DELETE "$META_PATH")
+  case $code in
+  204) binding=deleted ;;
+  404) binding=absent ;;
+  *) fail "delete binding $BINDING_PATH: HTTP $code $(oneline "$W/curl")" ;;
+  esac
+  say pass "key of $USER_NAME $key, binding $BINDING_PATH $binding, bucket $BUCKET kept"
+  exit 0
+fi
+[ "$MODE" = create ] || fail "MODE is $MODE, want create or remove"
+
+if [ "$RETENTION_DAYS" -gt 0 ] && [ "$VERSIONING" = true ]; then
+  # SeaweedFS expires objects through a time to live on the bucket's volumes, which would destroy
+  # the versions that versioning keeps; its own S3 lifecycle refuses the same combination.
+  fail "retentionDays $RETENTION_DAYS with versioning true is not offered by the in-cluster implementation"
+fi
+
+wsh "$W/buckets" s3.bucket.list || fail "list buckets: $(oneline "$W/err")"
+if grep -q -F -e "$(printf '  %s\t' "$BUCKET")" "$W/buckets"; then
+  bucket=kept
+else
+  wsh /dev/null s3.bucket.create -name "$BUCKET" || fail "create bucket $BUCKET: $(oneline "$W/err")"
+  bucket=made
+fi
+
+# One volume per growth: a new bucket otherwise takes 7 of the kit's 30 volume slots at its first
+# write, and the sixth bucket cannot be written (spike SVC-250, item 7).
+ttl=
+[ "$RETENTION_DAYS" -gt 0 ] && ttl=-ttl=${RETENTION_DAYS}d
+# shellcheck disable=SC2086 # $ttl is one flag or nothing
+wsh /dev/null fs.configure -locationPrefix="/buckets/$BUCKET/" -collection="$BUCKET" -volumeGrowthCount=1 $ttl -apply ||
+  fail "storage rule of bucket $BUCKET: $(oneline "$W/err")"
+
+wsh "$W/versioning" s3.bucket.versioning -name "$BUCKET" || fail "versioning of bucket $BUCKET: $(oneline "$W/err")"
+if [ "$VERSIONING" = true ] && ! grep -q '^Versioning: Enabled' "$W/versioning"; then
+  wsh /dev/null s3.bucket.versioning -name "$BUCKET" -enable || fail "enable versioning of bucket $BUCKET: $(oneline "$W/err")"
+elif [ "$VERSIONING" != true ] && grep -q '^Versioning: Enabled' "$W/versioning"; then
+  wsh /dev/null s3.bucket.versioning -name "$BUCKET" -suspend || fail "suspend versioning of bucket $BUCKET: $(oneline "$W/err")"
+fi
+
+has_user=no
+user_exists && has_user=yes
+code=$(bao GET "$META_PATH")
+case $code in
+200) has_binding=yes ;;
+404) has_binding=no ;;
+*) fail "read the metadata of binding $BINDING_PATH: HTTP $code $(oneline "$W/curl")" ;;
+esac
+
+if [ "$has_user" = yes ] && [ "$has_binding" = yes ]; then
+  key=kept
+else
+  if [ "$has_user" = yes ]; then
+    wsh /dev/null s3.configure -user="$USER_NAME" -delete -apply || fail "delete user $USER_NAME: $(oneline "$W/err")"
+  fi
+  ak=$(tr -dc 'A-Z0-9' </dev/urandom | head -c 20)
+  sk=$(tr -dc 'A-Za-z0-9' </dev/urandom | head -c 40)
+  wsh /dev/null s3.configure -user="$USER_NAME" -buckets="$BUCKET" -actions=Read,Write,List,Tagging \
+    -access_key="$ak" -secret_key="$sk" -apply || fail "make the key of user $USER_NAME: $(oneline "$W/err")"
+  printf '{"data":{"type":"s3","provider":%s,"endpoint":%s,"region":%s,"bucket":"%s","path-style":"true","access-key-id":"%s","secret-access-key":"%s","ca.crt":%s}}' \
+    "$PROVIDER_JSON" "$ENDPOINT_JSON" "$REGION_JSON" "$BUCKET" "$ak" "$sk" "$CA_JSON" >"$W/binding.json"
+  code=$(bao POST "$BINDING_PATH" "$W/binding.json")
+  rm -f "$W/binding.json"
+  case $code in
+  200 | 204) key=made ;;
+  *) fail "write binding $BINDING_PATH: HTTP $code $(oneline "$W/curl")" ;;
+  esac
+fi
+say pass "bucket $BUCKET $bucket, key of $USER_NAME $key, binding $BINDING_PATH"
