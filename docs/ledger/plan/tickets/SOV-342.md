# SOV-342 — The provider pod installs OpenTofu providers only from an OCI mirror of listed, digest-pinned packages

## In plain words

**The problem today.** The pod that runs OpenTofu for the cloud Workspaces has no OpenTofu configuration, so every tofu init downloads its providers from the public OpenTofu registry. After a cutover the Sovereign is cut off from the internet, and the Workspaces that hold its own cloud resources fail, while the sovereignty proof does not look at them.

**What changes.** The provider packages are published once at the origin as an OCI provider mirror, listed with their digests in Git, and the provider pod installs them only from that mirror with the pull credential. A guard keeps the list complete, and an offline test shows that init reaches no other host.

**Done means:**

- A Workspace's tofu init in the provider pod reads a CLI configuration that names one OCI mirror at the origin and no other installation method.
- Every provider version the modules require, their lock files pin or a pack names is listed with the digest of its OCI index, and a guard fails when one is missing.
- Each listed package exists at ghcr.io/openova-io/tofu-providers before the change that lists it merges, built from the zip the OpenTofu registry serves and checked against the registry's SHA-256.
- An offline tofu init of the CloudAdoption module installs every provider from a local copy of the mirror with all outside hosts unreachable, and fails, naming the provider, when the mirror lacks one.
- A provider pack's provider names stay in the pack's own folder: the shared list is generated from the packs' lists.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every `tofu init` that the Crossplane provider `provider-opentofu` runs for a Workspace installs its providers only from the OCI provider mirror `ghcr.io/openova-io/tofu-providers/<namespace>/<type>:<version>`, with the pull credential of the Sovereign, and from no other source: a provider that the mirror does not hold fails init instead of being fetched from `registry.opentofu.org`. The packages of that mirror are listed with the digest of their OCI index in the ConfigMap `crossplane-system/opentofu-providers`, the union of each provider pack's own list. A workflow publishes each listed package before the change that lists it merges, a Go guard keeps the list complete, and a script shows offline that init needs no outside host. The cutover's copy of the packages into the Sovereign (SOV-343) and the hold's count of the Workspaces (SOV-344) build on this.

## 3. The model (the law)
1. The provider pod reads one CLI configuration: the key `.tofurc` of the ConfigMap `crossplane-system/opentofu-cli-config`, mounted at `/etc/opentofu/cli`. Its `provider_installation` block has exactly one method, an `oci_mirror` for `registry.opentofu.org/*/*` with `repository_template = "ghcr.io/openova-io/tofu-providers/$${namespace}/$${type}"` (the Kustomization `infrastructure-providers` substitutes from `sovereign-variables`, and Flux writes `$${x}` as `${x}`). No `direct`, `network_mirror`, `filesystem_mirror` or `dev_overrides`.
2. The configuration names the pull credential as its only Docker-style file, `/etc/opentofu/oci/config.json`: the key `.dockerconfigjson` of the Secret that `REGISTRY_PULL_SECRET` names (`ghcr-pull`) in `crossplane-system`, the reflector's copy of `flux-system/ghcr-pull`, mounted read only with `optional: true`. A file that cannot be read fails init (fail closed). The Secret is read, never written, copied or rendered here; its writers stay those that `clusters/_template/bootstrap-secrets/ghcr-pull.yaml` names.
3. The ProviderConfig `default` (group `opentofu.upbound.io`) carries the credential `filename: .tofurc`, `source: Filesystem`, `fs.path: /etc/opentofu/cli/.tofurc`: provider-opentofu v1.1.11 writes each credential into the Workspace's folder and runs init with `TF_CLI_CONFIG_FILE=./.tofurc`. Its other credential, its configuration and its backend are unchanged.
4. A provider's name is written only in its pack's folder: `infra/providers/<pack>/tofu-providers.txt` lists the packages of that pack, one line each, `registry.opentofu.org/<namespace>/<type> <major.minor.patch> sha256:<64 hex>`, the versions its `.terraform.lock.hcl` pins. The ConfigMap `crossplane-system/opentofu-providers` (key `providers`, same line form) is generated from them by `bash tools/guards/cmd/tofu-providers/write-list.sh`, sorted by source; it is registered by the job `regenerate and prove no diff` of `.github/workflows/mirror-tofu-providers.yaml`, so the provider-leak guard counts its lines at their sources. This follows the precedent of the catalogue categories (`infra/providers/<provider>/card-categories.yaml`, read by the catalogue generator) and of generated files judged at their source (`scripts/generator_registry.py`).
5. The digest of a line is the digest of the OCI index that `go run ./cmd/tofu-providers pack` (in `tools/guards`) builds from the linux/amd64 zip `registry.opentofu.org` serves: an index of artifact type `application/vnd.opentofu.provider` with one image manifest of artifact type `application/vnd.opentofu.provider-target`, platform linux/amd64, the empty config and exactly one layer `archive/zip`, the zip as it is; no annotation and no time stamp, so the digest follows from the zip alone.
6. The guard `go run ./cmd/tofu-providers check` fails when a list line is malformed or names a source twice (L1); when a `required_providers` entry of the CloudAdoption composition's inline module has no version in the shared list that meets its constraint, or a module of a pack (every `*.tf` of the pack folder outside `tests`) none in its pack's list (L2; operators `=`, `!=`, `>`, `>=`, `<`, `<=`, `~>`); when a lock file of a pack pins a version its pack's list does not hold (L3); when a source of a pack's `spec.tofuProviders` is not in its pack's list (L4); when two packs list one source differently, or the ConfigMap is not what `write-list.sh` writes (L5).
7. The workflow `mirror-tofu-providers` runs on pull requests and on `main` when a pack's modules, lock file, `pack.yaml` or list, the composition, the two ConfigMaps, the check script, the command (its `*_test.go` files left out, which `tree-guards` tests) or the workflow changes. Its job `publish` takes, for every listed package, the zip at the download address the registry gives, checks it against the registry's SHA-256, builds the layout with `pack`, fails when the digest differs from the list, pushes it with ORAS 1.3.0 and the job's token when the tag is absent, reads it back, and fails when an existing tag names another digest: a tag is never moved.
8. `scripts/check-tofu-init-from-mirror.sh` runs tofu init of the composition's inline module with a CLI configuration (the kit's by default) against stub packages of the listed versions served over TLS on 127.0.0.1 by `tofu-providers serve`, with `HTTPS_PROXY` and `HTTP_PROXY` on a closed local port and `NO_PROXY=127.0.0.1`. OpenTofu is `TOFU` when set (1.10 or later), else release 1.10.8, the one the image of provider-opentofu v1.1.11 installs, fetched once and checked against its SHA-256. A missing tool, an older OpenTofu or a failed fetch fails the run; nothing is skipped.
9. Nothing else changes: the Provider's package line (step 11 and SOV-240 own it), the Kustomizations, the cutover chart, no node port, no live object.

+# mirror, with every outside host unreachable (SOV-342).
+#
+# The provider pod of provider-opentofu runs `tofu init` for each Workspace with the CLI
+# configuration crossplane-system/opentofu-cli-config. This script shows offline what that
+# configuration does. It cuts the inline module out of the CloudAdoption composition, builds
+# a stub package of each version the ConfigMap opentofu-providers lists (the command
+# tools/guards/cmd/tofu-providers: stub, then pack), serves them as an OCI registry over TLS
+# on 127.0.0.1 (tofu-providers serve), points the configuration at it (the origin host
+# replaced by the served address, $$ read as Flux writes it, the credential file replaced by
+# a local one) and runs tofu init with HTTPS_PROXY and HTTP_PROXY set to a closed local port
+# and NO_PROXY=127.0.0.1, so no outside host can be reached.

+# Usage:
+#   bash scripts/check-tofu-init-from-mirror.sh [--config FILE]

+# serve starts the mirror for the configuration $2 with every listed source but $3;

+// Command tofu-providers holds the OpenTofu provider packages that the provider
+// pod of provider-opentofu installs, and serves them the way an OCI provider
+// mirror does (SOV-342).
+//
+// The provider pod runs `tofu init` for every Workspace with the CLI
+// configuration crossplane-system/opentofu-cli-config: one oci_mirror for
+// registry.opentofu.org/*/* at ghcr.io/openova-io/tofu-providers and no other
+// installation method, so a provider comes from that mirror or not at all, never
+// from the public registry. The packages the mirror holds are listed, each with
+// the digest of its OCI index, in the ConfigMap crossplane-system/opentofu-providers
+// (clusters/_template/infrastructure/providers/base/opentofu-providers.yaml). That
+// file is written from the list of each provider pack,
+// infra/providers/<pack>/tofu-providers.txt, the versions its lock file pins: a
+// pack's providers are named only in the pack's own folder.
+//
+// Subcommands (from tools/guards):
+//
+//	go run ./cmd/tofu-providers check [-root R]
+//	    exit 1, with one line per finding, when
+//	    - a line of a list is not <registry.opentofu.org/namespace/type> <major.minor.patch>
+//	      <sha256:64 hex digits>, or lists a source a second time (rule L1);
+//	    - a required_providers entry of the CloudAdoption composition's inline module
+//	      has no listed version that meets its constraint, or a module of a pack has
+//	      none in the pack's list (rule L2; the operators = != > >= < <= ~> are read);
+//	    - a lock file of a pack pins a version its pack's list does not hold (rule L3);
+//	    - a source of a pack's spec.tofuProviders is not in its pack's list (rule L4);
+//	    - two packs list one source differently, or the ConfigMap is not what
+//	      write-list.sh writes from the packs' lists (rule L5).
+//	    Exit 0 when none holds, 2 when the tree cannot be read.
+//	go run ./cmd/tofu-providers list [-root R] [-check]
+//	    writes the ConfigMap from the packs' lists (write-list.sh runs this); with
+//	    -check it writes nothing and exits 1 when the file differs.
+//	go run ./cmd/tofu-providers pack -out DIR -version V ZIP...
+//	    writes an OCI image layout of one provider version from its zips
+//	    (terraform-provider-<type>_<V>_<os>_<arch>.zip) and prints the digest of its
+//	    index: artifact type application/vnd.opentofu.provider, one manifest per zip of
+//	    artifact type application/vnd.opentofu.provider-target with exactly one layer
+//	    archive/zip, no annotation and no time stamp, tagged V. The digest follows from
+//	    the zips alone; it is the digest a list line holds.
+//	go run ./cmd/tofu-providers stub -out DIR -source S -version V
+//	    writes a stub package of S at V for linux/amd64, for offline tests.
+//	go run ./cmd/tofu-providers serve -ca-out F -addr-out F REPOSITORY=LAYOUT...
+//	    answers the read side of the OCI distribution API for each layout over TLS on

+	}
+	*root = r
+	return true

+const usage = "usage: tofu-providers check|list|pack|stub|serve [flags] (see the comment of main.go)\n"

+func run(ctx context.Context, args []string, stdout, stderr io.Writer) int {
+	if len(args) == 0 {
+		say(stderr, usage)
+		return 2
+	}
+	fs := flag.NewFlagSet("tofu-providers "+args[0], flag.ContinueOnError)
+	fs.SetOutput(stderr)
+	switch args[0] {
+	case "check":
+		root := rootFlag(fs)
+		if fs.Parse(args[1:]) != nil || fs.NArg() != 0 || !resolveRoot(root, stderr) {
+			return 2
+		}
+		res, err := check(*root)
+		if err != nil {
+			say(stderr, "tofu-providers: cannot read the tree: %v\n", err)
+			return 2
+		}
+		for _, f := range res.findings {
+			say(stdout, "FAIL %s\n", f)
+		}
+		if len(res.findings) > 0 {
+			say(stdout, "tofu-providers: %d finding(s)\n", len(res.findings))
+			return 1
+		}
+		say(stdout, "tofu-providers: PASS — %d package(s) listed; %d required provider(s) and %d lock pin(s) are met by the lists\n", res.listed, res.requirements, res.pins)
+		return 0
+	case "list":
+		root := rootFlag(fs)
+		only := fs.Bool("check", false, "write nothing; exit 1 when the file differs")
+		if fs.Parse(args[1:]) != nil || fs.NArg() != 0 || !resolveRoot(root, stderr) {
+			return 2
+		}
+		changed, problems, err := writeList(*root, *only)
+		if err != nil {
+			say(stderr, "tofu-providers: %v\n", err)
+			return 2
+		}
+		for _, p := range problems {
+			say(stdout, "FAIL %s\n", p)
+		}
+		switch {
+		case len(problems) > 0:
+			return 1
+		case changed && *only:
+			say(stdout, "FAIL %s is not what the packs' lists give; run: bash %s\n", listPath, writerScript)
+			return 1
+		case changed:
+			say(stdout, "tofu-providers: wrote %s\n", listPath)
+		default:
+			say(stdout, "tofu-providers: %s is current\n", listPath)
+		}
+		return 0
+	case "pack":
+		out := fs.String("out", "", "the layout folder to write (empty or absent)")
+		ver := fs.String("version", "", "the provider version")
+		if fs.Parse(args[1:]) != nil || *out == "" || *ver == "" || fs.NArg() == 0 {
+			say(stderr, usage)
+			return 2
+		}
+		d, err := packLayout(*out, *ver, fs.Args())
+		if err != nil {
+			say(stderr, "tofu-providers: %v\n", err)
+			return 1
+		}
+		say(stdout, "%s\n", d)
+		return 0
+	case "stub":
+		out := fs.String("out", "", "the folder for the zip")
+		src := fs.String("source", "", "registry.opentofu.org/<namespace>/<type>")
+		ver := fs.String("version", "", "the provider version")
+		if fs.Parse(args[1:]) != nil || *out == "" || *src == "" || *ver == "" || fs.NArg() != 0 {
+			say(stderr, usage)
+			return 2
+		}
+		p, err := writeStub(*out, *src, *ver)
+		if err != nil {
+			say(stderr, "tofu-providers: %v\n", err)
+			return 1
+		}
+		say(stdout, "%s\n", p)
+		return 0
+	case "serve":
+		caOut := fs.String("ca-out", "", "file for the CA certificate (PEM)")
+		addrOut := fs.String("addr-out", "", "file for the address host:port, written once the server listens")
+		if fs.Parse(args[1:]) != nil || *caOut == "" || *addrOut == "" || fs.NArg() == 0 {
+			say(stderr, usage)
+			return 2
+		}
+		repos := map[string]string{}
+		for _, a := range fs.Args() {
+			name, dir, ok := strings.Cut(a, "=")
+			if !ok || name == "" || dir == "" {
+				say(stderr, "tofu-providers: %q is not REPOSITORY=LAYOUT\n", a)
+				return 2
+			}
+			repos[name] = dir
+		}
+		ln, srv, err := startServe(repos, *caOut)
+		if err != nil {
+			say(stderr, "tofu-providers: %v\n", err)
+			return 1
+		}
+		if err := os.WriteFile(*addrOut, []byte(ln.Addr().String()+"\n"), 0o600); err != nil {
+			say(stderr, "tofu-providers: %v\n", err)
+			return 1
+		}
+		go func() {
+			<-ctx.Done()
+			_ = srv.Close()
+		}()
+		if err := srv.Serve(ln); err != nil && !errors.Is(err, http.ErrServerClosed) {
+			say(stderr, "tofu-providers: %v\n", err)
+			return 1
+		}
+		return 0
+	}
+	say(stderr, usage)
+	return 2
+}

+func main() {
+	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
+	code := run(ctx, os.Args[1:], os.Stdout, os.Stderr)
+	stop()
+	os.Exit(code)

+// packLayout writes, into the empty or absent folder out, an OCI image layout
+// that holds one OpenTofu provider version: an index of artifact type
+// application/vnd.opentofu.provider with one image manifest per zip (artifact type
+// application/vnd.opentofu.provider-target, its platform from the zip's name, an
+// empty config and exactly one layer archive/zip, the zip as it is). The layout's
+// own index tags the provider index with the version. No manifest carries an
+// annotation or a time stamp, so the index digest follows from the zips alone and
+// is the same on every run. It returns that digest.
+func packLayout(out, ver string, zips []string) (string, error) {
+	if _, _, err := parseVersion(ver); err != nil {
+		return "", err
+	}
+	if len(zips) == 0 {
+		return "", fmt.Errorf("pack needs at least one zip")
+	}
+	blobs := layout{}
+	emptyDigest := blobs.add([]byte("{}"))
+	var descs []descriptor
+	seen := map[string]bool{}
+	for _, z := range zips {
+		m := zipNameRE.FindStringSubmatch(filepath.Base(z))
+		if m == nil {
+			return "", fmt.Errorf("%s: the name is not terraform-provider-<type>_<version>_<os>_<arch>.zip", z)
+		}
+		if m[2] != ver {
+			return "", fmt.Errorf("%s: the name gives version %s, not %s", z, m[2], ver)
+		}
+		key := m[3] + "/" + m[4]
+		if seen[key] {
+			return "", fmt.Errorf("two zips for the platform %s", key)
+		}
+		seen[key] = true
+		b, err := os.ReadFile(filepath.Clean(z))
+		if err != nil {
+			return "", err
+		}
+		layer := descriptor{MediaType: mtZip, Digest: blobs.add(b), Size: int64(len(b))}
+		mb, err := json.Marshal(manifest{
+			SchemaVersion: 2, MediaType: mtManifest, ArtifactType: atProviderTarget,
+			Config: &descriptor{MediaType: mtEmpty, Digest: emptyDigest, Size: 2},
+			Layers: []descriptor{layer},
+		})
+		if err != nil {
+			return "", err
+		}
+		descs = append(descs, descriptor{MediaType: mtManifest, ArtifactType: atProviderTarget,
+			Digest: blobs.add(mb), Size: int64(len(mb)), Platform: &platform{Architecture: m[4], OS: m[3]}})
+	}
+	sort.Slice(descs, func(i, j int) bool {
+		return descs[i].Platform.OS+"/"+descs[i].Platform.Architecture < descs[j].Platform.OS+"/"+descs[j].Platform.Architecture
+	})
+	ib, err := json.Marshal(manifest{SchemaVersion: 2, MediaType: mtIndex, ArtifactType: atProvider, Manifests: descs})
+	if err != nil {
+		return "", err
+	}
+	index := blobs.add(ib)
+	top, err := json.Marshal(manifest{SchemaVersion: 2, MediaType: mtIndex, Manifests: []descriptor{{
+		MediaType: mtIndex, ArtifactType: atProvider, Digest: index, Size: int64(len(ib)),
+		Annotations: map[string]string{refNameKey: ver},
+	}}})
+	if err != nil {
+		return "", err
+	}
+	if ents, err := os.ReadDir(out); err == nil && len(ents) > 0 {
+		return "", fmt.Errorf("%s is not empty", out)
+	}
+	if err := os.MkdirAll(filepath.Join(out, "blobs", "sha256"), 0o750); err != nil {
+		return "", err
+	}
+	for d, b := range blobs {
+		if err := os.WriteFile(filepath.Join(out, "blobs", "sha256", strings.TrimPrefix(d, "sha256:")), b, 0o600); err != nil {
+			return "", err
+		}
+	}
+	if err := os.WriteFile(filepath.Join(out, "oci-layout"), []byte(`{"imageLayoutVersion":"1.0.0"}`), 0o600); err != nil {
+		return "", err
+	}
+	return index, os.WriteFile(filepath.Join(out, "index.json"), top, 0o600)
+}

+func (r registry) ServeHTTP(w http.ResponseWriter, q *http.Request) {
+	if q.Method != http.MethodGet && q.Method != http.MethodHead {
+		r.fail(w, http.StatusMethodNotAllowed, "read only")

+	}

+		r.fail(w, http.StatusNotFound, p)
+		return
+	}

+	if strings.HasSuffix(rest, "/tags/list") {
+		name, kind = strings.TrimSuffix(rest, "/tags/list"), "tags"
+	} else if i := strings.LastIndex(rest, "/manifests/"); i > 0 {
+		name, kind, ref = rest[:i], "manifests", rest[i+len("/manifests/"):]

+// selfSigned makes a CA and a server certificate for 127.0.0.1 and localhost,
+// valid for one day. It returns the server's TLS certificate and the CA in PEM.
+func selfSigned() (tls.Certificate, []byte, error) {
+	now := time.Now()
+	caKey, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
+	if err != nil {
+		return tls.Certificate{}, nil, err
+	}
+	ca := &x509.Certificate{SerialNumber: big.NewInt(1), Subject: pkix.Name{CommonName: "tofu-providers serve CA"},
+		NotBefore: now.Add(-time.Hour), NotAfter: now.Add(24 * time.Hour), IsCA: true, BasicConstraintsValid: true,
+		KeyUsage: x509.KeyUsageCertSign | x509.KeyUsageDigitalSignature}
+	caDER, err := x509.CreateCertificate(rand.Reader, ca, ca, &caKey.PublicKey, caKey)
+	if err != nil {
+		return tls.Certificate{}, nil, err
+	}
+	caCert, err := x509.ParseCertificate(caDER)
+	if err != nil {
+		return tls.Certificate{}, nil, err
+	}
+	key, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
+	if err != nil {
+		return tls.Certificate{}, nil, err
+	}
+	leaf := &x509.Certificate{SerialNumber: big.NewInt(2), Subject: pkix.Name{CommonName: "127.0.0.1"},
+		NotBefore: now.Add(-time.Hour), NotAfter: now.Add(24 * time.Hour),
+		IPAddresses: []net.IP{net.ParseIP("127.0.0.1")}, DNSNames: []string{"localhost"},
+		KeyUsage: x509.KeyUsageDigitalSignature, ExtKeyUsage: []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth}}
+	der, err := x509.CreateCertificate(rand.Reader, leaf, caCert, &key.PublicKey, caKey)
+	if err != nil {
+		return tls.Certificate{}, nil, err
+	}
+	return tls.Certificate{Certificate: [][]byte{der}, PrivateKey: key},
+		pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: caDER}), nil

+		m := lineRE.FindStringSubmatch(l)
+		if m == nil {
+			problems = append(problems, fmt.Sprintf("%s:%d: %q is not <registry.opentofu.org/namespace/type> <major.minor.patch> <sha256: and 64 hex digits>", file, lineNo[i], l))
+			continue
+		}
+		v, _, err := parseVersion(m[2])
+		if err != nil {
+			problems = append(problems, fmt.Sprintf("%s:%d: %v", file, lineNo[i], err))
+			continue
+		}
+		if first, ok := seen[m[1]]; ok {
+			problems = append(problems, fmt.Sprintf("%s:%d: %s is listed twice (first at line %d); a source has one version", file, lineNo[i], m[1], first))
+			continue
+		}
+		seen[m[1]] = lineNo[i]
+		out = append(out, entry{source: m[1], version: v, digest: m[3]})
+	}
+	return out, problems
+}

+// union merges the packs' lists. Two packs that list one source with another
+// version or digest are a problem.
+func union(lists map[string][]entry) ([]entry, []string) {
+	var names []string
+	for n := range lists {
+		names = append(names, n)
+	}
+	sort.Strings(names)
+	by := map[string]entry{}
+	from := map[string]string{}
+	var problems []string
+	for _, n := range names {
+		for _, e := range lists[n] {
+			if have, ok := by[e.source]; ok {
+				if have != e {
+					problems = append(problems, fmt.Sprintf("%s lists %s and %s lists %s: one source has one version and one digest", from[e.source], have, n, e))
+				}
+				continue
+			}
+			by[e.source], from[e.source] = e, n
+		}
+	}
+	var out []entry
+	for _, e := range by {
+		out = append(out, e)
+	}
+	sort.Slice(out, func(i, j int) bool { return out[i].source < out[j].source })
+	return out, problems

+// stripComments blanks # and // comments and /* */ blocks outside double-quoted
+// strings; a string ends at the end of its line at the latest.
+func stripComments(s string) string {
+	out := []byte(s)
+	inStr, inBlock := false, false
+	for i := 0; i < len(out); i++ {
+		c := out[i]
+		switch {
+		case inBlock:
+			if c == '*' && i+1 < len(out) && out[i+1] == '/' {
+				out[i], out[i+1] = ' ', ' '
+				i++
+				inBlock = false
+			} else if c != '\n' {
+				out[i] = ' '
+			}
+		case inStr:
+			if c == '\\' && i+1 < len(out) && out[i+1] != '\n' {
+				i++
+			} else if c == '"' || c == '\n' {
+				inStr = false
+			}
+		case c == '"':
+			inStr = true
+		case c == '#' || (c == '/' && i+1 < len(out) && out[i+1] == '/'):
+			for i < len(out) && out[i] != '\n' {
+				out[i] = ' '
+				i++
+			}
+		case c == '/' && i+1 < len(out) && out[i+1] == '*':
+			out[i], out[i+1] = ' ', ' '
+			i++
+			inBlock = true
+		}
+	}
+	return string(out)
+}

+type token struct {
+	kind byte // 'i' identifier, 's' string, or the punctuation character itself
+	text string
+}
+
+func tokenize(s string) []token {
+	var out []token
+	for i := 0; i < len(s); {
+		c := s[i]
+		switch {
+		case c == '"':
+			j := i + 1
+			for j < len(s) && s[j] != '"' && s[j] != '\n' {
+				if s[j] == '\\' {
+					j++
+				}
+				j++
+			}
+			if j > len(s) {
+				j = len(s)
+			}
+			out = append(out, token{'s', s[i+1 : j]})
+			i = j + 1
+		case c == '_' || c >= 'a' && c <= 'z' || c >= 'A' && c <= 'Z':
+			j := i
+			for j < len(s) && (s[j] == '_' || s[j] == '-' || s[j] >= 'a' && s[j] <= 'z' || s[j] >= 'A' && s[j] <= 'Z' || s[j] >= '0' && s[j] <= '9') {
+				j++
+			}
+			out = append(out, token{'i', s[i:j]})
+			i = j
+		case strings.IndexByte("{}[]=,", c) >= 0:
+			out = append(out, token{c, string(c)})
+			i++
+		default:
+			i++
+		}
+	}
+	return out
+}
+
+// skipValue returns the index after the value that starts at i: a string, an
+// identifier, or a balanced { } or [ ] group.
+func skipValue(t []token, i int) int {
+	if i >= len(t) {
+		return i
+	}
+	if t[i].kind != '{' && t[i].kind != '[' {
+		return i + 1
+	}
+	depth := 0
+	for ; i < len(t); i++ {
+		switch t[i].kind {
+		case '{', '[':
+			depth++
+		case '}', ']':
+			depth--
+			if depth == 0 {
+				return i + 1
+			}
+		}
+	}
+	return i
+}
+
+// normalize writes a source address with its host: ns/type becomes
+// registry.opentofu.org/ns/type.
+func normalize(source string) string {
+	s := strings.ToLower(strings.TrimSpace(source))
+	if strings.Count(s, "/") == 1 {
+		return defaultHost + "/" + s
+	}
+	return s
+}

+// requiredProviders reads every required_providers block of an OpenTofu text
+// (a module file, or a file that holds an inline module).
+func requiredProviders(file, text string) []requirement {
+	clean := stripComments(text)
+	var out []requirement
+	for _, loc := range keywordRE.FindAllStringIndex(clean, -1) {
+		body := tokenize(clean[loc[1]:])
+		// body starts inside the block's brace; read entries until its closing brace.
+		for i := 0; i < len(body); {
+			if body[i].kind == '}' {
+				break
+			}
+			if body[i].kind != 'i' || i+2 >= len(body) || body[i+1].kind != '=' {
+				i = skipValue(body, i)
+				continue
+			}
+			r := requirement{file: file, name: body[i].text}
+			switch v := body[i+2]; v.kind {
+			case 's':
+				r.constraint = v.text
+				i += 3
+			case '{':
+				end := skipValue(body, i+2)
+				attrs := body[i+3 : end-1]
+				for j := 0; j < len(attrs); {
+					if attrs[j].kind == 'i' && j+2 < len(attrs) && attrs[j+1].kind == '=' {
+						if attrs[j+2].kind == 's' {
+							switch attrs[j].text {
+							case "source":
+								r.source = attrs[j+2].text
+							case "version":
+								r.constraint = attrs[j+2].text
+							}
+						}
+						j = skipValue(attrs, j+2)
+						continue
+					}
+					j++
+				}
+				i = end
+			default:
+				i = skipValue(body, i+2)
+			}
+			if r.source == "" {
+				r.source = "hashicorp/" + r.name
+			}
+			r.source = normalize(r.source)
+			out = append(out, r)
+		}
+	}
+	return out
+}

+// moduleFiles walks a pack folder for its *.tf files and lock files, leaving out
+// test folders.
+func moduleFiles(root, dir string) (tf, locks []string, err error) {
+	err = filepath.WalkDir(filepath.Join(root, dir), func(p string, d os.DirEntry, err error) error {
+		if err != nil {
+			return err
+		}
+		if d.IsDir() {
+			if skipDirs[d.Name()] {
+				return filepath.SkipDir
+			}
+			return nil
+		}
+		rel, _ := filepath.Rel(root, p)

+		case d.Name() == ".terraform.lock.hcl":

+		}
+		return nil

+var lockProviderRE = regexp.MustCompile(`^provider\s+"([^"]+)"\s*\{`)
+var lockVersionRE = regexp.MustCompile(`^\s*version\s*=\s*"([^"]+)"`)

+// lockPins reads the provider "<source>" { version = "<v>" } blocks of a lock file.
+func lockPins(root, rel string) (map[string]string, error) {
+	f, err := os.Open(filepath.Clean(filepath.Join(root, rel)))
+	if err != nil {
+		return nil, err
+	}
+	defer func() { _ = f.Close() }()
+	pins := map[string]string{}
+	cur := ""
+	sc := bufio.NewScanner(f)
+	for sc.Scan() {
+		l := sc.Text()
+		if m := lockProviderRE.FindStringSubmatch(l); m != nil {
+			cur = normalize(m[1])
+			continue
+		}
+		if m := lockVersionRE.FindStringSubmatch(l); m != nil && cur != "" {
+			pins[cur] = m[1]
+			cur = ""
+		}
+	}
+	return pins, sc.Err()
+}

+var sourceItemRE = regexp.MustCompile(`source:\s*["']?([^"',}\s]+)`)

+// packSources reads spec.tofuProviders[].source of a pack.yaml, in block or flow form.
+func packSources(root, rel string) ([]string, error) {
+	lines, err := readLines(filepath.Join(root, rel))
+	if err != nil {
+		return nil, err
+	}
+	var out []string
+	key := -1
+	for _, l := range lines {
+		indent := len(l) - len(strings.TrimLeft(l, " "))
+		t := strings.TrimSpace(l)
+		if key < 0 {
+			if strings.HasPrefix(t, "tofuProviders:") {
+				key = indent
+				for _, m := range sourceItemRE.FindAllStringSubmatch(t, -1) {
+					out = append(out, normalize(m[1]))
+				}
+			}
+			continue
+		}
+		if t == "" || strings.HasPrefix(t, "#") {
+			continue
+		}
+		if indent <= key && !strings.HasPrefix(t, "- ") || indent < key {
+			break
+		}
+		for _, m := range sourceItemRE.FindAllStringSubmatch(t, -1) {
+			out = append(out, normalize(m[1]))
+		}
+	}
+	return out, nil
+}

+// checkConstraints judges requirements against a list.
+func checkConstraints(reqs []requirement, listed map[string]entry, listName string) []string {
+	var out []string
+	for _, r := range reqs {
+		e, ok := listed[r.source]
+		if !ok {
+			out = append(out, fmt.Sprintf("%s: %s requires %s %q; %s does not list it", r.file, r.name, r.source, r.constraint, listName))
+			continue
+		}
+		if r.constraint == "" {
+			continue
+		}
+		terms, err := parseConstraint(r.constraint)
+		if err != nil {
+			out = append(out, fmt.Sprintf("%s: %s requires %s: %v", r.file, r.name, r.source, err))
+			continue
+		}
+		if !meets(e.version, terms) {
+			out = append(out, fmt.Sprintf("%s: %s requires %s %q; %s lists %s, which does not meet it", r.file, r.name, r.source, r.constraint, listName, e.version))
+		}
+	}
+	return out
+}

+func byS(es []entry) map[string]entry {
+	m := map[string]entry{}
+	for _, e := range es {
+		m[e.source] = e
+	}
+	return m

+// result is what check found and how much it read.
+type result struct {
+	findings                   []string
+	listed, requirements, pins int
+}

+// check judges the tree at root. An error means the tree could not be read.
+func check(root string) (result, error) {
+	var res result
+	packs, err := readPacks(root)
+	if err != nil {
+		return res, err
+	}
+	shared, problems, err := readListFile(root)
+	if err != nil {
+		return res, err
+	}
+	res.findings = append(res.findings, problems...)
+	res.listed = len(shared)
+	lists, problems, err := packLists(root, packs)
+	if err != nil {
+		return res, err
+	}
+	res.findings = append(res.findings, problems...)
+	all, problems := union(lists)
+	res.findings = append(res.findings, problems...)
+	want := renderList(all)
+	have, err := os.ReadFile(filepath.Clean(filepath.Join(root, listPath)))
+	if err != nil {
+		return res, err
+	}
+	if string(have) != want {
+		res.findings = append(res.findings, fmt.Sprintf("%s is not what %s writes from the packs' %s files; run: bash %s", listPath, writerScript, packListName, writerScript))
+	}
+	sharedBy := byS(shared)
+	comp, err := os.ReadFile(filepath.Clean(filepath.Join(root, compositionPath)))
+	if err != nil {
+		return res, err
+	}
+	reqs := requiredProviders(compositionPath, string(comp))
+	if len(reqs) == 0 {
+		return res, fmt.Errorf("%s holds no required_providers block", compositionPath)
+	}
+	res.requirements += len(reqs)
+	res.findings = append(res.findings, checkConstraints(reqs, sharedBy, listPath)...)
+	for _, p := range packs {
+		own := p.dir + "/" + packListName
+		ownBy := byS(lists[own])
+		tf, locks, err := moduleFiles(root, p.dir)
+		if err != nil {
+			return res, err
+		}
+		for _, f := range tf {
+			b, err := os.ReadFile(filepath.Clean(filepath.Join(root, f)))
+			if err != nil {
+				return res, err
+			}
+			reqs := requiredProviders(f, string(b))
+			res.requirements += len(reqs)
+			res.findings = append(res.findings, checkConstraints(reqs, ownBy, own)...)
+		}
+		for _, l := range locks {
+			pins, err := lockPins(root, l)
+			if err != nil {
+				return res, err
+			}
+			var srcs []string
+			for s := range pins {
+				srcs = append(srcs, s)
+			}
+			sort.Strings(srcs)
+			for _, s := range srcs {
+				res.pins++
+				e, ok := ownBy[s]
+				if !ok || e.version.String() != pins[s] {
+					res.findings = append(res.findings, fmt.Sprintf("%s pins %s %s; %s does not list that version", l, s, pins[s], own))
+				}
+			}
+		}
+		sources, err := packSources(root, p.dir+"/pack.yaml")
+		if err != nil {
+			return res, err
+		}
+		for _, s := range sources {
+			if _, ok := ownBy[s]; !ok {
+				res.findings = append(res.findings, fmt.Sprintf("%s/pack.yaml names %s in spec.tofuProviders; %s does not list it", p.dir, s, own))
+			}
+		}
+	}
+	return res, nil
+}

+// writeList writes the ConfigMap from the packs' lists, or with checkOnly reports
+// whether the file on disk differs.
+func writeList(root string, checkOnly bool) (changed bool, problems []string, err error) {
+	packs, err := readPacks(root)
+	if err != nil {
+		return false, nil, err
+	}
+	lists, problems, err := packLists(root, packs)
+	if err != nil {
+		return false, nil, err
+	}
+	all, more := union(lists)
+	problems = append(problems, more...)
+	if len(problems) > 0 {
+		return false, problems, nil
+	}
+	want := renderList(all)
+	have, err := os.ReadFile(filepath.Clean(filepath.Join(root, listPath)))
+	if err != nil && !os.IsNotExist(err) {
+		return false, nil, err
+	}
+	if string(have) == want {
+		return false, nil, nil
+	}
+	if checkOnly {
+		return true, nil, nil
+	}
+	if err := os.MkdirAll(filepath.Dir(filepath.Join(root, listPath)), 0o750); err != nil {
+		return false, nil, err
+	}
+	return true, nil, os.WriteFile(filepath.Join(root, listPath), []byte(want), 0o600)
+}

+// version is a provider version major.minor.patch. A listed version always has
+// three parts; a constraint may give one, two or three.
+type version [3]int
+
+func (v version) String() string { return fmt.Sprintf("%d.%d.%d", v[0], v[1], v[2]) }
+
+func (v version) cmp(o version) int {
+	for i := range v {
+		if v[i] != o[i] {
+			if v[i] < o[i] {
+				return -1
+			}
+			return 1
+		}
+	}
+	return 0
+}

+// parseVersion reads 1, 1.2 or 1.2.3 (missing parts are 0) and returns how many
+// parts were written. A pre-release or build suffix is not read: no listed
+// version has one.
+func parseVersion(s string) (version, int, error) {
+	var v version
+	parts := strings.Split(strings.TrimPrefix(s, "v"), ".")
+	if len(parts) == 0 || len(parts) > 3 {
+		return v, 0, fmt.Errorf("version %q is not major[.minor[.patch]]", s)
+	}

+			return v, 0, fmt.Errorf("version %q is not major[.minor[.patch]]", s)
+		}
+		v[i] = n
+	}

+}

+type term struct {
+	op    string
+	v     version
+	parts int
+}
+
+// parseConstraint reads a version constraint as OpenTofu writes it: terms
+// separated by commas, each an operator (= when absent) and a version.
+func parseConstraint(s string) ([]term, error) {
+	var out []term
+	for _, raw := range strings.Split(s, ",") {
+		t := strings.TrimSpace(raw)
+		if t == "" {
+			return nil, fmt.Errorf("constraint %q has an empty term", s)
+		}
+		op := "="
+		for _, o := range []string{"~>", ">=", "<=", "!=", ">", "<", "="} {
+			if strings.HasPrefix(t, o) {
+				op, t = o, strings.TrimSpace(t[len(o):])
+				break
+			}
+		}
+		v, n, err := parseVersion(t)
+		if err != nil {
+			return nil, fmt.Errorf("constraint %q: %v", s, err)
+		}
+		out = append(out, term{op: op, v: v, parts: n})
+	}
+	return out, nil
+}
+
+// meets reports whether v meets every term. ~> lets only the right-most written
+// part grow: ~> 1.2 is >= 1.2.0 and < 2.0.0, ~> 1.2.3 is >= 1.2.3 and < 1.3.0,
+// ~> 1 is >= 1.0.0 and < 2.0.0.
+func meets(v version, terms []term) bool {
+	for _, t := range terms {
+		c := v.cmp(t.v)
+		ok := false
+		switch t.op {
+		case "=":
+			ok = c == 0
+		case "!=":
+			ok = c != 0
+		case ">":
+			ok = c > 0
+		case ">=":
+			ok = c >= 0
+		case "<":
+			ok = c < 0
+		case "<=":
+			ok = c <= 0
+		case "~>":
+			upper := version{t.v[0] + 1, 0, 0}
+			if t.parts == 3 {
+				upper = version{t.v[0], t.v[1] + 1, 0}
+			}
+			ok = c >= 0 && v.cmp(upper) < 0
+		}
+		if !ok {
+			return false
+		}
+	}
+	return true
+}
