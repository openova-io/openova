# SOV-110 — Contract C5: schema, kit key list, the upstream package and its validator

## In plain words

**The problem today.** Every region of a Sovereign needs one document that says which registry it pulls charts, kit and packages from, who its parent is, and how its hand-over runs. Today these values are spread over the first-boot template and literals in the code, and no file defines them. The packages that make a Sovereign pull from its own registry cannot start until that document has a fixed form and code that reads it.

**What changes.** The variables document is published as a contract: a schema and the list of kit keys. A Go package reads, writes and checks it, derives a child's document from its parent's, flips it to the local registry and renders the node registry mirrors from it. A check on every pull request validates every variables document in the repository.

**Done means:**

- The schema of the variables document and the list of kit keys are published beside the contract index.
- The list of kit keys is the list of keys that the first-boot template passes to the bootstrap kit today, without the PowerDNS API key.
- The Go package refuses a document with an unknown key, a missing required key, a value outside its allowed set, or a key whose name looks like a secret, and it accepts every kit key.
- Each of the seven cross-field rules has a test document that fails with that rule and no other.
- A child's document derived from its parent never copies the parent's own origin values, and the flip to the local registry changes exactly three keys.
- A pull request that adds a variables document that breaks the contract turns red.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. Seventeen files are added. Fifteen are the embedded blocks of field 5, byte for byte. Two are copies made with `cp`: `core/controllers/pkg/upstream/contract/c5-upstream-variables.schema.json` and `core/controllers/pkg/upstream/contract/c5-kit-keys.txt` are byte for byte the two files of `docs/contracts/`. `go:embed` cannot reach a file outside the Go module, so the package embeds these copies. No existing file changes and nothing is deleted.
2. The variables document. Every value is a string. A document holds exactly the 39 contract keys of the schema (the 7 keys that are not required take their schema default when absent) plus any of the kit keys. The schema is a JSON Schema (draft 2020-12) over the ConfigMap's `data`, with `additionalProperties: false`; the kit keys are removed before the schema is applied.
3. The kit keys are the output of this command at the commit of this ticket, and nothing else:
   `awk '/path: \/var\/lib\/catalyst\/flux-bootstrap.yaml/,/^runcmd:/' infra/providers/_shared/cloudinit-control-plane.tftpl | grep -o '^            [A-Z][A-Z0-9_]*:' | tr -d ' :' | LC_ALL=C sort -u | grep -v '^POWERDNS_API_KEY$'`.
   `LC_ALL=C` fixes the order: the default sort order of another locale differs. `POWERDNS_API_KEY` is left out because it is a secret. Later, a package that adds a kit key adds it to `docs/contracts/c5-kit-keys.txt` and to its copy in the same pull request as its reader.
4. The cross-field rules, each reported with a message that starts `rule <n>:`.
   - Rule 1: `SOVEREIGN_CONSUME` `local` requires `REGISTRY_HOST` equal to `LOCAL_REGISTRY_HOST` and `REGISTRY_SCHEME` `https`.
   - Rule 2: `SOVEREIGN_CONSUME` `origin` requires a non-empty `ORIGIN_REGISTRY_HOST`, `REGISTRY_HOST` equal to it, and `REGISTRY_SCHEME` equal to `ORIGIN_REGISTRY_SCHEME`.
   - Rule 3: `MAIL_MODE` `relay` requires non-empty `MAIL_RELAY_HOST`, `MAIL_FROM` and `MAIL_RELAY_SECRET`.
   - Rule 4: `DNS_MODE` `upstream-managed` requires a non-empty `DNS_UPSTREAM_API_URL`.
   - Rule 5: no key holds a secret value. A key whose name ends in `_KEY`, `_TOKEN`, `_PASSWORD` or `_SECRET_VALUE` is refused, kit keys included, except `RELEASE_PUBLIC_KEY_B64` (a public key) and `SOVEREIGN_REGION_KEY` (the region's identifier, a kit key the bootstrap kit reads today). Rule 5 is a rule on key names, so `FromMap` enforces it; `Validate` enforces the other six.
   - Rule 6: `HANDOVER_HOLD_SECONDS` is between 30 and 3600.
   - Rule 7: no value of `ORIGIN_REGISTRY_HOST`, `ORIGIN_PARENT_FQDN`, `ORIGIN_PARENT_API_URL` or of an entry of `ORIGIN_PROXY_ENDPOINTS_JSON` has a host equal to the Sovereign's own FQDN or under it. The host is the value with its scheme, port and path removed, in lower case. With an empty own FQDN rule 7 is not judged.
5. The package `upstream`. Its exported names: the constants `Namespace` (`flux-system`) and `Name` (`sovereign-variables`), the variable `SecretNameExceptions`, the type `Variables` (one field per contract key) and these functions:
   - `FromMap(data map[string]string) (Variables, error)`: refuses a key name by rule 5, ignores kit keys, applies the schema (a missing required key, a value outside its enum or pattern and an unknown key fail), fills the defaults, and parses. `HANDOVER_AUTO` and `RELEASE_AUTO` become booleans, `HANDOVER_HOLD_SECONDS` a number, and the two `_JSON` keys maps of strings.
   - `(Variables) ToMap() map[string]string`: every contract key, defaults included; a map is rendered as compact JSON with sorted keys, a missing map as `{}`. `FromMap(ToMap(v))` equals `v`.
   - `(Variables) Validate(ownFQDN string) []error`: one error per violated rule of 1, 2, 3, 4, 6 and 7.
   - `Served(parentFQDN string, parent Variables) Variables`: what a parent hands to a child. Every key starts at its default. `SOVEREIGN_CONSUME` is `origin`; `REGISTRY_HOST` and `ORIGIN_REGISTRY_HOST` are the parent's `LOCAL_REGISTRY_HOST`; both schemes are `https`; `ORIGIN_PARENT_FQDN` is `parentFQDN` and `ORIGIN_PARENT_API_URL` is `https://console.<parentFQDN>/sovereign`; `ORIGIN_REGISTRY_CA_B64` is empty and `ORIGIN_PROXY_ENDPOINTS_JSON` is `{}`. The six `REGISTRY_PATH_*` keys, `REGISTRY_PROXY_PROJECTS_JSON` (a new map), `RELEASE_CHANNEL` and `RELEASE_PUBLIC_KEY_B64` are copied from the parent. `LOCAL_REGISTRY_HOST`, `K3S_VERSION`, `MAIL_MODE`, `MAIL_RELAY_HOST`, `MAIL_FROM`, `MAIL_RELAY_SECRET` and the keys without a default are left empty for the caller. The parent's own `ORIGIN_*` values are never copied.
   - `(Variables) Flipped() Variables`: a copy with `SOVEREIGN_CONSUME` `local`, `REGISTRY_HOST` equal to `LOCAL_REGISTRY_HOST` and `REGISTRY_SCHEME` `https`. Nothing else changes.
   - `Load(ctx, client.Reader) (Variables, error)`: reads the ConfigMap `flux-system/sovereign-variables` and parses it with `FromMap`.
   - `(Variables) RegistriesYAML(dragonflyProxy string, hostedRewrites []byte) ([]byte, error)`: the `mirrors` map of `/etc/rancher/k3s/registries.yaml`. For each name N of `REGISTRY_PROXY_PROJECTS_JSON` with project path P, the entry N lists, in order: `dragonflyProxy` when it is not empty; `https://<LOCAL_REGISTRY_HOST>`; and, only while `SOVEREIGN_CONSUME` is `origin`, the origin endpoint (`ORIGIN_PROXY_ENDPOINTS_JSON[N]` when present, else `<ORIGIN_REGISTRY_SCHEME>://<ORIGIN_REGISTRY_HOST>`). Its rewrite maps `(.*)` to `P/$1` when P is not empty. Three more entries follow: `LOCAL_REGISTRY_HOST` with the single local endpoint; while `origin`, `ORIGIN_REGISTRY_HOST` with the local endpoint and then the origin endpoint; and `*` with the single local endpoint and no rewrite. `hostedRewrites` is a YAML object from a registry name to a rewrite map; for each name it holds, its map replaces the computed rewrite (it carries the rules of the platform's own hosted project, which the provider modules render today). The `configs` map (pull logins and certificate authorities) carries secrets and is added by the caller; this function renders none.
   - `KitKeys() []string`: the kit keys, sorted.
   The package reads no environment variable. No default names a host outside the Sovereign; the one default with a host, `GITOPS_REPO_URL`, names a Service inside the cluster.
6. The command `core/controllers/pkg/upstream/cmd/check-variables` takes `[--root <dir>] [--own-fqdn <fqdn>] <file>...`. Each file holds one YAML document: a `v1` `ConfigMap` named `sovereign-variables` in `flux-system` whose `data` values are all strings. It must pass `FromMap` and `Validate`. The own FQDN for rule 7 is `--own-fqdn` when given, else the folder after the first path segment `clusters` (`clusters/<fqdn>/...`); a file with neither fails. It prints `ok <file>` or one `FAIL <file>: <reason>` line per reason, and exits 0, 1 (a file failed) or 2 (usage).
7. Guard G8, `scripts/check-variables-documents.sh`, run from the repository root. Rule A: each copy under `core/controllers/pkg/upstream/contract/` equals its file in `docs/contracts/`. Rule B: every `variables.yaml` under `clusters/` and `tests/` (tracked, or new and not ignored) passes the command of item 6. It prints `variables documents: <n>` last and exits 0 (pass), 1 (a rule failed) or 2 (the command does not build). `--self-test` builds the command and proves each rule can fail: equal copies pass and a changed copy fails; `tests/fixtures/variables/valid.yaml` passes; each of the seven `invalid-rule<N>.yaml` fails with rule N and no other rule; the own FQDN is taken from the path; a path without `clusters/<fqdn>/` fails; another ConfigMap name fails; an unquoted boolean value fails.
8. The workflow `.github/workflows/check-variables-documents.yaml` has the triggers `pull_request` and `merge_group` and no path filter. Its one job, `variables-documents`, sets up Go from `core/controllers/go.mod`, runs the package tests, the self-test and the guard.
9. The fixtures. `valid.yaml` is the example document of the contract (every contract key) plus every kit key with the value `kit-value`. Each `invalid-rule<N>.yaml` is the example document without kit keys and with one change that breaks rule N only. All use the own FQDN `alpha.example.org`.

// contract is the embedded schema, compiled once.
type contract struct {
	schema   *jsonschema.Schema
	defaults map[string]string
	kitKeys  map[string]bool
}

var (
	loaded    contract
	loadErr   error
	loadOnce  sync.Once
	schemaURL = "c5-upstream-variables.schema.json"
)

func load() (contract, error) {
	loadOnce.Do(func() {
		var doc struct {
			Properties map[string]struct {
				Default *string `json:"default"`
			} `json:"properties"`
		}
		if err := json.Unmarshal(schemaJSON, &doc); err != nil {
			loadErr = fmt.Errorf("upstream: the embedded schema is not JSON: %w", err)
			return
		}
		compiler := jsonschema.NewCompiler()
		if err := compiler.AddResource(schemaURL, bytes.NewReader(schemaJSON)); err != nil {
			loadErr = fmt.Errorf("upstream: the embedded schema: %w", err)
			return
		}
		compiled, err := compiler.Compile(schemaURL)
		if err != nil {
			loadErr = fmt.Errorf("upstream: the embedded schema does not compile: %w", err)
			return
		}
		c := contract{schema: compiled, defaults: map[string]string{}, kitKeys: map[string]bool{}}
		for key, p := range doc.Properties {
			if p.Default != nil {
				c.defaults[key] = *p.Default
			}
		}
		for _, line := range strings.Split(kitKeysText, "\n") {
			if line = strings.TrimSpace(line); line != "" {
				c.kitKeys[line] = true
			}
		}
		if len(doc.Properties) != len(fields) {
			loadErr = fmt.Errorf("upstream: the schema has %d keys and Variables %d", len(doc.Properties), len(fields))
			return
		}
		for _, f := range fields {
			if _, ok := doc.Properties[f.key]; !ok {
				loadErr = fmt.Errorf("upstream: the schema lacks the key %s", f.key)
				return
			}
			if c.kitKeys[f.key] {
				loadErr = fmt.Errorf("upstream: %s is both a contract key and a kit key", f.key)
				return
			}
		}
		loaded = c
	})
	return loaded, loadErr
}

// KitKeys returns the kit keys of the contract, sorted.
func KitKeys() []string {
	c, err := load()
	if err != nil {
		return nil
	}
	out := make([]string, 0, len(c.kitKeys))
	for k := range c.kitKeys {
		out = append(out, k)
	}
	sort.Strings(out)
	return out
}

// namesSecret reports whether rule 5 refuses the key name.
func namesSecret(key string) bool {
	for _, e := range SecretNameExceptions {
		if key == e {
			return false
		}
	}
	for _, s := range secretSuffixes {
		if strings.HasSuffix(key, s) {
			return true
		}
	}
	return false
}

// FromMap parses ConfigMap data. It fails on a missing required key or a value outside its enum or pattern.
// Keys listed in the kit key file are ignored. Any other unknown key is an error.
// It also fails on a key name that rule 5 refuses, a kit key included.
func FromMap(data map[string]string) (Variables, error) {
	c, err := load()
	if err != nil {
		return Variables{}, err
	}
	keys := make([]string, 0, len(data))
	for k := range data {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	var problems []string
	instance := map[string]interface{}{}
	for _, k := range keys {
		if namesSecret(k) {
			problems = append(problems, fmt.Sprintf("rule 5: the key %s names a secret value; a secret never goes into the variables document", k))
			continue
		}
		if !c.kitKeys[k] {
			instance[k] = data[k]
		}
	}
	if len(problems) > 0 {
		return Variables{}, fmt.Errorf("%s", strings.Join(problems, "; "))
	}
	if err := c.schema.Validate(instance); err != nil {
		return Variables{}, fmt.Errorf("schema: %s", schemaMessage(err))
	}
	full := map[string]string{}
	for k, v := range c.defaults {
		full[k] = v
	}
	for k, v := range instance {
		full[k] = v.(string)
	}
	return decode(full)
}

// schemaMessage flattens a validation error to its leaf messages, one per problem.
func schemaMessage(err error) string {
	ve, ok := err.(*jsonschema.ValidationError)
	if !ok {
		return err.Error()
	}
	var out []string
	var walk func(e *jsonschema.ValidationError)
	walk = func(e *jsonschema.ValidationError) {
		if len(e.Causes) == 0 {
			loc := strings.TrimPrefix(e.InstanceLocation, "/")
			if loc == "" {
				out = append(out, e.Message)
			} else {
				out = append(out, loc+": "+e.Message)
			}
			return
		}
		for _, cause := range e.Causes {
			walk(cause)
		}
	}
	walk(ve)
	sort.Strings(out)
	return strings.Join(out, "; ")
}

// decode turns the values of every contract key into a Variables. A key that
// is absent gives the zero value of its field.
func decode(m map[string]string) (Variables, error) {
	var v Variables
	for _, f := range fields {
		raw := m[f.key]
		switch {
		case f.str != nil:
			*f.str(&v) = raw
		case f.flag != nil:
			switch raw {
			case "true":
				*f.flag(&v) = true
			case "false", "":
				*f.flag(&v) = false
			default:
				return Variables{}, fmt.Errorf("%s: %q is not true or false", f.key, raw)
			}
		case f.num != nil:
			if raw == "" {
				break
			}
			n, err := strconv.Atoi(raw)
			if err != nil {
				return Variables{}, fmt.Errorf("%s: %q is not a whole number", f.key, raw)
			}
			*f.num(&v) = n
		case f.obj != nil:
			out := map[string]string{}
			if raw != "" {
				if err := json.Unmarshal([]byte(raw), &out); err != nil {
					return Variables{}, fmt.Errorf("%s: not a JSON object of strings: %v", f.key, err)
				}
				if out == nil {
					return Variables{}, fmt.Errorf("%s: not a JSON object of strings: null", f.key)
				}
			}
			*f.obj(&v) = out
		}
	}
	return v, nil
}

// ToMap renders every key of contract C5, defaults included. FromMap(ToMap(v)) == v.
func (v Variables) ToMap() map[string]string {
	out := make(map[string]string, len(fields))
	for _, f := range fields {
		switch {
		case f.str != nil:
			out[f.key] = *f.str(&v)
		case f.flag != nil:
			out[f.key] = strconv.FormatBool(*f.flag(&v))
		case f.num != nil:
			out[f.key] = strconv.Itoa(*f.num(&v))
		case f.obj != nil:
			m := *f.obj(&v)
			if m == nil {
				m = map[string]string{}
			}
			b, _ := json.Marshal(m) // a map of strings always marshals; the keys come out sorted
			out[f.key] = string(b)
		}
	}
	return out
}

// Validate returns one error per violated cross-field rule of contract C5.
func (v Variables) Validate(ownFQDN string) []error {
	var errs []error
	if v.Consume == "local" && (v.RegistryHost != v.LocalRegistryHost || v.RegistryScheme != "https") {
		errs = append(errs, fmt.Errorf("rule 1: SOVEREIGN_CONSUME is local, so REGISTRY_HOST must equal LOCAL_REGISTRY_HOST (%q) and REGISTRY_SCHEME must be https; they are %q and %q", v.LocalRegistryHost, v.RegistryHost, v.RegistryScheme))
	}
	if v.Consume == "origin" && (v.OriginRegistryHost == "" || v.RegistryHost != v.OriginRegistryHost || v.RegistryScheme != v.OriginRegistryScheme) {
		errs = append(errs, fmt.Errorf("rule 2: SOVEREIGN_CONSUME is origin, so ORIGIN_REGISTRY_HOST must not be empty and REGISTRY_HOST and REGISTRY_SCHEME must equal ORIGIN_REGISTRY_HOST (%q) and ORIGIN_REGISTRY_SCHEME (%q); they are %q and %q", v.OriginRegistryHost, v.OriginRegistryScheme, v.RegistryHost, v.RegistryScheme))
	}
	if v.MailMode == "relay" && (v.MailRelayHost == "" || v.MailFrom == "" || v.MailRelaySecret == "") {
		errs = append(errs, fmt.Errorf("rule 3: MAIL_MODE is relay, so MAIL_RELAY_HOST, MAIL_FROM and MAIL_RELAY_SECRET must not be empty"))
	}
	if v.DNSMode == "upstream-managed" && v.DNSUpstreamAPIURL == "" {
		errs = append(errs, fmt.Errorf("rule 4: DNS_MODE is upstream-managed, so DNS_UPSTREAM_API_URL must not be empty"))
	}
	if v.HandoverHoldSeconds < 30 || v.HandoverHoldSeconds > 3600 {
		errs = append(errs, fmt.Errorf("rule 6: HANDOVER_HOLD_SECONDS is %d; it must be between 30 and 3600", v.HandoverHoldSeconds))
	}
	own := strings.TrimSuffix(strings.ToLower(strings.TrimSpace(ownFQDN)), ".")
	if own != "" {
		origin := []struct{ key, value string }{
			{"ORIGIN_REGISTRY_HOST", v.OriginRegistryHost},
			{"ORIGIN_PARENT_FQDN", v.ParentFQDN},
			{"ORIGIN_PARENT_API_URL", v.ParentAPIURL},
		}
		names := make([]string, 0, len(v.OriginProxyEndpoints))
		for n := range v.OriginProxyEndpoints {
			names = append(names, n)
		}
		sort.Strings(names)
		for _, n := range names {
			origin = append(origin, struct{ key, value string }{"ORIGIN_PROXY_ENDPOINTS_JSON[" + n + "]", v.OriginProxyEndpoints[n]})
		}
		for _, o := range origin {
			if h := hostOf(o.value); h != "" && (h == own || strings.HasSuffix(h, "."+own)) {
				errs = append(errs, fmt.Errorf("rule 7: %s is %q, which names this Sovereign's own name %s", o.key, o.value, own))
			}
		}
	}
	return errs
}

// hostOf returns the lower-case host of a host, host:port or address value.
func hostOf(value string) string {
	s := strings.TrimSpace(value)
	if s == "" {
		return ""
	}
	if !strings.Contains(s, "://") {
		s = "//" + s
	}
	u, err := url.Parse(s)
	if err != nil {
		return strings.ToLower(s)
	}
	return strings.TrimSuffix(strings.ToLower(u.Hostname()), ".")
}

// defaults returns the variables that hold the default of every key that has one.
func defaults() Variables {
	c, err := load()
	if err != nil {
		return Variables{}
	}
	v, err := decode(c.defaults)
	if err != nil {
		return Variables{}
	}
	return v
}

// Served returns the variables a parent hands to a child. Consume is origin. The origin keys name the
// parent's own hosts (parent.LocalRegistryHost, https, "https://console.<parentFQDN>/sovereign").
// Paths, proxy projects, channel and release key are copied. The parent's own Origin* values are never copied.
// Per-child keys (LocalRegistryHost, K3sVersion, state and mail keys) are left empty for the caller to fill.
// Every other key takes its default; a key without a default stays empty.
func Served(parentFQDN string, parent Variables) Variables {
	v := defaults()
	v.Consume = "origin"
	v.OriginRegistryHost = parent.LocalRegistryHost
	v.OriginRegistryScheme = "https"
	v.OriginRegistryCAB64 = ""
	v.OriginProxyEndpoints = map[string]string{}
	v.RegistryHost = parent.LocalRegistryHost
	v.RegistryScheme = "https"
	v.ParentFQDN = parentFQDN
	v.ParentAPIURL = "https://console." + parentFQDN + "/sovereign"
	v.PathCharts = parent.PathCharts
	v.PathRelease = parent.PathRelease
	v.PathProviderPacks = parent.PathProviderPacks
	v.PathXpkg = parent.PathXpkg
	v.PathTofuProviders = parent.PathTofuProviders
	v.PathNodeArtifacts = parent.PathNodeArtifacts
	v.ProxyProjects = map[string]string{}
	for k, p := range parent.ProxyProjects {
		v.ProxyProjects[k] = p
	}
	v.ReleaseChannel = parent.ReleaseChannel
	v.ReleasePublicKeyB64 = parent.ReleasePublicKeyB64
	v.LocalRegistryHost = ""
	v.K3sVersion = ""
	v.MailMode, v.MailRelayHost, v.MailFrom, v.MailRelaySecret = "", "", "", ""
	return v
}

// Flipped returns v with Consume local, RegistryHost LocalRegistryHost and RegistryScheme https.
func (v Variables) Flipped() Variables {
	out := v
	out.OriginProxyEndpoints = copyMap(v.OriginProxyEndpoints)
	out.ProxyProjects = copyMap(v.ProxyProjects)
	out.Consume = "local"
	out.RegistryHost = v.LocalRegistryHost
	out.RegistryScheme = "https"
	return out
}

func copyMap(m map[string]string) map[string]string {
	if m == nil {
		return nil
	}
	out := make(map[string]string, len(m))
	for k, v := range m {
		out[k] = v
	}
	return out
}

// mirror is one entry of the mirrors map of /etc/rancher/k3s/registries.yaml.
type mirror struct {
	Endpoint []string          `json:"endpoint"`
	Rewrite  map[string]string `json:"rewrite,omitempty"`
}

// RegistriesYAML renders the mirrors map of the node file
// /etc/rancher/k3s/registries.yaml. dragonflyProxy is empty when the slot is
// off.
//
// The configs map of that file (pull logins and certificate authorities)
// carries secrets and is added by the caller. This function renders none of
// it. hostedRewrites is a YAML or JSON object from a registry name
// to a rewrite map; for each name it holds, its rewrite map replaces the
// rewrite this function would write. It carries the rewrite rules of the
// platform's own hosted project, which the provider modules render today.
// Empty means none.
//
// For each name N of ProxyProjects, with project path P, the entry N lists,
// in order: dragonflyProxy when it is not empty; https://<LocalRegistryHost>;
// and, only while Consume is origin, the origin endpoint
// (OriginProxyEndpoints[N] when present, else
// <OriginRegistryScheme>://<OriginRegistryHost>). Its rewrite maps "(.*)" to
// "P/$1" when P is not empty. Three more entries follow: LocalRegistryHost
// with the single endpoint https://<LocalRegistryHost>; while Consume is
// origin, OriginRegistryHost with the local endpoint first and the origin
// endpoint second; and "*" with the single endpoint
// https://<LocalRegistryHost> and no rewrite.
func (v Variables) RegistriesYAML(dragonflyProxy string, hostedRewrites []byte) ([]byte, error) {
	if v.LocalRegistryHost == "" {
		return nil, fmt.Errorf("upstream: LOCAL_REGISTRY_HOST is empty")
	}
	origin := v.Consume == "origin"
	if origin && v.OriginRegistryHost == "" {
		return nil, fmt.Errorf("upstream: SOVEREIGN_CONSUME is origin and ORIGIN_REGISTRY_HOST is empty")
	}
	if v.Consume != "origin" && v.Consume != "local" {
		return nil, fmt.Errorf("upstream: SOVEREIGN_CONSUME is %q, not origin or local", v.Consume)
	}
	rewrites := map[string]map[string]string{}
	if len(bytes.TrimSpace(hostedRewrites)) > 0 {
		if err := yaml.UnmarshalStrict(hostedRewrites, &rewrites); err != nil {
			return nil, fmt.Errorf("upstream: hostedRewrites: %w", err)
		}
	}
	for n := range rewrites {
		if _, ok := v.ProxyProjects[n]; !ok {
			return nil, fmt.Errorf("upstream: hostedRewrites names %q, which is not a key of REGISTRY_PROXY_PROJECTS_JSON", n)
		}
	}
	local := "https://" + v.LocalRegistryHost
	originDefault := v.OriginRegistryScheme + "://" + v.OriginRegistryHost
	mirrors := map[string]mirror{}
	for n, p := range v.ProxyProjects {
		m := mirror{}
		if dragonflyProxy != "" {
			m.Endpoint = append(m.Endpoint, dragonflyProxy)
		}
		m.Endpoint = append(m.Endpoint, local)
		if origin {
			if e, ok := v.OriginProxyEndpoints[n]; ok && e != "" {
				m.Endpoint = append(m.Endpoint, e)
			} else {
				m.Endpoint = append(m.Endpoint, originDefault)
			}
		}
		if r, ok := rewrites[n]; ok {
			m.Rewrite = r
		} else if p != "" {
			m.Rewrite = map[string]string{"(.*)": p + "/$1"}
		}
		mirrors[n] = m
	}
	extra := []struct {
		name string
		m    mirror
	}{{v.LocalRegistryHost, mirror{Endpoint: []string{local}}}}
	if origin {
		extra = append(extra, struct {
			name string
			m    mirror
		}{v.OriginRegistryHost, mirror{Endpoint: []string{local, originDefault}}})
	}
	extra = append(extra, struct {
		name string
		m    mirror
	}{"*", mirror{Endpoint: []string{local}}})
	for _, e := range extra {
		if _, taken := mirrors[e.name]; taken {
			return nil, fmt.Errorf("upstream: the registry name %q would have two mirror entries", e.name)
		}
		mirrors[e.name] = e.m
	}
	return yaml.Marshal(map[string]interface{}{"mirrors": mirrors})
}

// Command check-variables checks variables documents against contract C5.
// scripts/check-variables-documents.sh builds and runs it; it is guard G8.
//
//	check-variables [--root <dir>] [--own-fqdn <fqdn>] <file>...
//
// Each file is a path relative to --root (default: the current folder), or
// an absolute path. It
// must hold one YAML document: a v1 ConfigMap named sovereign-variables in
// the namespace flux-system whose data values are all strings. The data must
// pass upstream.FromMap (the schema, the kit keys, rule 5) and
// upstream.Validate (rules 1 to 4, 6 and 7).
//
// Rule 7 needs the Sovereign's own FQDN. It is --own-fqdn when given. Else it
// is the folder that follows the first path segment "clusters": the file
// clusters/<fqdn>/... names the Sovereign <fqdn>. A file with neither fails.
//
// Prints "ok <file>" or "FAIL <file>: <reason>" per file, one line per reason.
// Exit 0 when every file passes, 1 when one fails, 2 on a usage error.
package main

import (
	"flag"
	"fmt"
	"os"
	"path/filepath"
	"strings"

	"github.com/openova-io/openova/core/controllers/pkg/upstream"
	"sigs.k8s.io/yaml"
)

type document struct {
	APIVersion string `json:"apiVersion"`
	Kind       string `json:"kind"`
	Metadata   struct {
		Name      string `json:"name"`
		Namespace string `json:"namespace"`
	} `json:"metadata"`
	Data map[string]interface{} `json:"data"`
}

func main() {
	root := flag.String("root", ".", "the folder the file paths are relative to")
	own := flag.String("own-fqdn", "", "the Sovereign's own FQDN for rule 7; default: taken from the path")
	flag.Parse()
	if flag.NArg() == 0 {
		fmt.Fprintln(os.Stderr, "usage: check-variables [--root <dir>] [--own-fqdn <fqdn>] <file>...")
		os.Exit(2)
	}
	failed := false
	for _, file := range flag.Args() {
		reasons := check(*root, file, *own)
		if len(reasons) == 0 {
			fmt.Printf("ok %s\n", file)
			continue
		}
		failed = true
		for _, r := range reasons {
			fmt.Printf("FAIL %s: %s\n", file, r)
		}
	}
	if failed {
		os.Exit(1)
	}
}

// ownFromPath returns the folder after the first path segment "clusters", or "".
func ownFromPath(file string) string {
	parts := strings.Split(filepath.ToSlash(filepath.Clean(file)), "/")
	for i := 0; i+2 < len(parts); i++ {
		if parts[i] == "clusters" {
			return parts[i+1]
		}
	}
	return ""
}

func check(root, file, own string) []string {
	path := file
	if !filepath.IsAbs(path) {
		path = filepath.Join(root, file)
	}
	raw, err := os.ReadFile(filepath.Clean(path))
	if err != nil {
		return []string{err.Error()}
	}
	var doc document
	if err := yaml.UnmarshalStrict(raw, &doc); err != nil {
		return []string{"not one ConfigMap document: " + err.Error()}
	}
	var reasons []string
	if doc.APIVersion != "v1" || doc.Kind != "ConfigMap" || doc.Metadata.Name != upstream.Name || doc.Metadata.Namespace != upstream.Namespace {
		reasons = append(reasons, fmt.Sprintf("must be the v1 ConfigMap %s/%s, is %s %s %s/%s", upstream.Namespace, upstream.Name, doc.APIVersion, doc.Kind, doc.Metadata.Namespace, doc.Metadata.Name))
	}
	data := map[string]string{}
	for k, v := range doc.Data {
		s, ok := v.(string)
		if !ok {
			reasons = append(reasons, fmt.Sprintf("the value of %s is not a string; quote it", k))
			continue
		}
		data[k] = s
	}
	if len(reasons) > 0 {
		return reasons
	}
	v, err := upstream.FromMap(data)
	if err != nil {
		return []string{err.Error()}
	}
	if own == "" {
		own = ownFromPath(file)
	}
	if own == "" {
		return []string{"no own FQDN for rule 7: the path has no clusters/<fqdn>/ part and --own-fqdn is not given"}
	}
	for _, e := range v.Validate(own) {
		reasons = append(reasons, e.Error())
	}
	return reasons
}

# check-variables-documents.sh — guard G8 of contract C5, the variables document.
#
# Run from the repository root:
#   bash scripts/check-variables-documents.sh               # the real run
#   bash scripts/check-variables-documents.sh --self-test   # proves each rule can fail
#
# Rule A. The Go package core/controllers/pkg/upstream embeds a copy of each
#   published contract file. Each copy equals its file byte for byte:
#     docs/contracts/c5-upstream-variables.schema.json
#     docs/contracts/c5-kit-keys.txt
#   (under core/controllers/pkg/upstream/contract/). Change both together.
# Rule B. Every file named variables.yaml under clusters/ and tests/ (tracked,
#   or new and not ignored) is the v1 ConfigMap flux-system/sovereign-variables
#   and passes the schema and the cross-field rules 1 to 7 of contract C5
#   (upstream.FromMap and upstream.Validate). The Sovereign's own FQDN for
#   rule 7 is the folder after "clusters/" in the file's path.
#

# core/controllers/pkg/upstream/cmd/check-variables, built once per run.
# The self-test runs it on tests/fixtures/variables/: valid.yaml must pass,
# and each invalid-rule<N>.yaml must fail with rule <N> and no other rule.
#
# Prints one line per file and a last line "variables documents: <n>".
# Exit 0 pass, 1 a rule failed, 2 a setup error (no judgement).
set -euo pipefail

SELF_TEST=0
case "${1:-}" in
  --self-test) SELF_TEST=1 ;;
  "") ;;
  *) echo "usage: $0 [--self-test]" >&2; exit 2 ;;
esac

FIXTURES=tests/fixtures/variables
OWN=alpha.example.org

copies_equal() {
  local ok=0 name
  for name in c5-upstream-variables.schema.json c5-kit-keys.txt; do
    if ! cmp -s "$1/$name" "$2/$name"; then
      echo "FAIL rule A: $2/$name differs from $1/$name; copy the published file"
      ok=1
    fi
  done
  return "$ok"
}

if ! (cd core/controllers && go build -o "$TMP/check-variables" ./pkg/upstream/cmd/check-variables); then
  echo "check-variables-documents: the Go command does not build" >&2
  exit 2
fi

  failures=0
  pass() { echo "ok   $1"; }
  fail() { echo "FAIL $1"; failures=$((failures + 1)); }

  expect_fail() {
    local name="$1" text="$2"; shift 2
    if "$@" > "$TMP/out" 2>&1; then fail "$name (it passed)"; return; fi
    if grep -q -F -- "$text" "$TMP/out"; then pass "$name"; else cat "$TMP/out"; fail "$name (it failed without: $text)"; fi

    echo "check-variables-documents: self-test FAILED: $failures case(s)"
    exit 1
  fi
  echo "check-variables-documents: self-test passed"
  exit 0
fi

status=0
copies_equal docs/contracts "$PKG/contract" || status=1

git ls-files -co --exclude-standard -- clusters tests > "$TMP/all"
