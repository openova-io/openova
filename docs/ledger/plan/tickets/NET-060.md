# NET-060 — Read-only census of the network posture

## In plain words

**The problem today.** No gate run records how the network of a Sovereign is actually set up: whether kube-proxy still runs, how Cilium is configured, which namespaces have a default-deny policy, which Gateway listeners admit which routes, and how the nodes are labelled and tainted. Later network work changes all of these, and without a recorded starting point nobody can show what changed.

**What changes.** A new gate check reads these facts from every region in each gate run and writes them into the run record. The check is required, and it fails only when a fact could not be read; what the facts say never makes it fail.

**Done means:**

- Every gate run that selects the check holds six evidence blocks, D1.1 to D1.4, D1.7 and D1.8, for every region.
- A block that could not be read fails the check, so an unmeasured block never counts as recorded.
- What a block contains never fails the check: kube-proxy pods, missing default-deny policies or open listeners are recorded, not judged.
- The check only reads the cluster: it creates, changes and deletes nothing.
- The gate manifest lists NET-G04 as required, with its check file as the implementation.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every gate run of the acceptance suite records the network posture of each region of the Sovereign under test, read from the cluster API: whether kube-proxy runs, the Cilium configuration values that later network work changes, the default-deny NetworkPolicies, the Cilium policies, the Gateway listeners with the routes they admit, and the nodes with their labels, taints and addresses. A person who opens a run record finds these six evidence blocks for every region, under the steps of gate check NET-G04. The check is `required`. It fails only when a block could not be read; it never fails because of what a block says.

## 3. The model (the law)
1. Gate check NET-G04 "Network census recorded" is one file, `tests/acceptance/sovereign/internal/suite/check_network_census.go`, that calls `RegisterCheck` in `init()`. Its tests are one file, `tests/acceptance/sovereign/internal/suite/check_network_census_test.go`. Both are copied from the blocks of this ticket and fixed by their checksums.
2. For every region of the run, in region order, the check records six steps, one per evidence block, in this order: D1.1, D1.2, D1.3, D1.4, D1.7, D1.8. A step has the identifier `NET-G04.<n>`, with `n` counted from 1 over all regions (so two regions give `NET-G04.1` to `NET-G04.12`). Its evidence holds `block` (the block, for example `D1.7`) and `region` (the region id), and the step name says both.
3. The blocks:
   - D1.1 kube-proxy: the names of the pods of namespace `kube-system` whose name starts with `kube-proxy` or that carry the label `k8s-app=kube-proxy`; and for each node, what the node annotation `k3s.io/node-args` (the JSON list of arguments that k3s was started with) says: `disabled` when it holds `--disable-kube-proxy` or `--disable-kube-proxy=true`, `not disabled` when it does not, `no annotation k3s.io/node-args`, or `annotation k3s.io/node-args is not a JSON list`.
   - D1.2 Cilium configuration: from the ConfigMap `kube-system/cilium-config`, the values of `ipv4-native-routing-cidr`, `cluster-id`, `cluster-name`, `enable-wireguard` and `kube-proxy-replacement`, and the list of those keys that are absent; or `absent` when the ConfigMap does not exist.
   - D1.3 default deny: every NetworkPolicy whose name ends in `-default-deny`, as `<namespace>/<name>`, sorted, and the number of all NetworkPolicies.
   - D1.4 Cilium policies: the number of `CiliumNetworkPolicy` objects and the sorted names of the `CiliumClusterwideNetworkPolicy` objects.
   - D1.7 Gateway listeners: for every Gateway (sorted by namespace and name) and each of its listeners, the Gateway as `<namespace>/<name>`, the listener name, port, protocol, host name and `allowedRoutes` as they are in the object.
   - D1.8 nodes: every node, sorted by name, with its labels, its taints and its addresses.
4. A block passes when it was read and fails when it could not be read: the error of `kubectl` is the reason of the failed step. The content of a block never fails it. One exception is a finding, not a failure: when the API server does not serve a kind (its custom resource definition is not installed; `kubectl` then says `the server doesn't have a resource type`), blocks D1.4 and D1.7 record `kind not served` for that kind and pass.
5. The check only runs `kubectl get` through `kube.Region.GetList`. It creates, changes and deletes nothing in a cluster, and it runs no `kubectl exec`.
6. Blocks D1.5 and D1.6 (a dial from a test pod in namespace `default` to `169.254.169.254:80`, and from that pod to the OpenBao Service on port 8200) are not part of this ticket. They need a pod and a dial image, and this check writes nothing. The numbers D1.5 and D1.6 stay free for them.
7. In `docs/ledger/gates.yaml` the entry NET-G04 moves from `state: not-built` to `state: required` and gains the line `implementation: tests/acceptance/sovereign/internal/suite/check_network_census.go`. No other line of the file changes.
8. No other file of the suite changes. The module keeps using the Go standard library only.

// Check NET-G04, Network census recorded: the record of a run holds the
// network posture of every region, read from the cluster API. The census
// records what it reads. Its content never decides the check: a block passes
// when it was read and fails when it could not be read, so an unmeasured
// block is never counted as present. The check only runs `kubectl get`.
//
// The blocks, each recorded once per region:
//
//	D1.1  kube-proxy: the pods of kube-system named kube-proxy or labelled
//	      k8s-app=kube-proxy, and for each node whether the arguments that
//	      k3s wrote into the node annotation k3s.io/node-args hold
//	      --disable-kube-proxy
//	D1.2  the values of the ConfigMap kube-system/cilium-config that the
//	      list censusCiliumKeys names
//	D1.3  every NetworkPolicy whose name ends in -default-deny, with its
//	      namespace, and the number of all NetworkPolicies
//	D1.4  the number of CiliumNetworkPolicies, and the names of the
//	      CiliumClusterwideNetworkPolicies
//	D1.7  every listener of every Gateway, with its port, protocol, host
//	      name and allowedRoutes
//	D1.8  every node with its labels, taints and addresses
//
// The blocks D1.5 and D1.6 (dials from a test pod) are not part of this
// check: a dial needs a pod, and this check writes nothing.
const networkCensusID = "NET-G04"

// censusNotServedText is what kubectl prints when the API server does not
// serve a kind: its custom resource definition is not installed.
const censusNotServedText = "the server doesn't have a resource type"

// censusCiliumKeys are the keys of cilium-config that block D1.2 records.
var censusCiliumKeys = []string{"ipv4-native-routing-cidr", "cluster-id", "cluster-name", "enable-wireguard", "kube-proxy-replacement"}

// censusBlock is one evidence block. read fills ev with what it read and
// returns an error only when it could not read.
type censusBlock struct {
	id   string
	name string
	read func(ctx context.Context, region kube.Region, ev Evidence) error
}

var censusBlocks = []censusBlock{
	{"D1.1", "kube-proxy pods and the k3s argument --disable-kube-proxy", censusKubeProxy},
	{"D1.2", "Cilium configuration values", censusCiliumConfig},
	{"D1.3", "NetworkPolicies named *-default-deny", censusDefaultDeny},
	{"D1.4", "CiliumNetworkPolicies and CiliumClusterwideNetworkPolicies", censusCiliumPolicies},
	{"D1.7", "Gateway listeners and the routes they admit", censusListeners},
	{"D1.8", "nodes with labels, taints and addresses", censusNodes},
}

type networkCensusCheck struct{}

func init() { RegisterCheck(networkCensusCheck{}) }

func (networkCensusCheck) ID() string { return networkCensusID }

func (networkCensusCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
	n := 0
	for _, region := range cc.Regions {
		for _, b := range censusBlocks {
			n++
			rec.Step(networkCensusID+"."+strconv.Itoa(n), "census "+b.id+" in region "+region.ID+": "+b.name, func(ev Evidence) error {
				ev["block"], ev["region"] = b.id, region.ID
				return b.read(ctx, region, ev)
			})
		}
	}
	return nil
}

// censusList reads a list. served is false, with no error, when the API
// server does not serve the kind: that is a finding of the census.
func censusList(ctx context.Context, region kube.Region, resource, namespace string) (items []kube.Object, served bool, err error) {
	items, err = region.GetList(ctx, resource, namespace)
	if err != nil {
		if censusNotServed(err) {
			return nil, false, nil
		}
		return nil, false, err
	}
	return items, true, nil
}

func censusNotServed(err error) bool {
	return err != nil && strings.Contains(err.Error(), censusNotServedText)
}

func censusKubeProxy(ctx context.Context, region kube.Region, ev Evidence) error {
	pods, err := region.GetList(ctx, "pods", "kube-system")
	if err != nil {
		return err
	}
	found := []string{}
	for _, p := range pods {
		if strings.HasPrefix(p.Name(), "kube-proxy") || p.Str("metadata", "labels", "k8s-app") == "kube-proxy" {
			found = append(found, p.Name())
		}
	}
	sort.Strings(found)
	nodes, err := region.GetList(ctx, "nodes", "")
	if err != nil {
		return err
	}
	flags := map[string]string{}
	for _, node := range nodes {
		flags[node.Name()] = censusDisableKubeProxy(node.Str("metadata", "annotations", "k3s.io/node-args"))
	}
	ev["kube_proxy_pods"], ev["k3s_disable_kube_proxy"] = found, flags
	return nil
}

// censusDisableKubeProxy reads the annotation k3s.io/node-args, a JSON list
// of the arguments k3s was started with.
func censusDisableKubeProxy(annotation string) string {
	if annotation == "" {
		return "no annotation k3s.io/node-args"
	}
	var args []string
	if err := json.Unmarshal([]byte(annotation), &args); err != nil {
		return "annotation k3s.io/node-args is not a JSON list"
	}
	for _, a := range args {
		if a == "--disable-kube-proxy" || a == "--disable-kube-proxy=true" {
			return "disabled"
		}
	}
	return "not disabled"
}

func censusCiliumConfig(ctx context.Context, region kube.Region, ev Evidence) error {
	maps, err := region.GetList(ctx, "configmaps", "kube-system")
	if err != nil {
		return err
	}
	for _, m := range maps {
		if m.Name() != "cilium-config" {
			continue
		}
		data, _ := m.Get("data").(map[string]any)
		values, absent := map[string]any{}, []string{}
		for _, k := range censusCiliumKeys {
			if v, ok := data[k]; ok {
				values[k] = v
			} else {
				absent = append(absent, k)
			}
		}
		ev["cilium_config"], ev["absent_keys"] = values, absent
		return nil
	}
	ev["cilium_config"] = "absent"
	return nil
}

func censusDefaultDeny(ctx context.Context, region kube.Region, ev Evidence) error {

		return err

		}
	}

	return nil
}

func censusListeners(ctx context.Context, region kube.Region, ev Evidence) error {
	gateways, served, err := censusList(ctx, region, "gateways.gateway.networking.k8s.io", "")
	if err != nil {
		return err

		return nil

			})
		}
	}
	ev["listeners"] = listeners
	return nil
}

			"taints": node.Get("spec", "taints"), "addresses": node.Get("status", "addresses"),
		})
	}
	ev["nodes"] = out
	return nil
}

// censusEvidence returns the evidence of each step as JSON, by step id.
func censusEvidence(t *testing.T, r *runner) map[string]string {
	t.Helper()
	out := map[string]string{}
	for _, s := range r.run.Steps {
		b, err := json.Marshal(s.Evidence)
		if err != nil {
			t.Fatal(err)
		}
		out[s.ID] = string(b)
	}
	return out
}
