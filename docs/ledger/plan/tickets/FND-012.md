# FND-012 — Stop the tracker commits

## In plain words

**The problem today.** A scheduled job outside the repository rewrites the status board in the ledger every 15 minutes and pushes the change straight to the main branch. Almost fourteen thousand such commits exist. The board says that all 41 completion gates are done, which is not true, and its numbers are not the measure the platform uses any more.

**What changes.** The scheduled job is stopped first. The board is then replaced by five lines that name the two commands that do give the state: the plan tool and the gate verdict.

**Done means:**

- The ledger file no longer says that 41 of 41 gates are done.
- The file has five lines and names the plan tool and the gate verdict command.
- No commit rewrote the file on the main branch in the three hours before the work started.
- No commit rewrote the file on the main branch while the pull request was open.

The rest of this ticket is the exact instruction for the model that does the work.
