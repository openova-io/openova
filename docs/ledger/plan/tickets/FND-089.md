# FND-089 — The storefront offers no Sandbox agent picks and the order request carries no agents field

## In plain words

**The problem today.** The Sandbox product is withdrawn, but the storefront still carries its agent picker: a list of six coding agents, a cart field for the picks and a button grid on the application page. Every checkout still sends the picks to the organizations service, which stores them for nothing. Comments in the storefront still describe a Sandbox flow that no longer exists.

**What changes.** The picker, the agents field of the cart and of the order request, the Sandbox logo entry and the Sandbox comments leave the storefront. The organizations service no longer reads an agents field from the request; stored Organizations keep the field they have.

**Done means:**

- No storefront source file mentions the Sandbox or a list of agents.
- A checkout no longer sends agent picks with the new Organization.
- The organizations service no longer accepts agent picks into a new Organization; a request that still carries them is accepted and the picks are ignored.
- The storefront unit tests pass and the storefront builds.
- The organizations service builds and its tests pass, including the test that a cart entry sandbox is never installed as an application.

The rest of this ticket is the exact instruction for the model that does the work.
