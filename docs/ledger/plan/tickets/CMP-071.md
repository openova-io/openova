# CMP-071 — Policy files in every region's folder: scopes, the write functions, the empty document

## In plain words

**The problem today.** The policy values document, and later the other policy files, must be the same file in every region folder of the fleet repository, and no code writes there yet. The record folder of the compliance area has no commit scope, so nothing may write into it.

**What changes.** The commit library gains the scope of the record folder. The compliance package of the API gains the functions that list the regions, write one policy file into every region in one commit, give the bytes of a policy file and build the empty values document; the contract of the fleet repository lists both.

**Done means:**

- A commit through the record scope may touch only the record folder of its own Sovereign, and a scope built from an invalid Sovereign name refuses every commit.
- One write of a policy file changes the same file in every region folder of the Sovereign in one commit, and a deletion removes it from every region.
- A write that names an index file, a path outside the policy folder or a stale version, or that targets a Sovereign with no region folder, commits nothing.
- A serialised policy file carries the managed-by label, the change identifier and the annotation that turns variable substitution off, and the empty values document has exact, tested bytes.
- The contract of the fleet repository names the record scope and the policy-file functions, and promises no function that this change does not deliver.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. The policy files use the general region scope `gitwrite.RegionPlatform(fqdn, ["policy"], regions)`, which contract C4 section 2.2 already names as what `FleetPolicy` means (`docs/contracts/C4-git-layout-and-commit-library.md` line 239). No separate `FleetPolicy` constructor is added; `compliance.PolicyScope` is that call.
2. `FleetEvidence(fqdn)` has the name `fleet-evidence`, the robot `catalyst-fleet-bot` and exactly one prefix, `clusters/<fqdn>/evidence/`. An FQDN that is empty, `.`, `..` or holds a `/` gives no prefix (the existing `validName` of `scope.go`), so the scope refuses every commit.
3. Package `compliance` is the one writer of `platform/policy/**` in every region folder of the fleet repository `openova/sovereign-regions`, branch `main` (`compliance.FleetRepo`). It writes no Flux object, no `kustomization.yaml` and nothing outside `platform/policy/`.
4. `Regions` returns the region folders of `gitwrite.Regions`, sorted by name; a Sovereign with no region folder returns `ErrNoRegion`.
5. `WriteAll(ctx, w, fqdn, rel, content, ifMatch, change)` refuses with `gitwrite.ErrInvalid` a `rel` that is empty, absolute, ends in `/`, holds an empty, `.` or `..` element, or names an index file (`kustomization.yaml`, `kustomization.yml`, `Kustomization`), and a change that already sets its scope, repository or files. Otherwise it makes one commit through `gitwrite.WriteAllRegions` with `PolicyScope` of every region: the same bytes in every region, a nil content deletes the file in every region, and `ifMatch` is the compare-and-swap value of the copy in the first region by name.
6. `Serialize(obj, changeID)` returns `intent.Serialize` of a copy of `obj` with the label `app.kubernetes.io/managed-by: flux` and the annotations `catalyst.openova.io/change-id: <changeID>` and `kustomize.toolkit.fluxcd.io/substitute: disabled`; `obj` is not changed. No object, or an empty change identifier, is `gitwrite.ErrInvalid`.
7. `EmptyValuesDocument()` is the ConfigMap `compliance-policy-values` in namespace `flux-system` with the label `reconcile.fluxcd.io/watch: Enabled` and `data.values.yaml: "{}\n"`: the name, namespace and key that slot 27a reads (`clusters/_template/bootstrap-kit/27a-kyverno-policies.yaml` line 186). This ticket builds the object and writes it nowhere.
8. Contract C4 changes in five places: the `Scope.Name` comment, the constructor list (`FleetEvidence`), a paragraph on the record scope, the layout tree (`evidence/` and `platform/policy/policy-values.yaml`), and section 2.2, where the sentence "The scope of the record folder `evidence/` arrives with CMP-071." is replaced and a paragraph "Policy files (CMP-071)" names `Regions`, `WriteAll` and `Serialize`. It names no `EnsurePolicyFiles`: that function arrives with CMP-075.

+// checkRel refuses a path that is not a file path below the policy folder,

+func checkRel(rel string) error {

+// region of the Sovereign, in one commit. A nil content deletes the file in
+// every region. ifMatch is the compare-and-swap value of the copy in the
+// first region by name ("" for none, gitwrite.AbsentSHA for "must not

+// first (EnsurePolicyFiles).

+// WriteAll sets c.Scope (PolicyScope of every region), c.Repo (FleetRepo)
+// and c.Files; a c that already carries one of them is refused with
+// gitwrite.ErrInvalid. The caller sets Summary, ChangeID, Via, and
+// optionally Author, Trailers and Mode. The result lists one file per
+// region, regions in name order.
+func WriteAll(ctx context.Context, w gitwrite.Writer, sovereignFQDN, rel string, content []byte, ifMatch string, c gitwrite.Change) (gitwrite.Result, error) {
+	if err := checkRel(rel); err != nil {

+		return gitwrite.Result{}, fmt.Errorf("%w: WriteAll sets the scope, the repository and the files of the change", gitwrite.ErrInvalid)
+	}
+	regions, err := Regions(ctx, w, sovereignFQDN)
+	if err != nil {
+		return gitwrite.Result{}, err
+	}
+	f := gitwrite.FileChange{Path: policyDir + rel, Op: gitwrite.OpUpsert, Content: content, IfMatch: ifMatch}
+	if content == nil {
+		f.Op = gitwrite.OpDelete
+	}
+	c.Scope = PolicyScope(sovereignFQDN, regions)
+	c.Repo = FleetRepo
+	c.Files = []gitwrite.FileChange{f}
+	return gitwrite.WriteAllRegions(ctx, w, sovereignFQDN, regions, c)

+func Serialize(obj *unstructured.Unstructured, changeID string) ([]byte, error) {
+	if obj == nil {
+		return nil, fmt.Errorf("%w: no object to serialise", gitwrite.ErrInvalid)
+	}
+	if changeID == "" {
+		return nil, fmt.Errorf("%w: %s %s needs a change identifier", gitwrite.ErrInvalid, obj.GetKind(), obj.GetName())
+	}
+	c := obj.DeepCopy()
+	labels := c.GetLabels()
+	if labels == nil {
+		labels = map[string]string{}
+	}
+	labels[intent.ManagedByLabel] = intent.ManagedByValue
+	c.SetLabels(labels)
+	ann := c.GetAnnotations()
+	if ann == nil {
+		ann = map[string]string{}
+	}
+	ann[intent.ChangeIDAnnotation] = changeID
+	ann[SubstituteAnnotation] = SubstituteDisabled
+	c.SetAnnotations(ann)
+	return intent.Serialize(c)
