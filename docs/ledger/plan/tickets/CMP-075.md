# CMP-075 — Policy files in every region's folder: the alignment function at start-up, the local pack's document kept

## In plain words

**The problem today.** The policy values document must be the same file in every region folder of the fleet repository, but nothing writes it there, and a region added later starts with no policy files. The local provider pack applies its own copy of the same document at boot, with the NodePort ban at Enforce. An empty document applied from the region folders would replace that copy and switch the ban off, and the two Flux objects that apply the two copies would keep overwriting each other.

**What changes.** catalyst-api brings the policy files of every region to the same content once at start-up, and writes the empty values document where no region has one. The empty document and the document of the local pack are both created only when the cluster has none, so the ban of the pack stays at Enforce, and a document that a policy route writes later replaces either.

**Done means:**

- When no region of a Sovereign holds the policy values document, one commit writes the empty document into every region, marked to be created only where the cluster has none, and a second run commits nothing.
- A policy file that the reference region holds and another region lacks, or holds with other content, is copied there in one commit with compare-and-swap; no file is deleted.
- catalyst-api starts the compliance aggregator and then runs the alignment once in the background; a missing setting or a failed alignment is logged and the API keeps running.
- The values document of the local provider pack carries the same create-only mark and still sets the NodePort ban to Enforce, and a test that reads the pack's file fails when either is missing.
- A document that a policy route serialises carries no create-only mark, so it always replaces the one in the cluster.
- Contract C4 describes the alignment, the mark, and the document of the local pack.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. `EnsurePolicyFiles` lists the regions with `Regions`. A Sovereign with no region folder returns `ErrNoRegion` and commits nothing.
2. It reads the files below `clusters/<fqdn>/regions/<region>/platform/policy/` of every region through `w.List`, with the scope `PolicyScope(fqdn, regions)`, as path and blob SHA. The reference region is the first region by name whose folder holds `policy-values.yaml`; when none does, it is the first region by name.
3. When the reference holds no `policy-values.yaml`, the empty document (`EmptyValuesDocument`, serialised with the label and annotations of `Serialize` plus `kustomize.toolkit.fluxcd.io/ssa: IfNotPresent`) is written to `platform/policy/policy-values.yaml` of every region, with `IfMatch: gitwrite.AbsentSHA`.
4. Every file of the reference that another region lacks, or holds with another blob SHA, is written there with the reference's bytes. The reference copy is read once and must still have the listed SHA, else `*gitwrite.ConflictError`. The written copy carries `IfMatch` = that region's SHA, or `gitwrite.AbsentSHA` when it lacks the file.
5. Nothing is deleted: a file that only a non-reference region holds stays. When every region matches, nothing is committed and the result has `Committed` false. Otherwise there is exactly one commit: scope `PolicyScope` of every region, repository `FleetRepo`, `Via: controller`, summary `Align policy files across regions`, a new change identifier.
6. `Serialize` removes `kustomize.toolkit.fluxcd.io/ssa` from the copy it serialises, so a file it gives always replaces the object in the cluster, also when the object was read back from the empty document.
7. `startCompliance(ctx, log, agg, getenv)` calls `agg.Start(ctx)` and then, in a goroutine, `alignPolicyFilesFromEnv`: the commit library is built from `intentGitConfig` (`products/catalyst/bootstrap/api/cmd/api/intent_wire.go` line 125) and the FQDN from `SOVEREIGN_FQDN`; a missing setting is logged and nothing is called. `alignPolicyFiles` runs `EnsurePolicyFiles` within 2 minutes and logs the outcome; a failure is a warning. In `main.go` the one line `compliance.Start(ctx)` becomes `startCompliance(ctx, log, compliance, os.Getenv)`; main() keeps its line count.
8. `clusters/_template/providers/local/kit/policy-values.yaml` gains the annotation `kustomize.toolkit.fluxcd.io/ssa: IfNotPresent` and a comment that names its second writer and the test. Its values do not change: `bootstrapMode: false` and `forbidNodePortService.action: Enforce`. This is the rendered-once form of `clusters/_template/bootstrap-secrets/ghcr-pull.yaml` line 31, which is on `main` and which the pinned Flux already honours. The cost is stated: a later change of the pack's values reaches only a pack that is installed fresh, which is how the pack is brought up.
9. Contract C4, section 2.2, paragraph "Policy files (CMP-071)", gains the sentences on `kustomize.toolkit.fluxcd.io/ssa` in `Serialize` and on `EnsurePolicyFiles`. Nothing else in the contract changes.
10. Nothing is deleted. The commit library, slot 27a and the kit generator do not change.

+// the fleet repository (compliance.EnsurePolicyFiles; contract C4, section

+// runs once, and a failure is logged. getenv reads the environment
+// (os.Getenv in production).
+func startCompliance(ctx context.Context, log *slog.Logger, agg starter, getenv func(string) string) {
+	agg.Start(ctx)
+	go func() {
+		_, _ = alignPolicyFilesFromEnv(ctx, log, getenv)
+	}()
+}

+// alignPolicyFilesFromEnv builds the commit library from the configuration
+// of package intent (CATALYST_GITEA_URL, CATALYST_GITEA_TOKEN and
+// SOVEREIGN_FQDN) and aligns the policy files. A missing setting is logged
+// and returned, and nothing is called.
+func alignPolicyFilesFromEnv(ctx context.Context, log *slog.Logger, getenv func(string) string) (gitwrite.Result, error) {
+	cfg, err := intentGitConfig(getenv)
+	if err == nil {
+		var w *gitwrite.Client
+		if w, err = gitwrite.New(cfg); err == nil {
+			return alignPolicyFiles(ctx, log, w, strings.TrimSpace(getenv("SOVEREIGN_FQDN")))
+		}
+	}
+	log.Warn("compliance: policy files not aligned at start-up", "err", err)
+	return gitwrite.Result{}, err
+}
+
+// alignPolicyFiles runs compliance.EnsurePolicyFiles once, within
+// policyFilesTimeout, and logs its outcome.
+func alignPolicyFiles(ctx context.Context, log *slog.Logger, w gitwrite.Writer, fqdn string) (gitwrite.Result, error) {
