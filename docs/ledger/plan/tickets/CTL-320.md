# CTL-320 — Durable audit

## In plain words

**The problem today.** An audit event of the platform API, such as a grant of access, is kept only in the memory of the running API. When the API restarts, the audit trail on the console is empty. The code that should send each event to the durable event stream is a placeholder that sends nothing, and yet the audit listing names the stream as its source.

**What changes.** Every audit event is written to the durable event stream and acknowledged, and the API reads the newest events back when it starts, so the audit trail is the same after a restart. The listing says truthfully whether events go to the stream or stay in memory, and a caller that must not act without a record gets an error when the stream cannot take the event.

**Done means:**

- An audit event that the console lists before a restart of the API is listed after it, with the same identifier.
- Every audit event has an identifier and is stored once on the event stream, in the standard envelope for new event subjects.
- The audit listing names the stream as its transport only when events really go there, and says in-process otherwise.
- A caller that asks for a strict record gets an error, and the event is not listed, when the event server is stopped.
- Every audit event is also one line in the log of the API.
- A test against a real event server proves the restart case on every pull request that changes the API.
- The gate check Audit survives a restart is required: a gate run on the environment fails unless a grant made before a restart of the API is still listed after it.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
catalyst-api records every audit event durably. `audit.Bus.Publish` and the new `audit.Bus.PublishStrict` give each event an identifier (a ULID), publish it as a CloudEvents 1.0 envelope on the subject `catalyst.audit.recorded.v1` of the JetStream stream `CATALYST_ORG`, and wait for the stream's acknowledgement. At start the API reads the newest 1,000 events of that subject back into its ring buffer, so `GET /api/v1/sovereigns/{id}/audit/rbac` lists after a restart what it listed before. The `transport` field of that listing is `jetstream:CATALYST_ORG` when the publisher is set and `in-process` when it is not; it never names a transport that is not wired. The envelope lives in `core/controllers/pkg/natsbus`, where every later producer of a new subject finds it. Contract C3 names catalyst-api as producer and consumer of the subject. The new gate check CTL-G07 of the acceptance suite makes a grant, replaces the pods of the API, and passes only when the event of the grant is still listed; its manifest entry is `required`.

## 3. The model (the law)
1. **The envelope.** Every subject registered as `envelope: cloudevents` in `docs/contracts/C3-event-subjects.yaml` carries CloudEvents 1.0 in structured JSON mode (decision record ADR-0021, point C12). The attributes are `specversion` (always `1.0`), `id` (a ULID of 26 characters), `type` (`io.openova.` followed by the NATS subject), `source`, `subject` (the Organization slug; absent when the event has none), `time` (RFC 3339, UTC), `datacontenttype` (always `application/json`) and `data`. All are required except `subject`. The `id` is also sent as the header `Nats-Msg-Id`, so the stream keeps one copy of an event that is published twice. A subject of this envelope matches `^catalyst\.[a-z][a-z0-9_]*\.[a-z][a-z0-9_]*\.v[0-9]+$`.
2. **The package.** `core/controllers/pkg/natsbus/cloudevent.go` adds the type `CloudEvent` and the functions `NewCloudEvent`, `(*Publisher).SendCloudEvent`, `DecodeCloudEvent` and `NewID`. `SendCloudEvent` publishes to the subject that `type` names and returns only after the JetStream acknowledgement. The legacy type `Event` and the functions `Publish`, `NewEvent`, `Connect` and `Subscribe` of the package do not change.
3. **The name `SendCloudEvent`.** The method is not named with the word Publish in front of CloudEvent: the two words together hold the letters of a cloud provider's tool name, and `scripts/check-provider-leaks.py` would count every line that calls the method. Do not rename it.
4. **The audit event.** `audit.Event` gains two fields at its end: `ID` (`json:"id"`) and `Phase` (`json:"phase,omitempty"`, values `intent` and `result`). No existing field changes its name or its JSON key. The `data` of the envelope is the JSON of `audit.Event`. The envelope's `id` is the event's `ID`, its `time` is the event's `Timestamp`, it has no `subject`, and its `source` is `catalyst-api/<SOVEREIGN_FQDN>/<SOVEREIGN_PRIMARY_REGION>`, where a variable that is not set is written as `-`.
5. **The Bus.** `Publish(ctx, ev)` keeps its signature: it stamps the event (time, result `ok`, a new `ID` when empty), appends it to the ring, fans it out, forwards it to the publisher when one is set, and writes the log line; a publisher error is in the log line and is not returned. `PublishStrict(ctx, ev) error` forwards to the publisher first; on an error, or when no publisher is set (`audit.ErrNoPublisher`), it returns the error and the event is not in the ring; on success it appends and fans out. `Load(events)` appends events read from the stream, oldest first, without fan-out, forwarding or log line. `Transport()` returns `jetstream:CATALYST_ORG` when a publisher is set and `in-process` otherwise. The log line is one line per event with the key `audit` set to `true`, the event under `event`, and `publishError` when the publisher failed.
6. **The publisher.** `natspub.AuditPublisher` implements `audit.Publisher`. `Publish` waits at most 5 seconds for the acknowledgement, and the wait does not end when the caller's request is cancelled. `Replay(ctx, limit)` returns the newest `limit` events of the subject, oldest first; it asks the stream how many messages the subject holds and reads them with an ordered consumer, which the server removes by itself. `natspub.NewAuditBus(pub, ringCapacity, log)` builds the Bus and, with a publisher, loads the newest 1,000 events within 30 seconds; a replay that fails is logged as an error and leaves the ring empty.
7. **No stream is created.** The chart of `platform/nats-jetstream` declares `CATALYST_ORG`. No code of this ticket outside `_test.go` files creates a stream. There is no outbox table and no audit database.
8. **The wiring.** In `cmd/api/main.go`, `main()` calls `h.SetAuditBus(newAuditBusFromEnv(log))`. `newRBACAuditPublisherFromEnv` returns a `*natspub.AuditPublisher` when `CATALYST_NATS_URL` is set and NATS answers, and nil when the variable is empty (as today) or NATS cannot be reached at start (logged as an error). With nil the Bus is in-process and `PublishStrict` fails. The variable `CATALYST_AUDIT_NATS_SUBJECT`, which the placeholder only logged, is no longer read.
9. **The listing.** `HandleRBACAuditList` sets `transport` to `h.auditBus.Transport()`. The constant `rbacAuditTransport` is deleted. No other field of the response changes.
10. **The registry.** The entry `catalyst.audit.recorded.v1` of `docs/contracts/C3-event-subjects.yaml` gets `producers: [catalyst-api]` and `consumers: [catalyst-api]`.
11. **The gate check CTL-G07.** The file `tests/acceptance/sovereign/internal/suite/check_ctl_audit_survives_restart.go` registers the check. It needs the run's console session, the deployment identifier and one region; without them it fails. Step 1 makes one grant with `POST /api/v1/sovereigns/{id}/rbac/assign`: tier `viewer`, subject and Application both `ctl-g07-<run>`, e-mail `ctl-g07-<run>@gate.invalid`; the answer must be 201 with `applied` `created` and a UserAccess name. Step 2 reads `GET /api/v1/sovereigns/{id}/audit/rbac?limit=500`: it must hold an `rbac-grant-created` event of that UserAccess with an `id`, and `transport` must be `jetstream:CATALYST_ORG`. Step 3, in every region that has pods with the label `app.kubernetes.io/name=catalyst-api` in namespace `catalyst-system`: deletes those pods and waits for the rollout of Deployment `catalyst-api`; every pod must be new and Ready. Step 4 reads the listing again, at most five times, three seconds apart, and again only after no answer or a 502, 503 or 504: it must still hold the event with that `id`. Step 5 removes the grant with `DELETE /api/v1/deployments/{id}/admin/user-access/{name}` and expects 204; it runs whenever step 1 created a grant.
12. **The manifest.** The entry `CTL-G07` of `docs/ledger/gates.yaml` moves from `state: not-built` to `state: required` and gains `implementation: tests/acceptance/sovereign/internal/suite/check_ctl_audit_survives_restart.go`. No other field changes. Only CTL-320 may set it to required (rule 4 of `scripts/acceptance-gate.py`).
13. **The baseline.** `main()` and the handler package get shorter. `scripts/baselines/api-structure.json` is lowered by the guard's own command `--write-baseline`. It is never edited by hand.
14. **The tests on a real server.** `internal/natspub/audit_publisher_test.go` runs against NATS server 2.10.16, the release that the chart of `platform/nats-jetstream` runs. The test builds it with `go install github.com/nats-io/nats-server/v2@v2.10.16` into a folder of its own. No `go.mod` and no `go.sum` changes. A build that fails makes the tests fail; they are never skipped.

//	 "time":"<RFC 3339>","datacontenttype":"application/json","data":{...}}
//
// Every attribute is required except subject. The id is a ULID and is sent as
// the Nats-Msg-Id header, so the stream drops a repeated publish of the same
// event. The legacy subjects keep the Event envelope of subscriber.go.
package natsbus

import (
	"context"
	"crypto/rand"
	"encoding/binary"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"regexp"
	"strings"
	"time"

	"github.com/nats-io/nats.go/jetstream"
)

const (
	// cloudEventSpecVersion is the only specversion this package writes and reads.
	cloudEventSpecVersion = "1.0"
	// cloudEventTypePrefix comes before the NATS subject in the type attribute.
	cloudEventTypePrefix = "io.openova."
	// cloudEventContentType is the only datacontenttype this package writes.
	cloudEventContentType = "application/json"
)

// versionedSubject is the form of a subject registered after contract C3.
var versionedSubject = regexp.MustCompile(`^catalyst\.[a-z][a-z0-9_]*\.[a-z][a-z0-9_]*\.v[0-9]+$`)

// CloudEvent is the envelope of every subject registered after contract C3.
type CloudEvent struct {
	SpecVersion     string          `json:"specversion"`       // always "1.0"
	ID              string          `json:"id"`                // ULID
	Type            string          `json:"type"`              // "io.openova." + NATS subject
	Source          string          `json:"source"`            // who published it
	Subject         string          `json:"subject,omitempty"` // Organization slug, or absent
	Time            time.Time       `json:"time"`
	DataContentType string          `json:"datacontenttype"` // always "application/json"
	Data            json.RawMessage `json:"data"`
}

// NewCloudEvent fills SpecVersion, ID, Time and DataContentType and marshals
// data. natsSubject must match ^catalyst\.[a-z][a-z0-9_]*\.[a-z][a-z0-9_]*\.v[0-9]+$ .
// source must not be empty. subject is the Organization slug, or "".
func NewCloudEvent(natsSubject, source, subject string, data any) (CloudEvent, error) {
	if !versionedSubject.MatchString(natsSubject) {
		return CloudEvent{}, fmt.Errorf("natsbus: %q is not a subject of the form catalyst.<domain>.<event>.v<major>", natsSubject)
	}
	if source == "" {
		return CloudEvent{}, errors.New("natsbus: a CloudEvent needs a source")
	}
	raw, err := json.Marshal(data)
	if err != nil {
		return CloudEvent{}, fmt.Errorf("natsbus: marshal CloudEvent data: %w", err)
	}
	return CloudEvent{
		SpecVersion:     cloudEventSpecVersion,
		ID:              NewID(),
		Type:            cloudEventTypePrefix + natsSubject,
		Source:          source,
		Subject:         subject,
		Time:            time.Now().UTC(),
		DataContentType: cloudEventContentType,
		Data:            raw,
	}, nil
}

// natsSubject returns the NATS subject that the type attribute names. It
// returns an error when a required attribute is missing or has another value
// than this package writes.
func (ce CloudEvent) natsSubject() (string, error) {
	subject := strings.TrimPrefix(ce.Type, cloudEventTypePrefix)
	switch {
	case ce.SpecVersion != cloudEventSpecVersion:
		return "", fmt.Errorf("natsbus: CloudEvent specversion is %q, want %q", ce.SpecVersion, cloudEventSpecVersion)
	case subject == ce.Type || !versionedSubject.MatchString(subject):
		return "", fmt.Errorf("natsbus: CloudEvent type %q is not %s<catalyst.<domain>.<event>.v<major>>", ce.Type, cloudEventTypePrefix)
	case ce.ID == "":
		return "", errors.New("natsbus: CloudEvent has no id")
	case ce.Source == "":
		return "", errors.New("natsbus: CloudEvent has no source")
	case ce.Time.IsZero():
		return "", errors.New("natsbus: CloudEvent has no time")
	case ce.DataContentType != cloudEventContentType:
		return "", fmt.Errorf("natsbus: CloudEvent datacontenttype is %q, want %q", ce.DataContentType, cloudEventContentType)
	case !json.Valid(ce.Data):
		return "", errors.New("natsbus: CloudEvent data is not JSON")
	}
	return subject, nil
}

// SendCloudEvent publishes to the subject derived from ce.Type, with
// Nats-Msg-Id = ce.ID, and returns only after the JetStream acknowledgement.
// The wait is bounded by ctx. An envelope with a missing or wrong required
// attribute is not published.
//
// The name does not start with Publish on purpose: that word followed by
// CloudEvent holds the name of a cloud provider's tool, and
// scripts/check-provider-leaks.py would count every line that calls it.
func (p *Publisher) SendCloudEvent(ctx context.Context, ce CloudEvent) error {
	if p == nil || p.js == nil {
		return errors.New("natsbus: publisher not initialised")
	}
	subject, err := ce.natsSubject()
	if err != nil {
		return err
	}
	body, err := json.Marshal(ce)
	if err != nil {
		return fmt.Errorf("natsbus: marshal CloudEvent: %w", err)
	}
	if _, err := p.js.Publish(ctx, subject, body, jetstream.WithMsgID(ce.ID)); err != nil {
		return fmt.Errorf("natsbus: publish %s: %w", subject, err)
	}
	return nil
}

// DecodeCloudEvent parses a message body; it returns an error when the body
// is not a JSON object or specversion is not "1.0".
func DecodeCloudEvent(body []byte) (CloudEvent, error) {
	var ce CloudEvent
	if err := json.Unmarshal(body, &ce); err != nil {
		return CloudEvent{}, fmt.Errorf("natsbus: decode CloudEvent: %w", err)
	}
	if ce.SpecVersion != cloudEventSpecVersion {
		return CloudEvent{}, fmt.Errorf("natsbus: CloudEvent specversion is %q, want %q", ce.SpecVersion, cloudEventSpecVersion)
	}
	return ce, nil
}

// crockford is the alphabet of a ULID: base 32 without I, L, O and U.
const crockford = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"

// NewID returns a new ULID: 26 characters, 48 bits of Unix time in
// milliseconds followed by 80 random bits. Identifiers made in different
// milliseconds sort by time. It is the id NewCloudEvent fills in; a producer
// that needs the id before it builds the envelope calls NewID and sets
// CloudEvent.ID to it. Like uuid.New it panics when the system has no
// randomness, or when the clock is outside the range of a ULID.
func NewID() string {
	id, err := newULID(time.Now(), rand.Reader)
	if err != nil {
		panic("natsbus: no event id: " + err.Error())
	}
	return id
}

// newULID builds a ULID from a time and 10 bytes read from entropy. The time
// must lie between 1970 and the year 10889, the range of 48 bits of
// milliseconds.
func newULID(t time.Time, entropy io.Reader) (string, error) {
	ms := t.UnixMilli()
	if ms < 0 || ms >= 1<<48 {
		return "", fmt.Errorf("natsbus: the time %s is outside the range of a ULID", t.UTC().Format(time.RFC3339))
	}
	var b [16]byte
	binary.BigEndian.PutUint64(b[:8], uint64(ms)<<16)
	if _, err := io.ReadFull(entropy, b[6:]); err != nil {
		return "", err
	}
	// 128 bits are 26 groups of 5 bits, the last group first; the first
	// character holds the 3 bits that are left.
	hi, lo := binary.BigEndian.Uint64(b[:8]), binary.BigEndian.Uint64(b[8:])
	var out [26]byte
	for i := len(out) - 1; i >= 0; i-- {
		out[i] = crockford[lo&31]
		lo = lo>>5 | hi<<59
		hi >>= 5
	}
	return string(out[:]), nil
}

// Package natspub — audit_publisher.go: the audit.Publisher of catalyst-api.
//
// Every audit event is published as a CloudEvent (contract C3,
// docs/contracts/C3-event-subjects.yaml) on the subject
// catalyst.audit.recorded.v1 of the JetStream stream CATALYST_ORG. The
// envelope's id is the event's id, and it is sent as the Nats-Msg-Id header,
// so the stream keeps one copy of an event that is published twice. Publish
// returns only after the stream acknowledged the message.
//
// Replay reads the newest events back from the stream. NewAuditBus, which
// main.go calls once at start, loads the result into the audit Bus, so the
// listing routes show after a restart what they showed before it.
//
// This file creates no stream: the chart of bp-nats-jetstream declares
// CATALYST_ORG. While the stream is absent, Publish and Replay return an
// error.
package natspub

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"log/slog"
	"time"

	"github.com/nats-io/nats.go"
	"github.com/nats-io/nats.go/jetstream"

	"github.com/openova-io/openova/core/controllers/pkg/natsbus"
	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/audit"
)

const (
	// AuditSubject is the NATS subject of every audit event.
	AuditSubject = "catalyst.audit.recorded.v1"

	// auditPublishTimeout bounds the wait for the stream's acknowledgement
	// of one event.
	auditPublishTimeout = 5 * time.Second

	// auditReplayBatch is how many messages Replay asks for in one request.
	auditReplayBatch = 256

	// AuditReplayLimit is how many of the newest audit events NewAuditBus
	// reads back from the stream.
	AuditReplayLimit = 1000

	// auditReplayTimeout bounds that read.
	auditReplayTimeout = 30 * time.Second
)

// AuditPublisher implements audit.Publisher on a JetStream stream. Construct
// it with NewAuditPublisher. Publish is safe for concurrent use.
type AuditPublisher struct {
	url    string
	source string
	pub    *natsbus.Publisher
	log    *slog.Logger
}

// Compile-time assertion that the type satisfies the audit interface.
var _ audit.Publisher = (*AuditPublisher)(nil)

// NewAuditPublisher connects to NATS at url. source is the `source`
// attribute of every envelope it publishes: catalyst-api/<sovereign
// FQDN>/<region id>. It returns an error when url or source is empty or the
// server cannot be reached; the caller then runs without a publisher.
func NewAuditPublisher(url, source string, log *slog.Logger) (*AuditPublisher, error) {
	if url == "" {
		return nil, errors.New("natspub: CATALYST_NATS_URL is empty")
	}
	if source == "" {
		return nil, errors.New("natspub: the audit publisher needs a source")
	}
	if log == nil {
		log = slog.Default()
	}
	pub, err := natsbus.NewPublisher(url)
	if err != nil {
		return nil, fmt.Errorf("natspub: audit publisher: %w", err)
	}
	return &AuditPublisher{
		url:    url,
		source: source,
		pub:    pub,
		log:    log.With("component", "audit-publisher", "subject", AuditSubject),
	}, nil
}

// Publish wraps ev in a CloudEvent whose id is ev.ID and whose time is
// ev.Timestamp, publishes it on AuditSubject and waits for the stream's
// acknowledgement, at most auditPublishTimeout. The wait does not end when
// the caller's request is cancelled: an audit event of a change that has
// happened must still be recorded.
func (p *AuditPublisher) Publish(ctx context.Context, ev audit.Event) error {
	if p == nil || p.pub == nil {
		return errors.New("natspub: audit publisher not initialised")
	}
	if ev.ID == "" {
		return errors.New("natspub: an audit event needs an id")
	}
	ce, err := natsbus.NewCloudEvent(AuditSubject, p.source, "", ev)
	if err != nil {
		return err
	}
	ce.ID = ev.ID
	if !ev.Timestamp.IsZero() {
		ce.Time = ev.Timestamp.UTC()
	}
	ctx, cancel := context.WithTimeout(context.WithoutCancel(ctx), auditPublishTimeout)
	defer cancel()
	return p.pub.SendCloudEvent(ctx, ce)
}

// Replay returns the newest events of AuditSubject that the stream holds, at
// most limit of them, oldest first. It asks the stream how many messages the
// subject holds, reads them from the first one with an ordered consumer,
// which the server removes by itself, and keeps the last limit of them; the
// stream's own age limit bounds the read.
// A message that is not a CloudEvent with an audit event as data is skipped
// and counted in the log. Replay opens a connection of its own and closes it.
func (p *AuditPublisher) Replay(ctx context.Context, limit int) ([]audit.Event, error) {
	if p == nil || p.url == "" {
		return nil, errors.New("natspub: audit publisher not initialised")
	}
	if limit <= 0 {
		return nil, nil
	}
	nc, err := nats.Connect(p.url, nats.Name("catalyst-api/audit-replay"), nats.Timeout(10*time.Second))
	if err != nil {
		return nil, fmt.Errorf("natspub: audit replay: connect: %w", err)
	}
	defer nc.Close()
	js, err := jetstream.New(nc)
	if err != nil {
		return nil, fmt.Errorf("natspub: audit replay: jetstream: %w", err)
	}
	stream, err := js.Stream(ctx, natsbus.StreamCatalystOrg)
	if err != nil {
		return nil, fmt.Errorf("natspub: audit replay: stream %s: %w", natsbus.StreamCatalystOrg, err)
	}
	info, err := stream.Info(ctx, jetstream.WithSubjectFilter(AuditSubject))
	if err != nil {
		return nil, fmt.Errorf("natspub: audit replay: stream info: %w", err)
	}
	left := info.State.Subjects[AuditSubject] // messages of the subject still to read
	if left == 0 {
		return nil, nil
	}
	var skip uint64 // the messages before the newest limit
	if newest := uint64(limit); left > newest {
		skip = left - newest
	}
	cons, err := js.OrderedConsumer(ctx, natsbus.StreamCatalystOrg, jetstream.OrderedConsumerConfig{
		FilterSubjects: []string{AuditSubject},
		DeliverPolicy:  jetstream.DeliverAllPolicy,
	})
	if err != nil {
		return nil, fmt.Errorf("natspub: audit replay: consumer: %w", err)
	}
	tail := make([][]byte, 0, min(limit, auditReplayBatch))
	for left > 0 {
		if err := ctx.Err(); err != nil {
			return nil, fmt.Errorf("natspub: audit replay: %w", err)
		}
		size := auditReplayBatch
		if left < auditReplayBatch {
			size = int(left)
		}
		batch, err := cons.Fetch(size, jetstream.FetchMaxWait(5*time.Second))
		if err != nil {
			return nil, fmt.Errorf("natspub: audit replay: fetch: %w", err)
		}
		var got uint64
		for msg := range batch.Messages() {
			if got++; skip > 0 {
				skip--
				continue
			}
			tail = append(tail, msg.Data())
		}
		if err := batch.Error(); err != nil {
			return nil, fmt.Errorf("natspub: audit replay: fetch: %w", err)
		}
		if got == 0 || got > left {
			return nil, fmt.Errorf("natspub: audit replay: the stream sent %d messages, %d still expected", got, left)
		}
		left -= got
	}
	events, skipped := make([]audit.Event, 0, len(tail)), 0
	for _, body := range tail {
		ce, err := natsbus.DecodeCloudEvent(body)
		var ev audit.Event
		if err == nil {
			err = json.Unmarshal(ce.Data, &ev)
		}
		if err != nil || ev.AuditType == "" {
			skipped++
			continue
		}
		if ev.ID == "" {
			ev.ID = ce.ID
		}
		events = append(events, ev)
	}
	if skipped > 0 {
		p.log.Warn("audit replay: messages that are not audit events were skipped", "skipped", skipped)
	}
	return events, nil
}

// NewAuditBus builds the audit Bus of catalyst-api. ringCapacity is the size
// of the ring buffer (0: the default of package audit); log receives the log
// line of every event.
//
// With a publisher every event goes to the stream, and the ring is filled
// with the newest AuditReplayLimit events that the stream holds, so the
// listing routes show after a restart what they showed before it. A replay
// that fails is logged and leaves the ring empty; events published afterwards
// are still recorded. With a nil publisher the Bus runs in process only.
func NewAuditBus(pub *AuditPublisher, ringCapacity int, log *slog.Logger) *audit.Bus {
	if log == nil {
		log = slog.Default()
	}
	cfg := audit.BusConfig{RingCapacity: ringCapacity, Log: log}
	if pub != nil {
		cfg.Publisher = pub // never a nil pointer inside the interface
	}
	bus := audit.NewBus(cfg)
	replayed := 0
	if pub != nil {
		ctx, cancel := context.WithTimeout(context.Background(), auditReplayTimeout)
		defer cancel()
		events, err := pub.Replay(ctx, AuditReplayLimit)
		if err != nil {
			log.Error("audit: replay from the stream failed; the listing starts empty", "err", err)
		}
		replayed = bus.Load(events)
	}

// Nats-Msg-Id and body, in order.
func rawMessages(t *testing.T, url, subject string) (ids []string, bodies [][]byte) {
	t.Helper()
	nc, err := nats.Connect(url)
	if err != nil {
		t.Fatal(err)
	}
	defer nc.Close()
	js, err := jetstream.New(nc)
	if err != nil {
		t.Fatal(err)
	}

	defer cancel()
	stream, err := js.Stream(ctx, natsbus.StreamCatalystOrg)
	if err != nil {
		t.Fatal(err)
	}
	info, err := stream.Info(ctx, jetstream.WithSubjectFilter(subject))
	if err != nil {
		t.Fatal(err)
	}
	n := info.State.Subjects[subject]
	if n == 0 {
		return nil, nil
	}
	cons, err := js.OrderedConsumer(ctx, natsbus.StreamCatalystOrg, jetstream.OrderedConsumerConfig{FilterSubjects: []string{subject}})
	if err != nil {
		t.Fatal(err)
	}
	for ; n > 0; n-- {
		msg, err := cons.Next(jetstream.FetchMaxWait(5 * time.Second))
		if err != nil {
			t.Fatalf("%d messages on %s were not read: %v", n, subject, err)
		}
		ids = append(ids, msg.Headers().Get(jetstream.MsgIDHeader))
		bodies = append(bodies, msg.Data())
	}
	return ids, bodies
}

package suite

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"net/http"
	"net/url"
	"sort"
	"strings"
	"time"

	"github.com/openova-io/openova/tests/acceptance/sovereign/internal/api"
	"github.com/openova-io/openova/tests/acceptance/sovereign/internal/kube"
)

// Check CTL-G07, audit survives a restart. An audit event that the API lists
// before its pods are replaced must be listed after it, with the same
// identifier. The check:
//  1. makes one grant through the console API, for a subject that no user has
//     and an Application that does not exist, so that it gives nobody access;
//  2. reads the audit listing: it must hold the event of that grant with an
//     identifier, and name the JetStream stream as its transport;
//  3. deletes the pods of Deployment catalyst-system/catalyst-api in every
//     region that runs them and waits until the Deployment has replaced them;
//  4. reads the listing again: it must still hold the event;
//  5. removes the grant through the console API, whatever happened before.
//
// Step 3 changes no object of the Deployment itself: it deletes pods, as a
// node drain does, so the Deployment carries no restart annotation after it.
// After the restart the gateway needs a moment to learn the new pod: step 4
// asks at most ctlAuditAttempts times and waits between two attempts, and it
// asks again only when it got no answer or a 502, 503 or 504.
const (
	ctlAuditID         = "CTL-G07"
	ctlAuditNamespace  = "catalyst-system"
	ctlAuditDeployment = "catalyst-api"
	ctlAuditSelector   = "app.kubernetes.io/name=catalyst-api"
	ctlAuditTransport  = "jetstream:CATALYST_ORG" // audit.TransportJetStream of catalyst-api
	ctlAuditGrantType  = "rbac-grant-created"
	ctlAuditScopeKey   = "openova.io/application"
	ctlAuditAttempts   = 5
	ctlAuditPause      = 3 * time.Second
)

type ctlAuditCheck struct {
	kubectl kubectlFunc
	pause   time.Duration // between two attempts of step 4
}

func init() { RegisterCheck(ctlAuditCheck{kubectl: kube.Region.Run, pause: ctlAuditPause}) }

func (ctlAuditCheck) ID() string { return ctlAuditID }

// auditPage is what the check reads of GET /api/v1/sovereigns/{id}/audit/rbac.
type auditPage struct {
	Items []struct {
		ID            string `json:"id"`
		AuditType     string `json:"auditType"`
		UserAccessRef string `json:"userAccessRef"`
	} `json:"items"`
	Transport string `json:"transport"`
}

// grantEvent returns the identifier of the event of the grant, or "".
func (p auditPage) grantEvent(userAccess string) string {
	for _, it := range p.Items {
		if it.AuditType == ctlAuditGrantType && it.UserAccessRef == userAccess && it.ID != "" {
			return it.ID
		}
	}
	return ""
}

// has reports whether the page lists the event with this identifier.
func (p auditPage) has(id string) bool {
	for _, it := range p.Items {
		if it.ID == id {
			return true
		}
	}
	return false
}

// auditListing reads the newest 500 events of the listing. status is the HTTP
// status, or 0 when there was no answer.
func auditListing(ctx context.Context, c *api.Client, base string) (page auditPage, status int, err error) {
	res, err := c.Do(ctx, http.MethodGet, base+"/audit/rbac?limit=500", nil)
	if err != nil {
		return page, 0, err
	}
	if res.Status != http.StatusOK {
		return page, res.Status, fmt.Errorf("GET %s/audit/rbac: HTTP %d %s", base, res.Status, api.Snippet(res.Body))
	}
	return page, res.Status, res.JSON(&page)
}

// apiPods returns the pods of the API in one region: UID to name, and the
// names of the pods that are not Ready.
func (c ctlAuditCheck) apiPods(ctx context.Context, region kube.Region) (pods map[string]string, notReady []string, err error) {
	out, err := c.kubectl(region, ctx, nil, "get", "pods", "-n", ctlAuditNamespace, "-l", ctlAuditSelector, "-o", "json")
	if err != nil {
		return nil, nil, err
	}
	var list kube.List
	if err := json.Unmarshal(out, &list); err != nil {
		return nil, nil, fmt.Errorf("[%s] decode the pods of the API: %w", region.ID, err)
	}
	pods = map[string]string{}
	for _, p := range list.Items {
		name := p.Str("metadata", "name")
		pods[p.Str("metadata", "uid")] = name
		ready := false
		conditions, _ := p.Get("status", "conditions").([]any)
		for _, c := range conditions {
			if m, isMap := c.(map[string]any); isMap && m["type"] == "Ready" && m["status"] == "True" {
				ready = true
			}
		}
		if !ready || p.Str("metadata", "deletionTimestamp") != "" {
			notReady = append(notReady, name)
		}
	}
	sort.Strings(notReady)
	return pods, notReady, nil
}

// podNames returns the names of a pod map, sorted.
func podNames(pods map[string]string) []string {
	out := []string{}
	for _, name := range pods {
		out = append(out, name)
	}
	sort.Strings(out)
	return out
}

// restart replaces the pods of the API in every region that runs them. It
// returns an error unless every such region ends with pods that are all new
// and all Ready.
func (c ctlAuditCheck) restart(ctx context.Context, regions []kube.Region, ev Evidence) error {
	replaced := []string{}
	for _, region := range regions {
		before, _, err := c.apiPods(ctx, region)
		if err != nil {
			return err
		}
		if len(before) == 0 {
			continue // this region does not run the API
		}
		if _, err := c.kubectl(region, ctx, nil, "delete", "pod", "-n", ctlAuditNamespace, "-l", ctlAuditSelector,
			"--wait=true", "--timeout=5m"); err != nil {
			return err
		}
		if _, err := c.kubectl(region, ctx, nil, "rollout", "status", "deployment/"+ctlAuditDeployment,
			"-n", ctlAuditNamespace, "--timeout=10m"); err != nil {
			return err
		}
		after, notReady, err := c.apiPods(ctx, region)
		if err != nil {
			return err
		}
		replaced = append(replaced, fmt.Sprintf("%s: %s -> %s", region.ID,
			strings.Join(podNames(before), ","), strings.Join(podNames(after), ",")))
		ev["pods"] = replaced
		for uid, name := range after {
			if _, old := before[uid]; old {
				return fmt.Errorf("region %s: pod %s was not replaced", region.ID, name)
			}
		}
		if len(after) == 0 || len(notReady) > 0 {
			return fmt.Errorf("region %s: after the rollout %d pods of the API exist and these are not Ready: %s",
				region.ID, len(after), strings.Join(notReady, ","))
		}
	}
	if len(replaced) == 0 {
		return fmt.Errorf("no region runs a pod of Deployment %s/%s", ctlAuditNamespace, ctlAuditDeployment)
	}
	return nil
}

func (c ctlAuditCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
	if cc.API == nil || cc.Deploy == nil || cc.Deploy.ID == "" || len(cc.Regions) == 0 {
		return errors.New("the check needs a console session, the deployment identifier and one region")
	}
	base := "/api/v1/sovereigns/" + url.PathEscape(cc.Deploy.ID)
	subject := "ctl-g07-" + strings.ToLower(NewRunID(time.Now()))
	var grant, eventID string

	ok := checkStep(rec, ctlAuditID, 1, "a grant is made (POST /api/v1/sovereigns/{id}/rbac/assign)", func(ev Evidence) error {
		ev["subject"] = subject
		res, err := cc.API.Do(ctx, http.MethodPost, base+"/rbac/assign", map[string]any{
			"user":  map[string]string{"email": subject + "@gate.invalid", "keycloakSubject": subject},
			"tier":  "viewer",
			"scope": []map[string]string{{"key": ctlAuditScopeKey, "value": subject}},
		})
		if err != nil {
			return err
		}
		var out struct {
			Applied    string `json:"applied"`
			UserAccess struct {
				Name string `json:"name"`
			} `json:"userAccess"`
		}
		if res.Status == http.StatusCreated || res.Status == http.StatusOK {
			if err := res.JSON(&out); err != nil {
				return err
			}
		}
		ev["user_access"], ev["applied"] = out.UserAccess.Name, out.Applied
		if res.Status != http.StatusCreated || out.Applied != "created" || out.UserAccess.Name == "" {
			return fmt.Errorf("POST %s/rbac/assign: HTTP %d, applied %q, UserAccess %q; want 201, created and a name: %s",
				base, res.Status, out.Applied, out.UserAccess.Name, api.Snippet(res.Body))
		}
		grant = out.UserAccess.Name // only a grant this run created is removed in step 5
		return nil
	})
	ok = ok && checkStep(rec, ctlAuditID, 2, "the listing holds the event of the grant and names the stream as its transport (GET /api/v1/sovereigns/{id}/audit/rbac)", func(ev Evidence) error {
		page, _, err := auditListing(ctx, cc.API, base)
		if err != nil {
			return err
		}
		eventID = page.grantEvent(grant)
		ev["transport"], ev["event_id_before"] = page.Transport, eventID
		if eventID == "" {
			return fmt.Errorf("the listing holds no %s event of UserAccess %s with an id (%d items)", ctlAuditGrantType, grant, len(page.Items))
		}
		if page.Transport != ctlAuditTransport {
			return fmt.Errorf("the transport of the audit is %q, want %q: the events are not recorded on the stream", page.Transport, ctlAuditTransport)
		}
		return nil
	})
	ok = ok && checkStep(rec, ctlAuditID, 3, "the pods of Deployment "+ctlAuditNamespace+"/"+ctlAuditDeployment+" are deleted and replaced", func(ev Evidence) error {
		return c.restart(ctx, cc.Regions, ev)
	})
	if ok {
		checkStep(rec, ctlAuditID, 4, "the listing still holds the event after the restart", func(ev Evidence) error {
			var page auditPage
			for attempt := 1; ; attempt++ {
				var status int
				var err error
				page, status, err = auditListing(ctx, cc.API, base)
				ev["attempts"] = attempt
				if err == nil {
					break
				}
				again := status == 0 || status == http.StatusBadGateway || status == http.StatusServiceUnavailable || status == http.StatusGatewayTimeout
				if !again || attempt == ctlAuditAttempts {
					return err
				}
				timer := time.NewTimer(c.pause)
				select {
				case <-timer.C:
				case <-ctx.Done():
					timer.Stop()
					return ctx.Err()
				}
			}
			ev["transport"], ev["event_id_after"] = page.Transport, ""
			if page.has(eventID) {
				ev["event_id_after"] = eventID
			} else {
				return fmt.Errorf("event %s was listed before the restart and is not listed after it (%d items, transport %q)",
					eventID, len(page.Items), page.Transport)
			}
			return nil
		})
	}
	if grant != "" {
		checkStep(rec, ctlAuditID, 5, "the grant is removed (DELETE /api/v1/deployments/{id}/admin/user-access/{name})", func(ev Evidence) error {
			cleanup, cancel := context.WithTimeout(context.WithoutCancel(ctx), time.Minute)
			defer cancel()
			path := "/api/v1/deployments/" + url.PathEscape(cc.Deploy.ID) + "/admin/user-access/" + url.PathEscape(grant)
			res, err := cc.API.Do(cleanup, http.MethodDelete, path, nil)
			if err != nil {
				return err
			}
			ev["user_access"] = grant
			if res.Status != http.StatusNoContent {
				return fmt.Errorf("DELETE %s: HTTP %d %s; the UserAccess %s may be left behind", path, res.Status, api.Snippet(res.Body), grant)
			}
			return nil
		})
	}
	return nil
}

		answer(http.StatusCreated, map[string]any{"applied": "created", "userAccess": map[string]string{"name": "rbac-x"}})
	case r.Method == http.MethodGet && strings.HasSuffix(r.URL.Path, "/sovereigns/dep/audit/rbac"):
		if w.closed > 0 || w.deleted {
			w.closed = max(w.closed-1, 0)
			answer(http.StatusServiceUnavailable, map[string]string{"error": "no healthy upstream"})
			return
		}
		transport := "jetstream:CATALYST_ORG"
		if w.fault == "in-process" {
			transport = "in-process"
		}
		items := []map[string]string{{"id": "", "auditType": "rbac-grant-created", "userAccessRef": "rbac-other"}}
		answer(http.StatusOK, map[string]any{"items": append(items, w.ring...), "transport": transport})
	case r.Method == http.MethodDelete && strings.HasSuffix(r.URL.Path, "/deployments/dep/admin/user-access/rbac-x"):
		w.calls = append(w.calls, "DELETE")
		if w.fault == "kept" {
			answer(http.StatusInternalServerError, map[string]string{"error": "delete-failed"})
			return
		}
		rw.WriteHeader(http.StatusNoContent)
	default:
		answer(http.StatusNotFound, map[string]string{"error": "no such route: " + r.Method + " " + r.URL.Path})
	}
}

// kubectl answers for the cluster. Only region-a runs the API.
func (w *auditWorld) kubectl(r kube.Region, _ context.Context, _ io.Reader, args ...string) ([]byte, error) {
	w.Lock()
	defer w.Unlock()
	if !slices.Contains(args, "catalyst-system") {
		return nil, fmt.Errorf("unexpected kubectl %v", args)
	}
	runs := r.ID == "region-a" && w.fault != "nowhere"
	switch args[0] + " " + args[1] {
	case "get pods":
		if !slices.Contains(args, "app.kubernetes.io/name=catalyst-api") {
			return nil, fmt.Errorf("unexpected kubectl %v", args)
		}
		if !runs || w.deleted {
			return []byte(kubeList()), nil
		}
		ready := "True"
		if w.fault == "not-ready" && w.generation > 0 {
			ready = "False"
		}
		name := fmt.Sprintf("api-%d", w.generation)
		return []byte(kubeList(obj{"metadata": obj{"name": name, "uid": "uid-" + name},
			"status": obj{"conditions": kubeConditions("PodScheduled", "True", "Ready", ready)}})), nil
	case "delete pod":
		w.calls = append(w.calls, "kubectl delete")
		if !runs || !slices.Contains(args, "app.kubernetes.io/name=catalyst-api") || !slices.Contains(args, "--wait=true") {
			return nil, fmt.Errorf("unexpected kubectl %v", args)
		}
		if w.fault == "survives" {
			return []byte("pod deleted"), nil // the same pod is still there
		}
		w.deleted = true
		return []byte("pod deleted"), nil
	case "rollout status":
		w.calls = append(w.calls, "kubectl rollout")
		if !runs || !slices.Contains(args, "deployment/catalyst-api") {
			return nil, fmt.Errorf("unexpected kubectl %v", args)
		}
		if w.fault == "stuck" {
			return nil, errors.New("error: timed out waiting for the condition")
		}
		if w.deleted { // the new pod starts: its ring holds what the stream holds
			w.deleted = false
			w.generation++
			w.ring = append([]map[string]string(nil), w.stream...)
			switch w.fault {
			case "slow-gateway":
				w.closed = 2
			case "gateway-down":
				w.closed = 1000
			}
		}
		return []byte("deployment successfully rolled out"), nil
	}
	return nil, fmt.Errorf("unexpected kubectl %v", args)
}

// auditRun runs the check against a world the way the runner does and returns

}

func TestAuditSurvivesRestartCheck(t *testing.T) {
	const all = "POST,kubectl delete,kubectl rollout,DELETE"
	for fault, want := range map[string]struct{ reason, calls string }{
		"":             {"", all}, // the event is on the stream and is listed again
		"slow-gateway": {"", all}, // two 503 answers after the restart, then the listing

		"in-process":   {`the transport of the audit is "in-process"`, "POST,DELETE"},
		"no-id":        {"holds no rbac-grant-created event of UserAccess rbac-x with an id", "POST,DELETE"},

		"survives":     {"pod api-0 was not replaced", all},
		"stuck":        {"timed out waiting for the condition", all},
		"not-ready":    {"these are not Ready: api-1", all},
		"gateway-down": {"HTTP 503", all},
		"kept":         {"the UserAccess rbac-x may be left behind", all},
	} {

			w := &auditWorld{fault: fault}

			if (want.reason == "") != (res.Status == Pass) || !strings.Contains(res.Reason, want.reason) {
				t.Fatalf("status %s, reason %q; want a reason that holds %q (empty: PASS)", res.Status, res.Reason, want.reason)
			}
			if got := strings.Join(w.calls, ","); got != want.calls {
				t.Errorf("the check wrote %q, want %q", got, want.calls)
			}
			if res.Status != Pass {
				return
			}
			last := steps[len(steps)-2] // step 4; step 5 is the clean-up
			if last.ID != "CTL-G07.4" || last.Evidence["event_id_after"] != "01JCDZ8A0000000000000000AB" {
				t.Errorf("step %s has evidence %v", last.ID, last.Evidence)
			}
			if attempts := map[string]int{"": 1, "slow-gateway": 3}[fault]; last.Evidence["attempts"] != attempts {
				t.Errorf("step 4 asked %v times, want %d", last.Evidence["attempts"], attempts)
			}
			if steps[1].Evidence["event_id_before"] != "01JCDZ8A0000000000000000AB" || steps[1].Evidence["transport"] != "jetstream:CATALYST_ORG" {
				t.Errorf("step 2 has evidence %v", steps[1].Evidence)
			}
			if pods := fmt.Sprint(steps[2].Evidence["pods"]); pods != "[region-a: api-0 -> api-1]" {
				t.Errorf("step 3 has pods %s", pods)
			}
		})
	}
}
