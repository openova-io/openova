# INF-130 — Kinds ScanPolicy, HardeningBaseline, MachineRun; operations controller

## In plain words

**The problem today.** The machine plane can list machines and has an image that can scan one, but nothing starts a scan. Nothing decides when a scan runs or on which machines, and nothing reads its result: it would stay in a bucket where the platform does not look.

**What changes.** A scan policy says which machines are scanned, with which profiles and on which schedule. A controller creates a run at each scheduled time, scans every selected node with one runner Job, and writes what it found where the platform reads it.

**Done means:**

- A scan policy, a hardening baseline and a run are objects the platform accepts, with exactly the fields this version reads.
- At each time of a policy schedule one run is created, and the controller waits for that exact time instead of waking on a fixed period.
- Every selected node that is active and not quarantined gets one runner Job, and never more Jobs run at once than the policy allows.
- A Job that ends without a result is recorded as failed, and a result that does not say it completed writes no report.
- A completed hardening scan writes one report per machine, with the worst results first, and a machine without a profile is reported as skipped, never as passing.
- A completed inventory scan records on the Machine where its bill of materials is stored.
- A finished run is deleted when its retention time has passed.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The Blueprint `bp-machine-operations` defines three more kinds of the group `machines.openova.io`: `ScanPolicy`, `HardeningBaseline` and `MachineRun`, and `Machine` gains `status.sbom`. The binary `machine-controller` accepts `--controllers=operations`. That controller has two parts. The scheduler creates one `MachineRun` at each time of a `ScanPolicy`'s cron schedule and asks to be woken exactly at the next time. The run reconciler writes the targets of a run once, starts one node-mode Job of the image `machine-runner` per target (never more at once than `spec.maxParallel`, each target of a scheduled run at its own stable offset inside `spec.jitter`), reads the result document of every container of a finished Job, writes the hardening `PolicyReport` and `Machine.status.sbom`, sets the phase of the run, and deletes the run when it has been finished for the retention time. No chart template runs the controller yet: package INF-132 adds its Deployment and its access rules.

## 3. The model (the law)
1. **Four definitions change, and no other.** The files are in `platform/machine-operations/chart/crds/`. Every schema is closed: a field that is not listed is dropped. A definition holds only the fields that code of this ticket reads or writes. A field that a later package reads is absent; that package adds it with its reader.
   - `scanpolicies.yaml`, kind `ScanPolicy`, namespaced, with a status subresource. `spec`: `suspended` (boolean, default `false`); `namespaces` (list of namespace names, default empty); `machineSelector` (required; a label selector with `matchLabels` and `matchExpressions`); `profiles` (required, at least one, each `inventory` or `hardening`); `hardeningBaselineRef.name` (required when `profiles` contains `hardening`; a validation rule of the definition says so); `schedule` (string, default empty; a five-field cron expression in UTC); `jitter` (a duration of the form `2h`, `90m`, `30s`, default `1h`); `maxParallel` (1 to 50, default 5). `status`: `lastRunName`, `nextScheduleAt`, `conditions` (one type, `Ready`).
   - `hardeningbaselines.yaml`, kind `HardeningBaseline`, namespaced, no status. `spec`: `content.source` (the one value `complianceascode`) and `content.release` (such as `0.1.82`), both required; `profiles` (required, at least one; each has `osFamily`, `osVersion` and `profileId`; two entries may not name the same family and version); `tailoring.disabledRules` (rule identifiers, default empty).
   - `machineruns.yaml`, kind `MachineRun`, namespaced, with a status subresource. `spec` is immutable: `kind` (the one value `scan`); `policyRef.kind` (the one value `ScanPolicy`) and `policyRef.name`; `targets` (at most 1000 strings `<namespace>/<name>`, default empty, which means every machine the policy selects); `requestedBy` (required: an e-mail address, or `controller`); `reason`. `status`: `phase` (`Pending`, `Running`, `Succeeded`, `PartiallyFailed`, `Failed`), `startedAt`, `finishedAt`, `counts` (outcome to number of targets), `targets` (per target: `machine`, `outcome`, `message`, `jobName`, `startedAt`, `finishedAt`, `evidence`, `reportName`).
   - `machines.yaml` gains `status.sbom` with `key`, `sha256` and `collectedAt`, all required.
2. **The Go form.** `internal/machines/apis/v1alpha1/scan_types.go` holds the structs of the three kinds, their converters from and to `unstructured.Unstructured`, and the type `SBOM`; `types.go` gains the field `Sbom` of `MachineStatus`. A field exists in Go only when it exists in the definition, and the other way round. The controllers work on unstructured objects. No deep-copy generator is added.
3. **The scheduler** (`internal/machines/operations/scheduler.go`, one reconcile per `ScanPolicy`). A policy is checked first: `maxParallel` at least 1, `jitter` a duration, a valid selector, `hardeningBaselineRef` present when `profiles` contains `hardening`, `schedule` a cron expression, and `namespaces` set only on a policy in the namespace `catalyst-infra`. Then:
   - an invalid policy gets the condition `Ready` `False` with the reason `InvalidSpec`; a suspended one `False` with `Suspended`; one with an empty schedule `True` with `NoSchedule`. In all three `status.nextScheduleAt` is removed, no run is created and no wake-up is asked for;
   - a new policy, or one whose spec changed since `Ready` was written (the condition's `observedGeneration` differs from the generation), gets `status.nextScheduleAt` set to the first time of the schedule after now. No run is created for a time of the old schedule;
   - when now is before `status.nextScheduleAt`, the reconcile changes nothing and asks to be woken after exactly the remaining time;
   - when that time has come, it creates the run of that time, writes its name to `status.lastRunName`, and sets `status.nextScheduleAt` to the first time of the schedule after now. Times that passed while the controller did not run are not caught up: one run is created, for the stored time.
   Every wake-up is `ctrl.Result{RequeueAfter: <next time minus now>}`. There is no ticker, no sleep and no loop with a fixed period.
4. **The cron expression** (`cron.go`). Five fields, read in UTC: minute, hour, day of the month, month, day of the week (0 to 7; 0 and 7 are Sunday). A field is `*`, a number, a range `a-b`, a step `*/n` or `a-b/n`, or a comma-separated list of those; `a/n` runs from `a` to the end of the field. When both day fields are restricted, a day that matches either one matches. A schedule with no time in the next five years is `InvalidSpec`.
5. **The run of a scheduled time.** Its name is `<policy name>-<ULID in lower case>`. The first 48 bits of the ULID are the scheduled time in milliseconds; the other 80 bits are the first ten bytes of the SHA-256 of `<policy UID>/<scheduled time, RFC 3339, UTC>`. So one policy and one time always give the same name, and creating a run that exists is not an error: a scheduled time never gets two runs. The run is in the namespace of the policy, with `spec.kind: scan`, `spec.policyRef` naming the policy, `spec.requestedBy: controller`, `spec.reason: schedule <expression>`, no `spec.targets`, and the annotation `machines.openova.io/scheduled-for` with the scheduled time (RFC 3339, UTC).
6. **The targets of a run are written once**, at its first reconcile, into `status.targets`, with `status.startedAt`. A Machine is a target when it is in a namespace of the policy (the policy's own namespace, or `spec.namespaces`), matches `spec.machineSelector`, has `spec.class` `node`, has `status.phase` `Active`, and does not carry the condition `Quarantined` with status `True`. That condition is read from the object as it is; this ticket adds no field for it. With an empty `spec.targets` the targets are all such Machines, sorted by `<namespace>/<name>`. With `spec.targets` given, every name must be such a Machine.
7. **A run outside its policy starts nothing.** The run is outside its policy when its kind does not fit the kind of the policy, when the policy does not exist, is invalid or is suspended, or when a name in `spec.targets` is not a target by item 6. Then every name of `spec.targets` is written with outcome `Refused` (message `outside-policy` for a name that is not a target, or for every name when the policy itself is the reason; `not-started` for the others), the phase is `Failed`, and no Job is created. A policy that becomes absent, invalid or suspended while a run is open refuses the targets that have not started with `outside-policy`; Jobs that already run are still read.
8. **When a target starts.** A run without the annotation of item 5 starts its targets at once. A scheduled run starts each target at the scheduled time plus its offset: the first eight bytes of the SHA-256 of `<namespace>/<name>` of the Machine, as a number, modulo the jitter in seconds. Targets start in the order of that time, and at most `spec.maxParallel` Jobs of one run are unfinished at a time. While a target waits for its time, the reconcile asks to be woken exactly then.
9. **Starting a target.** The Machine is read again. One that is gone, not `Active`, not of class `node` or quarantined gets outcome `Refused`, message `not-eligible`, and no Job. A policy whose profiles contain `hardening` and whose baseline does not exist gives `Refused`, message `baseline-not-found`, and no Job. Otherwise the Job gets one container per profile, in the order `inventory`, `hardening`. The hardening container is added only when an entry of the baseline's `profiles` equals the Machine's `status.os.family` and `status.os.version`; there is no nearest-version match. When no entry does, the controller writes the hardening report with the one result `skip` (item 13) and the target message `hardening: no-profile-for-release`. A target that needs no container at all finishes at once with outcome `Succeeded`.
10. **The Job** (`job.go`), one per run and target, in the controller's own namespace (flag `--job-namespace`). Its name is `mr-` and the first 16 hex digits of the SHA-256 of `<run namespace>/<run name>/<machine namespace>/<machine name>`, so a target never gets two Jobs. Annotations `machines.openova.io/run` and `machines.openova.io/machine` name the run and the Machine as `<namespace>/<name>`; the labels are `app.kubernetes.io/name: machine-runner` and `machines.openova.io/mode: node`. `backoffLimit: 0`, `activeDeadlineSeconds: 3600`, `ttlSecondsAfterFinished: 86400`. The pod: service account `mr-node` with no token of the Kubernetes API mounted; `nodeName` is the Machine's `spec.externalId` (the Node name); it tolerates every taint; restart policy `Never`; no host network and no host process namespace. Each container: the runner image (flag `--runner-image`), named after its task, user 0, read-only root file system, no privilege escalation, not privileged. Mounts of each container: the Node's `/` read-only at `/host`; a memory `emptyDir` of its own at `/run/machine-runner`; the CSI volume of driver `secrets-store.csi.k8s.io` with `secretProviderClass: evidence-store`, read-only, at `/var/run/secrets/evidence-store`. The Job creates and changes no object.
11. **The arguments of a container** are those the runner reads: `--task=<inventory|hardening> --mode=node --machine=<namespace>/<name> --run=<namespace>/<name> --os-family=<status.os.family> --os-version=<status.os.version> --evidence-endpoint --evidence-region --evidence-bucket` (the controller's own three flags) `--evidence-prefix=<machine namespace>/<machine name>/<run name>/`, then `--address=<status.primaryAddress>` when it is not empty, and for `hardening` also `--profile-id`, `--content-release` (the baseline's `content.release`) and, when the baseline disables rules, `--disabled-rules` (comma-separated). A test passes every argument list to the runner's own `ParseArgs`.
12. **Reading a finished Job** (`runs.go`). A Job has ended when it carries the condition `Complete` or `Failed` with status `True`. The controller reads the Job and its Pods (label `batch.kubernetes.io/job-name`) from the API server, not from a cache, and takes the termination message of each container.
    - A container without a parsable result document is outcome `Failed`, message `no-result`. A Job that is gone is `Failed`, `no-result`.
    - A document that says `Succeeded` without `completed: true` is `Incomplete`, message `completion-marker-missing`. Nothing is written for it.
    - When the Job failed with the reason `DeadlineExceeded`, a container that did not succeed is `Timeout`, message `deadline-exceeded`.
    - A successful `inventory` document must name an evidence entry of kind `sbom`; without one it is `Failed`, `no-sbom-in-result`. With one, `Machine.status.sbom` is set (item 14).
    - A successful `hardening` document must name an evidence entry of kind `hardening-results`; without one it is `Failed`, `no-results-file-in-result`. The controller fetches that file from the evidence bucket. A file that cannot be fetched is an error and is tried again. A file whose SHA-256 differs from the entry, or that is not the schema `openova.io/machine-hardening-results/v1`, gives `Failed`, `results-file-invalid`, and the report stays as it was. Otherwise the report is written (item 13).
    - The outcome of the target is `Succeeded` when every container succeeded; otherwise the outcome of the first container, in the order of item 9, that did not. Its message joins `<task>: <message>` of every container that has a message, with `; `, as one line of at most 1024 characters. `evidence` holds the object keys of the successful containers. `reportName` names the report the target wrote.
13. **The hardening report** (`report.go`): kind `PolicyReport` of `wgpolicyk8s.io/v1alpha2`, named `machine-<machine name>-hardening`, in the namespace of the Machine, with an owner reference and `scope` naming the Machine, and the labels `machines.openova.io/machine: <name>` and `machines.openova.io/report: hardening`. One result per rule of the results file: `source: machine-hardening`, `policy` the profile identifier, `rule` the rule identifier, `timestamp`, and the properties `runName`, `contentRelease` and `evidenceKey` (the key of the results file). The XCCDF results map to `fail` (fail), `error` (error, unknown), `pass` (pass, fixed) and `skip` (everything else, such as notapplicable). Results are sorted worst first (fail, error, skip, pass; then by rule identifier) and cut at 200; a cut report carries the annotation `machines.openova.io/results-truncated: "true"`. `summary` counts every rule, also those cut. A results file with no rule gives the one result `skip` with the rule `no-profile-for-release`: a machine without a profile is never reported as `pass`. The report the controller writes itself for such a machine (item 9) has the `policy` `hardening` and no `evidenceKey`. An existing report of the same name is replaced.
14. **`Machine.status.sbom`** is set with a merge patch of the status subresource: `key` and `sha256` of the evidence entry, `collectedAt` the time the container finished. The inventory controller stays the only writer of every other field of a Machine.
15. **The phase of a run.** `Pending` while no target has started or finished; `Running` after that, while one is unfinished; when every target has an outcome: `Succeeded` when none failed (also with no target), `Failed` when none succeeded, `PartiallyFailed` otherwise, with `status.counts` and `status.finishedAt`. `Succeeded` and `NoChange` are the outcomes that count as success. A run with a final phase is deleted when `status.finishedAt` plus the retention (flag `--runs-retention`, default `720h`) has passed; until then the reconcile asks to be woken exactly at that time.
16. **The evidence bucket is read with the mounted binding** (`evidence.go`): the files `access-key-id`, `secret-access-key` and, when present, `ca.crt` in `/var/run/secrets/evidence-store`, read on every call; HTTPS with certificate validation, through the library `github.com/minio/minio-go/v7` that the module already requires; one read takes at most one minute and at most 16 MiB. No Kubernetes Secret is read or created.
17. **The command** (`cmd/machine-controller/main.go`). `--controllers` accepts `inventory`, `operations` or both. With `operations` the flags `--job-namespace`, `--runner-image`, `--evidence-endpoint` (must start with `https://`), `--evidence-region` and `--evidence-bucket` are required and `--runs-retention` must be above zero; the command stops with an error before it contacts a cluster when one is missing. The leader-election Lease is `machine-controller-operations` when only `operations` runs. The Job watch is held to the Job namespace, because the controller may read Jobs only there.
18. **Guards.** The two files that write to the cluster get one allow entry each in `scripts/baselines/direct-cluster-writes.json` (owner `INF`; `runs.go` 6 writes, `scheduler.go` 2 writes): they write operation records and observations, never intent. `scripts/baselines/polling.json` is not changed: the new code holds no ticker and no sleep.
19. **Not in this ticket.** No chart template, no access rule and no value: the controller is not deployed (INF-132). No profile `vulnerability` and no kind `rematch` (INF-140). No trigger, no SSH target and no run of another kind (INF-420, INF-430, INF-450). No route (INF-455). No event subject. A set of more than 1000 selected machines is not split into several runs: this version targets Nodes only.

package v1alpha1

import (
	metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"
	"k8s.io/apimachinery/pkg/apis/meta/v1/unstructured"
)

// The kinds of the operations controller.
var (
	ScanPolicyKind        = GroupVersion.WithKind("ScanPolicy")
	HardeningBaselineKind = GroupVersion.WithKind("HardeningBaseline")
	MachineRunKind        = GroupVersion.WithKind("MachineRun")
)

// Profiles of a ScanPolicy.
const (
	ProfileInventory = "inventory"
	ProfileHardening = "hardening"
)

// RunKindScan is the one kind of MachineRun of this version. RequestedByController is
// spec.requestedBy of a run the operations controller created.
const (
	RunKindScan           = "scan"
	RequestedByController = "controller"
)

// Phases of a MachineRun. The last three are final.
const (
	RunPending         = "Pending"
	RunRunning         = "Running"
	RunSucceeded       = "Succeeded"
	RunPartiallyFailed = "PartiallyFailed"
	RunFailed          = "Failed"
)

// Defaults of ScanPolicy.spec.
const (
	DefaultJitter      = "1h"
	DefaultMaxParallel = 5
)

// AnnotationScheduledFor is set on a MachineRun that the schedule of its policy created.
// Its value is the scheduled time (RFC 3339, UTC); each target starts at its own offset
// inside spec.jitter after that time. A run without it starts its targets at once.
const AnnotationScheduledFor = "machines.openova.io/scheduled-for"

// SBOM names the newest complete bill of materials of a Machine: Machine.status.sbom.
type SBOM struct {
	Key         string      `json:"key"`
	SHA256      string      `json:"sha256"`
	CollectedAt metav1.Time `json:"collectedAt"`
}

// LocalRef names an object in the namespace of the object that holds the reference.
type LocalRef struct {
	Name string `json:"name"`
}

// ScanPolicy says which machines are scanned, with which profiles and when.
type ScanPolicy struct {
	metav1.TypeMeta   `json:",inline"`
	metav1.ObjectMeta `json:"metadata,omitempty"`
	Spec              ScanPolicySpec   `json:"spec"`
	Status            ScanPolicyStatus `json:"status,omitempty"`
}

// ScanPolicySpec is the desired state of a ScanPolicy. An empty Jitter and a nil
// MaxParallel take the default of the definition.
type ScanPolicySpec struct {
	Suspended            bool                 `json:"suspended,omitempty"`
	Namespaces           []string             `json:"namespaces,omitempty"`
	MachineSelector      metav1.LabelSelector `json:"machineSelector"`
	Profiles             []string             `json:"profiles"`
	HardeningBaselineRef *LocalRef            `json:"hardeningBaselineRef,omitempty"`
	Schedule             string               `json:"schedule,omitempty"`
	Jitter               string               `json:"jitter,omitempty"`
	MaxParallel          *int32               `json:"maxParallel,omitempty"`
}

// ScanPolicyStatus is what the scheduler last did.
type ScanPolicyStatus struct {
	LastRunName    string             `json:"lastRunName,omitempty"`
	NextScheduleAt *metav1.Time       `json:"nextScheduleAt,omitempty"`
	Conditions     []metav1.Condition `json:"conditions,omitempty"`
}

// HardeningBaseline names the hardening content and the profile per release.
type HardeningBaseline struct {
	metav1.TypeMeta   `json:",inline"`
	metav1.ObjectMeta `json:"metadata,omitempty"`
	Spec              HardeningBaselineSpec `json:"spec"`
}

// HardeningBaselineSpec is the desired state of a HardeningBaseline.
type HardeningBaselineSpec struct {
	Content   HardeningContent   `json:"content"`
	Profiles  []HardeningProfile `json:"profiles"`
	Tailoring *Tailoring         `json:"tailoring,omitempty"`
}

// HardeningContent names the content and its release.
type HardeningContent struct {
	Source  string `json:"source"`
	Release string `json:"release"`
}

// HardeningProfile is the profile of one operating-system release.
type HardeningProfile struct {

// Package operations holds the operations controller of the machine plane: a scheduler
// that creates one MachineRun for every time of a ScanPolicy's schedule, and a run
// reconciler that starts one runner Job per target, reads each Job's result document,
// writes the hardening report and the bill-of-materials reference of the Machine, and
// deletes a finished run when its retention time has passed.
//
// Nothing in this package waits in a loop with a fixed period. A reconcile that must
// happen later asks for it at the exact time, with ctrl.Result.RequeueAfter.
package operations

import (
	"fmt"
	"strconv"
	"strings"
	"time"
)

// Schedule is a five-field cron expression, read in UTC: minute (0-59), hour (0-23),
// day of the month (1-31), month (1-12) and day of the week (0-7, 0 and 7 are Sunday).
// A field is *, a number, a range a-b, a step */n or a-b/n, or a comma-separated list
// of those. When both day fields are restricted, a day that matches either one matches.
type Schedule struct {
	minute, hour, dom, month, dow uint64
	domAny, dowAny                bool
}

var cronFields = []struct {
	name        string
	least, most int
}{{"minute", 0, 59}, {"hour", 0, 23}, {"day of the month", 1, 31}, {"month", 1, 12}, {"day of the week", 0, 7}}

// ParseSchedule reads a five-field cron expression.
func ParseSchedule(expr string) (Schedule, error) {
	fields := strings.Fields(expr)
	if len(fields) != len(cronFields) {
		return Schedule{}, fmt.Errorf("schedule %q must have five fields", expr)
	}
	var bits [5]uint64
	for i, field := range fields {
		f := cronFields[i]
		for _, part := range strings.Split(field, ",") {
			b, err := cronPart(part, f.least, f.most)
			if err != nil {
				return Schedule{}, fmt.Errorf("schedule %q, field %s: %w", expr, f.name, err)
			}
			bits[i] |= b
		}
	}
	if bits[4]&(1<<7) != 0 {
		bits[4] |= 1
	}
	return Schedule{minute: bits[0], hour: bits[1], dom: bits[2], month: bits[3], dow: bits[4],
		domAny: fields[2] == "*", dowAny: fields[4] == "*"}, nil
}

// cronPart reads one list item of a field and returns its values as a bit set.
func cronPart(part string, least, most int) (uint64, error) {
	span, stepText, hasStep := strings.Cut(part, "/")
	step := 1
	if hasStep {
		n, err := strconv.Atoi(stepText)
		if err != nil || n < 1 {
			return 0, fmt.Errorf("%q has no valid step", part)
		}
		step = n
	}
	lo, hi := least, most
	if span != "*" {
		from, to, isRange := strings.Cut(span, "-")
		a, err := strconv.Atoi(from)
		if err != nil {
			return 0, fmt.Errorf("%q is not a number", from)
		}
		lo, hi = a, a
		if isRange {
			if hi, err = strconv.Atoi(to); err != nil {
				return 0, fmt.Errorf("%q is not a number", to)
			}
		} else if hasStep {
			hi = most
		}
	}
	if lo < least || hi > most || lo > hi {
		return 0, fmt.Errorf("%q is outside %d-%d", part, least, most)
	}
	var out uint64
	for v := lo; v <= hi; v += step {
		out |= 1 << uint(v) // #nosec G115 -- v is between 0 and 59
	}
	return out, nil
}

func has(set uint64, v int) bool { return set&(1<<uint(v)) != 0 } // #nosec G115 -- v is between 0 and 59

// Next returns the first time of the schedule that is after t, in UTC with zero seconds.
// It returns the zero time when the schedule has no time within five years of t.
func (s Schedule) Next(t time.Time) time.Time {
	t = t.UTC().Truncate(time.Minute).Add(time.Minute)
	for limit := t.AddDate(5, 0, 0); t.Before(limit); {
		switch {
		case !has(s.month, int(t.Month())):
			t = time.Date(t.Year(), t.Month()+1, 1, 0, 0, 0, 0, time.UTC)
		case !s.dayMatches(t):
			t = time.Date(t.Year(), t.Month(), t.Day()+1, 0, 0, 0, 0, time.UTC)
		case !has(s.hour, t.Hour()):
			t = t.Truncate(time.Hour).Add(time.Hour)
		case !has(s.minute, t.Minute()):
			t = t.Add(time.Minute)
		default:
			return t
		}
	}
	return time.Time{}
}

func (s Schedule) dayMatches(t time.Time) bool {
	dom, dow := has(s.dom, t.Day()), has(s.dow, int(t.Weekday()))
	if s.domAny || s.dowAny {
		return (s.domAny || dom) && (s.dowAny || dow)
	}
	return dom || dow
}

// PlatformNamespace is the one namespace in which a policy may select the Machines of
// other namespaces with spec.namespaces.
const PlatformNamespace = "catalyst-infra"

// ConditionReady is the condition of a ScanPolicy. Its reasons follow.
const (
	ConditionReady    = "Ready"
	ReasonScheduled   = "Scheduled"
	ReasonNoSchedule  = "NoSchedule"
	ReasonSuspended   = "Suspended"
	ReasonInvalidSpec = "InvalidSpec"
)

// Scheduler creates one MachineRun for every time of a ScanPolicy's schedule. It keeps
// the next time in status.nextScheduleAt and asks to be woken exactly then.
type Scheduler struct {
	Client client.Client
	Now    func() time.Time
}

// SetupWithManager registers the controller: one reconcile when a ScanPolicy is created
// or its spec changes, and one at each time the reconcile asked for.
func (s *Scheduler) SetupWithManager(mgr ctrl.Manager) error {
	return ctrl.NewControllerManagedBy(mgr).
		Named("scan-schedule").
		For(newObject(v1alpha1.ScanPolicyKind), builder.WithPredicates(predicate.GenerationChangedPredicate{})).
		Complete(s)
}

// PolicyPlan is a ScanPolicy read into the form the controllers work with.
type PolicyPlan struct {
	Schedule    *Schedule // nil when spec.schedule is empty
	Jitter      time.Duration
	MaxParallel int
	Namespaces  []string
}

// PlanOf checks a ScanPolicy and reads its schedule, jitter, parallelism and namespaces.
func PlanOf(p *v1alpha1.ScanPolicy) (PolicyPlan, error) {
	plan := PolicyPlan{MaxParallel: v1alpha1.DefaultMaxParallel, Namespaces: []string{p.Namespace}}
	if p.Spec.MaxParallel != nil {
		plan.MaxParallel = int(*p.Spec.MaxParallel)
	}
	if plan.MaxParallel < 1 {
		return plan, fmt.Errorf("spec.maxParallel must be at least 1")
	}
	jitter := p.Spec.Jitter
	if jitter == "" {
		jitter = v1alpha1.DefaultJitter
	}
	var err error
	if plan.Jitter, err = time.ParseDuration(jitter); err != nil || plan.Jitter < 0 {
		return plan, fmt.Errorf("spec.jitter %q is not a duration", p.Spec.Jitter)
	}
	if len(p.Spec.Namespaces) > 0 {
		if p.Namespace != PlatformNamespace {
			return plan, fmt.Errorf("spec.namespaces is honoured only on a policy in the namespace %s", PlatformNamespace)
		}
		plan.Namespaces = p.Spec.Namespaces
	}
	if _, err := metav1.LabelSelectorAsSelector(&p.Spec.MachineSelector); err != nil {
		return plan, fmt.Errorf("spec.machineSelector: %w", err)
	}
	for _, profile := range p.Spec.Profiles {
		if profile == v1alpha1.ProfileHardening && p.Spec.HardeningBaselineRef == nil {
			return plan, fmt.Errorf("spec.hardeningBaselineRef is required when spec.profiles contains hardening")
		}
	}
	if strings.TrimSpace(p.Spec.Schedule) != "" {
		sched, err := ParseSchedule(p.Spec.Schedule)
		if err != nil {
			return plan, err
		}
		plan.Schedule = &sched
	}
	return plan, nil
}

// Reconcile creates the run of a scheduled time that has come and sets the next one.
func (s *Scheduler) Reconcile(ctx context.Context, req ctrl.Request) (ctrl.Result, error) {
	u := newObject(v1alpha1.ScanPolicyKind)
	if err := s.Client.Get(ctx, req.NamespacedName, u); err != nil {
		return ctrl.Result{}, client.IgnoreNotFound(err)
	}
	p, err := v1alpha1.ScanPolicyFromUnstructured(u)
	if err != nil {
		return ctrl.Result{}, err
	}
	before := p.Status
	before.Conditions = append([]metav1.Condition(nil), p.Status.Conditions...)
	plan, err := PlanOf(p)
	switch {
	case err != nil:
		return ctrl.Result{}, s.write(ctx, p, before, nil, false, ReasonInvalidSpec, err.Error())
	case p.Spec.Suspended:
		return ctrl.Result{}, s.write(ctx, p, before, nil, false, ReasonSuspended, "spec.suspended is true: no run is created")
	case plan.Schedule == nil:
		return ctrl.Result{}, s.write(ctx, p, before, nil, true, ReasonNoSchedule, "spec.schedule is empty: no run is created from a schedule")
	}
	now := s.now()
	at := metav1.NewTime(plan.Schedule.Next(now))
	if at.IsZero() {
		return ctrl.Result{}, s.write(ctx, p, before, nil, false, ReasonInvalidSpec, fmt.Sprintf("schedule %q has no time in the next five years", p.Spec.Schedule))
	}
	next := p.Status.NextScheduleAt
	ready := meta.FindStatusCondition(p.Status.Conditions, ConditionReady)
	switch {
	case next == nil || ready == nil || ready.ObservedGeneration != p.Generation:
		// A new policy or a changed spec: the first run is at the next time of the schedule.
	case now.Before(next.Time):
		return ctrl.Result{RequeueAfter: next.Sub(now)}, nil
	default:
		name, err := s.createRun(ctx, p, next.Time)
		if err != nil {
			return ctrl.Result{}, err
		}
		p.Status.LastRunName = name
	}
	if err := s.write(ctx, p, before, &at, true, ReasonScheduled, "the next run is created at status.nextScheduleAt"); err != nil {
		return ctrl.Result{}, err
	}
	return ctrl.Result{RequeueAfter: at.Sub(now)}, nil
}

func (s *Scheduler) now() time.Time {
	if s.Now != nil {
		return s.Now()
	}
	return time.Now()
}

// RunName is the name of the run of one scheduled time: the policy name, a dash and a
// ULID in lower case whose time part is the scheduled time and whose other 80 bits come
// from the policy's identifier and that time. The same policy and time give the same
// name, so a time is never run twice.
func RunName(policy, uid string, slot time.Time) string {
	const alphabet = "0123456789abcdefghjkmnpqrstvwxyz"
	sum := sha256.Sum256([]byte(uid + "/" + slot.UTC().Format(time.RFC3339)))
	var b [16]byte
	binary.BigEndian.PutUint64(b[:8], uint64(slot.UnixMilli())<<16) // #nosec G115 -- times after 1970
	copy(b[6:], sum[:10])
	hi, lo := binary.BigEndian.Uint64(b[:8]), binary.BigEndian.Uint64(b[8:])
	out := make([]byte, 26)
	for i := 25; i >= 0; i-- {
		out[i] = alphabet[lo&31]
		lo = lo>>5 | hi<<59
		hi >>= 5
	}
	return policy + "-" + string(out)
}

// createRun creates the MachineRun of one scheduled time. A run that exists already is
// the run of that time and is left as it is.
func (s *Scheduler) createRun(ctx context.Context, p *v1alpha1.ScanPolicy, slot time.Time) (string, error) {
	run := &v1alpha1.MachineRun{
		ObjectMeta: metav1.ObjectMeta{
			Name: RunName(p.Name, string(p.UID), slot), Namespace: p.Namespace,
			Annotations: map[string]string{v1alpha1.AnnotationScheduledFor: slot.UTC().Format(time.RFC3339)},
		},
		Spec: v1alpha1.MachineRunSpec{
			Kind:        v1alpha1.RunKindScan,
			PolicyRef:   v1alpha1.PolicyRef{Kind: v1alpha1.ScanPolicyKind.Kind, Name: p.Name},
			RequestedBy: v1alpha1.RequestedByController,
			Reason:      "schedule " + p.Spec.Schedule,
		},
	}
	obj, err := v1alpha1.MachineRunToUnstructured(run)
	if err != nil {
		return "", err
	}
	unstructured.RemoveNestedField(obj.Object, "status")
	if err := s.Client.Create(ctx, obj); err != nil && !apierrors.IsAlreadyExists(err) {
		return "", fmt.Errorf("create MachineRun %s/%s: %w", run.Namespace, run.Name, err)
	}
	return run.Name, nil
}

// write sets the condition Ready and status.nextScheduleAt, and sends the status only
// when it differs from before.
func (s *Scheduler) write(ctx context.Context, p *v1alpha1.ScanPolicy, before v1alpha1.ScanPolicyStatus, next *metav1.Time, ready bool, reason, message string) error {
	status := metav1.ConditionFalse
	if ready {
		status = metav1.ConditionTrue
	}
	p.Status.NextScheduleAt = next
	meta.SetStatusCondition(&p.Status.Conditions, metav1.Condition{Type: ConditionReady, Status: status, Reason: reason, Message: message, ObservedGeneration: p.Generation})
	if reflect.DeepEqual(before, p.Status) {
		return nil
	}
	obj, err := v1alpha1.ScanPolicyToUnstructured(p)
	if err != nil {
		return err
	}
	if err := s.Client.Status().Update(ctx, obj); err != nil {
		return fmt.Errorf("update the status of ScanPolicy %s/%s: %w", p.Namespace, p.Name, err)
	}
	return nil
}

	u := &unstructured.Unstructured{}
	u.SetGroupVersionKind(gvk)
	return u
}

	MessageNotStarted       = "not-started"

// RunReconciler brings one MachineRun to its end. It starts one runner Job per target,
// at most spec.maxParallel of the policy at a time, reads the result document of every
// finished Job, writes the hardening report and Machine.status.sbom, and deletes the run
// when it has been finished for Settings.Retention. The Job itself writes no object.
type RunReconciler struct {
	Client   client.Client
	Reader   client.Reader // reads Jobs and their Pods from the API server, not from a cache
	Store    Store
	Settings Settings
	Now      func() time.Time
}

// SetupWithManager registers the controller: one reconcile when a MachineRun is created,
// one for every event of a runner Job, and one at each time the reconcile asked for.
func (r *RunReconciler) SetupWithManager(mgr ctrl.Manager) error {
	return ctrl.NewControllerManagedBy(mgr).
		Named("machine-run").
		For(newObject(v1alpha1.MachineRunKind), builder.WithPredicates(predicate.GenerationChangedPredicate{})).
		Watches(&batchv1.Job{}, handler.EnqueueRequestsFromMapFunc(JobRun)).
		Complete(r)

// JobRun maps a runner Job to its MachineRun, named by the annotation machines.openova.io/run.
func JobRun(_ context.Context, o client.Object) []reconcile.Request {
	ns, name, ok := strings.Cut(o.GetAnnotations()[AnnotationRun], "/")
	if !ok {
		return nil
	}
	return []reconcile.Request{{NamespacedName: types.NamespacedName{Namespace: ns, Name: name}}}
}

// Offset is the stable start offset of one target inside the jitter of its policy: the
// first eight bytes of the SHA-256 of the target, <namespace>/<name>, modulo the jitter
// in seconds.
func Offset(target string, jitter time.Duration) time.Duration {
	seconds := uint64(jitter / time.Second) // #nosec G115 -- PlanOf refuses a negative jitter
	if seconds == 0 {
		return 0
	}
	sum := sha256.Sum256([]byte(target))
	return time.Duration(binary.BigEndian.Uint64(sum[:8])%seconds) * time.Second // #nosec G115 -- less than the jitter
}

// Quarantined reports whether a Machine carries the condition Quarantined with status True.
func Quarantined(u *unstructured.Unstructured) bool {
	conditions, _, _ := unstructured.NestedSlice(u.Object, "status", "conditions")
	for _, c := range conditions {
		if m, ok := c.(map[string]interface{}); ok && m["type"] == "Quarantined" && m["status"] == "True" {
			return true
		}
	}
	return false
}

// Eligible reports whether a run may start a Job for a Machine: class node, phase Active
// and not quarantined.
func Eligible(u *unstructured.Unstructured, m *v1alpha1.Machine) bool {
	return m.Spec.Class == v1alpha1.ClassNode && m.Status.Phase == v1alpha1.PhaseActive && !Quarantined(u)
}

func succeeded(o runresult.Outcome) bool { return o == runresult.Succeeded || o == runresult.NoChange }

// Summary gives the phase of a run whose targets have all finished, and the number of
// targets per outcome: Succeeded when none failed, Failed when none succeeded,
// PartiallyFailed otherwise.
func Summary(targets []v1alpha1.RunTarget) (string, map[string]int32) {
	counts := map[string]int32{}
	good, bad := 0, 0
	for _, t := range targets {
		counts[t.Outcome]++
		if succeeded(runresult.Outcome(t.Outcome)) {
			good++
		} else {
			bad++
		}
	}
	switch {
	case bad == 0:
		return v1alpha1.RunSucceeded, counts
	case good == 0:
		return v1alpha1.RunFailed, counts
	}
	return v1alpha1.RunPartiallyFailed, counts
}

func final(phase string) bool {
	return phase == v1alpha1.RunSucceeded || phase == v1alpha1.RunPartiallyFailed || phase == v1alpha1.RunFailed
}

// Reconcile moves one MachineRun one step forward.
func (r *RunReconciler) Reconcile(ctx context.Context, req ctrl.Request) (ctrl.Result, error) {
	u := newObject(v1alpha1.MachineRunKind)
	if err := r.Client.Get(ctx, req.NamespacedName, u); err != nil {
		return ctrl.Result{}, client.IgnoreNotFound(err)
	}
	run, err := v1alpha1.MachineRunFromUnstructured(u)
	if err != nil {
		return ctrl.Result{}, err
	}
	now := r.now()
	if final(run.Status.Phase) {
		due := now
		if run.Status.FinishedAt != nil {
			due = run.Status.FinishedAt.Add(r.Settings.Retention)
		}
		if now.Before(due) {
			return ctrl.Result{RequeueAfter: due.Sub(now)}, nil
		}
		uid := u.GetUID()
		return ctrl.Result{}, client.IgnoreNotFound(r.Client.Delete(ctx, u, client.Preconditions{UID: &uid}))
	}
	policy, plan, outside, err := r.policyOf(ctx, run)
	if err != nil {
		return ctrl.Result{}, err
	}
	stamp := metav1.NewTime(now)
	if run.Status.StartedAt == nil {
		run.Status.StartedAt = &stamp
		if err := r.freeze(ctx, run, policy, plan, outside, stamp); err != nil {
			return ctrl.Result{}, err
		}
	}
	scheduled, _ := time.Parse(time.RFC3339, run.Annotations[v1alpha1.AnnotationScheduledFor])
	dueAt := func(t *v1alpha1.RunTarget) time.Time {
		if scheduled.IsZero() {
			return time.Time{}
		}
		return scheduled.Add(Offset(t.Machine, plan.Jitter))
	}
	running := 0
	var waiting []*v1alpha1.RunTarget
	for i := range run.Status.Targets {
		t := &run.Status.Targets[i]
		switch {
		case t.Outcome != "":
		case t.JobName == "" && outside != "":
			t.Outcome, t.Message, t.FinishedAt = string(runresult.Refused), MessageOutsidePolicy, &stamp
		case t.JobName == "":
			waiting = append(waiting, t)
		default:
			done, err := r.collect(ctx, run, t, stamp)
			if err != nil {
				return ctrl.Result{}, err
			}
			if !done {
				running++
			}
		}
	}
	sort.SliceStable(waiting, func(i, j int) bool { return dueAt(waiting[i]).Before(dueAt(waiting[j])) })
	var wake time.Time
	for _, t := range waiting {
		if at := dueAt(t); at.After(now) {
			wake = at
			break
		}
		if running >= plan.MaxParallel {
			break
		}
		started, err := r.start(ctx, run, policy, t, stamp)
		if err != nil {
			return ctrl.Result{}, err
		}
		if started {
			running++
		}
	}
	open, begun := 0, false
	for _, t := range run.Status.Targets {
		if t.Outcome == "" {
			open++
		}
		begun = begun || t.Outcome != "" || t.JobName != ""
	}
	switch {
	case final(run.Status.Phase):
	case open == 0:
		run.Status.Phase, run.Status.Counts = Summary(run.Status.Targets)
		run.Status.FinishedAt = &stamp
	case !begun:
		run.Status.Phase = v1alpha1.RunPending
	default:
		run.Status.Phase = v1alpha1.RunRunning
	}
	obj, err := v1alpha1.MachineRunToUnstructured(run)
	if err != nil {
		return ctrl.Result{}, err
	}
	if !reflect.DeepEqual(obj.Object["status"], u.Object["status"]) {
		if err := r.Client.Status().Update(ctx, obj); err != nil {
			return ctrl.Result{}, fmt.Errorf("update the status of MachineRun %s/%s: %w", run.Namespace, run.Name, err)
		}
	}
	switch {
	case final(run.Status.Phase):
		return ctrl.Result{RequeueAfter: r.Settings.Retention}, nil
	case !wake.IsZero():
		return ctrl.Result{RequeueAfter: wake.Sub(now)}, nil
	}
	return ctrl.Result{}, nil
}

func (r *RunReconciler) now() time.Time {
	if r.Now != nil {
		return r.Now()
	}
	return time.Now()
}

// policyOf reads the ScanPolicy of a run. outside is not empty when the run is outside
// its policy: its kind does not fit, or the policy is absent, invalid or suspended.
func (r *RunReconciler) policyOf(ctx context.Context, run *v1alpha1.MachineRun) (p *v1alpha1.ScanPolicy, plan PolicyPlan, outside string, err error) {
	if run.Spec.Kind != v1alpha1.RunKindScan || run.Spec.PolicyRef.Kind != v1alpha1.ScanPolicyKind.Kind {
		return nil, plan, "the kind of the run does not fit the kind of its policy", nil
	}
	u := newObject(v1alpha1.ScanPolicyKind)
	if err := r.Client.Get(ctx, types.NamespacedName{Namespace: run.Namespace, Name: run.Spec.PolicyRef.Name}, u); err != nil {
		if apierrors.IsNotFound(err) {
			return nil, plan, "the policy does not exist", nil
		}
		return nil, plan, "", err
	}
	if p, err = v1alpha1.ScanPolicyFromUnstructured(u); err != nil {
		return nil, plan, "", err
	}
	if plan, err = PlanOf(p); err != nil {
		return p, plan, err.Error(), nil
	}
	if p.Spec.Suspended {
		return p, plan, "the policy is suspended", nil
	}
	return p, plan, "", nil
}

// freeze writes the targets of a run once: the Machines the policy selects now, or
// spec.targets when every one of them is selected. A run outside its policy gets every
// requested target as Refused and the phase Failed, and starts nothing.
func (r *RunReconciler) freeze(ctx context.Context, run *v1alpha1.MachineRun, policy *v1alpha1.ScanPolicy, plan PolicyPlan, reason string, at metav1.Time) error {
	names, outside := run.Spec.Targets, map[string]bool{}
	if reason != "" {
		ctrl.LoggerFrom(ctx).Info("the run is outside its policy", "reason", reason)
		for _, n := range names {
			outside[n] = true
		}
	} else {
		selector, _ := metav1.LabelSelectorAsSelector(&policy.Spec.MachineSelector)
		selected := map[string]bool{}
		for _, ns := range plan.Namespaces {
			list := &unstructured.UnstructuredList{}
			list.SetGroupVersionKind(v1alpha1.MachineListKind)
			if err := r.Client.List(ctx, list, client.InNamespace(ns), client.MatchingLabelsSelector{Selector: selector}); err != nil {
				return fmt.Errorf("list Machines of %s: %w", ns, err)
			}
			for i := range list.Items {
				if m, err := v1alpha1.MachineFromUnstructured(&list.Items[i]); err == nil && Eligible(&list.Items[i], m) {
					selected[m.Namespace+"/"+m.Name] = true
				}
			}
		}
		if len(names) == 0 {
			for n := range selected {
				names = append(names, n)
			}
			sort.Strings(names)
		}
		for _, n := range names {
			if !selected[n] {
				outside[n] = true
			}
		}
	}
	run.Status.Targets = nil
	for _, n := range names {
		t := v1alpha1.RunTarget{Machine: n}
		if len(outside) > 0 {
			t.Outcome, t.Message, t.FinishedAt = string(runresult.Refused), MessageNotStarted, &at
			if outside[n] {
				t.Message = MessageOutsidePolicy
			}
		}
		run.Status.Targets = append(run.Status.Targets, t)
	}
	if reason != "" || len(outside) > 0 {
		_, run.Status.Counts = Summary(run.Status.Targets)
		run.Status.Phase, run.Status.FinishedAt = v1alpha1.RunFailed, &at
	}
	return nil
}

// machine reads one Machine named <namespace>/<name>. A Machine that is gone gives nil.
func (r *RunReconciler) machine(ctx context.Context, target string) (*v1alpha1.Machine, *unstructured.Unstructured, error) {
	ns, name, _ := strings.Cut(target, "/")
	u := newObject(v1alpha1.MachineKind)
	if err := r.Client.Get(ctx, types.NamespacedName{Namespace: ns, Name: name}, u); err != nil {
		return nil, nil, client.IgnoreNotFound(err)
	}
	m, err := v1alpha1.MachineFromUnstructured(u)
	return m, u, err
}

// start creates the Job of one target, or finishes the target when no Job is needed. It
// reports whether a Job now runs.
func (r *RunReconciler) start(ctx context.Context, run *v1alpha1.MachineRun, policy *v1alpha1.ScanPolicy, t *v1alpha1.RunTarget, at metav1.Time) (bool, error) {
	refuse := func(message string) (bool, error) {
		t.Outcome, t.Message, t.FinishedAt = string(runresult.Refused), message, &at
		return false, nil
	}
	m, u, err := r.machine(ctx, t.Machine)
	if err != nil {
		return false, err
	}
	if m == nil || !Eligible(u, m) {
		return refuse(MessageNotEligible)
	}
	var tasks []Task
	for _, profile := range []string{v1alpha1.ProfileInventory, v1alpha1.ProfileHardening} {
		if !slices.Contains(policy.Spec.Profiles, profile) {
			continue
		}
		if profile == v1alpha1.ProfileInventory {
			tasks = append(tasks, Task{Name: runner.TaskInventory, Args: r.Settings.TaskArgs(runner.TaskInventory, run, m, "", nil)})
			continue
		}
		bu := newObject(v1alpha1.HardeningBaselineKind)
		if err := r.Client.Get(ctx, types.NamespacedName{Namespace: policy.Namespace, Name: policy.Spec.HardeningBaselineRef.Name}, bu); err != nil {
			if apierrors.IsNotFound(err) {
				return refuse(MessageBaselineNotFound)
			}
			return false, err
		}
		baseline, err := v1alpha1.HardeningBaselineFromUnstructured(bu)
		if err != nil {
			return false, err
		}
		if id := ProfileFor(baseline, m); id != "" {
			tasks = append(tasks, Task{Name: runner.TaskHardening, Args: r.Settings.TaskArgs(runner.TaskHardening, run, m, id, baseline)})
			continue
		}
		res := runner.HardeningResults{ContentRelease: baseline.Spec.Content.Release, Reason: runner.MessageNoProfile}
		if err := r.putReport(ctx, HardeningReport(m, run.Name, res, "", at.Time)); err != nil {
			return false, err
		}
		t.ReportName, t.Message = HardeningReportName(m.Name), runner.TaskHardening+": "+runner.MessageNoProfile
	}
	t.StartedAt = &at
	if len(tasks) == 0 {
		t.Outcome, t.FinishedAt = string(runresult.Succeeded), &at
		return false, nil
	}
	job := r.Settings.NodeJob(run, m, tasks)

		return false, fmt.Errorf("create Job %s/%s: %w", job.Namespace, job.Name, err)
	}
	t.JobName = job.Name
	return true, nil
}

// ProfileFor returns the profile of a baseline for the operating-system release of a
// Machine: the entry whose family and version equal the Machine's. No entry gives "".
func ProfileFor(b *v1alpha1.HardeningBaseline, m *v1alpha1.Machine) string {
	if m.Status.OS == nil {
		return ""
	}
	for _, p := range b.Spec.Profiles {
		if p.OSFamily == m.Status.OS.Family && p.OSVersion == m.Status.OS.Version {
			return p.ProfileID
		}
	}
	return ""
}

// collect reads the Job of a started target. While the Job runs it reports false. When
// the Job has ended, or is gone, it fills the target from the result document of every
// container and reports true. A container without a parsable document is Failed with
// no-result; a document that says success without completed is Incomplete.
func (r *RunReconciler) collect(ctx context.Context, run *v1alpha1.MachineRun, t *v1alpha1.RunTarget, at metav1.Time) (bool, error) {
	finish := func(outcome runresult.Outcome, messages []string) (bool, error) {
		message := strings.Join(strings.Fields(strings.Join(messages, "; ")), " ")
		if len(message) > maxMessage {
			message = message[:maxMessage]
		}
		t.Outcome, t.Message, t.FinishedAt = string(outcome), strings.ToValidUTF8(message, ""), &at
		return true, nil
	}
	job := &batchv1.Job{}
	if err := r.Reader.Get(ctx, types.NamespacedName{Namespace: r.Settings.JobNamespace, Name: t.JobName}, job); err != nil {
		if apierrors.IsNotFound(err) {
			return finish(runresult.Failed, []string{runresult.MessageNoResult})
		}
		return false, err
	}
	ended, deadline := false, false
	for _, c := range job.Status.Conditions {
		if (c.Type == batchv1.JobComplete || c.Type == batchv1.JobFailed) && c.Status == corev1.ConditionTrue {
			ended, deadline = true, c.Type == batchv1.JobFailed && c.Reason == batchv1.JobReasonDeadlineExceeded
		}
	}
	if !ended {
		return false, nil
	}
	pods := &corev1.PodList{}
	if err := r.Reader.List(ctx, pods, client.InNamespace(job.Namespace), client.MatchingLabels{LabelJobName: job.Name}); err != nil {
		return false, err
	}
	terminated := map[string]*corev1.ContainerStateTerminated{}
	for i := range pods.Items {
		for _, cs := range pods.Items[i].Status.ContainerStatuses {
			if cs.State.Terminated != nil {
				terminated[cs.Name] = cs.State.Terminated
			}
		}
	}
	m, _, err := r.machine(ctx, t.Machine)
	if err != nil {
		return false, err
	}
	outcome, messages := runresult.Succeeded, []string{}
	if t.Message != "" {
		messages = append(messages, t.Message)
	}
	for _, c := range job.Spec.Template.Spec.Containers {
		doc, collected := runresult.OrNoResult(nil), at
		if state := terminated[c.Name]; state != nil {
			doc, collected = runresult.OrNoResult([]byte(state.Message)), state.FinishedAt
		}
		switch {
		case deadline && !succeeded(doc.Outcome):
			doc = runresult.Document{Outcome: runresult.Timeout, Message: MessageDeadline}
		case succeeded(doc.Outcome) && !doc.Completed:
			doc = runresult.Document{Outcome: runresult.Incomplete, Message: MessageNoMarker}
		case succeeded(doc.Outcome) && c.Name == runner.TaskInventory:
			err = r.writeSBOM(ctx, m, &doc, collected)
		case succeeded(doc.Outcome) && c.Name == runner.TaskHardening:
			err = r.writeHardening(ctx, run, m, t, &doc, at)
		}
		if err != nil {
			return false, err
		}
		if succeeded(doc.Outcome) {
			for _, e := range doc.Evidence {
				t.Evidence = append(t.Evidence, e.Key)
			}
		} else if succeeded(outcome) {
			outcome = doc.Outcome
		}
		if doc.Message != "" {
			messages = append(messages, c.Name+": "+doc.Message)
		}
	}
	return finish(outcome, messages)
}

func evidenceOf(doc *runresult.Document, kind string) *runresult.Evidence {
	for i := range doc.Evidence {
		if doc.Evidence[i].Kind == kind {
			return &doc.Evidence[i]
		}
	}
	return nil
}

// writeSBOM sets Machine.status.sbom to the bill of materials of a finished inventory
// task. A document without one turns to Failed.
func (r *RunReconciler) writeSBOM(ctx context.Context, m *v1alpha1.Machine, doc *runresult.Document, at metav1.Time) error {
	e := evidenceOf(doc, runner.KindSBOM)
	if e == nil {
		*doc = runresult.Document{Outcome: runresult.Failed, Message: MessageNoSBOM}
		return nil
	}
	if m == nil {
		return nil
	}
	patch, err := json.Marshal(map[string]interface{}{"status": map[string]interface{}{"sbom": v1alpha1.SBOM{Key: e.Key, SHA256: e.SHA256, CollectedAt: at}}})
	if err != nil {
		return err
	}
	u := newObject(v1alpha1.MachineKind)
	u.SetNamespace(m.Namespace)
	u.SetName(m.Name)
	if err := r.Client.Status().Patch(ctx, u, client.RawPatch(types.MergePatchType, patch)); client.IgnoreNotFound(err) != nil {
		return fmt.Errorf("patch the status of Machine %s/%s: %w", m.Namespace, m.Name, err)
	}
	return nil
}

// writeHardening writes the hardening report of a finished hardening task from the file
// hardening.results.json in the evidence bucket. A document without that file, or a file
// that does not match its checksum or its schema, turns the document to Failed and
// leaves the report as it was. A file that cannot be fetched is an error, tried again.
func (r *RunReconciler) writeHardening(ctx context.Context, run *v1alpha1.MachineRun, m *v1alpha1.Machine, t *v1alpha1.RunTarget, doc *runresult.Document, at metav1.Time) error {
	e := evidenceOf(doc, runner.KindHardeningResults)
	if e == nil {
		*doc = runresult.Document{Outcome: runresult.Failed, Message: MessageNoResultsFile}
		return nil
	}
	data, err := r.Store.Get(ctx, e.Key)
	if err != nil {
		return fmt.Errorf("fetch %s: %w", e.Key, err)
	}
	var res runner.HardeningResults
	sum := sha256.Sum256(data)
	if hex.EncodeToString(sum[:]) != e.SHA256 || json.Unmarshal(data, &res) != nil || res.Schema != runner.HardeningResultsSchema {
		*doc = runresult.Document{Outcome: runresult.Failed, Message: MessageResultsInvalid}
		return nil
	}
	if m == nil {
		return nil
	}
	if err := r.putReport(ctx, HardeningReport(m, run.Name, res, e.Key, at.Time)); err != nil {
		return err
	}
	t.ReportName = HardeningReportName(m.Name)
	return nil
}

// putReport creates a report or replaces the one of the same name.
func (r *RunReconciler) putReport(ctx context.Context, report *unstructured.Unstructured) error {
	old := newObject(PolicyReportKind)
	err := r.Client.Get(ctx, client.ObjectKeyFromObject(report), old)
	switch {
	case apierrors.IsNotFound(err):
		err = r.Client.Create(ctx, report)
	case err == nil:
		report.SetResourceVersion(old.GetResourceVersion())
		err = r.Client.Update(ctx, report)
	}
	if err != nil {
		return fmt.Errorf("write PolicyReport %s/%s: %w", report.GetNamespace(), report.GetName(), err)
	}
	return nil
}

// A scheduled run starts each target at its own offset inside the jitter, and the
// reconciler asks to be woken exactly at the next offset.
func TestScheduledRunStartsEachTargetAtItsOffset(t *testing.T) {
	spec := policySpec("0 2 * * *", "inventory")
	spec["maxParallel"] = int64(5)
	r := runObject("r1")
	r.SetAnnotations(map[string]string{v1alpha1.AnnotationScheduledFor: "2026-12-01T02:00:00Z"})
	w := newWorld(t, nil, scanPolicy(ns, spec), machineObject("cp-1", "22.04", false), machineObject("cp-2", "22.04", false), machineObject("cp-3", "22.04", false), r)
	slot := at("2026-12-01 02:00")
	offsets := map[string]time.Duration{}
	var order []string
	for _, n := range []string{"cp-1", "cp-2", "cp-3"} {
		offsets[n] = Offset(ns+"/"+n, time.Hour)
		if offsets[n] != Offset(ns+"/"+n, time.Hour) || offsets[n] < 0 || offsets[n] >= time.Hour {
			t.Fatalf("Offset of %s is %s", n, offsets[n])
		}
		order = append(order, n)
	}
	for i := range order {
		for j := i + 1; j < len(order); j++ {
			if offsets[order[j]] < offsets[order[i]] {
				order[i], order[j] = order[j], order[i]
			}
		}
	}
	if offsets[order[0]] == offsets[order[1]] || offsets[order[1]] == offsets[order[2]] || offsets[order[0]] == 0 {
		t.Fatalf("the three test machines need three different offsets above zero, got %v", offsets)
	}
	w.now = slot
	run, wait := w.step("r1")
	if run.Status.Phase != v1alpha1.RunPending || len(w.jobs()) != 0 || wait != offsets[order[0]] {
		t.Fatalf("at the scheduled time: phase %s, %d Jobs, wake-up in %s, want %s", run.Status.Phase, len(w.jobs()), wait, offsets[order[0]])
	}
	w.now = slot.Add(offsets[order[0]])
	run, wait = w.step("r1")
	if run.Status.Phase != v1alpha1.RunRunning || len(w.jobs()) != 1 || target(run, order[0]).JobName == "" || wait != offsets[order[1]]-offsets[order[0]] {
		t.Fatalf("at the first offset: phase %s, %d Jobs, wake-up in %s", run.Status.Phase, len(w.jobs()), wait)
	}
	w.now = slot.Add(time.Hour)
	if _, wait = w.step("r1"); len(w.jobs()) != 3 || wait != 0 {
		t.Fatalf("after the jitter: %d Jobs, wake-up in %s", len(w.jobs()), wait)
	}
	if Offset("a/b", 0) != 0 {
		t.Fatal("a jitter of zero gave an offset")
	}
}

// Task is one container of a runner Job: the task name and the arguments of the runner.

	Name string
	Args []string

// JobName is the name of the Job of one run and one target: mr- and the first 16 hex
// digits of the SHA-256 of <run namespace>/<run name>/<machine namespace>/<machine name>.
// The same run and target give the same name, so a target never gets two Jobs.
func JobName(run, machine string) string {
	sum := sha256.Sum256([]byte(run + "/" + machine))
	return "mr-" + hex.EncodeToString(sum[:8])
}

// TaskArgs are the arguments of the runner for one task on one node. profile is the
// hardening profile and baseline its HardeningBaseline; both are used only for the task
// hardening.
func (s Settings) TaskArgs(task string, run *v1alpha1.MachineRun, m *v1alpha1.Machine, profile string, baseline *v1alpha1.HardeningBaseline) []string {
	family, version := "", ""
	if m.Status.OS != nil {
		family, version = m.Status.OS.Family, m.Status.OS.Version
	}
	args := []string{
		"--task=" + task, "--mode=" + runner.ModeNode,
		"--machine=" + m.Namespace + "/" + m.Name, "--run=" + run.Namespace + "/" + run.Name,
		"--os-family=" + family, "--os-version=" + version,
		"--evidence-endpoint=" + s.EvidenceEndpoint, "--evidence-region=" + s.EvidenceRegion, "--evidence-bucket=" + s.EvidenceBucket,
		"--evidence-prefix=" + m.Namespace + "/" + m.Name + "/" + run.Name + "/",
	}
	if m.Status.PrimaryAddress != "" {
		args = append(args, "--address="+m.Status.PrimaryAddress)
	}
	if task == runner.TaskHardening {
		args = append(args, "--profile-id="+profile, "--content-release="+baseline.Spec.Content.Release)
		if baseline.Spec.Tailoring != nil && len(baseline.Spec.Tailoring.DisabledRules) > 0 {
			args = append(args, "--disabled-rules="+strings.Join(baseline.Spec.Tailoring.DisabledRules, ","))
		}
	}

// task, on the target's Node, as root with a read-only root file system, the Node's file

			{Name: "host", VolumeSource: corev1.VolumeSource{HostPath: &corev1.HostPathVolumeSource{Path: "/"}}},

				Driver: "secrets-store.csi.k8s.io", ReadOnly: &yes,
				VolumeAttributes: map[string]string{"secretProviderClass": EvidenceProviderClass},
			}}},
		},
	}
	for _, t := range tasks {
		pod.Volumes = append(pod.Volumes, corev1.Volume{Name: "work-" + t.Name, VolumeSource: corev1.VolumeSource{EmptyDir: &corev1.EmptyDirVolumeSource{Medium: corev1.StorageMediumMemory}}})

		})
	}
	return &batchv1.Job{
		ObjectMeta: metav1.ObjectMeta{Name: JobName(run.Namespace+"/"+run.Name, m.Namespace+"/"+m.Name), Namespace: s.JobNamespace, Labels: labels, Annotations: annotations},

			Template: corev1.PodTemplateSpec{ObjectMeta: metav1.ObjectMeta{Labels: labels, Annotations: annotations}, Spec: pod},
		},
	}
}

package operations

import (
	"sort"
	"time"

	"k8s.io/apimachinery/pkg/apis/meta/v1/unstructured"
	"k8s.io/apimachinery/pkg/runtime/schema"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/machines/apis/v1alpha1"
	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/machines/runner"
)

// PolicyReportKind is the report kind the compliance view reads.
var PolicyReportKind = schema.GroupVersionKind{Group: "wgpolicyk8s.io", Version: "v1alpha2", Kind: "PolicyReport"}

// The fixed parts of a hardening report.
const (
	SourceHardening            = "machine-hardening"
	LabelReportMachine         = "machines.openova.io/machine"
	LabelReport                = "machines.openova.io/report"
	ReportHardening            = "hardening"
	AnnotationResultsTruncated = "machines.openova.io/results-truncated"
	MaxReportResults           = 200
)

// HardeningReportName is the name of the hardening report of a Machine.
func HardeningReportName(machine string) string { return "machine-" + machine + "-hardening" }

// reportResult maps the XCCDF result of a rule to a result of the report and its rank,
// worst first. A rule that was not evaluated is skip, never pass.
func reportResult(xccdf string) (string, int) {
	switch xccdf {
	case "fail":
		return "fail", 0
	case "error", "unknown":
		return "error", 1
	case "pass", "fixed":
		return "pass", 3
	}
	return "skip", 2
}

// HardeningReport builds the hardening report of one Machine from the file
// hardening.results.json of a run: one result per rule, worst first (fail, error, skip,
// pass; then by rule identifier), at most MaxReportResults. A longer list is cut and
// marked with the annotation machines.openova.io/results-truncated; the property
// evidenceKey of every result names the full file. The summary counts every rule.
// Results with no rule give the one result skip with the rule no-profile-for-release.
func HardeningReport(m *v1alpha1.Machine, run string, res runner.HardeningResults, evidenceKey string, at time.Time) *unstructured.Unstructured {
	type row struct {
		rule, result string
		rank         int
	}
	rows := make([]row, 0, len(res.Rules))
	summary := map[string]interface{}{"pass": int64(0), "fail": int64(0), "warn": int64(0), "error": int64(0), "skip": int64(0)}
	for _, r := range res.Rules {
		result, rank := reportResult(r.Result)
		rows = append(rows, row{rule: r.ID, result: result, rank: rank})
		summary[result] = summary[result].(int64) + 1
	}
	policy := res.ProfileID
	if len(rows) == 0 {
		rows, summary["skip"] = []row{{rule: runner.MessageNoProfile, result: "skip"}}, int64(1)
		if policy == "" {
			policy = ReportHardening
		}
	}
	sort.SliceStable(rows, func(i, j int) bool {
		if rows[i].rank != rows[j].rank {
			return rows[i].rank < rows[j].rank
		}
		return rows[i].rule < rows[j].rule
	})
	truncated := len(rows) > MaxReportResults
	if truncated {
		rows = rows[:MaxReportResults]
	}
	results := make([]interface{}, 0, len(rows))
	for _, r := range rows {
		properties := map[string]interface{}{"runName": run, "contentRelease": res.ContentRelease}
		if evidenceKey != "" {
			properties["evidenceKey"] = evidenceKey
		}
		results = append(results, map[string]interface{}{
			"source": SourceHardening, "policy": policy, "rule": r.rule, "result": r.result,
			"timestamp": map[string]interface{}{"seconds": at.Unix(), "nanos": int64(0)}, "properties": properties,
		})
	}
	scope := map[string]interface{}{"apiVersion": v1alpha1.GroupVersion.String(), "kind": v1alpha1.MachineKind.Kind, "namespace": m.Namespace, "name": m.Name, "uid": string(m.UID)}
	u := &unstructured.Unstructured{Object: map[string]interface{}{"scope": scope, "summary": summary, "results": results}}
	u.SetGroupVersionKind(PolicyReportKind)
	u.SetNamespace(m.Namespace)
	u.SetName(HardeningReportName(m.Name))
	u.SetLabels(map[string]string{LabelReportMachine: m.Name, LabelReport: ReportHardening})
	if truncated {
		u.SetAnnotations(map[string]string{AnnotationResultsTruncated: "true"})
	}
	owner := map[string]interface{}{"apiVersion": scope["apiVersion"], "kind": scope["kind"], "name": m.Name, "uid": string(m.UID)}
	_ = unstructured.SetNestedSlice(u.Object, []interface{}{owner}, "metadata", "ownerReferences")
	return u
}

package operations

import (
	"context"
	"crypto/tls"
	"crypto/x509"
	"errors"
	"fmt"
	"io"
	"net/http"
	"net/url"
	"os"
	"path/filepath"
	"strings"
	"time"

	"github.com/minio/minio-go/v7"
	"github.com/minio/minio-go/v7/pkg/credentials"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/machines/runner"
)

// Store reads one file of the evidence bucket.
type Store interface {
	Get(ctx context.Context, key string) ([]byte, error)
}

// MaxEvidenceBytes is the largest file the controller reads from the evidence bucket,
// and EvidenceTimeout the longest one read may take.
const (
	MaxEvidenceBytes = 16 << 20
	EvidenceTimeout  = time.Minute
)

// BucketStore reads the evidence bucket over HTTPS with certificate validation. The key
// pair is read from the object-storage binding mounted at BindingDir on every call, so a
// replaced key is used at once. No Kubernetes Secret is read.
type BucketStore struct {
	Endpoint   string // https://host[:port]
	Region     string
	Bucket     string
	BindingDir string
}

// Get returns the content of one object. It fails on an object longer than
// MaxEvidenceBytes and on a read that takes longer than EvidenceTimeout.
func (s BucketStore) Get(ctx context.Context, key string) ([]byte, error) {
	ctx, cancel := context.WithTimeout(ctx, EvidenceTimeout)
	defer cancel()
	var pair [2]string // the access key identifier and the secret access key
	for i, name := range []string{runner.BindingAccessKeyID, runner.BindingSecretAccessKey} {
		data, err := os.ReadFile(filepath.Join(s.BindingDir, name)) // #nosec G304 -- a fixed name in the mounted binding
		if pair[i] = strings.TrimSpace(string(data)); err != nil || pair[i] == "" {
			return nil, fmt.Errorf("the binding file %s cannot be read", name)
		}
	}
	pool, err := x509.SystemCertPool()
	if err != nil {
		pool = x509.NewCertPool()
	}
	ca, err := os.ReadFile(filepath.Join(s.BindingDir, runner.BindingCA)) // #nosec G304 -- a fixed name in the mounted binding
	if err == nil && !pool.AppendCertsFromPEM(ca) {
		return nil, fmt.Errorf("the binding file %s holds no certificate", runner.BindingCA)
	}
	if err != nil && !errors.Is(err, os.ErrNotExist) {
		return nil, fmt.Errorf("the binding file %s cannot be read", runner.BindingCA)
	}
	endpoint, err := url.Parse(s.Endpoint)
	if err != nil || endpoint.Scheme != "https" || endpoint.Host == "" {
		return nil, fmt.Errorf("the evidence endpoint %q is not https://host[:port]", s.Endpoint)
	}
	transport := http.DefaultTransport.(*http.Transport).Clone()
	transport.TLSClientConfig = &tls.Config{RootCAs: pool, MinVersion: tls.VersionTLS12}
	defer transport.CloseIdleConnections()
	c, err := minio.New(endpoint.Host, &minio.Options{Creds: credentials.NewStaticV4(pair[0], pair[1], ""), Secure: true, Region: s.Region, Transport: transport})
	if err != nil {
		return nil, err
	}
	obj, err := c.GetObject(ctx, s.Bucket, key, minio.GetObjectOptions{})
	if err != nil {
		return nil, err
	}
	defer func() { _ = obj.Close() }()
	data, err := io.ReadAll(io.LimitReader(obj, MaxEvidenceBytes+1))
	if err != nil {

	}
}
