# INF-110 — Kinds Machine and MachineSource; inventory controller with the node source

## In plain words

**The problem today.** The platform keeps no record of the machines it runs on. Nothing lists the cluster's own Nodes as objects that later work, such as scans and patching, can select, and nothing decides when a machine that has disappeared is really gone.

**What changes.** A new Blueprint ships the two resource definitions of a machine inventory, and a new controller binary turns every Kubernetes Node into a Machine object. It marks a Machine stale only after a complete listing, and holds a sweep that would mark too many. Nothing installs or runs them yet.

**Done means:**

- The chart bp-machine-operations holds the definitions of Machine and MachineSource of the group machines.openova.io, version v1alpha1, with only the fields of this version.
- The binary machine-controller of the API module builds and runs the inventory controller when it is started with --controllers=inventory.
- A test on a fake API server shows that three Nodes give three Machines of class node, and that a deleted Node turns its Machine stale.
- Each inventory rule of this version has its own test table: identity, complete or nothing, stale by listing, hold, revive, no address no run, and the retire and purge times.
- The API module requires controller-runtime v0.24.1, and its Kubernetes libraries stay at v0.36.0.
- The generated catalogue and inventory files list the new Blueprint and the two kinds.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The repository holds a new Blueprint folder, `platform/machine-operations`, whose chart defines two kinds of the API group `machines.openova.io`, version `v1alpha1`: `MachineSource` (one place machines are read from; this version knows one type, `nodes`) and `Machine` (one machine a source saw). The API module holds the Go form of both kinds, the source `nodes`, the inventory rules as pure functions with one test table each, a controller-runtime reconciler, and a new binary `machine-controller` that runs it with `--controllers=inventory`. A reviewer can run `go test ./internal/machines/apis/... ./internal/machines/source/... ./internal/machines/inventory/... ./cmd/machine-controller/` in the API module and watch three Nodes become three Machines of class `node` on a fake API server, and a deleted Node turn its Machine `Stale`. Nothing installs the chart or runs the binary yet: the chart templates come with package INF-112 and the kit slot with package INF-160.

## 3. The model (the law)
1. **The kinds.** `Machine` and `MachineSource` belong to the Blueprint `bp-machine-operations`. Group `machines.openova.io`, version `v1alpha1`, both namespaced, both with a `status` subresource. Their definitions are the two files in `platform/machine-operations/chart/crds/`. Every object is pruned of fields the definition does not list: no `x-kubernetes-preserve-unknown-fields` anywhere.
2. **The fields of this version, and no others.** `Machine`: `spec.sourceRef.name`, `spec.externalId`, `spec.class` (enum `node`, `virtual-machine`, `host`, `appliance`), each immutable; `status.phase` (`Active`, `Stale`, `Retired`), `status.ownership` (`declared`, `adopted`, `unmanaged`), `status.ownerRef`, `status.providerId`, `status.displayName`, `status.primaryAddress`, `status.addresses`, `status.fingerprint`, `status.os`, `status.firstSeen`, `status.lastSeen`, `status.lastEnumerationId`, `status.staleSince`. `MachineSource`: `spec.type` (enum with the one value `nodes`, immutable), `spec.suspended` (default false), `spec.stale.holdPercent` (1 to 100, default 20), `spec.stale.holdMinimum` (0 or more, default 10), `spec.stale.retireAfter` (default `720h`), `spec.stale.purgeAfter` (default `2160h`), `spec.stale.releaseHoldFor` (default `""`); `status.lastEnumeration`, `status.held`, `status.conditions` (`Ready`, `Complete`, `StaleHold`). A `Machine` has no `conditions`, `powerState`, `shape`, `sbom`, `hostKeys`, `patch` or `parent` in this version, and a `MachineSource` no `interval` or `labelRules`: later packages add each with its reader. This item is about the two definitions and about what the controller writes to an object. The Go values of package `source` are item 18.
3. **One writer.** Only the inventory controller creates, changes and deletes a `Machine` and writes the status of a `MachineSource`. A `Machine` is an observation: it never goes to Git and no route writes it. The five write calls of the controller are in one file, `products/catalyst/bootstrap/api/internal/machines/inventory/reconciler.go`, and the guard `scripts/check-no-direct-cluster-write.py` allows exactly these five through one allow entry of owner `INF`.
4. **Rule 1, identity.** A machine is identified by its namespace, `spec.sourceRef.name` and `spec.externalId`. A `Machine` of class `node` is named after its Node; any other `Machine` is named `<source name>-<first 10 hex digits of sha256(externalId)>`.
5. **Rule 3, complete or nothing.** Only an enumeration that ended without an error, says it is complete and read every scope may mark a machine stale. A failed or partial enumeration updates the machines it saw and marks nothing.
6. **Rule 4, stale by the source's own listing.** After a complete enumeration, an `Active` machine of the source that the enumeration did not list becomes `Stale`, with `staleSince` the end of that enumeration. The time since a machine was last seen is never the test.
7. **Rule 5, hold.** If rule 4 would mark more than `holdPercent` percent of the source's `Active` machines and at least `holdMinimum` of them, nothing is marked: `status.held` and the condition `StaleHold=True` are set. A hold that exists keeps its `enumerationId` and `since`; `wouldMarkStale` and `live` take the newest numbers. The hold ends when a later complete enumeration no longer trips the threshold (its candidates are marked), or when `spec.stale.releaseHoldFor` equals `status.held.enumerationId` (the candidates of the current complete enumeration are marked).
8. **Rule 6, revive.** A `Stale` or `Retired` machine that a sighting lists again becomes `Active`, loses `staleSince` and keeps `firstSeen`.
9. **Rule 12, no address, no run.** A machine with an empty `primaryAddress` is never the target of a run; class `node` is exempt. The function exists for the operations controller of a later package.
10. **Retire and purge.** A `Stale` machine becomes `Retired` at `staleSince + retireAfter`, and is deleted at `staleSince + retireAfter + purgeAfter`. The reconcile asks to run again at the next of these times.
11. **Labels.** Every `Machine` carries exactly five labels, written by the controller on every reconcile: `machines.openova.io/class`, `machines.openova.io/ownership`, `machines.openova.io/os-family` (the family, or `unknown`), `machines.openova.io/phase` (the phase in lower case) and `machines.openova.io/source`. A label set by anyone else is removed.
12. **A Node as a sighting.** `externalId` and `displayName` are the Node name; class `node`; `providerId` is `spec.providerID`; addresses from `status.addresses` (`InternalIP` gives type `Private`, `ExternalIP` gives `Public`, other types are skipped); `primaryAddress` is the first `Private` address; `fingerprint.firmwareUUID` and `fingerprint.machineID` are `nodeInfo.systemUUID` and `nodeInfo.machineID`; `os.family` and `os.version` are parsed from `nodeInfo.osImage` (`Ubuntu 22.04.4 LTS` gives `ubuntu`, `22.04`; an unknown image gives `unknown`, `""`); `os.arch` is `nodeInfo.architecture` with `amd64` written `x86_64` and `arm64` written `aarch64`; `os.kernel` is `nodeInfo.kernelVersion`. Ownership is `declared`, with `ownerRef` the Node. The enumeration of a source of type `nodes` is always complete when it returns; a failed list is an error.
13. **Events, not loops.** The controller reconciles a `MachineSource` when its spec changes, and every source of type `nodes` when a Node is added or removed or changes a fact of item 12 of this field. A Node status heartbeat starts no reconcile. No ticker, no sleep and no polling interval.
14. **The binary.** `products/catalyst/bootstrap/api/cmd/machine-controller` runs the controllers named by `--controllers` (comma-separated; the one known name is `inventory`), with leader election on the Lease `machine-controller-inventory`, health on `:8081` and metrics off.
15. **The framework.** controller-runtime `v0.24.1`, called directly, on `unstructured.Unstructured` objects converted with `runtime.DefaultUnstructuredConverter`. No deep-copy generator. The API module's `k8s.io/api`, `k8s.io/apimachinery` and `k8s.io/client-go` stay at `v0.36.0`.
16. **Nothing installs it yet.** The chart has no templates and no values, no kit slot installs it and the catalogue seed does not carry it; it is declared in `scripts/expected-unseeded-blueprints.yaml`. Its `blueprint.yaml` carries no `spec.class` and no `spec.lifecycle`: the Blueprint schema has no such fields yet, and the package that adds them sets them on every Blueprint.
17. **No growth of the handler package.** This ticket changes nothing under `products/catalyst/bootstrap/api/internal/handler` and nothing in `cmd/api/main.go`, and adds no route.
18. **The Go interface of a source is whole from the start.** The file `source.go` is the contract that every type of source implements. It is written once, in this ticket. Packages INF-320 and INF-930 add their sources as new files beside it and do not change it. So it holds Go values and types that no code of this version reads: the `Sighting` fields `VCPU`, `MemoryMiB`, `Flavor`, `Tags` and `Parent`; the field `PowerState`, which the source `nodes` sets to `PowerUnknown` and the controller does not read; the constants `ClassVirtualMachine`, `ClassHost`, `ClassAppliance`, `PowerRunning` and `PowerStopped`; and the types `Watcher`, `Change` and `ChangeType` with their two constants. Two of its comments name the sources `declared` and `cloudaccount` and an interval; those come with package INF-320. None of these is a field of a kind, a flag or a setting. The controller of this version writes none of these values to a `Machine`, calls no `Watcher` and has no interval, so items 2 and 13 hold as written. The file is correct as its block gives it: rule of conduct 9 is no reason to shorten it, and a reviewer does not ask for it to be shortened.

```markdown
# bp-machine-operations

Machine operations on the machines a Sovereign runs on, starting with an
inventory of the cluster's own Nodes.

## Role in Catalyst

Control-plane plumbing, not an Application a User installs. The kinds of the
API group `machines.openova.io` belong to this Blueprint: they arrive with its
chart and are absent where it is not installed. They are not platform
entities. See [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md) for the
place of a Blueprint in the model.

## What this version ships

The chart holds only the two custom resource definitions, in `chart/crds/`:

| Kind | Written by | Meaning |
|---|---|---|
| `MachineSource` | chart values or Git | One place machines are read from. Type `nodes` lists the Kubernetes Nodes of the cluster. |
| `Machine` | the inventory controller only | One machine a source saw. An observation, never committed to Git. |

The inventory controller is the binary `machine-controller` of the
catalyst-api module (`products/catalyst/bootstrap/api/cmd/machine-controller`),
run with `--controllers=inventory`. Its code is in
`products/catalyst/bootstrap/api/internal/machines/`. The chart does not run it
yet: its Deployment, its access rules and the built-in `nodes` source come
with the chart templates of a later version.

## How the inventory works

- A Machine is identified by its namespace, its source and the source's own
  identifier. A Machine of class `node` is named after its Node.
- An enumeration that fails, or that cannot read every scope, marks nothing.
- After a complete enumeration, an `Active` Machine that the source did not
  list becomes `Stale`. The time since it was last seen is never the test.
- If that would mark more than `spec.stale.holdPercent` (default 20) of the
  source's active Machines, and at least `spec.stale.holdMinimum` (default 10),
  nothing is marked: `status.held` and the condition `StaleHold` are set. Set
  `spec.stale.releaseHoldFor` to `status.held.enumerationId` to apply the sweep.
- A Machine that a source lists again becomes `Active` and keeps `firstSeen`.
- A Machine that is stale for `spec.stale.retireAfter` (default `720h`)
  becomes `Retired`; after a further `spec.stale.purgeAfter` (default `2160h`)
  it is deleted.
- Each Machine carries exactly five labels, written by the controller:
  `machines.openova.io/class`, `ownership`, `os-family`, `phase` and `source`.

## Configuration

`values.yaml` is empty in this version.

## Operations

No bootstrap-kit slot installs this chart yet. The definitions are installed
from `chart/crds/`, so the slot that installs it must set `install.crds` and
`upgrade.crds` to `CreateReplace`: only then does a later version that adds a
field reach a running Sovereign.
```

```go
// Enumerate lists every Node. The one scope is "nodes"; a failed list is an error and
// nothing is returned, so the listing is complete whenever it is returned.
func (n *Nodes) Enumerate(ctx context.Context) (Enumeration, error) {
	now := time.Now
	if n.Now != nil {
		now = n.Now
	}
	started := now()
	var list corev1.NodeList
	if err := n.Reader.List(ctx, &list); err != nil {
		return Enumeration{}, fmt.Errorf("nodes: list: %w", err)
	}
	sightings := make([]Sighting, 0, len(list.Items))
	for i := range list.Items {
		sightings = append(sightings, NodeSighting(&list.Items[i]))
	}
	sort.Slice(sightings, func(i, j int) bool { return sightings[i].ExternalID < sightings[j].ExternalID })
	return Enumeration{
		StartedAt:  started,
		FinishedAt: now(),
		Complete:   true,
		Scopes:     []ScopeResult{{Name: TypeNodes, Readable: true, Count: len(sightings)}},
		Sightings:  sightings,
	}, nil
}

// NodeSighting turns one Node into a Sighting of class node.
func NodeSighting(node *corev1.Node) Sighting {
	info := node.Status.NodeInfo
	family, version := ParseOSImage(info.OSImage)
	s := Sighting{
		ExternalID:  node.Name,
		DisplayName: node.Name,
		Class:       ClassNode,
		PowerState:  PowerUnknown,
		ProviderID:  node.Spec.ProviderID,
		Fingerprint: Fingerprint{FirmwareUUID: info.SystemUUID, MachineID: info.MachineID},
		OSFamily:    family,
		OSVersion:   version,
		Arch:        Arch(info.Architecture),
		Kernel:      info.KernelVersion,
	}
	for _, a := range node.Status.Addresses {
		switch a.Type {
		case corev1.NodeInternalIP:
			s.Addresses = append(s.Addresses, Address{Type: "Private", IP: a.Address})
		case corev1.NodeExternalIP:
			s.Addresses = append(s.Addresses, Address{Type: "Public", IP: a.Address})
		}
	}
	return s
}

func PrimaryAddress(addresses []Address) string {
	for _, a := range addresses {
		if a.Type == "Private" {
			return a.IP
		}
	}
	return ""
}

// osFamilies maps the start of a Node's osImage to the family names of the image
// catalogue. The first prefix that matches wins.
var osFamilies = []struct{ prefix, family string }{
	{"Ubuntu ", "ubuntu"},
	{"Debian GNU/Linux ", "debian"},
	{"Red Hat Enterprise Linux ", "rhel"},
	{"Rocky Linux ", "rocky"},
	{"AlmaLinux ", "almalinux"},
	{"Oracle Linux Server ", "oraclelinux"},
	{"SUSE Linux Enterprise Server ", "sles"},
	{"Windows Server ", "windows"},
}

var osVersion = regexp.MustCompile(`^[0-9]+(\.[0-9]+)?`)

// ParseOSImage reads a Node's osImage. "Ubuntu 22.04.4 LTS" gives "ubuntu", "22.04":
// the version is the first number, with its first dot part if it has one. An image
// whose start is not known, or that has no number after its name, gives "unknown", "".
func ParseOSImage(image string) (family, version string) {
	for _, f := range osFamilies {
		if strings.HasPrefix(image, f.prefix) {
			if v := osVersion.FindString(strings.TrimPrefix(image, f.prefix)); v != "" {
				return f.family, v
			}
			return "unknown", ""
		}
	}
	return "unknown", ""
}

// Arch maps a Node's architecture to the names of the image catalogue: amd64 is
// x86_64 and arm64 is aarch64. Any other value is kept as it is.
func Arch(nodeArch string) string {
	switch nodeArch {
	case "amd64":
		return "x86_64"
	case "arm64":
		return "aarch64"
	}
	return nodeArch
}
```

```go
// Package inventory is the inventory controller of the machine plane. It reads each
// MachineSource, enumerates it and keeps one Machine object per machine it saw.
//
// This file holds the inventory rules as pure functions, so that every rule is a
// table test in rules_test.go: rule 1 (identity), rule 3 (complete or nothing),
// rule 4 (stale by the source's own listing), rule 5 (hold), rule 6 (revive),
// rule 12 (no address, no run) and the retire and purge times of spec.stale.
package inventory

import (
	"crypto/sha256"
	"encoding/hex"
	"fmt"
	"sort"
	"time"

// MachineName is rule 1. A Machine of class node is named after its Node. Any other
// Machine is "<source name>-<first 10 hex digits of sha256(externalId)>". Together
// with its namespace and spec.sourceRef.name, the name stands for one externalId.
func MachineName(sourceName, class, externalID string) string {
	if class == v1alpha1.ClassNode {
		return externalID
	}
	sum := sha256.Sum256([]byte(externalID))
	return sourceName + "-" + hex.EncodeToString(sum[:])[:10]
}

// MayMarkStale is rule 3. Only an enumeration that ended without an error, says it
// is complete and read every scope may mark a machine stale.
func MayMarkStale(e source.Enumeration, err error) bool {
	if err != nil || !e.Complete || len(e.Scopes) == 0 {
		return false
	}
	for _, s := range e.Scopes {
		if !s.Readable {
			return false
		}
	}
	return true
}

// StaleCandidates is rule 4: the Active machines of the source that the enumeration
// did not list, by externalId, sorted. Time since a machine was last seen plays no part.
func StaleCandidates(active []string, listed map[string]bool) []string {
	var out []string
	for _, id := range active {
		if !listed[id] {
			out = append(out, id)
		}
	}
	sort.Strings(out)
	return out
}

// Settings are the stale rules of one MachineSource, with the defaults applied.
type Settings struct {
	HoldPercent    int
	HoldMinimum    int
	RetireAfter    time.Duration
	PurgeAfter     time.Duration
	ReleaseHoldFor string
}

// SettingsOf reads spec.stale. An absent field takes its default: holdPercent 20,
// holdMinimum 10, retireAfter 720h, purgeAfter 2160h, releaseHoldFor "".
func SettingsOf(stale *v1alpha1.StaleSpec) (Settings, error) {
	s := Settings{HoldPercent: v1alpha1.DefaultHoldPercent, HoldMinimum: v1alpha1.DefaultHoldMinimum}
	retire, purge := v1alpha1.DefaultRetireAfter, v1alpha1.DefaultPurgeAfter
	if stale != nil {
		if stale.HoldPercent != nil {
			s.HoldPercent = int(*stale.HoldPercent)
		}
		if stale.HoldMinimum != nil {
			s.HoldMinimum = int(*stale.HoldMinimum)
		}
		if stale.RetireAfter != "" {
			retire = stale.RetireAfter
		}
		if stale.PurgeAfter != "" {
			purge = stale.PurgeAfter
		}
		s.ReleaseHoldFor = stale.ReleaseHoldFor
	}
	if s.HoldPercent < 1 || s.HoldPercent > 100 {
		return Settings{}, fmt.Errorf("spec.stale.holdPercent %d is not between 1 and 100", s.HoldPercent)
	}
	if s.HoldMinimum < 0 {
		return Settings{}, fmt.Errorf("spec.stale.holdMinimum %d is below 0", s.HoldMinimum)
	}
	var err error
	if s.RetireAfter, err = time.ParseDuration(retire); err != nil || s.RetireAfter <= 0 {
		return Settings{}, fmt.Errorf("spec.stale.retireAfter %q is not a positive duration", retire)
	}
	if s.PurgeAfter, err = time.ParseDuration(purge); err != nil || s.PurgeAfter <= 0 {
		return Settings{}, fmt.Errorf("spec.stale.purgeAfter %q is not a positive duration", purge)
	}
	return s, nil
}

// Trips is the threshold of rule 5: marking wouldMark of the active machines is
// more than HoldPercent of them and at least HoldMinimum machines.
func (s Settings) Trips(active, wouldMark int) bool {
	return wouldMark >= s.HoldMinimum && wouldMark*100 > s.HoldPercent*active
}

// Sweep is what one enumeration does to the machines it did not list.
type Sweep struct {
	Mark []string       // externalIds that become Stale
	Held *v1alpha1.Held // the hold to record, or nil when no sweep is held
}

// DecideSweep applies rules 3, 4 and 5 to one enumeration. active holds the
// externalIds of the source's Active machines and held the hold recorded so far.
//
//   - An enumeration that may not mark (rule 3) marks nothing and keeps the hold as it is.
//   - A sweep under the threshold marks every candidate and ends the hold.
//   - A sweep over the threshold marks nothing and is held. A hold that exists keeps its
//     enumerationId and its since; wouldMarkStale and live take the new numbers.
//   - When spec.stale.releaseHoldFor equals the enumerationId of the recorded hold, a
//     sweep over the threshold marks every candidate and ends the hold.
func DecideSweep(s Settings, e source.Enumeration, err error, active []string, held *v1alpha1.Held, now time.Time) Sweep {
	if !MayMarkStale(e, err) {
		return Sweep{Held: held}
	}
	listed := make(map[string]bool, len(e.Sightings))
	for _, sight := range e.Sightings {
		listed[sight.ExternalID] = true
	}
	candidates := StaleCandidates(active, listed)
	if !s.Trips(len(active), len(candidates)) {
		return Sweep{Mark: candidates}
	}
	if held != nil && s.ReleaseHoldFor != "" && s.ReleaseHoldFor == held.EnumerationID {
		return Sweep{Mark: candidates}
	}
	next := &v1alpha1.Held{EnumerationID: e.ID, Since: metav1.NewTime(now)}
	if held != nil {
		next.EnumerationID, next.Since = held.EnumerationID, held.Since
	}
	next.WouldMarkStale, next.Live = int32(len(candidates)), int32(len(active)) // #nosec G115 -- counts of objects in one namespace
	return Sweep{Held: next}
}

// Revive is rule 6. A Stale or Retired machine that a sighting lists again becomes
// Active; firstSeen is kept. It reports whether the phase changed.
func Revive(st *v1alpha1.MachineStatus) bool {
	if st.Phase != v1alpha1.PhaseStale && st.Phase != v1alpha1.PhaseRetired {
		return false
	}
	st.Phase, st.StaleSince = v1alpha1.PhaseActive, nil
	return true
}

// Targetable is rule 12: a machine with no primary address is never the target of a
// run. Class node is exempt, because node mode uses no address.
func Targetable(m *v1alpha1.Machine) bool {
	return m.Spec.Class == v1alpha1.ClassNode || m.Status.PrimaryAddress != ""
}

// Step is what the stale times ask for one machine.
type Step string

// The steps.
const (
	Keep   Step = "Keep"
	Retire Step = "Retire"
	Purge  Step = "Purge"
)

// Age applies the retire and purge times. A Stale machine is retired once it has been
// stale for RetireAfter; a Retired machine is deleted once RetireAfter plus PurgeAfter
// have passed since staleSince. The time returned is when the next step falls due;
// it is zero when no step will fall due (an Active machine, or no staleSince).
func Age(s Settings, st v1alpha1.MachineStatus, now time.Time) (Step, time.Time) {
	if st.StaleSince == nil {
		return Keep, time.Time{}
	}
	retireAt := st.StaleSince.Add(s.RetireAfter)
	purgeAt := retireAt.Add(s.PurgeAfter)
	switch st.Phase {
	case v1alpha1.PhaseStale:
		if !now.Before(retireAt) {
			if !now.Before(purgeAt) {
				return Purge, time.Time{}
			}
			return Retire, purgeAt
		}
		return Keep, retireAt
	case v1alpha1.PhaseRetired:
		if !now.Before(purgeAt) {
			return Purge, time.Time{}
		}
		return Keep, purgeAt
	}
	return Keep, time.Time{}
}
```

```go
	}

	}

		t.Errorf("rule5: 10 of 100 absent is marked: got %d marked, held %v", len(got.Mark), got.Held)
	}

		t.Errorf("rule5: a later complete enumeration under the threshold ends the hold: %+v", got)
	}
```

```go
// Reconciler keeps the Machines of one MachineSource per reconcile. It is the only
// writer of Machine objects. Reader lists what a source of type nodes reads; in the
// manager it is the cached client, so the list comes from the Node informer.
type Reconciler struct {
	Client client.Client
	Reader client.Reader
	Now    func() time.Time
}

// SetupWithManager registers the controller: one reconcile per MachineSource when its
// spec changes, and one reconcile of every MachineSource of type nodes when a Node is
// added, removed or changes a fact a Machine records.
func (r *Reconciler) SetupWithManager(mgr ctrl.Manager) error {
	return ctrl.NewControllerManagedBy(mgr).
		Named("inventory").
		For(newObject(v1alpha1.MachineSourceKind), builder.WithPredicates(predicate.GenerationChangedPredicate{})).
		Watches(&corev1.Node{}, handler.EnqueueRequestsFromMapFunc(r.NodeSources), builder.WithPredicates(NodeFactsChanged())).
		Complete(r)
}

// NodeSources maps a Node event to every MachineSource of type nodes.
func (r *Reconciler) NodeSources(ctx context.Context, _ client.Object) []reconcile.Request {
	list := &unstructured.UnstructuredList{}
	list.SetGroupVersionKind(v1alpha1.MachineSourceListKind)
	if err := r.Client.List(ctx, list); err != nil {
		ctrl.LoggerFrom(ctx).Error(err, "list MachineSources for a Node event")
		return nil
	}
	var out []reconcile.Request
	for i := range list.Items {
		if t, _, _ := unstructured.NestedString(list.Items[i].Object, "spec", "type"); t == source.TypeNodes {
			out = append(out, reconcile.Request{NamespacedName: types.NamespacedName{Namespace: list.Items[i].GetNamespace(), Name: list.Items[i].GetName()}})
		}
	}
	return out
}

// NodeFactsChanged passes every Node that is added or removed, and an update only when
// the Sighting made from the Node changes. Status heartbeats pass no event.
func NodeFactsChanged() predicate.Funcs {
	return predicate.Funcs{
		UpdateFunc: func(e event.UpdateEvent) bool {
			oldNode, ok1 := e.ObjectOld.(*corev1.Node)
			newNode, ok2 := e.ObjectNew.(*corev1.Node)
			return !ok1 || !ok2 || !reflect.DeepEqual(source.NodeSighting(oldNode), source.NodeSighting(newNode))
		},
		GenericFunc: func(event.GenericEvent) bool { return false },
	}
}

}

// Reconcile enumerates one MachineSource and brings its Machines in line with it.
func (r *Reconciler) Reconcile(ctx context.Context, req ctrl.Request) (ctrl.Result, error) {
	u := newObject(v1alpha1.MachineSourceKind)
	if err := r.Client.Get(ctx, req.NamespacedName, u); err != nil {
		return ctrl.Result{}, client.IgnoreNotFound(err)
	}
	ms, err := v1alpha1.MachineSourceFromUnstructured(u)
	if err != nil {
		return ctrl.Result{}, err
	}
	settings, err := SettingsOf(ms.Spec.Stale)
	if err != nil {
		return ctrl.Result{}, r.writeSource(ctx, ms, false, "InvalidSpec", err.Error())
	}
	if ms.Spec.Suspended {
		return ctrl.Result{}, r.writeSource(ctx, ms, false, "Suspended", "spec.suspended is true: nothing is enumerated")
	}
	src, err := r.SourceFor(ms)
	if err != nil {
		return ctrl.Result{}, r.writeSource(ctx, ms, false, "InvalidSpec", err.Error())
	}
	now := r.now()
	e, enumErr := src.Enumerate(ctx)
	if enumErr != nil {
		e = source.Enumeration{StartedAt: now, FinishedAt: r.now()}
	}
	e.ID = NewULID(now)

	machines, err := r.listMachines(ctx, ms)
	if err != nil {
		return ctrl.Result{}, err
	}
	var active []string
	for id, m := range machines {
		if m.Status.Phase == v1alpha1.PhaseActive {
			active = append(active, id)
		}
	}
	sweep := DecideSweep(settings, e, enumErr, active, ms.Status.Held, now)
	ms.Status.Held = sweep.Held

	listed := map[string]bool{}
	var created int32
	for _, sight := range e.Sightings {
		listed[sight.ExternalID] = true
		if machines[sight.ExternalID] == nil {
			created++
		}
		if err := r.writeMachine(ctx, ms, machines[sight.ExternalID], sight, e); err != nil {
			return ctrl.Result{}, err
		}
	}
	stale := metav1.NewTime(e.FinishedAt)
	for _, id := range sweep.Mark {
		m := machines[id]
		m.Status.Phase, m.Status.StaleSince = v1alpha1.PhaseStale, &stale
		if err := r.putMachine(ctx, m, false); err != nil {
			return ctrl.Result{}, err
		}
	}
	var next time.Time
	for id, m := range machines {
		if listed[id] {
			continue
		}
		step, due := Age(settings, m.Status, now)
		switch step {
		case Retire:
			m.Status.Phase = v1alpha1.PhaseRetired
			if err := r.putMachine(ctx, m, false); err != nil {
				return ctrl.Result{}, err
			}
		case Purge:
			if err := r.deleteMachine(ctx, m); err != nil {
				return ctrl.Result{}, err
			}
		}
		if !due.IsZero() && (next.IsZero() || due.Before(next)) {
			next = due
		}
	}

	ms.Status.LastEnumeration = lastEnumeration(e, created, int32(len(sweep.Mark))) // #nosec G115 -- a count of Machines in one namespace
	reason, message, ready := "Enumerated", fmt.Sprintf("enumeration %s listed %d machines", e.ID, len(e.Sightings)), true
	if enumErr != nil {
		reason, message, ready = "EnumerationFailed", enumErr.Error(), false
	}
	if err := r.writeSource(ctx, ms, ready, reason, message, MayMarkStale(e, enumErr)); err != nil {
		return ctrl.Result{}, err
	}
	if enumErr != nil {
		return ctrl.Result{}, enumErr
	}
	if next.IsZero() {
		return ctrl.Result{}, nil
	}
	return ctrl.Result{RequeueAfter: next.Sub(now)}, nil
}

		}}

	}

// labelsOf are the five labels of a Machine: the only labels it may carry.
func labelsOf(m *v1alpha1.Machine) map[string]string {

	return map[string]string{

		v1alpha1.LabelOwnership: m.Status.Ownership,
		v1alpha1.LabelOSFamily:  family,

// putMachine writes a Machine: its labels first, then its status. Nothing is sent for
// a part that did not change.
func (r *Reconciler) putMachine(ctx context.Context, m *machine, isNew bool) error {
	labels := labelsOf(m.Machine)
	if isNew {
		m.Labels = labels
		obj, err := v1alpha1.MachineToUnstructured(m.Machine)
		if err != nil {
			return err
		}
		unstructured.RemoveNestedField(obj.Object, "status")
		if err := r.Client.Create(ctx, obj); err != nil {
			return fmt.Errorf("create Machine %s/%s: %w", m.Namespace, m.Name, err)
		}
		m.obj, m.ResourceVersion = obj, obj.GetResourceVersion()
	} else if !reflect.DeepEqual(m.obj.GetLabels(), labels) {
		m.obj.SetLabels(labels)
		if err := r.Client.Update(ctx, m.obj); err != nil {
			return fmt.Errorf("update the labels of Machine %s/%s: %w", m.Namespace, m.Name, err)
		}
		m.ResourceVersion = m.obj.GetResourceVersion()
	}
	m.Labels = labels
	obj, err := v1alpha1.MachineToUnstructured(m.Machine)
	if err != nil {
		return err
	}
	if !isNew && reflect.DeepEqual(obj.Object["status"], m.obj.Object["status"]) {
		return nil
	}
	if err := r.Client.Status().Update(ctx, obj); err != nil {
		return fmt.Errorf("update the status of Machine %s/%s: %w", m.Namespace, m.Name, err)
	}
	m.obj = obj
	return nil
}

// writeSource sets the conditions of a MachineSource and writes its status. complete
// is given only after an enumeration; without it, Complete and StaleHold are left as they are.
func (r *Reconciler) writeSource(ctx context.Context, ms *v1alpha1.MachineSource, ready bool, reason, message string, complete ...bool) error {
	set := func(kind string, ok bool, why, text string) {
		status := metav1.ConditionFalse
		if ok {
			status = metav1.ConditionTrue
		}
		meta.SetStatusCondition(&ms.Status.Conditions, metav1.Condition{Type: kind, Status: status, Reason: why, Message: text, ObservedGeneration: ms.Generation})
	}
	set(v1alpha1.ConditionReady, ready, reason, message)
	if len(complete) == 1 {
		if complete[0] {
			set(v1alpha1.ConditionComplete, true, "AllScopesRead", "the last enumeration read every scope")
		} else {
			set(v1alpha1.ConditionComplete, false, "Incomplete", "the last enumeration did not read every scope; nothing was marked stale")
		}
		if h := ms.Status.Held; h != nil {
			set(v1alpha1.ConditionStaleHold, true, "TooManyMissing", fmt.Sprintf("%d of %d active machines are missing; set spec.stale.releaseHoldFor to %s to mark them stale", h.WouldMarkStale, h.Live, h.EnumerationID))
		} else {
			set(v1alpha1.ConditionStaleHold, false, "NotHeld", "no sweep is held")
		}
	}
	obj, err := v1alpha1.MachineSourceToUnstructured(ms)
	if err != nil {
		return err
	}
	if err := r.Client.Status().Update(ctx, obj); err != nil {
		return fmt.Errorf("update the status of MachineSource %s/%s: %w", ms.Namespace, ms.Name, err)
	}
	return nil
}

// NewULID returns a ULID for the time t: 48 bits of milliseconds and 80 random bits,
// in the Crockford base-32 alphabet, 26 characters.
func NewULID(t time.Time) string {
	const alphabet = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"
	var b [16]byte
	binary.BigEndian.PutUint64(b[:8], uint64(t.UnixMilli())<<16) // #nosec G115 -- times after 1970
	if _, err := rand.Read(b[6:]); err != nil {
		panic(err)
	}
	hi, lo := binary.BigEndian.Uint64(b[:8]), binary.BigEndian.Uint64(b[8:])
	out := make([]byte, 26)
	for i := 25; i >= 0; i-- {
		out[i] = alphabet[lo&31]
		lo = lo>>5 | hi<<59
		hi >>= 5
	}
	return string(out)
}
```

```go
//
// Flag --controllers names the controllers to run, comma-separated. This version
// knows one controller, "inventory": it reads every MachineSource and keeps one
// Machine object per machine the source lists. Leader election uses the Lease
// machine-controller-<names> in the namespace of the pod, so that one replica works
// at a time. Health is served on :8081 (/healthz and /readyz); metrics are off.
package main

import (
	"flag"
	"fmt"
	"log/slog"
	"os"
	"sort"
	"strings"

	"github.com/go-logr/logr"
	"k8s.io/apimachinery/pkg/runtime"

	metricsserver "sigs.k8s.io/controller-runtime/pkg/metrics/server"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/machines/inventory"
)

// known lists the controllers this binary can run.
var known = map[string]bool{"inventory": true}

// parseControllers reads the value of --controllers: one or more known names,
// comma-separated, each at most once. It returns them sorted.
func parseControllers(value string) ([]string, error) {
	seen := map[string]bool{}
	var out []string
	for _, name := range strings.Split(value, ",") {
		name = strings.TrimSpace(name)
		switch {
		case name == "":
			return nil, fmt.Errorf("--controllers %q: a name is empty", value)
		case !known[name]:
			return nil, fmt.Errorf("--controllers %q: %q is not a controller of this binary (known: inventory)", value, name)
		case seen[name]:
			return nil, fmt.Errorf("--controllers %q: %q is named twice", value, name)
		}
		seen[name] = true
		out = append(out, name)
	}
	sort.Strings(out)
	return out, nil
}

func run(args []string) error {
	flags := flag.NewFlagSet("machine-controller", flag.ContinueOnError)
	value := flags.String("controllers", "", "controllers to run, comma-separated; known: inventory")
	if err := flags.Parse(args); err != nil {
		return err
	}
	names, err := parseControllers(*value)
	if err != nil {
		return err
	}
	ctrl.SetLogger(logr.FromSlogHandler(slog.NewJSONHandler(os.Stderr, nil)))

	scheme := runtime.NewScheme()
	if err := clientgoscheme.AddToScheme(scheme); err != nil {
		return err
	}
	cfg, err := ctrl.GetConfig()
	if err != nil {
		return err
	}
	mgr, err := ctrl.NewManager(cfg, ctrl.Options{
		Scheme:                 scheme,
		LeaderElection:         true,
		LeaderElectionID:       "machine-controller-" + strings.Join(names, "-"),
		HealthProbeBindAddress: ":8081",
		Metrics:                metricsserver.Options{BindAddress: "0"},
	})
	if err != nil {
		return err
	}
	for _, name := range names {
		if name == "inventory" {
			r := &inventory.Reconciler{Client: mgr.GetClient(), Reader: mgr.GetClient()}
			if err := r.SetupWithManager(mgr); err != nil {
				return fmt.Errorf("set up the inventory controller: %w", err)
			}
		}
	}
	if err := mgr.AddHealthzCheck("healthz", healthz.Ping); err != nil {
		return err
	}
	if err := mgr.AddReadyzCheck("readyz", healthz.Ping); err != nil {
		return err
	}
	return mgr.Start(ctrl.SetupSignalHandler())
}

func main() {
	if err := run(os.Args[1:]); err != nil {
		fmt.Fprintln(os.Stderr, "machine-controller:", err)
		os.Exit(1)
	}
```
