# PRD-501 — Resource server base: store, definitions loader, router with the token check, account-access consent resources, not-offered answers

## In plain words

**The problem today.** The open-banking product has its standards profile, its generated server code, its consent rules and its token rules, but nothing that answers a call. No router puts the generated operations behind the token check, no code keeps a consent, and nothing reads the partners that an installation defines. So no operation of the product can be called yet, and nothing stops a later change from adding a route that skips the token check.

**What changes.** The product gains a resource server that routes all 88 operations of its five served documents, checks the token on every one, serves the three account-access consent operations over a consent store kept in memory, reads the partners from the installation's definitions, and answers every other operation with the status the profile names. The product guard gains two rules: the route test must exist, and the list of operations not yet implemented may only shrink.

**Done means:**

- A call to any of the 88 routes without a token is refused with status 401 and the standard challenge header.
- A third party with a valid token can create an account-access consent, read it, and delete it once the customer has authorised it, and every answer validates against the publisher's document.
- Each of the 25 operations that the profile does not offer, and every operation of a family that the installation does not serve, answers status 404.
- The conformance test prints the counter 3/63: three of the 63 operations the profile serves are implemented.
- The product guard fails when the route test is removed, when an implemented operation is listed again as not implemented, or when a vendored document no longer matches its checksum.
- Every test of the product passes on the pull request, and the linter and the security scan find nothing new.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The open-banking product `products/fingate` has a resource server package, `internal/api`. It routes every operation of the five documents the product serves, 88 in all, through the generated server code of `internal/gen`. On every route the token rules T1 to T10 of `internal/token` run; before routing, rules T1 to T5 already refuse a call without a valid token. The three account-access consent operations work: create (`POST /account-access-consents`), read (`GET /account-access-consents/{ConsentId}`) and delete (`DELETE /account-access-consents/{ConsentId}`), over a consent store (`internal/store`) that applies the transition table of `internal/consent`. The partners and the served API families come from the installation's definitions (`internal/definitions`). Every other operation answers the profile's `notImplementedStatus`, 404. The test `TestDocumentConformance` prints `C1: 3/63`. The product guard `scripts/check-products.py` gains rule G-P4 (the route test exists) and rule G-P7 (the list of served operations not implemented yet only shrinks, and every vendored document matches its checksum).

## 3. The model (the law)
1. **Every route is authenticated.** The router has one route per operation of the documents `account-info`, `payment-initiation`, `vrp`, `confirmation-funds` and `events` of profile `rw-4.0.0`: 29 + 41 + 9 + 4 + 5 = 88 routes. The document `event-notifications` is not routed: its one operation is one the product calls on a third party. Before routing, `token.Checker.Verify` (rules T1 to T5) runs on every call; on failure the answer is 401 with the header `WWW-Authenticate: Bearer error="invalid_token"`. On a served route, `token.Checker.Check` (rules T1 to T10) runs with the grant and the scopes that the document's `security` gives the operation (`TPPOAuth2Security` is the client grant, `PSUOAuth2Security` the customer grant), the API family of the document and, for a customer operation, its consent family and the path values `AccountId` and `ConsentId`. A failed rule answers its status (401 for T1 to T6, 403 for T7 to T10). There is no observe mode and no switch that weakens a rule. `TestEveryRouteAuthenticated` in `products/fingate/internal/api/router_test.go` walks every route; its list of unrouted paths is empty.
2. **What is not served answers 404 after the token is verified.** An operation under a `notOffered` prefix of the profile (25 operations), an operation of an API family that the definitions do not serve, and an operation listed in `products/fingate/internal/api/unimplemented.txt` answer the profile's `notImplementedStatus` (404) with no body. They never reach generated code.
3. **`unimplemented.txt` only shrinks.** It names, one per line as `<api> <METHOD> <path>`, sorted, the operations the profile serves that this package does not implement yet: 60 lines (63 served minus the three consent operations). The router reads it with `go:embed`. A package that implements an operation deletes its line in the same change, and guard rule G-P7 counts the lines with a baseline that only falls. The C1 counter is `<63 minus the lines>/63`.
4. **The API families.** `account-info` is family `accounts` with consent family `account-access`; `payment-initiation` is `payments` with `payment`; `vrp` is `vrp` with `vrp`; `confirmation-funds` is `funds-confirmation` with `funds-confirmation`; `events` is `events` with no consent family. Each document's routes are mounted under the document's own server path (`/open-banking/v4.0/aisp` for account information), which lies under the profile's `basePath`.
5. **The consent operations.** Create stores a consent of family `account-access`, state `awaiting`, for the client of the token, with the identifier `aac-` and 32 random hexadecimal characters, and answers 201 with the wire code `AWAU`. It refuses with 400 an empty, unknown or repeated permission, a missing `Risk`, an expiry that is not in the future, and a transaction period whose start is after its end; a body that is not JSON answers 415. Read answers 200 with the wire code of the state. Delete applies the event `revoke` by the third party; only an `authorised` consent can be revoked, as the table of `internal/consent` says, so a delete of a consent in another state answers 400. A consent that does not exist, or that belongs to another client, answers 400 to read and delete. An authorised consent whose expiry has passed is expired by the system when it is read, never by a timer.
6. **Errors.** Every error body is the documents' `OBErrorResponse1` with one entry, the code `NARR` (the reason is given as text) and the reason in `Message`. Every answer carries `x-fapi-interaction-id`: the request's value, or a new random one.
7. **The store.** `store.Store` is the port: `Create`, `Get` (with the expiry on read), `Authorise` (the customer's decision, with the customer and the accounts) and `Apply` (any other event). Every accepted transition appends exactly one history entry in the same write. `store.Memory` is the implementation of this ticket; `storetest.Run` holds the tests every implementation must pass.
8. **The definitions.** `definitions.Parse` reads the installation's parameters (profile, host, ledger target, products, partners and their applications) and refuses a document that breaks one rule of the parameter schema, with every broken rule named. Only the family `accounts` is released; a document naming another family is refused. A `definitions.Holder` keeps the definitions in use and answers the partner lookup of rule T7; a new `Set` takes effect on the next call. Before the first `Set` a call answers 503.
9. **The guard.** G-P4 is a hard zero: `products/fingate/internal/api/router_test.go` declares `func TestEveryRouteAuthenticated(t *testing.T) {`. G-P7 is a ratchet: the lines of `unimplemented.txt` (baseline 60), and one count for each line of a `products/fingate/profiles/*/profile.yaml` that names a document whose SHA-256 differs from the one the line states. A `profile.yaml` that names no document is not judged (exit 2). A baseline only goes down.
10. Nothing is deleted.

//
// The definitions are the Application's parameters: the profile, the public host of the
// resource server, the ledger target, the API families the installation serves and the

package definitions

// Released lists the API families an installation may serve. A family is added here only by

// MaxPartners is the largest number of partners a document may hold.
const MaxPartners = 1000

// Definitions are the parameters of one installation.
type Definitions struct {

// Parse reads one definitions document and checks it. It returns every broken rule.
func Parse(raw []byte) (*Definitions, error) {
	var d Definitions
	dec := yaml.NewDecoder(bytes.NewReader(raw))
	dec.KnownFields(true)
	if err := dec.Decode(&d); err != nil {
		return nil, fmt.Errorf("definitions: %w", err)
	}
	if err := d.check(); err != nil {
		return nil, fmt.Errorf("definitions: %w", err)
	}
	return &d, nil

	bad := func(format string, a ...any) { errs = append(errs, fmt.Errorf(format, a...)) }

			}

			if !slices.Contains(clientAuth, a.ClientAuth) {
				bad("%s: clientAuth %q is not one of %s", where, a.ClientAuth, strings.Join(clientAuth, ", "))
			}
			if len(a.RedirectURIs) == 0 {
				bad("%s: redirectUris is empty", where)
			}
			for _, u := range a.RedirectURIs {
				if !strings.HasPrefix(u, "https://") {
					bad("%s: redirect address %q does not start with https://", where, u)
				}
			}
			if a.JWKSURI != "" && !strings.HasPrefix(a.JWKSURI, "https://") {
				bad("%s: jwksUri %q does not start with https://", where, a.JWKSURI)
			}
			if a.Webhook != "" && !strings.HasPrefix(a.Webhook, "https://") {
				bad("%s: webhook %q does not start with https://", where, a.Webhook)
			}
			for k, c := range a.Certificates {

					bad("%s.certificates[%d]: sha256 %q is not a base64url SHA-256", where, k, c.SHA256)

			}

		return slices.Contains(Released, family)

// Application returns the application whose client identifier is clientID, in the form the
// token rules read it.
func (d *Definitions) Application(clientID string) (token.Application, bool) {
	partnerID, appID, ok := strings.Cut(clientID, ".")
	if !ok {
		return token.Application{}, false
	}
	for _, p := range d.Partners {
		if p.ID != partnerID {
			continue
		}
		for _, a := range p.Applications {
			if a.ID != appID {
				continue
			}
			pins := make([]string, 0, len(a.Certificates))
			for _, c := range a.Certificates {
				pins = append(pins, c.SHA256)
			}
			return token.Application{PartnerState: p.State, Pins: pins, Products: slices.Clone(a.Products)}, true
		}
	}
	return token.Application{}, false
}

// Holder keeps the definitions in use. It is safe for concurrent use.
type Holder struct {
	current atomic.Pointer[Definitions]
}

// Set replaces the definitions in use.
func (h *Holder) Set(d *Definitions) { h.current.Store(d) }

// Current returns the definitions in use, or nil before the first Set.
func (h *Holder) Current() *Definitions { return h.current.Load() }

// ErrNoDefinitions is returned by a lookup before the first Set.
var ErrNoDefinitions = errors.New("definitions: none loaded yet")

// Application implements token.Partners.
func (h *Holder) Application(_ context.Context, clientID string) (token.Application, bool, error) {
	d := h.Current()
	if d == nil {
		return token.Application{}, false, ErrNoDefinitions
	}
	app, ok := d.Application(clientID)
	return app, ok, nil
}

// Package store keeps the consents of the open-banking product.
//
// A Consent is one row of the table consent with its rows of consent_history. Every change of
// state goes through the consent package's transition table, and every accepted transition
// appends exactly one history entry in the same write as the state. An authorised consent
// whose expiry has passed is expired by the system when it is read; no timer does it.
//
// Store is the port. Memory is the implementation for tests and for a ledger of fixtures; it keeps
// everything in the process. The PostgreSQL implementation follows the same port.
package store

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"slices"
	"sync"
	"time"

	"github.com/openova-io/openova/products/fingate/internal/consent"
)

// Consent is one stored consent.
type Consent struct {
	ID         string
	Family     consent.Family
	ClientID   string
	State      consent.State
	Request    json.RawMessage // the request body as received
	CustomerID string          // set when the customer authorises
	Accounts   []string        // the accounts the customer chose; set when the customer authorises
	ExpiresAt  time.Time       // zero: no expiry
	CreatedAt  time.Time
	StateAt    time.Time // when the state last changed
	History    []consent.HistoryEntry
}

// ErrNotFound is returned for a consent that does not exist.
var ErrNotFound = errors.New("store: consent not found")

// ErrExists is returned when a consent with the same identifier exists already.
var ErrExists = errors.New("store: consent exists already")

// Store keeps consents. A transition that the consent package refuses returns an error that
// wraps consent.ErrTransition and changes nothing.
type Store interface {
	// Create stores a new consent in the state awaiting, created by the third party.
	// ID, Family, ClientID and Request are read from c; ExpiresAt is read when it is set.
	Create(ctx context.Context, c Consent) (Consent, error)
	// Get returns the consent. When it is authorised and its expiry has passed, Get first
	// records the event expire by the system.
	Get(ctx context.Context, id string) (Consent, bool, error)
	// Authorise records the customer's decision authorise, with the customer and the accounts.
	Authorise(ctx context.Context, id, customerID string, accounts []string) (Consent, error)
	// Apply records one event caused by actor. Use Authorise for the event authorise.
	Apply(ctx context.Context, id string, event consent.Event, actor consent.Actor, reason string) (Consent, error)
}

// Memory is a Store that keeps everything in the process. It is safe for concurrent use.
type Memory struct {
	now func() time.Time

	mu   sync.Mutex
	rows map[string]Consent
}

// NewMemory returns an empty Memory store. now may be nil: time.Now.
func NewMemory(now func() time.Time) *Memory {
	if now == nil {
		now = time.Now
	}
	return &Memory{now: now, rows: map[string]Consent{}}
}

// Create implements Store.
func (m *Memory) Create(_ context.Context, c Consent) (Consent, error) {
	if c.ID == "" || c.ClientID == "" || !slices.Contains(consent.Families(), c.Family) {
		return Consent{}, fmt.Errorf("store: a consent needs an identifier, a client and a family, got %q, %q, %q", c.ID, c.ClientID, c.Family)
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	if _, ok := m.rows[c.ID]; ok {
		return Consent{}, fmt.Errorf("%w: %s", ErrExists, c.ID)
	}
	now := m.now()
	r := consent.Record{Family: c.Family}
	if err := r.Apply(consent.Create, consent.ThirdParty, "created", now); err != nil {
		return Consent{}, err
	}
	row := Consent{ID: c.ID, Family: c.Family, ClientID: c.ClientID, State: r.State,
		Request: slices.Clone(c.Request), ExpiresAt: c.ExpiresAt, CreatedAt: now, StateAt: now, History: r.History}
	m.rows[c.ID] = row
	return clone(row), nil
}

// Get implements Store.
func (m *Memory) Get(_ context.Context, id string) (Consent, bool, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	row, ok := m.rows[id]
	if !ok {
		return Consent{}, false, nil
	}
	now := m.now()
	if row.State == consent.Authorised && !row.ExpiresAt.IsZero() && !now.Before(row.ExpiresAt) {
		next, err := m.apply(row, consent.Expire, consent.System, "expires_at passed", now)
		if err != nil {
			return Consent{}, false, err
		}
		row = next
	}
	return clone(row), true, nil
}

// Authorise implements Store.
func (m *Memory) Authorise(_ context.Context, id, customerID string, accounts []string) (Consent, error) {
	if customerID == "" {
		return Consent{}, errors.New("store: authorise needs a customer")
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	row, ok := m.rows[id]
	if !ok {
		return Consent{}, fmt.Errorf("%w: %s", ErrNotFound, id)
	}
	row.CustomerID, row.Accounts = customerID, slices.Clone(accounts)
	next, err := m.apply(row, consent.Authorise, consent.Customer, "authorised", m.now())
	if err != nil {
		return Consent{}, err
	}
	return clone(next), nil
}

// Apply implements Store.
func (m *Memory) Apply(_ context.Context, id string, event consent.Event, actor consent.Actor, reason string) (Consent, error) {
	if event == consent.Authorise || event == consent.Create {
		return Consent{}, fmt.Errorf("store: use Authorise or Create for the event %s", event)
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	row, ok := m.rows[id]
	if !ok {
		return Consent{}, fmt.Errorf("%w: %s", ErrNotFound, id)
	}
	next, err := m.apply(row, event, actor, reason, m.now())
	if err != nil {
		return Consent{}, err
	}
	return clone(next), nil
}

// apply applies one event to row and stores the result. The caller holds m.mu.
func (m *Memory) apply(row Consent, event consent.Event, actor consent.Actor, reason string, at time.Time) (Consent, error) {
	r := consent.Record{Family: row.Family, State: row.State, History: slices.Clone(row.History)}
	if err := r.Apply(event, actor, reason, at); err != nil {
		return Consent{}, err
	}
	row.State, row.StateAt, row.History = r.State, at, r.History
	m.rows[row.ID] = row
	return row, nil
}

func clone(c Consent) Consent {
	c.Request = slices.Clone(c.Request)
	c.Accounts = slices.Clone(c.Accounts)
	c.History = slices.Clone(c.History)
	return c
}

// ServeHTTP answers a call to a resource path.
func (s *Server) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	iid := r.Header.Get(InteractionHeader)
	if iid == "" {
		iid = s.cfg.NewID()
		r.Header.Set(InteractionHeader, iid)
	}
	w.Header().Set(InteractionHeader, iid)
	if _, err := s.cfg.Checker.Verify(r.Context(), bearer(r)); err != nil {
		s.refuse(w, err)
		return
	}
	// The generated code binds a body of "application/json; charset=utf-8" twice and fails on
	// the second read; that form means the same as "application/json".
	if mt, params, err := mime.ParseMediaType(r.Header.Get("Content-Type")); err == nil && mt == "application/json" &&
		len(params) == 1 && strings.EqualFold(params["charset"], "utf-8") {
		r.Header.Set("Content-Type", "application/json")
	}
	_, pattern := s.mux.Handler(r)
	op := s.ops[pattern]
	if op == nil {
		s.mux.ServeHTTP(w, r) // no route: the router answers 404 or 405
		return
	}
	defs := s.cfg.Definitions.Current()
	if defs == nil {
		s.writeError(w, http.StatusServiceUnavailable, "the definitions of this installation are not loaded yet")
		return
	}
	if !op.Served || !defs.Serves(op.Product) {
		w.WriteHeader(s.cfg.Profile.NotImplementedStatus)
		return
	}
	s.mux.ServeHTTP(w, r)
}

// check applies rules T1 to T10 on a route. It runs after the generated code bound the parameters.
func (s *Server) check(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		op := s.ops[r.Pattern]
		if op == nil || !op.Served {
			w.WriteHeader(s.cfg.Profile.NotImplementedStatus)
			return
		}
		desc := token.Operation{Grant: op.Grant, Scopes: op.Scopes, Product: op.Product}
		if op.Grant == token.GrantCustomer {
			desc.ConsentFamily, desc.AccountID, desc.ConsentID = op.Consent, r.PathValue("AccountId"), r.PathValue("ConsentId")
			// A family's implementation names the consent permissions an operation needs (rule
			// T9) with a method permissions(key string) []string; without one, none is needed.
			if p, ok := any(s.impl).(interface{ permissions(key string) []string }); ok {
				desc.Permissions = p.permissions(op.Key)
			}
		}
		claims, err := s.cfg.Checker.Check(r.Context(), token.Request{JWS: bearer(r), Thumbprint: thumbprint(r), Operation: desc})

			s.refuse(w, err)
			return
		}
		next.ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), claimsKey, claims)))
	})
}

			Security *secList `yaml:"security"`
		} `yaml:"paths"`

		return "", nil, fmt.Errorf("api: %s: %w", file, err)

		return "", nil, fmt.Errorf("api: %s must name exactly one server, as a path", file)

				continue
			}

			}

				return "", nil, fmt.Errorf("api: %s: %s %s must have exactly one security requirement", file, m, path)
			}

				var g token.Grant
				switch scheme {
				case "TPPOAuth2Security":
					g = token.GrantClient
				case "PSUOAuth2Security":
					g = token.GrantCustomer
				default:
					return "", nil, fmt.Errorf("api: %s: %s %s uses the unknown scheme %s", file, m, path, scheme)
				}
				if len(scopes) == 0 {
					return "", nil, fmt.Errorf("api: %s: %s %s names no scope", file, m, path)
				}
				out[m+" "+path] = requirement{grant: g, scopes: scopes}
			}
		}
	}
	return strings.TrimSuffix(doc.Servers[0].URL, "/"), out, nil
}

// parseUnimplemented reads unimplemented.txt: one "<api> <METHOD> <path>" per line, no duplicates.

		line := sc.Text()
		f := strings.Fields(line)
		if len(f) != 3 || strings.Join(f, " ") != line || out[line] {
			return nil, fmt.Errorf("api: unimplemented.txt line %d %q is not \"<api> <METHOD> <path>\" or is repeated", n, line)
		}
		out[line] = true
	}
	return out, nil
}

func checkConsentRequest(b *accountinfo.OBReadConsent1, now time.Time) string {

		return "Data.Permissions is empty"

		if !p.Valid() {
			return fmt.Sprintf("Data.Permissions[%d] %q is not a permission", i, p)
		}
		if slices.Contains(b.Data.Permissions[:i], p) {
			return fmt.Sprintf("Data.Permissions[%d] %q is repeated", i, p)
		}
