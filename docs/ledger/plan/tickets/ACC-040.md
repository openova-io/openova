# ACC-040 — Access guards with their baselines

## In plain words

**The problem today.** The browser access gateway, the exec proxy and the exec handlers of the API still hold things the access design removes: a timer that writes the gateway database, a seeded administrator permission, credentials copied into the gateway store, a cloud provider name, image tags, a fabricated session code path, routes that pass without a signed-in user, and documents that claim session recording. Nothing stops a change from adding more of them while they are being removed.

**What changes.** A check on every pull request counts each of the eight kinds per file and compares the counts with stored numbers. A change that adds one fails. A change that removes one must lower the stored number in the same change. The one exception, the image tag that CI writes into the exec proxy chart, is listed with a reason and an owner.

**Done means:**

- A pull request that adds a timer to the gateway or exec proxy chart, a seeded administrator permission, a copied gateway credential, a provider name in the two charts or an image tag line in their values turns red.
- A pull request that adds the fabricated session code, a route in the exec handlers that passes without claims, or a document line that claims session recording outside a target section turns red.
- A pull request that removes one of these must lower the stored number in the same change, so the stored numbers are always exact.
- The timer and the seeded permission can never be excused by an allow entry; the only allow entry is the exec proxy image tag that CI writes, with its reason and owner.
- The check proves on trees of its own that each of its rules can fail, and prints one self-test ok line per guard.
- No product code, chart or document changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every pull request and merge group gets a check named `access-guards`. It runs `scripts/check-access-guards.sh`, which counts eight things per file, the guards ACC-GD1 to ACC-GD8: CronJob kinds in the gateway and exec-proxy chart templates, seeded administrator permissions in the gateway Blueprint, credential copies in the gateway templates, the provider name in the two access charts, image tag lines in their two values files, the fabricated session code under `products/`, routes of the exec handlers that pass without claims, and recording claims in the architecture document and the gateway Blueprint. It compares each file's count with the number stored for it in `scripts/baselines/access.json`. The check is red when a count is above its stored number, and red when it is below it until the stored number is lowered in the same change. A person sees the result on any pull request: the check prints the self-test, then the eight totals in the form `ACC-GD1=<n>`.

## 3. The model (the law)
1. The guard is the file `scripts/check-access-guards.sh`. It is a bash file that runs one Python 3 program, embedded in it. It needs bash, Python 3 (standard library only) and git. It reads the files that `git ls-files --cached --others --exclude-standard` lists in the checkout: tracked files, and new files that no ignore rule covers. A path with a folder named `node_modules` is never read.
2. It counts eight metrics per file. Each metric reads only the files named here:

   | Metric | Files it reads | What counts in a file |
   |---|---|---|
   | `ACC-GD1` | every file under `platform/guacamole/chart/templates` and `platform/k8s-ws-proxy/chart/templates` | each line that starts with `kind:`, then spaces, then `CronJob` |
   | `ACC-GD2` | every file under `platform/guacamole` | each `INSERT INTO guacamole_system_permission`, in any case, also across a line end |
   | `ACC-GD3` | every file under `platform/guacamole/chart/templates` | each line with `load_connection_credentials` |
   | `ACC-GD4` | every file under `platform/guacamole` and `platform/k8s-ws-proxy` | each line that names the provider of the first cloud, in any case (the expression `PROVIDER` of the script) |
   | `ACC-GD5` | `platform/guacamole/chart/values.yaml` and `platform/k8s-ws-proxy/chart/values.yaml` | each line that starts, after spaces, with `tag:` |
   | `ACC-GD6` | every file under `products` | each line with `synthesizeSession`, `GuacamoleClient` or `HandleShellsIssue` |
   | `ACC-GD7` | the files `k8s_exec*.go` directly in `products/catalyst/bootstrap/api/internal/handler`, and the files `*.go` directly in `products/catalyst/bootstrap/api/internal/accessintent` | each line `if claims == nil` when that line, the next line or the line after holds `return true` |
   | `ACC-GD8` | `docs/ARCHITECTURE.md` and every file under `platform/guacamole` | each line with `recording to SeaweedFS` or `recordings on SeaweedFS`, in any case, except a line of a target section of a Markdown file |

3. A target section, for `ACC-GD8`. In a file whose name ends in `.md`, a section starts at a heading line (one to six `#` and a space) and runs to the next heading of the same or a higher level. It is a target section when the first non-empty line after its heading starts with `> State: target.`, the target marker of `scripts/check-doc-state.py`, or when it lies inside a target section. A line inside a fenced code block is never a heading. In a file of another kind every matching line counts.
4. The stored numbers are the file `scripts/baselines/access.json`, called the baseline. Its form is the shared form of the guard baselines under `scripts/baselines`:
   ```
   {"schema": "openova.io/guard-baseline/v1",
    "counts": {"<metric>": {"<repository path>": <number>}},
    "allow": [{"metric": "<metric>", "path": "<repository path>", "count": <number>, "reason": "<ten characters or more>", "owner": "<area prefix>"}]}
   ```
   `counts` holds exactly the eight metrics, and per metric one entry for each file that has at least one count after the allow entries. A file that is absent from a metric is allowed zero. Every number is 1 or more.
5. `allow` lists matches that stay for a stated reason or belong to another area. The count of an allow entry is subtracted from the file's count before the comparison. An entry has exactly the five keys shown, `metric` is one of the eight, `count` is 1 or more, `reason` has ten characters or more, `owner` is three capital letters, and there is at most one entry per metric and path. `ACC-GD1` and `ACC-GD2` take no allow entry at all.
6. The rule, for every metric and every path: when the count after the allow entries is above the path's entry, the guard exits with code 1 and names the lines of the matches. When the entry is above the count, it exits with code 1 too: the baseline must be lowered in the same change. When an allow entry is above the file's count, or is malformed, it exits with code 1. Otherwise it exits with code 0. Whenever it judges, it prints eight lines `<metric>=<total>`, in the order `ACC-GD1` to `ACC-GD8`: what the tree holds, before the allow entries.
7. A baseline only goes down. `--write-baseline` writes the baseline from the tree. When the baseline file exists, it refuses to raise an entry or to add a path, exits with code 1 and leaves the file as it was; when it writes, it keeps the allow list as it is. When no baseline file exists, it writes the allow list `SEED_ALLOW` of the script: one entry, field 5. A later package that removes a match runs `bash scripts/check-access-guards.sh --write-baseline` in its own change.
8. When the checkout or the baseline cannot be read, the guard judges nothing and exits with code 2. A missing baseline, a baseline of another schema, a baseline without one of the eight metrics, a baseline entry of 0, a tree that is not a git checkout, and a missing one of the seven paths `platform/guacamole/chart/templates`, `platform/k8s-ws-proxy/chart/templates`, `platform/guacamole/chart/values.yaml`, `platform/k8s-ws-proxy/chart/values.yaml`, `products`, `products/catalyst/bootstrap/api/internal/handler` and `docs/ARCHITECTURE.md` are never a pass. The folder `products/catalyst/bootstrap/api/internal/accessintent` does not exist yet; it is read when it exists.
9. `--self-test` builds a small git tree of its own, once per case, 61 times, and shows for each rule that it fails and for each exception that it passes; a 62nd case checks the seed allow list. It reads nothing of the repository. For each guard whose cases all pass it prints one line `self-test ok <metric>`, eight lines in all, and it ends with the line `check-access-guards: self-test passed: 62 of 62 cases as expected`.
10. The workflow `.github/workflows/access-guards.yaml` has the name `access-guards`, the triggers `pull_request` and `merge_group`, and no path filter. Its one job, `access-guards`, runs the self-test first and then the guard. Its checkout step names the action by its commit, `actions/checkout@11d5960a326750d5838078e36cf38b85af677262 # v4.4.0`.
11. The script and the workflow are the two blocks of field 5, byte for byte. The baseline is written by the script (step 6 of field 16). It is never typed or edited by hand.
12. This ticket changes no product code, no chart, no document and no existing file. It deletes nothing.

class Unreadable(Exception):
    """The checkout or the baseline cannot be read. Nothing is judged: exit 2."""
def under(path, *tops):
    return any(path == top or path.startswith(top + "/") for top in tops)
def lines_with(text, regex):
    return [n + 1 for n, line in enumerate(text.split("\n")) if regex.search(line)]
def target_lines(lines):
    """The 0-based numbers of the lines that lie inside a target section of a Markdown text."""
    heads, fence = [], None
    for i, line in enumerate(lines):
        if fence:
            if line.strip() and set(line.strip()) == {fence[0]} and len(line.strip()) >= len(fence):
                fence = None
            continue
        m = FENCE.match(line)
        if m:
            fence = m.group(1)
            continue
        h = HEADING.match(line)
        if h:
            heads.append((i, len(h.group(1))))
    marked = {}
    for k, (i, level) in enumerate(heads):
        end = heads[k + 1][0] if k + 1 < len(heads) else len(lines)
        first = next((lines[j] for j in range(i + 1, end) if lines[j].strip()), "")
        marked[i] = bool(TARGET.match(first))
    out, stack, starts = set(), [], dict(heads)
    for i in range(len(lines)):
        if i in starts:
            while stack and stack[-1][0] >= starts[i]:
                stack.pop()
            stack.append((starts[i], marked[i]))
        if any(t for _, t in stack):
            out.add(i)
    return out

def listed(root):
    """The files git lists in the checkout: tracked, and new ones no ignore rule covers."""
    try:
        out = subprocess.run(["git", "-C", root, "ls-files", "-z", "--cached", "--others", "--exclude-standard"],
                             check=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE).stdout
    except (OSError, subprocess.CalledProcessError):
        raise Unreadable("%s is not a git checkout" % root)
    paths = set()
    for p in out.decode("utf-8", "surrogateescape").split("\0"):
        full = os.path.join(root, p)
        if p and "node_modules" not in p.split("/") and os.path.isfile(full) and not os.path.islink(full):
            paths.add(p)
    return sorted(paths)
def measure(root):
    """metric -> repository path -> line numbers (1-based) of what counts."""
    for need in REQUIRED:
        if not os.path.exists(os.path.join(root, need)):
            raise Unreadable("%s does not exist" % need)
    paths = listed(root)
    cache = {}

    def read(p):
        if p not in cache:
            with open(os.path.join(root, p), "rb") as f:
                cache[p] = f.read().decode("utf-8", "replace")
        return cache[p]

    return {metric: {p: n for p, n in GUARDS[metric](paths, read).items() if n} for metric in METRICS}
def check_allow(allow):
    """Returns (allow entries that are well formed, failure lines about the others)."""
    good, fails, seen = [], [], set()
    for i, e in enumerate(allow):
        where = "allow[%d]" % i
        if not isinstance(e, dict) or sorted(e) != ALLOW_KEYS:
            fails.append("%s: an allow entry has exactly the keys %s" % (where, ", ".join(ALLOW_KEYS)))
        elif e["metric"] not in METRICS:
            fails.append("%s: metric must be one of %s" % (where, ", ".join(METRICS)))
        elif e["metric"] in NO_ALLOW:
            fails.append("%s: %s takes no allow entry" % (where, e["metric"]))
        elif not isinstance(e["path"], str) or not e["path"]:
            fails.append("%s: path must be a repository path" % where)
        elif type(e["count"]) is not int or e["count"] < 1:
            fails.append("%s: count must be a whole number of 1 or more" % where)
        elif not isinstance(e["reason"], str) or len(e["reason"].strip()) < 10:
            fails.append("%s: reason must be ten characters or more" % where)
        elif not isinstance(e["owner"], str) or not OWNER.match(e["owner"]):
            fails.append("%s: owner must be an area prefix of three capital letters" % where)
        elif (e["metric"], e["path"]) in seen:
            fails.append("%s: a second allow entry for %s %s; one entry per metric and path" % (where, e["metric"], e["path"]))
        else:
            seen.add((e["metric"], e["path"]))
            good.append(e)
    return good, fails
def read_baseline(root):
    """Returns (counts, the allow list as written, its well-formed entries, failure lines)."""
    try:
        with open(os.path.join(root, BASELINE), encoding="utf-8") as f:
            doc = json.load(f)
    except (OSError, ValueError) as e:
        raise Unreadable("%s cannot be read: %s" % (BASELINE, e))
    counts = doc.get("counts") if isinstance(doc, dict) else None
    if not isinstance(doc, dict) or doc.get("schema") != SCHEMA or not isinstance(counts, dict) or sorted(counts) != sorted(METRICS):
        raise Unreadable("%s: need schema %s and counts for exactly %s" % (BASELINE, SCHEMA, ", ".join(METRICS)))
    for metric in METRICS:
        if not isinstance(counts[metric], dict) or not all(type(v) is int and v >= 1 for v in counts[metric].values()):
            raise Unreadable("%s: counts.%s must map a path to a whole number of 1 or more" % (BASELINE, metric))
    if not isinstance(doc.get("allow"), list):
        raise Unreadable("%s: allow must be a list" % BASELINE)
    return (counts, doc["allow"]) + check_allow(doc["allow"])
def net(have, allow):
    """(metric -> path -> count after the allow entries, failure lines for allow entries above the count)."""
    out = {metric: {p: len(lines) for p, lines in have[metric].items()} for metric in METRICS}
    fails = []
    for e in allow:
        now = out[e["metric"]].get(e["path"], 0)
        if e["count"] > now:
            fails.append("%s: %s has %d, its allow entry says %d; lower or remove the allow entry in the same change" % (e["metric"], e["path"], now, e["count"]))
        out[e["metric"]][e["path"]] = max(now - e["count"], 0)
    return {metric: {p: n for p, n in out[metric].items() if n} for metric in METRICS}, fails
def compare(have, after, entries):
    """One (rose, line) per path whose count after the allow entries is not exactly its baseline entry."""
    out = []
    for metric in METRICS:
        for p in sorted(set(after[metric]) | set(entries[metric])):
            now, entry = after[metric].get(p, 0), entries[metric].get(p, 0)
            if now > entry:
                at = ", ".join(str(n) for n in have[metric].get(p, []))
                out.append((True, "%s: %s has %d, the baseline allows %d (match lines: %s); %s" % (metric, p, now, entry, at, TITLE[metric])))
            elif now < entry:
                out.append((False, "%s: %s has %d, the baseline still says %d; lower the baseline in the same change" % (metric, p, now, entry)))
    return out
def dump(counts, allow):
    """The baseline text: one line per allow entry and per counted path, keys sorted."""
    rows = ",\n".join("    " + json.dumps(e, sort_keys=True) for e in allow)
    blocks = []
    for metric in sorted(counts):
        body = ",\n".join("      %s: %d" % (json.dumps(p), n) for p, n in sorted(counts[metric].items()))
        blocks.append("    %s: {%s}" % (json.dumps(metric), "\n" + body + "\n    " if body else ""))
    return '{\n  "allow": [%s],\n  "counts": {\n%s\n  },\n  "schema": %s\n}\n' % (
        "\n" + rows + "\n  " if rows else "", ",\n".join(blocks), json.dumps(SCHEMA))
def run(root, write=False, say=print, seed=None):
    """The whole guard. Returns the exit code. seed is the allow list of a first write."""
    try:
        have = measure(root)
        if write:
            if os.path.exists(os.path.join(root, BASELINE)):
                old, kept, good, bad = read_baseline(root)
            else:
                old, kept = None, SEED_ALLOW if seed is None else seed
                good, bad = check_allow(kept)
            after, over = net(have, good)
            refused = bad + over + [line for rose, line in (compare(have, after, old) if old is not None else []) if rose]
            if refused:
                for line in refused:
                    say("%s: FAIL %s" % (ME, line))
                say("%s: the baseline was not written: a baseline only goes down" % ME)
                return 1
            os.makedirs(os.path.join(root, os.path.dirname(BASELINE)), exist_ok=True)
            with open(os.path.join(root, BASELINE), "w", encoding="utf-8") as f:
                f.write(dump(after, kept))
            say("%s: wrote %s" % (ME, BASELINE))
        entries, _, allow, fails = read_baseline(root)
    except Unreadable as e:
        say("%s: cannot judge: %s" % (ME, e))
        return 2
    after, over = net(have, allow)
    fails += over + [line for rose, line in compare(have, after, entries)]
    for metric in METRICS:
        say("%s=%d" % (metric, sum(len(lines) for lines in have[metric].values())))
    for line in fails:
        say("%s: FAIL %s" % (ME, line))
    if fails:
        say("%s: %d failure(s). To lower the baseline after a match left: bash scripts/%s.sh --write-baseline" % (ME, len(fails), ME))
    return 1 if fails else 0
