# BSS-060 — Gate check: self-service onboarding

## In plain words

**The problem today.** Nothing tests that a new customer can buy on the storefront of a Sovereign and get a working application without help from the sovereign-admin. A break anywhere in sign-in, voucher, order, provisioning or the price list is found only by a person trying it.

**What changes.** The acceptance suite gains a check that walks the whole purchase as a new customer and waits for the bought application to answer. The list of checks marks it as expected to fail for now: it runs and is recorded but cannot fail a run until the gate has a mailbox for the sign-in code.

**Done means:**

- The check signs in a new customer by reading the mailed code from the gate lane's mailbox, and it fails at its first step, sending nothing, when the run holds no such mailbox.
- Only the voucher is issued by a sovereign-admin; the check proves that none of the customer's steps used the console session.
- It fails when the order is not paid from the voucher's credit, or when the Organization is not ready with its quota and a serving application within 30 minutes.
- It records whether the price list shows the package just bought and, when it does, that the one-price-list check still holds.
- At the end of every run the customer's Organization is deleted by its owner and the voucher is revoked, also when a step failed.
- Later checks of the billing area can reuse the customer Organization of the run without walking the purchase again.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The acceptance suite holds gate check BSS-G01, "Self-service onboarding", in `tests/acceptance/sovereign/internal/suite/check_bss_onboarding.go`, and the gate manifest lists it as `expected-fail`. In a cloud run the check walks the storefront of `https://marketplace.<sovereign-fqdn>/api` as a new customer: a sovereign-admin issues a voucher worth twice the cheapest plan; the customer signs in with the code mailed to an address of the gate lane's mailbox, redeems the voucher, orders that plan with one application paid from credit, and within 30 minutes its Organization is `Ready`, has the ResourceQuota `plan-quota` and the application's host answers HTTP 200. No call of the customer's steps carries the console session. The check then records the evidence key `price_list_state` (`published` or `not-seen`) and, when published, runs the assertion of BSS-G02 again. The journey is one memoised function, `onboardedOrg`, for the later checks of the billing area, and its clean-up runs through a new end-of-run hook of the runner, `AtEnd`. BSS-070 moves the check to `required`; this ticket does not.

## 3. The model (the law)
1. The check is one file that calls `RegisterCheck` in `init()` and holds the literal `BSS-G01`. The journey is `internal/suite/bss_org.go`; the storefront client and the mailbox reader are the new package `internal/storefront`. The runner gains `AtEnd`; no other file of the suite changes except the README.
2. Step 1 reads the gate lane's mailbox from the environment: `BSS_GATE_MAILBOX_IMAP` (`host:port`, implicit TLS), `BSS_GATE_MAILBOX_USER`, `BSS_GATE_MAILBOX_PASSWORD` and `BSS_GATE_MAILBOX_ADDRESS`, an address that holds `{tag}` once. When one is missing the step fails before any request. There is no sign-in bypass: the sign-in service does not change.
3. Step 2 reads the storefront anonymously: the cheapest plan without a product and with a price above 0 (`GET /api/catalog/plans?product=generic`), and the application with the fewest backing services among the listed applications that are deployable, not system and not of kind `service` (`GET /api/catalog/apps?published=true`).
4. Step 3 is the only sovereign-admin action: `POST /api/v1/org/billing/vouchers/issue` through the console, one redemption, a credit of twice the plan's price rounded up to whole OMR. The console calls of the journey go through a copy of the run's client that counts them.
5. Step 4: `POST /api/auth/magic-link` for the address with `{tag}` replaced by a value of the run, the newest mail to that address with the subject `Your login code` read over IMAP with `EXAMINE` and `BODY.PEEK` (the mailbox is not changed), `POST /api/auth/verify`, `GET /api/auth/me`. One code request per run; the sign-in service allows 5 a minute per source address. The customer must not be a sovereign-admin.
6. Step 5 makes the calls of the checkout page in its order: `POST /api/billing/vouchers/redeem-preview` (the credit issued), `POST /api/tenant/orgs` with `defer_launch` and the storefront's preselected parent domain, `POST /api/billing/checkout` with the package `plan.<slug>`, single region and capped overage, which must be paid from credit with an order identifier and no card session, then `POST /api/provisioning/start`.
7. Step 6 looks every 15 seconds, for at most 30 minutes, in every region through `kubectl get`: the Organization whose `spec.slug` (or name) is the slug with `Ready=True`, the ResourceQuota `plan-quota` in the namespace of that slug, an HTTPRoute with a host `<application>.<slug>.*`, and `GET https://<host>/` answering 200 after redirects. The check never writes with `kubectl`.
8. Step 7 fails when the counted console client made a call during steps 4 to 6, or when the customer's token is empty or equal to the console session.
9. Step 8 waits at most 5 minutes for the price document, read as BSS-G02 reads it, to list the package bought. Listed: `price_list_state` is `published` and the assertion of BSS-G02 must hold. Not listed: `not-seen`, and the step passes.
10. The clean-up, step 9, is registered with `AtEnd` once the voucher exists: the owner deletes the Organization (`DELETE /api/tenant/orgs/{id}`, 404 accepted), no region holds the Organization or its namespace within 10 minutes, and the voucher is revoked through the console (404 accepted: it was redeemed). A failed step 9 makes BSS-G01 FAIL.
11. `onboardedOrg(ctx, cc, rec)` runs the journey for the first caller of a run, which records its steps; later callers of the same run get the stored result or error and record nothing.
12. `AtEnd(check, f)` hooks run once after the last check of the run, in reverse order, with a context that the run's cancellation does not end, in a cloud run and in a run in self. A hook's failed step makes its check FAIL.
13. Every wait goes through the suite's `poll`; no sleep, no ticker. The module stays standard library only.
14. The manifest entry BSS-G01 moves from `not-built` to `expected-fail` and gains its `implementation` line; no other field and no other entry changes.
15. A check whose run lacks what it needs is built as `expected-fail` and stays so until the run has it. The gate lane has no mailbox today, so BSS-G01 fails at step 1 in every run until a package gives the lane its mailbox and passes the four values to the suite; that package must merge before BSS-070.

// Error is an answer outside 2xx.
type Error struct {
	Method, Path string
	Status       int
	Body         string
}

func (e *Error) Error() string {
	return fmt.Sprintf("%s %s: HTTP %d %s", e.Method, e.Path, e.Status, e.Body)
}

// do sends one request with body as JSON and decodes a 2xx answer into out.
// When the token has expired (HTTP 401) the client renews it once with the
// refresh token, as the storefront does, and sends the request again.
func (c *Client) do(ctx context.Context, method, path string, body, out any) error {
	var payload []byte
	if body != nil {
		b, err := json.Marshal(body)
		if err != nil {
			return err
		}
		payload = b
	}
	status, b, err := c.once(ctx, method, path, payload, c.Token)
	if err == nil && status == http.StatusUnauthorized && c.Refresh != "" {
		if c.renew(ctx) == nil {
			status, b, err = c.once(ctx, method, path, payload, c.Token)
		}
	}
	if err != nil {
		return err
	}
	if status < 200 || status > 299 {
		return &Error{Method: method, Path: path, Status: status, Body: snippet(b)}
	}
	if out == nil {
		return nil
	}
	if err := json.Unmarshal(b, out); err != nil {
		return fmt.Errorf("%s %s: decode HTTP %d body: %w (body=%s)", method, path, status, err, snippet(b))
	}
	return nil
}

// renew is POST /auth/refresh with the refresh token and no bearer token.
func (c *Client) renew(ctx context.Context) error {
	payload, err := json.Marshal(map[string]string{"refresh_token": c.Refresh})
	if err != nil {
		return err
	}
	status, b, err := c.once(ctx, http.MethodPost, "/auth/refresh", payload, "")
	if err != nil {
		return err
	}
	var out tokens
	if status != http.StatusOK || json.Unmarshal(b, &out) != nil || out.Token == "" {
		return &Error{Method: http.MethodPost, Path: "/auth/refresh", Status: status, Body: snippet(b)}
	}
	c.Token, c.Refresh = out.Token, out.Refresh
	return nil
}

// once sends one request, with the bearer token when it is not empty, and
// reads the answer.
func (c *Client) once(ctx context.Context, method, path string, payload []byte, token string) (int, []byte, error) {
	var rd io.Reader
	if payload != nil {
		rd = bytes.NewReader(payload)
	}
	req, err := http.NewRequestWithContext(ctx, method, c.Base+path, rd)
	if err != nil {
		return 0, nil, err
	}
	req.Header.Set("Accept", "application/json")
	if payload != nil {
		req.Header.Set("Content-Type", "application/json")
	}
	call := Call{Method: method, Path: path, Credential: "none"}
	if token != "" {
		req.Header.Set("Authorization", "Bearer "+token)
		call.Credential = "customer"
	}
	res, err := c.HTTP.Do(req)
	if err != nil {
		c.Calls = append(c.Calls, call)
		return 0, nil, fmt.Errorf("%s %s: %w", method, path, err)
	}
	defer func() { _ = res.Body.Close() }()
	call.Status = res.StatusCode
	c.Calls = append(c.Calls, call)
	b, err := io.ReadAll(io.LimitReader(res.Body, 4<<20))
	if err != nil {
		return res.StatusCode, nil, fmt.Errorf("%s %s: read body: %w", method, path, err)
	}
	return res.StatusCode, b, nil
}

func snippet(b []byte) string {

package storefront

import (
	"bufio"
	"context"
	"crypto/tls"
	"errors"
	"fmt"

	"regexp"
	"strconv"
	"strings"

// Mailbox reads the sign-in code that the sign-in service mailed to one
// address of the gate lane's mailbox. It speaks the few IMAP commands it
// needs (RFC 9051) over implicit TLS: LOGIN, EXAMINE INBOX (read-only),
// UID SEARCH by recipient and subject, UID FETCH BODY.PEEK[TEXT] and LOGOUT.
// It changes nothing in the mailbox: EXAMINE opens it read-only and PEEK sets
// no flag. The password is never printed.
type Mailbox struct {
	Addr     string // host:port of the IMAP server, implicit TLS
	User     string
	Password string
	// Dial opens the connection. Nil: TLS to Addr, the server name checked.
	Dial func(ctx context.Context, addr string) (net.Conn, error)
}

// ErrNoMail means the mailbox holds no sign-in mail for the address yet.
var ErrNoMail = errors.New("no sign-in mail for the address yet")

// codeSubject is the subject of the mail of the sign-in service
// (core/services/auth/handlers/handlers.go, sendCodeEmail).
const codeSubject = "Your login code"

// The code in the text mail ("Your login code: 123456") or, in the mail of
// the notification service, alone in an element.
var (
	codeInText = regexp.MustCompile(`(?i)login code:\s*(\d{6})\b`)
	codeInHTML = regexp.MustCompile(`>\s*(\d{6})\s*<`)
)

// CodeFrom returns the six-digit code of a sign-in mail body, or "".
func CodeFrom(body string) string {
	body = strings.ReplaceAll(body, "=\r\n", "") // quoted-printable soft breaks
	for _, re := range []*regexp.Regexp{codeInText, codeInHTML} {
		if m := re.FindStringSubmatch(body); m != nil {
			return m[1]
		}
	}
	return ""
}

// Code returns the code of the newest sign-in mail sent to address, or
// ErrNoMail when there is none.
func (m Mailbox) Code(ctx context.Context, address string) (string, error) {
	dial := m.Dial
	if dial == nil {
		dial = func(ctx context.Context, addr string) (net.Conn, error) {
			d := tls.Dialer{Config: &tls.Config{MinVersion: tls.VersionTLS12}}
			return d.DialContext(ctx, "tcp", addr)
		}
	}
	conn, err := dial(ctx, m.Addr)
	if err != nil {
		return "", fmt.Errorf("imap %s: %w", m.Addr, err)
	}
	defer func() { _ = conn.Close() }()
	if dl, ok := ctx.Deadline(); ok {
		_ = conn.SetDeadline(dl)
	} else {
		_ = conn.SetDeadline(time.Now().Add(2 * time.Minute))
	}
	s := &imapSession{r: bufio.NewReader(conn), w: conn}
	if line, err := s.line(); err != nil || !strings.HasPrefix(line, "* OK") {
		return "", fmt.Errorf("imap %s: no greeting: %q %v", m.Addr, line, err)
	}
	if _, _, err := s.cmd("LOGIN " + quote(m.User) + " " + quote(m.Password)); err != nil {
		return "", fmt.Errorf("imap %s: LOGIN: %w", m.Addr, err)
	}
	defer func() { _, _, _ = s.cmd("LOGOUT") }()
	if _, _, err := s.cmd("EXAMINE INBOX"); err != nil {
		return "", fmt.Errorf("imap %s: EXAMINE INBOX: %w", m.Addr, err)
	}
	lines, _, err := s.cmd("UID SEARCH TO " + quote(address) + " SUBJECT " + quote(codeSubject))
	if err != nil {
		return "", fmt.Errorf("imap %s: UID SEARCH: %w", m.Addr, err)
	}
	newest := uint64(0)
	for _, l := range lines {
		if !strings.HasPrefix(l, "* SEARCH") {
			continue
		}
		for _, f := range strings.Fields(l)[2:] {
			if n, err := strconv.ParseUint(f, 10, 32); err == nil && n > newest {
				newest = n
			}
		}
	}
	if newest == 0 {
		return "", ErrNoMail
	}
	_, literal, err := s.cmd(fmt.Sprintf("UID FETCH %d BODY.PEEK[TEXT]", newest))
	if err != nil {
		return "", fmt.Errorf("imap %s: UID FETCH: %w", m.Addr, err)
	}
	code := CodeFrom(string(literal))
	if code == "" {
		return "", fmt.Errorf("imap %s: the newest sign-in mail to %s (uid %d) holds no six-digit code", m.Addr, address, newest)
	}
	return code, nil
}

// quote writes s as an IMAP quoted string.
func quote(s string) string {
	return `"` + strings.NewReplacer(`\`, `\\`, `"`, `\"`).Replace(s) + `"`
}

type imapSession struct {
	r   *bufio.Reader
	w   io.Writer
	tag int
}

// line reads one line without its CRLF.
func (s *imapSession) line() (string, error) {
	l, err := s.r.ReadString('\n')
	return strings.TrimRight(l, "\r\n"), err
}

// literalSize is the size of the literal that ends a line ("{123}").
var literalSize = regexp.MustCompile(`\{(\d+)\}$`)

// cmd sends one tagged command and reads up to its tagged answer. It returns
// the untagged lines and the bytes of the literals they carried. An answer
// other than OK is an error.
func (s *imapSession) cmd(c string) ([]string, []byte, error) {
	s.tag++
	tag := fmt.Sprintf("a%d", s.tag)
	if _, err := io.WriteString(s.w, tag+" "+c+"\r\n"); err != nil {
		return nil, nil, err
	}
	var lines []string
	var literal []byte
	for {
		l, err := s.line()
		if err != nil {
			return lines, literal, err
		}
		if m := literalSize.FindStringSubmatch(l); m != nil {
			n, _ := strconv.Atoi(m[1])
			if n > 4<<20 {
				return lines, literal, fmt.Errorf("a literal of %d bytes", n)
			}
			b := make([]byte, n)
			if _, err := io.ReadFull(s.r, b); err != nil {
				return lines, literal, err
			}
			literal = append(literal, b...)
		}
		if rest, ok := strings.CutPrefix(l, tag+" "); ok {
			if !strings.HasPrefix(rest, "OK") {
				return lines, literal, errors.New(rest)
			}
			return lines, literal, nil
		}
		lines = append(lines, l)
	}
}

	box  map[int][2]string
	got  []string
	fail string // the command whose answer is NO
}

func (s *imapServer) serve(conn net.Conn) {
	defer func() { _ = conn.Close() }()
	r := bufio.NewReader(conn)
	_, _ = fmt.Fprint(conn, "* OK IMAP4rev2 ready\r\n")
	for {
		line, err := r.ReadString('\n')
		if err != nil {
			return
		}
		line = strings.TrimRight(line, "\r\n")
		s.got = append(s.got, line)
		tag, cmd, _ := strings.Cut(line, " ")
		switch {
		case s.fail != "" && strings.HasPrefix(cmd, s.fail):
			_, _ = fmt.Fprintf(conn, "%s NO refused\r\n", tag)
		case strings.HasPrefix(cmd, "LOGIN ") && !strings.HasSuffix(cmd, `"pw"`):
			_, _ = fmt.Fprintf(conn, "%s NO [AUTHENTICATIONFAILED] invalid credentials\r\n", tag)
		case strings.HasPrefix(cmd, "UID SEARCH TO "):
			uids := []string{}
			for uid := 1; uid <= len(s.box); uid++ {
				if m := s.box[uid]; strings.Contains(cmd, `TO "`+m[0]+`"`) {
					uids = append(uids, fmt.Sprint(uid))
				}
			}
			_, _ = fmt.Fprintf(conn, "* SEARCH %s\r\n%s OK done\r\n", strings.Join(uids, " "), tag)
		case strings.HasPrefix(cmd, "UID FETCH "):
			var uid int
			_, _ = fmt.Sscanf(cmd, "UID FETCH %d", &uid)
			text := s.box[uid][1]
			_, _ = fmt.Fprintf(conn, "* 1 FETCH (UID %d BODY[TEXT] {%d}\r\n%s)\r\n%s OK done\r\n", uid, len(text), text, tag)
		case cmd == "LOGOUT":
			_, _ = fmt.Fprintf(conn, "* BYE\r\n%s OK bye\r\n", tag)
			return
		default:
			_, _ = fmt.Fprintf(conn, "%s OK done\r\n", tag)
		}
	}
}

// serving looks once, in every region, for the Organization of res, its
// plan-quota and the HTTPRoute of the application, and asks the host of that
// route. It sets res.Region and res.AppHost when all are there.
func (o onboarding) serving(ctx context.Context, cc *CheckContext, client *http.Client, res *OnboardResult) (bool, string, error) {
	seen := []string{}
	for _, region := range cc.Regions {
		org, err := o.organization(ctx, region, res.OrgSlug)
		switch {
		case err != nil:
			seen = append(seen, region.ID+": "+err.Error())
			continue
		case org == nil:
			seen = append(seen, region.ID+": no Organization "+res.OrgSlug)
			continue
		}
		if status, reason, _, _ := org.Condition("Ready"); status != "True" {
			seen = append(seen, fmt.Sprintf("%s: Organization Ready=%q %s", region.ID, status, reason))
			continue
		}
		out, err := o.kubectl(region, ctx, nil, "get", "resourcequota", "plan-quota", "-n", res.OrgSlug, "--ignore-not-found", "-o", "name")
		if err != nil || strings.TrimSpace(string(out)) == "" {
			seen = append(seen, region.ID+": no ResourceQuota plan-quota in "+res.OrgSlug)
			continue
		}
		host, err := o.appHost(ctx, region, res.AppSlug+"."+res.OrgSlug+".")
		if err != nil || host == "" {
			seen = append(seen, region.ID+": no HTTPRoute with a host "+res.AppSlug+"."+res.OrgSlug+".*")
			continue
		}
		status, err := hostStatus(ctx, client, "https://"+host+"/")
		if err != nil || status != http.StatusOK {
			seen = append(seen, fmt.Sprintf("%s: https://%s/ answered %d %v", region.ID, host, status, err))
			continue
		}
		res.Region, res.AppHost = region.ID, host
		return true, region.ID + ": ready and serving", nil
	}
	return false, strings.Join(seen, "; "), nil
}

// organization returns the Organization whose slug is slug, or nil.
func (o onboarding) organization(ctx context.Context, region kube.Region, slug string) (kube.Object, error) {

}

// appHost returns the first host of an HTTPRoute that starts with prefix.
func (o onboarding) appHost(ctx context.Context, region kube.Region, prefix string) (string, error) {
	out, err := o.kubectl(region, ctx, nil, "get", "httproutes.gateway.networking.k8s.io", "-A", "-o", "json")
	if err != nil {
		return "", err
	}
	var l kube.List
	if err := json.Unmarshal(out, &l); err != nil {
		return "", err
	}
	hosts := []string{}
	for _, it := range l.Items {
		hs, _ := it.Get("spec", "hostnames").([]any)
		for _, h := range hs {
			if s, _ := h.(string); strings.HasPrefix(s, prefix) {
				hosts = append(hosts, s)
			}
		}
	}
	sort.Strings(hosts)
	if len(hosts) == 0 {
		return "", nil
	}
	return hosts[0], nil
}

// hostStatus is the status of GET u, after redirects.
func hostStatus(ctx context.Context, client *http.Client, u string) (int, error) {
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, u, nil)
	if err != nil {
		return 0, err
	}
	res, err := client.Do(req)
	if err != nil {
		return 0, err
	}
	_ = res.Body.Close()
	return res.StatusCode, nil
}
