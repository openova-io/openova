# FND-057 — The privacy guard fails closed and runs on every branch

## In plain words

**The problem today.** The privacy guard passes with only a warning when its pattern is not configured, and it runs only for the main branch. Its search command also has its options in the wrong order, so the search always ends in an error, and the guard reads that error as a clean result. The guard has never found anything.

**What changes.** The guard fails when its pattern is missing and when its search cannot run, and its search now really runs. It runs on pull requests to every branch, on every push and in the merge queue.

**Done means:**

- A run of the guard without its pattern fails and says that the pattern is not set.
- A run whose search finds a match fails, and a run whose search cannot run fails too.
- A run whose search finds nothing passes.
- The guard runs on pull requests to every branch, on every push and on the merge queue.
- The guard still searches the whole tree except its own file, and it never prints its pattern.
- Runs started by the dependency bot read the pattern from a Dependabot secret of the same name, which the architect sets before the merge.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The workflow `privacy-redact-guard` (`.github/workflows/redact-guard.yml`) can no longer pass by omission. When its pattern (the repository secret `PARTNER_REDACT_REGEX`) is empty, the job `scan` fails with the error `PARTNER_REDACT_REGEX is not set; the guard cannot run`. Its search really runs: a match fails the job, no match passes it, and a search that cannot run (a bad pattern, a git error) fails it. The workflow runs on pull requests to any branch, on every push to any branch, and on merge groups.

## 3. The model (the law)
1. The job `scan` passes in exactly one case: the pattern is set, and `git grep` ran and found no line (its exit code is 1).
2. An empty pattern fails the job with the error line `::error::PARTNER_REDACT_REGEX is not set; the guard cannot run` and exit code 1. The file contains no `exit 0`.
3. A match (exit code 0 of `git grep`) fails the job with the existing error line `::error::Private partner name detected — remove before merge (privacy P0 policy)`.
4. Any other exit code of `git grep` fails the job with the error line `::error::git grep failed with exit code <code>; the guard cannot run`.
5. The search keeps its scope: the whole tree, tracked and untracked files, case-insensitive, extended regular expressions, with line numbers, and exactly one excluded path, the guard's own file. Only the position of `--untracked` changes: it stands before the pattern, because git reads no option after the pattern.
6. The triggers are `pull_request`, `merge_group` and `push`, each with no filter: no `branches`, `branches-ignore`, `tags`, `tags-ignore`, `paths` or `paths-ignore`.
7. The pattern is never printed and never written into the repository. No `echo` line names the variable `$PARTNER_REDACT_REGEX`.
8. The workflow keeps its name `privacy-redact-guard` and its one job `scan`, so the name of the check does not change.

```yaml
name: privacy-redact-guard
on:
  pull_request:
  merge_group:
  push:
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Reject private partner names
        env:
          # Pattern held in the repo Actions secret to keep the
          # forbidden strings out of the public workflow file itself.
          # Operator sets PARTNER_REDACT_REGEX = '<pattern1>|<pattern2>|...'
          # via Settings -> Secrets and variables -> Actions -> New secret.
          # If unset, the guard fails: it never passes without its
          # pattern. Runs started by the dependency bot read the
          # Dependabot secret of the same name.
          PARTNER_REDACT_REGEX: ${{ secrets.PARTNER_REDACT_REGEX }}
        run: |
          if [ -z "$PARTNER_REDACT_REGEX" ]; then
            echo "::error::PARTNER_REDACT_REGEX is not set; the guard cannot run"
            exit 1
          fi
          rc=0
          git grep -ni --untracked -E "$PARTNER_REDACT_REGEX" -- ':!.github/workflows/redact-guard.yml' || rc=$?
          if [ "$rc" -eq 0 ]; then
            echo "::error::Private partner name detected — remove before merge (privacy P0 policy)"
            exit 1
          fi
          if [ "$rc" -ne 1 ]; then
            echo "::error::git grep failed with exit code $rc; the guard cannot run"
            exit 1
          fi
```
