## 2. End goal
The repository holds three inventories under `docs/generated/`: the slots of the bootstrap kit, the components and Blueprints, and the custom resource definitions. Each one is written by a script under `scripts/generators/` from the files of the tree. Nobody edits them by hand. A new check, `generated-docs`, runs on every pull request. It runs every generator again and is red when a committed inventory differs from what its generator writes. So an inventory cannot go out of date without a red check.

## 3. The model (the law)
1. A generator is one file `scripts/generators/<name>.py`. It needs Python 3 and PyYAML and nothing else. It reads files of the working tree. It never asks a cluster and never uses the network.
2. A generator has three modes. With no argument it writes its file under `docs/generated/` and prints `wrote: <path>`. With `--check` it writes nothing: it exits 0 and prints `current: <path>` when the file on disk equals what it would write; it exits 1 and prints a line that starts with `stale: <path>` when the file differs or does not exist. With `--self-test` it proves its rules on a throw-away tree and exits 0 only when every case passes. In every mode exit code 2 means that an input is missing or cannot be read.
3. The first line of every generated file is `Generated by scripts/generators/<name>.py. Do not edit.`
4. A generated file holds no value that CI writes on `main` without a pull request: no chart version, no Blueprint version, no slot pin, no image tag. Such a value would make the file stale with no pull request to repair it. The three generators read `Chart.yaml`, `blueprint.yaml` and the slot files, and leave their version fields out.
5. The output of a generator is a function of the tree alone. It holds no date, no commit hash and no count line. The order of its rows is fixed by the generator.
6. The three generators of this ticket and their files:
   - `scripts/generators/slots.py` writes `docs/generated/bootstrap-slots.md`. It reads `clusters/_template/bootstrap-kit/kustomization.yaml` (the order), every slot file of that folder (a file whose name starts with a digit and ends in `.yaml`), and `scripts/expected-bootstrap-deps.yaml`.
   - `scripts/generators/components.py` writes `docs/generated/components.md`. It reads every folder directly under `platform/` and `products/` (its `Chart.yaml` files and its `blueprint.yaml` files of kind Blueprint) and the slot files.
   - `scripts/generators/custom-resources.py` writes `docs/generated/custom-resources.md`. It reads every `.yaml` file that lies directly in a folder named `crds` under `platform/` or `products/`, and every `.go` file whose name does not end in `_test.go`.
7. `components.py` and `custom-resources.py` take their list of files from git: tracked files, and new files that no ignore rule covers. A file that an ignore rule covers is never read.
8. The workflow `.github/workflows/check-generated-docs.yaml` has the name `check-generated-docs` and one job with the name `generated-docs`. Its triggers are `pull_request`, `merge_group` and `push` to `main`. It has no path filter. The job runs every file `scripts/generators/*.py` with `--self-test`, and then every one with `--check`. A generator that a later package adds is found by its name; the workflow does not change for it.
9. The three scripts and the workflow are the four blocks of field 5, byte for byte.
10. The three files under `docs/generated/` are written by running the generators (steps 13 to 15 of field 16). They are never typed and never edited.
11. Nothing is deleted. `.github/workflows/check-catalog-generated-drift.yaml` stays as it is.

#!/usr/bin/env python3
"""slots.py - the inventory of the bootstrap kit slots, generated from the tree.

It reads   clusters/_template/bootstrap-kit/kustomization.yaml   (the order of the slots)
           clusters/_template/bootstrap-kit/<NN>*.yaml           (one slot file each)
           scripts/expected-bootstrap-deps.yaml                  (the declared dependencies)
It writes  docs/generated/bootstrap-slots.md

Usage, from any directory:
  python3 scripts/generators/slots.py              write the file
  python3 scripts/generators/slots.py --check      write nothing; exit 1 when the file on disk differs
  python3 scripts/generators/slots.py --self-test  prove every rule on a throw-away tree

Exit codes: 0 done or current; 1 the file is stale, or a self-test case failed;
2 an input is missing or cannot be read.

The output carries no chart version. CI writes versions on main without a pull
request, and this file must not go stale when it does.
"""
import difflib
import os
import re
import sys
import tempfile

try:
    import yaml
except ImportError:
    sys.stderr.write("slots.py needs PyYAML: pip install pyyaml\n")
    sys.exit(2)

SCRIPT = "scripts/generators/slots.py"
OUTPUT = "docs/generated/bootstrap-slots.md"
KIT = "clusters/_template/bootstrap-kit"
EXPECTED = "scripts/expected-bootstrap-deps.yaml"
SLOT_FILE = re.compile(r"^[0-9][^/]*\.yaml$")


class InputError(Exception):
    """An input is missing or does not have the shape this generator reads."""


def load_documents(root, relative):
    path = os.path.join(root, relative)
    try:
        with open(path, encoding="utf-8") as handle:
            return [d for d in yaml.safe_load_all(handle) if d is not None]
    except OSError as error:
        raise InputError("%s: cannot be read: %s" % (relative, error.strerror))
    except yaml.YAMLError as error:
        raise InputError("%s: is not valid YAML: %s" % (relative, str(error).splitlines()[0]))


def cell(text):
    return str(text).replace("|", "\\|").replace("\n", " ")


def code(text):
    return "`%s`" % str(text).replace("`", "'")


def helm_releases(root, name):
    relative = "%s/%s" % (KIT, name)
    found = []
    for document in load_documents(root, relative):
        if isinstance(document, dict) and document.get("kind") == "HelmRelease":
            found.append(document)
    return found


def text_or_dash(value):
    return "-" if value in (None, "") else cell(value)


def depends_on(release):
    names = []
    for item in (release.get("spec") or {}).get("dependsOn") or []:
        if isinstance(item, dict) and item.get("name"):
            names.append(str(item["name"]))
    return names


def show(value):
    if isinstance(value, bool):
        return "true" if value else "false"
    return str(value)


def switches(release):
    """spec.suspend and spec.values.enabled, whatever they hold; and
    spec.values.<key>.enabled when a substitution variable sets it."""
    spec = release.get("spec") or {}
    found = []
    if "suspend" in spec:
        found.append("suspend=%s" % show(spec["suspend"]))
    values = spec.get("values")
    if isinstance(values, dict):
        if "enabled" in values:
            found.append("values.enabled=%s" % show(values["enabled"]))
        for key, value in values.items():
            if isinstance(value, dict) and "enabled" in value:
                inner = value["enabled"]
                if isinstance(inner, str) and "${" in inner:
                    found.append("values.%s.enabled=%s" % (key, inner))
    return found


def expected_entries(root):
    documents = load_documents(root, EXPECTED)
    if len(documents) != 1 or not isinstance(documents[0], dict) or not isinstance(documents[0].get("slots"), list):
        raise InputError("%s: has no list under the key slots" % EXPECTED)
    entries = []
    for entry in documents[0]["slots"]:
        if not isinstance(entry, dict) or not entry.get("name"):
            raise InputError("%s: an entry of slots has no name" % EXPECTED)
        entries.append(entry)
    return entries


def generate(root):
    documents = load_documents(root, "%s/kustomization.yaml" % KIT)
    if len(documents) != 1 or not isinstance(documents[0], dict) or not isinstance(documents[0].get("resources"), list):
        raise InputError("%s/kustomization.yaml: has no list under the key resources" % KIT)
    registered = [str(name) for name in documents[0]["resources"]]
    try:
        on_disk = sorted(name for name in os.listdir(os.path.join(root, KIT)) if SLOT_FILE.match(name))
    except OSError as error:
        raise InputError("%s: cannot be listed: %s" % (KIT, error.strerror))
    expected = expected_entries(root)
    expected_by_name = {str(entry["name"]): entry for entry in expected}

    lines = [
        "Generated by %s. Do not edit." % SCRIPT,
        "",
        "# Bootstrap slots",
        "",
        "The slots of the bootstrap kit, `%s/`. A slot is one file of that folder." % KIT,
        "To change this file, change an input and run `python3 %s`." % SCRIPT,
        "The check `generated-docs` fails a pull request in which this file is stale.",
        "This file carries no chart version: CI writes versions, and this file does not change when CI does.",
        "",
        "## Registered slots",
        "",
        "One row for each HelmRelease of each file that `%s/kustomization.yaml` lists, in the order of that list." % KIT,
        "",
        "- Slot: the file name up to its first dash.",
        "- Switches: the value of `spec.suspend` and of `spec.values.enabled` when the slot sets it, and each `spec.values.<key>.enabled` that a substitution variable sets.",
        "- Expected dependencies: `same` when the entry of this HelmRelease in `%s` names the same set as Depends on; `differs` when it names another set; `not declared` when there is no entry." % EXPECTED,
        "",
        "| Slot | File | HelmRelease | Release name | Target namespace | Chart | Depends on | Switches | Expected dependencies |",
        "|---|---|---|---|---|---|---|---|---|",
    ]
    present = set()
    for name in registered:
        if "/" in name or not name.endswith(".yaml"):
            lines.append("| - | %s | (not a file of this folder) | - | - | - | - | - | - |" % cell(name))
            continue
        releases = helm_releases(root, name)
        slot = name.split("-", 1)[0].split(".", 1)[0]
        if not releases:
            lines.append("| %s | %s | (none) | - | - | - | - | - | - |" % (cell(slot), cell(name)))
        for release in releases:
            metadata = release.get("metadata") or {}
            spec = release.get("spec") or {}
            release_name = str(metadata.get("name") or "")
            if not release_name:
                raise InputError("%s/%s: a HelmRelease has no metadata.name" % (KIT, name))
            present.add(release_name)
            chart = ((spec.get("chart") or {}).get("spec") or {}).get("chart")
            needs = depends_on(release)
            entry = expected_by_name.get(release_name)
            if entry is None:
                verdict = "not declared"
            elif set(str(x) for x in entry.get("depends_on") or []) == set(needs):
                verdict = "same"
            else:
                verdict = "differs"
            found = switches(release)
            lines.append("| %s | %s | %s | %s | %s | %s | %s | %s | %s |" % (
                cell(slot), cell(name), cell(release_name),
                text_or_dash(spec.get("releaseName")), text_or_dash(spec.get("targetNamespace")),
                text_or_dash(chart),
                cell(", ".join(needs)) if needs else "-",
                cell(", ".join(code(x) for x in found)) if found else "-",
                verdict))

    lines += ["", "## Slot files that the kustomization does not list", ""]
    unlisted = [name for name in on_disk if name not in registered]
    if unlisted:
        lines += [
            "Flux never applies these files.",
            "",
            "| File | HelmRelease |",
            "|---|---|",
        ]
        for name in unlisted:
            names = []
            for release in helm_releases(root, name):
                release_name = str((release.get("metadata") or {}).get("name") or "")
                if release_name:
                    names.append(release_name)
                    present.add(release_name)
            lines.append("| %s | %s |" % (cell(name), cell(", ".join(names)) if names else "(none)"))
    else:
        lines.append("None.")

    lines += ["", "## Declared without a slot file", ""]
    absent = [entry for entry in expected if str(entry["name"]) not in present]
    if absent:
        lines += [
            "Entries of `%s` whose HelmRelease is in no slot file. Nothing installs them." % EXPECTED,
            "",
            "| Slot | HelmRelease | Depends on | Wave |",
            "|---|---|---|---|",
        ]
        for entry in absent:
            needs = [str(x) for x in entry.get("depends_on") or []]
            lines.append("| %s | %s | %s | %s |" % (
                text_or_dash(entry.get("slot")), cell(entry["name"]),
                cell(", ".join(needs)) if needs else "-", text_or_dash(entry.get("wave"))))
    else:
        lines.append("None.")
    return "\n".join(lines) + "\n"


def write(root):
    text = generate(root)
    path = os.path.join(root, OUTPUT)
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8", newline="\n") as handle:
        handle.write(text)
    print("wrote: %s" % OUTPUT)
    return 0


def check(root):
    text = generate(root)
    try:
        with open(os.path.join(root, OUTPUT), encoding="utf-8", newline="") as handle:
            on_disk = handle.read()
    except OSError:
        on_disk = None
    if on_disk == text:
        print("current: %s" % OUTPUT)
        return 0
    if on_disk is None:
        print("%s does not exist" % OUTPUT)
    else:
        diff = list(difflib.unified_diff(on_disk.splitlines(), text.splitlines(), "on disk", "generated", lineterm="", n=0))
        for line in diff[:30]:
            print(line[:240])
        if len(diff) > 30:
            print("... %d more lines of difference" % (len(diff) - 30))
    print("stale: %s. Run: python3 %s  and commit that file." % (OUTPUT, SCRIPT))
    return 1

#!/usr/bin/env python3
"""components.py - the inventory of components and Blueprints, generated from the tree.

It reads   every folder directly under platform/ and products/:
             its Chart.yaml files (the chart name),
             its blueprint.yaml files of kind Blueprint (the name and the visibility)
           clusters/_template/bootstrap-kit/<NN>*.yaml (which slot installs which chart)
It writes  docs/generated/components.md

Usage, from any directory of a full checkout:
  python3 scripts/generators/components.py              write the file
  python3 scripts/generators/components.py --check      write nothing; exit 1 when the file on disk differs
  python3 scripts/generators/components.py --self-test  prove every rule on a throw-away tree

Exit codes: 0 done or current; 1 the file is stale, or a self-test case failed;
2 an input is missing or cannot be read.

The files are those that git knows or would add: tracked files, and new files
that no ignore rule covers. The output carries no chart version and no
Blueprint version. CI writes versions on main without a pull request, and this
file must not go stale when it does.
"""
import difflib
import os
import re
import subprocess
import sys
import tempfile

try:
    import yaml
except ImportError:
    sys.stderr.write("components.py needs PyYAML: pip install pyyaml\n")
    sys.exit(2)

SCRIPT = "scripts/generators/components.py"
OUTPUT = "docs/generated/components.md"
KIT = "clusters/_template/bootstrap-kit"
AREAS = ("platform", "products")
SLOT_FILE = re.compile(r"^[0-9][^/]*\.yaml$")


class InputError(Exception):
    """An input is missing or does not have the shape this generator reads."""


def listed_files(root, areas):
    """Tracked files and new files that are not ignored, under the given folders, that exist on disk.
    A sparse checkout that leaves out a file this generator reads is refused: the output would be wrong."""
    command = ["git", "-C", root, "ls-files", "-t", "-z", "--cached", "--others", "--exclude-standard", "--"] + list(areas)
    try:
        done = subprocess.run(command, stdout=subprocess.PIPE, stderr=subprocess.PIPE, check=False)
    except OSError as error:
        raise InputError("git cannot be started: %s" % error.strerror)
    if done.returncode != 0:
        raise InputError("git ls-files failed: %s" % done.stderr.decode("utf-8", "replace").strip())
    names = set()
    for record in done.stdout.decode("utf-8", "surrogateescape").split("\0"):
        tag, _, name = record.partition(" ")
        if not name:
            continue
        if tag == "S":
            if is_input(name):
                raise InputError("%s: is left out by a sparse checkout; run this generator in a full checkout" % name)
            names.add(name)
        elif os.path.isfile(os.path.join(root, name)):
            names.add(name)
    return sorted(names)


def is_input(name):
    """True for a file whose content this generator reads."""
    parts = name.split("/")
    return parts[-1] == "Chart.yaml" or (parts[-1] == "blueprint.yaml" and "templates" not in parts[2:-1])


def load_documents(root, relative):
    path = os.path.join(root, relative)
    try:
        with open(path, encoding="utf-8") as handle:
            return [d for d in yaml.safe_load_all(handle) if d is not None]
    except OSError as error:
        raise InputError("%s: cannot be read: %s" % (relative, error.strerror))
    except yaml.YAMLError as error:
        raise InputError("%s: is not valid YAML: %s" % (relative, str(error).splitlines()[0]))


def cell(text):
    return str(text).replace("|", "\\|").replace("\n", " ")


def kit_slots(root):
    """Chart name -> the slots (file name up to the first dash) whose HelmRelease installs it."""
    folder = os.path.join(root, KIT)
    try:
        names = sorted(name for name in os.listdir(folder) if SLOT_FILE.match(name))
    except OSError as error:
        raise InputError("%s: cannot be listed: %s" % (KIT, error.strerror))
    slots = {}
    for name in names:
        slot = name.split("-", 1)[0].split(".", 1)[0]
        for document in load_documents(root, "%s/%s" % (KIT, name)):
            if isinstance(document, dict) and document.get("kind") == "HelmRelease":
                chart = (((document.get("spec") or {}).get("chart") or {}).get("spec") or {}).get("chart")
                if chart and slot not in slots.setdefault(str(chart), []):
                    slots[str(chart)].append(slot)
    return slots


def generate(root):
    files = listed_files(root, AREAS)
    slots = kit_slots(root)
    chart_files = set(name for name in files if name.endswith("/Chart.yaml"))
    chart_folders = set(os.path.dirname(name) for name in chart_files)

    components = {}
    for name in files:
        parts = name.split("/")
        if len(parts) >= 3:
            components.setdefault("%s/%s" % (parts[0], parts[1]), {"charts": [], "blueprints": []})

    for name in sorted(chart_files):
        folder = os.path.dirname(name)
        parts = folder.split("/")
        if len(parts) < 3:
            continue
        # A chart inside another chart is a vendored dependency of it, not a chart of the component.
        if any("/".join(parts[:depth]) in chart_folders for depth in range(3, len(parts))):
            continue
        documents = load_documents(root, name)
        if len(documents) != 1 or not isinstance(documents[0], dict) or not documents[0].get("name"):
            raise InputError("%s: has no name" % name)
        components["%s/%s" % (parts[0], parts[1])]["charts"].append((str(documents[0]["name"]), "/".join(parts[2:])))

    for name in files:
        parts = name.split("/")
        if len(parts) < 3 or parts[-1] != "blueprint.yaml" or "templates" in parts[2:-1]:
            continue
        documents = load_documents(root, name)
        if not documents or not isinstance(documents[0], dict) or documents[0].get("kind") != "Blueprint":
            continue
        blueprint_name = (documents[0].get("metadata") or {}).get("name")
        if not blueprint_name:
            raise InputError("%s: a Blueprint has no metadata.name" % name)
        visibility = (documents[0].get("spec") or {}).get("visibility")
        components["%s/%s" % (parts[0], parts[1])]["blueprints"].append(
            (str(blueprint_name), "/".join(parts[2:]), "-" if visibility in (None, "") else str(visibility)))

    lines = [
        "Generated by %s. Do not edit." % SCRIPT,
        "",
        "# Components and Blueprints",
        "",
        "One row for each folder directly under `platform/` and `products/`.",
        "To change this file, change an input and run `python3 %s`." % SCRIPT,
        "The check `generated-docs` fails a pull request in which this file is stale.",
        "This file carries no chart version and no Blueprint version: CI writes versions, and this file does not change when CI does.",
        "",
        "- Charts: the `name` of each `Chart.yaml` in the folder. A chart that is not in `chart/` shows its folder in brackets. A chart inside another chart is a vendored dependency and is not listed.",
        "- Blueprint: the `metadata.name` of each `blueprint.yaml` of kind Blueprint in the folder. A file that is not `blueprint.yaml` at the top of the folder shows its path in brackets. A file below a folder named `templates` is a chart template and is not read.",
        "- Visibility: `spec.visibility` of that Blueprint. A dash means the Blueprint does not set it.",
        "- Kit slots: the slots of `%s/` whose HelmRelease installs one of the charts. A dash means no slot installs it." % KIT,
        "",
        "| Folder | Charts | Blueprint | Visibility | Kit slots |",
        "|---|---|---|---|---|",
    ]
    for folder in sorted(components):
        entry = components[folder]
        charts = sorted(entry["charts"], key=lambda item: (item[1], item[0]))
        blueprints = sorted(entry["blueprints"], key=lambda item: (item[1], item[0]))
        chart_cells = [name if where == "chart" else "%s (%s)" % (name, where) for name, where in charts]
        blueprint_cells = [name if where == "blueprint.yaml" else "%s (%s)" % (name, where) for name, where, _ in blueprints]
        slot_cells = []
        for name, _ in charts:
            for slot in slots.get(name, []):
                if slot not in slot_cells:
                    slot_cells.append(slot)
        lines.append("| %s | %s | %s | %s | %s |" % (
            cell(folder),
            cell(", ".join(chart_cells)) if chart_cells else "-",
            cell(", ".join(blueprint_cells)) if blueprint_cells else "-",
            cell(", ".join(item[2] for item in blueprints)) if blueprints else "-",
            cell(", ".join(sorted(slot_cells))) if slot_cells else "-"))
    return "\n".join(lines) + "\n"


def write(root):
    text = generate(root)
    path = os.path.join(root, OUTPUT)
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8", newline="\n") as handle:
        handle.write(text)
    print("wrote: %s" % OUTPUT)
    return 0


def check(root):
    text = generate(root)
    try:
        with open(os.path.join(root, OUTPUT), encoding="utf-8", newline="") as handle:
            on_disk = handle.read()
    except OSError:
        on_disk = None
    if on_disk == text:
        print("current: %s" % OUTPUT)
        return 0
    if on_disk is None:
        print("%s does not exist" % OUTPUT)
    else:
        diff = list(difflib.unified_diff(on_disk.splitlines(), text.splitlines(), "on disk", "generated", lineterm="", n=0))
        for line in diff[:30]:
            print(line[:240])
        if len(diff) > 30:
            print("... %d more lines of difference" % (len(diff) - 30))
    print("stale: %s. Run: python3 %s  and commit that file." % (OUTPUT, SCRIPT))
    return 1

#!/usr/bin/env python3
"""custom-resources.py - the inventory of custom resource definitions, generated from the tree.

It reads   every .yaml file that lies directly in a folder named crds, under platform/ or products/
           every .go file whose name does not end in _test.go (does it name the plural?)
It writes  docs/generated/custom-resources.md

Usage, from any directory of a full checkout:
  python3 scripts/generators/custom-resources.py              write the file
  python3 scripts/generators/custom-resources.py --check      write nothing; exit 1 when the file on disk differs
  python3 scripts/generators/custom-resources.py --self-test  prove every rule on a throw-away tree

Exit codes: 0 done or current; 1 the file is stale, or a self-test case failed;
2 an input is missing or cannot be read.

The files are those that git knows or would add: tracked files, and new files
that no ignore rule covers. It reads files only. It never asks a cluster.
"""
import difflib
import os
import re
import subprocess
import sys
import tempfile

try:
    import yaml
except ImportError:
    sys.stderr.write("custom-resources.py needs PyYAML: pip install pyyaml\n")
    sys.exit(2)

SCRIPT = "scripts/generators/custom-resources.py"
OUTPUT = "docs/generated/custom-resources.md"
CRD_FILE = re.compile(r"^(platform|products)/(.+/)?crds/[^/]+\.ya?ml$")
HELM_LINE = re.compile(r"^\s*\{\{.*\}\}\s*$")


class InputError(Exception):
    """An input is missing or does not have the shape this generator reads."""


def listed_files(root):
    """Tracked files and new files that are not ignored, that exist on disk.
    A sparse checkout that leaves out a file this generator reads is refused: the output would be wrong."""
    command = ["git", "-C", root, "ls-files", "-t", "-z", "--cached", "--others", "--exclude-standard"]
    try:
        done = subprocess.run(command, stdout=subprocess.PIPE, stderr=subprocess.PIPE, check=False)
    except OSError as error:
        raise InputError("git cannot be started: %s" % error.strerror)
    if done.returncode != 0:
        raise InputError("git ls-files failed: %s" % done.stderr.decode("utf-8", "replace").strip())
    names = set()
    for record in done.stdout.decode("utf-8", "surrogateescape").split("\0"):
        tag, _, name = record.partition(" ")
        if not name:
            continue
        if tag == "S":
            if is_input(name):
                raise InputError("%s: is left out by a sparse checkout; run this generator in a full checkout" % name)
        elif os.path.isfile(os.path.join(root, name)):
            names.add(name)
    return sorted(names)


def is_input(name):
    """True for a file whose content this generator reads."""
    return bool(CRD_FILE.match(name)) or (name.endswith(".go") and not name.endswith("_test.go"))


def read_text(root, relative):
    try:
        with open(os.path.join(root, relative), encoding="utf-8", errors="replace") as handle:
            return handle.read()
    except OSError as error:
        raise InputError("%s: cannot be read: %s" % (relative, error.strerror))


UNREADABLE = "(a chart template that cannot be read as YAML)"


def definitions(root, relative):
    """The custom resource definitions of one file. A line that holds only a Helm
    directive is dropped first, so a definition inside {{ if }} ... {{ end }} is read.
    A file below a folder named templates may hold more Helm than that: when it cannot
    be read, it gets one row that says so. Any other file that cannot be read is an error."""
    try:
        return read_definitions(root, relative)
    except InputError:
        if "templates" not in relative.split("/")[:-1]:
            raise
        return [{"kind": UNREADABLE, "group": "-", "plural": "-", "scope": "-", "versions": "-", "file": relative}]


def read_definitions(root, relative):
    text = "\n".join(line for line in read_text(root, relative).split("\n") if not HELM_LINE.match(line))
    try:
        documents = [d for d in yaml.safe_load_all(text) if d is not None]
    except yaml.YAMLError as error:
        raise InputError("%s: is not valid YAML after its Helm directive lines are dropped: %s"
                         % (relative, str(error).splitlines()[0]))
    found = []
    for document in documents:
        if not isinstance(document, dict) or document.get("kind") != "CustomResourceDefinition":
            continue
        spec = document.get("spec") if isinstance(document.get("spec"), dict) else {}
        names = spec.get("names") if isinstance(spec.get("names"), dict) else {}
        versions = spec.get("versions")
        plain = [spec.get("group"), names.get("kind"), names.get("plural"), spec.get("scope")]
        if not all(isinstance(value, str) and value for value in plain) or not isinstance(versions, list) or not versions:
            raise InputError("%s: a CustomResourceDefinition lacks group, names.kind, names.plural, scope or versions" % relative)
        shown = []
        for version in versions:
            if not isinstance(version, dict) or not isinstance(version.get("name"), str) or not version["name"]:
                raise InputError("%s: a version has no name" % relative)
            label = str(version["name"])
            if version.get("served") is False:
                label += " (not served)"
            if version.get("storage") is True and len(versions) > 1:
                label += " (storage)"
            shown.append(label)
        found.append({
            "kind": str(names["kind"]), "group": str(spec["group"]), "plural": str(names["plural"]),
            "scope": str(spec["scope"]), "versions": ", ".join(shown), "file": relative,
        })
    return found


def cell(text):
    return str(text).replace("|", "\\|").replace("\n", " ")


def generate(root):
    files = listed_files(root)
    found = []
    for name in files:
        if CRD_FILE.match(name):
            found.extend(definitions(root, name))
    needles = {}
    for item in found:
        if item["kind"] == UNREADABLE:
            continue
        needles[(item["plural"], item["group"])] = ('"%s"' % item["plural"], "%s.%s" % (item["plural"], item["group"]))
    named = set()
    if needles:
        for name in files:
            if not name.endswith(".go") or name.endswith("_test.go"):
                continue
            text = read_text(root, name)
            for key, (quoted, full_name) in needles.items():
                if key not in named and (quoted in text or full_name in text):
                    named.add(key)

    lines = [
        "Generated by %s. Do not edit." % SCRIPT,
        "",
        "# Custom resources",
        "",
        "One row for each CustomResourceDefinition in a `.yaml` file that lies directly in a folder named `crds`, under `platform/` or `products/`.",
        "To change this file, change an input and run `python3 %s`." % SCRIPT,
        "The check `generated-docs` fails a pull request in which this file is stale.",
        "This file says what the tree defines. It does not say what a cluster has installed.",
        "",
        "- Versions: every version of the definition. `(not served)` marks a version with `served: false`. `(storage)` marks the stored version when there is more than one.",
        "- A file below a folder named `templates` that holds more Helm than whole directive lines cannot be read as YAML. It gets one row that says so.",
        "- Named in Go code: `yes` when a `.go` file whose name does not end in `_test.go` holds the plural in double quotes, or the plural followed by a dot and the group. `no` means that no Go code of this repository asks for the resource by name.",
        "",
        "| Kind | Group | Versions | Scope | Plural | File | Named in Go code |",
        "|---|---|---|---|---|---|---|",
    ]
    for item in sorted(found, key=lambda item: (item["group"], item["kind"], item["file"])):
        lines.append("| %s | %s | %s | %s | %s | %s | %s |" % (
            cell(item["kind"]), cell(item["group"]), cell(item["versions"]), cell(item["scope"]),
            cell(item["plural"]), cell(item["file"]),
            "-" if item["kind"] == UNREADABLE else "yes" if (item["plural"], item["group"]) in named else "no"))
    if not found:
        lines.append("| (none) | - | - | - | - | - | - |")
    return "\n".join(lines) + "\n"


def write(root):
    text = generate(root)
    path = os.path.join(root, OUTPUT)
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8", newline="\n") as handle:
        handle.write(text)
    print("wrote: %s" % OUTPUT)
    return 0


def check(root):
    text = generate(root)
    try:
        with open(os.path.join(root, OUTPUT), encoding="utf-8", newline="") as handle:
            on_disk = handle.read()
    except OSError:
        on_disk = None
    if on_disk == text:
        print("current: %s" % OUTPUT)
        return 0
    if on_disk is None:
        print("%s does not exist" % OUTPUT)
    else:
        diff = list(difflib.unified_diff(on_disk.splitlines(), text.splitlines(), "on disk", "generated", lineterm="", n=0))
        for line in diff[:30]:
            print(line[:240])
        if len(diff) > 30:
            print("... %d more lines of difference" % (len(diff) - 30))
    print("stale: %s. Run: python3 %s  and commit that file." % (OUTPUT, SCRIPT))
    return 1

def crd_text(kind, plural, group, scope="Namespaced", versions=(("v1", True, True),)):
    text = ("apiVersion: apiextensions.k8s.io/v1\nkind: CustomResourceDefinition\nmetadata:\n  name: %s.%s\nspec:\n"
            "  group: %s\n  scope: %s\n  names:\n    kind: %s\n    plural: %s\n  versions:\n"

    for name, served, storage in versions:
        text += "    - name: %s\n      served: %s\n      storage: %s\n" % (name, str(served).lower(), str(storage).lower())
    return text

# check-generated-docs.yaml - a generated document is never stale (FND-102).
#
# The files under docs/generated/ are inventories that a script writes from the tree.
# Nobody edits them by hand. A pull request that changes an input of a generator runs the
# generator and commits the result. This workflow proves it: it runs every generator with
# --check, and a generator exits 1 when the file on disk differs from what it would write.
#
# What a generator is:
#   - one file, scripts/generators/<name>.py, that needs Python 3 and PyYAML only;
#   - with no argument it writes its output file; an inventory is written under docs/generated/;
#   - with --check it writes nothing and exits 1 when that file is stale, 2 when an input
#     cannot be read;
#   - with --self-test it proves its rules on a throw-away tree and shows that --check can fail;
#   - its output holds no value that CI writes on main without a pull request (a chart
#     version, a Blueprint version, a slot pin, an image tag). Such a value would make the
#     file stale with no pull request to repair it. A file that must carry such a value does
#     not belong here: the release job that writes the value writes that file.
# A new generator needs no change here: the two loops below find it by its name.
# Do not add a second drift workflow.
#
# It has no path filter on purpose: an input can be any file, and a check that a path
# filter skips never reports. It also runs on every push to main, so that a pull request
# whose check is red can see whether main itself is stale.
name: check-generated-docs

on:
  pull_request:
  merge_group:
  push:
    branches: [main]

permissions:
  contents: read

jobs:
  generators:
    name: generated-docs
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - name: Install PyYAML
        run: pip install --quiet pyyaml
      - name: Self-test of every generator
        run: |
          set -euo pipefail
          count=0
          for generator in scripts/generators/*.py; do
            echo "::group::${generator} --self-test"
            python3 "$generator" --self-test
            echo "::endgroup::"
            count=$((count + 1))
          done
          echo "self-test: ${count} generator(s) passed"
      - name: Every generated file is current
        run: |
          set -euo pipefail
          stale=0
          count=0
          for generator in scripts/generators/*.py; do
            code=0
            python3 "$generator" --check || code=$?
            if [ "$code" -ne 0 ]; then
              echo "::error::${generator} --check ended with exit code ${code}. Run: python3 ${generator}  and commit the file it writes."
              stale=1
            fi
            count=$((count + 1))
          done
          echo "check: ${count} generator(s) run"
          exit "$stale"
