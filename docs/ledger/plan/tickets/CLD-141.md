# CLD-141 — Protect provider releases from pruning before they move

## In plain words

**The problem today.** Four releases of the bootstrap kit belong to one cloud each: the Hetzner autoscaler, cloud controller and disk driver, and the Huawei disk driver. A later task moves them out of the shared kit. When a file leaves the kit, Flux deletes the objects it held, so a running Sovereign would lose its disk driver and its cloud controller for a while.

**What changes.** The four releases carry the Flux mark that says: never delete this object when it leaves the kit. Nothing else changes, and no release is installed, upgraded or removed by this change.

**Done means:**

- Each of the four provider releases of the bootstrap kit carries the annotation kustomize.toolkit.fluxcd.io/prune with the value disabled.
- No other file of the bootstrap kit carries that annotation.
- The change to each of the four files is the two added annotation lines and nothing else.
- The placement, dependency and render checks of the bootstrap kit stay green.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The four HelmRelease objects of the bootstrap kit that belong to one cloud each carry the Flux annotation `kustomize.toolkit.fluxcd.io/prune: disabled`. They are `bp-cluster-autoscaler-hcloud` (slot 50), `bp-hcloud-ccm` (slot 55), `bp-hcloud-csi` (slot 55a) and `bp-huawei-evs-csi` (slot 55b). Flux's kustomize-controller reads this annotation on the live object: when a file leaves the Kustomization that applied it, an object with the annotation is skipped by garbage collection instead of being deleted. Package CLD-144 later moves these four files out of `clusters/_template/bootstrap-kit` into a provider overlay. With the annotation in place first, a running Sovereign keeps the four releases (and so its storage and its cloud controller) while it is handed from one Kustomization to the other. A person can see the result in the four files: two lines were added to the metadata of each HelmRelease, and nothing else changed.
