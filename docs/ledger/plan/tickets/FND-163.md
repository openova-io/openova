# FND-163 — Console regression: jobs, resource views, cloud and infrastructure read pages

## In plain words

**The problem today.** The console regression list holds 73 rows about the jobs page, the reconciliation lens, the cloud and infrastructure pages and the platform state those pages report that people walk by hand. The row map assigns them to a gate check, but no browser test asserts them, so a regression on those pages is found only when someone walks them again.

**What changes.** Each of the 73 rows becomes one browser test of the gate harness, titled with its row id and its clause, and the row map names its file. The gate check of these pages points at the folder of the tests and enters the gate as expected to fail, so every live gate run runs them and records the result; the rows stay in the ledger until a later task deletes them together with the scripts that read them.

**Done means:**

- Every row that the row map gives to FND-G21 has one browser test whose title starts with the row id, and its line in the row map names that test file.
- The row map guard passes, and a row of FND-G21 whose line names no file, a file without the row's test, or a skipped test turns it red.
- Gate check FND-G21 is expected-fail and its implementation is the folder of the tests, so the harness selects it and lists 73 tests in 11 files.
- A test that changes the Sovereign puts back what it changed: the failing Job it creates is deleted, the HelmRelease it suspends is resumed, the placement it changes is restored.
- The 286 rows of the ledger are unchanged: the 73 converted rows stay until FND-166 deletes them together with the scripts that read them.

+/** The namespaces an ingress rule of a NetworkPolicy admits ('*' for any) and its ports ('*' for any). */
+function npIngress(np: Obj): Array<{ from: string[]; ports: string[] }> {
+  return arr(np, 'spec.ingress').map((rule) => {
+    const peers = arr(rule, 'from')
+    const from = peers.length === 0 ? ['*'] : peers.flatMap((p) => {
+      const sel = field(p, 'namespaceSelector')
+      if (sel === undefined) return field(p, 'ipBlock') ? [] : [np.metadata.namespace ?? '']
+      const labels = (field(sel, 'matchLabels') ?? {}) as Record<string, string>
+      const exact = labels['kubernetes.io/metadata.name']
+      if (exact) return [exact]
+      return Object.keys(labels).length === 0 && arr(sel, 'matchExpressions').length === 0 ? ['*'] : [`selector:${JSON.stringify(sel)}`]
+    })
+    const ports = arr(rule, 'ports').map((p) => String(field(p, 'port') ?? '*'))
+    return { from, ports: ports.length === 0 ? ['*'] : ports }
+  })
+}
+
+function admits(nps: Obj[], ns: string, port: string): boolean {
+  return nps.some((np) => npIngress(np).some((r) => (r.from.includes('*') || r.from.includes(ns)) && (r.ports.includes('*') || r.ports.includes(port))))
+}

+/** The namespaces a CiliumNetworkPolicy's ingress admits from ('*' for the cluster or the world). */
+function cnpIngressFrom(cnp: Obj): string[] {
+  const specs = [field(cnp, 'spec'), ...arr(cnp, 'specs')].filter((s) => s && typeof s === 'object')
+  return specs.flatMap((s) => arr(s, 'ingress').flatMap((rule) => {
+    const out: string[] = []
+    for (const e of arr(rule, 'fromEntities')) if (e === 'cluster' || e === 'all' || e === 'world') out.push('*')
+    for (const ep of arr(rule, 'fromEndpoints')) {
+      const labels = (field(ep, 'matchLabels') ?? {}) as Record<string, string>
+      const ns = labels['k8s:io.kubernetes.pod.namespace'] ?? labels['io.kubernetes.pod.namespace']
+      if (ns) out.push(ns)
+      else if (Object.keys(labels).length === 0 && arr(ep, 'matchExpressions').length === 0) out.push(cnp.metadata.namespace ?? '')
+    }
+    return out
