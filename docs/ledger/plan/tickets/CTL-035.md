# CTL-035 — Route registration leaves main()

## In plain words

**The problem today.** The API server registers all of its routes, more than two hundred, inside its main function, mixed with the code that builds its dependencies. Every change that adds or removes a route edits the same file of 2,800 lines, so two such changes cannot run side by side. Nothing records the route table, so a route that is lost or rewired in a change is not noticed.

**What changes.** The routes are registered by one function per concern, each in a file of its own, and one function builds the router from them; the main function only calls it. A test compares the router with a recorded route table that was written from the code before the move.

**Done means:**

- The main function of the API server registers no route; it builds the router with one call.
- The routes of each concern of the API, such as deployments, sovereigns or organizations, are in a file of their own.
- Every route is served by the same handler behind the same middleware as before, and a test that compares the router with the recorded table passes.
- A test fails when a route, its handler or its middleware changes and the recorded table does not change with it.
- The size guard of the API records the smaller main function.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`products/catalyst/bootstrap/api/cmd/api/main.go` registers no route. `main()` builds its dependencies as before and then calls `buildRouter(routeDeps{...})` once, at the place where the session group of routes stood. `buildRouter` is in the new file `cmd/api/routes.go`: it creates the chi router, adds the five middlewares, calls one `registerPublic<Concern>` function per concern, opens the session group with its two middlewares, and calls one `registerSession<Concern>` function per concern. Each register function is in `cmd/api/routes_<concern>.go` and holds the registration statements of that concern, copied character for character with their comments. The new test `cmd/api/routes_golden_test.go` walks the router and compares it with `cmd/api/testdata/routes.golden`, a table of every route, its handler and its middleware chain that was recorded from the unchanged `main()`. The test passes, so no route, handler or middleware changed. The API-structure guard counts 938 lines for `func main` instead of 2090.

## 3. The model (the law)
1. The router of catalyst-api is chi (`github.com/go-chi/chi/v5` v5.2.1). What the API serves is fixed by its route table: for each route, the method, the path pattern, the handler and the chain of middlewares around it. In chi the order of registration matters in one case only: two patterns that have a path parameter with different names at the same place (for example `/api/v1/deployments/{id}/…` and `/api/v1/deployments/{depId}/…`) are tried in the order they were registered. The golden test proves this case too: for every route it builds a request from the pattern and checks that the router resolves it to that same pattern.
2. `cmd/api/routes.go` declares `type routeDeps struct` with the five values of `main()` that a registration reads, in the order `main()` declares them: `corsOrigin string`, `log *slog.Logger`, `h *handler.Handler`, `pprofEnabled bool`, `oidcProv *oidcprovider.Provider`. It declares `func buildRouter(d routeDeps) chi.Router`.
3. The concern of a route is the first path segment after `/api/v1/`. Paths under `/catalyst/v1/` are the concern `catalyst`, paths under `/auth/` the concern `auth`, `/healthz`, `/readyz`, `/metrics` and `/debug` the concern `probes`, and paths under `/oidc/` the concern `oidc`. This gives 25 concerns and 25 files `routes_<concern>.go`.
4. A route outside the session group is registered by `registerPublic<Concern>(r chi.Router, d routeDeps)`; a route inside it by `registerSession<Concern>(rg chi.Router, d routeDeps)`. The function starts with `h := d.h`, so every moved statement keeps its text, `h.<Handler>` included. The test `TestKubernetesResourcePutRoutes` of `cmd/api/duplicate_routes_test.go` reads the handler of a registration as that text.
5. Each registration statement moves with the comment lines directly above it. Comment lines directly below a statement that are followed by a blank line, or by the end of the session group, move with it too. Inside a function the statements keep the order they had in `main()`. `buildRouter` calls the public functions, and then the session functions, in the order in which each concern first appears in `main()`.
6. Two registrations depend on configuration. The pprof routes: `main()` still reads `CATALYST_PPROF_ENABLED`, keeps the result in `pprofEnabled` and still logs its warning; `registerPublicProbes` mounts `middleware.Profiler()` on `/debug` when `d.pprofEnabled` is true. The OIDC provider routes: `main()` declares `var oidcProv *oidcprovider.Provider` and assigns it where it built the provider before; `registerPublicOIDC` registers the five `/oidc/` routes when `d.oidcProv` is not nil.
7. Nothing else in `main()` changes: every dependency is built, every environment variable is read, every goroutine is started and every log line is written as before, in the same order. `main()` no longer imports `github.com/go-chi/chi/v5`, `github.com/go-chi/cors` and `github.com/prometheus/client_golang/prometheus/promhttp`.
8. The change is made by a program, not by hand: the embedded script `move-routes.py` reads `main.go`, writes the 26 files of laws 2 to 6, and rewrites `main.go`. It refuses, and writes nothing, when `main.go` does not have the shape it expects. It is run from `/tmp` and is not committed.
9. `testdata/routes.golden` has one line `chain <n>: <middlewares>` per middleware chain and one line `<METHOD> <path> <handler> <n>` per route, sorted. The test file documents the format. A later change that adds, removes or rewires a route edits this file in the same commit. A change of the chi, cors or Prometheus client library can change a name in it; that change edits the file too.
10. `scripts/baselines/api-structure.json` lowers `main_lines` of `products/catalyst/bootstrap/api/cmd/api/main.go` from 2090 to 938. Its other counts do not change.

// goldenPath holds the route table, sorted. A line "chain <n>: <names>"
// names one middleware chain; a line "<METHOD> <path> <handler> <n>" names
// one route and the chain that wraps it. METHOD is ANY when one handler
// serves all nine methods. A name is the Go name after the last "/" of its
// package path, or the Go type of a handler that is not a function. A
// function literal is "<F>.(closure)", F the innermost exported function
// it was made in, or "main.(func literal)": the compiler names a literal
// by where it is declared and inlined, which changes when code moves. A
// route whose request resolves to another pattern ends in " => <pattern>".
const goldenPath = "testdata/routes.golden"

var (
	pathParam      = regexp.MustCompile(`\{[^}]*\}`)
	closureSegment = regexp.MustCompile(`^(func[0-9]+|[0-9]+)$`)
	allMethods     = "CONNECT DELETE GET HEAD OPTIONS PATCH POST PUT TRACE"
)

func funcName(pc uintptr) string {
	f := runtime.FuncForPC(pc)
	if f == nil {
		return "?"
	}
	name := f.Name()
	name = name[strings.LastIndex(name, "/")+1:]
	segs := strings.Split(name, ".")
	closure := false
	for _, s := range segs[1:] {
		closure = closure || closureSegment.MatchString(s)
	}
	if !closure {
		return name
	}
	for i := len(segs) - 1; i >= 1; i-- {
		if s := segs[i]; s != "" && s[0] >= 'A' && s[0] <= 'Z' {
			return s + ".(closure)"
		}
	}
	return "main.(func literal)"
}

func handlerName(h http.Handler) string {
	if fn, ok := h.(http.HandlerFunc); ok {
		return funcName(reflect.ValueOf(fn).Pointer())
	}
	return reflect.TypeOf(h).String()
}

// routeTable walks the router and returns its golden lines, sorted.
func routeTable(r chi.Router) ([]string, error) {
	type route struct{ path, handler, chain, found string }
	methods := map[route][]string{}
	err := chi.Walk(r, func(method, path string, h http.Handler, mws ...func(http.Handler) http.Handler) error {
		names := make([]string, 0, len(mws))
		for _, mw := range mws {
			names = append(names, funcName(reflect.ValueOf(mw).Pointer()))
		}
		concrete := strings.ReplaceAll(pathParam.ReplaceAllString(path, "x"), "*", "x")
		key := route{path, handlerName(h), strings.Join(names, " "), r.Find(chi.NewRouteContext(), method, concrete)}
		methods[key] = append(methods[key], method)
		return nil
	})
	chains := map[string]int{}
	var chainList, lines []string
	for key := range methods {
		if chains[key.chain] == 0 {
			chains[key.chain] = 1
			chainList = append(chainList, key.chain)
		}
	}
	sort.Strings(chainList)
	for n, chain := range chainList {
		chains[chain] = n + 1
		lines = append(lines, fmt.Sprintf("chain %d: %s", n+1, chain))
	}
	for key, ms := range methods {
		sort.Strings(ms)
		if strings.Join(ms, " ") == allMethods {
			ms = []string{"ANY"}
		}
		for _, m := range ms {
			line := fmt.Sprintf("%s %s %s %d", m, key.path, key.handler, chains[key.chain])
			if key.found != key.path {
				line += " => " + key.found
			}
			lines = append(lines, line)
		}
	}
	sort.Strings(lines)
	return lines, err
}

		}
	}
}

		t.Fatalf("walk the router: %v", err)
	}

	for _, c := range []struct {
		where        string
		lines, other []string
	}{{"golden file", want, got}, {"router", got, want}} {
		in := map[string]bool{}
		for _, line := range c.other {
			in[line] = true
		}
		for _, line := range c.lines {
			if !in[line] {
				t.Errorf("only in the %s: %s", c.where, line)
			}
		}
	}
	if len(got) != len(want) {
		t.Errorf("the router has %d lines, %s has %d", len(got), goldenPath, len(want))
	}
}

def code_only(line):
    """The line without string literals and without a // comment, for counting brackets."""
    out, i, n = [], 0, len(line)
    while i < n:
        c = line[i]
        if c == '"':
            i += 1
            while i < n and line[i] != '"':
                i += 2 if line[i] == "\\" else 1
            i += 1
        elif c == "`":
            i = line.index("`", i + 1) + 1 if "`" in line[i + 1:] else n
        elif line.startswith("//", i):
            break
        else:
            out.append(c)
            i += 1
    return "".join(out)


def concern_of(path):
    m = re.match(r"^/api/v1/([^/]+)(/|$)", path)
    if m:
        c = m.group(1)
    elif path.startswith("/catalyst/v1/"):
        c = "catalyst"

        c = "auth"
    elif path in ("/healthz", "/readyz", "/metrics"):
        c = "probes"
    else:
        raise Refuse("route %s has no concern rule" % path)

    if not src.endswith("\n"):

    if end is None:
        raise Refuse("func main: no closing line }")

def tidy(lines):
    """Close each seam: no blank line twice, after an opening brace or before a closing one."""
    out = []
    for n, line in enumerate(lines):
        if line is SEAM:
            continue
        seam = n > 0 and lines[n - 1] is SEAM
        if seam and line == "" and out and (out[-1] == "" or out[-1].endswith("{")):
            continue
        if seam and line.strip() in ("}", "})") and out and out[-1] == "":
            out.pop()
        out.append(line)
    return out


def file_text(concern, funcs):
