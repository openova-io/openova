# CTL-030 — Delete the endpoint pipeline and the two duplicate registrations

## In plain words

**The problem today.** The API still offers three routes that create, change and delete an Application endpoint by opening a pull request on a per-Organization repository, with a status checker that never reports anything. The console still shows New, Edit and Delete buttons that call these routes. Two resource-editor routes are registered twice in the API, and the first registration of each is dead code that reads as if it served the route.

**What changes.** The three routes, their handlers, their checks and their tests are gone, and the Endpoints tab only lists endpoints. Each of the two resource-editor routes is registered once, with the handler that already serves it today, and a test fails if any route is registered twice.

**Done means:**

- The API answers no create, change or delete request for an Application endpoint; listing the endpoints of an Application works as before.
- The Endpoints tab of an Application in the sovereign-admin console lists the endpoints with an Open link and has no button.
- Saving a Kubernetes object from the resource editor and scaling a workload are served by the same handlers as before the change.
- A test of the API fails when one method and one path are registered twice.
- The interface document of the API no longer describes the three routes.
- Every test of the API module and of the console passes on the pull request.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The catalyst-api module (`products/catalyst/bootstrap/api`) has no route, handler, type or test of the endpoint pull-request pipeline. `POST /catalyst/v1/apps/{id}/endpoints`, `PATCH /catalyst/v1/apps/{id}/endpoints/{name}` and `DELETE /catalyst/v1/apps/{id}/endpoints/{name}` are not registered; `GET /catalyst/v1/apps/{id}/endpoints` still is. The package `internal/precheck`, which only that pipeline used, is deleted. In `cmd/api/main.go` each of `PUT /api/v1/sovereigns/{id}/k8s/{kind}/{ns}/{name}` and `PUT /api/v1/sovereigns/{id}/k8s/{kind}/{ns}/{name}/scale` is registered once, with the handler that serves it today. A new test in `cmd/api` fails when one method and one path are registered twice. In the sovereign-admin console the Endpoints tab of an Application lists the endpoints and has no New, Edit or Delete button, and `src/lib/catalog.api.ts` has no function that calls the three routes. `docs/api/catalyst-api-openapi.yaml` no longer describes them.

## 3. The model (the law)
1. The router of catalyst-api is chi (`github.com/go-chi/chi/v5` v5.2.1). When one method and one path are registered twice, chi serves the handler registered **last**. The earlier registration is dead.
2. Today `PUT /api/v1/sovereigns/{id}/k8s/{kind}/{ns}/{name}` is registered first with `h.HandleK8sResourceApply` and later with `h.HandleK8sResourcePut`, so `h.HandleK8sResourcePut` serves it. Today `PUT /api/v1/sovereigns/{id}/k8s/{kind}/{ns}/{name}/scale` is registered twice with `h.HandleK8sResourceScale`. The change deletes the **earlier** registration of each, with the comment block above it. What serves each route does not change. `POST /api/v1/sovereigns/{id}/k8s/{kind}/{ns}/{name}/apply` with `h.HandleK8sResourceApply` stays.
3. Deleted from the module: the registrations of the three endpoint routes in `main.go`; the handlers `HandleCreateAppEndpoint`, `HandlePatchAppEndpoint`, `HandleDeleteAppEndpoint` and `mutateAppEndpoint`; the types `endpointMutationRequest`, `endpointPRResponse`, `endpointPreCheckResults`; the functions `mapPrecheckOp`, `mapResultPass`, `allPass`, `formatCommit`, `formatPRTitle`, `buildEndpointManifest`, `portOrDefault`, `protocolOrDefault`, `visibilityOrDefault`, `NewProductionGiteaIaCWriter` (the method and the package function), `resolveGiteaTokenForOrg`, `NewProductionCertConflictLookup`, `certOwnerFromObject`, `wildcardCovers`; the type `noopStatusChecker`; the method `EndpointPrecheckDepsForTest`; the fields `CertLookup`, `DNSLookup`, `KyvernoLookup`, `ExpectedDNSTarget`, `WriterFactory` and `Requester` of `EndpointPrecheckDeps`; the wiring of the writer factory and of the certificate lookup in `main.go`; the package `internal/precheck`; the test files `endpoint_handler_per_org_token_test.go` and `endpoint_handler_integration_test.go`; and every test of `endpoint_handler_test.go` that called one of the three routes, with the fakes only they used.

+// routeRegistrations parses every non-test Go file of this package and
+// returns each call of the form <router>.<Verb>("<path>", <handler>).
+// Asserted against the parsed AST, so a route in a comment or a string
+// does not count.
+func routeRegistrations(t *testing.T) []routeReg {
+	t.Helper()
+	entries, err := os.ReadDir(".")
+	if err != nil {
+		t.Fatalf("read package directory: %v", err)
+	}
+	fset := token.NewFileSet()
+	var regs []routeReg
+	for _, e := range entries {
+		name := e.Name()
+		if e.IsDir() || !strings.HasSuffix(name, ".go") || strings.HasSuffix(name, "_test.go") {
+			continue
+		}
+		file, err := parser.ParseFile(fset, name, nil, parser.SkipObjectResolution)
+		if err != nil {
+			t.Fatalf("parse %s: %v", name, err)
+		}
+		ast.Inspect(file, func(n ast.Node) bool {
+			call, ok := n.(*ast.CallExpr)
+			if !ok || len(call.Args) != 2 {
+				return true
+			}
+			sel, ok := call.Fun.(*ast.SelectorExpr)
+			if !ok {
+				return true
+			}
+			method, ok := routeVerbs[sel.Sel.Name]
+			if !ok {
+				return true
+			}
+			lit, ok := call.Args[0].(*ast.BasicLit)
+			if !ok || lit.Kind != token.STRING {
+				return true
+			}
