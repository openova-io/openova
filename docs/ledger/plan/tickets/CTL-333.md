# CTL-333 — The org-services chart stops setting REDPANDA_BROKERS

## In plain words

**The problem today.** The platform chart still hands the Organization services the address of a Kafka broker and a hint that names the bus protocol. No Kafka broker runs on a Sovereign, the services no longer read the address, and no code ever read the hint. The chart values still offer both settings, so a sovereign-admin can set them and nothing happens.

**What changes.** The chart no longer renders the two settings and its values no longer offer them. The address of NATS, the one event bus, is rendered exactly as before.

**Done means:**

- A render of the platform chart holds no Kafka broker address and no protocol hint, on a Sovereign and on Catalyst-Zero.
- A value that someone still sets for the broker address or the protocol hint changes nothing in the render.
- The NATS address in the shared settings of the Organization services is the same as before, on both kinds of installation and when a sovereign-admin sets it.
- Every setting that an Organization service reads from the shared settings object still exists in that object.
- The chart values offer one event-bus setting, the NATS address.
- The chart templates and the chart values no longer mention Kafka or Redpanda.
- The chart tests of the platform chart pass on the pull request.

The rest of this ticket is the exact instruction for the model that does the work.

def apply_text(body, old, new, errors, where):
    count = body.count(old)
    if count != 1:
        errors.append("%s: the text %r occurs %d times, not once" % (where, old.splitlines()[0], count))
        return body
    return body.replace(old, new)


def apply_range(body, first, last, sha, new, errors, where):
    lines = body.splitlines(keepends=True)
    start = None
    for i, line in enumerate(lines):
        if line == first + "\n":
            start = i
            break
    if start is None:
        errors.append("%s: no line equals %r" % (where, first))
        return body
    end = None
    for i in range(start + 1, len(lines)):
        if lines[i] == last + "\n":
            end = i
            break
    if end is None:
        errors.append("%s: no line after %r equals %r" % (where, first, last))
        return body
    got = hashlib.sha256("".join(lines[start:end + 1]).encode("utf-8")).hexdigest()
    if got != sha:
        errors.append("%s: the %d lines from %r have SHA-256 %s, not %s" % (where, end + 1 - start, first, got, sha))
        return body
    return "".join(lines[:start]) + new + "".join(lines[end + 1:])
