# FND-080 — Set the manifest from the baseline

## In plain words

**The problem today.** The twelve first checks of the foundation area are all expected-fail in the gate manifest, so a gate run that breaks one of them still passes. The baseline of the first fresh installation of main now records which of them really pass. Until the manifest follows it, the gate guards nothing that already works.

**What changes.** Each of the twelve checks that passed both gate runs of the baseline becomes required. A check that failed, was skipped or did not run stays expected-fail, for a fix package of its own.

**Done means:**

- Every check that FND-080 delivers and that passed both runs of the baseline is required in the gate manifest.
- Every check that FND-080 delivers and that did not pass both runs is still expected-fail.
- No check of another package or another area changed, and no field other than the state changed.
- The manifest tool accepts the new manifest against main, with this package named in the pull-request body.
- A hand edit that makes a passed check expected-fail, or a failed check required, turns the acceptance red.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. The baseline file is the only source of the decision. A check passed the baseline when its line in the check table of `docs/ledger/plan/spikes/FND-070-baseline.md` says PASS in the column "Run 1" and PASS in the column "Run 2". FAIL, SKIP, `-` or a missing line is not a pass: a check that did not run is never set to required.
2. The checks of this package are the entries of `docs/ledger/gates.yaml` whose `delivered_by` is `FND-080`. Only they may change. Each must be one of FND-G01 to FND-G12; FND-G13 is delivered by FND-120 and is never touched here, although the baseline lists it.
3. A check of this package that passed gets `state: required`. A check that did not pass keeps its state. Nothing moves backward (manifest rule 2).
4. Only the line `  state: ...` of a changed entry changes. Every other line of the manifest stays byte for byte.
5. The manifest is written by the tool of the block `FND-080-manifest.py` of this ticket. The tool runs from `/tmp` and is not committed. Running it twice gives the same file.
6. Acceptance proves the result from the head alone: the tool's command `check` rebuilds the decision from the baseline file and refuses a passed check that is not required and a required check that did not pass.

"""Set the gate manifest from the baseline of the first fresh installation of main.

  python3 -I FND-080-manifest.py write        sets the states in docs/ledger/gates.yaml
  python3 -I FND-080-manifest.py check        exit 0 when the states agree with the baseline

  1  The baseline is docs/ledger/plan/spikes/FND-070-baseline.md. It must exist and hold the header
     line of its check table exactly once:
     | Check | State at run | Run 1 | Run 2 | First failing step | Reason |
  2  A check line starts with "| <check id> | ". Its cells are the check, the state at the run, the

  3  The checks of this package are the checks of docs/ledger/gates.yaml whose delivered_by is
     FND-080. Each must be one of FND-G01 to FND-G12; any other is refused.
  4  A check passed the baseline when its line says PASS in run 1 and PASS in run 2. FAIL, SKIP, a
     missing result or a missing line is not a pass.
  5  write: each check of this package that passed gets "state: required". A check that did not
     pass keeps its state. A passed check whose state is neither expected-fail nor required is

  6  check: each check of this package is required if it passed, and is not required if it did not.

import os
import re
import sys
import tempfile

MANIFEST = "docs/ledger/gates.yaml"
BASELINE = "docs/ledger/plan/spikes/FND-070-baseline.md"
PACKAGE = "FND-080"
ALLOWED = tuple("FND-G%02d" % i for i in range(1, 13))
HEADER = "| Check | State at run | Run 1 | Run 2 | First failing step | Reason |"
LINE = re.compile(r"^\| ([A-Z]{3}-G[0-9]{2}) \| ([^|]*) \| ([^|]*) \| ([^|]*) \| ")


class Refused(Exception):
    pass


def read(root, rel):
    try:
        with open(os.path.join(root, rel)) as fh:
            return fh.read()
    except OSError:
        raise Refused(rel + " does not exist")


def baseline(root):
    """{check id: (result in run 1, result in run 2)} from the baseline file."""
    lines = read(root, BASELINE).split("\n")
    n = sum(1 for ln in lines if ln == HEADER)
    if n != 1:
        raise Refused("%s holds the header line of its check table %d times; once is needed" % (BASELINE, n))
    out = {}
    for ln in lines:
        m = LINE.match(ln)
        if m:
            if m.group(1) in out:
                raise Refused("%s has two lines for %s" % (BASELINE, m.group(1)))
            out[m.group(1)] = (m.group(3).strip(), m.group(4).strip())
    return out


def mine(text):
    """The checks of this package, as {id: state}, from the text of the manifest."""
    import yaml
    try:
        m = yaml.safe_load(text)
        checks = m["checks"]
    except Exception as e:
        raise Refused("%s cannot be read: %s" % (MANIFEST, e))
    out = {c["id"]: c.get("state") for c in checks if isinstance(c, dict) and c.get("delivered_by") == PACKAGE}
    for cid in sorted(out):
        if cid not in ALLOWED:
            raise Refused("%s names %s as delivered_by of %s, which is not one of FND-G01 to FND-G12" % (MANIFEST, PACKAGE, cid))
    return out


def passed(results, cid):
    return results.get(cid) == ("PASS", "PASS")


def how(results, cid):
    if cid not in results:
        return "no line in the baseline"
    return "run 1 %s, run 2 %s" % (results[cid][0] or "-", results[cid][1] or "-")


def set_required(text, cid):
    """The text with the state line of check cid set to required."""
    lines = text.split("\n")
    try:
        start = lines.index("- id: " + cid)
    except ValueError:
        raise Refused("%s has no line '- id: %s'" % (MANIFEST, cid))
    end = start + 1
    while end < len(lines) and lines[end].startswith("  "):
        end += 1
    hits = [i for i in range(start + 1, end) if lines[i].startswith("  state: ")]
    if len(hits) != 1:
        raise Refused("%s: the entry of %s has %d state lines; one is needed" % (MANIFEST, cid, len(hits)))
    lines[hits[0]] = "  state: required"
    return "\n".join(lines)


def same_but_states(before, after, ids):
    import yaml
    a, b = yaml.safe_load(before), yaml.safe_load(after)
    for c in a["checks"]:
        if c["id"] in ids:
            c["state"] = "required"
    return a == b


def write(root):
    results = baseline(root)
    text = read(root, MANIFEST)
    checks = mine(text)
    report, changed = [], []
    for cid in sorted(checks):
        state = checks[cid]
        if not passed(results, cid):
            report.append("%s: keeps %s, %s" % (cid, state, how(results, cid)))
            continue
        if state not in ("expected-fail", "required"):
            raise Refused("%s passed the baseline but its state is %s; only expected-fail moves to required" % (cid, state))
        if state == "expected-fail":
            changed.append(cid)
        report.append("%s: required, PASS in run 1 and run 2" % cid)
    new = text
    for cid in changed:
        new = set_required(new, cid)
    if not same_but_states(text, new, changed):
        raise Refused("the change of %s would touch more than the state lines of %s" % (MANIFEST, ", ".join(changed)))
    if new != text:
        with open(os.path.join(root, MANIFEST), "w") as fh:
            fh.write(new)
    n = sum(1 for cid in checks if passed(results, cid))
    return report + ["wrote %s: %d of %d checks of %s are required" % (MANIFEST, n, len(checks), PACKAGE)]


def check(root):
    results = baseline(root)
    checks = mine(read(root, MANIFEST))
    for cid in sorted(checks):
        if passed(results, cid) and checks[cid] != "required":
            raise Refused("%s passed the baseline (PASS in run 1 and run 2) but its state is %s; run write" % (cid, checks[cid]))
        if not passed(results, cid) and checks[cid] == "required":
            raise Refused("%s is required but did not pass the baseline (%s)" % (cid, how(results, cid)))
    n = sum(1 for cid in checks if passed(results, cid))
    return ["%s matches the baseline: %d of %d checks of %s are required" % (MANIFEST, n, len(checks), PACKAGE)]
