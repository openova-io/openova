# AIP-222 — Signal intake, grouping, candidate scoring, rule results

## In plain words

**The problem today.** The operations-records service can store signals and incidents, but nothing turns an alert into a signal and nothing decides which incident a signal belongs to. So no incident is ever opened. An agent asked to correlate would also have no prepared groups, no candidates and no answer to fall back on when it is late.

**What changes.** Alert events become signal records, one open signal per alert. Pending signals are grouped per Organization and cluster, open incidents are scored as candidates, and fixed rules open a new incident or attach the signals to an existing one, with no agent involved.

**Done means:**

- A firing alert event becomes one open signal; the same alert again updates that signal, and its resolution clears it.
- A copy of a firing event that arrives after the alert was resolved opens nothing.
- An alert of the platform itself is recorded for the operations Organization, and a malformed event is refused.
- Pending signals of one Organization and cluster wait a set time, shorter when one of them is urgent, and are then decided by rule: attached to an open incident that reports the same alert or the same entity, or opened as a new incident.
- A severity that a person set is never changed by the rules.
- The document offered to the correlator and the rule result use the fields of the correlator answer.
- 121 table cases test the intake, the grouping, the scoring and the rule path, and they run on every pull request that changes the service.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The module `products/ops-records` gains two packages, both written in full in this ticket. `internal/signals` reads an alert event (a CloudEvents 1.0 message of the subject `catalyst.alert.changed.v1`) and records it as a signal: one open signal per alert, updated when the alert is reported again and cleared when it is resolved. `internal/correlate` is the rule path: it collects the pending signals of each Organization and cluster into a batch, decides when the batch is due, groups its signals, scores the open incidents as candidates, makes the rule result, and applies a decision to the records (open an incident, attach signals to one, or watch). `Engine.Tick` runs the whole rule path with no agent. The package also builds the document that a correlator agent will be offered and the rule result in the form of that agent's answer, so that the later judge dispatcher (AIP-223) can use both. Nothing installs the service yet, so no Sovereign behaviour changes. A person can observe the result on the pull request: the checks `work-package / acceptance` and `go-lint` are green, and the module's test job reports the new tests.

## 3. The model (the law)
1. **Two new packages, nothing else.** The change adds exactly six files: `internal/signals/signals.go` and `signals_test.go`, `internal/correlate/correlate.go`, `apply.go`, `correlate_test.go` and `apply_test.go`, each the block of the same name in this ticket. No existing file changes: not `go.mod`, not `go.sum` (the packages use only the Go standard library and the module's own `internal/ids` and `internal/store`), not `README.md`, not `internal/store`.
2. **The alert event** (the rules are written at the top of `signals.go`). Envelope: `specversion` `1.0`, a non-empty `id` and `source`, `type` `io.openova.catalyst.alert.changed.v1`, `time` in RFC 3339, `datacontenttype` `application/json`, and `subject`, which when present must equal the data's `organization`. The data is a JSON object with the twelve fields that `docs/contracts/C3-alert-changed-v1.schema.json` requires; `alertId`, `name` and `cluster` must not be empty, `state` is `firing` or `resolved`, `startsAt` is a time that is not zero, `organization` is empty or matches `^[a-z][a-z0-9-]{2,31}$`, and `labels` maps strings to strings. Any other event is refused with an error that wraps `signals.ErrInvalidEvent`.
3. **From alert to signal.** Organization: the data's `organization`, or the Intake's operations Organization for a platform alert (empty `organization`); with neither the event is refused. Fingerprint: `alert/<cluster>/<alertId>`. Entity: kind `entityKind` in lower case and reference `<namespace>/<entityName>` (or `<entityName>` without a namespace); when `entityKind` or `entityName` is empty, kind `cluster` and reference the cluster name. Severity floor: `critical` 1; `high` and `error` 2; `warning` and `medium` 3; anything else 4 (letter case and surrounding spaces ignored). Title: `summary`, or `name` when the summary is empty. Body: the data as received. Kind: `name`. Source: `alert`.
4. **Intake.** A firing event updates the open signal with the same fingerprint and Organization (last seen rises to the event time, never falls; the floor becomes the more urgent one; title and body are replaced). Without an open signal it is first judged as a late copy (next sentence); when it is not one, it inserts a new open signal with first seen = `startsAt`, last seen = the later of `startsAt` and the event time, and no incident. A firing event without an open signal is a late copy, and writes nothing, when its time is not after the last seen time of a cleared signal with that fingerprint and Organization; a time equal to it is a late copy too. Every cleared signal that is read counts, not only the one first seen last. A resolved event clears the open signal with that fingerprint (last seen rises to the event time, never falls; title and body are replaced by those of the resolved event; the floor stays as it is); without an open signal it writes nothing. A signal that belongs to an incident keeps it when cleared. Intake never opens or changes an incident.
   **A stated limit of the late-copy check.** It reads at most 1,000 cleared signals of the fingerprint (`store.MaxLimit`), those first seen earliest: the store lists signals oldest first and has no other read. An alert with more than 1,000 cleared signals is judged against those 1,000 only, so a late copy of it can be taken as a new firing. A firing alert is never ignored because of this limit. This is the behaviour this ticket specifies; it is not a defect to record or repair. Lifting it needs a newest-first read in `internal/store`, which is outside this ticket (field 11).
5. **Batches and waits.** A signal is pending when it is open and belongs to no incident. Pending signals form one batch per Organization and cluster. A batch is due its wait after the earliest last seen time of its signals, and never before the batch's last decision (the zero time means none). The wait is `Policy.Batch`, or `Policy.UrgentBatch` when a signal of the batch has a floor of 2 or 1. Both waits must be positive and the urgent wait may not be the longer one.
6. **Groups.** The signals of a batch are grouped by namespace (the part of the entity reference before the first `/`); a signal without one is grouped by its entity `<kind>/<ref>`. Groups are named `g1`, `g2`, ... in the order of their earliest first seen time, then of their key. A group's floor is the most urgent floor of its signals.
7. **Candidates and scores.** A candidate is an incident of the batch's Organization that is open or mitigated and has no parent. Its score for a group: 1.0 when one of its signals has the cluster and the fingerprint of a signal of the group; else 0.9 for the same cluster and entity; else 0.5 for the same cluster and namespace; else 0.25 for the same cluster; else it is no candidate. A score below 1.0 is multiplied by 0.75 when the incident's last activity (the latest last seen time of its signals, or its opening time) is more than 2 hours and at most 24 hours before the group's earliest first seen time, and by 0.5 when it is more than 24 hours before. Scores are rounded to two decimals. A group is offered at most 5 candidates: highest score first, then the most recently opened, then the greater identifier.
8. **Rule result.** A group whose best candidate scores 0.6 or more is attached to it, with the more urgent of the incident's severity and the group's floor, the score as confidence and a causal chain that starts with `rules: `. Every other group gets `new`, with the group's floor as severity and 1 minus the best score as confidence. The rules never answer `watch`. The rule result and the offered document use the field names of the correlator's answer (`decisions`: `groupId`, `decision`, `incidentId`, `causalChain`, `confidence`, `severity`) and request (`task` `correlate`, `organization`, `groups` with `signals`, `candidates`, `allowed`); `allowed` holds `attach` only when a candidate is offered.
9. **Apply** (`Applier.Apply`, rules at its declaration in `apply.go`). It takes the groups, one decision per group, the actor (kind `rules` or `agent`, with a name) and the time, inside one store transaction. Bad decisions (a group without a decision, a decision for a group not offered, a group decided twice, an unknown decision, `attach` without an incident, a severity outside 1 to 4 for `attach` or `new`, a person as actor) are refused with an error that wraps `correlate.ErrBadDecision`, and nothing is written. Only signals that still belong to no incident are moved. `watch` writes nothing. `attach` follows a merged incident to the one it was merged into; when that one is resolved a new incident is opened instead. A severity set by a person is never changed; otherwise the severity becomes the decision's severity, made at least as urgent as every floor of the incident's signals. `new` opens an incident titled after the group's most urgent free signal. Timeline entries: `opened`, `signals_attached`, `severity`. Rules never change an incident's state, and nothing is written to the outbox.
10. **The rule path.** `Engine.Tick` loads the pending batches of every Organization (at most 1,000 open signals per call) and their candidate incidents, and decides each due batch by its rule result in its own transaction. One call runs at a time.
11. **Every example value is a test value.** The addresses `sovereign.example.org` and `a@example.org` and the Organization slugs `acme` and `beta` in the test files are fixed test values, not systems.

// Package signals turns alert events into signal records of the operations-records service.
//
// An alert event is a CloudEvents 1.0 message in structured JSON mode on the subject
// catalyst.alert.changed.v1 (contract C3; the data is described by
// docs/contracts/C3-alert-changed-v1.schema.json). Its attributes are specversion "1.0", id,
// type "io.openova.catalyst.alert.changed.v1", source, subject (the Organization slug; absent
// for a platform alert), time, datacontenttype "application/json" and data. The data holds the
// twelve fields alertId, organization, cluster, namespace, entityKind, entityName, name, state,
// severity, startsAt, summary and labels; a producer may add more.
//
// The rules of the intake:
//
//   - Organization. The signal belongs to the data's organization. A platform alert (empty
//     organization) belongs to the operations Organization of the Intake. With neither, the
//     event is refused.
//   - Fingerprint. "alert/<cluster>/<alertId>". The same alert reported again has the same
//     fingerprint, so at most one open signal exists per fingerprint and Organization.
//   - Entity. EntityKind is entityKind in lower case and EntityRef is "<namespace>/<entityName>",
//     or "<entityName>" when the namespace is empty. When entityKind or entityName is empty the
//     entity is the cluster itself: kind "cluster", ref the cluster name.
//   - Severity floor. From severity, ignoring letter case and spaces around it: "critical" 1;
//     "high" and "error" 2; "warning" and "medium" 3; anything else 4.
//   - Firing. An open signal with the fingerprint is updated: its last seen time rises to the
//     event time, its floor becomes the more urgent of the two, its title and body become the
//     new ones. Without one, a new open signal is inserted with first seen = startsAt and last
//     seen = the later of startsAt and the event time; it belongs to no incident.
//   - Late copy. A firing event without an open signal is a late copy, and is ignored, when its
//     time is not after the last seen time of a cleared signal with the fingerprint: the alert
//     was resolved at or after that time. Every cleared signal that is read counts, not only the
//     one first seen last. Intake reads at most store.MaxLimit cleared signals of the fingerprint
//     for this, the ones first seen earliest. An alert with more cleared signals than that is
//     judged against those only, so a late copy of it can be taken as a new firing. A firing
//     alert is never ignored because of the limit.
//   - Resolved. The open signal with the fingerprint is cleared: its last seen time rises to the
//     event time, and its title and body become those of the resolved event. Its floor stays.
//     Without one, nothing is written.
//   - Title. The summary, or the alert name when the summary is empty. Body: the data as received.
//
// Intake writes only signals. It never opens or changes an incident: package correlate does.
package signals

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"regexp"
	"strings"
	"time"

	"github.com/openova-io/openova/products/ops-records/internal/ids"
	"github.com/openova-io/openova/products/ops-records/internal/store"
)

// Subject is the NATS subject of the alert events.
const Subject = "catalyst.alert.changed.v1"

// EventType is the CloudEvents type of an alert event: "io.openova." and the subject.
const EventType = "io.openova." + Subject

// Alert states.
const (
	StateFiring   = "firing"
	StateResolved = "resolved"
)

// What Intake did with an event.
const (
	Inserted = "inserted" // a new open signal
	Updated  = "updated"  // an open signal was reported again
	Cleared  = "cleared"  // an open signal was cleared
	Ignored  = "ignored"  // nothing was written
)

// ErrInvalidEvent is wrapped by every error about the event itself. Such an event can never be
// taken; the caller acknowledges it and does not retry it.
var ErrInvalidEvent = errors.New("signals: invalid alert event")

// organizationPattern is the form of an Organization slug.
var organizationPattern = regexp.MustCompile(`^[a-z][a-z0-9-]{2,31}$`)

// requiredFields are the twelve fields every alert data holds.
var requiredFields = []string{"alertId", "organization", "cluster", "namespace", "entityKind",
	"entityName", "name", "state", "severity", "startsAt", "summary", "labels"}

// Alert is the data of an alert event.
type Alert struct {
	AlertID      string            `json:"alertId"`
	Organization string            `json:"organization"`
	Cluster      string            `json:"cluster"`
	Namespace    string            `json:"namespace"`
	EntityKind   string            `json:"entityKind"`
	EntityName   string            `json:"entityName"`
	Name         string            `json:"name"`
	State        string            `json:"state"`
	Severity     string            `json:"severity"`
	StartsAt     time.Time         `json:"startsAt"`
	Summary      string            `json:"summary"`
	Labels       map[string]string `json:"labels"`
}

// Event is one decoded alert event.
type Event struct {
	ID      string          // the CloudEvents id
	Source  string          // who published it
	Subject string          // the Organization slug of the envelope; empty when absent
	Time    time.Time       // when it was published, in UTC
	Alert   Alert           // the data
	Data    json.RawMessage // the data as received
}

type envelope struct {
	SpecVersion     string          `json:"specversion"`
	ID              string          `json:"id"`
	Type            string          `json:"type"`
	Source          string          `json:"source"`
	Subject         string          `json:"subject"`
	Time            string          `json:"time"`
	DataContentType string          `json:"datacontenttype"`
	Data            json.RawMessage `json:"data"`
}

func invalid(format string, args ...any) error {
	return fmt.Errorf("%w: %s", ErrInvalidEvent, fmt.Sprintf(format, args...))
}

// Decode reads one alert event. Every error wraps ErrInvalidEvent.
func Decode(msg []byte) (Event, error) {
	var env envelope
	if err := json.Unmarshal(msg, &env); err != nil {
		return Event{}, invalid("not a JSON object: %v", err)
	}
	switch {
	case env.SpecVersion != "1.0":
		return Event{}, invalid("specversion %q, want 1.0", env.SpecVersion)
	case env.Type != EventType:
		return Event{}, invalid("type %q, want %s", env.Type, EventType)
	case env.ID == "":
		return Event{}, invalid("id is empty")
	case env.Source == "":
		return Event{}, invalid("source is empty")
	case env.DataContentType != "application/json":
		return Event{}, invalid("datacontenttype %q, want application/json", env.DataContentType)
	}
	at, err := time.Parse(time.RFC3339Nano, env.Time)
	if err != nil {
		return Event{}, invalid("time %q is not RFC 3339", env.Time)
	}
	data := bytes.TrimSpace(env.Data)
	var fields map[string]json.RawMessage
	if len(data) == 0 || data[0] != '{' || json.Unmarshal(data, &fields) != nil {
		return Event{}, invalid("data is not a JSON object")
	}
	for _, k := range requiredFields {
		if _, ok := fields[k]; !ok {
			return Event{}, invalid("data has no field %s", k)
		}
	}
	var a Alert
	if err := json.Unmarshal(data, &a); err != nil {
		return Event{}, invalid("data: %v", err)
	}
	switch {
	case a.AlertID == "":
		return Event{}, invalid("alertId is empty")
	case a.Name == "":
		return Event{}, invalid("name is empty")
	case a.Cluster == "":
		return Event{}, invalid("cluster is empty")
	case a.State != StateFiring && a.State != StateResolved:
		return Event{}, invalid("state %q, want firing or resolved", a.State)
	case a.StartsAt.IsZero():
		return Event{}, invalid("startsAt is zero")
	case a.Organization != "" && !organizationPattern.MatchString(a.Organization):
		return Event{}, invalid("organization %q is not a slug", a.Organization)
	case env.Subject != "" && env.Subject != a.Organization:
		return Event{}, invalid("subject %q differs from organization %q", env.Subject, a.Organization)
	}
	a.StartsAt = a.StartsAt.UTC()
	return Event{ID: env.ID, Source: env.Source, Subject: env.Subject, Time: at.UTC(), Alert: a,
		Data: append(json.RawMessage(nil), data...)}, nil
}

// SeverityFloor maps an alert severity to a severity floor of 1 (most urgent) to 4.
func SeverityFloor(severity string) int {
	switch strings.ToLower(strings.TrimSpace(severity)) {
	case "critical":
		return 1
	case "high", "error":
		return 2
	case "warning", "medium":
		return 3
	default:
		return 4
	}
}

// Fingerprint returns the fingerprint of an alert: "alert/<cluster>/<alertId>".
func Fingerprint(cluster, alertID string) string { return "alert/" + cluster + "/" + alertID }

// Entity returns the entity kind and reference of an alert.
func Entity(a Alert) (kind, ref string) {
	if a.EntityKind == "" || a.EntityName == "" {
		return "cluster", a.Cluster
	}
	ref = a.EntityName
	if a.Namespace != "" {
		ref = a.Namespace + "/" + a.EntityName
	}
	return strings.ToLower(a.EntityKind), ref
}

// Intake writes the signals of alert events.
type Intake struct {
	// OperationsOrganization receives the signals of platform alerts. Empty: a platform alert
	// is refused.
	OperationsOrganization string
	// NewID makes the identifier of a new signal. Nil means ids.New.
	NewID func() string
}

// Result says what Intake did with one event. Signal is the row as written, or the zero value
// when nothing was written.
type Result struct {
	Action string
	Signal store.Signal
}

// Take records one event in the transaction tx. It returns an error that wraps
// ErrInvalidEvent when the event cannot be taken, and a store error when the store fails.
func (in Intake) Take(ctx context.Context, tx store.Tx, ev Event) (Result, error) {
	a := ev.Alert
	org := a.Organization
	if org == "" {
		org = in.OperationsOrganization
	}
	if org == "" {
		return Result{}, invalid("platform alert %s and no operations Organization", a.AlertID)
	}
	fp := Fingerprint(a.Cluster, a.AlertID)
	open, err := tx.ListSignals(ctx, store.SignalFilter{Organization: org, Fingerprint: fp, State: store.SignalOpen})
	if err != nil {
		return Result{}, err
	}
	title := a.Summary
	if title == "" {
		title = a.Name
	}
	at := ev.Time
	if a.State == StateResolved {
		if len(open) == 0 {
			return Result{Action: Ignored}, nil
		}
		s := open[len(open)-1]
		s.State = store.SignalCleared
		s.LastSeen = later(s.LastSeen, at)
		s.Title, s.Body = title, ev.Data
		if err := tx.UpdateSignal(ctx, s); err != nil {
			return Result{}, err
		}
		return Result{Action: Cleared, Signal: s}, nil
	}
	floor := SeverityFloor(a.Severity)
	if len(open) > 0 {
		s := open[len(open)-1]
		s.LastSeen = later(s.LastSeen, at)
		s.SeverityFloor = min(s.SeverityFloor, floor)
		s.Title, s.Body = title, ev.Data
		if err := tx.UpdateSignal(ctx, s); err != nil {
			return Result{}, err
		}
		return Result{Action: Updated, Signal: s}, nil
	}
	cleared, err := tx.ListSignals(ctx, store.SignalFilter{Organization: org, Fingerprint: fp,
		State: store.SignalCleared, Limit: store.MaxLimit})
	if err != nil {
		return Result{}, err
	}
	for _, c := range cleared {
		if !at.After(c.LastSeen) {
			return Result{Action: Ignored}, nil
		}
	}
	newID := in.NewID
	if newID == nil {
		newID = ids.New
	}
	kind, ref := Entity(a)
	s := store.Signal{
		ID: newID(), Organization: org, Source: store.SourceAlert, Kind: a.Name,
		EntityKind: kind, EntityRef: ref, Cluster: a.Cluster, SeverityFloor: floor,
		Title: title, Body: ev.Data, Fingerprint: fp, State: store.SignalOpen,
		FirstSeen: a.StartsAt, LastSeen: later(a.StartsAt, at),
	}
	if err := tx.InsertSignal(ctx, s); err != nil {
		return Result{}, err
	}
	return Result{Action: Inserted, Signal: s}, nil
}

func later(a, b time.Time) time.Time {
	if b.After(a) {
		return b
	}
	return a
}

// Package correlate decides, by rules alone, which incident new signals belong to.
//
// The rule path is a main path: it runs without any agent, and its result stands whenever no
// agent answers in time. A judge (the correlator agent) is offered the same groups and
// candidates and answers in the same form as the rule result.
//
// The rules:
//
//   - Pending. A signal is pending when it is open and belongs to no incident. Pending signals
//     are decided per batch: one Organization and one cluster.
//   - Due. A batch waits Policy.Batch, or Policy.UrgentBatch when one of its signals has a
//     severity floor of 2 or more urgent. The wait starts at the earliest last seen time of its
//     signals, and never before the batch's last decision.
//   - Groups. The signals of a batch are grouped by namespace (the part of EntityRef before the
//     first "/"); a signal without a namespace is grouped by its entity "<kind>/<ref>". Groups are
//     named g1, g2, ... in the order of their earliest first seen time, then of their key. A
//     group's floor is the most urgent floor of its signals.
//   - Candidates. Every incident of the batch's Organization that is open or mitigated and was
//     not merged into another. Its score for a group: 1.0 when one of its signals has the same
//     cluster and fingerprint as a signal of the group; else 0.9 when one has the same cluster
//     and entity; else 0.5 when one has the same cluster and namespace; else 0.25 when one has
//     the same cluster; else it is no candidate. A score below 1.0 is multiplied by 1.0 when the
//     incident's last activity (the latest last seen time of its signals, or its opening time) is
//     at most 2 hours before the group's earliest first seen time, by 0.75 when it is at most 24
//     hours before, and by 0.5 otherwise. Scores are rounded to two decimals. A group is offered
//     its 5 best candidates: highest score first, then the most recently opened, then the greater
//     identifier.
//   - Rule result. A group whose best candidate scores AttachScore or more is attached to it,
//     with the more urgent of the incident's severity and the group's floor. Any other group
//     opens a new incident with the group's floor as its severity. The rule path never answers
//     watch.
//   - Apply. The rules and a judge write through Applier.Apply (apply.go), which states how a
//     decision changes the records. Engine.Tick is the rule path end to end.
//
// Times in a batch: a signal's first seen time is when its alert started; its last seen time is
// when it was last reported.

	Batch       time.Duration // the wait of a batch
	UrgentBatch time.Duration // the wait of a batch with a floor of 2 or more urgent

// Validate returns an error when a wait is not positive or the urgent wait is the longer one.
func (p Policy) Validate() error {
	if p.Batch <= 0 || p.UrgentBatch <= 0 {
		return fmt.Errorf("correlate: both waits must be positive, got %s and %s", p.Batch, p.UrgentBatch)
	}
	if p.UrgentBatch > p.Batch {
		return fmt.Errorf("correlate: the urgent wait %s is longer than the wait %s", p.UrgentBatch, p.Batch)
	}
	return nil
}

// Pending returns the batches of the pending signals among signals, ordered by Organization
// and cluster. Signals that are cleared or belong to an incident are left out.
func Pending(signals []store.Signal) []Batch {
	byKey := map[string]*Batch{}
	for _, s := range signals {
		if s.State != store.SignalOpen || s.IncidentID != "" {
			continue
		}
		b := byKey[s.Organization+"/"+s.Cluster]
		if b == nil {
			b = &Batch{Organization: s.Organization, Cluster: s.Cluster}
			byKey[s.Organization+"/"+s.Cluster] = b
		}
		b.Signals = append(b.Signals, s)
	}
	out := make([]Batch, 0, len(byKey))
	for _, b := range byKey {
		sortSignals(b.Signals)
		out = append(out, *b)
	}
	sort.Slice(out, func(i, j int) bool {
		if out[i].Organization != out[j].Organization {
			return out[i].Organization < out[j].Organization
		}
		return out[i].Cluster < out[j].Cluster
	})
	return out
}

// DueAt returns when the batch is decided. lastDecision is the time of the batch's last
// decision, or the zero time. A batch without signals is never due: DueAt returns the zero time.
func DueAt(b Batch, lastDecision time.Time, p Policy) time.Time {
	if len(b.Signals) == 0 {
		return time.Time{}
	}
	start := b.Signals[0].LastSeen
	wait := p.Batch
	for _, s := range b.Signals {
		if s.LastSeen.Before(start) {
			start = s.LastSeen
		}
		if s.SeverityFloor <= 2 {
			wait = p.UrgentBatch
		}
	}
	if lastDecision.After(start) {
		start = lastDecision
	}
	return start.Add(wait)
}

// Namespace returns the namespace of a signal: the part of EntityRef before the first "/", or
// the empty string.
func Namespace(s store.Signal) string {
	ns, _, found := strings.Cut(s.EntityRef, "/")
	if !found {
		return ""
	}
	return ns
}

// EntityOf returns "<kind>/<ref>" of a signal.
func EntityOf(s store.Signal) string { return s.EntityKind + "/" + s.EntityRef }

// Groups returns the groups of a batch.
func Groups(b Batch) []Group {
	byKey := map[string]*Group{}
	for _, s := range b.Signals {
		key := Namespace(s)
		if key == "" {
			key = EntityOf(s)
		}
		g := byKey[key]
		if g == nil {
			g = &Group{Key: key, Floor: store.SeverityLowest}
			byKey[key] = g
		}
		g.Signals = append(g.Signals, s)
		g.Floor = min(g.Floor, s.SeverityFloor)
	}
	out := make([]Group, 0, len(byKey))
	for _, g := range byKey {
		sortSignals(g.Signals)
		out = append(out, *g)
	}
	sort.Slice(out, func(i, j int) bool {
		a, b := out[i].Signals[0].FirstSeen, out[j].Signals[0].FirstSeen
		if !a.Equal(b) {
			return a.Before(b)
		}
		return out[i].Key < out[j].Key
	})
	for i := range out {
		out[i].ID = fmt.Sprintf("g%d", i+1)
	}
	return out
}

// Score returns the score of an incident for a group and the reason for it. A score of 0 means
// the incident is no candidate.
func Score(g Group, iv IncidentView) (float64, string) {
	base, reason := 0.0, ""
	for _, gs := range g.Signals {
		for _, is := range iv.Signals {
			s, r := 0.0, ""
			switch {
			case gs.Cluster == is.Cluster && gs.Fingerprint == is.Fingerprint:
				s, r = scoreFingerprint, "the same alert "+gs.Kind+" is reported again"
			case gs.Cluster == is.Cluster && EntityOf(gs) == EntityOf(is):
				s, r = scoreEntity, "the same entity "+EntityOf(gs)+" reports again"
			case gs.Cluster == is.Cluster && Namespace(gs) != "" && Namespace(gs) == Namespace(is):
				s, r = scoreNamespace, "the same namespace "+Namespace(gs)
			case gs.Cluster == is.Cluster:
				s, r = scoreCluster, "the same cluster "+gs.Cluster
			}
			if s > base {
				base, reason = s, r
			}
		}
	}
	if base == 0 {
		return 0, ""
	}
	if base < scoreFingerprint {
		gap := earliest(g).Sub(lastActivity(iv))
		switch {
		case gap <= 2*time.Hour:
		case gap <= 24*time.Hour:
			base *= 0.75
		default:
			base *= 0.5
		}
	}
	return round2(base), reason
}

// Candidates returns the candidates of a group among incidents, best first, at most
// MaxCandidates.
func Candidates(g Group, incidents []IncidentView) []Candidate {
	var out []Candidate
	for _, iv := range incidents {
		in := iv.Incident
		if in.Organization != organizationOf(g) || in.ParentID != "" ||
			(in.State != store.IncidentOpen && in.State != store.IncidentMitigated) {
			continue
		}
		score, reason := Score(g, iv)
		if score == 0 {
			continue
		}
		out = append(out, Candidate{IncidentID: in.ID, Title: in.Title, Severity: in.Severity,
			Entities: entities(iv.Signals), OpenedAt: in.OpenedAt.UTC(), Score: score, reason: reason})
	}
	sort.Slice(out, func(i, j int) bool {
		if out[i].Score != out[j].Score {
			return out[i].Score > out[j].Score
		}
		if !out[i].OpenedAt.Equal(out[j].OpenedAt) {
			return out[i].OpenedAt.After(out[j].OpenedAt)
		}
		return out[i].IncidentID > out[j].IncidentID
	})
	if len(out) > MaxCandidates {
		out = out[:MaxCandidates]
	}
	return out
}

// Rule returns the rule decision for a group, given its candidates best first.
func Rule(g Group, candidates []Candidate) Decision {
	if len(candidates) > 0 && candidates[0].Score >= AttachScore {
		c := candidates[0]
		return Decision{GroupID: g.ID, Decision: Attach, IncidentID: c.IncidentID,
			CausalChain: "rules: " + c.reason, Confidence: c.Score, Severity: min(c.Severity, g.Floor)}
	}
	best := 0.0
	if len(candidates) > 0 {
		best = candidates[0].Score
	}
	return Decision{GroupID: g.ID, Decision: New,
		CausalChain: fmt.Sprintf("rules: no open incident scores %.2f or more", AttachScore),
		Confidence:  round2(1 - best), Severity: g.Floor}
}

// Prepare groups a batch, scores the candidates among incidents and makes the rule result and
// the document offered to the correlator.
func Prepare(b Batch, incidents []IncidentView) Prepared {
	p := Prepared{Batch: b, Groups: Groups(b), Candidates: map[string][]Candidate{}}
	p.Request = Request{Task: "correlate", Organization: b.Organization,
		Groups: []RequestGroup{}, Candidates: []Candidate{}}
	offered := map[string]int{} // incident ID -> index in Request.Candidates
	for _, g := range p.Groups {
		cands := Candidates(g, incidents)
		p.Candidates[g.ID] = cands
		p.RuleResult.Decisions = append(p.RuleResult.Decisions, Rule(g, cands))
		rg := RequestGroup{GroupID: g.ID}
		for _, s := range g.Signals {
			rg.Signals = append(rg.Signals, RequestSignal{SignalID: s.ID, Kind: s.Kind, Entity: EntityOf(s),
				Title: s.Title, FirstSeen: s.FirstSeen.UTC(), SeverityFloor: s.SeverityFloor})
		}
		p.Request.Groups = append(p.Request.Groups, rg)
		for _, c := range cands {
			if i, ok := offered[c.IncidentID]; ok {
				if c.Score > p.Request.Candidates[i].Score {
					p.Request.Candidates[i].Score = c.Score
				}
				continue
			}
			offered[c.IncidentID] = len(p.Request.Candidates)
			p.Request.Candidates = append(p.Request.Candidates, c)
		}
	}
	p.Request.Allowed = []string{New, Watch}
	if len(p.Request.Candidates) > 0 {
		p.Request.Allowed = []string{Attach, New, Watch}
	}
	return p
}

// Load reads the pending batches of every Organization (organization empty) or of one, and
// the incidents that can be candidates. It reads at most store.MaxLimit open signals and
// store.MaxLimit open and as many mitigated incidents per call.
func Load(ctx context.Context, r store.Reader, organization string) ([]Batch, map[string][]IncidentView, error) {
	sigs, err := r.ListSignals(ctx, store.SignalFilter{Organization: organization, State: store.SignalOpen,
		Limit: store.MaxLimit})
	if err != nil {
		return nil, nil, err
	}
	batches := Pending(sigs)
	views := map[string][]IncidentView{}
	for _, b := range batches {
		if _, done := views[b.Organization]; done {
			continue
		}
		var list []IncidentView
		for _, state := range []string{store.IncidentOpen, store.IncidentMitigated} {
			ins, err := r.ListIncidents(ctx, store.IncidentFilter{Organization: b.Organization, State: state,
				Limit: store.MaxLimit})
			if err != nil {
				return nil, nil, err
			}
			for _, in := range ins {
				if in.ParentID != "" {
					continue
				}
				ss, err := r.ListSignals(ctx, store.SignalFilter{Organization: b.Organization, IncidentID: in.ID,
					Limit: store.MaxLimit})
				if err != nil {
					return nil, nil, err
				}
				list = append(list, IncidentView{Incident: in, Signals: ss})
			}
		}
		views[b.Organization] = list
	}
	return batches, views, nil
}

func organizationOf(g Group) string {
	if len(g.Signals) == 0 {
		return ""
	}
	return g.Signals[0].Organization
}

func earliest(g Group) time.Time {
	t := g.Signals[0].FirstSeen
	for _, s := range g.Signals {
		if s.FirstSeen.Before(t) {
			t = s.FirstSeen
		}
	}
	return t
}

func lastActivity(iv IncidentView) time.Time {
	t := iv.Incident.OpenedAt
	for _, s := range iv.Signals {
		if s.LastSeen.After(t) {
			t = s.LastSeen
		}
	}
	return t
}

func entities(signals []store.Signal) []string {
	seen := map[string]bool{}
	out := []string{}
	for _, s := range signals {
		if e := EntityOf(s); !seen[e] {
			seen[e] = true
			out = append(out, e)
		}
	}
	sort.Strings(out)
	if len(out) > 10 {
		out = out[:10]
	}
	return out
}

func sortSignals(ss []store.Signal) {
	sort.Slice(ss, func(i, j int) bool {
		if !ss[i].FirstSeen.Equal(ss[j].FirstSeen) {
			return ss[i].FirstSeen.Before(ss[j].FirstSeen)
		}
		return ss[i].ID < ss[j].ID
	})
}

func round2(x float64) float64 { return math.Round(x*100) / 100 }

package correlate

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"sync"
	"time"

	"github.com/openova-io/openova/products/ops-records/internal/ids"
	"github.com/openova-io/openova/products/ops-records/internal/store"
)

// How Apply applied the decision of one group.
const (
	AppliedAttach = "attached" // the free signals joined an incident
	AppliedNew    = "opened"   // the free signals opened a new incident
	AppliedWatch  = "watching" // nothing was written; the signals stay pending
	AppliedNone   = "nothing"  // every signal of the group already belongs to an incident
)

// Timeline entries Apply writes.
const (
	EventOpened   = "opened"
	EventAttached = "signals_attached"
	EventSeverity = "severity"
)

// RuleActor is the actor name of the rule path in a timeline.
const RuleActor = "correlate-rules"

// maxParentHops is how far Apply follows merged incidents to the one they were merged into.
const maxParentHops = 10

// ErrBadDecision is wrapped by every error about the decisions given to Apply.
var ErrBadDecision = errors.New("correlate: bad decisions")

// Actor is who decided: the rules (store.ByRules) or a judge (store.ByAgent), with a name.
type Actor struct {
	Kind string
	Name string
}

// Rules is the actor of the rule path.
var Rules = Actor{Kind: store.ByRules, Name: RuleActor}

// GroupResult is what Apply did for one group.
type GroupResult struct {
	GroupID    string
	Applied    string   // one of the Applied constants
	IncidentID string   // the incident the signals joined or opened; empty otherwise
	SignalIDs  []string // the signals that changed
	Note       string   // why the result differs from the decision; empty when it does not
}

// Applier applies decisions to the records.
type Applier struct {
	// NewIncidentID makes the identifier of a new incident. Nil means ids.NewIncident.
	NewIncidentID func() string
}

// Apply applies one decision per group in the transaction tx. Every group needs exactly one
// decision and every decision one group, or Apply returns an error wrapping ErrBadDecision and
// writes nothing. The decisions are applied in the order of the groups:
//
//   - Only the free signals of a group are moved: those that, read again in tx, belong to no
//     incident. A group without free signals gets AppliedNone.
//   - watch writes nothing.
//   - attach follows a merged incident to the incident it was merged into. When that incident
//     is resolved, the group opens a new incident instead. The signals join the incident, an
//     entry signals_attached is written, and the severity becomes the decision's severity,
//     made at least as urgent as every floor of the incident's signals, unless a person set it.
//     A changed severity writes an entry severity.
//   - new opens an incident titled after the group's most urgent free signal, with the
//     decision's severity made at least as urgent as the floor of the free signals, opened and
//     rated by the actor's kind. An entry opened is written.
func (a Applier) Apply(ctx context.Context, tx store.Tx, groups []Group, decisions []Decision, by Actor,
	now time.Time) ([]GroupResult, error) {
	if by.Kind != store.ByRules && by.Kind != store.ByAgent || by.Name == "" {
		return nil, fmt.Errorf("%w: actor %q %q", ErrBadDecision, by.Kind, by.Name)
	}
	byGroup := map[string]Decision{}
	for _, d := range decisions {
		if _, dup := byGroup[d.GroupID]; dup {
			return nil, fmt.Errorf("%w: group %q decided twice", ErrBadDecision, d.GroupID)
		}
		switch {
		case d.Decision != Attach && d.Decision != New && d.Decision != Watch:
			return nil, fmt.Errorf("%w: decision %q", ErrBadDecision, d.Decision)
		case d.Decision == Attach && d.IncidentID == "":
			return nil, fmt.Errorf("%w: attach of group %q names no incident", ErrBadDecision, d.GroupID)
		case d.Decision != Watch && (d.Severity < store.SeverityHighest || d.Severity > store.SeverityLowest):
			return nil, fmt.Errorf("%w: severity %d", ErrBadDecision, d.Severity)
		}
		byGroup[d.GroupID] = d
	}
	for _, g := range groups {
		if _, ok := byGroup[g.ID]; !ok {
			return nil, fmt.Errorf("%w: group %q has no decision", ErrBadDecision, g.ID)
		}
	}
	if len(byGroup) != len(groups) {
		return nil, fmt.Errorf("%w: a decision names a group that was not offered", ErrBadDecision)
	}
	out := make([]GroupResult, 0, len(groups))
	for _, g := range groups {
		r, err := a.applyGroup(ctx, tx, g, byGroup[g.ID], by, now)
		if err != nil {
			return nil, err
		}
		out = append(out, r)
	}
	return out, nil
}

func (a Applier) applyGroup(ctx context.Context, tx store.Tx, g Group, d Decision, by Actor,
	now time.Time) (GroupResult, error) {
	res := GroupResult{GroupID: g.ID}
	var free []store.Signal
	for _, s := range g.Signals {
		cur, err := tx.GetSignal(ctx, s.Organization, s.ID)
		if err != nil {
			return res, err
		}
		if cur.IncidentID == "" {
			free = append(free, cur)
		}
	}
	if len(free) == 0 {
		res.Applied = AppliedNone
		return res, nil
	}
	if d.Decision == Watch {
		res.Applied = AppliedWatch
		return res, nil
	}
	org := free[0].Organization
	if d.Decision == Attach {
		target, err := root(ctx, tx, org, d.IncidentID)
		if err != nil {
			return res, err
		}
		if target.State != store.IncidentResolved {
			if target.ID != d.IncidentID {
				res.Note = d.IncidentID + " was merged into " + target.ID
			}
			return a.attach(ctx, tx, res, target, free, d, by, now)
		}
		res.Note = target.ID + " is resolved; a new incident was opened"
	}
	return a.open(ctx, tx, res, org, free, d, by, now)
}

func (a Applier) attach(ctx context.Context, tx store.Tx, res GroupResult, in store.Incident, free []store.Signal,
	d Decision, by Actor, now time.Time) (GroupResult, error) {
	moved, err := moveSignals(ctx, tx, free, in.ID)
	if err != nil {
		return res, err
	}
	if err := appendEvent(ctx, tx, in, now, by, EventAttached, map[string]any{"groupId": d.GroupID,
		"signals": moved, "decision": d.Decision, "causalChain": d.CausalChain, "confidence": d.Confidence}); err != nil {
		return res, err
	}
	if in.SeveritySetBy != store.ByPerson {
		all, err := tx.ListSignals(ctx, store.SignalFilter{Organization: in.Organization, IncidentID: in.ID,
			Limit: store.MaxLimit})
		if err != nil {
			return res, err
		}
		want := d.Severity
		for _, s := range all {
			want = min(want, s.SeverityFloor)
		}
		if want != in.Severity {
			from := in.Severity
			in.Severity, in.SeveritySetBy = want, by.Kind
			if err := tx.UpdateIncident(ctx, in); err != nil {
				return res, err
			}
			if err := appendEvent(ctx, tx, in, now, by, EventSeverity, map[string]any{"from": from, "to": want}); err != nil {
				return res, err
			}
		}
	}
	res.Applied, res.IncidentID, res.SignalIDs = AppliedAttach, in.ID, moved
	return res, nil
}

func (a Applier) open(ctx context.Context, tx store.Tx, res GroupResult, org string, free []store.Signal,
	d Decision, by Actor, now time.Time) (GroupResult, error) {
	newID := a.NewIncidentID
	if newID == nil {
		newID = ids.NewIncident
	}
	head := free[0]
	sev := d.Severity
	for _, s := range free {
		sev = min(sev, s.SeverityFloor)
		if s.SeverityFloor < head.SeverityFloor {
			head = s
		}
	}
	in := store.Incident{ID: newID(), Organization: org, Title: head.Title, Severity: sev,
		SeveritySetBy: by.Kind, State: store.IncidentOpen, OpenedBy: by.Kind, OpenedAt: now}
	if err := tx.InsertIncident(ctx, in); err != nil {
		return res, err
	}
	moved, err := moveSignals(ctx, tx, free, in.ID)
	if err != nil {
		return res, err
	}
	if err := appendEvent(ctx, tx, in, now, by, EventOpened, map[string]any{"groupId": d.GroupID,
		"signals": moved, "decision": d.Decision, "causalChain": d.CausalChain, "confidence": d.Confidence,
		"severity": sev}); err != nil {
		return res, err
	}
	res.Applied, res.IncidentID, res.SignalIDs = AppliedNew, in.ID, moved
	return res, nil
}

// root returns the incident id, or the incident it was merged into, following at most
// maxParentHops merges.
func root(ctx context.Context, r store.Reader, org, id string) (store.Incident, error) {
	in, err := r.GetIncident(ctx, org, id)
	if err != nil {
		return in, err
	}
	for i := 0; in.ParentID != ""; i++ {
		if i == maxParentHops {
			return in, fmt.Errorf("correlate: incident %s is merged more than %d times deep", id, maxParentHops)
		}
		if in, err = r.GetIncident(ctx, org, in.ParentID); err != nil {
			return in, err
		}
	}
	return in, nil
}

func moveSignals(ctx context.Context, tx store.Tx, free []store.Signal, incidentID string) ([]string, error) {
	out := make([]string, 0, len(free))
	for _, s := range free {
		s.IncidentID = incidentID
		if err := tx.UpdateSignal(ctx, s); err != nil {
			return nil, err
		}
		out = append(out, s.ID)
	}
	return out, nil
}

func appendEvent(ctx context.Context, tx store.Tx, in store.Incident, at time.Time, by Actor, kind string,
	data map[string]any) error {
	raw, err := json.Marshal(data)
	if err != nil {
		return err
	}
	_, err = tx.AppendIncidentEvent(ctx, store.IncidentEvent{Organization: in.Organization, IncidentID: in.ID,
		At: at, ActorKind: by.Kind, Actor: by.Name, Kind: kind, Data: raw})
	return err
}

// BatchResult is what one decision of a batch did.
type BatchResult struct {
	Organization string
	Cluster      string
	Groups       []GroupResult
}

// Engine is the rule path: it decides every due batch by its rule result, without any agent.
// Tick may be called from several goroutines; one call runs at a time.
type Engine struct {
	Store   store.Store
	Policy  Policy
	Applier Applier
	Now     func() time.Time // nil means time.Now

	mu sync.Mutex
}

// Tick decides every batch that is due now, each in its own transaction, and returns what
// was done, ordered by Organization and cluster. A batch that is not due yet is left alone.
// The rule result attaches or opens, so a decided batch has no pending signal left; the
// batches of one call need not see each other's incidents, because a candidate shares the
// cluster of its group.
func (e *Engine) Tick(ctx context.Context) ([]BatchResult, error) {
	if err := e.Policy.Validate(); err != nil {
		return nil, err
	}
	e.mu.Lock()
	defer e.mu.Unlock()
	now := time.Now()
	if e.Now != nil {
		now = e.Now()
	}
	batches, views, err := Load(ctx, e.Store, "")
	if err != nil {
		return nil, err
	}
	var out []BatchResult
	for _, b := range batches {
		if DueAt(b, time.Time{}, e.Policy).After(now) {
			continue
		}
		p := Prepare(b, views[b.Organization])
		var groups []GroupResult
		err := e.Store.InTx(ctx, func(ctx context.Context, tx store.Tx) error {
			var err error
			groups, err = e.Applier.Apply(ctx, tx, p.Groups, p.RuleResult.Decisions, Rules, now)
			return err
		})
		if err != nil {
			return out, fmt.Errorf("correlate: batch %s: %w", b.Key(), err)
		}
		out = append(out, BatchResult{Organization: b.Organization, Cluster: b.Cluster, Groups: groups})
	}
	return out, nil
}

func TestPolicyValidate(t *testing.T) {

		{"equal waits", Policy{Batch: time.Minute, UrgentBatch: time.Minute}, true},
		{"a zero wait", Policy{Batch: time.Minute}, false},

	type tick struct {

		add  []store.Signal
		want string // fmt of the batch results
	}
	web := sig(1, "deployment", "acme/web", 3, 0)

			{11 * time.Minute, []store.Signal{webAgain}, "[{acme c1 [{g1 attached " + incID(900) + " [" + webAgain.ID + "] }]}]"}}},
		{"Organizations and clusters are decided apart", []tick{{time.Minute, []store.Signal{web, beta, other},
			"[{acme c1 [{g1 opened " + incID(900) + " [" + web.ID + "] }]} {acme c2 [{g1 opened " + incID(901) + " [" + other.ID + "] }]}" +
				" {beta c1 [{g1 opened " + incID(902) + " [" + beta.ID + "] }]}]"}}},
		{"nothing pending decides nothing", []tick{{time.Hour, nil, "[]"}}},
	}
	for _, c := range cases {
		t.Run(c.name, func(t *testing.T) {
			ctx := context.Background()
			st := seed(t, nil, nil)
			now := t0
			e := &Engine{Store: st, Policy: policy, Applier: Applier{NewIncidentID: counter()}, Now: func() time.Time { return now }}

				if err := st.InTx(ctx, func(ctx context.Context, tx store.Tx) error {

							return err
						}
					}

					t.Fatalf("tick %d: %s, want %s", i, g, tk.want)
				}
			}
		})
	}
}
