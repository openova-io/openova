# FND-096 — Remove the Sandbox sources

## In plain words

**The problem today.** The Sandbox product is withdrawn and nothing creates or serves a Sandbox any more, yet its controller, its two programs, its chart and its custom resource definition are still in the repository. They mislead readers, keep two test jobs and two guard baselines busy, and a fresh installation still registers a resource type that nothing uses. Nothing stops the word from spreading again.

**What changes.** The three Sandbox folders, the definition and one end-to-end script are deleted, and every generated file, register, baseline, workflow list and the repository guide that named them is brought in line. A new guard counts the files outside the documentation that still name the Sandbox, and that count may only fall.

**Done means:**

- The Sandbox controller, its two programs, its chart, its custom resource definition and its end-to-end script are gone, and the list of deleted paths names all five, so a pull request that brings one back turns red.
- The generated catalogue, the schema bundle of the API and the two generated inventories no longer list the Sandbox, and each is in sync with its generator.
- The pull-request test workflow no longer tests the two deleted Go modules, and every module it still lists exists.
- The baselines of the polling guard and the service-model guard no longer count the deleted files, and both guards pass.
- A new guard runs on every pull request and fails when more files outside the documentation hold the word sandbox than its baseline allows, or when its baseline rises.
- The other controllers of the shared controller module still build and pass their tests.

The rest of this ticket is the exact instruction for the model that does the work.

class Unreadable(Exception):
    """What a rule reads cannot be read. The rule then fails: it never passes on missing evidence."""


def git(root, *args, ok=(0,)):
    r = subprocess.run(("git",) + args, cwd=root, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    if r.returncode not in ok:
        raise Unreadable("git %s failed: %s" % (" ".join(args), r.stderr.decode("utf-8", "replace").strip()))
    return r.returncode, r.stdout


def parse(text, where):
    """The one number of a baseline text."""
    numbers = [line for line in text.split("\n") if line.strip() != "" and not line.startswith("#")]
    if len(numbers) != 1 or not (numbers[0].isascii() and numbers[0].isdigit()):
        raise Unreadable("%s must hold one line with a whole number" % where)
    return int(numbers[0])


def read_baseline(root):
    try:
        with open(os.path.join(root, BASELINE), encoding="utf-8") as f:
            return parse(f.read(), BASELINE)
    except (OSError, UnicodeDecodeError):
        raise Unreadable("%s is missing or cannot be read" % BASELINE)


def counted(root):
    """The sorted paths of the files that rule count counts."""
    code, out = git(root, "grep", "-l", "-z", "-i", "-F", "--untracked", "-e", WORD, "--", ".", ":(exclude)%s" % EXCLUDED, ok=(0, 1))
    if code == 1:
        return []
    return sorted(p for p in out.decode("utf-8", "surrogateescape").split("\0") if p)


def check(root, base):
    """(findings, summary) of rule count and, with a base commit, rule base."""
    allowed = read_baseline(root)
    files = counted(root)
    out = []
    if len(files) > allowed:
        out.append("%d files outside %s/ hold the word %s; the baseline is %d. Remove the word from the files you added it to" % (len(files), EXCLUDED, WORD, allowed))
    summary = "%d files outside %s/ hold the word %s; the baseline is %d" % (len(files), EXCLUDED, WORD, allowed)
    if len(files) < allowed:
        summary += "; it can be lowered to %d" % len(files)

            summary += "; at %s it is %d" % (base, before)
        else:
            summary += "; %s has no baseline to compare with" % base

    return 0
