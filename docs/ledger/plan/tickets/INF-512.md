# INF-512 — Runner test task: arguments, target check and Nuclei (profile network-passive)

## In plain words

**The problem today.** The machine plane can describe a light network test of a declared machine, but its runner cannot run one: the task test is refused and the image holds no test tool. Nothing yet guarantees that such a test reaches only the machine it was given.

**What changes.** The runner runs the passive network profile against one declared machine, on the ports of its scope only, and stores the findings in the evidence bucket. Any target that is not that machine's address and ports is refused before the tool starts.

**Done means:**

- A test run of the passive network profile starts the scanner with one fixed argument list: signed templates of the image only, four protocols, fingerprint, TLS and DNS checks only, no download, no out-of-band server and no redirect.
- A target that is a name, a range, a URL, a loopback, link-local, multicast, broadcast or unspecified address, or a port that is not one of the scope's, is refused and the scanner does not start.
- The findings are stored as one SARIF file of the run, and the result document counts them and names the file.
- A failed scanner or an unreadable report ends the run failed and stores nothing.
- The image holds Nuclei and its templates at exact versions whose checksums the build checks, and the machine-plane guard finds no forbidden or unpinned tool.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`machine-runner --task=test --mode=ssh --address=<ip> --ports=<p>,... --test-profile=network-passive [--requests-per-second=<n>]` runs one passive network test of one declared machine. It opens no SSH session (the Job shape of SSH mode: non-root, the egress policy of the run allows only the target address on the scope's ports). The target list is built from `--address` and `--ports` and nothing else, written to the work folder, read back and checked; anything else is refused before the tool starts. Profile `network-passive` runs Nuclei 3.11.1 with one fixed argument list against the signed templates of release 10.5.2 that the image holds; the findings are stored as `test.sarif.json` (evidence kind `test-sarif`) and the result member `test` gives their number and the object key. Profile `web-passive` is refused until INF-513. The image gains Nuclei and the templates of the protocols tcp, ssl, dns and http, both through `tools.lock.yaml` with checked SHA-256.

## 3. The model (the law)
1. **The Job shape.** `--task=test` runs only with `--mode=ssh` and opens no SSH session: no OpenBao login, no key pair, no certificate; the evidence key comes from the CSI mount as for every task. `--task=test --mode=node` gives `Refused` with `not-supported: mode node`. Every other task stays node-only: `--mode=ssh` with them gives `Refused` with `not-supported: mode ssh`, as before.
2. **The arguments.** For the task test, `--address` is required (an IP address), `--ports` is required (comma-separated whole numbers from 1 to 65535, each once), `--test-profile` is required (comma-separated, each of `web-passive` and `network-passive` at most once) and `--requests-per-second` is optional (a whole number from 1 to 50, default 10). The three flags given to any other task are refused. Every refusal of an argument gives `Refused` with `invalid-arguments: ...` and starts nothing.
3. **The target check.** `Targets(address, ports)` returns one line `<address>:<port>` per port (IPv6 in brackets) and refuses an address that is not one unicast address of a machine (unspecified, loopback, multicast, link-local, the IPv4 broadcast address, an address with a zone) and a port outside 1 to 65535 or given twice. `CheckTargets(lines, address, ports)` refuses any line that is not one of those targets or that occurs twice: another address, another port, a name, a URL, a range, an option, an empty line or an empty list. The task writes the list, reads the file back and runs `CheckTargets` on it before the tool starts; a refusal gives `Refused` with `target-refused: ...`.
4. **Profile `network-passive`** runs exactly `nuclei -duc -t /content/nuclei-templates -l <work>/test.targets -pt tcp,ssl,dns,http -dut -tags tech,detect,ssl,tls,dns -etags intrusive,dos,fuzz,bruteforce,default-login,vuln -ni -dr -rl <requests per second> -se <work>/nuclei.sarif.json -silent -nc`: no update check and no template download; unsigned templates refused; only the protocols tcp, ssl, dns and http, so no code or headless template, and no `-dast`, so no fuzzing; only fingerprints of services and technologies and TLS and DNS checks, never a template tagged as changing state, denying service, fuzzing, guessing passwords or probing a vulnerability (vulnerabilities come from the bill of materials of the machine); no out-of-band interaction server; no HTTP redirect; the rate limit. Exit code 0 is the only success.
5. **Profile `web-passive`** is refused in this version with `not-supported: test-profile web-passive`, also when it is given with `network-passive`; nothing runs. INF-513 adds it.
6. **The result.** `test.sarif.json` is one SARIF 2.1.0 log with one run per tool run, the runs of Nuclei's file unchanged. Nuclei writes no file when it found nothing: that is one run without results. Evidence kind `test-sarif`; result member `test` with `findings` (the number of results) and `resultsKey` (the object key of the file). A Nuclei exit other than 0, or a file that is not SARIF 2.1.0 with runs and results, gives `Failed` and stores nothing. The completion marker `test.completed` is written last.
7. **The image.** `tools.lock.yaml` gains `nuclei` 3.11.1 (the `linux_amd64` release zip, MIT, separate process) and `nuclei-templates` 10.5.2 (the tag archive, MIT, data). The build copies `nuclei` to `/usr/local/bin`, its licence to `/usr/share/doc/nuclei/`, and of the templates only the folders `http`, `network`, `ssl`, `dns` and the licence to `/content/nuclei-templates/`; it checks that `ssl/tls-version.yaml` is there and prints `nuclei -version`. `LICENSES.md` and the README name both. No forbidden tool name enters `products/machine-runner`.

+var numberRE = regexp.MustCompile(`^[1-9][0-9]{0,4}$`)

+// ParsePorts reads --ports: comma-separated whole numbers from 1 to 65535, each once.
+func ParsePorts(s string) ([]int, bool) {
+	var ports []int
+	for _, p := range splitKeys(s) {
+		n, err := strconv.Atoi(p)
+		if !numberRE.MatchString(p) || err != nil || n > 65535 || containsInt(ports, n) {
+			return nil, false
+		}
+		ports = append(ports, n)
+	}
+	return ports, len(ports) > 0
+}

+// parseRate reads --requests-per-second; an empty value is the default.
+func parseRate(s string) (int, bool) {
+	if s == "" {
+		return DefaultRequestsPerSec, true
+	}
+	n, err := strconv.Atoi(s)
+	return n, err == nil && numberRE.MatchString(s) && n <= MaxRequestsPerSec
+}

+// eachOnce reports whether every value is in allowed and none is given twice.
+func eachOnce(values, allowed []string) bool {
+	for i, v := range values {
+		if !contains(allowed, v) || contains(values[:i], v) {
+			return false
+		}
+	}
+	return true
+}

+// Targets returns the target list of a test: one line <address>:<port> per port, in the
+// order of ports, an IPv6 address in brackets. Nothing else is ever a target. It refuses
+// an address that is not one unicast address a machine can hold (unspecified, loopback,
+// multicast, link-local, broadcast, an address with a zone) and a port outside 1 to 65535
+// or given twice.
+func Targets(address string, ports []int) ([]string, error) {
+	ip, err := netip.ParseAddr(address)
+	if err != nil || ip.Zone() != "" {
+		return nil, fmt.Errorf("%q is not one IP address", address)
+	}
+	ip = ip.Unmap()
+	if !ip.IsGlobalUnicast() {
+		return nil, fmt.Errorf("%s is not the unicast address of a machine", ip)
+	}
+	if len(ports) == 0 {
+		return nil, errors.New("no port")
+	}
+	var out []string
+	for i, p := range ports {
+		if p < 1 || p > 65535 || containsInt(ports[:i], p) {
+			return nil, fmt.Errorf("port %d is not a port from 1 to 65535 given once", p)
+		}
+		out = append(out, netip.AddrPortFrom(ip, uint16(p)).String()) //nolint:gosec // p is from 1 to 65535, checked above
+	}
+	return out, nil
+}
+
+// CheckTargets refuses a target list that holds anything but the targets of address and
+// ports, each at most once: another address, another port, a name, a URL, a range, an
+// option or an empty line. The task test checks the file the tool reads with it.
+func CheckTargets(lines []string, address string, ports []int) error {
+	allowed, err := Targets(address, ports)
+	if err != nil {
+		return err
+	}
+	if len(lines) == 0 {
+		return errors.New("the target list is empty")
+	}
+	for i, l := range lines {
+		if !contains(allowed, l) || contains(lines[:i], l) {
+			return fmt.Errorf("%q is not a declared target", l)
+		}
+	}
+	return nil
+}

+// NucleiArgs are the arguments of profile network-passive: the templates of the image only,
+// with no update check and no download; signed templates only; protocols tcp, ssl, dns and
+// http, so no code or headless template, and no -dast, so no fuzzing; the tags of
+// NucleiTags without NucleiExcludedTags; no out-of-band interaction server and no HTTP
+// redirect away from the target; the rate limit; and the findings as SARIF.
+func NucleiArgs(templates, targets, sarif string, rate int) []string {
+	return []string{"-duc", "-t", templates, "-l", targets, "-pt", "tcp,ssl,dns,http", "-dut",
+		"-tags", NucleiTags, "-etags", NucleiExcludedTags, "-ni", "-dr",
+		"-rl", strconv.Itoa(rate), "-se", sarif, "-silent", "-nc"}
+}

+// test runs the profiles of the scope against the target and writes test.sarif.json, one
+// SARIF run per tool run. It opens no SSH session. Profile web-passive is refused in this
+// version. The target list is written, read back and checked before the tool starts.
+func test(ctx context.Context, cfg Config, env Env) taskResult {
+	for _, p := range cfg.TestProfiles {
+		if p != ProfileNetworkPassive {
+			return refused(messageNotSupported + "test-profile " + p)
+		}
+	}
+	targets, err := Targets(cfg.Address, cfg.Ports)
+	if err != nil {
+		return refused(messageTargetRefused + err.Error())
+	}
+	if info, err := os.Stat(env.Templates); err != nil || !info.IsDir() {
+		return failed("nuclei-templates-not-in-image: %s", env.Templates)
+	}
+	list := filepath.Join(env.WorkDir, fileTargets)
+	if err := os.WriteFile(list, []byte(strings.Join(targets, "\n")+"\n"), 0o600); err != nil {
+		return failed("the target list was not written: %v", err)
+	}
+	data, err := os.ReadFile(list) //nolint:gosec // a fixed name in the work folder
+	if err != nil {
+		return failed("the target list cannot be read: %v", err)
+	}
+	if err := CheckTargets(strings.Split(strings.TrimSuffix(string(data), "\n"), "\n"), cfg.Address, cfg.Ports); err != nil {
+		return refused(messageTargetRefused + err.Error())
+	}
+	sarif := filepath.Join(env.WorkDir, fileNucleiSARIF)
+	if err := os.Remove(sarif); err != nil && !errors.Is(err, os.ErrNotExist) {
+		return failed("%s cannot be removed: %v", fileNucleiSARIF, err)
+	}
+	if r := collect(ctx, nil, []int{0}, env.Nuclei, NucleiArgs(env.Templates, list, sarif, cfg.RequestsPerSec)...); r != nil {
+		return *r
+	}
+	// Nuclei writes no file when it found nothing: that is one run without results.
+	runs, findings := []json.RawMessage{json.RawMessage(`{"tool":{"driver":{"name":"nuclei"}},"results":[]}`)}, 0
+	if data, err := os.ReadFile(sarif); err == nil { //nolint:gosec // a fixed name in the work folder
+		if runs, findings, err = ParseSARIF(data); err != nil {
+			return failed("%s cannot be read: %v", fileNucleiSARIF, err)
+		}
+	} else if !errors.Is(err, os.ErrNotExist) {
+		return failed("%s cannot be read: %v", fileNucleiSARIF, err)
+	}
+	out := map[string]any{"version": sarifVersion, "$schema": sarifSchema, "runs": runs}
+	if err := writeJSON(filepath.Join(env.WorkDir, FileTestSARIF), out); err != nil {
+		return failed("%s was not written: %v", FileTestSARIF, err)
+	}
+	if err := writeMarker(env, TaskTest); err != nil {
+		return failed("the completion marker was not written: %v", err)
+	}
+	return taskResult{outcome: runresult.Succeeded, test: &runresult.Test{Findings: findings},
+		files: []file{{KindTestSARIF, FileTestSARIF}}}
+}
+
+// ParseSARIF returns the runs of a SARIF 2.1.0 log and the number of their results.
+func ParseSARIF(data []byte) ([]json.RawMessage, int, error) {
+	var log struct {
+		Version string            `json:"version"`
+		Runs    []json.RawMessage `json:"runs"`
+	}
+	if err := json.Unmarshal(data, &log); err != nil {
+		return nil, 0, err
+	}
+	if log.Version != sarifVersion || len(log.Runs) == 0 {
+		return nil, 0, fmt.Errorf("not a SARIF %s log with a run", sarifVersion)
+	}
+	n := 0
+	for _, r := range log.Runs {
+		var run struct {
+			Results *[]json.RawMessage `json:"results"`
+		}
+		if err := json.Unmarshal(r, &run); err != nil || run.Results == nil {
+			return nil, 0, errors.New("a run without results")
+		}
+		n += len(*run.Results)
+	}
+	return log.Runs, n, nil
+}
