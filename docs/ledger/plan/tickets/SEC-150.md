# SEC-150 — Seal-provider contract and the static node-file implementation

## In plain words

**The problem today.** The key that opens the secret store of a Sovereign still rests inside the cluster, beside the data it protects. The seal contract says that every cloud pack produces this key outside the cluster, with a small piece of code called the seal hook, but no pack has that hook. The provisioning service also copies only the top-level files of a pack, so a hook would be missing at the first real provision.

**What changes.** Each of the three cloud packs gets the seal hook of the contract. It makes one seal key per region and reports which kind of seal the pack has, and the provisioning service copies the hook together with the pack. Nothing on a node changes yet: writing the key to the nodes is a later task.

**Done means:**

- Each of the three cloud packs has a seal hook whose text is the text of the seal contract; only the volume device differs between packs.
- Each pack makes one 32-byte seal key per region, for the same regions as its cluster tokens, and reports the kind static-node-file.
- A test applies the hook by itself and fails when the key is not 32 bytes, when the file name does not carry the key identifier, or when the seal text holds key bytes.
- A provision copies the hook into its working directory, and a test fails when a pack calls a child module that is not copied.
- No node receives the key yet: the first-boot text of every node is the same as before.
- The provider interface document states the rule and says what is not done yet.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every provider pack under `infra/providers/` carries the seal hook of contract C8 (`docs/contracts/c8-seal-provider.md`): the OpenTofu child module `infra/providers/<name>/seal/main.tf`, kind `static-node-file`. Each provider module calls the hook once as `module "seal"`, with the region keys of its k3s tokens, and emits the hook's kind as the output `seal_kind`. The provisioning engine copies the directory `seal` into the directory it runs OpenTofu in, so `tofu init` finds the hook in a real provision. The hook is tested by itself in the packs `huawei` and `hetzner`. The shared first-boot template does not change in this package: no node receives the key yet.

## 3. The model (the law)
1. The hook of a pack is the file `infra/providers/<name>/seal/main.tf`. Its text is the HCL block of `docs/contracts/c8-seal-provider.md`, byte for byte. Only the value of the last output, `volume_device`, differs: `"/dev/vdb"` in the pack `huawei`, `""` in the packs `hetzner` and `local`.
2. The hook makes one `random_bytes` resource of 32 bytes per region key. The key identifier is the first 16 hexadecimal characters of the SHA-256 of the key's base64 text. The stanza names the key file by that identifier and never holds key bytes.
3. The node file of a region has the path `/var/lib/catalyst/seal/openbao-seal-<key identifier>.key`, the owner `100:1000` and the permissions `0400`. Its content is the base64 text of the 32 bytes.
4. Each provider module calls the hook exactly once, as `module "seal"` with `source = "./seal"`. `region_keys` is the set of region keys of `random_password.k3s_server_token`: `toset(local.region_keys)` in the packs `huawei` and `local`, `toset(local.all_region_keys)` in the pack `hetzner`. `seal_key_generation` is the module's own variable `seal_key_generation` (number, default `1`).
5. Each provider module emits `output "seal_kind"` with the value `module.seal.kind`.
6. `stageModule` in `products/catalyst/bootstrap/api/internal/provisioner/provisioner.go` copies the `.tf` and `.tftpl` files of `<module>/seal` into `<workdir>/seal`. It copies no other directory of a module. A pack calls no other child module by a local path.
7. The key is never a Kubernetes Secret, never in a ConfigMap and never in a worker template. This package writes it nowhere but the OpenTofu state.
8. Nothing is deleted by this package.

// writeTree writes files, given as path relative to root → content.
func writeTree(t *testing.T, root string, files map[string]string) {
	t.Helper()
	for rel, content := range files {
		p := filepath.Join(root, rel)
		if err := os.MkdirAll(filepath.Dir(p), 0o700); err != nil {
			t.Fatalf("mkdir %s: %v", filepath.Dir(p), err)
		}
		if err := os.WriteFile(p, []byte(content), 0o600); err != nil {
			t.Fatalf("write %s: %v", p, err)
		}
	}
}

// TestStageModule_StagesSealHook: the .tf files of <module>/seal land in
// <workdir>/seal, and nothing else of the module's directories does.
func TestStageModule_StagesSealHook(t *testing.T) {
	root := t.TempDir()

	dst := filepath.Join(root, "work", "dep-1")
