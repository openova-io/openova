# FND-070 — Baseline: one fresh provision of `main` as it stands

## In plain words

**The problem today.** No Sovereign has been installed fresh from what main publishes and then measured by the gate. The standing test environment was created in September and only updated in place since, so some required checks fail on properties that only a new installation sets. Nothing in the repository says what a fresh installation of main really does.

**What changes.** The standing environment is installed again from a release candidate and the gate runs against it twice. A file in the plan folder then records, from those two gate records, how long the installation took, what the cloud account held before it, how the hand-over ended and how every check came out.

**Done means:**

- Two gate records of one fresh installation of one release candidate are on main, and the record checker accepts both.
- The baseline file names those two records and the record of the environment before the wipe.
- The file gives the end of the hand-over chain, the installation times, the cloud account numbers before the fire, the nodes per region, the journeys, and one line per check with its result in both runs and its first failing step.
- For each of the three journey checks the file says whether a failed hand-over chain can explain a failure.
- The file is exactly what the tool of the ticket writes from the two records, so a hand edit turns the pull request red.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. The environment work (candidate cut, wipe, sweep, fire, both gate runs) is done by the architect before this ticket starts (field 9). The executor changes nothing on any environment and starts no workflow.
2. The baseline file is written by the tool of the block `FND-070-baseline.py` of this ticket and never by hand. The tool runs from `/tmp` and is not committed.
3. A flight record is a file `docs/ledger/acceptance/*.json` with the schema `openova.io/acceptance-sovereign/v2`, `mode` `run`, `run_in` `cloud`, producer kind `workflow` and producer workflow `foundation-gate.yaml`, a non-empty candidate id that starts with the time it was cut (`YYYYMMDDTHHMMSSZ`), and a `provision.created_at` later than that time: the environment was born after the candidate was cut.
4. The flight records are grouped by candidate id and deployment id. The group of the newest flight record (by `started_at`) is the flight. Its two newest records, the older first, are run 1 and run 2. With fewer than two the tool refuses; an older group never stands in.
5. The record before the wipe is the newest record whose `deployment_id` equals `provision.previous_deployment_id` of run 1, or `none on main`.
6. The line `Hand-over chain: ` comes from the evidence `ready_source` of step `D0.11` of each run: `completed` when it ends in `cutoverFinishedAt`, `failed at step <N>` when it ends in `step.<N>.finishedAt`, `not read` when no run read it. Two runs that read it differently are refused.
7. The values of the installation (provider, creation, end of the hand-over chain, pre-flight numbers, previous deployment) are those of run 1. Times are written in UTC to the second. A time that is missing, zero or unreadable is written `not read`; nothing that was not measured is written as a number. Certificates are not counted by the gate records, and the file says so.
8. Each check of either record gets one table line that starts with `| <check id> |`: its state at the run, its result in run 1 and in run 2, the first step of that check with status FAIL, and the check's reason. Step and reason are those of run 1, or of run 2 when run 1 passed. A `|` inside a value is written `\|`; a value is cut at 300 characters.
9. For FND-G10, FND-G11 and FND-G12 one line `Chain cause <id>: ` says, in this order of rules: `no, the hand-over chain completed`; `not measured, the check is in neither record`; `no, the check passed in both runs`; otherwise `not excluded, the hand-over chain <state> and the check is <result> in run 1 and <result> in run 2`.
10. The command `check` of the tool rebuilds the file from the two records it names (`Record 1: ` and `Record 2: `) and must find it unchanged. The two named records must be two flight records of one group, the older first.

"""The baseline of the first fresh installation of main, written from its two gate records.

A flight record is a file docs/ledger/acceptance/*.json with the schema openova.io/acceptance-sovereign/v2,
mode "run", run_in "cloud", producer kind "workflow" and workflow "foundation-gate.yaml", a candidate id that
starts with the time it was cut (YYYYMMDDTHHMMSSZ), and provision.created_at later than that time: the
environment was created after the candidate was cut. The flight records are grouped by candidate id and
deployment id. The group of the newest flight record (by started_at) is the flight; its two newest records,
the older first, are run 1 and run 2. A flight with fewer than two records is refused.

import json
import os

import sys

RECORDS = "docs/ledger/acceptance"

SCHEMA = "openova.io/acceptance-sovereign/v2"

TIME = re.compile(r"^(\d{4}-\d\d-\d\dT\d\d:\d\d:\d\d)(?:\.\d+)?(Z|[+-]\d\d:\d\d)$")


class Refused(Exception):
    pass


def when(text):
    """A record time as a UTC datetime; None for a missing, zero or unreadable time."""
    m = TIME.match(str(text or ""))
    if not m or m.group(1).startswith("0001-"):
        return None
    t = datetime.datetime.strptime(m.group(1), "%Y-%m-%dT%H:%M:%S")
    if m.group(2) != "Z":
        sign = 1 if m.group(2)[0] == "+" else -1
        t -= sign * datetime.timedelta(hours=int(m.group(2)[1:3]), minutes=int(m.group(2)[4:6]))
    return t.replace(tzinfo=datetime.timezone.utc)


def stamp(t):
    return t.strftime("%Y-%m-%dT%H:%M:%SZ") if t else "not read"


def cut_time(candidate_id):
    try:
        return datetime.datetime.strptime(str(candidate_id).split("-")[0], "%Y%m%dT%H%M%SZ").replace(tzinfo=datetime.timezone.utc)
    except ValueError:
        return None


def load(path):
    try:
        with open(path) as fh:
            rec = json.load(fh)
    except (OSError, ValueError):
        return None
    return rec if isinstance(rec, dict) else None


def is_flight(rec):
    if not rec or rec.get("schema") != SCHEMA or rec.get("mode") != "run" or rec.get("run_in") != "cloud":
        return False
    prod, cand = rec.get("producer") or {}, rec.get("candidate") or {}
    if prod.get("kind") != "workflow" or prod.get("workflow") != "foundation-gate.yaml" or not cand.get("id"):
        return False
    cut, born = cut_time(cand["id"]), when((rec.get("provision") or {}).get("created_at"))
    return bool(cut and born and born > cut and when(rec.get("started_at")))


def all_records(root):
    out = []
    for path in sorted(glob.glob(os.path.join(root, RECORDS, "*.json"))):
        rec = load(path)
        if rec is not None:
            out.append((RECORDS + "/" + os.path.basename(path), rec))
    return out


def key(rec):
    return (rec["candidate"]["id"], rec.get("deployment_id") or "")


def select(root):
    """(run 1, run 2) as (path, record) pairs, or Refused."""
    flights = [(p, r) for p, r in all_records(root) if is_flight(r)]
    if not flights:
        raise Refused("no fresh installation from a candidate on main: no gate record names a candidate and was made on an environment created after it was cut")
    flights.sort(key=lambda pr: (when(pr[1]["started_at"]), pr[0]))
    group = [pr for pr in flights if key(pr[1]) == key(flights[-1][1])]
    if len(group) < 2:
        cid, dep = key(flights[-1][1])
        raise Refused("the fresh installation of candidate rc/%s, deployment %s, has %d gate record on main; two are needed" % (cid, dep, len(group)))
    return group[-2], group[-1]


def chain(rec):
    """completed, failed at step <N>, or None when the run did not read it (step D0.11)."""
    for s in rec.get("steps") or []:
        if s.get("id") == "D0.11":
            src = str((s.get("evidence") or {}).get("ready_source") or "")
            if src.endswith(" cutoverFinishedAt"):
                return "completed"
            m = re.search(r" step\.(.+)\.finishedAt$", src)
            if m:
                return "failed at step " + m.group(1)
    return None


def cell(text, limit=300):
    t = " ".join(str(text if text is not None else "").split())
    t = t if len(t) <= limit else t[:limit - 3] + "..."
    return (t or "-").replace("|", "\\|")


def minutes(a, b):
    if not a or not b:
        return "not measured"
    if b < a:
        return "not measured (the end is before the start)"
    return str(int((b - a).total_seconds() // 60))


def checks_of(rec):
    return {c.get("id"): c for c in rec.get("checks") or [] if c.get("id")}

        if s.get("journey") == cid and s.get("status") == "FAIL":

    return None

def named(root, text):
    paths = []
    for n in ("1", "2"):
        m = re.findall(r"^Record %s: (\S+)$" % n, text, re.M)
        if len(m) != 1:
            raise Refused("%s names Record %s %d times; once is needed" % (OUT, n, len(m)))
        rec = load(os.path.join(root, m[0])) if m[0].startswith(RECORDS + "/") else None
        if rec is None:
            raise Refused("%s names %s, which is not a record of %s" % (OUT, m[0], RECORDS))
        paths.append((m[0], rec))
    return paths
