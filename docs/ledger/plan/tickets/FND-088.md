# FND-088 — The event registry and the shared bus package no longer name the Sandbox request subject

## In plain words

**The problem today.** The Sandbox product is withdrawn, and nothing publishes or consumes its request event any more. The event registry still lists that event with producers and consumers that are gone, and the shared message-bus package of the controllers still defines its name and tests its payload. Readers are told that the event exists.

**What changes.** The registry entry, the name in the bus package and the test of the old payload are removed. The test of a malformed message keeps running, on the subject of a created Organization.

**Done means:**

- The event registry no longer lists the Sandbox request event.
- The message-bus package of the controllers no longer names that event, and its package comment no longer names the Sandbox controller.
- The guard of the event registry passes: every subject that Go code names is still listed.
- The message-bus package builds, and its tests pass, including the test that a malformed message is skipped.

The rest of this ticket is the exact instruction for the model that does the work.
