## In plain words

Nobody had listed, for every open roll-out, the Secrets its chart needs, where each value comes from, who reads it, and which library feature covers it, so each roll-out found its gap only when it began.

**What changes.** The result of the spike is in the repository: one table of 27 rows over the nine open roll-outs, each row mapped to a library input or to one of ten named gaps, who should write the values given from outside into the store and when, and the proposed plan edits with five new packages.
