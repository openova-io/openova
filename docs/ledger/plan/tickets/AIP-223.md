# AIP-223 — Judge dispatcher: lanes, deadlines, agent tokens, A2A call, validation, late revision

## In plain words

**The problem today.** The operations-records service can decide by rule which incident new signals belong to, but it cannot ask an agent. Nothing gets an agent token, calls an agent, limits how many agents run at once, keeps a deadline, checks an answer or records what happened. An agent answer that arrives late, or that is wrong, would have nowhere to go.

**What changes.** A dispatcher in the service asks a judge agent one prepared question with its own short-lived token, waits at most the judge's deadline, writes the rule result when the agent is wrong, unavailable or late, and writes a valid answer instead. A valid answer that comes after the deadline revises what the rules wrote. Every question and its outcome is one row of the judgements table.

**Done means:**

- A valid correlator answer that comes before the deadline is written instead of the rule result, and the judgement records the outcome applied.
- An invalid answer, an agent that fails, a refused token or a spent turn budget leaves the rule result in place at once, and the judgement says why.
- At the deadline the rule result is written; a valid answer after it moves the signals to the incident the agent chose and records late_applied.
- A lane never runs more agent turns at once than its policy allows, and a cancelled turn frees its place at once.
- The request for an agent token carries the pod's ServiceAccount token, read again for every request.
- The agent is called with one blocking A2A request: nothing polls.

The rest of this ticket is the exact instruction for the model that does the work.

The Go module `products/ops-records` gains the package `internal/judge`, written in full in this ticket. It holds the judge policy (the values block `judges` of the service, parsed and validated), a client of the agent-token route of catalyst-api, an A2A 1.0 client, the dispatcher, and the correlator judge: the validation of its answer, the question built from a prepared batch, the late revision of what the rules wrote, and a ticker that asks about every due batch. ## 3. The model (the law)
1. **One new package, nothing else.** The change adds exactly eight files under `products/ops-records/internal/judge/`, each the block of the same name in this ticket: `policy.go`, `token.go`, `a2a.go`, `dispatcher.go`, `correlator.go`, `dispatcher_test.go`, `correlator_test.go` and `client_test.go`. No existing file changes, not `go.mod` and not `go.sum`: the package imports the Go standard library and the module's own `internal/ids`, `internal/store`, `internal/correlate` and `internal/agentguard`.
2. **Policy** (`policy.go`). One JSON document, unknown fields refused: `operationsOrganization` (an Organization slug), `agentRuntime.urlTemplate` (an `http` or `https` address with both `{organization}` and `{agent}`), `judges` (at least one; per judge `agent` matching `^[a-z][a-z0-9-]{1,62}$`, `lane` `deciding` or `background`, `deadlineSeconds` 10 to 1800, `urgentDeadlineSeconds` 0 for none or 10 to the deadline, `tokenTier` `viewer` or `developer`, `tokenTTLSeconds` 60 to 3600 and not below the deadline), `lanes` (only `deciding` and `background`, each at least 1 and each used by a judge), `batchSeconds` and `urgentBatchSeconds` (the rules of `correlate.Policy`), and `turnBudget` (`turns` 1 to 10000 per Organization and judge in each window of `windowSeconds` 60 to 86400). `turnBudget` is the choice of turns, window and key that the ticket of AIP-224 (field 11) gave to this package; the chart of AIP-226 renders it with the other values.
3. **Agent tokens** (`token.go`). `Tokens.Token` sends `POST <catalyst-api>/api/v1/internal/agent-tokens` with the body `{"organization", "agent", "tier", "ttlSeconds"}` and the header `Authorization: Bearer <the pod's projected ServiceAccount token>`, read again from its file (default `/var/run/secrets/kubernetes.io/serviceaccount/token`) for every request because the kubelet rotates it. An unreadable or empty file sends nothing. 200 with a non-empty `token` is the token; any other answer is an error that names the route's `error` code and `detail`. A token is never logged and never part of an error.
4. **The A2A call** (`a2a.go`). JSON-RPC 2.0 over HTTP to the address of the template, with the headers `Authorization: Bearer <agent token>`, `A2A-Version: 1.0`, `X-User-Id: ops-records`. `SendMessage` carries one user message (`role` `ROLE_USER`, a new `messageId`, no `contextId`: every turn is a new task) with the offered document as its one text part, and `configuration.returnImmediately` false, so the one HTTP request waits for the end of the turn and nothing polls (the repository refuses a new poll: `scripts/check-no-new-polling.py`). The answer is taken from the parts of the task's artifacts, else from its status message, else from a message the agent answered with: the last data part, else the last text part; a data part `{"data": {...}}` is unwrapped once; a text part that is one JSON document is that document, other text is returned as a JSON string so that it fails validation and is still recorded. A task that ends waiting for input or authentication, or that has not ended, is cancelled with `CancelTask` and gives no answer. A failed, cancelled or rejected task, a JSON-RPC error, an HTTP status other than 200 and an answer above 1 MiB are errors. The verbs, the role, the text part and the address template are those that lab test AIP-030 measured (`docs/ledger/plan/spikes/AIP-030.yaml`, `a2aURLTemplate` and `a2aProtocol`).
5. **The dispatcher** (`dispatcher.go`; its rules are written at the top of the file). `Ask` writes one judgement row (offered document, rule result, asked at, deadline at; outcome undecided) and starts one turn; a subject (Organization, subject kind, subject identifier) has at most one question in flight (`ErrBusy`). A turn waits for a free place of its lane until its deadline, takes one turn of the budget (`agentguard.Budget`, key `<organization>/<judge>`, counter `agentguard.MemoryCounter`; refused or uncountable means no call), asks for a token of the judge's agent, tier and life, and calls the agent. A turn lives at most `tokenTTLSeconds` from the question; its end by answer, error, cancel or end of life frees its place in the lane. Every string of the offered document passes `agentguard.CleanValue` with no link host allowed before the agent reads it, and the row records the document as it was sent.
6. **Outcomes**, each written in the same transaction as the records it changes: `applied` (a valid answer before the deadline, written instead of the rule result); `rejected_invalid` (an invalid answer, or one that cannot be written, before the deadline; the rule result at once); `unavailable` (no answer before the deadline: budget, token, call or cancel; the rule result at once); `timeout` (the deadline came first; the rule result at the deadline; the turn goes on); `late_applied` (after `timeout`, a valid answer within the turn's life revised what the rules wrote); `late_rejected` (after `timeout`, an invalid answer). A turn that ends without an answer after its deadline leaves `timeout`. The row records every answer with the time it came. `Options.Decided` is called with the row after each outcome is written, so the deadline's outcome is reported on time. `Cancel` ends one turn; `Close` refuses new questions, ends every turn and waits for each outcome. `Recover` marks every judgement a stopped dispatcher left undecided as `unavailable`, without writing its rule result: its subject is asked again under a new judgement. One dispatcher serves one database.
7. **Correlator validation** (`ValidateCorrelation`), in this order, the first failure rejecting the whole answer: (1) one JSON object with the one key `decisions`, a list of objects with the keys `groupId`, `decision`, `confidence`, `severity` and the optional `incidentId` and `causalChain`, no other key and no null; strings are strings, `decision` is `attach`, `new` or `watch`, `confidence` a number from 0 to 1, `severity` an integer from 1 to 4; (2) every offered group exactly once and no other; (3) every decision in the request's `allowed`; (4) an `attach` names an offered candidate, and with a causal chain of fewer than 12 characters or a confidence below 0.5 it becomes `new` (not a rejection); a decision that is not `attach` keeps no incident; (5) a severity is not less urgent than the most urgent floor of its group's signals.
8. **Correlator question** (`Correlation`). Judge `correlator`, subject kind `signal_batch`, subject `cluster/<cluster>`, urgent when a group's floor is 2 or more urgent. The offered document and the rule result are those of `correlate.Prepare`. The rules write through `correlate.Applier.Apply` as the actor `rules`; a valid answer writes through it as the actor `agent` named `correlator`.
9. **Late revision** (`Revise`), group by group, over what the rules wrote: a group the rules moved no signal of is left alone; `watch` writes an entry `judge_late` on the rules' incident; when that incident is no longer open, was merged, or has a severity a person set, a person has acted and only `judge_late` is written; the same place (attach to the rules' incident followed through merges, or `new` where the rules opened an incident) re-rates the incident, never less urgent than it is and never a severity a person set, and writes `judge_late`; otherwise the group's signals still in the rules' incident leave it (entry `signals_detached`) and the answer's decision is applied to them through `correlate.Applier.Apply`, and when the rules opened that incident for the group and it has no signal left it is merged into the incident the signals went to (entry `merged`).
10. **Ticker** (`CorrelationTicker.Tick`). Every pending batch that is due and has no question in flight is asked about; a batch's last decision is the answer time of its newest judgement, else its ask time.
11. **Every example value is a test value.** The host `kagent-controller.acme.svc.cluster.local`, the addresses `evil.example` and `127.0.0.1` of the test servers, the Organization slugs `acme` and `operations`, and the strings `agent-jwt`, `sa-token-one`, `sa-token-two` and `agent-token-acme-correlator` in the test files are fixed test values, not systems and not secrets.

import (
	"bytes"
	"encoding/json"

	"github.com/openova-io/openova/products/ops-records/internal/correlate"

// Lanes a judge can run in.
const (
	LaneDeciding   = "deciding"
	LaneBackground = "background"
)

// Tiers of an agent token. A judge never gets a higher one.
const (
	TierViewer    = "viewer"
	TierDeveloper = "developer"
)

// Placeholders of AgentRuntime.URLTemplate.
const (
	placeholderOrganization = "{organization}"
	placeholderAgent        = "{agent}"
)

var (
	agentPattern        = regexp.MustCompile(`^[a-z][a-z0-9-]{1,62}$`)
	organizationPattern = regexp.MustCompile(`^[a-z][a-z0-9-]{2,31}$`)
)

// Policy is the judge policy: the values block "judges" of the service's chart. Every field is
// required unless its comment says otherwise.
type Policy struct {
	// OperationsOrganization receives the signals of platform alerts.
	OperationsOrganization string `json:"operationsOrganization"`
	// AgentRuntime says where the agents answer.
	AgentRuntime AgentRuntime `json:"agentRuntime"`
	// Judges by name. The name is the one questions use.
	Judges map[string]Judge `json:"judges"`
	// Lanes holds the number of turns each lane runs at once.
	Lanes map[string]int `json:"lanes"`
	// BatchSeconds and UrgentBatchSeconds are the waits of a batch of new signals.
	BatchSeconds       int `json:"batchSeconds"`
	UrgentBatchSeconds int `json:"urgentBatchSeconds"`
	// TurnBudget limits the turns of each Organization and judge.
	TurnBudget TurnBudget `json:"turnBudget"`
}

// AgentRuntime holds the A2A address of the agents.
type AgentRuntime struct {
	// URLTemplate is the A2A address of one agent of one Organization's install, with the
	// placeholders {organization} and {agent}.
	URLTemplate string `json:"urlTemplate"`
}

// Judge is the policy of one judge.
type Judge struct {
	Agent                 string `json:"agent"`                 // the agent's name in the Organization's install
	Lane                  string `json:"lane"`                  // LaneDeciding or LaneBackground
	DeadlineSeconds       int    `json:"deadlineSeconds"`       // 10..1800; after it the rule result is written
	UrgentDeadlineSeconds int    `json:"urgentDeadlineSeconds"` // optional (0 for none); 10..DeadlineSeconds
	TokenTier             string `json:"tokenTier"`             // TierViewer or TierDeveloper
	TokenTTLSeconds       int    `json:"tokenTTLSeconds"`       // 60..3600, not below DeadlineSeconds; the life of a turn
}

// TurnBudget allows Turns turns per Organization and judge in each window of WindowSeconds.
type TurnBudget struct {
	Turns         int `json:"turns"`         // 1..10000
	WindowSeconds int `json:"windowSeconds"` // 60..86400
}

// ParsePolicy reads a policy from JSON and validates it. An unknown field is refused.
func ParsePolicy(data []byte) (Policy, error) {
	var p Policy
	dec := json.NewDecoder(bytes.NewReader(data))
	dec.DisallowUnknownFields()
	if err := dec.Decode(&p); err != nil {
		return Policy{}, fmt.Errorf("judge: policy: %w", err)
	}
	if dec.More() {
		return Policy{}, fmt.Errorf("judge: policy: data after the document")
	}
	return p, p.Validate()
}

// Validate returns an error naming the first rule the policy breaks.
func (p Policy) Validate() error {
	bad := func(format string, args ...any) error {
		return fmt.Errorf("judge: policy: "+format, args...)
	}
	if !organizationPattern.MatchString(p.OperationsOrganization) {
		return bad("operationsOrganization %q is not an Organization slug", p.OperationsOrganization)
	}
	if err := checkTemplate(p.AgentRuntime.URLTemplate); err != nil {
		return bad("agentRuntime.urlTemplate: %v", err)
	}
	if len(p.Judges) == 0 {
		return bad("judges is empty")
	}
	used := map[string]bool{}
	for _, name := range sortedKeys(p.Judges) {
		j := p.Judges[name]
		switch {
		case !agentPattern.MatchString(name):
			return bad("judge name %q", name)
		case !agentPattern.MatchString(j.Agent):
			return bad("judge %s: agent %q", name, j.Agent)
		case j.Lane != LaneDeciding && j.Lane != LaneBackground:
			return bad("judge %s: lane %q is not %s or %s", name, j.Lane, LaneDeciding, LaneBackground)
		case p.Lanes[j.Lane] < 1:
			return bad("judge %s: lane %s has no turns in lanes", name, j.Lane)
		case j.DeadlineSeconds < 10 || j.DeadlineSeconds > 1800:
			return bad("judge %s: deadlineSeconds %d is not 10..1800", name, j.DeadlineSeconds)
		case j.UrgentDeadlineSeconds != 0 && (j.UrgentDeadlineSeconds < 10 || j.UrgentDeadlineSeconds > j.DeadlineSeconds):
			return bad("judge %s: urgentDeadlineSeconds %d is not 10..%d", name, j.UrgentDeadlineSeconds, j.DeadlineSeconds)
		case j.TokenTier != TierViewer && j.TokenTier != TierDeveloper:
			return bad("judge %s: tokenTier %q is not %s or %s", name, j.TokenTier, TierViewer, TierDeveloper)
		case j.TokenTTLSeconds < 60 || j.TokenTTLSeconds > 3600:
			return bad("judge %s: tokenTTLSeconds %d is not 60..3600", name, j.TokenTTLSeconds)
		case j.TokenTTLSeconds < j.DeadlineSeconds:
			return bad("judge %s: tokenTTLSeconds %d is below deadlineSeconds %d", name, j.TokenTTLSeconds, j.DeadlineSeconds)
		}
		used[j.Lane] = true
	}
	for _, lane := range sortedKeys(p.Lanes) {
		switch {
		case lane != LaneDeciding && lane != LaneBackground:
			return bad("lane %q is not %s or %s", lane, LaneDeciding, LaneBackground)
		case p.Lanes[lane] < 1:
			return bad("lane %s has %d turns", lane, p.Lanes[lane])
		case !used[lane]:
			return bad("lane %s has no judge", lane)
		}
	}
	if err := p.Batches().Validate(); err != nil {
		return bad("batchSeconds and urgentBatchSeconds: %v", err)
	}
	if p.TurnBudget.Turns < 1 || p.TurnBudget.Turns > 10000 {
		return bad("turnBudget.turns %d is not 1..10000", p.TurnBudget.Turns)
	}
	if p.TurnBudget.WindowSeconds < 60 || p.TurnBudget.WindowSeconds > 86400 {
		return bad("turnBudget.windowSeconds %d is not 60..86400", p.TurnBudget.WindowSeconds)
	}
	return nil
}

// Batches returns the waits of the batches of new signals.
func (p Policy) Batches() correlate.Policy {
	return correlate.Policy{Batch: time.Duration(p.BatchSeconds) * time.Second,
		UrgentBatch: time.Duration(p.UrgentBatchSeconds) * time.Second}
}

// URL returns the A2A address of one agent of one Organization.
func (r AgentRuntime) URL(organization, agent string) string {
	return strings.NewReplacer(placeholderOrganization, organization, placeholderAgent, agent).Replace(r.URLTemplate)
}

func checkTemplate(t string) error {
	if !strings.Contains(t, placeholderOrganization) || !strings.Contains(t, placeholderAgent) {
		return fmt.Errorf("%q needs both %s and %s", t, placeholderOrganization, placeholderAgent)
	}
	u, err := url.Parse(AgentRuntime{URLTemplate: t}.URL("acme", "correlator"))
	if err != nil {
		return err
	}
	if (u.Scheme != "http" && u.Scheme != "https") || u.Host == "" || strings.Contains(u.Host, "{") {
		return fmt.Errorf("%q is not an http or https address", t)
	}
	return nil
}

func sortedKeys[V any](m map[string]V) []string {
	out := make([]string, 0, len(m))
	for k := range m {
		out = append(out, k)
	}
	sort.Strings(out)
	return out
}

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"net/http"
	"os"
	"path/filepath"
	"strings"
)

// DefaultServiceAccountFile is where Kubernetes projects the pod's ServiceAccount token.
const DefaultServiceAccountFile = "/var/run/secrets/kubernetes.io/serviceaccount/token"

// TokenPath is the route of catalyst-api that issues agent tokens.
const TokenPath = "/api/v1/internal/agent-tokens"

// maxTokenBody is the largest answer of the token route that is read.
const maxTokenBody = 64 << 10

// TokenRequest is the body of a request for an agent token.
type TokenRequest struct {
	Organization string `json:"organization"`
	Agent        string `json:"agent"`
	Tier         string `json:"tier"`
	TTLSeconds   int    `json:"ttlSeconds"`
}

// TokenSource gives agent tokens.
type TokenSource interface {
	Token(ctx context.Context, r TokenRequest) (string, error)
}

// Tokens asks catalyst-api for agent tokens. It authenticates with the pod's projected
// ServiceAccount token, read again for every request because the kubelet rotates it.
// A token is never logged and never part of an error.
type Tokens struct {
	BaseURL                 string       // catalyst-api, for example http://catalyst-api.catalyst-system.svc:8080
	ServiceAccountFile string       // empty means DefaultServiceAccountFile
	Client                  *http.Client // nil means http.DefaultClient
}

// Token asks for one agent token.
func (t *Tokens) Token(ctx context.Context, r TokenRequest) (string, error) {
	file := t.ServiceAccountFile
	if file == "" {
		file = DefaultServiceAccountFile
	}
	raw, err := os.ReadFile(filepath.Clean(file))
	if err != nil {
		return "", fmt.Errorf("judge: agent token: the ServiceAccount token cannot be read: %w", err)
	}
	sa := strings.TrimSpace(string(raw))
	if sa == "" {
		return "", errors.New("judge: agent token: the ServiceAccount token file is empty")
	}
	body, err := json.Marshal(r)
	if err != nil {
		return "", err
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, strings.TrimRight(t.BaseURL, "/")+TokenPath, bytes.NewReader(body))
	if err != nil {
		return "", fmt.Errorf("judge: agent token: %w", err)
	}
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+sa)
	client := t.Client
	if client == nil {
		client = http.DefaultClient
	}
	resp, err := client.Do(req)
	if err != nil {
		return "", fmt.Errorf("judge: agent token: %w", err)
	}
	defer func() { _ = resp.Body.Close() }()
	data, err := io.ReadAll(io.LimitReader(resp.Body, maxTokenBody))
	if err != nil {
		return "", fmt.Errorf("judge: agent token: %w", err)
	}
	if resp.StatusCode != http.StatusOK {
		var e struct {
			Error  string `json:"error"`
			Detail string `json:"detail"`
		}
		_ = json.Unmarshal(data, &e)
		return "", fmt.Errorf("judge: agent token refused: HTTP %d %s: %s", resp.StatusCode, e.Error, e.Detail)
	}
	var ok struct {
		Token string `json:"token"`
	}
	if err := json.Unmarshal(data, &ok); err != nil || ok.Token == "" {
		return "", errors.New("judge: agent token: the answer holds no token")
	}
	return ok.Token, nil
}

package judge

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"net/http"
	"strings"
	"time"

	"github.com/openova-io/openova/products/ops-records/internal/ids"
)

// A2A task states (A2A 1.0).
const (
	StateCompleted     = "TASK_STATE_COMPLETED"
	StateFailed        = "TASK_STATE_FAILED"
	StateCanceled      = "TASK_STATE_CANCELED"
	StateRejected      = "TASK_STATE_REJECTED"
	StateInputRequired = "TASK_STATE_INPUT_REQUIRED"
	StateAuthRequired  = "TASK_STATE_AUTH_REQUIRED"
)

// maxA2ABody is the largest A2A answer that is read.
const maxA2ABody = 1 << 20

// cancelWait is how long a CancelTask call may take.
const cancelWait = 10 * time.Second

// ErrNoAnswer is wrapped when the agent ended its turn without an answer.
var ErrNoAnswer = errors.New("judge: the agent gave no answer")

// Agent asks one agent one question.
type Agent interface {
	// Ask sends text as the one text of a user message and returns the answer, a valid JSON
	// document. It returns when the agent's turn has ended or ctx is done.
	Ask(ctx context.Context, url, bearer, text string) (json.RawMessage, error)
}

// A2A is an Agent that speaks A2A 1.0 JSON-RPC over HTTP.
//
// Ask sends SendMessage with returnImmediately false, so the one HTTP request waits for the end
// of the turn and nothing polls. A new message starts a new task: no context is shared between
// turns. The answer is taken from the parts of the task's artifacts, else from the parts of its
// status message, else from a message the agent answered with instead of a task: the last data
// part, else the last text part. A data part whose value is an object with the one key "data"
// is unwrapped once. A text part is the answer when it is one JSON document; any other text is
// returned as a JSON string, so that it fails validation and is still recorded. A task that
// waits for input or for authentication is cancelled with CancelTask, and Ask returns an error
// wrapping ErrNoAnswer. A failed, cancelled or rejected task is an error.
type A2A struct {
	Client *http.Client // nil means http.DefaultClient
	User   string       // the header X-User-Id; empty means "ops-records"
}

type rpcRequest struct {
	JSONRPC string `json:"jsonrpc"`
	ID      string `json:"id"`
	Method  string `json:"method"`
	Params  any    `json:"params"`
}

type rpcResponse struct {
	Result json.RawMessage `json:"result"`
	Error  *struct {
		Code    int    `json:"code"`
		Message string `json:"message"`
	} `json:"error"`
}

type a2aPart struct {
	Text *string         `json:"text,omitempty"`
	Data json.RawMessage `json:"data,omitempty"`
}

type a2aMessage struct {
	MessageID string    `json:"messageId,omitempty"`
	Role      string    `json:"role,omitempty"`
	Parts     []a2aPart `json:"parts"`
}

type a2aTask struct {
	ID     string `json:"id"`
	Status struct {
		State   string      `json:"state"`
		Message *a2aMessage `json:"message"`
	} `json:"status"`
	Artifacts []struct {
		Parts []a2aPart `json:"parts"`
	} `json:"artifacts"`
}

// Ask implements Agent.
func (a *A2A) Ask(ctx context.Context, url, bearer, text string) (json.RawMessage, error) {
	params := map[string]any{
		"message":       a2aMessage{MessageID: ids.New(), Role: "ROLE_USER", Parts: []a2aPart{{Text: &text}}},
		"configuration": map[string]any{"returnImmediately": false},
	}
	result, err := a.call(ctx, url, bearer, "SendMessage", params)
	if err != nil {
		return nil, err
	}
	var outer struct {
		Task    *a2aTask    `json:"task"`
		Message *a2aMessage `json:"message"`
		Status  *struct{}   `json:"status"`
		Parts   []a2aPart   `json:"parts"`
	}
	if err := json.Unmarshal(result, &outer); err != nil {
		return nil, fmt.Errorf("judge: A2A SendMessage: the result is not a task or a message: %w", err)
	}
	switch {
	case outer.Task != nil:
		return a.fromTask(ctx, url, bearer, *outer.Task)
	case outer.Message != nil:
		return answerOf(outer.Message.Parts)
	case outer.Status != nil:
		var task a2aTask
		if err := json.Unmarshal(result, &task); err != nil {
			return nil, fmt.Errorf("judge: A2A SendMessage: %w", err)
		}
		return a.fromTask(ctx, url, bearer, task)
	case outer.Parts != nil:
		return answerOf(outer.Parts)
	}
	return nil, fmt.Errorf("%w: the result is neither a task nor a message", ErrNoAnswer)
}

func (a *A2A) fromTask(ctx context.Context, url, bearer string, task a2aTask) (json.RawMessage, error) {
	switch task.Status.State {
	case StateCompleted:
		var parts []a2aPart
		for _, art := range task.Artifacts {
			parts = append(parts, art.Parts...)
		}
		if len(parts) == 0 && task.Status.Message != nil {
			parts = task.Status.Message.Parts
		}
		return answerOf(parts)
	case StateFailed, StateCanceled, StateRejected:
		return nil, fmt.Errorf("judge: A2A task %s ended %s", task.ID, task.Status.State)
	}
	// Waiting for input or authentication, or not ended: a judge cannot continue it.
	cctx, cancel := context.WithTimeout(context.WithoutCancel(ctx), cancelWait)
	defer cancel()
	if _, err := a.call(cctx, url, bearer, "CancelTask", map[string]any{"id": task.ID}); err != nil {
		return nil, fmt.Errorf("%w: task %s is %s and CancelTask failed: %v", ErrNoAnswer, task.ID, task.Status.State, err)
	}
	return nil, fmt.Errorf("%w: task %s was %s and is cancelled", ErrNoAnswer, task.ID, task.Status.State)
}

// answerOf returns the last data part, else the last text part, as a JSON document.
func answerOf(parts []a2aPart) (json.RawMessage, error) {
	for i := len(parts) - 1; i >= 0; i-- {
		if d := bytes.TrimSpace(parts[i].Data); len(d) > 0 && json.Valid(d) {
			var wrapped map[string]json.RawMessage
			if json.Unmarshal(d, &wrapped) == nil && len(wrapped) == 1 && wrapped["data"] != nil &&
				bytes.HasPrefix(bytes.TrimSpace(wrapped["data"]), []byte("{")) {
				d = bytes.TrimSpace(wrapped["data"])
			}
			return d, nil
		}
	}
	for i := len(parts) - 1; i >= 0; i-- {
		if parts[i].Text == nil || strings.TrimSpace(*parts[i].Text) == "" {
			continue
		}
		t := []byte(strings.TrimSpace(*parts[i].Text))
		if json.Valid(t) {
			return t, nil
		}
		return json.Marshal(*parts[i].Text)
	}
	return nil, fmt.Errorf("%w: no data part and no text part", ErrNoAnswer)
}

// call sends one JSON-RPC request and returns its result.
func (a *A2A) call(ctx context.Context, url, bearer, method string, params any) (json.RawMessage, error) {
	body, err := json.Marshal(rpcRequest{JSONRPC: "2.0", ID: ids.New(), Method: method, Params: params})
	if err != nil {
		return nil, err
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, url, bytes.NewReader(body))
	if err != nil {
		return nil, fmt.Errorf("judge: A2A %s: %w", method, err)
	}
	user := a.User
	if user == "" {
		user = "ops-records"
	}
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json")
	req.Header.Set("A2A-Version", "1.0")
	req.Header.Set("X-User-Id", user)
	req.Header.Set("Authorization", "Bearer "+bearer)
	client := a.Client
	if client == nil {
		client = http.DefaultClient
	}
	resp, err := client.Do(req)
	if err != nil {
		return nil, fmt.Errorf("judge: A2A %s: %w", method, err)
	}
	defer func() { _ = resp.Body.Close() }()
	data, err := io.ReadAll(io.LimitReader(resp.Body, maxA2ABody+1))
	if err != nil {
		return nil, fmt.Errorf("judge: A2A %s: %w", method, err)
	}
	if len(data) > maxA2ABody {
		return nil, fmt.Errorf("judge: A2A %s: the answer is longer than %d bytes", method, maxA2ABody)
	}
	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("judge: A2A %s: HTTP %d", method, resp.StatusCode)
	}
	var r rpcResponse
	if err := json.Unmarshal(data, &r); err != nil {
		return nil, fmt.Errorf("judge: A2A %s: the answer is not JSON-RPC: %w", method, err)
	}
	if r.Error != nil {
		return nil, fmt.Errorf("judge: A2A %s: error %d: %s", method, r.Error.Code, r.Error.Message)
	}
	if len(r.Result) == 0 || string(r.Result) == "null" {
		return nil, fmt.Errorf("judge: A2A %s: the answer has no result", method)
	}
	return r.Result, nil
}

// Package judge asks agents bounded questions and writes their answers: the bounded-judge
// contract of the operations-records service.
//
// A judge is an agent called with one prepared JSON document; it must answer with one JSON
// document that matches a schema. For every question the dispatcher holds the offered
// document, the rule result (what the rules decide without any agent), a validation function
// and a deadline. The rules:
//
//   - Record. Asking writes one row of ops.judgements: the offered document, the rule result,
//     the time asked and the deadline (the judge's deadline, or its urgent deadline for an
//     urgent question). Its outcome is undecided until one of the outcomes below is written,
//     always in the same transaction as the records that outcome changes.
//   - One at a time. A subject (Organization, subject kind, subject identifier) has at most one
//     question in flight; asking again returns ErrBusy.
//   - Lanes. Every judge runs in a lane, and a lane runs at most its number of turns at once.
//     A question waits for a free turn of its lane until its deadline, and no longer.
//   - Turn. A turn takes one turn of the budget of its Organization and judge (agentguard:
//     a refused or uncountable budget means no call), asks catalyst-api for an agent token of
//     the judge's agent, tier and life (the request carries the pod's ServiceAccount token),
//     and calls the agent over A2A with the offered document as the text and the token as
//     bearer. A turn lives at most the token's life from the time it was asked. Its end, by
//     answer, error, cancel or end of life, frees its turn of the lane.
//   - Text. Every string of the offered document passes agentguard.CleanValue, with no link
//     host allowed, before the agent reads it. The row records the document as it was sent.
//   - Outcomes. The rule result is written first unless a valid answer comes before the
//     deadline:
//     applied: a valid answer came before the deadline and was written instead.
//     rejected_invalid: an invalid answer came before the deadline; the rule result was written
//     at once.
//     unavailable: the turn ended without an answer before the deadline (budget, token, call,
//     cancel); the rule result was written at once. Recover also writes it, without the rule
//     result, for a question a stopped dispatcher left undecided.
//     timeout: the deadline came first; the rule result was written at the deadline. The turn
//     goes on.
//     late_applied: after timeout a valid answer came within the turn's life and revised what
//     the rules wrote.
//     late_rejected: after timeout an invalid answer came.
//     A turn that ends without an answer after its deadline leaves the outcome timeout.
//   - Answers. The row records the answer as the agent gave it, with the time it came, for
//     every outcome that has one. Validation decides; an answer that cannot be written is
//     treated as invalid.
//   - Decided. Options.Decided is called with the row after every outcome is written: the
//     deadline's outcome is reported on time.
package judge

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"log/slog"

	"time"

)

// Errors of Ask.
var (
	ErrBusy     = errors.New("judge: the subject has a question in flight")
	ErrClosed   = errors.New("judge: the dispatcher is closed")
	ErrQuestion = errors.New("judge: bad question")
)

// writeWait bounds every write of an outcome. Writes do not end with the turn.
const writeWait = 30 * time.Second

// Question is one question for a judge.
type Question struct {
	Judge        string // a key of Policy.Judges
	Organization string // an Organization slug
	SubjectKind  string // for example "signal_batch"
	SubjectID    string
	Urgent       bool // the judge's urgent deadline applies, when it has one
	Offered      any  // the document offered to the judge, as JSON
	RuleResult   any  // the result of the rule function, as JSON

	// Validate checks an answer against what was offered and returns it in the form that
	// Apply and Revise take, or an error.
	Validate func(answer json.RawMessage) (any, error)
	// Rule writes the rule result and returns what it wrote, for Revise.
	Rule func(ctx context.Context, tx store.Tx, now time.Time) (any, error)
	// Apply writes a valid answer that came before the deadline, instead of the rule result.
	Apply func(ctx context.Context, tx store.Tx, answer any, now time.Time) error
	// Revise writes a valid answer that came after the rule result was written.
	Revise func(ctx context.Context, tx store.Tx, written, answer any, now time.Time) error
}

// Options are the parts of a Dispatcher that have defaults.
type Options struct {
	Now     func() time.Time                     // nil means time.Now
	After   func(time.Duration) <-chan time.Time // the deadline timer; nil means time.After
	Counter agentguard.Counter                   // the turn counter; nil means a new MemoryCounter
	NewID   func() string                        // judgement identifiers; nil means ids.New
	Decided func(store.Judgement)                // called after each outcome is written; may be nil
	Log     *slog.Logger                         // nil means slog.Default()
}

// Dispatcher asks judges and writes their outcomes. Its methods may be called from several
// goroutines. One dispatcher serves one database.

	tokens TokenSource

	opt    Options

	cancel context.CancelFunc
	lanes  map[string]chan struct{}

	closed bool
	turns  map[string]*turn  // by judgement ID
	busy   map[string]string // subject key -> judgement ID

	judge  Judge
	row    store.Judgement

// result is what a call gave: an answer, or an error.

// New returns a dispatcher. The policy must be valid.
func New(s store.Store, p Policy, tokens TokenSource, agent Agent, o Options) (*Dispatcher, error) {
	if err := p.Validate(); err != nil {
		return nil, err
	}
	if s == nil || tokens == nil || agent == nil {
		return nil, errors.New("judge: New needs a store, a token source and an agent")
	}
	if o.Now == nil {
		o.Now = time.Now
	}
	if o.After == nil {
		o.After = time.After
	}
	if o.Counter == nil {
		o.Counter = &agentguard.MemoryCounter{}
	}
	if o.NewID == nil {
		o.NewID = ids.New
	}
	if o.Log == nil {
		o.Log = slog.Default()

		budget: &agentguard.Budget{Turns: p.TurnBudget.Turns, Window: time.Duration(p.TurnBudget.WindowSeconds) * time.Second,

// Ask writes the judgement row of q, starts its turn and returns the judgement's identifier.
// It does not wait for the turn.
func (d *Dispatcher) Ask(ctx context.Context, q Question) (string, error) {
	j, ok := d.policy.Judges[q.Judge]
	switch {
	case !ok:
		return "", fmt.Errorf("%w: judge %q is not in the policy", ErrQuestion, q.Judge)
	case !organizationPattern.MatchString(q.Organization):
		return "", fmt.Errorf("%w: Organization %q", ErrQuestion, q.Organization)
	case q.SubjectKind == "" || q.SubjectID == "":
		return "", fmt.Errorf("%w: the subject is empty", ErrQuestion)
	case q.Validate == nil || q.Rule == nil || q.Apply == nil || q.Revise == nil:
		return "", fmt.Errorf("%w: Validate, Rule, Apply and Revise are required", ErrQuestion)
	}
	offered, err := cleaned(q.Offered)
	if err != nil {
		return "", fmt.Errorf("%w: offered: %v", ErrQuestion, err)
	}
	rule, err := json.Marshal(q.RuleResult)
	if err != nil {
		return "", fmt.Errorf("%w: rule result: %v", ErrQuestion, err)
	}
	wait := time.Duration(j.DeadlineSeconds) * time.Second
	if q.Urgent && j.UrgentDeadlineSeconds > 0 {
		wait = time.Duration(j.UrgentDeadlineSeconds) * time.Second
	}
	key := q.Organization + "\x00" + q.SubjectKind + "\x00" + q.SubjectID
	d.mu.Lock()
	if d.closed {
		d.mu.Unlock()
		return "", ErrClosed
	}
	if _, taken := d.busy[key]; taken {
		d.mu.Unlock()
		return "", ErrBusy
	}
	d.busy[key] = ""
	d.wg.Add(1)
	d.mu.Unlock()

	now := d.opt.Now()
	row := store.Judgement{ID: d.opt.NewID(), Organization: q.Organization, Judge: q.Judge, SubjectKind: q.SubjectKind,
		SubjectID: q.SubjectID, Offered: offered, RuleResult: rule, Outcome: store.OutcomeUndecided,
		AskedAt: now, DeadlineAt: now.Add(wait)}
	if err := d.store.InTx(ctx, func(ctx context.Context, tx store.Tx) error { return tx.InsertJudgement(ctx, row) }); err != nil {
		d.mu.Lock()
		delete(d.busy, key)
		d.mu.Unlock()
		d.wg.Done()
		return "", err
	}
	t := &turn{q: q, judge: j, row: row, key: key}
	t.ctx, t.cancel = context.WithTimeout(d.ctx, time.Duration(j.TokenTTLSeconds)*time.Second)
	d.mu.Lock()
	d.busy[key] = row.ID
	d.turns[row.ID] = t
	d.mu.Unlock()
	go d.run(t, wait)
	return row.ID, nil
}

// Busy reports whether the subject has a question in flight.
func (d *Dispatcher) Busy(organization, subjectKind, subjectID string) bool {
	d.mu.Lock()
	defer d.mu.Unlock()
	_, ok := d.busy[organization+"\x00"+subjectKind+"\x00"+subjectID]
	return ok
}

// Cancel ends the turn of a judgement. It returns false when the judgement has no turn.
func (d *Dispatcher) Cancel(judgementID string) bool {
	d.mu.Lock()
	t := d.turns[judgementID]
	d.mu.Unlock()
	if t == nil {
		return false
	}
	t.cancel()
	return true
}

// Close refuses new questions, ends every turn and waits until each has written its outcome.
func (d *Dispatcher) Close() {
	d.mu.Lock()
	d.closed = true
	d.mu.Unlock()
	d.cancel()
	d.wg.Wait()
}

// Recover writes the outcome unavailable on every judgement that a stopped dispatcher left
// undecided, without its rule result: the turn is lost, and the subject is asked again under a
// new judgement. Run it once, before the first Ask. It returns how many rows it wrote.
func Recover(ctx context.Context, s store.Store) (int, error) {
	rows, err := s.ListJudgements(ctx, store.JudgementFilter{Undecided: true, Limit: store.MaxLimit})
	if err != nil {
		return 0, err
	}
	err = s.InTx(ctx, func(ctx context.Context, tx store.Tx) error {
		for _, j := range rows {
			j.Outcome = store.OutcomeUnavailable
			if err := tx.UpdateJudgement(ctx, j); err != nil {
				return err
			}
		}
		return nil
	})
	if err != nil {
		return 0, err
	}
	return len(rows), nil
}

func (d *Dispatcher) run(t *turn, wait time.Duration) {
	defer d.end(t)
	deadline := d.opt.After(wait)
	lane := d.lanes[t.judge.Lane]
	select {
	case lane <- struct{}{}:
	case <-deadline:
		d.writeRule(t, store.OutcomeTimeout, nil)
		return
	case <-t.ctx.Done():
		d.writeRule(t, store.OutcomeUnavailable, nil)
		return
	}
	defer func() { <-lane }()
	results := make(chan result, 1)
	go func() { results <- d.call(t) }()
	select {
	case r := <-results:
		d.early(t, r)
		return
	case <-deadline:
	}
	written, ok := d.writeRule(t, store.OutcomeTimeout, nil)
	r := <-results
	if ok {
		d.late(t, written, r)
	}
}

func (d *Dispatcher) end(t *turn) {
	t.cancel()
	d.mu.Lock()
	delete(d.busy, t.key)
	delete(d.turns, t.row.ID)
	d.mu.Unlock()
	d.wg.Done()
}

// call takes a turn of the budget, gets a token and asks the agent.
func (d *Dispatcher) call(t *turn) result {
	fail := func(err error) result { return result{err: err, at: d.opt.Now()} }
	if err := d.budget.Take(t.ctx, t.q.Organization+"/"+t.q.Judge); err != nil {
		return fail(err)
	}
	token, err := d.tokens.Token(t.ctx, TokenRequest{Organization: t.q.Organization, Agent: t.judge.Agent,
		Tier: t.judge.TokenTier, TTLSeconds: t.judge.TokenTTLSeconds})
	if err != nil {
		return fail(err)
	}
	answer, err := d.agent.Ask(t.ctx, d.policy.AgentRuntime.URL(t.q.Organization, t.judge.Agent), token, string(t.row.Offered))
	if err != nil {
		return fail(err)
	}
	if !json.Valid(answer) {
		return fail(fmt.Errorf("%w: the answer is not JSON", ErrNoAnswer))
	}
	return result{answer: answer, at: d.opt.Now()}
}

// early writes the outcome of a turn that ended before the deadline.
func (d *Dispatcher) early(t *turn, r result) {
	if r.err != nil {
		d.opt.Log.Info("judge: no answer before the deadline", "judgement", t.row.ID, "judge", t.q.Judge, "err", r.err)
		d.writeRule(t, store.OutcomeUnavailable, nil)
		return
	}
	answer, err := t.q.Validate(r.answer)
	if err == nil {
		err = d.write(t, store.OutcomeApplied, &r, func(ctx context.Context, tx store.Tx, now time.Time) error {
			return t.q.Apply(ctx, tx, answer, now)
		})
		if err == nil {
			return
		}
	}
	d.opt.Log.Info("judge: answer rejected", "judgement", t.row.ID, "judge", t.q.Judge, "err", err)
	d.writeRule(t, store.OutcomeRejectedInvalid, &r)
}

// late writes the outcome of an answer that came after the rule result was written.
func (d *Dispatcher) late(t *turn, written any, r result) {
	if r.err != nil {
		d.opt.Log.Info("judge: no answer after the deadline", "judgement", t.row.ID, "judge", t.q.Judge, "err", r.err)
		return
	}
	answer, err := t.q.Validate(r.answer)
	if err == nil {
		err = d.write(t, store.OutcomeLateApplied, &r, func(ctx context.Context, tx store.Tx, now time.Time) error {
			return t.q.Revise(ctx, tx, written, answer, now)
		})
		if err == nil {
			return
		}
	}
	d.opt.Log.Info("judge: late answer rejected", "judgement", t.row.ID, "judge", t.q.Judge, "err", err)
	_ = d.write(t, store.OutcomeLateRejected, &r, nil)
}

// writeRule writes the rule result with an outcome and returns what the rules wrote.
func (d *Dispatcher) writeRule(t *turn, outcome string, r *result) (any, bool) {
	var written any
	err := d.write(t, outcome, r, func(ctx context.Context, tx store.Tx, now time.Time) error {
		w, err := t.q.Rule(ctx, tx, now)
		written = w
		return err
	})
	return written, err == nil
}

// write runs fn and records the outcome, with the answer of r when r has one, in one
// transaction, then reports the row.
func (d *Dispatcher) write(t *turn, outcome string, r *result, fn func(ctx context.Context, tx store.Tx, now time.Time) error) error {
	ctx, cancel := context.WithTimeout(context.WithoutCancel(d.ctx), writeWait)
	defer cancel()
	row := t.row
	row.Outcome = outcome
	if r != nil && r.answer != nil {
		at := r.at
		if at.Before(row.AskedAt) {
			at = row.AskedAt
		}
		row.Answer, row.AnsweredAt = r.answer, &at
	}
	now := d.opt.Now()
	err := d.store.InTx(ctx, func(ctx context.Context, tx store.Tx) error {
		if fn != nil {
			if err := fn(ctx, tx, now); err != nil {
				return err
			}
		}
		return tx.UpdateJudgement(ctx, row)
	})
	if err != nil {
		d.opt.Log.Error("judge: the outcome cannot be written", "judgement", t.row.ID, "outcome", outcome, "err", err)
		return err
	}
	t.row = row // only the turn's own goroutine reads and writes t.row
	if d.opt.Decided != nil {
		d.opt.Decided(row)
	}
	return nil
}

// cleaned returns the offered document with every string passed through agentguard.
func cleaned(v any) (json.RawMessage, error) {
	raw, err := json.Marshal(v)
	if err != nil {
		return nil, err
	}
	var generic any
	if err := json.Unmarshal(raw, &generic); err != nil {
		return nil, err
	}
	return json.Marshal(agentguard.CleanValue(generic, nil))
}

// The correlator judge.
const (
	Correlator   = "correlator"   // its name in Policy.Judges and in timelines
	SubjectBatch = "signal_batch" // the subject kind of its questions

// An attach whose causal chain has fewer than MinCausalChain characters, or whose confidence is
// below MinConfidence, is changed to new.
const (
	MinCausalChain = 12
	MinConfidence  = 0.5
)

// Timeline entries a late revision writes.
const (
	EventLate     = "judge_late"
	EventDetached = "signals_detached"
	EventMerged   = "merged"
)

// maxHops is how far a late revision follows merged incidents.
const maxHops = 10

// ErrInvalidAnswer is wrapped by every error of answer validation.
var ErrInvalidAnswer = errors.New("judge: invalid answer")

var decisionKeys = map[string]bool{"groupId": true, "decision": true, "incidentId": true, "causalChain": true,
	"confidence": true, "severity": true}

// ValidateCorrelation checks an answer of the correlator against the request it was offered, in
// this order; the first failure rejects the whole answer:
//
//  1. The answer is one JSON object with the one key "decisions", a list of objects with the
//     keys groupId, decision, confidence and severity and the optional keys incidentId and
//     causalChain, and no other key. groupId, incidentId and causalChain are strings; decision
//     is attach, new or watch; confidence is a number from 0 to 1; severity an integer from 1 to 4.
//  2. Every offered group appears exactly once, and no other group appears.
//  3. Every decision is one of the request's allowed decisions.
//  4. An attach names one of the offered candidates. When its causal chain has fewer than
//     MinCausalChain characters or its confidence is below MinConfidence it is changed to new.
//     A decision that is not attach keeps no incident.
//  5. A severity is not less urgent than the most urgent severity floor of its group's signals.
//
// It returns the decisions to apply, in the order of the answer.
func ValidateCorrelation(req correlate.Request, answer json.RawMessage) ([]correlate.Decision, error) {
	bad := func(format string, args ...any) error {
		return fmt.Errorf("%w: "+format, append([]any{ErrInvalidAnswer}, args...)...)
	}
	top, err := object(answer)
	if err != nil || len(top) != 1 || top["decisions"] == nil {
		return nil, bad("the answer is not an object with the one key decisions")
	}
	var items []json.RawMessage
	if !bytes.HasPrefix(top["decisions"], []byte("[")) || json.Unmarshal(top["decisions"], &items) != nil {
		return nil, bad("decisions is not a list")
	}
	out := make([]correlate.Decision, 0, len(items))
	for i, item := range items {
		d, err := decision(item)
		if err != nil {
			return nil, bad("decision %d: %v", i, err)
		}
		out = append(out, d)
	}
	floors := map[string]int{}
	for _, g := range req.Groups {
		floors[g.GroupID] = store.SeverityLowest
		for _, s := range g.Signals {
			floors[g.GroupID] = min(floors[g.GroupID], s.SeverityFloor)
		}
	}
	seen := map[string]bool{}
	for _, d := range out {
		if _, offered := floors[d.GroupID]; !offered || seen[d.GroupID] {
			return nil, bad("group %q is not offered or is decided twice", d.GroupID)
		}
		seen[d.GroupID] = true
	}
	if len(seen) != len(floors) {
		return nil, bad("%d of %d offered groups are decided", len(seen), len(floors))
	}
	allowed := map[string]bool{}
	for _, a := range req.Allowed {
		allowed[a] = true
	}
	for _, d := range out {
		if !allowed[d.Decision] {
			return nil, bad("group %s: decision %s is not allowed", d.GroupID, d.Decision)
		}
	}
	candidates := map[string]bool{}
	for _, c := range req.Candidates {
		candidates[c.IncidentID] = true
	}
	for i := range out {
		d := &out[i]
		if d.Decision != correlate.Attach {
			d.IncidentID = ""
			continue
		}
		if !candidates[d.IncidentID] {
			return nil, bad("group %s: incident %q is not an offered candidate", d.GroupID, d.IncidentID)
		}
		if utf8.RuneCountInString(d.CausalChain) < MinCausalChain || d.Confidence < MinConfidence {
			d.Decision, d.IncidentID = correlate.New, ""
		}
	}
	for _, d := range out {
		if d.Severity > floors[d.GroupID] {
			return nil, bad("group %s: severity %d is less urgent than its floor %d", d.GroupID, d.Severity, floors[d.GroupID])
		}
	}
	return out, nil
}

// object decodes one JSON object into its keys.
func object(raw json.RawMessage) (map[string]json.RawMessage, error) {
	if !bytes.HasPrefix(bytes.TrimSpace(raw), []byte("{")) {
		return nil, errors.New("not an object")
	}
	var m map[string]json.RawMessage
	return m, json.Unmarshal(raw, &m)
}

func decision(raw json.RawMessage) (correlate.Decision, error) {
	var d correlate.Decision
	m, err := object(raw)
	if err != nil {
		return d, err
	}
	for k := range m {
		if !decisionKeys[k] {
			return d, fmt.Errorf("unknown key %q", k)
		}
	}
	for _, k := range []string{"groupId", "decision", "confidence", "severity"} {
		if m[k] == nil {
			return d, fmt.Errorf("%s is missing", k)
		}
	}
	for k, v := range m {
		if string(bytes.TrimSpace(v)) == "null" {
			return d, fmt.Errorf("%s is null", k)
		}
	}
	strs := map[string]*string{"groupId": &d.GroupID, "decision": &d.Decision, "incidentId": &d.IncidentID,
		"causalChain": &d.CausalChain}
	for k, p := range strs {
		if v := m[k]; v != nil && json.Unmarshal(v, p) != nil {
			return d, fmt.Errorf("%s is not a string", k)
		}
	}
	if json.Unmarshal(m["confidence"], &d.Confidence) != nil || d.Confidence < 0 || d.Confidence > 1 {
		return d, errors.New("confidence is not a number from 0 to 1")
	}
	if json.Unmarshal(m["severity"], &d.Severity) != nil || d.Severity < store.SeverityHighest || d.Severity > store.SeverityLowest {
		return d, errors.New("severity is not an integer from 1 to 4")
	}
	if d.Decision != correlate.Attach && d.Decision != correlate.New && d.Decision != correlate.Watch {
		return d, fmt.Errorf("decision %q is not attach, new or watch", d.Decision)
	}
	return d, nil
}

// BatchSubject is the subject identifier of the questions about a batch.
func BatchSubject(b correlate.Batch) string { return "cluster/" + b.Cluster }

// Correlation is the question for the correlator about one prepared batch. The rules write the
// rule result through a; a valid answer is written through a with the actor agent correlator.
// The question is urgent when a signal of the batch has a severity floor of 2 or more urgent.
func Correlation(p correlate.Prepared, a correlate.Applier) Question {
	urgent := false
	for _, g := range p.Groups {
		urgent = urgent || g.Floor <= 2
	}
	agent := correlate.Actor{Kind: store.ByAgent, Name: Correlator}
	return Question{Judge: Correlator, Organization: p.Batch.Organization, SubjectKind: SubjectBatch,
		SubjectID: BatchSubject(p.Batch), Urgent: urgent, Offered: p.Request, RuleResult: p.RuleResult,
		Validate: func(answer json.RawMessage) (any, error) { return ValidateCorrelation(p.Request, answer) },
		Rule: func(ctx context.Context, tx store.Tx, now time.Time) (any, error) {
			return a.Apply(ctx, tx, p.Groups, p.RuleResult.Decisions, correlate.Rules, now)
		},
		Apply: func(ctx context.Context, tx store.Tx, answer any, now time.Time) error {
			_, err := a.Apply(ctx, tx, p.Groups, answer.([]correlate.Decision), agent, now)
			return err
		},
		Revise: func(ctx context.Context, tx store.Tx, written, answer any, now time.Time) error {
			return Revise(ctx, tx, a, p.Groups, written.([]correlate.GroupResult), answer.([]correlate.Decision), agent, now)
		},
	}
}

// Revise writes a late answer of the correlator over what the rules wrote, group by group:
//
//   - A group the rules moved no signal of is left alone.
//   - watch: an entry judge_late on the rules' incident; nothing moves.
//   - When the rules' incident is no longer open, was merged, or has a severity a person set, a
//     person has acted: only an entry judge_late is written.
//   - The same place (attach to the rules' incident, followed through merges, or new when the
//     rules opened an incident for the group): the incident is re-rated, never less urgent
//     than it is, and gets an entry judge_late.
//   - Otherwise the group's signals that are still in the rules' incident leave it (entry
//     signals_detached) and the answer's decision is applied to them through a. When the rules
//     opened that incident for the group and it has no signal left, it is merged into the
//     incident the signals went to (entry merged).
func Revise(ctx context.Context, tx store.Tx, a correlate.Applier, groups []correlate.Group,
	written []correlate.GroupResult, answer []correlate.Decision, by correlate.Actor, now time.Time) error {
	decided := map[string]correlate.Decision{}
	for _, d := range answer {
		decided[d.GroupID] = d
	}
	for _, r := range written {
		d, ok := decided[r.GroupID]
		if !ok || r.IncidentID == "" {
			continue
		}
		var g correlate.Group
		for _, x := range groups {
			if x.ID == r.GroupID {
				g = x
			}
		}
		if len(g.Signals) == 0 {
			continue
		}
		org := g.Signals[0].Organization
		ruled, err := tx.GetIncident(ctx, org, r.IncidentID)
		if err != nil {
			return err
		}
		note := func(in store.Incident, how string) error {
			return event(ctx, tx, in, now, by, EventLate, map[string]any{"groupId": d.GroupID, "decision": d.Decision,
				"incidentId": d.IncidentID, "causalChain": d.CausalChain, "confidence": d.Confidence,
				"severity": d.Severity, "revision": how})
		}
		same := d.Decision == correlate.New && r.Applied == correlate.AppliedNew
		if d.Decision == correlate.Attach {
			target, err := follow(ctx, tx, org, d.IncidentID)
			if err != nil {
				return err
			}
			same = target.ID == ruled.ID
		}
		switch {
		case d.Decision == correlate.Watch:
			err = note(ruled, "kept")
		case ruled.State != store.IncidentOpen || ruled.ParentID != "" || ruled.SeveritySetBy == store.ByPerson:
			err = note(ruled, "kept: a person acted on the incident")
		case same:
			if err = rate(ctx, tx, ruled, d.Severity, by, now); err == nil {
				err = note(ruled, "rated")
			}
		default:
			err = move(ctx, tx, a, g, r, ruled, d, by, now)
		}
		if err != nil {
			return err
		}
	}
	return nil
}

func move(ctx context.Context, tx store.Tx, a correlate.Applier, g correlate.Group, r correlate.GroupResult,
	ruled store.Incident, d correlate.Decision, by correlate.Actor, now time.Time) error {
	var freed []store.Signal
	var freedIDs []string
	for _, id := range r.SignalIDs {
		s, err := tx.GetSignal(ctx, ruled.Organization, id)
		if err != nil {
			return err
		}
		if s.IncidentID != ruled.ID {
			continue
		}
		s.IncidentID = ""
		if err := tx.UpdateSignal(ctx, s); err != nil {
			return err
		}
		freed, freedIDs = append(freed, s), append(freedIDs, s.ID)
	}
	if len(freed) == 0 {
		return event(ctx, tx, ruled, now, by, EventLate, map[string]any{"groupId": d.GroupID, "decision": d.Decision,
			"revision": "kept: no signal of the group is left in the incident"})
	}
	res, err := a.Apply(ctx, tx, []correlate.Group{{ID: g.ID, Key: g.Key, Floor: g.Floor, Signals: freed}},
		[]correlate.Decision{d}, by, now)
	if err != nil {
		return err
	}
	to := res[0].IncidentID
	if err := event(ctx, tx, ruled, now, by, EventDetached, map[string]any{"groupId": d.GroupID, "signals": freedIDs,
		"to": to, "causalChain": d.CausalChain, "confidence": d.Confidence}); err != nil {
		return err
	}
	if r.Applied != correlate.AppliedNew || to == "" || to == ruled.ID {
		return nil
	}
	left, err := tx.ListSignals(ctx, store.SignalFilter{Organization: ruled.Organization, IncidentID: ruled.ID, Limit: 1})
	if err != nil || len(left) > 0 {
		return err
	}
	ruled.ParentID = to
	if err := tx.UpdateIncident(ctx, ruled); err != nil {
		return err
	}
	return event(ctx, tx, ruled, now, by, EventMerged, map[string]any{"into": to})
}

// rate makes an incident as urgent as want and every floor of its signals, never less urgent
// than it is, unless a person set its severity.
func rate(ctx context.Context, tx store.Tx, in store.Incident, want int, by correlate.Actor, now time.Time) error {
	if in.SeveritySetBy == store.ByPerson {
		return nil
	}
	signals, err := tx.ListSignals(ctx, store.SignalFilter{Organization: in.Organization, IncidentID: in.ID, Limit: store.MaxLimit})
	if err != nil {
		return err
	}
	want = min(want, in.Severity)
	for _, s := range signals {
		want = min(want, s.SeverityFloor)
	}
	if want == in.Severity {
		return nil
	}
	from := in.Severity
	in.Severity, in.SeveritySetBy = want, by.Kind
	if err := tx.UpdateIncident(ctx, in); err != nil {
		return err
	}
	return event(ctx, tx, in, now, by, correlate.EventSeverity, map[string]any{"from": from, "to": want})
}

// follow returns the incident id, or the one it was merged into.
func follow(ctx context.Context, r store.Reader, org, id string) (store.Incident, error) {
	in, err := r.GetIncident(ctx, org, id)
	for i := 0; err == nil && in.ParentID != ""; i++ {
		if i == maxHops {
			return in, fmt.Errorf("judge: incident %s is merged more than %d times deep", id, maxHops)
		}
		in, err = r.GetIncident(ctx, org, in.ParentID)
	}
	return in, err
}

func event(ctx context.Context, tx store.Tx, in store.Incident, at time.Time, by correlate.Actor, kind string, data map[string]any) error {
	raw, err := json.Marshal(data)
	if err != nil {
		return err
	}
	_, err = tx.AppendIncidentEvent(ctx, store.IncidentEvent{Organization: in.Organization, IncidentID: in.ID, At: at,
		ActorKind: by.Kind, Actor: by.Name, Kind: kind, Data: raw})
	return err
}

// CorrelationTicker asks the correlator about every batch that is due.
type CorrelationTicker struct {
	Store      store.Store
	Dispatcher *Dispatcher
	Batches    correlate.Policy // the waits; Policy.Batches
	Applier    correlate.Applier
	Now        func() time.Time // nil means time.Now
}

// Tick asks about every pending batch that is due and has no question in flight, and returns
// the identifiers of the judgements it started. A batch's last decision is the time its newest
// judgement was answered, or else asked.
func (c *CorrelationTicker) Tick(ctx context.Context) ([]string, error) {
	now := time.Now()
	if c.Now != nil {
		now = c.Now()
	}
	batches, views, err := correlate.Load(ctx, c.Store, "")
	if err != nil {
		return nil, err
	}
	var asked []string
	for _, b := range batches {
		subject := BatchSubject(b)
		if c.Dispatcher.Busy(b.Organization, SubjectBatch, subject) {
			continue
		}
		last, err := c.Store.ListJudgements(ctx, store.JudgementFilter{Organization: b.Organization, Judge: Correlator,
			SubjectKind: SubjectBatch, SubjectID: subject, Limit: 1})
		if err != nil {
			return asked, err
		}
		var lastDecision time.Time
		if len(last) == 1 {
			lastDecision = last[0].AskedAt
			if last[0].AnsweredAt != nil {
				lastDecision = *last[0].AnsweredAt
			}
		}
		if correlate.DueAt(b, lastDecision, c.Batches).After(now) {
			continue
		}
		id, err := c.Dispatcher.Ask(ctx, Correlation(correlate.Prepare(b, views[b.Organization]), c.Applier))
		if errors.Is(err, ErrBusy) {
			continue
		}
		if err != nil {
			return asked, fmt.Errorf("judge: batch %s: %w", b.Key(), err)
		}
		asked = append(asked, id)
	}
	return asked, nil
}

// counter makes incident identifiers 900, 901, ...
func counter() func() string {
	n := ruleIncidentID - 1
	var mu sync.Mutex
	return func() string { mu.Lock(); defer mu.Unlock(); n++; return incID(n) }
}

// correlation asks the correlator about the scenario's batch.

	t.Helper()

		correlate.Applier{NewIncidentID: counter()}))
	if err != nil {
		t.Fatal(err)
	}
	return id
}

// rpcServer answers JSON-RPC requests with the answers given per method, and records them.
type rpcServer struct {
	mu      sync.Mutex
	methods []string
	params  []map[string]any
	headers []http.Header
}

func (s *rpcServer) snapshot() ([]string, []map[string]any, []http.Header) {
	s.mu.Lock()
	defer s.mu.Unlock()
	return append([]string(nil), s.methods...), append([]map[string]any(nil), s.params...), append([]http.Header(nil), s.headers...)
}

func (s *rpcServer) start(t *testing.T, status int, answers map[string]string) *httptest.Server {
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		var req struct {
			JSONRPC string         `json:"jsonrpc"`
			ID      string         `json:"id"`
			Method  string         `json:"method"`
			Params  map[string]any `json:"params"`
		}
		if err := json.NewDecoder(r.Body).Decode(&req); err != nil || req.JSONRPC != "2.0" || req.ID == "" {
			http.Error(w, "not JSON-RPC", http.StatusBadRequest)
			return
		}
		s.mu.Lock()
		s.methods, s.params, s.headers = append(s.methods, req.Method), append(s.params, req.Params), append(s.headers, r.Header)
		s.mu.Unlock()
		if req.Method == "SendMessage" && answers[req.Method] == "block" {
			<-r.Context().Done()
			return
		}
		w.WriteHeader(status)
		_, _ = io.WriteString(w, `{"jsonrpc":"2.0","id":"`+req.ID+`",`+answers[req.Method]+`}`)
	}))
	t.Cleanup(srv.Close)
	return srv
}
