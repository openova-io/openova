# CLD-113 — Mesh and topology read the profile

## In plain words

**The problem today.** The code that connects the regions of a Sovereign picks the network port by testing the name of the cloud, and the code that draws the topology page assumes one cloud when none is recorded and tests another cloud by name. A new cloud therefore needs code changes in both places, and an unknown cloud is shown as a cloud it is not. The API also cannot tell which cloud profile describes the Sovereign it runs on.

**What changes.** The API learns its own cloud pack from a setting that the platform chart fills, and reads that pack's cloud profile. The topology page takes the kind of front door from the cloud profile and leaves the cloud empty when it is not known. Every region dials the mesh proxy port, whatever its cloud.

**Done means:**

- No cloud name is written in quotes in the mesh code, the topology loader or the topology handler, and the function that tested cloud names for the mesh port is gone.
- Every mesh peer dials port 12379 unless the dial-port setting overrides it.
- The topology page shows the front door of a Huawei Sovereign as gateway-eip and of a Hetzner Sovereign as cloud-lb, both read from the cloud profiles.
- A deployment whose cloud is not recorded shows no cloud and no front-door kind instead of a guessed one.
- The platform chart passes the cloud pack and the installation name to the API, and bootstrap-kit slot 13 fills the pack from the existing PROVIDER value.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The catalyst-api knows the provider pack of the Sovereign it runs on and reads its cloud profile (contract C2, `infra/providers/<pack>/profile.yaml`). A new file `products/catalyst/bootstrap/api/internal/cloudprofile/sovereign.go` adds `ForSovereign`: it loads the pack named by the environment variable `CLOUD_PROVIDER` and, when `CLOUD_INSTALLATION` is set, merges the installation document of that name, read from its ConfigMap. The platform chart sets both variables on the catalyst-api Deployment from the new values `global.cloud.provider` and `global.cloud.installation`; bootstrap-kit slot 13 sets `global.cloud.provider` from the existing substitute `${PROVIDER}`. The topology loader takes the front-door kind from `spec.network.loadBalancer.mode` of the profile (`external-hostport` gives `gateway-eip`, `controller` gives `cloud-lb`), takes the Sovereign's own pack on the live path, and leaves the provider empty when it is not known. The ClusterMesh code drops `isNoCCMCloud` and every per-region provider: every peer dials the clustermesh-proxy host port 12379, and the existing variable `CLUSTERMESH_APISERVER_DIAL_PORT` still overrides it. A person can observe this on the pull request: the new and changed tests pass, and the three Go files name no cloud in quotes.

## 3. The model (the law)
1. `cloudprofile.ForSovereign(ctx, dir, read)` returns the effective cloud profile of the Sovereign the process runs on. `CLOUD_PROVIDER` (trimmed) names the pack below `dir`. Empty, or naming no pack: error `ErrUnknownPack` at path `CLOUD_PROVIDER`. `CLOUD_INSTALLATION` (trimmed) empty: the pack profile is returned and `read` is not called. Set: `read` returns the document; its `metadata.name` must equal the variable (else `ErrBadValue` at `metadata.name`); the result is `Merge(pack, document)`. A nil `read` with the variable set is an error.
2. `cloudprofile.InstallationFromCluster(client)` reads the document from ConfigMap `catalyst-system/cloud-installation-<name>`, key `profile.yaml` (the constants of `installation.go`). `cloudprofile.PackName(p)` is `spec.extends` when set, else `metadata.name`. `cloudprofile.DefaultDir` is `/infra/providers`, where the catalyst-api image holds `infra/providers`.
3. The front-door kind of a provider is read from its pack profile below the loader's `providersDir` (default `cloudprofile.DefaultDir`): mode `external-hostport` gives `gateway-eip`, mode `controller` gives `cloud-lb`. A provider that is empty or names no readable pack gives an empty kind. No code compares a provider name.
4. The topology loader assumes no provider. When the deployment input has no provider, no `Regions` and no `Region` (the live path, served by the Sovereign's own API), the provider is `PackName(ForSovereign(...))`, with installation documents read through the deployment's dynamic client; on any error it stays empty. A region's provider is the provider its spec records. No `CloudTenant` entry is emitted for an empty provider. Node labels and `spec.providerID` are no longer read for the provider.
5. `firstProvider` (handler) returns the provider of the first region, else the request's `Provider`, else empty. The default `"hetzner"` is deleted.
6. `clusterMeshDialPort()` takes no argument. It returns `CLUSTERMESH_APISERVER_DIAL_PORT` when that holds a port from 1 to 65535, else `clusterMeshProxyDialPort` (12379). `isNoCCMCloud`, the field `regionSlot.provider`, the per-region provider lookup in `buildRegionSlots` and the parameter `provider` of `waitForClusterMeshLB` are deleted.
7. The catalyst-api Deployment (Helm template) sets `CLOUD_PROVIDER` from `global.cloud.provider` and `CLOUD_INSTALLATION` from `global.cloud.installation`, both empty by default. The raw-Kustomize twin, which only the mothership applies, sets both to `""`. Slot 13 sets `global.cloud.provider: '${PROVIDER:-}'` and no installation.
8. The handler package shrinks, so the line baseline of `scripts/check-api-structure.py` falls from 98217 to 98158. The provider-leak counts of the three Go files fall, and their lines in `scripts/provider-leak-baseline.tsv` fall with them (4 to 1, 2 to 1, 9 to 3).
9. Nothing else changes: no chart version, no pin, no `go.mod`, no other value of slot 13, the value `global.cloudProvider` and its reader stay as they are.

package cloudprofile

import (
	"context"
	"fmt"
	"os"
	"strconv"
	"strings"

	metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"
	"k8s.io/apimachinery/pkg/apis/meta/v1/unstructured"
	"k8s.io/apimachinery/pkg/runtime/schema"
	"k8s.io/client-go/dynamic"
)

// The Sovereign an API process runs on. The platform chart sets both
// variables on the catalyst-api Deployment from global.cloud.provider and
// global.cloud.installation.
const (
	// ProviderEnv names the provider pack, a directory below the providers
	// directory.
	ProviderEnv = "CLOUD_PROVIDER"
	// InstallationEnv names the installation document laid over the pack
	// (its metadata.name). Empty: the pack profile alone.
	InstallationEnv = "CLOUD_INSTALLATION"
	// DefaultDir is the providers directory in the catalyst-api image.
	DefaultDir = "/infra/providers"
)

// InstallationReader returns the installation document named name.
type InstallationReader func(ctx context.Context, name string) ([]byte, error)

// ForSovereign returns the effective cloud profile of the Sovereign this
// process runs on: the pack profile below dir that CLOUD_PROVIDER names,
// merged (Merge) with the installation document that CLOUD_INSTALLATION
// names when that is set; read fetches the document. An empty or unknown
// pack gives ErrUnknownPack at CLOUD_PROVIDER; a document whose
// metadata.name is not CLOUD_INSTALLATION gives ErrBadValue at
// metadata.name.
func ForSovereign(ctx context.Context, dir string, read InstallationReader) (*Profile, error) {
	name := strings.TrimSpace(os.Getenv(ProviderEnv))
	if name == "" {
		return nil, &FieldError{Err: ErrUnknownPack, Path: ProviderEnv, Detail: "not set"}
	}
	packs, err := Load(dir)
	if err != nil {
		return nil, err
	}
	pack, ok := packs[name]
	if !ok {
		return nil, &FieldError{Err: ErrUnknownPack, Path: ProviderEnv, Detail: strconv.Quote(name)}
	}
	inst := strings.TrimSpace(os.Getenv(InstallationEnv))
	if inst == "" {
		return pack, nil
	}
	if read == nil {
		return nil, fmt.Errorf("cloudprofile: %s is %q and there is no installation reader", InstallationEnv, inst)
	}
	data, err := read(ctx, inst)
	if err != nil {
		return nil, fmt.Errorf("cloudprofile: installation %q: %w", inst, err)
	}
	doc, err := Parse(data)
	if err != nil {
		return nil, err
	}
	if doc.Metadata.Name != inst {
		return nil, &FieldError{Err: ErrBadValue, Path: "metadata.name", Detail: fmt.Sprintf("%q, %s is %q", doc.Metadata.Name, InstallationEnv, inst)}
	}
	return Merge(pack, doc)
}

// PackName returns the pack of a profile: spec.extends of an effective
// profile, else metadata.name.
func PackName(p *Profile) string {
	switch {
	case p == nil:
		return ""
	case p.Spec.Extends != "":
		return p.Spec.Extends
	}
	return p.Metadata.Name
}

// InstallationFromCluster reads an installation document from its ConfigMap
// (see InstallationNamespace) through client.
func InstallationFromCluster(client dynamic.Interface) InstallationReader {
	return func(ctx context.Context, name string) ([]byte, error) {
		cmName := InstallationConfigMapPrefix + name
		gvr := schema.GroupVersionResource{Version: "v1", Resource: "configmaps"}
		cm, err := client.Resource(gvr).Namespace(InstallationNamespace).Get(ctx, cmName, metav1.GetOptions{})
		if err != nil {
			return nil, err
		}
		data, found, err := unstructured.NestedString(cm.Object, "data", InstallationKey)
		if err != nil || !found {
			return nil, fmt.Errorf("ConfigMap %s/%s: no key %s (%v)", InstallationNamespace, cmName, InstallationKey, err)
		}
		return []byte(data), nil
	}
}
