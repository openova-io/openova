# CTL-345 — The flow endpoints answer only from the local store; check CTL-G12

## In plain words

**The problem today.** The flow canvas of a deployment has two sources. The API builds the picture from its own jobs store, but when the store has no rows it forwards the request to a separate flow server, and a background loop pushes a copy of every picture to that server every five seconds. The second path is a second system that can only drift from the first, and nothing on a running Sovereign proves that the first path alone is enough.

**What changes.** The snapshot and the stream of the flow canvas are built from the jobs store and nothing else; a deployment without rows gets an empty picture, and the stream waits for its first row. The forwarding code, the push loop, its client and the unused route for posting flow events are deleted, and a new gate check proves on the environment that the stream answers with a picture.

**Done means:**

- The flow snapshot and the flow stream of a deployment never call a flow server.
- A deployment the jobs store holds no row for gets an empty snapshot, and its stream sends that empty snapshot and then a full one as soon as a row is written.
- The API no longer pushes snapshots to a flow server, and the route POST /api/v1/flows/{deploymentId}/events is gone from the router, from the route list and from the mutating-route table.
- The gate check CTL-G12 is required: a gate run on the environment fails unless the flow stream of the deployment under test answers with a snapshot frame of that deployment.
- The size guard of the API handler package and the polling guard record the deleted code.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`GET /api/v1/flows/{deploymentId}/snapshot` and `GET /api/v1/flows/{deploymentId}/stream` of catalyst-api answer from the API's own jobs store and from nothing else. A deployment that the store holds no row for gets the empty snapshot `{"type":"snapshot"}`; its stream sends that frame and then stays open on the store's subscription, and sends a full snapshot after the first row is written. Without a jobs store both routes answer 503 `jobs-store-unavailable`. The proxy to the flow server (`openova_flow_proxy.go` and its test), the five-second push loop (`flow_emitter.go`) and its client (`internal/flowemit`) are deleted. The route `POST /api/v1/flows/{deploymentId}/events`, which only forwarded to the flow server and which the console never calls, is deleted with its line in the route list and its row in contract C9. The new gate check CTL-G12 of the acceptance suite opens the flow stream of the deployment under test and passes only when the first event is a snapshot of that deployment; its manifest entry is `required`.

## 3. The model (the law)
1. **One source.** `HandleFlowSnapshot` and `HandleFlowStream` read the jobs store (`h.jobsStore()`) through `flowSnapshotFromJobs` and nothing else. No code of catalyst-api opens a connection to a flow server, reads `OPENOVA_FLOW_SERVER_URL`, or pushes a snapshot anywhere.
2. **No rows.** `flowSnapshotOrEmpty(id)` returns the snapshot that `flowSnapshotFromJobs` builds, or `&flowSnapshotLocalMessage{Type: "snapshot"}` when that returns false. It is written as `{"type":"snapshot"}`: the struct omits empty fields, and the console's reducer reads an absent list as empty.
3. **The snapshot route.** 400 `deploymentId required` for an empty id; 503 `{"error":"jobs-store-unavailable"}` (through `writeJSON`, which adds `status` and `code`) without a jobs store; otherwise 200 with `flowSnapshotOrEmpty(id)` as JSON.
4. **The stream route.** 400 for an empty id; 503 `jobs-store-unavailable` without a jobs store; 500 `streaming not supported` when the writer cannot flush; otherwise `flowStreamLocal`. `flowStreamLocal` subscribes first, sends `flowSnapshotOrEmpty(id)` as the first `snapshot` frame, and after each coalesced change sends `flowSnapshotOrEmpty(id)` again. It no longer closes the stream when the store has no rows; it closes only when the client goes away, a write fails, or the change channel closes. The 15-second heartbeat stays.
5. **Deleted.** `internal/handler/flow_emitter.go`, the folder `internal/flowemit`, `internal/handler/openova_flow_proxy.go`, `internal/handler/openova_flow_proxy_test.go`; the fields `flowEmit`, `flowEmitMu` and `flowEmitters` of `Handler` and the line of `NewWithPDM` that sets `flowEmit`; the call `h.startFlowEmitLoop(dep.ID)` of the Phase-1 watch; the method `HandleFlowEvents` and its route, its line in `cmd/api/testdata/routes.golden` and its row in `docs/contracts/C9-mutating-routes.yaml`. The four paths are appended to `docs/ledger/deleted-paths.txt`.
6. **The gate check CTL-G12.** The file `tests/acceptance/sovereign/internal/suite/check_ctl_flow_stream.go` registers the check. It needs the run's console session and the deployment id (`cc.API`, `cc.Deploy.ID`); without either it fails. It sends `GET <console>/api/v1/flows/<deployment id>/stream` with the `catalyst_session` cookie and `Accept: text/event-stream`, and passes when: the status is 200; the `Content-Type` starts with `text/event-stream`; the first event that carries data, within 30 seconds, is named `snapshot`; its data is a JSON object with `"type":"snapshot"`; its `flow`, when present, has the deployment id as `id`; and every node has the deployment id as `flowId`. It closes the stream after the first event. It only reads.
7. **The manifest.** The entry `CTL-G12` of `docs/ledger/gates.yaml` moves from `state: not-built` to `state: required` and gains `implementation: tests/acceptance/sovereign/internal/suite/check_ctl_flow_stream.go`. No other field changes. Only CTL-345 may set it to required (rule 4 of `scripts/acceptance-gate.py`).
8. **Baselines.** `scripts/baselines/api-structure.json` and `scripts/baselines/polling.json` are written by their own guards (`--write-baseline`), which lower them for the deleted code. Neither is edited by hand.

	}
	res, err := client.Do(req)
	if err != nil {
		return fmt.Errorf("GET %s: %w", path, err)
	}
	defer func() { _ = res.Body.Close() }()
	ev["status"], ev["content_type"] = res.StatusCode, res.Header.Get("Content-Type")
	if res.StatusCode != http.StatusOK {
		b, _ := io.ReadAll(io.LimitReader(res.Body, 4096))
		return fmt.Errorf("GET %s: HTTP %d %s; want 200", path, res.StatusCode, api.Snippet(b))
	}
	if !strings.HasPrefix(res.Header.Get("Content-Type"), "text/event-stream") {
		return fmt.Errorf("GET %s: Content-Type %q; want text/event-stream", path, res.Header.Get("Content-Type"))
	}
	first, err := flowStreamFirstEvent(bufio.NewReader(io.LimitReader(res.Body, flowStreamMaxBytes)))
	if err != nil {
		if ctx.Err() != nil {
			return fmt.Errorf("GET %s: no event within %v", path, timeout)
		}
		return fmt.Errorf("GET %s: %w", path, err)
	}
	ev["event"] = first.name
	if first.name != "snapshot" {
		return fmt.Errorf("GET %s: the first event is %q; want snapshot", path, first.name)
	}
	var msg struct {
		Type string `json:"type"`
		Flow *struct {
			ID     string `json:"id"`
			Status string `json:"status"`
		} `json:"flow"`
		Nodes []struct {
			ID     string `json:"id"`
			FlowID string `json:"flowId"`
		} `json:"nodes"`
	}
	if err := json.Unmarshal([]byte(first.data), &msg); err != nil {
		return fmt.Errorf("GET %s: the data of the snapshot event is not a JSON object: %s", path, api.Snippet([]byte(first.data)))
	}
	ev["type"], ev["nodes"], ev["has_flow"] = msg.Type, len(msg.Nodes), msg.Flow != nil
	if msg.Type != "snapshot" {
		return fmt.Errorf("GET %s: the snapshot event has type %q; want snapshot", path, msg.Type)
	}
	if msg.Flow != nil {
		ev["flow_status"] = msg.Flow.Status
		if msg.Flow.ID != dep {
			return fmt.Errorf("GET %s: the snapshot is of flow %q; want the deployment %q", path, msg.Flow.ID, dep)
		}
	}
	for _, n := range msg.Nodes {
		if n.FlowID != dep {
			return fmt.Errorf("GET %s: node %q has flowId %q; want the deployment %q", path, n.ID, n.FlowID, dep)
		}
	}
	return nil
}

// flowStreamFirstEvent returns the first event of the stream that carries
// data. Comment lines (": ...") and fields other than event and data are
// skipped; several data lines are joined with a newline.
func flowStreamFirstEvent(r *bufio.Reader) (flowStreamEvent, error) {
	name, data, hasData := "", []string{}, false
	for {
		line, err := r.ReadString('\n')
		if err != nil {
			if err == io.EOF {
				return flowStreamEvent{}, errors.New("the stream ended before its first event")
			}
			return flowStreamEvent{}, err
		}
		line = strings.TrimRight(line, "\r\n")
		switch {
		case line == "":
			if hasData {
				if name == "" {
					name = "message"
				}
				return flowStreamEvent{name: name, data: strings.Join(data, "\n")}, nil
			}
			name = ""
		case strings.HasPrefix(line, ":"):
		case strings.HasPrefix(line, "event:"):
			name = strings.TrimSpace(strings.TrimPrefix(line, "event:"))
		case strings.HasPrefix(line, "data:"):
			data, hasData = append(data, strings.TrimPrefix(strings.TrimPrefix(line, "data:"), " ")), true
		}
	}
}
