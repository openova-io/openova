# CMP-067 — The kit's own workloads pass the enforced policies, and a guard proves it on every pull request

## In plain words

**The problem today.** No check of the repository renders the kit the way Flux installs it and asks whether the policies that enforce after the bootstrap window admit what it renders. Three defects in two days passed every check and showed only on a running Sovereign: probes missing on the DNS DaemonSet, a sidecar without probes in the OpenBao CSI provider, and a policy whose engine controller could not read the kind it matches. Today ten more workloads of the kit would be refused.

**What changes.** A tree guard renders every release of the kit with its sub-charts, postRenderers and labels, judges it with the engine's own command-line tool against the enforcing policies and their exceptions, and checks the controllers' permissions from the same render. The refused workloads are repaired: three named exceptions, probes on the EVS CSI driver, the upstream Gitea test off, and the Sigstore cleanup hook through a Harbor proxy with requests.

**Done means:**

- The tree-guards step kit-policies is green on the pull request, and run on the base of the pull request it names the ten refused workloads.
- The same guard, run on the trees just before the three earlier repairs, names the DNS DaemonSet, the OpenBao CSI provider, and the reports controller without access to PersistentVolumes.
- The syft-grype CronJob is the one dated row of the guard's gap register, and a row whose object is no longer rendered or no longer refused fails the guard.
- Every container of the EVS CSI node DaemonSet and controller Deployment declares a liveness and a readiness probe, and the chart's own test fails without them.
- The Gitea chart renders no upstream connection test Pod, and the Sigstore cleanup hook pulls a pinned image through a Harbor proxy project with CPU and memory requests.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A new tree guard, `tools/guards/cmd/kit-policies`, runs in `.github/workflows/tree-guards.yaml` on every pull request. It renders every HelmRelease of the kit (`clusters/_template/bootstrap-kit/`) as Flux installs it, with the values its slot gives it, upstream sub-charts and their sidecars included, applies the release's postRenderers and helm-controller's origin labels, and judges the render with the Kyverno CLI of the engine (v1.19.2, checksum-verified) against the policies that enforce after the bootstrap window and the PolicyExceptions the engine honours. From the same render it checks that every kind a policy of `policies.kyverno.io` matches or looks up is granted to the Kyverno controller that acts on it. On this change it prints `0 finding(s)` with one known row, the syft-grype CronJob of `tools/guards/cmd/kit-policies/known-gaps.json`, retired by FND-193. The workloads it refuses on `main` today are repaired in the same change: three PolicyExceptions in the namespace `catalyst-policy-exceptions`, probes on every container of the EVS CSI driver with a chart test, the upstream Gitea connection test switched off, and the Sigstore post-delete hook through the Harbor proxy project `proxy-dockerhub` with requests.

## 3. The model (the law)
1. **What is judged.** Every HelmRelease of the kit, rendered with the kit's substitution from `tests/fixtures/variables/today.env`, with `SOVEREIGN_CONSUME=local` (the hand-over value that closes the bootstrap window) and `QA_FIXTURES_ENABLED=false` laid over it; the chart with its sub-charts; the release's postRenderers; helm-controller's origin labels (not on hooks); a test hook only when the release enables its tests and its `spec.test.filters` do not leave the hook out (helm-controller hands them to Helm's release testing, which never creates a hook they leave out). The guard sets `QA_FIXTURES_ENABLED=false` itself: `today.env` enables the QA matrix's fixtures, one of which is a QA policy that refuses falco, and those fixtures are not the kit's workloads.
2. **With what.** The Kyverno CLI whose version is the `appVersion` of `platform/kyverno/chart/Chart.yaml`; another version stops the guard. The mutating policies are applied first, then every ClusterPolicy rule that enforces and every ValidatingPolicy that denies, with the PolicyExceptions the engine honours (`--enablePolicyException`, `--exceptionNamespace` of its admission controller).
3. **Permissions.** For every policy of `policies.kyverno.io`, each kind it matches or looks up is granted (get, list, watch) to the controller that evaluates it, read from the ClusterRoles of the render bound to that controller's ServiceAccount, the roles they aggregate (`rbac.kyverno.io/aggregate-to-<controller>`) and the built-in `view`, with the tables CONTROLLERS and MATCHERS of `platform/kyverno-policies/chart/tests/apicall-rbac-correspondence.sh`. A legacy ClusterPolicy (as `platform/crossplane-claims/chart/templates/policies/userAccess-boundary.yaml`) is not judged by this check; the README line says so.
4. **The gap register.** A refusal is a finding unless a row of `known-gaps.json` names it (object, policy, reason, day, the package that retires it). A row whose object is no longer rendered or no longer refused is a finding, so a row retires itself. The file holds one row: the CronJob `syft-grype/syft-grype-bp-syft-grype`, refused by `harbor-proxy-pull`, dated 2026-11-26, retired by FND-193, which removes the chart.
5. **Every rule can fail.** The tests of the guard hold one failing case per rule. The render tests need bash, helm, yq, kubectl and the Kyverno CLI; they skip without them, unless `KIT_POLICIES_TOOLS=required`, which the tree-guards step sets.
6. **Upstream charts without a value for the missing piece get a named exception.** One PolicyException of `policies.kyverno.io/v1` each, in `catalyst-policy-exceptions`, for one policy and the named workloads only, its comment naming the upstream chart and version: crossplane 2.4.3 (`probes-present`, Deployments `crossplane` and `crossplane-rbac-manager`), external-secrets 0.10.7 (`probes-present`, Deployments `external-secrets`, `external-secrets-webhook`, `external-secrets-cert-controller`), and opentelemetry-operator 0.61.0 (`probes-present`, Deployment `opentelemetry-operator`). The test Pod `openbao-server-test` of openbao 0.30.7 gets none: slot 08 excludes it by `spec.test.filters` (SEC-162), so it is never created (point 1).
7. **First-party charts are repaired.** Every container of DaemonSet `csi-evs-node` and Deployment `csi-evs-controller` declares a livenessProbe and a readinessProbe. The CSI sidecars serve their health on `--http-endpoint` (node: port 9811, on the node, as the DaemonSet runs with hostNetwork; controller: ports 8080 to 8083 in the Pod), the `liveness-probe` sidecars are probed on their own listener, and `evs-csi-plugin` gains a readinessProbe. `platform/huawei-evs-csi/chart/tests/probes-present.sh` fails when a container lacks either.
8. **Upstream values that exist are used.** `gitea.test.enabled: false` switches off the upstream test Pod `gitea-test-connection` (busybox:latest, no requests); the chart's own function test stays the release's test. `policy-controller.leasescleanup` gives the post-delete hook `leases-cleanup` the image `harbor.openova.io/proxy-dockerhub/alpine/k8s:1.31.4` and requests of 10m CPU and 32Mi memory.
9. **The hook image is one the platform serves.** The hook runs `/bin/sh -c kubectl ...`, so it needs a shell and kubectl. `alpine/k8s:1.31.4` through `proxy-dockerhub` is the image the kit's other kubectl hooks use. It is not routed through `proxy-chainguard`: the registry `harbor.openova.io` has no such project (field 4), so a pull before the hand-over would fail.
10. **Nothing else moves.** No chart `version:` line changes (CI writes them), no policy changes, no Python line is added.

+#!/usr/bin/env bash
+# probes-present.sh - every container of the EVS CSI driver declares a
+# livenessProbe and a readinessProbe (CMP-067). The policy probes-present
+# enforces after the bootstrap window and refuses a DaemonSet or a Deployment
+# with a container that lacks either; tools/guards/cmd/kit-policies judges the
+# whole kit, this test holds the chart by itself.
+#
+# It renders the chart twice, as kit slot 55b enables it (enabled=true, no
+# snapshot class) and with the snapshot class on (the csi-snapshotter sidecar),
+# and compares, for the DaemonSet csi-evs-node and the Deployment
+# csi-evs-controller, the names of their containers with the expected list and
+# the names of the containers without both probes with the empty list. A probe
+# counts when it is a non-empty object, as the policy counts it.
+#
+# Usage:
+#   bash probes-present.sh           the chart above this file
+#   bash probes-present.sh <chart>   that chart directory
+#
+# Exit code: 0 pass. 1 a render failed or a list differs.
+# Needs helm and yq (mikefarah v4).
+set -euo pipefail
+export LC_ALL=C
+
+CHART="${1:-$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)}"
+TAG="[probes-present]"
+TMP="$(mktemp -d)"
+trap 'rm -rf "$TMP"' EXIT
+rc=0
+
+# names <render> <kind> <name> <filter>: the container names of that workload,
+# one line, space separated; the filter selects containers.
+names() {
+  K="$2" N="$3" yq ea -N "[select(.kind == strenv(K) and .metadata.name == strenv(N))] | .[0] | .spec.template.spec.containers[] | $4 | .name" "$1" | tr '\n' ' ' | sed 's/ $//'
+}
+
+# check <label> <render> <kind> <name> <expected container names>
+check() {
+  local got lacking
+  got="$(names "$2" "$3" "$4" '.')"
+  # A missing probe is read as {} (yq gives a missing key no length to compare).
+  lacking="$(names "$2" "$3" "$4" 'select(((.livenessProbe // {}) | length) == 0 or ((.readinessProbe // {}) | length) == 0)')"
+  if [ "$got" != "$5" ]; then
+    echo "$TAG FAIL $1: $3/$4 has the containers '$got', want '$5'"
+    rc=1
+  elif [ -n "$lacking" ]; then
+    echo "$TAG FAIL $1: in $3/$4 these containers lack a livenessProbe or a readinessProbe: $lacking"
+    rc=1
+  else
+    echo "$TAG PASS $1: every container of $3/$4 ($got) declares both probes"
+  fi
+}
+
+render() {
+  if ! helm template t "$CHART" --set enabled=true "$@" > "$TMP/render.yaml" 2> "$TMP/err"; then
+    cat "$TMP/err"
+    echo "$TAG FAIL: the chart does not render with $*"
+    exit 1
+  fi
+}
+
+render --set volumeSnapshotClass.enabled=false
+check "slot 55b" "$TMP/render.yaml" DaemonSet csi-evs-node "evs-driver-registrar liveness-probe evs-csi-plugin"
+check "slot 55b" "$TMP/render.yaml" Deployment csi-evs-controller "csi-provisioner csi-attacher csi-resizer liveness-probe evs-csi-plugin"
+render --set volumeSnapshotClass.enabled=true
+check "snapshot class on" "$TMP/render.yaml" Deployment csi-evs-controller "csi-provisioner csi-attacher csi-resizer csi-snapshotter liveness-probe evs-csi-plugin"
+exit "$rc"

+	}

+// policySet is what the guard gives the CLI: the enforcing and the mutating
+// policies, and which rules enforce.
+type policySet struct {
+	docs []obj
+	// legacy: ClusterPolicy or Policy name -> rule name -> the rule validates with Enforce.
+	legacy map[string]map[string]bool
+	// cel: the ValidatingPolicy and NamespacedValidatingPolicy names whose validationActions hold Deny.
+	cel map[string]bool
+	// mutators: the MutatingPolicy and NamespacedMutatingPolicy names.

+// readPolicies reads the policies of the render. A policy whose action the
+// guard cannot read, or an enforcing kind the CLI cannot judge without a
+// registry, stops it.
+func readPolicies(objects []obj) (*policySet, error) {
+	ps := &policySet{legacy: map[string]map[string]bool{}, cel: map[string]bool{}, mutators: map[string]bool{}}
+	for _, o := range objects {
+		g, kind, name := group(str(o["apiVersion"])), str(o["kind"]), str(dig(o, "metadata", "name"))
+		switch {
+		case g == "kyverno.io" && (kind == "ClusterPolicy" || kind == "Policy"):
+			if dig(o, "spec", "validationFailureActionOverrides") != nil {
+				return nil, fmt.Errorf("%s %s sets validationFailureActionOverrides, which the guard does not read", kind, name)
+			}
+			spec := strings.ToLower(str(dig(o, "spec", "validationFailureAction")))
+			rules, enforces, mutates := map[string]bool{}, false, false
+			for _, r := range list(dig(o, "spec", "rules")) {
+				rn := str(dig(r, "name"))
+				if dig(r, "mutate") != nil {
+					mutates = true
+				}
+				if v, ok := dig(r, "validate").(obj); ok {
+					if v["failureActionOverrides"] != nil {
+						return nil, fmt.Errorf("%s %s rule %s sets failureActionOverrides, which the guard does not read", kind, name, rn)
+					}
+					action := strings.ToLower(str(v["failureAction"]))
+					if action == "" {
+						action = spec
+					}
+					rules[rn] = action == "enforce"
+					enforces = enforces || rules[rn]
+				}
+				if dig(r, "verifyImages") != nil && spec == "enforce" {
+					return nil, fmt.Errorf("%s %s rule %s verifies images with Enforce, which the guard cannot judge without the registry", kind, name, rn)
+				}
+			}
+			if enforces || mutates {
+				ps.legacy[name] = rules
+				if kind == "Policy" { // the CLI names a namespaced policy <namespace>/<name>
+					ps.legacy[str(dig(o, "metadata", "namespace"))+"/"+name] = rules
+				}
+				ps.docs = append(ps.docs, o)
+			}
+			if enforces {
+				ps.enforcing++
+			}
+			if mutates {
+				ps.mutating++
+			}
+		case g == "policies.kyverno.io" && (kind == "ValidatingPolicy" || kind == "NamespacedValidatingPolicy"):
+			if contains(stringList(dig(o, "spec", "validationActions")), "Deny") {
+				ps.cel[name] = true
+				ps.docs = append(ps.docs, o)
+				ps.enforcing++
+			}
+		case g == "policies.kyverno.io" && (kind == "ImageValidatingPolicy" || kind == "NamespacedImageValidatingPolicy"):
+			if contains(stringList(dig(o, "spec", "validationActions")), "Deny") {
+				return nil, fmt.Errorf("%s %s denies, and the guard cannot judge an image verification without the registry", kind, name)
+			}
+		case g == "policies.kyverno.io" && (kind == "MutatingPolicy" || kind == "NamespacedMutatingPolicy"):
+			ps.mutators[name] = true
+			ps.docs = append(ps.docs, o)
+			ps.mutating++
+		}
+	}
+	if ps.enforcing == 0 {
+		return nil, fmt.Errorf("the render holds no enforcing policy: nothing can be judged (is the window closed?)")
+	}
+	return ps, nil

+// honoured returns the PolicyExceptions the engine of the render honours: the
+// flags --enablePolicyException and --exceptionNamespace of the container of its
+// admission controller. Without the first flag the engine honours none; without
+// the second, every namespace.
+func honoured(objects []obj) ([]obj, error) {
+	var args []string
+	found := false
+	for _, o := range objects {
+		if str(o["kind"]) != "Deployment" || !isController(o, "admission-controller") {
+			continue
+		}
+		found = true
+		for _, c := range list(dig(o, "spec", "template", "spec", "containers")) {
+			args = append(args, stringList(dig(c, "args"))...)
+		}
+	}
+	if !found {
+		return nil, fmt.Errorf("the render holds no Kyverno admission controller (a Deployment labelled app.kubernetes.io/part-of=kyverno, app.kubernetes.io/component=admission-controller)")
+	}
+	enabled, ns, nsSet := false, "", false
+	for _, a := range args {
+		switch {
+		case a == "--enablePolicyException" || a == "--enablePolicyException=true":
+			enabled = true
+		case strings.HasPrefix(a, "--exceptionNamespace="):
+			ns, nsSet = strings.TrimPrefix(a, "--exceptionNamespace="), true
+		}
+	}
+	var out []obj
+	for _, o := range objects {
+		g := group(str(o["apiVersion"]))
+		if str(o["kind"]) != "PolicyException" || (g != "kyverno.io" && g != "policies.kyverno.io") || !enabled {
+			continue
+		}
+		if !nsSet || ns == "" || str(dig(o, "metadata", "namespace")) == ns {
+			out = append(out, o)
+		}
+	}
+	return out, nil

+// judge applies the policies of the render to every object of it with the CLI.
+// The CLI keeps the objects it is given in one fake cluster, which refuses two
+// objects of one identity, so the copies of an identity that a second release
+// renders are judged in a run of their own.
+func (e *env) judge(objects []obj) (*verdict, error) {
+	ps, err := readPolicies(objects)
+	if err != nil {
+		return nil, err
+	}
+	exceptions, err := honoured(objects)
+	if err != nil {

+	seen := map[string]int{}

+			continue
+		}

+		n := seen[id]
+		seen[id] = n + 1
+		if n == len(layers) {
+			layers = append(layers, nil)
+		}
+		layers[n] = append(layers[n], o)
+	}

+		}
+		for _, r := range results {
+			if f, ok := ps.refusal(r); ok {
+				v.refusals = append(v.refusals, f)
+			}
+		}
+	}

+// refusal: a fail or an error of an enforcing rule. A result of a legacy policy
+// (source kyverno) names its rule, an autogen rule with the prefix autogen- or
+// autogen-cronjob-; a fail of one of its mutate rules is not a refusal. Only
+// denying ValidatingPolicies are given to the CLI. A fail of a policy the guard
+// cannot map to one it gave is a refusal.
+func (ps *policySet) refusal(r result) (refusal, bool) {
+	if (r.Result != "fail" && r.Result != "error") || len(r.Resources) == 0 {
+		return refusal{}, false
+	}

+	if rules, ok := ps.legacy[r.Policy]; ok && r.Source == "kyverno" {
+		base := strings.TrimPrefix(strings.TrimPrefix(r.Rule, "autogen-cronjob-"), "autogen-")
+		enforcing = rules[base]
+	} else if ps.mutators[r.Policy] && !ps.cel[r.Policy] {
+		enforcing = false
+	}
+	if !enforcing {
+		return refusal{}, false
+	}
+	res := r.Resources[0]
+	return refusal{Kind: res.Kind, Namespace: res.Namespace, Name: res.Name, Policy: r.Policy, Rule: r.Rule, Message: oneLine(r.Message)}, true

+// apply runs the CLI once and returns the results of its report. The CLI
+// applies the mutating policies first and validates what they return, as the
+// admission chain does; --output keeps the mutated objects off the report.
+func (e *env) apply(layer int, policies, objects, exceptions []obj) ([]result, error) {
+	dir := filepath.Join(e.work, fmt.Sprintf("judge-%d", layer))
+	if err := os.MkdirAll(dir, 0o700); err != nil {
+		return nil, err
+	}
+	files := map[string][]obj{"policies.yaml": policies, "resources.yaml": objects, "exceptions.yaml": exceptions}
+	for name, docs := range files {
+		var b bytes.Buffer
+		for _, d := range docs {
+			j, err := json.Marshal(d)
+			if err != nil {
+				return nil, err
+			}
+			b.WriteString("---\n")
+			b.Write(j)
+			b.WriteString("\n")
+		}
+		if err := os.WriteFile(filepath.Join(dir, name), b.Bytes(), 0o600); err != nil {
+			return nil, err
+		}
+	}
+	args := []string{"apply", filepath.Join(dir, "policies.yaml"), "--resource", filepath.Join(dir, "resources.yaml"),
+		"--policy-report", "--output-format", "json", "--output", filepath.Join(dir, "mutated.yaml"),
+		"--remove-color", "--continue-on-fail"}
+	if len(exceptions) > 0 {
+		args = append(args, "--exception", filepath.Join(dir, "exceptions.yaml"))
+	}
+	// The CLI exits 1 when a result fails, and writes no report when there is
+	// no result at all (exit 0); the report decides. A failed run without a
+	// report is an error.
+	stdout, runErr := e.cmd(nil, "", nil, e.kyverno, args...)
+	i := bytes.LastIndex(stdout, []byte(`{"kind":"ClusterReport"`))
+	if i < 0 && runErr == nil {
+		return nil, nil
+	}
+	if i < 0 {
+		return nil, fmt.Errorf("the Kyverno CLI wrote no report (run %d of %d objects): %v; its output: %s", layer, len(objects), runErr, firstLine(strings.ReplaceAll(string(stdout), "Warning:", "WARNING")))
+	}
+	var report struct {
+		Results []result `json:"results"`
+	}
+	if err := json.Unmarshal(bytes.TrimSpace(stdout[i:]), &report); err != nil {
+		return nil, fmt.Errorf("the report of the Kyverno CLI cannot be read: %v", err)
+	}
+	return report.Results, nil
+}

+// the policies that enforce after the bootstrap window, and that every kind a
+// policy of the kit matches or looks up is granted to the Kyverno controller
+// that evaluates it (CMP-067). Three defects passed every other check and were
+// refused only on a running Sovereign: the dnsdist probes of bp-powerdns
+// (pull request 8788), the agent sidecar of the OpenBao CSI provider
+// (8852) and the reports controller without read on PersistentVolumes (8854).
+//
+// The render (render.go). Every HelmRelease of the kit
+// (clusters/_template/bootstrap-kit/kustomization.yaml of -root) is rendered
+// the way Flux installs it: the document substituted as Flux's post-build step
+// substitutes the kit (tools/guards/cmd/image-path subst) with the value set
+// -vars and, laid over it, SOVEREIGN_CONSUME=local, the hand-over value that
+// closes the window, so every policy renders with the action it has after the
+// window, and QA_FIXTURES_ENABLED=false (afterWindow in render.go); a
+// suspended release skipped; the chart rendered with its
+// dependencies, upstream sub-charts and their sidecars included, with the
+// release's name, target namespace and values (valuesFrom names objects of the
+// cluster and is not read); then the release's postRenderers (kustomize) and
+// helm-controller's origin labels; the release namespace on an object of a
+// namespaced kind without one. Helm 3 renders the hooks apart from the release
+// manifest, so a hook gets neither the postRenderers nor the labels, as on a
+// cluster; a test hook is kept only when the release enables its tests
+// (spec.test.enable), the only case in which helm-controller creates it.

+// The verdict (judge.go). The policies are those of the render: every
+// ClusterPolicy or Policy with a validate rule whose action is Enforce, every

+// report prints every finding and every refusal the register holds, and
+// returns the number of findings. It sets verdict.known.
+func report(out io.Writer, releases []release, v *verdict, register []gapRow, perms *permissions) int {
+	origin := map[string][]string{}
+	for _, r := range releases {
+		where := fmt.Sprintf("%s (release %s/%s, chart %s)", r.file, r.namespace, r.name, r.chart)
+		for _, o := range r.objects {
+			k := key(str(o["kind"]), str(dig(o, "metadata", "namespace")), str(dig(o, "metadata", "name")))
+			if !contains(origin[k], where) {
+				origin[k] = append(origin[k], where)
+			}
+		}
+	}
+	var lines []string
+	held := make([]bool, len(register))
+	for _, f := range v.refusals {
+		where := strings.Join(origin[f.key()], "; ")
+		if where == "" {
+			where = "an object the render does not name"
+		}
+		row := -1
+		for i, g := range register {
+			if g.Kind == f.Kind && g.Namespace == f.Namespace && g.Name == f.Name && g.Policy == f.Policy {
+				row = i
+			}
+		}
+		if row >= 0 {
+			held[row] = true
+			v.known++
+			say(out, "kit-policies: KNOWN %s %s/%s, refused by %s, in the register (since %s, retired by %s): %s\n",
+				f.Kind, f.Namespace, f.Name, f.Policy, register[row].Since, register[row].RetiredBy, where)
+			continue
+		}
+		lines = append(lines, fmt.Sprintf("kit-policies: REFUSED %s %s/%s by %s: %s; rendered by %s", f.Kind, f.Namespace, f.Name, f.label(), f.Message, where))
+	}
+	for i, g := range register {
+		if held[i] {
+			continue
+		}
+		if len(origin[key(g.Kind, g.Namespace, g.Name)]) == 0 {
+			lines = append(lines, fmt.Sprintf("kit-policies: GAP ROW %s %s/%s (%s): the render holds no such object; delete the row from %s", g.Kind, g.Namespace, g.Name, g.Policy, gapsFile))
+		} else {
+			lines = append(lines, fmt.Sprintf("kit-policies: GAP ROW %s %s/%s (%s): the policy admits it; delete the row from %s", g.Kind, g.Namespace, g.Name, g.Policy, gapsFile))
+		}
+	}
+	lines = append(lines, perms.findings...)
+	sort.Strings(lines)
+	for _, l := range lines {
+		say(out, "%s\n", l)
+	}
+	return len(lines)
+}

+// controllerRules: the rules granted to the ServiceAccount of a controller's
+// Deployment; false when the render holds no such Deployment.
+func controllerRules(objects []obj, component string) ([]rule, bool) {
+	sa, ns, found := "", "", false
+	for _, o := range objects {
+		if str(o["kind"]) == "Deployment" && isController(o, component) {
+			sa, ns, found = str(dig(o, "spec", "template", "spec", "serviceAccountName")), str(dig(o, "metadata", "namespace")), true
+		}
+	}
+	if !found {
+		return nil, false
+	}
+	if sa == "" {
+		sa = "default"
+	}
+	roles := map[string]obj{}
+	for _, o := range objects {
+		if str(o["kind"]) == "ClusterRole" {
+			roles[str(dig(o, "metadata", "name"))] = o
+		}
+	}
+	var out []rule
+	for _, o := range objects {
+		if str(o["kind"]) != "ClusterRoleBinding" || str(dig(o, "roleRef", "kind")) != "ClusterRole" {
+			continue
+		}
+		bound := false
+		for _, s := range list(o["subjects"]) {
+			if str(dig(s, "kind")) == "ServiceAccount" && str(dig(s, "name")) == sa && str(dig(s, "namespace")) == ns {
+				bound = true
+			}
+		}
+		if bound {
+			out = append(out, roleRules(str(dig(o, "roleRef", "name")), roles)...)
+		}
+	}
+	return out, true

+// roleRules: the rules of a ClusterRole and of every ClusterRole its
+// aggregationRule selects; view is the built-in role; a role the render does
+// not hold grants nothing.
+func roleRules(name string, roles map[string]obj) []rule {
+	var selectors []any
+	var out []rule
+	if role, ok := roles[name]; ok {
+		out = rulesOf(role)
+		selectors = list(dig(role, "aggregationRule", "clusterRoleSelectors"))
+	} else if name == "view" {
+		out = append(out, builtinView...)
+		selectors = []any{obj{"matchLabels": toAny(viewLabel)}}
+	}
+	for _, other := range roles {
+		labels := stringMap(dig(other, "metadata", "labels"))
+		for _, s := range selectors {
+			if selects(s, labels) {
+				out = append(out, rulesOf(other)...)
+				break
+			}
+		}
+	}
+	return out
+}

+func rulesOf(role obj) []rule {
+	var out []rule
+	for _, r := range list(role["rules"]) {
+		if len(list(dig(r, "resourceNames"))) > 0 {
+			continue // a grant on named objects grants no list or watch
+		}
+		out = append(out, rule{groups: stringList(dig(r, "apiGroups")), resources: stringList(dig(r, "resources")), verbs: stringList(dig(r, "verbs"))})
+	}
+	return out
+}

+// selects: a label selector of matchLabels and matchExpressions (In, NotIn,
+// Exists, DoesNotExist). An empty selector selects nothing here: an
+// aggregationRule with one would select every ClusterRole.
+func selects(sel any, labels map[string]string) bool {
+	ml, me := stringMap(dig(sel, "matchLabels")), list(dig(sel, "matchExpressions"))
+	if len(ml) == 0 && len(me) == 0 {
+		return false
+	}
+	for k, v := range ml {
+		if labels[k] != v {
+			return false
+		}
+	}
+	for _, x := range me {
+		k, op, vals := str(dig(x, "key")), str(dig(x, "operator")), stringList(dig(x, "values"))
+		v, has := labels[k]
+		switch op {
+		case "In":
+			if !has || !contains(vals, v) {
+				return false
+			}
+		case "NotIn":
+			if has && contains(vals, v) {
+				return false
+			}
+		case "Exists":
+			if !has {
+				return false
+			}
+		case "DoesNotExist":
+			if has {
+				return false
+			}
+		default:
+			return false
+		}
+	}
+	return true
+}

+func granted(rules []rule, groupName, resource, verb string) bool {
+	for _, r := range rules {
+		if (contains(r.groups, groupName) || contains(r.groups, "*")) &&
+			(contains(r.resources, resource) || contains(r.resources, "*")) &&
+			(contains(r.verbs, verb) || contains(r.verbs, "*")) {
+			return true
+		}
+	}
+	return false
+}

+// allStrings: every string of an object, depth first.
+func allStrings(v any) []string {

+	case string:
+		return []string{x}
+	case obj:
+		var out []string
+		keys := make([]string, 0, len(x))
+		for k := range x {
+			keys = append(keys, k)
+		}
+		sort.Strings(keys)
+		for _, k := range keys {
+			out = append(out, allStrings(x[k])...)
+		}
+		return out
+	case []any:
+		var out []string
+		for _, e := range x {
+			out = append(out, allStrings(e)...)
+		}
+		return out
+	}
+	return nil
+}

+func stringMap(v any) map[string]string {
+	out := map[string]string{}
+	m, _ := v.(obj)
+	for k, x := range m {
+		if s, ok := x.(string); ok {
+			out[k] = s
+		}
+	}
+	return out
+}

+func toAny(m map[string]string) obj {
+	out := obj{}
+	for k, v := range m {
+		out[k] = v
+	}
+	return out
