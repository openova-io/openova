# FND-092 — Stop building the Sandbox images

## In plain words

**The problem today.** The Sandbox product was withdrawn, but three build jobs still build its images whenever the controller code changes. Each build ends with an automatic commit that writes a new image tag into the Sandbox chart. The removal of the Sandbox code cannot go on cleanly while a job keeps rebuilding it.

**What changes.** The three build jobs are removed and recorded as deleted. The tests of the two Sandbox code folders, which only those jobs ran, move to the general test job until the folders themselves are deleted.

**Done means:**

- No build job for a Sandbox image exists.
- No automatic commit changes an image tag of the Sandbox chart any more.
- The three removed files are on the list of deleted paths, so a guard fails if one of them comes back.
- The build job of the model gateway's bridge sidecar, whose name also holds the word, is still there and unchanged.
- The tests of the two Sandbox code folders still run on a pull request that changes them.
- The guard on the controller build jobs checks six jobs and passes.

The rest of this ticket is the exact instruction for the model that does the work.
