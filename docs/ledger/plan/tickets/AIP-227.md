# AIP-227 — Console read path: reverse proxy /api/v1/ops/* in catalyst-api

## In plain words

**The problem today.** The operations-records service has console routes for incidents and judgements, but a browser cannot reach them: they listen on an address that only catalyst-api may call, and they trust identity headers that someone must set. catalyst-api has no route that checks the session and forwards the request, so the console has nothing to read.

**What changes.** catalyst-api serves the five routes under /api/v1/ops and forwards them to the service with the Organization, the user and the tier taken from the verified session. Headers a caller sends to claim an identity are removed, and agent tokens are refused.

**Done means:**

- A request under /api/v1/ops from a session of an Organization reaches the service with that Organization, whatever identity headers the caller sent.
- A sovereign-admin whose session names no Organization reaches the service with an empty Organization and the tier sovereign-admin, the view of every Organization.
- An agent token gets 403 on every route under /api/v1/ops, and nothing is forwarded.
- A request without a session gets 401, and a session that names no Organization and is not a sovereign-admin gets 403.
- An event of the incident stream reaches the browser while the stream stays open.
- The actions route is listed in the mutating-route table as a database write.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. **Paths.** Four new files, each the block of the same name in this ticket: `internal/opsproxy/opsproxy.go`, `internal/opsproxy/opsproxy_test.go`, `cmd/api/routes_ops.go`, `cmd/api/routes_ops_test.go` (all under `products/catalyst/bootstrap/api/`). Three edits: one line in `cmd/api/routes.go`, five lines in `cmd/api/testdata/routes.golden`, one entry in `docs/contracts/C9-mutating-routes.yaml`. `cmd/api/main.go`, `internal/handler/**`, `go.mod` and `go.sum` do not change: the router is built in `routes.go`, and `scripts/check-api-structure.py` refuses any growth of `main()` and of `internal/handler`.
2. **Routes.** `opsproxy.Routes` names exactly the five routes of `products/ops-records/internal/api/api.go` (its `Register`). `registerSessionOps` in `routes_ops.go` registers each with `rg.Method` on one `*opsproxy.Proxy`, as the last registration of the session group in `buildRouter`. They therefore run behind `jobauth.RequireSessionOrJob`, the Organization scope guard `h.OrgScopeGuard` and `agenttoken.Restrict` (chain 2 of the golden file). No other path is forwarded: there is no catch-all mount.
3. **Identity.** For a request that reaches the proxy:
   - no session claims, or claims without an e-mail: 401 `unauthenticated`;
   - claim `typ` `agent` (any case, `agenttoken.Type`), on every method: 403 `agent-token-forbidden`. `agenttoken.Restrict` lets an agent token `GET`, so the proxy refuses it itself;
   - a session with an Organization (claim `org` or `org_id`, read as `auth.Claims.Org`, trimmed and lower-cased): that Organization, and its tier named as `ops-records` names it: `viewer`, `developer`, `operator`, `admin` and `owner` as they are; `org-admin` (`auth.OrgScopedTier`, the administrator of its own Organization) as `admin`; any other value, empty included, as `viewer`;
   - a session without an Organization: the empty Organization and the tier `sovereign-admin` when `lifecycle.SovereignAdmin` holds (realm role `catalyst-admin` or `catalyst-owner`, or tier `admin` or `owner`) and the tier is not `org-admin`; otherwise 403 `no-organization`. A forwarded empty Organization is the view of every Organization, so it is never sent for anyone else.
4. **Headers.** The forwarded request carries `x-openova-organization` (sent even when empty), `x-openova-user` (the session's e-mail, trimmed) and `x-openova-tier`. Every request header whose canonical name starts with `X-Openova-`, `Cookie`, `Authorization` and the query parameter `access_token` (the three ways a session reaches catalyst-api, `auth.Config.ReadSessionToken`) are removed first. Method, path, every other query parameter and the body are forwarded unchanged.
5. **Stream.** `httputil.ReverseProxy` with `FlushInterval: -1`: every write of the answer is flushed at once, so a server-sent event reaches the browser while the stream stays open. (The standard library already flushes a `text/event-stream` answer at once; `-1` keeps it so for any other type.)
6. **Address.** `CATALYST_OPS_RECORDS_URL` (`opsproxy.URLEnv`), read once when the router is built; unset or blank, `http://ops-records.ops-records.svc.cluster.local:8081` (`opsproxy.DefaultURL`): the namespace `ops-records`, the Service `ops-records`, and the console port `:8081`, the default of `OPS_RECORDS_CONSOLE_LISTEN`. An address that is not `http` or `https` with a host: every request is answered 503 `ops-records-unconfigured` after the identity checks. An unreachable `ops-records`: 502 `ops-records-unavailable`. Errors have the form `{"error": "<code>", "detail": "<text>"}`.
7. **Contract C9.** The actions route is one entry: `{component: catalyst-api, method: POST, path: "/api/v1/ops/incidents/{id}/actions", today: D, writeClass: database, operation: "", disposition: keep, batch: "-", package: "-", done: true}`. The four `GET` routes change no state and are not listed. `open_cluster_writers` does not move.
8. **Organization-console sessions stay where they are.** A session minted on an Organization's own console (tier `org-admin`), or any request on an Organization console host, is confined by the scope guard's deny-by-default list (`orgSafePathPrefixes` in `internal/handler/org_scope.go`), which does not name `/api/v1/ops`: such a request gets 403 `org-scoped-forbidden` before the proxy, as every unlisted path does today. This ticket does not change the list (`internal/handler` may not grow). An agent token is Organization-scoped too, so it meets that 403 first; the proxy's own refusal holds if the list ever names the path.
9. **Every example value is a test value.** The Organization slugs `acme` and `other`, the e-mail addresses under `.test`, the strings `a.b.c` and `catalyst_session=x`, the incident `i-1` and the addresses of the `httptest` servers are fixed test values, not systems and not secrets.

// Package opsproxy forwards the console routes /api/v1/ops/* of catalyst-api to
// the operations-records service (products/ops-records, its package
// internal/api).
//
// The browser never calls ops-records. It calls catalyst-api at the same
// paths. The session route group has already verified the session, applied
// the Organization scope guard and agenttoken.Restrict. The proxy then:
//
//   - refuses a request without session claims or without an e-mail: 401
//     unauthenticated;
//   - refuses an agent token (claim typ "agent") on every method: 403
//     agent-token-forbidden. agenttoken.Restrict lets GET pass, so the proxy
//     refuses it itself;
//   - refuses a session that names no Organization and is not a
//     sovereign-admin (lifecycle.SovereignAdmin): 403 no-organization;
//   - removes every x-openova-* header, Cookie, Authorization and the query
//     parameter access_token the caller sent, and sets three headers itself:
//     x-openova-organization (the session's Organization; empty for a
//     sovereign-admin, who sees every Organization), x-openova-user (the
//     session's e-mail) and x-openova-tier (the session's tier as
//     ops-records names it, see tierOf);
//   - flushes every write of the answer at once, so the server-sent events of
//     GET /api/v1/ops/stream arrive as ops-records sends them;
//   - answers 502 ops-records-unavailable when ops-records cannot be reached,
//     and 503 ops-records-unconfigured when its address cannot be read.
//
// The address of ops-records is the environment variable URLEnv; unset, it is
// DefaultURL, the console port of the in-cluster Service.
package opsproxy

import (
	"encoding/json"
	"fmt"
	"log/slog"
	"net/http"
	"net/http/httputil"
	"net/url"
	"os"
	"strings"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/agenttoken"
	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/auth"
	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/lifecycle"
)

const (
	// URLEnv names the base address of the console routes of ops-records.
	URLEnv = "CATALYST_OPS_RECORDS_URL"
	// DefaultURL is the console port of the Service ops-records in the
	// namespace ops-records.
	DefaultURL = "http://ops-records.ops-records.svc.cluster.local:8081"

	// The identity headers ops-records reads.
	HeaderOrganization = "x-openova-organization"
	HeaderUser         = "x-openova-user"
	HeaderTier         = "x-openova-tier"

	// TierSovereignAdmin is the tier of the view of every Organization.
	TierSovereignAdmin = "sovereign-admin"
)

// Route is one console route of ops-records.
type Route struct{ Method, Path string }

// Routes are the routes catalyst-api forwards, exactly those of ops-records.
var Routes = []Route{
	{http.MethodGet, "/api/v1/ops/incidents"},
	{http.MethodGet, "/api/v1/ops/incidents/{id}"},
	{http.MethodPost, "/api/v1/ops/incidents/{id}/actions"},
	{http.MethodGet, "/api/v1/ops/judgements"},
	{http.MethodGet, "/api/v1/ops/stream"},
}

// sessionTiers are the session tiers ops-records accepts as they are.
var sessionTiers = []string{"viewer", "developer", "operator", "admin", "owner"}

// Proxy serves the routes of Routes.
type Proxy struct {
	rp     *httputil.ReverseProxy
	broken error // the address cannot be read; every request answers 503
	log    *slog.Logger
}

// FromEnv returns the proxy to the address of URLEnv, or of DefaultURL.
func FromEnv(log *slog.Logger) *Proxy {
	base := strings.TrimSpace(os.Getenv(URLEnv))
	if base == "" {
		base = DefaultURL
	}
	return New(base, log)
}

// New returns the proxy to base, an http or https address.
func New(base string, log *slog.Logger) *Proxy {
	if log == nil {
		log = slog.Default()
	}
	p := &Proxy{log: log}
	target, err := url.Parse(base)
	if err == nil && ((target.Scheme != "http" && target.Scheme != "https") || target.Host == "") {
		err = fmt.Errorf("%q is not an http or https address", base)
	}
	if err != nil {
		p.broken = err
		log.Error("opsproxy: the address of ops-records cannot be read", "env", URLEnv, "error", err)
		return p
	}
	p.rp = &httputil.ReverseProxy{
		Rewrite:       func(pr *httputil.ProxyRequest) { pr.SetURL(target) },
		FlushInterval: -1,
		ErrorHandler: func(w http.ResponseWriter, r *http.Request, err error) {
			p.log.Warn("opsproxy: ops-records cannot be reached", "path", r.URL.Path, "error", err)
			writeError(w, http.StatusBadGateway, "ops-records-unavailable", "the operations records cannot be reached now")
		},
	}
	return p
}

// ServeHTTP checks the session and forwards the request with the identity
// headers it sets itself.
func (p *Proxy) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	claims := auth.ClaimsFromContext(r.Context())
	if claims == nil || strings.TrimSpace(claims.Email) == "" {
		writeError(w, http.StatusUnauthorized, "unauthenticated", "the operations records need a session")
		return
	}
	if strings.EqualFold(strings.TrimSpace(claims.Typ), agenttoken.Type) {
		writeError(w, http.StatusForbidden, "agent-token-forbidden", "an agent token cannot use the console routes of the operations records")
		return
	}
	org, tier, ok := identityOf(claims)
	if !ok {
		writeError(w, http.StatusForbidden, "no-organization", "this session names no Organization and is not a sovereign-admin")
		return
	}
	if p.broken != nil {
		writeError(w, http.StatusServiceUnavailable, "ops-records-unconfigured", "the address of the operations records cannot be read")
		return
	}
	out := r.Clone(r.Context())
	for name := range out.Header {
		if strings.HasPrefix(http.CanonicalHeaderKey(name), "X-Openova-") {
			out.Header.Del(name)
		}
	}
	out.Header.Del("Cookie")
	out.Header.Del("Authorization")
	if q := out.URL.Query(); q.Has("access_token") {
		q.Del("access_token")
		out.URL.RawQuery = q.Encode()
	}
	out.Header.Set(HeaderOrganization, org)
	out.Header.Set(HeaderUser, strings.TrimSpace(claims.Email))
	out.Header.Set(HeaderTier, tier)
	p.rp.ServeHTTP(w, out)
}

// identityOf returns the Organization and the tier of a session that is not
// an agent token. A session that names an Organization is confined to it; one
// that names none sees every Organization only when it is a sovereign-admin
// and not Organization-scoped.
func identityOf(c *auth.Claims) (org, tier string, ok bool) {
	org = strings.ToLower(strings.TrimSpace(c.Org))
	scoped := strings.EqualFold(strings.TrimSpace(c.Tier), auth.OrgScopedTier)
	if org == "" {
		if scoped || !lifecycle.SovereignAdmin(c) {
			return "", "", false
		}
		return "", TierSovereignAdmin, true
	}
	return org, tierOf(c.Tier), true
}

// tierOf names a session tier as ops-records does: a tier of sessionTiers as
// it is; the tier of an Organization-scoped session (auth.OrgScopedTier), the
// administrator of its own Organization, as admin; any other value as viewer,
// which only reads.
func tierOf(sessionTier string) string {
	t := strings.ToLower(strings.TrimSpace(sessionTier))
	if t == auth.OrgScopedTier {
		return "admin"
	}
	for _, known := range sessionTiers {
		if t == known {
			return t
		}
	}
	return "viewer"
}

func writeError(w http.ResponseWriter, status int, code, detail string) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(map[string]string{"error": code, "detail": detail})
}

// upstream records every request and answers 200; calls returns what it received.
func upstream(t *testing.T) (srv *httptest.Server, calls func() []seen) {
	t.Helper()
	var mu sync.Mutex
	var got []seen
	srv = httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {

		got = append(got, seen{r.Method, r.URL.Path, r.URL.RawQuery, string(body), r.Header.Clone()})
		mu.Unlock()
		w.WriteHeader(http.StatusOK)
	}))
	t.Cleanup(srv.Close)
	return srv, func() []seen { mu.Lock(); defer mu.Unlock(); return append([]seen(nil), got...) }
}

	w := httptest.NewRecorder()
	p.ServeHTTP(w, r)
	return w
