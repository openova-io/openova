# PRD-502 — Sandbox ledger

## In plain words

**The problem today.** The open-banking product reaches core banking only through its ledger port. Today the only thing that serves that port is a small test double inside the conformance kit, which runs in the same process as the test. There is no test bank that the product, its conformance runs and its partners can call over the network, so no end-to-end test of the product has a ledger to talk to.

**What changes.** The product gains a sandbox ledger: a package that serves all fourteen operations of the port over three made-up customers and five accounts, and a program that serves it over TLS with a health service and prints the kit's description of its data. The conformance kit passes against it, in process and over TLS.

**Done means:**

- The sandbox holds three customers and five accounts, all made up, and each account's transactions add up to its balance.
- The conformance kit run against the sandbox reports 41 of 41 checks passed and 14 of 14 operations called, both in process and against the program over TLS.
- The program prints the kit's fixture of its data set, and the kit reads that fixture with no unknown key.
- A renewed certificate is served to new connections without a restart, and a half-written certificate file does not stop the server.
- A payment made on the sandbox shows in its reads: an immediate one as a transaction and a lower balance, a scheduled one and a standing order in their lists.
- Every test of the product passes on the pull request, and the linter and the security scan find nothing new.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The open-banking product `products/fingate` has a sandbox ledger: a test bank that serves the ledger port `openova.fingate.ledger.v1.Ledger` from made-up data and never holds a bank's data. The package `internal/sandbox` serves all 14 operations of the port over three customers and five accounts held in memory. The program `cmd/fingate-sandbox-ledger` serves that package over gRPC and TLS on `:8443`, with the standard gRPC health service, reads a renewed certificate without a restart, and with `--print-kit-fixture` prints the fixture that describes its data to the ledger conformance kit. The conformance kit of `internal/ledgertest` passes against the sandbox with `checks passed: 41/41` and `operations called: 14/14`, in process and against the running program over TLS. The later packages that run the product against a ledger (its conformance workflow and the `bp-fingate-sandbox` Blueprint) use this program.

## 3. The model (the law)
1. **The package** `products/fingate/internal/sandbox` (files `ledger.go` and `data.go`). `New() *Ledger` returns a ledger that implements `ledgerv1.LedgerServer`, the generated server interface of `products/fingate/api/ledger/v1`, for all 14 operations, over a fresh copy of the data set. It is safe for concurrent use. All state is in memory; a new `Ledger` starts again from the data set.
2. **The data set** (`data.go`). Three customers and five accounts, all made up. `ResolveCustomer` maps the scheme `sandbox` (the constant `Scheme`) and a subject to a customer:

   | subject | customer | account | currency | category and type | balance |
   |---|---|---|---|---|---|
   | `alice` | `cust-0001` | `acc-0001-01` | GBP | Personal, CACC | 2443.20 |
   | `alice` | `cust-0001` | `acc-0001-02` | GBP | Personal, SVGS | 5204.17 |
   | `bob` | `cust-0002` | `acc-0002-01` | GBP | Personal, CACC | 1284.01 |
   | `bob` | `cust-0002` | `acc-0002-02` | EUR | Personal, CACC | 370.00 |
   | `carol` | `cust-0003` | `acc-0003-01` | GBP | Business, CACC | 20450.00 |

   Every account has transactions; each account's balance is its opening amount plus its transactions, and `New` writes each transaction's `balance_after`. Sort codes start with `0000` and the bank code of the IBANs is `SAND`, so no value names a real account. E-mail addresses use the domain `example.invalid`. The data carries no credential.
3. **Codes.** The values are codes of the profile documents `products/fingate/profiles/rw-4.0.0`: account category `Personal` or `Business`, account type `CACC` or `SVGS`, account status `Enabled`, balance types `CLBD` and `ITAV`, entry status `BOOK`, mandate status `ACTV`, party type `Sole`, schemes `UK.OBIE.SortCodeAccountNumber` and `UK.OBIE.IBAN`. The port carries these strings unchanged.
4. **Behaviour.** The error codes are the port's: an unknown customer, account or payment is `NOT_FOUND`; another customer's account is `PERMISSION_DENIED`; an amount above the balance is `FAILED_PRECONDITION` with the message `insufficient funds`; an idempotency key reused with other content is `ALREADY_EXISTS`; a malformed request is `INVALID_ARGUMENT`. `GetCapabilities` offers every resource and payment type of the port, in the currencies of the accounts (`EUR`, `GBP`). Lists are paged: 50 items when no size is given, at most 100. `ListTransactions` returns transactions oldest first, booked between `from` and `to`, both included; an empty bound is open; a bound that is not an RFC 3339 time is `INVALID_ARGUMENT`. `ListBalances` returns `CLBD` and `ITAV`. A `domestic` payment without an execution time is booked at once: status `settled`, the balance falls, and a `Debit` transaction with `balance_after` is appended. A scheduled payment (`domestic-scheduled`, or `domestic` with an execution time) is appended to the account's scheduled payments, and a `domestic-standing-order` to its standing orders; both stay `pending`, because the sandbox executes nothing later. The same idempotency key with the same content returns the same payment.
5. **The kit's fixture.** `KitFixture()` describes the data set to the conformance kit: customer `sandbox`/`alice`, other customer `sandbox`/`bob`, debtor account `acc-0001-01`, amount `1.00`, refused amount `1000000.00`, creditor `Sample Lettings Ltd`. Its JSON form has exactly the keys of `ledgertest.Fixture`, so `fingate-ledger-conformance --fixture` reads it.
6. **The program** `products/fingate/cmd/fingate-sandbox-ledger`. Flags: `--listen` (default `:8443`), `--cert-file` and `--key-file` (PEM files, required to serve), `--print-kit-fixture` (print the fixture as indented JSON and exit; it takes no certificate flag). TLS 1.2 is the lowest version accepted. The certificate and key are read again on the first connection after either file changed; when a changed pair cannot be read, the pair read before stays in use. The server registers the standard gRPC health service, `SERVING` for the empty service name and for `openova.fingate.ledger.v1.Ledger`. On SIGTERM or SIGINT it stops: health goes to `NOT_SERVING`, calls in flight get 10 seconds. Exit code 0: stopped by a signal, or the fixture was printed; 1: the server failed while it served; 2: it could not start.
7. **No new dependency.** The program uses `google.golang.org/grpc/health`, a package of `google.golang.org/grpc v1.85.0`, which `products/fingate/go.mod` already requires. `go.mod` and `go.sum` do not change.
8. **No poll.** No file of the change calls `time.Sleep`, `time.Tick` or `time.NewTicker`. The certificate files are checked when a connection starts, not on a timer.
9. Nothing else changes: no chart, no image file, no workflow, no README. No other package imports `internal/sandbox`.

// ledger port over a fixed set of made-up customers and accounts, held in memory. It is a test

// New returns a sandbox ledger that holds the data set of data.go, with no payment made.
func New() *Ledger {
	l := &Ledger{
		subjects:  map[string]string{},
		customers: map[string]*ledgerv1.Party{},
		accounts:  map[string]*account{},
		payments:  map[string]*ledgerv1.Payment{},
		keys:      map[string]*submitted{},
	}
	currencies := map[string]bool{}
	for _, c := range dataSet() {
		l.subjects[Scheme+"/"+c.subject] = c.id
		l.customers[c.id] = c.party
		for _, a := range c.accounts {
			acc := &account{
				owner: c.id, info: a.info, party: a.party, benefs: a.benefs,
				standing: a.standing, debits: a.debits, scheduled: a.scheduled,
			}
			acc.balance = mustAmount(a.opening)
			for _, t := range a.txns {
				v := mustAmount(t.GetAmount().GetAmount())
				if t.GetCreditDebit() == "Debit" {
					v = -v
				}
				acc.balance += v
				t.BalanceAfter = &ledgerv1.Money{Amount: formatAmount(acc.balance), Currency: a.info.GetCurrency()}
				acc.txns = append(acc.txns, t)
			}

func now() string { return time.Now().UTC().Format(time.RFC3339) }

// owned returns the account when the customer exists and holds it.
func (l *Ledger) owned(customer, accountID string) (*account, error) {
	if _, ok := l.customers[customer]; !ok {
		return nil, status.Errorf(codes.NotFound, "unknown customer %q", customer)
	}
	a, ok := l.accounts[accountID]
	if !ok {
		return nil, status.Errorf(codes.NotFound, "unknown account %q", accountID)
	}
	if a.owner != customer {
		return nil, status.Errorf(codes.PermissionDenied, "account %q is not the customer's", accountID)
	}
	return a, nil
}

// resource checks that a resource is offered and returns the customer's account.
func (l *Ledger) resource(name, customer, accountID string) (*account, error) {
	if !slices.Contains(l.caps.GetResources(), name) {
		return nil, status.Errorf(codes.Unimplemented, "this ledger does not offer %s", name)
	}
	return l.owned(customer, accountID)
}

// pageOf returns one page of a list of messages, cloned, and the token of the next page. A page
// token is the position of the first item of the page.
func pageOf[T proto.Message](items []T, token string, size int32) ([]T, string, error) {
	from := 0
	if token != "" {
		v, err := strconv.Atoi(token)
		if err != nil || v < 0 || v > len(items) {
			return nil, "", status.Errorf(codes.InvalidArgument, "page_token %q is not one this ledger issued", token)
		}
		from = v
	}
	limit := int(size)
	if limit <= 0 {
		limit = defaultPageSize
	}
	to := min(len(items), from+min(limit, maxPageSize))
	next := ""
	if to < len(items) {
		next = strconv.Itoa(to)
	}
	out := make([]T, 0, to-from)
	for _, x := range items[from:to] {
		out = append(out, proto.Clone(x).(T))
	}
	return out, next, nil
}

// window parses the optional from and to of a transaction request.
func window(from, to string) (time.Time, time.Time, error) {
	var bounds [2]time.Time
	for i, v := range []string{from, to} {
		if v == "" {
			continue
		}
		t, err := time.Parse(time.RFC3339, v)
		if err != nil {
			return bounds[0], bounds[1], status.Errorf(codes.InvalidArgument, "%q is not an RFC 3339 time", v)
		}
		bounds[i] = t
	}
	return bounds[0], bounds[1], nil
}

// ListTransactions returns one page of the account's transactions, oldest first, booked between
// from and to, both included; an empty bound is open.
func (l *Ledger) ListTransactions(_ context.Context, r *ledgerv1.ListTransactionsRequest) (*ledgerv1.ListTransactionsResponse, error) {
	l.mu.Lock()
	defer l.mu.Unlock()
	a, err := l.owned(r.GetCustomerId(), r.GetAccountId())
	if err != nil {
		return nil, err
	}
	from, to, err := window(r.GetFrom(), r.GetTo())
	if err != nil {
		return nil, err
	}
	var in []*ledgerv1.Transaction
	for _, t := range a.txns {
		booked, err := time.Parse(time.RFC3339, t.GetBookedAt())
		if err != nil {
			return nil, status.Errorf(codes.Internal, "transaction %s: %v", t.GetTransactionId(), err)
		}
		if (from.IsZero() || !booked.Before(from)) && (to.IsZero() || !booked.After(to)) {
			in = append(in, t)
		}
	}
	items, next, err := pageOf(in, r.GetPageToken(), r.GetPageSize())
	if err != nil {
		return nil, err
	}
	return &ledgerv1.ListTransactionsResponse{Transactions: items, NextPageToken: next}, nil
}

// unit is one currency unit in hundred-thousandths, the finest step an amount of the port has.
const unit = 100000

var amountRE = regexp.MustCompile(`^\d{1,13}$|^\d{1,13}\.\d{1,5}$`)

// parseAmount parses an amount of the port into hundred-thousandths; ok is false when it is
// not one.
func parseAmount(s string) (int64, bool) {
	if !amountRE.MatchString(s) {
		return 0, false
	}
	whole, frac, _ := strings.Cut(s, ".")
	v, err := strconv.ParseInt(whole+frac+strings.Repeat("0", 5-len(frac)), 10, 64)
	return v, err == nil
}

// mustAmount parses an amount of the data set, which is always well formed.
func mustAmount(s string) int64 {
	v, ok := parseAmount(s)
	if !ok {
		panic(fmt.Sprintf("sandbox data: %q is not an amount", s))
	}
	return v
}

// formatAmount writes hundred-thousandths as an amount of the port with two to five decimals.
func formatAmount(v int64) string {
	s := fmt.Sprintf("%d.%05d", v/unit, v%unit)
	for strings.HasSuffix(s, "0") && len(s)-strings.Index(s, ".") > 3 {
		s = s[:len(s)-1]
	}
	return s
}

// amountOn parses an amount in the account's currency.
func amountOn(a *account, money *ledgerv1.Money) (int64, error) {
	v, ok := parseAmount(money.GetAmount())
	if !ok {
		return 0, status.Errorf(codes.InvalidArgument, "amount %q is not an amount", money.GetAmount())
	}
	if money.GetCurrency() != a.info.GetCurrency() {
		return 0, status.Errorf(codes.InvalidArgument, "currency %q is not the account's %s", money.GetCurrency(), a.info.GetCurrency())
	}
	return v, nil
}

	}

}

// validPayment checks the fields of a payment request that do not depend on the ledger's data.
func validPayment(r *ledgerv1.SubmitPaymentRequest) error {
	if (r.GetType() == "domestic-standing-order") != (r.GetRecurrence() != nil) {
		return status.Error(codes.InvalidArgument, "recurrence is set exactly when the type is domestic-standing-order")
	}
	if r.GetType() == "domestic-scheduled" && r.GetRequestedExecutionAt() == "" {
		return status.Error(codes.InvalidArgument, "requested_execution_at is empty for a scheduled payment")
	}
	if v := r.GetRequestedExecutionAt(); v != "" {
		if _, err := time.Parse(time.RFC3339, v); err != nil {
			return status.Errorf(codes.InvalidArgument, "requested_execution_at %q is not an RFC 3339 time", v)
		}
	}
	if rec := r.GetRecurrence(); rec != nil && rec.GetFirstAmount() == nil {
		return status.Error(codes.InvalidArgument, "recurrence.first_amount is not set")
	}
	return nil
}

// SubmitPayment makes a payment once per idempotency key.
func (l *Ledger) SubmitPayment(_ context.Context, r *ledgerv1.SubmitPaymentRequest) (*ledgerv1.Payment, error) {
	l.mu.Lock()
	defer l.mu.Unlock()
	if r.GetIdempotencyKey() == "" {
		return nil, status.Error(codes.InvalidArgument, "idempotency_key is empty")
	}
	if prev, ok := l.keys[r.GetIdempotencyKey()]; ok {
		if !proto.Equal(prev.req, r) {
			return nil, status.Error(codes.AlreadyExists, "the idempotency key was used with other content")
		}
		return proto.Clone(prev.payment).(*ledgerv1.Payment), nil
	}
	if !slices.Contains(l.caps.GetPaymentTypes(), r.GetType()) {
		return nil, status.Errorf(codes.Unimplemented, "this ledger does not offer payment type %q", r.GetType())
	}
	if err := validPayment(r); err != nil {
		return nil, err
	}
	a, err := l.owned(r.GetCustomerId(), r.GetDebtorAccountId())
	if err != nil {
		return nil, err
	}
	v, err := amountOn(a, r.GetAmount())
	if err != nil {
		return nil, err
	}
	if rec := r.GetRecurrence(); rec != nil {
		if _, err := amountOn(a, rec.GetFirstAmount()); err != nil {
			return nil, err
		}
	}
	if a.balance < v {
		return nil, status.Error(codes.FailedPrecondition, "insufficient funds")
	}
	l.seq++
	at := now()
	p := &ledgerv1.Payment{PaymentId: fmt.Sprintf("pay-%06d", l.seq), Status: "pending", StatusAt: at}
	amount := &ledgerv1.Money{Amount: formatAmount(v), Currency: a.info.GetCurrency()}
	switch {
	case r.GetType() == "domestic" && r.GetRequestedExecutionAt() == "":
		a.balance -= v
		p.Status = "settled"
		a.txns = append(a.txns, &ledgerv1.Transaction{
			TransactionId: "tx-" + p.GetPaymentId(), Amount: amount, CreditDebit: "Debit", Status: "BOOK",
			BookedAt: at, ValueAt: at, Information: "Payment to " + r.GetCreditorName(), Reference: r.GetReference(),
			CounterpartyName: r.GetCreditorName(), CounterpartyIdentification: r.GetCreditorIdentification(),
			BalanceAfter: &ledgerv1.Money{Amount: formatAmount(a.balance), Currency: a.info.GetCurrency()},
		})
	case r.GetType() == "domestic-standing-order":
		rec := r.GetRecurrence()
		a.standing = append(a.standing, &ledgerv1.StandingOrder{
			StandingOrderId: "so-" + p.GetPaymentId(), Frequency: rec.GetFrequency(), Reference: r.GetReference(),
			NextAmount: proto.Clone(rec.GetFirstAmount()).(*ledgerv1.Money), NextAt: rec.GetFirstPaymentAt(), FinalAt: rec.GetFinalPaymentAt(),
			Status: "ACTV", CreditorName: r.GetCreditorName(), CreditorSchemeName: r.GetCreditorSchemeName(),
			CreditorIdentification: r.GetCreditorIdentification(),
		})
	default:
		a.scheduled = append(a.scheduled, &ledgerv1.ScheduledPayment{
			ScheduledPaymentId: "sp-" + p.GetPaymentId(), ExecutionAt: r.GetRequestedExecutionAt(), Amount: amount,
			Reference: r.GetReference(), CreditorName: r.GetCreditorName(), CreditorSchemeName: r.GetCreditorSchemeName(),
			CreditorIdentification: r.GetCreditorIdentification(),
		})
	}
	l.payments[p.GetPaymentId()] = p
	l.keys[r.GetIdempotencyKey()] = &submitted{req: proto.Clone(r).(*ledgerv1.SubmitPaymentRequest), payment: p}
	return proto.Clone(p).(*ledgerv1.Payment), nil
}

// GetPayment returns a payment by its identifier.
func (l *Ledger) GetPayment(_ context.Context, r *ledgerv1.GetPaymentRequest) (*ledgerv1.Payment, error) {
	l.mu.Lock()
	defer l.mu.Unlock()
	p, ok := l.payments[r.GetPaymentId()]
	if !ok {
		return nil, status.Errorf(codes.NotFound, "unknown payment %q", r.GetPaymentId())
	}
	return proto.Clone(p).(*ledgerv1.Payment), nil
}

// Command fingate-sandbox-ledger serves the ledger port of the open-banking product over
// gRPC and TLS, from the sandbox data set of package sandbox: three made-up customers and five
// accounts, held in memory. It is the test bank that the product and its partners use; it never
// holds a bank's data.
//
// Usage:
//
//	fingate-sandbox-ledger --cert-file <tls.crt> --key-file <tls.key> [--listen :8443]
//	fingate-sandbox-ledger --print-kit-fixture
//
// The certificate and key are PEM files, as a certificate issuer mounts them. They are read
// again on the first connection after either file changed, so a renewed certificate is served
// without a restart. The server also answers the standard gRPC health service, for the empty
// service name and for openova.fingate.ledger.v1.Ledger. It stops on SIGTERM or SIGINT.
//
// --print-kit-fixture prints the fixture that describes the data set to the ledger
// conformance kit, the file that fingate-ledger-conformance reads with --fixture, and exits.
//
// Exit codes: 0 stopped by a signal, or the fixture was printed; 1 the server failed while it
// served; 2 it could not start (a wrong flag, a certificate that cannot be read, an address
// that cannot be listened on).

// stopGrace is how long a stop waits for calls in flight before it closes every connection.
const stopGrace = 10 * time.Second

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), syscall.SIGTERM, os.Interrupt)
	defer stop()
	os.Exit(run(ctx, os.Args[1:], os.Stdout, os.Stderr, nil))
}

// keyPair serves a certificate and key from two files and reads them again when either changed.
type keyPair struct {
	certFile, keyFile string

	mu      sync.Mutex
	stamp   [2]time.Time
	current *tls.Certificate
}

// stamps returns the modification times of the two files.
func (k *keyPair) stamps() ([2]time.Time, error) {
	var s [2]time.Time
	for i, f := range []string{k.certFile, k.keyFile} {
		fi, err := os.Stat(f)
		if err != nil {
			return s, err
		}
		s[i] = fi.ModTime()
	}
	return s, nil
}

// load reads the files when they changed since the last read. When a changed pair cannot be
// read, the certificate read before stays in use.
func (k *keyPair) load() (*tls.Certificate, error) {
	k.mu.Lock()
	defer k.mu.Unlock()
	s, err := k.stamps()
	if err == nil && k.current != nil && s == k.stamp {
		return k.current, nil
	}
	if err == nil {
		var c tls.Certificate
		if c, err = tls.LoadX509KeyPair(filepath.Clean(k.certFile), filepath.Clean(k.keyFile)); err == nil {
			k.current, k.stamp = &c, s
			return k.current, nil
		}
	}
	if k.current != nil {
		return k.current, nil
	}
	return nil, err
}

func (k *keyPair) getCertificate(*tls.ClientHelloInfo) (*tls.Certificate, error) { return k.load() }

func run(ctx context.Context, args []string, stdout, stderr io.Writer, listening func(net.Addr)) int {
	fs := flag.NewFlagSet("fingate-sandbox-ledger", flag.ContinueOnError)
	fs.SetOutput(stderr)
	listen := fs.String("listen", ":8443", "the address to serve the ledger port on")
	certFile := fs.String("cert-file", "", "the PEM file of the server certificate; required to serve")
	keyFile := fs.String("key-file", "", "the PEM file of the certificate's private key; required to serve")
	printFixture := fs.Bool("print-kit-fixture", false, "print the conformance kit's fixture of the data set and exit")
	if err := fs.Parse(args); err != nil {
		return 2
	}
	usage := func(err error) int {
		_, _ = fmt.Fprintf(stderr, "fingate-sandbox-ledger: %v\n", err)
		return 2
	}
	if fs.NArg() > 0 {
		return usage(fmt.Errorf("unexpected argument %q", fs.Arg(0)))
	}
	if *printFixture {
		if *certFile != "" || *keyFile != "" {
			return usage(errors.New("--print-kit-fixture takes no --cert-file or --key-file"))
		}
		b, err := json.MarshalIndent(sandbox.KitFixture(), "", "  ")
		if err != nil {
			return usage(err)
		}
		if _, err := fmt.Fprintf(stdout, "%s\n", b); err != nil {
			return usage(err)
		}
		return 0
	}
	if *certFile == "" || *keyFile == "" {
		return usage(errors.New("--cert-file and --key-file are required"))
	}
	kp := &keyPair{certFile: *certFile, keyFile: *keyFile}
	if _, err := kp.load(); err != nil {
		return usage(err)
	}
	lis, err := net.Listen("tcp", *listen)
	if err != nil {
		return usage(err)
	}

	creds := credentials.NewTLS(&tls.Config{MinVersion: tls.VersionTLS12, GetCertificate: kp.getCertificate})
	s := grpc.NewServer(grpc.Creds(creds))
	ledgerv1.RegisterLedgerServer(s, sandbox.New())
	hs := health.NewServer()
	hs.SetServingStatus(ledgerv1.Ledger_ServiceDesc.ServiceName, healthpb.HealthCheckResponse_SERVING)
	healthpb.RegisterHealthServer(s, hs)

	served := make(chan error, 1)
	go func() { served <- s.Serve(lis) }()
	_, _ = fmt.Fprintf(stderr, "fingate-sandbox-ledger: serving the ledger port on %s\n", lis.Addr())
	if listening != nil {
		listening(lis.Addr())
	}
	select {
	case err := <-served:
		_, _ = fmt.Fprintf(stderr, "fingate-sandbox-ledger: %v\n", err)
		return 1
	case <-ctx.Done():
	}
	hs.Shutdown()
	force := time.AfterFunc(stopGrace, s.Stop)
	defer force.Stop()
	s.GracefulStop()
	_, _ = fmt.Fprintln(stderr, "fingate-sandbox-ledger: stopped")
	return 0
}

// writeCert writes a fresh self-signed certificate for 127.0.0.1 with the given serial number
// and its key into dir, stamps both files with the given time, and returns the certificate.
func writeCert(t *testing.T, dir string, serial int64, stamp time.Time) *x509.Certificate {
	t.Helper()
	priv, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
	if err != nil {
		t.Fatal(err)
	}
	tmpl := &x509.Certificate{
		SerialNumber:          big.NewInt(serial),
		Subject:               pkix.Name{CommonName: "sandbox-ledger"},
		NotBefore:             time.Now().Add(-time.Hour),
		NotAfter:              time.Now().Add(time.Hour),
		KeyUsage:              x509.KeyUsageDigitalSignature | x509.KeyUsageCertSign,
		ExtKeyUsage:           []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
		BasicConstraintsValid: true,
		IsCA:                  true,
		IPAddresses:           []net.IP{net.ParseIP("127.0.0.1")},
	}
	der, err := x509.CreateCertificate(rand.Reader, tmpl, tmpl, &priv.PublicKey, priv)
	if err != nil {
		t.Fatal(err)
	}
	keyDER, err := x509.MarshalECPrivateKey(priv)
	if err != nil {
		t.Fatal(err)
	}
	files := map[string][]byte{
		"tls.crt": pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: der}),
		"tls.key": pem.EncodeToMemory(&pem.Block{Type: "EC PRIVATE KEY", Bytes: keyDER}),
	}
	for name, b := range files {
		p := filepath.Join(dir, name)
		if err := os.WriteFile(p, b, 0o600); err != nil {
			t.Fatal(err)
		}
		if err := os.Chtimes(p, stamp, stamp); err != nil {
			t.Fatal(err)
		}
	}
	cert, err := x509.ParseCertificate(der)
	if err != nil {
		t.Fatal(err)
	}
	return cert
}

// syncBuffer is a buffer that the server goroutine and the test may use at once.
type syncBuffer struct {
	mu sync.Mutex
	b  bytes.Buffer
}

func (s *syncBuffer) Write(p []byte) (int, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	return s.b.Write(p)
}

func (s *syncBuffer) String() string {
	s.mu.Lock()
	defer s.mu.Unlock()
	return s.b.String()
}

// serve starts the program on a free loopback port with the files of dir. It returns the
// address and a function that stops the program and returns its exit code and its log.
func serve(t *testing.T, dir string) (string, func() (int, string)) {
	t.Helper()
	ctx, cancel := context.WithCancel(context.Background())
	addrs := make(chan net.Addr, 1)
	codes := make(chan int, 1)
	log := &syncBuffer{}
	go func() {
		codes <- run(ctx, []string{"--listen", "127.0.0.1:0", "--cert-file", filepath.Join(dir, "tls.crt"), "--key-file", filepath.Join(dir, "tls.key")},
			&syncBuffer{}, log, func(a net.Addr) { addrs <- a })
	}()
	select {
	case a := <-addrs:
		stopped := false
		stop := func() (int, string) {
			if !stopped {
				stopped = true
				cancel()
			}
			return <-codes, log.String()
		}
		t.Cleanup(func() {
			if !stopped {
				stop()
			}
		})
		return a.String(), stop
	case code := <-codes:
		cancel()
		t.Fatalf("the program exited with code %d before it served:\n%s", code, log.String())
		return "", nil
	}
}

func pool(certs ...*x509.Certificate) *x509.CertPool {
	p := x509.NewCertPool()
	for _, c := range certs {
		p.AddCert(c)
	}
	return p
}
