# PRD-010 — Remove the unbacked open-banking claims from the Keycloak README

## In plain words

**The problem today.** The README of the identity component says that it already serves as the authorization server of an open-banking product, with a security profile, certificate checks, consent screens and third-party registration. None of this exists in the platform: no chart, no code and no configuration does it. A reader takes the README at its word and plans on a capability that is not there.

**What changes.** The open-banking claims are removed from the README: one sentence, one list item, part of a diagram and five sections. One line says that open banking is not built. Everything the component really does stays described as before.

**Done means:**

- The README of the identity component names no open-banking profile, certificate scheme, third-party provider or payment directive.
- The README says in one line that open banking is not built.
- The sections Overview, Architecture, Configuration with its two deployment examples, and High Availability are still there; only their open-banking parts are gone.
- No other file changes: the chart of the component stays as it is.

The rest of this ticket is the exact instruction for the model that does the work.
