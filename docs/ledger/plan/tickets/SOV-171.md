# SOV-171 — Check SOV-G01 retries its reads of a settling Flux and reads the registry file as YAML

## In plain words

**The problem today.** The Born local acceptance check reads the Git sources of Flux once and the Kustomizations that apply the root once, and compares the two. A commit to the Sovereign's own repository during a run leaves the owner behind its source for a minute, and the check fails although Flux settles by itself. The check also refuses the registry file of a local install because that file is written as YAML and not as JSON, so it never judges what the file says.

**What changes.** The check reads both lists again every 15 seconds, for up to 6 minutes, while the only faults are owners that are still settling; any other fault fails at once as before. It reads the registry file as YAML, of which JSON is one form, and judges its content.

**Done means:**

- A commit to the Sovereign's own repository during a run no longer fails the Born local check: the check reads again until the owner has applied the new revision.
- An owner that stays behind its source or stays not Ready fails the check after a wait of at most six minutes, and the failure names the last state it saw.
- Every other fault, such as a root applied by hand, a source outside the Sovereign or a source with no artifact, still fails the check at once.
- The registry file of a node is judged by what it says, whether it is written as JSON or as YAML, and a form the check cannot read fails the node with a line number and never with the text of the line.
- The check is still marked as expected to fail, and the suite still uses only the standard library.
- Its tests run on every pull request without a cluster, with cases for a commit that lands during a run, an owner that stays behind, and each YAML form that is read or refused.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Gate check SOV-G01 (Born local), `tests/acceptance/sovereign/internal/suite/check_born_local.go`, judges a region that is still settling as settling, and a registry file by its content. Its step 3 in each region (the root Kustomizations are Ready and owned by Flux from the Sovereign's own repository) reads the Kustomizations of `flux-system` and the GitRepositories of the region together in each pass. When every fault of a pass is an owner that is not Ready or has not applied the revision its source holds, as right after a commit to `openova/sovereign-regions`, the step repeats the pass with `poll` of `runner.go` every 15 seconds for up to 6 minutes, and fails with the last state it saw when the region does not settle. Any other fault fails the step at once, as before. The judge of the registry file `/etc/rancher/k3s/registries.yaml` reads it as YAML: the JSON the provider modules write is one form of it, the block form the local pack writes (`scripts/local-pack.sh`) is another, so the local pack's file is judged by what it says and not refused for its form. A form the reader does not read fails the node with a line number, never with the text of the line. The check stays `expected-fail`, the suite module stays standard library only, and the tests run on every pull request without a cluster.

## 3. The model (the law)
1. **The files are fixed.** The two files of field 14 are changed by the block `SOV-171.patch` at the end of field 20 and by nothing else. The block carries its checksum.
2. **One pass of step 3.** A pass reads the Kustomizations of `flux-system`, then the GitRepositories of every namespace, and judges them with `bornLocalOwned` by the rules SOV-170 set: the roots of `bornLocalRoots`, their Flux labels, the owner, its source, the URL of that source, `Ready=True`, and `status.lastAppliedRevision` of the owner against `status.artifact.revision` of its source. Steps 1 and 2 and the ConfigMap `flux-system/sovereign-variables` are read once per region, as before.
3. **What settles.** `bornLocalOwner` reports a fault as settling only when the owner is a Kustomization of `flux-system` whose source is a GitRepository of the region inside the Sovereign with the path `openova/sovereign-regions`, and either the owner is not `Ready=True`, or its source holds a revision (`status.artifact.revision` is not empty) that is not the owner's `lastAppliedRevision`. A pass is settling when it failed and every fault in it is settling.
4. **The repeated pass.** Step 3 calls `poll(ctx, c.settle, c.every, ...)` of `runner.go`. A settling pass is read again after `every`. A pass with any other fault, and a read that fails, ends the step at once with that fault. A pass with no fault passes. The registered check holds `bornLocalSettle` (6 minutes) and `bornLocalEvery` (15 seconds); the owner `sovereign-region` has `interval: 1m` and `timeout: 5m` in `clusters/_template/sovereign-region/base/region-kustomization.yaml`, so an owner that has fetched a commit applies it inside that bound. A settle of 0 makes one pass. When the time is up the step fails with `timed out after <settle>; last observed: <the faults of the last pass>`. The evidence of the step records `passes`, the number of passes it read. The name of the step says the bound.
5. **What does not settle.** A root that is missing, not Ready, applied by hand or owned elsewhere; an owner that is no Kustomization of `flux-system`, reads no GitRepository of the region, or reads one outside the Sovereign or with another path; a source with no artifact. Each fails the first pass, also when an owner of the same pass is settling.
6. **The reads are injectable.** `bornLocalCheck` gains the fields `get` (the registered check holds `kube.Region.GetList`), `settle` and `every`. The tests set `get` to a fake that answers the reads of one region in order, and `settle` and `every` to milliseconds.
7. **The registry file is YAML.** `judgeBornLocalRegistry` decodes the base64 the probe printed, reads the file with `bornLocalYAML`, and decodes only its `mirrors`, as names that each hold a list of endpoints. Its rules do not change: an unreadable file, no name, no entry `*`, or a name whose first endpoint is not `https://<LOCAL_REGISTRY_HOST>` fails the node. The `configs`, which hold a login, are never recorded.
8. **The YAML reader.** `bornLocalYAML` is standard library Go in the same file. It reads a document that is one JSON value (on one line or on several), and block mappings and lists whose scalars are plain, single-quoted, double-quoted (with JSON escapes) or a JSON flow collection; it reads comments, a leading `---`, `~` and `null`. It refuses, with an error that names a line number and never the text of the line: a tab in an indent, an anchor, an alias, a tag, a block scalar, a directive, a second document, a line indented under no key or outside the structure above it, a repeated key, a mapping where a scalar belongs, a quoted scalar that does not end on its line, a flow collection that is not JSON, and a file with no document. What it refuses fails the node; it is never read as absent.
9. **Limits, kept on purpose.** A plain scalar is read as a string (the mirrors are strings). A plain or quoted scalar over several lines is refused. The fourth clause of SOV-G01, the catalogue as a verified `OCIRepository`, stays SOV-510's.
10. Nothing else changes: the node probe, its script and namespace, the steps of the check and their numbers, `docs/ledger/gates.yaml` (SOV-G01 stays `expected-fail` and delivered by SOV-170), the README of the suite. No new Python, no NodePort, no write to a live system.

+// yamlLine is one line of a YAML document that holds content: its number,
+// its indent in spaces and its text after the indent.
+type yamlLine struct {
+	n, indent int

+// bornLocalYAML reads a registry file as YAML into maps, lists and strings.
+// It reads a document that is one JSON value (the provider modules write
+// one), and block mappings and lists (the local pack, scripts/local-pack.sh)
+// whose scalars are plain, single- or double-quoted, or JSON. It refuses
+// every other form (a tab in an indent, an anchor, an alias, a tag, a block
+// scalar, a second document, a line under no key, a repeated key), so that
+// what it cannot read is never judged as absent. An error names a line,
+// never its text.
+func bornLocalYAML(b []byte) (any, error) {
+	lines := []yamlLine{}
+	for i, raw := range strings.Split(string(b), "\n") {
+		raw = strings.TrimRight(raw, " \r")
+		if text := strings.TrimLeft(raw, " "); text != "" && text[0] != '#' && (text != "---" || len(lines) > 0) {
+			lines = append(lines, yamlLine{i + 1, len(raw) - len(text), text})
+		}
+	}
+	if len(lines) == 0 {
+		return nil, errors.New("it holds no document")
+	}
+	if c := lines[0].text[0]; c == '{' || c == '[' {
+		texts := []string{}
+		for _, l := range lines {
+			texts = append(texts, l.text)
+		}
+		return yamlJSON(strings.Join(texts, "\n"), lines[0].n)
+	}
+	for _, l := range lines {
+		if l.text[0] == '\t' {
+			return nil, fmt.Errorf("line %d is indented with a tab", l.n)
+		}
+	}
+	v, err := yamlWhole(lines, lines[0].indent)
+	if err != nil {
+		return nil, err
+	}
+	return v, nil

+// yamlNode reads the block mapping or list whose lines start at indent and

+func yamlList(lines []yamlLine, indent int) ([]any, []yamlLine, error) {
+	list := []any{}
+	for len(lines) > 0 && lines[0].indent == indent && yamlItem(lines[0].text) {

+			end++

+func yamlMap(lines []yamlLine, indent int) (map[string]any, []yamlLine, error) {
+	m := map[string]any{}
+	for len(lines) > 0 && lines[0].indent == indent && !yamlItem(lines[0].text) {
+		l := lines[0]

+		}

+		}

+func yamlKey(text string, n int) (key, value string, keyed bool, err error) {

+			err = fmt.Errorf("line %d holds text after a quoted scalar", n)
+		}
+		if err != nil {
+			return nil, err
+		}
+		if s[0] == '\'' {
+			return strings.ReplaceAll(s[1:end-1], "''", "'"), nil
+		}
+		var v string
+		if json.Unmarshal([]byte(s[:end]), &v) != nil {
+			return nil, fmt.Errorf("line %d holds an escape in a double-quoted scalar that this check does not read", n)
+		}
+		return v, nil
+	case s[0] == '{' || s[0] == '[':
+		return yamlJSON(s, n)
+	case strings.ContainsAny(s[:1], yamlIndicators):
+		return nil, fmt.Errorf("line %d holds a value in a YAML form this check does not read", n)
+	}

+	}
+	switch {

+		return nil, fmt.Errorf("line %d holds a mapping where a scalar belongs", n)
+	case s == "~" || s == "null":
+		return nil, nil
+	}
+	return s, nil

+			i++
+		case s[i] == s[0]:
+			return i + 1, nil
+		}
+	}
+	return 0, fmt.Errorf("line %d holds a quoted scalar that does not end on it", n)
+}
