# CLD-090 — The three modules meet contract version 1; conformance tests

## In plain words

**The problem today.** The contract that every cloud module must meet is written down, but two of the three modules do not meet it and no test compares a module with it. The Hetzner and the Huawei module take their regions in two different shapes, so the provisioning engine has a special case for one cloud, and two build pipelines hold a fixed list of cloud names.

**What changes.** All three modules take the same inputs and give the same outputs, and the engine writes one shape of regions for every cloud. A test compares every module with the contract on every pull request, and the build pipelines find the modules by folder.

**Done means:**

- The Hetzner, the Huawei and the local module declare every input and every output of the contract, with the type the contract gives.
- A module that drifts from the contract turns the pull request red.
- A boot script that is rendered again never plans the replacement of a running machine, in any module.
- The engine writes the same shape of regions for every cloud, and the wipe of a Sovereign that was provisioned before this change still works.
- No build pipeline holds a list of cloud names: a new module folder is tested without a change to a pipeline.
- The gate check for contract conformance is required.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. **One contract.** `infra/providers/_contract/contract.json`, version 1, is the source. Every directory of `infra/providers` whose name does not start with `_` is a provider pack, and its module meets the contract: it declares every contract variable with the contract's type and the contract's `sensitive` flag; a required variable has no default; an optional variable has a default, and the contract's default where the contract sets one; it declares every contract output. A module may declare more variables and outputs.
2. **One type of `regions`.** Every module declares exactly the type below, and at least the three validations below with these messages:
```
variable "regions" {
  type = list(object({
    code               = string
    cloud_region       = string
    availability_zone  = optional(string, "")
    role               = string
    control_plane_size = string
    worker_size        = string
    worker_count       = number
  }))
  validation {
    condition     = length(var.regions) >= 1 && var.regions[0].role == "primary"
    error_message = "regions must have at least one entry and regions[0].role must be \"primary\"."
  }
  validation {
    condition     = alltrue([for r in var.regions : contains(["primary", "secondary"], r.role)])
    error_message = "regions[].role must be primary or secondary."
  }
  validation {
    condition     = length(distinct([for r in var.regions : r.code])) == length(var.regions)
    error_message = "regions[].code must be unique."
  }
}
```
A module whose cloud cannot span cloud regions adds one validation of its own: every `cloud_region` is the same. The Huawei module gets it; the local module has it. The Huawei module also keeps its validation of at most six regions. The Hetzner module reads `cloud_region` as the Hetzner location and does not read `availability_zone`.
3. **Two outputs carry the contract.** `contract_version` is the string `1`. `control_plane_ips_per_region` has one key per entry of `regions`, and the key is the region code, in every module.
4. **Boot data never replaces a node.** Every resource that sets `user_data` lists `user_data` in `lifecycle.ignore_changes`.
5. **No node port.** No resource of a module carries a port of the range 30000 to 32767. A front door reaches a node on a host port.
6. **The engine writes one shape.** `writeTfvars` writes `regions` in the contract's shape for every provider, by these rules for entry number i of the request's regions: `code` is the request's `code`, or its `cloudRegion` when `code` is empty; `cloud_region` is `cloudRegion`; `availability_zone` is the request's `zone`; `role` is `primary` for i = 0 and `secondary` otherwise, and a `role` in the request is not read; the two sizes and the count are passed as they are. A request without regions gives one entry built from the singular fields. The list is never null and never empty.
7. **The Huawei values until later packages.** For the provider `huawei` the engine writes, in every entry, `cloud_region` with the one cloud region of the request (the value it writes as `huawei_region` today) and `availability_zone` empty. The module falls back to its variable `huawei_az` for an empty zone. The engine keeps writing the variable `huawei_region` into the variables file, because the wipe and the janitor read it from the stored file; package CLD-103 removes it.
8. **A kept variables file.** A destroy that keeps the variables file of an older provision first adds `cloud_region` to every entry of `regions` that has none.
9. **The module's contract test.** `tests/contract.tftest.hcl` of every module is the module's own mock and override blocks, then the marker line `# --- contract body ---`, then `infra/providers/_contract/contract.tftest.body.hcl` byte for byte. The module's own required variables come from `tests/contract.auto.tfvars.json`.
10. **The test.** `TestProviderPacks` in `products/catalyst/bootstrap/api/internal/providers/conformance` asserts rules 1, 3 (the output is declared), 4, 5 and 9 and that `pack.yaml` names exactly the OpenTofu providers the module declares. `scripts/check-provider-contract.sh` runs it, and its `--self-test` proves that each rule can fail. Three sub-tests are written and skipped by exactly these lines, which later packages remove: `t.Skip("until CLD-102")`, `t.Skip("until CLD-132")`, `t.Skip("until CLD-144")`.
11. **CI finds the modules by directory.** No workflow holds a list of provider names for the module tests or for the boot-data size check.
12. **Deleted by this ticket:** the field `provider` of the Hetzner module's `regions` type, the Hetzner validation that lists five provider names, and the Hetzner filter `r.provider == "hetzner"`; the Huawei variable `huawei_region` (the module reads `regions[0].cloud_region`); the defaults of `default_storage_class`, `gitops_repo_url` and `catalyst_api_url` in the Hetzner and the Huawei module, and of `deployment_id` and `regions` in the Hetzner module; the engine function `coalesceRegions` and the block of `writeTfvars` that re-shaped `regions` for Huawei; the job matrix `provider: [hetzner, huawei]` of the workflow `cloud-init-size`.
13. **The gate manifest.** The entry CLD-G03 of `docs/ledger/gates.yaml` moves from `expected-fail` to `required`. No other line of that file changes. Gate check CLD-G12 is not part of this ticket (field 11).

// parseModule reads every *.tf file of dir. ok is false when dir has none.
func parseModule(dir string) (m *module, ok bool, err error) {
	files, err := filepath.Glob(filepath.Join(dir, "*.tf"))
	if err != nil {
		return nil, false, err
	}
	if len(files) == 0 {
		return nil, false, nil
	}
	sort.Strings(files)
	m = &module{dir: dir, variables: map[string]*hclsyntax.Block{}, outputs: map[string]*hclsyntax.Block{}, providers: map[string]bool{}}
	parser := hclparse.NewParser()
	for _, file := range files {
		f, diags := parser.ParseHCLFile(file)
		if diags.HasErrors() {
			return nil, false, fmt.Errorf("%s: %s", file, diags.Error())
		}
		body, isSyntax := f.Body.(*hclsyntax.Body)
		if !isSyntax {
			return nil, false, fmt.Errorf("%s: not native HCL syntax", file)
		}
		m.bodies = append(m.bodies, body)
		for _, b := range body.Blocks {
			switch {
			case b.Type == "variable" && len(b.Labels) == 1:
				m.variables[b.Labels[0]] = b
			case b.Type == "output" && len(b.Labels) == 1:
				m.outputs[b.Labels[0]] = b
			case b.Type == "resource" && len(b.Labels) == 2:
				m.resources = append(m.resources, b)
			case b.Type == "terraform":
				if err := m.addRequiredProviders(b); err != nil {
					return nil, false, fmt.Errorf("%s: %w", file, err)
				}
			}
		}
	}
	return m, true, nil
}

// addRequiredProviders records the source of every entry of the
// required_providers block inside a terraform block.
func (m *module) addRequiredProviders(terraform *hclsyntax.Block) error {
	for _, b := range terraform.Body.Blocks {
		if b.Type != "required_providers" {
			continue
		}
		for name, attr := range b.Body.Attributes {
			val, diags := attr.Expr.Value(nil)
			if diags.HasErrors() || !val.Type().IsObjectType() || !val.Type().HasAttribute("source") {
				return fmt.Errorf("required_providers.%s: no literal source", name)
			}
			m.providers[qualifiedSource(val.GetAttr("source").AsString())] = true
		}
	}
	return nil
}

// canonicalType renders a type constraint and its optional-attribute defaults
// in one form, so that two spellings of one type compare equal: object
// attributes are sorted, and an optional attribute carries its default.
func canonicalType(ty cty.Type, defaults *typeexpr.Defaults) string {
	switch {
	case ty.IsObjectType():
		names := make([]string, 0, len(ty.AttributeTypes()))
		for name := range ty.AttributeTypes() {
			names = append(names, name)
		}
		sort.Strings(names)
		parts := make([]string, 0, len(names))
		for _, name := range names {
			var child *typeexpr.Defaults
			if defaults != nil {
				child = defaults.Children[name]
			}
			part := name + "=" + canonicalType(ty.AttributeType(name), child)
			if ty.AttributeOptional(name) {
				part += " optional"
				if defaults != nil {
					if v, has := defaults.DefaultValues[name]; has {
						raw, err := ctyjson.Marshal(v, v.Type())
						if err != nil {
							raw = []byte("unprintable")
						}
						part += " default " + string(raw)
					}
				}
			}
			parts = append(parts, part)
		}
		return "object{" + strings.Join(parts, ", ") + "}"
	case ty.IsListType(), ty.IsSetType(), ty.IsMapType():
		var child *typeexpr.Defaults
		if defaults != nil {
			child = defaults.Children[""]
		}
		kind := "list"
		if ty.IsSetType() {
			kind = "set"
		} else if ty.IsMapType() {
			kind = "map"
		}
		return kind + "(" + canonicalType(ty.ElementType(), child) + ")"
	default:
		return ty.FriendlyNameForConstraint()
	}
}

// typeOf parses a type constraint expression.
func typeOf(expr hcl.Expression) (cty.Type, string, error) {
	ty, defaults, diags := typeexpr.TypeConstraintWithDefaults(expr)
	if diags.HasErrors() {
		return cty.NilType, "", fmt.Errorf("%s", diags.Error())
	}
	return ty, canonicalType(ty, defaults), nil
}

// checkVariables compares the module's variables with the contract's: every
// contract variable is declared with the same type and the same sensitive
// flag; a required one has no default; an optional one has a default, and
// the contract's default where the contract sets one.
func checkVariables(c *contractFile, m *module) []string {
	var problems []string
	for _, want := range c.Variables {
		block, declared := m.variables[want.Name]
		if !declared {
			problems = append(problems, fmt.Sprintf("variable %q is not declared", want.Name))
			continue
		}
		wantExpr, diags := hclsyntax.ParseExpression([]byte(want.Type), "contract.json", hcl.InitialPos)
		if diags.HasErrors() {
			problems = append(problems, fmt.Sprintf("variable %q: the contract's type does not parse: %s", want.Name, diags.Error()))
			continue
		}
		wantType, wantCanonical, err := typeOf(wantExpr)
		if err != nil {
			problems = append(problems, fmt.Sprintf("variable %q: the contract's type: %v", want.Name, err))
			continue
		}
		typeAttr, hasType := block.Body.Attributes["type"]
		if !hasType {
			problems = append(problems, fmt.Sprintf("variable %q has no type; the contract says %s", want.Name, want.Type))
			continue
		}
		_, gotCanonical, err := typeOf(typeAttr.Expr)
		if err != nil {
			problems = append(problems, fmt.Sprintf("variable %q: type: %v", want.Name, err))
			continue
		}
		if gotCanonical != wantCanonical {
			problems = append(problems, fmt.Sprintf("variable %q has the type %s; the contract says %s", want.Name, gotCanonical, wantCanonical))
		}

		sensitive := false
		if attr, has := block.Body.Attributes["sensitive"]; has {
			val, diags := attr.Expr.Value(nil)
			if diags.HasErrors() || val.Type() != cty.Bool {
				problems = append(problems, fmt.Sprintf("variable %q: sensitive is not a literal true or false", want.Name))
				continue
			}
			sensitive = val.True()
		}
		if sensitive != want.Sensitive {
			problems = append(problems, fmt.Sprintf("variable %q has sensitive = %t; the contract says %t", want.Name, sensitive, want.Sensitive))
		}

		defaultAttr, hasDefault := block.Body.Attributes["default"]
		contractDefault := strings.TrimSpace(string(want.Default))
		switch {
		case want.Required && hasDefault:
			problems = append(problems, fmt.Sprintf("variable %q has a default; the contract says it is required", want.Name))
		case !want.Required && !hasDefault:
			problems = append(problems, fmt.Sprintf("variable %q has no default; the contract says it is optional", want.Name))
		case !want.Required && contractDefault != "" && contractDefault != "null":
			wantVal, err := ctyjson.Unmarshal(want.Default, wantType)
			if err != nil {
				problems = append(problems, fmt.Sprintf("variable %q: the contract's default is not of its type: %v", want.Name, err))
				continue
			}
			gotVal, diags := defaultAttr.Expr.Value(nil)
			if diags.HasErrors() {
				problems = append(problems, fmt.Sprintf("variable %q: default is not a literal value", want.Name))
				continue
			}
			gotVal, err = convert.Convert(gotVal, wantType)
			if err != nil || !gotVal.RawEquals(wantVal) {
				problems = append(problems, fmt.Sprintf("variable %q has another default than the contract's %s", want.Name, contractDefault))
			}
		}
	}
	return problems
}

// checkBootData: boot data never replaces a node. Every resource that sets
// user_data lists it in lifecycle.ignore_changes.
func checkBootData(m *module) []string {
	var problems []string
	for _, r := range m.resources {
		if _, sets := r.Body.Attributes["user_data"]; !sets {
			continue
		}
		ignored := false
		for _, b := range r.Body.Blocks {
			if b.Type != "lifecycle" {
				continue
			}
			attr, has := b.Body.Attributes["ignore_changes"]
			if !has {
				continue
			}
			if hcl.ExprAsKeyword(attr.Expr) == "all" {
				ignored = true
				continue
			}
			list, diags := hcl.ExprList(attr.Expr)
			if diags.HasErrors() {
				continue
			}
			for _, item := range list {
				if traversal, diags := hcl.AbsTraversalForExpr(item); !diags.HasErrors() && traversal.RootName() == "user_data" {
					ignored = true
				}
			}
		}
		if !ignored {
			problems = append(problems, fmt.Sprintf("resource %s.%s sets user_data and does not list it in lifecycle.ignore_changes", r.Labels[0], r.Labels[1]))
		}
	}
	return problems
}

// nodePortsIn returns the ports of the node port range a literal names: a
// number, a quoted number, or a quoted range "low-high".
func nodePortsIn(expr hclsyntax.Expression) (hit string, found bool) {
	val, diags := expr.Value(nil)
	if diags.HasErrors() || !val.IsKnown() || val.IsNull() {
		return "", false
	}
	text := ""
	switch val.Type() {
	case cty.Number:
		text = val.AsBigFloat().Text('f', -1)
	case cty.String:
		text = val.AsString()
	default:
		return "", false
	}
	low, high, isRange := strings.Cut(text, "-")
	lowPort, err := strconv.Atoi(strings.TrimSpace(low))
	if err != nil {
		return "", false
	}
	highPort := lowPort
	if isRange {
		if highPort, err = strconv.Atoi(strings.TrimSpace(high)); err != nil {
			return "", false
		}
	}
	if lowPort <= nodePortMax && highPort >= nodePortMin {
		return text, true
	}
	return "", false
}

// checkNoNodePort: no resource of the module carries a port of the node
// port range, at any depth of its nested blocks.
func checkNoNodePort(m *module) []string {
	var problems []string
	var walk func(owner string, body *hclsyntax.Body)
	walk = func(owner string, body *hclsyntax.Body) {
		names := make([]string, 0, len(body.Attributes))
		for name := range body.Attributes {
			names = append(names, name)
		}
		sort.Strings(names)
		for _, name := range names {
			if !portAttributes[name] {
				continue
			}
			if hit, found := nodePortsIn(body.Attributes[name].Expr); found {
				problems = append(problems, fmt.Sprintf("resource %s has %s = %s, inside the node port range %d to %d", owner, name, hit, nodePortMin, nodePortMax))
			}
		}
		for _, b := range body.Blocks {
			walk(owner, b.Body)
		}
	}
	for _, r := range m.resources {
		walk(r.Labels[0]+"."+r.Labels[1], r.Body)
	}
	return problems
}

// checkContractTest: tests/contract.tftest.hcl holds the module's own header,
// the marker line once, and then the shared body byte for byte.
func checkContractTest(moduleDir string, body []byte) []string {

	if err != nil {

// templateArguments returns the argument names of every call that renders
// the shared control-plane template, one set per call.
func templateArguments(m *module) ([]map[string]bool, error) {
	var calls []map[string]bool
	var failure error
	for _, body := range m.bodies {
		_ = hclsyntax.VisitAll(body, func(node hclsyntax.Node) hcl.Diagnostics {
			call, isCall := node.(*hclsyntax.FunctionCallExpr)
			if !isCall || call.Name != "templatefile" || len(call.Args) != 2 {
				return nil
			}
			if !strings.Contains(string(call.Args[0].Range().SliceBytes(mustRead(call.Args[0].Range().Filename))), sharedTemplate) {
				return nil
			}
			object, isObject := call.Args[1].(*hclsyntax.ObjectConsExpr)
			if !isObject {
				failure = fmt.Errorf("%s: the arguments of the shared template are not an object literal", call.Range())
				return nil
			}
			names := map[string]bool{}
			for _, item := range object.Items {
				key, diags := item.KeyExpr.Value(nil)
				if diags.HasErrors() || key.Type() != cty.String {
					failure = fmt.Errorf("%s: an argument name of the shared template is not a literal", item.KeyExpr.Range())
					return nil
				}
				names[key.AsString()] = true
			}
			calls = append(calls, names)
			return nil
		})
	}
	return calls, failure
}

// mustRead reads a file that was parsed a moment ago.
func mustRead(file string) []byte {
	data, err := os.ReadFile(filepath.Clean(file))
	if err != nil {
		return nil
	}
	return data
}

func TestAddCloudRegionIfMissing(t *testing.T) {
	read := func(t *testing.T, path string) map[string]any {
		t.Helper()
		raw, err := os.ReadFile(filepath.Clean(path))
		if err != nil {
			t.Fatal(err)
		}
		var vars map[string]any
		if err := json.Unmarshal(raw, &vars); err != nil {
			t.Fatal(err)
		}
		return vars
	}
	cloudRegions := func(vars map[string]any) []any {
		var out []any
		for _, entry := range vars["regions"].([]any) {
			out = append(out, entry.(map[string]any)["cloud_region"])
		}
		return out
	}
	oldShape := `"regions": [{"code": "zone-tag-a", "role": "primary", "control_plane_size": "s", "worker_size": "w", "worker_count": 3}, {"code": "zone-tag-b", "role": "secondary", "control_plane_size": "s", "worker_size": "w", "worker_count": 3}]`

	t.Run("an entry without cloud_region gets the huawei_region of the file", func(t *testing.T) {
		path := filepath.Join(t.TempDir(), "tofu.auto.tfvars.json")
		if err := os.WriteFile(path, []byte(`{"huawei_region": "eu-test-9", "obs_bucket_name": "kept", `+oldShape+`}`), 0o600); err != nil {
			t.Fatal(err)
		}
		if err := addCloudRegionIfMissing(path, Request{HuaweiRegion: "not-read"}); err != nil {
			t.Fatal(err)
		}
		vars := read(t, path)
		if got := cloudRegions(vars); !reflect.DeepEqual(got, []any{"eu-test-9", "eu-test-9"}) {
			t.Fatalf("cloud_region of the entries = %v, want eu-test-9 twice", got)
		}
		first := vars["regions"].([]any)[0].(map[string]any)
		if first["code"] != "zone-tag-a" || first["role"] != "primary" || first["worker_count"] != float64(3) || vars["obs_bucket_name"] != "kept" {
			t.Fatalf("a value other than cloud_region changed: %v", vars)
		}
	})

	t.Run("a file without huawei_region takes the region of the request", func(t *testing.T) {
		path := filepath.Join(t.TempDir(), "tofu.auto.tfvars.json")
		if err := os.WriteFile(path, []byte(`{`+oldShape+`}`), 0o600); err != nil {
			t.Fatal(err)
		}
		if err := addCloudRegionIfMissing(path, Request{HuaweiRegion: "eu-test-7"}); err != nil {
			t.Fatal(err)
		}

			t.Fatalf("cloud_region of the entries = %v, want eu-test-7 twice", got)
		}
