# FND-033 — Checks: candidate identity, zero touch, nodes, releases and pods

## In plain words

**The problem today.** The acceptance suite does not check four basic facts about an installation: that what runs is what the release candidate names, that nobody changed the clusters by hand, that every region has the number of nodes that was asked for, and that every release and every platform pod is healthy. An older shell script checks some of this, but it runs in no pipeline, it accepts fewer nodes than were asked for, and its search for changes by hand reads the objects without the field that shows them. The record of a run does not say which chart versions and image digests ran, so two runs cannot be compared.

**What changes.** The suite gains four checks, one file each. The list of checks marks them as expected to fail, so they run and are recorded and cannot fail a run yet. The record of a run lists the chart version of every release and the digest of every platform image, per region.

**Done means:**

- The check for candidate identity fails when a release runs another chart version than the candidate pins, and when one image reference has two digests.
- The check for zero touch fails when a tracked object was changed or restarted by hand. It looks before the journeys and again after them.
- The check for nodes fails when a region has fewer or more ready nodes than were asked for, and when the run did not say how many were asked for.
- The check for releases and pods fails when a release is not ready or is stalled, when a platform container is in a crash loop, and when one has restarted more than three times.
- A region that cannot be read fails each check. It is never passed over.
- The record of a run carries the chart versions and the image digests, and the tool that checks records accepts them.
- The list of checks marks the four checks as expected to fail. A failure of one of them does not fail a run.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The acceptance suite under `tests/acceptance/sovereign/` has its first four gate checks: FND-G01 (candidate identity), FND-G02 (zero touch), FND-G03 (nodes) and FND-G04 (releases and pods). Each is one file `check_<name>.go` that registers itself. Each reads every region with `kubectl get` and fails when a region cannot be read. The gate manifest `docs/ledger/gates.yaml` names the four files and has the four entries in state `expected-fail`: a run that is given the manifest runs them and records their results, and a failure does not fail the run. The record of a run gains the object `artifacts`: the chart version of every HelmRelease and the digest of every image of the platform namespaces, per region. `scripts/acceptance-gate.py validate-record` accepts that object. The suite gains the flag `--nodes-requested`, which tells it how many nodes each region was asked for.

## 3. The model (the law)
1. The seventeen files of work step 5 are the result of the embedded patch `FND-033.patch`, byte for byte. Work step 5 states the checksum of each. `docs/ledger/gates.yaml` is changed by the four commands of work steps 7 to 10 and by nothing else: eight lines are added and four are removed.
2. A gate check of the suite is one file in `tests/acceptance/sovereign/internal/suite/`. It calls `RegisterCheck` in `init()` and holds the identifier of the check as a string constant. The four files are `check_candidate.go` (FND-G01), `check_zero_touch.go` (FND-G02), `check_nodes.go` (FND-G03) and `check_releases.go` (FND-G04).
3. Every check reads every region of `CheckContext.Regions`, through `kube.Region`, with `kubectl get`. A region that cannot be read fails the step that reads it. No region is passed over. A step that finds nothing to inspect fails with the words `nothing was measured`.
4. A platform namespace is a namespace that does not carry the label `openova.io/organization`. The organization controller puts that label on the host namespace of every Organization. `kube.Region.PlatformPods` returns the pods of the platform namespaces of one region. `kube.Object.Objects` returns the objects of a list inside an object.
5. A step of a check has the identifier `<check>.<n>`, for example `FND-G03.1`. `n` counts the steps of that check from 1, in the order they are recorded. The name of a step that reads one region holds the identifier of that region.
6. FND-G01, candidate identity. Its steps, in order:
   - One step: the suite was built from the candidate commit. The value of `suite_git_sha` in the record (the function `gitSHA` gives it) must equal `CheckContext.Candidate.Commit`. The step fails when the candidate commit is empty and when the two differ.
   - One step: the pins are read. The check reads every file `*.yaml` in `clusters/_template/bootstrap-kit/` under `CheckContext.RepoRoot`. For each HelmRelease document it takes the namespace and the name (`metadata`), the chart (`spec.chart.spec.chart`) and the version (`spec.chart.spec.version`). The suite has no YAML library, so the files are read by indentation, and a value counts only at the exact path of its keys. A HelmRelease document without a name or without a version is an error. The step fails when no pin is found.
   - For each region, one step: every HelmRelease of every namespace is listed. Its deployed version is the `chartVersion` of the first entry of `status.history` whose `status` is `deployed`, and is empty when there is no such entry. A HelmRelease is compared when the candidate pins it (the same namespace and name) and its `spec.suspend` is not `true`. The step fails when the deployed version of a compared HelmRelease differs from its pin. A HelmRelease that is not pinned, or is suspended, is listed and not compared. A pin without a HelmRelease in the region is written into the evidence (`pinned_and_absent`) and does not fail the step.
   - For each region, one step: every container and every init container of every pod of the platform namespaces is read. Its reference is the `image` of the pod specification. Its digest is the text after the last `@` in the `imageID` of the container status of the same name. The step fails when a container has no digest, and when one reference has more than one digest in the region.
   - One last step: it fails when one reference has more than one digest across the regions, and when a region was not read in full.
7. The artifacts. FND-G01 observes them: `charts` has one entry per HelmRelease per region (`region`, `namespace`, `release`, `chart`, `version`, `pinned`; `pinned` is empty when the candidate does not pin the release), and `images` has one entry per region, reference and digest (`region`, `ref`, `digest`, `containers`, the number of containers that run it). Both lists are sorted. The check hands them over in the evidence of its last step under the key `artifacts` (the constant `ArtifactsKey`), and `Run.Finalize` moves them to the field `Artifacts` of the record (JSON `artifacts`, left out when it is absent). The check hands them over only when the pins were read and every region was read in full with one HelmRelease or more and one container or more. A run where that is not so writes no `artifacts`.
8. FND-G02, zero touch.
   - The tracked objects of a region are every HelmRelease of every namespace, and every Deployment, DaemonSet and StatefulSet of the namespaces `catalyst-system`, `cnpg-system`, `kube-system` and `flux-system`.
   - Rule one: no HelmRelease, and no Deployment or DaemonSet of `catalyst-system`, `cnpg-system` or `kube-system`, has an entry in `metadata.managedFields` whose `manager` is `kubectl` or starts with `kubectl-`.
   - Rule two: no tracked Deployment, DaemonSet or StatefulSet has the annotation `kubectl.kubernetes.io/restartedAt` on its pod template (`spec.template.metadata.annotations`).
   - There is no exemption by time and none by name.
   - The objects are read with `--show-managed-fields`. `kubectl` prints no field manager without it. An object that comes back without any field manager was not measured, and the look fails.
   - The clusters are looked at twice. The first look is the function `zeroTouchStart`. `Execute` calls it after the discovery block and before the journeys, and it looks only when FND-G02 is among the selected checks. It gives one step per region, with the identifiers `FND-G02.start.1` and `FND-G02.start.2`. `Execute` adds these steps to the record after the journeys and before the checks, so that no journey sees them. The second look is taken when the check runs.
   - The check records, for each region, one step that passes only when the step of the first look for that region is in `CheckContext.Prior` and passed, and one step that looks again.
   - Its last step is recorded `SKIP`, with the reason `not measured: the suite has no source for the retry calls of the deployment`. So the status of FND-G02 is `FAIL` when a look failed, and `SKIP` in every other case. It is never `PASS` after this package (field 11).
9. FND-G03, nodes.
   - For each region, one step: the number of nodes whose condition `Ready` has status `True` must equal `CheckContext.Deploy.NodesRequested` for that region. Fewer nodes fail and more nodes fail. The step fails when the run did not say the number for that region.
   - For each region that `NodesRequested` names and the run does not reach, one failed step.
   - The numbers come from the new flag `--nodes-requested` (environment variable `ACCEPT_NODES_REQUESTED`, default empty). Its form is `<region id>=<nodes>,<region id>=<nodes>`. A part without `=`, an empty region, a value that is not a whole number of 1 or more, and a region named twice are refused: `Execute` returns the error before the first request, and the binary prints `FATAL: --nodes-requested: ...` and exits with code 3.
10. FND-G04, releases and pods. For each region, three steps:
    - Every HelmRelease of every namespace whose `spec.suspend` is not `true` has the condition `Ready` with status `True` and does not have the condition `Stalled` with status `True`. A suspended HelmRelease is counted and not judged.
    - No container or init container of a pod of the platform namespaces waits with the reason `CrashLoopBackOff`.
    - No container or init container of a pod of the platform namespaces has a `restartCount` above 3. Every count above 0 is written into the evidence.
11. `scripts/acceptance-gate.py`: the table `RECORD` gains the optional object `artifacts`, with the two lists `charts` and `images` and the fields of item 7. A field that the table does not list is refused, as before. A record without `artifacts` stays valid; the pass rule already says that such a record is never half of a valid pair. The self-test has 105 cases.
12. `docs/ledger/gates.yaml`: the entries FND-G01, FND-G02, FND-G03 and FND-G04 have `state: expected-fail` and an `implementation` line that names their file. No other line of the file changes.
13. `tests/acceptance/sovereign/internal/suite/journeys.go`, `match.go`, `discover.go` and `registry_test.go`, `tests/acceptance/sovereign/go.mod` and `scripts/sovereign-dod-verify.sh` are not changed. The module keeps using the Go standard library only.
14. This ticket deletes no file.

+	}

+	for _, p := range pods {
+		if !organization[p.Namespace()] {
+			out = append(out, p)
+		}
+	}
+	return out, nil

+// twoDigests lists the image references that have more than one digest, in
+// one region, or across every region when region is "".
+func twoDigests(images []ImageArtifact, region string) []string {
+	seen := map[string]map[string]bool{}
+	for _, im := range images {
+		if region != "" && im.Region != region {
+			continue
+		}
+		if seen[im.Ref] == nil {
+			seen[im.Ref] = map[string]bool{}
+		}
+		seen[im.Ref][im.Digest] = true
+	}
+	out := []string{}
+	for ref, digests := range seen {

+			list := make([]string, 0, len(digests))
+			for d := range digests {
+				list = append(list, d)
+			}
+			sort.Strings(list)
+			out = append(out, ref+" has "+strings.Join(list, " and "))
+		}
+	}

+var pinKey = regexp.MustCompile(`^( *)([A-Za-z0-9_.-]+):(?: +(.*))?$`)

+// readPins reads <root>/clusters/_template/bootstrap-kit/*.yaml and returns,
+// for each HelmRelease in it, the chart and the version it names, by
+// "<namespace>/<name>". The suite has no YAML library, so the files are read
+// by indentation: a value counts only at the exact path of its key.
+func readPins(root string) (map[string]chartPin, error) {
+	if root == "" {
+		return nil, errors.New("the run has no --repo-root")
+	}
+	files, err := filepath.Glob(filepath.Join(root, filepath.FromSlash(pinsDir), "*.yaml"))
+	if err != nil {
+		return nil, err
+	}
+	sort.Strings(files)
+	pins := map[string]chartPin{}
+	for _, file := range files {
+		text, err := os.ReadFile(filepath.Clean(file))
+		if err != nil {
+			return nil, err
+		}
+		for _, doc := range strings.Split("\n"+string(text), "\n---") {
+			at := pinValues(doc)
+			if at["kind"] != "HelmRelease" {
+				continue
+			}
+			pin := chartPin{Chart: at["spec/chart/spec/chart"], Version: at["spec/chart/spec/version"]}
+			if at["metadata/name"] == "" || pin.Version == "" {
+				return nil, fmt.Errorf("%s: a HelmRelease without a name or without spec.chart.spec.version", filepath.Base(file))
+			}
+			pins[at["metadata/namespace"]+"/"+at["metadata/name"]] = pin
+		}
+	}
+	return pins, nil
+}

+// pinValues returns the scalar values of one YAML document by the path of
+// their keys, for example "spec/chart/spec/version". Comment lines and list
+// items are passed over.
+func pinValues(doc string) map[string]string {
+	type level struct {
+		indent int
+		key    string
+	}
+	stack, out := []level{}, map[string]string{}
+	for _, line := range strings.Split(doc, "\n") {
+		m := pinKey.FindStringSubmatch(strings.TrimRight(line, " \r"))
+		if m == nil {
+			continue
+		}
+		indent := len(m[1])
+		for len(stack) > 0 && stack[len(stack)-1].indent >= indent {
+			stack = stack[:len(stack)-1]
+		}
+		stack = append(stack, level{indent, m[2]})
+		value := m[3]
+		if strings.HasPrefix(value, "#") {
+			value = ""
+		} else if i := strings.Index(value, " #"); i >= 0 {
+			value = value[:i]
+		}
+		if value = strings.Trim(strings.TrimSpace(value), `"'`); value == "" {
+			continue
+		}
+		keys := make([]string, len(stack))
+		for i, l := range stack {
+			keys[i] = l.key
+		}
+		if path := strings.Join(keys, "/"); out[path] == "" {
+			out[path] = value
+		}
+	}
+	return out
+}

+func (nodesCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
+	var requested map[string]int
+	if cc.Deploy != nil {
+		requested = cc.Deploy.NodesRequested
+	}

+	next := func() string { n++; return nodesID + "." + strconv.Itoa(n) }

+		reached[region.ID] = true
+		rec.Step(next(), "ready nodes equal requested nodes in region "+region.ID, func(ev Evidence) error {
+			nodes, err := region.GetList(ctx, "nodes", "")

+			}

+			for _, node := range nodes {
+				if status, _, _, _ := node.Condition("Ready"); status == "True" {
+					ready++
+				} else {
+					notReady = append(notReady, node.Name())
+				}
+			}
+			sort.Strings(notReady)
+			ev["nodes"], ev["ready"], ev["not_ready"] = len(nodes), ready, notReady

+			if !said {
+				return fmt.Errorf("the run did not say how many nodes region %s was asked for (--nodes-requested)", region.ID)
+			}
+			ev["requested"] = want
+			if ready != want {
+				return fmt.Errorf("%d nodes are Ready in region %s and %d were requested", ready, region.ID, want)
+			}
+			return nil
+		})
+	}
+	// A requested region that this run does not reach is a failure, never a skip.
+	missing := []string{}
+	for id := range requested {
+		if !reached[id] {
+			missing = append(missing, id)
+		}
+	}
+	sort.Strings(missing)
+	for _, id := range missing {
+		rec.Step(next(), "the run reaches requested region "+id, func(ev Evidence) error {
+			ev["requested"] = requested[id]
+			return fmt.Errorf("region %s was requested with %d nodes and the run has no kubeconfig for it", id, requested[id])
+		})
+	}
+	return nil

+// parseNodesRequested reads "<region id>=<nodes>,<region id>=<nodes>".
+// An empty string gives nil: the run did not say.
+func parseNodesRequested(s string) (map[string]int, error) {
+	parts := splitList(s)
+	if len(parts) == 0 {
+		return nil, nil
+	}
+	out := map[string]int{}
+	for _, part := range parts {
+		id, number, found := strings.Cut(part, "=")
+		id = strings.TrimSpace(id)
+		nodes, err := strconv.Atoi(strings.TrimSpace(number))
+		if !found || id == "" || err != nil || nodes < 1 {
+			return nil, fmt.Errorf("--nodes-requested: %q is not <region id>=<nodes>", part)
+		}
+		if _, twice := out[id]; twice {
+			return nil, fmt.Errorf("--nodes-requested: region %s is named twice", id)
+		}
+		out[id] = nodes
+	}
+	return out, nil

+// Check FND-G02, Zero touch: nobody changed a tracked object by hand.
+//
+// The tracked objects of a region are every HelmRelease of every namespace,
+// and the Deployments, DaemonSets and StatefulSets of the namespaces in
+// zeroTouchRestartNamespaces. Two rules:
+//
+//   - no HelmRelease, and no Deployment or DaemonSet of a namespace in
+//     zeroTouchManagerNamespaces, has a field manager named kubectl or
+//     kubectl-<anything>;
+//   - no tracked Deployment, DaemonSet or StatefulSet has the annotation
+//     kubectl.kubernetes.io/restartedAt on its pod template.
+//
+// There is no exemption by time and none by name. The clusters are looked at
+// twice: zeroTouchStart looks before the journeys (the runner calls it), and
+// Run looks again when the checks run. Run fails when either look failed.
+// The steps of the first look are not seen by the journeys.
+//
+// kubectl prints field managers only with --show-managed-fields. An object
+// that comes back without any field manager was not measured, and fails.
+//
+// The third clause of the check, that the deployment record shows no retry
+// call, is recorded as SKIP: the suite has no source for it yet. A SKIP is
+// never a PASS, so this check cannot pass before that source exists.
+const zeroTouchID = "FND-G02"
+
+const restartedAtAnnotation = "kubectl.kubernetes.io/restartedAt"
+
+var (
+	zeroTouchRestartNamespaces = []string{"catalyst-system", "cnpg-system", "kube-system", "flux-system"}
+	zeroTouchManagerNamespaces = []string{"catalyst-system", "cnpg-system", "kube-system"}

+type zeroTouchCheck struct{}

+func init() { RegisterCheck(zeroTouchCheck{}) }

+func (zeroTouchCheck) ID() string { return zeroTouchID }

+func (zeroTouchCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
+	n := 0
+	next := func() string { n++; return zeroTouchID + "." + strconv.Itoa(n) }
+	for _, region := range cc.Regions {
+		rec.Step(next(), "at the start of the run no tracked object of region "+region.ID+" was changed by hand", func(ev Evidence) error {
+			ev["region"] = region.ID
+			for _, s := range cc.Prior {
+				if s.Journey != zeroTouchID || s.Evidence["region"] != region.ID {
+					continue
+				}
+				ev["start_step"], ev["inspected"], ev["offenders"] = s.ID, s.Evidence["inspected"], s.Evidence["offenders"]
+				if s.Status != Pass {
+					return errors.New(s.Error)
+				}
+				return nil
+			}
+			return fmt.Errorf("no look was taken at region %s at the start of the run", region.ID)
+		})
+		rec.Step(next(), "at the end of the run no tracked object of region "+region.ID+" was changed by hand", func(ev Evidence) error {
+			return zeroTouchLook(ctx, region, ev)
+		})
+	}
+	rec.Skip(next(), "the deployment record shows no retry call",
+		"not measured: the suite has no source for the retry calls of the deployment")
+	return nil
+}

+// zeroTouchStart takes the first look, before the journeys. It returns one
+// step per region under the identifier of the check. The runner adds these
+// steps to the record after the journeys, and Run finds them in
+// CheckContext.Prior. It returns nothing when the check is not selected.
+func zeroTouchStart(ctx context.Context, r *runner, checks []Check) []*Step {
+	if !slices.ContainsFunc(checks, func(c Check) bool { return c.ID() == zeroTouchID }) {
+		return nil
+	}
+	look := &runner{out: r.out, run: &Run{}}
+	for i, region := range []kube.Region{r.A, r.B} {
+		look.step(zeroTouchID, zeroTouchID+".start."+strconv.Itoa(i+1),
+			"first look, before the journeys: no tracked object of region "+region.ID+" was changed by hand",
+			func(ev Evidence) error { return zeroTouchLook(ctx, region, ev) })
+	}
+	return look.run.Steps
+}

+// zeroTouchLook inspects the tracked objects of one region once.
+func zeroTouchLook(ctx context.Context, region kube.Region, ev Evidence) error {
+	ev["region"] = region.ID
+	inspected, offenders, unmeasured := 0, []string{}, []string{}
+	judge := func(o kube.Object, managers, restart bool) {
+		inspected++
+		name := o.Str("kind") + " " + o.Namespace() + "/" + o.Name()
+		if managers {
+			fields := o.Objects("metadata", "managedFields")
+			if len(fields) == 0 {
+				unmeasured = append(unmeasured, name)
+			}
+			for _, f := range fields {
+				if m := f.Str("manager"); m == "kubectl" || strings.HasPrefix(m, "kubectl-") {
+					offenders = append(offenders, name+": field manager "+m+" ("+f.Str("operation")+")")
+				}
+			}
+		}
+		if at := o.Str("spec", "template", "metadata", "annotations", restartedAtAnnotation); restart && at != "" {
+			offenders = append(offenders, name+": annotation "+restartedAtAnnotation+"="+at)
+		}
+	}
+	releases, err := region.GetList(ctx, hrResource, "", "--show-managed-fields")
+	if err != nil {
+		return err
+	}
+	for _, hr := range releases {
+		judge(hr, true, false)
+	}
+	for _, ns := range zeroTouchRestartNamespaces {
+		workloads, err := region.GetList(ctx, "deployments,daemonsets,statefulsets", ns, "--show-managed-fields")
+		if err != nil {
+			return err
+		}
+		for _, w := range workloads {
+			judge(w, slices.Contains(zeroTouchManagerNamespaces, ns) && w.Str("kind") != "StatefulSet", true)
+		}
+	}
+	sort.Strings(offenders)
+	sort.Strings(unmeasured)
+	ev["inspected"], ev["offenders"] = inspected, offenders
+	switch {
+	case inspected == 0:
+		return errors.New("no tracked object was found: nothing was measured")
+	case len(unmeasured) > 0:
+		return fmt.Errorf("%d objects came back without field managers, so they were not measured: %s", len(unmeasured), strings.Join(unmeasured, "; "))
+	case len(offenders) > 0:
+		return fmt.Errorf("%d findings: %s", len(offenders), strings.Join(offenders, "; "))
+	}
+	return nil
+}
