# FND-078 — The gate's cluster jobs run as a Job on the parent

## In plain words

**The problem today.** The gate's work against a Sovereign's cluster runs on the machine of the workflow, which must reach the Sovereign's API port. A Sovereign whose API port is closed to the internet can be reached only from the parent cluster, so today it cannot be gated at all. The access to the parent that the gate needs exists, but no workflow uses it.

**What changes.** An input of both gate workflows selects where the cluster work runs: on the workflow's own machine as today, or in a short-lived Job on the parent that runs the suite of the commit under test and hands its record back. A new guard keeps that access to the two gate workflows and to jobs that cannot run on a pull request.

**Done means:**

- Both gate workflows have the input execution with the default hosted, and no input runner; every job runs on a machine hosted by GitHub.
- In parent execution the addresses read, the wait for the hand-over chain, the suite, the sign-in check FND-G07 with its browser and the regions check of the standing workflow run in a Job on the parent, from images named by digest.
- The region kubeconfigs reach the Job in a Secret of the run, never in the Job object, and the Job and its Secrets are deleted whatever happened.
- Every call from the workflow to the parent is tried again after a lost connection, at most six times.
- The dial of the API port from outside and the zero-change plan check stay on the hosted machine.
- A workflow other than the two gate workflows that names the parent's secret, runs the Job script, uses the environment gate or calls a gate workflow turns tree-guards red.
- A job that uses the access without the environment gate, with another permission than contents read and packages write, or that may run on a pull request turns tree-guards red.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`.github/workflows/foundation-gate.yaml` and `.github/workflows/foundation-gate-standing.yaml` have an input `execution`: `hosted` (the default) keeps today's behaviour on the job's own machine; `parent` runs everything that dials a Sovereign's API port in a short-lived Job on the parent cluster, created through the scoped access of FND-079 (`docs/ledger/plan/spikes/FND-079.md`). The new `scripts/gate-parent-job.sh` builds or finds the images of the Job, writes the region kubeconfigs into a Secret of the run, creates the Job, streams its log, takes the files the Job prints back out of the log, and deletes the Job and its Secrets whatever happened. The workflow then validates and commits the record as it does today. The input `runner` is removed and every job runs on `ubuntu-latest`. The new guard `scripts/check-gate-parent-access.py`, two steps of the shared job tree-guards, keeps the access to the two gate workflows. The change is the five files of the block `FND-078.patch`.

## 3. The model (the law)
1. **One input, two places.** `execution` is an input of `workflow_dispatch` (a choice of `hosted` and `parent`, default `hosted`) and of `workflow_call` (a string, default `hosted`) of `foundation-gate.yaml`, and of `workflow_dispatch` of `foundation-gate-standing.yaml`, whose calls `gate-1` and `gate-2` pass it on. `bash scripts/gate-parent-job.sh execution <value>` reads it: empty and `hosted` mean hosted, `parent` means parent, anything else stops the job with exit code 2. The default is `hosted`, so a run started without the input behaves as today.
2. **No runner input.** The input `runner` and every `inputs.runner` leave both files; every job that is not a call runs on `ubuntu-latest`.
3. **What runs in the Job (parent execution).** The job `addresses` creates a Job of mode `addresses` (reads the nodes of both regions, `scripts/gate-outside-dial.py addresses`). The job `live` creates a Job of mode `live`: the creation time of both regions, the wait of at most 180 minutes for the hand-over chain, the suite from the files of the commit under test (`sovereign-acceptance run --record`, exactly as `scripts/acceptance-sovereign.sh` runs it, minting the owner session from the Sovereign's signer when no session is given), and every step of FND-G07: the user of the run, its session minted from the Sovereign's signer into a memory volume of the Pod, the browser probe `scripts/sso-zero-click-probe.mjs` in the Pod's second container, and the deletion of the user. The job `regions` of the standing workflow creates a Job of mode `regions` (`scripts/standing-gate.py source` and `converge`, regions b then a). No session or token minted from the Sovereign's signer leaves the Job.
4. **What stays on the hosted machine.** The job `outside` (the dial of NET-G02) has no environment and no secret. CLD-G12 keeps its step in the job `live` with the same access; the access has no right in the parent's namespace `catalyst`, so the check records that the parent could not be reached until a later package gives it an API route.
5. **The images, by digest.** `gate-parent-job.sh image` pushes into `ghcr.io/openova-io/openova/conformance`: (a) the suite image of the commit under test, built with `tests/acceptance/sovereign/Containerfile` exactly as `build-conformance.yaml` builds it (tag `gate-suite-<commit>`); (b) the Job image, that suite image by digest plus the commit's files at `/opt/candidate` without media files, with `git`, PyYAML, `jq`, `curl` and `openssl`, and a `.git` whose `HEAD` names the commit (tag `gate-job-<commit>-<recipe hash>`), because a run in cloud reads its scripts and tables from the repository root; (c) the probe image, the Playwright image `v1.46.0-jammy` by digest plus the package `playwright@1.46.0` (tag `gate-probe-<recipe hash>`). A tag that already exists as one manifest is reused. Images are built with `--provenance=false --sbom=false`, one manifest each, because containerd 1.7 cannot pull an index with an attestation. The parent's node pulls them by digest, outside the Pod's network, with a pull Secret of the run (the package is private).
6. **The Secret of the run.** The region kubeconfigs, the optional owner session and the scripts the Job runs travel in a Secret of the run, mounted read-only; they are never in the Job object. A second Secret of type `kubernetes.io/dockerconfigjson` holds the pull credential of the run's own token.
7. **The Job.** Namespace `acceptance-gate`, `backoffLimit: 0`, an `activeDeadlineSeconds` per mode, `ttlSecondsAfterFinished: 3600`, `automountServiceAccountToken: false`, Pod Security restricted (non-root 65534, `RuntimeDefault` seccomp, no privilege escalation, every capability dropped), requests and limits of CPU and memory on each container, `imagePullPolicy: IfNotPresent`, no host namespace, no Service.
8. **Results through the log.** The access can read a Pod's log but can neither exec into it nor read a Secret, so the Job prints its results into its log: `GATE-OUTPUT key=value`, `GATE-SUMMARY`, `GATE-ERROR`, files as base64 between `GATE-FILE-BEGIN <path> <sha256>` and `GATE-FILE-END <path>`, and `GATE-DONE` at the end. `run` refuses a file whose SHA-256 differs, a path outside its folder, a block without its end, and a log without `GATE-DONE`. The streamed log hides the file blocks and, on GitHub, cannot issue workflow commands.
9. **A bounded retry.** Every call to the parent is tried again when its error looks like a lost connection, at most `GATE_PARENT_TRIES` times (default 6, waiting 5, 10, 15, 20 and 25 seconds); a refusal ends at once; `AlreadyExists` after a lost connection counts as the create of the attempt before. A dropped log stream is followed again.
10. **Cleanup.** `run` deletes the Job and both Secrets on every exit, and a step with `always()` after it runs `gate-parent-job.sh cleanup` with the names the run wrote, then removes the parent kubeconfig from the machine.
11. **The guard.** `scripts/check-gate-parent-access.py` reads every workflow and fails on: (P0) a workflow of its list missing; (P1) a workflow not on the list (`foundation-gate.yaml`, `foundation-gate-standing.yaml`, one constant) that names `ACCEPTANCE_PARENT_KUBECONFIG`, runs `scripts/gate-parent-job.sh`, has a job with environment `gate` or an environment given by an expression, or calls a workflow of the list; (P2) a workflow of the list with a trigger other than `workflow_dispatch`, `workflow_call`, `pull_request`, `merge_group` and `schedule`; (P3) in a workflow of the list, a job that names the secret or runs the Job script (any command but `--self-test`, `execution` and `recipe`) without environment `gate`, with a permission other than `contents: read` and `packages: write` (its own, else the workflow's; none at all fails), or whose `if` is not false on `pull_request` and on `merge_group`, read with the function `evaluate` of `scripts/check-pr-jobs.py` (rule N2); (P4) the job `outside` of `foundation-gate.yaml` with an environment or a secret. Its self-test has one failing case for each rule.

+parse_log() { # $1 the log of container gate, $2 the folder: files/, outputs, summary.md, errors
+  python3 - "$1" "$2" <<'PY'
+import base64, hashlib, os, re, sys
+log, out = sys.argv[1], sys.argv[2]
+os.makedirs(os.path.join(out, "files"), exist_ok=True)
+outputs, summary, errors, bad, done = [], [], [], [], False
+block = None
+for raw in open(log, encoding="utf-8", errors="replace"):
+    line = raw.rstrip("\n")
+    if block is not None:
+        if line == "GATE-FILE-END " + block[0]:
+            name, want, parts = block
+            block = None
+            try:
+                data = base64.b64decode("".join(parts), validate=True)
+            except ValueError:
+                bad.append("%s: not base64" % name); continue
+            if hashlib.sha256(data).hexdigest() != want:
+                bad.append("%s: the content differs from its SHA-256" % name); continue
+            path = os.path.normpath(os.path.join(out, "files", name))
+            if not path.startswith(os.path.join(out, "files") + os.sep):
+                bad.append("%s: not a path inside the folder" % name); continue
+            os.makedirs(os.path.dirname(path), exist_ok=True)
+            open(path, "wb").write(data)
+        else:
+            block[2].append(line.strip())
+        continue
+    m = re.match(r"^GATE-FILE-BEGIN (\S+) ([0-9a-f]{64})$", line)
+    if m:
+        block = (m.group(1), m.group(2), []); continue
+    if line.startswith("GATE-OUTPUT ") and "=" in line:
+        outputs.append(line[len("GATE-OUTPUT "):])
+    elif line.startswith("GATE-SUMMARY "):
+        summary.append(line[len("GATE-SUMMARY "):])
+    elif line.startswith("GATE-ERROR "):
+        errors.append(line[len("GATE-ERROR "):])
+    elif line == "GATE-DONE":
+        done = True
+if block is not None:
+    bad.append("%s: the block has no end" % block[0])
+open(os.path.join(out, "outputs"), "w").write("".join(o + "\n" for o in outputs))
+open(os.path.join(out, "summary.md"), "w").write("".join(s + "\n" for s in summary))
+open(os.path.join(out, "errors"), "w").write("".join(e + "\n" for e in errors))
+for b in bad:
+    print("gate-parent-job: a file of the Job did not arrive whole: " + b, file=sys.stderr)
+if not done:
+    print("gate-parent-job: the Job did not finish its work (no GATE-DONE line in its log)", file=sys.stderr)
+sys.exit(0 if done and not bad else 1)
+PY
+}

+cmd_run() {
+  local mode="" jimg="" pimg=""
+  RUN_OUT=""
+  while [ $# -gt 0 ]; do
+    case "$1" in
+      --mode) mode="$2"; shift 2 ;;
+      --out) RUN_OUT="$2"; shift 2 ;;
+      --job-image) jimg="$2"; shift 2 ;;
+      --probe-image) pimg="$2"; shift 2 ;;
+      *) usage ;;
+    esac
+  done
+  case "$mode" in addresses | live | regions) ;; *) echo "gate-parent-job: --mode must be addresses, live or regions" >&2; exit 2 ;; esac
+  [ -n "$RUN_OUT" ] || usage
+  [[ "$jimg" =~ $DIGEST_RE ]] || { echo "gate-parent-job: --job-image must name a digest: <repository>@sha256:<64 hex>, not '$jimg'" >&2; exit 2; }
+  if [ "$mode" = live ] && ! [[ "$pimg" =~ $DIGEST_RE ]]; then
+    echo "gate-parent-job: --probe-image must name a digest: <repository>@sha256:<64 hex>, not '$pimg'" >&2; exit 2
+  fi
+  local v
+  for v in GATE_PARENT_KUBECONFIG GATE_KUBECONFIG_A GATE_KUBECONFIG_B; do
+    [ -r "${!v:-}" ] || die "$v is not a readable file"
+  done
+  mkdir -p "$RUN_OUT"
+  local name
+  name="gate-${GITHUB_RUN_ID:-0}-${GITHUB_RUN_ATTEMPT:-1}-$mode-$(od -An -N3 -tx1 /dev/urandom | tr -d ' \n')"
+  printf '%s\n' "$name" > "$RUN_OUT/name"
+  trap 'rm -f "$RUN_OUT/secret.json" "$RUN_OUT/pull.json"; cleanup_names "$RUN_OUT"' EXIT
+  manifests "$mode" "$name" "$jimg" "${pimg:-none}" "$RUN_OUT" || die "the manifests could not be written"
+  pk create -f "$RUN_OUT/secret.json" > /dev/null || die "the Secret of the run could not be created"
+  rm -f "$RUN_OUT/secret.json"
+  if [ -s "$RUN_OUT/pull.json" ]; then
+    pk create -f "$RUN_OUT/pull.json" > /dev/null || die "the pull Secret of the run could not be created"
+    rm -f "$RUN_OUT/pull.json"
+  fi
+  pk create -f "$RUN_OUT/job.json" > /dev/null || die "the Job could not be created"
+  echo "gate-parent-job: created the Job $name in $NS on the parent" >&2
+  # 1. The Pod starts: the node pulls the images.
+  local start_deadline=$(( $(date +%s) + ${GATE_START_MINUTES:-30} * 60 )) st last=""
+  while :; do
+    st="$(pod_state "$name")" || die "the Pod of the Job could not be read"
+    [ "$st" = started ] && break
+    case "$st" in stuck*) die "the Pod of the Job cannot start: ${st#stuck }" ;; esac
+    [ "$st" != "$last" ] && echo "gate-parent-job: the Pod of the Job: $st" >&2
+    last="$st"
+    [ "$(date +%s)" -ge "$start_deadline" ] && die "the Pod of the Job did not start within ${GATE_START_MINUTES:-30} minutes; last: $st"
+    sleep "${GATE_POLL_SECONDS:-10}"
+  done
+  # 2. Stream the log until the Job has ended. A dropped stream is followed again from shortly before.
+  local tok="" state since="" t_end n=0
+  if [ "${GITHUB_ACTIONS:-}" = true ]; then tok="$(od -An -N8 -tx1 /dev/urandom | tr -d ' \n')"; echo "::stop-commands::$tok"; fi
+  while :; do
+    state="$(job_state "$name")" || state=unknown
+    [ "$state" = succeeded ] || [ "$state" = failed ] && break
+    n=$((n + 1))
+    [ "$n" -gt "${GATE_FOLLOW_MAX:-500}" ] && break
+    kubectl --kubeconfig "$GATE_PARENT_KUBECONFIG" -n "$NS" logs -f "job/$name" -c gate ${since:+--since=${since}s} 2>/dev/null | view_filter
+    t_end="$(date +%s)"
+    sleep "${GATE_POLL_SECONDS:-10}"
+    since=$(( $(date +%s) - t_end + 5 ))
+  done
+  [ -n "$tok" ] && echo "::$tok::"
+  echo "gate-parent-job: the Job ended: $state" >&2
+  # 3. The whole log, and the files the Job printed in it.
+  pk logs "job/$name" -c gate > "$RUN_OUT/gate.log" || die "the log of the Job could not be read"
+  [ "$mode" = live ] && { pk logs "job/$name" -c probe > "$RUN_OUT/probe-container.log" || true; }
+  parse_log "$RUN_OUT/gate.log" "$RUN_OUT" || return 1
+  [ -n "${GITHUB_STEP_SUMMARY:-}" ] && cat "$RUN_OUT/summary.md" >> "$GITHUB_STEP_SUMMARY"
+  local e
+  while IFS= read -r e; do [ -n "$e" ] && echo "::error::$e"; done < "$RUN_OUT/errors"
+  return 0
+}

+sso_check() { # gate check FND-G07, as the hosted step does it; the session stays in the Pod's memory

+  done
+  kc get "users/$uid/groups" -r sovereign --fields name > "$d/member.json" \
+    || { stop "the groups of the user $user could not be read"; return; }

+    || { stop "the user $user is not in both groups /sovereign-admins and /sovereign-viewers"; return; }
+  ( umask 077; mint "$user" > "$SHARED/session" ) || { stop "the session of $user could not be minted"; return; }
+  [ -s "$SHARED/session" ] || { stop "the session of $user is empty"; return; }
+  touch "$SHARED/probe.go"

+  while [ ! -e "$SHARED/probe.done" ]; do
+    [ "$(date +%s)" -ge "$deadline" ] && { stop "the browser probe did not end within ${GATE_PROBE_MINUTES:-20} minutes"; return; }
+    sleep 5
+  done
+  rc="$(cat "$SHARED/probe.rc" 2>/dev/null || echo unknown)"

+  summ ""

+inner_live() {
+  local r t born="" chain="" last="nothing was read" s complete failed current deadline rc f
+  trap '[ -e "$SHARED/probe.go" ] || touch "$SHARED/probe.skip"' EXIT
+  # When the environment was created: the earliest creation of kube-system in the two regions.
+  for r in a b; do
+    t="$(kubectl --kubeconfig "$SECRET_DIR/k$r" get namespace kube-system -o jsonpath='{.metadata.creationTimestamp}')"
+    if [[ ! "$t" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]]; then born=""; break; fi
+    if [ -z "$born" ] || [[ "$t" < "$born" ]]; then born="$t"; fi
+  done
+  out "born=$born"
+  summ "Environment created at: ${born:-not read}"
+  # Wait until the hand-over chain has ended (completed, or failed at a step), at most 180 minutes.
+  deadline=$(( $(date +%s) + 180 * 60 ))
+  while :; do
+    if s="$(kubectl --kubeconfig "$KA" -n catalyst get configmap self-sovereign-cutover-status \
+          -o jsonpath='{.data.cutoverComplete}|{.data.failedStep}|{.data.currentStep}' 2>&1)"; then
+      IFS='|' read -r complete failed current <<<"$s"
+      if [ "$complete" = true ]; then chain="completed"; break; fi
+      if [ -n "$failed" ]; then chain="failed at step $failed"; break; fi
+      last="not ended, current step: ${current:-none}"
+    else
+      last="the status ConfigMap could not be read: $s"
+    fi
+    if [ "$(date +%s)" -ge "$deadline" ]; then
+      summ "Hand-over chain: did not end within 180 minutes; last observed: $last"
+      out "chain=timeout"
+      echo "GATE-ERROR The hand-over chain did not end within 180 minutes; last observed: $last. The suite was not run."
+      return
+    fi
+    sleep 30
+  done
+  out "chain=$chain"
+  summ "Hand-over chain: $chain"
+  if [ "$chain" != completed ]; then
+    summ "Hand-over error: $(kubectl --kubeconfig "$KA" -n catalyst get configmap self-sovereign-cutover-status -o jsonpath='{.data.lastError}' 2>&1 || true)"
+  fi
+  # The suite, as scripts/acceptance-sovereign.sh runs it, from the files of the commit under test.
+  export ACCEPT_KUBECONFIG_A="$KA" ACCEPT_KUBECONFIG_B="$KB" ACCEPT_MANIFEST=/opt/conformance/gates.json \
+    ACCEPT_RUN_IN=cloud ACCEPT_REPO_ROOT=/opt/candidate ACCEPT_CONSOLE="${ACCEPT_CONSOLE:-https://console.$ENV_LABEL.omani.works}"
+  mkdir -p "$SCRATCH/record"
+  CATALYST_SESSION="$(cat "$SECRET_DIR/session" 2>/dev/null || true)"
+  if [ -z "$CATALYST_SESSION" ] && [ "${ACCEPT_MINT:-0}" = 1 ]; then CATALYST_SESSION="$(mint "")"; fi
+  export CATALYST_SESSION
+  if [ -z "$CATALYST_SESSION" ]; then
+    echo "the session is empty: no owner session was given and none could be minted" | tee "$SCRATCH/acceptance.log"
+    rc=3
+  else
+    (cd /opt/candidate && sovereign-acceptance run --env "$ENV_LABEL" --record --record-dir "$SCRATCH/record") | tee "$SCRATCH/acceptance.log"
+    rc=${PIPESTATUS[0]}
+  fi
+  unset CATALYST_SESSION
+  out "suite_rc=$rc"
+  # Gate check FND-G07, unless the run was NOT MEASURED.
+  if [ "$rc" != 4 ]; then
+    sso_check
+    sso_delete
+  fi
+  emit_file acceptance.log "$SCRATCH/acceptance.log"
+  for f in "$SCRATCH"/record/*.json; do
+    [ -f "$f" ] && emit_file "record/$(basename "$f")" "$f"
+  done
+  emit_file sso/result.json "$SCRATCH/sso/result.json"
+}

+self_test() {

+  ok() { n=$((n + 1)); if [ "$1" = 0 ]; then echo "ok   $2"; else echo "FAIL $2"; fails=$((fails + 1)); fi; }

+  # exists). It writes every call into calls, the Job state from job.state, the log from log.txt.
+  mkdir -p "$T/bin"
+  cat > "$T/bin/kubectl" <<'STUB'

+S="$STUB_DIR"
+echo "$*" >> "$S/calls"

+if [ "$c" -le "${STUB_FAIL_TIMES:-0}" ]; then echo 'Unable to connect to the server: http2: client connection lost' >&2; exit 1; fi
+case "${STUB_FINAL:-ok}" in
+  forbidden) echo 'Error from server (Forbidden): jobs.batch is forbidden' >&2; exit 1 ;;
+  exists) echo 'Error from server (AlreadyExists): jobs.batch "x" already exists' >&2; exit 1 ;;
+esac
+a=" $* "
+case "$a" in
+  *" create -f "*) f="${a#* create -f }"; f="${f%% *}"; cp "$f" "$S/created-$(basename "$f")"; echo created ;;
+  *" get job "*) printf '{"status": {%s}}\n' "$(cat "$S/job.state" 2>/dev/null)" ;;
+  *" get pods "*) echo '{"items": [{"status": {"phase": "Running", "containerStatuses": [{"name": "gate", "state": {"running": {}}}]}}]}' ;;
+  *" logs -f "*) cat "$S/log.txt"; echo '"succeeded": 1' > "$S/job.state" ;;

+  *" delete "*) echo deleted ;;

+  ok $? "retry: two lost connections, then the answer: 3 calls, done"
+  reset_stub; STUB_FAIL_TIMES=99 pk get job x >/dev/null 2>&1; [ $? = 1 ] && [ "$(calls)" = 6 ]
+  ok $? "retry: the bound: 6 calls, then failed"
+  reset_stub; STUB_FAIL_TIMES=0 STUB_FINAL=forbidden pk get job x >/dev/null 2>&1; [ $? = 1 ] && [ "$(calls)" = 1 ]
+  ok $? "retry: a refusal is not tried again"
+  reset_stub; STUB_FAIL_TIMES=1 STUB_FINAL=exists pk create -f "$T/parent.yaml" >/dev/null 2>&1; [ $? = 0 ] && [ "$(calls)" = 2 ]
+  ok $? "retry: AlreadyExists after a lost connection is the create of the attempt before"
+  reset_stub; STUB_FAIL_TIMES=0 STUB_FINAL=exists pk create -f "$T/parent.yaml" >/dev/null 2>&1; [ $? = 1 ]
