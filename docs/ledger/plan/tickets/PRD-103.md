# PRD-103 — Ledger port and conformance kit

## In plain words

**The problem today.** The open-banking product must reach a bank's core-banking system, and nothing in the product says how. Without one fixed interface and a way to test it, every bank adapter would be written to a guess, and a broken adapter would be found only by a customer.

**What changes.** The product gains the ledger port: fourteen operations with fixed messages and fixed error codes, and the Go code generated from it. A conformance kit calls every operation and checks formats, paging, repeated payments and error codes; a small program runs it against any ledger, and an in-memory ledger passes it.

**Done means:**

- The port file names fourteen operations, and a test fails when the port file and the generated Go code disagree.
- The conformance program run against the in-memory ledger reports 41 of 41 checks passed and 14 of 14 operations called, and exits with code 0.
- Fourteen deliberately broken ledgers each make the kit report the check that catches the defect.
- Against a ledger served over TLS with a certificate it does not trust, the program fails instead of passing.
- The new dependencies of the product have no known vulnerability on the day the change is made, and the scan of every pull request finds nothing new.
- Every test of the product, the older packages included, passes on every pull request that changes it.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The open-banking product `products/fingate` holds its ledger port, the only way the product reaches core banking: the file `api/ledger/v1/ledger.proto`, a gRPC service `openova.fingate.ledger.v1.Ledger` of 14 operations, and the Go code generated from it (`ledger.pb.go`, `ledger_grpc.pb.go`, package `ledgerv1`). The package `internal/ledgertest` holds the conformance kit, `Run`, which calls all 14 operations against a ledger and reports one named check each for formats, paging, repeated payments and error codes, and an in-memory ledger, `Memory`, that passes it. The program `cmd/fingate-ledger-conformance` runs the kit, with `--target inmemory` against the in-memory ledger or with `--target <host:port> --fixture <file>` against any ledger served over TLS. `go run ./cmd/fingate-ledger-conformance --target inmemory`, run in `products/fingate`, prints `checks passed: 41/41` and `operations called: 14/14` and exits 0. The module gains the gRPC and protobuf libraries and moves to Go 1.26.0. Every test of the module runs on every pull request that changes it.

## 3. The model (the law)
1. **The port.** `products/fingate/api/ledger/v1/ledger.proto` is the block `ledger.proto` of this ticket. Its service `Ledger` has exactly these 14 operations: `GetCapabilities`, `ResolveCustomer`, `ListAccounts`, `GetAccount`, `ListBalances`, `ListTransactions`, `ListBeneficiaries`, `ListStandingOrders`, `ListDirectDebits`, `ListScheduledPayments`, `GetParty`, `CheckFunds`, `SubmitPayment`, `GetPayment`. Amounts are decimal strings, currencies ISO 4217 codes, times RFC 3339. The error codes are fixed: `NOT_FOUND` (unknown customer, account or payment), `PERMISSION_DENIED` (the account is not the customer's), `FAILED_PRECONDITION` (the ledger refuses the payment; the status message says why), `UNIMPLEMENTED` (a resource or payment type absent from `Capabilities`), `UNAVAILABLE` (retry is safe), `ALREADY_EXISTS` (an idempotency key reused with different content). The port has no consent, subscription, token or event operation. Version 1 carries domestic payments only: `domestic`, `domestic-scheduled`, `domestic-standing-order`.
2. **Generated code.** `ledger.pb.go` and `ledger_grpc.pb.go` are the output of protoc 3.12.4 with protoc-gen-go v1.36.12 and protoc-gen-go-grpc v1.6.1, run in `products/fingate` with the command written in the port file. They are copied from this ticket and never edited by hand. The test `TestGeneratedCodeMatchesTheProtoFile` compares every operation, message and field number of the port file with the descriptor compiled into `ledger.pb.go` and fails when they differ. No `//go:generate` directive is added: the executor and CI have no protoc.
3. **Dependencies.** `products/fingate/go.mod` is the block `go.mod`: `go 1.26.0`; direct requirements `google.golang.org/grpc v1.85.0`, `google.golang.org/protobuf v1.36.12`, `gopkg.in/yaml.v3 v3.0.1`; indirect `golang.org/x/net v0.62.0`, `golang.org/x/sys v0.49.0`, `golang.org/x/text v0.43.0`, `google.golang.org/genproto/googleapis/rpc v0.0.0-20260817212433-ac3dfec99bb1`. `go.sum` is the block `go.sum`. Go 1.26.0 is required because `golang.org/x/net v0.62.0`, the first version without a known vulnerability, declares it.
4. **The kit** (`internal/ledgertest/kit.go`). `Run(ctx, cc grpc.ClientConnInterface, fx Fixture) *Report` calls the ledger behind `cc`. The fixture names two identities that resolve to two different customers, an account of the first that can pay `Amount` and cannot pay `RefusedAmount`, and a creditor. The kit asserts: capabilities name only the five resources and three payment types of the port and at least one currency; an amount matches `^\d{1,13}$|^\d{1,13}\.\d{1,5}$`, a currency is three capital letters, a time is RFC 3339, a credit or debit indicator is `Credit` or `Debit`, a payment status is `pending`, `accepted`, `settled` or `rejected`; walking a list with pages of one and of two gives the same items in the same order, no page holds more than asked, no item repeats, and at least one account has two transactions; the same idempotency key with the same content returns the same payment and with other content is `ALREADY_EXISTS`; each error code above except `UNAVAILABLE`, which a caller cannot provoke, is produced where the port says; and every one of the 14 operations was called. A resource or payment type absent from the capabilities must answer `UNIMPLEMENTED`. Against a ledger that offers everything the run has 41 named checks; `Report.Print` writes one line `PASS <name>` or `FAIL <name>: <reason>` per check, then `checks passed: <n>/<total>` and `operations called: <n>/14`.
5. **The in-memory ledger** (`internal/ledgertest/memory.go`). `NewMemory(caps)` serves a fixed data set: subject `alice` of scheme `kit` is customer `cust-alice` with accounts `acc-1001` (1000.00 GBP, three transactions, one item of each other list) and `acc-1002` (50.00 GBP); subject `bob` is `cust-bob` with `acc-2001`. `MemoryFixture()` describes it. `FullCapabilities()` offers everything in GBP. `Serve(srv, opts...)` serves any ledger over an in-process connection with no network. Pages are 50 items when no size is given, at most 100.
6. **The program** (`cmd/fingate-ledger-conformance/main.go`). Flags: `--target` (`inmemory`, or `host:port` of a ledger served over TLS), `--fixture` (a JSON file with the keys `customer`, `other_customer`, `debtor_account_id`, `amount`, `refused_amount`, `creditor_name`, `creditor_scheme_name`, `creditor_identification`; an unknown key is an error), `--ca-file`, `--server-name`, `--timeout`. TLS 1.2 is the lowest version accepted. Exit code 0: every check passed; 1: a check failed; 2: the run could not start.
7. Nothing else changes: no file outside the paths of field 14, no workflow, no chart, no server of the product.

// that passes it.
//
// Run calls every operation of the port against a ledger and returns one result per named
// check. A ledger conforms when no check fails. The kit reads the ledger through a fixture:
// two identities that resolve to two different customers, an account of the first customer

// payments, so it is run against a test ledger only.

//

//   - Every field the port fixes has its format: an amount matches ^\d{1,13}$|^\d{1,13}\.\d{1,5}$,

func Run(ctx context.Context, cc grpc.ClientConnInterface, fx Fixture) *Report {
	cnt := &counting{cc: cc, seen: map[string]bool{}}
	k := &kit{ctx: ctx, c: ledgerv1.NewLedgerClient(cnt), fx: fx, run: runID()}
	if err := fx.Validate(); err != nil {
		k.check("fixture", err)
	} else {
		k.all()
	}
	rep := &Report{Results: k.results, Operations: len(ledgerv1.Ledger_ServiceDesc.Methods)}
	for m := range cnt.seen {
		rep.Called = append(rep.Called, m[strings.LastIndex(m, "/")+1:])
	}
	sort.Strings(rep.Called)
	var missing []string
	for _, m := range ledgerv1.Ledger_ServiceDesc.Methods {
		if !slices.Contains(rep.Called, m.MethodName) {
			missing = append(missing, m.MethodName)
		}

	if len(missing) > 0 {
		err = fmt.Errorf("not called: %s", strings.Join(missing, ", "))
	}
	rep.Results = append(rep.Results, Result{Name: "every-operation-called", Err: err})
	return rep
}

		return time.Now().UTC().Format("20060102T150405.000000000")
	}
	return hex.EncodeToString(b)
}

// wantCode returns nil when err carries the code want.
func wantCode(err error, want codes.Code) error {
	if err == nil {
		return fmt.Errorf("the call succeeded; want %s", want)
	}
	if got := status.Code(err); got != want {
		return fmt.Errorf("got %s (%s); want %s", got, status.Convert(err).Message(), want)
	}
	return nil
}

func checkMoney(field string, m *ledgerv1.Money) error {
	if m == nil {
		return fmt.Errorf("%s is not set", field)
	}
	if !amountRE.MatchString(m.GetAmount()) {
		return fmt.Errorf("%s.amount %q is not an amount", field, m.GetAmount())
	}
	if !currencyRE.MatchString(m.GetCurrency()) {
		return fmt.Errorf("%s.currency %q is not an ISO 4217 code", field, m.GetCurrency())
	}
	return nil
}

// checkTime checks an RFC 3339 time; an empty value passes unless it is required.
func checkTime(field, v string, required bool) error {
	if v == "" {
		if required {
			return fmt.Errorf("%s is empty", field)
		}
		return nil
	}
	if _, err := time.Parse(time.RFC3339, v); err != nil {
		return fmt.Errorf("%s %q is not an RFC 3339 time", field, v)
	}
	return nil
}

func checkCreditDebit(field, v string) error {
	if v != "Credit" && v != "Debit" {
		return fmt.Errorf("%s %q is neither Credit nor Debit", field, v)
	}
	return nil
}

func firstErr(errs ...error) error {
	for _, err := range errs {
		if err != nil {
			return err
		}
	}
	return nil
}

func validCapabilities(c *ledgerv1.Capabilities) error {
	for _, set := range []struct {
		name    string
		got     []string
		allowed []string
	}{{"resources", c.GetResources(), Resources}, {"payment_types", c.GetPaymentTypes(), PaymentTypes}} {
		seen := map[string]bool{}
		for _, v := range set.got {
			if !slices.Contains(set.allowed, v) {
				return fmt.Errorf("%s holds %q, which the port does not know", set.name, v)
			}
			if seen[v] {

			seen[v] = true
		}
	}
	if len(c.GetCurrencies()) == 0 {
		return errors.New("currencies is empty")
	}
	for _, v := range c.GetCurrencies() {
		if !currencyRE.MatchString(v) {
			return fmt.Errorf("currency %q is not an ISO 4217 code", v)
		}
	}
	return nil
}

func (k *kit) accounts() bool {
	accs, err := k.listAccounts(k.cust)
	if err == nil && len(accs) == 0 {
		err = errors.New("the customer has no account")
	}
	seen := map[string]bool{}
	for _, a := range accs {
		if err != nil {
			break
		}
		err = validAccount(a)
		if err == nil && seen[a.GetAccountId()] {
			err = fmt.Errorf("account %s is listed twice", a.GetAccountId())
		}
		seen[a.GetAccountId()] = true
	}
	if err == nil && !seen[k.fx.DebtorAccountID] {
		err = fmt.Errorf("debtor_account_id %s is not an account of the customer", k.fx.DebtorAccountID)
	}
	k.check("list-accounts", err)
	if err != nil {
		return false
	}
	k.accs = accs

	_, err = k.listAccounts("fingate-conformance-unknown-" + k.run)
	k.check("list-accounts-unknown-customer", wantCode(err, codes.NotFound))

	err = nil
	for _, a := range accs {
		ctx, cancel := k.call()
		got, gerr := k.c.GetAccount(ctx, &ledgerv1.GetAccountRequest{CustomerId: k.cust, AccountId: a.GetAccountId()})
		cancel()
		if gerr != nil {
			err = fmt.Errorf("account %s: %w", a.GetAccountId(), gerr)
			break
		}
		if !proto.Equal(got, a) {
			err = fmt.Errorf("account %s: reading it alone differs from its entry in the list", a.GetAccountId())
			break
		}
	}
	k.check("get-account", err)

	ctx, cancel := k.call()
	_, err = k.c.GetAccount(ctx, &ledgerv1.GetAccountRequest{CustomerId: k.cust, AccountId: "fingate-conformance-unknown-" + k.run})
	cancel()
	k.check("get-account-unknown", wantCode(err, codes.NotFound))

	others, err := k.listAccounts(k.other)
	if err == nil && len(others) == 0 {
		err = errors.New("the other customer has no account")
	}
	if err != nil {
		k.check("get-account-not-owned", fmt.Errorf("listing the other customer's accounts: %w", err))
		return false
	}
	k.foreign = others[0].GetAccountId()
	ctx, cancel = k.call()
	_, err = k.c.GetAccount(ctx, &ledgerv1.GetAccountRequest{CustomerId: k.cust, AccountId: k.foreign})
	cancel()
	k.check("get-account-not-owned", wantCode(err, codes.PermissionDenied))
	return true
}

// page is one page of a list: the identifiers of its items, each item's own check, and the
// token of the next page.
type page struct {
	ids  []string
	errs []error
	next string
}

// lister fetches one page of one account's list.
type lister func(ctx context.Context, account, token string, size int32) (page, error)

// walk reads the whole list of an account with pages of the given size.
func (k *kit) walk(l lister, account string, size int32) ([]string, error) {
	var ids []string
	token := ""
	for n := 0; ; n++ {
		if n == 1000 {
			return nil, errors.New("more than 1000 pages")
		}
		ctx, cancel := k.call()
		p, err := l(ctx, account, token, size)
		cancel()
		if err != nil {
			return nil, err
		}
		if len(p.ids) > int(size) {
			return nil, fmt.Errorf("a page of size %d holds %d items", size, len(p.ids))
		}
		if err := firstErr(p.errs...); err != nil {
			return nil, err
		}
		ids = append(ids, p.ids...)
		if p.next == "" {
			break
		}
		token = p.next
	}
	seen := map[string]bool{}
	for _, id := range ids {
		if id == "" {
			return nil, errors.New("an item has an empty identifier")
		}
		if seen[id] {
			return nil, fmt.Errorf("item %s appears twice", id)
		}
		seen[id] = true
	}
	return ids, nil
}

// paged checks one list on every account with pages of one and of two. It returns the most
// items one account holds.
func (k *kit) paged(l lister) (int, error) {
	most := 0
	for _, a := range k.accs {
		one, err := k.walk(l, a.GetAccountId(), 1)
		if err != nil {
			return 0, fmt.Errorf("account %s, pages of 1: %w", a.GetAccountId(), err)
		}
		two, err := k.walk(l, a.GetAccountId(), 2)
		if err != nil {
			return 0, fmt.Errorf("account %s, pages of 2: %w", a.GetAccountId(), err)
		}
		if !slices.Equal(one, two) {
			return 0, fmt.Errorf("account %s: pages of 1 give %v, pages of 2 give %v", a.GetAccountId(), one, two)
		}
		most = max(most, len(one))
	}
	return most, nil
}

func (k *kit) transactions() {
	l := func(ctx context.Context, account, token string, size int32) (page, error) {
		r, err := k.c.ListTransactions(ctx, &ledgerv1.ListTransactionsRequest{CustomerId: k.cust, AccountId: account, PageToken: token, PageSize: size})
		p := page{next: r.GetNextPageToken()}
		for _, t := range r.GetTransactions() {
			pre := "transaction " + t.GetTransactionId()
			p.ids = append(p.ids, t.GetTransactionId())
			p.errs = append(p.errs, firstErr(checkMoney(pre+": amount", t.GetAmount()), checkCreditDebit(pre+": credit_debit", t.GetCreditDebit()),
				nonEmpty(pre+": status", t.GetStatus()), checkTime(pre+": booked_at", t.GetBookedAt(), true),
				checkTime(pre+": value_at", t.GetValueAt(), false)))
			if t.GetBalanceAfter() != nil {
				p.errs = append(p.errs, checkMoney(pre+": balance_after", t.GetBalanceAfter()))
			}
		}
		return p, err
	}
	most, err := k.paged(l)
	if err == nil && most < 2 {
		err = errors.New("no account of the customer has two transactions, so no walk crosses a page")
	}
	k.check("list-transactions", err)
	ctx, cancel := k.call()
	_, err = k.c.ListTransactions(ctx, &ledgerv1.ListTransactionsRequest{CustomerId: k.cust, AccountId: k.foreign, PageSize: 1})
	cancel()
	k.check("list-transactions-not-owned", wantCode(err, codes.PermissionDenied))
}

func (k *kit) pagedResources() {
	req := func(account, token string, size int32) *ledgerv1.AccountPageRequest {
		return &ledgerv1.AccountPageRequest{CustomerId: k.cust, AccountId: account, PageToken: token, PageSize: size}
	}
	listers := map[string]lister{
		"beneficiaries": func(ctx context.Context, account, token string, size int32) (page, error) {
			r, err := k.c.ListBeneficiaries(ctx, req(account, token, size))
			p := page{next: r.GetNextPageToken()}
			for _, x := range r.GetItems() {
				p.ids = append(p.ids, x.GetBeneficiaryId())
			}
			return p, err
		},
		"standing-orders": func(ctx context.Context, account, token string, size int32) (page, error) {
			r, err := k.c.ListStandingOrders(ctx, req(account, token, size))
			p := page{next: r.GetNextPageToken()}
			for _, x := range r.GetItems() {
				pre := "standing order " + x.GetStandingOrderId()
				p.ids = append(p.ids, x.GetStandingOrderId())
				p.errs = append(p.errs, checkTime(pre+": next_at", x.GetNextAt(), false), checkTime(pre+": final_at", x.GetFinalAt(), false))
				if x.GetNextAmount() != nil {
					p.errs = append(p.errs, checkMoney(pre+": next_amount", x.GetNextAmount()))
				}
			}
			return p, err
		},
		"direct-debits": func(ctx context.Context, account, token string, size int32) (page, error) {
			r, err := k.c.ListDirectDebits(ctx, req(account, token, size))
			p := page{next: r.GetNextPageToken()}
			for _, x := range r.GetItems() {
				pre := "direct debit " + x.GetDirectDebitId()
				p.ids = append(p.ids, x.GetDirectDebitId())
				p.errs = append(p.errs, checkTime(pre+": previous_at", x.GetPreviousAt(), false))
				if x.GetPreviousAmount() != nil {
					p.errs = append(p.errs, checkMoney(pre+": previous_amount", x.GetPreviousAmount()))
				}
			}
			return p, err
		},
		"scheduled-payments": func(ctx context.Context, account, token string, size int32) (page, error) {
			r, err := k.c.ListScheduledPayments(ctx, req(account, token, size))
			p := page{next: r.GetNextPageToken()}
			for _, x := range r.GetItems() {
				pre := "scheduled payment " + x.GetScheduledPaymentId()
				p.ids = append(p.ids, x.GetScheduledPaymentId())
				p.errs = append(p.errs, checkMoney(pre+": amount", x.GetAmount()), checkTime(pre+": execution_at", x.GetExecutionAt(), true))
			}
			return p, err
		},
	}
	for _, res := range []string{"beneficiaries", "standing-orders", "direct-debits", "scheduled-payments"} {
		l := listers[res]
		if !slices.Contains(k.caps.GetResources(), res) {
			ctx, cancel := k.call()
			_, err := l(ctx, k.accs[0].GetAccountId(), "", 1)
			cancel()
			k.check("list-"+res+"-unimplemented", wantCode(err, codes.Unimplemented))
			continue
		}
		_, err := k.paged(l)
		k.check("list-"+res, err)
		ctx, cancel := k.call()
		_, err = l(ctx, k.foreign, "", 1)
		cancel()
		k.check("list-"+res+"-not-owned", wantCode(err, codes.PermissionDenied))
	}
}

// paymentRequest builds a payment of the given type from the debtor account.
func (k *kit) paymentRequest(typ, key, amount string) *ledgerv1.SubmitPaymentRequest {
	money := &ledgerv1.Money{Amount: amount, Currency: k.debtorCurrency()}
	r := &ledgerv1.SubmitPaymentRequest{
		IdempotencyKey: key, CustomerId: k.cust, DebtorAccountId: k.fx.DebtorAccountID, Type: typ, Amount: money,
		CreditorName: k.fx.CreditorName, CreditorSchemeName: k.fx.CreditorSchemeName, CreditorIdentification: k.fx.CreditorIdentification,
		Reference: "conformance " + k.run, EndToEndId: key,
	}
	tomorrow := time.Now().UTC().Add(24 * time.Hour).Truncate(time.Second)
	switch typ {
	case "domestic-scheduled":
		r.RequestedExecutionAt = tomorrow.Format(time.RFC3339)
	case "domestic-standing-order":
		r.Recurrence = &ledgerv1.Recurrence{Frequency: "MNTH", FirstPaymentAt: tomorrow.Format(time.RFC3339), NumberOfPayments: 3,
			FirstAmount: &ledgerv1.Money{Amount: amount, Currency: money.GetCurrency()}}
	}
	return r
}

func (k *kit) submit(r *ledgerv1.SubmitPaymentRequest) (*ledgerv1.Payment, error) {
	ctx, cancel := k.call()
	defer cancel()
	return k.c.SubmitPayment(ctx, r)
}

func validPayment(p *ledgerv1.Payment) error {
	if p.GetPaymentId() == "" {
		return errors.New("payment_id is empty")
	}
	if !slices.Contains(paymentStatuses, p.GetStatus()) {
		return fmt.Errorf("payment %s: status %q is not one of %s", p.GetPaymentId(), p.GetStatus(), strings.Join(paymentStatuses, ", "))
	}
	return checkTime("payment "+p.GetPaymentId()+": status_at", p.GetStatusAt(), true)
}

func (k *kit) payments() {
	for _, typ := range PaymentTypes {
		if !slices.Contains(k.caps.GetPaymentTypes(), typ) {
			_, err := k.submit(k.paymentRequest(typ, k.key(), k.fx.Amount))
			k.check("submit-payment-"+typ+"-unimplemented", wantCode(err, codes.Unimplemented))
			continue
		}
		req := k.paymentRequest(typ, k.key(), k.fx.Amount)
		p, err := k.submit(req)
		if err == nil {
			err = validPayment(p)
		}
		k.check("submit-payment-"+typ, err)
		if err != nil {
			continue
		}
		again, err := k.submit(proto.Clone(req).(*ledgerv1.SubmitPaymentRequest))
		if err == nil && again.GetPaymentId() != p.GetPaymentId() {
			err = fmt.Errorf("the same key and content gave payment %s, then %s", p.GetPaymentId(), again.GetPaymentId())
		}
		k.check("idempotent-resubmission-"+typ, err)
		ctx, cancel := k.call()
		got, err := k.c.GetPayment(ctx, &ledgerv1.GetPaymentRequest{PaymentId: p.GetPaymentId()})
		cancel()
		if err == nil {
			err = validPayment(got)
		}
		if err == nil && got.GetPaymentId() != p.GetPaymentId() {
			err = fmt.Errorf("reading payment %s back returned payment %s", p.GetPaymentId(), got.GetPaymentId())
		}
		k.check("get-payment-"+typ, err)
		if typ == "domestic" {
			changed := proto.Clone(req).(*ledgerv1.SubmitPaymentRequest)
			changed.Reference += " changed"
			_, err = k.submit(changed)
			k.check("idempotency-key-conflict", wantCode(err, codes.AlreadyExists))
		}
	}
	if slices.Contains(k.caps.GetPaymentTypes(), "domestic") {
		_, err := k.submit(k.paymentRequest("domestic", k.key(), k.fx.RefusedAmount))
		if werr := wantCode(err, codes.FailedPrecondition); werr != nil {
			err = werr
		} else if status.Convert(err).Message() == "" {
			err = errors.New("the refusal carries no status message")
		} else {
			err = nil
		}
		k.check("submit-payment-refused", err)
		r := k.paymentRequest("domestic", k.key(), k.fx.Amount)
		r.DebtorAccountId = k.foreign
		_, err = k.submit(r)
		k.check("submit-payment-not-owned", wantCode(err, codes.PermissionDenied))
		r = k.paymentRequest("domestic", k.key(), k.fx.Amount)
		r.DebtorAccountId = "fingate-conformance-unknown-" + k.run
		_, err = k.submit(r)
		k.check("submit-payment-unknown-account", wantCode(err, codes.NotFound))
	}
	ctx, cancel := k.call()
	_, err := k.c.GetPayment(ctx, &ledgerv1.GetPaymentRequest{PaymentId: "fingate-conformance-unknown-" + k.run})
	cancel()
	k.check("get-payment-unknown", wantCode(err, codes.NotFound))
}

// owned returns the account when the customer exists and holds it.
func (m *Memory) owned(customer, account string) (*memAccount, error) {
	if _, ok := m.customers[customer]; !ok {
		return nil, status.Errorf(codes.NotFound, "unknown customer %q", customer)
	}
	a, ok := m.accounts[account]
	if !ok {
		return nil, status.Errorf(codes.NotFound, "unknown account %q", account)
	}
	if a.owner != customer {
		return nil, status.Errorf(codes.PermissionDenied, "account %q is not the customer's", account)
	}
	return a, nil
}

// window returns the bounds of one page of n items and the token of the next page.
func window(n int, token string, size int32) (int, int, string, error) {
	from := 0
	if token != "" {
		v, err := strconv.Atoi(token)
		if err != nil || v < 0 || v > n {
			return 0, 0, "", status.Errorf(codes.InvalidArgument, "page_token %q is not one this ledger issued", token)
		}
		from = v
	}
	limit := int(size)
	if limit <= 0 {
		limit = defaultPageSize
	}
	limit = min(limit, maxPageSize)
	to := min(n, from+limit)
	next := ""
	if to < n {
		next = strconv.Itoa(to)
	}
	return from, to, next, nil
}

// pageOf returns one page of a list of messages, cloned.
func pageOf[T proto.Message](items []T, token string, size int32) ([]T, string, error) {
	from, to, next, err := window(len(items), token, size)
	if err != nil {
		return nil, "", err
	}
	out := make([]T, 0, to-from)
	for _, x := range items[from:to] {
		out = append(out, proto.Clone(x).(T))
	}
	return out, next, nil
}

// unit is one currency unit in hundred-thousandths, the finest step an amount of the port has.
const unit = 100000

// decimal parses an amount of the port into hundred-thousandths; ok is false when it is not one.
func decimal(s string) (int64, bool) {
	if !amountRE.MatchString(s) {
		return 0, false
	}
	whole, frac, _ := strings.Cut(s, ".")
	v, err := strconv.ParseInt(whole+frac+strings.Repeat("0", 5-len(frac)), 10, 64)
	return v, err == nil
}

// formatAmount writes hundred-thousandths as an amount of the port with two to five decimals.
func formatAmount(v int64) string {
	s := fmt.Sprintf("%d.%05d", v/unit, v%unit)
	for strings.HasSuffix(s, "0") && len(s)-strings.Index(s, ".") > 3 {
		s = s[:len(s)-1]
	}
	return s
}

// amountOn parses an amount in the account's currency.
func amountOn(a *memAccount, money *ledgerv1.Money) (int64, error) {
	v, ok := decimal(money.GetAmount())
	if !ok {
		return 0, status.Errorf(codes.InvalidArgument, "amount %q is not an amount", money.GetAmount())
	}
	if money.GetCurrency() != a.account.GetCurrency() {
		return 0, status.Errorf(codes.InvalidArgument, "currency %q is not the account's %s", money.GetCurrency(), a.account.GetCurrency())
	}
	return v, nil
}

	}

}

// SubmitPayment makes a payment once per idempotency key.
func (m *Memory) SubmitPayment(_ context.Context, r *ledgerv1.SubmitPaymentRequest) (*ledgerv1.Payment, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	if r.GetIdempotencyKey() == "" {
		return nil, status.Error(codes.InvalidArgument, "idempotency_key is empty")
	}
	if prev, ok := m.keys[r.GetIdempotencyKey()]; ok {
		if !proto.Equal(prev.req, r) {
			return nil, status.Error(codes.AlreadyExists, "the idempotency key was used with other content")
		}
		return proto.Clone(prev.payment).(*ledgerv1.Payment), nil
	}
	if !m.has(m.caps.GetPaymentTypes(), r.GetType()) {
		return nil, status.Errorf(codes.Unimplemented, "this ledger does not offer payment type %q", r.GetType())
	}
	if (r.GetType() == "domestic-standing-order") != (r.GetRecurrence() != nil) {
		return nil, status.Error(codes.InvalidArgument, "recurrence is set exactly when the type is domestic-standing-order")
	}
	a, err := m.owned(r.GetCustomerId(), r.GetDebtorAccountId())
	if err != nil {
		return nil, err
	}
	v, err := amountOn(a, r.GetAmount())
	if err != nil {
		return nil, err
	}
	if a.balance < v {
		return nil, status.Error(codes.FailedPrecondition, "insufficient funds")
	}
	m.seq++
	p := &ledgerv1.Payment{PaymentId: fmt.Sprintf("pay-%d", m.seq), Status: "pending", StatusAt: now()}
	if r.GetType() == "domestic" && r.GetRequestedExecutionAt() == "" {
		a.balance -= v
		p.Status = "accepted"
	}
	m.payments[p.GetPaymentId()] = p
	m.keys[r.GetIdempotencyKey()] = &memPayment{req: proto.Clone(r).(*ledgerv1.SubmitPaymentRequest), payment: p}
	return proto.Clone(p).(*ledgerv1.Payment), nil
}

// GetPayment returns a payment by its identifier.
func (m *Memory) GetPayment(_ context.Context, r *ledgerv1.GetPaymentRequest) (*ledgerv1.Payment, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	p, ok := m.payments[r.GetPaymentId()]
	if !ok {
		return nil, status.Errorf(codes.NotFound, "unknown payment %q", r.GetPaymentId())
	}
	return proto.Clone(p).(*ledgerv1.Payment), nil
}

// Serve serves a ledger over an in-process connection, with no network and no TLS, and
// returns a connection to it. Close the connection, then call stop.
func Serve(srv ledgerv1.LedgerServer, opts ...grpc.ServerOption) (conn *grpc.ClientConn, stop func(), err error) {
	lis := bufconn.Listen(1 << 20)
	s := grpc.NewServer(opts...)
	ledgerv1.RegisterLedgerServer(s, srv)
	go func() { _ = s.Serve(lis) }()
	conn, err = grpc.NewClient("passthrough:///inmemory",
		grpc.WithContextDialer(func(ctx context.Context, _ string) (net.Conn, error) { return lis.DialContext(ctx) }),
		grpc.WithTransportCredentials(insecure.NewCredentials()))
	if err != nil {
		s.Stop()
		return nil, nil, err
	}
	return conn, s.Stop, nil
}

// on returns an interceptor that changes the answer of one method of the port.
func on(method string, change func(resp any, err error) (any, error)) grpc.UnaryServerInterceptor {
	return func(ctx context.Context, req any, info *grpc.UnaryServerInfo, h grpc.UnaryHandler) (any, error) {
		resp, err := h(ctx, req)
		if info.FullMethod == method {
			return change(resp, err)
		}
		return resp, err
	}
}

// swapCode replaces one error code by another.
func swapCode(from, to codes.Code) func(any, error) (any, error) {
	return func(resp any, err error) (any, error) {
		if status.Code(err) == from {
			return nil, status.Error(to, "changed by the test")
		}
		return resp, err
	}
}

// Command fingate-ledger-conformance proves that a ledger serves the ledger port of the
// open-banking product. It runs the conformance kit against the ledger and prints one line per
// check, PASS or FAIL with the reason, then the number of checks passed and of operations
// called.
//
// Usage:
//
//	fingate-ledger-conformance --target inmemory
//	fingate-ledger-conformance --target <host:port> --fixture <file.json> [--ca-file <file.pem>] [--server-name <name>]
//
// With --target inmemory the kit runs against the in-memory ledger of the product, in the same
// process. Otherwise it dials the ledger over TLS and reads its test data from the fixture, a
// JSON object with the keys customer and other_customer (each an object with scheme and
// subject), debtor_account_id, amount, refused_amount, creditor_name, creditor_scheme_name and
// creditor_identification. The kit submits payments: run it against a test ledger only.
//
// Exit codes: 0 every check passed; 1 a check failed; 2 the run could not start (a wrong flag,
// a fixture or certificate file that cannot be read).

import (

)

func main() {
	os.Exit(run(os.Args[1:], os.Stdout, os.Stderr))
}

// readFixture reads a fixture file; an unknown key is an error.
func readFixture(path string) (ledgertest.Fixture, error) {
	var fx ledgertest.Fixture
	b, err := os.ReadFile(filepath.Clean(path))
	if err != nil {
		return fx, err
	}
	d := json.NewDecoder(bytes.NewReader(b))
	d.DisallowUnknownFields()
	if err := d.Decode(&fx); err != nil {
		return fx, fmt.Errorf("%s: %w", path, err)
	}
	return fx, fx.Validate()
}

// transport returns the TLS credentials that verify the ledger's certificate.
func transport(caFile, serverName string) (credentials.TransportCredentials, error) {
	cfg := &tls.Config{MinVersion: tls.VersionTLS12, ServerName: serverName}
	if caFile != "" {
		pem, err := os.ReadFile(filepath.Clean(caFile))
		if err != nil {
			return nil, err
		}
		cfg.RootCAs = x509.NewCertPool()
		if !cfg.RootCAs.AppendCertsFromPEM(pem) {
			return nil, fmt.Errorf("%s holds no PEM certificate", caFile)
		}
	}
	return credentials.NewTLS(cfg), nil
}

func run(args []string, stdout, stderr io.Writer) int {
	fs := flag.NewFlagSet("fingate-ledger-conformance", flag.ContinueOnError)
	fs.SetOutput(stderr)
	target := fs.String("target", "", "inmemory, or the host:port of a ledger served over TLS")
	fixture := fs.String("fixture", "", "the JSON file that describes the ledger's test data; required unless the target is inmemory")
	caFile := fs.String("ca-file", "", "a PEM file of the authorities that sign the ledger's certificate; default: the system's")
	serverName := fs.String("server-name", "", "the name the ledger's certificate must carry; default: the host of the target")
	timeout := fs.Duration("timeout", 2*time.Minute, "how long the whole run may take")
	if err := fs.Parse(args); err != nil {
		return 2
	}
	usage := func(err error) int {
		_, _ = fmt.Fprintf(stderr, "fingate-ledger-conformance: %v\n", err)
		return 2
	}
	if fs.NArg() > 0 {
		return usage(fmt.Errorf("unexpected argument %q", fs.Arg(0)))
	}

	var (
		conn *grpc.ClientConn
		fx   ledgertest.Fixture
		err  error
	)
	switch {
	case *target == "":
		return usage(errors.New("--target is required"))
	case *target == "inmemory":
		if *fixture != "" || *caFile != "" || *serverName != "" {
			return usage(errors.New("--target inmemory takes no --fixture, --ca-file or --server-name"))
		}
		var stop func()
		conn, stop, err = ledgertest.Serve(ledgertest.NewMemory(ledgertest.FullCapabilities()))
		if err != nil {
			return usage(err)
		}
		defer stop()
		fx = ledgertest.MemoryFixture()
	default:
		if *fixture == "" {
			return usage(errors.New("--fixture is required unless the target is inmemory"))
		}
		if fx, err = readFixture(*fixture); err != nil {
			return usage(err)
		}
		creds, err := transport(*caFile, *serverName)
		if err != nil {
			return usage(err)
		}
		if conn, err = grpc.NewClient(*target, grpc.WithTransportCredentials(creds)); err != nil {
			return usage(err)
		}
	}
	defer func() { _ = conn.Close() }()

	ctx, cancel := context.WithTimeout(context.Background(), *timeout)
	defer cancel()
	rep := ledgertest.Run(ctx, conn, fx)
	if err := rep.Print(stdout); err != nil {
		return usage(err)
	}
	if !rep.Passed() {
		return 1
	}
	return 0
}

// self-signed certificate for 127.0.0.1. It returns the address and the certificate in PEM.
func tlsLedger(t *testing.T) (string, []byte) {
	t.Helper()
	priv, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)

		t.Fatal(err)

		NotAfter:              time.Now().Add(time.Hour),
		KeyUsage:              x509.KeyUsageDigitalSignature | x509.KeyUsageCertSign,
		ExtKeyUsage:           []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
		BasicConstraintsValid: true,
		IsCA:                  true,
		IPAddresses:           []net.IP{net.ParseIP("127.0.0.1")},
	}

	if err != nil {
		t.Fatal(err)
	}

	ledgerv1.RegisterLedgerServer(s, ledgertest.NewMemory(ledgertest.FullCapabilities()))
	go func() { _ = s.Serve(lis) }()
	t.Cleanup(s.Stop)
	return lis.Addr().String(), pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: der})
}
