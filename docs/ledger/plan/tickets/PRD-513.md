# PRD-513 — Resource server: PostgreSQL consent store with migration 0001, the definitions informer and the fingate-api program

## In plain words

**The problem today.** The resource server of the open-banking product keeps its consents only in memory, so they are lost when the process stops. Nothing reads the installation's definitions from the cluster, and there is no program that serves the routes and connects them to the ledger adapter, so nothing of the product can run. The store's tests also have no database to run against on a pull request.

**What changes.** Consents and their history are stored in PostgreSQL, whose first migration creates exactly the two consent tables. An informer keeps the definitions current from one ConfigMap, and the new program fingate-api serves every route over mutual TLS and reads accounts from the ledger adapter that the definitions name. A new CI job runs every test of the product against a real PostgreSQL and fails when a test is skipped.

**Done means:**

- The PostgreSQL consent store passes the same port tests as the in-memory store, in a CI job that has a database.
- That CI job turns red when a test is skipped, so the database tests cannot silently stop running.
- The first migration creates only the tables consent and consent_history, and starting the program twice applies it once.
- A change of a partner's state in the definitions ConfigMap takes effect on the next call, and an invalid version of the ConfigMap is refused while the definitions in use stay.
- The program refuses a caller without a client certificate, or with one from an unknown authority, already in the TLS handshake, and answers a call without a token with 401.
- A customer who authorised a consent reads the consented account through the program from the ledger adapter, and the program refuses an adapter whose certificate no trusted authority issued.
- Every test of the product passes, and the linter and the security scan find nothing new.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The open-banking product `products/fingate` keeps its consents in PostgreSQL. The new store `store.Postgres` (`products/fingate/internal/store/postgres.go`) implements the port `store.Store` and passes the port tests `storetest.Run`, the same tests the in-memory store passes. Its migration `0001` (`products/fingate/internal/store/migrations/0001_consent.sql`) creates the tables `consent` and `consent_history` and nothing else. The new informer (`products/fingate/internal/definitions/informer.go`) keeps a `definitions.Holder` set from the key `definitions.yaml` of the ConfigMap `fingate-definitions` in the program's namespace. The new program `products/fingate/cmd/fingate-api` opens the store, starts the informer, waits for the first valid definitions, opens the connection to the ledger adapter they name (`internal/ledgerclient`, gRPC over TLS), and serves every route of `internal/api` with mutual TLS on `:8443`, with `/healthz` and `/readyz` on `:8080`. An account operation of an authorised consent answers with what the ledger adapter holds. The workflow `fingate-ci` gains the job `go test with PostgreSQL — products/fingate`: it starts a PostgreSQL service, runs every test of the module against it, and fails when any test or subtest is skipped. A person sees it on the pull request: that check runs and passes, and its log shows `--- PASS: TestPostgresPassesThePortTests`.

## 3. The model (the law)
1. **The store follows the port.** `store.Postgres` implements `store.Store` with the same rules as `store.Memory`: every change of state goes through the transition table of `internal/consent`; every accepted transition writes the state and exactly one `consent_history` row in one transaction; a refused transition writes nothing; an authorised consent whose expiry has passed is expired by the system when it is read, once, under the row lock. The clock is the function given to `OpenPostgres`, never the database's; times are stored to the microsecond in UTC.
2. **Migration 0001 holds the consent tables only.** `consent` (`id` text primary key, `family`, `client_id`, `state`, `request`, `customer_id`, `accounts` text array, `expires_at`, `created_at`, `state_at`) and `consent_history` (`consent_id`, `seq`, `from_state`, `to_state`, `actor`, `reason`, `at`; primary key `consent_id, seq`). The column `request` is of type `json`, not `jsonb`, because the port returns the body byte for byte as it was stored and `jsonb` rewrites it; the port test `CreateThenGet` compares the bytes. No other table of the product is created here: each comes with the package that reads it.
3. **Migrations.** The files `migrations/NNNN_<name>.sql` are embedded and applied in the order of their numbers, which start at `0001` and have no gap. The table `schema_migrations` (`version`, `name`, `applied_at`), created by the store itself, records each applied migration; a migration is applied once. All of it runs in one transaction under the advisory lock `0x66696e67617465`, so two programs that start together apply a migration once.
4. **The definitions come from one ConfigMap.** Its name defaults to `fingate-definitions` (`definitions.ConfigMapName`, flag `--definitions-configmap`), in the namespace of flag `--namespace`; the document is under the data key `definitions.yaml` (`definitions.DataKey`). The informer watches that one object (field selector `metadata.name`). A version that `definitions.Parse` accepts, and the program's accept function accepts, replaces the definitions in the holder; a version that is invalid, has no key `definitions.yaml`, or is refused, is reported and changes nothing. A deleted ConfigMap changes nothing. The informer reads; it never writes to the cluster.
5. **The program.** `fingate-api` reads every credential from a file: the server certificate and key, the authority bundle of client certificates, and the PostgreSQL connection address (`--database-url-file`); the address is never a flag value or an environment variable. It waits for the first valid definitions, loads the profile they name from `--profiles-dir`, and builds the token check with the audience `https://<host>` of the definitions, the issuer of `--issuer` and the key set of `--jwks-url`. It opens one connection to the ledger adapter with `ledgerclient.Dial` and gives `api.New` the client `ledgerclient.New` of it, with the default timeout: the target is the definitions' `ledger.target`; the name the adapter's certificate must carry is the definitions' `ledger.serverName`, or the host of the target when that is empty; the authorities trusted for that certificate are those of `--ledger-ca-file`, or the system's when the flag is not given. The adapter is verified, at TLS 1.2 or later; it does not ask the program for a certificate. The connection is made on the first call to the ledger. Later versions of the definitions that change the profile, the host or the ledger are refused until a restart. It serves with `ClientAuth: tls.RequireAndVerifyClientCert`: a caller without a certificate, or with one that no authority of `--client-ca-file` issued, is refused in the handshake. TLS 1.2 is limited to `TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256` and `TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384`, the suites of FAPI 1.0 Advanced section 8.5 that Go implements; the profile's `security.fapi` can only be `fapi1-advanced-final`. `/readyz` answers 200 only while the resource server serves and the database answers; the ledger is not part of readiness, so while it cannot answer an operation that reads it answers 500 and the consent operations keep working. Exit codes: 0 stopped by a signal, 1 a listener failed, 2 it could not start.
6. **A skipped database test fails CI.** The tests that need PostgreSQL read its address from `FINGATE_TEST_DATABASE_URL` and skip without it. The new job of `fingate-ci` sets it, runs `go test -count=1 -v ./...` in `products/fingate`, and fails on a failed test, on any line `--- SKIP` (a subtest's too), and when `--- PASS: TestPostgresPassesThePortTests` is missing. Before that it proves on throw-away modules that a skipped test, a skipped subtest, a failed test and a missing named test each fail it.
7. **No polling.** No new non-test Go file uses `time.Sleep`, `time.NewTicker` or `time.Tick` (guard `check-no-new-polling.py`).
8. Nothing is deleted.

```sql
-- Migration 0001 of the open-banking product: the consents and their history.
--
-- consent holds one row per consent; consent_history one row per accepted transition, written
-- in the same transaction as the state. The column request is of type json, not jsonb: it keeps

-- product come with the migrations of the packages that read them.

    id          text PRIMARY KEY,
    family      text NOT NULL CHECK (family IN ('account-access', 'payment', 'funds-confirmation', 'vrp')),
    client_id   text NOT NULL,
    state       text NOT NULL CHECK (state IN ('awaiting', 'authorised', 'rejected', 'revoked', 'expired', 'consumed')),
    request     json,
    customer_id text,
    accounts    text[],
    expires_at  timestamptz,
    created_at  timestamptz NOT NULL,
    state_at    timestamptz NOT NULL
);

CREATE TABLE consent_history (
    consent_id text NOT NULL REFERENCES consent (id),
    seq        integer NOT NULL CHECK (seq >= 1),
    from_state text NOT NULL,
    to_state   text NOT NULL,
    actor      text NOT NULL CHECK (actor IN ('third-party', 'customer', 'bank', 'system')),
    reason     text NOT NULL,
    at         timestamptz NOT NULL,
    PRIMARY KEY (consent_id, seq)
);
```

```go
// OpenPostgres connects to the database at url (a PostgreSQL connection address), applies the
// migrations and returns the store. now may be nil: time.Now.
func OpenPostgres(ctx context.Context, url string, now func() time.Time) (*Postgres, error) {
	if now == nil {
		now = time.Now
	}
	pool, err := pgxpool.New(ctx, url)
	if err != nil {
		return nil, fmt.Errorf("store: %w", err)
	}
	p := &Postgres{pool: pool, now: now}
	if err := p.migrate(ctx); err != nil {
		pool.Close()
		return nil, err
	}
	return p, nil
}

// Migrations returns the numbers of the migrations this package holds, in order.
func Migrations() ([]int, error) {
	files, err := migrationFiles()
	if err != nil {
		return nil, err
	}
	out := make([]int, 0, len(files))
	for _, f := range files {
		out = append(out, f.version)
	}
	return out, nil
}

type migrationFile struct {
	version int
	name    string
}

func migrationFiles() ([]migrationFile, error) {
	entries, err := fs.ReadDir(migrations, "migrations")
	if err != nil {
		return nil, fmt.Errorf("store: %w", err)
	}
	var out []migrationFile
	for _, e := range entries {
		m := migrationName.FindStringSubmatch(e.Name())
		if m == nil {
			return nil, fmt.Errorf("store: migration file %q is not named <four digits>_<name>.sql", e.Name())
		}
		v, _ := strconv.Atoi(m[1])
		out = append(out, migrationFile{version: v, name: e.Name()})
	}
	sort.Slice(out, func(i, j int) bool { return out[i].version < out[j].version })
	for i, f := range out {
		if f.version != i+1 {
			return nil, fmt.Errorf("store: migration %s is not number %04d: the numbers start at 0001 and have no gap", f.name, i+1)
		}
	}
	return out, nil
}

// migrate applies every migration that schema_migrations does not record, in one transaction.
func (p *Postgres) migrate(ctx context.Context) error {
	files, err := migrationFiles()
	if err != nil {
		return err
	}
	return pgx.BeginFunc(ctx, p.pool, func(tx pgx.Tx) error {
		if _, err := tx.Exec(ctx, `SELECT pg_advisory_xact_lock($1)`, int64(migrationLock)); err != nil {
			return fmt.Errorf("store: lock the migrations: %w", err)
		}
		if _, err := tx.Exec(ctx, `CREATE TABLE IF NOT EXISTS schema_migrations (
			version integer PRIMARY KEY, name text NOT NULL, applied_at timestamptz NOT NULL)`); err != nil {
			return fmt.Errorf("store: create schema_migrations: %w", err)
		}
		rows, err := tx.Query(ctx, `SELECT version FROM schema_migrations`)
		if err != nil {
			return fmt.Errorf("store: read schema_migrations: %w", err)
		}
		done, err := pgx.CollectRows(rows, pgx.RowTo[int])
		if err != nil {
			return fmt.Errorf("store: read schema_migrations: %w", err)
		}
		for _, f := range files {
			if slices.Contains(done, f.version) {
				continue
			}
			sql, err := migrations.ReadFile("migrations/" + f.name)
			if err != nil {
				return fmt.Errorf("store: %w", err)
			}
			if _, err := tx.Exec(ctx, string(sql)); err != nil {
				return fmt.Errorf("store: migration %s: %w", f.name, err)
			}
			if _, err := tx.Exec(ctx, `INSERT INTO schema_migrations (version, name, applied_at) VALUES ($1, $2, $3)`,
				f.version, f.name, p.stamp()); err != nil {
				return fmt.Errorf("store: record migration %s: %w", f.name, err)
			}
		}
		return nil
	})
}

// stamp returns the time now, in UTC, to the microsecond, as the database stores it.
func (p *Postgres) stamp() time.Time { return p.now().UTC().Truncate(time.Microsecond) }

func dbTime(t time.Time) time.Time { return t.UTC().Truncate(time.Microsecond) }

// Create implements Store.
func (p *Postgres) Create(ctx context.Context, c Consent) (Consent, error) {
	if c.ID == "" || c.ClientID == "" || !slices.Contains(consent.Families(), c.Family) {
		return Consent{}, fmt.Errorf("store: a consent needs an identifier, a client and a family, got %q, %q, %q", c.ID, c.ClientID, c.Family)
	}
	now := p.stamp()
	r := consent.Record{Family: c.Family}
	if err := r.Apply(consent.Create, consent.ThirdParty, "created", now); err != nil {
		return Consent{}, err
	}
	row := Consent{ID: c.ID, Family: c.Family, ClientID: c.ClientID, State: r.State,
		Request: slices.Clone(c.Request), CreatedAt: now, StateAt: now, History: r.History}
	if !c.ExpiresAt.IsZero() {
		row.ExpiresAt = dbTime(c.ExpiresAt)
	}
	err := pgx.BeginFunc(ctx, p.pool, func(tx pgx.Tx) error {
		_, err := tx.Exec(ctx, `INSERT INTO consent (id, family, client_id, state, request, expires_at, created_at, state_at)
			VALUES ($1, $2, $3, $4, $5, $6, $7, $8)`,
			row.ID, string(row.Family), row.ClientID, string(row.State), jsonText(row.Request), nullTime(row.ExpiresAt), now, now)
		if err != nil {
			return err
		}
		return insertHistory(ctx, tx, row.ID, row.History[0])
	})
	var pe *pgconn.PgError
	if errors.As(err, &pe) && pe.Code == "23505" {
		return Consent{}, fmt.Errorf("%w: %s", ErrExists, c.ID)
	}
	if err != nil {
		return Consent{}, fmt.Errorf("store: create %s: %w", c.ID, err)
	}
	return row, nil
}

// Get implements Store.
func (p *Postgres) Get(ctx context.Context, id string) (Consent, bool, error) {
	c, ok, err := read(ctx, p.pool, id, false)
	if err != nil || !ok {
		return Consent{}, false, err
	}
	if c.State != consent.Authorised || c.ExpiresAt.IsZero() || p.now().Before(c.ExpiresAt) {
		return c, true, nil
	}
	// Expired on read: the event is recorded once, under the row lock, by whichever read comes first.
	err = pgx.BeginFunc(ctx, p.pool, func(tx pgx.Tx) error {
		cur, _, err := read(ctx, tx, id, true)
		if err != nil {
			return err
		}
		if cur.State == consent.Authorised {
			cur, err = applyEvent(ctx, tx, cur, consent.Expire, consent.System, "expires_at passed", p.stamp(), nil)
			if err != nil {
				return err
			}
		}
		c = cur
		return nil
	})
	if err != nil {
		return Consent{}, false, err
	}
	return c, true, nil
}

// Authorise implements Store.
func (p *Postgres) Authorise(ctx context.Context, id, customerID string, accounts []string) (Consent, error) {
	if customerID == "" {
		return Consent{}, errors.New("store: authorise needs a customer")
	}
	return p.change(ctx, id, consent.Authorise, consent.Customer, "authorised", func(c *Consent) {
		c.CustomerID, c.Accounts = customerID, slices.Clone(accounts)
	})
}

// Apply implements Store.
func (p *Postgres) Apply(ctx context.Context, id string, event consent.Event, actor consent.Actor, reason string) (Consent, error) {
	if event == consent.Authorise || event == consent.Create {
		return Consent{}, fmt.Errorf("store: use Authorise or Create for the event %s", event)
	}
	return p.change(ctx, id, event, actor, reason, nil)
}

// change applies one event to the consent id in one transaction.
func (p *Postgres) change(ctx context.Context, id string, event consent.Event, actor consent.Actor, reason string, set func(*Consent)) (Consent, error) {
	var out Consent
	err := pgx.BeginFunc(ctx, p.pool, func(tx pgx.Tx) error {
		c, ok, err := read(ctx, tx, id, true)
		if err != nil {
			return err
		}
		if !ok {
			return fmt.Errorf("%w: %s", ErrNotFound, id)
		}
		out, err = applyEvent(ctx, tx, c, event, actor, reason, p.stamp(), set)
		return err
	})
	if err != nil {
		return Consent{}, err
	}
	return out, nil
}

// querier is a pool or a transaction.
type querier interface {
	Exec(ctx context.Context, sql string, args ...any) (pgconn.CommandTag, error)
	Query(ctx context.Context, sql string, args ...any) (pgx.Rows, error)
	QueryRow(ctx context.Context, sql string, args ...any) pgx.Row
}

// read returns the consent id with its history; lock takes the row lock of the transaction q.
func read(ctx context.Context, q querier, id string, lock bool) (Consent, bool, error) {
	sql := `SELECT id, family, client_id, state, request::text, customer_id, accounts, expires_at, created_at, state_at
		FROM consent WHERE id = $1`
	if lock {
		sql += ` FOR UPDATE`
	}
	var (
		c                   Consent
		family, state       string
		request, customerID *string
		expires             *time.Time
	)
	err := q.QueryRow(ctx, sql, id).Scan(&c.ID, &family, &c.ClientID, &state, &request, &customerID, &c.Accounts, &expires, &c.CreatedAt, &c.StateAt)
	if errors.Is(err, pgx.ErrNoRows) {
		return Consent{}, false, nil
	}
	if err != nil {
		return Consent{}, false, fmt.Errorf("store: read %s: %w", id, err)
	}
	c.Family, c.State = consent.Family(family), consent.State(state)
	if request != nil {
		c.Request = []byte(*request)
	}
	if customerID != nil {
		c.CustomerID = *customerID
	}
	if expires != nil {
		c.ExpiresAt = *expires
	}
	rows, err := q.Query(ctx, `SELECT seq, from_state, to_state, actor, reason, at FROM consent_history
		WHERE consent_id = $1 ORDER BY seq`, id)
	if err != nil {
		return Consent{}, false, fmt.Errorf("store: read the history of %s: %w", id, err)
	}
	c.History, err = pgx.CollectRows(rows, func(r pgx.CollectableRow) (consent.HistoryEntry, error) {
		var h consent.HistoryEntry
		var from, to, actor string
		err := r.Scan(&h.Seq, &from, &to, &actor, &h.Reason, &h.At)
		h.From, h.To, h.Actor = consent.State(from), consent.State(to), consent.Actor(actor)
		return h, err
	})
	if err != nil {
		return Consent{}, false, fmt.Errorf("store: read the history of %s: %w", id, err)
	}
	return c, true, nil
}

// applyEvent applies one event to c through the transition table and writes the state, the
// fields set changes, and the one new history row. A refused transition writes nothing.
func applyEvent(ctx context.Context, tx pgx.Tx, c Consent, event consent.Event, actor consent.Actor, reason string, at time.Time, set func(*Consent)) (Consent, error) {
	r := consent.Record{Family: c.Family, State: c.State, History: slices.Clone(c.History)}
	if err := r.Apply(event, actor, reason, at); err != nil {
		return Consent{}, err
	}
	if set != nil {
		set(&c)
	}
	c.State, c.StateAt, c.History = r.State, at, r.History
	if _, err := tx.Exec(ctx, `UPDATE consent SET state = $2, state_at = $3, customer_id = $4, accounts = $5 WHERE id = $1`,
		c.ID, string(c.State), at, nullText(c.CustomerID), c.Accounts); err != nil {
		return Consent{}, fmt.Errorf("store: write %s: %w", c.ID, err)
	}
	if err := insertHistory(ctx, tx, c.ID, c.History[len(c.History)-1]); err != nil {
		return Consent{}, err
	}
	return c, nil
}

func insertHistory(ctx context.Context, tx pgx.Tx, id string, h consent.HistoryEntry) error {
	_, err := tx.Exec(ctx, `INSERT INTO consent_history (consent_id, seq, from_state, to_state, actor, reason, at)
		VALUES ($1, $2, $3, $4, $5, $6, $7)`, id, h.Seq, string(h.From), string(h.To), string(h.Actor), h.Reason, h.At)
	if err != nil {
		return fmt.Errorf("store: write the history of %s: %w", id, err)
	}
	return nil
}

func jsonText(b []byte) *string {
	if b == nil {
		return nil
	}
	s := string(b)
	return &s
}

func nullText(s string) *string {
	if s == "" {
		return nil
	}
	return &s
}

func nullTime(t time.Time) *time.Time {
	if t.IsZero() {
		return nil
	}
	return &t
}
```

```go
// The informer that loads the definitions from the cluster.
//
// The definitions of an installation are the YAML document under the key DataKey of one
// ConfigMap in the program's own namespace; the chart writes it, and its default name is
// ConfigMapName. An Informer watches that one object through the Kubernetes API. Each version it
// sees is parsed and checked whole; a valid document replaces the definitions in the Holder, so a
// change of a partner's state takes effect on the next call. A version that is invalid, that has
// no key DataKey, or that the accept function refuses is reported and changes nothing: the
// definitions in use stay. A deleted ConfigMap changes nothing either.

import (
	"context"
	"fmt"
	"sync"

	corev1 "k8s.io/api/core/v1"
	metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"
	"k8s.io/apimachinery/pkg/fields"
	"k8s.io/client-go/informers"
	"k8s.io/client-go/kubernetes"
	"k8s.io/client-go/tools/cache"
)

// ConfigMapName is the default name of the ConfigMap that holds the definitions.
const ConfigMapName = "fingate-definitions"

// DataKey is the key of the ConfigMap's data that holds the definitions document.
const DataKey = "definitions.yaml"

// Informer keeps a Holder set to the definitions of one ConfigMap.
type Informer struct {
	factory informers.SharedInformerFactory
	name    string
	holder  *Holder
	accept  func(*Definitions) error
	logf    func(format string, a ...any)

	loaded chan struct{}
	once   sync.Once
}

// NewInformer returns an informer on the ConfigMap name in namespace that sets h. accept may be
// nil; when it returns an error for a valid document, that document is refused. logf receives
// one line for every version applied or refused; it may be nil.
func NewInformer(client kubernetes.Interface, namespace, name string, h *Holder, accept func(*Definitions) error, logf func(format string, a ...any)) *Informer {
	if logf == nil {
		logf = func(string, ...any) {}
	}
	selector := fields.OneTermEqualSelector("metadata.name", name).String()
	factory := informers.NewSharedInformerFactoryWithOptions(client, 0, informers.WithNamespace(namespace),
		informers.WithTweakListOptions(func(o *metav1.ListOptions) { o.FieldSelector = selector }))
	return &Informer{factory: factory, name: name, holder: h, accept: accept, logf: logf, loaded: make(chan struct{})}
}

// Loaded is closed when the Holder holds the first valid definitions.
func (i *Informer) Loaded() <-chan struct{} { return i.loaded }

// Run watches the ConfigMap until ctx ends.
func (i *Informer) Run(ctx context.Context) error {
	inf := i.factory.Core().V1().ConfigMaps().Informer()
	if _, err := inf.AddEventHandler(cache.ResourceEventHandlerFuncs{
		AddFunc:    i.apply,
		UpdateFunc: func(_, obj any) { i.apply(obj) },
		DeleteFunc: func(obj any) {
			if cm := configMap(obj); cm != nil && cm.Name == i.name {
				i.logf("definitions: ConfigMap %s/%s was deleted; the definitions in use stay", cm.Namespace, cm.Name)
			}
		},
	}); err != nil {
		return fmt.Errorf("definitions: %w", err)
	}
	i.factory.Start(ctx.Done())
	<-ctx.Done()
	i.factory.Shutdown()
	return nil
}

func configMap(obj any) *corev1.ConfigMap {
	if d, ok := obj.(cache.DeletedFinalStateUnknown); ok {
		obj = d.Obj
	}
	cm, _ := obj.(*corev1.ConfigMap)
	return cm
}

// apply parses one version of the ConfigMap and sets the Holder when it is valid and accepted.
func (i *Informer) apply(obj any) {
	cm := configMap(obj)
	if cm == nil || cm.Name != i.name {
		return
	}
	at := fmt.Sprintf("ConfigMap %s/%s version %s", cm.Namespace, cm.Name, cm.ResourceVersion)
	raw, ok := cm.Data[DataKey]
	if !ok {
		i.logf("definitions: refused %s: it has no key %s; the definitions in use stay", at, DataKey)
		return
	}
	d, err := Parse([]byte(raw))
	if err == nil && i.accept != nil {
		err = i.accept(d)
	}
	if err != nil {
		i.logf("definitions: refused %s: %v; the definitions in use stay", at, err)
		return
	}
	i.holder.Set(d)
	i.once.Do(func() { close(i.loaded) }) // before the line is reported: its reader finds Loaded closed
	i.logf("definitions: loaded %s: profile %s, host %s, %d partners", at, d.Profile, d.Host, len(d.Partners))
}
```

```go
// operation of the profile's documents behind the token rules, over mutual TLS: a caller that
// presents no client certificate, or one that no authority of --client-ca-file issued, is refused
// in the handshake. The consents are kept in PostgreSQL, whose migrations it applies at start.

// reached only through the ledger port, over gRPC and TLS, at the target the definitions name.
//

// keyPair serves a certificate and key from two files and reads them again when either changed.
type keyPair struct {
	certFile, keyFile string

	mu      sync.Mutex
	stamp   [2]time.Time
	current *tls.Certificate
}

func (k *keyPair) stamps() ([2]time.Time, error) {
	var s [2]time.Time
	for i, f := range []string{k.certFile, k.keyFile} {
		fi, err := os.Stat(f)
		if err != nil {
			return s, err
		}
		s[i] = fi.ModTime()
	}
	return s, nil
}

// load reads the files when they changed since the last read. When a changed pair cannot be
// read, the certificate read before stays in use.
func (k *keyPair) load() (*tls.Certificate, error) {
	k.mu.Lock()
	defer k.mu.Unlock()
	s, err := k.stamps()
	if err == nil && k.current != nil && s == k.stamp {
		return k.current, nil
	}
	if err == nil {
		var c tls.Certificate
		if c, err = tls.LoadX509KeyPair(filepath.Clean(k.certFile), filepath.Clean(k.keyFile)); err == nil {
			k.current, k.stamp = &c, s
			return k.current, nil
		}
	}
	if k.current != nil {
		return k.current, nil
	}
	return nil, err
}
```

```go
// authority is a certificate authority of the test.
type authority struct {
	cert *x509.Certificate
	key  *ecdsa.PrivateKey
	pem  []byte
}

func newAuthority(t *testing.T, name string) *authority {
	t.Helper()
	key, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
	if err != nil {
		t.Fatal(err)
	}
	tmpl := &x509.Certificate{SerialNumber: big.NewInt(1), Subject: pkix.Name{CommonName: name},
		NotBefore: time.Now().Add(-time.Hour), NotAfter: time.Now().Add(time.Hour),
		KeyUsage: x509.KeyUsageCertSign, BasicConstraintsValid: true, IsCA: true}
	der, err := x509.CreateCertificate(rand.Reader, tmpl, tmpl, &key.PublicKey, key)
	if err != nil {
		t.Fatal(err)
	}
	cert, _ := x509.ParseCertificate(der)
	return &authority{cert: cert, key: key, pem: pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: der})}
}

// issue returns a certificate for 127.0.0.1 with the usage given, and its key, both PEM.
func (a *authority) issue(t *testing.T, serial int64, usage x509.ExtKeyUsage) (tls.Certificate, []byte, []byte) {
	t.Helper()
	key, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
	if err != nil {
		t.Fatal(err)
	}
	tmpl := &x509.Certificate{SerialNumber: big.NewInt(serial), Subject: pkix.Name{CommonName: "fingate-api test"},
		NotBefore: time.Now().Add(-time.Hour), NotAfter: time.Now().Add(time.Hour),
		KeyUsage: x509.KeyUsageDigitalSignature, ExtKeyUsage: []x509.ExtKeyUsage{usage},
		IPAddresses: []net.IP{net.ParseIP("127.0.0.1")}}
	der, err := x509.CreateCertificate(rand.Reader, tmpl, a.cert, &key.PublicKey, a.key)
	if err != nil {
		t.Fatal(err)
	}
	keyDER, err := x509.MarshalECPrivateKey(key)
	if err != nil {
		t.Fatal(err)
	}
	certPEM := pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: der})
	keyPEM := pem.EncodeToMemory(&pem.Block{Type: "EC PRIVATE KEY", Bytes: keyDER})
	pair, err := tls.X509KeyPair(certPEM, keyPEM)
	if err != nil {
		t.Fatal(err)
	}
	return pair, certPEM, keyPEM
}

func write(t *testing.T, dir, name string, data []byte) string {
	t.Helper()
	p := filepath.Join(dir, name)
	if err := os.WriteFile(p, data, 0o600); err != nil {
		t.Fatal(err)
	}
	return p
}

// lines is the program's error output, split into lines that a test can wait for.
type lines struct {
	mu   sync.Mutex
	buf  bytes.Buffer
	all  strings.Builder
	next chan string
}

func newLines() *lines { return &lines{next: make(chan string, 256)} }

func (l *lines) Write(p []byte) (int, error) {
	l.mu.Lock()
	defer l.mu.Unlock()
	l.all.Write(p)
	l.buf.Write(p)
	for {
		line, err := l.buf.ReadString('\n')
		if err != nil {
			l.buf.WriteString(line)
			return len(p), nil
		}
		l.next <- strings.TrimSuffix(line, "\n")
	}
}

func (l *lines) text() string {
	l.mu.Lock()
	defer l.mu.Unlock()
	return l.all.String()
}

// waitFor returns the first line that starts with prefix, and fails after ten seconds.
func (l *lines) waitFor(t *testing.T, prefix string) string {
	t.Helper()
	deadline := time.After(10 * time.Second)
	for {
		select {
		case line := <-l.next:
			if strings.HasPrefix(line, prefix) {
				return line
			}
		case <-deadline:
			t.Fatalf("no line %q within ten seconds; output:\n%s", prefix, l.text())
			return ""
		}
	}
}

// signer mints PS256 tokens and serves their key set over TLS.
type signer struct {
	key *rsa.PrivateKey
	srv *httptest.Server
}

func newSigner(t *testing.T) *signer {
	t.Helper()
	key, err := rsa.GenerateKey(rand.Reader, 2048)
	if err != nil {
		t.Fatal(err)
	}
	doc, _ := json.Marshal(map[string]any{"keys": []map[string]string{{"kty": "RSA", "use": "sig", "kid": "k1",
		"n": base64.RawURLEncoding.EncodeToString(key.N.Bytes()),
		"e": base64.RawURLEncoding.EncodeToString(big.NewInt(int64(key.E)).Bytes())}}})
	srv := httptest.NewTLSServer(http.HandlerFunc(func(w http.ResponseWriter, _ *http.Request) { _, _ = w.Write(doc) }))
	t.Cleanup(srv.Close)
	return &signer{key: key, srv: srv}
}

// mint signs a token bound to the certificate with the thumbprint. A consentID that is not
// empty makes it the token of a customer who authorised that consent.
func (s *signer) mint(t *testing.T, thumbprint, consentID string) string {
	t.Helper()
	now := time.Now()
	h, _ := json.Marshal(map[string]string{"alg": "PS256", "typ": "JWT", "kid": "k1"})
	claims := map[string]any{"iss": issuer, "aud": "https://" + host, "exp": now.Add(5 * time.Minute).Unix(),
		"iat": now.Unix(), "client_id": clientID, "scope": "openid accounts", "cnf": map[string]string{"x5t#S256": thumbprint}}
	if consentID != "" {
		claims[token.ConsentClaim] = consentID
	}
	c, _ := json.Marshal(claims)
	in := base64.RawURLEncoding.EncodeToString(h) + "." + base64.RawURLEncoding.EncodeToString(c)
	d := sha256.Sum256([]byte(in))
	sig, err := rsa.SignPSS(rand.Reader, s.key, crypto.SHA256, d[:], &rsa.PSSOptions{SaltLength: rsa.PSSSaltLengthEqualsHash})
	if err != nil {
		t.Fatal(err)
	}
	return in + "." + base64.RawURLEncoding.EncodeToString(sig)
}

// newLedger serves the in-memory ledger of package ledgertest over gRPC and TLS on a local port,
// with a certificate that ca issued for 127.0.0.1, and returns its target in the form of the
// definitions' ledger.target.
func newLedger(t *testing.T, ca *authority) string {
	t.Helper()
	pair, _, _ := ca.issue(t, 5, x509.ExtKeyUsageServerAuth)
	lis, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		t.Fatal(err)
	}
	srv := grpc.NewServer(grpc.Creds(credentials.NewTLS(&tls.Config{MinVersion: tls.VersionTLS12, Certificates: []tls.Certificate{pair}})))
	ledgerv1.RegisterLedgerServer(srv, ledgertest.NewMemory(ledgertest.FullCapabilities()))
	go func() { _ = srv.Serve(lis) }()
	t.Cleanup(srv.Stop)
	return "dns:///" + lis.Addr().String()
}

// started is one running program.
type started struct {
	api, health string
	client      *fake.Clientset
	store       *store.Memory
	out         *lines
	stop        func() int
}

// start writes the files of a valid start into dir and runs the program with them. ledgerCA is
// the authority the program trusts for the certificate of the ledger adapter.
func start(t *testing.T, dir string, ca, ledgerCA *authority, sig *signer, configMapData map[string]string) *started {
	t.Helper()
	_, serverCert, serverKey := ca.issue(t, 2, x509.ExtKeyUsageServerAuth)
	jwksCA := pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: sig.srv.Certificate().Raw})
	args := []string{"--listen", "127.0.0.1:0", "--health-listen", "127.0.0.1:0",
		"--cert-file", write(t, dir, "tls.crt", serverCert), "--key-file", write(t, dir, "tls.key", serverKey),
		"--client-ca-file", write(t, dir, "client-ca.crt", ca.pem),
		"--database-url-file", write(t, dir, "database-url", []byte("postgres://unused.invalid/fingate\n")),
		"--namespace", testNS, "--profiles-dir", "../../profiles",
		"--issuer", issuer, "--jwks-url", sig.srv.URL + "/certs", "--issuer-ca-file", write(t, dir, "issuer-ca.crt", jwksCA),
		"--ledger-ca-file", write(t, dir, "ledger-ca.crt", ledgerCA.pem)}
	s := &started{client: fake.NewClientset(), store: store.NewMemory(nil), out: newLines()}
	if configMapData != nil {
		cm := &corev1.ConfigMap{ObjectMeta: metav1.ObjectMeta{Name: definitions.ConfigMapName, Namespace: testNS}, Data: configMapData}
		if _, err := s.client.CoreV1().ConfigMaps(testNS).Create(context.Background(), cm, metav1.CreateOptions{}); err != nil {
			t.Fatal(err)
		}
	}
	addrs := make(chan [2]string, 1)
	ctx, cancel := context.WithCancel(context.Background())
	code := make(chan int, 1)
	go func() {
		code <- run(ctx, args, s.out, deps{
			kube:      func() (kubernetes.Interface, error) { return s.client, nil },
			openStore: func(context.Context, string) (database, error) { return memory{s.store}, nil },
			listening: func(a, h net.Addr) { addrs <- [2]string{a.String(), h.String()} },
		})
	}()
	select {
	case a := <-addrs:
		s.api, s.health = a[0], a[1]
	case c := <-code:
		cancel()
		t.Fatalf("run returned %d before it listened:\n%s", c, s.out.text())
	}
	var once sync.Once
	result := 0
	s.stop = func() int {
		once.Do(func() { cancel(); result = <-code })
		return result
	}
	t.Cleanup(func() { s.stop() })
	return s
}

	}
}

func get(t *testing.T, address string) int {
	t.Helper()
	req, err := http.NewRequest(http.MethodGet, address, nil)
	if err != nil {
		t.Fatal(err)
	}
	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		t.Fatal(err)
	}
	_ = resp.Body.Close()
	return resp.StatusCode
}

// tlsClient returns a client that trusts ca and presents cert; a zero cert presents none.
func tlsClient(ca *authority, cert tls.Certificate) *http.Client {
	roots := x509.NewCertPool()
	roots.AddCert(ca.cert)
	cfg := &tls.Config{MinVersion: tls.VersionTLS12, RootCAs: roots}
	if cert.Certificate != nil {
		cfg.Certificates = []tls.Certificate{cert}
	}
	return &http.Client{Timeout: 10 * time.Second, Transport: &http.Transport{TLSClientConfig: cfg}}
}

func call(t *testing.T, c *http.Client, method, address, jws, body string) (*http.Response, string) {
	t.Helper()
	req, err := http.NewRequest(method, address, strings.NewReader(body))
	if err != nil {
		t.Fatal(err)
	}
	if body != "" {
		req.Header.Set("Content-Type", "application/json")
	}
	if jws != "" {
		req.Header.Set("Authorization", "Bearer "+jws)
	}
	resp, err := c.Do(req)
	if err != nil {
		t.Fatalf("%s %s: %v", method, address, err)
	}
	defer func() { _ = resp.Body.Close() }()
	b, _ := io.ReadAll(resp.Body)
	return resp, string(b)
}

const consentBody = `{"Data":{"Permissions":["ReadAccountsBasic"],"ExpirationDateTime":"2099-01-01T00:00:00+00:00"},"Risk":{}}`

// authorised creates a consent over the connection, has the customer cust-alice of the
// in-memory ledger authorise it for the account acc-1001, and returns the customer's token.
func (s *started) authorised(t *testing.T, partner *http.Client, sig *signer, thumb string) string {
	t.Helper()
	resp, body := call(t, partner, http.MethodPost, "https://"+s.api+consents, sig.mint(t, thumb, ""), consentBody)
	if resp.StatusCode != http.StatusCreated {
		t.Fatalf("create: %d %s", resp.StatusCode, body)
	}
	var created struct {
		Data struct {
			ConsentID string `json:"ConsentId"`
		}
	}
	if err := json.Unmarshal([]byte(body), &created); err != nil || created.Data.ConsentID == "" {
		t.Fatalf("create: %s", body)
	}
	if _, err := s.store.Authorise(context.Background(), created.Data.ConsentID, "cust-alice", []string{"acc-1001"}); err != nil {
		t.Fatal(err)
	}
	return sig.mint(t, thumb, created.Data.ConsentID)
}

func TestRunServesTheRoutesWithMutualTLS(t *testing.T) {
	ca, other, sig := newAuthority(t, "partner authority"), newAuthority(t, "unknown authority"), newSigner(t)
	ledgerCA := newAuthority(t, "ledger authority")
	target := newLedger(t, ledgerCA)
	clientPair, _, _ := ca.issue(t, 3, x509.ExtKeyUsageClientAuth)
	strangerPair, _, _ := other.issue(t, 4, x509.ExtKeyUsageClientAuth)
	thumb := token.Thumbprint(clientPair.Certificate[0])
	s := start(t, t.TempDir(), ca, ledgerCA, sig, map[string]string{definitions.DataKey: definitionsDoc(thumb, "approved", host, target)})
	s.out.waitFor(t, "fingate-api: serving the resource server on "+s.api+" with mutual TLS, profile rw-4.0.0, host "+host+", ledger "+target+";")
	if c := get(t, "http://"+s.health+"/healthz"); c != http.StatusOK {
		t.Fatalf("/healthz: %d", c)
	}
	if c := get(t, "http://"+s.health+"/readyz"); c != http.StatusOK {
		t.Fatalf("/readyz: %d", c)
	}
	base := "https://" + s.api
	partner := tlsClient(ca, clientPair)

	// The handshake refuses a caller without a client certificate and one from an unknown authority.
	for name, c := range map[string]*http.Client{"no certificate": tlsClient(ca, tls.Certificate{}), "unknown authority": tlsClient(ca, strangerPair)} {
		req, _ := http.NewRequest(http.MethodGet, base+consents+"/x", nil)
		if resp, err := c.Do(req); err == nil {
			_ = resp.Body.Close()
			t.Fatalf("%s: the call reached the server with status %d", name, resp.StatusCode)
		}
	}

	// Every route checks the token: no token is 401 with the challenge.
	resp, body := call(t, partner, http.MethodGet, base+accounts, "", "")
	if resp.StatusCode != http.StatusUnauthorized || resp.Header.Get("WWW-Authenticate") != token.Challenge {
		t.Fatalf("no token: %d %q %s", resp.StatusCode, resp.Header.Get("WWW-Authenticate"), body)
	}

	// A consent is created over the real connection; the certificate bound in the token is the one presented.
	resp, body = call(t, partner, http.MethodPost, base+consents, sig.mint(t, thumb, ""), consentBody)
	if resp.StatusCode != http.StatusCreated {
		t.Fatalf("create: %d %s", resp.StatusCode, body)
	}
	var created struct {
		Data struct {
			ConsentID string `json:"ConsentId"`
		}
	}
	if err := json.Unmarshal([]byte(body), &created); err != nil || created.Data.ConsentID == "" {
		t.Fatalf("create: %s", body)
	}
	if c, ok, err := s.store.Get(context.Background(), created.Data.ConsentID); err != nil || !ok || c.ClientID != clientID {
		t.Fatalf("stored: %+v %v %v", c, ok, err)
	}
	resp, body = call(t, partner, http.MethodGet, base+consents+"/"+created.Data.ConsentID, sig.mint(t, thumb, ""), "")
	if resp.StatusCode != http.StatusOK || !strings.Contains(body, `"Status":"AWAU"`) {
		t.Fatalf("read: %d %s", resp.StatusCode, body)
	}

	// An account operation reads the ledger adapter of the definitions, over TLS: the customer of
	// an authorised consent sees the account the consent names, as the ledger holds it.
	resp, body = call(t, partner, http.MethodGet, base+accounts, s.authorised(t, partner, sig, thumb), "")
	if resp.StatusCode != http.StatusOK || !strings.Contains(body, `"AccountId":"acc-1001"`) || strings.Contains(body, "acc-1002") {
		t.Fatalf("accounts from the ledger: %d %s", resp.StatusCode, body)
	}

	// A suspended partner is refused on the next call.
	s.updateDefinitions(t, definitionsDoc(thumb, "suspended", host, target))
	s.out.waitFor(t, "fingate-api: definitions: loaded")
	if resp, body := call(t, partner, http.MethodPost, base+consents, sig.mint(t, thumb, ""), consentBody); resp.StatusCode != http.StatusForbidden {
		t.Fatalf("suspended partner: %d %s", resp.StatusCode, body)
	}

	// A change of the host, and a change of the ledger, is refused until a restart.
	s.updateDefinitions(t, definitionsDoc(thumb, "approved", "other.bank.example", target))
	if l := s.out.waitFor(t, "fingate-api: definitions: refused"); !strings.Contains(l, "a restart applies profile rw-4.0.0, host other.bank.example, ledger "+target) {
		t.Fatalf("host change: %q", l)
	}
	s.updateDefinitions(t, definitionsDoc(thumb, "approved", host, "dns:///other-adapter:8443"))
	if l := s.out.waitFor(t, "fingate-api: definitions: refused"); !strings.Contains(l, "a restart applies profile rw-4.0.0, host "+host+", ledger dns:///other-adapter:8443") {
		t.Fatalf("ledger change: %q", l)
	}

	if code := s.stop(); code != 0 || !strings.Contains(s.out.text(), "fingate-api: stopped\n") {
		t.Fatalf("stop: exit %d\n%s", code, s.out.text())
	}
}

// The program trusts only the authorities of --ledger-ca-file for the ledger adapter: with
// another authority there, the adapter's certificate is refused and a read of the ledger is a
// server error, while the consent operations, which do not read the ledger, still answer.
func TestRunVerifiesTheLedgersCertificate(t *testing.T) {
	ca, sig := newAuthority(t, "partner authority"), newSigner(t)
	target := newLedger(t, newAuthority(t, "ledger authority"))
	clientPair, _, _ := ca.issue(t, 3, x509.ExtKeyUsageClientAuth)
	thumb := token.Thumbprint(clientPair.Certificate[0])
	s := start(t, t.TempDir(), ca, newAuthority(t, "another authority"), sig,
		map[string]string{definitions.DataKey: definitionsDoc(thumb, "approved", host, target)})
	s.out.waitFor(t, "fingate-api: serving the resource server on "+s.api)
	partner := tlsClient(ca, clientPair)
	resp, body := call(t, partner, http.MethodGet, "https://"+s.api+accounts, s.authorised(t, partner, sig, thumb), "")
	if resp.StatusCode != http.StatusInternalServerError || strings.Contains(body, "acc-1001") {
		t.Fatalf("accounts from a ledger with an untrusted certificate: %d %s", resp.StatusCode, body)
	}
}

func TestRunRefusesABadStart(t *testing.T) {
```
