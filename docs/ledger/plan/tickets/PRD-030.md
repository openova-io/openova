# PRD-030 — Product guard at today's values (rules G-P1 to G-P3)

## In plain words

**The problem today.** The model server, the embedding server and the chat front end are meant to reach a model only through the platform's model gateway, and to receive their credentials as mounted files. Nothing checks this today. A change can publish a model server on a route of its own, point a chart at a model provider's public host, or read one more credential from a Secret object into an environment variable, and no check notices.

**What changes.** One guard checks the three charts on every pull request. A route object in a model server's chart and a model provider's host name in any of the three folders are refused outright. The lines that read a Secret object into an environment variable are counted per file and may only fall.

**Done means:**

- A pull request that adds an HTTPRoute, Ingress, Gateway or GRPCRoute to the chart templates of the model server or of the embedding server turns red.
- A pull request that names api.openai.com, api.anthropic.com or generativelanguage.googleapis.com anywhere in the three chart folders turns red.
- A pull request that adds a secretKeyRef line to the templates of the three charts turns red; one that removes such a line must lower the stored number in the same change.
- The stored numbers hold 13 secretKeyRef lines in four files, and nothing else.
- The guard proves on itself that each of its rules can fail.
- No chart and no product code changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. The guard is the script `scripts/check-products.py`. It reads the working tree. It needs Python 3 and nothing else.
2. Each rule is one function, one list of folders and one fixture for the self-test. The rules are registered in the list `RULES`. A later package adds a rule by adding one function with its folders and fixture to that list, and one key to the `counts` of the baseline. No other rule changes.
3. A rule reads every file under each of its folders, every sub-directory included, and counts per file the lines that break it:
   - `G-P1`, hard zero. Folders `platform/vllm/chart/templates` and `platform/bge/chart/templates`. A line that matches this regular expression: a line that declares one of the four route kinds, also as a list item and also in quotes. A comment line does not match.
     ```
     ^\s*(?:-\s+)?kind:\s*["']?(HTTPRoute|Ingress|Gateway|GRPCRoute)["']?\s*(?:#.*)?$
     ```
   - `G-P2`, hard zero. Folders `platform/vllm`, `platform/bge` and `platform/librechat`, every file. A line that contains `api.openai.com`, `api.anthropic.com` or `generativelanguage.googleapis.com`, in any letter case.
   - `G-P3`, ratchet. Folders `platform/vllm/chart/templates`, `platform/bge/chart/templates` and `platform/librechat/chart/templates`. A line that contains `secretKeyRef`, comment lines included.
4. The stored numbers are the file `scripts/baselines/products.json`, called the baseline. Its form is the shared form of the guard baselines under `scripts/baselines`:
   ```
   {"schema": "openova.io/guard-baseline/v1",
    "counts": {"G-P1": {}, "G-P2": {}, "G-P3": {"<repository path>": <number>}},
    "allow": []}
   ```
   `counts` holds one key per rule. Under a rule, a file with at least one line is an entry; a file that is absent is allowed zero; every number is 1 or more. A hard-zero rule has no entry at all.
5. `allow` is the empty list, always. This guard takes no allow entry: every count falls to zero, or a zero holds.
6. The rule of the guard, for every rule and every file: a count above its entry exits with code 1 and names the line numbers. An entry above the count exits with code 1 too: the baseline must be lowered in the same change. A baseline entry for a hard-zero rule exits with code 1. An allow entry exits with code 1. Otherwise the exit code is 0. Whenever it judges, it prints one line `<rule>=<total>` per rule.
7. A baseline only goes down. `--write-baseline` writes the baseline from the tree. It refuses to raise an entry or to add a file when the baseline exists, and it refuses any line of a hard-zero rule; then it exits with code 1 and leaves the file as it was.
8. A rule over folders that do not exist cannot fail. So when a scanned folder is missing or holds no file, or when the baseline is missing, of another schema, holds another set of rules or keys, or holds an entry of 0, the guard judges nothing and exits with code 2. That is never a pass.
9. `--self-test` builds small trees of its own, 38 times, and shows for each rule that it fails and for each exception that it passes. It reads nothing of the repository.
10. The workflow `.github/workflows/check-products.yaml` has the triggers `pull_request` and `merge_group` and no path filter. Its one job, `check-products`, runs the self-test first and then the guard.
11. G-P1 does not read `platform/librechat`: its chart has an Ingress today, and it is not a model server. No rule reads `platform/kserve` or `platform/knative`: they are not part of the AI hub.

class Unreadable(Exception):
    """A scanned folder or the baseline cannot be read. Nothing is judged: exit 2."""


class Rule(object):
    """One rule: its name, the folders it scans, how it counts, and the fixture of its self-test.

    measure(root) returns repository path -> line numbers (1-based) of the lines that break
    the rule; files without such a line are left out.
    fixture["base"]: files that make every folder of the rule exist and break no rule.
    fixture["fail"]: (what, files) cases; each must make the guard fail on this rule.
    fixture["pass"]: (what, files) cases; each must leave the guard green.
    """

    def __init__(self, name, folders, measure, hard_zero, why, fixture):
        self.name, self.folders, self.measure = name, folders, measure
        self.hard_zero, self.why, self.fixture = hard_zero, why, fixture


def files_under(root, folder):
    """Repository paths of every file under folder, every sub-directory included, sorted."""
    top = os.path.join(root, folder)
    if not os.path.isdir(top):
        raise Unreadable("%s is not a directory" % folder)
    out = []
    for here, dirs, names in os.walk(top):
        dirs.sort()
        for name in names:
            if os.path.isfile(os.path.join(here, name)):
                out.append(os.path.relpath(os.path.join(here, name), root).replace(os.sep, "/"))
    if not out:
        raise Unreadable("%s holds no file" % folder)
    return sorted(out)


def scan(root, folders, pattern):
    """path -> line numbers of the lines of the files under folders that match pattern."""
    found = {}
    for folder in folders:
        for path in files_under(root, folder):
            with open(os.path.join(root, path), "rb") as f:
                lines = f.read().split(b"\n")
            hits = [n + 1 for n, line in enumerate(lines) if pattern.search(line)]
            if hits:
                found[path] = hits
    return found

    """rule name -> repository path -> line numbers."""

def read_baseline(root):
    """Returns (counts, failure lines). Raises Unreadable when the file cannot be judged."""
    try:
        with open(os.path.join(root, BASELINE), encoding="utf-8") as f:
            doc = json.load(f)
    except (OSError, ValueError) as e:
        raise Unreadable("%s cannot be read: %s" % (BASELINE, e))
    if not isinstance(doc, dict) or sorted(doc) != TOP_KEYS:
        raise Unreadable("%s: need exactly the keys %s" % (BASELINE, ", ".join(TOP_KEYS)))
    counts = doc["counts"]
    if doc["schema"] != SCHEMA or not isinstance(counts, dict) or sorted(counts) != sorted(NAMES):
        raise Unreadable("%s: need schema %s and counts for exactly %s" % (BASELINE, SCHEMA, ", ".join(NAMES)))
    for name in NAMES:
        entries = counts[name]
        if not isinstance(entries, dict) or not all(isinstance(k, str) and k and type(v) is int and v >= 1
                                                    for k, v in entries.items()):
            raise Unreadable("%s: counts.%s must map a path to a whole number of 1 or more" % (BASELINE, name))
    if not isinstance(doc["allow"], list):
        raise Unreadable("%s: allow must be a list" % BASELINE)
    fails = []
    if doc["allow"]:
        fails.append("allow: this guard takes no allow entry; a count falls to zero, or a zero holds")
    for r in RULES:
        if r.hard_zero and counts[r.name]:
            fails.append("%s: is a hard zero; the baseline holds no entry for it (found: %s)"
                         % (r.name, ", ".join(sorted(counts[r.name]))))
    return counts, fails


def compare(have, counts):
    """One (rose, line) per rule and path whose count is not exactly its baseline entry."""
    out = []
    for r in RULES:
        for path in sorted(set(have[r.name]) | set(counts[r.name])):
            now, entry = len(have[r.name].get(path, [])), counts[r.name].get(path, 0)
            if now > entry:
                at = ", ".join(str(n) for n in have[r.name][path])
                out.append((True, "%s: %s has %d, the baseline allows %d (match lines: %s); %s"
                            % (r.name, path, now, entry, at, r.why)))
            elif now < entry:
                out.append((False, "%s: %s has %d, the baseline still says %d; lower the baseline in the same change"
                            % (r.name, path, now, entry)))
    return out


def run(root, write=False, say=print):
    """The whole guard. Returns the exit code."""
    try:
        have = measure(root)
        if write:
            target = os.path.join(root, BASELINE)
            rises = []
            for r in RULES:
                if r.hard_zero:
                    rises += ["%s: %s has %d; %s is a hard zero" % (r.name, p, len(n), r.name)
                              for p, n in sorted(have[r.name].items())]
            if os.path.exists(target):
                old, _ = read_baseline(root)
                rises += [line for rose, line in compare(have, old) if rose]
            if rises:
                for line in rises:
                    say("%s: FAIL %s" % (ME, line))
                say("%s: the baseline was not written: a baseline only goes down" % ME)
                return 1
            counts = {r.name: ({} if r.hard_zero else {p: len(n) for p, n in have[r.name].items()}) for r in RULES}
            os.makedirs(os.path.dirname(target), exist_ok=True)
            with open(target, "w", encoding="utf-8") as f:
                f.write(json.dumps({"schema": SCHEMA, "counts": counts, "allow": []}, indent=2, sort_keys=True) + "\n")
            say("%s: wrote %s" % (ME, BASELINE))
        counts, fails = read_baseline(root)
    except Unreadable as e:
        say("%s: cannot judge: %s" % (ME, e))
        return 2
    fails += [line for _, line in compare(have, counts)]
    for name in NAMES:
        say("%s=%d" % (name, sum(len(n) for n in have[name].values())))
    for line in fails:
        say("%s: FAIL %s" % (ME, line))
    if fails:
        say("%s: %d failure(s). To lower the baseline after a line left: python3 scripts/%s.py --write-baseline"
            % (ME, len(fails), ME))
    return 1 if fails else 0
