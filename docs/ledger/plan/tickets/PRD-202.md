# PRD-202 — cortex store: migrations, roles, trimmed query

## In plain words

**The problem today.** The document search of the AI hub has no code. Its folder holds only a long README that describes a design that was withdrawn. Two lab tests measured how its search must be built so that each person finds only what they may read and still gets exact results fast, and nothing applies what they found.

**What changes.** The product gets its database layer: the tables, two database roles with row-level security, and the search built the way the lab tests measured it. A CI job runs its tests against the platform's own PostgreSQL image on every pull request, and a short README describes what exists.

**Done means:**

- A person who may read only some documents never gets a passage of another document from the store, even from a query that has no filter of its own.
- A document with its own reader list is hidden from the other readers of its source and visible to the people on the list and to the managers of the source.
- A session that names no principals reads nothing or fails, and the role of the query process cannot change any table except to queue a job.
- A change of the grants of a source changes what the search returns as soon as it is committed.
- For a reader of few documents the search scans that reader's own rows exactly instead of the approximate index, and a test that explains the plan on a real database proves it.
- A CI job runs every test of the store against the platform's PostgreSQL image on each pull request and turns red when a test is skipped.
- The README of the product describes the store in at most 30 lines.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
`products/cortex` is the Go module `github.com/openova-io/openova/products/cortex` with one package, `internal/store`. Its embedded migration `0001` creates the tables `source`, `source_acl`, `document`, `document_acl`, `chunk` and `job`, the roles `cortex_query` and `cortex_index`, and forced row-level security on `chunk` and `document`. Every `chunk` row carries `readers text[]`, the principals that may read its document, under a GIN index, and the chunk policy tests only that column. `Postgres` implements the port `Store` (`Search`, `ReadableSources`, `ReplaceChunks`, `ApplyDefinitions`). The search binds the caller's principals in its `WHERE` clause as well as in the setting the policy reads, sets `hnsw.iterative_scan` per transaction and sorts the hits again. A grant change rewrites the readers of every chunk it covers in its own transaction. Opening the store checks the role, the `vector` version (0.8.0 or later) and the vector length. `.github/workflows/cortex-ci.yaml` vets and tests the module on every pull request and runs the database test `TestPostgresStore` (14 subtests) against `ghcr.io/cloudnative-pg/postgresql`, pinned by digest, the image the platform's PostgreSQL chart runs; a skipped test fails it. `products/cortex/README.md` is replaced in place by 24 lines. A person sees it this way: the check `go test with PostgreSQL — products/cortex` is green on the pull request, and its log shows the plan of a narrow per-document reader as a bitmap scan on `chunk_readers`, and the same statement without the bound principals as an index scan on `chunk_embedding`.

## 3. The model (the law)
1. One read rule. A principal list may read a document when one of the principals is in `source_acl` for the document's source and either the document inherits or that row's role is `manager`; or when one of the principals is in `document_acl` for the document.
2. `chunk.readers` equals that rule for the chunk's document after every commit of the store. The chunk policy is `readers && current_setting('cortex.principals')::text[]`. The document policy tests the document row's own columns, because a policy on `document` that reads `document` recurses (spike PRD-060).
3. Row-level security is enabled and forced on `chunk` and `document`. `cortex_query` has `SELECT` on every table and `INSERT` on `job`, nothing else. `cortex_index` has `SELECT`, `INSERT`, `UPDATE` and `DELETE` on every table and `USAGE` on the sequences. Both roles are `NOLOGIN`. The database owner may take them with `SET ROLE` and does not inherit their rights, so the owner reads no `chunk` and no `document` row.
4. A search is one read-only transaction: `set_config('cortex.principals', <principals>, true)`, `SET LOCAL hnsw.iterative_scan = relaxed_order`, the statement `SearchSQL` with `c.readers && $3::text[]` bound to the same principals, then a sort by score, best first. The principal list must not be empty. Every value is a bound parameter.
5. A grant change rewrites `chunk.readers` of the chunks it covers in the same transaction: `ApplyDefinitions` when `source_acl` of a source changes, `ReplaceChunks` when it is given a reader list. Only rows whose readers differ are written.
6. The store refuses to open when `vector` is older than 0.8.0, when the vector length differs from the database, and when the connection does not run as the role asked for.
7. Migrations are embedded SQL files applied at start by the database owner, each in its own transaction under an advisory lock. `{{dimensions}}` in a migration is replaced by the vector length (64 to 4096).
8. The old `products/cortex/README.md` is rewritten in place: no path is deleted and `docs/ledger/deleted-paths.txt` is not touched.

# Cortex: knowledge search

The AI hub's document search for one Organization: uploaded documents are split into passages, embedded through the platform's model gateway, and found again by meaning, each search trimmed to what the caller may read.

**Status: store only.** No chart, no Blueprint and no running service ship yet. `docs/STATUS.md` is the inventory of what is built.

## Role in Catalyst

An Application Blueprint, `bp-cortex`, not published yet, written fresh in Go on platform services: the PostgreSQL capability with the `vector` extension holds documents, passages and grants, and every model is reached through the model gateway. The decision record is [ADR-0034](../../docs/adr/0034-later-products-ai-hub-and-open-banking.md).

## What is here

- `internal/store/`: migration `0001`, the two database roles and the `Store` port. `cortex_query` (the query process) reads and queues jobs; `cortex_index` (the index process) writes the rest. Row-level security is forced on `chunk` and `document`: a session reads only rows whose readers meet the principals it set in `cortex.principals`, and a session that set none fails.
- Each passage row carries its readers, the principals of its source's grants or of the document's own reader list plus the source's managers. The search binds the caller's principals as well, so a narrow reader gets an exact scan of its own rows (spikes PRD-060 and PRD-061, under `docs/ledger/plan/spikes/`).

## Configuration

The vector length is `models.embed.dimensions` (64 to 4096); it is written into migration `0001`, and the store refuses to open on a database of another length. The store needs `vector` 0.8.0 or later. Migrations run as the database owner; the first run creates the two roles, so the owner needs `CREATEROLE` then, unless both roles exist and it may grant them.

## Operations

- Run the unit tests with `cd products/cortex && go test ./...`. With `CORTEX_TEST_DATABASE_URL` (a superuser address of a PostgreSQL with `vector`) the store's tests run against it; `.github/workflows/cortex-ci.yaml` runs them on the platform's PostgreSQL image and fails on a skipped test.
- A grant change rewrites the readers of every passage it covers, in the transaction that changes the grant: run it from the index process, never from a request. Such updates are not HOT; vacuum the `chunk` table after a large one.
- Measured limit: a search stays under 200 ms for readers of up to about 20,000 passages in one store (2 % of a million on four CPUs). Broader readers are slower; the numbers are in spike PRD-061.

-- model (models.embed.dimensions); the migrator writes it before it runs this file.
--
-- A principal may read a document when it is in source_acl for the document's source and
-- either the document inherits or that row's role is manager; or when it is in
-- document_acl for the document. chunk.readers holds exactly the principals of that rule
-- for the chunk's document, so the chunk policy tests the chunk row's own column. The
-- store rewrites readers whenever a grant changes.

CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE source (
  id text PRIMARY KEY, title text NOT NULL,
  definition_sha256 text NOT NULL,
  state text NOT NULL DEFAULT 'idle' CHECK (state IN ('idle','syncing','error')),
  last_sync_at timestamptz, last_error text);

CREATE TABLE source_acl (
  source_id text NOT NULL REFERENCES source ON DELETE CASCADE,
  principal text NOT NULL, role text NOT NULL CHECK (role IN ('reader','manager')),
  PRIMARY KEY (source_id, principal, role));

CREATE TABLE document (
  id uuid PRIMARY KEY, source_id text NOT NULL REFERENCES source ON DELETE CASCADE,
  external_id text NOT NULL, title text NOT NULL, uri text NOT NULL,
  content_sha256 text NOT NULL, object_key text NOT NULL,
  state text NOT NULL CHECK (state IN ('fetched','indexed','failed')),

  UNIQUE (source_id, external_id));

  document_id uuid NOT NULL REFERENCES document ON DELETE CASCADE,
  principal text NOT NULL, PRIMARY KEY (document_id, principal));

CREATE TABLE chunk (
  id bigserial PRIMARY KEY,
  document_id uuid NOT NULL REFERENCES document ON DELETE CASCADE,
  source_id text NOT NULL, ordinal int NOT NULL, page int, text text NOT NULL,
  readers text[] NOT NULL,
  embedding vector({{dimensions}}) NOT NULL);
CREATE INDEX chunk_embedding ON chunk USING hnsw (embedding vector_cosine_ops);
CREATE INDEX chunk_source ON chunk (source_id);
CREATE INDEX chunk_readers ON chunk USING gin (readers);
CREATE INDEX chunk_document ON chunk (document_id);

  id uuid PRIMARY KEY,
  kind text NOT NULL CHECK (kind IN ('sync','index','delete')),
  source_id text, document_id uuid,
  state text NOT NULL CHECK (state IN ('queued','running','done','failed','dead')),
  attempts int NOT NULL DEFAULT 0, not_before timestamptz NOT NULL DEFAULT now(),

GRANT INSERT ON job TO cortex_query;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO cortex_index;
GRANT USAGE ON ALL SEQUENCES IN SCHEMA public TO cortex_index;

// Package store is the database of cortex: migration 0001, the two database roles and the
// trimmed search. Store is the port the processes use; Postgres implements it.
//
// Every read of a chunk or a document is trimmed by row-level security to the caller's
// principals. A chunk row carries its readers, the principals that may read its document,
// so the chunk policy tests the row's own column, and the search binds the same principals
// a second time in its WHERE clause. A one-percent reader then gets an exact scan of its
// rows through the GIN index on readers, not the HNSW index, whose recall is below 0.99
// under such a filter (spikes PRD-060 and PRD-061).

	"errors"
	"fmt"
	"regexp"

	DocumentID string
	SourceID   string
	Page       int
	Text       string
	Score      float64
}

	Ordinal   int
	Page      int // 0 when the format has no pages
	Text      string
	Embedding []float32

	ID       string
	Title    string
	Digest   string   // SHA-256 of the sources[] entry; stored as source.definition_sha256
	Readers  []string // principals that read every inheriting document of the source
	Managers []string // principals that manage the source and read all of its documents
}

	if len(principals) == 0 {
		return ErrNoPrincipals
	}
	for _, p := range principals {
		if !principalPattern.MatchString(p) {
			return fmt.Errorf("store: %q is not a principal", p)
		}
	}
	return nil
}

func checkDimensions(d int) error {
	if d < 64 || d > 4096 {
		return fmt.Errorf("store: the vector length %d is not between 64 and 4096", d)
	}
	return nil
}

// The migrations of cortex, embedded and applied at start:
//
//	migrations/<NNNN>_<name>.sql
//
// Versions start at 0001 and have no gap. A released migration is never changed; a change
// of the schema is a new version. The text {{dimensions}} in a migration is replaced by the
// vector length before it runs.
//
// The migrator keeps the applied versions in the table schema_migrations. Each migration
// runs in its own transaction, together with the row that records it, under a
// transaction-scoped advisory lock, so two processes that start at the same time apply each
// migration once. It runs as the database owner. The first run creates the roles
// cortex_query and cortex_index, so the owner needs CREATEROLE then, unless both roles
// exist already and the owner may grant them.

//go:embed migrations/*.sql
var migrationFiles embed.FS

// Migration is one version of the schema.
type Migration struct {
	Version int
	Name    string
	SQL     string
}

// ErrSchemaNewer is returned when the database holds a version this program does not know.
var ErrSchemaNewer = errors.New("store: the database schema is newer than this program")

// migrateLock is the key of the advisory lock the migrator takes in each transaction.
const migrateLock int64 = 0x636f727465782d6d // "cortex-m"

var migrationName = regexp.MustCompile(`^([0-9]{4})_([a-z0-9_]+)\.sql$`)

// Migrations returns the migrations of this program, oldest first.
func Migrations() ([]Migration, error) {
	sub, err := fs.Sub(migrationFiles, "migrations")
	if err != nil {
		return nil, err
	}
	return parseMigrations(sub)
}

// parseMigrations reads the migration files of the top directory of fsys.
func parseMigrations(fsys fs.FS) ([]Migration, error) {
	entries, err := fs.ReadDir(fsys, ".")
	if err != nil {
		return nil, fmt.Errorf("store: migrations: %w", err)
	}
	var out []Migration
	for _, e := range entries {
		m := migrationName.FindStringSubmatch(e.Name())
		if e.IsDir() || m == nil {
			return nil, fmt.Errorf("store: migrations: %q is not <NNNN>_<name>.sql", e.Name())
		}
		body, err := fs.ReadFile(fsys, e.Name())
		if err != nil {
			return nil, fmt.Errorf("store: migrations: %w", err)
		}
		version, _ := strconv.Atoi(m[1])
		out = append(out, Migration{Version: version, Name: m[2], SQL: string(body)})
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Version < out[j].Version })
	for i, mig := range out {
		if mig.Version != i+1 {
			return nil, fmt.Errorf("store: migrations: version %04d is missing or doubled", i+1)
		}
	}
	if len(out) == 0 {
		return nil, errors.New("store: migrations: none found")
	}
	return out, nil
}

// render writes the vector length into a migration.
func render(sql string, dimensions int) (string, error) {
	if err := checkDimensions(dimensions); err != nil {
		return "", err
	}
	return strings.ReplaceAll(sql, "{{dimensions}}", strconv.Itoa(dimensions)), nil
}

const migrationsTable = `CREATE TABLE IF NOT EXISTS schema_migrations (
    version    integer     PRIMARY KEY,
    name       text        NOT NULL,
    applied_at timestamptz NOT NULL DEFAULT now())`

// Migrate connects to url as the database owner, applies every migration the database does
// not have yet, oldest first, and returns the versions it applied. dimensions is the vector
// length of the embedding model. It returns ErrSchemaNewer, and changes nothing, when the
// database has a version this program does not know.
func Migrate(ctx context.Context, url string, dimensions int) ([]int, error) {
	migs, err := Migrations()
	if err != nil {
		return nil, err
	}
	if err := checkDimensions(dimensions); err != nil {
		return nil, err
	}
	conn, err := pgx.Connect(ctx, url)
	if err != nil {
		return nil, fmt.Errorf("store: migrate: %w", err)
	}
	defer func() { _ = conn.Close(context.WithoutCancel(ctx)) }()
	var applied []int
	for _, mig := range migs {
		done, err := migrateOne(ctx, conn, mig, len(migs), dimensions)
		if err != nil {
			return applied, fmt.Errorf("store: migration %04d: %w", mig.Version, err)
		}
		if done {
			applied = append(applied, mig.Version)
		}
	}
	return applied, nil
}

// migrateOne applies mig in one transaction when the database is older than it.
func migrateOne(ctx context.Context, conn *pgx.Conn, mig Migration, known, dimensions int) (bool, error) {
	tx, err := conn.Begin(ctx)
	if err != nil {
		return false, err
	}
	defer func() { _ = tx.Rollback(context.WithoutCancel(ctx)) }()
	if _, err := tx.Exec(ctx, `SELECT pg_advisory_xact_lock($1)`, migrateLock); err != nil {
		return false, err
	}
	if _, err := tx.Exec(ctx, migrationsTable); err != nil {
		return false, err
	}
	var current int
	if err := tx.QueryRow(ctx, `SELECT coalesce(max(version), 0) FROM schema_migrations`).Scan(&current); err != nil {
		return false, err
	}
	if current > known {
		return false, fmt.Errorf("%w: version %d, this program knows %d", ErrSchemaNewer, current, known)
	}
	if current >= mig.Version {
		return false, nil
	}
	sql, err := render(mig.SQL, dimensions)
	if err != nil {
		return false, err
	}
	if _, err := tx.Exec(ctx, sql); err != nil {
		return false, err
	}
	if _, err := tx.Exec(ctx, `INSERT INTO schema_migrations (version, name) VALUES ($1, $2)`, mig.Version, mig.Name); err != nil {
		return false, err
	}
	return true, tx.Commit(ctx)
}

import (
	"context"
	"errors"
	"fmt"
	"sort"
	"strconv"
	"strings"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"

// Postgres is the store on PostgreSQL with the vector extension. It connects as the database
// owner and takes one role on every connection with SET ROLE.
type Postgres struct {
	pool       *pgxpool.Pool
	role       Role
	dimensions int
}

var _ Store = (*Postgres)(nil)

// SearchSQL is the trimmed query. $1 is the query vector, $2 the sources asked for (already
// intersected with the readable ones), $3 the caller's principals, $4 the limit. The
// principals are bound here and again, through the setting cortex.principals, in the row
// policy: bound twice, the planner takes the exact scan of the reader's rows for a narrow
// reader under a custom plan and a generic plan alike (spike PRD-061).
const SearchSQL = `SELECT c.id, c.document_id::text, c.source_id, coalesce(c.page, 0), c.text,
       1 - (c.embedding <=> $1::vector) AS score
FROM chunk c
WHERE c.source_id = ANY ($2::text[])
  AND c.readers && $3::text[]
ORDER BY c.embedding <=> $1::vector
LIMIT $4`

// readersOf is the readers rule for the document row d: the principals in source_acl of its
// source when it inherits, else only the managers there, and every principal in document_acl
// for it. It is the document policy of migration 0001, written as a list.
const readersOf = `ARRAY(
  SELECT s.principal FROM source_acl s
   WHERE s.source_id = d.source_id AND (d.acl_inherit OR s.role = 'manager')
  UNION
  SELECT a.principal FROM document_acl a WHERE a.document_id = d.id
  ORDER BY 1)`

// rewriteSQL makes readers of every chunk of the source $1 equal to the rule. It rewrites
// only the chunks whose readers differ.
const rewriteSQL = `UPDATE chunk c SET readers = r.readers
FROM (SELECT d.id, ` + readersOf + ` AS readers FROM document d WHERE d.source_id = $1) r
WHERE c.document_id = r.id AND c.readers IS DISTINCT FROM r.readers`

// Open connects to url, takes role on every connection, and checks that the vector extension
// is 0.8.0 or later and that the embedding column holds vectors of length dimensions.
// Migrate must have run before.
func Open(ctx context.Context, url string, role Role, dimensions int) (*Postgres, error) {
	if role != RoleQuery && role != RoleIndex {
		return nil, fmt.Errorf("store: unknown role %q", role)
	}
	if err := checkDimensions(dimensions); err != nil {
		return nil, err
	}
	cfg, err := pgxpool.ParseConfig(url)
	if err != nil {
		return nil, fmt.Errorf("store: %w", err)
	}
	cfg.AfterConnect = func(ctx context.Context, c *pgx.Conn) error {
		_, err := c.Exec(ctx, "SET ROLE "+pgx.Identifier{string(role)}.Sanitize())
		return err
	}
	pool, err := pgxpool.NewWithConfig(ctx, cfg)
	if err != nil {
		return nil, fmt.Errorf("store: %w", err)
	}
	p := &Postgres{pool: pool, role: role, dimensions: dimensions}
	if err := p.check(ctx); err != nil {
		pool.Close()
		return nil, err
	}
	return p, nil
}

// Close closes the connections.
func (p *Postgres) Close() { p.pool.Close() }

// check reads the role in use, the extension version and the embedding column's type.
func (p *Postgres) check(ctx context.Context) error {
	var user, version, column string
	err := p.pool.QueryRow(ctx, `SELECT current_user,
	  coalesce((SELECT extversion FROM pg_extension WHERE extname = 'vector'), ''),
	  coalesce((SELECT format_type(a.atttypid, a.atttypmod) FROM pg_attribute a
	             WHERE a.attrelid = to_regclass('chunk') AND a.attname = 'embedding'), '')`).Scan(&user, &version, &column)
	if err != nil {
		return fmt.Errorf("store: %w", err)
	}
	if user != string(p.role) {
		return fmt.Errorf("store: the connection runs as %q, want %q", user, p.role)
	}
	if !versionAtLeast(version, 0, 8) {
		return fmt.Errorf("%w: found %q", ErrExtension, version)
	}
	if want := fmt.Sprintf("vector(%d)", p.dimensions); column != want {
		if column == "" {
			return errors.New("store: the table chunk is missing; run Migrate first")
		}
		return fmt.Errorf("%w: the database holds %s, the model gives %s", ErrDimensions, column, want)
	}
	return nil
}

// versionAtLeast reports whether the version "<major>.<minor>[.<patch>]" is major.minor or later.
func versionAtLeast(version string, major, minor int) bool {
	parts := strings.SplitN(version, ".", 3)
	if len(parts) < 2 {
		return false
	}
	ma, err1 := strconv.Atoi(parts[0])
	mi, err2 := strconv.Atoi(parts[1])
	if err1 != nil || err2 != nil {
		return false
	}
	return ma > major || (ma == major && mi >= minor)
}

// vectorLiteral writes v in the text form of the vector type.
func vectorLiteral(v []float32) string {
	var b strings.Builder
	b.WriteByte('[')
	for i, x := range v {
		if i > 0 {
			b.WriteByte(',')
		}
		b.WriteString(strconv.FormatFloat(float64(x), 'g', -1, 32))
	}
	b.WriteByte(']')
	return b.String()
}

// trimmed runs fn in a read-only transaction whose setting cortex.principals holds principals.
func (p *Postgres) trimmed(ctx context.Context, principals []string, fn func(pgx.Tx) error) error {
	if err := checkPrincipals(principals); err != nil {
		return err
	}
	tx, err := p.pool.BeginTx(ctx, pgx.TxOptions{AccessMode: pgx.ReadOnly})
	if err != nil {
		return fmt.Errorf("store: %w", err)
	}
	defer func() { _ = tx.Rollback(context.WithoutCancel(ctx)) }()
	if _, err := tx.Exec(ctx, `SELECT set_config('cortex.principals', $1::text[]::text, true)`, principals); err != nil {
		return fmt.Errorf("store: %w", err)
	}
	if err := fn(tx); err != nil {
		return err
	}
	return tx.Commit(ctx)
}

// Search runs SearchSQL for the caller's principals and returns the hits by score, best first.
func (p *Postgres) Search(ctx context.Context, principals []string, sources []string, vector []float32, limit int) ([]Hit, error) {
	if limit < 1 || limit > MaxLimit {
		return nil, fmt.Errorf("store: the limit %d is not between 1 and %d", limit, MaxLimit)
	}
	if len(vector) != p.dimensions {
		return nil, fmt.Errorf("%w: the query vector has %d values, want %d", ErrDimensions, len(vector), p.dimensions)
	}
	var hits []Hit
	err := p.trimmed(ctx, principals, func(tx pgx.Tx) error {
		if len(sources) == 0 {
			return nil
		}
		// The HNSW scan stays in use for broad readers; without this it returns too few rows.
		if _, err := tx.Exec(ctx, `SET LOCAL hnsw.iterative_scan = relaxed_order`); err != nil {
			return fmt.Errorf("store: %w", err)
		}
		rows, err := tx.Query(ctx, SearchSQL, vectorLiteral(vector), sources, principals, limit)
		if err != nil {
			return fmt.Errorf("store: search: %w", err)
		}
		hits, err = pgx.CollectRows(rows, func(r pgx.CollectableRow) (Hit, error) {
			var h Hit
			err := r.Scan(&h.ChunkID, &h.DocumentID, &h.SourceID, &h.Page, &h.Text, &h.Score)
			return h, err
		})
		if err != nil {
			return fmt.Errorf("store: search: %w", err)
		}
		return nil
	})
	if err != nil {
		return nil, err
	}
	sortHits(hits)
	return hits, nil
}

// sortHits orders hits by score, best first, then by chunk id. relaxed_order may return rows
// out of distance order, so the store sorts again.
func sortHits(hits []Hit) {
	sort.SliceStable(hits, func(i, j int) bool {
		if hits[i].Score != hits[j].Score {
			return hits[i].Score > hits[j].Score
		}
		return hits[i].ChunkID < hits[j].ChunkID
	})
}

// ReadableSources returns, sorted, the sources in which a principal holds a grant in
// source_acl, or a document_acl entry on a document the caller may read.
func (p *Postgres) ReadableSources(ctx context.Context, principals []string) ([]string, error) {
	var ids []string
	err := p.trimmed(ctx, principals, func(tx pgx.Tx) error {
		rows, err := tx.Query(ctx, `SELECT s.source_id FROM source_acl s WHERE s.principal = ANY ($1::text[])
UNION
SELECT d.source_id FROM document_acl a JOIN document d ON d.id = a.document_id WHERE a.principal = ANY ($1::text[])
ORDER BY 1`, principals)
		if err != nil {
			return fmt.Errorf("store: readable sources: %w", err)
		}
		ids, err = pgx.CollectRows(rows, pgx.RowTo[string])
		if err != nil {
			return fmt.Errorf("store: readable sources: %w", err)
		}
		return nil
	})
	return ids, err
}

// ReplaceChunks deletes the document's chunks and writes chunks in their place, each with
// the document's readers. When readers is not nil, the document gets exactly that reader
// list and stops inheriting the readers of its source; its managers still read it.
func (p *Postgres) ReplaceChunks(ctx context.Context, documentID string, chunks []Chunk, readers []string) error {
	if len(readers) > 0 {
		if err := checkPrincipals(readers); err != nil {
			return err
		}
	}
	for _, c := range chunks {
		if len(c.Embedding) != p.dimensions {
			return fmt.Errorf("%w: chunk %d has %d values, want %d", ErrDimensions, c.Ordinal, len(c.Embedding), p.dimensions)
		}
	}
	tx, err := p.pool.Begin(ctx)
	if err != nil {
		return fmt.Errorf("store: %w", err)
	}
	defer func() { _ = tx.Rollback(context.WithoutCancel(ctx)) }()
	// Wait for an ApplyDefinitions in flight and hold it off until this commits: the readers
	// written below are then those of the committed grants, never of grants a revoke replaces
	// meanwhile. The lock comes first, as in ApplyDefinitions, so the two never deadlock.
	if _, err := tx.Exec(ctx, `SELECT pg_advisory_xact_lock_shared($1)`, applyLock); err != nil {
		return fmt.Errorf("store: %w", err)

		return fmt.Errorf("%w: document %s", ErrNotFound, documentID)

		return fmt.Errorf("store: %w", err)
	}
	if readers != nil {
		if _, err := tx.Exec(ctx, `DELETE FROM document_acl WHERE document_id = $1::uuid`, documentID); err != nil {
			return fmt.Errorf("store: %w", err)
		}
		if _, err := tx.Exec(ctx, `INSERT INTO document_acl (document_id, principal)
SELECT $1::uuid, p FROM unnest($2::text[]) AS p ON CONFLICT DO NOTHING`, documentID, readers); err != nil {
			return fmt.Errorf("store: %w", err)
		}
		if _, err := tx.Exec(ctx, `UPDATE document SET acl_inherit = false WHERE id = $1::uuid`, documentID); err != nil {
			return fmt.Errorf("store: %w", err)
		}
	}
	var list []string
	if err := tx.QueryRow(ctx, `SELECT `+readersOf+` FROM document d WHERE d.id = $1::uuid`, documentID).Scan(&list); err != nil {
		return fmt.Errorf("store: %w", err)
	}
	if _, err := tx.Exec(ctx, `DELETE FROM chunk WHERE document_id = $1::uuid`, documentID); err != nil {
		return fmt.Errorf("store: %w", err)
	}

	for _, c := range chunks {

		if c.Page > 0 {
			page = c.Page

// ApplyDefinitions makes source and source_acl equal to defs in one transaction. A source not
// in defs is deleted with its documents and chunks. When the grants of a source change,
// readers of every chunk of that source is rewritten in the same transaction, so a grant is
// visible to search exactly when it is committed. Run it from the index process, never from
// a request: a grant change writes every chunk it covers.
func (p *Postgres) ApplyDefinitions(ctx context.Context, defs []SourceDefinition) error {
	ids := make([]string, 0, len(defs))
	seen := map[string]bool{}
	for _, d := range defs {
		if d.ID == "" || d.Title == "" || d.Digest == "" {
			return fmt.Errorf("store: source %q needs an id, a title and a digest", d.ID)
		}
		if seen[d.ID] {
			return fmt.Errorf("store: source %q is defined twice", d.ID)
		}
		seen[d.ID] = true
		for _, list := range [][]string{d.Readers, d.Managers} {
			if len(list) > 0 {
				if err := checkPrincipals(list); err != nil {
					return fmt.Errorf("source %q: %w", d.ID, err)
				}
			}
		}
		ids = append(ids, d.ID)
	}
	tx, err := p.pool.Begin(ctx)
	if err != nil {
		return fmt.Errorf("store: %w", err)
	}
	defer func() { _ = tx.Rollback(context.WithoutCancel(ctx)) }()
	if _, err := tx.Exec(ctx, `SELECT pg_advisory_xact_lock($1)`, applyLock); err != nil {
		return fmt.Errorf("store: %w", err)
	}
	if _, err := tx.Exec(ctx, `DELETE FROM source WHERE id <> ALL ($1::text[])`, ids); err != nil {
		return fmt.Errorf("store: %w", err)
	}
	for _, d := range defs {
		if _, err := tx.Exec(ctx, `INSERT INTO source (id, title, definition_sha256) VALUES ($1, $2, $3)
ON CONFLICT (id) DO UPDATE SET title = EXCLUDED.title, definition_sha256 = EXCLUDED.definition_sha256
WHERE (source.title, source.definition_sha256) IS DISTINCT FROM (EXCLUDED.title, EXCLUDED.definition_sha256)`,
			d.ID, d.Title, d.Digest); err != nil {
			return fmt.Errorf("store: source %q: %w", d.ID, err)
		}
		principals := append(append([]string{}, d.Readers...), d.Managers...)
		roles := make([]string, 0, len(principals))
		for range d.Readers {
			roles = append(roles, "reader")
		}
		for range d.Managers {
			roles = append(roles, "manager")
		}
		var changed int64
		if err := tx.QueryRow(ctx, `WITH want AS (
  SELECT DISTINCT p, r FROM unnest($2::text[], $3::text[]) AS w(p, r)),
gone AS (
  DELETE FROM source_acl s WHERE s.source_id = $1
     AND NOT EXISTS (SELECT 1 FROM want WHERE want.p = s.principal AND want.r = s.role) RETURNING 1),
added AS (
  INSERT INTO source_acl (source_id, principal, role) SELECT $1, p, r FROM want
  ON CONFLICT DO NOTHING RETURNING 1)
SELECT (SELECT count(*) FROM gone) + (SELECT count(*) FROM added)`, d.ID, principals, roles).Scan(&changed); err != nil {
			return fmt.Errorf("store: source %q: %w", d.ID, err)
		}
		if changed > 0 {
			if _, err := tx.Exec(ctx, rewriteSQL, d.ID); err != nil {
				return fmt.Errorf("store: source %q: rewrite readers: %w", d.ID, err)
			}
		}
	}
	return tx.Commit(ctx)
}

// applyLock is the key of the advisory lock ApplyDefinitions takes alone and ReplaceChunks
// takes shared, so two index processes apply the definitions one after the other and no
// chunk is committed with the readers of grants that changed while it was written.
const applyLock int64 = 0x636f727465782d64 // "cortex-d"

// waitUntil checks cond every 10 ms and fails the test after 30 s.
func waitUntil(t *testing.T, what string, cond func() bool) {
	t.Helper()
	for deadline := time.Now().Add(30 * time.Second); !cond(); time.Sleep(10 * time.Millisecond) {
		if time.Now().After(deadline) {
			t.Fatalf("timed out waiting until %s", what)
		}
	}
}

// same reports whether two lists hold the same values; nil and empty are the same.
func same(a, b []string) bool {
	return len(a) == len(b) && (len(a) == 0 || reflect.DeepEqual(a, b))
}

func cosine(a, b []float32) float64 {
	var ab, aa, bb float64
	for i := range a {
		ab += float64(a[i]) * float64(b[i])
		aa += float64(a[i]) * float64(a[i])
		bb += float64(b[i]) * float64(b[i])
	}
	return ab / math.Sqrt(aa*bb)
}
