# FND-015 — Candidate tool and cut workflow

## In plain words

**The problem today.** A Sovereign under test follows a branch, and main moves under it while the test runs. There is no fixed, named copy of main to test, so two test runs never test the same thing. Nothing stops two upgrades of core components from landing in the same test either.

**What changes.** A command cuts a candidate: a branch named after the time and the commit, pointing at one commit of main that passed the pin coherence check. It refuses a candidate in which more than one core component changed its version since the last candidate, and it never moves a candidate once it exists. A workflow started by hand runs it, and a dry run proves it before the push credential exists.

**Done means:**

- Running the cut on a coherent commit of main creates the branch rc/<time>-<commit> pointing at that commit and prints its name.
- The cut refuses a commit whose pins are not coherent, a commit not on main, and an existing candidate name, each with its own exit code.
- The cut refuses a candidate in which two or more of the nine core components changed their upstream version since the newest candidate.
- A self-test proves every exit code of the tool, and it runs on every pull request that changes the tool or its workflow.
- The workflow pushes a candidate only with the release-writer credential; without it a run must be a dry run, which checks everything and pushes nothing.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A person or a later workflow can cut a release candidate with one command: `bash scripts/release-candidate.sh cut`. The command takes a commit of `main` (by default its head), runs the existing pin coherence check `scripts/check-train-coherent.sh` in a checkout of that commit, compares the upstream versions of the nine kernel components with the newest earlier candidate, and creates the branch `rc/<id>` on `origin`, pointing at that commit. It refuses when the pins are not coherent, when more than one kernel component moved, and when the ref exists. `verify <id>` confirms a candidate later, and `prune` deletes candidates no gate record names, keeping the newest ten. The workflow `cut-release-candidate` runs the cut when started by hand and writes the candidate into the job summary; on a pull request that changes the tool, its test or the workflow it runs the tool's test. Nothing in this package pushes a candidate yet: the push needs the release-writer credential of package FND-017 (field 11).

## 3. The model (the law)
1. A candidate is the branch ref `rc/<id>` on `origin`. It points at one commit that is on `main` (an ancestor of `origin/main`) and carries no commit of its own. `<id>` is `<UTC time of the cut, yyyymmddThhmmssZ>-<first 7 hex characters of the commit>`, for example `20261120T060000Z-4be7a11`; it matches `^[0-9]{8}T[0-9]{6}Z-[0-9a-f]{7}$`. This is the value that `scripts/acceptance-gate.py` reads as `refs/remotes/origin/rc/<id>` and that the deployment request field `gitopsBranch` accepts.
2. `scripts/release-candidate.sh` has three commands. Their exit codes are a contract for later packages:
   - `cut [--commit <sha>] [--dry-run]`: 0 created (with `--dry-run`: would be created, nothing pushed), and `<id>` is the only line on standard output; 1 the pins are not coherent; 2 more than one kernel component moved; 3 the ref `rc/<id>` exists; 4 the tool could not run (an unknown argument, a commit that is not on `origin/main`, a kernel version that cannot be read, a failed fetch or push).
   - `verify <id>`: 0 when the ref exists, its commit's first 7 characters end `<id>`, its commit is an ancestor of `origin/main`, and the coherence command exits 0 at that commit; then the commit is the only line on standard output. 1 in every other case.
   - `prune [--dry-run]`: deletes every candidate ref whose `<id>` no gate record names, except the ten newest ids; prints each deleted id. A gate record is a file `docs/ledger/acceptance/*.json` on `origin/main`; it names a candidate by its field `candidate.id`. A record that cannot be read stops the prune with exit 4 before anything is deleted. Refs under `rc/` of another shape are never touched.
3. The coherence command is `scripts/check-train-coherent.sh`, run with `bash` in a separate checkout (`git worktree`) of the commit. It is called, never copied. Any exit code other than 0 refuses the cut with exit 1.
4. The kernel components are nine. Their upstream version at a commit is: for `k3s`, the set of `default` values of the variable `k3s_version` in every `infra/providers/<provider>/variables.tf`; for `cilium`, `flux`, `crossplane`, `openbao`, `kyverno`, `cnpg`, `keycloak` and `cert-manager`, the `name=version` pairs of `dependencies` in `platform/<component>/chart/Chart.yaml`. A component counts as moved when its value differs from the value at the newest earlier candidate (the greatest `<id>`). At most one may move. The first candidate has nothing to compare with. A component whose version cannot be read at the commit being cut refuses the cut with exit 4: a missing value is never read as "unchanged".
5. The tool never moves or deletes a ref that `cut` did not just create: it checks with `git ls-remote` that the ref is absent and pushes with `--force-with-lease=refs/heads/rc/<id>:` (an empty lease: the push fails if the ref appeared in the meantime). It writes no file into the working tree.
6. Two environment variables exist only for `scripts/test-release-candidate.sh`: `RC_COHERENCE_CMD` replaces the coherence command, and `RC_CUT_TIME` fixes the time part of `<id>`. No file under `.github/` names either (A3).
7. The workflow `cut-release-candidate` pushes with the token in the secret `RELEASE_WRITER_TOKEN` and never with the workflow token: the ruleset `.github/rulesets/rc.json` lets only the team `release-writer` create a ref under `rc/`. The workflow token is read-only. A run started without `dry_run` and without that secret fails before the cut with a message that names the secret.
8. On a pull request that changes `scripts/release-candidate.sh`, `scripts/test-release-candidate.sh` or the workflow file, the workflow runs only the job `test`; the job `cut` runs only when started by hand.

#!/usr/bin/env bash
# release-candidate.sh - cut, verify and prune release candidates.
#
# A candidate is the branch ref rc/<id> on origin. It points at one commit of main and
# carries no commit of its own. <id> is <UTC yyyymmddThhmmssZ>-<first 7 hex of the commit>,
# for example 20261120T060000Z-4be7a11. The tool never moves a ref that exists, and it
# writes no file into the working tree.
#
#   cut [--commit <sha>] [--dry-run]
#     Default commit: origin/main. Runs scripts/check-train-coherent.sh in a checkout of the
#     commit. Compares the upstream version of each kernel component with the newest earlier
#     candidate. Creates and pushes rc/<id>. With --dry-run it pushes nothing.
#     Exit 0: created (or, with --dry-run, would be created); <id> is the only line on stdout.
#     Exit 1: the pins are not coherent (the coherence output names the pin).
#     Exit 2: more than one kernel component moved (named on stderr).
#     Exit 3: the ref rc/<id> exists.
#     Exit 4: the tool could not run (argument, commit not on origin/main, unreadable
#             input, failed fetch or push).
#   verify <id>
#     Exit 0: the ref exists, its commit ends <id> and is an ancestor of origin/main, and
#     scripts/check-train-coherent.sh exits 0 there; the commit is the only line on stdout.
#     Exit 1: anything else.
#   prune [--dry-run]
#     Deletes the candidate refs that no gate record names, keeping the newest ten. A gate
#     record is a file docs/ledger/acceptance/*.json on origin/main; it names a candidate by
#     candidate.id. Prints each deleted id. Exit 0: done. Exit 4: could not run.
#
# Kernel components and where their upstream version is read at a commit:
#   k3s: the default of variable "k3s_version" in infra/providers/*/variables.tf
#   cilium flux crossplane openbao kyverno cnpg keycloak cert-manager:
#     dependencies[*].version in platform/<component>/chart/Chart.yaml
#

#   RC_CUT_TIME       fixes the time part of <id> (yyyymmddThhmmssZ).

cmd_cut() {
  local commit="refs/remotes/origin/main" dry=0 sha t id prev rc moved n old new
  while [ "$#" -gt 0 ]; do
    case "$1" in
      --commit) [ "$#" -ge 2 ] || die "--commit needs a value"; commit="$2"; shift 2 ;;
      --dry-run) dry=1; shift ;;
      *) die "unknown argument to cut: $1" ;;
    esac
  done
  t="${RC_CUT_TIME:-$(date -u +%Y%m%dT%H%M%SZ)}"
  [[ "$t" =~ ^[0-9]{8}T[0-9]{6}Z$ ]] || die "the time $t is not yyyymmddThhmmssZ"
  fetch || die "git fetch origin failed"
  sha="$(git rev-parse --verify --quiet "${commit}^{commit}")" || die "cannot resolve $commit"
  git merge-base --is-ancestor "$sha" refs/remotes/origin/main || die "commit $sha is not on origin/main"
  id="$t-${sha:0:7}"
  say "candidate rc/$id at commit $sha"

  rc=0; coherence "$sha" || rc=$?
  [ "$COHERENCE_RAN" -eq 1 ] || die "the coherence command could not run at $sha"
  if [ "$rc" -ne 0 ]; then say "refused: the pins at $sha are not coherent (exit $rc)"; exit 1; fi

  new="$(kernel "$sha")" || die "cannot read the kernel versions at $sha"
  if printf '%s\n' "$new" | grep -E ' -$' >&2; then die "the kernel version above cannot be read at $sha"; fi
  prev="$(candidates | { grep -v -x -F "$id" || true; } | tail -n 1)"
  if [ -z "$prev" ]; then
    say "no earlier candidate: nothing to compare the kernel versions with"
  else
    old="$(kernel "refs/remotes/origin/rc/$prev")" || die "cannot read the kernel versions of rc/$prev"
    moved="$(awk 'NR == FNR {v[$1] = $2; next} v[$1] != $2 {print $1 " (" v[$1] " -> " $2 ")"}' \
      <(printf '%s\n' "$old") <(printf '%s\n' "$new"))"
    n="$(printf '%s' "$moved" | grep -c . || true)"
    if [ "$n" -gt 1 ]; then
      say "refused: $n kernel components moved since rc/$prev, at most one may:"
      printf '%s\n' "$moved" | sed 's/^/  /' >&2
      exit 2
    fi
    say "kernel components moved since rc/$prev: ${moved:-none}"
  fi

  rc=0; git ls-remote --exit-code origin "refs/heads/rc/$id" >/dev/null || rc=$?
  if [ "$rc" -eq 0 ]; then say "refused: rc/$id exists"; exit 3; fi
  [ "$rc" -eq 2 ] || die "cannot read the refs of origin"
  if [ "$dry" -eq 1 ]; then
    say "dry run: rc/$id would point at $sha; nothing pushed"
  else
    git push --quiet --force-with-lease="refs/heads/rc/$id:" origin "$sha:refs/heads/rc/$id" >&2 \
      || die "the push of rc/$id was refused"
    say "created rc/$id"
  fi
  echo "$id"
}

cmd_verify() {
  local id="${1:-}" sha rc
  [ "$#" -eq 1 ] || { say "usage: verify <id>"; exit 1; }
  [[ "$id" =~ $ID_RE ]] || { say "not a candidate identifier: $id"; exit 1; }
  fetch || { say "git fetch origin failed"; exit 1; }
  sha="$(git rev-parse --verify --quiet "refs/remotes/origin/rc/$id^{commit}")" \
    || { say "rc/$id does not exist"; exit 1; }
  [ "${sha:0:7}" = "${id##*-}" ] || { say "rc/$id points at $sha, which does not end the id"; exit 1; }
  git merge-base --is-ancestor "$sha" refs/remotes/origin/main \
    || { say "rc/$id points at $sha, which is not on origin/main"; exit 1; }
  rc=0; coherence "$sha" || rc=$?
  [ "$rc" -eq 0 ] || { say "the pins at $sha are not coherent (exit $rc)"; exit 1; }
  say "rc/$id verified"
  echo "$sha"
}

# cut-release-candidate.yaml - cut the release candidate rc/<id> from one commit of main.
#
# The rules are in scripts/release-candidate.sh. A pull request that changes the tool, its
# test or this file runs the test only. A run started by hand runs the test, then
# "release-candidate.sh cut", and writes the candidate into the job summary.
#
# The cut pushes rc/<id> with the token in the secret RELEASE_WRITER_TOKEN, never with the
# workflow token: the ruleset .github/rulesets/rc.json lets only the release-writer team
# create a ref under rc/. Until that secret exists, start a run with dry_run set to true: it
# runs every check of the cut and pushes nothing.
name: cut-release-candidate

on:
  workflow_dispatch:
    inputs:
      commit:
        description: The commit of main to cut. Empty means the head of main.
        required: false
        default: ''
        type: string
      dry_run:
        description: Run every check of the cut and push nothing.
        required: false
        default: false
        type: boolean
  pull_request:
    paths:
      - 'scripts/release-candidate.sh'
      - 'scripts/test-release-candidate.sh'
      - '.github/workflows/cut-release-candidate.yaml'

permissions:
  actions: read
  contents: read
  packages: read
  pull-requests: read

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: false

jobs:
  test:
    name: release-candidate self-test
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v4
        with:
          persist-credentials: false
      - name: Every exit code of the tool is proven
        run: bash scripts/test-release-candidate.sh

  cut:
    name: cut
    needs: test
    if: github.event_name == 'workflow_dispatch'
    runs-on: ubuntu-latest
    timeout-minutes: 60
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
          persist-credentials: false
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Install PyYAML and yq
        run: |
          set -e
          pip install --quiet pyyaml
          sudo wget -q https://github.com/mikefarah/yq/releases/download/v4.45.1/yq_linux_amd64 -O /usr/local/bin/yq
          sudo chmod +x /usr/local/bin/yq
          yq --version
          helm version --short
      - name: Push access for rc/<id>
        if: ${{ !inputs.dry_run }}
        env:
          RELEASE_WRITER_TOKEN: ${{ secrets.RELEASE_WRITER_TOKEN }}
        run: |
          if [ -z "$RELEASE_WRITER_TOKEN" ]; then
            echo "::error::The secret RELEASE_WRITER_TOKEN does not exist. Start the run with dry_run set to true."
            exit 1
          fi
          git remote set-url --push origin "https://x-access-token:${RELEASE_WRITER_TOKEN}@github.com/${GITHUB_REPOSITORY}.git"
      - name: Cut
        env:
          GH_TOKEN: ${{ github.token }}
          COMMIT: ${{ inputs.commit }}
          DRY_RUN: ${{ inputs.dry_run }}
        run: |
          set -euo pipefail
          args=(cut)
          if [ -n "$COMMIT" ]; then args+=(--commit "$COMMIT"); fi
          if [ "$DRY_RUN" = "true" ]; then args+=(--dry-run); fi
          rc=0
          id="$(bash scripts/release-candidate.sh "${args[@]}")" || rc=$?
          if [ "$rc" -ne 0 ]; then
            echo "No candidate: release-candidate.sh cut exited $rc. The log of this step says why." >> "$GITHUB_STEP_SUMMARY"
          elif [ "$DRY_RUN" = "true" ]; then
            echo "Dry run: rc/$id would be cut. Nothing was pushed." >> "$GITHUB_STEP_SUMMARY"
          else
            echo "Candidate: rc/$id" >> "$GITHUB_STEP_SUMMARY"
          fi
          exit "$rc"
