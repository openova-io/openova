# CMP-084 — Validate policies to ValidatingPolicy: flux-managed, and the CronJob guard judges the new kind

## In plain words

**The problem today.** The policy that refuses workloads Flux does not manage is still written in the engine's legacy policy kind, which the engine line after the current one no longer serves. It has no test suite of its own, two suites of its carve-outs expect a pass that cannot fail, and the guard that judges the Jobs of the kit's CronJobs against it reads only the legacy kind.

**What changes.** The policy is written in the new validating kind, in the same file and under the same name, and a new suite gives the same verdicts on the legacy policy and on the new one; the carve-out suites expect a real skip. The CronJob guard reads the policy of the new kind as the kit renders it, and the legacy count falls by one.

**Done means:**

- The policy chart renders flux-managed as a ValidatingPolicy that matches the seven kinds of the legacy rule on create and update, and no longer judges a deletion.
- The suite of the policy has fifteen results and passes on the legacy policy and on the new one.
- The Helm hook and vCluster probe suites read the same copy of the policy and expect a skip for the objects the carve-outs spare.
- A copy of the policy in a suite that is not the current render turns the pull request red.
- The CronJob guard judges every CronJob of the kit against the policy of the new kind and finds none denied; a validation it cannot read counts as a denial.
- The legacy policy guard counts one object fewer: 22 on the base of this ticket.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. **In place.** The template keeps its path, its `metadata.name` `flux-managed`, its labels and annotations, and its values keys `compliancePolicies.fluxManaged.enabled`, `action`, `excludeNamespaces` and `extraExcludeNamespaces` with their defaults. The mode comes from the helper `bp-kyverno-policies.actions` (Audit until the hand-over, Deny after it), as for the policies CMP-062 and CMP-063 rewrote.
2. **Shape.** `apiVersion: policies.kyverno.io/v1`, `kind: ValidatingPolicy`; `spec.evaluation.background.enabled: true` (the legacy `background: true`); `spec.matchConstraints.resourceRules`: four rules of version `v1`, operations `CREATE` and `UPDATE`, on `deployments`, `statefulsets` and `daemonsets` of `apps`, `jobs` and `cronjobs` of `batch`, `services` of the core group and `ingresses` of `networking.k8s.io`: the seven kinds of the legacy rule.
3. **Each exclude filter is a match condition** (an object it spares is not judged, a skip): `exclude-namespaces` (the helper `bp-kyverno-policies.excludeNamespacesExpr` over `excludeNamespaces` and `extraExcludeNamespaces`), `exclude-cnpg-operator-objects` (label `app.kubernetes.io/managed-by: cloudnative-pg`), `exclude-organization-namespaces` (namespace label `openova.io/organization`), `exclude-vcluster-cidr-probe` (a Service named `test-service-delete-me-*`) and `exclude-helm-hooks` (annotation `helm.sh/hook`, whatever its value, as the legacy filter `"*"` read it).
4. **The deny conditions are one validation.** An object is admitted when `app.kubernetes.io/managed-by` is `flux`, or `helm.toolkit.fluxcd.io/name` or `kustomize.toolkit.fluxcd.io/name` is not empty, or it is a Crossplane package runtime (the label `pkg.crossplane.io/revision` on its pod template or selector, and a controller owner of `pkg.crossplane.io` whose kinds are all `ProviderRevision` or `FunctionRevision`). The Crossplane carve-out was a deny condition and stays in the validation (a pass, not a skip). The message is the legacy text, as a `messageExpression`.
5. **A DELETE is no longer judged.** The legacy rule named no operation and judged DELETE too, which denied Crossplane's deletion of an old revision's runtime Deployment unless the carve-out admitted it. The new policy matches `CREATE` and `UPDATE` only, as probes-present has since CMP-063 (pull request 8827). Who manages an object is judged when it is created or changed. Case 10 of the suite `crossplane-package-runtime-admitted` (a DELETE, through its `values.yaml`) is removed with that file; check C3 of `tests/crossplane-runtime-suite-current.sh` proves that neither flux-managed nor probes-present matches a DELETE.
6. **Same verdicts.** The suite `tests/flux-managed` was green on the legacy render first (kyverno CLI v1.19.2), each result naming the rule `workload-must-be-flux-managed`. Then only `policy.yaml` (the new render) and one key of each result (`rule:` became `isValidatingPolicy: true`) changed; resources, `values.yaml` and expected results are the same files. Its five skip results were reported `Excluded` on the legacy kind, which the CLI accepts for any expected result; the new kind gives each a skip through one match condition.
7. **The carve-out suites read one copy.** `helm-hook-admitted` and `vcluster-cidr-probe-admitted` read `../flux-managed/policy.yaml`; their own copies are deleted. Their expected `pass` for the object a carve-out spares becomes `skip`: on the legacy kind that pass could not fail. These skip results also pass on the legacy render, for the reason of point 6.
8. **Current copies.** `tests/suites-current.sh` lists the suite after `app-label-mutate`; the Crossplane suite's `policy.yaml` (both policies) stays the render that `tests/crossplane-runtime-suite-current.sh` C1 compares, and its self-test breaks the new Crossplane validation and the operations of flux-managed.
9. **The guard reads the new kind.** `tools/guards/cmd/cronjob-jobs` finds the policy `flux-managed` of kind `ValidatingPolicy` or `ClusterPolicy` in the render. For a ValidatingPolicy it evaluates `matchConstraints`, the match conditions, the variables and the validations with a subset of CEL written in the guard (no new module dependency). Where it cannot read the policy it errs toward a denial: a field of `matchConstraints` it does not read selects the object, a match condition it cannot evaluate holds, a validation it cannot evaluate denies. A denial names the chart, the CronJob and the labels the policy names. A legacy ClusterPolicy is still read as before.
10. **Baselines only fall.** `scripts/baselines/kyverno-legacy.json` loses the template (23 to 22 objects on the base of this ticket); `scripts/baselines/policy-suites.json` loses `flux-managed`, which now has a suite.
11. **Names.** The row of `cmd/cronjob-jobs` in `tools/guards/README.md` and the step name in `.github/workflows/tree-guards.yaml` name the new kind.
12. No chart version line changes and no Python line is added.

+		return forMatch
+	}
+	for _, x := range list {
+		r, _ := x.(obj)
+		hit, known := ruleSelects(r, o)
+		if !known {
+			hit = forMatch
+		}
+		if hit {
+			return true
+		}
+	}
+	return false
+}
+
+// ruleSelects reads one resource rule. The resource of a kind is its lower
+// case plural with s, which holds for the two kinds the guard builds (Job and
+// Pod).
+func ruleSelects(r obj, o obj) (hit, known bool) {
+	if r == nil {
+		return false, false
+	}
+	group, version := splitAPIVersion(str(o["apiVersion"]))
+	for k, v := range r {
+		var want string
+		switch k {
+		case "apiGroups":
+			want = group
+		case "apiVersions":
+			want = version
+		case "operations":
+			want = "CREATE"
+		case "resources":
+			want = strings.ToLower(str(o["kind"])) + "s"
+		case "resourceNames":
+			if list, isList := v.([]any); isList && len(list) == 0 {
+				continue
+			}
+			want = str(dig(o, "metadata", "name"))
+		case "scope":
+			switch str(v) {
+			case "", "*", "Namespaced":
+				continue
+			case "Cluster":
+				return false, true
+			}
+			return false, false
+		default:
+			return false, false
+		}
+		list, isList := v.([]any)
+		if !isList {
+			return false, false
+		}
+		in := false
+		for _, x := range list {
+			s, isString := x.(string)
+			if !isString {
+				return false, false
+			}
+			if s == want || s == "*" || (k == "resources" && s == "*/*") {
+				in = true
+			}
+		}
+		if !in {
+			return false, true
+		}
+	}
+	return true, true
+}
+
+func splitAPIVersion(apiVersion string) (group, version string) {
+	if i := strings.Index(apiVersion, "/"); i >= 0 {
+		return apiVersion[:i], apiVersion[i+1:]
+	}
+	return "", apiVersion
+}
+
+// namedLabels gives the labels a validation names: each alternative of its
+// top-level || that compares one label of object.metadata.labels with a
+// string literal.
+func (vp *vpolicy) namedLabels(n node) []string {
+	var out []string
+	for _, alt := range disjuncts(n) {
+		b, isBinary := alt.(binaryNode)
+		if !isBinary {
+			continue
+		}
+		if b.op == "in" {
+			if k, isLit := b.l.(litNode); isLit {
+				if s, isString := k.v.(string); isString && vp.isLabels(b.r, 0) {
+					out = append(out, s+" (any value)")
+				}
+			}
+			continue
+		}
+		key, ok := vp.labelOf(b.l)
+		lit, isLit := b.r.(litNode)
+		if !ok || !isLit {
+			continue
+		}
+		s, isString := lit.v.(string)
+		switch {
+		case !isString:
+		case b.op == "==" && s != "":
+			out = append(out, key+": "+s)
+		case b.op == "!=" && s == "":
+			out = append(out, key+" (any value)")
+		}
+	}
+	return out
+}
+
+func disjuncts(n node) []node {
+	if b, isBinary := n.(binaryNode); isBinary && b.op == "||" {
+		return append(disjuncts(b.l), disjuncts(b.r)...)
+	}
+	return []node{n}
+}
+
+// labelOf reads L[?'k'].orValue of the empty string, or L['k'], L the labels
+// of the object.
+func (vp *vpolicy) labelOf(n node) (string, bool) {
+	var ix indexNode
+	switch x := n.(type) {
+	case callNode:
+		lit, isLit := oneArg(x).(litNode)
+		inner, isIndex := x.target.(indexNode)
+		if x.fn != "orValue" || !isLit || lit.v != "" || !isIndex || !inner.opt {
+			return "", false
+		}
+		ix = inner
+	case indexNode:
+		if x.opt {
+			return "", false
+		}
+		ix = x
+	default:
+		return "", false
+	}
+	k, isLit := ix.i.(litNode)
+	s, isString := k.v.(string)
+	if !isLit || !isString || !vp.isLabels(ix.x, 0) {
+		return "", false
+	}
+	return s, true
+}
+
+func oneArg(c callNode) node {
+	if len(c.args) != 1 {
+		return nil
+	}
+	return c.args[0]
+}
+
+// isLabels tells whether n is object.metadata.labels, the same with .? and
+// orValue({}), or a variable defined so.
+func (vp *vpolicy) isLabels(n node, depth int) bool {
+	if depth > len(vp.variables) {
+		return false
+	}
+	switch x := n.(type) {
+	case selectNode:
+		if id, isIdent := x.x.(identNode); isIdent && id.name == "variables" {
+			def := vp.variables[x.field]
+			return !x.opt && def != nil && def.err == nil && vp.isLabels(def.root, depth+1)
+		}
+		m, isSelect := x.x.(selectNode)
+		if x.field != "labels" || !isSelect || m.field != "metadata" {
+			return false
+		}
+		id, isIdent := m.x.(identNode)
+		return isIdent && id.name == "object"
+	case callNode:
+		m, isMap := oneArg(x).(mapNode)
+		s, isSelect := x.target.(selectNode)
+		return x.fn == "orValue" && isMap && len(m.keys) == 0 && isSelect && s.opt && vp.isLabels(s, depth)
+	}
+	return false
+}

+// The CEL subset: values are nil, bool, int64, float64 (numbers of the
+// render), string, []any, obj, optVal and varScope.
+
+type optVal struct {
+	ok bool
+	v  any
+}

+// varScope is the value of the identifier variables.
+type varScope struct{ e *env }
+
+type env struct {
+	vars    map[string]any
+	defs    map[string]*parsed
+	values  map[string]any
+	errs    map[string]error
+	running map[string]bool
+}
+
+func newEnv(o obj, nsLabels map[string]string, defs map[string]*parsed) *env {
+	ns := str(dig(o, "metadata", "namespace"))
+	group, version := splitAPIVersion(str(o["apiVersion"]))
+	e := &env{defs: defs, values: map[string]any{}, errs: map[string]error{}, running: map[string]bool{}}
+	var nsObject any
+	if ns != "" {
+		nsObject = obj{"apiVersion": "v1", "kind": "Namespace", "metadata": obj{"name": ns, "labels": toAny(nsLabels)}}
+	}
+	e.vars = map[string]any{
+		"object": o, "oldObject": nil, "namespaceObject": nsObject,
+		"request": obj{"operation": "CREATE", "namespace": ns, "name": str(dig(o, "metadata", "name")),
+			"kind": obj{"group": group, "version": version, "kind": str(o["kind"])}},
+		"variables": varScope{e: e},
+	}
+	return e
+}
+
+func (e *env) run(p *parsed) (any, error) {
+	if p.err != nil {
+		return nil, p.err
+	}
+	return e.eval(p.root, nil)
+}
+
+func (e *env) variable(name string) (any, error) {
+	if v, done := e.values[name]; done {
+		return v, nil
+	}
+	if err, done := e.errs[name]; done {
+		return nil, err
+	}
+	def := e.defs[name]
+	if def == nil {
+		return nil, fmt.Errorf("no variable %s", name)
+	}
+	if e.running[name] {
+		return nil, fmt.Errorf("variable %s refers to itself", name)
+	}
+	e.running[name] = true
+	v, err := e.run(def)
+	delete(e.running, name)
+	if err != nil {
+		e.errs[name] = err
+		return nil, err
+	}
+	e.values[name] = v
+	return v, nil
+}

+type node any
+
+type (
+	litNode    struct{ v any }
+	identNode  struct{ name string }
+	selectNode struct {
+		x     node
+		field string
+		opt   bool
+	}
+	indexNode struct {
+		x, i node
+		opt  bool
+	}
+	hasNode  struct{ s selectNode }
+	callNode struct {
+		target node // nil for a global function
+		fn     string
+		args   []node
+	}
+	listNode  struct{ elems []node }
+	mapNode   struct{ keys, vals []node }
+	unaryNode struct {
+		op string
+		x  node
+	}
+	binaryNode struct {
+		op   string
+		l, r node
+	}
+	condNode struct{ c, t, f node }
+	compNode struct {
+		macro  string
+		target node
+		v      string
+		body   node
+	}
+)

+type token struct {
+	kind byte // 'i' identifier, 's' string, 'n' number, 'p' punctuation, 0 the end
+	text string
+	val  any
+	pos  int
+}
+
+func isIdentStart(c byte) bool { return c == '_' || (c|0x20 >= 'a' && c|0x20 <= 'z') }
+func isIdentPart(c byte) bool  { return isIdentStart(c) || (c >= '0' && c <= '9') }
+
+func lex(s string) ([]token, error) {
+	var out []token
+	for i := 0; i < len(s); {
+		c := s[i]
+		switch {
+		case c == ' ' || c == '\t' || c == '\n' || c == '\r':
+			i++
+		case isIdentStart(c):
+			j := i + 1
+			for j < len(s) && isIdentPart(s[j]) {
+				j++
+			}
+			word := s[i:j]
+			if j < len(s) && (s[j] == '\'' || s[j] == '"') {
+				if word != "r" && word != "R" {
+					return nil, fmt.Errorf("the literal prefix %s at %d is not read by the guard", word, i)
+				}
+				text, n, err := lexString(s[j:], true)
+				if err != nil {
+					return nil, fmt.Errorf("%v at %d", err, i)
+				}
+				out = append(out, token{kind: 's', text: s[i : j+n], val: text, pos: i})
+				i = j + n
+				continue
+			}
+			out = append(out, token{kind: 'i', text: word, pos: i})
+			i = j
+		case c >= '0' && c <= '9':
+			// A decimal int or a decimal with a fraction; no exponent, hex or unsigned.
+			j := i
+			for j < len(s) && (s[j] >= '0' && s[j] <= '9' || (s[j] == '.' && j+1 < len(s) && s[j+1] >= '0' && s[j+1] <= '9')) {
+				j++
+			}
+			text := s[i:j]
+			var val any
+			var err error
+			if strings.Contains(text, ".") {
+				val, err = strconv.ParseFloat(text, 64)
+			} else {
+				val, err = strconv.ParseInt(text, 10, 64)
+			}
+			if err != nil || (j < len(s) && isIdentPart(s[j])) {
+				return nil, fmt.Errorf("the number %s at %d is not read by the guard", text, i)
+			}
+			out = append(out, token{kind: 'n', text: text, val: val, pos: i})
+			i = j
+		case c == '\'' || c == '"':
+			text, n, err := lexString(s[i:], false)
+			if err != nil {
+				return nil, fmt.Errorf("%v at %d", err, i)
+			}
+			out = append(out, token{kind: 's', text: s[i : i+n], val: text, pos: i})
+			i += n
+		default:
+			two := ""
+			if i+1 < len(s) {
+				two = s[i : i+2]
+			}
+			switch {
+			case two == "==" || two == "!=" || two == "<=" || two == ">=" || two == "&&" || two == "||":
+				out = append(out, token{kind: 'p', text: two, pos: i})
+				i += 2
+			case strings.IndexByte("!<>+-?:.,()[]{}", c) >= 0:
+				out = append(out, token{kind: 'p', text: string(c), pos: i})
+				i++
+			default:
+				return nil, fmt.Errorf("the character %q at %d is not read by the guard", c, i)
+			}
+		}
+	}
+	return append(out, token{pos: len(s)}), nil
+}
+
+// lexString reads a quoted string at the start of s; it gives the text and
+// the length read.
+func lexString(s string, raw bool) (string, int, error) {
+	q := s[0]
+	if strings.HasPrefix(s, string([]byte{q, q, q})) {
+		return "", 0, fmt.Errorf("a triple-quoted string is not read by the guard")
+	}
+	var b strings.Builder
+	for j := 1; j < len(s); j++ {
+		c := s[j]
+		switch {
+		case c == q:
+			return b.String(), j + 1, nil
+		case c == '\n':
+			return "", 0, fmt.Errorf("a line break in a string")
+		case c == '\\' && !raw:
+			j++
+			if j == len(s) {
+				return "", 0, fmt.Errorf("an unterminated string")
+			}
+			switch s[j] {
+			case '\\', '\'', '"', '`', '?':
+				b.WriteByte(s[j])
+			case 'n':
+				b.WriteByte('\n')
+			case 't':
+				b.WriteByte('\t')
+			case 'r':
+				b.WriteByte('\r')
+			default:
+				return "", 0, fmt.Errorf("the escape \\%c is not read by the guard", s[j])
+			}
+		default:
+			b.WriteByte(c)
+		}
+	}
+	return "", 0, fmt.Errorf("an unterminated string")
+}
+
+type parser struct {
+	toks []token
+	i    int
+}
+
+func parseCEL(s string) (node, error) {
+	toks, err := lex(s)
+	if err != nil {
+		return nil, err
+	}
+	p := &parser{toks: toks}
+	n, err := p.expr()
+	if err != nil {
+		return nil, err
+	}
+	if t := p.peek(); t.kind != 0 {
+		return nil, fmt.Errorf("unexpected %q at %d", t.text, t.pos)
+	}
+	return n, nil
+}
+
+func (p *parser) peek() token { return p.toks[p.i] }
+
+func (p *parser) is(text string) bool {
+	t := p.peek()
+	return t.kind == 'p' && t.text == text
+}
+
+func (p *parser) accept(text string) bool {
+	if p.is(text) {
+		p.i++
+		return true
+	}
+	return false
+}
+
+func (p *parser) expect(text string) error {
+	if !p.accept(text) {
+		t := p.peek()
+		return fmt.Errorf("want %q at %d, found %q", text, t.pos, t.text)
+	}
+	return nil
+}
+
+func (p *parser) expr() (node, error) {
+	c, err := p.binary(0)
+	if err != nil || !p.accept("?") {
+		return c, err
+	}
+	t, err := p.binary(0)
+	if err != nil {
+		return nil, err
+	}
+	if err := p.expect(":"); err != nil {
+		return nil, err
+	}
+	f, err := p.expr()
+	if err != nil {
+		return nil, err
+	}
+	return condNode{c: c, t: t, f: f}, nil
+}
+
+var levels = [][]string{{"||"}, {"&&"}, {"==", "!=", "<", "<=", ">", ">=", "in"}, {"+"}}
+
+func (p *parser) binary(level int) (node, error) {
+	if level == len(levels) {
+		return p.unary()
+	}
+	l, err := p.binary(level + 1)
+	if err != nil {
+		return nil, err
+	}
+	for {
+		op := ""
+		t := p.peek()
+		for _, o := range levels[level] {
+			if t.text == o && (t.kind == 'p' || (t.kind == 'i' && o == "in")) {
+				op = o
+			}
+		}
+		if op == "" {
+			return l, nil
+		}
+		p.i++
+		r, err := p.binary(level + 1)
+		if err != nil {
+			return nil, err
+		}
+		l = binaryNode{op: op, l: l, r: r}
+	}
+}
+
+func (p *parser) unary() (node, error) {
+	for _, op := range []string{"!", "-"} {
+		if p.accept(op) {
+			x, err := p.unary()
+			if err != nil {
+				return nil, err
+			}
+			return unaryNode{op: op, x: x}, nil
+		}
+	}
+	return p.member()
+}
+
+func (p *parser) member() (node, error) {
+	n, err := p.primary()
+	if err != nil {
+		return nil, err
+	}
+	for {
+		switch {
+		case p.accept("."):
+			opt := p.accept("?")
+			t := p.peek()
+			if t.kind != 'i' {
+				return nil, fmt.Errorf("want a field name at %d", t.pos)
+			}
+			p.i++
+			if opt || !p.is("(") {
+				n = selectNode{x: n, field: t.text, opt: opt}
+				continue
+			}
+			args, err := p.args()
+			if err != nil {
+				return nil, err
+			}
+			if n, err = method(n, t.text, args); err != nil {
+				return nil, err
+			}
+		case p.accept("["):
+			opt := p.accept("?")
+			i, err := p.expr()
+			if err != nil {
+				return nil, err
+			}
+			if err := p.expect("]"); err != nil {
+				return nil, err
+			}
+			n = indexNode{x: n, i: i, opt: opt}
+		default:
+			return n, nil
+		}
+	}
+}
+
+// method builds a call on a target, or the macro of that name.
+func method(target node, fn string, args []node) (node, error) {
+	switch fn {
+	case "all", "exists", "map", "filter":
+		v, isIdent := firstArg(args).(identNode)
+		if !isIdent || len(args) != 2 {
+			return nil, fmt.Errorf("the macro %s is read by the guard with a variable name and one expression only", fn)
+		}
+		return compNode{macro: fn, target: target, v: v.name, body: args[1]}, nil
+	}
+	return callNode{target: target, fn: fn, args: args}, nil
+}
+
+func firstArg(args []node) node {
+	if len(args) == 0 {
+		return nil
+	}
+	return args[0]
+}
+
+func (p *parser) args() ([]node, error) {
+	return p.list("(", ")")
+}
+
+// list reads open, expressions separated by commas (a trailing comma
+// allowed), close.
+func (p *parser) list(open, close string) ([]node, error) {
+	if err := p.expect(open); err != nil {
+		return nil, err
+	}
+	var out []node
+	for !p.accept(close) {
+		n, err := p.expr()
+		if err != nil {
+			return nil, err
+		}
+		out = append(out, n)
+		if !p.accept(",") {
+			if err := p.expect(close); err != nil {
+				return nil, err
+			}
+			break
+		}
+	}
+	return out, nil
+}
+
+func (p *parser) primary() (node, error) {
+	t := p.peek()
+	switch {
+	case t.kind == 's' || t.kind == 'n':
+		p.i++
+		return litNode{v: t.val}, nil
+	case t.kind == 'i':
+		p.i++
+		switch t.text {
+		case "true":
+			return litNode{v: true}, nil
+		case "false":
+			return litNode{v: false}, nil
+		case "null":
+			return litNode{v: nil}, nil
+		}
+		if !p.is("(") {
+			return identNode{name: t.text}, nil
+		}
+		args, err := p.args()
+		if err != nil {
+			return nil, err
+		}
+		if t.text != "has" {
+			return callNode{fn: t.text, args: args}, nil
+		}
+		s, isSelect := firstArg(args).(selectNode)
+		if len(args) != 1 || !isSelect || s.opt {
+			return nil, fmt.Errorf("has() needs one field selection")
+		}
+		return hasNode{s: s}, nil
+	case p.is("("):
+		p.i++
+		n, err := p.expr()
+		if err != nil {
+			return nil, err
+		}
+		return n, p.expect(")")
+	case p.is("["):
+		elems, err := p.list("[", "]")
+		return listNode{elems: elems}, err
+	case p.accept("{"):
+		var m mapNode
+		for !p.accept("}") {
+			k, err := p.expr()
+			if err != nil {
+				return nil, err
+			}
+			if err := p.expect(":"); err != nil {
+				return nil, err
+			}
+			v, err := p.expr()
+			if err != nil {
+				return nil, err
+			}
+			m.keys, m.vals = append(m.keys, k), append(m.vals, v)
+			if !p.accept(",") {
+				if err := p.expect("}"); err != nil {
+					return nil, err
+				}
+				break
+			}
+		}
+		return m, nil
+	}
+	return nil, fmt.Errorf("unexpected %q at %d", t.text, t.pos)
+}
+
+func (e *env) eval(n node, scope map[string]any) (any, error) {
+	switch n := n.(type) {
+	case litNode:
+		return n.v, nil
+	case identNode:
+		if v, bound := scope[n.name]; bound {
+			return v, nil
+		}
+		if v, known := e.vars[n.name]; known {
+			return v, nil
+		}
+		return nil, fmt.Errorf("the identifier %s is not known to the guard", n.name)
+	case selectNode:
+		x, err := e.eval(n.x, scope)
+		if err != nil {
+			return nil, err
+		}
+		return selectField(x, n.field, n.opt)
+	case indexNode:
+		x, err := e.eval(n.x, scope)
+		if err != nil {
+			return nil, err
+		}
+		i, err := e.eval(n.i, scope)
+		if err != nil {
+			return nil, err
+		}
+		return indexValue(x, i, n.opt)
+	case hasNode:
+		x, err := e.eval(n.s.x, scope)
+		if err != nil {
+			return nil, err
+		}
+		m, isMap := x.(obj)
+		if !isMap {
+			return nil, fmt.Errorf("has() of a field of a value that is not a map")
+		}
+		_, has := m[n.s.field]
+		return has, nil
+	case listNode:
+		out := []any{}
+		for _, x := range n.elems {
+			v, err := e.eval(x, scope)
+			if err != nil {
+				return nil, err
+			}
+			out = append(out, v)
+		}
+		return out, nil
+	case mapNode:
+		out := obj{}
+		for i := range n.keys {
+			k, err := e.eval(n.keys[i], scope)
+			if err != nil {
+				return nil, err
+			}
+			ks, isString := k.(string)
+			if !isString {
+				return nil, fmt.Errorf("a map key that is not a string is not read by the guard")
+			}
+			if out[ks], err = e.eval(n.vals[i], scope); err != nil {
+				return nil, err
+			}
+		}
+		return out, nil
+	case unaryNode:
+		x, err := e.eval(n.x, scope)
+		if err != nil {
+			return nil, err
+		}
+		if b, isBool := x.(bool); isBool && n.op == "!" {
+			return !b, nil
+		}
+		if i, isInt := x.(int64); isInt && n.op == "-" {
+			return -i, nil
+		}
+		if f, isFloat := x.(float64); isFloat && n.op == "-" {
+			return -f, nil
+		}
+		return nil, fmt.Errorf("%s of %T", n.op, x)
+	case binaryNode:
+		if n.op == "&&" || n.op == "||" {
+			return e.logic(n, scope)
+		}
+		l, err := e.eval(n.l, scope)
+		if err != nil {
+			return nil, err
+		}
+		r, err := e.eval(n.r, scope)
+		if err != nil {
+			return nil, err
+		}
+		return binaryOp(n.op, l, r)
+	case condNode:
+		c, err := e.eval(n.c, scope)
+		if err != nil {
+			return nil, err
+		}
+		b, isBool := c.(bool)
+		if !isBool {
+			return nil, fmt.Errorf("the condition of ?: is not a bool")
+		}
+		if b {
+			return e.eval(n.t, scope)
+		}
+		return e.eval(n.f, scope)
+	case callNode:
+		return e.call(n, scope)
+	case compNode:
+		return e.comprehension(n, scope)
+	}
+	return nil, fmt.Errorf("an expression the guard does not read")
+}

+// logic is && and || as CEL has them: the deciding value wins over an error
+// on the other side.
+func (e *env) logic(n binaryNode, scope map[string]any) (any, error) {
+	decides := n.op == "||"
+	l, lerr := e.eval(n.l, scope)
+	if b, isBool := l.(bool); lerr == nil && isBool && b == decides {
+		return decides, nil
+	}
+	r, rerr := e.eval(n.r, scope)
+	if b, isBool := r.(bool); rerr == nil && isBool && b == decides {
+		return decides, nil
+	}
+	if lerr != nil {
+		return nil, lerr
+	}
+	if rerr != nil {
+		return nil, rerr
+	}
+	_, lb := l.(bool)
+	_, rb := r.(bool)
+	if !lb || !rb {
+		return nil, fmt.Errorf("%s of a value that is not a bool", n.op)
+	}
+	return !decides, nil
+}

+func selectField(x any, field string, opt bool) (any, error) {
+	switch v := x.(type) {
+	case optVal:
+		if !v.ok {
+			return optVal{}, nil
+		}
+		got, err := selectField(v.v, field, opt)
+		if o, isOpt := got.(optVal); err != nil || isOpt {
+			return o, err
+		}
+		return optVal{ok: true, v: got}, nil
+	case obj:
+		got, has := v[field]
+		if opt {
+			return optVal{ok: has, v: got}, nil
+		}
+		if !has {
+			return nil, fmt.Errorf("no such key: %s", field)
+		}
+		return got, nil
+	case varScope:
+		if opt {
+			return nil, fmt.Errorf("variables.?%s is not read by the guard", field)
+		}
+		return v.e.variable(field)
+	}
+	return nil, fmt.Errorf("the field %s of a value of type %T", field, x)
+}

+func indexValue(x, i any, opt bool) (any, error) {
+	switch v := x.(type) {
+	case optVal:
+		if !v.ok {
+			return optVal{}, nil
+		}
+		got, err := indexValue(v.v, i, opt)
+		if o, isOpt := got.(optVal); err != nil || isOpt {
+			return o, err
+		}
+		return optVal{ok: true, v: got}, nil
+	case obj:
+		k, isString := i.(string)
+		if !isString {
+			return nil, fmt.Errorf("a map index that is not a string")
+		}
+		return selectField(v, k, opt)
+	case []any:
+		n, isInt := intOf(i)
+		in := isInt && n >= 0 && n < int64(len(v))
+		switch {
+		case in && opt:
+			return optVal{ok: true, v: v[n]}, nil
+		case in:
+			return v[n], nil
+		case isInt && opt:
+			return optVal{}, nil
+		}
+		return nil, fmt.Errorf("the index %v of a list of %d", i, len(v))
+	}
+	return nil, fmt.Errorf("an index of a value of type %T", x)
+}

+func (e *env) call(n callNode, scope map[string]any) (any, error) {
+	var target any
+	if n.target != nil {
+		v, err := e.eval(n.target, scope)
+		if err != nil {
+			return nil, err
+		}
+		target = v
+	}
+	var args []any
+	for _, a := range n.args {
+		v, err := e.eval(a, scope)
+		if err != nil {
+			return nil, err
+		}
+		args = append(args, v)
+	}
+	if n.target == nil {
+		if n.fn == "size" && len(args) == 1 {
+			return sizeOf(args[0])
+		}
+		return nil, fmt.Errorf("the function %s is not read by the guard", n.fn)
+	}
+	if o, isOpt := target.(optVal); isOpt {
+		switch {
+		case n.fn == "orValue" && len(args) == 1:
+			if o.ok {
+				return o.v, nil
+			}
+			return args[0], nil
+		case n.fn == "hasValue" && len(args) == 0:
+			return o.ok, nil
+		case n.fn == "value" && len(args) == 0 && o.ok:
+			return o.v, nil
+		}
+		return nil, fmt.Errorf("%s of an optional value", n.fn)
+	}
+	if n.fn == "size" && len(args) == 0 {
+		return sizeOf(target)
+	}
+	s, isString := target.(string)
+	if !isString {
+		return nil, fmt.Errorf("the method %s of a value of type %T is not read by the guard", n.fn, target)
+	}
+	var a string
+	if len(args) == 1 {
+		a, isString = args[0].(string)
+	}
+	switch {
+	case !isString || len(args) != 1:
+	case n.fn == "startsWith":
+		return strings.HasPrefix(s, a), nil
+	case n.fn == "endsWith":
+		return strings.HasSuffix(s, a), nil
+	case n.fn == "contains":
+		return strings.Contains(s, a), nil
+	case n.fn == "matches":
+		re, err := regexp.Compile(a)
+		if err != nil {
+			return nil, err
+		}
+		return re.MatchString(s), nil
+	}
+	return nil, fmt.Errorf("the method %s is not read by the guard", n.fn)
+}

+func (e *env) comprehension(n compNode, scope map[string]any) (any, error) {
+	x, err := e.eval(n.target, scope)
+	if err != nil {
+		return nil, err
+	}
+	var items []any
+	switch v := x.(type) {
+	case []any:
+		items = v
+	case obj:
+		keys := make([]string, 0, len(v))
+		for k := range v {
+			keys = append(keys, k)
+		}
+		sort.Strings(keys)
+		for _, k := range keys {
+			items = append(items, k)
+		}
+	default:
+		return nil, fmt.Errorf("%s over a value that is not a list or a map", n.macro)
+	}
+	inner := map[string]any{}
+	for k, v := range scope {
+		inner[k] = v
+	}
+	var firstErr error
+	out := []any{}
+	for _, it := range items {
+		inner[n.v] = it
+		switch n.macro {
+		case "map":
+			v, err := e.eval(n.body, inner)
+			if err != nil {
+				return nil, err
+			}
+			out = append(out, v)
+		case "filter":
+			keep, err := boolOf(e.eval(n.body, inner))
+			if err != nil {
+				return nil, err
+			}
+			if keep {
+				out = append(out, it)
+			}
+		default:
+			b, err := boolOf(e.eval(n.body, inner))
+			switch {
+			case err != nil:
+				if firstErr == nil {
+					firstErr = err
+				}
+			case n.macro == "all" && !b:
+				return false, nil
+			case n.macro == "exists" && b:
+				return true, nil
+			}
+		}
+	}
+	switch {
+	case n.macro == "map" || n.macro == "filter":
+		return out, nil
+	case firstErr != nil:
+		return nil, firstErr
+	}
+	return n.macro == "all", nil
+}

+func binaryOp(op string, l, r any) (any, error) {
+	switch op {
+	case "==":
+		return celEqual(l, r), nil
+	case "!=":
+		return !celEqual(l, r), nil
+	case "in":
+		switch c := r.(type) {
+		case []any:
+			for _, x := range c {
+				if celEqual(l, x) {
+					return true, nil
+				}
+			}
+			return false, nil
+		case obj:
+			k, isString := l.(string)
+			if !isString {
+				return nil, fmt.Errorf("in of a map with a key that is not a string")
+			}
+			_, has := c[k]
+			return has, nil
+		}
+		return nil, fmt.Errorf("in of a value of type %T", r)
+	case "<", "<=", ">", ">=":
+		a, aNum := num(l)
+		b, bNum := num(r)
+		as, aStr := l.(string)
+		bs, bStr := r.(string)
+		less, more := a < b, a > b
+		switch {
+		case aStr && bStr:
+			less, more = as < bs, as > bs
+		case !aNum || !bNum:
+			return nil, fmt.Errorf("%s of %T and %T", op, l, r)
+		}
+		return map[string]bool{"<": less, "<=": !more, ">": more, ">=": !less}[op], nil
+	case "+":
+		as, aStr := l.(string)
+		bs, bStr := r.(string)
+		al, aList := l.([]any)
+		bl, bList := r.([]any)
+		ai, aInt := l.(int64)
+		bi, bInt := r.(int64)
+		a, aNum := num(l)
+		b, bNum := num(r)
+		switch {
+		case aStr && bStr:
+			return as + bs, nil
+		case aList && bList:
+			return append(append([]any{}, al...), bl...), nil
+		case aInt && bInt:
+			return ai + bi, nil
+		case aNum && bNum:
+			return a + b, nil
+		}
+	}
+	return nil, fmt.Errorf("%s of %T and %T", op, l, r)
+}
+
+// celEqual is CEL's equality: numbers by value, other values of different
+// types are not equal.
+func celEqual(a, b any) bool {
+	if x, isNum := num(a); isNum {
+		y, both := num(b)
+		return both && x == y
+	}
+	switch x := a.(type) {
+	case nil:
+		return b == nil
+	case bool:
+		y, same := b.(bool)
+		return same && x == y
+	case string:
+		y, same := b.(string)
+		return same && x == y
+	case []any:
+		y, same := b.([]any)
+		if !same || len(x) != len(y) {
+			return false
+		}
+		for i := range x {
+			if !celEqual(x[i], y[i]) {
+				return false
+			}
+		}
+		return true
+	case obj:
+		y, same := b.(obj)
+		if !same || len(x) != len(y) {
+			return false
+		}
+		for k, v := range x {
+			w, has := y[k]
+			if !has || !celEqual(v, w) {
+				return false
+			}
+		}
+		return true
+	}
+	return false
+}
