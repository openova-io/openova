# NET-030 — Retired names lose their policy privileges

## In plain words

**The problem today.** Three chart settings still give special rights to names nobody uses any more. The namespaces dmz, mgmt and rtz are exempt from the security policies, and a namespace called sandbox is allowed network traffic. Whoever creates a namespace with one of these names inherits those rights.

**What changes.** The four names lose their rights. Nothing that runs today uses them.

**Done means:**

- The security policies exempt no namespace named dmz, mgmt or rtz.
- The network rules allow nothing for a namespace named sandbox.
- Everything else in the three settings files is unchanged.
- The existing chart tests still pass.
