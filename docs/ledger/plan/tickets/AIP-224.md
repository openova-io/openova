# AIP-224 — Guard library agentguard and its adversarial corpus

## In plain words

**The problem today.** The operations-records service will hand alert text, log lines and records to agents and answer their tool calls. Text that comes from outside the platform can carry planted instructions, secrets and links that send data away. The service has no guard for any of this, and nothing proves that harmless text, such as a question that names an action, passes untouched.

**What changes.** A guard library in the service makes such text inert, replaces secrets, removes foreign links, keeps answers within the size limit and refuses agent turns when it cannot count them. A corpus of attack and benign cases runs as its test on every pull request that changes the service.

**Done means:**

- A planted marker such as [[action: resolve]] and a line that starts with a role label such as System: are made inert.
- Passwords, tokens, private keys and URL passwords in a text are replaced with [REDACTED].
- A link to a host that is not on the allow-list is replaced, and with an empty allow-list every link is replaced.
- Each of the 25 benign cases, questions about actions among them, comes back from the guard unchanged.
- The turn budget refuses a turn when its counter fails or it has no limit, window or counter.
- The corpus test runs in CI on every pull request that changes products/ops-records.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The Go module `products/ops-records` gains the package `internal/agentguard`, written in the Go standard library only. It holds the functions that the later parts of the service call on every text that comes from outside the platform before an agent reads it, and on every tool answer before an agent gets it: `Inert`, `Redact`, `Links`, `Clean`, `CleanValue`, `Fit`, `FitList`, and the turn budget `Budget` with its in-memory counter `MemoryCounter`. ## 3. The model (the law)
1. The package is the five files of field 16, copied from the blocks of this ticket: `guard.go`, `fit.go`, `budget.go`, `guard_test.go` and `testdata/corpus.json`. It imports only the Go standard library. `go.mod` does not change.
2. `Inert(text)`: every `[[` gets a zero-width space (U+200B) between its two brackets, so `[[[` becomes `[`, U+200B, `[`, U+200B, `[`. Every line whose start, after blanks or invisible characters (space, tab, U+00A0, U+200B, U+2060, U+FEFF), is `system`, `assistant` or `user` with optional blanks and a colon, or the words `tool result`, ignoring case, gets `> ` put before it. A line ends at a line feed, a carriage return, U+0085, U+2028 or U+2029. Every other byte is kept.
3. `Redact(text)` replaces with `[REDACTED]`, in this order: a PEM private key block (to its END line, or to the end of the text when it has none); the value after `Bearer` or `Basic` when it has at least 16 characters and is not letters only; a JSON web token; the password of a URL (`scheme://user:password@host`); the value after a key that ends in `password`, `passwd`, `secret`, `token`, `api key`, `access key`, `private key` or `credential(s)` and then `:` or `=` (quotes around the value are kept); the value after the command-line flags `--password`, `--passwd`, `--secret`, `--token` and `--api-key`.
4. `Links(text, hosts)` replaces with `[link removed]` every link whose host is not allowed. A link is a `scheme://` address, a `www.` address, a `//host` address after a blank, a bracket, a quote or `=`, and every `javascript:`, `vbscript:` and `data:<type>/<subtype>` address. A link is kept only when its scheme is `http` or `https` and its host, without port and ignoring case, equals an entry of `hosts`. The entry `*.example.org` allows every host below `example.org` and not `example.org` itself. With no hosts every link is removed: the allow-list fails closed.
5. `Clean(text, hosts)` is `Inert(Redact(Links(text, hosts)))`. `CleanValue(v, hosts)` returns a copy of a value decoded from JSON in which every string, at any depth of maps and slices, has passed `Clean`; keys and other values are copied unchanged. Every check gives its own output back unchanged when it is run on it again; `TestCorpus` proves this for each case.
6. `MaxAnswer` is 24000: the largest answer, in characters, that a tool gives an agent. `Fit(text, max)` keeps a longer text's start and end with the line `[N characters dropped]` between them, in at most `max` characters. `FitList(sizes, max)` keeps the first entry of a list, then entries alternately from the end (the newest) and from the start, stops at the first entry that does not fit, and returns the indexes it keeps and the number it drops.
7. The turn budget fails closed. `Budget.Take(ctx, key)` returns nil only when its `Counter` counted the turn within `Turns` turns of the current window of length `Window`. When the limit is passed it returns an error that wraps `ErrBudgetSpent`. In every other case, a nil budget, no turns, no window, no counter, an empty key, a counter error (a done context among them) or a count below one, it returns an error that wraps `ErrBudgetUnknown` and the turn is refused. `MemoryCounter` counts in memory and keeps the newest window of each key.
8. The corpus. Each case of `testdata/corpus.json` has the fields `id`, `kind` (`attack` or `benign`), `check` (`inert`, `redact`, `links` or `clean`), `input` and `want`. The cases of `links` and `clean` use the allow-list `console.t01.omani.works`, `*.apps.t01.omani.works`. A benign case wants its input unchanged; an attack case wants a changed text. `TestCorpus` fails when the corpus has fewer than 60 cases, fewer than 20 benign or fewer than 40 attack cases, an unknown field, an empty or repeated `id`, or a case whose output differs from `want`.
9. A benign question that names an action, such as "Can someone acknowledge INC-... and merge it with the database incident?", must not trigger anything: the guard gives it back unchanged, so nothing downstream sees a changed or a fenced text. No part of the service takes an action because a text asks for one. An action can come only from an agent's answer that matches its schema; a planted marker such as `[[action: resolve ...]]` is made inert by rule 2.
10. Fixed test values, named here so that no rule of conduct is in doubt. The corpus and the tests hold made-up values in the shape of secrets: the passwords `hunter2`, `correct horse`, `s3cr3t-value`, `pa55word`, `s3cret`, `pw123`, `x1` and `y2`, the tokens and keys `abcdefghijklmnop0123456789`, `abcdefghij0123456789`, `QWxhZGRpbjpvcGVuc2VzYW1l`, `9f8e7d6c5b4a`, `abc123def`, `abc123`, `k-123456`, a made-up JSON web token and a made-up private key block of the words `example`. They are not a secret of any system; the guard must replace each of them, which is what the cases prove. In `corpus.json` the space of `PRIVATE KEY` is written `\u0020` and the first `J` of the token is written `\u004a`, so that a secret scanner finds no key and no token in the file; JSON reading decodes them. The host name `evil.example` is the target that the link cases must remove.

// Package agentguard keeps text from outside the platform from steering an agent, and keeps
// secrets and foreign links out of what an agent reads and what a tool answers.
//
//   - Inert makes untrusted text inert: it breaks every "[[" with a zero-width space, and it
//     puts "> " before every line that starts with a role label.
//   - Redact replaces secrets with [REDACTED].
//   - Links replaces every link whose host is not on the allow-list with [link removed].
//   - Clean applies Links, Redact and Inert, in this order, to one string. CleanValue applies
//     Clean to every string of a decoded JSON value.
//   - Fit and FitList keep an answer within MaxAnswer characters (fit.go).
//   - Budget counts the turns of an agent per key and window, and fails closed (budget.go).
//
// Text that holds no attack passes unchanged. testdata/corpus.json proves both sides: each attack
// case becomes its expected text; each benign case, such as a question that names an action,
// comes back as it went in.
package agentguard

import (
	"net/url"
	"regexp"
	"strings"
	"unicode/utf8"
)

// The texts the guard writes.
const (
	ZeroWidthSpace = "\u200b"         // Inert puts it between two opening brackets
	Redacted       = "[REDACTED]"     // Redact puts it in place of a secret
	LinkRemoved    = "[link removed]" // Links puts it in place of a link whose host is not allowed
)

// roleLabel matches the start of a line that names a role: blanks or invisible characters
// (U+00A0, U+200B, U+2060, U+FEFF), then "system", "assistant" or "user" with optional blanks
// and a colon, or "tool result" as a word. Case is ignored.
var roleLabel = regexp.MustCompile(`(?i)^[ \t\x{00a0}\x{200b}\x{2060}\x{feff}]*(?:(?:system|assistant|user)[ \t]*:|tool[ \t]+result\b)`)

// lineEnd reports whether r ends a line: line feed, carriage return, next line (U+0085),
// line separator (U+2028) or paragraph separator (U+2029).
func lineEnd(r rune) bool {
	switch r {
	case '\n', '\r', '\u0085', '\u2028', '\u2029':
		return true
	}
	return false
}

// Inert breaks every "[[" with a zero-width space, so "[[[" becomes "[", ZWSP, "[", ZWSP, "[",
// and puts "> " before every line that starts with a role label. Every other byte is kept.
func Inert(text string) string {
	var b strings.Builder
	b.Grow(len(text) + 8)
	start, prev := true, rune(0)
	for i := 0; i < len(text); {
		r, n := utf8.DecodeRuneInString(text[i:])
		if start && roleLabel.MatchString(text[i:]) {
			b.WriteString("> ")
		}
		if r == '[' && prev == '[' {
			b.WriteString(ZeroWidthSpace)
		}
		b.WriteString(text[i : i+n])
		prev = r
		start = lineEnd(r)
		i += n
	}
	return b.String()
}

var (
	pemBlock  = regexp.MustCompile(`(?s)-----BEGIN [A-Z0-9 ]*PRIVATE KEY-----.*?(?:-----END [A-Z0-9 ]*PRIVATE KEY-----|\z)`)
	authValue = regexp.MustCompile(`(?i)\b(bearer|basic)([ \t]+)([A-Za-z0-9._~+/=-]{16,})`)
	jwtValue  = regexp.MustCompile(`\beyJ[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]*`)
	userinfo  = regexp.MustCompile(`(?i)\b([a-z][a-z0-9+.-]*://[^\s:/@]+):[^\s/@]+@`)
	keyValue  = regexp.MustCompile(`(?i)\b([A-Za-z0-9_.-]*(?:password|passwd|secret|token|api[_-]?key|access[_-]?key|private[_-]?key|credentials?)["']?[ \t]*[:=][ \t]*)("[^"\n]*"|'[^'\n]*'|[^\s"',;&]+)`)
	flagValue = regexp.MustCompile(`(?i)((?:^|\s)--?(?:password|passwd|secret|token|api-key)[ \t]+)([^\s-]\S*)`)
)

// Redact replaces secrets with [REDACTED], in this order:
//  1. a PEM private key block, from its BEGIN line to its END line or to the end of the text;
//  2. the value after "Bearer" or "Basic" when it has at least 16 characters, not all letters;
//  3. a JSON web token (three dot-separated parts, the first starting with "eyJ");
//  4. the password of a URL ("scheme://user:password@host");
//  5. the value after a key that ends in password, passwd, secret, token, api key, access key,
//     private key or credential(s), and then ":" or "="; quotes around the value are kept;
//  6. the value after a command-line flag --password, --passwd, --secret, --token or --api-key.
func Redact(text string) string {
	text = pemBlock.ReplaceAllString(text, Redacted)
	text = replace(authValue, text, func(s []string) string {
		if strings.Trim(s[3], "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz") == "" {
			return s[0] // letters only: a word, not a credential
		}
		return s[1] + s[2] + Redacted
	})
	text = jwtValue.ReplaceAllString(text, Redacted)
	text = userinfo.ReplaceAllString(text, "${1}:"+Redacted+"@")
	text = replace(keyValue, text, func(s []string) string {
		v := s[2]
		if q := v[0]; (q == '"' || q == '\'') && len(v) >= 2 {
			return s[1] + string(q) + Redacted + string(q)
		}
		return s[1] + Redacted
	})
	return flagValue.ReplaceAllString(text, "${1}"+Redacted)
}

var (
	linkURL      = regexp.MustCompile(`(?i)\b[a-z][a-z0-9+.-]*://(?:[^\s<>"'()\[\]{}]|\[REDACTED\])+`)
	linkWWW      = regexp.MustCompile(`(?i)\bwww\.[^\s<>"'()\[\]{}]+`)
	linkRelative = regexp.MustCompile(`(^|[\s(<"'=])(//[^\s<>"'()\[\]{}/][^\s<>"'()\[\]{}]*)`)
	linkScript   = regexp.MustCompile(`(?i)\b(?:(?:javascript|vbscript):|data:[a-z]+/[a-z0-9.+-]+[;,])[^\s<>"'()\[\]{}]*`)
)

// Links replaces every link whose host is not allowed with [link removed]. A link is a
// "scheme://..." address, a "www." address, a "//host" address after a blank, a bracket, a
// quote or "=", and any "javascript:", "vbscript:" or "data:<type>/<subtype>" address. A link
// is kept only when its scheme is http or https and its host, without port and ignoring case,
// equals an entry of hosts; an entry "*.example.org" allows every host below example.org, not
// example.org itself. With no hosts every link is removed.
func Links(text string, hosts []string) string {
	text = linkURL.ReplaceAllStringFunc(text, func(m string) string { return keep(m, m, hosts) })
	text = linkWWW.ReplaceAllStringFunc(text, func(m string) string { return keep(m, "http://"+m, hosts) })
	text = replace(linkRelative, text, func(s []string) string { return s[1] + keep(s[2], "https:"+s[2], hosts) })
	return linkScript.ReplaceAllString(text, LinkRemoved)
}

// keep returns link when the address raw has an allowed scheme and host, else LinkRemoved.
func keep(link, raw string, hosts []string) string {
	u, err := url.Parse(strings.ReplaceAll(raw, Redacted, "x")) // a link that Redact has already cleaned
	if err != nil {
		return LinkRemoved
	}
	if s := strings.ToLower(u.Scheme); s != "http" && s != "https" {
		return LinkRemoved
	}
	h := strings.ToLower(u.Hostname())
	if h == "" {
		return LinkRemoved
	}
	for _, a := range hosts {
		a = strings.ToLower(a)
		if suffix, ok := strings.CutPrefix(a, "*"); ok {
			if strings.HasPrefix(suffix, ".") && len(h) > len(suffix) && strings.HasSuffix(h, suffix) {
				return link
			}
		} else if h == a {
			return link
		}
	}
	return LinkRemoved
}

// replace puts f(submatches) in place of every match of re in text.
func replace(re *regexp.Regexp, text string, f func(s []string) string) string {
	var b strings.Builder
	last := 0
	for _, ix := range re.FindAllStringSubmatchIndex(text, -1) {
		s := make([]string, len(ix)/2)
		for g := range s {
			if ix[2*g] >= 0 {
				s[g] = text[ix[2*g]:ix[2*g+1]]
			}
		}
		b.WriteString(text[last:ix[0]])
		b.WriteString(f(s))
		last = ix[1]
	}
	b.WriteString(text[last:])
	return b.String()
}

// Clean applies Links, Redact and Inert, in this order, to text from outside the platform.
func Clean(text string, hosts []string) string {
	return Inert(Redact(Links(text, hosts)))
}

// CleanValue returns a copy of v, a value decoded from JSON, in which every string, at any
// depth of maps and slices, has passed Clean. Keys and other values are copied unchanged.
func CleanValue(v any, hosts []string) any {
	switch t := v.(type) {
	case string:
		return Clean(t, hosts)
	case map[string]any:
		out := make(map[string]any, len(t))
		for k, e := range t {
			out[k] = CleanValue(e, hosts)
		}
		return out
	case []any:
		out := make([]any, len(t))
		for i, e := range t {
			out[i] = CleanValue(e, hosts)
		}
		return out
	}
	return v
}

package agentguard

import (
	"strconv"
	"unicode/utf8"
)

// MaxAnswer is the largest answer, in characters, that a tool gives an agent.
const MaxAnswer = 24000

// Fit returns text when it has at most max characters. A longer text keeps its start and its
// end, which holds the newest lines of a log, with the line "[N characters dropped]" between
// them, and has at most max characters in all. A max of zero or less returns "".
func Fit(text string, max int) string {
	n := utf8.RuneCountInString(text)
	if n <= max {
		return text
	}
	if max <= 0 {
		return ""
	}
	note := func(k int) string { return "\n[" + strconv.Itoa(k) + " characters dropped]\n" }
	r := []rune(text)
	room := max - utf8.RuneCountInString(note(n)) // the note for n is at least as long as any shorter one
	if room < 2 {
		return string(r[:max])
	}
	head := (room + 1) / 2
	tail := room - head
	return string(r[:head]) + note(n-room) + string(r[n-tail:])
}

// FitList chooses the entries of a list, in the list's order with the newest last, whose sizes
// add up to at most max. It takes the first entry, then entries alternately from the end and
// from the start, and stops at the first entry that does not fit. It returns the indexes it
// keeps, in rising order, and the number of entries it drops. The caller keeps room in max for
// the line that says how many were dropped.
func FitList(sizes []int, max int) (keep []int, dropped int) {
	lo, hi := 0, len(sizes)-1
	used, fromEnd := 0, false
	var front, back []int
	for lo <= hi {
		i := lo
		if fromEnd {
			i = hi
		}
		if sizes[i] < 0 || used+sizes[i] > max {
			break
		}
		used += sizes[i]
		if fromEnd {
			back = append(back, i)
			hi--
		} else {
			front = append(front, i)
			lo++
		}
		fromEnd = !fromEnd
	}
	keep = front
	for j := len(back) - 1; j >= 0; j-- {
		keep = append(keep, back[j])
	}
	return keep, len(sizes) - len(keep)
}

package agentguard

import (
	"context"
	"errors"
	"fmt"
	"sync"
	"time"
)

// ErrBudgetSpent is returned when a key has used every turn of the current window.
var ErrBudgetSpent = errors.New("agentguard: turn budget spent")

// ErrBudgetUnknown is returned when the budget cannot be counted: it has no limit, no window
// or no counter, the key is empty, or the counter failed or gave a count below one.
var ErrBudgetUnknown = errors.New("agentguard: turn budget cannot be counted")

// Counter counts turns per key and window.
type Counter interface {
	// Add adds one turn for key in the window that starts at start and returns the number of
	// turns of that window after adding.
	Add(ctx context.Context, key string, start time.Time) (int, error)
}

// Budget allows at most Turns turns per key in each window of length Window. Windows start
// at multiples of Window since the zero time. A key names what is counted, for example an
// Organization and an agent.
//
// Budget fails closed: Take allows a turn only when the counter has counted it within the
// limit. Every other case refuses the turn.
type Budget struct {
	Turns   int
	Window  time.Duration
	Counter Counter
	Now     func() time.Time // nil means time.Now
}

// Take counts one turn for key. It returns nil when the turn is allowed, an error that wraps
// ErrBudgetSpent when the limit is reached, and an error that wraps ErrBudgetUnknown in every
// other case.
func (b *Budget) Take(ctx context.Context, key string) error {
	if b == nil || b.Turns <= 0 || b.Window <= 0 || b.Counter == nil || key == "" {
		return ErrBudgetUnknown
	}
	now := time.Now
	if b.Now != nil {
		now = b.Now
	}
	start := now().UTC().Truncate(b.Window)
	n, err := b.Counter.Add(ctx, key, start)
	if err != nil {
		return fmt.Errorf("%w: %v", ErrBudgetUnknown, err)
	}
	if n < 1 {
		return fmt.Errorf("%w: count %d", ErrBudgetUnknown, n)
	}
	if n > b.Turns {
		return fmt.Errorf("%w: %d of %d turns for %q", ErrBudgetSpent, n, b.Turns, key)
	}
	return nil
}

// MemoryCounter is a Counter in memory, for one process and for tests. It keeps the newest
// window of each key. A turn whose window is older than the newest one counts in the newest.
type MemoryCounter struct {
	mu   sync.Mutex
	keys map[string]memoryWindow
}

type memoryWindow struct {
	start time.Time
	n     int
}

// Add counts one turn. It fails when ctx is done.
func (c *MemoryCounter) Add(ctx context.Context, key string, start time.Time) (int, error) {
	if err := ctx.Err(); err != nil {
		return 0, err
	}
	c.mu.Lock()
	defer c.mu.Unlock()
	if c.keys == nil {
		c.keys = make(map[string]memoryWindow)
	}
	w := c.keys[key]
	if start.After(w.start) {
		w = memoryWindow{start: start}
	}
	w.n++
	c.keys[key] = w
	return w.n, nil
}
