# SOV-170 — The Sovereign repository is seeded at bootstrap and serves the root

## In plain words

**The problem today.** A Sovereign must be born local: its nodes pull images only through the region's own registry, and Flux reads its root objects and every Git source from inside the Sovereign. Nothing on a running Sovereign tests this today, so a node that still falls back to a public registry, or a root that still comes from the parent, passes every acceptance run.

**What changes.** The acceptance suite gains a check that reads, in every region, the start arguments and the registry file of each node, the Git sources of Flux and the owners of the root Kustomizations. The list of checks marks it as expected to fail for now: the seeding of the Sovereign's own repository comes in a later task.

**Done means:**

- The acceptance suite has gate check SOV-G01, Born local, and the list of checks marks it as expected to fail, so it runs and is recorded and cannot fail a run yet.
- In every region the check fails when a node did not start k3s with the public registry endpoints disabled, or when the registry file of a node does not send every image name to the region's own registry first.
- It fails when Flux reads a Git source from outside the Sovereign.
- It fails when a root Kustomization is not Ready, or was not applied by Flux from the Sovereign's own repository at the revision that repository holds.
- A value the check cannot read fails the step that needs it and never counts as a pass, and the login held in the registry file never appears in its evidence.
- Its tests run on every pull request without a cluster, with one failing case for each rule.
- The checks SEC-G01, SEC-G02 and SEC-G03, which share the node probe, read the same nodes and number their steps as before.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The acceptance suite under `tests/acceptance/sovereign/` has one more gate check, SOV-G01 (Born local), in the file `internal/suite/check_born_local.go`. When the suite runs with the gate manifest, the check takes the regions in the order of the run, the primary first. In each region it records three steps: every node started k3s with `--disable-default-registry-endpoint`; no Flux `GitRepository` reads from outside the Sovereign; the root Kustomizations are Ready and applied by Flux from the Sovereign's own repository `openova/sovereign-regions`, at the revision of that source. Then it runs the node probe of `sec_probe.go` in a namespace `born-local-<run>` of its own, one Pod on every node, and judges the registry file `/etc/rancher/k3s/registries.yaml` of each node: it lists `https://<LOCAL_REGISTRY_HOST>` first for every name and has the entry `*`. The manifest `docs/ledger/gates.yaml` names the file and has the entry SOV-G01 in state `expected-fail`: the check runs and is recorded, and it cannot fail a run. The tests of the check need no cluster and run on every pull request. The README of the suite says what the check writes to a cluster.

This ticket delivers the check and not the seeding. The seed Job, the `postBuild.substituteFrom` of the region Kustomization and the root served from the Sovereign's own repository change files under `clusters/_template/sovereign-region/**`, which the stability register `docs/ledger/stability.yaml` (entry `topology-region-git-layout`, `change_policy: closed`) opens to FND-900 only, and the boot template under `infra/providers/`. So, as INF-051 did for INF-G01 (it set INF-G01 to `expected-fail` and left `required` to INF-052), this ticket sets SOV-G01 to `expected-fail`, not `required`. SOV-170 stays the package named in `delivered_by` of the entry. ## 3. The model (the law)
1. **The files are fixed.** The five files of field 14 are changed by the block `SOV-170.patch` at the end of field 20 and by nothing else. The block carries its checksum.
2. **The form of a check.** A gate check of the suite is one file in `tests/acceptance/sovereign/internal/suite/` that calls `RegisterCheck` in `init()` and holds the identifier of the check as a string constant. SOV-G01 is the type `bornLocalCheck`. It calls `kubectl` through its field `kubectl` of the type `kubectlFunc`; the registered check holds `kube.Region.Run` there, the tests a fake cluster.
3. **The variables.** In each region the check reads the ConfigMap `flux-system/sovereign-variables`: `SOVEREIGN_FQDN` judges the hosts of rule 5 and 6, `LOCAL_REGISTRY_HOST` the registry file of rule 7. A ConfigMap, key, annotation, file or list the check cannot read fails the step that needs it. An absent value is never read as a pass.
4. **The nodes.** Every Node carries the annotation `k3s.io/node-args`, the arguments k3s started with as a JSON list, and the list holds `--disable-default-registry-endpoint`. k3s records `--name=value` as the two words `--name` and `value`, so the flag followed by a word that `strconv.ParseBool` reads as false is not set. A Node without the annotation, or a region with no Node, fails the step.
5. **The Git sources.** Flux has at least one `GitRepository` in the region, and the host of every `spec.url` is a cluster Service (a name ending in `.svc` or `.svc.cluster.local`), `SOVEREIGN_FQDN`, or a name under it. A host that only ends like the name (`evil<fqdn>`) is outside.
6. **The root.** The root Kustomizations are the list `bornLocalRoots`: `bootstrap-kit`, `bootstrap-kit-crs`, `sovereign-tls` and `infrastructure-providers`, the last one in the primary region only. The list equals `RootKustomizations` of `core/cmd/sovereign-ops/internal/seedrepo/seedrepo.go`, the Kustomizations that seed-repo commits; the test `TestBornLocalRootsAreTheSeededOnes` keeps the two equal. Each root is a Kustomization of `flux-system`, is `Ready=True`, and carries the Flux labels `kustomize.toolkit.fluxcd.io/name` and `kustomize.toolkit.fluxcd.io/namespace: flux-system`. The Kustomization they name is the owner. The owner's `spec.sourceRef` is a `GitRepository` of the region whose URL is inside the Sovereign (rule 5) and has the path `/openova/sovereign-regions` (a trailing `/` and `.git` are ignored); the owner is `Ready=True`, and its `status.lastAppliedRevision` equals `status.artifact.revision` of that source.
7. **The registry file.** After the three steps of every region, the node probe of `sec_probe.go` runs with the selector `kubernetes.io/hostname`, so it starts one Pod on every node, in a namespace `born-local-<run>` of its own, and deletes that namespace also when a step failed. Its script `bornLocalScript` prints the region's `LOCAL_REGISTRY_HOST` and the registry file in base64, or `registries=unreadable`; it judges nothing and writes nothing. The judge `judgeBornLocalRegistry` decodes the file as JSON, the form the provider modules write, and fails a node when the file is unreadable, is not that JSON, lists no name, has no entry `*`, or has a name whose first endpoint is not `https://<LOCAL_REGISTRY_HOST>`. Only the mirrors are decoded and recorded as evidence, never the `configs`, which hold a login.
8. **The shared probe.** The type `secProbe` gains two fields: `selector`, the label selector of the nodes (`secControlPlane` when empty), and `first`, the number of the last step the check recorded before the probe. SEC-G01, SEC-G02 and SEC-G03 set neither, so they keep their control-plane nodes and their step numbers from 1.
9. **What the check writes.** Through the probe only: `kubectl create namespace`, `kubectl create` of the probe Pods, `kubectl exec` of the script, `kubectl delete namespace`. It never patches and never writes to a node.
10. **The manifest.** The entry `SOV-G01` of `docs/ledger/gates.yaml` moves from `state: not-built` to `state: expected-fail` and gains the line `implementation: tests/acceptance/sovereign/internal/suite/check_born_local.go`. No other field of the entry and no other entry changes.
11. **The README.** `tests/acceptance/sovereign/README.md` names SOV-G01 in its list of the checks that write with `kubectl`, and says what it creates: the namespace `born-local-<run>` with one probe Pod on every node, whose script reads only `/etc/rancher/k3s/registries.yaml`.
12. **Limits, kept on purpose.** The fourth clause of SOV-G01, the catalogue as a verified `OCIRepository`, is SOV-510's. The registry file is read as JSON only: the YAML file of the local pack fails. A node-local proxy listed before the region's registry fails.
13. Nothing is deleted. No new Python, no NodePort, no write to a live system.

+// bornLocalInside reports whether the host of a source URL is a cluster
+// Service, the Sovereign's FQDN or a name under it.
+func bornLocalInside(raw, fqdn string) bool {
+	u, err := url.Parse(raw)
+	if err != nil {
+		return false
+	}
+	h, fqdn := strings.ToLower(u.Hostname()), strings.ToLower(fqdn)
+	return strings.HasSuffix(h, ".svc") || strings.HasSuffix(h, ".svc.cluster.local") || (fqdn != "" && (h == fqdn || strings.HasSuffix(h, "."+fqdn)))

+func bornLocalOwned(region kube.Region, primary bool, ks, repos []kube.Object, fqdn string, ev Evidence) error {
+	byName, sources := map[string]kube.Object{}, map[string]kube.Object{}
+	for _, k := range ks {
+		byName[k.Name()] = k
+	}
+	for _, r := range repos {
+		sources[r.Namespace()+"/"+r.Name()] = r
+	}
+	faults, owners, roots := []string{}, map[string][]string{}, Evidence{}
+	for _, name := range bornLocalRoots {
+		k, ok := byName[name]
+		if !ok {
+			if primary || name != bornLocalPrimaryOnly {
+				faults = append(faults, "no Kustomization flux-system/"+name)
+			}
+			continue
+		}
+		if status, _, message, _ := k.Condition("Ready"); status != "True" {
+			faults = append(faults, fmt.Sprintf("%s is not Ready (%s)", name, message))
+		}
+		owner := k.Str("metadata", "labels", "kustomize.toolkit.fluxcd.io/name")
+		roots[name] = owner
+		if owner == "" || k.Str("metadata", "labels", "kustomize.toolkit.fluxcd.io/namespace") != "flux-system" {
+			faults = append(faults, name+" is not owned by a Kustomization of flux-system")
+			continue
+		}
+		owners[owner] = append(owners[owner], name)
+	}
+	read := Evidence{}
+	for _, o := range slices.Sorted(maps.Keys(owners)) {
+		source, fault := bornLocalOwner(byName, sources, o, fqdn)
+		read[o] = source
+		if fault != "" {
+			faults = append(faults, fmt.Sprintf("the owner %s of [%s] %s", o, strings.Join(owners[o], " "), fault))
+		}
+	}
+	ev["roots"], ev["owners"] = roots, read
+	if len(faults) > 0 {
+		return fmt.Errorf("region %s: %s", region.ID, strings.Join(faults, "; "))
+	}
+	return nil
+}

+// bornLocalOwner judges the Kustomization that applied a root Kustomization:
+// the URL of its source, and what is wrong with it ("" when nothing is).
+func bornLocalOwner(byName, sources map[string]kube.Object, name, fqdn string) (string, string) {
+	o, ok := byName[name]
+	if !ok {
+		return "", "is not a Kustomization of flux-system"
+	}
+	kind, ns := o.Str("spec", "sourceRef", "kind"), o.Str("spec", "sourceRef", "namespace")
+	if ns == "" {
+		ns = o.Namespace()
+	}
+	src, ok := sources[ns+"/"+o.Str("spec", "sourceRef", "name")]
+	if kind != "GitRepository" || !ok {
+		return "", fmt.Sprintf("reads the %s %s/%s, which is no GitRepository of the region", kind, ns, o.Str("spec", "sourceRef", "name"))
+	}
+	raw := src.Str("spec", "url")
+	u, err := url.Parse(raw)
+	if err != nil || !bornLocalInside(raw, fqdn) || strings.TrimSuffix(strings.TrimSuffix(u.Path, "/"), ".git") != bornLocalRepository {
+		return raw, "reads " + raw + ", not the Sovereign's own repository"
+	}
+	if status, _, message, _ := o.Condition("Ready"); status != "True" {
+		return raw, "is not Ready (" + message + ")"
+	}
+	applied, held := o.Str("status", "lastAppliedRevision"), src.Str("status", "artifact", "revision")
+	if applied == "" || applied != held {
+		return raw, fmt.Sprintf("applied the revision %q, its source holds %q", applied, held)
+	}
+	return raw, ""
+}

+// judgeBornLocalRegistry judges what the probe printed in the mode born-local.
+func judgeBornLocalRegistry(v probeValues, ev Evidence) error {
+	own := "https://" + v.one("own")
+	ev["own_registry"] = own
+	switch raw := v["registries"]; {
+	case len(raw) == 0:
+		return errors.New("the probe did not finish")
+	case raw[len(raw)-1] == "unreadable":
+		return errors.New("the node has no readable /etc/rancher/k3s/registries.yaml")
+	}
+	var file struct {
+		Mirrors map[string]struct {
+			Endpoint []string `json:"endpoint"`
+		} `json:"mirrors"`
+	}
+	b, err := base64.StdEncoding.DecodeString(v.one("registries"))
+	if err != nil || json.Unmarshal(b, &file) != nil {
+		return errors.New("/etc/rancher/k3s/registries.yaml is not the JSON the provider modules write")
+	}
+	mirrors, other := map[string][]string{}, []string{}
+	for name, m := range file.Mirrors {
+		mirrors[name] = m.Endpoint
+		if len(m.Endpoint) == 0 || m.Endpoint[0] != own {
+			other = append(other, name)
+		}
+	}
+	sort.Strings(other)
+	ev["mirrors"] = mirrors
+	faults := []string{}
+	if len(mirrors) == 0 {
+		faults = append(faults, "the registry file lists no name")
+	} else if _, ok := file.Mirrors["*"]; !ok {
+		faults = append(faults, `the registry file has no entry "*", so a name it does not list does not go to the region's own registry`)
+	}
+	if len(other) > 0 {
+		faults = append(faults, fmt.Sprintf("the first endpoint is not %s for [%s]", own, strings.Join(other, " ")))
+	}
+	if len(faults) > 0 {
+		return errors.New(strings.Join(faults, "; "))
+	}
+	return nil
+}
