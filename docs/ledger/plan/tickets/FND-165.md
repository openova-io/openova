# FND-165 — Console regression: compliance, sovereignty and hand-over pages, storefront pages

## In plain words

**The problem today.** The console regression list holds 46 rows about the sovereignty cutover as the Settings and Jobs pages show it, the hand-over of a Sovereign to its owner, the deployment wizard, the voucher pages and the storefront funnel of a customer from a voucher to two running Organizations, that people walk by hand. The row map assigns them to a gate check, but no browser test asserts them, so a regression on those surfaces is found only when someone walks them again.

**What changes.** Each of the 46 rows becomes one browser test of the gate harness, titled with its row id and its clause, and the row map names its file. The gate check of these surfaces points at the folder of the tests and enters the gate as expected to fail, so every live gate run runs them and records the result; the rows stay in the ledger until a later task deletes them together with the scripts that read them.

**Done means:**

- Every row that the row map gives to FND-G23 has one browser test whose title starts with the row id, and its line in the row map names that test file.
- The row map guard passes, and a row of FND-G23 whose line names no file, a file without the row's test, or a skipped test turns it red.
- Gate check FND-G23 is expected-fail and its implementation is the folder of the tests, so the harness selects it and lists 46 tests in 4 files.
- The two Organizations the storefront walk creates have fixed names and are deleted by their customer before and after the walk, and the two vouchers it issues are revoked.
- The 286 rows of the ledger are unchanged: the 46 converted rows stay until FND-166 deletes them together with the scripts that read them.

+/** The provisioning record of a tenant on the storefront (GET /api/provisioning/tenant/{id}, what the timeline renders). */
+async function provision(request: APIRequestContext, tenantId: string): Promise<{ status: string; steps: Array<{ name: string; status: string }> }> {
+  const r = await request.get(mkt(`/api/provisioning/tenant/${encodeURIComponent(tenantId)}`))
+  if (r.status() !== 200) throw new Error(`GET /api/provisioning/tenant/${tenantId} answered ${r.status()}`)
+  const body = (await r.json()) as { status?: unknown; steps?: unknown }
+  if (typeof body.status !== 'string' || !Array.isArray(body.steps)) throw new Error(`GET /api/provisioning/tenant/${tenantId} answered no status and steps`)
+  return { status: body.status, steps: (body.steps as Array<{ name?: unknown; status?: unknown }>).map((s) => ({ name: String(s.name ?? ''), status: String(s.status ?? '') })) }
+}

+/** Waits for the end of a provisioning, collecting every stage it saw go red. */
+async function provisioned(request: APIRequestContext, tenantId: string, slug: string): Promise<{ status: string; steps: Array<{ name: string; status: string }>; failedSeen: string[] }> {
+  const failedSeen = new Set<string>()
+  const final = await until(`the provisioning of ${slug} ends`, async () => {
+    const p = await provision(request, tenantId)
+    for (const s of p.steps) if (s.status === 'failed') failedSeen.add(s.name)
+    return p.status === 'completed' || p.status === 'failed' ? p : null
+  }, 2_400_000, 15_000)
+  return { ...final, failedSeen: [...failedSeen] }
+}

+/** An IMAP session over implicit TLS: one command at a time, the lines and literals it answered. */
+function imap(port: number, servername: string): Promise<{ cmd: (c: string) => Promise<string>; close: () => void }> {
+  return new Promise((ready, fail) => {
+    const sock = connect({ host: '127.0.0.1', port, servername })
+    sock.setEncoding('latin1')
+    let buf = ''
+    let greeted = false
+    let n = 0
+    let wait: { tag: string; verb: string; done: (s: string) => void; fail: (e: Error) => void } | null = null
+    const cmd = (c: string) => new Promise<string>((done, f) => {
+      const tag = `g${++n}`
+      wait = { tag, verb: c.split(' ')[0], done, fail: f }
+      sock.write(`${tag} ${c}\r\n`)
+    })
+    sock.on('data', (d: string) => {
+      buf += d
+      if (!greeted) {
+        if (buf.includes('\r\n')) { greeted = true; buf = ''; ready({ cmd, close: () => sock.end() }) }
+        return
+      }
+      const w = wait
+      if (!w) return
+      const end = new RegExp(`(^|\\r\\n)${w.tag} (OK|NO|BAD)[^\\r\\n]*\\r\\n`).exec(buf)
+      if (!end) return
+      const out = buf
+      buf = ''
+      wait = null
+      if (end[2] === 'OK') w.done(out)
+      else w.fail(new Error(`IMAP ${w.verb} answered ${end[2]}`)) // never the command: LOGIN holds the password
+    })
+    sock.on('error', (e) => (wait ? wait.fail(e) : fail(e)))
+  })
+}

+      const body = (await s.cmd(`UID FETCH ${newest} BODY.PEEK[TEXT]`)).replace(/=\r\n/g, '')
