# FND-099 — Remove two custom resources that nothing reads

## In plain words

**The problem today.** The platform chart installs two custom resource kinds, Runbook and SecretPolicy, on every cluster. No program of the platform creates, reads or acts on an object of either kind; both were schemas for controllers that were never built. They make the platform look as if it had automatic runbooks and secret rotation, which it does not have.

**What changes.** The two definitions are deleted. The chart's notes, the schema bundle of the API server and the generated inventory of custom resources no longer list them, and the list of deleted paths names both files.

**Done means:**

- The platform chart no longer holds a definition of the kind Runbook or of the kind SecretPolicy.
- Every other definition of the chart is still there.
- The schema bundle of the API server matches the remaining definitions, and its test passes.
- The generated inventory of custom resources lists neither kind and is current.
- The chart's notes list the remaining definitions and name neither file.
- The list of deleted paths names both files, so a pull request that brings one back turns red.

The rest of this ticket is the exact instruction for the model that does the work.
