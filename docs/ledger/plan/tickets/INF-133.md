# INF-133 — Check INF-G02: node host scans, as a suite file

## In plain words

**The problem today.** The machine plane can scan every node of a Sovereign for its hardening state and its installed software, but no acceptance run tests that a scan really happens. A scan that never starts, or one that ends without a report or a bill of materials for some node, would go unnoticed.

**What changes.** The acceptance suite gains a check that starts one scan of the nodes in each region and then looks for the report and the bill of materials of that scan on every node. The list of checks marks it as expected to fail for now, so it runs and is recorded but cannot fail a run yet.

**Done means:**

- The check starts no scan unless the default node policy exists and every node is known to the machine plane as an active machine of class node.
- It starts one scan run per region and fails when the runs have not finished within 30 minutes or one of them did not succeed.
- It fails when a node has no hardening report of that run, a report without a result, or a report that holds only the row no-profile-for-release, in which no hardening rule was checked.
- It fails when the bill of materials recorded for a node is not the one of that run, or has no valid checksum or collection time.
- It never reads the storage bucket of the scan files; it reads only what the Kubernetes API serves.
- It deletes the run in every region it asked to create one, also when it fails, when that create returned an error, and when the delete of another region failed.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The acceptance suite holds gate check INF-G02, "Node host scans", in the file `tests/acceptance/sovereign/internal/suite/check_inf_g02.go`, and the gate manifest lists it as `expected-fail`. When the suite runs against a Sovereign (locally on the provider pack or in the cloud), the check creates one `MachineRun` of kind `scan` for ScanPolicy `catalyst-infra/nodes` in every region, waits until every run is final, and passes only when every Node of every region has a target of that run that succeeded, a hardening report of that run with at least one result of a rule that was checked, and in `Machine.status.sbom` the key `catalyst-infra/<node>/<run>/sbom.cdx.json` with a SHA-256. It deletes its runs before it ends. Package INF-160 installs the release on the Sovereign and moves the check to `required`; this ticket does neither.

## 3. The model (the law)
1. The check is one file of the suite that calls `RegisterCheck` in `init()` and holds the literal `INF-G02`; its test is one file beside it. No other file of the suite changes except the package comment of `internal/kube` and the README, which list the checks that write to a cluster.
2. Step 1, in every region: ScanPolicy `catalyst-infra/nodes` exists, and every Node has a Machine of its own name in `catalyst-infra` with `spec.class` `node`, the label `machines.openova.io/class=node` and `status.phase` `Active` (the Machines the operations controller targets). A region that fails it fails the check, and no run is created.
3. Step 2: one MachineRun `catalyst-infra/inf-g02-<run id>` is created in every region with `kubectl create -f -`: kind `scan`, `policyRef` ScanPolicy `nodes`, `requestedBy` `acceptance-suite`, no `targets` (the policy selects them).
4. Step 3: every 15 seconds the check reads the run of every region. It ends when every run has a final phase (`Succeeded`, `PartiallyFailed`, `Failed`), or fails when 30 minutes have passed since it started waiting. A reading that fails is no observation. Every run must be `Succeeded`.
5. Step 4, for every Node of every region: the run's target `catalyst-infra/<node>` has outcome `Succeeded`, lists the evidence key `catalyst-infra/<node>/<run>/sbom.cdx.json` and names the report `machine-<node>-hardening`; `Machine.status.sbom.key` equals that key, `sha256` is 64 lower-case hexadecimal digits and `collectedAt` is a time in RFC 3339 form; PolicyReport `catalyst-infra/machine-<node>-hardening` has at least one result, at least one result whose `rule` is not `no-profile-for-release`, and every result has `properties.runName` equal to the run. When the baseline has no profile for the release of a node, or the content has no data stream for it, the operations controller writes that report with the single row `no-profile-for-release` (result `skip`) and the target still ends `Succeeded` (`products/catalyst/bootstrap/api/internal/machines/operations/runs.go`, `products/catalyst/bootstrap/api/internal/machines/runner/hardening.go`): no hardening rule was checked on that node, and the node fails.
6. The bill of materials is read through the Kubernetes API, never from the evidence bucket. No check of the suite reads object storage today and no route of catalyst-api serves the evidence bucket; the API that serves the bill of materials is the Kubernetes API, as `Machine.status.sbom`. That the file is CycloneDX is proven where it is written: the runner refuses to upload an inventory whose `bomFormat` is not `CycloneDX` (`products/catalyst/bootstrap/api/internal/machines/runner/inventory.go`, test `TestInventoryWithoutACycloneDXDocumentIsFailed`).
7. Step 5: the run is deleted with `kubectl delete ... --wait=false --ignore-not-found` in every region the check sent a create to, also when that create returned an error (the API server may have stored the run before its answer was lost), also when an earlier step failed, and in the other regions also when the delete of one region failed; the step then fails and names those regions. The check never patches.
8. The check waits only through its `wait` function (`rebootWait` of `check_inf_g01.go` in the suite), never with a sleep or a ticker; the test drives a fake clock.
9. The manifest entry INF-G02 moves from `not-built` to `expected-fail` and gains its `implementation` line; no other field and no other entry changes.

// nodes returns the names of the Nodes of a region that the policy does not
// select through a Machine, and the names of all its Nodes, sorted.
func (c infScanCheck) nodes(ctx context.Context, region kube.Region) (all, unselected []string, err error) {
	if _, err := c.get(ctx, region, infScanPolicies, infScanPolicy, "-n", infScanNamespace); err != nil {
		return nil, nil, fmt.Errorf("[%s] ScanPolicy %s/%s: %w", region.ID, infScanNamespace, infScanPolicy, err)
	}
	nodes, err := c.get(ctx, region, "nodes")
	if err != nil {
		return nil, nil, err
	}
	machines, err := c.get(ctx, region, infScanMachines, "-n", infScanNamespace)
	if err != nil {
		return nil, nil, err
	}
	active := map[string]bool{}
	for _, m := range machines.Objects("items") {
		active[m.Name()] = m.Str("spec", "class") == "node" && m.Str("status", "phase") == "Active" &&
			m.Str("metadata", "labels", "machines.openova.io/class") == "node"
	}
	for _, n := range nodes.Objects("items") {
		all = append(all, n.Name())
		if !active[n.Name()] {
			unselected = append(unselected, n.Name())
		}
	}
	sort.Strings(all)
	sort.Strings(unselected)
	if len(all) == 0 {
		return nil, nil, fmt.Errorf("[%s] the region lists no Node", region.ID)
	}
	return all, unselected, nil
}

// judge returns what is wrong with the scan of the nodes of one region.
func (c infScanCheck) judge(ctx context.Context, region kube.Region, run kube.Object, nodes []string, ev map[string]any) ([]string, error) {
	targets := map[string]kube.Object{}
	for _, t := range run.Objects("status", "targets") {
		targets[t.Str("machine")] = t
	}
	machines, err := c.get(ctx, region, infScanMachines, "-n", infScanNamespace)
	if err != nil {
		return nil, err
	}
	sboms := map[string]kube.Object{}
	for _, m := range machines.Objects("items") {
		if s, isMap := m.Get("status", "sbom").(map[string]any); isMap {
			sboms[m.Name()] = s
		}
	}
	reports, err := c.get(ctx, region, infScanReports, "-n", infScanNamespace)
	if err != nil {
		return nil, err
	}
	byName := map[string]kube.Object{}
	for _, r := range reports.Objects("items") {
		byName[r.Name()] = r
	}
	wrong, keys := []string{}, map[string]string{}
	for _, node := range nodes {
		key, report := infScanNamespace+"/"+node+"/"+run.Name()+"/sbom.cdx.json", "machine-"+node+"-hardening"
		t, sbom := targets[infScanNamespace+"/"+node], sboms[node]
		switch {
		case t == nil:
			wrong = append(wrong, node+": the run has no target "+infScanNamespace+"/"+node)
		case t.Str("outcome") != infScanSucceeded:
			wrong = append(wrong, fmt.Sprintf("%s: the target ended %q (%s)", node, t.Str("outcome"), t.Str("message")))
		case !infScanLists(t, key):
			wrong = append(wrong, node+": the target lists no evidence "+key)
		case t.Str("reportName") != report:
			wrong = append(wrong, fmt.Sprintf("%s: the target names the report %q, want %s", node, t.Str("reportName"), report))
		case sbom.Str("key") != key:
			wrong = append(wrong, fmt.Sprintf("%s: Machine.status.sbom.key is %q, want %s", node, sbom.Str("key"), key))
		case !infScanSHA.MatchString(sbom.Str("sha256")) || !infScanTime(sbom.Str("collectedAt")):
			wrong = append(wrong, fmt.Sprintf("%s: Machine.status.sbom has the sha256 %q and the collection time %q", node, sbom.Str("sha256"), sbom.Str("collectedAt")))
		default:
			keys[node] = key + " sha256:" + sbom.Str("sha256")
			results := byName[report].Objects("results")
			switch {
			case len(results) == 0:
				wrong = append(wrong, fmt.Sprintf("%s: PolicyReport %s/%s is missing or has no result", node, infScanNamespace, report))
			case !infScanChecked(results):
				wrong = append(wrong, fmt.Sprintf("%s: PolicyReport %s/%s checked no hardening rule, it holds only the row %s (%s)",
					node, infScanNamespace, report, infScanNoProfile, t.Str("message")))
			}
			for _, r := range results {
				if got := r.Str("properties", "runName"); got != run.Name() {
					wrong = append(wrong, fmt.Sprintf("%s: a result of PolicyReport %s names the run %q, want %s", node, report, got, run.Name()))
					break
				}
			}
		}
	}
	ev[region.ID] = keys
	return wrong, nil
}

func infScanLists(t kube.Object, key string) bool {
	list, _ := t.Get("evidence").([]any)
	for _, k := range list {
		if k == key {
			return true
		}
	}
	return false
}

// infScanTime reports whether s is a time in RFC 3339 form, the form the CRD
// gives collectedAt (date-time).
func infScanTime(s string) bool {
	_, err := time.Parse(time.RFC3339, s)
	return err == nil
}

// infScanChecked reports whether a hardening report holds a result of a rule
// that was checked, not only the row no-profile-for-release. The operations
// controller writes that row, and the target still succeeds, when no rule of
// the node could be checked.
func infScanChecked(results []kube.Object) bool {
	for _, r := range results {
		if r.Str("rule") != infScanNoProfile {
			return true
		}
	}
	return false
}

			final := 0

			}
			if err := c.wait(ctx, infScanPoll); err != nil {
				return err
			}
		}
		for _, region := range cc.Regions {
			if p := phases[region.ID]; p != infScanSucceeded {
				return fmt.Errorf("[%s] MachineRun %s/%s ended %s, counts %v", region.ID, infScanNamespace, name, p, runs[region.ID].Get("status", "counts"))
			}
		}

	})

			}
			return nil
		})
	}
	if len(created) > 0 {
		checkStep(rec, infScanID, 5, "the runs the check created are deleted", func(ev Evidence) error {
			cleanup, cancel := context.WithTimeout(context.WithoutCancel(ctx), time.Minute)
			defer cancel()
			deleted, failed := []string{}, []string{}
			for _, region := range created {
				if _, err := c.kubectl(region, cleanup, nil, "delete", infScanRuns, name, "-n", infScanNamespace,
					"--wait=false", "--ignore-not-found"); err != nil {

					continue // the runs of the other regions are still deleted
				}

			}
			if len(failed) > 0 {
				return fmt.Errorf("%s; a run that is not deleted is deleted after the retention of the chart", strings.Join(failed, "; "))
			}
			return nil
		})
	}
	return nil
}
