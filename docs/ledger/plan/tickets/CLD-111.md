# CLD-111 — Wipe and janitor through capabilities

## In plain words

**The problem today.** The wipe and the background janitor of the API server reach one cloud by name: the janitor imports that cloud's adapter, asserts on its type and calls five of its sweeps one by one; the wipe guesses the provider of a deployment from the credentials it was sent and falls back to the other cloud, and both hard-code that cloud's default region. Nothing stops a sweep or a wipe from deleting a disk that is still attached to a server.

**What changes.** The janitor and the wipe call any cloud through the sweeper and prober capability interfaces, read the provider from the deployment record and leave the region to the adapter. Both adapters keep every volume that is attached to a server.

**Done means:**

- No file of the API server's handler package imports a cloud adapter except the front-door reconcile of the gateway load balancer, and none asserts on an adapter type elsewhere.
- The janitor runs the orphan sweep of every cloud that offers one, still log-only by default, still protecting every deployment that is not wiped, and its summary line keeps its keys.
- A wipe of a deployment with no provider in its record is refused with a 400 on provider; a wipe never guesses the provider and never defaults a region.
- A wipe without credentials in its body still runs when the record, the deployment's variables file or the operator's configuration holds them, and is refused with a 400 naming the missing field otherwise.
- The orphan sweep and the wipe of both cloud adapters never delete a volume that is attached to a server; a unit test of each adapter proves it.
- A failed record of the second cloud is still kept by the janitor until that cloud's adapter can list or probe its servers (CLD-181).

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The handler package of the API server reaches the cloud of a deployment only through the provider port and its capability interfaces. The janitor's project-wide orphan sweep is `providers.OrphanSweeper` of every registered provider that has one, its failed-record probe asks `providers.LivenessProber` after `ListServers`, and neither imports the Huawei adapter, asserts on its type or names a region. The wipe reads the provider from the deployment record, resolves the credentials with one order that names no provider, and passes the protected deployment prefixes to the adapter, whose `Wipe` now reclaims the detached storage-driver volumes itself (the logic of `wipe_evs_backstop.go`, which is deleted). Both adapters refuse to delete a volume that is attached to a server, in the sweep and in the wipe. The sweeps, their log-only default, their protected prefixes and their log keys are unchanged; so are the fail-closed rules of the failed-record reap.

## 3. The model (the law)
All paths below are under `products/catalyst/bootstrap/api/`.
1. `internal/providers/huawei/sweeper.go` declares that `*Provider` implements `providers.OrphanSweeper` and `providers.LivenessProber`. `SweepKinds()` is `EIPs`, `Keypairs`, `VPCs`, `EVS`, `OBSBuckets`, in that order: the janitor logs each count as `orphan<kind>Deleted` (destructive) or `orphan<kind>WouldReap` (log-only, #5545), the keys it logged before.
2. `SweepOrphans` wraps the five existing `SweepOrphan*` methods (they keep their names, so `Preflight`'s seam `sweepVPCs` does not change), each under its former janitor budget (2, 2, 5, 10 and 5 minutes), with `in.ProtectedIDs` and `in.Destructive`. A failing kind does not stop the next; the errors are joined. The region is `in.CloudRegion`, else the credentials' `region`, else the adapter's default. A nil `in.ProtectedIDs` and missing credentials are refused before any cloud call.
3. `HasLiveInfrastructure` wraps `HasServersByNamePrefix` (#5327); missing credentials are an error that reports alive.
4. `providers.WipeSpec` gains `ProtectedIDs`: the prefixes of every other deployment that may own resources. The Huawei `Wipe` ends with `reapDetachedVolumes`: the EVS sweep, destructive, with `ProtectedIDs` minus the wiped deployment's own prefix (#5028). A nil `ProtectedIDs` reaps nothing. The handler's wipe and the janitor's destroy of a failed record pass `buildActivePrefixes()`.
5. A volume attached to a server is never deleted: the EVS sweep's rule `isReclaimableOrphanEVS` (status `available` and zero attachments) is now proven for the sweep and the wipe step; the Hetzner purge (`internal/hetzner/purge.go`) reads a volume's `server` and keeps an attached volume in both of its volume passes.
6. `internal/handler/janitor.go` imports no adapter. `cleanCloudOrphans` ranges over `providers.Names()` and calls `providers.As[providers.OrphanSweeper]`; `sweepCredentials` takes the credentials of the first record of that provider (by id) whose credentials hold every field the cloud profile marks required, else the operator's configuration alone. `failedDeploymentInfraAlive` reads the provider with `provisioner.ResolveProvider` (empty: alive, error `provider unknown`), calls `ListServers`, and when that is empty `providers.As[providers.LivenessProber]`. Deleted: the import of the Huawei adapter, `huaweiProvider()`, `huaweiSweepCreds`, `discoverHuaweiCreds`, the five `cleanOrphan*Huawei` functions and the region literals.
7. `internal/handler/wipe.go`: the body is `{"credentials": {...}}`; the legacy fields of the body are read only through the adapter's `providers.LegacyAliaser` (`credentialsOf`). The Huawei adapter names no alias (#2144), so its typed fields and the `hetznerToken` overload no longer reach its credentials. The provider is `provisioner.ResolveProvider(&dep.Request)`; empty is HTTP 400 `{"error":"invalid-field","field":"provider"}`. Deleted: `resolveProviderName` and its default, the provider inference, `buildWipeCredsRaw`, `huaweiCreds`, `loadHuaweiCredsFromTfvars`, `huaweiOperatorCredsFromEnv`, the region literals and the post-destroy branch on the provider name.
8. `deploymentCredentials` fills each key, first non-blank wins: the body (map, then the adapter's legacy fields), the record (`Request.Credential`), the adapter's own variables file in the workdir (`workdirCredentials`: the adapter's `TfVars`, run on marker credentials, names the variable of each key, #5135), the operator's `CATALYST_<PROVIDER>_<KEY>` (#5193). The keys are the profile's fields, the server-only keys and every key of the body or the record. No value is defaulted.
9. `missingCredential` refuses a wipe with HTTP 400 on `credentials.<key>` when a field the profile marks required is blank, unless a legacy field was used (the rule of the credentials route, CLD-112) or no profile can be read.
10. `wipe_evs_backstop.go` is deleted and listed in `docs/ledger/deleted-paths.txt`; the handler-structure baseline is lowered by its tool.
11. `internal/handler/post_handover_gateway_elb.go` keeps the one assertion on the adapter type, moved there from `janitor.go`, until the cloud controller's `FrontDoorReconciler` replaces it (CLD-152).

+// every sweep would treat every catalyst resource as an orphan.
+func (p *Provider) SweepOrphans(ctx context.Context, in providers.SweepInput) (providers.SweepResult, error) {
+	progress := in.Progress
+	if progress == nil {
+		progress = func(string) {}
+	}
+	if in.ProtectedIDs == nil {
+		return providers.SweepResult{}, errors.New("huawei: orphan sweep refused: no protected deployment prefixes")
+	}
+	hw, err := credsFromProviderCreds(in.Creds)
+	if err != nil {
+		return providers.SweepResult{}, err
+	}
+	region := strings.TrimSpace(in.CloudRegion)
+	if region == "" {
+		region = regionFromCreds(in.Creds)
+	}
+	res := providers.SweepResult{Deleted: map[string]int{}}
+	var errs []error
+	for _, k := range sweepKinds {
+		kctx, cancel := context.WithTimeout(ctx, k.budget)
+		n, serr := k.sweep(p, kctx, hw.AccessKey, hw.SecretKey, hw.ProjectID, region, in.ProtectedIDs, in.Destructive, progress)
+		cancel()
+		res.Deleted[k.name] = n
+		if serr != nil {
+			errs = append(errs, fmt.Errorf("%s: %w", k.name, serr))
+		}
+	}
+	return res, errors.Join(errs...)

+// effort: an error is reported, never returned.
+func (p *Provider) reapDetachedVolumes(ctx context.Context, spec providers.WipeSpec, hw hwCreds, region string, progress func(msg string)) int {
+	if spec.ProtectedIDs == nil {
+		return 0

+	}
