# AIP-225 — MCP endpoint and console HTTP routes inside the service

## In plain words

**The problem today.** The operations-records service keeps signals, incidents and judgements, and can judge them, but nothing can read them. An agent has no tool to look at an incident or add a note, the console has no route to list incidents or act on one, and the program never starts the judge or the rule path.

**What changes.** The service gains a tool endpoint for agents and console routes for people, both confined to the caller's Organization. Its program serves both, recovers judgements a stopped run left open, and decides new signals with the correlator judge, or by the rules when no correlator is configured.

**Done means:**

- An agent token of one Organization reads and notes only that Organization's incidents; an incident of another Organization answers not found, exactly as one that does not exist.
- Every tool answer is cleaned by the guard library and has at most 24,000 characters; a long list keeps its first and its newest entries and says how many it dropped.
- Every console route filters by the Organization catalyst-api forwards, and an agent token gets 403 on every console route, the actions route included, before anything is read or written.
- A person above viewer can acknowledge, re-rate, merge, detach and resolve an incident; each action is written with its timeline entry in one transaction, and the stream sends it to that Organization only.
- The program reads the database to decide new signals only when a batch is due or a change wakes it, never on a fixed interval, and stops cleanly with a stream open.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The Go module `products/ops-records` gains the tool endpoint (`internal/mcp`) and the console routes (`internal/api`), and its program `cmd/ops-records` serves them and decides new signals. ## 3. The model (the law)
1. **Paths.** The change adds twelve files and edits three, each the block of the same name in this ticket: new `cmd/ops-records/decide.go` and `decide_test.go`; new `internal/api/api.go`, `actions.go`, `stream.go`, `views.go`, `api_test.go`; new `internal/mcp/server.go`, `tools.go`, `verify.go`, `mcp_test.go` and `internal/mcp/mcptest/mcptest.go`; and the patch `AIP-225.patch` to `cmd/ops-records/main.go`, `cmd/ops-records/main_test.go` and `products/ops-records/README.md`. `go.mod` and `go.sum` do not change: the token check uses the Go standard library only.
2. **Tool endpoint** (`internal/mcp`, rules at the top of `server.go`). MCP streamable HTTP, `POST /mcp`, one JSON-RPC 2.0 message per request, stateless; a notification gets 202 and no body; the methods are `initialize`, `ping`, `tools/list` and `tools/call`. Every request carries `Authorization: Bearer <agent token>`; without one, or with one the verifier refuses, the answer is HTTP 401. There is no fallback bearer and no credential of the service's own.
3. **Agent token check** (`verify.go`). RS256 only; the header `kid` names a key of catalyst-api's key set `GET /api/v1/auth/signers.jwks`, and a key is kept only when its `kid` is the RFC 7638 thumbprint of the key itself (the way `handoverjwt.Signer.KeyID` writes it); `typ` is `agent`; `aud` (one string or a list) contains `platform-tools`; `iss` equals `OPS_RECORDS_TOKEN_ISSUER`; `exp` is present and in the future; `nbf`, when present, is past; `org_id` is a slug; `agent` matches `^[a-z][a-z0-9-]{1,62}$`; `tier` is on the ladder and is capped at `developer`. The key set is read on demand, never on a timer: when a token names a key the set does not hold, or when the set is older than five minutes (the route's `max-age`), and never twice within 30 seconds; while the route fails, the last set read stays in use.
4. **Organization of a tool.** The Organization is the token's `org_id`. Every tool reads and writes that Organization only; a record of another Organization answers "not found", the same text as one that does not exist. Every tool needs tier viewer.
5. **The one writing tool.** `add_incident_note` (`incidentId`, `text` of 1 to 2,000 characters) appends one timeline entry `note` with actor kind `agent` and the token's agent as actor, the text redacted by `agentguard.Redact`. It changes no desired state and nothing outside the service's database.
6. **Answers.** Every answer is JSON in one text part, after `agentguard.CleanValue` with no link host allowed, and has at most `agentguard.MaxAnswer` (24,000) characters: a list under `items`, `events` or `signals` that is too long keeps its first and its newest entries (`agentguard.FitList`) and gets `dropped` with the number left out; anything still too long is cut by `agentguard.Fit`.
7. **Console routes** (`internal/api`, rules at the top of `api.go`): `GET /api/v1/ops/incidents?state=&limit=`, `GET /api/v1/ops/incidents/{id}` (with `events` and `signals`), `POST /api/v1/ops/incidents/{id}/actions`, `GET /api/v1/ops/judgements?judge=&outcome=&limit=` (`outcome=undecided` selects the undecided ones), `GET /api/v1/ops/stream` (server-sent events). They listen on their own address, `OPS_RECORDS_CONSOLE_LISTEN` (default `:8081`), so that the chart (AIP-226) can open that port to catalyst-api pods only: the routes trust the headers `x-openova-organization`, `x-openova-user` and `x-openova-tier`.
8. **Console identity.** A bearer that is an agent token (claim `typ` `agent`, read without verifying: the answer only ever refuses) gets 403 `agent_token_forbidden` on every console route, before anything is read or written. A request without `x-openova-user`, or with a tier off the ladder (`viewer`, `developer`, `operator`, `admin`, `owner`, `sovereign-admin`), gets 401 `missing_identity`. An empty Organization, the view of every Organization, is accepted only with the tier `sovereign-admin`. Every read and write is filtered by a non-empty Organization; another Organization's record answers 404 `not_found`.
9. **Actions.** A viewer only reads: an action needs a tier above viewer (403 `tier_too_low`). Each action is written in one transaction with its timeline entry, actor kind `person`, actor the `x-openova-user` e-mail; an action on a resolved incident or on one merged into another gets 409 `invalid_state`. `acknowledge` writes `acknowledged`. `set_severity` (1 to 4) sets the severity as set by a person, writes `severity` and feedback `severity`. `detach` (`signalId`) takes the signal out of the incident, so that it is pending again and decided anew, writes `signals_detached` and feedback `detach`. `merge` (`otherIncidentId`, followed to the incident it was merged into) moves every signal to the target, sets the parent, writes `merged` and `signals_attached` and feedback `merge`, and makes the target as urgent as the merged incident unless a person set the target's severity. `resolve` sets the state and the resolution time and writes `resolved`. The answer is the incident as `GET` answers it.
10. **Stream.** Every action, every note, every rule decision and every judge outcome is one change `{"organization", "incidentId" or "judgementId", "kind"}`, sent as the event `incident` to the streams of that Organization and to the streams of every Organization. A stream that falls 64 changes behind is ended; the console connects again. The stream lives in one process: the service runs one replica, as its dispatcher requires.
11. **Program** (`cmd/ops-records/main.go`). `serve` needs `OPS_RECORDS_CATALYST_API_URL`, `OPS_RECORDS_TOKEN_ISSUER` and `OPS_RECORDS_JUDGE_POLICY` (a file read by `judge.ParsePolicy`); a missing or invalid one is exit code 2 before the database is opened. `migrate` and `version` need none of them. `serve` runs `judge.Recover`, then serves the health routes and `POST /mcp` on `OPS_RECORDS_LISTEN` and the console routes on `OPS_RECORDS_CONSOLE_LISTEN`, and on stop ends the streams (`Hub.Close` on shutdown) so that shutdown is not held by a stream that is never idle.
12. **Deciding** (`cmd/ops-records/decide.go`). With a judge named `correlator` in the policy, `judge.CorrelationTicker` asks it (the dispatcher writes the rule result when the agent is invalid, unavailable or late); otherwise `correlate.Engine` decides by the rules alone. After each round the decider computes when the earliest pending batch without a question in flight is due (its last decision is the answer time of its newest judgement, else its ask time) and waits for that time, for a wake, or for the stop. With no pending signal it waits for a wake alone: it never reads the store on a fixed interval, and adds no `time.NewTicker`, `time.Tick` or `time.Sleep`. A person's action and every judge outcome wake it. A batch still due after a round is tried again after the urgent wait, never at once.
13. **Every example value is a test value.** The Organization slugs `acme`, `globex` and `operations`, the hosts `kagent-controller.acme.svc.cluster.local`, `auth.sovereign.test`, `evil.example` and `127.0.0.1`, the e-mail addresses under `.test`, the strings `agent-jwt`, `token=abcdef0123456789abcdef` and `password=hunter2hunter2`, and the RSA keys made by `mcptest.NewSigner` at test time are fixed test values, not systems and not secrets.

// Package mcp serves the tool endpoint of the operations-records service.
//
// Transport: MCP streamable HTTP, POST /mcp, one JSON-RPC 2.0 message per request, stateless.
// A notification (a message without id) is answered 202 with no body. Methods: initialize,
// ping, tools/list and tools/call.
//
// The rules:
//
//   - Caller. Every request carries "Authorization: Bearer <agent token>", accepted by
//     Verifier: signed by a key of catalyst-api's key set, aud containing platform-tools.
//     Without one the answer is HTTP 401. There is no fallback bearer and no credential of
//     the service's own.
//   - Organization. The Organization is the token's claim org_id. Every tool reads and writes
//     that Organization only: a record of another Organization is "not found", exactly as one
//     that does not exist.
//   - Tiers. tools/list shows the tools of the token's tier, and tools/call checks it again.
//     Every tool here needs tier viewer.
//   - Writes. add_incident_note is the one tool that writes: one timeline entry "note" on an
//     incident, by the actor kind agent named by the token. It is a record tool: it changes no
//     desired state and nothing outside this service's database.
//   - Answers. Every answer is JSON in one text part. It passes agentguard.CleanValue with no
//     link host allowed (links removed, secrets redacted, outside text made inert) and has at
//     most agentguard.MaxAnswer characters: a longer list keeps its first and its newest
//     entries and says in "dropped" how many it left out.
package mcp

import (
	"bytes"
	"context"
	"encoding/json"
	"io"
	"net/http"
	"strings"
	"time"
	"unicode/utf8"

	"github.com/openova-io/openova/products/ops-records/internal/agentguard"
	"github.com/openova-io/openova/products/ops-records/internal/api"

// ProtocolVersions are the MCP versions the server speaks, newest first.
var ProtocolVersions = []string{"2025-06-18", "2025-03-26", "2024-11-05"}

// maxBody is the largest request body.
const maxBody = 1 << 20

// JSON-RPC error codes.
const (
	codeParse          = -32700
	codeInvalidRequest = -32600
	codeNoMethod       = -32601
	codeInvalidParams  = -32602
	codeUnauthorized   = -32001
)

// Server is the tool endpoint.
type Server struct {
	Store   store.Store
	Verify  func(ctx context.Context, bearer string) (Identity, error)
	Version string
	Now     func() time.Time // nil means time.Now
	Hub     *api.Hub         // receives a change after every note; nil sends none
}

type rpcRequest struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      json.RawMessage `json:"id"`
	Method  string          `json:"method"`
	Params  json.RawMessage `json:"params"`
}

type rpcError struct {
	Code    int    `json:"code"`
	Message string `json:"message"`
}

func reply(w http.ResponseWriter, status int, id json.RawMessage, result any, e *rpcError) {
	if len(id) == 0 {
		id = json.RawMessage("null")
	}
	body := map[string]any{"jsonrpc": "2.0", "id": id}
	if e != nil {
		body["error"] = e
	} else {
		body["result"] = result
	}
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(body)
}

// ServeHTTP answers POST /mcp.
func (s *Server) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	if r.Method != http.MethodPost {
		w.Header().Set("Allow", http.MethodPost)
		http.Error(w, "POST one JSON-RPC message", http.StatusMethodNotAllowed)
		return
	}
	bearer := strings.TrimSpace(r.Header.Get("Authorization"))
	if len(bearer) > 7 && strings.EqualFold(bearer[:7], "bearer ") {
		bearer = strings.TrimSpace(bearer[7:])
	} else {
		bearer = ""
	}
	if bearer == "" {
		w.Header().Set("WWW-Authenticate", "Bearer")
		reply(w, http.StatusUnauthorized, nil, nil, &rpcError{codeUnauthorized, "an agent token is required"})
		return
	}
	who, err := s.Verify(r.Context(), bearer)
	if err != nil {
		w.Header().Set("WWW-Authenticate", `Bearer error="invalid_token"`)
		reply(w, http.StatusUnauthorized, nil, nil, &rpcError{codeUnauthorized, "agent token refused: " + err.Error()})
		return
	}
	body, err := io.ReadAll(io.LimitReader(r.Body, maxBody+1))
	if err != nil || len(body) > maxBody {
		reply(w, http.StatusRequestEntityTooLarge, nil, nil, &rpcError{codeInvalidRequest, "the body is too large"})
		return
	}
	var req rpcRequest
	if t := bytes.TrimSpace(body); len(t) > 0 && t[0] == '[' {
		reply(w, http.StatusOK, nil, nil, &rpcError{codeInvalidRequest, "one message per request; batches are not served"})
		return
	}
	if err := json.Unmarshal(body, &req); err != nil {
		reply(w, http.StatusOK, nil, nil, &rpcError{codeParse, "the body is not JSON-RPC: " + err.Error()})
		return
	}
	if req.JSONRPC != "2.0" || req.Method == "" {
		reply(w, http.StatusOK, req.ID, nil, &rpcError{codeInvalidRequest, "jsonrpc must be 2.0 and method is required"})
		return
	}
	if len(req.ID) == 0 || string(req.ID) == "null" {
		w.WriteHeader(http.StatusAccepted)
		return
	}
	result, e := s.dispatch(r.Context(), who, req)
	reply(w, http.StatusOK, req.ID, result, e)
}

func (s *Server) dispatch(ctx context.Context, who Identity, req rpcRequest) (any, *rpcError) {
	switch req.Method {
	case "initialize":
		var p struct {
			ProtocolVersion string `json:"protocolVersion"`
		}
		_ = json.Unmarshal(req.Params, &p)
		version := ProtocolVersions[0]
		for _, v := range ProtocolVersions {
			if v == p.ProtocolVersion {
				version = v
			}
		}
		return map[string]any{"protocolVersion": version, "capabilities": map[string]any{"tools": map[string]any{"listChanged": false}},
			"serverInfo": map[string]any{"name": "ops-records", "version": s.Version}}, nil
	case "ping":
		return map[string]any{}, nil
	case "tools/list":
		list := []map[string]any{}
		for _, t := range tools {
			if allowed(who.Tier, t.minTier) {
				list = append(list, map[string]any{"name": t.name, "description": t.description, "inputSchema": json.RawMessage(t.schema)})
			}
		}
		return map[string]any{"tools": list}, nil
	case "tools/call":
		var p struct {
			Name      string          `json:"name"`
			Arguments json.RawMessage `json:"arguments"`
		}
		if err := json.Unmarshal(req.Params, &p); err != nil {
			return nil, &rpcError{codeInvalidParams, "params must hold name and arguments"}
		}
		for _, t := range tools {
			if t.name == p.Name && allowed(who.Tier, t.minTier) {
				return s.call(ctx, who, t, p.Arguments), nil
			}
		}
		return nil, &rpcError{codeInvalidParams, "unknown tool " + p.Name}
	}
	return nil, &rpcError{codeNoMethod, "unknown method " + req.Method}
}

func allowed(tier, minTier string) bool {
	return minTier == TierViewer || tier == minTier
}

// call runs one tool and returns its MCP result.
func (s *Server) call(ctx context.Context, who Identity, t tool, args json.RawMessage) map[string]any {
	if len(bytes.TrimSpace(args)) == 0 || string(bytes.TrimSpace(args)) == "null" {
		args = json.RawMessage("{}")
	}
	v, err := t.run(ctx, s, who, args)
	if err != nil {
		return map[string]any{"content": []map[string]any{{"type": "text", "text": err.Error()}}, "isError": true}
	}
	text, err := Render(v)
	if err != nil {
		return map[string]any{"content": []map[string]any{{"type": "text", "text": "the answer cannot be written"}}, "isError": true}
	}
	return map[string]any{"content": []map[string]any{{"type": "text", "text": text}}}
}

// listKeys are the fields whose list Render shortens, in this order, when an answer is too long.

// Render returns v as JSON after agentguard.CleanValue with no link host allowed, in at most
// agentguard.MaxAnswer characters. A list under one of listKeys keeps its first and its newest
// entries, and "dropped" says how many were left out; any other answer that is still too long
// is cut by agentguard.Fit.
func Render(v any) (string, error) {
	raw, err := marshal(v)
	if err != nil {
		return "", err
	}
	var generic any
	if err := json.Unmarshal(raw, &generic); err != nil {
		return "", err
	}
	generic = agentguard.CleanValue(generic, nil)
	out, err := marshal(generic)
	if err != nil || utf8.RuneCount(out) <= agentguard.MaxAnswer {
		return string(out), err
	}
	if m, ok := generic.(map[string]any); ok {
		for _, key := range listKeys {
			list, ok := m[key].([]any)
			if !ok || len(list) == 0 {
				continue
			}
			sizes := make([]int, len(list))
			total := 0
			for i, e := range list {
				b, err := marshal(e)
				if err != nil {
					return "", err
				}
				sizes[i] = utf8.RuneCount(b) + 1
				total += sizes[i]
			}
			// The room for the list: what the rest of the answer leaves, less the field dropped.
			room := agentguard.MaxAnswer - (utf8.RuneCount(out) - total) - len(`,"dropped":1000000`)
			keep, dropped := agentguard.FitList(sizes, room)
			kept := make([]any, 0, len(keep))
			for _, i := range keep {
				kept = append(kept, list[i])
			}
			m[key], m["dropped"] = kept, dropped
			if out, err = marshal(m); err != nil || utf8.RuneCount(out) <= agentguard.MaxAnswer {
				return string(out), err
			}
		}
	}
	return agentguard.Fit(string(out), agentguard.MaxAnswer), nil
}

func marshal(v any) ([]byte, error) {
	var b bytes.Buffer
	enc := json.NewEncoder(&b)
	enc.SetEscapeHTML(false)
	if err := enc.Encode(v); err != nil {
		return nil, err
	}
	return bytes.TrimRight(b.Bytes(), "\n"), nil
}

import (

// KeySetPath is the route of catalyst-api that publishes the public keys of its signers.
const KeySetPath = "/api/v1/auth/signers.jwks"

// Audience is the audience every platform tool server requires of an agent token.
const Audience = "platform-tools"

// Key set timing: a key set is read again when it is older than KeySetMaxAge, the route's
// cache life, or when a token names a key it does not hold; never twice within KeySetFloor.
const (
	KeySetMaxAge = 5 * time.Minute
	KeySetFloor  = 30 * time.Second
)

// Tier ranks. An agent token's tier is capped at developer.
const (
	TierViewer    = "viewer"
	TierDeveloper = "developer"
)

var (
	agentPattern = regexp.MustCompile(`^[a-z][a-z0-9-]{1,62}$`)
	slugPattern  = regexp.MustCompile(`^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?$`)
	higherTiers  = []string{"operator", "admin", "owner", "org-admin", "sovereign-admin"}
)

// Identity is the verified caller of a tool.
type Identity struct {
	Organization string // claim org_id
	Agent        string // claim agent
	Tier         string // TierViewer or TierDeveloper
}

// KeySet reads the public keys of catalyst-api's signers from URL, on demand: there is no
// timer. A key is kept only when its kid is the RFC 7638 thumbprint of the key itself.
type KeySet struct {
	URL    string           // catalyst-api's base address and KeySetPath
	Client *http.Client     // nil means a client with a 5 second time limit
	Now    func() time.Time // nil means time.Now

	mu    sync.Mutex
	keys  map[string]*rsa.PublicKey
	read  time.Time // when keys were read
	tried time.Time // when the route was last asked
}

// Key returns the key named kid.
func (k *KeySet) Key(ctx context.Context, kid string) (*rsa.PublicKey, error) {
	k.mu.Lock()
	defer k.mu.Unlock()
	now := time.Now()
	if k.Now != nil {
		now = k.Now()
	}
	key, held := k.keys[kid]
	if held && now.Sub(k.read) < KeySetMaxAge {
		return key, nil
	}
	if !k.tried.IsZero() && now.Sub(k.tried) < KeySetFloor {
		if held {
			return key, nil
		}
		return nil, fmt.Errorf("mcp: the key %q is not in the key set", kid)
	}
	k.tried = now
	keys, err := k.fetch(ctx)
	if err != nil {
		if held {
			return key, nil // the last key set read stays in use while the route fails
		}
		return nil, err
	}
	k.keys, k.read = keys, now
	if key, held = keys[kid]; !held {
		return nil, fmt.Errorf("mcp: the key %q is not in the key set", kid)
	}
	return key, nil
}

func (k *KeySet) fetch(ctx context.Context) (map[string]*rsa.PublicKey, error) {
	client := k.Client
	if client == nil {
		client = &http.Client{Timeout: 5 * time.Second}
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, k.URL, nil)
	if err != nil {
		return nil, fmt.Errorf("mcp: key set: %w", err)
	}
	resp, err := client.Do(req)
	if err != nil {
		return nil, fmt.Errorf("mcp: key set: %w", err)
	}
	defer func() { _ = resp.Body.Close() }()
	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("mcp: key set: HTTP %d", resp.StatusCode)
	}
	var set struct {
		Keys []struct {
			Kty string `json:"kty"`
			Alg string `json:"alg"`
			Kid string `json:"kid"`
			N   string `json:"n"`
			E   string `json:"e"`
		} `json:"keys"`
	}
	if err := json.NewDecoder(io.LimitReader(resp.Body, 1<<20)).Decode(&set); err != nil {
		return nil, fmt.Errorf("mcp: key set: %w", err)
	}
	keys := map[string]*rsa.PublicKey{}
	for _, j := range set.Keys {
		n, errN := base64.RawURLEncoding.DecodeString(j.N)
		e, errE := base64.RawURLEncoding.DecodeString(j.E)
		if j.Kty != "RSA" || (j.Alg != "" && j.Alg != "RS256") || errN != nil || errE != nil || len(e) == 0 || len(e) > 4 {
			continue
		}
		key := &rsa.PublicKey{N: new(big.Int).SetBytes(n), E: int(new(big.Int).SetBytes(e).Int64())}
		if key.N.BitLen() >= 2048 && j.Kid == KeyID(key) {
			keys[j.Kid] = key
		}
	}
	return keys, nil
}

// KeyID returns the RFC 7638 thumbprint of key: SHA-256 of {"e":..,"kty":"RSA","n":..},
// base64url without padding. catalyst-api writes it as the kid of an agent token.
func KeyID(key *rsa.PublicKey) string {
	n := base64.RawURLEncoding.EncodeToString(key.N.Bytes())
	e := base64.RawURLEncoding.EncodeToString(big.NewInt(int64(key.E)).Bytes())
	sum := sha256.Sum256([]byte(`{"e":"` + e + `","kty":"RSA","n":"` + n + `"}`))
	return base64.RawURLEncoding.EncodeToString(sum[:])
}

// Verifier accepts agent tokens: RS256, signed by a key of the key set named by the token's
// kid, typ "agent", aud containing Audience, iss equal to Issuer, not expired, with an
// Organization, an agent name and a tier.
type Verifier struct {
	Keys   *KeySet
	Issuer string
	Now    func() time.Time // nil means time.Now
}

// audience reads aud as one string or a list of strings.
type audience []string

func (a *audience) UnmarshalJSON(b []byte) error {
	var one string
	if json.Unmarshal(b, &one) == nil {
		*a = audience{one}
		return nil
	}
	var list []string
	if err := json.Unmarshal(b, &list); err != nil {
		return err
	}
	*a = list
	return nil
}

type claims struct {
	Iss   string   `json:"iss"`
	Aud   audience `json:"aud"`
	Typ   string   `json:"typ"`
	OrgID string   `json:"org_id"`
	Agent string   `json:"agent"`
	Tier  string   `json:"tier"`
	Exp   *float64 `json:"exp"`
	Nbf   *float64 `json:"nbf"`
}

// Verify returns the identity of an agent token, or why it is refused.
func (v *Verifier) Verify(ctx context.Context, bearer string) (Identity, error) {
	parts := strings.Split(bearer, ".")
	if len(parts) != 3 {
		return Identity{}, errors.New("the bearer is not a JWT")
	}
	var header struct {
		Alg string `json:"alg"`
		Kid string `json:"kid"`
	}
	if err := decodePart(parts[0], &header); err != nil || header.Alg != "RS256" || header.Kid == "" {
		return Identity{}, errors.New("the token is not RS256 with a kid")
	}
	key, err := v.Keys.Key(ctx, header.Kid)
	if err != nil {
		return Identity{}, err
	}
	sig, err := base64.RawURLEncoding.DecodeString(parts[2])
	if err != nil {
		return Identity{}, errors.New("the signature is not base64url")
	}
	sum := sha256.Sum256([]byte(parts[0] + "." + parts[1]))
	if rsa.VerifyPKCS1v15(key, crypto.SHA256, sum[:], sig) != nil {
		return Identity{}, errors.New("the signature does not verify")
	}
	var c claims
	if err := decodePart(parts[1], &c); err != nil {
		return Identity{}, errors.New("the claims cannot be read")
	}
	now := time.Now()
	if v.Now != nil {
		now = v.Now()
	}
	switch {
	case !strings.EqualFold(strings.TrimSpace(c.Typ), "agent"):
		return Identity{}, errors.New("the token is not an agent token")
	case !slices.Contains(c.Aud, Audience):
		return Identity{}, fmt.Errorf("aud does not contain %q", Audience)
	case v.Issuer == "" || c.Iss != v.Issuer:
		return Identity{}, fmt.Errorf("the issuer %q is not trusted", c.Iss)
	case c.Exp == nil || float64(now.Unix()) >= *c.Exp:
		return Identity{}, errors.New("the token has expired or has no exp")
	case c.Nbf != nil && float64(now.Unix()) < *c.Nbf:
		return Identity{}, errors.New("the token is not valid yet")
	case !slugPattern.MatchString(c.OrgID):
		return Identity{}, errors.New("the token names no Organization")
	case !agentPattern.MatchString(c.Agent):
		return Identity{}, errors.New("the token names no agent")
	}
	tier := strings.TrimPrefix(strings.ToLower(strings.TrimSpace(c.Tier)), "catalyst-")
	switch {
	case tier == TierViewer || tier == TierDeveloper:
	case slices.Contains(higherTiers, tier):
		tier = TierDeveloper
	default:
		return Identity{}, fmt.Errorf("the tier %q is not on the ladder", c.Tier)
	}
	return Identity{Organization: c.OrgID, Agent: c.Agent, Tier: tier}, nil
}

func decodePart(part string, v any) error {
	raw, err := base64.RawURLEncoding.DecodeString(part)
	if err != nil {
		return err
	}
	return json.Unmarshal(raw, v)
}

		}

	}

	if err != nil {

// Package api serves the console routes of the operations-records service.
//
// The browser never calls this service. catalyst-api verifies the session and forwards the
// request with three headers it sets itself, after removing any the caller sent:
//
//	x-openova-organization  the session's Organization; empty for a sovereign-admin
//	x-openova-user          the session's e-mail
//	x-openova-tier          the session's tier: one of Tiers
//
// The routes listen on an address of their own, which the chart opens to catalyst-api pods
// only. The rules:
//
//   - Agents. A request whose bearer is an agent token (claim typ "agent") is refused with
//     403 agent_token_forbidden on every route, before anything is read or written.
//   - Identity. A request without x-openova-user, or with a tier that is not one of Tiers, is
//     refused with 401 missing_identity. An empty Organization, the view of every
//     Organization, is accepted only with the tier sovereign-admin.
//   - Organization. Every read and every write is filtered by the Organization header when it
//     is not empty: a record of another Organization is answered 404 not_found, exactly as one
//     that does not exist.
//   - Actions. A viewer only reads: an action needs a tier above viewer (403 tier_too_low).
//     An action, its timeline entry and its feedback row (merge, detach, set_severity) are
//     written in one transaction, by the actor kind person named by x-openova-user. An action
//     on a resolved incident, or on one merged into another, is refused with 409
//     invalid_state.
//
// Routes:
//
//	GET  /api/v1/ops/incidents?state=&limit=             {"items": [incident]}, newest first
//	GET  /api/v1/ops/incidents/{id}                      incident with "events" and "signals"
//	POST /api/v1/ops/incidents/{id}/actions              the incident as GET answers it, after the action
//	GET  /api/v1/ops/judgements?judge=&outcome=&limit=   {"items": [judgement]}, newest first
//	GET  /api/v1/ops/stream                              server-sent events, one per incident change
//

// IsAgentToken reports whether an Authorization header carries a JWT whose claim typ is
// "agent". The signature is not checked: the answer only ever refuses.
func IsAgentToken(authorization string) bool {
	raw := strings.TrimSpace(authorization)
	if len(raw) > 7 && strings.EqualFold(raw[:7], "bearer ") {
		raw = strings.TrimSpace(raw[7:])
	}
	parts := strings.Split(raw, ".")
	if len(parts) != 3 {
		return false
	}
	payload, err := base64.RawURLEncoding.DecodeString(strings.TrimRight(parts[1], "="))
	if err != nil {
		return false
	}
	var claims struct {
		Typ string `json:"typ"`
	}
	return json.Unmarshal(payload, &claims) == nil && strings.EqualFold(strings.TrimSpace(claims.Typ), "agent")
}

func (s *Server) guard(acts bool, h func(http.ResponseWriter, *http.Request, caller)) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		if IsAgentToken(r.Header.Get("Authorization")) {
			fail(w, http.StatusForbidden, "agent_token_forbidden", "an agent token cannot use the console routes")
			return
		}
		c := caller{org: strings.TrimSpace(r.Header.Get(HeaderOrganization)),
			user: strings.TrimSpace(r.Header.Get(HeaderUser)), tier: strings.TrimSpace(r.Header.Get(HeaderTier)), rank: -1}
		for i, t := range Tiers {
			if c.tier == t {
				c.rank = i
			}
		}
		switch {
		case c.user == "" || c.rank < 0:
			fail(w, http.StatusUnauthorized, "missing_identity", "the headers "+HeaderUser+" and "+HeaderTier+" are required")
		case c.org == "" && c.tier != TierSovereignAdmin:
			fail(w, http.StatusUnauthorized, "missing_identity", "only a sovereign-admin reads every Organization")
		case acts && c.rank == 0:
			fail(w, http.StatusForbidden, "tier_too_low", "a viewer cannot act on an incident")
		default:
			h(w, r, c)
		}
	}
}

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"net/http"

// The actions of POST /api/v1/ops/incidents/{id}/actions.
const (
	// ActionAcknowledge writes the timeline entry "acknowledged". The state does not change.
	ActionAcknowledge = "acknowledge"
	// ActionSetSeverity sets the severity (field severity, 1..4) as set by a person, which rules
	// and agents never change again. Timeline "severity", feedback "severity".
	ActionSetSeverity = "set_severity"
	// ActionMerge merges the incident into the incident otherIncidentId, followed to the one it
	// was merged into: the signals move there, the incident's parent is set, and the target
	// becomes as urgent as the incident unless a person set its severity. Timeline "merged" on
	// the incident and "signals_attached" on the target, feedback "merge".
	ActionMerge = "merge"
	// ActionDetach takes the signal signalId out of the incident; the signal is pending again
	// and is decided anew. Timeline "signals_detached", feedback "detach".
	ActionDetach = "detach"
	// ActionResolve resolves the incident. Timeline "resolved".
	ActionResolve = "resolve"
)

// Timeline entries the actions write that no other package writes.
const (
	EventAcknowledged = "acknowledged"
	EventResolved     = "resolved"
	EventMerged       = "merged"
	EventAttached     = "signals_attached"
	EventDetached     = "signals_detached"
	EventSeverity     = "severity"
)

// maxHops is how far an action follows merged incidents to the one they were merged into.
const maxHops = 10

// maxActionBody is the largest request body of the actions route.
const maxActionBody = 16 << 10

// ActionRequest is the body of the actions route. Unknown fields are refused.
type ActionRequest struct {
	Action          string `json:"action"`
	Severity        int    `json:"severity,omitempty"`
	OtherIncidentID string `json:"otherIncidentId,omitempty"`
	SignalID        string `json:"signalId,omitempty"`
}

// conflict is an action the state of the records does not allow.
type conflict string

func (c conflict) Error() string { return string(c) }

func (s *Server) act(w http.ResponseWriter, r *http.Request, c caller) {
	var req ActionRequest
	dec := json.NewDecoder(http.MaxBytesReader(w, r.Body, maxActionBody))
	dec.DisallowUnknownFields()
	if err := dec.Decode(&req); err != nil {
		fail(w, http.StatusBadRequest, "invalid_request", "the body is not an action: "+err.Error())
		return
	}
	if msg := checkRequest(req); msg != "" {
		fail(w, http.StatusBadRequest, "invalid_request", msg)
		return
	}
	var touched []store.Incident
	err := s.Store.InTx(r.Context(), func(ctx context.Context, tx store.Tx) error {
		var err error
		touched, err = s.apply(ctx, tx, c, r.PathValue("id"), req)
		return err
	})
	var cf conflict
	switch {
	case errors.As(err, &cf):
		fail(w, http.StatusConflict, "invalid_state", cf.Error())
		return
	case err != nil:
		s.storeFailed(w, err)
		return
	}
	for _, in := range touched {
		if s.Hub != nil {
			s.Hub.Publish(Change{Organization: in.Organization, IncidentID: in.ID, Kind: req.Action})
		}
	}
	if s.Wake != nil {
		s.Wake()
	}
	d, err := ReadDetail(r.Context(), s.Store, c.org, touched[0].ID)
	if err != nil {
		s.storeFailed(w, err)
		return
	}
	write(w, http.StatusOK, d)
}

// checkRequest returns why a request is not an action, or "".
func checkRequest(req ActionRequest) string {
	switch req.Action {
	case ActionAcknowledge, ActionResolve:
	case ActionSetSeverity:
		if req.Severity < store.SeverityHighest || req.Severity > store.SeverityLowest {
			return "set_severity needs a severity from 1 to 4"
		}
	case ActionMerge:
		if !ids.ValidIncident(req.OtherIncidentID) {
			return "merge needs otherIncidentId, an incident identifier"
		}
	case ActionDetach:
		if !ids.Valid(req.SignalID) {
			return "detach needs signalId, a signal identifier"
		}
	default:
		return fmt.Sprintf("action %q is not one of acknowledge, set_severity, merge, detach, resolve", req.Action)
	}
	return ""
}

// apply writes one action in tx and returns the incidents it changed, the acted-on one first.
func (s *Server) apply(ctx context.Context, tx store.Tx, c caller, id string, req ActionRequest) ([]store.Incident, error) {
	in, err := tx.GetIncident(ctx, c.org, id)
	if err != nil {
		return nil, err
	}
	switch {
	case in.ParentID != "":
		return nil, conflict("the incident was merged into " + in.ParentID + "; act on that one")
	case in.State == store.IncidentResolved:
		return nil, conflict("the incident is resolved")
	}
	now := s.now()
	ev := func(target store.Incident, kind string, data map[string]any) error {
		raw, err := json.Marshal(data)
		if err != nil {
			return err
		}
		_, err = tx.AppendIncidentEvent(ctx, store.IncidentEvent{Organization: target.Organization, IncidentID: target.ID,
			At: now, ActorKind: store.ByPerson, Actor: c.user, Kind: kind, Data: raw})
		return err
	}
	feedback := func(kind string, data map[string]any) error {
		raw, err := json.Marshal(data)
		if err != nil {
			return err
		}
		_, err = tx.AddFeedback(ctx, store.Feedback{Organization: in.Organization, IncidentID: in.ID, Person: c.user,
			Kind: kind, Data: raw, At: now})
		return err
	}
	touched := []store.Incident{in}
	switch req.Action {
	case ActionAcknowledge:
		err = ev(in, EventAcknowledged, map[string]any{})
	case ActionResolve:
		in.State, in.ResolvedAt = store.IncidentResolved, &now
		if err = tx.UpdateIncident(ctx, in); err == nil {
			err = ev(in, EventResolved, map[string]any{})
		}
	case ActionSetSeverity:
		from := in.Severity
		in.Severity, in.SeveritySetBy = req.Severity, store.ByPerson
		if err = tx.UpdateIncident(ctx, in); err == nil {
			if err = ev(in, EventSeverity, map[string]any{"from": from, "to": req.Severity}); err == nil {
				err = feedback(store.FeedbackSeverity, map[string]any{"from": from, "to": req.Severity})
			}
		}
	case ActionDetach:
		var sg store.Signal
		if sg, err = tx.GetSignal(ctx, in.Organization, req.SignalID); err != nil {
			return nil, err
		}
		if sg.IncidentID != in.ID {
			return nil, conflict("the signal " + sg.ID + " does not belong to the incident")
		}
		sg.IncidentID = ""
		if err = tx.UpdateSignal(ctx, sg); err == nil {
			if err = ev(in, EventDetached, map[string]any{"signals": []string{sg.ID}}); err == nil {
				err = feedback(store.FeedbackDetach, map[string]any{"signalId": sg.ID})
			}
		}
	case ActionMerge:
		var into store.Incident
		if into, err = merge(ctx, tx, in, req.OtherIncidentID, ev); err == nil {
			touched = append(touched, into)
			err = feedback(store.FeedbackMerge, map[string]any{"into": into.ID})
		}
	}
	return touched, err
}

// merge merges in into the incident other, followed to the one it was merged into, and
// returns that incident as it is after the merge.
func merge(ctx context.Context, tx store.Tx, in store.Incident, other string,
	ev func(store.Incident, string, map[string]any) error) (store.Incident, error) {
	into, err := tx.GetIncident(ctx, in.Organization, other)
	for i := 0; err == nil && into.ParentID != ""; i++ {
		if i == maxHops {
			return into, conflict(fmt.Sprintf("the incident %s is merged more than %d times deep", other, maxHops))
		}
		into, err = tx.GetIncident(ctx, in.Organization, into.ParentID)
	}
	switch {
	case err != nil:
		return into, err
	case into.ID == in.ID:
		return into, conflict("an incident cannot be merged into itself")
	case into.State == store.IncidentResolved:
		return into, conflict("the incident " + into.ID + " is resolved")
	}
	moved := []string{}
	for {
		page, err := tx.ListSignals(ctx, store.SignalFilter{Organization: in.Organization, IncidentID: in.ID, Limit: store.MaxLimit})
		if err != nil {
			return into, err
		}
		if len(page) == 0 {
			break
		}
		for _, sg := range page {
			sg.IncidentID = into.ID
			if err := tx.UpdateSignal(ctx, sg); err != nil {
				return into, err
			}
			moved = append(moved, sg.ID)
		}
	}
	in.ParentID = into.ID
	if err := tx.UpdateIncident(ctx, in); err != nil {
		return into, err
	}
	if err := ev(in, EventMerged, map[string]any{"into": into.ID, "signals": moved}); err != nil {
		return into, err
	}
	if err := ev(into, EventAttached, map[string]any{"from": in.ID, "signals": moved}); err != nil {
		return into, err
	}
	if into.SeveritySetBy == store.ByPerson || in.Severity >= into.Severity {
		return into, nil
	}
	from := into.Severity
	into.Severity = in.Severity
	if err := tx.UpdateIncident(ctx, into); err != nil {
		return into, err
	}
	return into, ev(into, EventSeverity, map[string]any{"from": from, "to": into.Severity})
}

// Change is one change of the incidents of an Organization, sent on the stream as the event
// "incident". Kind is the action of a person, "rules" for a decision of the rule path, or
// "judgement" for an outcome of a judge, which names the judgement instead of an incident.
type Change struct {
	Organization string `json:"organization"`
	IncidentID   string `json:"incidentId,omitempty"`
	JudgementID  string `json:"judgementId,omitempty"`
	Kind         string `json:"kind"`
}

// subscriberBuffer is how many changes a subscriber may fall behind before it is dropped. A
// dropped subscriber's stream ends; the console connects again and reads the incidents anew.
const subscriberBuffer = 64

// Hub hands every change to the streams that may see it. It lives in one process: the service
// runs one replica, as its dispatcher requires.
type Hub struct {
	mu     sync.Mutex
	subs   map[chan Change]string // the Organization each stream may see; empty sees every one
	closed bool
}

// NewHub returns a hub without streams.
func NewHub() *Hub { return &Hub{subs: map[chan Change]string{}} }

// Close ends every stream, and every stream opened later at once. The program calls it when
// it stops, because a stream is never idle.
func (h *Hub) Close() {
	h.mu.Lock()
	defer h.mu.Unlock()
	h.closed = true
	for ch := range h.subs {
		delete(h.subs, ch)
		close(ch)
	}
}

// Publish hands c to every stream of its Organization and to every stream that sees all. It
// never waits: a stream that is full is dropped.
func (h *Hub) Publish(c Change) {
	h.mu.Lock()
	defer h.mu.Unlock()
	for ch, org := range h.subs {
		if org != "" && org != c.Organization {
			continue
		}
		select {
		case ch <- c:
		default:
			delete(h.subs, ch)
			close(ch)
		}
	}
}

func (h *Hub) subscribe(org string) chan Change {
	h.mu.Lock()
	defer h.mu.Unlock()
	ch := make(chan Change, subscriberBuffer)
	if h.closed {
		close(ch)
		return ch
	}
	h.subs[ch] = org
	return ch
}

func (h *Hub) unsubscribe(ch chan Change) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if _, ok := h.subs[ch]; ok {
		delete(h.subs, ch)
		close(ch)
	}
}

// stream sends the changes the caller may see as server-sent events, each flushed when it is
// written, until the client goes away or the stream is dropped.
func (s *Server) stream(w http.ResponseWriter, r *http.Request, c caller) {
	flusher, ok := w.(http.Flusher)
	if !ok || s.Hub == nil {
		fail(w, http.StatusInternalServerError, "stream_unavailable", "this server cannot stream")
		return
	}
	ch := s.Hub.subscribe(c.org)
	defer s.Hub.unsubscribe(ch)
	w.Header().Set("Content-Type", "text/event-stream")
	w.Header().Set("Cache-Control", "no-cache")
	w.Header().Set("X-Accel-Buffering", "no")
	w.WriteHeader(http.StatusOK)
	_, _ = io.WriteString(w, ": ready\n\n")
	flusher.Flush()
	for {
		select {
		case <-r.Context().Done():
			return
		case change, open := <-ch:
			if !open {
				return
			}
			data, err := json.Marshal(change)
			if err != nil {
				return
			}
			if _, err := fmt.Fprintf(w, "event: incident\ndata: %s\n\n", data); err != nil {
				return
			}
			flusher.Flush()
		}
	}
}

package main

import (
	"context"
	"time"

	"github.com/openova-io/openova/products/ops-records/internal/api"
	"github.com/openova-io/openova/products/ops-records/internal/correlate"
	"github.com/openova-io/openova/products/ops-records/internal/judge"
	"github.com/openova-io/openova/products/ops-records/internal/store"
)

// decider decides the batches of pending signals: through the correlator judge when the policy
// has one (judge.CorrelationTicker; the dispatcher writes the rule result when the agent is
// invalid, unavailable or late), else by the rules alone (correlate.Engine).
//
// It reads the store only when it is woken or when the next batch is due: after each decision
// round it computes when the earliest pending batch that has no question in flight is due and
// waits for that time, for wake, or for the end of ctx. With no pending signal it waits for
// wake alone. Every change that can make a batch pending or free a busy one calls wake: an
// action of a person and every outcome of a judge. A batch that is still due after a round
// (its decision failed) is tried again after the urgent wait, never at once.
type decider struct {
	store   store.Store
	batches correlate.Policy
	tick    func(ctx context.Context) error
	busy    func(organization, subjectKind, subjectID string) bool // nil for the rules alone
	close   func()
	after   func(time.Duration) <-chan time.Time
	now     func() time.Time
	logf    func(format string, args ...any)
	woken   chan struct{}
}

// newDecider builds the decider of cfg's policy. Its changes go to hub.
func newDecider(s store.Store, cfg serveConfig, hub *api.Hub, logf func(string, ...any)) (*decider, error) {
	d := &decider{store: s, batches: cfg.policy.Batches(), close: func() {}, after: time.After, now: time.Now, logf: logf,
		woken: make(chan struct{}, 1)}
	if _, ok := cfg.policy.Judges[judge.Correlator]; !ok {
		engine := &correlate.Engine{Store: s, Policy: d.batches}
		d.tick = func(ctx context.Context) error {
			results, err := engine.Tick(ctx)
			for _, b := range results {
				for _, g := range b.Groups {
					if g.IncidentID != "" {
						hub.Publish(api.Change{Organization: b.Organization, IncidentID: g.IncidentID, Kind: "rules"})
					}
				}
			}
			return err
		}
		return d, nil
	}
	disp, err := judge.New(s, cfg.policy, &judge.Tokens{BaseURL: cfg.catalystAPI}, &judge.A2A{}, judge.Options{
		Decided: func(j store.Judgement) {
			hub.Publish(api.Change{Organization: j.Organization, JudgementID: j.ID, Kind: "judgement"})
			d.wake()
		}})
	if err != nil {
		return nil, err
	}
	ticker := &judge.CorrelationTicker{Store: s, Dispatcher: disp, Batches: d.batches}
	d.tick = func(ctx context.Context) error {
		_, err := ticker.Tick(ctx)
		return err
	}
	d.busy, d.close = disp.Busy, disp.Close
	return d, nil
}

// wake makes the decider look at the pending signals now. It never waits.
func (d *decider) wake() {
	select {
	case d.woken <- struct{}{}:
	default:
	}
}

// run decides until ctx ends.
func (d *decider) run(ctx context.Context) {
	for ctx.Err() == nil {
		if err := d.tick(ctx); err != nil && ctx.Err() == nil {
			d.logf("decide: %v", err)
		}
		var due <-chan time.Time
		next, found, err := d.next(ctx)
		switch {
		case err != nil && ctx.Err() == nil:
			d.logf("decide: the next batch: %v", err)
			due = d.after(d.batches.UrgentBatch)
		case found:
			wait := next.Sub(d.now())
			if wait <= 0 { // still due after the round: its decision failed
				wait = d.batches.UrgentBatch
			}
			due = d.after(wait)
		}
		select {
		case <-ctx.Done():
		case <-d.woken:
		case <-due:
		}
	}
}

// next returns when the earliest pending batch without a question in flight is due, and
// false when there is none. A batch's last decision is the answer time of its newest
// judgement, else its ask time, as judge.CorrelationTicker counts it.
func (d *decider) next(ctx context.Context) (time.Time, bool, error) {
	batches, _, err := correlate.Load(ctx, d.store, "")
	if err != nil {
		return time.Time{}, false, err
	}
	var first time.Time
	found := false
	for _, b := range batches {
		var last time.Time
		if d.busy != nil {
			subject := judge.BatchSubject(b)
			if d.busy(b.Organization, judge.SubjectBatch, subject) {
				continue
			}
			rows, err := d.store.ListJudgements(ctx, store.JudgementFilter{Organization: b.Organization,
				Judge: judge.Correlator, SubjectKind: judge.SubjectBatch, SubjectID: subject, Limit: 1})
			if err != nil {
				return time.Time{}, false, err
			}
			if len(rows) == 1 {
				last = rows[0].AskedAt
				if rows[0].AnsweredAt != nil {
					last = *rows[0].AnsweredAt
				}
			}
		}
		if due := correlate.DueAt(b, last, d.batches); !found || due.Before(first) {
			first, found = due, true
		}
	}
	return first, found, nil
}

	}); err != nil {
		t.Fatal(err)

	d.busy = func(org, kind, subject string) bool { return busy && org == "acme" && subject == "cluster/c1" }
	if next, found, _ := d.next(context.Background()); !found || !next.Equal(answered.Add(waits.Batch)) {
		t.Fatalf("the judge: next %v %v", next, found)
	}
	busy = true
	if _, found, _ := d.next(context.Background()); found {
		t.Fatal("a batch with a question in flight was counted")
	}
}

func TestDeciderWaits(t *testing.T) {
	s := store.NewMemory()
	now := time.Date(2026, 12, 1, 9, 0, 0, 0, time.UTC)
	ticks := make(chan struct{}, 4)
	timers := make(chan time.Duration, 4)
	d := &decider{store: s, batches: waits, woken: make(chan struct{}, 1), logf: t.Logf,
		now:   func() time.Time { return now },
		tick:  func(context.Context) error { ticks <- struct{}{}; return nil },
		after: func(wait time.Duration) <-chan time.Time { timers <- wait; return nil }}
	ctx, cancel := context.WithCancel(context.Background())
	done := make(chan struct{})
	go func() { d.run(ctx); close(done) }()
	step := func(what string) {
		t.Helper()
		select {
		case <-ticks:
		case <-time.After(5 * time.Second):
			t.Fatalf("no decision round after %s", what)
		}
	}
	step("the start")
	pending(t, s, now.Add(-20*time.Second)) // due in 40 seconds
	d.wake()
	step("wake")
	if wait := <-timers; wait != 40*time.Second {
		t.Fatalf("waited %s for a batch due in 40s", wait)
	}
	pending(t, s, now.Add(-10*time.Minute)) // due already: the round did not decide it
	d.wake()
	step("the second wake")
	if wait := <-timers; wait != waits.UrgentBatch {
		t.Fatalf("waited %s for a batch the round left due, want the urgent wait", wait)
	}
	cancel()
	<-done
	if len(timers) != 0 {
		t.Fatalf("%d timers more than the rounds needed", len(timers))
	}
}
