# SOV-040 — Guard G1: source-address ratchet

## In plain words

**The problem today.** Many lines of the code write the address of the company's registry, its Git or another public source as fixed text. A Sovereign that must pull everything from its own registry and its own Git cannot change those lines, and new ones keep being added. Nothing counts them.

**What changes.** A check on every pull request counts those lines in six parts of the code and compares each count with a stored number. A change that adds such a line fails. A change that removes some lowers the stored number.

**Done means:**

- A pull request that adds a line with such an address to one of the six parts of the code turns red.
- Comment lines, test files and image names are not counted.
- Every pull request shows the six counts, so the number of addresses left can be read at any time.
- The tool that writes the stored numbers can lower them and never raise them.
- The check proves on itself that each of its rules can fail.
- No product code changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every pull request gets a check named `upstream-literals`. It counts, in six parts of the code, the lines that write a company or public source address as fixed text: a link with the scheme `oci://`, `https://`, `http://` or `git://` to an `openova.io` host, `ghcr.io`, `github.com/openova-io`, `raw.githubusercontent.com` or a Crossplane package host; a `package:` line that names one of these hosts; `get.k3s.io`; the address `212.72.24.20`; and the named service hosts of `openova.io`. It prints the six counts and compares each with the number stored in `scripts/upstream-literals-baseline.txt`. The check is red when a count is above its stored number. A person can read the six counts on any pull request.

## 3. The model (the law)
1. The guard is the script `scripts/check-upstream-literals.sh`. It reads the working tree. It needs bash, grep, sort and the other shell tools, and nothing else.
2. It counts lines in six scopes, always in this order and with these names:
   - `infra`: every file under `infra/providers`.
   - `kit`: every file under `clusters/_template`.
   - `charts`: the files `platform/*/chart/values.yaml` and `products/*/chart/values.yaml`, and every file under `products/catalyst/chart/templates`.
   - `api`: the `.go` files under `products/catalyst/bootstrap/api`, without the files whose name ends in `_test.go`.
   - `controllers`: the `.go` files under `core/controllers` and `core/services`, without the files whose name ends in `_test.go`.
   - `console`: every file under `products/catalyst/bootstrap/ui/src` whose name holds neither `.test.` nor `.spec.`.
3. A line counts when it matches the extended regular expression of the script (the variable `PATTERN` in the block of field 5). With `H` one of the hosts `[a-z0-9.-]*openova.io`, `ghcr.io`, `github.com/openova-io`, `raw.githubusercontent.com`, `xpkg.upbound.io` and `xpkg.crossplane.io`, the forms are: `(oci|https?|git)://H`; `package:` followed by spaces, an optional quote and `H`; `212.72.24.20`; `get.k3s.io`; and `(pdns|mail|pool|console|admin|marketplace|sso|auth).openova.io`.
4. A line whose first non-blank characters are `#`, `//`, `*`, `/*`, `{{/*` or `{{- /*` is a comment line and is not counted. An image name, such as `ghcr.io/openova-io/x:1` without a scheme, does not match, by design. A binary file is not read.
5. The baseline is the file `scripts/upstream-literals-baseline.txt`. It has exactly six lines, `<scope>=<count>`, in the order of item 2, and nothing else.
6. The rule: when a count is above its baseline number, the script prints a line that starts with `check-upstream-literals: FAIL <scope>:` and exits with code 1. When a count is below its baseline number, it prints a line that starts with `check-upstream-literals: note:` and exits with code 0: the change that removed the lines lowers the baseline in the same pull request. Every run that judges prints first the six lines `<scope>=<count>`.
7. A baseline only goes down. `--write-baseline` writes the baseline from the tree. When the baseline file exists and a count is above its number, it writes nothing, prints `check-upstream-literals: the baseline was not written: a baseline only goes down` and exits with code 1.
8. `--list <scope>` prints one line `<path>:<line number>:<text>` for each counted line of that scope, sorted by path and line number, and nothing else.
9. When a scope directory of item 2 is missing, the baseline is missing, or the baseline is not six lines of the form of item 5, the script judges nothing, prints a line that starts with `check-upstream-literals: cannot judge:` and exits with code 2. A wrong argument or an unknown scope after `--list` also exits with code 2. A missing baseline is never a pass.
10. `--self-test` builds a small tree of its own, 21 times, and shows for each rule that it fails and for each exception that it passes. It reads nothing of the repository.
11. The guard has no allow-list of files.
12. The workflow `.github/workflows/check-upstream-literals.yaml` has the triggers `pull_request` and `merge_group` and no path filter. #!/usr/bin/env bash
# check-upstream-literals.sh - guard G1: source addresses written into the code may only fall.
#
# A Sovereign must be able to pull everything from its own registry and its own Git. Every
# company or public source address that is written into the code as a literal is a place
# where it cannot. This guard counts those lines in six scopes and refuses a rise. It is a
# ratchet: it asks for no clean-up, it refuses one more line.
#
# Scopes (paths under the repository root):
#   infra        every file under infra/providers
#   kit          every file under clusters/_template
#   charts       platform/*/chart/values.yaml, products/*/chart/values.yaml and every file
#                under products/catalyst/chart/templates
#   api          the .go files under products/catalyst/bootstrap/api, without *_test.go
#   controllers  the .go files under core/controllers and core/services, without *_test.go
#   console      every file under products/catalyst/bootstrap/ui/src whose name holds
#                neither ".test." nor ".spec."
#
# A line counts when it matches the extended regular expression PATTERN below, with H one of
# the hosts [a-z0-9.-]*openova.io, ghcr.io, github.com/openova-io, raw.githubusercontent.com,
# xpkg.upbound.io, xpkg.crossplane.io:
#   (oci|https?|git)://H | package: *["']?H | the parent's bastion address | get.k3s.io
#   | (pdns|mail|pool|console|admin|marketplace|sso|auth).openova.io
# A line whose first non-blank characters are #, //, *, /* or a template comment ({{/* or
# {{- /*) is not counted. An image name (ghcr.io/x/y:tag with no scheme) is not matched, by
# design. Binary files are not read.
#
# The baseline is scripts/upstream-literals-baseline.txt: six lines, <scope>=<count>, in the
# order above. A count above its baseline fails. A count below it passes with a note: the
# change that removed the lines lowers the baseline in the same pull request, with
# --write-baseline. That command refuses to raise a number, so a baseline only goes down.
#
# Usage:
#   bash scripts/check-upstream-literals.sh                   print <scope>=<count>; compare
#   bash scripts/check-upstream-literals.sh --list <scope>    print path:line:text of each hit
#   bash scripts/check-upstream-literals.sh --write-baseline  write the baseline from the tree
#   bash scripts/check-upstream-literals.sh --self-test       prove that every rule can fail
#   --root <dir>  measure another checkout (default: the one this script lies in)
#
# Exit codes: 0 no count is above its baseline; 1 a count is above its baseline, or
# --write-baseline refused to raise one; 2 the tree or the baseline cannot be read, or the
# arguments are wrong, so nothing was judged.
set -euo pipefail
export LC_ALL=C

ME=check-upstream-literals
SELF="${BASH_SOURCE[0]}"
BASELINE=scripts/upstream-literals-baseline.txt
SCOPES=(infra kit charts api controllers console)
REQUIRED=(infra/providers clusters/_template products/catalyst/chart/templates
          products/catalyst/bootstrap/api core/controllers core/services
          products/catalyst/bootstrap/ui/src)
H='([a-z0-9.-]*openova\.io|ghcr\.io|github\.com/openova-io|raw\.githubusercontent\.com|xpkg\.upbound\.io|xpkg\.crossplane\.io)'
Q="[\"']"
PATTERN='(oci|https?|git)://'"$H"'|package: *'"$Q"'?'"$H"'|212\.72\.24\.20|get\.k3s\.io|(pdns|mail|pool|console|admin|marketplace|sso|auth)\.openova\.io'
COMMENT='^[^:]*:[0-9]+:[[:space:]]*(#|//|\*|/\*|\{\{-?[[:space:]]*/\*)'

die() { echo "$ME: cannot judge: $*"; exit 2; }

# hits <root> <scope> - one line path:line:text per counted line, sorted by path and line.
hits() {
  local root="$1" scope="$2" f
  local -a args=() opts=()
  case "$scope" in
    infra)       args=(infra/providers) ;;
    kit)         args=(clusters/_template) ;;
    charts)      args=(products/catalyst/chart/templates)
                 for f in "$root"/platform/*/chart/values.yaml "$root"/products/*/chart/values.yaml; do
                   if [ -f "$f" ]; then args+=("${f#"$root"/}"); fi
                 done ;;
    api)         args=(products/catalyst/bootstrap/api); opts=(--include='*.go' --exclude='*_test.go') ;;
    controllers) args=(core/controllers core/services); opts=(--include='*.go' --exclude='*_test.go') ;;
    console)     args=(products/catalyst/bootstrap/ui/src); opts=(--exclude='*.test.*' --exclude='*.spec.*') ;;
    *)           return 3 ;;
  esac
  ( cd "$root" && { grep -rnHIE ${opts[@]+"${opts[@]}"} -e "$PATTERN" -- "${args[@]}" || [ $? -eq 1 ]; } ) \
    | { grep -vE "$COMMENT" || [ $? -eq 1 ]; } \
    | sort -t: -k1,1 -k2,2n
}

# count <root> <scope> - the number of counted lines; fails when the files cannot be read.
count() {
  local out
  out="$(hits "$1" "$2")" || return 1
  if [ -z "$out" ]; then echo 0; else printf '%s\n' "$out" | wc -l | tr -d ' '; fi
}

check_tree() {
  local d
  for d in "${REQUIRED[@]}"; do
    [ -d "$ROOT/$d" ] || die "$d is not a directory under $ROOT"
  done
}

# read_baseline - fills BASE[<scope>] from the baseline file, or dies.
declare -A BASE=() NOW=()
read_baseline() {
  local -a lines=()
  local i
  [ -f "$ROOT/$BASELINE" ] || die "$BASELINE does not exist; write it with --write-baseline"
  mapfile -t lines < "$ROOT/$BASELINE"
  [ "${#lines[@]}" -eq "${#SCOPES[@]}" ] || die "$BASELINE must hold exactly ${#SCOPES[@]} lines, <scope>=<count> in the order ${SCOPES[*]}"
  for i in "${!SCOPES[@]}"; do
    [[ "${lines[$i]}" =~ ^${SCOPES[$i]}=([0-9]+)$ ]] || die "$BASELINE line $((i + 1)) must be ${SCOPES[$i]}=<count>, not '${lines[$i]}'"
    BASE[${SCOPES[$i]}]=$((10#${BASH_REMATCH[1]}))
  done
}

measure() {
  local s
  for s in "${SCOPES[@]}"; do
    NOW[$s]="$(count "$ROOT" "$s")" || die "the files of scope $s cannot be read"
  done
}

# rises - one FAIL line per scope whose count is above its baseline.
rises() {
  local s
  for s in "${SCOPES[@]}"; do
    if [ "${NOW[$s]}" -gt "${BASE[$s]}" ]; then
      echo "$ME: FAIL $s: ${NOW[$s]} lines, the baseline allows ${BASE[$s]}. List them: bash scripts/$ME.sh --list $s"
    fi
  done
}

judge() {
  local s fails
  for s in "${SCOPES[@]}"; do echo "$s=${NOW[$s]}"; done
  fails="$(rises)"
  for s in "${SCOPES[@]}"; do
    if [ "${NOW[$s]}" -lt "${BASE[$s]}" ]; then
      echo "$ME: note: $s is below its baseline of ${BASE[$s]}. Lower the baseline in the same change: bash scripts/$ME.sh --write-baseline"
    fi
  done
  if [ -n "$fails" ]; then
    printf '%s\n' "$fails"
    echo "$ME: a source address is an input of the Sovereign, not a literal in the code"
    return 1
  fi
  return 0
}

write_baseline() {
  local s fails
  if [ -f "$ROOT/$BASELINE" ]; then
    read_baseline
    fails="$(rises)"
    if [ -n "$fails" ]; then
      printf '%s\n' "$fails"
      echo "$ME: the baseline was not written: a baseline only goes down"

      *$'\n'*) [ "$out" = "$needle" ] || ok=0 ;;
