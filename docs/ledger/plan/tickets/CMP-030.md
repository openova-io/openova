## 3. The model (the law)
1. Seven result states: `pass`, `fail`, `warn`, `na` (the producer says the check does not apply), `waived` (an active waiver covers the subject), `exempt` (an exemption of the model covers the subject), `not-measured` (no producer result, a producer error, or an incomplete scan).
2. A check's `source` is one of `kyverno`, `evaluator`, `trivy-vulnerability`, `trivy-configaudit`, `trivy-exposedsecret`, `trivy-rbac`. Only findings of that source count for the check.
3. **Rule 1, effective result.** For a subject and a check, take the findings whose subject and check match and whose source equals the check's source; ignore findings of any other source. Of several such findings the worst wins, in the order `fail`, `warn`, `not-measured`, `pass`, `na`. A finding with any other result counts as `not-measured`. Then: if a waiver covers the subject and the check, the result is `waived`; else if an exemption of the model names the subject's namespace and the check (or `*`), `exempt`; else if there is no finding, `not-measured`. A cluster-scoped subject (namespace `""`) is never exempt.
4. **Rule 2, subject score.** `den` is the sum of the weights of the checks whose effective result is `pass`, `fail` or `warn`; `num` is the sum of those that are `pass`. Score = floor(100 × num / den), or nil when `den` is 0. A check of weight 0 is counted in `Counts` and never in `num` or `den`. When a check with `mandatory: true` has effective result `fail` and the subject's environment type is listed in `mandatoryCap.environmentTypes`, the score is the smaller of the score and `mandatoryCap.value`, and `capped` is true. A nil score is never capped.
5. **Rule 3, axis value.** For an axis of type `checks`: `Num` and `Den` are the sums of rule 2 over every subject of the scope, restricted to the checks of the axis. Value = floor(100 × Num / Den), or nil with the axis `naText` as `Reason` when `Den` is 0. `Subjects` counts the subjects with a non-zero denominator on the axis, `NotMeasured` the others. `Gap` is the check of the axis with the largest sum of weights of `fail` and `warn` results, and `GapLost` that sum; on a tie the check that comes first in the model wins; `""` when no weight was lost. An axis of type `measure` has no value in this package: nil with its `naText`.
6. **Rule 4, overall.** A group's mean is the mean of its non-nil axis values. Overall = round(sum of group weight × group mean over the groups with at least one non-nil axis, divided by the sum of those group weights); round is half away from zero. `Partial` is true when a group was left out. Overall is nil when every group was left out. A level is the name of the first entry of `levels` whose `min` is at or below the value. In the scope `workload` with one subject, rule 2's cap also bounds Overall and sets `Capped`.
7. **Rule 5, never a false pass.** `not-measured`, `na`, `waived` and `exempt` never enter a numerator or a denominator.
8. **Waivers are a parameter.** `SubjectScore` and `ScopePosture` take a last parameter `covers` of type `Covers func(k SubjectKey, check string) Result`. It returns `waived` when an active waiver covers the subject and the check; any other value means no waiver. A nil `covers` covers nothing. Exemptions come from the model.
9. **The loader.** `LoadModel` accepts only `apiVersion: compliance.openova.io/v1alpha1`, `kind: ComplianceModel`. It reads these fields of `spec`, applies their rules, and returns an error that names the first rule broken; it returns no partial model. Fields it does not read are ignored, so a model that carries fields of later packages still loads.

| Field | Rule |
|---|---|
| `version` | required; a semantic version (`1.0.0`, `0.0.0`) |
| `levels[]` | 2 to 10 items; `name` required and unique; `min` 0 to 100; strictly falling `min`; the last `min` is 0 |
| `mandatoryCap` | required; `value` 0 to 100; `environmentTypes` required, may be empty |
| `severityWeights` | required; `critical`, `high`, `medium`, `low` each required, 0 to 100 |
| `groups[]` | 1 to 4 items; `id` required, unique, pattern `^[a-z][a-z0-9-]*$`; `title` required; `weight` 1 to 100 |
| `axes[]` | 1 to 30 items; `id` required, unique, same pattern; `title` required; `group` an id of `groups`; `type` `checks` or `measure`; `measure` required for type `measure` and one of `runtime-clean`, `memory-efficiency`, absent for type `checks`; `naText` required |
| `checks[]` | required, may be empty; `id` required and unique; `title` required, at most 80 characters; `source` of item 2; `axis` an id of an axis of type `checks`; `severity` `critical`, `high`, `medium` or `low`; `weight` optional, 0 to 100, default the severity weight; `mandatory` optional, default false; `ownerSide` `organization` or `sovereign`; `valuesKey` required when `source` is `kyverno`, absent otherwise; `switchable` optional, default true; `description` required; `remediation` required, at least 20 characters |
| `exemptions[]` | required, may be empty; `namespace` required; `checks` at least one non-empty item, and `*` only as the single item; `reason` required, at least 20 characters; `owner` required |

// Package compliance holds the types of the compliance read model and its
// pure functions: the loader of the ComplianceModel object and the score
// rules. Nothing in this package reads a cluster, keeps state or registers a
// metric. The read model and the adapters that produce findings call it.
package compliance

import (
	"time"

	"github.com/openova-io/openova/products/catalyst/bootstrap/api/internal/k8scache"
)

// Result is the verdict of one check on one subject.
type Result string

const (
	Pass        Result = "pass"
	Fail        Result = "fail"
	Warn        Result = "warn"
	NA          Result = "na"           // the producer says the check does not apply
	Waived      Result = "waived"       // an active waiver covers the subject
	Exempt      Result = "exempt"       // a platform exemption of the model covers the subject
	NotMeasured Result = "not-measured" // no producer result, a producer error, or an incomplete scan
)

// Source is the enum of ComplianceModel.spec.checks[].source: the only
// producer whose findings count for a check. The loader accepts kyverno,
// evaluator, trivy-vulnerability, trivy-configaudit, trivy-exposedsecret and
// trivy-rbac.
type Source string

// The sources that have a producer today.
const (
	SourceKyverno   Source = "kyverno"
	SourceEvaluator Source = "evaluator"
)

// Scope names of a Posture.
const (
	ScopeSovereign    = "sovereign"
	ScopeOrganization = "organization"
	ScopeEnvironment  = "environment"
	ScopeApplication  = "application"
	ScopeNamespace    = "namespace"
	ScopeWorkload     = "workload"
)

// SubjectKey identifies what is judged: a top-level workload or a cluster object.
type SubjectKey struct {
	Cluster   string // informer cluster id
	Namespace string // "" for a cluster-scoped subject
	Kind      string // Deployment, StatefulSet, DaemonSet, CronJob, Job, Pod (bare only), Namespace, ClusterRole, Role, PersistentVolumeClaim, Service, HelmRelease, ...
	Name      string
}

// Subject is a SubjectKey with the facts the score rules read.
type Subject struct {
	Key             SubjectKey
	Organization    string // slug, "" for platform
	Environment     string // "" when none
	EnvironmentType string // the text after the last "-" of Environment; "" when none
	Application     string // "" when none
	Exposure        string // "internet" | "production" | "other"
}

// ObjectRef names a Kubernetes object.
type ObjectRef struct {
	APIVersion, Kind, Namespace, Name string
}

// Finding is one producer verdict of one check on one subject.
type Finding struct {
	Check      string // check id of the model
	Source     Source
	Subject    SubjectKey
	Result     Result            // as the producer reported; waivers and exemptions are applied by the read model, not by adapters
	Message    string            // what was found; at most 500 characters
	Evidence   ObjectRef         // the object that proves the verdict (the report, the backup, the certificate)
	Properties map[string]string // small, source-specific details; never a secret value
	ObservedAt time.Time
	NextChange time.Time // zero, or the instant at which the verdict changes with no new event
}

// Adapter turns one informer event into findings. One adapter per source kind.
type Adapter interface {
	// Kinds returns the informer kind names this adapter consumes.
	Kinds() []string
	// Apply returns the complete set of findings that the event's object now
	// supports. The read model replaces every finding previously attributed
	// to the same object. For a DELETED event it returns nil.
	Apply(ev k8scache.Event, r Resolver) []Finding
}

// Resolver answers questions from the informer cache. It never calls the API server.
type Resolver interface {
	// TopOwner follows ownerReferences (Pod to ReplicaSet to Deployment; Pod to Job to CronJob)
	// and returns the top controller, or the object itself when it has no controller owner.
	TopOwner(cluster, namespace, kind, name string) SubjectKey
	// Subject returns the subject with its Organization, Environment, Application and Exposure.
	Subject(k SubjectKey) Subject
	Now() time.Time
}

// Counts holds how many effective results of each kind a subject or a scope has.
type Counts struct {
	Pass, Fail, Warn, NA, Waived, Exempt, NotMeasured int
}

// AxisValue is the value of one axis of the model for one scope.
type AxisValue struct {
	ID          string
	Value       *int   // nil = not measured
	Level       string // "" when Value is nil
	Num, Den    int    // weighted; zero for a measure axis
	Subjects    int    // subjects with at least one result in the denominator
	NotMeasured int    // subjects in scope with none
	Gap         string // the check of the axis with the largest lost weight, "" when none
	GapLost     int    // that check's lost weight
	Reason      string // the axis naText when Value is nil
}

// Posture is the score of one scope.
type Posture struct {
	Scope, ID      string // sovereign | organization | environment | application | namespace | workload
	Cluster        string // "" = all regions
	Overall        *int
	Level          string
	Partial        bool // true when a group had no measured axis and was left out
	Capped         bool // workload scope only: the mandatory cap was applied
	Axes           []AxisValue
	Counts         Counts
	ModelVersion   string    // spec.version of the model that scored the scope; several versions joined by "," when clusters differ
	OldestInput    time.Time // oldest last-report time among the producers that feed the scope
	StaleProducers []string
}

// Covers reports a waiver. It returns Waived when an active waiver covers the
// subject and the check; any other value means that no waiver covers them.
// A nil Covers covers nothing.
type Covers func(k SubjectKey, check string) Result

// LoadModel parses and checks the spec of a ComplianceModel object. It
// returns an error naming the first rule the object breaks; the caller then
// keeps the model it had. Fields this package does not read are ignored.
func LoadModel(obj *unstructured.Unstructured) (*Model, error) {
	if obj == nil {
		return nil, fmt.Errorf("compliance model: no object")
	}
	if obj.GetAPIVersion() != ModelAPIVersion || obj.GetKind() != ModelKind {
		return nil, fmt.Errorf("compliance model: object is %s %s, want %s %s", obj.GetAPIVersion(), obj.GetKind(), ModelAPIVersion, ModelKind)
	}
	spec, ok := obj.Object["spec"].(map[string]interface{})
	if !ok {
		return nil, fmt.Errorf("compliance model: spec: required")
	}
	b, err := json.Marshal(spec)
	if err != nil {
		return nil, fmt.Errorf("compliance model: spec: %w", err)
	}
	var raw rawModel
	if err := json.Unmarshal(b, &raw); err != nil {
		return nil, fmt.Errorf("compliance model: spec: %w", err)
	}
	m := &Model{}
	for _, step := range []func(*rawModel, *Model) error{
		loadVersion, loadLevels, loadMandatoryCap, loadSeverityWeights,
		loadGroups, loadAxes, loadChecks, loadExemptions,
	} {
		if err := step(&raw, m); err != nil {
			return nil, fmt.Errorf("compliance model: %w", err)
		}
	}
	return m, nil
}

func requiredString(path string, v *string) (string, error) {
	if v == nil || *v == "" {
		return "", fmt.Errorf("%s: required", path)
	}
	return *v, nil
}

func requiredInt(path string, v *int, lo, hi int) (int, error) {
	if v == nil {
		return 0, fmt.Errorf("%s: required", path)
	}
	if *v < lo || *v > hi {
		return 0, fmt.Errorf("%s: %d is outside %d..%d", path, *v, lo, hi)
	}
	return *v, nil
}

func loadVersion(raw *rawModel, m *Model) error {
	v, err := requiredString("version", raw.Version)
	if err != nil {
		return err
	}
	if !semverRE.MatchString(v) {
		return fmt.Errorf("version: %q is not a semantic version", v)
	}
	m.Version = v
	return nil
}

func loadLevels(raw *rawModel, m *Model) error {
	if len(raw.Levels) < 2 || len(raw.Levels) > 10 {
		return fmt.Errorf("levels: %d items, want 2..10", len(raw.Levels))
	}
	seen := map[string]bool{}
	for i, rl := range raw.Levels {
		path := fmt.Sprintf("levels[%d]", i)
		name, err := requiredString(path+".name", rl.Name)
		if err != nil {
			return err
		}
		if seen[name] {
			return fmt.Errorf("%s.name: %q is not unique", path, name)
		}
		seen[name] = true
		lmin, err := requiredInt(path+".min", rl.Min, 0, 100)
		if err != nil {
			return err
		}
		if i > 0 && lmin >= m.Levels[i-1].Min {
			return fmt.Errorf("%s.min: levels are not sorted by min, highest first", path)
		}
		m.Levels = append(m.Levels, Level{Name: name, Min: lmin})
	}
	if last := m.Levels[len(m.Levels)-1]; last.Min != 0 {
		return fmt.Errorf("levels: the last min is %d, want 0", last.Min)
	}
	return nil
}

func loadMandatoryCap(raw *rawModel, m *Model) error {

func loadGroups(raw *rawModel, m *Model) error {
	if len(raw.Groups) < 1 || len(raw.Groups) > 4 {
		return fmt.Errorf("groups: %d items, want 1..4", len(raw.Groups))
	}
	seen := map[string]bool{}
	for i, rg := range raw.Groups {
		path := fmt.Sprintf("groups[%d]", i)
		id, err := requiredString(path+".id", rg.ID)
		if err != nil {
			return err
		}
		if !idRE.MatchString(id) {
			return fmt.Errorf("%s.id: %q does not match %s", path, id, idRE)
		}
		if seen[id] {
			return fmt.Errorf("%s.id: %q is not unique", path, id)
		}
		seen[id] = true
		title, err := requiredString(path+".title", rg.Title)
		if err != nil {
			return err
		}
		w, err := requiredInt(path+".weight", rg.Weight, 1, 100)
		if err != nil {
			return err
		}
		m.Groups = append(m.Groups, Group{ID: id, Title: title, Weight: w})
	}
	return nil
}

func loadAxes(raw *rawModel, m *Model) error {
	if len(raw.Axes) < 1 || len(raw.Axes) > 30 {
		return fmt.Errorf("axes: %d items, want 1..30", len(raw.Axes))
	}
	groups := map[string]bool{}
	for _, g := range m.Groups {
		groups[g.ID] = true
	}
	seen := map[string]bool{}
	for i, ra := range raw.Axes {
		path := fmt.Sprintf("axes[%d]", i)
		id, err := requiredString(path+".id", ra.ID)
		if err != nil {
			return err
		}
		if !idRE.MatchString(id) {
			return fmt.Errorf("%s.id: %q does not match %s", path, id, idRE)
		}
		if seen[id] {
			return fmt.Errorf("%s.id: %q is not unique", path, id)
		}
		seen[id] = true
		title, err := requiredString(path+".title", ra.Title)
		if err != nil {
			return err
		}
		group, err := requiredString(path+".group", ra.Group)
		if err != nil {
			return err
		}
		if !groups[group] {
			return fmt.Errorf("%s.group: %q is not an id of groups", path, group)
		}
		typ, err := requiredString(path+".type", ra.Type)
		if err != nil {
			return err
		}
		measure := ""
		switch typ {
		case AxisTypeChecks:
			if ra.Measure != nil && *ra.Measure != "" {
				return fmt.Errorf("%s.measure: must be absent when type is checks", path)
			}
		case AxisTypeMeasure:
			if measure, err = requiredString(path+".measure", ra.Measure); err != nil {
				return err
			}
			if !validMeasures[measure] {
				return fmt.Errorf("%s.measure: %q is not a known measure", path, measure)
			}
		default:
			return fmt.Errorf("%s.type: %q is not checks or measure", path, typ)
		}
		naText, err := requiredString(path+".naText", ra.NAText)
		if err != nil {
			return err
		}
		m.Axes = append(m.Axes, Axis{ID: id, Title: title, Group: group, Type: typ, Measure: measure, NAText: naText})
	}
	return nil
}

func loadChecks(raw *rawModel, m *Model) error {
	if raw.Checks == nil {

	checkAxes := map[string]bool{}
	for _, a := range m.Axes {
		if a.Type == AxisTypeChecks {

		}
	}
	seen := map[string]bool{}
	for i, rc := range *raw.Checks {
		path := fmt.Sprintf("checks[%d]", i)
		c := Check{Switchable: true}
		var err error
		if c.ID, err = requiredString(path+".id", rc.ID); err != nil {
			return err
		}
		if seen[c.ID] {
			return fmt.Errorf("%s.id: %q is not unique", path, c.ID)
		}
		seen[c.ID] = true
		if c.Title, err = requiredString(path+".title", rc.Title); err != nil {
			return err
		}
		if utf8.RuneCountInString(c.Title) > 80 {
			return fmt.Errorf("%s.title: longer than 80 characters", path)
		}
		src, err := requiredString(path+".source", rc.Source)
		if err != nil {
			return err

			return err
		}

			return err
		}

			return fmt.Errorf("%s.severity: %q is not critical, high, medium or low", path, c.Severity)
		}

			if c.Weight, err = requiredInt(path+".weight", rc.Weight, 0, 100); err != nil {
				return err
			}
		}

		}

			return err
		}

			return fmt.Errorf("%s.ownerSide: %q is not organization or sovereign", path, c.OwnerSide)
		}
		if c.Source == SourceKyverno {
			if c.ValuesKey, err = requiredString(path+".valuesKey", rc.ValuesKey); err != nil {
				return err
			}
		} else if rc.ValuesKey != nil && *rc.ValuesKey != "" {
			return fmt.Errorf("%s.valuesKey: must be absent when source is %s", path, c.Source)
		}
		if rc.Switchable != nil {
			c.Switchable = *rc.Switchable
		}
		if c.Description, err = requiredString(path+".description", rc.Description); err != nil {
			return err
		}
		if c.Remediation, err = requiredString(path+".remediation", rc.Remediation); err != nil {
			return err
		}
		if utf8.RuneCountInString(c.Remediation) < 20 {
			return fmt.Errorf("%s.remediation: shorter than 20 characters", path)
		}
		m.Checks = append(m.Checks, c)
	}

func loadExemptions(raw *rawModel, m *Model) error {
	if raw.Exemptions == nil {
		return fmt.Errorf("exemptions: required")
	}
	for i, re := range *raw.Exemptions {
		path := fmt.Sprintf("exemptions[%d]", i)
		e := Exemption{}
		var err error
		if e.Namespace, err = requiredString(path+".namespace", re.Namespace); err != nil {
			return err
		}
		if re.Checks == nil || len(*re.Checks) == 0 {
			return fmt.Errorf("%s.checks: required, at least one item", path)
		}
		for j, id := range *re.Checks {
			if id == "" {
				return fmt.Errorf("%s.checks[%d]: empty", path, j)
			}
			if id == "*" && len(*re.Checks) > 1 {
				return fmt.Errorf("%s.checks: \"*\" must be the only item", path)
			}
		}
		e.Checks = append([]string{}, *re.Checks...)
		if e.Reason, err = requiredString(path+".reason", re.Reason); err != nil {
			return err
		}
		if utf8.RuneCountInString(e.Reason) < 20 {
			return fmt.Errorf("%s.reason: shorter than 20 characters", path)
		}
		if e.Owner, err = requiredString(path+".owner", re.Owner); err != nil {
			return err
		}
		m.Exemptions = append(m.Exemptions, e)
	}
	return nil
}

// exempts reports whether an exemption of the model covers the check in the namespace.
func (m *Model) exempts(namespace, check string) bool {
	if namespace == "" {
		return false
	}
	for _, e := range m.Exemptions {
		if e.Namespace != namespace {
			continue
		}
		for _, id := range e.Checks {
			if id == "*" || id == check {
				return true
			}
		}
	}
	return false
}

// level returns the name of the first level whose Min is at or below v.
func (m *Model) level(v int) string {
	for _, l := range m.Levels {
		if v >= l.Min {
			return l.Name
		}
	}
	return ""
}

package compliance

import "math"

// The score rules. Every number is read from the model.
//
// Rule 1, effective result. For a subject and a check, only findings whose
// Source equals the check's source count; findings of any other source are
// ignored. Of several findings of the right source the worst wins, in the
// order fail, warn, not-measured, pass, na. Then: a waiver that covers the
// subject and the check gives waived; else an exemption of the model for the
// subject's namespace gives exempt; else no finding gives not-measured.
//
// Rule 2, subject score. den is the sum of the weights of the checks whose
// effective result is pass, fail or warn; num is the sum of those that pass.
// Score = floor(100 * num / den), or nil when den is 0. A check of weight 0
// is counted in Counts and never in num or den. When a mandatory check fails
// and the subject's environment type is listed in the mandatory cap, the
// score is at most the cap value and capped is true.
//
// Rule 3, axis value. For an axis of type checks, num and den are the sums
// of rule 2 over every subject of the scope, restricted to the checks of the
// axis. Value = floor(100 * num / den), or nil with the axis naText when den
// is 0. Gap is the check of the axis with the largest sum of weights of fail
// and warn results. An axis of type measure has no value in this package:
// nil with its naText.
//
// Rule 4, overall. Each group's mean is the mean of its non-nil axis values.
// Overall = round(sum of group weight * group mean / sum of those group
// weights), over the groups with at least one non-nil axis. Partial is true
// when a group was left out; Overall is nil when every group was left out.
// The level is the first level whose min is at or below the value.
//
// Rule 5, never a false pass. not-measured, na, waived and exempt never enter
// a numerator or a denominator.

// rank orders results for rule 1: the lower the rank, the worse the result.
var rank = map[Result]int{Fail: 0, Warn: 1, NotMeasured: 2, Pass: 3, NA: 4}

type findingKey struct {
	subject SubjectKey
	check   string
}

func indexFindings(fs []Finding) map[findingKey][]Finding {
	idx := make(map[findingKey][]Finding, len(fs))
	for _, f := range fs {
		k := findingKey{subject: f.Subject, check: f.Check}
		idx[k] = append(idx[k], f)
	}
	return idx
}

// effectiveResult applies rule 1. A finding whose Result is not one of
// fail, warn, not-measured, pass or na counts as not-measured.
func effectiveResult(m *Model, k SubjectKey, c *Check, found []Finding, covers Covers) Result {
	worst := Result("")
	for _, f := range found {
		if f.Source != c.Source {
			continue
		}
		r := f.Result
		if _, known := rank[r]; !known {
			r = NotMeasured
		}
		if worst == "" || rank[r] < rank[worst] {
			worst = r
		}
	}
	switch {
	case covers != nil && covers(k, c.ID) == Waived:
		return Waived
	case m.exempts(k.Namespace, c.ID):
		return Exempt
	case worst == "":
		return NotMeasured
	}
	return worst
}

func (c *Counts) add(r Result) {
	switch r {
	case Pass:
		c.Pass++
	case Fail:
		c.Fail++
	case Warn:
		c.Warn++
	case NA:
		c.NA++
	case Waived:
		c.Waived++
	case Exempt:
		c.Exempt++
	default:
		c.NotMeasured++
	}
}

func (c *Counts) plus(o Counts) {
	c.Pass += o.Pass
	c.Fail += o.Fail
	c.Warn += o.Warn
	c.NA += o.NA
	c.Waived += o.Waived
	c.Exempt += o.Exempt
	c.NotMeasured += o.NotMeasured
}

// subjectResults returns the effective result of every check of the model,
// in the order of m.Checks, and their counts.
func subjectResults(m *Model, s Subject, idx map[findingKey][]Finding, covers Covers) ([]Result, Counts) {
	rs := make([]Result, len(m.Checks))
	var c Counts
	for i := range m.Checks {
		chk := &m.Checks[i]
		rs[i] = effectiveResult(m, s.Key, chk, idx[findingKey{subject: s.Key, check: chk.ID}], covers)
		c.add(rs[i])
	}
	return rs, c
}

// mandatoryCapApplies reports whether rule 2's cap applies to the subject.
func mandatoryCapApplies(m *Model, s Subject, rs []Result) bool {
	listed := false
	for _, t := range m.MandatoryCap.EnvironmentTypes {
		if t == s.EnvironmentType {
			listed = true
			break
		}
	}
	if !listed {
		return false
	}
	for i := range m.Checks {
		if m.Checks[i].Mandatory && rs[i] == Fail {
			return true
		}
	}
	return false
}

// weighted adds the weight of a result to num and den (rules 2 and 5).
func weighted(r Result, w int, num, den *int) {
	if w == 0 {
		return
	}
	switch r {
	case Pass:
		*num += w
		*den += w
	case Fail, Warn:
		*den += w
	}
}

// SubjectScore applies rules 1, 2 and 5 to one subject. covers may be nil.
func SubjectScore(m *Model, s Subject, fs []Finding, covers Covers) (score *int, capped bool, c Counts) {
	rs, counts := subjectResults(m, s, indexFindings(fs), covers)
	num, den := 0, 0
	for i := range m.Checks {
		weighted(rs[i], m.Checks[i].Weight, &num, &den)
	}
	if den == 0 {
		return nil, false, counts
	}
	v := 100 * num / den
	if !mandatoryCapApplies(m, s, rs) {
		return &v, false, counts
	}
	if v > m.MandatoryCap.Value {
		v = m.MandatoryCap.Value
	}
	return &v, true, counts
}

// ScopePosture applies rules 1 to 5 to the subjects of one scope. The caller
// passes the subjects that belong to the scope. For the workload scope with
// one subject, the mandatory cap of rule 2 also bounds Overall and sets
// Capped. covers may be nil. OldestInput and StaleProducers are left empty:
// the read model fills them.
func ScopePosture(m *Model, scope, id, cluster string, subjects []Subject, fs []Finding, covers Covers) Posture {
	p := Posture{Scope: scope, ID: id, Cluster: cluster, ModelVersion: m.Version}
	idx := indexFindings(fs)
	results := make([][]Result, len(subjects))
	for si, s := range subjects {
		var c Counts
		results[si], c = subjectResults(m, s, idx, covers)
		p.Counts.plus(c)
	}

	groupValues := map[string][]int{}
	for _, ax := range m.Axes {
		av := AxisValue{ID: ax.ID}
		if ax.Type != AxisTypeChecks {
			av.Reason = ax.NAText
			p.Axes = append(p.Axes, av)
			continue
		}
		lost := make([]int, len(m.Checks))
		for si := range subjects {
			num, den := 0, 0
			for ci := range m.Checks {
				chk := &m.Checks[ci]
				if chk.Axis != ax.ID {
					continue
				}
				r := results[si][ci]
				weighted(r, chk.Weight, &num, &den)
				if r == Fail || r == Warn {
					lost[ci] += chk.Weight
				}
			}
			av.Num += num
			av.Den += den
			if den > 0 {
				av.Subjects++
			} else {
				av.NotMeasured++
			}
		}
		for ci := range m.Checks {
			if lost[ci] > av.GapLost {
				av.Gap, av.GapLost = m.Checks[ci].ID, lost[ci]
			}
		}
		if av.Den == 0 {
			av.Reason = ax.NAText
		} else {
			v := 100 * av.Num / av.Den
			av.Value = &v
			av.Level = m.level(v)
			groupValues[ax.Group] = append(groupValues[ax.Group], v)
		}
		p.Axes = append(p.Axes, av)
	}

	sum, weights := 0.0, 0
	for _, g := range m.Groups {
		vals := groupValues[g.ID]
		if len(vals) == 0 {
			p.Partial = true
			continue
		}
		total := 0
		for _, v := range vals {
			total += v
		}
		sum += float64(g.Weight) * float64(total) / float64(len(vals))
		weights += g.Weight
	}
	if weights == 0 {
		return p
	}
	overall := int(math.Round(sum / float64(weights)))
	if scope == ScopeWorkload && len(subjects) == 1 && mandatoryCapApplies(m, subjects[0], results[0]) {
		if overall > m.MandatoryCap.Value {
			overall = m.MandatoryCap.Value
		}
		p.Capped = true
	}
	p.Overall = &overall
	p.Level = m.level(overall)
	return p
}

// next is a small deterministic generator for the property test: it
// advances the state x and returns a number in 0..n-1.
func next(x *int, n int) int {
	*x = (*x*1103515245 + 12345) & 0x7fffffff
	return (*x >> 16) % n
}

// raised reports whether after is a higher score than before.
func raised(before, after *int) bool {
	if after == nil {
		return false
	}
	return before == nil || *after > *before
}

// Property: replacing any pass by not-measured or na never raises a score.

	results := []Result{Pass, Fail, Warn, NA, NotMeasured, Waived, Exempt, Result("error")}
	sources := []Source{SourceKyverno, SourceEvaluator}
	namespaces := []string{"shop", "monitoring", "kube-system"}
	envTypes := []string{"prod", "dev", ""}
	seed := 20261113
	for round := 0; round < 3000; round++ {
		var subjects []Subject
		var fs []Finding
		for i, n := 0, 1+next(&seed, 3); i < n; i++ {
			s := subj(namespaces[next(&seed, len(namespaces))], fmt.Sprintf("w%d", i), envTypes[next(&seed, len(envTypes))])
			subjects = append(subjects, s)

				for j, k := 0, next(&seed, 3); j < k; j++ {
					fs = append(fs, find(s, c.ID, sources[next(&seed, len(sources))], results[next(&seed, len(results))]))
				}
			}
		}
		waivedCheck := m.Checks[next(&seed, len(m.Checks))].ID
		covers := func(_ SubjectKey, check string) Result {

				return Waived
			}
			return ""
