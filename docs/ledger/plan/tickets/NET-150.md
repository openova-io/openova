# NET-150 — Default-deny scaffolding and dial checks

## In plain words

**The problem today.** A Sovereign cannot put one platform namespace at a time under default deny. The policy chart only knows an all-or-nothing default deny for the whole cluster, which cut the console entry path when it was tried, and nothing in the acceptance suite dials a connection to prove that a policy denies or allows it.

**What changes.** A namespace is put under default deny by listing it in one chart value, with its own hand-written allow object, and the old cluster-wide default deny is deleted. A new gate check dials a table of connections from pods in every region and records whether each one was allowed or denied.

**Done means:**

- With its default values the policy chart still renders only the deny of the instance metadata address, so nothing changes on a running Sovereign.
- A namespace listed in the new chart value is under default deny: nothing enters its pods, and only cluster DNS leaves them.
- An allow object written for a namespace renders only while that namespace is listed, and the chart refuses a rule without a peer or a port, a port or port range that opens every port, every way of opening a namespace to the whole internet it knows, and a value that is not a list of namespace names.
- The three old default-deny objects and the values only they read are gone from the chart.
- The acceptance suite holds a dial table whose first rows say that the namespace default must not reach OpenBao, the Git service and the shared PostgreSQL, and a check that dials each row from a pod in every region and fails on a mismatch.
- That check runs in every cloud gate run as expected to fail, so its results are recorded and do not fail the run until the stores are under default deny.
- Tests fail when the chart, the helper, the table reader or the check break one of these rules.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The chart `bp-network-policies` (`platform/network-policies/chart`) can put platform namespaces under default deny one at a time. A namespace listed in the new value `enforcedNamespaces` is selected by the new object `baseline-default-deny`: nothing enters its pods and only DNS to the cluster resolver leaves them. What else it may send and receive is written by hand in its own allow file `templates/allow/<namespace>.yaml`, which the new helper `network-policies.allow` turns into the object `allow-<namespace>` only while the namespace is listed. The list is empty by default, so the default render is unchanged: the deny of the instance metadata address alone. The three legacy templates of the cluster-wide default deny, and the values only they read, are deleted. The acceptance suite gains the dial table `tests/acceptance/sovereign/policy-dials.yaml` and the check NET-G06 (`check_policy_dials.go`, step block POL), which dials every row of the table from a Pod in every region; its first three rows deny the namespace `default` OpenBao, the Git service and the shared PostgreSQL. This ticket sets NET-G06 to `expected-fail`, so the next cloud gate record carries the POL block with those three rows and a mismatch does not fail the run; NET-166 sets it to `required`. No namespace is put under default deny here.

## 3. The model (the law)
1. `values.yaml` holds two keys and no other: `enabled: true` and `enforcedNamespaces: []`. The keys `legacyBaseline`, `allowSystemNamespaces`, `allowEgressDNS`, `dnsNamespace` and `dnsServiceName` are deleted, with the templates `default-deny.yaml`, `allow-system-namespaces.yaml` and `allow-egress-dns.yaml` that read them.
2. `baseline-deny-metadata` and the helm test Pod render exactly as before.
3. `templates/baseline-default-deny.yaml` renders, when `enabled` is true and `enforcedNamespaces` is not empty, one `CiliumClusterwideNetworkPolicy` named `baseline-default-deny`: endpoint selector `io.kubernetes.pod.namespace In <enforcedNamespaces, in order>`, `ingress: [{}]` (no peer), and one egress rule to the pods of `kube-system` labelled `k8s-app: kube-dns` on port 53 over UDP and TCP with the DNS rule `matchPattern: "*"`. It stops the render when `enforcedNamespaces` is neither a list nor null (so `false`, `0`, `""` and a map stop it and never mean "no default deny"), holds an entry that is not an RFC 1123 label, or names a namespace twice.
4. An allow file `templates/allow/<ns>.yaml` defines the template `allow.<ns>.rules` (a map with the lists `ingress` and `egress`) and calls `{{- include "network-policies.allow" . }}`. The helper (`templates/allow/_helpers.tpl`) takes `<ns>` from the file name. It renders nothing unless `enabled` is true and `<ns>` is in `enforcedNamespaces`. Otherwise it renders one object `allow-<ns>` whose selector is `io.kubernetes.pod.namespace: <ns>` and `access.openova.io/session DoesNotExist` (session pods do not inherit the rules of their namespace), whose first ingress and first egress rule allow the namespace itself, followed by the rules of the file.
5. The helper stops the render, with a message that names the file and the rule, on: a key other than `ingress` and `egress`; in a rule, a key other than `toPorts` and the peer keys of its direction (ingress `fromEndpoints`, `fromEntities`, `fromCIDR`, `fromCIDRSet`; egress `toEndpoints`, `toEntities`, `toCIDR`, `toCIDRSet`, `toFQDNs`); a rule with no non-empty peer key; a rule without `toPorts` or without `ports`, or the port `0`; a port that is not a number from 1 to 65535 written in decimal without a leading zero (Cilium 1.19.3 reads a port with `strconv.ParseUint(port, 0, 16)`, so `"00"`, `"0000"` and `"0x0"` are the port 0, every port, and `"010"` is the port 8; a port name is refused too); a port range from the port `1` to an `endPort` of 65535 or more (every port); an endpoint selector without the label `io.kubernetes.pod.namespace` (in `matchLabels`, with or without the prefix `k8s:`, or a `matchExpressions` term with the operator `In`); an entity other than `ingress`, `kube-apiserver`, `host` and `remote-node` (so `world`, `world-ipv4`, `world-ipv6`, `all` and `cluster` are refused); a range in `fromCIDR`, `toCIDR`, `fromCIDRSet` or `toCIDRSet` wider than /8 (IPv4) or /16 (IPv6); a DNS name of `toFQDNs` with a wildcard other than one leading `*.` or `**.` before a name that holds a dot. An allow file whose name is not `<namespace>.yaml` with a namespace name stops the render too.
6. `templates/allow/_README.tpl` renders nothing and holds the rule template, the rules of an allow file and the standing rule: a change that adds a kit namespace, or a flow to an enforced namespace, carries its allow file, its entry in `enforcedNamespaces` for a new namespace, and one allow row and one deny row in `policy-dials.yaml`.
7. `tests/render.sh` judges rules R1 to R6 (header of the file): 28 broken rules each stop the render with their message, 7 valid rules render (an ordinary port and an ordinary port range among them), 8 wrong values stop the render, a file `net-yml.yml` stops it; and it proves with twenty-seven changed copies of the chart that each rule can fail. `tests/function-test-render.sh` runs its cases 2 and 4 with `enforcedNamespaces={default}` instead of the deleted legacy switch.
8. `policy-dials.yaml` is YAML in flow style that is JSON once its whole-line `#` comments are left out, with the schema `openova.io/policy-dials/v1` and the rows `default-to-openbao` (`openbao/openbao:8200`), `default-to-git` (`gitea/gitea-http:3000`) and `default-to-shared-postgres` (`shared-data/shared-pg-rw:5432`), each from the namespace `default` with no label and `expect: deny`.
9. `check_policy_dials.go` registers NET-G06 with `RegisterCheck` and edits no other suite file. In every region it starts one dial Pod per source (namespace and labels) with the image `secProbeImage` of `sec_probe.go`, on the Pod network, as user 65534, without a token; it dials each row with busybox `nc -z -vv -w 3` after a control dial to `kube-dns.kube-system.svc.cluster.local:53`; it deletes the Pods it created. A row passes when `allow` connects or `deny` times out. A refused or unresolved dial, or a control dial that does not connect, fails the row. A `deny` row to a Service first reads the EndpointSlices of the Service (`kubectl get`, read only) and fails when none of its endpoints is ready (an unset condition counts as ready), because a timeout would then prove nothing. A dial Pod sleeps 3600 seconds, the most it lives when the delete step never runs. The types and methods `DialSource`, `DialTarget`, `DialRow`, `ReadDialTable`, `Dialer` (`Start`, `Dial`, `ReadyEndpoints`, `Stop`, `Pods`) are exported for the checks of other areas.
10. `docs/ledger/gates.yaml`: NET-G06 moves from `not-built` to `expected-fail` and gains `implementation: tests/acceptance/sovereign/internal/suite/check_policy_dials.go`. No other line of the file changes.
11. Not done, by decision: no namespace in `enforcedNamespaces`, no allow file for a real namespace, no change to the kit slot, no generator, no edit of `runner.go` or `registry.go`.

+// ReadDialTable reads the dial table and checks every row. The file is YAML in
+// flow style that is JSON once its comment lines are left out: a line whose
+// first character other than a space is # is a comment.
+func ReadDialTable(data []byte) ([]DialRow, error) {
+	var kept bytes.Buffer
+	for _, line := range strings.Split(string(data), "\n") {
+		if !strings.HasPrefix(strings.TrimLeft(line, " \t"), "#") {
+			kept.WriteString(line + "\n")
+		}
+	}
+	dec := json.NewDecoder(&kept)
+	dec.DisallowUnknownFields()
+	var t struct {
+		Schema string    `json:"schema"`
+		Dials  []DialRow `json:"dials"`
+	}
+	if err := dec.Decode(&t); err != nil {
+		return nil, fmt.Errorf("the dial table is not JSON once its comment lines are left out: %v", err)
+	}
+	if dec.More() {
+		return nil, errors.New("the dial table holds more than one document")
+	}
+	if t.Schema != PolicyDialsSchema {
+		return nil, fmt.Errorf("the dial table has schema %q, want %q", t.Schema, PolicyDialsSchema)
+	}
+	if len(t.Dials) == 0 {
+		return nil, errors.New("the dial table has no row")
+	}
+	seen := map[string]bool{}
+	for i, r := range t.Dials {
+		if err := checkDialRow(r); err != nil {
+			return nil, fmt.Errorf("row %d (%q): %v", i+1, r.Name, err)
+		}
+		if seen[r.Name] {
+			return nil, fmt.Errorf("row %d: the name %q is used twice", i+1, r.Name)
+		}
+		seen[r.Name] = true
+	}
+	return t.Dials, nil
+}

+func checkDialRow(r DialRow) error {
+	switch {
+	case !dialNameRE.MatchString(r.Name):
+		return errors.New("the name is not a lower-case name of letters, digits and dashes")
+	case !dialNameRE.MatchString(r.From.Namespace):
+		return fmt.Errorf("from.namespace %q is not a namespace name", r.From.Namespace)
+	case r.Expect != "allow" && r.Expect != "deny":
+		return fmt.Errorf("expect is %q, want allow or deny", r.Expect)
+	case r.To.Port < 1 || r.To.Port > 65535:
+		return fmt.Errorf("to.port %d is not a port", r.To.Port)
+	}
+	for k, v := range r.From.Labels {
+		if k == DialLabel {
+			return fmt.Errorf("from.labels may not set %s, the label of the dial Pod", DialLabel)
+		}
+		name := k
+		if i := strings.LastIndex(k, "/"); i >= 0 {
+			name = k[i+1:]
+		}
+		if !labelPartRE.MatchString(name) || (v != "" && !labelPartRE.MatchString(v)) {
+			return fmt.Errorf("from.labels %q: %q is not a label", k, v)
+		}
+	}
+	byService := r.To.Namespace != "" || r.To.Service != ""
+	switch {
+	case byService && r.To.Address != "":
+		return errors.New("to names a Service and an address; name one")
+	case byService && (!dialNameRE.MatchString(r.To.Namespace) || !dialNameRE.MatchString(r.To.Service)):
+		return fmt.Errorf("to.namespace %q and to.service %q must both be names", r.To.Namespace, r.To.Service)
+	case !byService && net.ParseIP(r.To.Address) == nil:
+		return fmt.Errorf("to.address %q is not an IP address, and to names no Service", r.To.Address)
+	}
+	return nil

+		return fmt.Errorf("the dial Pod in %s did not connect to %s:%d (%s: %s): it has no working network, so the row was not measured",
+			r.From.Namespace, dialControlHost, dialControlPort, res.Control, res.ControlOutput)
+	}
+	switch {
+	case r.Expect == "allow" && res.Outcome == DialConnected, r.Expect == "deny" && res.Outcome == DialTimedOut:
+		return nil
+	case res.Outcome == DialRefused:
+		return fmt.Errorf("want %s; the dial of %s was refused: it reached the destination and no listener answered, so the row proves nothing", r.Expect, r.To)
+	case res.Outcome == DialUnresolved:
+		return fmt.Errorf("want %s; the name %s does not resolve", r.Expect, r.To.Host())
+	}
+	return fmt.Errorf("want %s; the dial of %s %s (%s)", r.Expect, r.To, res.Outcome, res.Output)

+func (c policyDialsCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
+	if cc.RepoRoot == "" {
+		return errors.New("the dial table is read from the checkout of --repo-root, and the run has none")
+	}
+	if len(cc.Regions) == 0 {
+		return errors.New("the run has no region")
+	}

+	if err != nil {
+		return err
+	}
+	rows, err := ReadDialTable(data)
+	if err != nil {
+		return fmt.Errorf("%s: %v", policyDialsTable, err)
+	}
+	sources := make([]DialSource, 0, len(rows))
+	for _, r := range rows {
+		sources = append(sources, r.From)
+	}
+	run := strings.ToLower(NewRunID(time.Now()))
+	n := 0
+	for _, region := range cc.Regions {
+		d := &Dialer{Kubectl: c.kubectl, Region: region, Run: run}
+		n++
+		started := checkStep(rec, policyDialsID, n, "POL: a dial Pod is Ready for every source of the dial table in region "+region.ID, func(ev Evidence) error {
+			err := d.Start(ctx, sources)
+			ev["block"], ev["region"], ev["rows"], ev["pods"] = "POL", region.ID, len(rows), d.Pods()
+			return err
+		})
+		for _, r := range rows {
+			if !started {
+				break // no row is dialed when a Pod is not Ready; the step above failed
+			}
+			n++
+			name := fmt.Sprintf("POL %s in region %s: %s to %s is %s", r.Name, region.ID, r.From.Namespace, r.To, r.Expect)
+			checkStep(rec, policyDialsID, n, name, func(ev Evidence) error {
+				ev["block"], ev["row"], ev["region"], ev["from"], ev["to"], ev["expect"] = "POL", r.Name, region.ID, r.From.key(), r.To.String(), r.Expect
+				if r.Expect == "deny" && r.To.Service != "" {
+					ready, err := d.ReadyEndpoints(ctx, r.To)
+					if err != nil {
+						return err
+					}
+					ev["ready_endpoints"] = ready
+					if ready == 0 {
+						return fmt.Errorf("the Service %s/%s has no ready endpoint: nothing listens, so a timeout would prove nothing", r.To.Namespace, r.To.Service)
+					}
+				}
+				res, err := d.Dial(ctx, r.From, r.To)
+				if err != nil {
+					return err
+				}
+				ev["control"], ev["observed"], ev["output"] = res.Control, res.Outcome, res.Output
+				return judgeDial(r, res)
+			})
+		}
+		if len(d.order) > 0 {
+			n++
+			checkStep(rec, policyDialsID, n, "POL: the dial Pods of region "+region.ID+" are deleted", func(ev Evidence) error {
+				ev["pods"] = d.Pods()
+				return d.Stop(ctx)
+			})
+		}
+	}
+	return nil
