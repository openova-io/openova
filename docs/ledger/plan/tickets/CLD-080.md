# CLD-080 — Contract directory: module contract, profile schema, pack schema, conventions, two profiles

## In plain words

**The problem today.** The rules that a cloud module must follow are written only as prose, and nothing checks them. What the platform knows about each cloud (its regions, machine sizes, credential fields, storage and limits) is spread over the console, the provisioning service and the modules. Other work cannot start against a cloud profile because no profile, no schema and no code to read one exist.

**What changes.** The contract of a cloud module and the schemas of the cloud profile and of the pack declaration are published as files. Each of the two clouds gets a profile and a pack declaration that a check validates on every pull request, and a Go package can load, merge and validate profiles. The Crossplane conventions are published as a contract document.

**Done means:**

- Each of the two clouds has a cloud profile and a pack declaration, and both are valid against their published schemas.
- A profile with an unknown or missing field, or with a value of one installation in it, turns the provider contract check red.
- An installation document that sets a field it may not set, or that leaves a cloud without a region, an image or a machine size, is refused with a named error.
- The module contract lists the 33 common variables, the 5 outputs, the 21 tolerated extras and the 14 template inputs.
- The Crossplane conventions are published beside the other contracts, and the contract index names the two schemas of the cloud profile.
- The gate list marks the provider contract check as built and expected to fail until the modules meet the contract.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The provider contract of the platform is a set of files that CI checks. `infra/providers/_contract/` holds the machine-readable module contract `contract.json` (33 common variables, 5 outputs, 21 engine extras, 14 template inputs), the JSON Schemas `cloudprofile.schema.json` and `pack.schema.json` (contract C2), two plan fixtures, the shared body of every module's `tests/contract.tftest.hcl`, and the list of generated files. The Go package `products/catalyst/bootstrap/api/internal/cloudprofile` loads the profiles and packs, validates them against the schemas, merges an installation document over a pack profile, and reports each fault as a typed error with the field path. `scripts/check-provider-contract.sh` runs that package's tests; the workflow `check-provider-contract` runs it and its self-test on every pull request. The Crossplane conventions are published as `docs/contracts/c6-crossplane-conventions.md`, and the contract index names the C2 schemas. ## 3. The model (the law)
1. The sixteen new files of field 5 are the result of the embedded patch `CLD-080.patch` and of nothing else. Work step 5 states the checksum of each.
2. `docs/ledger/gates.yaml` is changed by the command of work step 6 and by nothing else: two lines are added and one is removed. `docs/contracts/README.md` is changed by work steps 9, 10 and 11 and by nothing else: eight lines are added and four are removed.
3. A cloud profile is a data file, never a served resource. Its file header is `apiVersion: catalyst.openova.io/v1alpha1`, `kind: CloudProfile`. A pack declaration has the same `apiVersion` and `kind: ProviderPack`. The schema files are JSON Schema draft 2020-12 with `additionalProperties: false` on every object. The `$id` of each schema is a name, not an address: `urn:openova:catalyst:cloudprofile:v1alpha1` and `urn:openova:catalyst:providerpack:v1alpha1`.
4. A field is in the profile schema only when a work package reads it; the reader is named in the field's `description`. The names that other areas will add are reserved in the schema's `$comment` and are not in the schema. There is no `mesh` section, no `cost` section and no `bootstrapUnits` field. `spec.network.loadBalancer.mode` admits `external-hostport`; `controller` is a legacy value for the unproven second pack. `spec.seal` is optional until CLD-092 makes it required.
5. An installation document has the same kind, sets `spec.extends` to a pack name and may set only these fields below `spec`: `extends`, `lifecycle`, `api`, `regions`, `compute.image`, `compute.flavors`, `compute.defaults`, `network.apiCIDRs`, `registry`; and `metadata.name`. Maps merge; lists and scalars replace. The effective profile of a pack with `requiresInstallation: true` must have at least one region, an image and a flavor.
6. The errors of the Go package are `ErrUnknownField`, `ErrMissingField`, `ErrBadEnum`, `ErrBadValue`, `ErrNotInstallationField`, `ErrUnknownPack` and `ErrIncomplete`, each wrapped in a `*FieldError` that names the field path.
7. Neither pack's files hold a value of one installation: no endpoint domain, image identifier, zone, region, flavor or address range of a private installation. The Huawei pack profile has no region, no image and no flavor; an installation document kept outside the repository supplies them.
8. No new line counts under the guard `scripts/check-upstream-literals.sh`: a source address is an input of the Sovereign, never a literal in these files. Its baseline `scripts/upstream-literals-baseline.txt` is not raised.
9. Nothing is deleted.

+`infra/providers/_contract/cloudprofile.schema.json` and
+`infra/providers/_contract/pack.schema.json`. They stay under
+`infra/providers/` because the API image and the modules read them there.
+

+they have merged, the platform does not do what a line says.

+## Versions
+
+- Crossplane 2, the highest 2.4 patch (2.4.3 on 2026-11-12).
+- `provider-opentofu` v1.1.11.
+- Function `function-patch-and-transform`, the highest release on the day
+  CLD-065 runs, recorded in the slot file. No other function is used for
+  infrastructure.

+

+carries the label `compose.openova.io/workspace-class` with the value `base`

+|---|---|---|

+		return nil, err

+	names, err := packNames(dir)

+// Validate checks the document of p against the schema it was loaded with,
+// and checks that spec.regions is empty only when spec.requiresInstallation
+// is true.
+func Validate(p *Profile) error {
+	if p == nil || p.schema == nil || p.doc == nil {
+		return errors.New("cloudprofile: the profile was not read by Load or Merge")
+	}
+	if err := schemaError(p.schema.Validate(p.doc)); err != nil {
+		return err
+	}
+	var spec struct {
+		RequiresInstallation bool  `json:"requiresInstallation"`
+		Regions              []any `json:"regions"`
+	}
+	if err := fromDoc(p.doc["spec"].(map[string]any), &spec); err != nil {
+		return err
+	}
+	if !spec.RequiresInstallation && len(spec.Regions) == 0 {
+		return &FieldError{Err: ErrMissingField, Path: "spec.regions", Detail: "empty, and spec.requiresInstallation is not true"}
+	}
+	return nil
+}

+// validated checks doc against schema and returns it as a Profile.
+func validated(doc map[string]any, schema *jsonschema.Schema) (*Profile, error) {
+	p := &Profile{doc: doc, schema: schema}
+	if err := Validate(p); err != nil {
+		return nil, err
+	}
+	if err := fromDoc(doc, p); err != nil {
+		return nil, err
+	}
+	return p, nil
+}

+// Merge lays the installation document over the pack profile and returns
+// the effective profile: metadata.name is the installation's name and
+// spec.extends the pack's name. Maps merge; lists and scalars replace.
+func Merge(pack, installation *Profile) (*Profile, error) {
+	if pack == nil || pack.schema == nil || pack.doc == nil {
+		return nil, errors.New("cloudprofile: the pack profile was not read by Load")
+	}
+	if installation == nil || installation.doc == nil {
+		return nil, errors.New("cloudprofile: the installation document was not read by Parse")
+	}
+	if pack.Spec.Extends != "" {
+		return nil, &FieldError{Err: ErrBadValue, Path: "spec.extends", Detail: "the first argument is an installation, not a pack profile"}
+	}
+	if installation.APIVersion != APIVersion {
+		return nil, &FieldError{Err: ErrBadEnum, Path: "apiVersion", Detail: strconv.Quote(installation.APIVersion)}
+	}
+	if installation.Kind != ProfileKind {
+		return nil, &FieldError{Err: ErrBadEnum, Path: "kind", Detail: strconv.Quote(installation.Kind)}
+	}
+	if installation.Metadata.Name == "" {
+		return nil, &FieldError{Err: ErrMissingField, Path: "metadata.name"}
+	}
+	if installation.Spec.Extends == "" {
+		return nil, &FieldError{Err: ErrMissingField, Path: "spec.extends"}
+	}
+	if installation.Spec.Extends != pack.Metadata.Name {
+		return nil, &FieldError{Err: ErrUnknownPack, Path: "spec.extends", Detail: fmt.Sprintf("%q, the pack is %q", installation.Spec.Extends, pack.Metadata.Name)}
+	}
+	if err := checkInstallationFields(installation.doc); err != nil {
+		return nil, err
+	}
+	merged := deepCopy(pack.doc)
+	mergeInto(merged, installation.doc)
+	merged["metadata"] = map[string]any{"name": installation.Metadata.Name}
+	merged["spec"].(map[string]any)["extends"] = pack.Metadata.Name
+	eff, err := validated(merged, pack.schema)
+	if err != nil {
+		return nil, err
+	}
+	if eff.Spec.RequiresInstallation {
+		switch {
+		case len(eff.Spec.Regions) == 0:

+		case eff.Spec.Compute.Image == "":
+			return nil, &FieldError{Err: ErrIncomplete, Path: "spec.compute.image", Detail: "no image"}
+		case len(eff.Spec.Compute.Flavors) == 0:
+			return nil, &FieldError{Err: ErrIncomplete, Path: "spec.compute.flavors", Detail: "no flavor"}
+		}

+// checkInstallationFields refuses every field below spec that is not an
+// installation field, and every metadata field but name.
+func checkInstallationFields(doc map[string]any) error {
+	for _, k := range sortedKeys(doc) {
+		switch k {
+		case "apiVersion", "kind":
+		case "metadata":
+			m, ok := doc[k].(map[string]any)
+			if !ok {
+				return &FieldError{Err: ErrBadValue, Path: k, Detail: "not a mapping"}
+			}
+			for _, mk := range sortedKeys(m) {
+				if mk != "name" {
+					return &FieldError{Err: ErrNotInstallationField, Path: "metadata." + mk}
+				}
+			}
+		case "spec":
+			m, ok := doc[k].(map[string]any)
+			if !ok {
+				return &FieldError{Err: ErrBadValue, Path: k, Detail: "not a mapping"}
+			}
+			if err := walkInstallation("spec", m); err != nil {
+				return err
+			}
+		default:
+			return &FieldError{Err: ErrUnknownField, Path: k}
+		}
+	}
+	return nil
+}

+func walkInstallation(prefix string, m map[string]any) error {
+	for _, k := range sortedKeys(m) {
+		path := prefix + "." + k
+		if installationFields[path] {
+			continue
+		}
+		child, isMap := m[k].(map[string]any)
+		if isMap && hasInstallationFieldBelow(path) {
+			if err := walkInstallation(path, child); err != nil {
+				return err
+			}
+			continue
+		}
+		return &FieldError{Err: ErrNotInstallationField, Path: path}
+	}
+	return nil
+}

+func hasInstallationFieldBelow(path string) bool {
+	for f := range installationFields {
+		if strings.HasPrefix(f, path+".") {
+			return true
+		}
+	}
+	return false
+}

+func compileSchema(file string) (*jsonschema.Schema, error) {
+	data, err := os.ReadFile(filepath.Clean(file))
+	if err != nil {
+		return nil, err
+	}
+	c := jsonschema.NewCompiler()
+	c.Draft = jsonschema.Draft2020
+	url := "file:///" + filepath.Base(file)
+	if err := c.AddResource(url, bytes.NewReader(data)); err != nil {
+		return nil, fmt.Errorf("%s: %w", file, err)
+	}
+	s, err := c.Compile(url)
+	if err != nil {
+		return nil, fmt.Errorf("%s: %w", file, err)
+	}
+	return s, nil

+// decode turns YAML into the JSON value tree the schema validator reads.
+func decode(data []byte) (map[string]any, error) {
+	js, err := yaml.YAMLToJSON(data)
+	if err != nil {
+		return nil, &FieldError{Err: ErrBadValue, Path: "(document)", Detail: err.Error()}
+	}
+	dec := json.NewDecoder(bytes.NewReader(js))
+	dec.UseNumber()
+	var v any
+	if err := dec.Decode(&v); err != nil {
+		return nil, &FieldError{Err: ErrBadValue, Path: "(document)", Detail: err.Error()}
+	}
+	m, ok := v.(map[string]any)
+	if !ok {
+		return nil, &FieldError{Err: ErrBadValue, Path: "(document)", Detail: "not a mapping"}
+	}
+	return m, nil

+var quoted = regexp.MustCompile(`'([^']*)'`)

+// schemaError turns the first failing leaf of a validation error into a
+// *FieldError. Leaves are ordered by field path, then by keyword, so the
+// result does not depend on map order.
+func schemaError(err error) error {
+	if err == nil {
+		return nil
+	}
+	var ve *jsonschema.ValidationError
+	if !errors.As(err, &ve) {
+		return err
+	}
+	var leaves []*jsonschema.ValidationError
+	var walk func(*jsonschema.ValidationError)
+	walk = func(e *jsonschema.ValidationError) {
+		if len(e.Causes) == 0 {
+			leaves = append(leaves, e)
+			return
+		}
+		for _, c := range e.Causes {
+			walk(c)
+		}
+	}
+	walk(ve)
+	sort.SliceStable(leaves, func(i, j int) bool {
+		if leaves[i].InstanceLocation != leaves[j].InstanceLocation {
+			return leaves[i].InstanceLocation < leaves[j].InstanceLocation
+		}
+		return leaves[i].KeywordLocation < leaves[j].KeywordLocation
+	})
+	leaf := leaves[0]
+	path := fieldPath(leaf.InstanceLocation)
+	keyword := leaf.KeywordLocation[strings.LastIndex(leaf.KeywordLocation, "/")+1:]
+	switch keyword {
+	case "additionalProperties":
+		return &FieldError{Err: ErrUnknownField, Path: join(path, firstQuoted(leaf.Message)), Detail: leaf.Message}
+	case "required":
+		return &FieldError{Err: ErrMissingField, Path: join(path, firstQuoted(leaf.Message)), Detail: leaf.Message}
+	case "enum", "const":
+		return &FieldError{Err: ErrBadEnum, Path: path, Detail: leaf.Message}
+	default:
+		return &FieldError{Err: ErrBadValue, Path: path, Detail: leaf.Message}
+	}
+}
+
+func firstQuoted(s string) string {
+	if m := quoted.FindStringSubmatch(s); m != nil {
+		return m[1]
+	}
+	return ""
+}
+
+func join(path, name string) string {
+	switch {
+	case name == "":
+		return path
+	case path == "":
+		return name
+	}
+	return path + "." + name
+}
+
+// fieldPath turns the JSON pointer /spec/regions/0/code into spec.regions[0].code.
+func fieldPath(ptr string) string {
+	var b strings.Builder
+	for _, seg := range strings.Split(strings.TrimPrefix(ptr, "/"), "/") {
+		if seg == "" {
+			continue
+		}
+		seg = strings.ReplaceAll(strings.ReplaceAll(seg, "~1", "/"), "~0", "~")
+		if _, err := strconv.Atoi(seg); err == nil {
+			b.WriteString("[" + seg + "]")
+			continue
+		}
+		if b.Len() > 0 {
+			b.WriteString(".")
+		}
+		b.WriteString(seg)
+	}
+	return b.String()
+}
+
+func sortedKeys(m map[string]any) []string {
+	keys := make([]string, 0, len(m))
+	for k := range m {
+		keys = append(keys, k)
+	}
+	sort.Strings(keys)
+	return keys
+}
+
+func deepCopy(m map[string]any) map[string]any {
+	out := make(map[string]any, len(m))
+	for k, v := range m {
+		if child, ok := v.(map[string]any); ok {
+			out[k] = deepCopy(child)
+			continue
+		}
+		out[k] = v
+	}
+	return out
+}
+
+// mergeInto lays src over dst: maps merge, everything else replaces.
+func mergeInto(dst, src map[string]any) {
+	for k, v := range src {
+		sm, sIsMap := v.(map[string]any)
+		dm, dIsMap := dst[k].(map[string]any)
+		if sIsMap && dIsMap {
+			mergeInto(dm, sm)
+			continue
+		}
+		if sIsMap {
+			dst[k] = deepCopy(sm)
+			continue
+		}
+		dst[k] = v
+	}
+}
