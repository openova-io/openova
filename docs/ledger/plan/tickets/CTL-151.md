# CTL-151 — Intent-lock report and the check that the lock holds

## In plain words

**The problem today.** The intent lock is installed and only counts the writes that do not come from Git. Nobody can read that count: there is no report of how many such writes each group of kinds still receives, or which component makes them. The gate check that must prove that a group, once switched to refusing, really refuses has no code.

**What changes.** A script prints, for every group of kinds of the lock, how many objects there are, which components other than Flux still write their desired state, and how often the lock would have refused a request. The acceptance suite gets the check that the lock holds; it records that report from every region on every run, and fails until a group is switched to refusing and really refuses.

**Done means:**

- Running the report script against a cluster prints one JSON document with one entry per group of kinds of the lock.
- The report counts a refused request once, not twice.
- The report script proves on itself that each of its counting rules can fail.
- The gate check of the lock fails when no group of kinds refuses, or when a refusing group is still written by a component other than Flux.
- The gate check fails when a real create of a refusing kind is let through, or when the account of the API may still write that kind.
- The gate manifest lists the check of the lock as expected-fail, with its code file.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The intent lock of the platform chart (`products/catalyst/chart/templates/intent-lock/`, delivered by CTL-150) gets its burn-down report and its gate check. `scripts/intent-lock-report.py --kubeconfig <path>` reads one cluster with `kubectl` and prints one JSON document: per stage, its action, its kinds, the number of live objects, the managers other than Flux that own `spec` of those objects, and the audit count of its binding. The new gate check CTL-G04 (`tests/acceptance/sovereign/internal/suite/check_ctl_lock.go`) runs that script for every region and keeps each report as evidence of the run, which makes the report part of every gate record. It fails while no stage is at `deny`, so it is honest today. For a stage at `deny` it proves the lock with three facts: the stage is at zero in the report, a real create of a copy of a live object of each of its kinds is refused by the lock, and the service account of the API may not create, update, patch or delete those kinds. The manifest entry of CTL-G04 moves from `not-built` to `expected-fail`. CTL-178 later sets the first stage to `deny` and the check to `required`.

## 3. The model (the law)
1. A stage is a `ValidatingAdmissionPolicyBinding` whose `spec.policyName` is `catalyst-intent-lock`, named `catalyst-intent-lock-<stage>`. Its action is `deny` when `spec.validationActions` holds `Deny`, else `audit`. Its kinds are the `<resource>.<group>` pairs of `spec.matchResources.resourceRules`.
2. The report counts `nonFluxSpecManagers`: each entry of `metadata.managedFields` of a live object of the stage whose `fieldsV1` has the key `f:spec` and whose `manager` is neither `kustomize-controller` nor `helm-controller` adds one to that manager. An entry without `f:spec` (status, metadata) never counts.
3. The report's `auditCount` sums, over every endpoint of the Service `default/kubernetes`, the series of `apiserver_validating_admission_policy_check_total` with `policy="catalyst-intent-lock"`, the stage's `policy_binding` and `enforcement_action="audit"`. The series `warn` is never added: a binding in audit mode adds one to `audit` and one to `warn` for each request it would refuse (`docs/ledger/plan/spikes/CTL-050.md`, section S3). `auditCount` is `null` when no endpoint could be read, and the report says how many endpoints it read.
4. A kind that the cluster does not serve has no object. Any other failure to read stops the report with exit code 2: a report with zeros from an unread cluster is never printed.
5. A stage is at zero when `nonFluxSpecManagers` is empty and `auditCount` is `0` or `null`. The report judges nothing; the check judges.
6. The check counts nothing itself. It runs the script of the checkout at `--repo-root`; the script is the rule of the report.
7. The check fails when no stage is at `deny` in any region: a lock that refuses nothing does not hold.
8. A refusal is proven by a real create, never by a server-side dry run. The copy keeps `apiVersion`, `kind` and every top-level field of the live object except `metadata` and `status`; its name, and its namespace for a namespaced kind, is `ctl-lock-<run>`, a namespace the check creates. The check deletes a copy that the lock let through, and the namespace. The refusal must come from the lock: its error names `catalyst-intent-lock` and holds `is owned by Git`.
9. The service account of the API is the one of Deployment `catalyst-system/catalyst-api` in each region that runs it. `kubectl auth can-i` must answer `no` for `create`, `update`, `patch` and `delete` of every kind at `deny`.
10. The suite stays a module of the Go standard library only. The script uses the Python standard library only.
11. The manifest entry of CTL-G04 changes only in `state` and `implementation`.

"""The intent-lock report: per stage of the lock, what it would refuse.

  intent-lock-report.py --kubeconfig <path>    print the report of one cluster as JSON
  intent-lock-report.py --self-test            prove each counting rule; exit 0 or 1

A stage is a ValidatingAdmissionPolicyBinding of the policy catalyst-intent-lock,
named catalyst-intent-lock-<stage> (products/catalyst/chart/templates/intent-lock).
action: deny when its validationActions hold Deny, else audit. resources: the kinds
it matches, as <resource>.<group>. objects: the live objects of those kinds; a kind
the cluster does not serve has none. nonFluxSpecManagers: each managedFields entry
of such an object that has f:spec and whose manager is not kustomize-controller or
helm-controller adds one to that manager. auditCount: the sum, over every endpoint
of the Service default/kubernetes, of apiserver_validating_admission_policy_check_total
with this policy, the stage's binding and enforcement_action="audit". The "warn"
series is not counted: audit mode adds one to both for each request it would refuse
(docs/ledger/plan/spikes/CTL-050.md). auditCount is null when no endpoint could be
read; "endpoints" says how many were read. A stage is at zero when
nonFluxSpecManagers is empty and auditCount is 0 or null. The report judges
nothing; gate check CTL-G04 does. Exit code 2: the bindings, the endpoints or a
list of a served kind could not be read (the reason is on standard error).
"""
import json
import re
import subprocess
import sys

POLICY = "catalyst-intent-lock"
FLUX = ("kustomize-controller", "helm-controller")
METRIC = "apiserver_validating_admission_policy_check_total"
NOT_SERVED = "the server doesn't have a resource type"
SERIES = re.compile(r"^" + METRIC + r"\{(.*)\}\s+(\S+)\s*$")
LABEL = re.compile(r'(\w+)="((?:[^"\\]|\\.)*)"')


class Unreadable(Exception):
    pass


def get_json(kubectl, *args):
    code, out, err = kubectl(*args)
    if code != 0:
        raise Unreadable(f"kubectl {' '.join(args)}: {err.strip()}")
    return json.loads(out)


def audit_sums(page):
    """binding name -> the sum of the audit series of the policy in one metrics page."""
    sums = {}
    for line in page.splitlines():
        m = SERIES.match(line)
        labels = dict(LABEL.findall(m.group(1))) if m else {}
        if labels.get("policy") == POLICY and labels.get("enforcement_action") == "audit":
            sums[labels.get("policy_binding")] = sums.get(labels.get("policy_binding"), 0) + float(m.group(2))
    return sums


def build_report(kubectl):
    """kubectl(*args) returns (exit code, standard output, standard error)."""
    bindings = [b for b in get_json(kubectl, "get", "validatingadmissionpolicybindings", "-o", "json")["items"]
                if b["spec"].get("policyName") == POLICY]
    servers = []
    for subset in get_json(kubectl, "get", "endpoints", "kubernetes", "-n", "default", "-o", "json").get("subsets") or []:
        ports = subset.get("ports") or [{"port": 443}]
        port = next((p["port"] for p in ports if p.get("name") == "https"), ports[0]["port"])
        for a in subset.get("addresses") or []:
            servers.append(f"https://[{a['ip']}]:{port}" if ":" in a["ip"] else f"https://{a['ip']}:{port}")
    pages = []
    for server in servers:
        code, out, _ = kubectl("--server", server, "--tls-server-name", "kubernetes", "get", "--raw", "/metrics")
        if code == 0:
            pages.append(audit_sums(out))
    stages = []
    for b in sorted(bindings, key=lambda x: x["metadata"]["name"]):
        name = b["metadata"]["name"]
        kinds = sorted({r + "." + g if g else r for rule in b["spec"].get("matchResources", {}).get("resourceRules") or []
                        for g in rule.get("apiGroups") or [] for r in rule.get("resources") or []})
        objects, managers = 0, {}
        for kind in kinds:
            code, out, err = kubectl("get", kind, "-A", "-o", "json", "--show-managed-fields")
            if code != 0 and NOT_SERVED in err:
                continue
            if code != 0:
                raise Unreadable(f"kubectl get {kind}: {err.strip()}")
            for item in json.loads(out)["items"]:
                objects += 1
                for entry in item["metadata"].get("managedFields") or []:
                    if "f:spec" in (entry.get("fieldsV1") or {}) and entry.get("manager") not in FLUX:
                        managers[entry.get("manager")] = managers.get(entry.get("manager"), 0) + 1
        audit = sum(page.get(name, 0) for page in pages) if pages else None
        stages.append({"stage": name[len(POLICY) + 1:] if name.startswith(POLICY + "-") else name,
                       "action": "deny" if "Deny" in (b["spec"].get("validationActions") or []) else "audit",
                       "resources": kinds, "objects": objects, "nonFluxSpecManagers": managers,
                       "auditCount": None if audit is None else int(audit)})
    return {"policy": POLICY, "endpoints": {"total": len(servers), "read": len(pages)}, "stages": stages}

    print(f"SELF-TEST FAILED ({len(failed)} of {len(cases)} cases)" if failed else f"SELF-TEST OK ({len(cases)} cases)")
    return 1 if failed else 0

// Check CTL-G04, the lock holds. The check runs scripts/intent-lock-report.py
// of the checkout at RepoRoot for every region and keeps each report of the
// intent lock as evidence; the script is the rule of the report. A lock with no
// stage at deny refuses nothing, and the check fails. For each kind at deny:
//   - its stage is at zero: no manager but Flux owns spec of one of its
//     objects, and its audit count is 0 or null;
//   - in every region that serves it, the lock refuses a create of a copy of a
//     live object of it (a real create: a dry run is no proof). The copy and
//     its namespace are named ctl-lock-<run>; the check deletes both;
//   - in every region that runs Deployment catalyst-system/catalyst-api, its
//     service account may not create, update, patch or delete it.
const (
	ctlLockID      = "CTL-G04"
	ctlLockScript  = "scripts/intent-lock-report.py"
	ctlLockPolicy  = "catalyst-intent-lock"
	ctlLockRefusal = "is owned by Git" // a part of the message of the policy
)

type ctlLockCheck struct{ kubectl kubectlFunc }

func init() { RegisterCheck(ctlLockCheck{kubectl: kube.Region.Run}) }

func (ctlLockCheck) ID() string { return ctlLockID }

// lockStage is one stage of the report.
type lockStage struct {
	Stage     string          `json:"stage"`
	Action    string          `json:"action"`
	Resources []string        `json:"resources"`
	Managers  map[string]int  `json:"nonFluxSpecManagers"`
	Audit     json.RawMessage `json:"auditCount"` // a number, or null
}

// report runs the script for one region. raw is the whole report.
func (c ctlLockCheck) report(ctx context.Context, root string, region kube.Region) (raw any, stages []lockStage, err error) {
	cmd := exec.CommandContext(ctx, "python3")
	cmd.Args = append(cmd.Args, filepath.Join(root, filepath.FromSlash(ctlLockScript)), "--kubeconfig", region.Kubeconfig)
	var out, errb bytes.Buffer
	cmd.Stdout, cmd.Stderr = &out, &errb
	if err := cmd.Run(); err != nil {
		return nil, nil, fmt.Errorf("%s for region %s: %v: %s", ctlLockScript, region.ID, err, lastLine(errb.String()))
	}
	var rep struct {
		Stages []lockStage `json:"stages"`
	}
	if err = json.Unmarshal(out.Bytes(), &raw); err == nil {
		err = json.Unmarshal(out.Bytes(), &rep)
	}
	if err != nil {
		return nil, nil, fmt.Errorf("%s for region %s printed no report: %v", ctlLockScript, region.ID, err)
	}
	return raw, rep.Stages, nil
}

func (c ctlLockCheck) Run(ctx context.Context, cc *CheckContext, rec StepRecorder) error {
	stages := map[string][]lockStage{} // region id -> its report
	if !checkStep(rec, ctlLockID, 1, "the lock report of every region is read", func(ev Evidence) error {
		reports := Evidence{}
		ev["reports"] = reports
		for _, region := range cc.Regions {
			raw, s, err := c.report(ctx, cc.RepoRoot, region)
			if err != nil {
				return err
			}
			reports[region.ID], stages[region.ID] = raw, s
			if len(s) == 0 {
				return fmt.Errorf("region %s has no binding of the policy %s: the lock is not installed", region.ID, ctlLockPolicy)
			}
		}
		return nil
	}) {
		return nil
	}
	denied, kinds := map[string][]string{}, []string{} // region id -> its kinds at deny; every kind at deny
	if !checkStep(rec, ctlLockID, 2, "a stage is at deny, and every stage at deny is at zero", func(ev Evidence) error {
		faults := []string{}
		for _, region := range cc.Regions {
			for _, s := range stages[region.ID] {
				if s.Action != "deny" {
					continue
				}
				denied[region.ID], kinds = append(denied[region.ID], s.Resources...), append(kinds, s.Resources...)
				if audit := string(s.Audit); len(s.Managers) > 0 || (audit != "0" && audit != "null") {
					faults = append(faults, fmt.Sprintf("region %s, stage %s: managers other than Flux own spec %v, audit count %s",
						region.ID, s.Stage, s.Managers, audit))
				}
			}
		}
		slices.Sort(kinds)
		kinds = slices.Compact(kinds)
		ev["denied"] = kinds
		if len(kinds) == 0 {
			return errors.New("no stage is at deny in any region: the lock refuses nothing yet")
		}
		if len(faults) > 0 {
			return errors.New(strings.Join(faults, "; "))
		}
		return nil
	}) {
		return nil
	}
	checkStep(rec, ctlLockID, 3, "a create of each kind at deny is refused by the lock", func(ev Evidence) error {
		return c.probeCreates(ctx, cc.Regions, denied, kinds, ev)
	})
	checkStep(rec, ctlLockID, 4, "the account of the API may not write a kind at deny", func(ev Evidence) error {
		return c.askAPIAccount(ctx, cc.Regions, denied, ev)
	})
	return nil
}

// probeCreates tries, in every region that serves a kind at deny, to create a
// copy of a live object of it, taken from the first region that has one.
func (c ctlLockCheck) probeCreates(ctx context.Context, regions []kube.Region, denied map[string][]string, kinds []string, ev Evidence) error {
	name := "ctl-lock-" + strings.ToLower(NewRunID(time.Now()))
	sources, serving := map[string]kube.Object{}, map[string][]kube.Region{}
	for _, region := range regions {
		for _, kind := range denied[region.ID] {
			out, err := c.kubectl(region, ctx, nil, "get", kind, "-A", "-o", "json")
			if err != nil && strings.Contains(err.Error(), notServed) {
				continue
			}
			var list kube.List
			if err == nil {
				err = json.Unmarshal(out, &list)
			}
			if err != nil {
				return fmt.Errorf("read %s in region %s: %w", kind, region.ID, err)
			}
			serving[kind] = append(serving[kind], region)
			if _, ok := sources[kind]; !ok && len(list.Items) > 0 {
				sources[kind] = list.Items[0]
			}
		}
	}
	cleanup, cancel := context.WithTimeout(context.WithoutCancel(ctx), time.Minute)
	defer cancel()
	refused, faults, made := []string{}, []string{}, map[string]kube.Region{}
	defer func() {
		for _, region := range made {
			_, _ = c.kubectl(region, cleanup, nil, "delete", "namespace", name, "--wait=false", "--ignore-not-found")
		}
	}()
	for _, kind := range kinds {
		source, ok := sources[kind]
		if !ok {
			faults = append(faults, "no region that serves "+kind+" at deny has an object of it to copy: no refusal can be shown")
			continue
		}
		body, meta, del := map[string]any{}, map[string]any{"name": name}, []string{"delete", kind, name, "--wait=false", "--ignore-not-found"}
		for k, v := range source {
			if k != "metadata" && k != "status" {
				body[k] = v
			}
		}
		if source.Namespace() != "" {
			meta["namespace"], del = name, append(del, "-n", name)
		}
		body["metadata"] = meta
		manifest, err := json.Marshal(body)
		if err != nil {
			return err
		}
		for _, region := range serving[kind] {
			if _, done := made[region.ID]; source.Namespace() != "" && !done {
				if _, err := c.kubectl(region, ctx, nil, "create", "namespace", name); err != nil {
					return err
				}
				made[region.ID] = region
			}
			at := kind + " in region " + region.ID
			_, err := c.kubectl(region, ctx, bytes.NewReader(manifest), "create", "-f", "-")
			switch {
			case err == nil:
				_, _ = c.kubectl(region, cleanup, nil, del...)
				faults = append(faults, at+": the copy was created; the lock did not refuse it")
			case strings.Contains(err.Error(), ctlLockPolicy) && strings.Contains(err.Error(), ctlLockRefusal):
				refused = append(refused, at)
			default:
				faults = append(faults, at+": the create failed, but not by the lock: "+err.Error())
			}
		}
	}
	ev["copy"], ev["refused"] = name, refused
	if len(faults) > 0 {
		return errors.New(strings.Join(faults, "; "))
	}
	return nil
}

// askAPIAccount asks, in every region that runs the API, whether its service
// account may write a kind at deny there.
func (c ctlLockCheck) askAPIAccount(ctx context.Context, regions []kube.Region, denied map[string][]string, ev Evidence) error {
	asked, faults := []string{}, []string{}
	for _, region := range regions {
		out, err := c.kubectl(region, ctx, nil, "get", "deployment", "catalyst-api", "-n", "catalyst-system", "-o", "json")
		if err != nil && strings.Contains(err.Error(), "NotFound") {
			continue
		}
		var api kube.Object
		if err == nil {
			err = json.Unmarshal(out, &api)
		}
		if err != nil {
			return fmt.Errorf("read Deployment catalyst-system/catalyst-api in region %s: %w", region.ID, err)
		}
		user := "system:serviceaccount:catalyst-system:" + cmp.Or(api.Str("spec", "template", "spec", "serviceAccountName"), "default")
		asked = append(asked, region.ID+": "+user)
		for _, kind := range denied[region.ID] {
			for _, verb := range []string{"create", "update", "patch", "delete"} {
				out, err := c.kubectl(region, ctx, nil, "auth", "can-i", verb, kind, "--all-namespaces", "--as", user)
				switch answer := strings.TrimSpace(string(out)); answer {
				case "no":
				case "yes":
					faults = append(faults, fmt.Sprintf("region %s: %s may %s %s", region.ID, user, verb, kind))
				default:
					return fmt.Errorf("region %s: kubectl auth can-i %s %s answered %q: %v", region.ID, verb, kind, answer, err)
				}
			}
		}
	}
	ev["asked"] = asked
	if len(asked) == 0 {
		return errors.New("no region runs Deployment catalyst-system/catalyst-api: the account of the API was not found")
	}
	if len(faults) > 0 {
		return errors.New(strings.Join(faults, "; "))
	}
	return nil
}
