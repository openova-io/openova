# SEC-100 — Delete the abandoned OpenBao multi-region mechanisms

## In plain words

**The problem today.** The OpenBao chart carries three half-built ways to make OpenBao span two regions: a stretched raft join that no OpenBao server reads, a snapshot copy that the second region fetches and never restores, and a failover resource for OpenBao. The kit slot turns all three on for a Sovereign with a hot standby. They suggest a replication that does not exist, and they sit beside the one mechanism that does work between regions, peer push.

**What changes.** The three mechanisms are deleted: their templates, their values, their render tests and their settings in the kit slot. Peer push stays exactly as it is, and the chart's README and the security document no longer describe the snapshot copy.

**Done means:**

- The OpenBao chart has no template, value or test of the stretched raft join, the snapshot copy or the OpenBao Continuum resource.
- The kit slot of OpenBao no longer sets those values, and still sets the peer push values.
- The default render of the OpenBao chart is the same as before.
- The render tests of peer push and of the declarative OpenBao configuration still pass, and the configuration no longer gains a snapshot policy or role when the old switch is set.
- The generated table of kit slots shows no switch for the OpenBao slot, and the list of deleted paths names the seven deleted files.
- The chart's README and the security document no longer describe a snapshot copy between regions.

The rest of this ticket is the exact instruction for the model that does the work.

def apply(text, edit):
    """Return (new text, None) or (None, reason)."""
    kind = edit[1]
    if kind == "text":
        old, new = edit[2], edit[3]
        n = text.count(old)
        if n != 1:
            return None, "the old text occurs %d times, not once" % n
        return text.replace(old, new), None
    first, last, count, new = edit[2], edit[3], edit[4], edit[5]
    rows = text.split("\n")
    hits = [i for i, r in enumerate(rows) if r == first]
    if len(hits) != 1:
        return None, "the first line occurs %d times, not once" % len(hits)
    start = hits[0]
    ends = [i for i in range(start, len(rows)) if rows[i] == last]
    if not ends:
        return None, "the last line does not occur at or after the first line"
    if ends[0] - start + 1 != count:
        return None, "the block holds %d lines, not %d" % (ends[0] - start + 1, count)
    rows[start:ends[0] + 1] = new
    return "\n".join(rows), None
