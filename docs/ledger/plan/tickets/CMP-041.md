# CMP-041 — ComplianceModel: definition, data files, chart template, exemptions, guard

## In plain words

**The problem today.** The compliance plane scores every cluster against a catalogue of checks, but the catalogue, its weights and the reasons why some namespaces are exempt from a policy exist nowhere as data. A policy can be added with no check that scores it, and a namespace can be exempted from a policy with no recorded reason.

**What changes.** The policy chart ships the definition of the compliance model and renders its one object from data files in the chart; a namespace exempted with no reason fails the render. A guard on every pull request keeps the data files, the policies and their tests in agreement, and the lists of policies without a test and of exempt namespaces may only shrink.

**Done means:**

- The policy chart renders one compliance model object, named default, that holds the ten axes and the 22 checks of its data files.
- A namespace added to an exclude list of a policy without a reason in the data files fails the render of the chart.
- A pull request that adds a policy with no check, a check with no policy, or a new exempt namespace turns the tree guards red.
- The tests of the guard show that each of its rules can fail.
- The inventory of custom resources lists the new kind.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
After this ticket the policy chart `platform/kyverno-policies/chart` (Blueprint `bp-kyverno-policies`) carries the definition of the cluster-scoped kind `ComplianceModel` (group `compliance.openova.io`, version `v1alpha1`) in its new `crds/` folder, three data files with their JSON Schemas under `model/`, and the template `templates/compliance-model.yaml`, which renders the one object `default` of the cluster: the score model of `model/model.yaml` (ten axes), the 22 checks of `model/checks.yaml`, and one exemption for each of the 20 namespaces that an exclude list of `values.yaml` names, with the reason and owner of `model/exemptions.yaml`. A namespace in an exclude list with no reason fails the render. The chart test `model-render.sh` proves the render and is run by the policy chart's runner. The guard `tools/guards/cmd/check-compliance-model` runs in the workflow `tree-guards` on every pull request and holds the data files, the policy templates, their suites and the exempt namespaces together; two baselines under `scripts/baselines/` let the checks without a suite and the exempt namespaces only fall. No code of catalyst-api changes: the per-cluster loader that reads the object, and check CMP-G03, are CMP-042.

## 3. The model (the law)
1. **One kind, in its Blueprint.** `ComplianceModel`, group `compliance.openova.io`, version `v1alpha1` (served, storage), scope `Cluster`, plural `compliancemodels` (decision record 0029, K3). Its definition is `platform/kyverno-policies/chart/crds/compliancemodel.yaml` and nowhere else; no file under `products/catalyst/chart/crds/` defines it. Kit slot 27a creates it on install and replaces it on upgrade (`install.crds` and `upgrade.crds` `CreateReplace`, already on `main`), so an existing Sovereign receives it with the chart's next release.
2. **The data files.** `model/model.yaml` holds `version`, `levels`, `mandatoryCap`, `severityWeights`, `groups` and the ten `axes`; `model/checks.yaml` holds the list `checks` (22 entries, each of source `kyverno`); `model/exemptions.yaml` holds the map `namespaces`, a `reason` and an `owner` for each of the 20 exempt namespaces. Each file `model/<name>.yaml` has the schema `model/schema/<name>.schema.json`.
3. **One object.** `templates/compliance-model.yaml` renders exactly one document: `apiVersion: compliance.openova.io/v1alpha1`, `kind: ComplianceModel`, `metadata.name: default`. `spec` is `model/model.yaml` verbatim, plus `checks` (the list of `model/checks.yaml` verbatim and in its order) and `exemptions`: for every namespace of an `excludeNamespaces` or `extraExcludeNamespaces` list of a block under `compliancePolicies` in `values.yaml`, one entry with that namespace, the checks whose lists hold it (in the order of `checks.yaml`), and its reason and owner; entries sorted by namespace. A missing or unparsable data file fails the render, and so does a listed namespace with no reason: `exemption <namespace> has no reason`. The object is release content: no value changes a weight.
4. **The chart test.** `platform/kyverno-policies/chart/tests/model-render.sh` asserts points 3 on the chart (one document; 22 checks verbatim; the rest of `spec` verbatim; the 20 namespaces with their reasons; a namespace with a reason joins a check's exemption; a namespace with no reason fails the render), and runs each assertion again on a copy of the chart with one defect and fails unless every copy fails. `scripts/run-policy-chart-tests.sh` lists it last in `SHELL_TESTS`; the workflow `Chart tests (PR)` runs it with the chart directory as its argument under the release's yq v4.44.3.
5. **The guard.** `tools/guards/cmd/check-compliance-model` (Go, no new Python) checks seven rules, each shown to fail by its tests: M1 each data file is valid against its schema (a schema keyword the validator does not implement is an error); M2 the model's references resolve and its ids are unique; M3 every validating policy template of the policy chart and of `platform/crossplane-claims/chart/templates/policies/` has a check of its name, and every `kyverno` check one template; M4 a check's `valuesKey` is the values block its own template reads; M5 every `kyverno` check has a suite `tests/<id>/kyverno-test.yaml` or is listed in `scripts/baselines/policy-suites.json`; M6 the exempt namespaces of `values.yaml` are those of `scripts/baselines/policy-exemptions.json` and of `model/exemptions.yaml`; M7 `ComplianceModel` and `ComplianceDecision` are defined only in group `compliance.openova.io` under `platform/kyverno-policies/chart/crds/`. It reads YAML with yq (mikefarah, v4) and reads no code of catalyst-api. `.github/workflows/tree-guards.yaml` runs its tests and then the guard, after the step `compliance-live-reads`; `tools/guards/README.md` has its row.
6. **The baselines only fall.** `scripts/baselines/policy-suites.json` (metric `policy_checks_without_suite`, 21 checks) and `scripts/baselines/policy-exemptions.json` (metric `policy_exempt_namespaces`, 20 namespaces) have the schema `openova.io/guard-baseline/v1`. A new entry is a finding of the guard; so is an entry that no longer applies.
7. **The inventory.** `docs/generated/custom-resources.md` gains the row that `scripts/generators/custom-resources.py` writes. Its column "Named in Go code" is `no`: no Go code of the tree names `compliancemodels` until CMP-042 adds the informer, and CMP-042 then regenerates the row.
8. **Nothing else moves.** No code of catalyst-api, no role, no gate check and no `values.yaml` changes. The loader `LoadModel` of CMP-030 (`products/catalyst/bootstrap/api/internal/compliance/model.go`) already accepts this apiVersion and kind; CMP-042 connects it to the object of each cluster.

+# model-render.sh - the ComplianceModel object of the policy chart (CMP-041).
+#
+# templates/compliance-model.yaml renders one object of kind ComplianceModel
+# from model/model.yaml, model/checks.yaml and model/exemptions.yaml. This test
+# renders it and asserts, on the chart:
+#
+#   1  the template renders exactly one document: apiVersion
+#      compliance.openova.io/v1alpha1, kind ComplianceModel, name default;
+#   2  spec.checks holds 22 checks, the list of model/checks.yaml verbatim and
+#      in its order; every other field of spec but exemptions is
+#      model/model.yaml verbatim;
+#   3  spec.exemptions names the 20 exempt namespaces of values.yaml, each with
+#      the reason and owner of model/exemptions.yaml; kube-system is exempt
+#      from the 18 checks whose values block carries the shared exclude list,
+#      cnpg from flux-managed alone and trivy-system from flux-managed and
+#      harbor-proxy-pull;
+#   4  a namespace with a reason added to an exclude list joins the exemption
+#      of that check (cnpg with --set ...forbidNodePortService.excludeNamespaces);
+#   5  a namespace with no reason in model/exemptions.yaml added to any exclude
+#      list (excludeNamespaces or extraExcludeNamespaces, of a check or of a
+#      policy that has none) fails the render with
+#      "exemption <namespace> has no reason".
+#
+# Then it shows that each assertion can fail: it runs them again on copies of
+# the chart with one defect each (a check removed, a second document, the
+# model's name changed, a reason removed, the reason rule removed, the
+# extraExcludeNamespaces join removed) and fails unless every copy fails.
+#
+# Usage:
+#   bash model-render.sh            the chart above this file
+#   bash model-render.sh <chart>    that chart directory (Chart tests (PR) passes it)

+# and yq (mikefarah v4). Exit code: 0 pass. 1 an assertion failed. 2 wrong usage.
+set -euo pipefail

+  echo "usage: bash model-render.sh [<chart directory>]" >&2
+  exit 2
+fi
+CHART="${1:-$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)}"
+HELM="${HELM_BIN:-helm}"
+TAG="[model-render]"
+TEMPLATE="templates/compliance-model.yaml"

+trap 'rm -rf "$WORK"' EXIT

+# expect <label> <got> <want>
+expect() {
+  if [ "$2" = "$3" ]; then
+    echo "$TAG PASS $1"
+  else
+    fail "$1: got '$2', want '$3'"
+  fi
+}

+# render <chart> <out> [helm arguments...]: renders the model template.
+render() {
+  local chart="$1" out="$2"

+# exemption <render> <namespace>: the checks of the namespace's exemption, comma-separated.

+// stripComments drops Helm comments and YAML comment lines.
+func stripComments(text string) string {
+	text = helmComment.ReplaceAllString(text, "")
+	var keep []string
+	for _, line := range strings.Split(text, "\n") {
+		if strings.HasPrefix(strings.TrimSpace(line), "#") {
+			continue
+		}
+		keep = append(keep, line)
+	}
+	return strings.Join(keep, "\n")
+}

+// readPolicies returns every validating policy document of the template files (M3). A
+// document whose name is not literal is returned with the name "<not literal: ...>",
+// which no check carries.
+func readPolicies(t tree) ([]policyTemplate, error) {
+	var out []policyTemplate
+	for _, dir := range []string{Templates, ClaimsPolicies} {
+		err := filepath.WalkDir(filepath.Join(t.root, dir), func(p string, d os.DirEntry, err error) error {
+			if err != nil {
+				return err
+			}
+			if d.IsDir() || (!strings.HasSuffix(p, ".yaml") && !strings.HasSuffix(p, ".yml")) {
+				return nil
+			}
+			b, err := os.ReadFile(p) // #nosec G304 -- a file of the tree under judgement
+			if err != nil {
+				return err
+			}
+			rel, _ := filepath.Rel(t.root, p)
+			rel = filepath.ToSlash(rel)
+			for _, doc := range docSplit.Split(stripComments(string(b)), -1) {
+				k := policyKind.FindStringSubmatch(doc)
+				if k == nil || (k[1] == "ClusterPolicy" && !validates.MatchString(doc)) {
+					continue
+				}
+				name := ""
+				if m := metaName.FindStringSubmatch(doc); m != nil {
+					name = strings.Trim(m[1], `"'`)
+				}
+				if name == "" || strings.Contains(name, "{{") {
+					name = "<not literal: " + strings.TrimSpace(name) + ">"
+				}
+				out = append(out, policyTemplate{file: rel, name: name, text: doc, inChart: dir == Templates})
+			}
+			return nil
+		})
+		if err != nil {
+			return nil, fmt.Errorf("%s cannot be read: %v", dir, err)
+		}
+	}
+	return out, nil
+}

+// readBaseline reads the names of one baseline file.
+func readBaseline(t tree, rel, metric string) (map[string]bool, error) {
+	b, err := t.read(rel)
+	if err != nil {
+		return nil, fmt.Errorf("%s cannot be read: %v", rel, err)
+	}
+	var doc struct {
+		Schema string                    `json:"schema"`
+		Counts map[string]map[string]int `json:"counts"`
+		Allow  []any                     `json:"allow"`
+	}
+	dec := json.NewDecoder(bytes.NewReader(b))
+	dec.DisallowUnknownFields()
+	if err := dec.Decode(&doc); err != nil {
+		return nil, fmt.Errorf("%s is not a baseline: %v", rel, err)
+	}
+	entries, ok := doc.Counts[metric]
+	if doc.Schema != BaselineSchema || !ok || len(doc.Counts) != 1 || doc.Allow == nil || len(doc.Allow) != 0 {
+		return nil, fmt.Errorf("%s must be {\"schema\": %q, \"counts\": {%q: {...}}, \"allow\": []}", rel, BaselineSchema, metric)
+	}
+	out := map[string]bool{}
+	for name, n := range entries {
+		if n != 1 {
+			return nil, fmt.Errorf("%s: the entry %s is %d, every entry is 1", rel, name, n)
+		}
+		out[name] = true
+	}
+	return out, nil
+}

+// checkExemptions applies M6 and returns the number of exempt namespaces.
+func checkExemptions(t tree, blocks map[string]map[string]any, reasonsDoc any, add func(string, string, ...any)) (int, error) {
+	exempt := map[string]bool{}

+		for _, key := range []string{"excludeNamespaces", "extraExcludeNamespaces"} {
+			list, present := b[key]
+			if !present {
+				continue
+			}
+			names, isList := list.([]any)
+			if !isList && list != nil {
+				return 0, fmt.Errorf("%s: a %s value is not a list", Values, key)
+			}
+			for _, n := range names {
+				s, isStr := n.(string)
+				if !isStr {
+					return 0, fmt.Errorf("%s: a %s entry is not a string", Values, key)
+				}
+				exempt[s] = true
+			}
+		}
+	}
+	allowed, err := readBaseline(t, ExemptBaseline, ExemptMetric)
+	if err != nil {
+		return 0, err
+	}
+	m, _ := reasonsDoc.(map[string]any)
+	reasons, _ := m["namespaces"].(map[string]any)
+	for _, ns := range sortedKeys(exempt) {
+		if !allowed[ns] {
+			add("M6", "the namespace %s is exempt in %s and not in %s: the set of exempt namespaces may only shrink", ns, Values, ExemptBaseline)
+		}
+		if _, ok := reasons[ns]; !ok {
+			add("M6", "the exempt namespace %s has no reason in %s/exemptions.yaml", ns, ModelDir)
+		}
+	}
+	for _, ns := range sortedKeys(allowed) {
+		if !exempt[ns] {
+			add("M6", "%s lists %s, which no exclude list of %s holds any more: remove the entry", ExemptBaseline, ns, Values)
+		}
+	}
+	for _, ns := range sortedKeys(reasons) {
+		if !exempt[ns] {
+			add("M6", "%s/exemptions.yaml gives a reason for %s, which no exclude list of %s holds: remove it", ModelDir, ns, Values)
+		}
+	}
+	return len(exempt), nil

+var (

+	namesKind  = regexp.MustCompile(`(?m)^[ \t]+kind:[ \t]*["']?(\w+)["']?[ \t]*$`)
+	groupLine  = regexp.MustCompile(`(?m)^  group:[ \t]*["']?([\w.-]+)["']?[ \t]*$`)
+	moduleLine = regexp.MustCompile(`(?m)^[ \t]*kind:[ \t]*["']?(ComplianceModel|ComplianceDecision)["']?[ \t]*$`)

+// checkModuleKinds applies M7 and returns the number of module definitions found.
+func checkModuleKinds(t tree, add func(string, string, ...any)) (int, error) {
+	files, err := t.files()
+	if err != nil {
+		return 0, err
+	}
+	found := 0
+	for _, f := range files {
+		if !strings.HasSuffix(f, ".yaml") && !strings.HasSuffix(f, ".yml") {
+			continue
+		}
+		b, err := t.read(f)
+		if err != nil {
+			return 0, fmt.Errorf("%s cannot be read: %v", f, err)
+		}
+		text := string(b)
+		if strings.HasPrefix(f, PlatformCRDs+"/") && moduleLine.MatchString(stripComments(text)) {
+			add("M7", "%s defines a module kind of the policy Blueprint (%s): it belongs in %s", f, moduleLine.FindStringSubmatch(stripComments(text))[1], ModuleCRDs)
+		}
+		if !strings.Contains(text, "CustomResourceDefinition") {
+			continue
+		}
+		for _, doc := range docSplit.Split(stripComments(text), -1) {
+			if !crdKind.MatchString(doc) {
+				continue
+			}
+			for _, k := range namesKind.FindAllStringSubmatch(doc, -1) {
+				if !isModuleKind(k[1]) {
+					continue
+				}
+				found++
+				group := ""
+				if g := groupLine.FindStringSubmatch(doc); g != nil {
+					group = g[1]
+				}
+				if group != ModuleGroup {
+					add("M7", "%s defines %s in group %q, want %s", f, k[1], group, ModuleGroup)
+				}
+				if !strings.HasPrefix(f, ModuleCRDs+"/") {
+					add("M7", "%s defines %s outside %s", f, k[1], ModuleCRDs)
+				}
+			}
+		}
+	}
+	return found, nil
+}
+
+func isModuleKind(k string) bool {
+	for _, m := range moduleKinds {
+		if k == m {
+			return true
+		}
+	}
+	return false
+}

+func sortedKeys[V any](m map[string]V) []string {
+	out := make([]string, 0, len(m))
+	for k := range m {
+		out = append(out, k)
+	}
+	sort.Strings(out)
+	return out
+}

+// The JSON Schema keywords this validator implements (draft 2020-12, the subset the
+// schemas of the policy chart's model files use). A schema that uses any other keyword
+// is refused: a keyword the validator does not know would otherwise hold nothing.
+var knownKeywords = map[string]bool{
+	"$schema": true, "$id": true, "title": true, "description": true, "$defs": true, "$ref": true,
+	"type": true, "enum": true, "const": true,
+	"properties": true, "required": true, "additionalProperties": true, "propertyNames": true,
+	"items": true, "minItems": true, "maxItems": true, "uniqueItems": true,
+	"minLength": true, "maxLength": true, "pattern": true,
+	"minimum": true, "maximum": true,
+	"if": true, "then": true, "else": true, "not": true, "allOf": true,
+}
+
+// validator checks one document against one schema. root is the whole schema, for $ref.
+type validator struct {
+	root map[string]any
+}
+
+// Validate returns one line per place where doc breaks schema, in a fixed order, and an
+// error when the schema itself cannot be applied (an unknown keyword, a $ref that does
+// not resolve, a keyword of the wrong type).
+func Validate(schema map[string]any, doc any) ([]string, error) {
+	v := validator{root: schema}
+	var out []string
+	if err := v.check(schema, doc, "$", &out); err != nil {
+		return nil, err
+	}
+	sort.Strings(out)
+	return out, nil
+}

+func (v validator) resolve(ref string) (map[string]any, error) {
+	const prefix = "#/$defs/"
+	if !strings.HasPrefix(ref, prefix) {
+		return nil, fmt.Errorf("$ref %q: only #/$defs/<name> is supported", ref)
+	}
+	defs, _ := v.root["$defs"].(map[string]any)
+	s, ok := defs[strings.TrimPrefix(ref, prefix)].(map[string]any)
+	if !ok {
+		return nil, fmt.Errorf("$ref %q does not resolve", ref)
+	}
+	return s, nil
+}

+func typeName(x any) string {
+	switch t := x.(type) {
+	case nil:
+		return "null"
+	case bool:
+		return "boolean"
+	case string:
+		return "string"
+	case float64:
+		if t == math.Trunc(t) {
+			return "integer"
+		}
+		return "number"
+	case []any:
+		return "array"
+	case map[string]any:
+		return "object"
+	}
+	return fmt.Sprintf("%T", x)
+}

+func number(s map[string]any, key string) (float64, bool, error) {
+	x, ok := s[key]
+	if !ok {
+		return 0, false, nil
+	}
+	f, isNum := x.(float64)
+	if !isNum {
+		return 0, false, fmt.Errorf("schema keyword %s is not a number", key)
+	}
+	return f, true, nil
+}

+// check appends to out one line per rule of s that doc breaks at path.
+func (v validator) check(s map[string]any, doc any, path string, out *[]string) error {
+	keys := make([]string, 0, len(s))
+	for k := range s {
+		keys = append(keys, k)
+	}
+	sort.Strings(keys)
+	for _, k := range keys {
+		if !knownKeywords[k] {
+			return fmt.Errorf("schema keyword %s is not supported by this validator", k)
+		}
+	}
+	fail := func(format string, args ...any) { *out = append(*out, path+": "+fmt.Sprintf(format, args...)) }
+
+	if ref, ok := s["$ref"]; ok {
+		r, isStr := ref.(string)
+		if !isStr {
+			return fmt.Errorf("$ref is not a string")
+		}
+		target, err := v.resolve(r)
+		if err != nil {
+			return err
+		}
+		if err := v.check(target, doc, path, out); err != nil {
+			return err
+		}
+	}
+	got := typeName(doc)
+	if t, ok := s["type"]; ok {
+		want, isStr := t.(string)
+		if !isStr {
+			return fmt.Errorf("schema keyword type is not a string")
+		}
+		if got != want && (want != "number" || got != "integer") {
+			fail("is %s, want %s", got, want)
+			return nil
+		}
+	}
+	if e, ok := s["enum"]; ok {
+		list, isList := e.([]any)
+		if !isList {
+			return fmt.Errorf("schema keyword enum is not a list")
+		}
+		found := false
+		for _, x := range list {
+			if equal(x, doc) {
+				found = true
+			}
+		}
+		if !found {
+			fail("%s is not one of %s", show(doc), show(list))
+		}
+	}
+	if c, ok := s["const"]; ok && !equal(c, doc) {
+		fail("%s is not %s", show(doc), show(c))
+	}
+	if err := v.checkString(s, doc, fail); err != nil {
+		return err
+	}
+	if err := v.checkNumber(s, doc, fail); err != nil {
+		return err
+	}
+	if err := v.checkArray(s, doc, path, out, fail); err != nil {
+		return err
+	}
+	if err := v.checkObject(s, doc, path, out, fail); err != nil {
+		return err
+	}
+	return v.checkCombinators(s, doc, path, out, fail)
+}

+func (v validator) checkString(s map[string]any, doc any, fail func(string, ...any)) error {
+	str, isStr := doc.(string)
+	if !isStr {
+		return nil
+	}
+	n := float64(utf8.RuneCountInString(str))
+	if lo, ok, err := number(s, "minLength"); err != nil {
+		return err
+	} else if ok && n < lo {
+		fail("is %d characters, want at least %d", int(n), int(lo))
+	}
+	if hi, ok, err := number(s, "maxLength"); err != nil {
+		return err
+	} else if ok && n > hi {
+		fail("is %d characters, want at most %d", int(n), int(hi))
+	}
+	if p, ok := s["pattern"]; ok {
+		ps, isStr := p.(string)
+		if !isStr {
+			return fmt.Errorf("schema keyword pattern is not a string")
+		}
+		re, err := regexp.Compile(ps)
+		if err != nil {
+			return fmt.Errorf("schema pattern %q: %v", ps, err)
+		}
+		if !re.MatchString(str) {
+			fail("%q does not match %s", str, ps)
+		}
+	}
+	return nil
+}
+
+func (v validator) checkNumber(s map[string]any, doc any, fail func(string, ...any)) error {
+	f, isNum := doc.(float64)
+	if !isNum {
+		return nil
+	}
+	if lo, ok, err := number(s, "minimum"); err != nil {
+		return err
+	} else if ok && f < lo {
+		fail("%v is below the minimum %v", f, lo)
+	}
+	if hi, ok, err := number(s, "maximum"); err != nil {
+		return err
+	} else if ok && f > hi {
+		fail("%v is above the maximum %v", f, hi)
+	}
+	return nil
+}
+
+func (v validator) checkArray(s map[string]any, doc any, path string, out *[]string, fail func(string, ...any)) error {
+	list, isList := doc.([]any)
+	if !isList {
+		return nil
+	}
+	n := float64(len(list))
+	if lo, ok, err := number(s, "minItems"); err != nil {
+		return err
+	} else if ok && n < lo {
+		fail("has %d items, want at least %d", len(list), int(lo))
+	}
+	if hi, ok, err := number(s, "maxItems"); err != nil {
+		return err
+	} else if ok && n > hi {
+		fail("has %d items, want at most %d", len(list), int(hi))
+	}
+	if u, ok := s["uniqueItems"]; ok {
+		b, isBool := u.(bool)
+		if !isBool {
+			return fmt.Errorf("schema keyword uniqueItems is not a boolean")
+		}
+		for i := 0; b && i < len(list); i++ {
+			for j := i + 1; j < len(list); j++ {
+				if equal(list[i], list[j]) {
+					fail("items %d and %d are equal", i, j)
+				}
+			}
+		}
+	}
+	if it, ok := s["items"]; ok {
+		item, isMap := it.(map[string]any)
+		if !isMap {
+			return fmt.Errorf("schema keyword items is not a schema")
+		}
+		for i, x := range list {
+			if err := v.check(item, x, fmt.Sprintf("%s[%d]", path, i), out); err != nil {
+				return err
+			}
+		}
+	}
+	return nil
+}

+func (v validator) checkObject(s map[string]any, doc any, path string, out *[]string, fail func(string, ...any)) error {
+	obj, isObj := doc.(map[string]any)
+	if !isObj {
+		return nil
+	}
+	if r, ok := s["required"]; ok {
+		list, isList := r.([]any)
+		if !isList {
+			return fmt.Errorf("schema keyword required is not a list")
+		}
+		for _, x := range list {
+			name, _ := x.(string)
+			if _, has := obj[name]; !has {
+				fail("%s is required", name)
+			}
+		}
+	}
+	props := map[string]any{}
+	if p, ok := s["properties"]; ok {
+		m, isMap := p.(map[string]any)
+		if !isMap {
+			return fmt.Errorf("schema keyword properties is not a map")
+		}
+		props = m
+	}
+	names := make([]string, 0, len(obj))
+	for k := range obj {
+		names = append(names, k)
+	}
+	sort.Strings(names)
+	for _, k := range names {
+		if pn, ok := s["propertyNames"]; ok {
+			ps, isMap := pn.(map[string]any)
+			if !isMap {
+				return fmt.Errorf("schema keyword propertyNames is not a schema")
+			}
+			if err := v.check(ps, k, path+" key "+k, out); err != nil {
+				return err
+			}
+		}
+		if ps, ok := props[k]; ok {
+			sub, isMap := ps.(map[string]any)
+			if !isMap {
+				return fmt.Errorf("schema of property %s is not a schema", k)
+			}
+			if err := v.check(sub, obj[k], path+"."+k, out); err != nil {
+				return err
+			}
+			continue
+		}
+		switch ap := s["additionalProperties"].(type) {
+		case nil:
+		case bool:
+			if !ap {
+				fail("%s is not an allowed key", k)
+			}
+		case map[string]any:
+			if err := v.check(ap, obj[k], path+"."+k, out); err != nil {
+				return err
+			}
+		default:
+			return fmt.Errorf("schema keyword additionalProperties is neither a boolean nor a schema")
+		}
+	}
+	return nil
+}
+
+func (v validator) holds(s any, doc any, path string) (bool, error) {
+	m, isMap := s.(map[string]any)
+	if !isMap {
+		return false, fmt.Errorf("a schema of if, then, else, not or allOf is not a schema")
+	}
+	var probe []string
+	if err := v.check(m, doc, path, &probe); err != nil {
+		return false, err
+	}
+	return len(probe) == 0, nil
+}
+
+func (v validator) checkCombinators(s map[string]any, doc any, path string, out *[]string, fail func(string, ...any)) error {
+	if all, ok := s["allOf"]; ok {
+		list, isList := all.([]any)
+		if !isList {
+			return fmt.Errorf("schema keyword allOf is not a list")
+		}
+		for _, sub := range list {
+			m, isMap := sub.(map[string]any)
+			if !isMap {
+				return fmt.Errorf("an item of allOf is not a schema")
+			}
+			if err := v.check(m, doc, path, out); err != nil {
+				return err
+			}
+		}
+	}
+	if n, ok := s["not"]; ok {
+		held, err := v.holds(n, doc, path)
+		if err != nil {
+			return err
+		}
+		if held {
+			fail("matches a schema it must not match (%s)", show(n))
+		}
+	}
+	cond, ok := s["if"]
+	if !ok {
+		return nil
+	}
+	held, err := v.holds(cond, doc, path)
+	if err != nil {
+		return err
+	}
+	branch := "else"
+	if held {
+		branch = "then"
+	}
+	if b, ok := s[branch]; ok {
+		m, isMap := b.(map[string]any)
+		if !isMap {
+			return fmt.Errorf("schema keyword %s is not a schema", branch)
+		}
+		return v.check(m, doc, path, out)
+	}
+	return nil
+}

+func equal(a, b any) bool {
+	x, _ := json.Marshal(a)
+	y, _ := json.Marshal(b)
+	return string(x) == string(y)

+	b, _ := json.Marshal(x)
+	return string(b)
