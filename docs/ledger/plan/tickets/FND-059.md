# FND-059 — The guards that run on every pull request share a few jobs

## In plain words

**The problem today.** Most guards of this repository are one short script, and each has a workflow of its own with no path filter. So every pull request, even one that changes a single document, starts 49 jobs, and most of them run for less than a minute. The organisation can run only 20 hosted jobs at once, so pull requests wait for a runner for up to half an hour.

**What changes.** The short guards run as steps of three shared jobs: one for the guards that read the tree, one for the guards that read the pull request itself, and the Go lint job for the guards that need Go. Each guard keeps its own named step, its command and the events it ran on, and one red guard no longer hides another.

**Done means:**

- A pull request that changes one document starts 12 jobs.
- Every guard that ran on every pull request before still runs on every pull request, merge group and push it ran on before, with the same command.
- When one guard fails, its shared job is red, the red step carries the name of that guard, and every other guard of the job still runs.
- The aggregate check ci-gate still judges every shared job, and the ruleset file of main requires tree-guards in place of the vendor disk library check.
- A later change that makes a pull request of one document start more than 12 jobs turns the check tree-guards red.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
A pull request that changes only `docs/STATUS.md` starts 12 jobs, not 49. The guards that were one short script each, and a workflow of their own with no path filter, run as steps of three shared jobs: `tree-guards` (new file `.github/workflows/tree-guards.yaml`), `pull-request-guards` (new file `.github/workflows/pull-request-guards.yaml`) and the existing job `go-lint` (`.github/workflows/go-lint.yaml`). Each guard keeps a step of its own whose name starts with its old check name, so the log and the list of steps of a red run name the guard. Each step runs after a failed step too, so one red guard hides no other. The 29 old workflow files are deleted. The new script `scripts/check-pr-jobs.py` proves the rules and keeps them: it counts the jobs of a one-document pull request, checks that the shared jobs let every guard run and name it, and, for this change, that every step of every deleted workflow runs elsewhere with the same command, on the same events, after the same setup. If one more guard workflow of the plain form reached `main` after this ticket was written, a tool of this ticket folds it into `tree-guards` in the same way, and the same proofs judge the result.

## 3. The model (the law)
1. **Three groups, by what a guard needs.**
   - `tree-guards`: the guards that read the tree and need only a checkout of two commits, Python 3.12 with PyYAML, bash and git. Its steps come from the 22 workflows `access-guards.yaml`, `agent-plane-guards.yaml`, `bss-ratchets.yaml`, `check-api-structure.yaml`, `check-contracts-ctl.yaml`, `check-lifecycle-ratchets.yaml`, `check-machine-plane.yaml`, `check-network-guards.yaml`, `check-no-conflict-markers.yaml`, `check-no-direct-cluster-write.yaml`, `check-no-new-polling.yaml`, `check-no-vendor-disk-library.yaml`, `check-products.yaml`, `check-provider-leaks.yaml`, `check-repo-hygiene.yaml`, `check-service-model.yaml`, `check-upstream-literals.yaml`, `plan-validate.yaml`, `check-generated-docs.yaml`, `secret-guards.yaml`, `check-pins.yaml` and `check-reserved-slugs.yaml`.
   - `pull-request-guards`: the guards that read the pull request (its body, title, labels or commit range) or the full history, and that ran again when the body was edited or a label changed. Its steps come from the 5 workflows `banned-words-validate.yaml`, `pr-body-validate.yaml`, `rt11-cutover-hold.yaml`, `gate-manifest.yaml` and `naming-guard.yaml`, and from the job `pr` of `check-release-owned-lines.yaml`. The persona-name guard (`naming-guard.yaml`) reads only the tree; it is here because its old workflow also ran when the body was edited, and this job already has the full checkout it needs.
   - `go-lint`: the guards that need Go and nothing else join the job that already sets up Go. Its new steps come from the 2 workflows `check-provider-contract.yaml` and `check-variables-documents.yaml`. Each sets up the Go of its own module first, with the same inputs as its old workflow.
2. **What stays its own workflow, and why.** `ci-gate.yaml` (it stands for every other check). `work-package.yaml` (its checks are named in the fixed text of every ticket). `security-scan.yaml` (it downloads Trivy, needs the full history and scans the tree twice). `console-lint.yaml` (it needs Node). `check-lock-stages.yaml` (it needs Helm, and no other guard that starts on every pull request does; a group of one guard stays a workflow). `redact-guard.yml` (it reads a secret and runs on pushes to every branch). The job `push` of `check-release-owned-lines.yaml` (it judges pushes to main only). Every workflow with a path filter.
3. **One step per old step.** A guard step is named `<old check name> | <old step name>`, where the old check name is the name of the old job. For three old workflows the steps carry the name of the guard instead, because the name of the old job did not name it (`plan-validate`, `provider-leaks`, `no-conflict-markers`; field 9 gives their old check names). Its `run`, `env`, `working-directory` and `with` are those of the old step, character for character. A guard whose old job had a step without a name gets a name that describes that step.
4. **No red step hides another.** In each shared job every step from the first guard step on has an `if` that starts with `!cancelled()`. GitHub runs such a step also after an earlier step failed, and the job is red when any step failed. The setup steps before them have no `if`.
5. **The events of a guard do not change.** A step runs on every event its old workflow ran on: pull requests and merge groups for every guard; pushes to main where the old workflow had them (`github.event_name != 'workflow_dispatch'` in `tree-guards`, no condition in `go-lint`); a start by hand only for the conflict-marker guard. Where the old workflow had no push trigger, the step carries `github.event_name == 'pull_request' || github.event_name == 'merge_group'` (in `tree-guards`) or `github.event_name != 'push'` (in `go-lint`). `pull-request-guards` starts on the union of the pull-request event types of its old workflows: `opened`, `edited`, `reopened`, `synchronize`, `labeled`, `unlabeled`. An old step's own `if` is kept after the `!cancelled() &&`.
6. **The setup does not change.** A guard runs after a checkout of at least as many commits as its old one, with the same setup action inputs, and with PyYAML installed where its old job installed it. The two steps that change the checkout run last in `tree-guards`: the probe of the secret guards adds a line to a chart template and restores it, and the known answer of the provider-leak scanner checks out a fixed commit into the folder `known-answer`.
7. **The check names.** `ci-gate` (`scripts/ci-gate.py`) judges every check run of the commit by its job, so a red step makes its shared job red and `ci-gate` red. In the required checks of `.github/rulesets/main.json` the context `vendor-disk-library` becomes `tree-guards`: that check no longer exists, and its two steps are steps of `tree-guards`. The other contexts stay as they are.
8. **The count is kept.** `tree-guards` runs `python3 scripts/check-pr-jobs.py --self-test`, `folded` and `count`. A later change that makes a one-document pull request start more than 12 jobs, or that adds a step to a shared job that a red step could hide, turns `tree-guards` red.
9. **Pinned references.** The two new workflow files hold only actions pinned by a commit: `actions/checkout@11d5960a326750d5838078e36cf38b85af677262` and `actions/setup-python@a26af69be951a213d495a4c3e4e4022e16d87065`, the two commits that `.github/workflows/check-pins.yaml` already uses (pre-flight P1). The two setup steps added to `go-lint.yaml`, an existing file, keep `actions/setup-go@v5` as their old workflows had it.
10. **Deleted.** The 29 workflow files of law 1 and the job `pr` of `check-release-owned-lines.yaml` with that workflow's `pull_request` and `merge_group` triggers. No other workflow, guard script or baseline changes, but for law 11.
11. **One workflow that arrived late.** This ticket was written for the 37 workflows that started on every pull request at the commit of field 4. Another package may add one more before this ticket runs. Then a one-document pull request would start 13 jobs, and this ticket holds no steps for the new guard. The tool of the block `FND-059-arrival.py` settles that case. You decide nothing.
    - No workflow arrived: the tool changes nothing. This is the usual case.
    - One workflow arrived, and it keeps the rules R1 to R8 in the head of the tool. In short: its file is named `check-<name>.yaml`; its triggers are `pull_request` and `merge_group`, with or without `push` to main, without filters; it has one job on `ubuntu-latest`; the job checks out at most two commits and sets up at most Python 3.12 and PyYAML; every other step has a name, a command and at most an environment of plain texts; no step holds an expression or a secret; and no ruleset and no ticket of an unmerged package names its check. Then the tool makes its guard steps steps of `tree-guards`, placed before the two steps that change the checkout, each with the name of law 3, the `if` of law 4 and the events of law 5, and it deletes the file of the workflow.
    - Any other case (two or more arrived, or one that breaks a rule): the tool changes nothing and this ticket stops.

    The proof does not depend on which case it was: `moved`, `folded` and `count` judge the tree that results, and every folded step runs in `tree-guards` on the pull request. Field 14 holds the pattern `.github/workflows/check-*.yaml` for this case only.

#!/usr/bin/env python3
"""FND-059-fill.py <template> <output> - copy run blocks of old workflows into a new workflow.

A line '<indent>#FILL <workflow file> <job> <step number from 0>' is replaced by the run
block of that step of .github/workflows/<workflow file>, one line per line of the block,
each with the same indent; an empty line stays empty. Every other line is copied as it is.
"""
import sys

import yaml

out = []
for line in open(sys.argv[1], encoding="utf-8").read().split("\n"):
    if line.strip().startswith("#FILL "):
        indent = line[:len(line) - len(line.lstrip())]
        _, wf, job, n = line.split()
        run = yaml.safe_load(open(".github/workflows/" + wf, encoding="utf-8"))["jobs"][job]["steps"][int(n)]["run"]
        out += [indent + x if x else "" for x in run.rstrip("\n").split("\n")]
    else:
        out.append(line)
open(sys.argv[2], "w", encoding="utf-8").write("\n".join(out))

def glob_re(pattern):
    out, i = "", 0
    while i < len(pattern):

            take()
            w = conj()
            v = True if (v is True or w is True) else (UNKNOWN if UNKNOWN in (v, w) else False)
        return v
    try:
        v = disj()
        return v if peek()[0] == "end" else UNKNOWN
    except (ValueError, IndexError):
        return UNKNOWN


def step_runs(step, event, status):
    cond = step.get("if")
    if cond is None:
        return status == "success"
    v = evaluate(cond, event, status)
    if v is UNKNOWN:
        v = True                          # a step whose if cannot be read may run
    if not re.search(r"\b(always|cancelled|failure)\(\)", str(cond)):
        v = v and status == "success"     # an if without a status function holds success()
    return v


# ---- workflows
def load_text(text, where):
    try:
        d = yaml.safe_load(text)
    except yaml.YAMLError as e:
        raise Unreadable("%s: %s" % (where, e))
    if not isinstance(d, dict):
        raise Unreadable("%s: not a workflow" % where)
    return d


def triggers(d):
    on = d.get(True, d.get("on"))
    if isinstance(on, str):
        on = {on: None}
    if isinstance(on, list):
        on = {k: None for k in on}
    return {k: (v or {}) for k, v in (on or {}).items()}


def on_every_pr(d):
    pr = triggers(d).get("pull_request")
    return pr is not None and "paths" not in pr and "paths-ignore" not in pr


def event_set(d, job, step=None):
    """The events of EVENTS on which the step (or the job) runs: a set of (event, detail)."""
    out = set()
    for e, spec in triggers(d).items():
        if e not in EVENTS:
            continue
        if evaluate(job.get("if"), e) is False:
            continue
        if step is not None and not step_runs(step, e, "success"):
            continue
        if e == "pull_request":
            for t in spec.get("types") or DEFAULT_TYPES:
                out.add((e, t))
        elif e == "push":
            out.add((e, tuple(spec.get("branches") or ("**",))))
        else:
            out.add((e, None))
    return out


def covers(new, old):
    for e, detail in old:
        if e == "push":
            if not any(n == "push" and (("**",) == nd or set(detail) <= set(nd)) for n, nd in new):
                return False
        elif (e, detail) not in new:
            return False
    return True


def workflows(read):
    """{path: workflow} for every workflow that read() lists."""
    out = {}
    for path, text in read():
        out[path] = load_text(text, path)
    return out


def tree_reader(root):
    def read():
        for p in sorted(glob.glob(os.path.join(root, ".github/workflows/*.y*ml"))):
            rel = os.path.relpath(p, root)
            if rel.endswith((".yml", ".yaml")):
                yield rel, open(p, encoding="utf-8").read()
    return read


def commit_reader(root, commit):
    def git(*args):
        r = subprocess.run(["git", "-C", root] + list(args), stdout=subprocess.PIPE, stderr=subprocess.PIPE)
        if r.returncode:
            raise Unreadable("git %s: %s" % (" ".join(args), r.stderr.decode().strip()))
        return r.stdout.decode("utf-8", "replace")

    def read():
        for rel in sorted(git("ls-tree", "--name-only", commit, ".github/workflows/").split("\n")):
            if rel.endswith((".yml", ".yaml")) and rel.count("/") == 2:
                yield rel, git("show", "%s:%s" % (commit, rel))
    return read


# ---- count
def matrix_size(job, where):
    strategy = job.get("strategy")
    if not isinstance(strategy, dict) or "matrix" not in strategy:
        return 1
    m = strategy["matrix"]
    if not isinstance(m, dict):
        raise Unreadable("%s: the matrix is an expression and cannot be counted" % where)
    lists = [v for k, v in m.items() if k not in ("include", "exclude")]
    include = m.get("include") or []
    if any(not isinstance(v, list) for v in lists) or not isinstance(include, list):
        raise Unreadable("%s: the matrix is an expression and cannot be counted" % where)
    n = 1
    for v in lists:
        n *= len(v)
    return (n if lists else 0) + len(include)


def jobs_started(flows, path, event, seen=()):
    d, n = flows[path], 0
    for name, job in (d.get("jobs") or {}).items():
        if evaluate(job.get("if"), event) is False:
            continue
        uses = job.get("uses")
        if isinstance(uses, str) and uses.startswith("./"):
            callee = uses[2:].split("@")[0]
            if callee not in flows or callee in seen:
                raise Unreadable("%s job %s: the called workflow %s cannot be read" % (path, name, callee))
            n += jobs_started(flows, callee, event, seen + (path,)) * matrix_size(job, "%s job %s" % (path, name))
        else:
            n += matrix_size(job, "%s job %s" % (path, name))
    return n


def count(flows, paths):
    rows = []
    for path in sorted(flows):
        pr = triggers(flows[path]).get("pull_request")
        if pr is None:
            continue
        types = pr.get("types")
        if types and not set(types) & {"opened", "synchronize"}:
            continue
        if pr.get("branches") and not passes(pr["branches"], "main"):
            continue
        if pr.get("branches-ignore") and passes(pr["branches-ignore"], "main"):
            continue
        if "paths" in pr and not any(passes(pr["paths"], p) for p in paths):
            continue
        if "paths-ignore" in pr and all(passes(pr["paths-ignore"], p) for p in paths):
            continue
        n = jobs_started(flows, path, "pull_request")
        if n:
            rows.append((n, path))
    return rows


# ---- folded
def folded(flows, path, job_name):
    errs, ok = [], []
    d = flows.get(path)
    job = ((d or {}).get("jobs") or {}).get(job_name) if d else None
    if job is None:
        return ["%s: no job %s" % (path, job_name)], ok
    if not on_every_pr(d) or "merge_group" not in triggers(d):
        errs.append("%s: J1 the workflow does not start on every pull request and every merge group" % path)
    steps = job.get("steps") or []
    after = [bool(re.search(r"!\s*cancelled\(\)|always\(\)", str(s.get("if", "")))) for s in steps]
    first = after.index(True) if True in after else len(steps)
    for i in range(first, len(steps)):
        if not after[i]:
            errs.append("%s: J2 step %d (%s) does not run after a failure, but a step before it does"
                        % (path, i + 1, steps[i].get("name") or steps[i].get("uses")))
    names = [s.get("name") for s in steps if s.get("name")]
    for s in steps:
        if "run" in s and not s.get("name"):
            errs.append("%s: J3 a step runs a command and has no name: %s" % (path, s["run"].split("\n")[0]))
    for n in sorted(set(x for x in names if names.count(x) > 1)):
        errs.append("%s: J3 two steps are named %s" % (path, n))
    for i in range(first, len(steps)):
        rest = re.sub(r"!\s*cancelled\(\)|always\(\)|github\.event_name\s*[!=]=\s*'[^']*'|&&|\|\||[!()\s]", "",
                      str(steps[i].get("if", "")).strip().removeprefix("${{").removesuffix("}}"))
        if rest:
            errs.append("%s: J4 the if of step %d (%s) uses more than !cancelled(), always() and the event name"
                        % (path, i + 1, steps[i].get("name")))
    if errs:
        return errs, ok
    for event in [e for e in triggers(d) if e in EVENTS]:
        if evaluate(job.get("if"), event) is False:
            continue
        section = [i for i in range(first, len(steps)) if step_runs(steps[i], event, "success")]
        for bad in section:
            status, failed, ran = "success", [], []
            for i, s in enumerate(steps):
                if not step_runs(s, event, status):
                    continue
                ran.append(i)
                if i == bad:
                    failed.append(i)
                    status = "failure"
            others = [i for i in section if i != bad]
            if status != "failure" or failed != [bad] or not set(others) <= set(ran):
                errs.append("%s on %s: J5 a failure of step %d (%s) is not seen, or hides another step"
                            % (path, event, bad + 1, steps[bad].get("name")))
            else:
                ok.append("%s on %s: %s fails: the job is red, names it, and %d other steps ran"
                          % (job_name, event, steps[bad].get("name"), len(others)))
    return errs, ok


# ---- moved
def setup_of(steps, upto):
    """What the steps before index upto set up."""
    depth, tools, pyyaml = None, {}, False
    for s in steps[:upto]:
        uses = str(s.get("uses", "")).split("@")[0]
        w = s.get("with") or {}
        if uses == "actions/checkout" and "path" not in w:
            depth = int(w.get("fetch-depth", 1))
        elif uses in SETUP_ACTIONS:
            tools[uses] = tuple(sorted((k, str(v)) for k, v in w.items() if k != "cache"))
        elif str(s.get("run", "")).strip() in PYYAML:
            pyyaml = True
    return depth, tools, pyyaml


def is_setup(s):
    uses = str(s.get("uses", "")).split("@")[0]
    return (uses == "actions/checkout" and "path" not in (s.get("with") or {})) or uses in SETUP_ACTIONS \
        or str(s.get("run", "")).strip() in PYYAML


def same(a, b):
    keys = ("run", "env", "working-directory", "with")
    return all(a.get(k) == b.get(k) for k in keys) and \
        str(a.get("uses", "")).split("@")[0] == str(b.get("uses", "")).split("@")[0]


def enough(old, new):
    od, ot, oy = old
    nd, nt, ny = new
    if od is not None and (nd is None or (nd != 0 and (od == 0 or nd < od))):
        return False
    if oy and not ny:
        return False
    return all(nt.get(k) == v for k, v in ot.items())


def moved(old_flows, new_flows):
    errs, n_steps = [], 0
    targets = []
    for path, d in sorted(new_flows.items()):
        for jn, job in (d.get("jobs") or {}).items():
            steps = job.get("steps") or []
            for i, s in enumerate(steps):
                targets.append((path, jn, d, job, steps, i, s))
    gone_files, gone_jobs = 0, 0
    for path, d in sorted(old_flows.items()):
        if not on_every_pr(d):
            continue
        if path not in new_flows:
            gone_files += 1
        for jn, job in (d.get("jobs") or {}).items():
            if path not in new_flows or jn not in (new_flows[path].get("jobs") or {}):
                gone_jobs += 1
            steps = job.get("steps") or []
            for i, s in enumerate(steps):
                if is_setup(s):
                    continue
                n_steps += 1
                need, setup = event_set(d, job, s), setup_of(steps, i)
                pr = any(e == "pull_request" for e, _ in need)
                found = [t for t in targets if same(s, t[6]) and covers(event_set(t[2], t[3], t[6]), need)
                         and enough(setup, setup_of(t[4], t[5])) and (on_every_pr(t[2]) or not pr)]
                if not found:
                    errs.append("%s job %s: step %d (%s) runs nowhere else on every pull request with the same "
                                "command, events and setup" % (path, jn, i + 1, s.get("name") or str(s.get("run", s.get("uses"))).split("\n")[0]))
    return errs, (gone_files, gone_jobs, n_steps)

def main(argv):

            rows = count(workflows(tree_reader(root)), paths)
            for n, path in rows:
                print("pr-jobs: %d %s" % (n, path))
            total = sum(n for n, _ in rows)
            print("pr-jobs: a pull request that changes %s starts %d jobs; the limit is %d"
                  % (" ".join(paths), total, limit))
            return 1 if total > limit else 0
        if argv == ["folded"]:
            flows, bad = workflows(tree_reader(root)), 0
            for path, job in SHARED:
                errs, ok = folded(flows, path, job)
                for line in ok:
                    print("pr-jobs: ok " + line)
                for line in errs:
                    print("pr-jobs: FAIL " + line)
                bad += len(errs)
            print("pr-jobs: folded: %s" % ("%d rule(s) broken" % bad if bad else "ok, %d shared jobs" % len(SHARED)))
            return 1 if bad else 0
        if len(argv) == 3 and argv[:2] == ["moved", "--base"]:
            errs, (files, jobs, steps) = moved(workflows(commit_reader(root, argv[2])), workflows(tree_reader(root)))
            for line in errs:

            print("pr-jobs: moved: %d workflows and %d jobs that started on every pull request are gone; "
                  "%d guard steps compared, %d run nowhere" % (files, jobs, steps, len(errs)))
            return 1 if errs else 0
    except Unreadable as e:
        print("pr-jobs: cannot read: %s" % e)
        return 2
    print(__doc__)
    return 2
