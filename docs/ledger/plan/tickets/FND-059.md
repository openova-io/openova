# FND-059 — The guards that run on every pull request share a few jobs

## In plain words

**The problem today.** Most guards of this repository are one short script, and each has a workflow of its own with no path filter. So every pull request, even one that changes a single document, starts 47 jobs, and most of them run for less than a minute. The organisation can run only 20 hosted jobs at once, so pull requests wait for a runner for up to half an hour.

**What changes.** The short guards run as steps of three shared jobs: one for the guards that read the tree, one for the guards that read the pull request itself, and the Go lint job for the guards that need Go. Each guard keeps its own named step, its command and the events it ran on, and one red guard no longer hides another.

**Done means:**

- A pull request that changes one document starts 12 jobs.
- Every guard that ran on every pull request before still runs on every pull request, merge group and push it ran on before, with the same command.
- When one guard fails, its shared job is red, the red step carries the name of that guard, and every other guard of the job still runs.
- The aggregate check ci-gate still judges every shared job, and the ruleset file of main requires tree-guards in place of the vendor disk library check.
- A later change that makes a pull request of one document start more than 12 jobs turns the check tree-guards red.

The rest of this ticket is the exact instruction for the model that does the work.

## 3. The model (the law)
1. **Three groups, by what a guard needs.**
   - `tree-guards`: the guards that read the tree and need only a checkout of two commits, Python 3.12 with PyYAML, bash and git. Its steps come from the 21 workflows `access-guards.yaml`, `agent-plane-guards.yaml`, `bss-ratchets.yaml`, `check-api-structure.yaml`, `check-contracts-ctl.yaml`, `check-lifecycle-ratchets.yaml`, `check-machine-plane.yaml`, `check-network-guards.yaml`, `check-no-conflict-markers.yaml`, `check-no-direct-cluster-write.yaml`, `check-no-new-polling.yaml`, `check-no-vendor-disk-library.yaml`, `check-products.yaml`, `check-provider-leaks.yaml`, `check-repo-hygiene.yaml`, `check-service-model.yaml`, `check-upstream-literals.yaml`, `plan-validate.yaml`, `check-generated-docs.yaml`, `secret-guards.yaml` and `check-pins.yaml`.
   - `pull-request-guards`: the guards that read the pull request (its body, title, labels or commit range) or the full history, and that ran again when the body was edited or a label changed. Its steps come from the 5 workflows `banned-words-validate.yaml`, `pr-body-validate.yaml`, `rt11-cutover-hold.yaml`, `gate-manifest.yaml` and `naming-guard.yaml`, and from the job `pr` of `check-release-owned-lines.yaml`. The persona-name guard (`naming-guard.yaml`) reads only the tree; it is here because its old workflow also ran when the body was edited, and this job already has the full checkout it needs.
   - `go-lint`: the guards that need Go and nothing else join the job that already sets up Go. Its new steps come from the 2 workflows `check-provider-contract.yaml` and `check-variables-documents.yaml`. Each sets up the Go of its own module first, with the same inputs as its old workflow.
2. **What stays its own workflow, and why.** `ci-gate.yaml` (it stands for every other check). `work-package.yaml` (its four checks are named in the fixed text of every ticket). `security-scan.yaml` (it downloads Trivy and scans the tree twice). `console-lint.yaml` (it needs Node). `check-lock-stages.yaml` (it needs Helm; a new workflow file may hold no action reference that is not pinned by a commit, and the repository holds no pinned commit of `azure/setup-helm`). `redact-guard.yml` (it reads a secret and runs on pushes to every branch). The job `push` of `check-release-owned-lines.yaml` (it judges pushes to main only). Every workflow with a path filter.
3. **One step per old step.** A guard step is named `<old check name> | <old step name>`, where the old check name is the name of the old job. For three old workflows the steps carry the name of the guard instead, because the name of the old job did not name it (`plan-validate`, `provider-leaks`, `no-conflict-markers`; field 9 gives their old check names). Its `run`, `env`, `working-directory` and `with` are those of the old step, character for character. A guard whose old job had a step without a name gets a name that describes that step.
4. **No red step hides another.** In each shared job every step from the first guard step on has an `if` that starts with `!cancelled()`. GitHub runs such a step also after an earlier step failed, and the job is red when any step failed. The setup steps before them have no `if`.
5. **The events of a guard do not change.** A step runs on every event its old workflow ran on: pull requests and merge groups for every guard; pushes to main where the old workflow had them (`github.event_name != 'workflow_dispatch'` in `tree-guards`, no condition in `go-lint`); a start by hand only for the conflict-marker guard. Where the old workflow had no push trigger, the step carries `github.event_name == 'pull_request' || github.event_name == 'merge_group'` (in `tree-guards`) or `github.event_name != 'push'` (in `go-lint`). `pull-request-guards` starts on the union of the pull-request event types of its old workflows: `opened`, `edited`, `reopened`, `synchronize`, `labeled`, `unlabeled`. An old step's own `if` is kept after the `!cancelled() &&`.
6. **The setup does not change.** A guard runs after a checkout of at least as many commits as its old one, with the same setup action inputs, and with PyYAML installed where its old job installed it. The two steps that change the checkout run last in `tree-guards`: the probe of the secret guards adds a line to a chart template and restores it, and the known answer of the provider-leak scanner checks out a fixed commit into the folder `known-answer`.
7. **The check names.** `ci-gate` (`scripts/ci-gate.py`) judges every check run of the commit by its job, so a red step makes its shared job red and `ci-gate` red. In the required checks of `.github/rulesets/main.json` the context `vendor-disk-library` becomes `tree-guards`: that check no longer exists, and its two steps are steps of `tree-guards`. The other contexts stay as they are.
8. **The count is kept.** `tree-guards` runs `python3 scripts/check-pr-jobs.py --self-test`, `folded` and `count`. A later change that makes a one-document pull request start more than 12 jobs, or that adds a step to a shared job that a red step could hide, turns `tree-guards` red.
9. **Pinned references.** The two new workflow files hold only actions pinned by a commit: `actions/checkout@11d5960a326750d5838078e36cf38b85af677262` and `actions/setup-python@a26af69be951a213d495a4c3e4e4022e16d87065`, the two commits that `.github/workflows/check-pins.yaml` already uses (pre-flight P1). The two setup steps added to `go-lint.yaml`, an existing file, keep `actions/setup-go@v5` as their old workflows had it.
10. **Deleted.** The 28 workflow files of law 1 and the job `pr` of `check-release-owned-lines.yaml` with that workflow's `pull_request` and `merge_group` triggers. No other workflow, guard script or baseline changes.

def glob_re(pattern):
    out, i = "", 0
    while i < len(pattern):
        c = pattern[i]
        if pattern.startswith("**/", i):
            out, i = out + "(?:.*/)?", i + 3
            continue
        if pattern.startswith("**", i):
            out, i = out + ".*", i + 2
            continue
        if c == "*":
            out += "[^/]*"
        elif c in "?+":
            out += c
        elif c == "[":
            j = pattern.index("]", i)
            out, i = out + pattern[i:j + 1], j
        else:
            out += re.escape(c)
        i += 1
    return re.compile(out + r"\Z")


def passes(patterns, path):
    hit = False

    return hit

TOKEN = re.compile(r"\s*(?:(\|\||&&|==|!=|!|\(|\)|,)|'((?:[^']|'')*)'|([A-Za-z_][A-Za-z0-9_\-.*]*)|(\S))")


def evaluate(text, event, status="success"):
    """True, False or UNKNOWN. event: the event name, status: success, failure or cancelled."""
    if text is None:
        return None
    if isinstance(text, bool):
        return text
    s = str(text).strip()
    if s.startswith("${{") and s.endswith("}}"):
        s = s[3:-2].strip()
    toks, pos = [], 0
    while pos < len(s):
        m = TOKEN.match(s, pos)
        if not m or m.group(4):
            return UNKNOWN
        pos = m.end()
        if m.group(1):
            toks.append(("op", m.group(1)))
        elif m.group(2) is not None:
            toks.append(("str", m.group(2).replace("''", "'")))
        elif m.group(3):
            toks.append(("id", m.group(3)))
    toks.append(("end", None))
    at = [0]

    def peek():
        return toks[at[0]]

    def take():
        at[0] += 1
        return toks[at[0] - 1]

    def truth(v):
        return UNKNOWN if v is UNKNOWN else bool(v)

    def primary():
        kind, val = take()
        if kind == "op" and val == "(":
            v = disj()
            take()
            return v
        if kind == "op" and val == "!":
            v = truth(primary())
            return UNKNOWN if v is UNKNOWN else not v
        if kind == "str":
            return val
        if kind == "id":
            if peek() == ("op", "("):
                take()
                depth = 1
                while depth:
                    k, v = take()
                    if k == "end":
                        raise ValueError("unclosed call")
                    depth += (k, v) == ("op", "(")
                    depth -= (k, v) == ("op", ")")
                calls = {"success": status == "success", "failure": status == "failure",
                         "cancelled": status == "cancelled", "always": True}
                return calls.get(val, UNKNOWN)
            if val in ("true", "false"):
                return val == "true"
            if val == "github.event_name":
                return event if event is not None else UNKNOWN
            return UNKNOWN
        raise ValueError("bad expression")

    def comparison():
        v = primary()
        while peek()[0] == "op" and peek()[1] in ("==", "!="):
            op = take()[1]
            w = primary()
            if v is UNKNOWN or w is UNKNOWN:
                v = UNKNOWN
            else:
                v = (str(v).lower() == str(w).lower()) == (op == "==")
        return v

    def conj():
        v = truth(comparison())
        while peek() == ("op", "&&"):
            take()
            w = truth(comparison())
            v = False if (v is False or w is False) else (UNKNOWN if UNKNOWN in (v, w) else True)
        return v

    def disj():
        v = conj()
        while peek() == ("op", "||"):
            take()
            w = conj()
            v = True if (v is True or w is True) else (UNKNOWN if UNKNOWN in (v, w) else False)
        return v
    try:
        v = disj()
        return v if peek()[0] == "end" else UNKNOWN
    except (ValueError, IndexError):
        return UNKNOWN


def step_runs(step, event, status):

    if cond is None:

    v = evaluate(cond, event, status)

    if not re.search(r"\b(always|cancelled|failure)\(\)", str(cond)):
        v = v and status == "success"     # an if without a status function holds success()
    return v

def matrix_size(job, where):
    strategy = job.get("strategy")
    if not isinstance(strategy, dict) or "matrix" not in strategy:
        return 1
    m = strategy["matrix"]
    if not isinstance(m, dict):
        raise Unreadable("%s: the matrix is an expression and cannot be counted" % where)
    lists = [v for k, v in m.items() if k not in ("include", "exclude")]
    include = m.get("include") or []
    if any(not isinstance(v, list) for v in lists) or not isinstance(include, list):
        raise Unreadable("%s: the matrix is an expression and cannot be counted" % where)
    n = 1
    for v in lists:
        n *= len(v)
    return (n if lists else 0) + len(include)


def jobs_started(flows, path, event, seen=()):
    d, n = flows[path], 0
    for name, job in (d.get("jobs") or {}).items():
        if evaluate(job.get("if"), event) is False:
            continue
        uses = job.get("uses")
        if isinstance(uses, str) and uses.startswith("./"):
            callee = uses[2:].split("@")[0]
            if callee not in flows or callee in seen:
                raise Unreadable("%s job %s: the called workflow %s cannot be read" % (path, name, callee))
            n += jobs_started(flows, callee, event, seen + (path,)) * matrix_size(job, "%s job %s" % (path, name))
        else:
            n += matrix_size(job, "%s job %s" % (path, name))
    return n

def folded(flows, path, job_name):

    job = ((d or {}).get("jobs") or {}).get(job_name) if d else None

        if "run" in s and not s.get("name"):
            errs.append("%s: J3 a step runs a command and has no name: %s" % (path, s["run"].split("\n")[0]))
    for n in sorted(set(x for x in names if names.count(x) > 1)):

    errs, n_steps = [], 0
    targets = []
    for path, d in sorted(new_flows.items()):
        for jn, job in (d.get("jobs") or {}).items():
            steps = job.get("steps") or []
            for i, s in enumerate(steps):
                targets.append((path, jn, d, job, steps, i, s))
    gone_files, gone_jobs = 0, 0
    for path, d in sorted(old_flows.items()):
        if not on_every_pr(d):
            continue
        if path not in new_flows:
            gone_files += 1
        for jn, job in (d.get("jobs") or {}).items():
            if path not in new_flows or jn not in (new_flows[path].get("jobs") or {}):
                gone_jobs += 1
            steps = job.get("steps") or []
            for i, s in enumerate(steps):
                if is_setup(s):
                    continue
                n_steps += 1
                need, setup = event_set(d, job, s), setup_of(steps, i)
                pr = any(e == "pull_request" for e, _ in need)
                found = [t for t in targets if same(s, t[6]) and covers(event_set(t[2], t[3], t[6]), need)
                         and enough(setup, setup_of(t[4], t[5])) and (on_every_pr(t[2]) or not pr)]
                if not found:
                    errs.append("%s job %s: step %d (%s) runs nowhere else on every pull request with the same "
                                "command, events and setup" % (path, jn, i + 1, s.get("name") or str(s.get("run", s.get("uses"))).split("\n")[0]))
    return errs, (gone_files, gone_jobs, n_steps)
