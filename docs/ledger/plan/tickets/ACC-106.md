# ACC-106 — Session agent and session images

## In plain words

**The problem today.** A session of the access plane runs two programs in its pod: the remote-desktop daemon and an agent that gives it the connection settings, relays the browser's tunnel to it and ships the recording. The agent has no code and no image, the daemon is mirrored only by the version tag of an older release, and nothing tells the access controller which images a session pod runs.

**What changes.** The agent is written, tested and built into a small hardened image by a build of its own. The daemon at version 1.6.0 is mirrored from one fixed upstream digest, and the chart names both images, each by digest, to the access controller.

**Done means:**

- The agent's tests pass, among them one that runs the handshake, the relay and the recording shipper in one chain against a stand-in daemon and a stand-in controller.
- An agent whose configuration is missing, or has an unknown or a missing field, stops at start with exit code 78.
- With recording switched off the agent ships nothing and asks the daemon for no recording.
- The agent's image is a static program on a distroless base that runs as a numeric user that is not root; its build tests it on every pull request, and on the main branch builds, signs and pins it.
- The daemon is mirrored from the upstream digest of version 1.6.0, never from a tag, and the mirrored digest is written into the chart values.
- The access controller's environment names each session image by digest once that digest is written, moved with the registry override, and names no image whose digest is not written yet.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
Every session pod of the access plane (ADR-0033) will run two containers built here: `guacd` 1.6.0, mirrored to `ghcr.io/openova-io/openova/guacd` from one fixed upstream digest, and the session agent `ghcr.io/openova-io/openova/access-session-agent`, a static Go program on a distroless base. The agent reads the session's configuration from `/etc/access/config.json`, posts `ready` to the access controller once `guacd` accepts a connection on the loopback address, serves the broker's tunnel on port 8443 (`/tunnel`, one tunnel at a time, the session's UID required), runs the `guacd` handshake for each connection, ships the recording files under `/rec` in sealed chunks (none while `chunkBytes` is 0), and posts `closed` after the last chunk. `.github/workflows/build-access-session-agent.yaml` tests it on every pull request and, on `main`, builds, signs and attests the image and writes its digest to `access.session.images.agent.digest` of `platform/guacamole/chart/values.yaml`; `.github/workflows/build-bp-guacamole.yaml` writes the digest of the mirrored `guacd` to `access.session.images.guacd.digest`. The access controller's Deployment then carries `ACCESS_IMAGE_GUACD` and `ACCESS_IMAGE_AGENT`, each `<repository>@<digest>`. The session pod itself is built by ACC-104; this package delivers the images and their names.

## 3. The model (the law)
1. **One module.** `core/cmd/access-session-agent` is its own Go module (`go 1.23`, one dependency `github.com/gorilla/websocket v1.5.3`) with the command `main.go` and the packages `internal/config`, `internal/handshake`, `internal/relay` and `internal/shipper`, each with tests.
2. **Configuration.** `config.Load` reads `/etc/access/config.json` (the downward-API file of the pod annotation `access.openova.io/config`), schema `openova.io/access-session-config/v1`. An unknown field, a missing field or a value out of range is a start failure: the agent logs it and exits with code 78. The configuration may not set the `guacd` parameters the agent sets itself (`recording-*`, `typescript-*`, `create-*-path`, `recording-include-keys`, `disable-copy`, `disable-paste`). A chunk is at most 4 MiB. `chunkBytes` 0 means recording off.
3. **Handshake.** For each connection the agent runs the `guacd` handshake on a `net.Conn` to `127.0.0.1:4822`: `select` with the protocol, then `size`, `audio`, `video`, `image`, `timezone` and `connect` with the values of the protocol's `args`, taken from `params`, from `paramFiles` (each file under `/var/run/secrets/openova` read at each handshake, its trailing newline removed) and from the common table. With recording off no recording or typescript parameter is sent. A credential file that holds an expired certificate refuses the connection with end reason `credential-expired`.
4. **Relay.** An HTTP server on port 8443 of each pod address but loopback and link-local serves `/healthz` and `/tunnel`. `/tunnel` is a WebSocket; it refuses a request whose header `X-Access-Session-UID` is not the session's UID, takes one tunnel at a time, refuses a tunnel before `guacd` answers, and counts connections from 1. When `guacd` ends the connection the session ends with reason `user`; a tunnel the broker drops does not end the session.
5. **Shipper.** `ready` and `closed` go to the base address `ingest` of the configuration, with retry until the controller takes them; a refusal is not retried. With recording on, the files of the current connection under `/rec` are sealed in chunks by size, by time and at the end and put to the ingest route with retry; a chunk not delivered for 30 seconds, or a recording volume 90 percent or more full (statfs of `/rec`), fails the recording, and the agent then posts `closed` and exits with code 1. On SIGTERM the agent posts `closed` with reason `operator` after the last chunk.
6. **What the agent never does.** It reads no service-account token, opens no connection but to `guacd` on the loopback address, to the controller's base address and on its own listener, and logs no parameter value.
7. **Image.** `core/cmd/access-session-agent/Containerfile`: a build stage `golang:1.25.14-alpine3.24` pinned by digest builds with `CGO_ENABLED=0`; the final stage `gcr.io/distroless/static-debian12` pinned by digest runs the binary as `USER 10001:10001`, port 8443. The build context is the repository root.
8. **Agent build.** `.github/workflows/build-access-session-agent.yaml`, the shape of `build-k8s-ws-proxy.yaml`: job `test` (`go vet`, `go test -count=1 -race`) on pull requests and pushes that change the module or the workflow; on `main` job `build` builds and pushes the image with commit tags only, signs and attests it with `./.github/actions/sign-and-attest` and the inputs `release-key` and `release-key-password` (FND-063), writes `access.session.images.agent.digest` with yq v4.44.3, commits it with `./.github/actions/deploy-bump` and dispatches `blueprint-release` for `guacamole`.
9. **Mirror of guacd.** `.github/workflows/build-bp-guacamole.yaml` pulls `docker.io/guacamole/guacd@sha256:8974eaa9ba32f713daf311e7cc8cd7e4cdfba1edea39eed75524e78ef4b08f4f` (the index digest of tag 1.6.0), pushes `:latest`, pushes the version tag `1.6.0` only through `scripts/ci/push-version-tag.sh` (a version tag that exists is never moved), reads the digest that tag names, writes it to `access.session.images.guacd.digest`, bumps the patch version of `Chart.yaml` and commits both files. The dispatch input `upstream_version` and the default 1.5.5 are gone, and the `python3 -c` line that read the digest is replaced by the `--format '{{.Manifest.Digest}}'` of `docker buildx imagetools inspect`.
10. **Values.** `access.session.images.guacd` and `.agent`, each `repository` (`ghcr.io/openova-io/openova/guacd`, `ghcr.io/openova-io/openova/access-session-agent`) and `digest` (empty in Git until CI writes it). No other value changes.
11. **Controller environment.** `templates/controller-deployment.yaml` renders `env` only when one of the two digests is set, and `ACCESS_IMAGE_GUACD` or `ACCESS_IMAGE_AGENT` only when its own digest is set, through `bp-guacamole.registryImage`: a digest that is not `sha256:` and 64 hex digits fails the render, and `global.imageRegistry` moves the registry host. The rest of the Deployment does not change.
12. **Chart test.** `platform/guacamole/chart/tests/render.sh` case 3 asserts the two variables with both digests, with each alone, with neither (no `env`, and the Deployment otherwise equal), with `global.imageRegistry`, and that an agent digest `latest` fails the render; case 8 asserts the two repositories of `values.yaml`.
13. No new Python (one line of Python leaves a workflow), no change to a live system, no version line of a `Chart.yaml`.

+		}
+	}

+// address: the instruction format and the handshake of ADR-0033's tunnel, hop
+// 3, as spike ACC-020 recorded them against guacd 1.6.0.

+import (
+	"bufio"
+	"bytes"
+	"errors"

+	"strings"
+	"time"
+	"unicode/utf8"

+const (
+	maxElement     = 1 << 20 // code points of one element
+	maxInstruction = 4 << 20 // bytes of one instruction
+	// Timeout bounds the whole handshake.
+	Timeout = 30 * time.Second
+)
+
+// Encode writes one instruction: each element is <length>.<value>, the length
+// counted in Unicode code points; a comma separates elements, a semicolon ends
+// the instruction.
+func Encode(elems ...string) string {
+	var b strings.Builder
+	for i, e := range elems {
+		if i > 0 {
+			b.WriteByte(',')
+		}
+		b.WriteString(strconv.Itoa(utf8.RuneCountInString(e)))
+		b.WriteByte('.')
+		b.WriteString(e)
+	}
+	b.WriteByte(';')
+	return b.String()
+}
+
+// Reader reads instructions from guacd.
+type Reader struct{ r *bufio.Reader }
+
+// NewReader reads instructions from r.
+func NewReader(r io.Reader) *Reader { return &Reader{bufio.NewReaderSize(r, 64<<10)} }
+
+// Buffered is the number of bytes read from the connection and not returned.
+func (r *Reader) Buffered() int { return r.r.Buffered() }
+
+// Next returns the next whole instruction as it was sent, and its elements
+// when elems is true. A connection that ends between two instructions is
+// io.EOF; anything else that is not one valid instruction is an error.
+func (r *Reader) Next(elems bool) ([]byte, []string, error) {
+	var raw bytes.Buffer
+	var out []string
+	for {
+		head, err := r.r.ReadSlice('.')
+		if err != nil || len(head) > 11 {
+			if errors.Is(err, io.EOF) && len(head) == 0 && raw.Len() == 0 {
+				return nil, nil, io.EOF
+			}
+			return nil, nil, fmt.Errorf("no element length: %v", err)
+		}
+		n, err := strconv.Atoi(string(head[:len(head)-1]))
+		if err != nil || n < 0 || n > maxElement {
+			return nil, nil, fmt.Errorf("bad element length %q", head)
+		}
+		raw.Write(head)
+		start := raw.Len()
+		for i := 0; i < n; i++ {
+			b, err := r.r.ReadByte()
+			if err != nil {
+				return nil, nil, io.ErrUnexpectedEOF
+			}
+			raw.WriteByte(b)
+			for k := width(b); k > 1; k-- {
+				c, err := r.r.ReadByte()
+				if err != nil {
+					return nil, nil, io.ErrUnexpectedEOF
+				}
+				raw.WriteByte(c)
+			}
+		}
+		if elems {
+			out = append(out, string(raw.Bytes()[start:]))
+		}
+		t, err := r.r.ReadByte()
+		if err != nil {
+			return nil, nil, io.ErrUnexpectedEOF
+		}
+		raw.WriteByte(t)
+		if raw.Len() > maxInstruction {
+			return nil, nil, errors.New("an instruction is longer than 4 MiB")
+		}
+		switch t {
+		case ';':
+			if !utf8.Valid(raw.Bytes()) {
+				return nil, nil, errors.New("an instruction is not valid UTF-8")
+			}
+			return raw.Bytes(), out, nil
+		case ',':
+		default:
+			return nil, nil, fmt.Errorf("bad terminator %q", t)
+		}
+	}
+}
+
+// width is the length in bytes of the UTF-8 sequence that b starts.
+func width(b byte) int {
+	switch {
+	case b >= 0xF0:
+		return 4
+	case b >= 0xE0:
+		return 3
+	case b >= 0xC0:
+		return 2
+	}
+	return 1
+}
+
+// Size is what the browser reported of its display.
+type Size struct {
+	Width, Height, DPI int
+	Timezone           string
+}
+
+// GuacdError is an error instruction guacd sent instead of args or ready.
+type GuacdError struct{ Message, Status string }
+
+func (e *GuacdError) Error() string { return "guacd: " + e.Message + " (status " + e.Status + ")" }
+
+// Result is what a handshake gave: the connection identifier of ready and the
+// parameter names that guacd asked for.
+type Result struct {
+	ID   string
+	Args []string
+}
+
+// Run performs the handshake on conn: select with protocol; read args; send
+// size, audio and video (both empty), image, timezone and name; send connect
+// with, when args starts with a protocol version, that version first, then one
+// value per name in args, empty for a name params lacks; read ready. Every
+// byte guacd sends after ready stays in r.
+func Run(conn net.Conn, r *Reader, protocol, name string, s Size, params map[string]string) (Result, error) {
+	if err := conn.SetDeadline(time.Now().Add(Timeout)); err != nil {
+		return Result{}, err
+	}
+	send := func(elems ...string) error {
+		_, err := io.WriteString(conn, Encode(elems...))
+		return err
+	}
+	if err := send("select", protocol); err != nil {
+		return Result{}, err
+	}
+	args, err := expect(r, "args")
+	if err != nil {
+		return Result{}, err
+	}
+	for _, in := range [][]string{
+		{"size", strconv.Itoa(s.Width), strconv.Itoa(s.Height), strconv.Itoa(s.DPI)},
+		{"audio"}, {"video"}, {"image", "image/png", "image/jpeg", "image/webp"},
+		{"timezone", s.Timezone}, {"name", name},
+	} {
+		if err := send(in...); err != nil {
+			return Result{}, err
+		}
+	}
+	values := []string{"connect"}
+	if len(args) > 0 && strings.HasPrefix(args[0], "VERSION_") {
+		values, args = append(values, args[0]), args[1:]
+	}
+	for _, a := range args {
+		values = append(values, params[a])
+	}
+	if err := send(values...); err != nil {
+		return Result{}, err
+	}
+	ready, err := expect(r, "ready")
+	if err != nil {
+		return Result{}, err
+	}
+	if len(ready) != 1 {
+		return Result{}, fmt.Errorf("ready has %d values, want 1", len(ready))
+	}
+	return Result{ID: ready[0], Args: args}, conn.SetDeadline(time.Time{})
+}
+
+// expect reads one instruction and wants opcode op; it returns the values.
+func expect(r *Reader, op string) ([]string, error) {
+	_, el, err := r.Next(true)
+	switch {
+	case err != nil:
+		return nil, fmt.Errorf("waiting for %s: %w", op, err)
+	case el[0] == "error" && len(el) == 3:
+		return nil, &GuacdError{Message: el[1], Status: el[2]}
+	case el[0] != op:
+		return nil, fmt.Errorf("guacd sent %q, want %s", el[0], op)
+	}
+	return el[1:], nil
+}

+// ErrCredentialExpired says that a credential file holds a certificate whose
+// time has passed: a reconnect after the credential expired (reconnect rule).
+var ErrCredentialExpired = errors.New("a credential file holds an expired certificate")

+// Params builds the parameters of connection n (from 1): the literal
+// parameters of the configuration; the content of each parameter file, read
+// from dir now (never kept between handshakes) with one trailing newline
+// removed; and the parameters the agent sets itself. Recording and typescript
+// parameters are set only when the session is recorded.
+func Params(c *config.Config, n int, dir string, now time.Time) (map[string]string, error) {
+	p := map[string]string{}
+	for k, v := range c.Params {
+		p[k] = v
+	}
+	for k, name := range c.ParamFiles {
+		b, err := os.ReadFile(filepath.Clean(filepath.Join(dir, name)))
+		if err != nil {
+			return nil, fmt.Errorf("read the file of parameter %s: %w", k, err)
+		}
+		if expired(b, now) {
+			return nil, fmt.Errorf("parameter %s: %w", k, ErrCredentialExpired)
+		}
+		p[k] = strings.TrimSuffix(string(b), "\n")
+	}
+	p["disable-copy"] = strconv.FormatBool(!c.Controls.ClipboardCopy)
+	p["disable-paste"] = strconv.FormatBool(!c.Controls.ClipboardPaste)
+	if c.Recording() {
+		p["recording-path"], p["recording-name"], p["create-recording-path"] = RecPath, "screen-"+strconv.Itoa(n), "true"
+		p["recording-include-keys"] = strconv.FormatBool(c.Controls.Keystrokes)
+		if c.Terminal {
+			p["typescript-path"], p["typescript-name"], p["create-typescript-path"] = RecPath, "typescript-"+strconv.Itoa(n), "true"
+		}
+	}
+	return p, nil

+// expired says whether b holds a PEM certificate that is no longer valid at now.
+func expired(b []byte, now time.Time) bool {
+	for rest := b; ; {
+		var blk *pem.Block
+		if blk, rest = pem.Decode(rest); blk == nil {
+			return false
+		}
+		if blk.Type != "CERTIFICATE" {
+			continue
+		}
+		if cert, err := x509.ParseCertificate(blk.Bytes); err == nil && now.After(cert.NotAfter) {
+			return true
+		}
+	}
+}

+// CredentialID names what was issued for the session, never a secret: the
+// serial of the client certificate (kind pod), the database user (kind
+// database) or the SSH key identifier, which is the session UID (kind ssh).
+func CredentialID(c *config.Config, dir string) (string, error) {
+	switch c.Kind {
+	case "ssh":
+		return c.SessionUID, nil
+	case "database":
+		b, err := os.ReadFile(filepath.Clean(filepath.Join(dir, "db-username")))
+		user := strings.TrimSpace(string(b))
+		if err == nil && user == "" {
+			err = errors.New("the file db-username is empty")
+		}
+		return user, err
+	case "pod":
+		name, ok := c.ParamFiles["client-cert"]
+		if !ok {
+			return "", errors.New("kind pod has no parameter file client-cert")
+		}
+		b, err := os.ReadFile(filepath.Clean(filepath.Join(dir, name)))
+		if err != nil {
+			return "", err
+		}
+		blk, _ := pem.Decode(b)
+		if blk == nil {
+			return "", fmt.Errorf("the file %s holds no PEM block", name)
+		}
+		cert, err := x509.ParseCertificate(blk.Bytes)
+		if err != nil {
+			return "", fmt.Errorf("the file %s: %w", name, err)
+		}
+		return serial(cert.SerialNumber.Bytes()), nil
+	}
+	return "", fmt.Errorf("kind %q has no credential identifier", c.Kind)
+}

+// serial writes a serial number as OpenBao does: hexadecimal bytes joined by colons.
+func serial(b []byte) string {
+	if len(b) == 0 {
+		b = []byte{0}
+	}
+	parts := make([]string, len(b))
+	for i := range b {
+		parts[i] = hex.EncodeToString(b[i : i+1])
+	}
+	return strings.Join(parts, ":")

+// UIDHeader carries the UID of the session the broker opens a tunnel for.

+// End is how a connection ended.
+type End string

+const (
+	// Dropped: the broker's socket ended first. The session stays; the broker
+	// may open the next connection (reconnect rule).
+	Dropped End = "dropped"
+	// GuacdEnded: guacd ended the connection, so the protocol session is over.
+	GuacdEnded End = "guacd-ended"
+	// Refused: the handshake did not reach ready.
+	Refused End = "refused"
+	// Shutdown: Close ended it.
+	Shutdown End = "shutdown"

+	Now     func() time.Time
+	Begin   func(n int)                     // before the handshake of connection n
+	Finish  func(n int, how End, err error) // after connection n ended

+func (s *Server) ServeHTTP(w http.ResponseWriter, r *http.Request) {

+			return

+	case "/tunnel":

+	default:

+	}

+func (s *Server) tunnel(w http.ResponseWriter, r *http.Request) {
+	if r.Method != http.MethodGet {
+		fail(w, http.StatusMethodNotAllowed, "method", "only GET opens a tunnel")
+		return
+	}
+	if r.Header.Get(UIDHeader) != s.Config.SessionUID {
+		fail(w, http.StatusForbidden, "uid-mismatch", "the tunnel is not for this session")
+		return
+	}
+	size, err := parseSize(r)
+	if err != nil {
+		fail(w, http.StatusBadRequest, "bad-size", err.Error())
+		return
+	}
+	n, code := s.claim()
+	if code != "" {
+		fail(w, http.StatusConflict, code, "the agent holds a tunnel already, or is shutting down")
+		return
+	}
+	defer s.release()
+	s.Begin(n)
+	g, rd, err := s.handshake(r.Context(), n, size)
+	if err != nil {
+		s.Log.Warn("the handshake failed", "connection", n, "error", err)
+		fail(w, http.StatusBadGateway, "handshake-failed", "guacd did not accept the connection")
+		s.Finish(n, Refused, err)
+		return
+	}
+	ws, err := s.upgrader.Upgrade(w, r, nil)
+	if err != nil {
+		_ = g.Close()
+		s.Finish(n, Dropped, err)
+		return
+	}
+	if !s.track(ws, g) {
+		_ = ws.Close()
+		_ = g.Close()
+		s.Finish(n, Shutdown, nil)
+		return
+	}
+	s.Log.Info("tunnel open", "connection", n)
+	how := pump(ws, g, rd)
+	if s.isClosed() {
+		how = Shutdown
+	}
+	s.Log.Info("tunnel ended", "connection", n, "how", string(how))
+	s.Finish(n, how, nil)
+}

+// handshake dials guacd and runs the handshake of connection n. The
+// parameter values are never logged.
+func (s *Server) handshake(ctx context.Context, n int, size handshake.Size) (net.Conn, *handshake.Reader, error) {
+	params, err := handshake.Params(s.Config, n, s.CredDir, s.Now())
+	if err != nil {
+		return nil, nil, err
+	}
+	g, err := s.Dial(ctx)
+	if err != nil {
+		return nil, nil, err
+	}
+	rd := handshake.NewReader(g)
+	if _, err := handshake.Run(g, rd, s.Config.Protocol, s.Config.Subject, size, params); err != nil {
+		_ = g.Close()
+		return nil, nil, err
+	}
+	return g, rd, nil
+}

+// pump copies guacd's instructions to the broker, whole instructions in one
+// text message, and the broker's messages to guacd unchanged, until one side
+// ends. The side that ended first says how the connection ended.
+func pump(ws *websocket.Conn, g net.Conn, rd *handshake.Reader) End {
+	ws.SetReadLimit(1 << 20)
+	done := make(chan End, 2)
+	go func() {
+		var buf []byte
+		for {
+			raw, _, err := rd.Next(false)
+			buf = append(buf, raw...)
+			if len(buf) > 0 && (err != nil || rd.Buffered() == 0 || len(buf) >= batchMax) {
+				if werr := ws.WriteMessage(websocket.TextMessage, buf); werr != nil {
+					done <- Dropped
+					return
+				}
+				buf = buf[:0]
+			}
+			if err != nil {
+				done <- GuacdEnded
+				return
+			}
+		}
+	}()
+	go func() {
+		for {
+			_, msg, err := ws.ReadMessage()
+			if err != nil {
+				done <- Dropped
+				return
+			}
+			if _, err := g.Write(msg); err != nil {
+				done <- GuacdEnded
+				return
+			}
+		}
+	}()
+	how := <-done
+	if how == GuacdEnded {
+		_ = ws.WriteControl(websocket.CloseMessage, websocket.FormatCloseMessage(websocket.CloseNormalClosure, ""), time.Now().Add(time.Second))
+	}
+	_ = ws.Close()
+	_ = g.Close()
+	<-done
+	return how
+}

+func parseSize(r *http.Request) (handshake.Size, error) {
+	q := r.URL.Query()
+	num := func(k string, max int) (int, error) {
+		v, err := strconv.Atoi(q.Get(k))
+		if err != nil || v < 1 || v > max {
+			return 0, errors.New("query " + k + " is not an integer from 1 to " + strconv.Itoa(max))
+		}
+		return v, nil
+	}
+	var s handshake.Size
+	var err error
+	if s.Width, err = num("width", 16384); err != nil {
+		return s, err
+	}
+	if s.Height, err = num("height", 16384); err != nil {
+		return s, err
+	}
+	if s.DPI, err = num("dpi", 2400); err != nil {
+		return s, err
+	}
+	if s.Timezone = q.Get("timezone"); !timezoneRE.MatchString(s.Timezone) {
+		return s, errors.New("query timezone is not a time zone name")
+	}
+	return s, nil
+}

+func (s *Server) claim() (int, string) {
+	s.mu.Lock()
+	defer s.mu.Unlock()
+	switch {
+	case s.closed:
+		return 0, "shutting-down"
+	case s.busy:
+		return 0, "busy"
+	}
+	s.busy = true
+	s.open.Add(1)
+	s.n++
+	return s.n, ""
+}

+func (s *Server) release() {
+	s.mu.Lock()
+	defer s.mu.Unlock()
+	s.busy, s.active = false, nil
+	s.open.Done()
+}

+// Wait returns when no tunnel is open. After Close no tunnel opens.
+func (s *Server) Wait() { s.open.Wait() }

+func (s *Server) track(c ...io.Closer) bool {
+	s.mu.Lock()
+	defer s.mu.Unlock()
+	s.active = c
+	return !s.closed
+}

+func (s *Server) isClosed() bool {
+	s.mu.Lock()
+	defer s.mu.Unlock()
+	return s.closed
+}

+// Close takes no new tunnel and ends the open one.
+func (s *Server) Close() {
+	s.mu.Lock()
+	defer s.mu.Unlock()
+	s.closed = true
+	for _, c := range s.active {
+		_ = c.Close()
+	}
+}

+// it posts ready and closed, and puts the chunks of the recording.
+package shipper
+
+import (
+	"bytes"
+	"context"
+	"crypto/sha256"
+	"encoding/hex"
+	"encoding/json"
+	"errors"
+	"fmt"

+	"net/http"
+	"strconv"
+	"time"

+
+// Client calls the routes under the base address of the controller's
+// internal port.
+type Client struct {
+	Base  string // the configuration's ingest, without a final slash
+	UID   string
+	HTTP  *http.Client
+	Pause time.Duration // the pause after the first failed attempt; it doubles up to 5 seconds
+}
+
+// Refused is an answer in the 4xx range: another attempt cannot change it.
+type Refused struct {
+	Status int
+	Body   string
+}
+
+func (e *Refused) Error() string {
+	return fmt.Sprintf("the controller refused with %d: %s", e.Status, e.Body)
+}
+
+// Ready posts ready with the credential identifier until the controller takes
+// it, refuses it, or ctx ends.
+func (c *Client) Ready(ctx context.Context, credentialID string) error {
+	return c.retry(ctx, func() error { return c.post(ctx, "ready", map[string]string{"credentialID": credentialID}) })
+}
+
+// Closed posts closed with an end reason until the controller takes it,
+// refuses it, or ctx ends.
+func (c *Client) Closed(ctx context.Context, reason string) error {
+	return c.retry(ctx, func() error { return c.post(ctx, "closed", map[string]string{"reason": reason}) })
+}
+
+// Chunk puts chunk seq (from 1) of a stream with its SHA-256 until the
+// controller takes it, refuses it, or giveUp has passed.
+func (c *Client) Chunk(ctx context.Context, stream string, seq int, b []byte, giveUp time.Duration) error {
+	ctx, cancel := context.WithTimeout(ctx, giveUp)
+	defer cancel()
+	sum := sha256.Sum256(b)
+	path := "/internal/v1/sessions/" + c.UID + "/streams/" + stream + "/chunks/" + strconv.Itoa(seq)
+	return c.retry(ctx, func() error {
+		return c.send(ctx, http.MethodPut, path, b, map[string]string{"X-Chunk-SHA256": hex.EncodeToString(sum[:])})
+	})
+}
+
+func (c *Client) post(ctx context.Context, route string, body map[string]string) error {
+	b, err := json.Marshal(body)
+	if err != nil {
+		return err
+	}
+	return c.send(ctx, http.MethodPost, "/internal/v1/sessions/"+c.UID+"/"+route, b, map[string]string{"Content-Type": "application/json"})
+}
+
+// send makes one attempt.
+func (c *Client) send(ctx context.Context, method, path string, body []byte, header map[string]string) error {
+	req, err := http.NewRequestWithContext(ctx, method, c.Base+path, bytes.NewReader(body))
+	if err != nil {
+		return err
+	}
+	for k, v := range header {
+		req.Header.Set(k, v)
+	}
+	resp, err := c.HTTP.Do(req)
+	if err != nil {
+		return err
+	}
+	defer func() { _ = resp.Body.Close() }()
+	text, _ := io.ReadAll(io.LimitReader(resp.Body, 512))
+	switch {
+	case resp.StatusCode >= 200 && resp.StatusCode < 300:
+		return nil
+	case resp.StatusCode >= 400 && resp.StatusCode < 500:
+		return &Refused{Status: resp.StatusCode, Body: string(text)}
+	}
+	return fmt.Errorf("%s %s answered %d", method, path, resp.StatusCode)
+}
+
+// retry runs attempt until it succeeds, it is refused, or ctx ends.
+func (c *Client) retry(ctx context.Context, attempt func() error) error {
+	pause := c.Pause
+	for {
+		err := attempt()
+		var refused *Refused
+		if err == nil || errors.As(err, &refused) {
+			return err
+		}
+		t := time.NewTimer(pause)
+		select {
+		case <-ctx.Done():
+			t.Stop()
+			return fmt.Errorf("%w; the last attempt: %v", ctx.Err(), err)
+		case <-t.C:
+		}
+		pause = min(2*pause, 5*time.Second)
+	}
+}

+// End reasons of a failed recording (the session's endReason).
+const (
+	RecordingFailed     = "recording-failed"
+	RecordingVolumeFull = "recording-volume-full"
+)
+
+// Failure ends the session: the recording cannot go on.
+type Failure struct {
+	Reason string
+	Err    error
+}
+
+// Recorder ships the recording files that guacd writes for each connection:
+// screen-<n>, and with a terminal typescript-<n> and typescript-<n>.timing,
+// as the streams screen-<n>, typescript-<n> and typescript-timing-<n>. A chunk
+// is sealed when ChunkBytes are unsent, when ChunkTime passed since the first
+// unsent byte was read, and when the connection ends.
+type Recorder struct {
+	Client     *Client
+	Dir        string
+	ChunkBytes int
+	ChunkTime  time.Duration
+	Terminal   bool
+	GiveUp     time.Duration           // a chunk not delivered for this long fails the recording (30 s)
+	Settle     time.Duration           // at the end, the files are read until they did not grow for this long
+	Used       func() (float64, error) // the share of the recording volume in use; 0.9 or more fails it
+}
+
+// Connection ships the files of one connection until Stop.
+type Connection struct {
+	watch   io.Closer
+	streams []*stream
+	wg      sync.WaitGroup
+}
+
+type stream struct {
+	r      *Recorder
+	name   string
+	path   string
+	f      *os.File
+	seq    int
+	wake   chan struct{}
+	stop   chan struct{}
+	failed func(Failure)
+}
+
+// Follow starts shipping the files of connection n. A failure is reported
+// once to failed, and that stream ships nothing more.
+func (r *Recorder) Follow(ctx context.Context, n int, failed func(Failure)) (*Connection, error) {
+	c := &Connection{}
+	names := [][2]string{{"screen-" + strconv.Itoa(n), "screen-" + strconv.Itoa(n)}}
+	if r.Terminal {
+		names = append(names, [2]string{"typescript-" + strconv.Itoa(n), "typescript-" + strconv.Itoa(n)},
+			[2]string{"typescript-timing-" + strconv.Itoa(n), "typescript-" + strconv.Itoa(n) + ".timing"})
+	}
+	for _, nm := range names {
+		c.streams = append(c.streams, &stream{r: r, name: nm[0], path: filepath.Join(r.Dir, nm[1]),
+			wake: make(chan struct{}, 1), stop: make(chan struct{}), failed: failed})
+	}
+	var once sync.Once
+	var last time.Time
+	w, err := watch(r.Dir, func() {
+		for _, s := range c.streams {
+			select {
+			case s.wake <- struct{}{}:
+			default:
+			}
+		}
+		if time.Since(last) < time.Second {
+			return
+		}
+		last = time.Now()
+		if used, err := r.Used(); err != nil || used >= 0.9 {
+			once.Do(func() {
+				failed(Failure{RecordingVolumeFull, fmt.Errorf("the recording volume is %.0f%% full (%v)", 100*used, err)})
+			})
+		}
+	})
+	if err != nil {
+		return nil, err
+	}
+	c.watch = w
+	for _, s := range c.streams {
+		c.wg.Add(1)
+		go func() { defer c.wg.Done(); s.run(ctx) }()
+	}
+	return c, nil
+}
+
+// Stop seals and ships what is left of every file, then returns.
+func (c *Connection) Stop() {
+	for _, s := range c.streams {
+		close(s.stop)
+	}
+	c.wg.Wait()
+	_ = c.watch.Close()
+	for _, s := range c.streams {
+		if s.f != nil {
+			_ = s.f.Close()
+		}
+	}
+}

+func (s *stream) run(ctx context.Context) {
+	var pending []byte
+	var first time.Time
+	timer := time.NewTimer(time.Hour)
+	timer.Stop()
+	for stopping := false; ; {
+		select {
+		case <-s.wake:
+		case <-timer.C:
+		case <-s.stop:
+			stopping = true
+			s.settle()
+		}
+		b, err := s.read()
+		if err != nil {
+			s.failed(Failure{RecordingFailed, err})
+			return
+		}
+		if len(b) > 0 && len(pending) == 0 {
+			first = time.Now()
+			timer.Reset(s.r.ChunkTime)
+		}
+		pending = append(pending, b...)
+		for len(pending) >= s.r.ChunkBytes || (len(pending) > 0 && (stopping || time.Since(first) >= s.r.ChunkTime)) {
+			k := min(len(pending), s.r.ChunkBytes)
+			s.seq++
+			if err := s.r.Client.Chunk(ctx, s.name, s.seq, pending[:k], s.r.GiveUp); err != nil {
+				s.failed(Failure{RecordingFailed, fmt.Errorf("chunk %d of stream %s: %w", s.seq, s.name, err)})
+				return
+			}
+			if pending = pending[k:]; len(pending) > 0 {
+				first = time.Now()
+				timer.Reset(s.r.ChunkTime)
+			}
+		}
+		if stopping {
+			return
+		}
+	}
+}
+
+// settle waits until the file did not change for Settle, at most 8 times as long.
+func (s *stream) settle() {
+	limit := time.NewTimer(8 * s.r.Settle)
+	defer limit.Stop()
+	for {
+		quiet := time.NewTimer(s.r.Settle)
+		select {
+		case <-s.wake:
+			quiet.Stop()
+		case <-quiet.C:
+			return
+		case <-limit.C:
+			quiet.Stop()
+			return
+		}
+	}
+}

+// read returns the bytes the file gained since the last read; nothing while
+// guacd has not created it.
+func (s *stream) read() ([]byte, error) {
+	if s.f == nil {
+		f, err := os.Open(filepath.Clean(s.path))
+		if errors.Is(err, os.ErrNotExist) {
+			return nil, nil
+		}
+		if err != nil {
+			return nil, err
+		}
+		s.f = f
+	}
+	return io.ReadAll(s.f)
+}

+// watch calls wake on every change of a file in dir (inotify, no timer).
+func watch(dir string, wake func()) (io.Closer, error) {
+	fd, err := syscall.InotifyInit1(syscall.IN_NONBLOCK | syscall.IN_CLOEXEC)
+	if err != nil {
+		return nil, fmt.Errorf("inotify: %w", err)
+	}
+	if _, err := syscall.InotifyAddWatch(fd, dir, syscall.IN_CREATE|syscall.IN_MODIFY|syscall.IN_CLOSE_WRITE|syscall.IN_MOVED_TO); err != nil {
+		_ = syscall.Close(fd)
+		return nil, fmt.Errorf("watch %s: %w", dir, err)
+	}
+	f := os.NewFile(uintptr(fd), "inotify")
+	go func() {
+		buf := make([]byte, 16<<10)
+		for {
+			if _, err := f.Read(buf); err != nil {
+				return
+			}
+			wake()
+		}
+	}()
+	return f, nil
+}

+// VolumeUsed is the share of the file system of dir in use, by statfs.
+func VolumeUsed(dir string) func() (float64, error) {
+	return func() (float64, error) {
+		var st syscall.Statfs_t
+		if err := syscall.Statfs(dir, &st); err != nil {
+			return 0, err
+		}
+		if st.Blocks == 0 {
+			return 0, errors.New("the file system reports no blocks")
+		}
+		return float64(st.Blocks-st.Bfree) / float64(st.Blocks), nil
+	}

+	answers []int
+	calls   []call

+func (in *ingest) ServeHTTP(w http.ResponseWriter, r *http.Request) {

+	in.mu.Lock()

+	if len(in.answers) > 1 {
+		in.answers = in.answers[1:]
+	}
+	in.mu.Unlock()
+	w.WriteHeader(status)

+// podListeners listens on port of each address of the pod but loopback and
+// link-local: the broker dials status.podIP; loopback is guacd's alone.
+func podListeners(port string) ([]net.Listener, error) {
+	addrs, err := net.InterfaceAddrs()
+	if err != nil {
+		return nil, err
+	}
+	var out []net.Listener
+	for _, a := range addrs {
+		ip, ok := a.(*net.IPNet)
+		if !ok || ip.IP.IsLoopback() || ip.IP.IsLinkLocalUnicast() {
+			continue
+		}
+		ln, err := net.Listen("tcp", net.JoinHostPort(ip.IP.String(), port))
+		if err != nil {
+			return nil, err
+		}
+		out = append(out, ln)
+	}
+	if len(out) == 0 {
+		return nil, errors.New("the pod has no address but loopback")
+	}
+	return out, nil

+func run(ctx context.Context, o options) int {
+	cfg, err := config.Load(o.config)
+	if err != nil {
+		o.log.Error("the configuration cannot be used", "path", o.config, "error", err)
+		return exitConfig
+	}
+	credentialID, err := handshake.CredentialID(cfg, o.creds)
+	if err != nil {
+		o.log.Error("no credential identifier", "kind", cfg.Kind, "error", err)
+		return 1
+	}
+	client := &shipper.Client{Base: strings.TrimSuffix(cfg.Ingest, "/"), UID: cfg.SessionUID, HTTP: &http.Client{Timeout: 10 * time.Second}, Pause: o.pause}
+	rec := &shipper.Recorder{Client: client, Dir: o.rec, ChunkBytes: cfg.ChunkBytes, ChunkTime: time.Duration(cfg.ChunkSeconds) * time.Second,
+		Terminal: cfg.Terminal, GiveUp: o.giveUp, Settle: o.settle, Used: o.used}
+	work, cancelWork := context.WithCancel(context.WithoutCancel(ctx)) // outlives SIGTERM until the last chunk
+	defer cancelWork()
+
+	ended := make(chan shipper.Failure, 4) // the first end the agent sees ends the session
+	end := func(f shipper.Failure) {
+		select {
+		case ended <- f:
+		default:
+		}
+	}
+	var mu sync.Mutex
+	var current *shipper.Connection
+	dialer := &net.Dialer{Timeout: 2 * time.Second}
+	srv := &relay.Server{Config: cfg, CredDir: o.creds, Now: time.Now, Log: o.log,
+		Dial: func(ctx context.Context) (net.Conn, error) { return dialer.DialContext(ctx, "tcp", o.guacd) },
+		Begin: func(n int) {
+			if !cfg.Recording() {
+				return
+			}
+			c, err := rec.Follow(work, n, end)
+			if err != nil {
+				end(shipper.Failure{Reason: shipper.RecordingFailed, Err: err})
+				return
+			}
+			mu.Lock()
+			current = c
+			mu.Unlock()
+		},
+		Finish: func(n int, how relay.End, err error) {
+			mu.Lock()
+			c := current
+			current = nil
+			mu.Unlock()
+			if c != nil {
+				c.Stop()
+			}
+			switch {
+			case how == relay.GuacdEnded:
+				end(shipper.Failure{Reason: "user"})
+			case how == relay.Refused && errors.Is(err, handshake.ErrCredentialExpired):
+				end(shipper.Failure{Reason: "credential-expired", Err: err})
+			case how == relay.Refused:
+				end(shipper.Failure{Reason: "start-failed", Err: err})
+			}
+		},
+	}
+	hs := &http.Server{Handler: srv, ReadHeaderTimeout: 10 * time.Second}
+	for _, ln := range o.listeners {
+		go func() { _ = hs.Serve(ln) }()
+	}
+	go func() {
+		if err := waitForGuacd(work, srv.Dial); err != nil {
+			return
+		}
+		if err := client.Ready(work, credentialID); err != nil {
+			o.log.Error("ready was not delivered", "error", err)
+			return
+		}
+		o.log.Info("ready delivered", "credentialID", credentialID)
+	}()
+
+	code, reason := 0, operator
+	select {
+	case <-ctx.Done():
+	case f := <-ended:
+		reason = f.Reason
+		if f.Reason == shipper.RecordingFailed || f.Reason == shipper.RecordingVolumeFull {
+			code = 1
+		}
+		o.log.Info("the session ends", "reason", f.Reason, "error", f.Err)
+	}
+	srv.Close()
+	_ = hs.Close()
+	srv.Wait()
+	closing, cancel := context.WithTimeout(work, 15*time.Second)
+	defer cancel()
+	if err := client.Closed(closing, reason); err != nil {
+		o.log.Error("closed was not delivered", "reason", reason, "error", err)
+		return 1
+	}
+	return code
+}

+// waitForGuacd returns once guacd accepts a connection.
+func waitForGuacd(ctx context.Context, dial func(context.Context) (net.Conn, error)) error {
+	for {

+		select {
+		case <-ctx.Done():
+			t.Stop()
+			return ctx.Err()
+		case <-t.C:
+		}
+	}
