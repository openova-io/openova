# SOV-760 — Kit keys are set by commit and at provisioning

## In plain words

**The problem today.** A sovereign-admin cannot change a kit key of a running Sovereign. The variables document of each region is committed once, when the region is seeded, and no route of the API edits it afterwards.

**What changes.** A new route of the API sets one listed kit key in the variables documents of the chosen regions, with one commit to the fleet repository. The keys it may set are a list in the contracts folder, empty for now; the matching field of the create request is a later task.

**Done means:**

- A session of tier owner that sets a listed key gets one commit that changes the variables document of every named region, or of every region when none is named.
- Setting a key to the value it already holds makes no commit.
- A key that is not on the list, a value with a control character, an unknown region and a session of another tier are each refused, and nothing is committed.
- A region whose document is not seeded yet, or a document that changed since it was read, is answered with 409; an API without its Git configuration answers 503.
- The list of settable keys exists in the contracts folder and, byte for byte, inside the API; it holds no key yet.
- The route is in the routes table of the API and in the contract of mutating routes, with write class git.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
catalyst-api serves `PUT /api/v1/sovereign/kit-keys/{key}`. A session of tier owner sends `{"value": "<string>", "regions": ["<region-id>"]}` (regions optional) and the API sets `data[<key>]` of the ConfigMap document `clusters/<fqdn>/regions/<region-id>/platform/root/sovereign-variables.yaml` of the fleet repository in every named region, or in every region when `regions` is absent or empty, with one commit of the commit library (contract `docs/contracts/C4-git-layout-and-commit-library.md`, scope RegionPlatform, module `root`). Flux then applies the document as ConfigMap `flux-system/sovereign-variables`. Only the keys of the new list `docs/contracts/c5-kit-keys-settable.txt` are accepted; the list is empty, so today every key is refused, and the package that ships the reader of a key adds the key there. This package is the route only: the optional field `kitKeys` of the create request is package SOV-761, which depends on this one.

## 3. The model (the law)
1. **One route.** `PUT /api/v1/sovereign/kit-keys/{key}` is registered in `registerSessionSovereign` (`products/catalyst/bootstrap/api/cmd/api/routes_sovereign.go`) next to the release route, served by `(*lifecycle.KitKeysRoute).Put` (`products/catalyst/bootstrap/api/internal/lifecycle/kitkeys.go`). It is one line of `cmd/api/testdata/routes.golden` (`PUT /api/v1/sovereign/kit-keys/{key} lifecycle.(*KitKeysRoute).Put-fm 2`) and one row of `docs/contracts/C9-mutating-routes.yaml` (`today: G`, `writeClass: git`, `disposition: keep`, `done: true`).
2. **Tier owner only.** A request without a session, or with a session that has neither the realm role `catalyst-owner` nor the tier `owner`, is answered 403 `forbidden` (`SovereignOwner`).
3. **Only listed keys.** A key that is not a line of the settable list is answered 400 `key-not-settable` with `field: key`. The list is parsed by `ParseKitKeyList` (one key per line, `#` comments and blank lines skipped, a line that is not a key name is an error). The API embeds a byte copy of the list, `cmd/api/contract/c5-kit-keys-settable.txt`, because an embed cannot leave its Go module; `TestSettableKitKeysCopy` fails when the copies differ. At start the API refuses a list that holds a key that is not a kit key of `docs/contracts/c5-kit-keys.txt` (`upstream.KitKeys()`): it logs the error and then sets no key at all.
4. **The body.** Unknown fields are refused (400 `bad-body`). `value` is required and is valid UTF-8 without a control character, because Flux substitutes it into manifests as it is (400 `bad-value`, `field: value`). A region that is not a folder of the Sovereign is answered 400 `unknown-region` with `field: regions`; repeated region ids are taken once.
5. **One commit.** Every named document is read with its blob SHA and written back with `IfMatch` on that SHA, all in one `gitwrite.Change` (summary `kit-keys: set <key>`, via API, the session's e-mail as author). The edit sets `data[<key>]` and the annotation `catalyst.openova.io/change-id`; it refuses a document that is not ConfigMap `sovereign-variables` (409 `bad-document`). When every document already holds the value, no file changes and the commit library makes no commit. Nothing is written to a cluster.
6. **The answers.** 202 `{"commit", "paths"}` on success. 409 `region-not-seeded` when a region has no document, 409 `no-region` when the Sovereign has no region folder, 409 `head-moved` when a file changed since it was read (the caller sends again). 503 `git-not-configured` when the commit library has no configuration (the same `CATALYST_GITEA_URL`, `CATALYST_GITEA_TOKEN` and `SOVEREIGN_FQDN` that the intent route reads through `intentGitConfig`), 503 `git-unavailable` when the repository cannot be reached.
7. Flips no gate check. No new Python, no change to a live system, no version line of a `Chart.yaml`. The field `kitKeys` of the create request is not added here (SOV-761).

+// settableKitKeys parses a settable key list and refuses a key that is not
+// one of kit, the kit keys of contract C5 (upstream.KitKeys).
+func settableKitKeys(text string, kit []string) (map[string]bool, error) {
+	keys, err := lifecycle.ParseKitKeyList(text)
+	for k := range keys {
+		if !slices.Contains(kit, k) {
+			return nil, fmt.Errorf("%s is not a kit key of docs/contracts/c5-kit-keys.txt", k)
+		}
+	}
+	return keys, err
+}

+// newKitKeysRoute builds PUT /api/v1/sovereign/kit-keys/{key} with the commit
+// library of package intent (intentGitConfig). Without that configuration the
+// route has no Git and answers 503; with a settable list that is refused it
+// has no settable key and refuses every key. getenv is os.Getenv in production.
+func newKitKeysRoute(log *slog.Logger, getenv func(string) string) *lifecycle.KitKeysRoute {
+	route := &lifecycle.KitKeysRoute{Log: log, FQDN: strings.TrimSpace(getenv("SOVEREIGN_FQDN"))}
+	var err error
+	if route.Settable, err = settableKitKeys(settableKitKeysText, upstream.KitKeys()); err != nil {
+		log.Error("kit keys: the settable list is refused; no kit key can be set", "err", err)
+	}
+	cfg, err := intentGitConfig(getenv)
+	if err == nil {
+		route.Git, err = gitwrite.New(cfg)
+	}
+	if err != nil {
+		route.Git = nil
+		log.Warn("kit keys: the commit library is not configured; the route answers 503", "err", err)
+	}
+	return route

+//
+// PUT /api/v1/sovereign/kit-keys/{key} with the body {"value": "<string>",
+// "regions": ["<region-id>"]} sets one kit key in the variables document of
+// the named regions, or of every region when regions is absent or empty: the

+// keys of docs/contracts/c5-kit-keys-settable.txt are accepted.

+// answers 202 {"commit","paths"}; 400 {"error","field"} for a refused key,

+// kitKeyName is a key name short enough that the commit summary

+// ParseKitKeyList reads a key list in the form of
+// docs/contracts/c5-kit-keys-settable.txt: one key per line; blank lines and
+// lines that start with # are skipped. A line that is not a key name is an error.
+func ParseKitKeyList(text string) (map[string]bool, error) {
+	keys := map[string]bool{}
+	for i, line := range strings.Split(text, "\n") {
+		line = strings.TrimSpace(line)
+		if line == "" || strings.HasPrefix(line, "#") {
+			continue
+		}
+		if !kitKeyName.MatchString(line) {
+			return nil, fmt.Errorf("line %d: %q is not a key name", i+1, line)
+		}
+		keys[line] = true
+	}
+	return keys, nil
+}

+func kitKeyRefuse(w http.ResponseWriter, code int, errCode, field, detail string) {
+	body := map[string]string{"error": errCode, "detail": detail}
+	if field != "" {
+		body["field"] = field
+	}
+	writeJSON(w, code, body)

+// gitRefuse answers a failed call of the commit library.
+func gitRefuse(w http.ResponseWriter, what string, err error) {
+	switch {
+	case gitwrite.IsConflict(err):
+		kitKeyRefuse(w, http.StatusConflict, "head-moved", "", what+": the file changed since it was read; send the request again")
+	case errors.Is(err, gitwrite.ErrUnavailable):
+		kitKeyRefuse(w, http.StatusServiceUnavailable, "git-unavailable", "", what+": "+err.Error())
+	default:
+		kitKeyRefuse(w, http.StatusInternalServerError, "git-failed", "", what+": "+err.Error())
+	}

+// validKitKeyValue reports whether v is valid UTF-8 without a control
+// character: Flux substitutes the value into manifests as it is.
+func validKitKeyValue(v string) bool {
+	for _, r := range v {
+		if r < 0x20 || r == 0x7f {
+			return false
+		}
+	}
+	return utf8.ValidString(v)

+// Put handles PUT /api/v1/sovereign/kit-keys/{key}.
+func (k *KitKeysRoute) Put(w http.ResponseWriter, r *http.Request) {
+	claims := auth.ClaimsFromContext(r.Context())
+	if !SovereignOwner(claims) {
+		kitKeyRefuse(w, http.StatusForbidden, "forbidden", "", "a kit key is set by a session of tier owner")
+		return
+	}
+	key := chi.URLParam(r, "key")
+	if !k.Settable[key] {
+		kitKeyRefuse(w, http.StatusBadRequest, "key-not-settable", "key", fmt.Sprintf("%q is not listed in docs/contracts/c5-kit-keys-settable.txt", key))
+		return
+	}
+	var req struct {
+		Value   *string  `json:"value"`
+		Regions []string `json:"regions"`
+	}
+	dec := json.NewDecoder(http.MaxBytesReader(w, r.Body, maxKitKeyBody))
+	dec.DisallowUnknownFields()
+	if err := dec.Decode(&req); err != nil {
+		kitKeyRefuse(w, http.StatusBadRequest, "bad-body", "", err.Error())
+		return
+	}
+	if req.Value == nil || !validKitKeyValue(*req.Value) {
+		kitKeyRefuse(w, http.StatusBadRequest, "bad-value", "value", "value is a string without control characters")
+		return
+	}
+	if k.Git == nil {
+		kitKeyRefuse(w, http.StatusServiceUnavailable, "git-not-configured", "", "the commit library is not configured on this API")
+		return
+	}
+	ctx := r.Context()
+	all, err := gitwrite.Regions(ctx, k.Git, FleetRepo, k.FQDN)
+	if err != nil {
+		gitRefuse(w, "list the regions", err)
+		return
+	}
+	regions := all
+	if len(req.Regions) > 0 {
+		regions = nil
+		for _, id := range req.Regions {
+			if i := sort.SearchStrings(all, id); i == len(all) || all[i] != id {
+				kitKeyRefuse(w, http.StatusBadRequest, "unknown-region", "regions", fmt.Sprintf("%q is not a region of %s", id, k.FQDN))
+				return
+			}
+			if i := sort.SearchStrings(regions, id); i == len(regions) || regions[i] != id {
+				regions = append(regions[:i], append([]string{id}, regions[i:]...)...)
+			}
+		}
+	}
+	if len(regions) == 0 {
+		kitKeyRefuse(w, http.StatusConflict, "no-region", "", "the repository holds no region folder of "+k.FQDN)
+		return
+	}
+	scope := gitwrite.RegionPlatform(k.FQDN, []string{"root"}, regions)
+	change := gitwrite.Change{Scope: scope, Repo: FleetRepo, Summary: "kit-keys: set " + key, ChangeID: gitwrite.NewChangeID(), Via: gitwrite.ViaAPI}
+	if claims.Email != "" {
+		change.Author = gitwrite.Identity{Name: claims.Email, Email: claims.Email}
+	}
+	paths := []string{}
+	for _, id := range regions {
+		path := "clusters/" + k.FQDN + "/regions/" + id + "/" + VariablesFile
+		content, sha, err := k.Git.Read(ctx, scope, FleetRepo, path)
+		if errors.Is(err, gitwrite.ErrNotFound) {
+			kitKeyRefuse(w, http.StatusConflict, "region-not-seeded", "", "region "+id+" holds no "+VariablesFile+": its root is not seeded yet")
+			return
+		} else if err != nil {
+			gitRefuse(w, "read "+path, err)
+			return
+		}
+		out, err := setKitKey(content, key, *req.Value, change.ChangeID)
+		if err != nil {
+			kitKeyRefuse(w, http.StatusConflict, "bad-document", "", path+": "+err.Error())
+			return
+		}
+		change.Files = append(change.Files, gitwrite.FileChange{Path: path, Op: gitwrite.OpUpsert, Content: out, IfMatch: sha})
+		paths = append(paths, path)
+	}
+	res, err := k.Git.Commit(ctx, change)
+	if err != nil {
+		gitRefuse(w, "commit", err)
+		return
+	}
+	if k.Log != nil {
+		k.Log.Info("kit key set by commit", "key", key, "regions", regions, "commit", res.Commit, "committed", res.Committed)
+	}
+	writeJSON(w, http.StatusAccepted, map[string]any{"commit": res.Commit, "paths": paths})
+}
+
+// setKitKey returns the document with data[key] set to value and the
+// annotation catalyst.openova.io/change-id set to changeID. When data[key]
+// already holds value, it returns the document unchanged, so the commit
+// library makes no commit.
+func setKitKey(content []byte, key, value, changeID string) ([]byte, error) {
+	var doc map[string]interface{}
+	if err := yaml.Unmarshal(content, &doc); err != nil {
+		return nil, fmt.Errorf("not YAML: %w", err)
+	}
+	meta, _ := doc["metadata"].(map[string]interface{})
+	if doc["apiVersion"] != "v1" || doc["kind"] != "ConfigMap" || meta["name"] != "sovereign-variables" {
+		return nil, errors.New("not the ConfigMap sovereign-variables")
+	}
+	data, _ := doc["data"].(map[string]interface{})
+	if current, ok := data[key].(string); ok && current == value {
+		return content, nil
+	}
+	if data == nil {
+		data = map[string]interface{}{}
+	}
+	data[key] = value
+	doc["data"] = data
+	annotations, _ := meta["annotations"].(map[string]interface{})
+	if annotations == nil {
+		annotations = map[string]interface{}{}
+	}
+	annotations["catalyst.openova.io/change-id"] = changeID
+	meta["annotations"] = annotations
+	return yaml.Marshal(doc)
+}
