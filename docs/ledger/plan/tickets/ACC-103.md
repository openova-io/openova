# ACC-103 — The target and grant kinds, their controller and the grant life cycle

## In plain words

**The problem today.** The access plane has no objects to declare who may open a session to what and when. Nothing computes whether a grant is open, nothing ends it when its window closes, and nothing tells the compliance stream that access began or ended. The chart of the access plane renders only its instance card.

**What changes.** Targets and grants are objects in Git with a life cycle that a controller computes from their windows and approvals. Only Git writes them, the controller runs once per Sovereign, and every opening and ending of a grant is an event on the platform stream.

**Done means:**

- A target of kind pod applied through Git becomes Ready, and the controller has made the service account its session pods will use.
- An approved grant is Active inside its window, Scheduled before it and Expired after it, a grant that lacks its approval is Pending, and each change happens within seconds of the window edge, with no timer that polls.
- A grant that its own subject approved, or that anyone but Git writes, is refused by the API server.
- The controller sends grant_activated and grant_ended, registered in the event contract, before it writes the new phase.
- On a two-region Sovereign the controller runs in the primary region only, and the other region reaches it through a ClusterMesh Service.
- A Sovereign that already runs the access chart receives the two definitions on its next upgrade.
- Gate check ACC-G13 is required and runs on the cloud environments.

The rest of this ticket is the exact instruction for the model that does the work.

`platform/guacamole/chart` (Blueprint `bp-guacamole`, kit slot 52) carries the definitions `AccessTarget` (spec.kind `pod` only) and `AccessGrant` of group `access.openova.io/v1alpha1` in `crds/`, with their CEL rules, and renders the ValidatingAdmissionPolicy `access-kinds-writers` with its binding in `Deny`: only Flux (`flux-system:kustomize-controller`) writes the spec of a target or a grant. ## 3. The model (the law)
1. **Two definitions.** `platform/guacamole/chart/crds/accesstarget.yaml` and `crds/accessgrant.yaml`, namespaced, version `v1alpha1`, with the status subresource. AccessTarget: `spec.kind` (enum `[pod]`, immutable), `displayName`, `pod.selector`, `policy.approval.required` (default true), `policy.approval.count`, `policy.maxDuration` (5m to 12h); CEL: `spec.pod` is required for kind pod. AccessGrant: `targetRef`, `subject`, `window` (each immutable), `account` (immutable), `reason`, `ticket`, `suspended` with `suspendReason`, `approvals` (`by`, `at`); CEL: `notAfter` later than `notBefore`; a suspended grant has a reason; no approval by the grant's own subject (message `an approval may not be given by the grant's own subject`). No field of a later package (requesters, approvers, recording, controls, break-glass, other kinds).
2. **Writer lock.** `templates/admission-kinds.yaml`: policy `access-kinds-writers` on create, update and delete of `accesstargets`, `accessgrants` and `accesssessions`; it admits Flux, an update that leaves `spec` unchanged (the controller's status writes), the garbage and namespace collectors, and for sessions the controller only. Its message names the kind and `may be written only by Git through the Catalyst API`. The binding's `validationActions` is `[Deny]` from the start: these kinds have no earlier writer.
3. **Region rule.** The helper `bp-guacamole.accessActive` is true when `access.enabled` and (`access.crossRegion.enabled` is false or the role is `primary`). The Deployment `access-controller`, its ServiceAccount, ClusterRole, ClusterRoleBinding, leader-election Role and RoleBinding render when that helper is true and the image digest is set (`bp-guacamole.controllerRendered`). The Service `access-controller` (port 8080 named `http`) and the writer lock render with `access.enabled` in every region; with `access.crossRegion.enabled` the Service carries `service.cilium.io/global: "true"` and `service.cilium.io/shared` `"true"` on the primary and `"false"` on the secondary. `templates/crossregion-netpol.yaml` renders the CiliumNetworkPolicy `access-controller-crossregion-ingress` with `access.crossRegion.enabled`, a peer cluster and the API `cilium.io/v2`: it admits the peer clusters' `bp-oidc-gate` pods of namespace `oidc-gate` to port 8080 of the controller's pods.
4. **Values.** The three values of the top-level key `crossRegion` move under `access.crossRegion` unchanged; the top-level key is gone. `access` gains `sovereignFQDN`, `regionID`, `controller.image` (`repository`, `digest`), `controller.replicas` (1), `controller.resources`, `session.deniedTargetNamespaces` (`openbao`, `kube-system`, `flux-system`, `guacamole`) and `nats.url` (`nats://nats-jetstream.nats-system.svc.cluster.local:4222`, the namespace of slot 07). A value is added only with its reader: `access.hostname` and the session, recording, OpenBao and review values arrive with the packages that read them.
5. **Image.** `bp-guacamole.registryImage` takes a digest, not a tag; a digest that is not `sha256:` and 64 hex digits fails the render. `global.imageRegistry` still moves the registry host. The digest is empty in Git until the build of `main` writes it; until then the chart renders no controller.
6. **Target controller.** For every target: a target in a denied namespace gets `Ready` and `ServiceAccountReady` False with reason `NamespaceNotAllowed`; otherwise it makes sure the ServiceAccount `access-session` (no token mounted) exists in the release namespace and sets both conditions True with reason `Present`. It writes only the status.
7. **Grant controller.** The phase rules in order: target missing, window longer than `maxDuration`, self-approval, a repeated approver, or an account on a target of kind pod give `Invalid` with a reason; then `Suspended`; `Expired` from `notAfter`; `Pending` while approvals are fewer than the target requires; `Scheduled` before `notBefore`; else `Active`. It requeues with `RequeueAfter` at the next window edge (no ticker), and a change of a target reconciles its grants. Entering `Active` sends `grant_activated`; leaving it sends `grant_ended` with the new phase in lower case as the reason (`expired`, `suspended`, `invalid`, `pending`), and a grant deleted while Active gives `deleted`. The send waits for the stream's acknowledgement through `natsbus.Publisher.SendCloudEvent` (CTL-320); a failed send returns the error, so the status keeps its old phase and the reconcile is retried with the same envelope id.
8. **Events.** `internal/events/events.go` holds the payloads; the envelope source is `access-controller/<sovereignFQDN>/<regionID>`. Both subjects are registered in `docs/contracts/C3-event-subjects.yaml`, owner ACC, producer `access-controller`.
9. **Rights.** The ClusterRole reads targets and grants and writes only their `status`; it gets and creates ServiceAccounts; the Role holds the leader lease. No write on `spec`.
10. **Slot 52.** The values gain `access.sovereignFQDN: ${SOVEREIGN_FQDN}`, `access.regionID: '${SOVEREIGN_REGION_CANONICAL_LABEL:-}'` and `access.crossRegion` with the three substitutions the top-level key had. `install.crds` and `upgrade.crds` are `CreateReplace`: Helm creates `crds/` only on an install unless the release says so, and every Sovereign that already runs this slot is upgraded, not installed. `dependsOn` does not change.
11. **Build.** `.github/workflows/access-controller-build.yaml`, the shape of `useraccess-controller-build.yaml`: the job `test` (go vet, `go test -race`) on pull requests and pushes that change the controller; on `main` the job `build` builds `core/controllers/access/Containerfile`, signs and attests the image, writes `access.controller.image.digest` with yq v4.44.3, commits with the deploy-bump action and dispatches `blueprint-release` for the chart.
12. **Gate check.** `check_acc_g13.go` registers ACC-G13 with eight steps, in a namespace `acc-g13-<run>` of the primary region, applied as the Flux account: the target is Ready within 30 seconds; a self-approved grant is refused by the API server; a grant created as the cluster administrator is refused by the writer lock; an approved grant inside its window is Active within 10 seconds; a grant without approval is Pending; a grant whose window opens in 60 seconds is Scheduled, then Active within 10 seconds of `notBefore`; a grant with a window of 90 seconds is Expired within 10 seconds of `notAfter`; no pod of the controller runs outside the primary region. It deletes the namespace at the end. The fixtures are `tests/acceptance/sovereign/fixtures/access/g13/{target,grant-approved,grant-unapproved,grant-self-approved}.yaml`. In `docs/ledger/gates.yaml` ACC-G13 becomes `state: required` with `implementation:` that file.
13. **Guard records.** The polling guard lists the one `RequeueAfter` of `grant_controller.go` with the reason "clock event". Network guard G2 names `templates/crossregion-netpol.yaml` as an exception: a NetworkPolicy of the policy chart cannot admit a ClusterMesh peer. The two generated files `docs/generated/bootstrap-slots.md` and `docs/generated/custom-resources.md` are written by their generators.

+// Phase computes the phase of a grant by the rules of the access design, in
+// their order: Invalid, Suspended, Expired, Pending, Scheduled, Active. target
+// is nil when the grant's target does not exist. reason is set for Invalid.
+func Phase(g *accessv1.AccessGrant, target *accessv1.AccessTarget, now time.Time) (phase, reason string, err error) {
+	if target == nil {
+		return accessv1.PhaseInvalid, accessv1.ReasonTargetNotFound, nil
+	}
+	longest, err := target.MaxDuration()
+	if err != nil {
+		return "", "", err
+	}
+	self, twice, seen := false, false, map[string]bool{}
+	for _, a := range g.Spec.Approvals {
+		self = self || a.By == g.Spec.Subject.Email
+		twice = twice || seen[a.By]
+		seen[a.By] = true
+	}
+	w := g.Spec.Window
+	switch {
+	case w.NotAfter.Sub(w.NotBefore.Time) > longest:
+		return accessv1.PhaseInvalid, accessv1.ReasonWindowTooLong, nil
+	case self:
+		return accessv1.PhaseInvalid, accessv1.ReasonSelfApproval, nil
+	case twice:
+		return accessv1.PhaseInvalid, accessv1.ReasonDuplicateApprover, nil
+	case target.Spec.Kind != accessv1.KindPod || g.Spec.Account != "":
+		// A target of kind pod offers no account; it is the only kind.
+		return accessv1.PhaseInvalid, accessv1.ReasonAccountNotAllowed, nil
+	case g.Spec.Suspended:
+		return accessv1.PhaseSuspended, "", nil
+	case !now.Before(w.NotAfter.Time):
+		return accessv1.PhaseExpired, "", nil
+	case target.ApprovalRequired() && len(g.Spec.Approvals) < target.ApprovalCount():
+		return accessv1.PhasePending, "", nil
+	case now.Before(w.NotBefore.Time):
+		return accessv1.PhaseScheduled, "", nil
+	}
+	return accessv1.PhaseActive, "", nil
+}

+// requeueAfter is the time to the next edge of the window that can change the
+// phase, or 0 when time changes it no more.
+func requeueAfter(g *accessv1.AccessGrant, phase string, now time.Time) time.Duration {
+	if phase != accessv1.PhasePending && phase != accessv1.PhaseScheduled && phase != accessv1.PhaseActive {
+		return 0
+	}
+	for _, edge := range []time.Time{g.Spec.Window.NotBefore.Time, g.Spec.Window.NotAfter.Time} {
+		if now.Before(edge) {
+			return edge.Sub(now)
+		}
+	}
+	return 0
+}

+	case phase == accessv1.PhaseActive && was != accessv1.PhaseActive:
+		if err := r.send(ctx, key, events.SubjectGrantActivated, activated(&g)); err != nil {
+			return ctrl.Result{}, err
+		}
+		next.ActivatedAt, next.EndedAt = &at, nil
+	case was == accessv1.PhaseActive && phase != accessv1.PhaseActive:
+		if err := r.send(ctx, key, events.SubjectGrantEnded, ended(&g, strings.ToLower(phase))); err != nil {
+			return ctrl.Result{}, err
+		}
+		next.EndedAt = &at
+	}
+	if !equality.Semantic.DeepEqual(next, g.Status) {
+		g.Status = next
+		if err := r.Status().Update(ctx, &g); err != nil {
+			return ctrl.Result{}, err
+		}
+	}
+	r.settle(key, phase, &g)
+	return ctrl.Result{RequeueAfter: requeueAfter(&g, phase, now)}, nil
+}

+// gone sends grant_ended for a deleted grant that this process saw Active.
+func (r *GrantReconciler) gone(ctx context.Context, key types.NamespacedName) error {
+	r.mu.Lock()
+	last, ok := r.active[key]
+	r.mu.Unlock()
+	if !ok {
+		return nil
+	}
+	last.Reason = events.ReasonDeleted
+	if err := r.send(ctx, key, events.SubjectGrantEnded, last); err != nil {
+		return err
+	}
+	r.mu.Lock()
+	delete(r.active, key)
+	delete(r.unsettled, key)
+	r.mu.Unlock()
+	return nil
+}
+
+// send sends one event of a grant and waits for its acknowledgement. The
+// envelope of an unsettled transition with the same subject is sent again.
+func (r *GrantReconciler) send(ctx context.Context, key types.NamespacedName, subject string, data any) error {
+	r.mu.Lock()
+	if r.unsettled == nil {
+		r.unsettled = map[types.NamespacedName]sent{}
+	}
+	s, ok := r.unsettled[key]
+	r.mu.Unlock()
+	if !ok || s.subject != subject {
+		ce, err := events.Envelope(subject, r.Source, data)
+		if err != nil {
+			return err
+		}
+		s = sent{subject: subject, ce: ce}
+		r.mu.Lock()
+		r.unsettled[key] = s
+		r.mu.Unlock()
+	}
+	sendCtx, cancel := context.WithTimeout(ctx, sendTimeout)
+	defer cancel()
+	if err := r.Events.SendCloudEvent(sendCtx, s.ce); err != nil {
+		return fmt.Errorf("grant %s: send %s: %w", key, subject, err)
+	}
+	return nil
+}
+
+// settle records the phase that was written for a grant.
+func (r *GrantReconciler) settle(key types.NamespacedName, phase string, g *accessv1.AccessGrant) {
+	r.mu.Lock()
+	defer r.mu.Unlock()
+	if r.active == nil {
+		r.active = map[types.NamespacedName]events.GrantEnded{}
+	}
+	delete(r.unsettled, key)
+	if phase == accessv1.PhaseActive {
+		r.active[key] = ended(g, "")
+	} else {
+		delete(r.active, key)
+	}
+}
+
+func activated(g *accessv1.AccessGrant) events.GrantActivated {
+	approvers := make([]string, 0, len(g.Spec.Approvals))
+	for _, a := range g.Spec.Approvals {
+		approvers = append(approvers, a.By)
+	}
+	return events.GrantActivated{
+		Namespace: g.Namespace, Grant: g.Name, Target: g.Spec.TargetRef.Name, Subject: g.Spec.Subject.Email,
+		Account: g.Spec.Account, Reason: g.Spec.Reason, Ticket: g.Spec.Ticket,
+		NotBefore: events.Time(g.Spec.Window.NotBefore.Time), NotAfter: events.Time(g.Spec.Window.NotAfter.Time),
+		Approvers: approvers,
+	}
+}
+
+func ended(g *accessv1.AccessGrant, reason string) events.GrantEnded {
+	return events.GrantEnded{Namespace: g.Namespace, Grant: g.Name, Subject: g.Spec.Subject.Email, Reason: reason}
+}

+	if err := r.Get(ctx, req.NamespacedName, &t); err != nil {
+		return ctrl.Result{}, client.IgnoreNotFound(err)
+	}
+	before := t.DeepCopy().Status
+	var failed error
+	status, reason, message := metav1.ConditionTrue, reasonPresent, fmt.Sprintf("service account %s/%s exists", r.SessionNamespace, SessionServiceAccount)
+	switch {
+	case slices.Contains(r.DeniedNamespaces, t.Namespace):
+		status, reason = metav1.ConditionFalse, reasonNamespaceNotAllowed
+		message = fmt.Sprintf("a target of kind %s may not be in namespace %s (access.session.deniedTargetNamespaces)", t.Spec.Kind, t.Namespace)
+	default:
+		if failed = r.ensureServiceAccount(ctx); failed != nil {
+			status, reason, message = metav1.ConditionFalse, reasonWriteFailed, failed.Error()
+		}
+	}
+	for _, typ := range []string{accessv1.ConditionServiceAccountReady, accessv1.ConditionReady} {
+		meta.SetStatusCondition(&t.Status.Conditions, metav1.Condition{
+			Type: typ, Status: status, Reason: reason, Message: message, ObservedGeneration: t.Generation,
+		})
+	}
+	t.Status.ObservedGeneration = t.Generation
+	if !equality.Semantic.DeepEqual(before, t.Status) {
+		if err := r.Status().Update(ctx, &t); err != nil {
+			return ctrl.Result{}, err
+		}
+	}
+	return ctrl.Result{}, failed
+}

+// ensureServiceAccount creates the session service account when it is absent.
+func (r *TargetReconciler) ensureServiceAccount(ctx context.Context) error {
+	key := types.NamespacedName{Namespace: r.SessionNamespace, Name: SessionServiceAccount}
+	var sa corev1.ServiceAccount
+	err := r.Reader.Get(ctx, key, &sa)
+	if err == nil || !apierrors.IsNotFound(err) {
+		return err
+	}
+	no := false
+	sa = corev1.ServiceAccount{
+		ObjectMeta: metav1.ObjectMeta{Name: key.Name, Namespace: key.Namespace, Labels: map[string]string{
+			"app.kubernetes.io/managed-by": "access-controller",
+		}},
+		AutomountServiceAccountToken: &no,
+	}
+	if err := r.Create(ctx, &sa); err != nil && !apierrors.IsAlreadyExists(err) {
+		return fmt.Errorf("create service account %s: %w", key, err)
+	}
+	return nil
+}

+// watch applies the grants as the Flux account and reads their phases once a
+// second until the scheduled one is Active and the expiring one Expired, or
+// until 12 seconds after the later of those two window edges.
+func (c accG13Check) watch(ctx context.Context, region kube.Region, ns string, grants []*accG13Grant, fill func(*accG13Grant) (string, error), ev Evidence) (time.Time, error) {
+	docs, windows := []string{}, map[string]string{}
+	for _, g := range grants {
+		m, err := fill(g)
+		if err != nil {
+			return time.Time{}, err
+		}
+		docs, windows[g.name] = append(docs, m), g.from.Format(time.RFC3339)+" to "+g.to.Format(time.RFC3339)
+	}
+	applied := c.now()
+	ev["windows"], ev["applied"] = windows, applied.UTC().Format(time.RFC3339)
+	if _, err := c.kubectl(region, ctx, strings.NewReader(strings.Join(docs, "\n---\n")), append(accG13Apply, "-f", "-")...); err != nil {
+		return applied, fmt.Errorf("apply the grants as %s: %w", accG13Flux, err)
+	}
+	scheduled, expiring := grants[2], grants[3]
+	end := expiring.to
+	if scheduled.from.After(end) {
+		end = scheduled.from
+	}
+	end = end.Add(accG13Within + 2*time.Second)
+	seen := map[string][]accG13Phase{}
+	ev["seen"] = seen
+	for {
+		var list kube.List
+		if err := c.get(ctx, region, &list, "accessgrants", "-n", ns); err != nil {
+			return applied, err
+		}
+		now := c.now()
+		for _, o := range list.Items {
+			for _, g := range grants {
+				if p := o.Str("status", "phase"); o.Name() == g.name && p != "" && (len(g.seen) == 0 || g.seen[len(g.seen)-1].Phase != p) {
+					g.seen = append(g.seen, accG13Phase{Phase: p, At: now.Sub(applied).Seconds(), at: now})
+					seen[g.name] = g.seen
+				}
+			}
+		}
+		if slices.Contains(accG13Phases(scheduled), "Active") && slices.Contains(accG13Phases(expiring), "Expired") || !now.Before(end) {
+			return applied, nil
+		}
+		if err := c.sleep(ctx, time.Second); err != nil {
+			return applied, err
+		}
+	}
+}

+func accG13Phases(g *accG13Grant) []string {
+	out := []string{}
+	for _, p := range g.seen {
+		out = append(out, p.Phase)
+	}
+	return out

+// accG13Order wants phase a read (when a is not empty) and then phase b, and b
+// read first no later than 10 seconds after edge.
+func accG13Order(g *accG13Grant, a, b string, edge time.Time, ev Evidence) error {
+	ev[g.name] = g.seen
+	names := accG13Phases(g)
+	ia, ib := slices.Index(names, a), slices.Index(names, b)
+	switch {
+	case ib < 0 || (a != "" && (ia < 0 || ib < ia)):
+		return fmt.Errorf("grant %s went through %v, want %s", g.name, names, strings.TrimPrefix(a+" and then "+b, " and then "))
+	case g.seen[ib].at.After(edge.Add(accG13Within)):
+		return fmt.Errorf("grant %s was %s %.0f seconds after %s, more than %s", g.name, b, g.seen[ib].at.Sub(edge).Seconds(), edge.UTC().Format(time.RFC3339), accG13Within)
+	}
+	return nil
+}
