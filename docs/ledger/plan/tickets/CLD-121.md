# CLD-121 — Providers routes

## In plain words

**The problem today.** The console has no way to ask the API which clouds a Sovereign can be built on, what a cloud offers or which cloud the Sovereign itself runs on. So the wizard keeps its own lists of providers, regions and machine sizes in its code, and they drift from the provider packs and from the installation documents an operator adds.

**What changes.** Three read routes answer from the provider packs of the image and the installation documents of the cluster: the list of clouds, the effective profile of one cloud, and the effective profile of the Sovereign itself. A gate check proves on every region that the list matches the packs and documents.

**Done means:**

- A signed-in session can list the clouds; a pack that needs an installation appears only through an installation document, and a cloud that is not proven appears only when all are asked for.
- The profile of one cloud, alone or merged with a named installation document, and the profile of the Sovereign itself are served; an unknown cloud or installation answers 404, and a Sovereign without a cloud profile answers 503.
- A profile that fails its schema answers 500 with the error profile-invalid and the cloud it belongs to; a cluster whose installation documents cannot be read answers 500 installations-unreadable, never an empty list.
- No answer of the three routes holds a credential value.
- Gate check CLD-G07 is required: on every region the list holds exactly the packs of the image and the installation documents of the cluster.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The new package `products/catalyst/bootstrap/api/internal/providersapi` serves three read routes. `GET /api/v1/providers` lists one entry per pack profile whose `requiresInstallation` is not set and one per installation document (`id` is `<provider>` or `<provider>/<installation>`), sorted by `id`, and without `?include=all` only the entries whose `lifecycle` is `proven`. `GET /api/v1/providers/{provider}` answers the `spec` of the pack profile, merged with the installation document that `?installation=<name>` names. `GET /api/v1/sovereign/cloud-profile` answers the effective profile of the Sovereign the API runs on (`CLOUD_PROVIDER`, `CLOUD_INSTALLATION`). The routes are registered in the session group of `POST /api/v1/deployments` by `cmd/api/routes_providers.go` and `cmd/api/routes_sovereign.go`, and `cmd/api/testdata/routes.golden` records them on chain 2. Gate check CLD-G07 (`tests/acceptance/sovereign/internal/suite/check_providers.go`) is `required`: on every region, `GET /api/v1/providers?include=all` lists exactly the ids that the packs of the image and the installation ConfigMaps of the cluster give. A person sees it in the tests of package `providersapi`, in the route table, and in the gate record. The wizard reads these routes in CLD-122.

## 3. The model (the law)
1. **Two sources, nothing else.** The pack profiles are read with `cloudprofile.Load` below `cloudprofile.DefaultDir` (`/infra/providers`, copied into the image by `products/catalyst/bootstrap/api/Containerfile` line 181). The installation documents are the ConfigMaps of namespace `catalyst-system` labelled `catalyst.openova.io/cloud-installation=true`, key `profile.yaml` (the constants of `products/catalyst/bootstrap/api/internal/cloudprofile/installation.go`), read by one `List` per request through `jobauth.InCluster`. Not through the informer: the cache strips the `data` of every ConfigMap (`products/catalyst/bootstrap/api/internal/k8scache/factory.go` lines 2165 to 2167). A labelled ConfigMap without the key is an error, never skipped.
2. **The list.** An entry is `{id, provider, installation, displayName, lifecycle, credentialSource}`. Every installation document is parsed (`cloudprofile.Parse`) and merged over the pack its `spec.extends` names (`cloudprofile.Merge`); a pack that sets `requiresInstallation` is listed only through a document.
3. **One profile.** `GET /api/v1/providers/{provider}` answers the pack's `spec`; with `?installation=<name>` the merged `spec` of the document of that name that extends that pack. Errors: 404 `{"error":"unknown-provider"}`, 404 `{"error":"unknown-installation"}`.
4. **The Sovereign's profile.** `GET /api/v1/sovereign/cloud-profile` answers `cloudprofile.ForSovereign` with a reader that takes the document by its `metadata.name` from the same `List`. Error: 503 `{"error":"cloud-profile-missing"}` when `CLOUD_PROVIDER` is empty or names no pack; any other error is 500 `profile-invalid`.
5. **Errors of the read.** 500 `{"error":"profile-invalid","provider":"<name>","detail":"…"}` when a pack or a document fails its schema or a document extends an unknown pack. One error is added beyond the route contract: 500 `{"error":"installations-unreadable","detail":"…"}` when the ConfigMaps cannot be listed, because an unreadable cluster must never answer an empty list.
6. **No credential value.** A route answers the typed `spec`, never a ConfigMap: a credential field carries its `key`, `label`, `secret` and `required` and no value. Every test answer is checked for a value placed beside the document in its ConfigMap.
7. **Access.** The three routes sit in the session group (chain 2 of `routes.golden`: `RequireSessionOrJob`, `OrgScopeGuard`, `agenttoken.Restrict`), without `MothershipOnly`, so they answer on every Sovereign. 401 and 403 come from that group; the package adds no role check. No route writes: their write class is `none`.
8. **CLD-G07.** The check asserts the first clause of the gate per region, and both regions must give the same list, as either may answer. The second clause (a create request without credentials passes validation for an operator-credential pack) is not judged by this check, as CLD-067 left the registry clause of CLD-G06 unjudged: CLD-106 (operator credentials from mounted files) adds that step.
9. **Not changed.** `products/catalyst/bootstrap/api/cmd/api/main.go` (`buildRouter` in `routes.go` makes the routes, as it makes those of CTL-035; `main.go` stays at its line baseline), package `internal/handler`, package `internal/cloudprofile`, and every chart.

+// Installations returns every installation document kept on the cluster.

+// New returns the routes over dir and the documents that list returns.
+func New(dir string, list Installations) *Routes { return &Routes{dir: dir, list: list} }

+// FromCluster lists the installation ConfigMaps through the client that client
+// returns. A client that cannot be built, or a labelled ConfigMap without the
+// key cloudprofile.InstallationKey, is an error, never an empty list.
+func FromCluster(client func() (kubernetes.Interface, error)) Installations {
+	return func(ctx context.Context) ([][]byte, error) {
+		c, err := client()
+		if err != nil {
+			return nil, err
+		}
+		l, err := c.CoreV1().ConfigMaps(cloudprofile.InstallationNamespace).List(ctx, metav1.ListOptions{LabelSelector: cloudprofile.InstallationLabel + "=true"})
+		if err != nil {
+			return nil, err
+		}
+		docs := make([][]byte, 0, len(l.Items))
+		for _, cm := range l.Items {
+			data, ok := cm.Data[cloudprofile.InstallationKey]
+			if !ok {
+				return nil, fmt.Errorf("ConfigMap %s/%s has no key %s", cm.Namespace, cm.Name, cloudprofile.InstallationKey)
+			}
+			docs = append(docs, []byte(data))
+		}
+		return docs, nil
+	}

+		// Load starts its error with the file <dir>/<pack>/profile.yaml.
+		rest, _ := strings.CutPrefix(err.Error(), filepath.Clean(rt.dir)+string(filepath.Separator))
+		name, _, _ := strings.Cut(rest, string(filepath.Separator))
+		if rest == err.Error() || strings.HasPrefix(name, "_") || name == rest {
+			name = ""
+		}
+		return nil, nil, invalid(name, err)
+	}
+	if !installations {
+		return packs, nil, nil
+	}
+	docs, err := rt.list(ctx)
+	if err != nil {
+		return nil, nil, map[string]string{"error": "installations-unreadable", "detail": err.Error()}
+	}
+	var effective []*cloudprofile.Profile
+	for _, data := range docs {
+		doc, err := cloudprofile.Parse(data)
+		if err != nil {
+			return nil, nil, invalid("", err)
+		}
+		pack, ok := packs[doc.Spec.Extends]
+		if !ok {
+			return nil, nil, invalid(doc.Spec.Extends, &cloudprofile.FieldError{Err: cloudprofile.ErrUnknownPack, Path: "spec.extends", Detail: strconv.Quote(doc.Spec.Extends)})
+		}
+		eff, err := cloudprofile.Merge(pack, doc)
+		if err != nil {
+			return nil, nil, invalid(doc.Spec.Extends, err)
+		}
+		effective = append(effective, eff)
+	}
+	return packs, effective, nil
+}

+		write(w, http.StatusOK, pack.Spec)
+	default:
+		for _, p := range installations {
+			if p.Spec.Extends == name && p.Metadata.Name == installation {
+				write(w, http.StatusOK, p.Spec)
+				return
+			}
+		}
+		write(w, http.StatusNotFound, map[string]string{"error": "unknown-installation"})
+	}

+		}
+		if err == nil {

+		}
+		return nil, err

+	case err != nil:
+		write(w, http.StatusInternalServerError, invalid(strings.TrimSpace(os.Getenv(cloudprofile.ProviderEnv)), err))

+	}
