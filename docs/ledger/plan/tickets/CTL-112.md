# CTL-112 — Region scopes of the commit library

## In plain words

**The problem today.** Some intent must be applied in every region, such as the policy mode and the machine policies, and some belongs to the infrastructure of one region, such as a node pool. Both live in the region folders of the fleet repository. The commit library can write there today only with the controllers' scope, which allows every file of every region, so nothing stops a writer from touching another region's files or the files that controllers render.

**What changes.** The commit library gains a scope that allows only the named module folders of the named regions, a helper that lists the regions of a Sovereign, and a helper that writes the same files into every region in one commit. Nothing that runs today calls them yet.

**Done means:**

- A write into a module folder of a listed region is accepted, and a write into another region, another module, the rendered files of a region or the writer-only intent is refused before any call to Git.
- A scope built with no region or no module refuses every write.
- Writing the same files into three regions makes exactly one commit.
- A write into every region is refused with a conflict when the first region's file has changed since it was read, and the other regions' copies are overwritten.
- The new code builds, vets and passes its tests on the pull request, and no existing file of the repository changes.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The commit library `core/controllers/pkg/gitwrite` (import path `github.com/openova-io/openova/core/controllers/pkg/gitwrite`, added by CTL-110) gains the region scopes of contract C4 (`docs/contracts/C4-git-layout-and-commit-library.md`, the paragraph "Region scopes (CTL-112)" and section 2.2). `RegionPlatform(fqdn, modules, regionIDs)` is a scope with robot `catalyst-fleet-bot` that allows exactly `clusters/<fqdn>/regions/<listed region>/platform/<listed module>/**` of the fleet repository. `Regions` lists the region folders of a Sovereign. `WriteAllRegions` writes the same files into every listed region folder in one commit, with compare-and-swap on the copy in the first region in sorted order. The two later uses of contract C4 section 2.2 then have a scope: every-region intent (modules `root`, `policy`, `machine-ops`, every region) and one region's infrastructure intent (module `infrastructure`, one region). Two new files carry the code and its tests. Nothing that runs today calls them; their first users are later packages (SOV-420 among them).

## 3. The model (the law)
The files of this ticket are complete and embedded. These are the rules they implement, so that a reader can check them; you do not write any of it.

1. **The scope.** `func RegionPlatform(sovereignFQDN string, modules, regionIDs []string) Scope` returns `Name` `region-platform`, `Robot` `catalyst-fleet-bot`, and one prefix `clusters/<fqdn>/regions/<region>/platform/<module>/` for each listed region and each listed module. The regions are sorted, the modules are sorted, and each is counted once; the prefixes are in the order region, then module. The prefix ends with `/`, so `platform/<module>.yaml` (a file the application-controller renders for a platform Application) is outside it.
2. **An empty list refuses every commit.** No region or no module gives no prefix. The library's path policy (CTL-110) refuses every path when a scope has no prefix, with `ErrForbiddenPath` and before any network call.
3. **A name never widens the scope.** A Sovereign FQDN, region or module that is empty, `.`, `..`, or holds a `/` gives no prefix. With an invalid FQDN the scope has no prefix at all.
4. **Regions.** `func Regions(ctx context.Context, w Writer, r Repo, sovereignFQDN string) ([]string, error)` lists `clusters/<fqdn>/regions` with `w.List` and the scope `RegionPlatform(fqdn, nil, nil)` (so the robot `catalyst-fleet-bot` reads), and returns the names of the directories in it, sorted. A file in that folder is not a region. A missing folder gives an empty, non-nil slice. An invalid FQDN (rule 3) returns an error that wraps `ErrInvalid`, before any network call.
5. **WriteAllRegions.** `func WriteAllRegions(ctx context.Context, w Writer, sovereignFQDN string, regionIDs []string, c Change) (Result, error)`. The path of each file of `c` is relative to a region folder, for example `platform/policy/mode.yaml`. Each file becomes `clusters/<fqdn>/regions/<region>/<path>` once for each region. The regions are sorted and an ID listed twice counts once. All copies go to one call of `w.Commit`, so they land in one commit or none (CTL-110: one batch call to Gitea).
6. **Compare-and-swap on the first region.** The `IfMatch` of a file is kept on its copy in the first region in sorted order. The copies in the other regions carry no `IfMatch` and are overwritten. When the first region's file changed since the caller read it, the commit fails with `*ConflictError` for that path and nothing is written.
7. **The scope still decides.** `c.Scope` must allow every copy; normally it is `RegionPlatform(fqdn, modules, regionIDs)`. A copy outside it is refused with `ErrForbiddenPath`, and nothing is committed.
8. **Refusals of WriteAllRegions** before any network call: no region, an invalid FQDN or an invalid region ID return an error that wraps `ErrInvalid`. A change with no file returns `ErrInvalid` from `Commit`. `c` itself is not changed.
9. **Result.** `Result.Files` lists the copies region by region in sorted order, and within a region in the order of `c.Files`. When every copy already has the wanted content, no commit is made and `Committed` is false (CTL-110).
10. **Not changed.** No file of CTL-110 changes. The five existing scopes, `Commit`, `Read`, `List` and the fake keep their behaviour. The contract file `docs/contracts/C4-git-layout-and-commit-library.md` already describes these functions and is not changed.
11. **Not in this package.** The scope of the record folder `evidence/` (CMP-071); a pull-request mode (CTL-700); per-robot tokens (CTL-126); every caller (SOV-420 and the other packages that write every-region or infrastructure intent).

package gitwrite

import (
	"context"
	"fmt"
	"path"
	"sort"
	"strings"
)

// The region scopes of contract C4 (docs/contracts/C4-git-layout-and-commit-library.md,
// section 2.2). Intent that every region applies, and intent for one
// region's infrastructure, lives in the region folders of the fleet
// repository, below clusters/<fqdn>/regions/<region-id>/platform/<module>/.
// Each region's sovereign-region Kustomization applies its own folder.

// regionPlatformScope is the Name of a RegionPlatform scope.
const regionPlatformScope = "region-platform"

// RegionPlatform is the scope of intent in the region folders of the fleet
// repository: robot "catalyst-fleet-bot", and one prefix
// "clusters/<fqdn>/regions/<region-id>/platform/<module>/" for each listed
// region and each listed module, regions and modules each sorted.
//
// Every-region intent lists every region (modules "root", "policy",
// "machine-ops"); one region's infrastructure intent lists module
// "infrastructure" and that one region. An empty list of modules or of
// regions gives no prefix, so the scope refuses every commit. A Sovereign
// FQDN, region or module that is empty, ".", "..", or holds a "/" gives no
// prefix either: a name never widens the scope.
func RegionPlatform(sovereignFQDN string, modules, regionIDs []string) Scope {
	s := Scope{Name: regionPlatformScope, Robot: fleetRobot}
	if !validName(sovereignFQDN) {
		return s
	}
	for _, region := range sortedNames(regionIDs) {
		for _, module := range sortedNames(modules) {
			s.Prefixes = append(s.Prefixes, regionDir(sovereignFQDN, region)+"platform/"+module+"/")
		}
	}
	return s
}

// Regions returns the IDs of the region folders of one Sovereign in the
// fleet repository r: the directories directly under
// "clusters/<fqdn>/regions/", sorted. Files in that folder are not
// regions. A missing folder gives an empty slice. Regions reads with the
// robot of RegionPlatform; an FQDN that is not a valid name returns
// ErrInvalid before any network call.
func Regions(ctx context.Context, w Writer, r Repo, sovereignFQDN string) ([]string, error) {
	if !validName(sovereignFQDN) {
		return nil, fmt.Errorf("%w: %q is not a Sovereign FQDN", ErrInvalid, sovereignFQDN)
	}
	entries, err := w.List(ctx, RegionPlatform(sovereignFQDN, nil, nil), r, "clusters/"+sovereignFQDN+"/regions")
	if err != nil {
		return nil, err
	}
	ids := []string{}
	for _, e := range entries {
		if e.IsDir {
			ids = append(ids, path.Base(e.Path))
		}
	}
	sort.Strings(ids)
	return ids, nil
}

// WriteAllRegions commits the files of c into the folder of every region of
// regionIDs, in one commit made by w.Commit.
//
// The path of each file of c is relative to a region folder, for example
// "platform/policy/mode.yaml". It becomes
// "clusters/<fqdn>/regions/<region-id>/<path>" once for each region. The
// regions are sorted, and an ID listed twice counts once. The IfMatch of a
// file applies to its copy in the first region in that order; the copies
// in the other regions carry no IfMatch. So the caller reads the first
// region's file, and the commit fails with *ConflictError when that file
// changed since.
//
// c.Scope must allow every copy; normally it is
// RegionPlatform(fqdn, modules, regionIDs). A copy outside it is refused
// with ErrForbiddenPath, and nothing is committed. Result.Files lists the
// copies region by region in sorted order, and within a region in the
// order of c.Files. No region, or a Sovereign FQDN or region ID that is
// not a valid name, returns ErrInvalid before any network call. c itself
// is not changed.
func WriteAllRegions(ctx context.Context, w Writer, sovereignFQDN string, regionIDs []string, c Change) (Result, error) {
	if !validName(sovereignFQDN) {
		return Result{}, fmt.Errorf("%w: %q is not a Sovereign FQDN", ErrInvalid, sovereignFQDN)
	}
	for _, id := range regionIDs {
		if !validName(id) {
			return Result{}, fmt.Errorf("%w: %q is not a region ID", ErrInvalid, id)
		}
	}
	regions := sortedNames(regionIDs)
	if len(regions) == 0 {
		return Result{}, fmt.Errorf("%w: WriteAllRegions needs at least one region", ErrInvalid)
	}
	files := make([]FileChange, 0, len(regions)*len(c.Files))
	for i, region := range regions {
		for _, f := range c.Files {
			f.Path = regionDir(sovereignFQDN, region) + f.Path
			if i > 0 {
				f.IfMatch = ""
			}
			files = append(files, f)
		}
	}
	all := c
	all.Files = files
	return w.Commit(ctx, all)
}

// regionDir is the folder of one region in the fleet repository, with a
// trailing slash.
func regionDir(sovereignFQDN, region string) string {
	return "clusters/" + sovereignFQDN + "/regions/" + region + "/"
}

// validName reports whether s can be one element of a path: not empty,
// not "." or "..", and without a "/".
func validName(s string) bool {
	return s != "" && s != "." && s != ".." && !strings.Contains(s, "/")
}

// sortedNames returns the valid names of names, sorted, each once.
func sortedNames(names []string) []string {
	var out []string
	for _, n := range names {
		if validName(n) {
			out = append(out, n)
		}
	}
	sort.Strings(out)
	var uniq []string
	for _, n := range out {
		if len(uniq) == 0 || uniq[len(uniq)-1] != n {
			uniq = append(uniq, n)
		}
	}
	return uniq
}
