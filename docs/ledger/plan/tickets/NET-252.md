- Measured: 2026-11-19, 13:50 to 23:46 UTC, two CI runs on hosted runners, one job at a time, no cloud account.
- Outcome: **HTTPS**. A front listener in the Gateway's namespace terminates TLS with the Gateway's own certificates for two host names and meets the pass rule of NET-270 over HTTPS on the public port 443.

## Question

Decision record 0038 (WF2, WF8) builds the firewall on a front listener that the platform writes in front of the Cilium gateway listener. - **HTTPS.** Does a front listener in the Gateway's namespace terminate TLS with the Gateway's certificates for two host names and meet the pass rule over HTTPS: a clean request 200, a cross-site-scripting request 403 and an SQL injection request 403 for both host names, every route of both hosts answering, and a new HTTPRoute served?
