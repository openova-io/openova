# AIP-111 — Move the sidecar, take identity from the gateway, publish quantity

## In plain words

**The problem today.** The only code that records model usage trusts two headers that any caller can set, so a caller can charge its usage to another customer. It turns each request into money with one fixed price and publishes that amount, while the billing engine expects quantities and sets prices itself. It sits in front of a gateway that is being retired, under a name that the platform's acceptance check already refuses.

**What changes.** The code moves to a new service, the model meter. It takes the identity of a request only from the headers the model gateway sets after it has checked the credential, refuses a request without them, and publishes one usage event with token counts and no price on the subject the billing engine reads. The subject is registered, and the build, the tests and the guards follow the new path.

**Done means:**

- The folder of the old metering sidecar no longer exists, and the model meter builds and passes its tests in its own folder.
- A request without the gateway's identity headers is answered with an error, is not forwarded, and produces no usage event.
- A header that a caller sets about a customer or a tenant has no effect on the usage event.
- An answered request produces one usage event that carries token counts and no price, amount or user.
- The usage subject of the model meter is registered in the event-subject contract, and every guard of the repository passes.
- The model meter is tested on every pull request that changes it, and its image is built on main.

The rest of this ticket is the exact instruction for the model that does the work.

## 2. End goal
The folder `core/services/metering-sidecar` is gone. In its place the Go module `core/services/model-meter` (module path `github.com/openova-io/openova/core/services/model-meter`, package `meter` plus `main`) is the model meter: a reverse proxy between the model gateway and the model back ends. It routes a request by its `Host` header to a back end named in the environment variable `BACKENDS`. It takes the identity of the request only from the five headers that `docs/contracts/model-contract.md` section 3 names, and refuses a request without them with HTTP 400 `missing_identity`, without forwarding it. For an unstreamed answer with status 2xx and a usage block it publishes exactly one usage event, `catalyst.usage.recorded.v1`, as a CloudEvents 1.0 envelope with eight attributes whose data holds measures (token counts and one request) and no price, amount, user or agent name, as section 4 of that contract defines. A failed publish is spooled to disk and published again later with the same event identifier. Every request writes one JSON log line and one entry of an in-memory ring of 1,000 requests. A streamed answer is passed through and publishes no event yet (package AIP-112). The shared events package gains `PublishRaw`. The subject is registered in `docs/contracts/C3-event-subjects.yaml`, the build matrix, the pull-request tests, the dependency bot, two guard baselines and the list of deleted paths follow the move.

## 3. The model (the law)
1. No file exists under `core/services/metering-sidecar`. The line `core/services/metering-sidecar` is in `docs/ledger/deleted-paths.txt`.
2. The module `core/services/model-meter` holds exactly the eleven files of the block `AIP-111.patch`, each with the SHA-256 that work step 7 states. Nothing is composed by hand.
3. Identity comes only from `X-Openova-Organization`, `X-Openova-Principal-Kind`, `X-Openova-Principal`, `X-Openova-Alias` and `X-Request-Id`. Every one is required; a request where one is absent or empty gets 400 with the error code `missing_identity`, is not forwarded and publishes no event. No file of the module holds the text `x-customer-id`, `x-tenant-id`, `micro_omr` or `PRICE_MICRO` in any letter case.
4. Routing: a path that does not start with `/v1/` gets 404 (code `not_found`); a `Host` (its port removed) that is not a key of `BACKENDS` gets 421 (code `misdirected_request`); a back end that cannot be reached gets 502 (code `backend_error`). Error bodies have the form `{"error": {"message": "...", "type": "...", "code": "..."}}` of the model contract.
5. At most one usage event per forwarded request: exactly one when the back end answered 2xx with an unstreamed body of at most 8 MiB that holds a `usage` object; none otherwise. It is published after the response is written. Its identifier is a new ULID that the meter makes for the event; it is the JetStream message identifier and the spool file name.
6. The event: subject `catalyst.usage.recorded.v1`; `type` `io.openova.catalyst.usage.recorded.v1`; `source` the value of `EVENT_SOURCE`; `subject` the Organization; data `organization`, `resource` (`kind: llm-model`, `id`: the alias), `occurredAt` and `measures`. The measures follow the mapping table of the model contract, section 4: input is prompt tokens less cached and cache-write tokens, never below 0; a token measure of 0 is left out; `llm.requests` is always 1.
7. The configuration is `LISTEN_ADDR` (default `:8080`), `BACKENDS` (required), `NATS_URL`, `SPOOL_DIR` (default `/var/lib/model-meter/spool`), `EVENT_SOURCE` (required) and `PUBLISH_TIMEOUT` (default `5s`). The variables `NEWAPI_UPSTREAM_URL`, `LISTEN_PORT`, `PRICE_MICRO_OMR_PER_TOKEN`, `NATS_PUBLISH_TIMEOUT`, `TENANT_ID_HEADER` and `CUSTOMER_ID_HEADER` are no longer read. The JSON `/metrics` and `/healthz` routes of the sidecar are removed; the admin listener comes with AIP-113.
8. `core/services/shared/events/nats.go` gains `func (c *NATSConn) PublishRaw(ctx context.Context, subject, msgID string, body []byte) error`, which publishes `body` unchanged with `msgID` as the JetStream message identifier and returns after the acknowledgement. Nothing else in the shared module changes but one comment.
9. `docs/contracts/C3-event-subjects.yaml` gets exactly one new line, at its end, for `catalyst.usage.recorded.v1` (owner BSS, producer `model-meter`, no consumer). The entry of the legacy subject `catalyst.usage.recorded` is not changed.

+// user and no agent name.

+	EventType       = "io.openova.catalyst.usage.recorded.v1"

+	MeterInput      = "llm.tokens.input"

+	MeterOutput     = "llm.tokens.output"
+	MeterRequests   = "llm.requests"
+)
+
+// UsageEvent is the data block of one usage event.
+type UsageEvent struct {
+	ID           string // ULID, also the envelope id and the JetStream message identifier
+	Organization string
+	Alias        string // resource.id
+	OccurredAt   time.Time
+	Measures     []Measure // built by MeasuresFrom
+}
+
+// Measure is one quantity of the event.
+type Measure struct {
+	Meter    string `json:"meter"`
+	Quantity int64  `json:"quantity"`
+}
+
+// MeasuresFrom maps the usage block of the back end to the measures of the event:
+// input is prompt tokens less cached and cache-write tokens, never below 0; cache_read is the
+// cached tokens; cache_write is the cache-write tokens; output is the completion tokens, which
+// include the reasoning tokens. A token measure of 0 is left out; llm.requests is always 1.
+func MeasuresFrom(u Usage) []Measure {
+	var out []Measure
+	add := func(meter string, q int64) {
+		if q > 0 {
+			out = append(out, Measure{Meter: meter, Quantity: q})
+		}
+	}
+	add(MeterInput, u.PromptTokens-u.CachedTokens-u.CacheWriteTokens)
+	add(MeterCacheRead, u.CachedTokens)
+	add(MeterCacheWrite, u.CacheWriteTokens)
+	add(MeterOutput, u.CompletionTokens)

+const maxMillis = 1<<48 - 1
+
+// NewEventID returns a new ULID: 26 characters of Crockford base 32, the first 10 the time in
+// milliseconds, the last 16 eighty random bits.
+func NewEventID() (string, error) {
+	return newULID(time.Now(), rand.Reader)
+}
+
+func newULID(now time.Time, entropy io.Reader) (string, error) {
+	ms := now.UnixMilli()
+	if ms < 0 || ms > maxMillis {
+		return "", errors.New("meter: the time does not fit a ULID")
+	}
+	var random [10]byte
+	if _, err := io.ReadFull(entropy, random[:]); err != nil {
+		return "", fmt.Errorf("meter: read random bits: %w", err)
+	}
+	var out [26]byte
+	for i := 9; i >= 0; i-- {
+		out[i] = crockford[ms%32]
+		ms /= 32
+	}
+	for i := 0; i < 16; i++ {
+		v := 0
+		for k := 0; k < 5; k++ {
+			bit := i*5 + k
+			v = v<<1 | int(random[bit/8]>>(7-bit%8)&1)
+		}
+		out[10+i] = crockford[v]
+	}
+	return string(out[:]), nil
+}

+// Package meter is the model meter: a reverse proxy between the model gateway and the model
+// back ends that publishes one usage event per answered request.
+//
+// The gateway verifies the caller's credential and sends the request here with the identity
+// headers of identity.go. The meter routes the request by its Host header to a back end of
+// BACKENDS, writes the response through to the gateway, reads the usage block of the response,
+// and publishes catalyst.usage.recorded.v1 with quantities and no price
+// (docs/contracts/model-contract.md, sections 3 and 4).
+//
+// Behaviour:
+//
+//  1. A request whose path does not start with /v1/ gets 404. A request whose Host is not a
+//     key of BACKENDS gets 421.
+//  2. A request without one of the identity headers gets 400 missing_identity and is not
+//     forwarded. No usage event is published for it.
+//  3. The response is written through as it arrives. Usage is read from an unstreamed JSON
+//     body of at most MaxBodyBytes. A streamed response (text/event-stream) is passed through
+//     and publishes no event.
+//  4. At most one usage event is published per forwarded request: exactly one when the back
+//     end answered with a 2xx status and a usage block was read, none otherwise. It is
+//     published after the response has been written.
+//  5. Every request, whatever its outcome, produces one JSON log line and one entry in the
+//     ring of the last RingSize requests.

+// Add keeps rec, and drops the oldest record when the ring is full.
+func (r *Ring) Add(rec Record) {
+	r.mu.Lock()
+	defer r.mu.Unlock()
+	if len(r.entries) < r.size {
+		r.entries = append(r.entries, rec)
+		return
+	}
+	r.entries[r.next] = rec
+	r.next = (r.next + 1) % r.size

+// Get returns the newest record of the request identifier.
+func (r *Ring) Get(requestID string) (Record, bool) {
+	r.mu.Lock()
+	defer r.mu.Unlock()
+	n := len(r.entries)
+	for k := 1; k <= n; k++ {
+		i := ((r.next-k)%n + n) % n
+		if r.entries[i].RequestID == requestID {
+			return r.entries[i], true
+		}
+	}
+	return Record{}, false

+				// always reads a plain body.

+			},

+			ErrorHandler:   h.backendFailed,

+// ServeHTTP implements http.Handler.
+func (h *Handler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
+	start := h.now()
+	id, idErr := IdentityFromHeaders(r.Header)
+	rec := Record{RequestID: id.RequestID, Organization: id.Organization, PrincipalKind: id.PrincipalKind,
+		Principal: id.Principal, Alias: id.Alias, Status: StatusRejected}
+	host := strings.ToLower(r.Host)
+	if hp, _, err := net.SplitHostPort(r.Host); err == nil {
+		host = strings.ToLower(hp)
+	}
+	rt, known := h.routes[host]
+	rec.Backend = rt.name
+	switch {
+	case !strings.HasPrefix(r.URL.Path, "/v1/"):
+		rec.Backend = ""
+		rec.HTTPStatus = writeError(w, http.StatusNotFound, "not_found", "the meter serves /v1/ only")
+	case !known:
+		rec.HTTPStatus = writeError(w, http.StatusMisdirectedRequest, "misdirected_request", "no back end is configured for this host")
+	case idErr != nil:
+		rec.HTTPStatus = writeError(w, http.StatusBadRequest, "missing_identity", "an identity header is absent or empty")
+	default:
+		h.forward(w, r, rt, id, &rec, start)
+		return
+	}

+	h.ring.Add(rec)

+// forward sends the request to the back end, then publishes the usage event when one is due.
+func (h *Handler) forward(w http.ResponseWriter, r *http.Request, rt route, id Identity, rec *Record, start time.Time) {
+	ex := &exchange{}
+	rt.proxy.ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), exchangeKey{}, ex)))
+	rec.HTTPStatus = ex.httpStatus
+	rec.Stream = ex.stream
+	if ex.failed || ex.httpStatus < 200 || ex.httpStatus > 299 {
+		rec.Status = StatusError
+	} else {
+		rec.Status = StatusOK
+	}
+	if rec.Status == StatusOK && !ex.stream && ex.usage.Complete {
+		// The response is written; send it on before the publish.
+		_ = http.NewResponseController(w).Flush()
+		h.publish(r.Context(), id, ex.usage, rec)
+	}
+	h.logLine(*rec, ex.usage, start, ex.firstByte)
+	h.ring.Add(*rec)
+}

+func (h *Handler) publish(ctx context.Context, id Identity, u Usage, rec *Record) {
+	evID, err := h.newID()

+// observe is the ModifyResponse hook: it records the status and reads the usage block of an
+// unstreamed 2xx body, then gives the proxy the same bytes to write to the caller.
+func (h *Handler) observe(resp *http.Response) error {
+	ex, _ := resp.Request.Context().Value(exchangeKey{}).(*exchange)
+	if ex == nil {
+		return nil
+	}
+	ex.httpStatus = resp.StatusCode
+	ex.firstByte = h.now()
+	if resp.StatusCode < 200 || resp.StatusCode > 299 {
+		return nil
+	}
+	if strings.HasPrefix(strings.ToLower(resp.Header.Get("Content-Type")), "text/event-stream") {
+		ex.stream = true // metered from AIP-112; passed through untouched until then
+		return nil
+	}
+	orig := resp.Body
+	body, err := io.ReadAll(io.LimitReader(orig, MaxBodyBytes+1))
+	if err != nil {
+		return fmt.Errorf("meter: read the back end's body: %w", err)
+	}
+	if len(body) > MaxBodyBytes {
+		resp.Body = struct {
+			io.Reader
+			io.Closer
+		}{io.MultiReader(bytes.NewReader(body), orig), orig}
+		return nil
+	}
+	if err := orig.Close(); err != nil {
+		h.log.Warn("meter: close the back end's body", "error", err)
+	}
+	resp.Body = io.NopCloser(bytes.NewReader(body))
+	ex.usage = ParseJSON(body)
+	return nil
+}

+// backendFailed is the ErrorHandler of the proxy: the back end could not be reached, or its
+// body could not be read.
+func (h *Handler) backendFailed(w http.ResponseWriter, r *http.Request, err error) {
+	if ex, _ := r.Context().Value(exchangeKey{}).(*exchange); ex != nil {
+		ex.failed = true
+		ex.httpStatus = http.StatusBadGateway
+	}
+	h.log.Warn("meter: the back end failed", "error", err)
+	writeError(w, http.StatusBadGateway, "backend_error", "the back end failed")
+}

+// writeError writes the error body of the model contract and returns the status.

+	}

+	w.Header().Set("Content-Type", "application/json")
+	w.WriteHeader(status)
+	if _, err := w.Write(body); err != nil {
+		slog.Debug("meter: write the error body", "error", err)
+	}
+	return status
+}

+// The JetStream publisher of the usage event, with a disk spool.
+//
+// Design contract:
+//
+//  1. The event is published after the response has been written to the caller, so a slow
+//     publish never delays the caller's bytes.
+//
+//  2. A publish that fails, or that is not acknowledged within PublishTimeout, does not lose
+//     the event. The envelope bytes are written to the spool directory, in a file named by the
+//     event identifier, and DrainSpoolLoop publishes them again with the same identifier until
+//     the bus acknowledges them. The bus keeps one copy of a message published twice.
+//
+//  3. A full disk does not stop the meter. A spool write that fails is counted as dropped and
+//     logged at error level. It is the only path that loses an event.
+
+package meter
+
+import (
+	"context"
+	"encoding/json"
+	"errors"
+	"fmt"
+	"log/slog"
+	"os"
+	"path/filepath"
+	"strings"
+	"sync/atomic"
+	"time"
+)
+
+// Bus publishes one message on a JetStream subject with a message identifier and returns after
+// the acknowledgement. *events.NATSConn of core/services/shared implements it.
+type Bus interface {
+	PublishRaw(ctx context.Context, subject, msgID string, body []byte) error
+}
+
+// Publisher publishes or spools one event; it never blocks the response path.
+type Publisher interface {
+	Publish(ctx context.Context, ev UsageEvent) error
+}
+
+// ErrSpooled is returned by Publish when the event was written to the spool directory for a
+// later publish.
+var ErrSpooled = errors.New("meter: the event was spooled for a later publish")
+
+// SpoolPublisher publishes usage events to JetStream with a disk-spool fallback.
+type SpoolPublisher struct {
+	Bus            Bus // nil: every event is spooled
+	Source         string
+	PublishTimeout time.Duration
+	SpoolDir       string
+
+	// Counters, read with MetricsSnapshot. atomic.Int64 so reads are race-free.
+	publishedOK    atomic.Int64
+	publishFailed  atomic.Int64
+	spooled        atomic.Int64
+	spoolDrained   atomic.Int64
+	spoolDropFatal atomic.Int64
+}
+
+// Publish publishes the event synchronously and returns nil after the acknowledgement. When no
+// bus is configured, or the publish fails, the envelope is written to the spool directory and
+// Publish returns ErrSpooled. Any other error means the event is lost.
+func (p *SpoolPublisher) Publish(ctx context.Context, ev UsageEvent) error {
+	body, err := ev.CloudEvent(p.Source)
+	if err != nil {
+		p.spoolDropFatal.Add(1)
+		slog.Error("meter: the event cannot be encoded and is dropped", "id", ev.ID, "error", err)
+		return err
+	}
+	if p.Bus != nil {
+		pubCtx, cancel := context.WithTimeout(ctx, p.PublishTimeout)
+		err := p.Bus.PublishRaw(pubCtx, Subject, ev.ID, body)
+		cancel()
+		if err == nil {
+			p.publishedOK.Add(1)
+			return nil
+		}
+		p.publishFailed.Add(1)
+		slog.Warn("meter: publish failed, spooling the event", "id", ev.ID, "error", err)
+	}
+	if err := p.spoolEnvelope(ev.ID, body); err != nil {
+		p.spoolDropFatal.Add(1)
+		slog.Error("meter: the event could not be spooled and is dropped", "id", ev.ID, "error", err)
+		return err
+	}
+	p.spooled.Add(1)
+	return ErrSpooled

+// spoolEnvelope writes the envelope bytes to SpoolDir/<id>.json. The file name is the event
+// identifier, so a second spool of the same event overwrites the first.
+func (p *SpoolPublisher) spoolEnvelope(id string, body []byte) error {
+	if p.SpoolDir == "" {
+		return errors.New("meter: no spool directory configured")
+	}
+	name := safeFilename(id)
+	tmp := filepath.Join(p.SpoolDir, name+".tmp")
+	final := filepath.Join(p.SpoolDir, name+".json")
+	if err := os.WriteFile(tmp, body, 0o600); err != nil {
+		return fmt.Errorf("meter: spool write: %w", err)
+	}
+	if err := os.Rename(tmp, final); err != nil {
+		if rmErr := os.Remove(tmp); rmErr != nil {
+			slog.Warn("meter: spool temporary file remove failed", "file", tmp, "error", rmErr)
+		}
+		return fmt.Errorf("meter: spool rename: %w", err)
+	}
+	return nil
+}

+// DrainSpoolLoop drains the spool directory at the given interval until ctx is cancelled.
+func (p *SpoolPublisher) DrainSpoolLoop(ctx context.Context, interval time.Duration) {
+	t := time.NewTicker(interval)
+	defer t.Stop()
+	for {
+		select {
+		case <-ctx.Done():
+			return
+		case <-t.C:
+			p.DrainSpoolOnce(ctx)
+		}
+	}
+}
+
+// DrainSpoolOnce reads the spool directory once and publishes each envelope again, with the
+// event identifier of the envelope as the message identifier. A published envelope's file is
+// removed. When a publish fails the drain stops and the files stay for the next pass. A file
+// that is not an envelope with an identifier is removed and counted as dropped.
+func (p *SpoolPublisher) DrainSpoolOnce(ctx context.Context) {
+	if p.Bus == nil || p.SpoolDir == "" {
+		return
+	}
+	entries, err := os.ReadDir(p.SpoolDir)
+	if err != nil {
+		slog.Warn("meter: spool directory read failed", "dir", p.SpoolDir, "error", err)
+		return
+	}
+	for _, e := range entries {
+		if e.IsDir() || !strings.HasSuffix(e.Name(), ".json") {
+			continue
+		}
+		full := filepath.Clean(filepath.Join(p.SpoolDir, e.Name()))
+		body, err := os.ReadFile(full)
+		if err != nil {
+			slog.Warn("meter: spool file read failed", "file", full, "error", err)
+			continue
+		}
+		var head struct {
+			ID string `json:"id"`
+		}
+		if err := json.Unmarshal(body, &head); err != nil || head.ID == "" {
+			slog.Error("meter: a spooled file is not an envelope, removing it", "file", full)
+			if rmErr := os.Remove(full); rmErr != nil {
+				slog.Warn("meter: spool remove failed", "file", full, "error", rmErr)
+			}
+			p.spoolDropFatal.Add(1)
+			continue
+		}
+		pubCtx, cancel := context.WithTimeout(ctx, p.PublishTimeout)
+		err = p.Bus.PublishRaw(pubCtx, Subject, head.ID, body)
+		cancel()
+		if err != nil {
+			return // still down: leave the files for the next pass
+		}
+		if rmErr := os.Remove(full); rmErr != nil {
+			slog.Warn("meter: spool remove failed", "file", full, "error", rmErr)
+		}
+		p.spoolDrained.Add(1)
+	}
+}

+	return map[string]int64{

+		"publish_failed":   p.publishFailed.Load(),

+	}

+// safeFilename strips path-unsafe characters from an identifier so that the spool file name
+// cannot escape SpoolDir.
+func safeFilename(s string) string {
+	if s == "" {
+		return fmt.Sprintf("anon-%d", time.Now().UnixNano())
+	}
+	var b strings.Builder
+	for _, r := range s {
+		switch {
+		case r >= 'a' && r <= 'z',
+			r >= 'A' && r <= 'Z',
+			r >= '0' && r <= '9',
+			r == '-', r == '_':
+			b.WriteRune(r)
+		default:
+			b.WriteRune('_')
+		}
+	}
+	out := b.String()
+	if len(out) > 200 {
+		out = out[:200]
+	}
+	return out
+}

+// Usage is the quantity block of one response.
+type Usage struct {
+	PromptTokens, CachedTokens, CacheWriteTokens, CompletionTokens, ReasoningTokens int64
+	ToolCalls                                                                       int
+	ResponseModel                                                                   string

+// usageBlock is the "usage" object of an OpenAI chat.completion body.
+type usageBlock struct {
+	PromptTokens        int64 `json:"prompt_tokens"`
+	CompletionTokens    int64 `json:"completion_tokens"`
+	PromptTokensDetails struct {
+		CachedTokens     int64 `json:"cached_tokens"`
+		CacheWriteTokens int64 `json:"cache_write_tokens"`
+	} `json:"prompt_tokens_details"`
+	CompletionTokensDetails struct {
+		ReasoningTokens int64 `json:"reasoning_tokens"`
+	} `json:"completion_tokens_details"`
+}
+
+// ParseJSON reads usage from an unstreamed chat.completion body. A body that is not JSON, or
+// that has no "usage" object, gives a Usage whose Complete is false.
+func ParseJSON(body []byte) Usage {
+	var doc struct {
+		Model   string `json:"model"`
+		Choices []struct {
+			Message struct {
+				ToolCalls []json.RawMessage `json:"tool_calls"`
+			} `json:"message"`
+		} `json:"choices"`
+		Usage *usageBlock `json:"usage"`
+	}
+	if err := json.Unmarshal(body, &doc); err != nil || doc.Usage == nil {
+		return Usage{}
+	}
+	u := Usage{
+		PromptTokens:     doc.Usage.PromptTokens,
+		CachedTokens:     doc.Usage.PromptTokensDetails.CachedTokens,
+		CacheWriteTokens: doc.Usage.PromptTokensDetails.CacheWriteTokens,
+		CompletionTokens: doc.Usage.CompletionTokens,
+		ReasoningTokens:  doc.Usage.CompletionTokensDetails.ReasoningTokens,
+		ResponseModel:    doc.Model,
+		Complete:         true,
+	}
+	for _, c := range doc.Choices {
+		u.ToolCalls += len(c.Message.ToolCalls)
+	}
+	return u
+}
