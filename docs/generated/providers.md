# Provider packs

The provider packs of this repository and their cloud profiles.
A pack is a folder `infra/providers/<name>/` whose name does not start with `_`.
It holds the pack declaration `pack.yaml` and the cloud profile `profile.yaml`.
Their schemas are `infra/providers/_contract/pack.schema.json` and `infra/providers/_contract/cloudprofile.schema.json`.
To change this file, change a `pack.yaml` or a `profile.yaml` and run `python3 scripts/generators/providers.py`.
The check `generated-docs` fails a pull request in which this file is stale.

- A pack profile holds no value of one installation. When a profile sets `requiresInstallation: true`, an installation document that is kept outside this repository supplies its regions, its image and its flavors. Such a value that the pack profile leaves empty reads `from the installation`.
- `not set`: the file does not set the field; the schema gives its default.
- A dash means an empty text, or a list that is empty or not set.
